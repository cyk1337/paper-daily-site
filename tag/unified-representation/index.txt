18:T8f4,The model uses a shared 24-layer bidirectional Transformer backbone with model dimension 512. Inputs are converted into token-level embeddings, processed jointly, mean-pooled, projected to a 768-dimensional embedding, and L2-normalized. Text uses a standard embedding table. Images, video, and audio are each mapped by modality-specific encoders into soft token embeddings that enter the same shared backbone. This is the key difference from classic dual-tower retrieval models: mixed-modal inputs can interact inside the sequence model before pooling.

A central architectural change is the simplified per-layer embedding design. Gemma-style PLE normally uses an additional token lookup table to inject input-conditioned residual information into each layer. Here, the model reuses the main input embeddings and modality encoder outputs instead of maintaining a separate PLE lookup table. Each layer applies a layer-specific projection, normalization, and gating mechanism to inject this information. The ablations indicate that this simplification is not merely cheaper; it also works better for this embedding setting.

Training follows a three-stage curriculum. The early stage emphasizes text-only learning to stabilize language and code representations. Later stages introduce multimodal tasks and broader domains. Distillation from Gemini Embedding 2 is separated from contrastive and regularization objectives: the model first inherits a strong global embedding geometry from the teacher, then undergoes contrastive fine-tuning to adapt the space to its own architecture and retrieval behavior. This separation is important. Pure distillation can preserve teacher structure, but it may overconstrain the student space; contrastive adaptation gives the student a chance to optimize for its own embedding geometry.

The deployment story is also part of the method. The shared backbone is only 271M parameters; adding vision yields 439M, adding audio yields 577M, and the full model is 744M. The system supports selective encoder loading, adjustable visual token budgets, truncatable embedding dimensions, and quantization-aware checkpoints. Evaluation spans seven broad benchmark suites covering text, multilingual text, code, image, video, documents, speech, and environmental sound tasks. The headline claim is that EmbeddingGemma 2 defines a new quality-efficiency Pareto frontier across modalities, often outperforming specialist systems and models that are 2x to 12x larger.

The most useful evidence comes from the ablations. First, simplified PLE outperforms the version with a dedicated lookup table while reducing cost, suggesting that preserving an input-to-layer semantic pathway matters more than maintaining a separate PLE vocabulary. Third, co-training the vision encoder is important; weak adaptation or freezing degrades the shared embedding space. Fourth, contrastive fine-tuning after distillation is better than relying on distillation alone. Fifth, native audio understanding beats an ASR-then-text pipeline, indicating that non-lexical acoustic information contributes materially to embedding quality.
