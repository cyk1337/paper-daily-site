Replace uses only newly generated synthetic data and is already known to collapse quickly. The main focus is selection: generate a candidate synthetic pool, score it with a verifier, and keep only the “good” subset for the next round.

The key move is to model the verifier’s reference distribution explicitly as a biased local observation rather than an approximation to the global truth. Under this view, the selection operator is not a denoiser. It is a directional projection toward the local manifold. Samples are retained in proportion to how well they match the silo’s own support, so repeated selection trims away globally important but locally underrepresented regions. To mitigate this, the authors propose a collaborative verifier framework under a no-raw-data-sharing constraint. Instead of pooled verification, they build proxy reference distributions across silos using Wasserstein geometry. Two constructions are emphasized: geodesic interpolations between local empirical distributions, and Wasserstein barycenters across multiple silos. These proxies are then used as collective references for scoring synthetic samples. The design choice is important. Simple feature averaging, parameter averaging, or majority voting would not preserve distributional geometry well enough, especially for tail coverage and mode structure. Wasserstein proxies are intended to recover a more faithful global reference at the distribution level while respecting silo boundaries. The target behavior is defined through paired anchors: for each prompt q, there is a target-positive response y_q^p and a target-negative response y_q^n. A standard influence-based method would typically average the gradient differences g(q, y_q^p) - g(q, y_q^n) across target pairs and then score each candidate SFT example z by how well its gradient aligns with that averaged direction.

The paper argues that this uniform aggregation is too crude. If the current model already assigns relatively high probability to some positive anchors, those target pairs correspond to nearby behavioral directions that can be strengthened efficiently with a small amount of data. Distant target pairs may still describe the desired behavior semantically, but they are weaker guides for local data selection under a fixed budget.

Concretely, PRISM computes a preference score π_q for each target pair, defined from the model’s normalized probability of the positive anchor relative to the negative anchor. It then uses π_q to weight the gradient difference for that pair, producing a preference-aware target direction. Candidate training examples are scored by the similarity between their influence signal and this weighted target direction. High-scoring examples are those expected to move the model in a direction that increases preference for the desired behavior.

The paper also provides a first-order local analysis: near the current parameter point, PRISM approximates the direction that most efficiently increases target preference per unit data budget. It extends the line of work that connects in-context learning with instruction data selection, especially NUGGETS, but changes the evaluation protocol in three important ways.

First, instead of using a fixed global anchor set for every candidate, wICI builds a dynamic local probe set for each candidate example. The probe set is constructed in three stages: semantic retrieval to find related examples, semantic clustering to avoid near-duplicate probes, and complexity-guided selection to keep the probes challenging enough. This design addresses three failure modes of naive evaluation: unrelated probes add noise, redundant probes waste computation, and trivial probes overestimate demonstration quality.

Second, the paper measures influence through reductions in instruction-following difficulty (IFD). IFD is defined from the gap between conditional and unconditional generation difficulty, and is used as a proxy for how much the model benefits from the instruction. A candidate example is inserted as a one-shot demonstration; if the probe’s IFD decreases, the candidate is considered helpful. This is more informative than a binary success metric because it preserves the magnitude of improvement.

Third, the per-probe influences are aggregated with a normalized cosine-distance weighting scheme. The weighting is meant to emphasize transferable gains rather than over-rewarding memorization on extremely close neighbors. After scoring, the final subset is selected greedily under a diversity constraint based on cosine similarity, so the chosen tuning set is not overly redundant.

Relative to NUGGETS, the differences are clear: local semantically relevant probes instead of a fixed global anchor set, continuous influence scores instead of coarse binary scoring, explicit difficulty-aware evaluation, and a more efficient selection procedure.
