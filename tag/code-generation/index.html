传统的基于规则的变异测试工具会生成大量微不足道、冗余或等效的变异体，而现有的基于 LLM 的方法大多是“测试盲”的，无法推理现有测试已经覆盖了什么。

评利用 LLM 进行测试感知的代码变异生成，属于软件工程领域的应用，对预训练研究启发有限，作为 coding agent 评估的背景知识了解即可。
Nils Kiele,Zainab Saad,Zirui Wang,Steve Drew,Samira Ebrahimi Kahou
