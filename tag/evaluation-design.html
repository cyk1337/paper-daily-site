Same Evidence, Different Target: Decoding How Diagnostic Evidence Bears on Causal Questions from Language-Model States

这篇论文研究一个更细的因果推理问题：同一条诊断证据，对不同 causal target 的含义可能不同。模型如果只看证据措辞、正负倾向或词面重合，可能把同一证据错误地套到另一个因果问题上。作者构造 paired prompts，固定诊断证据不变，只改变因果目标，用 Favors、Challenges、Unresolved、Wrong Target 四类标签测试模型是否真的匹配 evidence 和 target。

评setup 比多数 probing paper 干净，适合借鉴到 reasoning representation 分析；先看 paired-prompt 设计和 pair recovery 指标，正文不必细抠。

Are Online Skill and Memory Modules Always Worth Their Tokens? A Budget-Constrained Study of Web Agents

这篇工作讨论的不是如何再给 web agent 叠一个模块，而是一个更基础的问题：在固定测试时推理预算下，在线 memory / workflow / skill 模块到底值不值它们消耗的 token。很多在线 agent 方法把 actor 之外的开销当成“额外能力”而不是“预算占用”，只报告主 actor 的步数或成功率，却不把技能归纳、记忆检索、工作流注入、验证控制这些辅助调用的 token 一并计入。作者把问题重新表述为预算分配：同样的总 token，是拿去做在线技能/记忆机制，还是直接给 vanilla actor 更多 observe-act 轮次。这个问题对 agent 评测很关键，因为在线模块的收益依赖任务顺序、历史轨迹质量和模块调用频率，而这些都可能让看似更复杂的系统在真实预算约束下并不划算。

评这篇不教你造新 agent，但会提醒你别再拿“外挂模块免费”做实验；只看预算对齐设置和主表就够，很多 test-time scaling 结论会被它重算一遍。
