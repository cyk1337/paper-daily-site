AWM: Answerable Working Memory for Long-Document VQA Agents

An Empirical Study of Reward Specification and Benchmark Reliability in GRPO-based LLM Unlearning

这篇论文研究的不是“如何把某个知识点忘掉”这么简单，而是 GRPO 型 LLM unlearning 里，奖励函数到底在教模型学什么，以及现有 benchmark 是否足以判断模型真的学到了预期行为。作者把问题说得很清楚：在 generative QA 场景里，传统的两个目标——压制目标知识、保留非目标能力——并不能唯一确定模型在 target-adjacent prompt 上该怎么回答。很多问题并不要求模型直接泄露目标知识，但也不该一律拒答；更合理的行为是退到更宽泛的话题层级，给出有用但不泄露的回答。论文要解决的核心问题，就是 reward specification 是否能把这种“broad-topic, non-target, still helpful”的行为真正学出来，以及 RWKU 一类 forgetting benchmark 是否会把 refusal collapse、judge artifact 或残余泄露误判成成功 unlearning。

评非常扎实的 RLHF (GRPO) 机制分析，揭示了 Reward 设计在 Unlearning 任务中的坑（Reward Hacking、策略崩溃），对理解 RL 训练动态和评估指标的局限性极具启发，建议细读实验分析部分。

Le Critique: Privileged Value Functions for LLM Reinforcement Learning

LLM 强化学习中，以 GRPO 为代表的 group-relative 方法通过同一 prompt 采样多条响应来估计优势，优点是不需要单独的 critic 模型、工程简单；缺点是只有序列级信用分配、训练会被最慢的 rollout 拖慢（straggler 效应）、异步场景下 off-policy 程度更高。基于价值函数的方法（如 PPO）理论上能提供 token 级优势并缓解上述问题，但工程复杂度高，且 critic 拟合不好时性能反而不如无 critic 方法，因此在实践中被边缘化。

评值得看 value 设计和吞吐分析；若实验 setup 干净，它会改变“LLM RL 不值得上 critic”的默认判断。
Siddarth Venkatraman,Matthieu Dinot,Laurence Aitchison
