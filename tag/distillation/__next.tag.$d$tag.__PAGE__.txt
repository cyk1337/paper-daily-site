9:T442,Its relevance to pretraining is mainly through training mechanics rather than language modeling objectives. The contribution is not a new LM loss, but a different answer to the memory wall: change the gradient pathway itself instead of only compressing or recomputing activations. That matters for three reasons. First, it pushes local learning from a mostly empirical idea toward a gradient-estimation framework with theory, at least for deep linear networks and residual nonlinear networks near the right regime. Second, the locality definition is operationally meaningful for large-model training: only one block’s activations need to be kept at a time. Third, the LLM finetuning results suggest that first-order local gradient surrogates can beat zeroth-order methods under similar memory budgets, which is a useful signal for low-memory adaptation. The limitation is equally important: the evidence is not yet large-scale from-scratch LLM pretraining. So this is better viewed as a promising training paradigm candidate than as a drop-in replacement for standard pretraining recipes.a:T77d,The method, ProxyProp, partitions a deep transformer into gradient-isolated blocks. For block l, instead of waiting for gradients to flow through all downstream blocks, the method attaches a local proxy network that takes the block output h_l and predicts the final network output. The proxy is trained by distillation against the global model output. The block update is then computed by backpropagating through the proxy, not through the actual downstream stack.

The central idea is not merely to add an auxiliary head. The proxy is meant to estimate the downstream input-output Jacobian seen from that block. In deep linear networks, the paper argues that an optimal linear proxy implicitly recovers the expected linear map from the current representation to the final output, making the local gradient exact. For nonlinear residual networks, the analysis depends on residual parameterization: when skip connections dominate, the downstream mapping is close to identity plus a small perturbation, so the proxy-induced gradient error can be bounded; at initialization, the local gradient can even match the true gradient exactly. This is the main reason the method is positioned for modern residual transformers rather than arbitrary deep architectures.

Operationally, each block can be updated immediately after its forward pass, satisfying the decoupled or unlocked learning setup. Memory savings come from avoiding full-network activation storage and retaining only the local computation graph for one block plus its proxy. Compared with classic local-loss training, ProxyProp is trying to predict the effect of the remaining network on the final output, rather than forcing each block to solve the task directly. Compared with zeroth-order methods such as MeZO, it still uses gradient information, but obtains it through a local surrogate, which is why it can be more compute-efficient at similar memory cost.b:T672,The experiments appear to have two main parts. The first is supervised learning with vision transformers, used as a controlled setting to study the memory-accuracy trade-off under different block partitions. The reported takeaway is that ProxyProp dominates prior local learning baselines across partition choices: for a given memory budget it achieves better accuracy, or for a given accuracy it uses less memory. The important pattern to inspect is how performance degrades as the model is split into more blocks and locality becomes stronger. The claim is that ProxyProp degrades more gracefully, which would support the gradient-approximation story.

The second part is memory-efficient LLM finetuning. Here the comparison to MeZO is the key result. The paper states that ProxyProp achieves better downstream performance at comparable memory cost, even when MeZO is allowed roughly 8x more compute time. That is a meaningful comparison because zeroth-order optimization is often considered when memory is extremely constrained, but it suffers from high variance and slow convergence.

第一部分是 Attention-Decay。做法是在显式 CoT 路径中，对非分隔符的 step tokens 施加逐步增强的 attention suppression。直观上，模型原本可以直接在每个推理词上保留和传播信息；加入 decay 后，这些普通 token 的可访问信息通路被压窄，模型被迫把关键语义压缩到相邻的 separator hidden states 上。这样，separator 不再只是标点，而变成承载步骤摘要的 latent carrier。这个设计和直接引入额外 latent token 不同，它复用了原始词表中的结构 token，因此不需要额外定义固定长度的隐变量槽位。

第二部分是 dual-path distillation。论文同时保留显式路径和隐式学生路径，并在 token-level 与 sequence-level 做多层蒸馏对齐。显式路径提供可监督的 CoT 轨迹，隐式路径学习用更少的 latent anchors 复现这些推理状态。作者强调 online-policy distillation，即蒸馏对象来自模型自身当前策略生成的 latent trajectory，而不是完全离线的教师缓存。这一设计据称能降低训练内存开销，也让学生更贴近推理时真实会走到的状态分布。

第三部分是 Dynamic Implicit Exit。模型学习一个退出信号，根据当前问题复杂度和内部推理状态决定何时停止 latent reasoning 并输出答案。相比固定 latent 步数，这让简单问题可以更早结束，复杂问题保留更深的内部计算。

The central observation is that separator tokens such as newlines, commas, and periods already act as structural aggregation points in attention. The method amplifies that tendency and turns those tokens into semantic anchors.

The first component is Attention-Decay. During training on the explicit reasoning path, the model progressively suppresses attention to non-separator step tokens. This narrows the information pathways through ordinary reasoning words and forces the model to route and compress useful intermediate information into the hidden states of separator tokens. In effect, separators become compact carriers of step-level reasoning summaries. This differs from methods that introduce a fixed number of dedicated latent tokens: Sep-Latent reuses natural vocabulary items and lets the compression structure emerge around them.

The second component is dual-path distillation. An explicit path with textual CoT is kept as a supervised reference, while an implicit student path learns to reproduce the reasoning trajectory using compressed latent anchors. Distillation is applied at both token and sequence levels. The paper further uses online-policy distillation, meaning the model distills from its own current latent trajectories rather than only from an offline teacher cache. The claimed benefit is lower memory cost and better alignment with the states encountered at inference time.

The third component is Dynamic Implicit Exit. The model predicts when to stop latent reasoning based on the current internal state and the difficulty of the query, instead of consuming a fixed latent budget for every example.

The novelty is therefore not a new backbone, but a training framework that combines structural-token anchoring, constrained information flow, explicit-to-implicit distillation, and adaptive stopping.f:T461,The evaluation covers math and commonsense reasoning benchmarks.
