The first layer is SFT. Pistis-27B and Pistis-9B are built on Qwen3.6 and Qwen3.5 respectively. The Thinking variants are trained on structured multimodal reasoning data, while the Agentic variants additionally include agentic trajectories covering long-horizon planning, iterative reasoning, tool use, and mixed text-vision interaction. This stage is important because the paper explicitly notes that on-policy distillation is sensitive to student-teacher overlap and can fail without a strong cold start.

The second layer is IDRL. Instead of using a static weighted sum of distillation and RL losses, or running distillation and RL as separate stages, IDRL alternates between on-policy distillation updates and RL updates within a single training loop. In the distillation step, the student is trained against the teacher distribution on student-generated sequences, giving dense token-level supervision. In the RL step, the policy is optimized against task reward. The motivation is that a static joint loss can create objective interference within the same update, while a purely staged pipeline prevents the two signals from interacting during training. Interleaving is meant to decouple the objectives in time while still allowing them to shape the same evolving policy. The claimed benefits are better exploration, higher retained policy entropy, and more stable optimization.

For long-horizon agentic training, the paper adds PAS, or step-level positive-advantage suppression. This targets a common failure mode in trajectory-level RL: if a trajectory succeeds overall, some ineffective or even wrong intermediate actions may still receive positive credit because they share the trajectory’s positive advantage. PAS suppresses positive advantage on such steps, reducing this hitchhiking effect. The exact formula is not visible from the provided text, but the intent is clear: not every action on a successful trajectory deserves reinforcement.

The third layer is Pistis-Auto-Harnessing. PAH does not change the policy weights or the tool interface. Instead, an Optimization Agent proposes bounded revisions to the inference harness using development trajectories, validates them against a development metric, and keeps only those revisions that improve the metric. The selected harness is then frozen for evaluation. 真正的方法核心是 Tilted-Target DOPD。作者指出，若直接把 DOPD 的 sampled-token surrogate 用在缓存轨迹上，会出现 stationary target 不保真的问题。原因是缓存来自旧的 behavior policy，当 student 更新后，基于缓存 action 估计的 regularizer 不再等价于当前 student 相对目标策略的 KL；即使 student 已经到达理想 shifted policy，loss 仍可能非零，梯度也不会消失，训练会继续把模型推离目标。为了解决这个问题，作者让每个缓存 shift 显式“倾斜”冻结的 behavior policy，构造出一个明确的 tilted target distribution，然后最小化当前 student 到该 target 的 KL。这样做后，至少在缓存状态上，目标是静态且可达的：当 student 匹配 target 时，loss 和梯度都应消失。文中还强调，这个构造保留了 token-level DOPD surrogate 在初始阶段的期望更新方向，因此既继承了原方法的有效起步信号，又修复了离线训练后期的目标漂移。

At a shared token state, the log-probability ratio between the specialist and the pre-stage anchor is treated as the policy shift learned during post-training. This is a useful abstraction because it isolates the incremental behavior change rather than copying the specialist distribution wholesale, and it does not require parameter alignment across teachers.

For multi-capability composition, Lightning Weave aligns these log-ratio shifts on student-generated token states and takes a weighted sum to form a joint shift. Importantly, it composes shifts first and constructs a single target distribution afterward, rather than building separate targets and averaging them later. That means all capability sources jointly shape each student decision at the token level.

The main technical contribution is Tilted-Target DOPD. The paper argues that directly reusing DOPD’s sampled-token surrogate on cached trajectories does not preserve the intended stationary solution. The cache was generated under an older behavior policy, and once the student moves away from that policy, the sampled-action regularizer no longer matches the KL that should be imposed relative to the current student. As a result, even if the student reaches the desired shifted policy, the cached surrogate can still produce non-zero gradients and push the model away from the solution. To fix this, each cached shift is used to explicitly tilt the frozen behavior policy into a target distribution, and training minimizes KL from the current student to that explicit target. This gives the offline objective a proper fixed point: when the student matches the target on cached states, both loss and gradient vanish. The paper also argues that this construction preserves the expected initial update direction of token-level DOPD, so it keeps the useful early-stage signal while repairing the late-stage mismatch.

From a systems perspective, the framework converts expensive online multi-teacher scoring into a one-time offline caching step. With K anchor pairs, naive online OPD may require up to 2K anchor-model evaluations per student rollout. The main novelty is the training recipe rather than the architecture. Stage I, Pure Distillation (PD), differs from standard KD in a simple but important way: it trains only on examples where the uncompressed RAG teacher is correct. Standard distillation would also transfer the teacher’s mistakes. PD uses the teacher only where it provides reliable supervision, giving the compressed model a strong initialization without forcing it to internalize the teacher’s failure modes.

Stage II, Hard Exploration (HE), is the key step. Reinforcement learning is applied only to queries on which the uncompressed RAG fails. This is a targeted exploration strategy. Instead of spending RL budget on the full data distribution, including easy cases already handled well by imitation, the method concentrates optimization on the subset where imitation is provably insufficient. The intended effect is not just error correction. It is to encourage the compressed model to discover computation patterns better suited to dense compressed inputs, and therefore capable of surpassing the token-based teacher.

Methodologically, this is a selective optimization recipe: use high-confidence supervision to enter a good basin, then use exploration only on high-value hard cases. Relative to prior soft-compression work, the differences are threefold: distill only correct teacher responses, apply RL only on teacher-failure cases, and explicitly allow the compressed model to deviate from the teacher rather than treating the teacher as the final upper bound.16:T61b,The evaluation covers five open-domain QA benchmarks and, importantly, extends retrieval depth beyond the common top-5 setting to a much wider range from top-5 to top-30. The headline result is that DEX-Comp achieves performance comparable to, and in some settings better than, the uncompressed RAG baseline while using 16× compressed context and delivering about 4× to 24× inference acceleration. It also outperforms prior soft-compression baselines.

The ablation logic is one of the stronger parts of the paper. Distillation alone yields a competent compressed model, but it does not reliably break the teacher ceiling. RL over the full dataset is less efficient and less stable because it wastes exploration budget on examples that do not need it. The paper also reports generalization across datasets and backbone models, which suggests the recipe is not tied to one specific compressor-decoder pair.
