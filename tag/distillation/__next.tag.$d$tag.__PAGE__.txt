9:Tb9b,方法从 on-policy distillation 出发，但关键不是普通 teacher-student KL，而是“能力组合”的表示方式。作者对每个 specialist 构造一个 anchor pair：一个是 post-training 前的基线模型，一个是经过某种专项训练后的 specialist。对于同一个 token state，specialist 相对 anchor-before 的 log probability ratio 被视为该专项训练带来的 policy shift。这样定义有两个好处。第一，它抽取的是增量能力，而不是把 teacher 的全部分布都搬过来，因此更容易和其他 specialist 的增量叠加。第二，它不要求不同教师参数同构，只要求能在 student 生成的状态上打分。

在多能力组合时，Lightning Weave先把不同 anchor pair 的 log-ratio shift 对齐到 student 的 token states 上，再做加权求和，得到一个联合 shift。这里的设计选择很重要：作者不是分别构造多个 target 再做混合，而是先组合 shift，再构造单一目标分布。这样所有能力源在每个 token 决策点上共同作用，避免后续 target averaging 带来的不一致。

真正的方法核心是 Tilted-Target DOPD。作者指出，若直接把 DOPD 的 sampled-token surrogate 用在缓存轨迹上，会出现 stationary target 不保真的问题。原因是缓存来自旧的 behavior policy，当 student 更新后，基于缓存 action 估计的 regularizer 不再等价于当前 student 相对目标策略的 KL；即使 student 已经到达理想 shifted policy，loss 仍可能非零，梯度也不会消失，训练会继续把模型推离目标。为了解决这个问题，作者让每个缓存 shift 显式“倾斜”冻结的 behavior policy，构造出一个明确的 tilted target distribution，然后最小化当前 student 到该 target 的 KL。这样做后，至少在缓存状态上，目标是静态且可达的：当 student 匹配 target 时，loss 和梯度都应消失。文中还强调，这个构造保留了 token-level DOPD surrogate 在初始阶段的期望更新方向，因此既继承了原方法的有效起步信号，又修复了离线训练后期的目标漂移。

工程上，这个框架把昂贵的多教师在线打分转成一次性缓存。若有 K 个 anchor pair，在线 OPD 需要每条 student rollout 经过最多 2K 个 anchor 模型评分；Lightning Weave则先对缓存轨迹离线打分，之后训练只依赖 student 和缓存分数。这样多能力组合的成本主要前置到数据准备阶段，训练期更接近普通离线蒸馏。

For each specialist, the authors form an anchor pair: a checkpoint before the relevant post-training stage and the resulting specialist after that stage. At a shared token state, the log-probability ratio between the specialist and the pre-stage anchor is treated as the policy shift learned during post-training. This is a useful abstraction because it isolates the incremental behavior change rather than copying the specialist distribution wholesale, and it does not require parameter alignment across teachers.

For multi-capability composition, Lightning Weave aligns these log-ratio shifts on student-generated token states and takes a weighted sum to form a joint shift. Importantly, it composes shifts first and constructs a single target distribution afterward, rather than building separate targets and averaging them later. That means all capability sources jointly shape each student decision at the token level.

The main technical contribution is Tilted-Target DOPD. The paper argues that directly reusing DOPD’s sampled-token surrogate on cached trajectories does not preserve the intended stationary solution. The cache was generated under an older behavior policy, and once the student moves away from that policy, the sampled-action regularizer no longer matches the KL that should be imposed relative to the current student. As a result, even if the student reaches the desired shifted policy, the cached surrogate can still produce non-zero gradients and push the model away from the solution. To fix this, each cached shift is used to explicitly tilt the frozen behavior policy into a target distribution, and training minimizes KL from the current student to that explicit target. This gives the offline objective a proper fixed point: when the student matches the target on cached states, both loss and gradient vanish. The paper also argues that this construction preserves the expected initial update direction of token-level DOPD, so it keeps the useful early-stage signal while repairing the late-stage mismatch.

The paper also studies why cross-model subliminal transfer is weaker than same-model transfer, using diagnostics and interventions.12:T7ab,方法分成两部分：TDES 和 SABA。

TDES（Target-Distilled Edge Scoring）解决父子错配。现有 DDTree 的边选择近似是 parent-agnostic 的：child token 在不同 parent 下贡献相同，只由该位置的 token probability 决定。GRAFT 改成显式给 edge 打分。做法是从 target model 的验证轨迹里蒸馏一个轻量 edge scorer，输入是相邻位置候选节点及其上下文特征，输出该 parent-child transition 被 target 接受的兼容性分数。然后树构建时不再只按各位置 token 概率乘积选路径，而是结合 edge score 进行 parent-conditional 组装。这样保留了 DLM 一次前向产出候选节点的优点，又补上了“节点之间是否能连成 target 偏好的路径”这一层信息。

从机制上看，这一步很像把 target 的局部条件分布偏好压缩成一个便宜的结构预测器。它不是重新跑 target，也不是让 drafter 变成 AR，而是在 assembly 阶段补一个 learned compatibility model。相比直接增大候选集，这种做法更有效，因为问题不是候选 token 不在，而是树结构把它们接错了。

SABA（State-Aware Budget Allocation）解决固定预算失配。作者把每轮 throughput 看成 accepted gain 与 verification overhead 的函数，学习一个按当前 decoding state 选择 tree budget 的策略。直觉上，easy round 本来 acceptance 就长，再加节点收益很快饱和；hard round 适度扩树更值钱，但也不是越大越好。SABA 用当前轮的状态特征预测不同 budget 下的收益，选 throughput 最优预算。这里的关键不是复杂控制器，而是把“树大小”从静态超参变成在线决策变量。

整体上，GRAFT 没有改 DLM 本身，也没有改 target verification 机制，而是专门优化 DLM-based tree assembly 这一层。这种切分是合理的，因为瓶颈正出在 one-pass future distributions 到 executable tree 的映射。13:T781,GRAFT has two components: TDES and SABA.

TDES, or Target-Distilled Edge Scoring, addresses parent-child mismatch. DDTree is effectively parent-agnostic: a child token contributes the same score regardless of which parent path it extends, because scoring is driven by per-position token probabilities. GRAFT instead learns an explicit edge scorer distilled from target-model traces. The scorer takes candidate parent-child pairs from adjacent positions, together with contextual features, and predicts how compatible that transition is with the target model. Tree assembly then uses these edge scores, rather than only the product of marginal token probabilities, to select target-compatible paths under a node budget.

Mechanistically, this is a lightweight structural predictor that compresses local target preferences into a cheap model. It does not rerun the target and does not force the DLM drafter into autoregressive expansion. It patches the missing conditional dependency at the tree-assembly stage. That is the right intervention point, because the failure mode is not merely missing candidate tokens; it is incorrect attachment among already available candidates.

SABA, or State-Aware Budget Allocation, addresses budget misallocation. The paper models per-round throughput as a trade-off between draft gain and verification cost, then chooses the budget conditioned on the current decoding state. Easy rounds already have long accepted prefixes, so larger trees mostly add cost. Hard rounds benefit more from extra nodes, but only up to a saturation point. SABA predicts the utility of different budgets from state features and selects the throughput-optimal one online.

Overall, GRAFT leaves the DLM and the target verification mechanism unchanged. It focuses specifically on the mapping from one-pass future distributions to an executable draft tree. That decomposition is sensible and technically clean.14:T4a2,The main empirical claim is consistent end-to-end throughput improvement with very small overhead. That matters because it suggests the method is not trading away the cost structure of speculative decoding.
