9:T8fd,方法核心是把 teacher 与 student 的预测重写到一个 common support 上。做法分三步。

第一步是序列对齐。作者先用字符级 offset 和 decode 后文本一致性检查，找出 student token 序列与 teacher token 序列中覆盖同一文本子串的 chunk 对齐关系。这样对齐的不是 token id，而是“相同文本跨度”。

第二步是 common-support construction。对每个对齐 chunk，构造一组“文本等价 continuation event”。如果是 1-to-1 chunk，事件可以是两边词表里 decode 成同一字符串的 token 对；如果是 1-to-many 或 many-to-1，事件就变成“一边一个 token，对应另一边一个 token sequence”。关键点在于，sequence event 的概率不是额外建模，而是直接用自回归链式法则，把 chunk 内各步条件概率连乘得到。文中举的例子是 teacher 一个 token“120”对应 student 三个 token“[1][2][0]”；固定前缀 [1][2] 后，可以把 120↔[1][2][0]、121↔[1][2][1] 等都作为显式事件。这样做比 ALM 只保留 observed chunk 更细，因为它把 alternative continuations 也展开到了共同支持集里。

第三步是 residual normalization + uniform matching。显式列出的共同事件之外，其余概率质量都并入一个 residual event。于是 teacher 和 student 都得到定义在同一 support 上的归一化分布，可以统一用一个分布匹配目标训练，不再需要像 X-Token 那样按 tokenizer 覆盖率切换 P-KL/H-KL。这个设计的取舍很清楚：它不追求枚举全部跨词表续写，而是在可计算的 support 上尽量保留结构，再用 residual 保证概率闭合。

从全文看，真正的创新不只是“加了一个 residual”，而是把跨 tokenizer 对齐从 token identity matching 改成 text-equivalent event matching，并且把 one-to-many / many-to-one 情况纳入同一个目标。这样统一后，训练接口更像标准 logits KD，工程上更容易接到现有蒸馏流水线里。

另一个实用点是 top-k distillation。作者发现只取 teacher top-16 或 top-128 token 来构造 support，平均性能只小幅下降，但训练步时显著降低。这说明 CSD 的收益主要来自 teacher 分布头部的结构信息，而不是完整长尾。a:T878,CSD builds a common support of text-equivalent continuation events and matches teacher and student on that support.

Step 1 is sequence alignment. The method aligns student and teacher token ranges that decode to the same text span, using character offsets plus decoded-text consistency checks. The alignment target is therefore shared text, not shared token ids.

Step 2 is common-support construction. For each aligned chunk, CSD defines explicit events corresponding to equivalent textual continuations. In 1-to-1 cases, an event can be a pair of tokens from the two vocabularies that decode to the same string. In 1-to-many or many-to-1 cases, an event becomes a token on one side paired with a token sequence on the other side. The probability of a sequence event is computed directly from the model’s autoregressive conditionals via the chain rule. The example in the paper is a teacher token like “120” aligned with a student sequence “[1][2][0]”; by fixing the within-chunk prefix “[1][2]”, one can enumerate events such as 120↔[1][2][0], 121↔[1][2][1], and so on. This is the key difference from ALM: CSD does not only keep the observed chunk and a catch-all complement, but explicitly represents alternative continuations when they can be mapped onto shared textual outcomes.

Step 3 is residual normalization and uniform matching. Any probability mass outside the selected explicit support is assigned to a residual event. This gives both teacher and student normalized distributions over the same event set, so a single matching objective can be used across chunk types and tokenizer pairs. That removes the need for pair-specific loss selection such as X-Token’s P-KL versus H-KL.

The real contribution is not merely adding a residual bucket. It is the move from token-identity matching to text-equivalent event matching, while covering 1-to-1, 1-to-many, and many-to-1 cases within one formulation. The first is on-policy distillation. The student is initialized from a block-wise calibrated checkpoint, following the Block-AP style recipe from EfficientQAT: starting from RTN quantization, each transformer block is calibrated sequentially with a reconstruction loss so that quantized block outputs match full-precision block outputs. This gives a stable low-bit starting point.

The second component is teacher supervision on the student’s own trajectories. During training, the quantized student samples responses using its quantized forward pass. For every generated prefix h_t = (x, y_{<t}), a frozen full-precision teacher provides the next-token distribution on that exact prefix. This directly addresses prefix mismatch, because the teacher now supervises the contexts the student actually visits, including prefixes that already contain student mistakes.

The key technical idea is candidate-wise Dynamic KL. The authors show that forward KL is better at correcting severe underprediction, while reverse KL is better at suppressing severe overprediction. Instead of choosing one KL direction for the whole distribution, they assign token-wise weights between FKL and RKL based on the teacher/student probability ratio for each candidate token. This is more targeted than a fixed convex combination of the two KLs. The analysis section further shows that two-sided errors are especially common at high-entropy prefixes, which explains why reasoning trajectories become unstable exactly at uncertain intermediate steps.

对比三类训练目标：
1) CE on corpus tokens：直接对语料 token 做交叉熵（等价于把语料当“真值”）。
2) Token-level KD：用 target 在 corpus prefix 下的 next-token 分布 p_T(·|x,y_<t) 做蒸馏；实现上只保留 top-8 token，把其余合并成第 9 类（降低蒸馏开销/噪声），对 drafter 的对应 9-way 分布做 KL/CE。
3) KD + survival gate：gate 只保留那些“在 greedy verification 下会被接受”的位置。直觉是 speculative decoding 的收益来自能被 verifier 接受的位置，因此把 loss 聚焦到这些位置可能更有效。

关键设计是把同一训练语料做四种 response 版本来隔离变量：
- external responses（原始语料，response 由别的模型/人写）
- greedy regenerated responses（用 target 贪心重写 response）
- 两个 matched-length regenerated 版本：因为 regeneration 往往更长，作者分别用 cut（截断到原长度）和 mask-loss（长度外不计 loss）来控制“长度变化”这个混杂因素。

机制解释围绕“标签一致性”展开：regeneration 后，语料 token 与 target greedy token 的一致率大幅上升；在一致的位置，CE 已经把 drafter 推向 target 的 mode，token-level KD 只能提供对非 argmax token 的那点概率质量，边际收益自然变小。对 survival gate 也是类似：当 response 本身就是 target greedy 轨迹时，“哪些位置会 survive”变得更平凡，gate 的区分度下降。11:T76c,核心结论在多个控制变量下保持一致：
- 在 external responses 上，token-level distillation 和 survival gate 都能带来显著 acceptance 提升；
- 一旦换成 greedy regenerated responses，distillation 的增益大幅缩水，只剩小幅提升；gate 的增益基本消失（little or none）。
- 这种缩水不依赖于数据顺序、初始化、position weight、gate 形式、学习率、verifier、decoding temperature 等设置；控制实验会改变缩水幅度，但方向稳定。

在 block 内，Lafa 不是用共享时间的标准 flow matching，而是引入 tokenwise time 的 asynchronous flow。具体地，作者把离散 token 先映射到 embedding 空间，用高斯噪声到 token embedding 的连续路径做 flow matching。不同位置的 token 使用不同的时间进度 τ_i(t)：靠前位置更早接近干净 token，靠后位置更慢。这给了模型一种“块内左到右偏置的双向建模”能力。它不是严格因果，也不是完全对称的双向去噪，而是介于两者之间，既允许块内信息交互，又保留文本顺序结构。这个设计比标准离散 diffusion 或 fully bidirectional masked modeling 更贴近语言的生成结构。

架构上，文章强调 causal attention on the prefix，bidirectional attention within block，并通过异步时间调度让块内不同位置处于不同噪声水平。这样模型在同一次前向中既看到稳定的前缀条件，又能在块内并行更新多个位置。由于 continuation 仍按 block 递进，历史 block 的缓存可以像 AR 一样复用，这是很多非 AR 方法做不到的。

训练上，作者不是只做 flow objective，而是联合 blockwise denoising flow 与 prefix AR prediction。这个联合目标有两个作用。第一，它让从 AR checkpoint 适配到 flow 更自然，因为模型保留了熟悉的 next-token 路径。第二，它实证上增强了 AR 能力，作者将其解释为一种 multi-token prediction effect：flow 训练迫使模型在给定前缀时更好地建模局部未来 token 的联合结构，从而反哺 AR 头。

推理上有三层。第一层是标准的 blockwise parallel flow decoding，利用 prefix cache 并行生成一个 block。第二层是 flow map distillation：把多步 ODE 积分蒸馏成 one-step 或 few-step flow map，减少采样步数，这是连续 flow 相比离散 diffusion 的一个重要优势。第三层是 self-speculative decoding：先用 flow path 快速 draft，再用同一模型的 AR path 验证接受前缀。这里和传统 speculative decoding 的不同点在于，draft 与 verifier 不是两个模型，而是同一模型的两种能力，因此额外参数和部署复杂度更低。

Lafa adopts block-autoregressive factorization: the prefix remains causal, while the continuation is partitioned into fixed-size blocks. This choice has two immediate benefits. First, generation across blocks remains left-to-right, so prefix caching is retained. Second, parallelism is localized within each block, which makes training and inference much easier to implement on top of existing Transformer infrastructure.

Inside a block, Lafa does not use standard flow matching with a single shared time variable for all positions. Instead, it introduces asynchronous flow through tokenwise time. Tokens are first embedded into a continuous space, and flow matching is performed from Gaussian noise to token embeddings. Different positions follow different time schedules τ_i(t): earlier positions move toward clean token embeddings faster, later positions more slowly. This creates a left-to-right bias inside the block without enforcing strict causality. The result is a hybrid inductive bias: bidirectional interaction within the block, but with an ordering preference that better matches language than fully symmetric denoising or fully bidirectional masked modeling.

Architecturally, the model uses causal attention on the prefix and bidirectional attention within the current block, while asynchronous tokenwise time ensures that different positions are denoised at different rates. This allows the model to condition on a stable prefix while updating multiple future positions in parallel. Because continuation still advances block by block, cached history from previous blocks can be reused much like in AR decoding, which is a major practical advantage over many non-AR approaches.

Inference has three layers. First, there is standard blockwise parallel flow decoding with prefix caching. Relative to discrete diffusion LMs such as D3PM/SEDD/MDLM-style approaches, the difference is not only continuous versus discrete state space. - Keep the OPD objective: for each prefix visited by the student, compute token-level rewards from the teacher distribution (implemented over the student top-K candidates), corresponding to minimizing reverse KL from student to teacher on-policy.

So this is better viewed as a promising training paradigm candidate than as a drop-in replacement for standard pretraining recipes.20:T77d,The method, ProxyProp, partitions a deep transformer into gradient-isolated blocks. For block l, instead of waiting for gradients to flow through all downstream blocks, the method attaches a local proxy network that takes the block output h_l and predicts the final network output. The proxy is trained by distillation against the global model output. The block update is then computed by backpropagating through the proxy, not through the actual downstream stack.

The central idea is not merely to add an auxiliary head. The proxy is meant to estimate the downstream input-output Jacobian seen from that block. In deep linear networks, the paper argues that an optimal linear proxy implicitly recovers the expected linear map from the current representation to the final output, making the local gradient exact. For nonlinear residual networks, the analysis depends on residual parameterization: when skip connections dominate, the downstream mapping is close to identity plus a small perturbation, so the proxy-induced gradient error can be bounded; at initialization, the local gradient can even match the true gradient exactly. This is the main reason the method is positioned for modern residual transformers rather than arbitrary deep architectures.

Operationally, each block can be updated immediately after its forward pass, satisfying the decoupled or unlocked learning setup. Memory savings come from avoiding full-network activation storage and retaining only the local computation graph for one block plus its proxy. Compared with classic local-loss training, ProxyProp is trying to predict the effect of the remaining network on the final output, rather than forcing each block to solve the task directly. The first component is Attention-Decay. During training on the explicit reasoning path, the model progressively suppresses attention to non-separator step tokens. This narrows the information pathways through ordinary reasoning words and forces the model to route and compress useful intermediate information into the hidden states of separator tokens. This differs from methods that introduce a fixed number of dedicated latent tokens: Sep-Latent reuses natural vocabulary items and lets the compression structure emerge around them.

The second component is dual-path distillation. An explicit path with textual CoT is kept as a supervised reference, while an implicit student path learns to reproduce the reasoning trajectory using compressed latent anchors. Distillation is applied at both token and sequence levels. The paper further uses online-policy distillation, meaning the model distills from its own current latent trajectories rather than only from an offline teacher cache. The claimed benefit is lower memory cost and better alignment with the states encountered at inference time.

The third component is Dynamic Implicit Exit. The model predicts when to stop latent reasoning based on the current internal state and the difficulty of the query, instead of consuming a fixed latent budget for every example.
