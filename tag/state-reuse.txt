18:T4e6,AdaPLD modifies both stages of reuse-based model-free SD.
1) Adaptive retrieval (lexical-first, semantic fallback): use exact token matching on the most recent token as an anchor to retrieve prior positions in the unified memory (prompt + generated history). Only when lexical retrieval yields no candidates does it invoke semantic retrieval via representation similarity, expanding reachability while preserving the precision/latency profile of lexical matching. Candidates are then reranked by hidden-state similarity to pick an anchor most compatible with the current decoding state.
2) Adaptive reuse (draft tree instead of single span): starting from the selected anchor, it (a) copies a main continuation span when the anchor is lexically matched; (b) adds a small set of branch tokens sampled/selected from the target model’s next-token distribution to hedge ambiguity; (c) performs a successor reuse step to extend branches by one more reused token when alignment exists in memory. The resulting small draft tree is verified in one target-model pass using tree attention.
