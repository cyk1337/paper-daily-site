18:T438,UpLoop uses layer-wise local recurrence. Each selected Transformer layer executes multiple local rounds before passing the hidden state to the next layer. This preserves the pretrained depth hierarchy and avoids the mismatch induced by whole-model or block-level looping.

The second component is gated residual writing. The first round is identical to the original pretrained forward pass. Extra rounds apply hidden-wise gates to the attention and MLP residual branches. These gates are specific to the layer, loop index, and residual branch. Parameters are still shared across loop executions of the same layer, but each refinement step can write with a different strength across hidden channels.

The third component is a depth-aware training objective. Intermediate supervision keeps each recurrent depth decodable, while an improvement objective encourages later rounds to refine earlier ones instead of drifting. This matters because recurrent hidden trajectories can otherwise become poorly controlled, especially when the model is evaluated at a different number of loops.19:T41d,Standard MoE-LoRA writes the adapted weight as W = W0 + Σ g_i B_i A_i, where A_i projects from d dimensions to rank r and B_i maps back. With scalar gates g_i, the router controls magnitude but not orientation; the spatial contribution of each expert is fixed by B_i A_i. A more expressive alternative would be W = W0 + Σ B_i G_i A_i with an r×r transformation G_i per expert, but a fully general G_i is still relatively expensive.

RotMoLE constrains G_i to be a rotation-style transform. For rank 2, a single angle θ_i defines a 2D rotation matrix directly. For r > 2, the method uses a small number of extra parameters to define a temporary rotation plane for each expert, then constructs an r×r rotation matrix R_i within that plane. The final form becomes W = W0 + Σ g_i B_i R_i A_i. The point is to add directional flexibility without paying for a full unconstrained transformation.
