18:T7ab,方法分成两部分：TDES 和 SABA。

TDES（Target-Distilled Edge Scoring）解决父子错配。现有 DDTree 的边选择近似是 parent-agnostic 的：child token 在不同 parent 下贡献相同，只由该位置的 token probability 决定。GRAFT 改成显式给 edge 打分。做法是从 target model 的验证轨迹里蒸馏一个轻量 edge scorer，输入是相邻位置候选节点及其上下文特征，输出该 parent-child transition 被 target 接受的兼容性分数。然后树构建时不再只按各位置 token 概率乘积选路径，而是结合 edge score 进行 parent-conditional 组装。这样保留了 DLM 一次前向产出候选节点的优点，又补上了“节点之间是否能连成 target 偏好的路径”这一层信息。

从机制上看，这一步很像把 target 的局部条件分布偏好压缩成一个便宜的结构预测器。它不是重新跑 target，也不是让 drafter 变成 AR，而是在 assembly 阶段补一个 learned compatibility model。相比直接增大候选集，这种做法更有效，因为问题不是候选 token 不在，而是树结构把它们接错了。

SABA（State-Aware Budget Allocation）解决固定预算失配。作者把每轮 throughput 看成 accepted gain 与 verification overhead 的函数，学习一个按当前 decoding state 选择 tree budget 的策略。直觉上，easy round 本来 acceptance 就长，再加节点收益很快饱和；hard round 适度扩树更值钱，但也不是越大越好。SABA 用当前轮的状态特征预测不同 budget 下的收益，选 throughput 最优预算。这里的关键不是复杂控制器，而是把“树大小”从静态超参变成在线决策变量。

整体上，GRAFT 没有改 DLM 本身，也没有改 target verification 机制，而是专门优化 DLM-based tree assembly 这一层。这种切分是合理的，因为瓶颈正出在 one-pass future distributions 到 executable tree 的映射。19:T781,GRAFT has two components: TDES and SABA.

TDES, or Target-Distilled Edge Scoring, addresses parent-child mismatch. DDTree is effectively parent-agnostic: a child token contributes the same score regardless of which parent path it extends, because scoring is driven by per-position token probabilities. GRAFT instead learns an explicit edge scorer distilled from target-model traces. The scorer takes candidate parent-child pairs from adjacent positions, together with contextual features, and predicts how compatible that transition is with the target model. Tree assembly then uses these edge scores, rather than only the product of marginal token probabilities, to select target-compatible paths under a node budget.

Mechanistically, this is a lightweight structural predictor that compresses local target preferences into a cheap model. It does not rerun the target and does not force the DLM drafter into autoregressive expansion. It patches the missing conditional dependency at the tree-assembly stage. That is the right intervention point, because the failure mode is not merely missing candidate tokens; it is incorrect attachment among already available candidates.

SABA, or State-Aware Budget Allocation, addresses budget misallocation. The paper models per-round throughput as a trade-off between draft gain and verification cost, then chooses the budget conditioned on the current decoding state. Easy rounds already have long accepted prefixes, so larger trees mostly add cost. Hard rounds benefit more from extra nodes, but only up to a saturation point. SABA predicts the utility of different budgets from state features and selects the throughput-optimal one online.

Overall, GRAFT leaves the DLM and the target verification mechanism unchanged. It focuses specifically on the mapping from one-pass future distributions to an executable draft tree. That decomposition is sensible and technically clean.1a:T4a2,The main empirical claim is consistent end-to-end throughput improvement with very small overhead. The paper reports 2.13x to 6.36x throughput gains over baselines across models and datasets, while adding less than 0.5 ms overhead per decoding round. That matters because it suggests the method is not trading away the cost structure of speculative decoding.

The ablations are more informative than the headline numbers. TDES improves MAT, indicating that parent-child compatibility is a real bottleneck for DLM-based tree construction. The paper shows both examples and aggregate evidence that target-compatible tokens are often already present among candidates, but become unusable because they are connected to the wrong parent. SABA shows that a fixed budget is not robust: the throughput-optimal tree size varies substantially across rounds. Dynamic allocation preserves most of the acceptance gain while avoiding unnecessary verification cost.

From a systems perspective, the strongest result is not a single benchmark number but the combination of stable gains across tasks and low added latency. That makes the method more credible as a practical layer on top of DLM drafters.1b:T455,This is a skim paper, but the introduction, method section, and ablations are worth reading carefully.

具体做法分三步。第一步，每个 layer、每个 KV head 选出 k 个 anchor 位置，这些 anchor 的 key 和 value 精确存储。文中强调 recency window 会被并入 anchor 预算，也就是最近一段 token 默认保真，这符合长上下文推理里“近邻依赖强、最近 token 更敏感”的经验。

第二步，对每个非 anchor token，分别在 K 和 V 空间里找到最相近的 anchor，用该 anchor 的方向做一维投影。于是一个原本 D 维向量，被压成“anchor index + scalar coefficient”。这一步不是把 token 聚成簇后共享同一个向量，而是共享方向、保留幅度，因此比纯聚类中心替代更细一些。K 和 V 共享 anchor 位置，但 assignment、投影系数、residual 集合分别独立，这个设计是合理的，因为 key 影响匹配分数，value 影响读出内容，两者误差敏感性不同。

第三步，在总字节预算固定的情况下，只给一部分位置额外存储 residual。residual 先做 randomized Hadamard transform，把能量打散，降低少数坐标异常值对 2-bit 量化的伤害；再按 token 做 absmax 归一化，用面向高斯源的四级 Lloyd-Max codebook 量化，坐标 2 bit 存储。更关键的是 residual 不是平均分配，而是按“恢复 attention output error 的收益”来选位置，并且同一层内各 head 竞争共享 residual 预算。这说明作者优化目标不是向量级 MSE，而是更贴近最终注意力输出的误差。

The representation has three parts. First, for each layer and KV head, the method selects k anchor positions and stores their keys and values exactly. The anchor budget includes a recency window, so recent tokens are preserved with high fidelity by construction.

Second, every non-anchor token is approximated separately in K-space and V-space by projecting it onto the direction of its closest anchor. This turns a D-dimensional vector into an anchor index plus a scalar coefficient. It is more expressive than replacing tokens with a shared centroid, because magnitude remains token-specific even when direction is shared. Keys and values share anchor positions, but assignments, projection coefficients, and residual sets are separate, which makes sense because K and V affect attention in different ways.

Third, only a subset of positions receives an additional stored residual under a fixed byte budget. Residuals are rotated with a randomized Hadamard transform to spread energy and reduce outlier sensitivity, then quantized at 2 bits per coordinate using per-token absmax scaling and a four-level Lloyd-Max codebook. The important part is not just the codec: residuals are allocated according to how much they reduce attention-output error, not according to generic reconstruction loss. Residual budget is shared across heads within a layer, so heads compete for bytes where they matter most.
