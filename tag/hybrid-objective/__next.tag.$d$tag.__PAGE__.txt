a:T4d7,A training sequence interleaves the system prompt, the user task, assistant actions, and environment observations. GRPO is applied to the assistant-action token positions. ECHO adds an auxiliary next-token cross-entropy loss on selected environment-observation positions. These observation tokens are not sampled by the policy, but the model already computes logits for them under teacher forcing over the full transcript, so their negative log-likelihood can be gathered from the same forward pass.

The design has three important properties. First, it is on-policy: the environment targets are generated in response to the current policy’s own actions. As the policy changes and visits new terminal states, the prediction targets also change. Second, it converts failed rollouts into useful training data. A failed command may still reveal which file was missing, which test failed, or which assumption about the container was wrong. Third, it encourages the policy network itself to model terminal dynamics instead of attaching a separate world model. This differs from expert SFT because the targets come from interaction rather than demonstrations, and it differs from plain GRPO because non-action tokens are no longer loss-masked.b:T59d,The experiments are run in TerminalBench-style Docker environments with Qwen3-8B, OpenThinker-Agent-v1-SFT, and Qwen3-14B as starting policies. The paper reports that in the Qwen3-8B setting, fewer than 15% of on-policy rollouts often solve the task, making the sparse-reward problem concrete.

On TerminalBench-2.0, ECHO improves Qwen3-8B pass@1 from 2.70% under GRPO to 5.17%. For Qwen3-14B, it improves pass@1 from 5.17% to 10.79%. The relative gains are large, while the absolute numbers remain low, which is a useful signal: the method improves learning efficiency in a hard sparse-reward regime, but does not by itself solve terminal-agent training.

The paper also evaluates environment-token cross-entropy on held-out off-policy trajectories generated by Qwen3-32B. ECHO substantially reduces this loss, while GRPO alone barely changes it. This supports the claim that the method improves prediction of terminal behavior rather than only shifting action probabilities.
