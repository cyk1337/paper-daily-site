1）任务与表征设定：一步 Collatz 映射 T(n)=n/2（偶）或 3n+1（奇），输入输出都用 base-b 的数字序列（MSD→LSD）表示，encoder 读入 n 的 digits，decoder 自回归生成 T(n) 的 digits（teacher forcing 训练，greedy 解码评测）。作者强调该任务同时包含分支（奇偶）、剩余类线索、以及 carry 传播等局部/非局部计算，且难例与易例混合，适合观察“结构先出现但难以读出”。
2）“结构是否早学到”的证据：对 encoder 隐状态做线性探针（parity probe）来测量是否已编码奇偶/剩余结构。全文关键点是：在序列级准确率仍接近随机/低水平时，线性探针已接近满分，说明 encoder 表示空间已线性可分地包含关键算术属性。
3）“读出是否为瓶颈”的因果干预：
- Encoder transplant：把已训练好的 encoder 移植到一个“新初始化 decoder”的模型中继续训练，观察 grokking 是否显著提前；若提前，说明 encoder 结构已足够，瓶颈在 decoder 学会如何使用。
- Decoder transplant / rewind：相反地移植/回滚 decoder（或仅重置 decoder）来测试 plateau 是否主要由 decoder 造成。作者报告“只回滚 decoder 基本消除长平台”，并且“移植训练好的 decoder 反而会主动拖慢/破坏”，强化了“decoder 读出学习困难且可能形成错误读出策略”的观点。
4）Tokenizer/表示（numeral base）作为归纳偏置：作者做 15 个 base 的 sweep，分析不同 base 下局部可计算性差异：在偶数 base 下，n/2 分支可用一位 lookahead 局部计算；而 3n+1 分支需要跨位 carry 传播，base 的选择改变 carry 结构与局部模式可见性，从而改变 decoder 的可学习性。极端例子是 binary：作者发现训练崩溃后“塌陷且不恢复”，表明某些表示会让 decoder 的读出学习几乎不可达。
5）边界条件（可迁移性）：用 Collatz 训练出的 encoder 去迁移到 GCD 预测，转移效果差，说明这里 encoder 学到的结构更像“任务特化的可分解线索”（如奇偶/剩余模式组合），而非可复用的通用算术原语；这也提醒预训练中“早期学到的结构”未必等价于“可迁移能力”。6:T765,Methodologically, the paper combines probing, distributional comparisons, causal encoder–decoder interventions, and a 15-base sweep.
- Task setup: one-step Collatz map T(n)=n/2 if n is even else 3n+1. Inputs/targets are digit sequences in base b, ordered most-significant to least-significant. The encoder reads digits of n; the decoder autoregressively emits digits of T(n). Training uses teacher forcing; evaluation uses greedy decoding, making sequence-level accuracy sensitive to readout quality.
- Early-structure evidence: linear probes on encoder states (notably parity) show that key arithmetic attributes become linearly decodable very early, well before sequence accuracy improves—supporting “structure is present”.
- Causal bottleneck localization:
  1) Encoder transplant: plug a trained encoder into a fresh model with a newly initialized decoder; if grokking accelerates, the encoder already contains usable structure.
  2) Decoder rewind/reset: selectively reinitialize only the decoder during training; if the plateau disappears, the delay is primarily decoder-side.
  3) Decoder transplant harm: transferring a trained decoder can actively impede learning, consistent with the decoder locking into a poor readout strategy that is hard to unlearn.
- Representation/tokenization as inductive bias: sweeping numeral bases reveals that local computability differs by base. In even bases, the n/2 branch is locally computable with minimal lookahead, while 3n+1 requires carry propagation across digits; base choice changes the carry structure and thus the decoder’s effective credit assignment and learnability. Binary is an extreme case where training collapses and does not recover.
- Boundary via transfer: Collatz-trained encoders transfer poorly to GCD prediction, indicating that the learned structure is not a broadly reusable arithmetic primitive in this setting.7:T56e,Key experimental details and reported numbers from the full text:
- Data: each training step samples 1,000 integers uniformly from [1, 10,000]; evaluation uses a fixed 5,000-number held-out set. Data are procedurally generated (deterministic, noise-free).
- Default base: base 8 for probing/bottleneck/capacity studies; 15-base sweep for representation effects.
- Quantitative highlights:
  1) Representation outruns behavior: a linear parity probe reaches 99.7% accuracy by ~2k steps while sequence-level accuracy is still ~38%, followed by a long plateau lasting tens of thousands of steps.
  2) Decoder readout dominates the delay: giving a fresh decoder a trained encoder yields ~2.75× faster grokking; rewinding/resetting only the decoder largely removes the long plateau; transplanting a trained decoder can be actively detrimental.
  3) Base sweep: bases aligned with the arithmetic yield high final accuracy; binary collapses and never recovers, showing strong dependence of decoder learnability on numeral representation.
  4) Transfer: Collatz encoders transfer poorly to GCD prediction, serving as a negative result/boundary condition.
