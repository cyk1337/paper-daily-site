LoopCD: Loop-wise Contrastive Decoding for Improving Reasoning in Looped Language Models

这篇工作关注 Looped Language Model 的一个很具体但很关键的问题：模型通过共享权重的多轮 latent refinement 做“隐式推理”时，并不是所有 token 都会随着 loop 次数增加而稳定变好。作者发现，少量 reasoning-critical token 会出现 loop instability：有的 token 过早自信，后续修正失败；有的 token 在不同迭代间来回摆动；这些局部不稳定会沿着推理轨迹传播，最后拖垮答案。论文要解决的就是，能否不改训练、不加外部模型，只利用 LoopLM 自己在不同 loop 里的内部动态，在推理时把这些 hard token 处理得更稳。

评针对 LoopLM (Latent Reasoning) 的一种 inference-time 对比解码方法，通过对比不同迭代深度的 logits 来提升推理稳定性，对研究 latent reasoning 机制有启发。
Byeongho Yu,Junhyuk So,Eunhyeok Park
