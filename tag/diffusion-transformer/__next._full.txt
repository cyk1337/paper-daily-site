18:T58d,They implement variable length via token merging rather than token truncation.
1) Alignment objective: they frame the problem as preserving datapoint-wise similarity structure across lengths; truncation-based VLTs exacerbate drift because early tokens encode coarse semantics while later tokens encode residual details.
2) Merging-based modulation: starting from a full token set, they merge tokens to reduce count. Crucially, if the diffusion model is given the merging pattern, the shortened latent can be lifted to a “full-length-equivalent” representation with matched cardinality, enabling a direct definition of cross-length representation shift (referenced as Eq. 5 / Sec. 3.1). Minimizing this shift encourages merging of similar tokens.
3) Learnable global merging: data-dependent merging is unusable at generation time (no input image to compute a merge plan). They propose a data-independent, globally learnable merging pattern parameterized by global embeddings, trained with a straight-through estimator to handle discrete merge decisions while optimizing reconstruction and alignment.
4) Diffusion transformer interface: they add merged positional embeddings and proportional attention so merged tokens retain coherent positional semantics and appropriate weighting.
