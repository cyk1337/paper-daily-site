18:T432,The paper proceeds from a controlled ablation to a general design principle.
1) Directionality test: On a ~440M Transformer, split layers into three blocks and reallocate only FFN/MLP intermediate width (d_ff) across blocks while keeping total parameters fixed. Compare uniform vs wider-early vs wider-middle vs wider-late.
2) Tapered Language Models (TLM): replace blocky reallocations with a smooth, monotonic decay of a parameter-bearing dimension across depth under a fixed total budget. The main instantiation is tapering d_ff using linear/cosine/sigmoid schedules (cosine tends to work best). The authors argue the same principle could apply to other depth-wise capacity knobs (heads, KV dim, state size, memory slots, MoE experts), but the empirical focus is FFN tapering.
For explanation, they quantify how much each layer writes “novel” content into the residual stream: deeper-layer MLP outputs become increasingly aligned with the existing residual, consistent with refinement rather than feature creation. Tapering reduces capacity where it is less utilized.19:T404,The proposed Variable-Width Transformer changes the model dimension by layer. The best-performing profile is ×-shaped: wide at the bottom, narrow in the middle, and wide again near the top. The implementation detail that matters is the residual stream. Instead of inserting learned projections between layers, the model keeps a fixed global residual dimension equal to the widest layer. Each block reads from and writes to a layer-specific slice of this residual stream. When a layer is narrower, unused coordinates bypass the block. When a later layer expands, those coordinates are restored from the most recent layer that actively processed them; if no such value exists, the coordinate is zero-padded. This parameter-free resizing avoids projection bottlenecks and keeps the skip path closer to a standard residual stream.
