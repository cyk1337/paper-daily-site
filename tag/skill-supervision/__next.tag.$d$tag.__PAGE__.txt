a:T59c,OPID builds a strictly on-policy self-distillation pipeline by rewriting each completed trajectory into hierarchical natural-language “skills”, then using the same policy to rescore the same sampled outputs under skill-augmented context.

1) Hindsight skill extraction: from each finished on-policy trajectory, generate:
- Episode-level skills: global workflow summaries / failure-avoidance rules (coarse but broadly applicable).
- Step-level skills: state-conditioned guidance at pivotal timesteps (precise but sparse).

2) Critical-first skill routing: identify critical timesteps and inject step-level skills there; otherwise fall back to episode-level skills. This targets the granularity trade-off in long-horizon interaction: global guidance is stable but too coarse at decision bottlenecks; local guidance is accurate but should not be applied everywhere.

3) Skill-based self-distillation advantage: take the routed skill text as privileged context appended to the interaction history. Using the old policy, compute token-level log-prob shifts for the same on-policy response between (a) original context and (b) skill-augmented context. This shift acts as a dense preference/advantage signal and is combined with the episode-level outcome advantage for policy optimization.

4) Inference: no analyzer, no retrieval, no skill memory.
