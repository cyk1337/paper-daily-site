9:T72d,The experimental design is clean and well targeted. The authors use a generator–probe setup. A generator model first produces a full chain-of-thought rationale. That rationale is then injected into the context of a separate probe model as an assistant response, and the probe predicts the final answer. This separates rationale generation from rationale consumption. To avoid trivial leakage, explicit answer-declaration sentences are automatically removed before any perturbation is applied.

The core method is a hierarchy of structure-destroying perturbations. Sentence Shuffle preserves each sentence but randomizes sentence order, testing whether sentence-level derivation order matters. Word Shuffle destroys all compositional structure and preserves only the token inventory, isolating lexical activation. The key intervention is n-gram shuffle: the rationale is segmented into contiguous token windows of size n, token order is preserved within each window, and the windows are randomly permuted. n=1 is effectively a bag of words; larger n gradually restores local structure. The recovery curve as n increases reveals how much useful probe-time signal is carried by short local neighborhoods.

The paper also runs several controls to rule out simpler explanations. These include explicit answer copying, option-anchor effects, generic reference text, and the possibility that any input text would show the same small-window recovery. A question-text perturbation control is especially important: the same phenomenon does not appear as strongly when perturbing the question itself, suggesting that CoT-style rationale text has a distinctive local structure that the model can exploit. The qualitative pattern is tested across multiple datasets, model families, parameter scales, and both open- and closed-source configurations.a:T53d,The most illustrative setup is Config D, where Qwen3.5-35B-A3B generates rationales and Qwen2.5-14B serves as the probe. This pairing yields a large observable CoT gain, making perturbation effects easier to measure. The headline numbers from the motivating example are already informative: input-output prompting gives 50.9% accuracy, full CoT reaches 83.9%, Sentence Shuffle remains at 83.1%, Word Shuffle still achieves 66.5%, and preserving only 2-token windows recovers performance to 76.5%. That means most of the gain beyond a word bag can be recovered with extremely short local spans.

Each condition pools three random seeds with 500 examples per seed, for n=1500 total, and significance is tested with two-sided McNemar tests. The paper reports that the same qualitative n-gram recovery pattern holds across multiple generator–probe configurations, model families, scales, and datasets, with the effective recovery window typically around 2–3 tokens. The control experiments show that the effect is not primarily explained by answer leakage, option repetition, or generic lexical overlap. Another useful result is that perturbing question text does not show the same strong small-window recovery, which supports the claim that the phenomenon is specific to rationale text rather than a generic property of LM input processing.b:T411,For a skim-level read, focus on the introduction, the main perturbation setup, and the control experiments.
