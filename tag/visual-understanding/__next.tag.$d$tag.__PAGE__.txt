9:T753,The paper introduces VGAU-Diag, a fine-grained evaluation framework for vision generation-assisted understanding. The framework has three main components. First, it performs difficulty-aware evaluation by stratifying samples rather than collapsing everything into one aggregate score. This is meant to reveal whether visual generation helps consistently or only on easier cases. Second, it supports controlled comparison across three representative paradigms under the same setting: Vision-CoT, where textual and visual reasoning are interleaved; Generate-then-Answer, where the model first creates auxiliary visual content and then reasons in text; and Vision-Reasoning, where the visual output itself serves as the reasoning product. Third, it introduces Oracle-Assisted Reference Protocols that decouple generation quality from understanding ability by supplying faithful or controlled visual aids.

The task domain is visual planning. Models must infer task-relevant spatial states from images and produce executable action sequences. This is a useful choice because it is verifiable and exposes a clearer causal chain between visual state estimation and final decision quality than standard multiple-choice benchmarks. The paper also revisits prior Vision-CoT evaluations and argues that some gains were inflated by optimal-step prior leakage, meaning the model could benefit from structural priors rather than from the actual generated visual content. After correcting for that issue, targeted Generate-then-Answer becomes more reliable than generic stepwise visual reasoning.

This is fundamentally an evaluation paper. Its value lies in decomposing the broad claim that generation helps understanding into measurable sub-questions: Is the generated visual aid relevant? Is it faithful? Can the model use it? Does the benefit persist as reasoning difficulty increases?a:T643,The empirical findings are organized around diagnosis rather than leaderboard performance. First, the benefit of visual generation is strongly difficulty-dependent. It can help on easier instances, but the gains become unstable as reasoning complexity increases. Second, oracle-assisted analysis suggests that visual understanding is often the dominant bottleneck. Even when faithful visual aids are provided, current unified multimodal models may still fail to exploit them effectively. In contrast, stronger proprietary VLMs benefit more from oracle aids, which indicates that the limitation is not only generation quality.

Third, the paper identifies a three-stage transition in generation-assisted understanding. Task-irrelevant visuals mostly act as interference. Visually plausible but incorrect aids can actively mislead the model. Only high-fidelity, task-aligned visual aids provide stable assistance. Fourth, after removing prior leakage in earlier Vision-CoT-style evaluations, a more targeted Generate-then-Answer strategy is more reliable than generic visual step-by-step reasoning. The implication is that useful visual generation should focus on decision-critical states rather than simply adding more intermediate visual outputs.

The key design is to re-encode classical vision-task outputs as RGB images, so the model continues to 'generate images', but those images can be deterministically decoded back into structured outputs such as segmentation masks, depth maps, and surface normals. For example, in segmentation, the prompt may explicitly ask the model to render a target category in pure yellow <255,255,0>, after which the output can be parsed into a mask by color clustering or thresholding. This gives three practical benefits. First, one shared set of weights can support many 2D and 3D tasks, with prompts acting as the task switch. Second, the amount of new training data is relatively small because instruction tuning mainly teaches the model to answer in the requested format. Third, because the output space remains RGB images, the model is more likely to retain its original image generation and editing capabilities.
