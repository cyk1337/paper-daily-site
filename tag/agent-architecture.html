Multi-Stream LLMs: Unblocking Language Models with Parallel Streams of Thoughts, Inputs and Outputs

这篇工作要解决的不是传统意义上的语言建模精度问题，而是 chat-style LLM 的单流执行瓶颈：用户输入、模型输出、内部思考、工具交互都被线性串到一条 token 序列里，导致模型只能“读完再想、想完再写、写完再等”。这种串行化在长工具调用、持续交互、代码代理和计算机使用场景里会带来高首 token 延迟、难以边读边写、难以在生成中响应新信息，也让 system / user / model / thought 的边界在长上下文里变得模糊，进而影响 prompt injection 鲁棒性和可监控性。

评将单流自回归拆分为多流并行的思路很有趣，打破了传统 Chat 模型的交互限制，值得关注其具体的微调数据构造和并行流的实现机制。
