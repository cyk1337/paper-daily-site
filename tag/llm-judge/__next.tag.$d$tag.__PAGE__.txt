a:T59d,The paper has a structural part and an empirical part. Structurally, for an odd-numbered unweighted majority panel with k judges and a single replacement ballot, the panel prediction can change if and only if the original vote margin is one, m = |2s-k| = 1. This is a deterministic arithmetic fact about majority voting, not a statistical claim. It identifies the exact affected set for single-ballot substitution.

Empirically, the authors build multi-model judge panels for code-generation evaluation and introduce a verification signal from a different evidence source. They compare several replacement rules, including random replacement, fixed replacement, and replacing a vote on the majority side. They then report two diagnostics on the same data: the same effective-vote statistic used in prior work, and margin-stratified accuracy/error analyses. The key result is that these diagnostics answer different questions. Aggregate dependence can remain unchanged while conditional gains on pivotal examples are large and reliable.

The mechanism is simple. Most examples are structurally unaffected by single-ballot substitution, so averaging over the full population dilutes any verifier benefit. If the verifier is especially useful where the panel is near the decision boundary, the gain is real but localized. The paper also includes an exploratory analysis linking part of the pivotal-region error pattern to panel composition.b:T552,The experiments cover three code benchmarks and four panel sizes, k in {3, 5, 7, 9}. The main setting uses seven LLM judges plus one verification signal. At larger scale, replacing one judge with the verifier changes the effective-vote count by about -0.04 with a 95% confidence interval of [-0.10, +0.02], so the aggregate metric shows no distinguishable improvement. Yet panel accuracy still increases.

The margin-stratified analysis explains why. For non-pivotal cases, such as at least 5–2 agreement in a 7-judge panel, single-ballot substitution cannot alter the majority outcome, so the accuracy gain is exactly 0. For 4–3 cases, the same verification signal improves accuracy by more than 10 percentage points. In the main setting, 199 of 569 panel errors occur in the pivotal region. So pivotal cases do not contain all errors, but they have higher error rates, and every decision change induced by single-ballot substitution is confined there.

The paper also evaluates margin gating. Once a substitution rule is fixed, verifier calls outside the pivotal region can be skipped without changing predictions. In their experiments, this reduces verifier-call frequency to 12%–27% while preserving the same outputs as universal substitution. 从问题设定上看，这篇工作和一般 LLM-as-judge 论文的区别在于三点。第一，它不是开放式偏好评审，而是细粒度 rubric decision，更接近 process reward model 的 step-level judgment。第二，它把 citation quality 拆成 relevance 与 support 两个不同认知负担的子任务，避免把错误混在一起。第三，它强调 retrieval harness 会影响 judge 输入分布，因此 judge 评测结果只在给定 attribution extraction 和 source presentation 方式下成立，这种系统视角比单纯比较模型分数更实用。d:T7f7,The paper does not introduce a new judge model. Its contribution is a benchmark and an analysis protocol designed around actual reward-model use. The evaluation pipeline follows prior source-attribution work: parse attribution-citation pairs from markdown long-form outputs using an AST-based parser, then score each pair against rubric criteria. The new piece is a controlled adversarial benchmark with gold labels for the two LLM-judged dimensions.

The benchmark is a single long-form report spanning 25 topic domains, intentionally seeded with factual errors and misleading citations. This design prevents judges from succeeding through shallow lexical overlap alone. The labeled unit is the attribution-citation pair. In total there are 624 pairs and 1,248 rubric decisions. All labels are human-reviewed, and 378 hard cases are explicitly adjudicated from judge disagreements. That matters because it shifts the benchmark toward boundary cases, where reward signals are most fragile.

The study evaluates 8 off-the-shelf judges from Anthropic, Google, and OpenAI, without task-specific fine-tuning. This is deliberate: the goal is to reflect realistic deployment, where teams often plug in a general-purpose model as a judge. Metrics are also chosen with reward use in mind. F1 and Cohen’s kappa measure agreement with gold labels, while pass-rate drift, false positive rate, and false negative rate expose directional bias. This is the central methodological point: two judges with similar F1 can induce very different RL behavior if one over-accepts weak citations and the other over-rejects valid but complex ones.

Relative to generic LLM-as-judge papers, the setup differs in three ways. It uses structured rubric decisions rather than open-ended preference judgments. It separates source relevance from factual support instead of collapsing them into one score. This split is informative: relevance looks more like topical matching plus local evidence alignment, while factual support requires stricter evidence sufficiency and factual verification.

The second key result is that directional bias varies substantially even when scalar accuracy is similar. The paper highlights large differences in pass-rate drift, false positive rate, and false negative rate across judges. That matters directly for RLVR. A high false positive rate rewards unsupported claims; a high false negative rate suppresses correct but nuanced attributions. The benchmark therefore does more than rank judges. It shows that reward design must account for the shape of judge errors, not just average agreement.

This produces a large pool of raw candidate criteria, on the order of 10^3 to 10^4. The induced rubric-conditioned judge is evaluated along four axes: structural adequacy, reliability, preference fit, and adversarial robustness. Structural adequacy checks whether criteria are atomic, non-overlapping, and behaviorally covering. Reliability measures agreement across judges or prompt templates. Preference fit asks whether the rubric adds predictive value for human preferences beyond a no-rubric prior. Adversarial robustness tests whether high scores can be obtained while violating the intended construct.
