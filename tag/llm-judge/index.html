Edu-QuRating 解决的是教育类预训练数据筛选过粗的问题：只用一个“是否有教育价值”的分数，无法区分准确性、结构性、趣味性、读者年龄适配、基础读写训练价值等维度。

评做数据筛选的人可以看：不是新范式，但把单分数过滤器推进到多维 rubric 很实用；先看 rubric 设计和蒸馏误差，别急着相信它会自动带来 pretrain gain。

Decomposing LLM-Judge Uncertainty to Target Expert Labels

解决 LLM judge 的“不确定性”混合了两种不同来源：专家之间本来就会分歧的 aleatoric uncertainty，以及 judge 自身无知导致、可通过补标减少的 epistemic uncertainty，从而导致人工标注预算被错误分配的问题。

评做 judge-based data loop 的人该看：它直接否定“按总不确定性补标”这个偷懒做法；先读 ChaosNLI 结果和置信度失真那段，足够决定要不要接进标注系统。

Clean Engineering, Unstable Measurement: A Preregistered Reliability Failure of Black-Box LLM Observers on Shared Endpoints

这篇文章检验的是一个常被默认、但很少被正式验证的前提：把黑盒 LLM 当作 judge / observer 放进评测、数据筛选、训练闭环时，这个“测量仪器”是否足够稳定。作者不是泛泛讨论 judge bias，而是按仪器校准的标准来做：同一请求、同一模型名、冻结协议、预注册阈值、不可事后修补，要求 judge 在同窗重复和跨日重放下给出近乎一致的排序或判定。结果是，两轮研究都在“仪器验证”阶段直接失败，后续原本要研究的科学问题根本无法开展。核心问题因此不是某个具体 benchmark 分数波动，而是：共享推理端点上的黑盒 LLM，能否承担科学测量工具的角色。

评这篇会直接影响你怎么看 LLM-as-a-judge：若你在用共享端点评分数据或做 ablation，先把它当高噪声仪器，至少复现文中的稳定性检查再信结果。
Haoyaun Zhu,Jie Zhang
