H-Scale: Hessian-Guided Scale Refinement for NVFP4 Sub-Byte LLM Inference

NVFP4（Blackwell 原生支持的 4-bit 浮点）采用极细粒度 micro-block（如 group size=16）+ 每组 FP8 局部 scale 的设计。精度损失的关键不再只是“权重量化值怎么选”，而是“每组 scale 怎么校准”。论文要解决的是：在不改推理算子、不引入额外推理开销的前提下，如何更好地为每个 16 元素组选择硬件合法的 scale，从而显著缩小 NVFP4 与 BF16 的精度差距。

评只看 scale 搜索目标和校准激活近似；若内部要上 Blackwell FP4，应复现实验而不是只信 PTQ 曲线。

QUADS: Stabilizing NVFP4 Reinforcement Learning for MoE via QUantization-error Alignment across Dual Sides

这篇工作解决的是一个很具体的工程—算法接口问题：在 MoE 大模型的 RL 训练里，rollout 端如果用 Blackwell 上原生 W4A4 的 NVFP4 来提速，会因为 rollout 与 trainer 的 log-probability 偏差迅速放大而训练崩溃。作者要找出的不是“低精度会不会掉点”这种泛泛结论，而是：崩溃主要来自权重量化还是激活量化；如果主要来自激活误差，那么在 rollout 和 trainer 分离的 RL 管线里，怎样做误差对齐，才能既保住 W4A4 吞吐，又不破坏 GRPO 的策略梯度稳定性。

评这篇该看的是“激活误差比权重误差更致命”这个结论；若你在做低精度 RL 或 rollout-serving 一体化，先复现 log-prob gap 诊断再谈提速。
Zhengyang Zhuge,Hao Yu,Xin Wang,Zheng Li,Yizhong Cao,Dayiheng Liu,Jianwei Zhang
