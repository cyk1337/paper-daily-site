5:T56a,Policy Split implements “two modes, one model” with collaborative dual-mode entropy regularization. (1) Dual-mode instantiation: the same LLM parameters θ represent a normal mode and a high-entropy (HE) mode, where HE is identified by an additional system prompt. The authors show prompting alone barely changes the output distribution (negligible inter-mode KL), so explicit RL training is required to form a robust HE mode. (2) Objectives: normal mode uses vanilla GRPO-like advantages to maximize task correctness, keeping entropy changes conservative. HE mode modifies the advantage in three key ways: (A) add an entropy-preference term to reward higher-entropy rollouts; (B) add a KL-divergence term to push HE exploration away from the normal mode’s region; (C) apply clamping (threshold κ) so entropy-related advantages cannot flip the sign of the learning signal, stabilizing training and preventing low-quality but high-entropy samples from being reinforced. Entropy is estimated via log-probabilities in a symmetric form, with an equivalence argument provided in the appendix. (3) Collaboration: both modes share parameters and training signals/experience, so the normal mode can benefit from newly discovered correct rollouts found by HE, while HE explores under constraints that keep accuracy acceptable, leading to increasing divergence between modes over training.6:T520,【Skim level】
