9:T4e0,1) Task formulation (VTEC): split into Error Detection (locate wrong tokens/regions) and Error Correction (produce the corrected text), with samples designed to be unsolvable from linguistic context alone.
2) High-quality test set: manually curated real-world images with natural errors; strict selection rule that visual cues are necessary; multi-stage annotation with cross-checking and adjudication; plus error-free images from EST-VQA/TextVQA for detection calibration. Final test set size: 1,229.
3) Scalable training set for targeted training/RL: a three-stage Generate–Edit–Examination pipeline.
- Generate: GPT-4o proposes corrupted text; Qwen3-235B filters out cases fixable by language-only reasoning.
- Edit: Qwen-Image-Edit-2509 writes the corrupted text back into the image regions.
- Examination: Qwen3-VL-235B-A22B-Instruct performs correction/verification to filter low-quality edits and label mismatches.
This yields 4,531 synthetic-but-checked training samples.
4) Evaluation paradigms: (a) prompt-based strategies (direct correction, background information enhancement), and (b) targeted model training including RL-based tuning, aiming to approximate each model’s ceiling before concluding there remains a large human gap.a:T414,The paper addresses a specific failure mode in low-bit post-training quantization for LLMs: why quality collapses sharply at 3 bits even when per-layer quantizers are carefully tuned. The full paper argues that the main issue is not merely large local weight error, but residual-stream distribution drift. In a Transformer, the residual stream is shared across layers, so quantization noise introduced by early layers persists and changes the input distribution seen by all later layers. Standard PTQ calibrates layer l on clean FP16 activations, but at inference that layer actually receives activations already perturbed by upstream quantization. This creates a calibration mismatch between the optimization target and the deployed distribution. The paper formalizes this mismatch with layerwise KL divergence and shows that accumulated drift is almost perfectly correlated with log-perplexity, with Pearson r = 0.999. That reframes the problem from isolated layer quality to cross-layer error propagation through the shared residual pathway.b:T490,Its value for foundation-model researchers is less about a new training paradigm and more about turning an empirical deployment pain point into a measurable distributional dynamics problem. First, the paper provides a strong empirical claim: if residual distribution drift is controlled, low-bit PTQ quality is largely controlled as well. That is useful beyond PTQ, because it suggests directions for quantization-aware training, activation-distribution shaping, and robustness-oriented pretraining. Second, it shows that common Gaussian assumptions are poor approximations in modern LLMs: 84% of LLaMA-3-8B layers fail a Gaussianity test, and residual variance grows by 6,548× across depth. This means deep-layer activations are statistically heterogeneous and increasingly fragile. Third, the method preserves standard group-128 asymmetric quantization and adds no runtime overhead, so the contribution is a practical calibration recipe rather than a benchmark-only trick. For people working on pretraining and model design, the broader lesson is that many deployment failures are rooted in how brittle learned internal distributions become in deep residual stacks.c:T5c4,The method is presented as RDQ, but the real mechanism is CEC, Cascaded Error Compensation, a sequential drift-aware calibration procedure. It does not invent a new quantizer; it changes what distribution each layer is calibrated on. Standard methods such as AWQ, GPTQ, and LeanQuant calibrate each layer independently under the assumption that its inputs come from the clean FP16 model. CEC instead quantizes layers in order. After layers 0..l-1 are quantized, calibration data are run through this partially quantized model, and the actual drifted inputs to layer l are captured. Those inputs are then used to fit per-channel scales for the current layer. The implementation keeps AWQ-style channel-importance scoring and a 20-point grid search over alpha, optimizing actual output reconstruction error rather than only weight-space criteria. A useful safeguard is that alpha = 0, equivalent to plain RTN, is always included; if no scaling beats it, the method falls back to s = 1. This prevents harmful overfitting during calibration. Another important engineering detail is exact scale folding into the preceding RMSNorm weights, so the inference graph and kernels remain unchanged. The paper also groups projections that share the same normalized input, such as q/k/v and gate/up in LLaMA blocks, making the folding step structurally valid. The novelty is therefore not a new quantization formula, but explicitly incorporating cross-layer drift into the calibration loop.d:T436,Experiments cover LLaMA-3-8B, Qwen-2.5-7B, and Mistral-7B, mainly under W3A16 and W4A16 settings.
