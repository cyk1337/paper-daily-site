CARVE: Content-Aware Recurrent with Value Efficiency for Chunk-Parallel Linear Attention

这篇工作处理的是 delta-rule 递归语言模型里一个很具体、但很关键的问题：如何在固定大小状态矩阵中做“有依据的遗忘”。GDN-2 这类方法已经把标量门控升级成了逐元素矩阵门控，表达力更强，但门控只看当前输入 token，不看当前内存状态，因此遗忘决策是 memory-blind 的。模型在不知道某个槽位里存的是高价值关联还是陈旧噪声的情况下，就先决定擦除多少内容。另一个问题是 value 维度上的全矩阵门控代价高，尤其不利于 chunk-parallel 训练和高效实现。CARVE 的目标就是同时解决这两个缺陷：让遗忘依赖内存内容，同时不引入额外渐近成本。

评如果你在看 linear attention / recurrent 替代 Transformer，这篇值得读公式：它不是又一个门控小改，而是把可并行训练的约束直接写进状态更新设计里。

How Long Does Infinite Width Last? Signal Propagation in Long-Range Linear Recurrences

这篇工作研究的是：在线性递归模型里，经典的无限宽度信号传播理论到底能在多长序列长度上保持准确。已有理论大多假设宽度 n 趋于无穷，此时隐藏态能量会按均值场规律传播；但对现代长序列递归模型，时间步 t 往往和宽度一起变大，有限宽度误差会不断累积。论文聚焦一个更尖锐的问题：对随机初始化的线性 recurrence，有限宽度偏离会在什么 depth-width 联合尺度上从可忽略变成主导，并给出精确而不是粗糙下界的刻画。

评只看定理和 regime 图；它不会直接改 pretrain 配方，但会约束你对长程 recurrent 架构初始化理论的信任范围。
