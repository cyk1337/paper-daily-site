b:T5dd,TF-Engram is built around three requirements. First, memory construction is train-free: phrase-specific semantic entries are built offline from external corpora without optimizing the backbone model or training adapters. Second, memory fidelity is preserved by avoiding aggressive hash compression. Instead of mapping many unrelated phrases into a small GPU-resident hash table, the system keeps more precise phrase entries and moves the capacity burden to a storage hierarchy. Third, access latency is handled with a GPU–DRAM–SSD memory hierarchy and predictive prefetching.

The paper distinguishes Engram-style memory from RAG. RAG retrieves text chunks and appends them to the prompt, increasing context length and attention cost. Engram-style memory retrieves compact phrase-level signals and injects them into the model’s hidden states. This makes it better aligned with stable short-granularity knowledge such as technical terms, entity phrases, and frequent semantic patterns. It also differs from adapters or LoRA-like methods because it aims to avoid any additional training.

The system component is Early-Exit Guided Predictive Prefetching. During autoregressive decoding, early or intermediate model signals are used to predict which phrase memories are likely to be needed later, allowing entries to be fetched from DRAM or NVMe SSD before they are on the critical path.
