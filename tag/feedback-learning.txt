17:T440,WikiLoop represents external knowledge as an agent-native Wiki containing structured pages, inter-page links, and provenance to source passages. A Navigator searches, reads pages, follows links, accumulates evidence, and answers questions. A Builder proposes schema-constrained patches that create or revise pages, links, and provenance. Both roles are implemented by a shared role-conditioned policy, but with separate prompts, states, actions, and rewards. The training schedule starts with Joint SFT, then applies Navigator RL, Builder RL with a frozen Navigator evaluator, and finally Joint RL over role-homogeneous batches. The Navigator objective uses a sufficiency-before-efficiency rule: retrieval-cost pressure is applied only after evidence coverage is complete, reducing premature stopping. The Builder objective uses guarded utility differences. 核心搜索机制继承并扩展了 GEPA 一类的 Pareto-based search。作者不是只按单一 aggregate score 排序，而是按 per-example 或 per-metric 的 Pareto dominance 保留候选。这样做的原因很直接：不同候选往往在不同子样本、不同指标上各有优势，如果过早压成单一平均分，搜索会丢掉互补结构，后续反思也会失去素材。这个设计原先主要用于 prompt optimization，这里被推广到任意文本 artifact。

论文统一了三种模式。第一是 single-task：对单个问题迭代搜索。第二是 multi-task：把一批相关问题放在一起搜索，让候选在任务间迁移模式，例如 CUDA kernel 优化中，不同 kernel 的局部技巧可以互相借用。第三是 generalization：在训练集样本上优化 artifact，但目标是对未见输入也有效，这一点从 prompt 扩展到了 agent architecture 和 scheduling policy。

另一个技术重点是 side information 的一等公民化。以往很多系统也会把报错或日志塞进 prompt，但通常是 ad hoc 的。这里作者把 SI 变成统一 API 契约，使 proposer 可以系统地消费 stack trace、性能 profile、图像渲染结果、子指标等反馈。论文的消融表明，这不是锦上添花，而是决定收敛速度和最终质量的关键变量。

If you want to go deeper, inspect how much hidden task-specific labor is embedded in evaluator design and proposer prompting.1d:T812,方法核心是 Reflection-Enhanced Self-Distillation（Resd）。整体仍沿用 on-policy self-distillation 框架：当前策略 πθ 采样轨迹，旧策略或滑动平均策略 πθ_old 作为 self-teacher，在更“特权”的上下文下输出每一步 token 分布，student 去拟合 teacher 的分布。训练目标写成统一的 f-divergence 形式，兼容 forward KL、reverse KL、JSD 等，并对 likelihood ratio 做 clipping 来稳住训练。

Resd 的新增部分不在 loss，而在 teacher context 的构造。它做了两层增强：
1. retrospective reflection：对每条失败轨迹，额外生成一段回顾式反思，内容不是泛泛总结，而是定位局部错误、解释为什么失败、指出如果当时做什么会更好。这样 teacher 在重看同一轨迹时，不再只看到原始环境反馈，而是看到一份已经被语言化、因果化、局部化的纠错说明。
2. persistent global playbook：把训练过程中反复出现、可复用的经验教训沉淀成一个持续更新的“手册”。后续 teacher prompt 不只带当前轨迹的 reflection，还会带上相关 playbook 条目。这样监督信号不再局限于单条 rollout，而是能跨 step 复用失败中提炼出的策略知识。

这两点合起来，等于把环境反馈从 passive conditioning 变成 active supervision。和标准 SDPO/OPSD 的区别，不是 teacher 更强，也不是引入外部 oracle，而是先对失败反馈做解释层加工，再让 self-teacher 在这个 enriched context 下重估 token 分布。作者还强调该模块是 plug-and-play 的，原则上可接到不同 self-distillation objective 上。

从机制上看，这个设计为什么可能有效：raw feedback 往往是结果级、全局级、低带宽的；reflection 把它变成局部决策层面的错误归因，playbook 再把一次性经验变成跨样本先验。对于 token-level distillation，这种结构化上下文更容易改变 teacher 在关键决策点的条件分布，而不是只在结尾处给出模糊惩罚。1e:T7ed,The method, Reflection-Enhanced Self-Distillation (Resd), keeps the standard on-policy self-distillation backbone. The current policy πθ samples trajectories. A self-teacher, instantiated from older or moving-average weights πθ_old, is given privileged context and produces token distributions for the same trajectory. The student then matches the teacher distribution with a unified f-divergence objective, with clipped likelihood ratios for stability. The loss family can recover forward KL, reverse KL, JSD, and related variants.

The main change is not in the loss but in how the teacher context is constructed. Resd adds two layers of structure:
1. Retrospective reflection. For each failed rollout, the system generates a reflection that diagnoses likely local mistakes, explains why the trajectory failed, and states what correction would have helped. This converts raw failure feedback into a more explicit error-attribution signal.
2. Persistent global playbook. Recurrent lessons extracted from failures are stored in a reusable playbook that persists across training steps. Future teacher prompts can condition not only on the current trajectory and its reflection, but also on accumulated reusable lessons.

This changes feedback from passive conditioning into active corrective supervision. Compared with standard SDPO/OPSD, the novelty is not a stronger external teacher and not a different policy class. The novelty is an intermediate interpretation layer that rewrites failure feedback into a form that can more directly alter the teacher’s token-level posterior.

Mechanistically, the design is sensible. Raw environment feedback is often global, low-bandwidth, and outcome-level. Reflection turns it into localized causal guidance. The playbook then amortizes that guidance across future examples.
