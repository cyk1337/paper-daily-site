c:T49e,MoNe attaches a fast-weight neural memory to each decoder layer of a frozen Transformer. The context is split into fixed-size segments, with T=512 in the paper. During the context-reading phase, segments are processed sequentially and each layer updates its own memory through localized gradient updates; backbone weights are never modified. The memory module is a per-head SwiGLU MLP rather than a single linear map, giving it more capacity to store associative structure under a small parameter budget. During generation, the original context tokens are not reread. Query tokens are projected with the frozen Wq, used to read the final fast-weight state, and converted into memory tokens. After RMSNorm and learned head-wise gating, these tokens are projected through the frozen Wk and Wv and concatenated with the query’s normal attention entries. This gives O(N) preprocessing, approximately O(1) query cost with respect to context length, and a KV footprint that does not grow with N. Compared with RAG, it is less tied to locally retrievable chunks.
