9:T563,The benchmark is built around controlled evidence requirements. For counting, the authors define three overlap regimes across views: complete overlap, subset overlap, and complementary views. The first two can often be solved by simple per-view heuristics such as taking the maximum count. Complementary views cannot: the model must determine which detections correspond to the same physical object and which are unique, so cross-view deduplication becomes necessary.

For cross-view consistency, the benchmark avoids a naive “spot the difference” setup. Instead, it introduces localized edits either in regions visible from both viewpoints or in regions visible from only one viewpoint. Only the former creates a true contradiction. This tests whether the model reasons about visibility and shared evidence, rather than merely detecting image-level differences.

A third task, multi-view spatial reasoning, asks models to infer physical proximity relations by combining evidence across viewpoints. The dataset is built from real-world multi-view captures from DL3DV-10K and manually verified. The paper also adds diagnostic analyses: attribution to simple aggregation strategies, sensitivity to image order, no-image bias checks, explicit reasoning prompts, and scaling with additional views. These analyses make the benchmark useful for failure diagnosis, not just ranking.a:T57e,The evaluation covers 12 open-weight and proprietary VLMs under an open-ended protocol. The clearest result appears in counting. Accuracy is relatively moderate on complete overlap, around 45.5%–81.5%, and on subset overlap, around 26.7%–76.7%. But on complementary views, where true cross-view integration is required, performance drops sharply to 4.5%–50.0%. This gap strongly suggests that many models do not reliably establish object correspondence across views.

The consistency task is even more revealing. Accuracy stays around 50%, essentially chance level, and models respond similarly to edits in shared regions and view-specific regions. That means they are often detecting differences without understanding whether those differences are compatible with two views of the same scene.

The auxiliary analyses add useful detail. A substantial fraction of counting outputs can be explained by simple per-view aggregation rules, indicating shortcut behavior. Sensitivity to image order suggests unstable multi-image fusion. Performance under reduced or removed visual input reveals language prior bias. Explicit reasoning prompts help only marginally, which implies the bottleneck is not merely missing chain-of-thought at decoding time; it is more likely a representational failure to bind observations into a coherent scene model. Adding more views does not consistently fix the issue either.b:T433,BedBench comprises 13 procedurally generated tasks over voxel-based 3D objects (10–15 connected unit cubes, rendered from two opposite views) and simple geometric scenes. Key design choices:
1) Ask both individual-judgment questions and exact-answer questions on the same underlying objects, enabling within-family comparisons.
2) Add consistency checks across questions (e.g., compare “most common colors” against the model’s own reported color distribution), plus a control where the model is given its own counts as text to isolate reasoning/consistency from visual readout.
3) Filter ambiguous instances at generation time using projection/silhouette distinguishability constraints and visibility checks, so errors are less attributable to underspecified views.
4) Include image-dependence controls: no-image runs, best-constant baselines, and MCQ layout artifact checks.

For each image, the authors sample a coherent subgraph via a random walk of up to ten steps, preserving objects, their attributes, and pairwise relations. From this shared primitive set, they generate captions with different structures and complexity levels. This enables matched comparisons between composed captions and decomposed counterparts built from the same underlying primitives. Evaluation uses a retrieval-style protocol with hard negatives designed to isolate errors in object recognition, attribute binding, and relation reasoning. On top of this setup, the paper defines two analyses. The first is the compositional integration gap: the performance difference between composed and decomposed captions under matched perturbations, intended to measure the cost of joint reasoning alone. The second is skill load: performance as a function of primitive counts, separated into self-load, where a skill degrades as more primitives of the same type are added, and cross-load, where it degrades as other primitive types increase. This is more informative than standard compositional benchmarks because it asks not only whether models fail at higher complexity, but why they fail.f:T511,The experiments cover 87K image-caption pairs for compositional integration analysis and 274K pairs for skill-load analysis, spanning object, attribute, and relation skills. The authors evaluate a diverse set of VLMs, including standard contrastive encoders, models explicitly trained for compositional reasoning, and non-contrastive architectures. The main findings are threefold. First, there is a consistent compositional integration cost: composed captions are harder than matched decomposed counterparts. However, this gap explains only part of the overall degradation as caption complexity increases. Second, each skill shows distinct sensitivity to primitive counts, and the degradation is not purely type-local. Models exhibit both self-load and cross-load effects, meaning that increasing relation primitives, for example, can also hurt object or attribute-related performance. Third, these patterns appear across model families, though with different magnitudes and shapes, suggesting that some architectures or training objectives may help with one bottleneck while leaving others untouched.
