CurveShift: Is Agent Progress Scalar? Separating Level from Shape

很多“模型进步”被压成一个标量（平均分、时间跨度、潜在能力值），但这会混淆两件事：整体能力的均匀上移（level shift）与对高难题的相对额外增益（shape change）。论文要回答的是：近一年的“更偏向攻克难题”的进步叙事，究竟是能力曲线形状真的变了，还是只是天花板效应/题目区分度导致的表观现象？

评读 Rasch 控制实验即可；它会让你少把 agent 分数曲线的右移误读成能力结构变化。
