First, it builds a broad evaluation setup over 22 translation directions: 10 non-English-centric and 12 English-centric pairs, spanning high-, medium-, and low-resource languages. Directions are treated separately rather than merged by language pair, which is the right choice because the target language directly affects token activation. Second, the authors tighten prompting to control output format. They found that a standard in-context translation prompt often caused some models to produce explanations or noisy text instead of clean translations, which would contaminate automatic evaluation. They therefore designed two additional prompts, used rule-based noise detection plus manual inspection, and selected Prompt 2 for the cleanest outputs. This is an important methodological detail because noisy outputs would distort both translation metrics and token-dynamics analysis. Third, they introduce Token Activation Rate (TAR), a metric intended to capture how effectively a model uses language-specific tokens of the target language during generation. TAR is then analyzed jointly with typological distance, COMET, BLEU, and the number of reasoning tokens.
