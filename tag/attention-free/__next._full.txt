The input side uses a ByteRotate encoder: instead of learning 256 separate byte embeddings, it learns one vector and derives all byte representations through DFT phase rotation. This means the whole byte alphabet is covered with only 128 parameters. Sequence modeling is handled by a multi-scale reverberant state, which replaces attention with three banks of content-gated exponential decay states. The recurrence is s_t = gamma_t s_{t-1} + (1-gamma_t) v_t, where gamma_t depends on content, and the three decay ranges cover short, medium, and long memory. A reverb block is LayerNorm, then reverb in parallel with causal depthwise convolution, then learned gate mixing, then FFN. The trunk has three such blocks with hidden size 128. A notable engineering addition is fast scan: the recurrence is parallelized in chunks of 16 using a cumprod/cumsum closed form, numerically matching the sequential loop to 1e-7 while giving roughly 10–50x wall-clock speedup. That makes the 512 MB training point feasible on free-tier hardware. The baseline is a parameter-matched attention model with the same skeleton, replacing reverb plus convolution by 4-head causal SDPA. Each head is parameterized as a damped resonator, with a kernel defined over lag t using exponential decay and oscillatory response. The main parameters are alpha for damping, omega for angular frequency, and phi for phase. In implementation, unconstrained parameters are mapped into valid ranges with softplus/sigmoid transforms, and heads are initialized with log-spaced half-lives and frequencies so different channels start with different timescales.

The input is projected through grouped linear layers into a drive tensor and a gate tensor. The drive is processed by the resonant mixer, while the gate is applied after mixing to provide content-dependent modulation without constructing query-key similarity matrices. During training and prefill, each head performs causal convolution with its resonant kernel, implemented with FFT for O(T log T) complexity. During autoregressive decoding, the model does not maintain a growing KV cache. Instead, each head keeps a fixed-size complex recurrent state, stored as paired real tensors for numerical stability. Each new token updates that state according to the same damped resonant dynamics, and the output is read from the updated state.

Two auxiliary components are important. A local lexical path preserves short-range token detail, which the resonant field alone may blur. An optional cross-head coupling matrix allows information exchange across resonant channels, reducing the expressivity loss from fully independent heads. The block is then combined with a standard feed-forward layer, so the overall architecture still resembles a modern LM block.

Relative to SSM-style models such as S4 or Mamba, the paper emphasizes explicit resonant kernels and frequency-selective dynamics rather than a more general state-space formulation. Relative to linear attention, it removes token-token similarity entirely and relies on learned causal kernels plus gating.
