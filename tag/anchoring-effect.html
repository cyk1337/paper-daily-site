Try Again, Don't Look Back: Blind Resampling Outperforms Self-Repair in Small Code Models

这篇论文解决的问题很具体：代码模型自修复到底是在利用执行反馈，还是只是在多试一次。已有代码 Agent 往往把“失败程序 + 测试输出 + 请修正”与单次生成比较，这会把反馈价值和额外采样机会混在一起。论文用安慰剂对照把两者拆开，发现小模型里真正有效的是重新采样，而不是看回自己的失败答案。

评非常干净的 ablation study，揭示了小模型在 self-repair 时的 anchoring 现象，证明了 blind resampling 的高性价比，直接改变了对代码 Agent 重试策略的 prior 认知。
Yuvraj Verma
