DEPT: Document Embedding Preservation Tuning for Unified Query Expansion and Retrieval

这篇工作解决的是一个很具体但常被回避的问题：如果用同一个 decoder-only LLM 同时做 query expansion 和 dense retrieval，并且端到端用检索损失训练，那么检索监督会同时改写 query 侧生成行为和 document 侧嵌入空间，导致训练目标在不断移动。作者把这个问题概括为 unified expansion-retrieval 中的 document embedding drift。它不是简单的训练不稳定，而是 retrieval loss 可以通过“移动文档目标”来被部分满足，从而削弱了对 query expansion 质量本身的约束。

评探讨了在同一个 LLM 中联合优化生成（查询扩展）和表示（检索）的训练动态，其解决“移动目标”问题的正则化技巧对多任务统一微调有参考价值。
Jingyuan Wang,Richong Zhang,Zhijie Nie,Mingxin Li,Yanzhao Zhang
