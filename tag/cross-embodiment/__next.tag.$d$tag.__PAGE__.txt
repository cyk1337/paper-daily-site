9:T87a,方法名是 Continuous-Action World Models，核心对象是 latent action function。作者不把动作看成固定长度、固定频率的命令序列，而是把一段动作表示成带时间戳的样本点 {(τ_i,a_i,m_i)}，其中 m_i 记录哪些动作分量有效。编码器 E_ϕ 把这些时间采样点压到固定大小的 latent function Z，解码器 D_ψ 接收 Z 和任意物理时间 query τ，输出该时刻的 end-effector action。这样同一动作可以在不同采样频率下被观测和重建，也可以在推理时按目标控制频率重新查询。

训练分两阶段。Stage A 是 function pretraining。作者用一个 Mixture-of-Transformers 编码器分别处理位置、姿态、夹爪等动作流，再通过联合注意力融合，学习跨动作分量的共享表示。预训练目标至少包括两类：一是动作重建，让 latent function 能从时间查询恢复原始轨迹；二是 temporal sampling view consistency，让同一物理动作在不同采样频率、不同时间视图下映射到一致表示。这个设计的关键不是做更强的自编码，而是让 heterogeneous trajectory 在“物理时间”坐标系里对齐，从而扩大可用于预训练的数据池。

Stage B 是把 pretrained function space 接到 world-model backbone。输入侧包括视觉观测、语言指令、机器人 proprioception，以及预测的未来视觉特征；预测头输出 latent function，再由共享 decoder 按指定 query times 解码成动作。文中提到 current visual features 通过 output residual 进入预测头，说明作者不想让 latent function 完全承担当前观测的低层细节，而是更偏向承载跨 embodiment 的 dynamics prior。训练时既监督 latent representation，也监督解码后的动作，形成 representation-level 和 action-level 的双重约束。

和常见 robot policy / world model 的区别在于：它不是直接学 observation-to-action，也不是把不同机器人动作简单投到统一离散 token 空间，而是先定义一个连续时间、固定容量、可跨频率查询的中间函数空间。这个中间层是全文真正的创新点。a:T7ca,The method, Continuous-Action World Models (CoAWM), centers on a latent action function. Instead of representing an action as a fixed-length command sequence, the paper uses timestamped action samples {(tau_i, a_i, m_i)}, where m_i indicates valid components. An encoder maps these samples into a fixed-size latent function Z, and a decoder takes Z plus arbitrary physical-time queries to produce end-effector actions. This makes it possible to observe the same motion at one sampling rate and execute or reconstruct it at another.

Training has two stages. Stage A is function pretraining. A Mixture-of-Transformers encoder processes position, orientation, and gripper streams with specialized branches and joint attention. The pretraining objectives include action reconstruction and consistency across temporal sampling views, so that the same physical motion observed at different frequencies maps to a shared representation. The point is not just better autoencoding; it is to align heterogeneous trajectories in a common physical-time space and thereby enlarge the pool of usable pretraining data.

Stage B connects the pretrained function space to a world-model backbone. The prediction head consumes visual observations, language instructions, robot proprioception, and predicted future visual features, with current visual features added through an output residual. It predicts a latent action function, and the shared decoder turns that function into actions at query times chosen for the desired execution frequency. Training supervises both the latent representation and the decoded actions, giving the model both representation-level and action-level constraints.

Compared with standard robot policies or world models, the key difference is that the paper does not directly learn observation-to-action mappings in a fixed discrete-time space, and it does not force all robots into a naive shared action tokenization.
