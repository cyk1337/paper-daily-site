WIDE: Boosting Adaptive LLM Inference via Token-level Dynamic Width Pruning

这篇工作解决的是 LLM 推理阶段动态剪枝里一个长期存在但一直没真正打通的问题：细粒度动态稀疏在算法上看起来更合理，因为不同 token 需要的计算量不同；但一旦把决策粒度从整层/整模块下推到 attention head group 和 FFN channel group，执行模式就会变得高度不规则，GPU 上很难拿到真实端到端加速。现有方法往往二选一：要么做静态结构化剪枝，部署友好但精度掉得快；要么做动态路由，质量保留更好，但实际吞吐收益有限。WIDE 的核心问题，就是如何把 token 级、宽度维的动态计算分配做成既能保精度、又能在 prefill 和 decode 两种场景下真正跑快的系统。

评动态稀疏方向少见的硬件落地友好方案，重点看两阶段训练设计和实际吞吐量数据，§3方法与§5实验值得读。
Haozhe Hu,Hao Wu,Peiran Yin,Chao Han,Yunpu Ma,Xiaoyu Shen

PrunePath: Towards Highly Structured Sparse Language Models

这篇工作处理的是一个很具体但长期没有被很好解决的问题：FFN 占了现代 LLM 大部分参数和相当一部分推理开销，但常见剪枝方法要么是非结构化稀疏，难以转成真实硬件收益；要么结构过硬，精度掉得快。MoEfication 这条路把 dense FFN 重排成若干 expert，只激活部分 expert，方向是对的，但已有代表方法 LTE 用独立 sigmoid 给每个 expert 做二分类，缺少 token 级全局预算约束，容易在低预算场景下保守过激活，导致稀疏度不够可控，重建误差也偏大。PrunePath 的核心问题，就是如何把 dense FFN 变成一种既结构化、又可按 token 自适应、还能在单一 checkpoint 上连续调节稀疏度的稀疏 FFN。

评别只看“稀疏-精度曲线”，重点看它把路由做成 token 级预算旋钮、以及解码 kernel 是否真能吃到收益；若实现细节不扎实就只是换皮 MoE。
Zhexuan Gu,Zixun Fu,Yancheng Yuan

Rotation-Aligned Key Channel Pruning for Efficient Vision-Language Model Inference

这篇论文解决 VLM 推理时视觉 KV cache 过大的问题。视觉输入通常被编码成数百到数千个 token，图像、视频和多图场景会让 KV cache 成为主要显存瓶颈。现有方法多做视觉 token pruning，但直接丢 token 会伤害文档理解、细粒度感知和 grounding 等任务。作者转向另一个压缩轴：在保留更多视觉 token 的同时压缩 Key 的 channel 维度。

评别把它当“新模型”，当成 VLM KV 压力的工程解法：重点看旋转对齐+结构化 mask 是否真比纯 token pruning 稳。
