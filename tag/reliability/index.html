在多步工具调用任务中，模型早期的错误（选错工具或参数错误）会污染后续上下文，导致任务失败。现有的聚合成功率指标无法区分是单次调用能力不足，还是早期错误导致的级联失效，且在精确匹配（exact-match）评分下，传统的错误严重程度和恢复率模型无法被正确估计。

评做 tool-use 训练的人该看；它提醒你很多“不可恢复”的结论其实是 metric 造出来的，先看测量协议再谈 agent 能力，重点读 propagation analysis 那部分。
Afiya Noorain,Subhranshu Mohanty,Amritesh Banerjee,Abhijit Dasgupta
