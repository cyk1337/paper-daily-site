18:T479,The proposed method is NOVA-KV (Non-Orthogonal Vector-quantized Attention for KV cache). The authors formulate KV compression as a rate-distortion problem where distortion is error in attention products, split into a key-side term from q·k inner products and a value-side term from attention-weighted values. Under a high-resolution assumption they derive closed-form optimal transforms: for values the optimal transform is orthogonal and recovers the covariance-based transform used heuristically in prior work such as Oscar; for keys the optimal transform is non-orthogonal and satisfies a generalized Parseval relation, meaning MSE in the transform domain equals key-query inner-product distortion in the original domain. This reduces quantizer design to a standard MSE problem. On top of that, NOVA-KV applies vector quantization to key coefficients and groups entries so that group volumes are approximately equalized; this allows equal-size codebooks to approach the variable-rate distortion bound while preserving a fixed-width layout required by serving engines. The method is integrated into SGLang with a fused Triton decoding kernel.19:T4df,The method, Block-GTQ, is built on TurboQuant-MSE but replaces uniform per-head bit allocation with integer bit allocation over RoPE 2D blocks inside each layer and KV head. The starting point is the RoPE attention logit q^T R_Δ k, which decomposes into a sum of 2×2 rotated block terms. This makes key-cache quantization naturally block-sensitive: quantization error in different blocks perturbs future logits by different amounts. The paper defines a label-free block energy score from Q/K activation statistics to estimate how important each block is for future query-key interactions. It then combines this score with the TQ-MSE empirical error law, where squared error scales roughly as 4^{-b}, to compute the marginal gain of assigning one more bit to a block. Under a fixed average-bit budget, bits are allocated greedily as integers. Blocks with the same assigned width are then encoded using the original TQ-MSE local quantizer, so the implementation remains lightweight. Values are still quantized with uniform TQ-MSE because V does not enter the RoPE key-logit computation. The paper also implements a packed-cache serving path so the compressed K/V codes are used in an actual inference pipeline rather than only in offline analysis.1a:T57c,The evaluation has three layers. First, mechanism validation: on a ten-model diagnostic panel, Block-GTQ is compared against uniform TQ-MSE at matched K-only budgets. At both 2 and 3 bits per dimension, it reduces per-layer RoPE-logit MAE by 32% to 80%, and wins all 367/367 layer comparisons at each budget. This indicates a broad structural improvement rather than gains from a few favorable layers. Second, long-context downstream tasks: on Llama-3.1-8B-Instruct at K2V2, the six-task NIAH average rises from 70.6 to 97.4, and the eight-task LongBench-EN average rises from 36.87 to 53.31 relative to uniform-allocation TQ-MSE. Third, reasoning robustness: on DeepSeek-R1-Distill-Qwen-7B, AIME 2024/2025 scores at K3V2 are 51.7/37.5 for Block-GTQ, close to fp16 at 54.2/37.9, while uniform TQ-MSE collapses to 0.0/0.0. That result is especially telling because it shows how low-bit key errors can destroy long-chain reasoning once they distort attention distributions, and how RoPE-aware allocation can prevent that failure. On the systems side, with Qwen2.5-3B-Instruct and a K3V3 packed path, the method achieves 3.24× KV-cache compression at 128K context, reduces peak memory from 56.31GB to 19.85GB, and lowers single-request decode latency from 70.96ms to 52.95ms.
