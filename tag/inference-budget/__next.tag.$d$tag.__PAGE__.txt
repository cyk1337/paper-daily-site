The key contribution is not a catalog of model internals, but a decomposition of the main degrees of freedom that govern DLM behavior. First, they run a unified downstream evaluation across eight benchmarks spanning general knowledge, reasoning, coding, and machine translation, instead of letting each model be judged on a different task mix. The authors compare three existing online augmentation methods—AWM, ASI, and ReasoningBank—against a budget-matched vanilla baseline called Vanilla-IB. The augmented agents keep the default actor horizon of up to 10 steps, while spending additional tokens on workflow induction, skill extraction, memory retrieval, reasoning-bank updates, and related control logic. Vanilla-IB removes all auxiliary modules and reallocates the same overall budget to a longer actor interaction horizon.

That design choice is the core contribution. The paper does not propose a new agent architecture; it proposes a stricter control condition. Instead of comparing “augmented agent vs plain actor with a smaller budget,” it compares “augmented agent vs plain actor with the same total token budget.” The study is explicitly online: tasks are processed sequentially, and any reusable knowledge must be accumulated from earlier evaluation trajectories rather than built offline in advance. This makes the trade-off sharper, because online augmentation is sensitive to task order and cannot amortize its cost over a precompiled skill library.

The paper’s methodological contribution is therefore an evaluation protocol with three requirements: report total token usage across all modules, compare methods under matched budgets, and report multi-run variance rather than relying on a single aggregate score.11:T572,The main benchmark is WebArena, evaluated on three domains: Shopping (187 tasks), Reddit (106 tasks), and Admin (182 tasks). Across these settings, the headline result is consistent: Vanilla-IB achieves the best aggregate success rate overall while often using fewer total tokens than AWM, ASI, and ReasoningBank. In other words, once auxiliary token overhead is counted, spending the budget on more direct interaction is usually better than spending it on online memory or skill machinery.

With Qwen 3.6-27B, Vanilla-IB remains competitive with the best augmented methods, suggesting the budget-matching issue is not specific to consumer-style websites.

The paper argues that single-run success rates hide substantial task-level variability, especially in online settings where later performance depends on earlier trajectories.
