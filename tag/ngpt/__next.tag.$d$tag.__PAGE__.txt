9:T549,The model uses a normalized Transformer backbone. It keeps the nGPT residual-update rule and adds L2 normalization for concatenated gated attention outputs before the output projection and for SwiGLU activations before the MLP down-projection, implemented with fused Triton kernels. The 72 physical layers are partitioned into a 16-layer input block, a 40-layer shared recurrent block, and a 16-layer output block. The input and output blocks run once; the recurrent block runs k times, and the input-block representation is re-injected before each loop. Attention uses gated grouped-query attention with 16 query heads and 4 KV groups. The stack interleaves 36 MLP-only layers, 27 sliding-window attention layers, and 9 full-attention layers, giving a 3:1 local/global attention pattern. Training starts with a k=1 non-looped phase on about 4.5T tokens using NVFP4. A BF16 continuation phase then samples loop counts from {1,2,3,4} and trains with truncated backpropagation through loops. The model is later extended to 256K context. Post-training uses nine SFT epochs over packed 256K-token sequences, followed by 200 asynchronous GRPO steps across 23 environments. The RLVR stage uses a difficulty-aware loop curriculum: rollout workers run at fixed loop counts, and prompts with lower profiled pass rates are preferentially assigned to deeper loops.a:T49a,The reported pretraining scale is about 6T tokens, with an additional long-context extension phase of about 300B tokens. On the equal-weight average of 12 benchmarks, performance rises from 35.2 at one loop to 39.7 at two loops and 40.6 at four loops. On four agentic benchmarks, four loops reduce generated tokens per attempt by 1.3 to 2.5 times relative to one loop, suggesting that extra latent compute can partly substitute for longer textual traces. The RLVR loop curriculum has its largest effect at deeper loops; Terminal-Bench v2.1 increases from 14.0% to 21.4% in the reported ablation. The paper also evaluates last-loop KV caching, where each loop overwrites the previous loop’s cache so attention memory stays at the one-loop size. - State geometry: every token hidden vector is constrained to \(\mathbb{S}^{d-1}\), preventing norm blow-up.
- Input injection: instead of Euclidean mixing, the input is re-injected via geodesic movement toward an input anchor, parameterized by an injection strength \(\lambda\), implemented with spherical linear interpolation (Slerp).
- Damping: the Euclidean convex-combination update is replaced by a spherical interpolation step with coefficient \(\eta_i\), now interpretable as an angular step size. The same patience-based decay schedule is used, but without the need for FPRM’s coupled residual-rescaling coefficients.
- Halting: the stopping residual is defined as an angular discrepancy (worst-token angle between the current iterate and its proposal), which is naturally scale-invariant—removing the need for relative-norm residual normalization.
- Guarantees: fixed-point existence follows from continuity plus injection; local convergence is characterized via the tangent-space Jacobian with an explicit step-size window; sufficiently strong injection yields a unique global attractor.
