5:T461,VERDICT formulates verification as a coupled scoring problem among frozen, modality-specialized judges.
- Three frozen judges score each candidate step from different perspectives: Visual grounding, Logical validity, and Contextual relevance.
- Disagreement-aware consensus: instead of aggregating independently, they introduce coupling and interpret the interaction as a coordination game. The consensus-adjusted scores correspond to a unique Nash equilibrium with a claimed closed-form solution, so each judge’s adjusted belief accounts for others.
- Dual acceptance rule: a mean-confidence threshold ensures sufficient collective endorsement, while a dispersion (agreement) constraint rejects unstable steps with unresolved conflict. Among accepted candidates, they rank by consensus confidence to pick the most stable continuation.
- Key distinction vs mean/variance: averaging is symmetric and loses “who disagrees with whom”; variance ignores belief strength. Coupling introduces structured, asymmetric influence (e.g., a stubborn visual judge can dominate disagreement in a way fixed weights cannot capture).6:T6ac,ObjectStream is a training-free, plug-and-play memory framework built on frozen Video-LLM representations. It does not modify the backbone model. The method has three components.

The first is Latent Object-Anchored Memory. Instead of storing historical visual tokens as a flat sequence, the method induces spatially coherent latent object candidates directly from patch-level features of the frozen model, links corresponding objects across frames, and maintains their histories under a memory budget. The goal is to convert long video memory from token-centric storage into object-centric trajectories.

The second is Object-Conditioned Temporal Residuals. Persistent object histories alone can miss short-lived but important events, such as abrupt appearance changes or interactions. To address that, the method stores residual evidence around object-level changes, preserving transient information that would otherwise be compressed away.

The third is a Recent Visual Grounding Window. Object histories are useful for long-term tracking, but answering current questions still requires access to recent raw visual context. The grounding window keeps the latest observations so the model can remain visually grounded without relying only on abstracted memory.

So the design is a three-part memory system: persistent object histories, transient change residuals, and recent visual context. Compared with token pruning, frame selection, or segment-level memory, the main difference is not just stronger compression but a different organizing principle. The method is also notable for avoiding external detectors or segmentation models; the object-like units are induced from the model’s own latent space.7:T51b,The experiments cover both online streaming and offline long-video understanding, with Qwen2.5-VL-7B as the main backbone. On streaming benchmarks, ObjectStream improves Real-Time Visual Perception on OVO-Bench by 10.0 points, Backward Tracing by 4.9 points, and StreamingBench by 2.9 points. The gains are especially consistent with the paper’s claim that object-anchored memory helps when evidence must be traced over time.

On offline long-video benchmarks, the method reportedly surpasses the full-token baseline while discarding 82.5% of visual tokens. That is the most important efficiency result: performance is maintained or improved under aggressive token reduction, suggesting that better memory organization can outperform brute-force retention of raw visual tokens.

The ablations support the division of labor among the three components. Object anchors handle long-term consistency, temporal residuals preserve abrupt changes, and the recent window supports immediate grounding. Removing any one of them hurts performance, which indicates that the method is not a single compression trick but a multi-timescale memory design.
