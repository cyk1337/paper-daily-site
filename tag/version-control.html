ChronoMem: Version Control and Semantic Rollback for Large Language Model Agent Memory

LLM agent 的长期记忆通常只会向前累积，缺少可检查、可版本化、可语义回滚的机制，导致纠错、概念漂移和记忆污染后难以恢复。

评值得知道这个 memory pattern，但不必精读；若快照粒度和存储开销没处理好，语义回滚会很快变成工程债。

GitOfThoughts: Version-Controlled Reasoning and Agent Memory You Can Replay, Diff, and Merge

论文解决的是 agent 推理和记忆缺少可复现、可审计、可合并的持久化载体这一问题，并进一步检验一个更关键的假设：跨问题记忆是否真的能提升 agent 在新问题上的准确率。作者把这两个问题分开处理：GitOfThoughts 先提供一个版本化推理基底，再用同一个 agent 框架替换不同记忆存储，测试记忆本身是否带来收益。

评推翻Agent记忆有用共识的反常识工作，预注册实验设计和零结果对做长上下文、内置记忆或Agent的研究员是强信号，必须看§4的实验细节。
Pavan C Shekar,Abhishek H S,Aswanth Krishnan
