When Does Visual Generation Help Visual Understanding in Unified Multimodal Models?

这篇工作要回答的不是“统一多模态模型能不能做视觉生成”，而是更具体的一个诊断问题：视觉生成在什么条件下真的能帮助视觉理解。现有结论之所以摇摆，作者认为主要有三类评测混淆：样本难度混在一起、不同生成辅助范式没有在统一设置下比较、生成与理解在闭环中纠缠导致失败归因不清。论文因此把问题从方法宣称转成评测诊断：如果把难度、范式和 oracle 条件都控制住，视觉生成到底是在帮忙、添噪声，还是误导理解。

评对统一多模态模型（如 Chameleon）中'生成反哺理解'的假设进行了很好的诊断，指出当前瓶颈在理解端而非生成端，做统一建模的值得看其 Oracle 实验设计。

Where a New Concept Must Enter: Entry Point Gates Cross-Task Usability in Unified Multimodal Models

这篇论文研究统一多模态模型里一个很具体、也很容易被混淆的问题：理解任务和生成任务之间到底有没有“架构内部的知识迁移通道”，以及这个通道在什么位置才真正可用。作者刻意避开 joint training 中数据重叠带来的归因混乱，构造一种污染可控的概念注入实验：把一个全新的视觉概念和伪词只通过单一方向写入模型，再测试另一方向是否能使用。核心问题不是联合训练有没有涨点，而是模型内部哪些共享计算真的支持跨任务导出。

评非常 clean 的控制实验，揭示了 VLM 中理解和生成任务不对称的架构根源，对设计统一多模态架构极具启发，建议细读实验设计和 Entry Point 的分析。

STBridge: Shared-Target Alignment for Bridging Understanding and Generation in UMMs

当前统一多模态模型（UMM）仅在架构层面整合视觉理解与生成能力，但缺乏显式的语义对齐约束。面对同一用户意图，理解路径输出的文本描述与生成路径输出的图像在细粒度语义维度（实体、属性、空间关系、局部细节等）存在明显偏差，无法锚定到同一目标视觉状态。

评这篇该看的是问题定义，不是编辑结果；它提醒你‘共享骨干≠共享语义’，做原生多模态预训练时应把跨输出一致性单独量化并进训练目标。

Refinement via Regeneration: Enlarging Modification Space Boosts Image Refinement in Unified Multimodal Models

统一多模态模型（UMM）做 T2I 生成时，如何把“初次生成的图”进一步提升到更高的 prompt 对齐上限。论文指出主流的“先理解差异→生成编辑指令→局部编辑”(RvE) 会被两类约束卡住：编辑指令对 mismatch 的描述天然粗糙且不完备；编辑任务要求未编辑区域像素级保持，导致可修改空间过小，难以做结构性修正（多物体、关系、布局类 prompt 尤其明显）。

评只看方法和失败案例即可；它提醒 UMM 生成闭环里，过强 preservation 约束会限制纠错空间。
