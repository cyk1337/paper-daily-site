b:T567,1) Benchmark (UniKE): each edit defines a textual fact rewrite (q, y -> y'), plus an image prompt p_img and a visually checkable implication t_vis, evaluated via a VQA query q_vqa on the generated image. This makes cross-modal edit transfer automatically testable.
2) Edit coverage: attribute edits (intrinsic visual properties like color/pattern) and relation edits (depictable relations like location/occupation), with increasingly compositional prompts to stress generalization.
3) Baselines: apply standard parameter-editing methods to fix the text answer, then test whether image generations change accordingly.
4) Reasoning-augmented parameter editing: a protocol-level intervention. The model is prompted to produce an intermediate textual reasoning/statement that explicitly verbalizes the edited fact, which is then used as stronger conditioning for image generation. The hypothesis is that edited knowledge remains latent unless activated in the textual context.
5) Mechanistic analysis: argues for a conditioning-pathway bottleneck—edit-induced representation changes that suffice for text recall can be attenuated before reaching the image generator (especially with explicit projection interfaces), or be too weak to override strong visual priors.
