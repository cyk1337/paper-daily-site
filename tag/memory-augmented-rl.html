Multi-Turn Reasoning When Context Arrives in Pieces: Scalable Sharding and Memory-Augmented RL

这篇工作处理的是多轮对话里信息分片到达时，模型明明已经见过全部关键信息，却仍然在最终求解时明显掉点的问题。作者把这个现象放在 Lost in Conversation 框架下，进一步指出两个更具体的训练瓶颈：一是现有多轮碎片化数据太贵，难以支撑 RLVR 规模训练；二是让模型始终依赖完整历史并不是一个稳健策略，因为历史越长，检索和整合越差，训练时也缺少一个明确的“跨轮压缩与保留”机制。论文想解决的不是普通长上下文 QA，而是增量式信息暴露下，模型如何在每一轮主动写出可持续使用的中间记忆，并靠最终可验证奖励把这种能力学出来。

评只看 sharding pipeline 和 full-history 对照；若结果扎实，它会削弱“长上下文训练自然学会增量状态”的 prior。
Shu Tong Luo,Wenqin Liu,Rui Liu,Mingming Gong,Jiaxian Guo
