9:T45c,BVB (Blender-VideoBench) evaluates agents by asking them to reconstruct egocentric indoor videos as animated Blender scenes under a standardized protocol. The benchmark uses 288 test clips from VSI-Bench and evaluates reconstructions against 5,130 spatiotemporal QA pairs.

To ensure comparability, the authors provide a minimal harness (Mini-BVB) with only two actions: request video frames (by timestamp or uniform sampling) and execute commands / Blender Python code inside a Docker sandbox. There is no fixed step/frame budget; instead, each scene has a shared spend cap. External asset libraries are disallowed, forcing reconstruction from primitives and explicit camera animation, and requiring the agent to output an editable Blender file.

Scoring is two-axis: Dual VQA (DV) measures semantic retention by asking the same questions on the source and the rendered reconstruction, counting only questions the judge answers correctly on the source; Latent Similarity (LS) measures perceptual match via frozen V-JEPA 2.1 embeddings.
