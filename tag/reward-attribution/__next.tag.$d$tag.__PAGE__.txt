b:T73b,The method uses a two-level reward design. The model is prompted to produce structured parallel reasoning with explicit tags such as <Parallel>, <Path>, and <Summary>, separating path generation from final aggregation. Training then combines: (1) an outcome reward at the summary/final-answer level, typically based on correctness, and (2) a process reward at the individual-path level.

The core idea is to define the process reward with Shapley values. A set of reasoning paths is treated as a cooperative game, each path is a player, and the utility of a coalition is the quality obtained when a subset of paths is provided to the summarization/evaluation mechanism. Shapley value is then used to measure the average marginal contribution of each path across different coalition contexts. This is a natural fit because the value of a path is not intrinsic; it depends on whether it complements, duplicates, or contradicts other paths.

Exact Shapley computation is exponential in the number of paths, so the paper uses Monte Carlo permutation sampling. For sampled path orderings, it measures the utility gain when a path is added to the current prefix coalition, and averages these gains to estimate the path’s Shapley value. This makes the method tractable.

A Generative Reward Model is used to score the utility of different path subsets, providing the coalition values needed for Shapley estimation. The resulting training signal combines global correctness pressure with fine-grained path attribution. Optimization is built on top of GRPO rather than introducing a new policy optimization algorithm. Relative to prior systems such as Parallel-R1, the main difference is not the existence of parallel reasoning itself, but the explicit decomposition of reward across paths instead of treating the whole path set as one undifferentiated unit.c:T56f,The experiments are centered on mathematical reasoning benchmarks, with emphasis on Pass@k, especially Pass@16, and on training stability. The headline result reported in the paper is an average 42.3% improvement on Pass@16 over a strong parallel-thinking baseline. That suggests the method is better at converting parallel sampling budget into useful candidate diversity.

From the experimental narrative, the key comparisons include SFT-style parallel reasoning, standard outcome-level RL, and the proposed path-attributed RL. The main takeaways are:
1. Fine-grained attribution beats uniform reward sharing, indicating that credit assignment is a real bottleneck.
2. Training is more stable and converges faster, consistent with the claim that mis-rewarding bad paths injects optimization noise.
3. Monte Carlo Shapley remains useful with a limited number of samples, so the method does not require highly accurate Shapley estimates to help.

The most informative ablations are likely the usual ones: outcome reward only vs process reward only vs both; number of paths; number of Monte Carlo samples; with or without the generative reward model; and robustness when path quality is highly uneven. The excerpt does not expose all table values, but the central empirical claim is clear: the gain comes from better path-level reward allocation rather than from the prompting structure alone.d:T478,This is a skim paper, not one that requires line-by-line study. Start with the introduction and isolate the central criticism: summary-level reward lets ineffective paths get positive updates. Then read the method section with three questions in mind: how the parallel reasoning structure is organized, how coalition utility is defined and scored by the generative reward model, and how Monte Carlo Shapley is approximated in practice.

In experiments, prioritize the main result table and the training curves. If time is limited, verify three things: whether Pass@k gains are consistent, whether the benefit is really tied to path-level attribution, and whether the evidence for improved stability is convincing.

Two deeper questions are worth keeping in mind. First, whether the Shapley-based reward is aligned with the policy objective or mainly acts as heuristic reward shaping. Second, whether errors in the reward model can amplify attribution noise. Those questions matter more than the headline number if one wants to judge whether this approach can scale to larger reasoning RL settings.
