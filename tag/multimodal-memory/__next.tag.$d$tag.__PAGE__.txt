9:T798,The contribution is primarily dataset design plus a controlled diagnostic protocol.
- Data format: persona-grounded conversational histories spanning 11–24 sessions; each query is embedded in a chronological haystack and covers six question families (single-session extraction, cross-session selection/bridging, knowledge updates, temporal-plan disruptions, and refusal-after-evidence-removal controls).
- Deterministic evidence chains: each item requires 1–3 facts organized as Narrower/Selector/Answer roles (NAR* SEL* ANS). A per-fact deletion test enforces necessity: removing any required fact makes the question unanswerable.
- Modality gaps: at least one required fact must rely on a native modality relation that a text-only/caption-based agent would lose, with dialogue constraints preventing leakage.
  - Images: background detail, fine-grained attributes, spatial configuration.
  - Video: action ordering, state transitions, repetition counts (constructed so generic captions preserve the event but lose the selector).
  - Audio: prosody-based discrimination (happy/unhappy tone with neutral wording) across ≥2 candidates; intentionally exposes write-path loss under ASR/captioning.
- Four-stage diagnosis under matched controls:
  1) Write: compare storage/representation choices (e.g., textualization vs more faithful forms).
  2) Retrieve: measure whether all required units are found.
  3) Deliver/packing: measure whether retrieved artifacts survive being packed into the reader request under media caps.
  4) Read: with gold delivered chains, test whether the reader can integrate evidence across modalities and sessions.
  Plus abstention controls to test refusal behavior when evidence is missing.
- Automated generation pipeline: LLM-driven chain design with validate-and-repair loops, programmatic checks over multiple failure modes, synthetic media generation (image/video/TTS), and human audits for well-posedness.a:T78f,LMMR has four main components. First, it builds a shared concept space across modalities. Instead of converting images into text summaries, it projects textual hidden states and visual patch features through modality-specific projectors into a shared sparse autoencoder dictionary. Sparse activations in that dictionary serve as common semantic addresses. This is meant to preserve more visual fidelity than captioning while providing a more structured alignment layer than raw embedding similarity.

Second, those shared concept addresses are used to build a query-conditioned memory graph. Visual evidence is linked to its dialogue turns, timestamps, and session context, so the system can reason not only about relevance but also about temporal validity. This is a key distinction from flat multimodal retrieval: the model must decide which state of an entity is currently valid, not merely which past observation looks related.

Third, the graph is encoded to aggregate cross-modal and temporal dependencies, while native visual tokens are still retained in the multimodal prefix. This dual path is important: concept abstraction organizes evidence, but raw visual tokens preserve details that abstraction may discard. The graph readout is then injected as a residual into a continuous latent rollout, allowing the model to integrate textual, visual, and temporal evidence in latent space before a grounding token returns the process to lexical generation.

Fourth, the overall design is neuro-symbolic in a restrained sense. The symbolic part is not a hand-written logic engine, but a sparse concept-address layer plus graph structure that makes evidence composition more explicit. The neural backbone still performs the final fusion and generation. Compared with flat cross-modal fusion, the main novelty is treating memory organization as a separate stage rather than simply concatenating retrieved items into the model context.b:T4a5,The evaluation uses Mem-Gallery and MemEye, covering nine long-term memory task categories and twelve settings with varying visual-detail requirements and memory complexity. First, LMMR improves over textified-memory approaches on tasks that require fine-grained visual grounding, because it avoids premature compression of visual evidence. Third, the query-conditioned memory state itself appears to matter: the gain is not only from better retrieval, but from organizing retrieved evidence before answer generation.
