ViCoStream: Streaming VideoLLMs Can Run Beyond 100 FPS with Stage-Wise Coordinated Inference

这篇工作解决的是流式 VideoLLM 的系统瓶颈问题，而不是单点模块加速。作者指出，真实部署里的 streaming VideoLLM 同时受两个目标约束：视频输入吞吐必须跟得上实时流，用户发问时首 token 延迟又要低。现有方法常分别优化视觉编码、token pruning、KV 压缩等局部模块，但没有回答一个更关键的问题：整个系统能否长期稳定地“边看边处理”，并在任意长视频上维持固定延迟和内存预算。ViCoStream 的核心问题因此是，如何把流式 VideoLLM 视为一个多阶段协调流水线，识别并约束最慢阶段，使吞吐和查询延迟都可控，而不是让瓶颈在不同模块之间来回转移。

评只看系统分解和瓶颈迁移实验；若setup干净，视觉token预算与prefill调度可直接影响内部VideoLLM serving设计。
