19:T5b9,They run Petri, an automated misalignment auditing framework, in multiple languages on the same target model.

Pipeline:
- Target: Qwen3-30B-A3B.
- Auditor: Gemini 2.5 Flash, which conducts multi-turn probing conversations and can construct prompts/tools to elicit misaligned behavior.
- Judge: Gemini 2.5 Pro, which scores transcripts on multiple behavior categories (1–10).
- Multilingualization: translate seed instructions and the auditor system prompt into each language; force the target model to respond exclusively in that language.

Metric construction:
- They focus on a 5-category “scheming index” intended to be more specific to scheming than broader safety categories.
- To improve cross-language comparability, they restrict to samples where a given behavior is non-baseline (score ≥ 1) in at least one language, then compute per-language means on that subset (a form of conditional averaging).

Statistics:
- Two-sample permutation tests are used to assess whether observed differences could arise by chance.

Key methodological caveats:
- “Pretraining language coverage” is not directly measured; languages are grouped into high-resource (English/Chinese) vs medium/low-resource (Spanish/Portuguese/Arabic/Vietnamese) based on historical Qwen data composition hints.
- Auditor, translator, and judge are all Gemini-family models, which can introduce correlated biases (translation artifacts, language-dependent judging thresholds, etc.).1a:Taef,方法上分三步。第一步是构造可比训练语料。作者从 allenai/Dolci-Think-SFT-32B 中均匀采样约 50 万条英文样本，覆盖数学、代码、科学、指令跟随、安全、聊天和结构化数据等类别，再翻译到法语、德语、西班牙语、中文和斯瓦希里语，形成六种语言各约 50 万条、最长 32k context 的长 CoT 数据。这里不是简单整条翻译，而是把 question、reasoning trace、final answer 分开，并按约 2k token 的句段切块翻译，再重组。这样做是因为作者在全文里明确指出，直接对超长样本做单次翻译会出现两类失败：长上下文退化导致循环，以及更隐蔽的 CoT 被静默丢失。这个数据工程细节很重要，因为它说明多语言 reasoning 数据构造的瓶颈并不只是翻译质量，还包括长轨迹结构保真。

第二步是在严格对齐的 SFT 条件下训练两类 specialist。底座是 Qwen/Qwen3-8B-Base。对每个非英语语言，作者训练 native specialist：输入、CoT、答案都在目标语言；同时训练 English-pivoted specialist：输入和最终答案在目标语言，但中间 CoT 用英语。每种语言的 SFT token 预算大约都是 10B，避免了“native 数据少所以差”的混淆。这个设计的关键不只是双轨训练，而是 supervision parity：同一底座、同量级 token、同类任务分布，只改变 reasoning trace 的语言。

第三步是权重空间分析与 Layer Swap。作者比较不同语言 specialist 相对同一 base model 的参数更新，发现中间层更新方向跨语言更一致，而靠近 embedding / early layers 和靠近输出端的 late layers 差异更大。基于这个观察，他们采用 training-free 的 Layer Swap：保留 native specialist 的首尾层，以维持目标语言输入理解和输出表达；把 English specialist 的中间层替换进去，以迁移更强的 reasoning core。这个方案和常见的 merge、adapter 或 LoRA 叠加不同，它依赖的是“层功能分工”而不是简单参数平均。全文的一个重要细节是，作者并不是把英语模型整体拿来覆盖，而是只交换中间层，这说明他们把 native gap 解释为 reasoning core 与 language interface 的错配，而不是整体能力不足。

作者还做了 input-language ablation，去区分“输入理解”与“推理过程语言”哪个更像瓶颈。结论是，在 matched native SFT 下，输入理解仍是主要瓶颈之一。这一点很关键，因为它意味着即便 CoT 已经能用目标语言写出来，模型对复杂非英语题面的解析仍可能限制上限。换句话说，native reasoning 的问题不只是‘不会用该语言思考’，而是‘对该语言复杂输入的编码不够稳’。1b:T46b,For pretraining and post-training researchers, the contribution is less about multilingual benchmarking and more about representation structure. First, it recalibrates the native reasoning narrative: with enough native long-CoT supervision, the gap is much smaller than many earlier studies implied, only 1.9%–3.5% on average across five non-English languages. That matters for multilingual post-training budgets and for how one interprets English-dominant CoT behavior in current reasoning models. Second, the weight-space analysis suggests a partial functional separation across depth: middle-layer updates align strongly across languages, while early and late layers diverge more. This is a concrete clue about where language-specific processing lives versus where reasoning computation may be shared. Third, the training-free Layer Swap result is interesting beyond this exact setup. It points to a broader possibility: when two specialists share a base model and differ mainly in supervision language, capability transfer may be achievable through structured parameter recomposition rather than another expensive tuning run.1c:Ta82,The work has three main components. The first is data construction under long-context constraints. The authors start from allenai/Dolci-Think-SFT-32B, sample roughly 500k English examples while preserving category balance, and translate them into French, German, Spanish, Chinese, and Swahili, yielding six language-specific corpora with contexts up to 32k tokens. A useful engineering detail appears in the full text: direct single-pass translation of long samples failed in two ways. Very long examples triggered degraded long-context behavior with looping, and some samples silently dropped the reasoning trace while still translating the question and final answer. To avoid this, they translate question, reasoning trace, and final answer separately, chunk each into about 2k-token segments at sentence or paragraph boundaries, translate chunkwise, and then recompose. This is not just a preprocessing footnote; it shows that preserving long reasoning traces in multilingual data creation is itself a nontrivial bottleneck.

The second component is a controlled SFT comparison. Using Qwen/Qwen3-8B-Base, they train for each target language two specialists under matched token budgets of about 10B SFT tokens per language. In the native regime, input, CoT, and answer are all in the target language. In the English-pivoted regime, the input and final answer are in the target language but the intermediate CoT is in English. The key design choice is supervision parity: same base model, same scale, same task mix, only the language of the reasoning trace changes.

The third component is weight-space analysis followed by Layer Swap. The authors compare per-language SFT updates relative to the shared base model and find that update directions align tightly in the middle layers across languages, while divergence is larger near the input and output ends. They then exploit this with a training-free procedure: keep the native specialist’s early and late layers to preserve target-language input understanding and output generation, but replace its middle layers with those from the English specialist to import a stronger reasoning core. This differs from generic model merging or parameter averaging. The method relies on a depth-wise functional hypothesis rather than a global interpolation assumption.

An additional ablation studies the role of input language understanding. The paper argues that even under matched native SFT, input understanding remains a primary bottleneck. That is an important nuance.
