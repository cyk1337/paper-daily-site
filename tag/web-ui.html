ComponentBench: Diagnosing Component-Level Failures in Computer-Use Agents

现有的计算机使用 Agent 评测要么是长程工作流，要么是原子的 GUI 基础测试，缺乏针对现实中组件级交互（如切换按钮组）的诊断性评测。

MT-Web2Code: Benchmarking Coding Agents on Multi-Turn Regional Reconstruction and Localized Modification

现有面向网页UI生成的多模态编码基准大多采用单轮全页生成设置，仅能评估模型一次性生成完整页面的能力，无法匹配真实前端开发中迭代修改现有代码库的工作流，也无法衡量模型在多轮编辑中保留非目标区域内容、阻断错误跨轮传播的能力。

评把“局部改动不许破坏其余页面”做成双轴指标是对的；只需看任务构造与指标定义，模型对比结果当作弱信号。
Qiming Li,Shujie Hu,Haohan Liu,Xiaocheng Feng,Songxiang Liu,Guanglu Wan
