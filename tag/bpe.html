Pruned BPE: Post-training Visibility Pruning and Token Reallocation for Byte Pair Encoding

这篇工作处理的是 BPE 词表分配里的一个老问题：BPE 的训练目标是逐步构造高频 merge，但语言模型真正看到的是最终编码后的可见 token 集。两者并不一致。很多 merge token 在训练过程中有用，只是作为更长 token 的中间节点存在；等最终编码完成后，这些 token 几乎不会真正出现在语料里。标准 BPE 仍然把它们放进模型可见词表，等于把有限的词表预算花在低暴露、低训练频次的 token 上。论文要解决的不是“怎么剪小词表”，而是“在保持可见词表大小不变的前提下，如何把可见词表从中间构造节点里解耦出来，重新分配给更值得暴露给模型的 token”。

评这个点抓得准：BPE 确实把不少词表浪费在“只参与构造、不该暴露给模型”的节点上；建议立刻做 internal ablation，看 token 数下降能否换成真实 pretrain gain。
Kenny Shao

In-Place Tokenizer Expansion for Pre-trained LLMs

这篇论文解决的是一个很实际的预训练资产迁移问题：模型已经预训练完，tokenizer 却不再适合新的部署语言分布。原 tokenizer 对英语、代码和少数语言压缩较好，但对 Hindi、Vietnamese、Thai 等语言切得很碎，导致同样文本需要更多 decode step。对云端大模型，扩大词表的参数成本通常不敏感；但对端侧模型，embedding / LM head 的词表维度会直接影响显存占用和每 token 解码带宽。因此问题不是简单地“换一个更大的 tokenizer”，而是在不重训模型、不丢掉已有能力、且控制端侧成本的前提下，把 tokenizer 原地扩展到更好的多语覆盖。

评这是少见的“可逆兼容”的 tokenizer 升级方案，直接影响多语扩展与端侧带宽；优先读方法与对照实验，确认是否真能免大规模再训。

Equity with Efficiency: An Empirical Study of Tokenizers for Multilingual Large Language Models

这篇论文解决的是多语言 LLM 中一个长期被低估但很基础的问题：tokenizer 的结构偏置会系统性抬高非拉丁、低资源语言的 token 长度，从而同时影响训练效率、推理成本、有效上下文长度和跨语言能力公平性。过去不少工作各自提出 parity-aware BPE、形态学驱动分词、BLT 这类替代方案，但通常只和 byte-level BPE 做单边比较，缺少在统一数据、统一词表规模、统一训练预算下的直接对照。作者要回答的不是“某个新 tokenizer 能否赢过 BPE”，而是“在真实多语言建模约束下，不同公平化 tokenizer 到底带来什么代价和收益，收益出现在哪一层：压缩率、公平性、还是下游建模表现”。

评tokenizer 论文大多停在压缩率，这篇至少把变量带进了 1.5B 训练；先看 controlled setup 和各语言 token inflation 表，若设计干净，值得纳入 multilingual recipe。

SuperBPE: Space Travel for Language Models

现有主流BPE分词器在预分词阶段强制按空格拆分，仅能生成不跨词边界的子词单元，但空格并非可靠的语义分隔符，无法覆盖多词固定表达、跨语言语义单元的建模需求，同时当词表规模扩大时，常规BPE的序列压缩效率很快进入边际收益递减区间，冗余的token既提升训练与推理成本，也限制了模型的语义表示性能。

评这篇会直接动到 tokenizer 的默认 prior：先看编码效率表，再看等词表、等算力下 LM 质量是否守住；若成立，内部词表实验该把“跨空格 merge”列为正式变量。

From Where Words Come: Efficient Regularization of Code Tokenizers Through Source Attribution

代码类 BPE tokenizer 在“仓库/语言来源高度不均衡”的训练语料上容易过拟合：把某些大仓库、重复模板、随机/压缩变量名、甚至损坏文本中的高频片段合并成 token，导致大量 token 在真实训练/推理中几乎不出现（under-trained / unused tokens）。这些 token 不仅浪费词表容量与训练预算，还可能带来推理不稳定、幻觉与 token 级攻击面。论文要解决的是：如何在不推翻 BPE 框架的前提下，用“来源归因（source attribution）”对 BPE 的合并目标做正则化，减少来源单一的合并，从而显著降低 under-trained token。

评把代码tokenizer的“词表过拟合”变成可训练的正则项很实用；建议直接照着source-attribution权重重训一次BPE，看unused token与跨仓库泛化是否立竿见影。
Pavel Chizhov,Egor Bogomolov,Ivan P. Yamshchikov
