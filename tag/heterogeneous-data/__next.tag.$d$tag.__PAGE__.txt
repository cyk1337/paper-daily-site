9:T41f,FedTAR (Task-awARe Federated fine-tuning) uses routing statistics as a proxy for latent task structure and ties it to update aggregation:
1) During local fine-tuning, each client collects routing features such as average expert utilization, expert co-activation patterns, and routing confidence.
2) Apply SVD on routing features to obtain low-dimensional task coordinates that make clients clusterable by implicit task preference.
3) Apply SVD on local parameter updates to extract dominant update directions.
4) Perform task-aware clustering and aggregation (within and across clusters) based on task coordinates, rather than indiscriminate averaging.
5) Learn a mapping between the task space and the update space, then reconstruct the aggregated global update so it remains aligned with task-specific dominant directions—aiming to preserve expert specialization and reduce conflicts on shared experts.
