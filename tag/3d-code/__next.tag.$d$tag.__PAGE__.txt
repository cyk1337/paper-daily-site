9:T732,The system has two main components. The first is 3DCodeVerse-2M. Instead of merely aggregating public code, the authors perform substantial representation unification and executabilization. They collect diverse 3D sources, including CAD construction sequences, Blender scripts, Shadertoy programs, Three.js / React Three Fiber projects, Thingiverse assets, and more. They then convert heterogeneous formats into runnable source code: for example, DeepCAD construction sequences are translated into CadQuery programs, and Articraft geometry routines are inlined while preserving URDF articulation specifications. Each sample is packaged as a standalone executable program with source files, assets, textual descriptions, provenance, and available verification records. The hard part here is not scale alone, but removing specialized or unavailable dependencies so that samples can actually run in the declared environment. The second component is the 3DCodeVerse Harness. It decomposes a complex 3D project into a DAG of coding and assembly tasks, lets multiple agents generate and integrate source files, executes and renders the result, and then uses an independent judge agent plus spatial consistency checks to evaluate it. The spatial checks are important because they prevent visually plausible but geometrically invalid outputs from scoring well. Feedback is converted into localized repair objectives, enabling repeated execution-evaluation-revision cycles. This differs from generic ReAct-style loops because the process is centered on executable artifacts, structured verification, and targeted repair rather than open-ended natural-language reflection. The harness is also designed as a data engine: it records successful programs, failed attempts, targeted repairs, and preference comparisons for later SFT and preference learning.a:T453,The headline results are straightforward. Fine-tuning on 3DCodeVerse-2M substantially improves executable 3D code generation: on 3DCodeBench, execution rates reach 84.9% for a 9B model and 92.9% for a 27B model. This suggests the dataset is effective at teaching models to produce runnable 3D programs. In addition, the Harness improves generation quality by 15.5 to 29.1 points over one-shot generation across coding agents, indicating that iterative execution-judging-repair is necessary for complex 3D projects rather than a marginal add-on. The paper also emphasizes support for projects with thousands of lines of code, which makes the setup closer to real software engineering than static object generation. A useful detail is that evaluation is split into execution success, visual assessment, and spatial/structural checks, making it stricter than render-only evaluation.
