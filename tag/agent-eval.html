What Twelve LLM Agent Benchmark Papers Disclose About Themselves: A Pilot Audit and an Open Scoring Schema

这篇工作处理的不是“如何把 agent benchmark 做得更强”，而是一个更基础的问题：当前很多 LLM agent benchmark 论文没有把一次评测运行的关键条件交代清楚，导致同一模型、同一 benchmark 名称下的分数常常不可比，也难以复现。全文把问题单位明确设成“agent run”而不是 benchmark 本身，即模型、scaffold、环境镜像、停止规则、grader 这些要素共同组成的一次运行。作者想回答的是：如果只要求论文和公开仓库提供足够让读者尝试忠实复跑的信息，那么现有论文到底披露了多少。

评做Agent评测或要复现Agent基准结果的研究员可参考其披露规范，避免实验结果不可复现的坑
