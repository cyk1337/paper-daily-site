18:T8ba,论文的技术路线是把“数据选择”当成完整 pipeline 来评估，而不是只比一个打分函数：

1）对照组设计：repacking vs natural long docs
- repacking：把短文本拼成 128K 序列，长度满足但跨段依赖弱。
- random-long：从自然长文档池随机抽样，保留真实长文档结构（跨章节引用、延迟指代、分布式证据）。
- 关键发现是：random-long 在更长评测长度上更占优，说明“真实长依赖结构”比“仅仅更长”更重要。

2）在固定候选池内比较多类 selector
- generic-quality：PPL、gzip compressibility 等。
- LLM-judge：用大模型打分判断文档是否“适合长上下文训练”。
- likelihood/dependency-aware：包括 LongFilter、Prospector、以及 LongPPL key-token density。
- 论文强调所有自然长文档 selector 都在同一候选池上操作，避免“语料不同导致结论不同”。

3）LongPPL-density 与 truncLongPPL
- LongPPL 的核心是定义 key token：该 token 在长上下文条件下的 log-likelihood 相对短上下文显著提升（超过阈值 α，同时满足 β 等条件）。文档分数是 key token 的密度（比例）。直觉是：密度高的文档包含更多需要远距离信息才能预测的监督信号。
- full-span 计算昂贵（要在接近目标长度 L 的 span 上算长/短上下文对比）。论文提出 truncLongPPL：只在文档前缀的某个比例 r 上计算密度，用它近似全文排序。
- 这不是简单的“截断省算力”，而是验证了：对 128K 目标长度，算 reference span 的前半段就能保留大部分选择收益，并带来端到端 2.28× 的打分加速（文中写作 2.28× 2.28×）。

1) Baseline pipeline comparison: repacking vs natural long docs
- Repacking constructs 128K sequences by concatenating shorter texts, satisfying length but typically lacking cross-section dependencies.
- Random-long samples genuine long documents, preserving delayed references and distributed evidence.
- The study finds random-long performs better at longer evaluation lengths, suggesting that real long-range structure matters more than mere sequence length.

2) Controlled selector comparison within a fixed candidate pool
Selectors fall into three families:
- Generic quality: perplexity, gzip compressibility.
- LLM-judge: a model-based “is this good long-context training data?” scorer.
- Dependency/likelihood-aware: LongFilter, Prospector, and LongPPL-based key-token density.
All natural-long selectors operate on the same candidate pool to avoid confounding from corpus differences.

3) LongPPL key-token density and truncLongPPL
- LongPPL defines “key tokens” whose log-likelihood improves substantially when conditioning on long context vs short context (thresholded by parameters like α and β). Document score is the density (fraction) of such tokens, aligning selection with documents that actually require long-range context.
- Full-span LongPPL scoring is expensive at scale. truncLongPPL computes key-token density on a truncated prefix (fraction r of the reference span) and uses it as a proxy for full-span ranking.
- Empirically, scoring only the first half of the reference span at 128K yields downstream performance close to full-span scoring, with an end-to-end scoring speedup of about 2.28×.

这套设计有两个关键点，缺一不可。

第一，per-stream embedding replication。若只是简单复制同一个 token n 次，多个 stream 的初始状态几乎相同，模型很难学出有分工的内部计算。作者为每个 stream 复制一套词嵌入表，把 token x_i 扩成 (E1(x_i), E2(x_i), ..., En(x_i))。continued pretraining 过程中，这些 embedding table 会逐渐分化，让不同 stream 承担不同的表示角色。这个设计很像给“同一个 token 的多步内部思考”提供不同起点，否则 sequence expansion 很容易退化成重复计算。

第二，persistent intermediate KV。此前一些 length-scaling 方案，比如 PHD，为了不让推理成本爆炸，会把中间重复 token 的 KV 设为 transient，只在当前 token 内部起作用，不作为后续位置的上下文保留。这样虽然便宜，但中间计算不能跨位置积累，能力上更像局部 refinement。Hidden Decoding 反过来保留所有 stream 的 KV，让前面位置在中间 stream 上形成的计算结果，能被后面 token 继续访问。作者认为，只有这样，中间 stream 才不只是“当前 token 的额外层数”，而是能形成真正可持续的 latent computation。

问题随之而来：如果对 nL 长序列做全连接注意力，成本会从原来的 O(L^2) 变成 O(n^2 L^2)，在长上下文和大模型上不可接受。为此论文提出 Stream-Factorized Attention。做法是把跨 stream 的信息交换限制在少数层：大多数层只在各自 stream 内做注意力，只有少数“交换层”允许 stream 间通信，而且这些层沿用 base model 原本的注意力模式，比如 sliding-window 或 full attention。这样，绝大多数层避免了对整个 nL 序列做稠密注意力，额外成本更接近对 n 的线性增长，而不是平方增长。

Two design choices are central.

First, per-stream embedding replication. If the same token were simply repeated n times with the same embedding table, the streams would start from nearly identical states and the extra computation could collapse into redundant processing. The paper therefore replicates the vocabulary embedding table into n stream-specific tables, so token x_i becomes (E1(x_i), E2(x_i), ..., En(x_i)). During continued pretraining, these tables can diverge and give different streams different representational roles.

Second, persistent intermediate KV states. Some earlier length-scaling approaches keep repeated-token KV transient so that intermediate computation helps only within the current token and does not persist as context for later positions. That keeps inference cheaper, but it limits the extra computation to local refinement. Hidden Decoding instead retains the KV of all streams, allowing latent computation accumulated at earlier positions to remain available to later tokens. This is the paper’s key argument for why sequence expansion can become capability scaling rather than mere local smoothing.

The resulting challenge is attention cost. Full attention over an nL-length sequence would scale as O(n^2 L^2), which is not viable for long contexts and large models. The paper introduces Stream-Factorized Attention to control this. Most layers attend only within each stream, while cross-stream communication is allowed only in a subset of layers. Those exchange layers follow the base model’s original attention pattern, such as sliding-window or full attention. This avoids dense attention over the entire expanded sequence in most layers, making the added cost much closer to linear in n than quadratic.

Relative to recurrent-depth Transformers, the distinction is sharp. Looped models reuse depth and create explicit recurrence through the same blocks, which clashes with pipeline execution. Hidden Decoding flattens extra computation into the sequence dimension and preserves a standard single-pass training graph. Relative to naive token repetition, it adds the ingredients needed to make repeated positions useful as latent compute slots: stream-specific initialization, persistent memory, and controlled cross-stream mixing.2c:T659,The experiments test two claims: scalability to frontier-scale models and capability gains from increasing the expansion factor.

The 80B model improves on all nine shared benchmarks, with reported gains including SciCode 45.8 to 50.0 and PHYBench 69.8 to 73.8. The 617B model also improves on all nine shared benchmarks, including GPQA Diamond 89.1 to 91.2, HLE 33.6 to 35.4, and FrontierMath 49.0 to 51.0. An important experimental choice is that these comparisons use the same early SFT-only post-training recipe, without RL. That makes the comparison cleaner and supports the claim that the gains come from continued pretraining with Hidden Decoding rather than from downstream alignment differences.

For scaling with expansion factor, the paper runs a progressive study on the 80B model, increasing n from 2 to 4 to 8. MMLU improves monotonically from 85.0 to 86.7 to 87.5, while Pile-test BPB drops from 0.386 to 0.378. The BPB result matters: it shows that Hidden Decoding improves the underlying language-modeling objective, not only reasoning benchmarks after post-training.
