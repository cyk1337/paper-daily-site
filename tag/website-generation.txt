18:T75a,The method has three tightly coupled components. First, scaffold-driven structured generation: instead of asking the model to create an entire project from scratch, the policy operates inside a pre-validated React template. The template already guarantees core build configuration, routing skeleton, and server setup. The model mainly fills in or edits components and page logic. This sharply reduces the combinatorial search space and removes many low-level failure modes from RL exploration.

Second, a hierarchical verification-and-rendering pipeline filters outputs before expensive reward modeling. The pipeline checks structural compliance, required artifacts/actions, project files, commands, and selected content rules, then attempts automated build and rendering. This stage serves two purposes: it rejects invalid samples early, and it provides dense penalties for structural hallucinations such as missing files, malformed commands, or broken project layouts.

Third, a cascaded multimodal reward uses a VLM only after the sample passes the lower-level gates. The VLM evaluates rendered websites for layout quality, typography consistency, visual hierarchy, stylistic alignment with user intent, and visual cues of functionality. The important design choice is the cascade. The VLM is not used as a universal judge over raw generations; it is applied only to samples that are already structurally plausible and renderable. That reduces reward noise and cost.

Compared with multi-agent website generation, this avoids brittle interface mismatches between specialized agents. Compared with pure supervised finetuning, it optimizes final project quality rather than imitation of reference code. Compared with single-score reward schemes, it is closer to reward shaping: hard constraints secure minimum viability, then softer multimodal signals improve higher-level quality.19:T64e,The headline numbers are strong and easy to interpret. On a 7B base model, the valid render ratio rises from 30.56% to 95.89%, indicating that the scaffold plus hierarchical verification nearly eliminates the common failure mode of producing non-runnable projects. Aesthetic score improves by 44.32%, suggesting that the cascaded VLM reward does more than preserve executability; it also pushes visual quality upward. Functional quality increases from 1.59% to 29.21%, which is arguably the most important result because it shows gains in actual interaction and logic rather than merely better-looking screenshots.

The paper also claims that WebGen-R1 consistently outperforms much larger open-source models up to 72B and approaches DeepSeek-R1 671B on functional success. If the evaluation protocol is matched, that is a meaningful result: better reward design and action-space control can partly compensate for a large parameter gap on this task.

The most informative ablations are likely the expected ones. Removing the scaffold should hurt build/render success substantially. Removing hierarchical verification should reduce sample efficiency and destabilize RL because expensive multimodal rewards get wasted on invalid generations. Removing the VLM reward should preserve some functionality but degrade layout quality, style consistency, and prompt-aligned aesthetics.
