ReFlow: Replay-Driven Decoupling for Efficient RL Post-Training

这篇工作处理的是 LLM RL post-training 里的一个老问题，但切得更深：rollout 生成远比策略更新贵，而且多轮 agent 轨迹长度、工具调用时延、样本难度都高度不均，导致同步训练里 trainer 经常等数据，异步训练里又会因为 stale policy 过大而掉质量。已有异步系统主要是在“生成和训练并行”这一层做文章，仍然保留了批次级的数据依赖，trainer 还是会因为 fresh rollout 不够而停顿。ReFlow 要解决的是：能不能在不明显破坏 RL 稳定性的前提下，把 rollout 需求进一步降下来，把训练和生成真正解耦，并且让资源分配随 workload 动态变化。

评读系统设计和 replay ablation；若质量不掉，这会改变 RL 后训练里“轨迹只能用一次”的工程默认。

WEFT: Scaling Tool-Use Post-Training for General-Purpose Agents

WEFT 处理的是工具使用后训练中的信号可靠性问题。作者指出，单纯扩展可执行环境不够，因为训练样本来自完整的 agentic interaction system：环境、任务、agent harness 和 evaluator。任何一个环节出错，都会把环境 bug、不可行任务或 verifier 错误误当成模型失败，从而给 SFT/RL 引入错误监督。

评读系统分解和 failure attribution 部分；它提醒 agent 后训练的瓶颈常在 evaluator/harness，而不是环境数量。

SkillGym: Training Skill-Use Agents with Automatic Verifiable Environment Generation

核心问题是：如何把互联网上已有的 agent skill 转成可验证、可训练的 skill-use 数据，而不是只让 agent 在少数固定环境里从自身经验归纳技能。难点不在于收集 skill 文档，而在于构造 skill-critical 任务：任务必须真的需要理解和应用 skill，同时结果要能被可执行 verifier 稳定判断。

评构建可验证 Agent 环境并合成 SFT 数据的完整 pipeline，对关注 Agent 数据合成和后训练（post-train）的研究员有参考价值，重点看其 builder-reviewer 任务构造逻辑。
Renxi Wang,Mingshan Hee,Fajri Koto,Timothy Baldwin,Haonan Li
