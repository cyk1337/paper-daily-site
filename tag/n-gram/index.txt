- Empirical observation: GRPO revisits the same prompts across steps/epochs and the policy changes incrementally, so completions for a given prompt are highly repetitive over time. The paper quantifies this locality (48–96% coverage of a later rollout by a prior one; recurring spans of 7–23 tokens).
- Drafter: a per-prompt n-gram table built from a bounded window of recent rollouts. Given the current context, it proposes continuations via lookup (model-free), and the target policy verifies them using standard speculative decoding accept/reject, preserving the exact output distribution.
- Runtime co-design: naive CPU-host lookup can serialize with GPU decoding, causing large GPU idle due to host round trips. NgramRL introduces an asynchronous multipath prefetcher: during GPU verification, the CPU prefetches drafts for likely next-step verification outcomes (indexed by outcome states such as (j, b)). An adaptive fan-out policy (a causal budget allocator) decides which branches to prefetch so most steps avoid post-verification host synchronization; uncovered branches fall back to synchronous lookup without changing semantics.19:T48b,X-gram decomposes lookup augmentation into (1) token-to-memory mapping, (2) information extraction, and (3) injection, and addresses specific failure modes.
- Mapping: probability-balanced hybrid hashing. Head tokens get dedicated capacity; tail tokens share hash buckets, improving update density per effective row under Zipf statistics.
- Extraction: a lightweight ShortConv-based n-gram feature extractor (normalized SwiGLU ShortConv, multi-scale). It refines retrieved 1-gram vectors into local x-gram features to increase representational diversity and mitigate slot redundancy.
- Injection: mixed injection centered on the attention value stream (content pathway) plus optional inter-layer residual injection, modulated by depth-aware gating to match layer-wise demand.
- Training stability: stabilizes post-injection residual pathways and uses a sparse-aware LR schedule for token-indexed parameters.
