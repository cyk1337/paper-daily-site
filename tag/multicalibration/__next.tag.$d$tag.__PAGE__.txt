9:T520,The paper introduces reasoning-aware multicalibration: keep externally important groups (e.g., topics that must be calibrated for policy reasons) and add internally important groups derived from observable CoT properties (uncertainty markers, revisions, self-checking, considering multiple answers, etc.). Then run a standard post-hoc multicalibration procedure (greedy iterative corrections such as iterative histogram binning) over the union of these groups.

A deliberate design choice is to use CoT signal as *group definitions* rather than as extra features for the base scorer:
- Calibration on topics is preserved by construction because the multicalibration constraints explicitly include them.
- The method is post-hoc: the generator and the initial scoring function are fixed, so it can wrap any existing confidence signal.
- Because calibrated scores are not used as rewards, the approach reduces incentives for CoT manipulation and is less sensitive to CoT unfaithfulness, as long as the observable properties remain statistically linked to errors.
