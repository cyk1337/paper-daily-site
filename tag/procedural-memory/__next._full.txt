17:T6b5,PMD organizes online experience into a three-level procedural memory and uses that memory only on the teacher path during training. The deployed student has no inference-time memory dependency. Level-0 experience memory stores raw trajectories, rewards, and feedback. It has the highest fidelity but weak transfer. Level-1 insight memory reflects over multiple attempts on the same problem and extracts compact strategies and lessons, removing much of the trajectory-level redundancy. Level-2 behavior memory groups semantically related problems and distills reusable reasoning patterns across them; this has the strongest transfer but also the highest risk of becoming too coarse. Training proceeds in a co-evolving loop: the current policy generates rollouts, receives verifier feedback, writes new information into memory, and the refreshed memory then conditions a self-teacher that supervises the next policy update. This is the main departure from SDPO. In SDPO, the teacher is still largely episode-local, built from sibling rollouts or local feedback. In PMD, the teacher is additionally informed by what the model has learned in prior epochs, so supervision carries cross-episode procedural structure. The co-evolution claim is central. A frozen memory becomes stale as the policy changes its visited states; a frozen policy prevents memory from improving in quality as capability grows. Another important design choice is to avoid inference-time memory use. Many reflection or memory-agent methods improve performance by carrying external memory into deployment, but that adds system complexity and a train-test mismatch. PMD instead treats memory as a training scaffold whose purpose is to be internalized.18:T5cd,The headline results are fairly clear from the provided text. PMD is evaluated on two verifiable domains, SCIKNOWEVAL and LIVECODEBENCH, using Qwen3-8B and OLMo3-Instruct-7B as base models. Relative to GRPO and SDPO, PMD improves performance by 3.8–5.5% on SCIKNOWEVAL and 7.9–13.6% on LIVECODEBENCH. The most important evidence is mechanistic rather than just end-task gain: freezing either the memory while updating the policy, or freezing the policy while updating the memory, causes more than a 10% drop on SCIKNOWEVAL. That directly supports the claim that policy-memory co-evolution is the main source of improvement rather than an implementation detail. The paper also reports better test-time compute scaling: PMD continues to benefit from additional rollouts after SDPO starts to saturate, so the gap widens with rollout budget. That is consistent with the method's intent, since it aims to improve internalized procedural priors and teacher quality rather than only one-shot sampling success. The abstract also notes that combining Level-1 insight and Level-2 behavior memory gives the strongest distilled policy, suggesting that raw experience is too local while high-level behavior patterns alone are too coarse.
