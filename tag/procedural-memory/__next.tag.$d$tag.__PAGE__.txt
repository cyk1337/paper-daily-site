9:T8e7,APEx maintains two levels of experience. Instance-level memory stores summarized execution traces for concrete queries, preserving operational details that can later be retrieved. Category-level skills aggregate many experiences within a category-modality bucket and distill them into reusable procedural guidance. At inference time, a query q is routed to a bucket, relevant memories R_M(q) and the corresponding skill R_S(q) are retrieved, and both are packed into a structured context E(q). The Planner uses E(q) to generate a research plan. The Executor follows that plan through multi-turn tool interaction and produces a trajectory τ and a final answer. After execution, the trajectory is summarized into a new memory entry, and once enough fresh experience accumulates, the Distiller updates the category-level skill.

The key idea is not just hierarchical memory, but the Executor-Distiller-Planner loop. Planner converts retrieved experience into a task-specific plan, Executor interacts with tools, and Distiller abstracts new trajectories into procedural skills. These modules are trained with a three-stage alternating GRPO schedule rather than a single joint objective. The motivation is cross-module credit assignment: if everything is optimized end-to-end at once, it is difficult for final task reward to shape the quality of distilled skills in a stable way. Alternating optimization gives each module a cleaner relative-reward signal while the others are partially fixed. In that sense, skill distillation is treated as reward-guided policy learning, not prompt-based summarization.

Another notable component is skill-guided TTRL. During deployment, the Planner performs test-time reinforcement learning on unlabeled queries, while retrieved skills and memories act as procedural priors that regularize online adaptation. The model is therefore not exploring from scratch at test time; it adapts locally around previously distilled high-quality procedures. The resulting improved trajectories are then written back into memory and can later trigger skill updates. This is the main conceptual difference from standard memory-augmented retrieval: retrieval helps the current sample, but APEx is designed so that the current sample also improves future behavior.a:T64b,The headline result reported in the paper is an average score of 64.4% across deep research benchmarks. This is 14.7 points above GPT-5.4 and 3.0 points above the strongest memory-augmented baseline. For judging the method, the second comparison matters more, because it isolates the gain from experience organization and training rather than from a stronger base model.

The paper also highlights a context-efficiency result: a skill-only variant remains competitive while injecting fewer memory tokens. That supports the claim that category-level procedural skills are a more compact carrier of useful experience than flat trajectory retrieval. This matters for long-context agents, where the bottleneck is often not retrieval quality but context budget and retrieval noise.

From the full text, the experimental story appears to rely on three main ablation axes. First, replacing hierarchical experience with flat memory retrieval hurts performance, suggesting that instance memories and category skills play different roles. Second, removing reward-guided distillation or the alternating GRPO schedule degrades both skill quality and downstream task performance, supporting the claim that useful skills must be shaped by task reward. Third, removing skill-guided TTRL weakens online adaptation, indicating that test-time updates without procedural priors become high-variance exploration. Those implementation choices are likely to determine whether the method transfers to other agent settings.c:T6b5,PMD organizes online experience into a three-level procedural memory and uses that memory only on the teacher path during training. The deployed student has no inference-time memory dependency. Level-0 experience memory stores raw trajectories, rewards, and feedback. It has the highest fidelity but weak transfer. Level-1 insight memory reflects over multiple attempts on the same problem and extracts compact strategies and lessons, removing much of the trajectory-level redundancy. Level-2 behavior memory groups semantically related problems and distills reusable reasoning patterns across them; this has the strongest transfer but also the highest risk of becoming too coarse. Training proceeds in a co-evolving loop: the current policy generates rollouts, receives verifier feedback, writes new information into memory, and the refreshed memory then conditions a self-teacher that supervises the next policy update. This is the main departure from SDPO. In SDPO, the teacher is still largely episode-local, built from sibling rollouts or local feedback. In PMD, the teacher is additionally informed by what the model has learned in prior epochs, so supervision carries cross-episode procedural structure. The co-evolution claim is central. A frozen memory becomes stale as the policy changes its visited states; a frozen policy prevents memory from improving in quality as capability grows. Another important design choice is to avoid inference-time memory use. Many reflection or memory-agent methods improve performance by carrying external memory into deployment, but that adds system complexity and a train-test mismatch.
