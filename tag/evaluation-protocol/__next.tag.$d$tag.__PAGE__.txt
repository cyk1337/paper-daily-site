Criterion synthesis then proceeds in two independent passes:
- a PRD-only pass that extracts required behaviors and constraints from the request,
- a reference-diff-only pass that records what changed in the accepted implementation without inferring business intent.

These are reconciled to filter incidental edits and unsupported inferences, then refined into atomic Code Points. The key design choice is to freeze these acceptance contracts before evaluation so that all agents are judged against the same target.

Scoring is three-stage:
- L0 performs structural checks for explicit hard violations,
- L1 uses bounded call-graph search to gather candidate code and integration context,
- L2 applies a judge to each Code Point with cited evidence, while allowing semantically equivalent implementations rather than requiring the reference patch.

数据设计上，FEB-30 包含 30 条 fact-evolution trajectories，覆盖 6 个诊断类别和 3 个难度等级。6 个类别分别对应外在 QA 评测看不清的不同失败模式：
1. C1 LLM Compensation：memory 状态错了，但模型仍可能答对。
2. C2 Retrieval Bottleneck：memory 对了，但 retrieval 因词汇不匹配或抽象层级差异而失败。
3. C3 Classification Accuracy：系统是否正确判断新观察是 create、update、reinforce 还是 conflict。
4. C4 Synthesis Quality：多来源观察是否被正确合并成事实，哪些该合并，哪些应分开。
5. C5 Temporal Correctness：事实随时间演化、撤回、漂移时，memory state 是否保持正确时序。
6. C6 Multi-Author Attribution：不同作者来源对 corroboration、冲突处理、置信度整合的影响是否被正确建模。

FEB-30 contains 30 fact-evolution trajectories spanning 6 diagnostic categories and 3 difficulty levels. The categories are designed to isolate failure modes that extrinsic QA-based evaluation cannot disentangle:
1. C1, LLM Compensation: the memory state is wrong, but the model may still answer correctly.
2. C2, Retrieval Bottleneck: the memory state is correct, but retrieval fails because of lexical mismatch or abstraction mismatch.
3. C3, Classification Accuracy: whether the system correctly classifies observations as create, update, reinforce, or conflict.
4. C4, Synthesis Quality: whether evidence from multiple artifacts is merged into the right fact structure.
5. C5, Temporal Correctness: whether the memory state tracks temporal evolution, retraction, and drift correctly.
6. C6, Multi-Author Attribution: whether source identity is handled correctly in corroboration, conflict handling, and confidence updates.

Difficulty is controlled in a structured way. L1 is close to surface matching, with target claims appearing almost verbatim. L2 embeds claims in more realistic document context. L3 requires inference from multiple statements and includes substantial distractor content.

The most important design choice is what the authors call paradigm inversion. Instead of starting from documents and then annotating facts, they first define the exact atomic claims that should hold at each state of a trajectory, then generate documents from those trajectories. This makes the ground truth deterministic from the start. The pipeline also uses multi-model rotation and three-judge verification to reduce generator-specific artifacts and improve factual consistency.

Evaluation is split into intrinsic and extrinsic metrics. Intrinsic evaluation directly compares the memory store against the state-specific ground truth, using metrics such as claim coverage, update detection, and false update rate. Extrinsic evaluation keeps the usual QA accuracy. The point is not to replace end-to-end evaluation, but to complement it with a unit-test-like view of the memory component itself.19:T5bf,The central empirical result is straightforward: intrinsic and extrinsic evaluations diverge substantially. The paper reports an average gap of 16 percentage points, and 44% of trajectories show what the authors consider a meaningful divergence. This is the main evidence that QA accuracy alone is not a reliable measure of memory quality.

By construction, C1 and C2 are the clearest demonstrations of the problem. C1 produces cases where systems answer correctly despite broken memory. C2 produces cases where memory is correct but the final answer is wrong because retrieval fails. Categories C3 through C6 are more diagnostic of internal memory-pipeline behavior, including update classification, synthesis, temporal consistency, and source attribution. Two systems with similar QA scores can therefore have very different internal memory quality.
