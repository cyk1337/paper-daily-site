NCP-ArchPreview Technical Report: Moving towards Latent Space Language Models through Next Concept Prediction

论文要解决的问题是：标准 next-token prediction 只在 token 粒度提供监督，高层语义结构只能作为隐状态中的副产物出现；如果希望语言模型在更粗的概念粒度上预测未来，怎样设计一个仍然能保持自回归生成能力、并且能扩展到万亿 token 训练规模的架构。NCP-ArchPreview 的目标不是替代 token 级 LM，而是在 token 级 NTP 之上加入显式的 Next Concept Prediction，让模型同时学习“下一个 token”和“未来一段文本对应的离散概念”。

评应立刻看 architecture 和 ablation：若 concept feedback 的收益在等算力下成立，会改变多 token latent objective 只是小模型玩具的 prior。

FASQ: Flexible Accelerated Subspace Quantization for Calibration-Free LLM Compression
