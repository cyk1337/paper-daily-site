9:T82e,The method, GravityOCR, is a parameter-shared AR–block-diffusion model built by adapting GLM-OCR. The same decoder is run under two attention patterns. The first path is a block-diffusion drafter. The output sequence is partitioned into contiguous blocks of size at most B. Dependencies remain causal across blocks, but attention is bidirectional within the current block. During training, a random subset of positions in the current block is masked and the model learns to denoise them conditioned on the completed prefix and the partially observed block. At inference, the current block starts fully masked and is iteratively denoised to produce a draft block in parallel.

The second path is a causal AR verifier. Given the same prefix, it checks the draft token by token and commits only the longest prefix that matches AR greedy predictions. Once a mismatch appears, commitment stops and the next drafting round begins. This design is the key idea: the diffusion path proposes, but the AR path decides. With top-1 verification, the committed output matches pure AR greedy decoding in exact arithmetic, so acceleration comes from accepting multiple drafted tokens per round rather than changing the final decision rule.

This differs from standard speculative decoding, which usually relies on a separate small drafter or an auxiliary multi-token head. Here both drafting and verification use the full shared backbone. Training combines the original AR NLL with a block-diffusion denoising objective so the model can operate under both masks. Post-training then applies GRPO only through the causal AR path using OCR rewards at the sequence and structure levels. The rationale is clean: optimize the path that determines the final output, and let shared parameters transfer improvements to the drafter indirectly. The paper also contrasts direct block-diffusion commitment with self-speculative verification. Direct commitment offers more parallelism but is brittle on tables, formulas, and other structurally coupled outputs; verification trades some parallelism for AR-like reliability.a:T69d,The model is evaluated on OmniDocBench v1.6 after adapting GLM-OCR. Second, GRPO applied only through the AR path improves the score from 94.92 to 95.16, showing that reward optimization helps the final verifier-controlled output without breaking the shared drafter. Third, with a full self-speculative implementation in SGLang, the system reaches 9.7 tokens per forward, counting both diffusion drafting and AR verification passes. This yields a 3.94× speedup in token generation and a 1.32× speedup in end-to-end page processing over causal AR decoding. The gap between those two numbers is informative: decoder token loops are only part of the total OCR latency budget. Fourth, the paper characterizes the accuracy–parallelism trade-off. Direct block diffusion is more aggressive but loses more accuracy; self-speculative verification is limited by draft–verifier agreement, and that agreement becomes the main determinant of practical speedup.

The ablations worth noting involve block size, denoising schedule, verification behavior, and task type. Plain text OCR tends to accept longer drafts because many positions are strongly image-grounded. HTML tables and LaTeX formulas are harder because local token dependencies are stronger, so the verifier truncates drafts earlier.
