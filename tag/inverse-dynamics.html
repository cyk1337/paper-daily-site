No Gaussian Required: Contrastive Inverse Dynamics for JEPA World Models

这篇工作解决 JEPA 类世界模型的表示坍塌问题。具体目标是在不强行规定 latent 分布为高斯、不改变测试时规划流程的前提下，让模型从动作转移数据中获得反坍塌信号。

评为自监督表示学习（特别是 JEPA 架构）提供了一种优雅的反坍塌机制，用对比逆动力学替代了生硬的高斯正则化，对探索非自回归预训练目标的稳定性有启发。

Scaling GUI Agents with Visual State Transitions

这篇工作关注 GUI agent 的一个老问题：高质量任务轨迹贵、RL 交互训练重，而直接用 instruction-conditioned trajectory fine-tuning 又把视觉定位、界面动态理解、动作语义和任务规划全压进一个 next-action objective 里，导致数据效率和优化都不理想。作者要解决的是，能不能在不依赖额外任务级标注的前提下，先用更便宜、更容易扩展的 state transition 数据，把 GUI 交互里最基础的 action-grounded visual representation 和局部 dynamics 先学出来，再去做任务轨迹微调。

评值得看 STP loss 和 data scaling 图；它把 GUI agent 的瓶颈从指令轨迹转向状态动力学，值得内部复现小版。
Xiangyan Liu,Kaixin Li,Haonan Wang,Biao Wu,Meng Fang,Longxu Dou,Chao Du,Michael Qizhe Shieh,Tianyu Pang
