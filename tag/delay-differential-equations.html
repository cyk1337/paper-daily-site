DSSMs: State Space Models with Explicit Memory via Delay Differential Equations

这篇文章要解决的是 SSM 一类线性递归模型的老问题：它们训练和推理都高效，但长期记忆依赖被压缩进固定维状态后，精确检索和延迟回忆能力明显弱于注意力模型。作者不是在现有 SSM 上做局部补丁，而是回到连续动力系统表述，问一个更根本的问题：如果 ODE 形式的状态演化天然只能通过当前状态压缩过去，那么能否把“过去的某个状态”显式接回系统里，让模型拥有真正的 delayed memory，而不是只靠指数衰减模态去近似记忆。DSSM 的核心就是把标准 SSM 从 ODE 扩展到带延迟项的 DDE，使状态更新不仅依赖当前状态，也依赖若干步之前的历史状态，从而改善长距离精确回忆。

评SSM显式记忆方向的新思路，延迟反馈机制设计有参考性，重点看§3稳定性参数化和频域核推导。
Yixiao Qian,Song Chen,Jiaxu Liu,Shengze Cai,Chao Xu
