9:T887,方法名叫 Mosaic，核心是两层优化信号。

第一层是 session-aware trajectory-level advantage estimation。普通 broadcasting 做法是先按任务内 rollout group 的 outcome reward 做 GRPO 式标准化，再把同一个 trajectory advantage 广播给所有 token。Mosaic 认为这样忽略了 session 使用效率，于是在“相同 outcome”内部再看 session count 的相对排序。直观上，若两条轨迹都成功，使用更少 session 的那条应得到更高 advantage；若两条都失败，反而不应简单惩罚 session 多的轨迹，因为失败样本仍需要探索空间。论文因此设计了一个有界调制项，用 session 数在同 reward 组内的 rank 去修正 trajectory-level advantage。这里有两个关键约束：一是调制不能打乱由 outcome reward 决定的主排序，二是调制幅度要受控，避免 session 偏好压过任务成败本身。作者强调它的作用不是替代 outcome signal，而是拉开 homogeneous-reward group 内部的 advantage 间距，提高学习信号分辨率。

第二层是 session-level advantage shaping。作者把每个 session 对最终 outcome 的边际贡献视作一种 immediate reward。做法上，是比较包含该 session 与不包含该 session 时的 outcome 增益，得到 session-level marginal gain；然后按 session type 分开做 group-relative normalization，再把这个 shaping signal 与上面的 trajectory-level advantage 结合。之所以要按 session type 分开归一化，是因为不同类型 session 的边际收益分布不同，例如压缩 session、主 agent session、fork 出来的子 agent session，其长度、功能和对最终成功率的贡献尺度都不一样，混在一起标准化会让某些类型的信号被系统性放大或压小。

整体上，Mosaic 形成了一个层级目标：trajectory-level signal 负责长期、全局、结果导向的优化；session-level shaping 负责局部、短程、边际贡献导向的优化。并且整个方法保持 critic-free，仍沿用 group-relative 的思路，而不是额外训练 value model。这是它和 PPO-style token/value advantage 路线的主要区别。a:T45f,This is not a pretraining paper in the narrow sense, but it matters for the pretrain-to-post-train interface, especially for long-context agents, tool-using systems, and reasoning models with explicit context management. The first component is session-aware trajectory-level advantage estimation. In the standard broadcasting setup, one computes a GRPO-style normalized trajectory advantage from outcome rewards within a rollout group, then assigns that same advantage to all tokens across all sessions. Mosaic argues that this ignores session efficiency. It therefore refines the trajectory-level signal using the relative ranking of session counts within trajectories that share the same outcome. Intuitively, if two trajectories both succeed, the one using fewer sessions should receive a larger advantage. If both fail, however, extra sessions should not be penalized in the same way because failed samples still serve exploration. The paper implements this through a bounded modulation term based on session-count ranking inside homogeneous-reward groups. Two design constraints are central: the modulation must not overturn the primary ordering induced by outcome reward, and its magnitude must remain controlled so that session preference does not dominate task success. The point is not to replace outcome supervision, but to increase advantage resolution within reward-tied groups.

The second component is session-level advantage shaping. Each session is assigned an immediate shaping signal based on its marginal contribution to the final outcome. Concretely, the method estimates a session-level marginal outcome gain, normalizes it with group-relative statistics separately for each session type, and combines this shaping term with the trajectory-level advantage. The type-conditioned normalization is important because different session types have different gain distributions. A compaction session, a main-agent session, and a forked subagent session differ in length, function, and contribution scale. Pooling them into one normalization scheme would distort the signal.

Together, these two components form a hierarchical objective: the trajectory-level term provides a global, long-horizon, outcome-oriented signal, while the session-level shaping term captures local marginal effects. The method remains critic-free throughout, staying closer to GRPO than to PPO-style value-based token advantage estimation.c:T6a1,Experiments are conducted on BrowseComp with Qwen3.5-4B as the base model, under two representative multi-session settings: context compaction and subagent forking. 相关性估计来自 self-replay + privileged information：每个 verifier 在评估时依赖某些信息（例如：正确 SQL 的参考、执行错误信息、工具调用的规范/约束、指令中的某条约束文本等）。MRTPO 对同一条已采样的 response y 做两次 teacher-forcing 式的重放（replay）：一次在“包含 reward k 的 verifier 信息”的上下文下，一次在“移除该信息”的上下文下，得到每个位置 t 的 next-token 分布 p_t^{(+k)} 与 p_t^{(-k)}。用 token-wise Jensen–Shannon divergence 作为差异度 d_{k,t}=JSD(p_t^{(+k)}||p_t^{(-k)})，把它解释为该 token 对 reward k 的敏感度/相关性。然后把 reward k 的优势 A_k^{(j)}（来自 group 标准化）按 d_{k,t} 在 token 维度上归一化，得到 token advantage A_{k,t}^{(j)}，再把所有 reward 的 token advantage 聚合成最终 A_t^{(j)} 进入 PPO/GRPO 的 clipped surrogate objective。

与已有方法的区别：GDPO/SAW 等主要解决“每个 reward 在 response-level 贡献多少”（reward weighting / normalization），但仍是 token-uniform；OPSD 类自蒸馏方法是直接拟合带 privileged info 的 teacher 分布，目标函数形态不同，且不显式做多 reward 的 credit 分解。MRTPO 的关键取舍是：不需要额外生成（仍用同一条 response 重放），不需要 token 标注，不引入额外模型；代价是每个 reward 需要额外两次前向重放来算 JSD（计算开销随 reward 数 K 增长）。e:T4bb,MRTPO (Multi-Reward-to-Token Policy Optimization) keeps the standard PPO/GRPO clipped objective intact and changes only the per-token advantage A_t. For each reward k, it constructs two replay contexts for the same sampled response: one with the verifier’s information for reward k available (+k), and one with that information removed (-k). It then teacher-forces the response under both contexts to obtain next-token distributions p_t^(+k) and p_t^(-k) at every position t. Token relevance is measured as d_{k,t} = JSD(p_t^(+k) || p_t^(-k)). The group-normalized advantage for reward k is redistributed across tokens proportionally to d_{k,t} (with normalization over t), yielding reward-specific token advantages that are then aggregated across rewards.

Key distinctions: GDPO/SAW decide reward contributions at the response level but remain token-uniform; OPSD-like on-policy self-distillation fits a privileged teacher distribution directly rather than explicitly decomposing multi-reward credit. The main technical contribution is the entropy-shift analysis. For each position, the paper measures the change in entropy between the teacher and student next-token distributions after conditioning the teacher on feedback. This yields two regimes. In context sharpening, entropy drops sharply and the teacher concentrates probability on a narrow expression aligned with the feedback. In context spreading, entropy increases or lies in the lower tail of the per-sequence entropy-shift distribution, meaning the teacher preserves multiple feedback-consistent alternatives. The paper interprets sharpening as encouraging memorization of a particular phrasing, while spreading better preserves semantic understanding of the criterion.

Based on this, the authors propose masking positions for distillation using entropy shift. They keep the lower tail of the entropy-shift distribution within each generation and remove the highest-shift positions from the distillation loss. So the student is not forced to imitate every confident teacher token. Instead, it is trained more on positions where feedback constrains meaning without collapsing to one fixed wording. A careful read with figures and ablations is closer to an hour.13:T8a8,ProVer 的名字对应三步：Propose、Verify、Credit。

第一步 propose：在同一个 GRPO group 内，作者拿成功轨迹和失败轨迹做对比，让一个 agentic judge 去定位成功轨迹中“可能导致结果分叉”的片段。这里的关键设计是只让 judge 负责提出候选 segment，而不是直接给 segment 打 reward。这样做是为了利用 LLM 在模式识别和对比解释上的长处，但避免把训练信号完全交给一个容易漂移、可被利用的评审器。

第二步 verify：对 propose 出来的片段，恢复该片段开始前和结束后的环境状态，从这两个边界状态分别用当前策略采样新的 continuations。作者用两端 continuation 的经验终局成功率之差，来估计这个 segment 的 advantage。直观上，如果“经过这个片段之后”的状态更容易被当前策略继续做成，那么这个片段就确实为成功创造了更好的后续条件；反之，如果差异不明显，说明 judge 提议的片段未必真关键。这个设计很像把局部 credit assignment 建立在可验证 outcome 上，而不是建立在中间过程的语言评价上。

第三步 credit：只有当验证得到的 segment advantage 为正时，才把这部分额外 credit 加到原始 GRPO 的 token-level 更新上，而且只加给该 segment 内的 policy token。也就是说，ProVer 不是替换 GRPO，而是在 GRPO 的轨迹级优势之上叠加一个局部、稀疏、经验证的 bonus。这样既保留了 GRPO 不需要 value model 的优点，也缓解了 uniform advantage 带来的噪声。

和已有路线相比，区别主要有三点。与 critic/value-based 方法相比，它不依赖一个单独学习的中间价值估计器，因此少了一层 distribution shift 和 reward hacking 风险。与 process reward model 或 LLM evaluator 直接打分相比，它不直接信 judge，而是要求 outcome-level verification。与对所有中间状态做 exhaustive branching 相比，它只在被提议的关键片段边界做分支采样，计算成本更低。论文的核心创新不在某个复杂公式，而在这个“proposal by model, verification by environment outcome”的分工。14:T677,ProVer has three stages: Propose, Verify, and Credit.

In the propose stage, an LLM-based judge compares successful and failed trajectories from the same GRPO group and selects a segment in a successful trajectory that may have caused the divergence in outcome. The judge is used only for localization, not for direct reward assignment. This is an important design choice: it leverages model-based pattern recognition without trusting model judgment as the final training signal.

In the verify stage, the method restores the environment states immediately before and after the proposed segment, then samples fresh continuations from the current policy from both boundary states. The difference in empirical terminal success rates estimates the segment’s advantage. Intuitively, if the post-segment state is much easier for the current policy to complete successfully than the pre-segment state, then the segment likely contributed real causal progress.

In the credit stage, only positively verified segment advantages are added to the original GRPO advantages, and only for policy tokens inside the proposed segment. So ProVer does not replace GRPO. It augments GRPO with sparse, localized, outcome-grounded bonus credit.

Relative to prior approaches, the distinction is clear. It avoids a separately trained value model, so it reduces dependence on critic generalization. It avoids directly optimizing against an LLM evaluator’s intermediate scores, so it is less exposed to evaluator gaming. And it avoids exhaustive branching from every intermediate state, so it is much cheaper than full Monte Carlo credit assignment over the whole trajectory.15:T83a,The method has two stages: diagnosis and training-time credit gating.

The diagnostic tool is a fixed-rollout counterfactual test. Instead of resampling a new response under a modified image, the method teacher-forces the exact same generated response under both the original image I and an intervened image I^cf. This removes confounding from trajectory changes. Evidence-Function Sensitivity (EFS) measures how much the predictive distribution at claim tokens changes under the intervention. If the model is visually responsive, EFS should increase. But EFS alone is not enough, because changing the image can shift the likelihood of the whole response. To isolate claim-level support, the paper defines claim persistence and calibrates it using residual tokens from the same rollout, so that trajectory-wide likelihood drift is discounted. This separation between sensitivity and retractability is the conceptual core of the paper.

Based on that diagnosis, the authors propose Persistence-Aware Credit Gating (PACG). During RL training, they identify routed direct visual claims, meaning token spans that are treated as direct image-grounded assertions. For tokens with positive advantage, claims that retract sufficiently under the counterfactual keep their full positive credit, while unusually persistent claims receive attenuated positive credit. Negative-advantage tokens and non-routed tokens are left unchanged. The design is intentionally conservative: it does not punish all visual tokens, and it does not require supervised labels for claim support. It only reduces positive reinforcement where the model appears to preserve unsupported visual assertions. PACG is designed to plug into existing RLVR optimizers such as DAPO and VPPO, and it adds no inference-time cost.

Compared with prior perception rewards, token reweighting, or multimodal process reward models, the novelty here is the target of supervision. The paper is less concerned with whether the model looked at the image, and more concerned with whether the specific visual statement should survive when the evidence is removed.16:T664,The paper begins with a strong empirical observation. On four multimodal reasoning benchmarks, among 8,521 answer-correct trajectories produced by Qwen2.5-VL-7B, 2,370 trajectories, or 27.81%, contain at least one direct visual claim that is not supported by the image. This shows that the issue is not rare noise; outcome-level RL can systematically reinforce unsupported claims.

The diagnostic experiments reveal what the authors call Sensitivity–Persistence Decoupling. Under DAPO and VPPO, training increases EFS and improves overall retractability, yet unsupported claims become more persistent. GRPO also increases EFS, but without the same deterioration in unsupported-claim persistence. This is an important result because it ties the problem to the optimizer and its credit-broadcasting behavior, rather than treating it as an unavoidable property of multimodal RL.

Visual grounding is estimated through a counterfactual measure: compare the model’s predictive distribution under the original image and a corrupted image, and use the KL divergence as a proxy for visual dependency. If the trajectory changes a lot when the image is corrupted, it likely relies on visual evidence rather than language priors. Stability is approximated by average trajectory entropy, motivated by prior observations that lower-entropy trajectories tend to be more reliable under RLVR. The second part is token-level anchoring through vision-guided advantage allocation. Standard DAPO/GRPO-style methods broadcast one sequence-level advantage to all tokens. Tokens that appear more visually grounded or more consequential for downstream reasoning receive stronger optimization weight.
