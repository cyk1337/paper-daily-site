Code Correctness Signals in LLM Hidden States: Pre-Generation Probing and Repair Geometry

这项工作研究代码生成正确性是否已经写在模型生成前的隐藏状态里，以及自我修复过程中是否存在稳定的“修复成功方向”。对象是 Qwen3-4B-Instruct-2507 在 LiveCodeBench 任务上的 prompt-final hidden state，而不是生成代码后的隐藏状态。

评通过控制变量（prompt长度）的 probing 实验，证实了代码正确性在生成前已在 hidden state 中线性可分，对做 test-time compute 或 early exit 的研究员有启发。
