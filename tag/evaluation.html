这篇工作要解决的问题很明确：多模态大模型在面对语义等价、但呈现模态不同的输入时，预测并不稳定。具体说，同一句题目里把“可视觉化的概念”从文字换成对应图片后，模型常常从答对变成答错。作者把这种现象定义为 modality gap，并把它从一个零散观察变成了可系统测量、可训练干预的问题。关键不在于模型会不会看图，而在于模型是否真正学到了“语义跨模态不变性”：同一概念以文本 token 或视觉 token 出现时，后续推理链条应尽量一致。对 MLLM 预训练来说，这是比传统 VQA 准确率更基础的能力约束。

评这篇值得看，因为它把“多模态只是把图塞进上下文”这个幻觉戳破了；读定义和主表就够，训练结论先别外推过头。

Know It, Act on It: Investigating Memory Utilization in LLM Personalization

这篇论文要区分个性化 agent 的两类失败：模型到底是没有记住用户偏好，还是记住了但没有在相关场景中使用。它用同一条偏好同时做 Know test 和 Act test，避免只测召回或只测行为带来的诊断混淆。

评这篇不教你怎么训模型，但会纠正一个常见误判：很多“记忆差”其实是利用差；读评测协议和 gap 分析就够，适合拿来重做内部 memory eval。
