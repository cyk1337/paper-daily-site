Sycophancy Suppression Can Impair Rational Updating: Anti-Sycophancy Should Preserve the Ability to Update

这篇工作要解决的不是“模型会不会改答案”这个表面问题，而是把两类看起来相似、机制却不同的改答行为拆开：一类是在用户施压但没有提供新证据时，模型为了迎合而放弃原答案，作者称为 Unsupported-Yielding；另一类是在第二轮确实拿到支持性证据后，模型据此修正答案，作者称为 Rational-Updating。现有 anti-sycophancy 方法大多只盯着前者，默认“少改答”就是好事，但全文实验表明，这类干预常常连后者一起压掉，导致模型失去正常吸收新信息并更新判断的能力。论文真正要回答的是：如何区分迎合式改答与证据驱动改答，以及为什么现有抑制方法会同时伤到两者。

评对齐里一个常见坏 prior 是“少改口=更可靠”，这篇把它拆穿了；读评测设计和 trade-off 图就够，方法结论比具体干预更重要。

LitReview Arena: Evaluating Literature Review Agents with Battle-Style Peer Review Platform

这篇工作解决的是一个评测问题：自动生成 literature review 到底该怎么评，尤其是那些无法靠 reference overlap、citation accuracy 或 coverage heuristic 直接判定的部分。作者认为，文献综述真正影响研究者使用价值的地方，恰恰是最难自动打分的部分，比如结构是否合理、论证是否站得住、研究空白是否有判断力、未来方向是否具体而不空泛。现有 benchmark 往往能评检索、评引用、评表面覆盖，但很难评“这篇综述是否真的像一个懂行的人写的”。因此他们提出 LitReview Arena，用 battle-style 的专家偏好评测协议，把 literature review 评测做成接近同行评审的流程。

评做 agent eval 的人可以看，但对 pretrain 只属间接相关；重点看专家 judge 协议和 LLM judge 失配分析，别把 arena 排名当能力真值。

When Does Visual Generation Help Visual Understanding in Unified Multimodal Models?

这篇工作要回答的不是“统一多模态模型能不能做视觉生成”，而是更具体的一个诊断问题：视觉生成在什么条件下真的能帮助视觉理解。现有结论之所以摇摆，作者认为主要有三类评测混淆：样本难度混在一起、不同生成辅助范式没有在统一设置下比较、生成与理解在闭环中纠缠导致失败归因不清。论文因此把问题从方法宣称转成评测诊断：如果把难度、范式和 oracle 条件都控制住，视觉生成到底是在帮忙、添噪声，还是误导理解。

评对统一多模态模型（如 Chameleon）中'生成反哺理解'的假设进行了很好的诊断，指出当前瓶颈在理解端而非生成端，做统一建模的值得看其 Oracle 实验设计。
