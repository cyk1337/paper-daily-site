这篇工作解决的是一个评测效率问题：SWE agent 的完整 benchmark 运行太贵，能不能只跑一个小子集，就较准确地恢复模型在全量 benchmark 上的分数和相对排名。已有 IRT 方法大多只看最终 pass/fail，把长轨迹的探索、编辑、测试、回退这些过程信息全部压成一个二值结果。作者认为这会丢掉大量测量信号，尤其是在 agent 任务里，失败方式和成功路径本身就携带难度与区分度信息。

评将 Agent 的执行轨迹（过程信号）引入 IRT 评估模型，比单纯看 pass/fail 更科学，对设计低成本、高保真的 Agent 评测集很有参考价值。
Kefeng Duan,Dewu Zheng,Yanlin Wang,Xiwen Wang,Ensheng Shi,Xilin Liu,Yuchi Ma,Jiachi Chen,Mingwei Liu,Zibin Zheng

The Answer Is Not the Argument

这篇工作要回答的不是“监控模型能不能判断答案对错”，而是更细的一层：当推理链本身有错误、但最终答案恰好是对的时，监控模型能否独立发现并定位推理中的首个错误。很多 CoT 监控设定会把一个“可信参考答案”一并给监控器，这会把“检查论证是否成立”和“看到答案后判断结论像不像对”混在一起。作者用 HLE 物理题上的真实模型解答，而不是人工注入错误，专门构造并标注了这种最关键也最难的情形：正确答案掩盖了错误推理。

评值得看实验协议；它提醒过程监督评测别把答案泄漏当推理验证能力，尤其是 correct-answer/wrong-trace 子集。
Will Yeadon,Sergio Juárez,Paul Mackay,T. J. Dowling,Elise Agra,Oto-obong Inyang,Arin Mizouri,Craig P. Testrow

Retrieved but not ranked: surface-form bias in structural retrieval, from mathematics to agent trajectories

这篇工作要回答的不是“embedding retrieval 是否有用”，而是一个更尖锐的问题：当表面词形和底层结构被刻意拆开时，检索模型到底跟着哪一个走。作者把这个问题放到两个几乎无关的域里做同一套协议：竞赛数学题检索，以及 embodied agent 轨迹检索。核心发现很直接：现有 embedding 检索在“结构相同但措辞不同”的场景下，rank-1 往往仍被表面相似性主导；而且这种偏置不是某个 benchmark 的偶然产物，因为在两个域里都能看到，但表现形式又受 benchmark 构造方式强烈影响。

评对做 RAG、memory、agent trace reuse 的人，这篇把“召回没问题，排序被词面绑架”讲得很干净；读实验协议和错误分析就够了。
Nabira Rashid,Manolis Kellis
