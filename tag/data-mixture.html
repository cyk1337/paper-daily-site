HERMES: A Multi-Granularity Labeling Substrate for Pre-training Data Mixtures

HERMES 解决的是预训练数据 mixture 中“标签系统”不够灵活的问题。很多数据混合方法默认语料已经被分好组，但分组方式决定了 mixer 能表达什么。来源标签太粗，人工 taxonomy 只能沿一个语义轴划分，普通 embedding clustering 又是固定 K 的平面划分，想换粒度就要重新聚类。HERMES 把问题转到一次性、多粒度、层级化的数据标注：每篇文档只标一次，之后通过 code prefix 改变粒度。

MultiSynt/MT: Trillion-Token Multi-Parallel Pre-Training Data Translated Across 36 Languages

这篇工作解决的是开放多语预训练里一个很现实的瓶颈：英语之外，尤其是中低资源欧洲语言，公开可用的高质量预训练语料既不够大，也不够干净，导致多语 LLM 的训练长期受限。作者选择的路径不是继续做原生网页抓取，而是把高质量英语网页语料系统性翻译成 36 种语言，构造一个可公开发布、规模达到 4.8T 目标语言 token 的 synthetic parallel pretraining corpus。论文真正要回答的不是“能不能翻译出很大数据”，而是更难的问题：翻译语料在预训练里到底能替代多少 native data，在哪些能力上有效，在哪些能力上会留下 translationese 和文化锚定的缺口，以及现有 benchmark 是否能看出这些差异。
