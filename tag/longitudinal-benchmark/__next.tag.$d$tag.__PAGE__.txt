9:T6bd,The core artifact is AgingBench, a longitudinal benchmark for deployed agents. The paper defines four aging mechanisms. Compression aging happens when information is already underspecified or over-compressed at write time, so future-critical details are lost. Interference aging happens when many similar memories accumulate and the target fact becomes buried or confused with nearby entities. Revision aging happens when changed, retracted, or derived state is not updated correctly. Maintenance aging happens when lifecycle operations such as flushing, recompaction, migration, or prompt changes silently alter behavior. To make these mechanisms measurable, the benchmark uses a temporal dependency DAG that encodes cross-session dependencies, superseding facts, confusable entities, and controlled lifecycle events. Evaluation is then performed over agent trajectories, producing aging curves over an operational lifetime rather than a single snapshot score. A particularly useful design choice is the use of paired counterfactual probes. One probe replaces the agent’s retrieval with oracle retrieval over the agent-written memory; another replaces both writing and retrieval with gold context. This helps localize failures to the write/store/retrieve/use pipeline. If oracle retrieval fixes the issue, retrieval is the likely bottleneck; if even gold context does not fix it, the problem is more likely in memory utilization, prompting, or the harness itself. All scenarios are generated programmatically, with controllable session count, dependency density, update rate, chain depth, and interference density, making the benchmark more like a controlled stress-testing surface than an open-ended naturalistic dataset.a:T435,From the provided full-text excerpt, the experimental emphasis appears to be on benchmark behavior and failure signatures rather than on a single headline score.
