18:T5d2,The method, VIGOR (VarIance Guided Online Rollout allocation), starts from an analysis of GRPO under binary rewards. The key observation is that the magnitude of the learning signal is governed by within-group reward variance. If all sampled responses for a prompt are either all correct or all incorrect, the group-relative advantage carries little discriminative information. If the group contains a mix of successes and failures, GRPO gets a meaningful comparison signal. Based on this, VIGOR replaces uniform rollout allocation with iterative refinement. Each prompt first receives a small initial number of rollouts. The algorithm estimates group-level reward variance from these partial samples, selects the prompts with the highest variance, and allocates additional rollouts only to them. This repeats until a fixed total budget is exhausted. The distinction from DAPO-style approaches is important: VIGOR does not first over-generate a larger pool and then filter. It allocates budget online during generation, which avoids paying extra rollout cost purely for selection. Compared with methods that improve utilization through stale rollouts or auxiliary signals, it leaves the GRPO objective unchanged and only changes where the rollout budget goes. The paper also provides a theoretical speedup analysis under a Pareto reward-variance model, arguing that the benefit of iterative refinement grows rapidly with the number of refinement rounds when informativeness is heavy-tailed.19:T40d,The evaluation covers both math reasoning and coding RLVR. On math, the authors test Qwen2.5-1.5B, 3B, 7B, and Phi-4-Mini-Instruct across six benchmarks. The main result is consistent: VIGOR reaches the same accuracy with fewer rollouts, with up to 2.3x rollout-efficiency improvement on Qwen2.5-3B. Under rollout-matched comparisons, where methods are given the same total rollout budget, VIGOR achieves the best average score across all four model settings. On coding, using Qwen3-8B on LiveCodeBench v6, VIGOR reaches GRPO’s final full pass rate with 1.49x fewer rollouts and improves average test pass rate by 3.4 points. The most informative evidence is in the training curves rather than the final table alone: gains appear early, which supports the claim that online allocation is most valuable when the policy is still changing quickly. The root is the prompt; each ReAct turn (thought–action–observation) forms a semantically meaningful node/prefix that can be revisited and branched. Budget allocation is defined over these anchors (roots and internal prefixes).

The guiding principle is mixed-reward contrast construction: allocate more budget to anchors whose descendant continuations are likely to contain both successes and failures, because such anchors can generate sibling trajectories with opposite terminal outcomes, yielding stronger contrast for credit assignment under outcome-only rewards.

The framework has two stages:
1) Global root allocation over a large prompt pool: decide which prompts get zero vs positive rollout budget, favoring prompts with non-extreme success probabilities to increase terminal reward variance.
2) Local tree expansion: given collected rollouts, score encountered prefix nodes and allocate additional continuation branches to prefixes likely to produce outcome-diverse descendants.

A shared success-probability predictor estimates conditional success probability from prefix histories and is used to approximate each anchor’s utility under the descendant-set objective.
