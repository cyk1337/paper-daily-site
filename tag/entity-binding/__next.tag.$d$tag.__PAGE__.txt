9:T69b,The key method is a multi-slot probing framework. Standard probes often assume that a token position is dominated by a single semantic role or concept. Here, the authors explicitly allow a single residual-stream state to multiplex multiple entity-related representations, and they try to disentangle those slots in an unsupervised way.

Using Qwen3-32B as the default analysis model, they construct synthetic prompts with multiple entities and inspect residual activations across token positions. The main finding is that two slots are especially robust: a current-entity slot and a prior-entity slot. The current slot tracks the entity currently being described; the prior slot tracks the immediately preceding entity. Importantly, these slots are largely orthogonal, meaning that “trait X for the current entity” and “trait X for the prior entity” are not just weak variants of the same direction but occupy distinct representational subspaces.

The paper then studies what these slots are used for. The prior-entity slot is not merely epiphenomenal: it supports relational computations such as order-sensitive reasoning and conflict detection. But it is not a general-purpose memory interface. The authors find that downstream computations usually do not use it for explicit recall or for direct binding retrieval, even when probing shows that the relevant information is encoded there. In other words, the model stores prior-entity information, but later circuits do not seem to route that information into all tasks that would benefit from it. The answer is yes: the most reliable recoverable signals correspond to the current entity and the immediately previous entity, and these slots are approximately orthogonal.

Second, there is functional analysis. The paper tests whether these slots participate in different downstream computations. The prior-entity slot helps with relational inferences such as sequence order and conflict detection, but it is much less useful for explicit recall or for answering binding-style questions like “who has trait X?”, even though probing indicates that the information is encoded.
