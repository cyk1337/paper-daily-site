Dissecting model behavior through agent trajectories

论文识别并形式化了 LLM coding agent 中存在的“意图-执行差距”（intent-execution gap）：模型意图与 harness 实际执行之间的双向不匹配，以及环境中发生的事件与模型接收到的反馈之间的不匹配。这一差距导致即使基础能力更强的模型，在 agent 任务上也可能表现不佳（MA > MB 的基础能力，但 acc(H, MA) ≈ acc(H, MB)）。

评对做 agent/posttrain 接口的人有参考：很多'model 不行'其实是 harness 对齐失败；只看 intent-execution gap 定义和 SSA 设计即可。
Gaurav Gupta,Vatshank Chaturvedi,Jun Huan,Anoop Deoras
