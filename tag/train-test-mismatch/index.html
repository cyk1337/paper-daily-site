Agreement rather than normalisation keeps depth reusable in looped language models

这篇论文在追问一个很具体、但对 looped LM 成败很关键的问题：循环复用深度时，为什么训练预算之外的 loop step 还能继续可用？已有直觉通常把原因归到 loop 边界处的归一化，认为它能防止状态尺度失控，从而让重复应用同一层栈保持稳定。作者把这个解释拆成两个可检验的命题：一是“边界归一化本身必需”，二是“训练时的 loop 拓扑和推理时的 loop 拓扑必须一致”。论文的核心贡献，是把这两个常被混在一起的因素分开，并证明真正决定可复用性的不是归一化，而是训练—推理 loop 拓扑的一致性；一旦一致，边界归一化不但不是收益，反而会把模型更紧地绑在训练时的特定 loop 深度上。

评这篇会改你对 looped LM 稳定性的 prior：别再把锅先甩给 norm growth，先查 train-test loop mismatch；建议直接看 Ouro 干预实验和多 seed 从训结果。
Ivan Viakhirev,Kirill Borodin,Maxim Abramov,Grach Mkrtchian

Multi-Block Diffusion Language Models

这项工作解决的是 Block Diffusion LM 从单块解码走向多块并行解码时的训练-推理错配。已有 BD-LM 通常用 teacher forcing 训练：模型只看到“干净前缀 + 一个带噪 block”。这适合 Single-Block Diffusion，也方便 KV cache，但 block 之间仍然串行。D2F 让多个带噪 suffix block 互相可见，能带来 MultiBD 能力，但训练状态仍不等于真实推理状态：推理时只能维护一个有界 running-set，而且不同 slot 的噪声强度差异很大。论文的核心问题是：如何让 BD-LM 学会在一个固定大小、噪声异质的多 block 窗口中稳定解码，同时保留 KV cache、prefix cache 和实际 serving 速度收益。

评刘鹏飞团队在 Diffusion LM 上的重要推进，MultiTF 巧妙解决了多块并行解码的 train-test mismatch，关注非自回归生成的必读。
