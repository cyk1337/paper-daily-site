On the training side, Multi-block Teacher Forcing concatenates a clean prefix with a bounded group of consecutive noisy blocks, instead of corrupting only the current block. Noisy blocks inside the group can attend to one another through a Group-Aware Dual-Stream Mask, while preserving block-causal generation constraints. The dual-stream design separates the prediction view from the conditioning content view, so the model can use neighboring noisy blocks without leaking the target token. MultiTF also uses a more aggressive and randomized noise scheduler inside each group, creating heterogeneous slot-wise noise patterns similar to inference: front slots may be nearly solved while later slots remain heavily masked. Blocks are partitioned into groups with varying sizes so the model sees different running-set sizes and relative slot positions. On the inference side, the Block Buffer keeps a fixed number of physical block slots.
