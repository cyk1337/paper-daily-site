c:T4e1,The base model is a causal video world model trained with flow matching over video chunks. In the standard setup, the model denoises the current chunk conditioned on clean past chunks. Next Forcing augments this setup with lightweight multi-chunk prediction modules that predict multiple future chunks, such as next 1, next 2, and next 3. These modules form a causal prediction chain, so farther-horizon prediction is not just an independent auxiliary head attached to the same representation. To make the auxiliary losses affect the main model more directly, the MCP modules fuse intermediate features from multiple main-model layers rather than using only the final layer. The paper also applies a larger timestep shift to the MCP modules, making their denoising task harder and increasing their reliance on the main model’s learned temporal representation. At inference time, the auxiliary modules can be kept to predict future chunks in parallel with the current generation process, turning the training auxiliary path into an acceleration mechanism.
