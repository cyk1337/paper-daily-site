Abstention as an Action Can Kill Both the Reward Gradient and the KL Anchor: Collapse Law and Repair for Error-Penalized Reinforcement Learning

当前RLHF中广泛使用的带弃权动作的错误惩罚奖励规则（答对+1、答错-λ、弃权0），理论上可引导理性智能体按Chow阈值实现校准式弃权，但在采用KL锚定的策略梯度训练下，会出现模型逐渐滑向全弃权的崩溃现象，且KL正则完全无法发挥预期的锚定稳定作用。该工作明确崩溃的底层机制、推导形式化的崩溃规律，并提出可落地的修复方案。

评把弃权当普通离散动作会让 KL anchor 和梯度一起消失，这对 RLVR 安全训练很关键；上线错误惩罚前必须检查 group norm 后的有效 λ。

Toward Plasticity-Preserving KL Regularization for Capability Retention in LLM Reinforcement Learning

RL 后训练（RLHF/RLVR）会让策略偏离 base model，造成已有能力遗忘。标准 KL 正则把整个响应分布都锚定到 reference policy，既保留正确模式也保留错误模式，过度限制探索；完全去掉 KL 又会导致漂移和遗忘。问题是能否只在需要保留的地方施加约束。

评建议看目标函数推导；它提醒 KL 不是越全越安全，保留塑性要约束正确性条件分布。

Post-Training at the Edge of Detectability: A Game-Theoretic Approach to Fine-Tuning

这篇工作处理的是 RL fine-tuning 里一个长期存在但常被经验化处理的问题：KL 正则系数 β 应该怎么设。传统做法把 β 当作超参数，用网格搜索、人工调节，或在线追踪某个目标 KL；这些方法都缺少一个清楚的原则，尤其当目标是“提升任务奖励，同时尽量保留参考模型行为”时，KL 本身只是距离约束，并没有直接回答“偏离到什么程度才算合适”。作者把这个问题改写成一个顺序检测博弈：agent 想通过策略改动获得更高奖励，monitor 则持续观察输出并判断它是否仍来自参考策略；一旦检测到偏离，部署终止。这样，β 不再只是调参旋钮，而被解释为在统计可检测性约束下的最优权衡参数。

评把KL系数和统计可检测性绑定的视角很新，对RLHF超参调优有理论启发，重点看均衡推导那一节。

DRIFT: Decoupled Rollouts and Importance-Weighted Fine-Tuning for Efficient Multi-Turn Optimization

多轮交互/纠错场景下，在线 RL 能处理分布漂移但 rollout 成本随回合数线性甚至更差增长；离线 SFT 便宜但容易因分布偏移学不到真正的“纠错策略”，出现 behavioral collapse。论文要解决的是：能否把多轮 KL-regularized RL 的收益，用一种近似 SFT 的训练形态实现，从而把 rollout 与优化解耦，显著降低多轮优化的计算成本。

Stabilizing LLM Supervised Fine-Tuning via Explicit Distributional Control

评看 KL trust-region 推导和遗忘曲线；如果 setup 干净，这类 anchor 约束可直接进 SFT 消融。
