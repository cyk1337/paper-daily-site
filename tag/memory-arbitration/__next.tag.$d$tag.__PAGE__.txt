9:T73a,CAMA has two main components: correlation-aware evidence decoupling and missing-evidence recovery.

The first component is query-conditioned latent-source arbitration. Instead of treating each retrieved memory as an independent vote, the method maps memories into latent evidential factors or slots. The intuition is that multiple memories may express the same underlying source of evidence, just through different agents, timestamps, or phrasings. CAMA uses neural dependency inference to estimate whether memories are redundant under the current query, and combines this with provenance-based symbolic priors derived from source chains, dependency links, or write traces. Hypothesis support is then aggregated at the latent-factor level rather than the raw-memory level, reducing repeated counting of the same evidence.

The second component is sequential evidence recovery. The paper argues that the initial retrieval set is itself biased: similarity-based retrieval tends to over-select correlated memories and miss independent evidence that could overturn a false majority. CAMA therefore does not restrict arbitration to the initial top-K slice. Instead, it learns a recovery policy that, under a budget, decides whether to expand retrieval or trace provenance/dependency links to acquire additional independent evidence. This is a sensible design because it treats the current evidence set as a biased sample rather than a complete basis for decision-making.

Methodologically, this is not a new LLM architecture. It is a combination of evidence aggregation, symbolic provenance, and sequential retrieval policy for multi-agent memory arbitration. The main novelty is making dependence modeling query-conditioned and latent-source based, rather than relying on static heuristics such as agent identity, timestamp, or semantic similarity alone.a:T4fe,The experiments are designed to show that CAMA suppresses false majorities caused by correlated memories and outperforms standard baselines on long-term multi-agent memory benchmarks.
