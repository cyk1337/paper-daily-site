The Self-Correction Illusion: LLMs Correct Others but Not Themselves

这篇工作要回答的不是“模型会不会自我纠错”，而是更具体的问题：同一条错误陈述，如果内容完全不变，只改变它在 chat template 里的来源角色，模型的纠错意愿会不会显著变化。作者把错误 claim 做到字节级一致，只改外层包装：放在 assistant 自己的 <thought>、user 消息、tool 返回、system memory 等不同槽位里。全文给出的结论很明确：很多所谓 self-correction deficit，并不主要来自推理能力不足，而是来自 agent harness 对“这句话属于谁”的编码方式。模型往往更愿意审查外部来源的说法，却不愿显式否定自己内部 scratchpad 里的说法。

评这个 setup 很干净；只看 role 重标实验，就足以更新对“自我纠错失败”的归因。
Kuan-Yen Chen,Fang-Yi Su,Jung-Hsien Chiang
