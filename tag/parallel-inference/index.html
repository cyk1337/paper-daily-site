Compiling Autoregressive LLM Control into Policy-Exact Parallel Inference for Hierarchical RAG

把“用 AR 解码来执行有限动作空间的 LLM 控制器”这件事，从串行 token 生成改造成并行、零生成的等价推断：在分层 RAG 这类 bounded-horizon（例如每轮选 b=3 个 section）的控制问题里，如何在不牺牲“历史依赖的策略精确性”（能条件化在已选动作上）且不暴露 JSON 协议面（语法/标识符错误）的前提下，把串行 grammar-constrained decoding 的关键路径从 O(b) 个依赖 forward 降到常数级。

评值得看的是“policy-exact 且两次 forward”的编译思路；先盯 lemma 的假设（精确算术/数值误差）和系统对比是否干净，别被概念性加速骗了。

PI-Mem: Pushing Long-Context Reasoning to 3.6M Tokens with Parallel-Iterative Memory

这篇工作处理的是超长上下文推理里的一个老问题：基于 recurrent memory 的方法虽然把计算从全局注意力里解放出来，但它们通常按 chunk 串行更新 memory，早期证据容易被后续无关内容覆盖，而且延迟会随 chunk 数线性增长。PI-Mem 试图同时解决这两个问题：既减少 memory overwrite，又把跨 chunk 处理改成并行。

评读方法图和 RL 退出奖励即可；若 3.6M 评测不是合成检索题，这会影响长上下文预训练预算判断。
