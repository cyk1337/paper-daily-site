LAVOIR appends a slot block for candidate missing information. A single forward pass returns both the decision distribution and a predicted VOI score for each slot. The model keeps Laya’s ModernBERT-large decision head and adds a zero-initialized segment embedding so that, when no slots are present, the logits match Laya exactly in fp32. The VOI head reads each slot representation together with features of the current decision distribution and predicts a scalar value. It is a small MLP with about 0.27M parameters, LayerNorm, a 256-unit GELU hidden layer, and a scalar output. A Gini-based cap constrains the predicted value by the maximum expected gain of a calibrated posterior, which prevents the model from over-asking when it is already confident.
