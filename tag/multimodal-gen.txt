18:T5cb,The method has two main components. The first is token editing. Instead of training only on masked positions as in vanilla MDM, the model is trained with two perturbations at once: some tokens are masked, and some already visible tokens are deliberately corrupted. The model predicts distributions for all positions. For masked positions, it performs the usual denoising prediction. For visible positions, it learns whether the current token should be revised and what it should become. This changes the role of the model from pure fill-in-the-blank generation to iterative correction, enabling inference-time refinement closer to continuous diffusion.

The second component is grouped cross-entropy. The authors argue that large codebooks are difficult not only because the output space is bigger, but because one-hot CE ignores semantic proximity among codes. They cluster the codebook embeddings with K-means, for example mapping a 100k-token codebook into a coarser 16k-group partition. The model still predicts the full token distribution, but probabilities are also aggregated at the group level, and an auxiliary CE loss is applied to the ground-truth group. They further extend this to multiple clustering granularities, yielding hierarchical supervision. This is different from label smoothing: the extra supervision is structured and embedding-aware rather than uniform. The paper also includes a fused implementation to keep the added loss practical in memory and latency.19:T406,Start with three parts. Third, read the grouped CE formulation carefully and compare it mentally with label smoothing and hierarchical soft targets.
