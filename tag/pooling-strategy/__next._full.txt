18:T7a3,SCSP changes the extraction pipeline rather than the model weights. The method has four components.

First, the document is partitioned into sentence-aware chunks, each capped at a maximum token length. This is not only for tractability. It narrows the semantic scope of the later compression prompt so that token-importance estimation happens in a more coherent local context.

Second, a short semantic-compression prompt such as “Brief summary: \"” is appended to each chunk. The prompt is not used to generate summaries explicitly. Instead, it is meant to trigger the model’s internal compression behavior, so that the prompt token’s attention pattern reflects which tokens in the chunk matter most semantically. The punctuation choice is deliberate: the colon and opening quote reduce the chance that the next-token distribution collapses onto punctuation continuation rather than semantic compression.

Third, the authors introduce a prompt-isolated attention mask. This mask prevents later document tokens from attending to the inserted prompts, which avoids contaminating the original document-token representations. At the same time, each prompt is restricted to attend only within its own chunk, so the resulting attention pattern is a local importance signal rather than a globally entangled one.

Fourth, token importance is estimated from the prompt-induced attention distributions, informative tokens are selected, and their representations from an intermediate layer are selectively pooled into the final embedding. Two design choices matter here. The method uses an intermediate layer rather than the final layer, consistent with the common observation that final layers in generative LLMs are often less suitable for semantic embedding geometry. And SCSP is designed as a plug-in on top of existing training-free methods such as Echo, TP, and HTP, so it complements prior work on backward information flow rather than replacing it.19:T537,From the available full-text excerpt, the main empirical claim is that SCSP consistently improves several training-free long-context embedding baselines across multiple benchmarks, and can also further improve fine-tuned embedding models. The compared baselines include Echo, Token Prepending (TP), and Hierarchical Token Prepending (HTP). The gain is attributed to selective aggregation rather than another mechanism for fixing causal information flow.

The most important ablations are likely the following. First, sentence-aware chunking versus naive fixed-length chunking: if sentences are split arbitrarily, the compression prompt should produce noisier importance estimates. Second, the prompt-isolated mask: without isolation, the inserted prompts can interfere with document-token representations and reduce the benefit. Third, the token-selection ratio, the chosen extraction layer, and selective pooling versus mean pooling: these determine whether the method is truly benefiting from better token choice rather than from prompt insertion alone.
