Fisher-R1: Training LLM Agents for Reliable Hypothesis Testing

LLM coding agent 在做开放式假设检验时，经常能写出可运行代码并得到数值结果，但会在统计方法选择、前提假设检查和结论推断上出错，导致 p 值和结论在统计上无效；现有数据分析 benchmark 没有系统评估这种“代码能跑但推断错误”的失效模式。

评P-Bench 对做 agent 评测的人有参考价值，Fisher-R1 的 RL 训练 recipe 可看，但核心是统计推断这个特定垂直场景，通用 pretrain 启发有限。
Jiacheng Miao,Jin Mu,Guanhua Chen,James Zou

Resolution Diagnostics for Paired LLM Evaluation

这项工作解决的是 LLM leaderboard 的分辨率问题：两个模型在同一组 prompt 上相差几个百分点时，这个差距是否足以支持“模型 A 优于模型 B”的统计判断。作者把共享 prompt 的评测明确建模为 paired hypothesis testing，而不是把两个模型分数当作独立样本比较。

评对 LLM Leaderboard 统计显著性的硬核打假，指出很多相邻排名其实是 noise，做 eval 体系的同学必看。
Anany Kotawala
