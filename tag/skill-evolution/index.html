FedSkillGit: Federated Skill Evolution via Version Control

这篇工作处理的是联邦场景下的“技能持续演化”问题：多个数据持有方都在用 LLM agent 执行任务，也都能从本地轨迹里提炼出自然语言技能，但原始执行轨迹不能共享。直接沿用传统联邦学习的做法，让每个客户端改完整份 skill document 再上传，会遇到三个结构性问题：一是隐私并不会因为不传原始轨迹就自动解决，技能文本本身仍可能泄露私有实体、流程和环境信息；二是大部分轮次只改动技能文档的一小部分，整篇上传的通信成本和知识增量不匹配；三是服务器很难从一整篇改写后的文档里识别每个客户端到底贡献了什么知识，也就难以做细粒度聚合和质量控制。论文的核心问题不是一般意义上的 FL 优化，而是如何把“自然语言技能更新”重新表示成适合联邦协作、可审计、可聚合、且尽量保隐私的知识单元。

评值得 skim：commit 作为 Agent 技能更新单元很干净，可借到 continual post-train/memory 系统里。

SkillLift: Learning Dense Rubrics from Sparse Oracles for Efficient Skill Evolution

这篇工作处理的是 agent skill 自演化里的监督稀缺问题。现有方法把 skill 文本直接当优化对象，每次改完都要跑一次完整 agent rollout，再用 oracle 的成败或分数回传信号。问题在于，这种监督既贵又稀：一次评估要消耗整条执行轨迹，skill 文本空间又高度离散，少量 noisy 的 outcome 信号很难稳定指向“下一版 skill 应该怎么改”。结果就是优化容易退化成局部补丁，只修最近一次失败案例，难以形成可迁移的高质量技能。

评利用排序作为更平滑的监督信号，通过学习 rubric 来降低 Agent 技能进化的评估成本，对设计高效的 Agent 自我改进机制有启发。
Haoxiang Kang,Ming Wen
