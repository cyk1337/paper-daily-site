9:T590,The method has three main pieces. First, a library of 14 semantics-preserving transformations, including control-flow rewrites, dead-code injection, and identifier renaming. These are meant to cover both realistic refactorings and stress-test perturbations. Semantic preservation is operationalized through per-test equivalence on the project test suite rather than formal program equivalence, which is pragmatic and aligned with SWE-bench acceptance. Second, a randomized variant sampler applies selected transformations at sampled locations to create independent perturbed repositories. This is intentionally not an adversarial search procedure. The point is to show that even simple, unguided local rewrites already hurt agents, so the measured effect is a lower bound. Third, the evaluation design explicitly handles agent stochasticity by repeating runs on both the original seed repo and its perturbed variants and comparing them in a paired manner. The study also tracks not only issue resolution rate but step count and token cost. Experiments cover two scaffolds, mini-SWE agent and OpenCode, with four frontier models: Claude Opus 4.5, Kimi K2.5, MiniMax M2.5, and Qwen 3.6-27B, on 54 instances from SWE-bench Verified and SWE-bench Pro.
