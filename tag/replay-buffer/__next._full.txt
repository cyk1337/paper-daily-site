18:T6a8,EliteReplay has two stages. Before RL training, the frozen base model is used to build an elite archive with MAP-Elites. This is a key design choice: simply replaying random correct samples from the base model would mostly recover frequent strategies and still underrepresent rare ones. MAP-Elites discretizes a behavior-descriptor space into cells and keeps at most one high-quality solution per cell, so the replay set is explicitly balanced over distinct strategy types rather than over raw sample frequency.

During post-training, the model is optimized with GRPO plus a small replay loss on the archived elite solutions. The replay term acts as an anchor, encouraging the policy to keep assigning probability to diverse correct strategies while still allowing RL to improve task reward. This differs from generic KL regularization or entropy bonuses. KL-to-reference constrains overall drift from the base model but does not specifically protect low-probability correct strategies. Entropy regularization encourages spread, but spread alone does not guarantee preservation of distinct correct solutions. EliteReplay is more targeted: it stores verified, behaviorally distinct solutions and explicitly rehearses them.

Another important technical point is the definition of diversity. The paper evaluates diversity at the level of solution strategies, using a deterministic structural description extracted from the solution itself. This matters because surface-form variation is a poor proxy in SQL: many strings differ syntactically while implementing the same strategy. The deterministic strategy extractor makes the evaluation more stable and better aligned with the intended notion of diversity.19:T62e,The experiments are centered on text-to-SQL, which is a good testbed because many questions admit multiple equivalent correct queries and some are genuinely ambiguous. On BIRD, EliteReplay reaches 74.8% pass@128, essentially matching a strong baseline, MaxRL, at 73.7%, but increases the number of distinct correct strategies per question from 6.2 to 9.1. So the method preserves more meaningful variation without giving up high-budget correctness. On the out-of-distribution Spider benchmark, EliteReplay achieves 93.2% pass@128, outperforming the strongest baseline by 6.3 points while producing up to 77% more distinct correct strategies.

The retention results are especially important. EliteReplay retains 62% and 60% of the base model’s correct strategies on BIRD and Spider, respectively, at least 23 points better than any baseline. That indicates the method is not merely generating a different set of diverse outputs; it is specifically preserving the base model’s existing correct behavioral support. On AmbiQT, which tests ambiguous questions, EliteReplay covers both interpretations on 27.0% of examples versus 14.2% for the strongest baseline. This is a strong sign that preserving diverse correct strategies has direct functional value.

The main ablation logic compares plain RL, ordinary replay, and replay built from a QD archive. The takeaway is that naive replay is insufficient because the base model’s own sampling distribution is already skewed toward frequent strategies.
