a:T7b6,The core method is Future-L1. Starting from a standard video MLLM backbone, the model is augmented with a latent visual reasoning channel controlled by three special tokens: <|latent_start|>, <|latent|>, and <|latent_end|>. Generation begins in text mode. Once <|latent_start|> is emitted, each subsequent latent position produces a hidden state that is not projected to the vocabulary; instead, that hidden state is fed back as the next-step input embedding. This creates an autoregressive continuous-state process inside the latent span, and those latent states remain in the KV cache so later text tokens can condition on them. Span length is variable, and multiple latent spans can appear in one response, allowing adaptive allocation of visual reasoning budget.

Training has two stages. The first is supervised cold start. The authors build Future-L1-50K from TwiFF-2.7M using visual-gain curation rather than naive sampling. For each candidate example, they compare a strong base model under two conditions: observed video prefix only, versus prefix plus an intermediate future-frame hint. They keep examples where the future visual hint provides measurable marginal utility. This removes easy cases that do not need future imagination and noisy cases where the hint is not informative. During SFT, the model learns both when to open latent spans and how to align latent hidden states with future-frame embeddings.

The second stage is LA-DAPO, a latent-aware RL objective. It optimizes sampled latent trajectories using outcome-contrastive rewards and temporal-diversity rewards. The first favors latent futures that lead to correct event prediction; the second discourages repetitive or collapsed latent thought patterns. The motivation is clear: if optimization only rewards the final answer, the latent channel may become decorative. By assigning credit to latent trajectory quality, the method tries to make the continuous visual reasoning path genuinely useful.b:T438,The concept of temporal fidelity is proposed, defined as the ability to capture, retain, and reason over short-lived, answer-critical visual evidence. Momentary visual events are defined as observable actions or state transitions whose decisive evidence is localized within a short temporal window. The Moment-Video benchmark is constructed, containing 1,000 human-verified video-QA pairs across 7 domains and 25 fine-grained subcategories. Four complementary task types form a progressive evaluation pipeline: Temporal Occurrence (TO) verifies whether models can detect the existence of brief events; Temporal Counting (TC) verifies the ability to track repeated transient actions or state changes; Action Description (AD) verifies the ability to characterize dynamic details of momentary events (direction, trajectory, interaction, etc.); Temporal Reasoning (TR) verifies the ability to infer event consequences by integrating pre-event, event, and post-event states.
