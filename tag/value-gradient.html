Value-Gradient Hypothesis of RL for LLMs

这篇论文要回答的是一个近两年后训练里很实际、但理论上一直悬着的问题：为什么没有显式 critic 的 PPO/GRPO，在 LLM 上仍然能做长程 credit assignment，而且常常有效？按经典 RL 直觉，只有终局奖励、动作离散、轨迹很长时，纯 score-function 更新应该方差很大，信用分配很弱，不该这么好用。作者的核心论点是：这些方法并不是真的“没有 value 信号”。在可微 rollout 的连续放松下，actor 的更新在期望上等价于一种 value-gradient-like 更新；到了离散 token 的 transformer 策略里，虽然采样本身不可微，但 attention 和残差路径让 autodiff 产生的经验 costate 近似了这个 value gradient。论文进一步把 RL 的收益拆成两部分：一部分是模型当前能传递多少可用的 value-gradient 信号，另一部分是还剩多少 reward headroom 可以被利用。这个分解被用来解释 RL 在预训练不同 checkpoint 上为何效果差异很大。

评从理论上解释了为什么GRPO等无critic RL能工作——自动微分通过注意力天然传播价值信号。这改变了对RLHF机制的理解，值得做RL-pretrain的人精读。
Arip Asadulaev,Daniil Ognev,Karim Salta,Martin Takac
