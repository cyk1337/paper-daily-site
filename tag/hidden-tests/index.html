FrontierCS 2: A Benchmark for Computer Science R&D

这篇工作要回答的问题不是“模型能不能做代码题”，而是“LLM agent 能不能在真实研究仓库里，基于已有系统做出接近论文贡献级别的改进”。作者认为现有 open-ended benchmark 大多给一个题目、收一个最终程序、做一次离线评分，这和真实计算机科学研发差得很远。真实研发更像是在一个可运行仓库上删掉某个关键创新，再要求研究者把它补回来并超过原实现。论文的核心问题就是如何把这种研发过程做成一个可评测、可保密、又尽量贴近真实研究环境的 benchmark。

评读任务构造和隐藏评分协议即可；它是 agent 研发能力的好压力测试，但不是训练方法论文。
