9:T4b9,The paper contributes a measurement framework and a clean counterfactual design. First, it operationalizes factionalism through interaction traces. In each round, every agent makes an observable commitment and sends that commitment plus a short message to selected peers. From this trace, the authors build a directed weighted agreement graph. An edge from agent i to agent j gains weight when j's next-round commitment matches the commitment that i sent to j. The normalization is important: it controls for contact frequency and convergence timing, so the metric reflects alignment conditional on communication rather than raw message volume.

Second, the experimental design isolates label effects from model effects. The same underlying agents and tasks are run under different visible-label conditions: true family labels, shuffled family labels, neutral labels such as colors, and no visible identity. This is the core methodological move. It separates clustering caused by actual model differences from clustering caused by the mere presence of a label. The reported outcome is that the grouping follows the visible label, including shuffled and neutral labels, rather than the underlying model family.a:T452,The contribution is a structured design space for inference-time cross-lingual exploration rather than a single new algorithm. They claim four inherent dimensions governing cross-lingual exploration (details are in the main method section; from the provided content and cited prior work, these dimensions plausibly include: reasoning vs answering language, pivot vs non-pivot routing, which prompt components are translated, and multi-path sampling/aggregation).
A key stance is to move beyond an English-only pivot: some culturally/localized facts are more accessible in their native language.
