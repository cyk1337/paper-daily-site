18:T713,方法上，作者把问题形式化成 call-decision test。每个样本先有 ASR transcript，再由 text LLM 给出 transcript-side label；同时系统还可以选择调用本地音频 encoder（CLAP、AST、WavLM）或 generative audio model（Qwen2-Audio、Qwen2.5-Omni、MOSS-Audio）。关键不是单独比较这些模型，而是训练一个 routing / selection policy，在固定开发集上决定何时保留 transcript 标签、何时看 encoder、何时发起 generative call。

论文设计了几种策略。transcript-first route 用 transcript 风险分数来决定是否升级到 generative model；风险分数由 transcript label 的开发集错误率估计、Whisper 不确定性、text-LLM label likelihood 不确定性、以及是否输出非法标签等特征组成。encoder-first route 则先让 CLAP 对所有波形打分，再把低 margin 样本送去 generative model。更强的 full selector 把问题写成 row-action 对上的 correctness prediction：用 L2 正则 logistic model 预测某个动作在某个样本上是否会答对，特征包括动作置信度、transcript 不确定性和长度、encoder/generative 标记、动作成本、动作身份等。CLAP 和 WavLM 的开发集预测采用 out-of-fold，避免 selector 直接吃到泄漏的监督信号。

最关键的对照是 matched no-call selector。它和 full selector 使用同样的训练协议、同样的开发集调参流程，只是把 generative actions 整体移除。这样 full-vs-no-call 的差异就能更干净地解释成“生成式音频调用本身的边际价值”，而不是 selector 更强、特征更多、或调参更充分。作者还把成本单独报告，不把 latency / privacy / hosted exposure 混进 accuracy 里。这个设计很工整，适合做接口层面的审计。19:T66a,主实验在 Dynamic-SUPERB VocalSound 六分类任务上进行，chance 为 0.167。开发集 480 条，holdout 240 条，并做了文件 stem、推测 speaker/session 等层面的无重叠检查。这个任务先验证 transcript 不够用：transcript-only 只有 0.296 accuracy。直接看音频模型时，Qwen2.5-Omni 达到 0.883，Qwen2-Audio 0.838，MOSS-Audio 0.808，zero-shot CLAP 0.762，AudioSet AST 0.404。到这里如果停下，很容易得出“必须用 generative audio model”的结论。

但作者继续加入开发集监督的 encoder 控制组，结论就变了。CLAP class-bias tuning 到 0.792；CLAP score probe 0.796 accuracy / 0.784 macro-F1；CLAP embedding probe 0.850 / 0.849；AST embedding probe 0.817 / 0.813；WavLM-base+ probe 0.854 / 0.853。再往上，CLAP–WavLM correctness oracle 到 0.938，联合 CLAP–WavLM ridge probe 到 0.896 / 0.892。也就是说，在这个闭集任务上，轻量或中等规模的判别式音频表示已经吃掉了 generative audio model 的大部分收益空间。

摘要给出的 headline 结论更直接：在 VocalSound 上，supervised selector 在 full action set 下达到 0.900 accuracy，而去掉所有 generative actions 的 matched no-call selector 仍有 0.892，差值只有 0.008，且 95% bootstrap CI 为 [-0.025, 0.042]。这说明在已知标签决策里，生成式音频调用的边际收益很小。作者还在 ESC-50 Animals、AudioBench 的情感子集、以及 SpeechTextMatching 上做了补充实验，用来说明这个结论的适用范围是“known closed-set label decisions”，而不是开放式对话或一般音频推理。1a:T6cc,The task is framed as a call-decision problem. For each example, the system has an ASR transcript, a transcript-side label from a text LLM, optional local audio encoders such as CLAP, AST, and WavLM, and optional generative audio models such as Qwen2-Audio, Qwen2.5-Omni, and MOSS-Audio. The goal is not to compare these components in isolation, but to learn a policy that decides when to keep the transcript label, when to rely on encoder evidence, and when to make a generative audio call.

Several routing strategies are evaluated. A transcript-first route uses a transcript risk score built from development-estimated transcript error risk, normalized Whisper uncertainty, text-LLM label-likelihood uncertainty, and an invalid-label flag. An encoder-first route uses CLAP margins and sends low-confidence cases to a generative model. The strongest setup is a full selector: an L2-regularized logistic correctness model over row-action pairs, with features including action confidence, transcript uncertainty and length, encoder flags, generative-call flags, action cost, and action identity. CLAP and WavLM development predictions are generated out-of-fold to avoid leakage.

The decisive control is the matched no-call selector. It uses the same training protocol, the same development tuning procedure, and the same selection machinery, but removes all generative actions. That makes the full-versus-no-call comparison a clean estimate of the marginal value of generative audio calls, rather than a comparison confounded by different selectors or different tuning effort. Costs are reported separately from accuracy, which keeps latency, privacy exposure, and hosted-interface concerns from being folded into the main accuracy metric.1b:T6f7,The main benchmark is Dynamic-SUPERB VocalSound, a six-way human-vocalization classification task with chance accuracy 0.167. The development split has 480 rows and the holdout has 240, with checks for overlap in file stems and inferred speaker/session groupings. The first result confirms that transcripts are insufficient: transcript-only accuracy is 0.296. Audio models are much stronger: Qwen2.5-Omni reaches 0.883, Qwen2-Audio 0.838, MOSS-Audio 0.808, zero-shot CLAP 0.762, and AudioSet AST 0.404. If evaluation stopped there, one could easily conclude that generative audio models are necessary.

The more informative comparison comes after adding supervised encoder controls. CLAP class-bias tuning reaches 0.792. A CLAP score probe reaches 0.796 accuracy and 0.784 macro-F1. A CLAP embedding probe reaches 0.850 and 0.849. AST embeddings reach 0.817 and 0.813. A WavLM-base+ probe reaches 0.854 and 0.853. A CLAP-WavLM correctness oracle reaches 0.938, and a joint CLAP-WavLM ridge probe reaches 0.896 and 0.892. These results show that discriminative audio representations already recover most of the benefit on this closed-set task.

The headline result from the abstract is the key one: on VocalSound, the supervised selector with the full action set reaches 0.900 accuracy, while the matched no-call selector still reaches 0.892. The gap is only 0.008, with a 95% bootstrap interval of [-0.025, 0.042]. In other words, once transcript and encoder evidence are available to the same development-selected policy, generative audio calls add little on this task.
