Speculative Macro Commit for Faster Tool-Using Agents

工具型 Agent 的端到端时延瓶颈不只在模型推理，还在多轮 action–observation 的串行依赖：每次工具调用与环境返回都会阻塞下一步决策。已有 action-level speculation（先用小模型预测下一步动作、再由大模型验证）通常只能在“相邻一步”粒度上复用工作，难以把更长的多步链条真正变成可提交的加速收益。论文要解决的是：如何在不要求大模型显式选择新 meta-tool 的情况下，把 trace 中重复出现的多步模式用于运行时加速，并尽量保持任务质量。

评将推测解码的思路应用到 Agent 的工具调用轨迹上，通过小模型预执行环境交互来掩盖大模型的延迟，思路很巧妙，值得关注系统优化的研究员一读。
Zeyu Liu,Souvik Kundu,Peter A. Beerel
