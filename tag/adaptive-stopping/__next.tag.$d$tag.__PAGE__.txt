9:T983,方法名为 StreamStop。整体结构是冻结一个 reasoning model M 来持续生成 reasoning stream，同时引入一个单独的 prefix reader R 和一个轻量 stop head。reader 只读取当前公开可见的信息：任务上下文、交互历史、以及当前已经生成出来的 reasoning prefix；stop head 基于 reader 特征和一些进度元信息，决定当前是继续等待更多 reasoning chunk，还是立刻停止并用当前前缀去触发环境动作生成。

论文把这个过程建模成一个 prefix MDP。状态包含公共上下文 h、当前 reasoning prefix xt、其 token 长度 kt、以及 checkpoint 索引 t。控制动作只有 Wait 和 Stop。Wait 会让冻结的 reasoning model 再吐出下一段 reasoning chunk；Stop 则终止前缀过程，并调用 reasoning model 的 action-generation 接口 AM，用当前前缀生成环境动作。关键在训练目标：作者不是直接预测 reward，也不是预测“答案稳定了没有”，而是定义了 prefix-level action agreement——从某个前缀生成的动作是否与 full-reasoning reference action 一致。这个 reference action 来自完整 reasoning 后的模型动作，因此停机策略是针对具体 reasoning model 的行为来拟合的，而不是依赖某种通用置信度启发式。

更具体地，作者离线收集 reasoning trajectories，并在多个前缀位置标注动作结果。这样每个决策点上，不同 stopping time 的后果都可观测。基于这些离线记录，论文定义了一个带 discount 的目标，在“保留 full-reasoning 动作一致性”和“少消耗 reasoning token”之间做权衡。discount factor γ 直接控制 trade-off：γ 越小，越鼓励早停；γ 越接近 1，越重视与 full reasoning 行为保持一致。作者还把 γ 作为条件输入之一，使同一个训练好的 stop policy 可以在推理时按不同预算偏好切换，而不必重新训练。

和已有方法相比，区别主要有三点。第一，不需要访问 reasoning model 的 hidden state 或 token logprob，因此适配 text-only API。第二，停机信号不是通用 confidence，而是模型特定的 prefix-action agreement，直接对齐“停在这里会不会改变最终动作”。第三，训练是离线的 expected-return optimization，因为不同前缀的结果都已记录，可以精确比较不同 stopping time，而不是在线 RL 式试错。a:T8a4,The method, StreamStop, uses three components: a frozen reasoning model M that streams reasoning text, a separate frozen prefix reader R that encodes the currently available reasoning prefix, and a lightweight trainable stop head that decides whether to wait for more reasoning or stop and act. The stop head only sees public information: the task context, interaction history, the visible reasoning prefix, and simple progress metadata. It does not access the reasoning model’s hidden states or token probabilities.

The paper formulates the problem as a prefix MDP. A state contains the public context h, the current reasoning prefix xt, its token length kt, and the checkpoint index t. The control action is either Wait or Stop. Wait reveals the next chunk from the frozen reasoning model. Stop terminates the prefix process and invokes the reasoning model’s action-generation interface using the current prefix. The central training signal is prefix-level action agreement: whether the action generated from a partial prefix matches the reference action produced after full reasoning. This is a model-specific target, because the stopping policy is trained to preserve the behavior of a particular reasoning model rather than to follow a generic confidence heuristic.

Training is done offline from collected reasoning trajectories with action annotations at multiple prefix lengths. Because the outcomes of different stopping times are recorded, the paper can optimize an exact expected-return objective over stopping decisions. A discount factor gamma controls the tradeoff between preserving the full-reasoning action and saving reasoning tokens: smaller gamma favors earlier stopping, while gamma closer to 1 favors agreement with the full-reasoning reference. Importantly, gamma is also provided as a conditioning input, so one trained policy can be used at inference time under different budget preferences.

Compared with prior work, the main differences are clear. It is text-only and API-compatible. It uses action agreement rather than hidden-state confidence or answer stability. And it learns the stopping rule offline from observed prefix outcomes rather than through online trial-and-error.b:T807,The experiments are conducted on interactive agent environments including WebShop and ScienceWorld. The main empirical question is whether StreamStop can reduce reasoning-token usage while preserving action quality or task return. The introduction and provided content do not expose the full result tables, but several important findings are already clear.

First, the paper includes a useful feasibility diagnostic. A 1.7B prefix reader is used to score action candidates from partial reasoning prefixes, while a 27B reasoning model generates actions from those same prefixes. Reader agreement with the full-reasoning action increases as the prefix grows, and many decisions have a sufficient prefix that is substantially shorter than the full reasoning trace. This supports the core premise that stopping can be judged by a smaller model and that there is real room to save reasoning tokens.

Second, StreamStop outperforms fixed-length reasoning and heuristic stopping rules across models and environments in the agreement-versus-token tradeoff. It can use fewer reasoning tokens at similar action agreement, or preserve more of the full-reasoning behavior at a similar token budget. The paper attributes this to learning a model-specific offline policy rather than relying on a universal threshold.

Third, the ablations highlight the importance of the training target and the discount conditioning. Replacing action agreement with weaker proxy signals leads to less reliable stopping. Removing gamma conditioning reduces flexibility because separate policies are then needed for different budget preferences. Another practical contribution is the released dataset of reasoning trajectories with prefix-level action annotations, which enables reproducible offline comparison of stopping rules without rerunning full online rollouts each time.
