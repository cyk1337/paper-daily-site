Context Blindness in DPO: Mitigating Object Hallucination in MLLMs via Context-Calibrated Preference Optimization

这篇工作盯住的不是“如何再造一批更好的偏好数据”，而是一个更基础的问题：现有 DPO 类目标在训练 MLLM 抗幻觉时，是否真的学会了利用额外上下文来增强对正确回答的偏好。论文给出的结论是否定的。作者把这种现象称为 context blindness：即便输入里加入了有助于 grounding 的上下文，标准 DPO 的优化形式也不会显式奖励“有上下文时偏好边际更大”，因此模型学到的偏好常常对上下文不敏感。这一点直接关系到 object hallucination，因为很多幻觉并不是模型不会比较好坏回答，而是它没有把视觉或补充文本上下文真正纳入偏好判断。

评读 CPG 定义和 ablation 即可；它提醒偏好数据加上下文不等于训练信号真的依赖上下文。
Byungoh Ko,Jinyoung Park,Jongha Kim,Jeehye Na,Jaewon Cho,Hyunwoo J. Kim
