18:T4b5,Raincheck implements deferred multimodal prefill:
- Start with any existing pruning method to select a fraction of “important” multimodal tokens for initial prefill (plus all text/control tokens). Keep the remaining multimodal tokens as deferred tokens.
- During decoding, process deferred tokens in source order in small chunks, leveraging the fact that decode is often memory-bound at small batch sizes and leaves unused compute. A scheduler caps deferred tokens per decode step to bound TPOT increase.
- Continue unfinished deferred prefill after the answer is returned (during user reading/tool time), so later turns can reuse a more complete context state.
- Correctness mechanisms: (1) attention visibility control so that extending the input context does not introduce illegal dependencies of already-generated states on newly-prefilled input; (2) affine state mapping for hybrid models with recurrent/compression layers, updating the recurrent state online using recorded transitions so the model need not rerun the full sequence.
- Systems design emphasizes fused prefill+decode execution to reduce repeated weight access; an alternative disaggregated prefill-decode design is also described.19:T516,Decoding is modeled as a stopped stochastic process: for a fixed prompt x and sampling configuration, the generated length Y is a stopping time determined by the appearance of stop tokens/strings. The discrete hazard p_t and survival S_t characterize the length distribution, but the hazard is context-dependent and random because it depends on sampled continuations.

To explain why lengths look approximately Gaussian (despite strong token-level dependence), the paper introduces a segment-based mechanism: a response is a concatenation of M semantic segments (sentences, list items, reasoning steps). Conditional on M, segment lengths L_i are treated as i.i.d., and Y=\sum_i L_i. Normality then follows from a CLT at the segment level, with an explicit Berry–Esseen-type error term.

From the normal approximation, the paper derives architecture-agnostic lower bounds on achievable point-prediction error (e.g., MAE close to \sigma\sqrt{2/\pi}) and pass-rate bounds, plus an excess-risk decomposition that separates an irreducible “system” term from a “model” term. It also explains the empirically observed affine variance law \sigma=\alpha\mu+b and interprets \alpha via segment-count variability, linking predictability to generation dynamics rather than to a particular regressor head.1a:T4e9,The empirical section is designed to validate the statistical claims and to show that many predictor architectures converge to the same ceiling.
- On 300 ShareGPT prompts with 200 sampled decodes each, per-prompt MAE matches the Gaussian prediction \sigma\sqrt{2/\pi} within ~1.9%.
- Central mass under the normal approximation is within ~2 percentage points.
- Residual non-normality is small and directionally consistent with the paper’s sampling-noise correction (median skewness ~+0.27, excess kurtosis ~+0.35).
- The affine law \sigma=\alpha\mu+b holds, but (\alpha,b) varies substantially across models and post-training recipes (Table 1), supporting the claim that “benchmark difficulty” changes with the target model.
- Under fixed model/data/sampling, a range of predictors (MLP on hidden states, entropy-guided pooling like EGTP, FiLM conditioning, soft-label classification, MoE routing) end up with similar performance near the theoretical bound, suggesting limited headroom from architectural tweaks alone.
- The motivating instability examples include MAE shifting from ~80 (ForeLen + Qwen2.5-7B) to >150 (ShareGPT + Qwen3-32B) and >260 under RL-sampled data, attributed to increased intrinsic variance rather than predictor degradation.1b:T833,实验重点围绕 acceptance length（AL）与 KV 预算的关系展开，因为 speculative decoding 的实际收益高度依赖 draft 被 target 接受的长度。论文主要在 SPEED-Bench 上评测，特别强调 32K 输入长度、带 reasoning 的长输出场景，这比很多只看短输出的压缩实验更贴近真实瓶颈。

论文还展示了一个重要现象：随着 output sequence length 增长，SWA 会逐步追上并超过 SnapKV，说明“最近生成 token”的价值在长 decode 中持续上升，而 prefill 选出的 token 价值在衰减。作者把这作为 decode staleness 的直接证据。并且这种现象在 hybrid attention 模型里更明显，因为只有部分层保留 full attention 时，有限的全注意力层更依赖被保留下来的 KV 质量，错误选择的代价更高。

On the inference side, the paper starts from two static extremes. One is pure sliding-window attention, which always keeps the most recent B tokens. The other is prefill-based selection, where a fixed subset of prompt KVs is chosen once using aggregated attention scores, as in SnapKV. Sliding window is strong on recency but weak on remote context. Prefill selection preserves long-range prompt information but becomes stale as decoding progresses. RIFT combines the two. The KV budget is explicitly split between recent generated tokens and importance-selected historical tokens. This preserves local continuity while still keeping a sparse set of long-range anchors.

The second idea is decode-time refresh. The importance-selected subset is not frozen after prefill; it can be recomputed periodically during generation. That lets the retained historical context adapt to the current decoding state. The trade-off is extra latency, so RIFT is presented as a family of strategies with different refresh frequencies and complexity/quality trade-offs.

The training-side contribution is compression-aware knowledge distillation. The authors argue that a drafter trained with full context but deployed with compressed context suffers from a substantial mismatch. To address this, they distill under compression-driven attention masks that mimic the inference-time cache restriction. First, periodic rounding. During prefill, chunked kernels already update and write the recurrent state only once per chunk. The problematic regime is autoregressive decoding, where the kernel is invoked once per token and the state is quantized after every step. PACE introduces a decode buffer that stores recent keys and values for a small number of generated tokens, and only flushes them into the recurrent state every dP steps. This reduces how often quantization noise is injected. The paper derives a per-head retained-error bound showing that the surviving error increases with head decay and decreases with the rounding period. The argument is simple but useful: if the recurrence contracts errors between writebacks, less frequent rounding can outperform more frequent rounding even at the same bit width.

Second, channel-aligned grouping. The authors analyze the gated-delta state and find that large-magnitude entries are column-structured rather than randomly scattered. Intuitively, some delta-value channels stay large across many tokens, and the outer-product update writes that persistence into whole columns of the state. If quantization groups cut across columns, one large entry can dominate the shared scale and waste levels on many small entries. Grouping along the key axis, so that each group stays within a column, produces more homogeneous dynamic ranges. The paper supports this with max/RMS statistics and a channel-permutation experiment that ties the observed structure back to persistent delta channels.

Third, head-level mixed precision. PACE-4 quantizes all heads to 4-bit. PACE-4/8 keeps the quarter of heads in each layer that retain rounding error the longest at 8-bit, while the rest remain at 4-bit. This follows directly from the per-head decay analysis: some heads are much more sensitive to quantization than others, so uniform precision is wasteful.

The implementation side is also important. The paper includes Triton kernels for periodic decoding with packed 4-bit state, and it accounts for decode-buffer memory in the reported totals.
