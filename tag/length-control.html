Survival-Guided Length Control for Efficient Diffusion Language Models

这篇论文解决 masked diffusion language model 推理中的长度控制问题：给定一个 prompt，应该生成多少个新 token。现有 AOAR 式解码通常使用任务无关的较大 Lmax，再按固定去噪步数处理整块 masked canvas。很多样本真实答案远短于 Lmax，模型仍会在无用位置上反复去噪，造成主要推理开销。

评做 DLM/LLaDA 的值得看，重点不是 7x，而是它把“长度只是解码超参”这个 prior 打掉了；先看长度分布分析和停止规则对精度的敏感性。

Taming the Thinker: Conditional Entropy Shaping for Adaptive LLM Reasoning

这篇工作处理的是 reasoning RL 里一个很现实的矛盾：为了提高复杂题准确率，模型往往被鼓励生成更长、更发散的 CoT；但这种探索式训练会把简单题也拖成长推理，带来明显的 overthinking、时延和推理成本。已有两类方法各有缺口：一类基于高熵 token 鼓励探索，通常能提准确率，但会进一步拉长输出；另一类直接压长度或做按需触发 CoT，能省 token，却容易伤到真正需要深思考的难题。作者要解决的是如何让模型在简单题上更果断，在难题或错误路径上更愿意探索，而且这种调节不是按题目预先分类，而是在 token 级别、沿着当前推理路径动态发生。

评只看熵按正确性分流的设计即可；结论方向合理，但没有规模和消融细节前，不应改训练栈。

On Stable Long-Form Generation: Benchmarking and Mitigating Length Volatility

长文本生成的主要问题不只是“平均能不能写够长度”，而是同一指令多次采样时输出长度分布高度不稳定（length volatility），导致成本不可控、可靠性差。论文要解决的是：如何系统量化这种波动、定位与内部机制相关的可观测模式，并给出无需训练的缓解策略。

评建议只读 VOLTBench 指标和 attention trace 分析；GLoBo 像解码补丁，机制证据更有价值。

Length Value Model: Scalable Value Pretraining for Token-Level Length Modeling

这篇论文要解决的是生成长度的 token 级建模问题。现有长度控制多依赖 prompt、序列级长度惩罚，或生成前的长度预测器；这些方法只能在整段回答层面施加约束，不能描述生成过程中每一步离结束还有多远，也难以捕捉中途从短回答转向长推理的动态变化。
