Geometric Iterative Retrieval for Neural Audio Codec Resynthesis

这篇工作解决的是神经音频 codec 的 resynthesis 问题：已知第一层或粗层 RVQ token，怎样恢复后续残差层，才能把离散 token 重新解码成更高保真的音频。已有两条路各有明显缺陷：逐层离散分类尊重 RVQ 层级，但不利用 codebook 几何；一步连续回归利用几何，但容易均值化、过平滑，也缺少逐层纠错能力。作者要找的是第三条路：既保留 RVQ 的 coarse-to-fine 结构，又在连续 codebook 空间里做迭代预测。

评音频/语音 LM 研究员值得关注，提出了一种利用 RVQ 几何空间进行对比检索的解码新范式，比纯分类或回归更好。

Khala: Scaling Acoustic Token Language Models Toward High-Fidelity Music Generation

这篇论文想解决纯 acoustic-token 音乐生成里的一个关键矛盾：只用离散音频 token 是否能同时承载长程音乐结构和高保真声学细节，而不依赖额外的 semantic token 阶段或 diffusion / neural renderer。难点在于 token 层级要足够深，语言模型还要能处理高码率、长序列、多 RVQ 层的生成问题，并且需要在有歌词时保持文本-人声对齐。

评音频 token LM 方向值得扫方法图；重点看 64-layer RVQ 与固定步数细化是否真能替代扩散尾部。
