9:T974,方法上分三步。第一步是定义 single-token feature。作者没有只靠自动解释文本，而是用 top-k=20 激活 token 的统计量构造三个连续指标：Gap Ratio 衡量第一名 token 对第二名的优势，Lexical Purity 衡量 top-k 中是否被同一 token 及大小写变体主导，Complete Word 过滤掉子词碎片。最终采用 gap>=0.3、purity>=0.6、且必须是完整词的保守阈值。这个 operating point 只覆盖约 1.48% 的 feature，但作者用三种信号验证它：解释文本匹配率、decoder 几何聚类、以及后续因果消融显著性。

第二步是几何与层深分析。作者从 Neuronpedia 上取 3.9M 个 SAE feature，覆盖 6 个基座模型和 3 个 SAE family：GPT2-Small 上的 res-jb，Gemma 系列上的 GemmaScope/JumpReLU，Llama-3.1-8B 与 DeepSeek-R1-8B 上的 LlamaScope/TopK，并额外在 Gemma-2-2B、Gemma-3-1B 上加入 community BatchTopK 以便同底模跨 family 比较。核心观察是 single-token feature 在 decoder space 中更紧密，聚类紧度约高 4.7 倍；它们高度集中在早层，GPT2-Small 中 91% 在 Layer 0，Gemma 中主要在 L0-L4；并且 L0 到 L1 有明显结构跃迁，Grassmannian alignment 只有 0.26，而后续层间通常大于 0.9。这说明 token identity 相关方向在最早层有特殊地位，之后表征更平滑地传播。

第三步是因果检验。作者做的是 zero-ablation at full layer depth：在某层把目标 SAE feature 置零，然后观察目标 token logit 的变化，并沿完整剩余网络传播，而不是只看局部重构误差。对于跨 family 检测，作者指出 activation-based detection 在 LlamaScope 上会失效，因为 TopK 到 JumpReLU 的转换改变了激活分布，于是改用 decoder-alignment detection：直接计算 feature decoder 向量与词嵌入矩阵的余弦相似度，再施加同样的 gap/purity 条件。这样可以在没有激活数据时做跨 family 对齐。关键结论是：GemmaScope 和 BatchTopK 上匹配到的 single-token feature 更像“因果锚点”，消融后目标 token 排名常显著下降；而 LlamaScope 上很多匹配 feature 呈现局部冗余，目标 token 往往能很快恢复原排名，恢复率达到 96%–98%。作者还专门检查了激活函数差异，认为不能简单把这种差异归因于 TopK vs JumpReLU，本质上是 SAE family 学到的表示分解方式不同。a:T7b4,实验规模是这篇文章比较扎实的部分。数据来自 6 个模型、3 个 SAE family，总计 3.9M feature，模型从 124M 的 GPT2-Small 到 9B 级 Gemma-2-9B，跨近两个数量级。主要结果有几组。
