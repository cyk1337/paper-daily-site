1. 视觉监督训练：作者用约 1M 参数的 core 去初始化 85M 参数的 ViT-Base，再在 ImageNet-1K 上训练，top-1 相比随机初始化提升 +2.2 个百分点。这是最核心的 headline result，因为它说明一个很小的 recurrent core 可以迁移到大得多的目标模型，并带来稳定收益。

2. 下游表征质量：论文没有把收益局限在分类，而是检查了更能反映表征结构的任务。给出的数字包括：ADE20K 语义分割 mIoU 从 26.6 提升到 28.8；ImageNet-S 零样本分割 mAP 从 32.3 到 42.9；VOC07 目标定位 CorLoc 从 9.9 到 18.4；NYUv2 深度估计 RMSE 从 1.104 降到 0.998。这里的模式很重要：定位、分割、深度都变好，说明初始化影响的不只是分类头适配，而是中间表征更规整。

3. 自监督与跨域：作者还报告 DINO 自监督训练也有收益，说明 Procedural Core 不依赖监督标签。更关键的是，收益延伸到语言模型，在 FineWeb-Edu 自然语言数据和 CodeParrot 代码数据上训练的模型也优于随机或结构化初始化。当前片段没有给出语言实验的具体 loss 或 perplexity 数字，但这一点使它和一般 CV 初始化工作拉开了距离。

4. 对比基线：文中明确说优于 random initialization 和 structured initialization（如 Trockman and Kolter, 2023）。这说明收益不是“任何非随机初始化都行”，而是 procedural recurrent core 这个特定先验更有效。

5. 机制分析：作者发现 recurrence 带来的参数共享会把计算分布到更广的方向集合，尤其包含低能量成分；在 ViT 中，结构主要集中在 attention value/output pathway，并能抑制高范数 token outlier。这个分析很关键，因为初始化论文常见问题是“有效但说不清为什么”，而这里至少给出了一条可检验的机制链路。

Stage one trains a very small recurrent auxiliary transformer on procedural data instead of warming up each target model directly. The auxiliary model is a minimal recurrent ViT with only three unique blocks: an input block, a recurrent middle block, and an output block. The objective and procedural data setup follow prior procedural warm-up work. The key idea is not to maximize the auxiliary model’s standalone performance, but to force useful computation into a compact reusable parameter set through depth-wise sharing. Recurrence acts as a compression mechanism: if deep transformers partly implement block-recurrent programs, then a recurrent model is a natural place to store that structure compactly.

Stage two expands this compact core into a target transformer of arbitrary width and depth. Depth is handled by unrolling the recurrent block across layers. Width is handled by tiling or expansion rules that map the smaller learned weights into a wider model. The result is a deterministic initialization procedure, not a new warm-up run for each target architecture.

The novelty has three layers. First, it turns procedural pretraining from a repeated training stage into a reusable initialization asset. Second, it uses recurrence as the transfer format, rather than directly interpolating or transplanting warm-up weights. Third, the paper goes beyond reporting gains and studies why the method transfers: depth-wise sharing appears to spread computation across a broader set of directions, including lower-energy components that matter for transfer; in ViTs, the strongest effects concentrate in the attention value/output pathway and suppress high-norm token outliers.

From an LLM perspective, the most interesting part is that the same idea is tested not only in vision but also in natural language and code modeling, which argues for a more general transformer prior rather than a vision-specific trick.1a:T894,The experimental section is substantial and goes well beyond ImageNet classification.

1. Supervised vision training: a roughly 1M-parameter core is expanded to initialize an 85M-parameter ViT-Base, then trained on ImageNet-1K. This gives a +2.2 point top-1 improvement over random initialization. This is the central result because it shows that a very small recurrent core can transfer to a much larger target model.

2. Representation-sensitive downstream tasks: the gains are not limited to classification. Reported numbers include ADE20K semantic segmentation improving from 26.6 to 28.8 mIoU, ImageNet-S zero-shot segmentation from 32.3 to 42.9 mAP, VOC07 localization from 9.9 to 18.4 CorLoc, and NYUv2 depth estimation improving from 1.104 to 0.998 RMSE. This pattern matters: segmentation, localization, and depth all improve, which suggests the initialization changes internal representations rather than only helping classifier fitting.

3. Self-supervised and cross-domain transfer: the paper also reports gains for DINO, so the effect is not tied to supervised labels. More importantly, the method also helps language models trained on FineWeb-Edu and code models trained on CodeParrot. The excerpt does not expose exact language-model loss or perplexity numbers, but this is what separates the work from a standard CV initialization paper.

4. Baselines: Procedural Core beats both random initialization and structured initialization baselines such as Trockman and Kolter (2023). So the result is not just “any non-random start helps.”

5. Mechanistic analysis: the paper argues that recurrence spreads useful computation across a wider set of directions, especially lower-energy ones, and that in ViTs the effect concentrates in the attention value/output pathway while suppressing high-norm token outliers.
