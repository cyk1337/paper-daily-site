TIRE: Top-Down Formula Instantiation with Reliable Execution for Physics Problem Synthesis

这篇工作要解决的不是“再做一个物理题数据集”，而是物理推理训练数据里一个长期存在的结构性问题：现有数据要么来自人工命题，质量高但规模小；要么直接让 LLM 从文本生成题目和解答，规模大但监督信号不可靠。物理题比纯数学更难，因为它不仅要算对，还要保证自然语言场景、物理定律、适用条件、参数设定和数值答案彼此一致。TIRE 试图把“专家自上而下命题”的可控性，与“程序执行可验证”的可靠性，以及“LLM 生成自然语言”的扩展性放到同一条流水线上。

评一种通过符号执行前置来保证合成数据数值正确性的 pipeline，对于关注复杂推理数据合成（如数学/物理）的研究员有一定启发，重点看其公式实例化的具体设计。
Xiaoyu Wu,Zhaoxin Yu,Xinglin Xiao,Nan Xu
