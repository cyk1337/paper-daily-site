Pipelined Gradient Coding

这篇工作处理的是分布式训练里的经典瓶颈：straggler 会拖慢每一步的梯度聚合，而传统 gradient coding 虽然能容忍 straggler，却要求每个 worker 在每一步额外计算多个数据分片的梯度，常常把“抗拖尾”换成了“更高计算时延”。论文要解决的不是编码能不能恢复全梯度，而是如何在不增加单步计算负担的前提下，保留 gradient coding 的容错能力。

评做大规模分布式预训练系统的可参考，重点看流水线设计和收敛证明，是缓解straggler的新思路。
Xian Su,Jun Li

Faster Synchronous On-Policy RL via Straggler-Aware Group Sizing

同步在线RL训练（如GRPO/DAPO）中，rollout生成长度的高方差导致严重的掉队者（straggler）问题：组内单次超长rollout会延迟整个组的奖励计算和参数更新，造成GPU空闲浪费。这一问题随组规模增大而恶化，使得增大组规模以提升优势估计质量的目标与实际壁钟效率之间存在根本矛盾。

评读 §方法和吞吐曲线即可；如果内部 GRPO 还用固定 group size，这篇值得马上复现小规模 ablation。
Azal Ahmad Khan,Ammar Ahmed,Zeshan Fayyaz,Sheng Di,Mingyi Hong,Ali Anwar

MACS: Modality-Aware Capacity Scaling for Efficient Multimodal MoE Inference

这篇工作解决的是多模态 MoE 模型在 Expert Parallelism 推理时的 straggler 问题，尤其是现有按 token 数量做 capacity 管理的方法在多模态场景下失真。原因有两个：视觉 token 信息密度差异很大，很多 patch 是冗余背景；同时不同任务的图文比例变化很大，固定 capacity 因子会导致资源分配和同步等待都不稳定。论文的目标是在不改训练的前提下，做更贴近真实负载的推理期调度。

评多模态MoE推理效率的工程优化，对实际部署有参考价值，但属于推理系统优化而非预训练方法创新，方法部分值得skim。
