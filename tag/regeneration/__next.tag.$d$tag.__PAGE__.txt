9:T6f2,实验对象是 DFlash 风格的 block drafter：在 anchor 位置 a 读取 frozen target 到 a 的 hidden features，一次性预测未来 K=15 个 token slot；每个样本最多采 128 个 anchors。slot 权重用指数衰减 w_k=exp(-(k-1)/γ)，并用保留权重归一化。
对比三类训练目标：
1) CE on corpus tokens：直接对语料 token 做交叉熵（等价于把语料当“真值”）。
2) Token-level KD：用 target 在 corpus prefix 下的 next-token 分布 p_T(·|x,y_<t) 做蒸馏；实现上只保留 top-8 token，把其余合并成第 9 类（降低蒸馏开销/噪声），对 drafter 的对应 9-way 分布做 KL/CE。
3) KD + survival gate：gate 只保留那些“在 greedy verification 下会被接受”的位置。直觉是 speculative decoding 的收益来自能被 verifier 接受的位置，因此把 loss 聚焦到这些位置可能更有效。

关键设计是把同一训练语料做四种 response 版本来隔离变量：
- external responses（原始语料，response 由别的模型/人写）
- greedy regenerated responses（用 target 贪心重写 response）
- 两个 matched-length regenerated 版本：因为 regeneration 往往更长，作者分别用 cut（截断到原长度）和 mask-loss（长度外不计 loss）来控制“长度变化”这个混杂因素。

机制解释围绕“标签一致性”展开：regeneration 后，语料 token 与 target greedy token 的一致率大幅上升；在一致的位置，CE 已经把 drafter 推向 target 的 mode，token-level KD 只能提供对非 argmax token 的那点概率质量，边际收益自然变小。对 survival gate 也是类似：当 response 本身就是 target greedy 轨迹时，“哪些位置会 survive”变得更平凡，gate 的区分度下降。a:T76c,核心结论在多个控制变量下保持一致：
- 在 external responses 上，token-level distillation 和 survival gate 都能带来显著 acceptance 提升；
- 一旦换成 greedy regenerated responses，distillation 的增益大幅缩水，只剩小幅提升；gate 的增益基本消失（little or none）。
- 这种缩水不依赖于数据顺序、初始化、position weight、gate 形式、学习率、verifier、decoding temperature 等设置；控制实验会改变缩水幅度，但方向稳定。
- matched-length 控制显示：缩水不是简单由“regenerated 更长”导致。distillation 的缩水在 cut/mask 两种长度匹配下大多仍存在。
- gate 的一个细节：在 cut 版本里 gate 还能留下小增益，原因是 cut 会降低 ungated objectives 的 acceptance（截断改变了验证行为/分布），但 gated objective 受影响较小；而 mask-loss 不会改变生成序列本身，因此不产生这种相对优势。
- horizon study（训练时长扫描）：在 external responses 上，随着训练变长，CE 的 acceptance 掉得更快，导致 distillation 相对收益变大；但在各自“最佳训练长度”处，regenerated 上的 distillation 增益仍远小于 external。
- 跨数据/跨模态复现：第二个 vision corpus 复现同样缩水；text-only replication 更换 target/corpus/verifier，并加入 AR drafter，仍观察到 distillation 与 gate 的缩水（在 greedy 与 sampled decoding 下对 distillation 都成立；AR drafter 在 greedy 下也成立）。
- label control：把 external responses 的标签直接替换成 target greedy tokens，用 CE 训练就能拿到 distillation 的大部分收益，支持“增益主要来自把标签对齐到 target mode”这一解释。

Three objectives are compared:
1) Cross-entropy on corpus tokens.
2) Token-level distillation from the target next-token distribution under the corpus prefix, implemented as a 9-way distribution (top-8 tokens + merged tail) for efficiency.
3) The same KD but masked by a “survival gate” that keeps only positions whose preceding continuation would be accepted under greedy verification.

Crucially, they vary the response source while holding prompts/images fixed: original external responses vs greedy regenerated responses. Because regeneration changes average length, they add two length-matched regenerated variants (truncate vs mask loss beyond the original length) to disentangle length effects from label-source effects. A battery of controls (init, data order, position weights, gate variants, LR, verifier, decoding temperature) tests robustness.c:T582,Main finding: KD and survival gating yield large acceptance gains on external responses, but greedy regeneration removes most of those gains—KD becomes a small improvement and the gate provides little to none. The direction holds across many controls.

Length controls show the shrinkage is not primarily due to regenerated responses being longer: most KD shrinkage remains under both truncation and loss-masking. The gate only retains a small gain under truncation because truncation hurts acceptance for ungated objectives more than for the gated one; loss-masking does not create that artifact.

A training-horizon sweep shows objective ranking depends on training length: on external responses, CE acceptance degrades more with longer training, making KD look increasingly better; yet at each objective’s best checkpoint, KD’s gain on regenerated responses is still far smaller than on external.

Replications: the effect appears on a second vision corpus and in a text-only setup with different target/corpus/verifier; KD shrinkage holds under greedy and sampled decoding, and also with an autoregressive drafter (under greedy).

A label-control supports the mechanism: replacing external labels with the target’s greedy tokens and training with CE recovers most of KD’s apparent gain, consistent with “benefit comes from aligning labels to the target mode,” which regeneration already does.d:T406,Refinement via Regeneration (RvR): treat refinement as another round of conditional generation rather than instruction-driven local editing. Conditioning uses the target prompt plus high-level semantic tokens (ViT features) extracted from the initial image; importantly, it drops pixel-level VAE-latent conditioning to avoid anchoring the output to the original appearance.
Two mechanisms enlarge the effective modification space:
1) Data/supervision: build training pairs from independently generated T2I samples under the same prompt with different alignment quality, instead of true editing pairs. The target (better-aligned) image is not required to be a pixel-consistent edit of the source (worse-aligned) image, so the model is rewarded for semantic correction even if it requires global restructuring.
2) Pipeline: rely on semantic ViT representations only, enabling broad revisions guided by semantics rather than appearance preservation.
