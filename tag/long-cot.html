Not All Tokens Deserve Equal Credit: Counterfactual Sensitivity Credit Reallocation for Long-CoT Reasoning

DreamReasoner-8B: Block-Size Curriculum Learning for Diffusion Reasoning Models

这篇论文解决的是 block diffusion language model 在长 CoT 推理中能否使用大 block 的问题。block diffusion 希望把跨 block 依赖做成自回归，把 block 内 token 用扩散去噪并行生成，以换取推理并行度。但大 block 会削弱逐步生成的细粒度约束，直接训练大 block 时推理能力明显下降。论文把 block size 从一个固定超参提升为训练和推理共同作用的尺度变量，研究训练 block size、推理 block size、解码策略三者如何影响长推理。

评这篇会直接影响你对 diffusion LM 做 reasoning 的 prior：先别盯采样步数，先复现 block-size curriculum；若结论稳，训练粒度就是比解码并行度更关键的控制杆。

Unified Data Selection for LLM Reasoning

这篇工作解决的是一个很实际的训练瓶颈：长链式推理数据越来越多，但真正能提升模型 reasoning 的样本比例并不高，而现有筛选方法要么太粗，要么太贵。长度、困惑度、平均熵这类全局指标把所有 token 一视同仁，无法区分“真正承载推理转折的信息点”和大量模板化、低信息密度的铺垫文本；而用强模型打分或训练额外选择器，又会把数据筛选本身变成一项昂贵流程。作者要找的是一个训练无关、模型对齐、能同时服务 SFT、RFT、RL 的统一样本质量指标，用来识别哪些长 CoT 轨迹更值得学。

评应立刻复现到内部 reasoning 数据过滤；关键看 HES 是否只是在挑“难题”，以及 top-entropy token 的可解释性。
