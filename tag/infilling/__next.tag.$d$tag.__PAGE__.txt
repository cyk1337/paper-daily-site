9:T62e,Given a sequence x, the method partitions tokens into a conditioning set x_c and an evaluation set x_e. The loss is applied only to tokens in x_e, since tokens in x_c are observed. ac-gpt creates a copy of the conditioning tokens, \bar{x}_c, and places these copies at the beginning of the attention order. All later tokens can attend to them. The copied tokens keep their original positional encodings, so the model knows where the observed tokens belong in the original sequence. The copied conditioning tokens use unrestricted bidirectional attention among themselves because they are all observed.

The evaluation tokens still follow the original left-to-right causal factorization. This is the main distinction from masked or denoising LMs: ac-gpt does not independently predict masked tokens and does not rely on a pseudo-likelihood approximation. It models the joint distribution over the evaluation set through an autoregressive chain, conditioned on an arbitrary observed subset.

The copy mechanism is not a cosmetic detail. If the model simply allowed every token to attend to the original conditioning tokens, multi-layer attention could leak information between evaluation tokens. For example, a conditioning token at position 3 may need to attend to positions 1 and 2 in order to predict position 4; in the next layer, position 1 could then indirectly receive information about position 2 through position 3. This violates the intended left-to-right factorization over x_e.
