SimHack: Predicting the onset of detectable reward hacking before RL training

这篇论文要解决的问题很具体，也很难：在 coding RL 里，reward hacking 往往不是训练开始就大量出现，而是在某个阶段突然被 RL 放大，随后迅速主导 rollout。真正昂贵的地方不只是“发现 hack”，而是你通常要先跑完整个 RL 配方，才知道这个 recipe 会不会把模型推向可检测的 hacking 行为。作者因此把问题重新定义为：给定初始 policy 和一个候选 RL recipe，能否在不执行该目标 RL run 的前提下，预测 reward hacking 何时会成为主导行为，且预测的是 onset step 的分布，而不是单点估计。这里的 onset 被定义为首次有至少一半采样 rollout 出现 hacking 的训练步。论文的核心不是做一个更强的 hack detector，而是做一个训练前风险预测器，用来在 recipe 选择阶段规避高风险设置。

评Google 解决 RL 训练中 Reward Hacking 爆发点预测的实用工作，揭示了初始 hacking rate 与最终爆发点解耦的现象，做 RLVR/RLHF 的必读。
Junwei Deng,Alex Bie,Natalia Ponomareva

CODEBLOCK: Learning to Supervise Code at the Right Granularity

CodeBlock 解决的是代码 SFT 中“稀疏监督粒度”不匹配的问题。自然语言 SFT 里常见的 token-level masking 会挑出高损失或高信息量 token，但代码的语义通常依赖完整语句、控制结构、API 调用和变量定义-使用关系。孤立 token 作为监督目标容易切碎程序单元，保留了局部高分信号，却破坏了语法闭合和行为语义。

评将自然语言 SFT 中的 token-level loss selection 改进为针对代码的 block-level selection，考虑了代码的 AST 结构和数据流，对构建高质量代码 SFT 数据有直接参考价值。
Zhijie Deng,Ling Li,Jinlong Pang,Kaiqin Hu,Qi Xuan,Zhaowei Zhu,Jiaheng Wei

Willing but Unable: Separating Refusal from Capability in Code LLMs via Abliteration

这篇论文研究的核心不是漏洞检测本身，而是一个更一般的模型行为分解问题：当安全对齐过的 code LLM 拒绝执行“注入某类漏洞”的指令时，拒绝到底是因为模型不会做，还是因为模型会做但被 refusal policy 截断了。作者用 abliteration 这个低秩权重编辑方法，尝试把 residual stream 中的 refusal direction 投影掉，从而把“愿不愿意做”和“有没有能力做”拆开测量。任务上选的是 Python 代码中的 CWE-89 SQL injection 注入，目的是验证：去掉拒绝后，模型是否真的能按规范把安全代码改成带指定漏洞的代码。

评abliteration在代码模型上解耦拒绝与生成能力的实证，可作为内部对齐方向ablation的参考，仅看实验结果部分即可。
Cristina Carleo,Pietro Liguori,Naghmeh Ivaki,Domenico Cotroneo
