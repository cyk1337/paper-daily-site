Can We Trust Item Response Theory for AI Evaluation?

评重点看模拟结果部分的可靠性边界，做基于IRT的benchmark分析时需注意小模型量regime的估计误差。

Extending Item Response Theory for Efficient and Meaningful Multilingual Evaluation

并行多语种 benchmark（同一题目多语言版本）在大模型评测里有三个结构性问题：评测成本随语言数线性增长；自动翻译带来的错误难以系统发现；以及题目可能混合“通用能力”与“文化/语言特定知识”，导致跨语言比较失真。论文要解决的是：用一个统一的统计模型同时做（1）缺失评测的性能预测以降本，（2）定位可疑翻译项，（3）把内容因素与语言因素在参数层面拆开。

评读模型设定和误差发现结果；多语言 eval 若还只看平均准确率，这篇会迫使你改 dashboard。

Growing Pains: Extensible and Efficient LLM Benchmarking Via Fixed Parameter Calibration

LLM评测基准与模型发布速度过快，导致“每个模型×每个数据集×全量题目”的穷举评测成本不可承受；现实中leaderboard往往对不同模型评不同子集，造成分数不可比、排名不稳定。论文要解决的是：在基准集合随时间扩展、模型只在当时可用数据集上被评测的真实场景下，如何用少量锚题把新数据集/新模型与历史评测尺度对齐，并避免反复重跑历史模型。

评把动态leaderboard当量表链接来做很对味；只看方法假设与锚题敏感性实验，能直接指导你们评测管线怎么省推理又保可比。

Beyond Scores: Diagnostic LLM Evaluation via Fine-Grained Abilities

现有LLM评测把跨任务表现压成单一分数，掩盖“能力组成”层面的差异，导致：1）无法定位模型到底缺哪类细粒度能力（知识点/认知过程）；2）无法做“按任务需求选模型”；3）难以预测模型在未见题目/新基准上的表现。论文要解决的是：在不改变原有benchmark作答协议的前提下，仅基于模型-题目对错矩阵，构建可解释、可迁移的细粒度能力画像，并用它来诊断与预测。

评别被“能力画像”口号骗，价值在于仅用对错矩阵+mIRT就能做稳定回归监控；看Q-matrix构建和跨基准预测那节即可。
