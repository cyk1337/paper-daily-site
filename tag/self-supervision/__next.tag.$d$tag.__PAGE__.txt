9:T816,The core method is XTE, Cross-Modal Temporal Edits. Starting from an original video-text pair (V, y), the authors define a family of temporal edit operators A_k and matching caption rewrite functions g_k. On the video side, edits include clip reversal, event reordering, and temporal masking. On the text side, the caption is synchronously rewritten with temporal markers such as before, after, and reversed. The result is a paired temporal counterfactual: the edited video and edited text remain semantically aligned, while differing from the original pair only in chronology. That is the key design choice. Because the original and edited videos share nearly the same frames, static spatial cues are held constant, and the model is forced to rely on temporal structure rather than appearance shortcuts.

On the model side, ViTAL-X does not retrain a large video model from scratch. It starts from frozen image-text backbones such as OpenCLIP or SigLIP-2, then adds a shallow spatiotemporal transformer to model cross-frame dependencies, together with targeted LoRA fine-tuning. The trade-off is clear: preserve the strong static semantic priors learned from large-scale image-text pretraining, inject temporal modeling only where needed, avoid catastrophic forgetting, and keep training efficient.

The training objective is contrastive learning over XTE-generated hard negatives. The novelty is not the loss form itself, but the negative distribution. Standard video-text contrastive learning uses unrelated videos as negatives, which differ in actors, objects, and scenes, allowing the model to solve the task through static shortcuts. XTE replaces those with temporal counterfactuals of the same video, so static appearance is no longer sufficient.

The paper also introduces XTE-Bench, a diagnostic benchmark aimed specifically at temporal order, direction, and causality. That evaluation asset is important because standard benchmarks often let models score well through spatial bias, making it hard to verify whether temporal understanding has actually improved.a:T5d0,From the provided full-text content, the main empirical claims are threefold.

First, XTE-Bench reveals that current large video-language models remain weak on basic temporal reasoning, even when they are large. This supports the paper’s main argument that temporal blindness is not automatically fixed by parameter scaling.

Second, ViTAL-X is positioned as highly efficient. The paper claims that a roughly 0.4B-parameter model trained on only 1M clips can outperform some 7B-parameter models and baselines trained on about 600 times more data. The important point is not only the headline comparison, but the implication: when the failure mode comes from the wrong objective and the wrong negative distribution, scaling alone has poor marginal returns.

Third, the method is reported to generalize beyond the custom diagnostic benchmark to multiple independent video-understanding benchmarks. 1) Value-anchored RM: the model predicts both a scalar reward R(x,y) and a prompt-specific value V(x), where V(x) estimates the expected reward under the current sampling policy for that prompt. V(x) serves as an adaptive baseline.

2) Advantage-derived supervision: for each on-policy response y, compute an RM advantage A(x,y)=R(x,y)-V(x). Responses are split into positive-advantage and negative-advantage sets, yielding pseudo preference pairs (x, y_pos, y_neg).

3) Ambiguity filtering with a curriculum threshold: samples with small |A| are treated as ambiguous and filtered out. This is meant to control bootstrapping noise and avoid reinforcing uncertain or near-tie comparisons.

4) Contrastive/ranking objective: the RM is updated with a contrastive preference loss on the constructed pairs, analogous in spirit to Bradley–Terry training but with labels induced by advantages rather than human/judge preferences.

第二是 header anonymization。作者不是做全局统一替换，而是实例级、双射式的 header 映射。每张表的列名被映射成唯一占位 token，既保留同一表内的引用一致性，又切断跨样本的词汇共现统计。这样做比简单删除 header 更稳，因为结构关系还在；也比固定匿名词表更强，因为模型难以在不同样本间重新建立稳定的“某个匿名 token 常对应某类运算”的伪规律。这个设计很像在预训练里故意破坏 spurious lexical anchor，但保留局部结构可解性。

第三是 self-supervised learning，而且是 program-first 而不是 question-first。作者先从表中构造可执行程序，得到确定答案，再让 LLM 把程序和答案表达成自然语言问题。这样生成链路的约束方向与常见做法相反：不是先写问题再猜程序，而是先保证程序正确、答案可执行，再生成语言表述。好处是逻辑一致性高，训练样本可自动验证，减少“问题像真的、程序是错的”这类噪声。结合 operation sketches，模型在训练时看到的是表、匿名 header、问题、草图以及对应程序/答案，从而把监督集中到结构映射而不是词面联想。

First, operation sketches. Instead of forcing the model to infer the full computational template from the natural-language question, the method provides a minimal symbolic sketch of the operation structure, such as ratio, difference, percentage change, or simple compositions of these. The point is not to inject heavy supervision, but to externalize low-level arithmetic structure so the model can spend more capacity on table grounding: row/column selection, entity binding, conditional filtering, and relational interpretation. The paper explicitly argues that these sketches are not unrealistic test-time oracles, because the question already implies the operation pattern; the sketch simply makes that structure explicit.

Second, header anonymization. This is not a global replacement scheme. It is an instance-level bijective mapping applied separately to each table. The design preserves within-table referential consistency while breaking cross-example lexical statistics. That matters: removing headers entirely would destroy useful structure, while using a fixed anonymization vocabulary could still let the model relearn stable pseudo-correlations. The per-instance mapping is a stronger way to suppress lexical memorization while keeping the task solvable through structure.

Third, self-supervised learning via a program-first pipeline. The authors reverse the usual generation order. They first construct executable programs over tables, obtain verified answers, and only then use an LLM to verbalize them into natural-language questions. This is a key design choice. In many synthetic pipelines, question-first generation leads to semantically plausible but logically inconsistent program annotations. Program-first generation keeps the supervision executable and correctness-guaranteed, which raises the purity of the training signal. During training, the model sees tables, anonymized headers, questions, sketches, and corresponding programs/answers, encouraging alignment between language and structure rather than language and lexical shortcuts.

Relative to prior work, TaNOS is not just data augmentation and not just prompting. It is a representation-and-objective redesign for structural reasoning.
