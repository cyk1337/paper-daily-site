AsyncTool: Evaluating the Asynchronous Function Calling Capability under Multi-Task Scenarios

这项工作提出 AsyncTool，用来评估 LLM agent 在多任务、工具调用有延迟、结果可能乱序返回时，能否进行异步工具使用。核心问题不是工具调用格式是否正确，而是模型能否在等待一个工具结果时推进其他独立任务，并在结果返回后恢复正确的任务状态。

评做Agent能力评估的团队可参考其延迟模拟和多任务并发的评测设计，重点看§2的基准构造方法即可。

Concurrency without Model Changes: Future-based Asynchronous Function Calling for LLMs

这篇工作解决的是 function calling agent 里的执行层串行瓶颈。标准同步协议要求模型发出函数调用后，必须等函数执行完成、结果写回上下文，模型才能继续解码。这样会把“模型思考/规划”和“工具执行”强行串行化，导致端到端延迟随函数调用数快速累积。论文的问题意识很明确：很多延迟并不是模型能力不够，而是 runtime 把本可并发的部分锁死了。

评这是少见的“只改执行层就能大幅降延迟”的agent工作；读实现语义与依赖调度即可，别期待对预训练有直接方法论。
Guangyu Feng,Huanzhi Mao,Prabal Dutta,Joseph E. Gonzalez
