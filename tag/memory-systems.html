MemTrace: Tracing and Attributing Errors in Large Language Model Memory Systems

这篇论文关注的是 memory-augmented LLM system 的可追责性问题：系统答错了，错误究竟是在什么时候、哪一步 memory operation 中被引入的。难点不在于判断结果对错，而在于 memory 是跨轮、跨会话持续演化的，错误可能早在写入、更新、压缩、覆盖时就埋下，直到很久之后在检索或回答阶段才暴露。传统 chronological log 只能给出时间顺序，不能表达变量如何被创建、修改、传播和最终影响答案，因此很难做真正的 failure attribution。

评这不是 pretrain 论文，但做长上下文/RAG memory 的人该看；先读 failure taxonomy 和 attribution 例子，能直接改你们内部 debug 流程。
Xinle Deng,Ruobin Zhong,Hujin Peng,Xiaoben Lu,Yanzhe Wu,Guang Li ... 省略 8 位作者 ... ,Rui Hu,Baohua Dong,Hangcheng Zhu,Ningyu Zhang

Your Agents Are Aging Too: Agent Lifespan Engineering for Deployed Systems

这篇工作讨论的不是单次 agent 能力，而是部署后 agent 会不会随着时间变差。核心问题可以概括为：当模型权重冻结，但 memory 写入、检索、压缩、更新、维护持续发生时，如何系统地定义、测量并定位 agent 在长期运行中的可靠性退化。作者把这类问题命名为 agent aging，强调失效点不只在底座模型，而在整个 agent harness 的状态演化。

评概念比数字更有用；看 aging taxonomy 和任务构造，别把它当基座能力评测。
Jianing Zhu,Yeonju Ro,John Robertson,Kevin Wang,Junbo Li,Haris Vikalo,Aditya Akella,Zhangyang Wang
