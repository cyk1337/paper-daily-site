18:T6cd,The work is a controlled benchmark. The design holds model, harness, task, evaluator, and execution environment fixed within paired blocks, changing only the user prompt. It evaluates six 500B-class reasoning models served through one provider: DeepSeek-V4-Pro, Kimi-K2.6, Kimi-K2.7-Code, Nemotron-3-Ultra-550B-A55B, Inkling, and GLM-5.2. Two real agent harnesses are used: PI.DEV through OpenAI-style chat completions, and Claude Code through an Anthropic-to-chat-completions translation gateway. The task set contains 24 deterministic coding tasks across Python, JavaScript, and Go, with visible tests plus hidden deterministic evaluators that are never placed in the workspace. Prompt variants are frozen templates. The primary variants preserve the objective, acceptance criteria, and test command while changing framing: precise baseline, deep thinking, exhaustive exploration, multiple approaches, maximum certainty, adjacent cleanup, no-questions autonomy, bounded efficiency, and related forms. Stress variants intentionally break semantic equivalence through ambiguity, conflicting constraints, irrelevant context, misleading hints, or multi-turn restatement. The metrics separate behavioral work from billing: reasoning tokens, visible output tokens, tool calls, turns, repeated reads/searches/tests, time to first edit, wall time, out-of-scope changes, cached and uncached input tokens, actual cost, and estimated no-cache cost. The main statistic is a paired reasoning ratio against the median baseline for the same model-harness-task block. The base is Italia 10B, a from-scratch dense decoder-only Transformer trained on about 9T tokens across 50+ languages, with a native 16K context. Architecturally it is fairly standard for its size: 40 layers, hidden size 4096, GQA with 48 query heads and 8 KV heads, RoPE, squared ReLU MLPs, no dropout, and untied embeddings. Stage 1 is continued pretraining to extend the native context from 16,384 to 32,768 tokens, with the RoPE base reset to 500,000 at that boundary. This is not just positional extrapolation; it is meant to let the model adapt its attention behavior under a new length distribution. At inference time, YaRN is then used to stretch the context further to 131,072 tokens. Stage 2 is large-scale SFT on a 12.3B-token instruction mixture, followed by a short math-focused annealing run before RL. That annealing step is important: it narrows the policy toward verifiable reasoning before entering a higher-variance RL phase. Stage 3 applies GRPO with verifiable rewards, initially on math. Stage 4 inserts DPO under what the paper calls the Delta Learning Hypothesis, suggesting DPO is used as a preference-boundary correction step rather than as a replacement for RL. Stage 5 runs multi-environment GRPO over five domains: mathematics, code, multiple-choice QA, instruction following, and tool calling. The intent is to avoid over-specializing the policy to a single reward shape.
