19:T560,The method has three parts. First, the paper defines a confabulated reflection operationally: a reflection is considered confabulated if it fails to mention the correct target object for the task. In ALFWorld, the target object can be recovered from the gamefile metadata, so this can be checked automatically from existing logs. Second, the authors introduce Reflection Repetition Rate (RRR), a log-based metric that measures how often later reflections are near-duplicates of earlier ones using SequenceMatcher similarity, with 0.85 as the duplication threshold. Environments with RRR >= 0.5 are treated as having frozen reflective memory, meaning the memory stops evolving and starts repeating itself. Third, they validate causality through ablations and propose a mitigation. Frozen environments are split into memory-harmful cases, where removing memory helps the agent solve the task faster, and task-hard cases, where the agent still fails without memory. The mitigation replaces open-ended self-diagnosis with programmatic feedback extraction: instead of asking the model to explain failure freely, the system parses trajectory-level signals tied more closely to environment facts and converts them into constrained feedback. The key design choice is to reduce the model’s freedom to invent causal stories and anchor memory updates to observable trajectory evidence.1a:T491,The main evidence comes from ALFWorld, with supporting cases from HumanEval. In ALFWorld, the authors identify 16 frozen environments where none of the 121 collected reflections mention the correct target object. That is a strong sign of systematic drift rather than occasional noise. RRR correlates strongly with trials-to-solve, with r = 0.808, suggesting that repetitive reflective memory is tightly associated with poor task progress. A no-memory ablation shows that in some environments the agent can solve the task faster when reflective memory is removed, which demonstrates that memory can be actively misleading rather than simply ineffective. The mitigation is modest but informative: programmatic feedback extraction raises correct object mention from 0% to 86%, reduces RRR from 0.64 to 0.10, and solves 3 of the 16 frozen ALFWorld environments. On HumanEval, the paper reports 4 analogous problems where the agent repeats nearly identical but incorrect diagnoses across attempts.
