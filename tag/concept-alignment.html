XSearch: Explainable Code Search via Concept-to-Code Alignment

现有语义代码搜索方法基于全局嵌入相似度匹配，存在两个核心问题：(1) 可解释性差——仅返回相似度分数，无法说明代码哪些部分满足查询的哪些功能需求；(2) 分布外泛化差——模型倾向于依赖函数名等浅层线索进行匹配，在测试分布变化时性能崩溃。这两个问题的根源在于现有方法的归纳匹配（inductive matching）范式：通过二元监督学习查询与代码的统计相关性，而非像开发者一样通过演绎验证（deductive validation）逐一检查功能需求是否被满足。

评别把它当“更强检索器”，而是看它怎么把检索监督从全局相似度改成可验证的概念证据；重点读对齐定义与OOD设置是否干净。
