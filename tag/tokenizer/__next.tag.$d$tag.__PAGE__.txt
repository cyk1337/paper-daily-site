This turns merge-budget selection into choosing a model along a one-dimensional path. For each tokenizer, the paper fits a unigram model over tokenized data and scores it with information criteria that trade off log-likelihood against model complexity. The study includes AIC, BIC, two-part MDL, and refined MDL/COMP-style criteria, plus entropy-based filtering baselines. This is different from standard BPE, which greedily constructs merges by frequency; here the merge list is assumed given, and the problem is post hoc selection of an optimal subset. A second ingredient is synthetic text augmentation: when the adaptation corpus is small, unigram and bigram estimates are sparse, so the authors generate synthetic text from the original data to improve distributional estimates before computing the selection criteria. Matched 控制实验也很关键。结果显示，额外 token 数本身带来的攻击代价接近 0，因此 Reserved 与 Split 的差异几乎都可以归因于 reserved representation，而不是长度变化或异常分词扰动。这一点把机制解释钉得很牢。

The attacker is allowed to control only the bytes of one tool result. They cannot modify the system prompt, user task, tool schema, or serving configuration. The defender controls only the tokenizer call, and therefore the mapping from bytes to token ids. Around this setup, the paper defines three key conditions.

Reserved keeps the forged chat-template markers as native reserved token ids. Split keeps the bytes identical and therefore the rendered text identical, but forces those same marker strings to be encoded as ordinary subwords rather than reserved ids. This is the core fixed-bytes contrast: same bytes, different ids. Because splitting reserved markers also increases token count, the paper adds Matched, which preserves the reserved ids but injects the same number of extra tokens elsewhere in ordinary text. Split and Matched therefore share bytes and token count, differing only in whether the forged markers retain their reserved representation. The attack-success-rate difference between them is defined as the identity gap.

This design is stronger than prior work because it does not rewrite the marker text and does not rely on crude character-level splitting. It changes only token identity while holding the visible string fixed. That directly answers whether the authority comes from text or representation.

The paper then goes beyond behavioral measurement. It analyzes the embedding layer and shows that the average of the marker's subword embeddings does not substitute for the reserved token vector. However, on Llama-3.1, the nearest ordinary token in embedding space can approximate the reserved marker's effect. An adaptive attacker that searches for non-reserved tokens near the reserved marker indeed finds such substitutes. This is an important mechanistic result: a large part of the authority is concentrated in a learned input vector, not in a high-level parser over template syntax.

Another strong component is the base-versus-instruct comparison. Across every tested base/instruction-tuned pair, the instruction-tuned checkpoint shows a stronger preference for the reserved marker. That suggests post-training repeatedly reinforces the semantics of these control tokens as high-authority boundaries. For chat-model training recipes, this is a direct link between formatting conventions and downstream vulnerability.f:T94e,The main evaluations use InjecAgent and AgentDojo. Attack success is defined as whether the model's next generation contains the attacker-named tool call. InjecAgent covers both direct-harm and data-stealing cases, while AgentDojo checks whether the same effect persists in a multi-turn agent loop. Each configuration is run three to five times at temperature 0 to reduce noise from serving-engine nondeterminism.

The headline result is the fixed-bytes contrast. On Llama-3.1, GLM-4.5, and Seed-OSS-36B, replacing forged reserved markers with ordinary subwords lowers attack success on InjecAgent by 39 to 66 percentage points. The gap remains visible in AgentDojo's multi-turn setting. This means the attack is not driven mainly by 'looking like a template'; it is driven to a large extent by the model actually receiving reserved token ids. Qwen3-8B is the notable exception. There, the marker text itself already carries most of the attack, and the reserved-versus-split gap is small. The paper argues this is largely a ceiling effect because the readout is already near 100%, which also explains why prior character-splitting experiments reported almost no difference.

The Matched control is critical. The cost of extra tokens alone is close to zero, so the Reserved-versus-Split gap is not explained by length or unusual segmentation. That substantially strengthens the causal claim that the reserved representation itself carries the effect.

The embedding experiments add mechanistic evidence. Subword-vector averaging fails to reproduce the reserved marker's authority, so a simple compositional-text explanation is insufficient. But a nearest-neighbor ordinary token can sometimes approximate it, which implies the authority is locally transferable in embedding space. The adaptive-attacker experiment confirms this by finding non-reserved tokens that behave similarly.

Finally, the paper audits tokenizer configurations for the 400 most-downloaded chat models on Hugging Face. Among 67 distinct tokenizer setups, 33 leave tool-protocol tokens such as <tool_response> untouched under the standard mitigation that only re-encodes declared special tokens. The paper then shows the same reserved-token effect exists on that tool channel as well. This is operationally important because it turns a conceptual weakness into a concrete deployment gap in common serving stacks.10:T624,This is a must-read paper, and it is worth reading in the order of problem decomposition, controls, mechanism, and deployment consequences.

先看 tokenizer。作者分别给出 modular BPE 和 modular Unigram 的构造方法，目标是训练一个“大而可拆”的 multilingual tokenizer，然后从中抽取任意语言子集对应的 subtokenizer。这里难点不只是把不同语言的词表拼起来，因为简单拼接会破坏 token id、merge 规则或概率结构的一致性，也不保证抽出来的子词表还能接近单语 tokenizer 的压缩率。论文的做法是从训练阶段就约束 tokenizer 的结构，使每种语言或语言组对应的子词单元可以被稳定抽取，同时保留 byte-level fallback 和 lossless detokenization。对 BPE 和 Unigram 都提供了可抽取方案，说明作者不是只在某一种分词算法上做特例。

再看模型训练。核心思想是让模型在预训练时反复看到不同的 subtokenizer 组合，从而学会在不同 token inventory 下读写文本。论文把这些 subtokenizer 采样后组成 mini-batches，训练同一个模型共享主干参数，但输入 embedding 和输出预测都只在当前子词表上工作。这样做的直接结果是：部署到某个语言子集时，不需要加载完整 multilingual output matrix，只需保留目标语言相关 token 的 embedding/output rows。由于输出层 softmax 的维度显著缩小，推理速度和显存占用都会改善。

这套设计和传统 multilingual tokenizer 的区别有三点。第一，传统方法把所有语言塞进一个固定词表，压缩率和输出层成本一起被全局绑定；这里则把“共享训练”和“专用部署”拆开。第二，传统做法若想针对某语言优化，通常只能单独训练 monolingual tokenizer 和模型，跨语言共享会被破坏；这里保留了一个统一模型，只在 tokenizer/output head 层面做模块化。第三，作者强调目标不是追求极端压缩，而是在接近 monolingual compression 的前提下，保持多语言共享能力和部署灵活性。

On the tokenizer side, the authors propose both modular BPE and modular Unigram schemes. The objective is to train a large multilingual tokenizer from which one can extract subtokenizers for any language or language subset. The challenge is not simply concatenating language-specific vocabularies. A naive union would break consistency in token IDs, merge rules, or token probabilities, and the extracted subsets would not necessarily preserve monolingual-like compression. The paper therefore designs the tokenizer training process so that language-specific components remain extractable while preserving byte-level fallback and lossless detokenization. The fact that the framework works for both BPE and Unigram is important; it suggests the idea is not tied to one tokenizer family.

On the model side, the key idea is to expose the model during pretraining to many different subtokenizer combinations. These subtokenizers are sampled and used to form batches, so the same backbone learns to read and predict text under varying token inventories. In each case, the input embedding and output prediction operate only on the active sub-vocabulary. At deployment time, this allows the system to load only the rows of the embedding/output matrices relevant to the target language subset, instead of the full multilingual vocabulary. The efficiency gain comes from two places: shorter sequences for the target languages and a smaller softmax/output layer.

Compared with standard multilingual tokenization, the difference is threefold. First, conventional approaches bind language coverage and output-layer cost into one fixed vocabulary; this framework decouples shared training from specialized deployment. Second, the usual way to optimize for a language is to train a separate monolingual tokenizer and often a separate model, which weakens multilingual sharing; here the model remains unified and only the tokenizer/output interface becomes modular. Third, the paper is not chasing maximal compression at any cost. The target is monolingual-like compression together with multilingual parameter sharing and deployment flexibility.

Because the model does not always train under the same giant vocabulary, high-resource languages have less structural advantage in vocabulary allocation.
