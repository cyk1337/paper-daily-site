Mellum2 Technical Report

这份技术报告要解决的是一个很现实的基座问题：在单卡 H100、接近 7B dense 模型的推理成本约束下，能否做出一个对代码、工具使用、长上下文和推理都更均衡的小型 MoE 基座，并把训练 recipe 讲清楚。它不是单点方法论文，而是围绕“质量—延迟—可部署性”三者平衡给出一整套架构、数据、训练和长上下文扩展方案。

评不是范式突破，但 recipe 很像认真做过取舍的工程稿；重点看多 token prediction 兼作 draft model、滑窗层配比和三阶段数据课程，适合拿来对照内部代码 MoE 设定。
