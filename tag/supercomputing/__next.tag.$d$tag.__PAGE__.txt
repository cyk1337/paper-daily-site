9:T5b5,UBEP (Unified-Bus Expert Parallelism) is a communication library for low-latency MoE inference, built on three synergistic core mechanisms:
1) Kernel Decomposition: Breaks the sequential constraint of traditional BSP by partitioning on-accelerator AIV compute units into independent task groups that run in parallel (e.g., most AIVs handle token sending, while a smaller group handles token count computation and prefix sums). Lightweight point-to-point synchronization (asynchronous signal polling of shared memory) replaces global barriers, allowing overlap of independent tasks. Cost modeling derives the optimal allocation ratio between the two groups to overlap metadata processing latency without sacrificing transmission bandwidth.
2) Hierarchical Token-level Scheduling: Addresses hierarchical latency differences within superpods, using a hardware-accelerated mapper to generate optimal allocation schedules within 1 microsecond, resolving load imbalance from irregular token traffic.
3) Data-as-Flag: Leverages hardware-native 512-byte atomic load/store support to embed control flags directly in the data payload, achieving implicit consistency without separate control messages and eliminating expensive cross-NPU global synchronization.
