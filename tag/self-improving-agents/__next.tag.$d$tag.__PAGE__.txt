9:T7e9,The method is built around a single universal meta-operation, Ω. Ω itself is never modified. At each depth, Ω reads the full execution context of the solver stack below and writes the next layer of code. That layer is constrained to two artifacts: a short task-level pre-process that injects strategic context before solving, and a small helper library that the solver can call. This restriction is important. It narrows the search space and makes each layer act more like a strategy-and-tools writer than a full system reimplementation.

The recursive gain comes from what each new Ω call can see. Depth k does not only observe which tasks failed. It also sees the code produced by depth k-1 and the traces resulting from that code. This gives the next layer a way to evaluate prior improvement mechanisms, not just prior answers. That is the main difference from flat self-refinement loops, which usually revise outputs based on error feedback but do not reason explicitly about the code or policy that produced those outputs.

The paper frames this as emergent depth. Lower layers fix local failures. Higher layers identify cross-task regularities, write reusable helpers, decide when to suppress a previous heuristic, and sometimes override an earlier strategy entirely. To grow such stacks, the authors use an evolutionary archive rather than a single greedy chain. Multiple candidate layer chains are maintained, evaluated, and extended. This matters because layer interactions are path-dependent; a single chain can get stuck early.

A key control is the non-recursive variant. It preserves the capability of a single Ω call but removes recursive access to prior generated code and stacked layers. That ablation is meant to isolate the value of recursion itself. Relative to self-modifying agents, OpenEvolve-style systems, or explicit meta-scaffolding methods, the distinguishing choice here is simple: do not rewrite the improver; let the same improver operate on an increasingly complete history of the system.a:T74c,The evaluation spans eight benchmark families, including combinatorial optimization, text classification (the paper explicitly mentions Symptom2Disease and LawBench), terminal-agent tasks, mathematical discovery (including AlphaEvolve Math and ARC-AGI-2), symbolic regression, and algorithm speedup. Results are reported on two backbones.

The cleanest quantitative result is the recursion ablation on CO-Bench. Removing recursion drops archive-best validation from 0.845 to 0.714, an absolute gain of +0.131 from recursion alone. The authors present this as the main evidence that the benefit is not just a stronger one-shot meta-prompt, but the recursive structure itself.

The paper also includes a useful case study on assignment_problem. A one-shot solver writes code that imports scipy, but the sandbox lacks scipy, so the script crashes and scores 0. Flat self-refinement keeps exploring nearby import-based solutions. Meta^n at depth 2, after inspecting all 36 tasks together, notices repeated dependency failures and emits a global pre-process plus helper functions, including a rule to avoid scipy and a validate_output utility. The resulting solver reimplements the Hungarian algorithm and reaches a score of 1.0. Depth 3 then reasons over both the traces and the depth-2 code, deciding whether to keep, refine, or replace that strategy.

First, it reframes memory retrieval as an implicit non-parametric policy and the stored utility score as a proxy reward. Under this view, writing high-scoring episodes and reusing them later is a form of policy improvement in memory space. The Echo Gap is then defined as a systematic mismatch between self-assessed reward and true success, amplified by retrieval frequency.

Second, the paper provides a diagnosis through the Error-Independence Assumption (EIA). The key claim is that a stronger verifier is not sufficient if its errors are correlated with the original self-grading bias. The recoverable benefit of correction depends on two quantities: how well verifier scores align with true utility, and how decorrelated verifier errors are from the original bias. This is the most useful conceptual contribution: correction requires not just more capability, but a different error channel.

Third, the paper proposes mitigation through per-memory de-inflation rather than global calibration. A label-blind global remapping of scores cannot identify which specific memories are overvalued. Instead, the authors argue for memory-specific demotion using auxiliary signals that are less likely to share the same bias. They instantiate this idea with an answer-free de-inflation method and test it in a Memento-style retrieve–inject–write loop.d:T55b,The experiments are split into bank-level diagnosis and end-to-end behavioral impact. At the memory-bank level, the paper shows that incorrect episodes are systematically over-rewarded across the studied model families and factual memory banks, and that the inflation correlates with future reuse. This is not mere random judge noise. More capable re-graders are often better on average, but their residual errors can still align with the original self-grading bias, which limits their corrective value.

At the agent level, the paper evaluates a faithful memory loop on BIRD text-to-SQL. The agent retrieves similar past episodes, injects them into context, solves the current task, and writes the new episode back without access to ground-truth labels at write time. Final evaluation uses official execution accuracy. The reported result is that self-graded write-back progressively corrupts the memory bank, while the proposed de-inflation method consistently improves over the self-graded baseline across random seeds. This shows that the Echo Gap is not only a scoring artifact; it translates into measurable behavioral degradation.
