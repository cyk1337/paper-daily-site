18:T44f,PRECOG offline-encodes each document chunk by running the SSM language model over it and capturing per-layer hidden states. At query time, a lightweight embedding index retrieves the best-matching state, which is injected directly as the initial condition of the model's recurrent state. Because the SSM recurrence is time-translation invariant (Δt and B depend only on the current token; A is fixed), the pre-computed state is identical to what the model would reach by ingesting the chunk at the start of the query. The same mechanism fails for Transformers: RoPE or absolute positional encodings make the KV-cache position-entangled, so a pre-computed cache is invalid at other positions; even setting position aside, a Transformer KV-cache for 3000 tokens requires roughly 500× more storage than the SSM hidden state. The paper also proposes SMC (Structured Memory Consolidation), which organizes states from past interactions into a hierarchical persistent memory with cognitive-domain clustering, two-level retrieval, and an adjustable fidelity-storage dial, keeping session initialization O(1).19:T517,The work first proposes Routing Slot Memories (RSM), a unifying framework that decomposes fixed-size memory updates into two independent dimensions: (1) write routing, which selects a subset of memory slots to write new content to; (2) slot-wise decay, which applies forgetting operators only to slots that receive new writes, leaving unselected slots completely untouched with no overwrites or decay. Under this framework, SSMs correspond to the extreme of dense full-slot writes with global gradual decay, while SWA corresponds to the extreme of deterministic round-robin single-slot writes with hard eviction (unselected slots retain content until overwritten on their rotation). Raven is a concrete RSM instantiation that uses learned, input-dependent sparse routing to select a small subset of slots per step—neither writing to all slots nor rotating deterministically through a single slot. New content is only written to selected slots, and learnable decay is applied exclusively to these updated slots, while unselected slots retain their content indefinitely without any update or decay. The Raven block requires no auxiliary convolution or sliding-window attention layers; a single RSM layer supports both persistent memory and precise recall while maintaining strict linear time complexity.1a:T785,The paper introduces two variants. The base version is a Dirichlet-process cache. For each incoming representation, the model compares it to existing memory-slot keys. If the nearest slot is farther than a threshold, it allocates a new slot; otherwise it merges the input into the nearest slot and updates the corresponding key/value. This is the DP-means rule, the small-variance MAP limit of a Dirichlet-process mixture, but used here as an online write operator rather than latent-variable inference. Readout remains content-based, so the model retains some of the retrieval behavior of attention while avoiding per-token storage.

The second variant is a surprise-adaptive Dirichlet-process cache. A fixed concentration works for stationary streams, but not when novelty arrives in bursts. The paper therefore adapts the concentration using a surprise signal derived from recent allocation rate. When novelty rises, the cache becomes more willing to open new slots; when the stream becomes predictable again, the effective budget tightens and memory consolidates. The two variants share the same allocate-on-novelty and read mechanism. They differ only in whether concentration is fixed or dynamically scheduled.

The distinctions from prior work are carefully drawn. This is not clustered or routing attention, which approximates full softmax within a bounded context and usually uses a fixed number of clusters. It is not Memorizing Transformer, kNN-LM, or other external-memory systems that still store token-level entries. It is also not fixed-budget sparse caching such as StreamingLLM or H2O, where capacity is controlled by eviction. The closest family is novelty-gated memory such as Titans or EM-LLM, but here novelty is defined by a DP-means-style distance threshold rather than a purely learned write gate. 第一部分是有限状态工具的可内化定理。若 oracle 也只是有限内存 M、有限命令字母表和有限观测字母表，那么控制器只需额外增加 log2|M|+O(1) bit，就能把 oracle 的状态并入自身状态，做 product-state simulation。这个结论说明：有限接口、有限记忆的工具不会从根本上突破有限状态机的表达边界。作者还强调有限状态接口假设是必要的；一旦放松，哪怕是 1 bit oracle，也可能因为接口编码方式而变得任意强。

第二部分是最小无界工具的构造。作者定义了一个 tape oracle，只支持局部 read / write / move 三种操作。控制器内部只需 O(log|Q|+log|Γ|) bit，就能模拟任意单带图灵机，其中 Q 是图灵机状态集，Γ 是带符号表。这里的思想很直接：把无界工作记忆完全外包给 tape，控制器只维护当前 TM 状态和少量局部信息。这个构造给出了“工具增强表达力”的最小充分条件：不是复杂计算器，不是强检索器，而是可寻址、可写、可移动的无界外部存储。

Second, the paper separates nonparametric from parametric attention.
- Softmax attention is interpreted as a form of Nadaraya-Watson kernel regression. It estimates the key-to-value map by local averaging over stored examples, which requires retaining the KV cache.
- Sparse attention may cap cost by evicting tokens, but it still operates by keeping some raw examples and discarding others. It addresses selection, not experience merging.
- Parametric attention instead maintains a finite-dimensional regressor or state that is updated online. Experience is absorbed into bounded memory through an update rule rather than stored as an ever-growing example set.
