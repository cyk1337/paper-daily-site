9:T462,The paper constructs shallow-but-wide transformers where the approximation power is placed in the attention blocks themselves, not in separate deep FFNs. Through carefully designed ReLU-activated attention interactions, the model computes interpretable nonlinear features of inputs (polynomial features or B-spline bases). A final linear-attention layer then approximates the least-squares solution over these features, yielding an end-to-end in-context nonlinear regressor.
Compared to modular approaches that assume universal approximation via deep feedforward networks and then apply linear attention, this work emphasizes fully constructive feature realization (claimed to be exact for the chosen bases) and depth that does not scale with target accuracy; it highlights, for instance, a two-layer attention-only construction for regression with a linear cardinal B-spline basis.
