18:T478,The paper defines a self-consistency hypothesis, H_SC, over a finite set of text-described items. Each item is treated as an atomic alternative; the audit does not assume linear, additive, smooth, or feature-based utilities. The only economic structure is quasi-linearity in money: the utility of an offer equals the item’s utility minus its listed price. Two query types are compared. Item queries ask for the maximum willingness to pay for a single item. Offer-pair queries ask for the signed price change that would make the user indifferent between two priced offers. If a shared dollar utility exists, differences between item-query estimates should agree with the compensation elicited directly from offer-pair queries. The paper provides a joint bootstrap test measuring deviation from the best-fitting shared utility, plus two local diagnostics. P1 checks path consistency among offer-pair judgments. P2 checks whether offer-pair judgments match price-adjusted differences of item-query judgments. The diagnostics report statistical evidence, dollar-scale effect sizes, price-normalized magnitudes, and supported preference reversals.19:T619,The study compares three models in the GPT-5.4 to GPT-5.6 Sol line over three migration edges: 5.4→5.5, 5.5→Sol, and 5.4→Sol. The setup is intentionally controlled to mimic a real dependency upgrade: all request parameters are fixed and only the model identifier changes. Reasoning effort is set to medium for all models, no output-length cap is imposed, and each model-item pair is sampled independently K=50 times.

The evaluation uses 900 public benchmark items spanning graduate-level knowledge, olympiad mathematics, and instruction following. The paper first screens for items with headroom, excluding cases that are always correct or always incorrect across all models, since those items carry little information about migration-induced change.

At the item level, the method estimates pass probabilities for each model and classifies each item into four categories: reliably improved, reliably regressed, practically equivalent, or inconclusive. The classification uses both a practical-significance threshold and FDR control. A key strength is that the authors do not stop at nominal hypothesis testing. They build a label-permutation null and rerun the entire classification pipeline at matched sample size, so the calibration applies to the full decision procedure rather than to an isolated test statistic.

For instruction following, the same responses are scored under both strict and loose verifiers. This is an important design choice because it helps separate semantic capability changes from output-format or protocol-compliance changes.1a:T4f0,The main empirical result is simple and strong: all nine migration-benchmark cells contain both reliable improvements and reliable regressions. No upgrade is uniformly better.

The headline numbers are informative. Even migration edges with positive aggregate score changes contain up to 8.3% reliably regressed items. Conversely, edges with negative aggregate changes still contain up to 10.7% reliably improved items. In other words, the net score hides substantial bidirectional churn.

The instruction-following results are especially revealing. On the latest migration, the same edge shows a 3.9-point regression under strict scoring but only a 0.04-point regression under loose scoring, widening the strict-loose gap by 3.9 points. That suggests a large fraction of the measured regression comes from exact compliance with verifier expectations rather than from a broad semantic failure.

Methodologically, the use of 50 repeated samples per item is one of the paper’s main strengths. It allows the authors to distinguish stable pass-probability shifts from sampling noise. The released response-level archive and per-item scoring outputs are also useful, since they enable re-analysis and alternative rescoring without re-querying mutable commercial APIs.1b:T421,LACE (Local Augmented Control-Variate Evaluation) is built on the control-variate idea. The key insight is local centering: within a target profile region around z, estimate the conditional mean of the cheap signal E[S|Z=z], then form the centered signal S̃ = S - E[S|Z=z]. Because the centered signal has zero conditional mean at Z=z, any linear augmentation leaves the estimand θ(z) unchanged; the augmentation coefficient β(z) is used solely for variance reduction. In practice, a kernel function localizes items in profile space Z, and a ridge-regularized local regression estimates β(z), yielding a local ridge control-variate estimator. The framework handles continuous, ordered-discrete, and unordered-categorical profile spaces uniformly, and extends to paired model-gap estimation and deployment-weighted scoring. Theory establishes unbiasedness, oracle optimality within centered linear augmentations, and first-order adaptivity, plus a local gain formula Gain(z)=1/{1-(1-π)R²(z)} that quantifies how useful cheap signals are in each region.1c:T42f,Reasoning Jury is a two-phase evaluation system for step-segmented reasoning traces marked with [STEP-x] tokens. Phase 1 is independent judgment: a panel of jurors from diverse model families each read the problem and reasoning trace independently, and output a structured defect list including description, affected step IDs, severity, and supporting evidence. This ensures no anchoring effect and decorrelated judgment biases across jurors. Phase 2 is consensus building, with two available modes: Consolidation mode passes the original trace and all Phase 1 verdicts to a judge model to produce a unified consensus. Deliberation mode uses a moderator to run multi-turn debates between jurors, who discuss defect points until consensus is reached or discussion stalls. The moderator never accesses the original problem or reasoning trace — it only maintains consensus state at the claim level, selects speakers, and decides termination timing, then synthesizes the final consensus. All outputs are grounded to specific step markers for auditability and actionability.1d:T5fc,The evaluation covers 56,476 inferences: 4 models, 2,017 items, and 7 budgets. Non-monotone behavior appears in roughly 3% to 19% of items under the main controlled analyses, and reaches 25.8% in some all-item settings. It is also model-specific: the same item rarely induces overthinking across models, with cross-model overlap around 6% to 14%. Model rankings reverse across budgets. On GSM8K, LLaMA-3.3 70B leads at 256 tokens with 62.4% accuracy, while GPT-OSS 20B reaches 94.8% at 4,096 tokens and becomes the strongest model under that budget. On GPQA, LLaMA-3 8B is nominally first at 512 tokens with 21.2%, while GPT-OSS 20B reaches 51.0% at 4,096 tokens, close to another model at 50.0%; the small GPQA sample limits significance at that endpoint, but several intermediate reversals are significant. Truncation is a major confound: Qwen-3 32B remains truncated on 59.7% of GPQA items even at 4,096 tokens, while LLaMA-3.3 70B is truncated on only 0.5%. Oracle analysis finds large complementarity. On GPQA, the oracle exceeds the best single model by up to 27.8 percentage points. On GSM8K, the oracle gap peaks at +16.9 points at 256 tokens and then declines as models converge. The budget-aware router improves cross-domain GPQA performance by +2.67 points over the best-per-budget baseline, with a 95% confidence interval of [0.94, 4.40], capturing 14.1% of the oracle gap. Budget features help within-domain by +1.6 to +5.7 points but hurt cross-domain transfer by 1.2 points, indicating domain-specific budget effects.1e:T764,The setup distinguishes the as-of date t0 from the model training cutoff T. Text written after t0 but before T is bridge data. It can contain information caused by the later world state that also determines the final outcome Y. A model trained on this bridge data may obtain outcome information without ever seeing the benchmark item itself. The paper formalizes this as a back-door leakage path from the later world state through bridge data into the model prediction.

The first technical result is a non-identifiability theorem. A passive backtest observes forecasts, outcomes, timing relative to the cutoff, and possibly covariates, but it cannot separate recency from leakage. The identified set for leakage inflation is a sharp interval, and collecting more items does not make it collapse. A flat pre/post profile is therefore not proof of cleanliness, and a non-flat profile is not proof of leakage.

The second part derives a per-question leakage law. Inflation is the product of honest uncertainty and an extraction factor. The extraction factor has a strong nonlinear payoff: extracting half of the leaked signal already yields about three quarters of the full inflation. This explains why weak recall can still move benchmark scores. The analysis predicts that leakage concentrates on questions that surprised the crowd and had dense training coverage.

The measurement strategy requires an external reference. With a known cutoff, the paper uses a regression-discontinuity design to identify cutoff-localized leakage. With a matched clean control, it uses a difference-in-differences design to estimate global leakage and report a leakage-adjusted score. Matching is central: naive pre/post comparisons are replaced by comparisons that control for timing, question characteristics, and baseline difficulty. Paraphrase probes are treated as detection tools, not measurement tools.1f:T4ee,The empirical section starts with ForecastBench. The authors evaluate five flagship models on the official panel, restricted to questions that resolved after each model’s documented training cutoff. These outcomes could not have been memorized under the documented cutoffs. Even so, four of the five models fail the standard pre/post check, with spurious leakage gaps as large as +0.061. A matched-window check collapses the gaps across all five models, supporting the interpretation that the apparent signal is recency rather than leakage.

The estimators are validated using twin models with planted leakage. One model is kept clean, while the other receives controlled leakage. The proposed estimators recover the planted dose, location, and per-question profile, and return a null result on the clean twin. On deployed frontier systems, the estimators identify one cutoff-localized signature and clear five models whose apparent advantages were explained by recency at the design’s power floors.
