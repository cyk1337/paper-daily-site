18:T815,RADAR 分三段：Repair / Adopt / Diagnose，并用平方损失（Brier/MSE）下的风险分解来组织。
1) 风险分解：在只允许对原始分数 P 做标量映射 s(P) 的前提下，把 repaired score 的风险拆成 outcome noise、score 隐藏的信息（即仅看 P 无法区分但对正确性可预测的子群差异）、以及 mapping error（标量映射可修的部分）。如果进一步限制映射必须保序（单调），还会引入 pooling gap（因为单调约束会把一些可分的点池化）。这一步的意义是：告诉你“校准做不好”到底是数据不够、还是接口本身丢信息。
2) Repair：提出 PAIC（Probe-Anchored Isotonic Calibration）。思路是：离线训练一个 correctness probe g(Z)（可用更丰富特征/更大模型/更贵计算），在目标域无标注 prompts 上跑 probe，得到 g 的预测；然后学习一个从原始分数 P 到新分数的单调映射，使其在 P 的各分段上尽量贴近 probe 的条件期望，从而实现无目标域标注的单调校准。它本质是“用 probe 作为锚点，把 richer predictor 蒸馏成 P 的单调函数”。论文强调 PAIC 的 excess risk 受控于 probe 的 score-conditional bias（在给定 P 的条件下 probe 的系统偏差）与拟合误差，而不是 probe 的整体准确率。
3) Adopt：指出“与不完美 probe 的一致性”可能会把候选分数排序搞错，因此需要一个带控制错误上线概率的比较规则。作者给出基于 held-out labels 的 paired risk comparison，并用 betting-based procedure 控制部署一个并未降低平方风险的候选的概率（类似 sequential testing / e-value 风格）。
4) Diagnose：修复后仍可能存在与特征对齐的残差结构（系统性错误子群）。难点是同一 prompt 的多次采样答案相关，不能当 i.i.d.。作者用 cross-prompt kernel products + prompt-level multiplier 的检验方式，在 sibling answers 相关的情况下仍保持有效性，用于发现“哪些特征簇上 residual 仍显著”。19:T5c3,RADAR = Repair, Adopt, Diagnose, organized around squared loss (Brier/MSE).
1) Risk decomposition: the risk of a scalar-repaired score is decomposed into outcome noise, information hidden by the score (predictable residual structure not expressible as a function of the scalar), and mapping error (the only part scalar recalibration can fix). If the repair is constrained to be order-preserving (monotone), an additional pooling gap can appear due to forced aggregation.
2) Repair via PAIC (Probe-Anchored Isotonic Calibration): train an external correctness probe g(Z) using richer features/compute. On unlabeled target prompts, run the probe and fit a monotone function of the original score P that matches the probe’s score-conditional behavior. Conceptually, it distills a richer predictor into a deployable monotone map of P. The theory emphasizes that excess risk depends on the probe’s score-conditional bias (given P), not its overall accuracy.
3) Adopt: agreement with an imperfect probe can mis-rank candidate scores, so the paper proposes a paired risk comparison using held-out labels and a betting-based procedure that controls the probability of deploying a candidate that does not actually reduce squared risk.
4) Diagnose: introduces a feature-aware residual audit that remains valid when multiple sampled answers per prompt are dependent, using cross-prompt kernel products and a prompt-level multiplier procedure to detect systematic residual structure.1a:T412,URW has an offline calibration stage and an online weighting stage.
- Offline: For each criterion judgment, URW queries the same verifier using a fixed pool of paraphrased judgment templates. Template-to-template variability provides a soft uncertainty proxy even under deterministic decoding. Using a small calibration set with gold labels, URW measures how this soft signal correlates with correctness.
- Online: For each new criterion, URW converts the soft signal into a split-conformal p-value, and uses that p-value directly as the aggregation weight for the criterion in a weighted-sum rubric score.
The key design choice is conformal calibration: it yields distribution-free coverage control, framed here as controlling the probability of assigning spuriously low weight to a correct judgment. Compared to prior work, URW is criterion-level (not only response-level), training-free (no uncertainty head/probe), and compatible with single-verifier, zero-temperature deployments (unlike sampling-based consistency or committee methods).1b:T4ad,The study uses three settings. E1 measures spontaneous reward hacking: 17 language models each receive one full sandboxed terminal-agent attempt on each of 38 tasks, without being instructed or authorized to hack. An attempt is a complete ReAct-style agent session, not a single model response. The agent can inspect files, call tools, run the visible scorer, edit its solution, and resubmit until a 40-turn or 3600-second limit. E2 measures exploit quality and detectability when hacking is explicitly allowed as a red-team exercise. The tasks use thresholds above the best compliant baselines, and the agent must provide a CHEAT_SUMMARY.md. Detection is then tested under artifact-only review, additional trajectory inspection, and independent recomputation. The paper then studies the common similarity fallback, whole-function CodeBLEU, and shows why it fails structurally in this setting. Several results stand out.

First, compile rate is weakly responsive to interventions that materially improve generated code. The paper’s point is not just that the metric is noisy, but that it can miss genuine quality changes.

The setup fixes three ingredients: an original score, a set of surface features, and a provenance-separated construct measurement. The same residualization operator is then examined under three evidential regimes.

First, in the designed-intervention regime, the authors use a code audit where unit-test execution provides correctness labels and only comments/docstrings manipulate the formatting channel. Because the intervention preserves correctness while changing format, attenuation of the format effect becomes directly measurable. Here residualization is used as an audit perturbation: if mirrored formatting conditions move closer after adjustment while correctness margins remain stable, one can claim attenuation of that specific surface channel.

Second, in the observational regime, no such intervention exists. The authors define slices using the errors of a surface-only predictor and test whether the residualized score aligns better with external annotations on that slice. The key point is that this supports only a slice-restricted alignment claim. Since the slice is itself induced by a model of surface effects, improvement inside the slice does not identify broader validity or better population-level measurement.

Third, the paper studies construct–artifact entanglement. When the target construct is genuinely correlated with the artifact, subtracting the predictable surface component can remove construct-relevant signal together with nuisance variation. The proposed model is a noise-augmented mixture Bradley–Terry (MBT). Relative to a standard BT model, the key change is not just extra flexibility. Each component remains transitive and interpretable as a coherent ordering, while the observed aggregate can be intransitive because it mixes across components.
