ME-Dex 1.0: Bringing Heterogeneous Tactile Sensing into World Action Modeling

这篇工作要解决的是：如何把异构触觉传感器、不同机械手/夹爪形态、视觉观测与动作序列放进同一个可预测的世界动作模型里，并且让模型不仅把触觉当条件输入，而是真正去预测未来触觉状态，再用这些未来视觉+未来触觉表征来生成动作。难点有三层。第一是数据层，现有机器人数据集大多没有原生同步触觉，且不同触觉数据格式差异很大。第二是表示层，不同传感器的空间布局、量纲和接触语义不一致，直接拼接训练很难形成共享表征。第三是模型层，如何在统一架构里同时建模未来视频、未来触觉和动作，并让动作生成阶段能访问到前两者的预测表征，而不是退化成普通的条件策略学习。

评将触觉作为 token 纳入统一生成模型（Flow Matching + MoE），对多模态统一预训练（尤其是具身方向）有参考价值，关注其架构设计。

Open-UniMo: Towards Unified Motion-Language Understanding and Generation in the Open World

这篇工作要解决的不是一般的 text-to-motion 或 motion captioning，而是更难的统一建模问题：在开放世界、长时序、弱对齐的 motion-language 数据上，如何让一个单一模型同时做好动作生成和动作理解。作者指出现有路线有三处结构性短板。第一，很多方法把 motion 当成挂在 LLM 旁边的辅助模态，结果表示空间被文本主导，跨模态交互不对称。第二，纯 next-token autoregressive 目标对长动作序列并不友好，动作的时间演化是连续过程，局部 token 误差会沿序列累积。第三，开放世界数据的动作分布更复杂，过去几百级别的 motion codebook 容量不够，tokenizer 重建误差会直接传到生成质量和理解质量上。Open-UniMo 的核心问题因此可以概括为：在统一 token 接口下，怎样提升 motion 作为一等模态的表示容量与训练信号质量，并让双向任务在同一模型里形成真正的语义闭环，而不是两个方向各自凑合可用。

评值得扫 tokenizer 和训练配方部分；若 motion token 真能和文本词表稳定共训，会影响非文本模态接入 LM 的设计选择。

VideoTok4D: A 4D-Aware Video Tokenizer for Compact World Representation

这篇工作要解决的是视频 tokenizer 的表示对象错位问题。现有大多数视频 tokenizer 仍把视频当作按时间排列的 2D 图像序列来压缩，因此学到的是“观测视角绑定”的 token，而不是“底层动态世界”的紧凑表示。这样的表示适合重建已观测片段，却不适合在新视角下保持几何一致性，也不擅长把相机运动和物体真实运动分开。作者因此把目标改成：学习一个面向 4D 动态场景的 tokenizer，用更少 token 表示稳定场景结构与随时间变化的对象动态，并支持条件化的动态新视角生成。

评值得看的是“静/动token解耦+轨迹对齐注意力”这套归纳偏置；先核对是否在生成/预测上有硬收益，别只被重建指标带跑。

LoopVAE: Recurrent Depth Across Scales for Visual Tokenization

这篇工作要解决的不是单一模型技巧，而是一个更基础的问题：在原生统一的多模态预训练里，语言、视觉理解、视觉生成三种能力到底如何相互影响，什么时候互相促进，什么时候彼此竞争，以及视觉应当在训练的哪个阶段、以什么方式进入模型。现有很多多模态系统是先有 LLM，再把视觉模块接上去，因而很难看清视觉是否真正参与了基础表征的形成。作者试图把这个问题从经验配方拉回到可控实验：用合成数据和真实数据分开研究，把“知识流向”“模态协同/冲突”“早期统一”“可扩展 recipe”拆开验证，最后再在 13.5B MoE、2T token 规模上做组合检验。
