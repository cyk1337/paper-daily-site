Salesforce Koa: An Enterprise Language Model for Agentic Tool Use

这篇工作处理的是企业场景里一个很实际的问题：开源基座模型能不能在不使用客户私有数据的前提下，被后训练成稳定的 tool-using agent，而且在强化 agentic tool use 之后不明显伤到通用能力。难点不在单轮 function calling，而在多轮、带状态、带业务约束的工作流执行。企业任务往往依赖组织特定 schema、API、权限和流程，公开 benchmark 上的工具调用数据并不能直接覆盖这类分布。作者要解决的核心矛盾，是如何把“企业 agent 的声明式工作流定义”转成可执行、可打分、可用于 RL 的训练环境，让模型学到任务完成而不是只学会模仿调用格式。

评值得看 reward pipeline，不必读成基座报告；干净点在于任务成功奖励绑定工具状态，风险是企业域规格过强。
