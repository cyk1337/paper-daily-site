LibraSpec: Dynamic Diffusion-Based Speculative Decoding via Marginal-Gain-Driven Optimization

这篇论文解决 diffusion-based speculative decoding 里的动态投机长度选择问题。已有方法通常预测“会接受多少 token”，这适合自回归 draft model，因为草稿 token 也是顺序生成的；但 diffusion drafter 可以低成本并行生成一个候选块，真正昂贵的是把多少候选 token 送给 target model 验证。因此问题从 accepted length prediction 变成了 expected speedup optimization。

评只看边际收益推导和成本模型；若验证开销建模干净，可直接迁移到内部推测解码 ablation。
Zexun Lin,Yuan Feng,Junlin Lv,Kevin S. Zhou,Xike Xie

AdaFlash: Adaptive Speculative Decoding via On-Policy Distilled Diffusion Drafters

这篇工作处理的是 diffusion drafter 用于 speculative decoding 时一个很具体、但此前没有被讲透的问题：单步并行起草虽然便宜，但 bidirectional attention 带来的全局耦合会让 draft 质量方差明显变大。这个方差有两层表现。第一层是 domain-level variance：同一个 diffusion drafter 在不同任务域上的 acceptance rate 波动比 AR drafter 更大，静态蒸馏好的 drafter 一旦遇到分布偏移，速度收益会迅速掉下去。第二层是 token-level variance：同一条 draft 序列里，不同位置 token 的接受概率差异很大，固定 candidate length 会让 target model 花不少验证算力在低接受概率 token 上。论文要解决的不是“如何再做一个更快的 speculative decoding”，而是“如何让 diffusion drafter 在真实 serving 场景里更稳、更自适应，不因为方差问题把理论并行优势吃掉”。

评对扩散式draft模型的诊断（方差问题）比方法本身更有价值；做推测解码的看§3的问题分析即可，方法属增量。
Yu-Yang Qian,Hao-Cong Wu,Chen Chen,Jiacheng Sun,Zhenhua Dong,Peng Zhao,Zhi-Hua Zhou

TAPS: Target-Aware Prefix Tree Selection for Diffusion-Drafted Speculative Decoding

扩散式推测解码中，当草稿生成变得廉价后，瓶颈转移到了目标模型的验证阶段。现有树形验证方法按边际概率排序候选节点，忽略了验证是前缀条件的——被拒绝前缀下的子孙节点虽有高边际概率但无法到达，造成验证开销浪费且接受长度提升有限。

评只看 tree selection 部分；它抓住了验证前缀条件化这个细节，适合和内部 spec-decoding 实现对照。
Zhuoyu Wang,Junnan Huang,Xinyu Chen

Accelerating Speculative Decoding with Block Diffusion Draft Trees

评把“边缘分布draft”形式化成最优draft tree很干净，能直接指导你训练更适配spec-dec的drafter；只看目标函数与算法段落即可。
