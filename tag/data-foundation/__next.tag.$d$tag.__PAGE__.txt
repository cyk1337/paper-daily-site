a:T533,The system proposal (Trellis) is organized around the claim that agent search over experience graphs is a distinct database access pattern.
- Data model: nodes/edges capturing prompts/contexts, produced artifacts (e.g., code), tool I/O, objective rewards, parent/child and sibling relations, mutable search statistics, and lineage.
- Two-loop architecture: an inner loop of agent sessions and an outer loop of RSI tree search over a persistent substrate, making agents effectively stateless/serverless.
- Recasting core operations as queries:
  (1) Recovery becomes a query over the frontier.
  (2) Cross-session reuse becomes vector-seeded retrieval plus graph traversal.
  (3) Training-data extraction becomes materialized views projecting graphs into datasets.
  (4) Replay becomes an as-of temporal query to reconstruct what the agent “knew” at that time.
- Unifying memory tiers: declarative/procedural/episodic memories are treated as projections/special cases of the same governed experience graph, accessed via a query layer combining structured filters, vector similarity, and graph traversal.
