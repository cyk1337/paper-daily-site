18:T445,SkillSeek is a deterministic two-stage retriever exposed as an MCP server, so it can be used by harnesses such as Claude Code, Codex CLI, and OpenHands without changing the agent implementation. Stage 1 uses a BGE-base bi-encoder with 110M parameters and 768-dimensional embeddings to score all indexed skills by cosine similarity and retrieve the top 20. Stage 2 uses a bge-reranker-v2-m3 cross-encoder with 568M parameters to jointly score each query-skill pair and return the top 5. The indexed text is not the full SKILL.md body. It is the skill name and description plus a Tool-REX v3 structured profile containing four tags: file type, primary operation, and two secondary operations. This is a practical design choice: name and description alone often miss the surface forms needed by the reranker, while appending the full body adds noise. The Tool-REX tags are generated offline by an LLM, and online retrieval uses no LLM tokens. The analysis also swaps the stage-2 reranker for Qwen3-Reranker variants and commercial rerankers while keeping the bi-encoder and indexing format fixed.19:T40a,The evaluation uses the 89-task SkillsBench benchmark over a 4-by-11 grid of pool, backbone, and retrieval method settings.
