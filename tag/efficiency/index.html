这篇工作关注长程 Agent 的 harness 控制问题：在同一个执行状态下，是否应该触发额外规划、验证、工具调用、回滚或其他编排动作。固定规则会带来冗余推理，也可能在错误时机打断流程。

评将 Agent harness 的调度视为因果学习问题，思路新颖，对设计更高效的 Agent 系统有一定参考价值，可关注其干预机制设计。

WaveZip: Wavelet-Driven Space-Time Decoupling for Video Token Condensation

长视频输入LVLM时会产生海量时空视觉token，导致注意力计算复杂度随token数二次增长，推理效率低下。现有token压缩方法直接在空间特征域操作：硬剪枝会破坏空间连贯性，均匀合并会模糊语义显著区域，根源是这类方法在空域无法解耦两类混淆——空间维度上，任务相关的细粒度证据和冗余背景纹理混杂；时间维度上，慢变的语义趋势和采样噪声、视觉抖动、场景突变等高频波动混杂，即频率混淆问题。

评把“压缩决策放到频域”这条路走得更系统，适合做长视频推理的可解释基线；重点看频带假设是否在不同数据集/模型上稳。
Yuhui Zeng,Wang Chen,Jinfa Huang,Tianyu Xie,Yongdong Luo,Jiayi Ji,Xiawu Zheng,jiebo Luo
