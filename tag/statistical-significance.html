How Much Coordination Gain Is Real? A Paired Noise-Floor Protocol for Multi-Agent LLM Benchmarks

这篇工作要解决的不是“怎样做出更强的 multi-agent coordination”，而是一个更基础的测量问题：在同一模型、同一 benchmark、同一任务集合上，如果两个协议在 trial-0 的 API 输入已经做到配置等价，那么它们之间天然会有多大的配对波动。作者发现，很多协调架构论文报告的提升幅度本身就落在这个噪声地板附近，因而单次实验里的小幅领先，未必足以支持“架构优于架构”的结论。论文把问题收缩到一个很干净的设定：不先争论机制是否有效，而是先测清楚 benchmark+model+harness 这一整套系统的 paired noise floor。

评做LLM Agent与能力评测的建议速读：多agent基准固有噪声达±15pp，10个点内的增益不可靠，必须设严格惰性对照跑多种子；纯预训练研究者知道结论即可。
Alibek T Kaliyev,Artem Maryanskyy

Resolution Diagnostics for Paired LLM Evaluation

这项工作解决的是 LLM leaderboard 的分辨率问题：两个模型在同一组 prompt 上相差几个百分点时，这个差距是否足以支持“模型 A 优于模型 B”的统计判断。作者把共享 prompt 的评测明确建模为 paired hypothesis testing，而不是把两个模型分数当作独立样本比较。

评对 LLM Leaderboard 统计显著性的硬核打假，指出很多相邻排名其实是 noise，做 eval 体系的同学必看。
