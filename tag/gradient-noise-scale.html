How Does Local Landscape Geometry Evolve in Language Model Pre-Training?

这篇论文研究语言模型预训练过程中局部 loss landscape 的几何形态如何变化，以及这种变化能否给 learning rate warmup、batch size schedule 这类关键超参数提供更有原则的调参依据。核心问题不是再提出一个训练技巧，而是解释两个长期依赖经验处理的现象：为什么早期大 learning rate 容易导致 loss spike 或 plateau，为什么后期 batch size 与 learning rate decay 都会影响最终 basin 的形状和验证损失。

评值得立刻对照内部训练日志复现 sharpness/GNS 曲线；若结论稳，warmup 和 batch ramp 可少靠经验调。
Zhanpeng Zhou,Yuhan Sun,Bingrui Li,Jinbo Wang,Huaijin Wu,Lei Wu,Junchi Yan
