From Patches to Trajectories: Privileged Process Supervision for Software-Engineering Agents

现有软件工程智能体的SFT训练仅通过最终测试是否通过筛选教师轨迹，无法对中间步骤的有效性（每步都基于已有信息、无逻辑跳跃）和效率（无冗余、循环步骤）进行监督，导致学生模型继承教师轨迹的缺陷，推理稳定性差、成本高。

Neurosymbolic Repo-level Code Localization

现有代码定位方法和基准存在「关键词捷径」问题：基准查询包含大量文件名、函数名等关键词，模型仅通过表层词汇匹配就能定位代码，缺乏不依赖命名提示的逻辑结构推理能力，在无关键词锚点的代码定位场景下性能骤降。

评这篇该看的是 benchmark 诊断，不是方法本身；如果你做代码预训练或 SWE agent，先看它如何把“高分”拆成关键词匹配假象，再决定要不要在内部评测里加去命名扰动版。
