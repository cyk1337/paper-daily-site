9:T7ef,方法核心是 StitchVM。结构上分三段：
1. frozen diffusion head：取一个预训练 diffusion 或 flow 模型的前半段/截断段，用来处理 noisy latent zt。因为这部分网络天然适配不同噪声水平的输入，所以它负责把 noisy latent 编码成中间特征。
2. pretrained reward tail：取一个已经训练好的 reward model 的后半段，使其保留强语义和偏好判断能力。这个 reward model 原本工作在像素空间或解码图像上。
3. stitching layer：在 head 与 tail 之间插入一个轻量映射层，把 diffusion feature 对齐到 reward feature 空间。

关键难点不是“接起来”，而是“接在哪一层”。作者借鉴 model stitching 文献，寻找一个 representation compatibility 较高的 stitch point。判断标准是：在某些层，diffusion head 的特征是否可以通过近似线性变换映射到 reward tail 的特征。如果可以，那么先用闭式解或线性回归拟合一个初始映射，再做短程 finetune，就有机会在不破坏 reward tail 预测能力的前提下，让整个 stitched model 直接对 noisy latent 输出 value。

这个设计相对已有方法的区别很明确：
- 不像 Tweedie，它不需要额外 denoiser 前向和 VAE decode，再把估计出的 x0 送进 reward model，因此推理链更短。
- 不像 MC，它不需要从 zt rollout 多条完整去噪轨迹，省掉大量采样成本。
- 不像已有直接 value model，它不从小规模 noisy-latent 数据从头训练一个新模型，也不只是简单复用 diffusion feature 做一个浅层头，而是显式把 foundation reward model 的后段能力迁移过来。

从全文叙述看，作者强调两个训练阶段：先做 stitch point 搜索和线性初始化，确认 head/tail 在某层可对齐；再做小成本 finetuning，闭合剩余表征差距。这样做的原因很直接：如果一开始端到端训练，容易把 reward tail 原有能力破坏掉，也会失去“低成本迁移”的意义。a:T72d,The proposed method, StitchVM, has three components.
1. A frozen diffusion head: a truncated prefix of a pretrained diffusion or flow model that naturally processes noisy latents at different timesteps.
2. A pretrained reward tail: a sliced suffix of a strong reward model that already knows how to predict prompt fidelity, aesthetics, or other downstream rewards from image-space features.
3. A stitching layer: a lightweight mapping inserted between the two so that diffusion features can be fed into the reward tail.

The main technical issue is where to stitch. The paper borrows from model stitching and looks for layers where the diffusion-head representation can be mapped to the reward-tail representation with a near-linear transform. If such a point exists, the bridge can be initialized analytically or with simple regression, and only a short finetuning phase is needed to close the remaining gap. This preserves most of the reward model’s predictive skill while making it operate directly on noisy latents.

This differs from prior alternatives in a clean way:
- Unlike Tweedie-based methods, it does not need an extra denoiser pass plus VAE decoding before reward evaluation.
- Unlike Monte Carlo value estimation, it avoids expensive denoising rollouts from each zt.
- Unlike prior learned value models, it is not trained from scratch on noisy-latent supervision at small scale, nor does it merely attach a shallow head to diffusion features. Instead, it explicitly reuses the upper layers of a pretrained reward model.

The training recipe appears to have two stages: identify a compatible stitch point and fit an initial linear bridge, then run a short finetuning stage. That choice is important. End-to-end training from the start would risk destroying the reward tail and would weaken the claim of low-cost transfer.b:T76f,From the available full-text portion, the paper evaluates StitchVM across multiple diffusion backbones, including SD 3.5 Medium and SD 3.5 Large, and positions it as useful for both training-time alignment and inference-time guidance. Even without the full result tables here, the experimental agenda is clear.

First, value estimation quality. StitchVM should be compared against Tweedie approximations, Monte Carlo estimates, and prior learned value models, especially as a function of noise level. The decisive test is whether it remains accurate in high-noise regimes where Tweedie is known to be biased.

Second, downstream alignment quality. Since the value model is meant to guide optimization, the paper should measure prompt fidelity, aesthetic preference, or related reward-aligned metrics under training-time or inference-time alignment. The practical claim is that better noisy-latent value estimates translate into better reward optimization at similar or lower compute.

Third, transfer and generalization. Because the method is sold as a reusable interface between pretrained diffusion models and pretrained reward models, the important checks are:
- whether one reward tail can be stitched to multiple diffusion backbones,
- whether changing the reward model still requires only short finetuning,
- how sensitive performance is to stitch-point selection,
- and how much of the gain comes from linear initialization versus subsequent finetuning.

When reading the full paper, the most informative ablations are likely the stitch depth, frozen versus trainable components, the effect of closed-form initialization, error curves across timesteps, and compute-versus-accuracy trade-offs against MC rollouts.
