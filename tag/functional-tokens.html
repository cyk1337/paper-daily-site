ATLAS: Agentic or Latent Visual Reasoning? One Word is Enough for Both

这篇工作处理的是一个很具体但一直没有被很好统一的问题：视觉推理里，模型往往需要在中间步骤对图像做操作，例如放大局部、补辅助线、标注文字、更新棋盘状态。直接生成中间图像，代价高且通常要求统一生成架构；走 agent 路线，用代码或工具调用去操作图像，又会把一个简单视觉动作展开成很长的文本或程序，推理链变长，外部执行也带来延迟；走 latent reasoning 路线，把中间视觉过程塞进隐变量，虽然紧凑，但训练上常引入递归依赖，不再兼容标准自回归并行训练，而且监督往往绑定在少数任务上，泛化不稳。ATLAS 想解决的核心问题，就是能否用一种仍然保持标准 AR VLM 训练和推理接口的方式，把“中间视觉操作”压缩成可学习、可扩展、可被 RL 直接优化的离散推理单元。

评Meta 试图用离散 token 统一 agentic tool use 和 latent reasoning，思路很巧，值得看它怎么设计这个 functional token 的训练目标和 routing 机制。
Ziyu Guo,Rain Liu,Xinyan Chen,Pheng-Ann Heng
