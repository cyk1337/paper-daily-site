CLEAR: Continuous Latent Adapter Routing for Utility-Preserving LLM Safety Alignment

这篇工作处理的是安全对齐里的一个老问题：安全性一旦通过 SFT、LoRA、RLHF 这类全局参数更新写进模型，模型会把同一套“更保守”的行为施加到所有输入上，结果是 harmful prompt 的拒答能力上去了，但 benign 或 safety-adjacent prompt 也被一并扰动，出现 over-refusal、推理能力下降、事实性变差。CLEAR 的目标不是再做一个更强的安全 adapter，而是把“是否启用安全行为、启用到什么强度”变成输入条件化的连续控制问题。论文把这个问题落在 latent routing 上：冻结 backbone，只训练一个 safety LoRA 和一个很小的 gate，让模型在有害输入上更像安全模型，在无害输入上尽量保持原模型。

评通过 latent routing 动态激活 safety adapter 来缓解 alignment tax，思路直接且有效，对 post-train 阶段的 safety alignment 有参考价值。
Chengxiao Wang,Enyi Jiang,Xiaojing Liao,Sanmi Koyejo
