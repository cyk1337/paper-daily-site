9:T43b,ARC-KV keeps the reconstruction-based formulation of methods such as Attention Matching, but amortizes the costly anchor discovery step. It first trains a value-aware indexer that scores real keys using reference activations, reference queries, and the cached KV pairs. The indexer is trained against held-out post-fitting attention-output fidelity, with disjoint scoring, fitting, and holdout queries, rather than supervised by OMP-selected anchors. After anchors are chosen, deterministic merging groups keys by their response profiles to reference queries and moves each anchor toward the mass-weighted centroid of its group, so non-anchor information is partially absorbed while the compact key remains constrained. Finally, with compact keys fixed, the method solves for the mass bias β and compact values C_v in closed form for the current context. This differs from eviction methods because discarded tokens can still influence the reconstructed cache, and differs from OMP-based AM because only the selection prior is amortized while reconstruction remains context-specific.a:T4db,RheoSampling introduces a dual-identity probability design. Instead of relying purely on deterministic top-k expansion, it inserts one stochastically sampled token into the candidate pool after the top-m deterministic selections. The key idea is to give this sampled token two probability identities. During dynamic tree construction, it is assigned a proxy probability so it can compete with deterministic candidates for expansion and survival. During verification, it is evaluated with its true sampling probability, which preserves lossless stochastic decoding.

This decoupling resolves the conflict between context-adaptive dynamic trees and proper stochastic sampling. The second major contribution is an equivalence-class analysis. Once randomness is introduced into a dynamic tree, token identities and tree topology become tightly coupled, making direct analysis intractable. The authors compress this large stochastic tree space into equivalence classes and use that framework to prove losslessness. The third component is an Optimal-Transport-based verification algorithm, designed to improve acceptance rate while maintaining correctness. They also add a sparse draft distribution strategy to reduce overhead on large vocabularies.b:T482,The experimental comparison is mainly against top-k dynamic-tree baselines such as EAGLE-3, with acceptance rate and wall-clock speedup as the main metrics under standard stochastic decoding. The central empirical claim is that RheoSampling consistently outperforms these baselines across multiple LLMs and benchmarks, especially when temperature is nonzero. The paper explicitly points out that EAGLE-style implementations effectively treat draft probabilities as 1.0 during verification, which explains the one-hot collapse and poor tail exploration.

The experiments are designed to show that the theoretical fix matters in practice. They compare behavior across stochastic settings, showing that dynamic trees degrade once sampling is introduced unless probability semantics are handled carefully. Additional gains come from the OT-based verification and sparse draft distribution. - Dataflow: keep the residual stream in FP16; use FCMGE (FP compare) with learned thresholds to convert channels into packed bits; run a learned boolean feed-forward “program” implemented via EXT/BSL/EOR/CNT; decode selected boolean traces back to numeric space via CNT/SDOT and apply small FP corrections (FMLA).
