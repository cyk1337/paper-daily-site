Skip a Layer or Loop It? Learning Program-of-Layers in LLMs

LLM 推理对所有输入执行固定深度、固定顺序的层前向传播，不考虑输入难度差异。本文探索：能否将预训练层视为可灵活组合的模块，为每个输入动态生成'层程序'（跳过或循环某些层），以实现更高效或更准确的推理？

评探索了 LLM 层的动态路由（跳过/循环），虽然主要针对推理优化，但其关于'预训练层可作为独立模块重组'的发现对理解模型内部机制和设计新架构有启发。

Looped Diffusion Language Models

这篇工作要解决的不是“MDM 能不能做语言建模”，而是更具体的一层：在 masked diffusion language model 已经靠多步去噪做迭代计算的前提下，Transformer 内部是否还值得再做 looped computation，以及怎样 loop 才能在固定训练算力下带来真实收益。难点在于，MDM 天生已经有时间维上的反复 refinement，如果再把层内计算重复一遍，收益可能只是表面上的“更深了”，也可能被训练 FLOPs 吃掉。作者关心的是一个很工程、也很基础的问题：如何把参数、深度、训练 FLOPs、推理 FLOPs 这几条轴重新解耦，让 MDM 获得比单纯堆层数更好的 compute allocation。

评如果你在跟踪 diffusion/MDLM 路线，这篇值得先看实验表和 compute 对齐方式；想法不新，但若公平成立，会直接改变“MDM 深度只能靠堆层”的默认做法。
Sanghyun Lee,Chunsan Hong,Seungryong Kim,Jonghyun Lee,Jongho Park,Dongmin Park
