这篇工作处理的是 RLVR/GRPO 里一个很具体但代价很高的问题：每个 prompt 固定采样很多条 rollout，其中相当一部分样本组几乎没有奖励方差，因而对 GRPO 的相对优势估计和梯度更新贡献很小，却占掉了大部分生成算力。作者关心的不是再造一个新的 RL 目标，而是在不改 GRPO 基本范式的前提下，怎样把 rollout 预算更有选择地投到“当前最有学习信号”的样本上，尤其是在训练早期。

TRACE: A Unified Rollout Budget Allocation Framework for Efficient Agentic Reinforcement Learning

在 RLVR（verifiable reward）做多轮 ReAct 式 agent 强化学习时，rollout 很贵，但“有效学习信号”并不均匀：有的 prompt 太易/太难导致终局奖励几乎无方差；同一条长轨迹里，不同 turn 的前缀对最终成败的“可分叉性/可对比性”差异很大。论文要解决的是：在固定 rollout 预算下，如何同时在 prompt 根节点和轨迹内部前缀节点上分配采样与分叉预算，最大化可用于策略优化的 reward contrast，从而提升样本效率。

评这篇值得从“训练信号密度”而不是 agent 花活去看；若实验干净，它会改变你只在 prompt 级做 RL 采样分配的默认做法，先看 allocation 定义和 sample-efficiency 图。

Spend Your Rollouts Where It Counts: Rollout Allocation for Group-Based RL Post-Training

基于分组的RL后训练方法（如GRPO）为每个prompt分配相同的rollout采样预算，导致大量算力浪费在奖励分布坍缩、梯度信号可忽略的prompt上；同时由于训练过程中策略持续演化，prompt的信息量无法预先计算，只能在线估计，但全量估算所有prompt的信息量算力成本过高。

评只看 reward-variance 诊断和 allocation 消融；若结果稳，应把 RL rollout budget 从固定 K 改成在线分配。

Where to Spend Rollouts: Hit-Utility Optimal Rollout Allocation for Group-Based RLVR

基于分组的可验证奖励强化学习（RLVR，如GRPO）采用固定每prompt分配相同rollout数的策略，对简单prompt分配过多算力，对困难prompt分配不足，导致Pass@K性能下降，硬问题探索不充分。

评针对 GRPO 采样效率的务实优化，通过后验概率动态分配 rollout 预算，做 RLHF/RLVR 系统的同学值得参考其分配逻辑。
