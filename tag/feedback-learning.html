Learning with Rare Success but Rich Feedback via Reflection-Enhanced Self-Distillation

这篇工作处理的是一个很具体、也很棘手的 post-train 学习问题：当环境奖励极稀疏、成功轨迹几乎拿不到，但环境又能返回较丰富的执行反馈时，模型怎样从失败中稳定起步。已有 on-policy self-distillation，如 SDPO/OPSD，已经把轨迹级稀疏奖励改写成 token 级蒸馏信号，但它们通常只是把环境反馈原样拼到 teacher prompt 里，默认模型自己会从这些原始错误信息中提炼出可学习的修正信号。作者指出，真正的瓶颈不只是有没有反馈，而是反馈是否被组织成可迁移、可复用、可监督的形式。尤其在 rare-success regime 下，teacher 几乎只能依赖失败轨迹来给 student 提供监督；如果失败反馈只是未结构化日志、报错信息或 binary outcome，teacher 给出的 token 分布改进会很弱，学生也很难靠单次 rollout 自举起来。

评值得看它如何把“失败反馈”变成 token 级纠错监督；但要重点审计反思生成是否泄漏答案/引入额外算力，先读方法与消融再信结论。
