9:T4ee,Message Passing Language Models (MPLMs) are implemented as a runtime framework rather than a new model:
- A single user query spawns multiple concurrent LLM threads, each with its own prompt/context and textual ID, decoded in parallel via batched inference.
- The model emits tagged substrings that the runtime interprets as execution directives, analogous to MPI primitives:
  - <spawn[...]> ... </spawn>: create new threads with given IDs and seed prompts.
  - <send[...]> ... </send>: send a text message to specified threads.
  - <recv[...]>: block until messages arrive from specified threads.
  - <stop>: terminate a thread.
- A lightweight controller sits above the inference engine, handling scheduling, message queues, blocking/unblocking, and injecting received messages into the target thread contexts—without changing token sampling or KV-cache management.
- Key difference vs fork-join: communication is point-to-point and can happen repeatedly during execution, not only at a final join, aiming to reduce redundant exploration and lower synchronization granularity.
- Trade-off: messages are plain text (easy to integrate, model-agnostic) but consume context window and introduce robustness issues (format drift, prompt injection, context bloat).a:T8c1,作者提出一个统一的 score × decoder 网格，把大量无监督推理时扩展方法放进同一坐标系里比较。score 侧考察四类内生信号：perplexity、contrastive score、power-distribution likelihood，以及 self-verification。decoder 侧考察三类消费这些分数的方式：optimization、sampling、consensus。optimization 用 best-of-N 近似；sampling 用 SMC 和 MCMC，从 p_final(y|x) ∝ p_LM(y|x)·s(y|x) 这样的重加权分布中采样；consensus 则在多样本条件下选答案模态，可用多数投票或分数加权聚合。

全文最关键的技术判断是：self-verification 比 likelihood 派生分数更适合作为无监督 correctness score。原因有三。第一，它条件在完整候选答案上，而不是只看生成概率，因此更接近后验判断。第二，它和下游目标语义一致，问的是“这个答案对不对”，而不是“这个答案像不像模型平时会说的话”。第三，作者把它定义为 verdict token 的归一化概率 s_sv = p(✓)/(p(✓)+p(✗))，从而减少绝对 logit 尺度带来的不稳定。

另一个有意思的点是 virtual thinking prefix。作者在 self-verification 判别前插入一串不对用户可见的 filler tokens，让模型多消耗一些计算，再读取最后的 verdict logits。这里不是让模型生成完整 reasoning，而只是让 verifier 侧做一个二分类判断。作者发现结构化 filler，比如倒计时 token，比简单的点号更有效。这个观察和一些 prior work 中“无训练 filler token 对生成侧 reasoning 没用”的结论不同。作者给出的解释是，verifier-side 的任务更简单，只需把内部状态推到更可分的 verdict，而不需要维持长程连贯文本生成。

方法上的另一贡献是把 score quality、decoding effectiveness、aggregation effectiveness 分开评估。也就是说，某个分数本身排序能力强，不代表它与某种 decoder 结合后就一定带来更高准确率。全文反复强调 score 的好坏不是静态属性，而是由 decoder 如何消费它共同决定。这一点在分析 SMC/MCMC 时尤其重要，因为分数动态范围不合适会导致粒子塌缩或采样退化。b:T8b5,The main contribution is a unified score × decoder grid. On the score side, the paper compares four intrinsic signals: perplexity, contrastive scoring, power-distribution likelihood, and self-verification. On the decoder side, it compares three families that consume those scores: optimization, sampling, and consensus. Optimization is instantiated as best-of-N. Sampling is implemented with SMC and MCMC over a reweighted target distribution p_final(y|x) ∝ p_LM(y|x) · s(y|x). Consensus selects the modal answer under that induced distribution, using either majority vote or score-weighted aggregation.

The central technical claim is that self-verification is structurally better suited than likelihood-derived scores for unsupervised elicitation. It conditions on the full candidate answer, is semantically aligned with the downstream objective, and is defined as a normalized verdict probability, s_sv = p(check)/(p(check)+p(cross)). That normalization reduces sensitivity to absolute logit scale and makes the score more comparable across candidates.

A second notable idea is the virtual-thinking prefix. Before producing the final verification verdict, the model is forced to consume a sequence of filler tokens that spend extra compute without exposing visible reasoning. The paper finds that structured fillers, such as countdown tokens, work better than uniform fillers like repeated dots. This is an interesting contrast with prior work showing that plug-and-play filler tokens are ineffective for generator-side latent reasoning without training. The authors’ explanation is plausible: verifier-side virtual thinking is an easier task because the model only needs to sharpen a binary judgment, not generate a coherent reasoning trace.

Another strong aspect of the paper is the evaluation design. It separates score quality, decoding effectiveness, and aggregation effectiveness. A score that ranks candidates well in a fixed pool does not necessarily improve best-of-N or sampling-based decoding. The paper repeatedly shows that score quality is not an intrinsic scalar property; it depends on how the decoder consumes the score, especially when dynamic-range mismatch or particle collapse appears in SMC/MCMC.c:T5d2,Experiments are run on MATH500 using both the base and instruction-tuned Qwen3-1.7B. Importantly, the paper evaluates the full score × decoder grid rather than highlighting only one favorable combination. The broad result is that self-verification with virtual thinking performs best or near-best on many axes, especially for candidate ranking and unsupervised selection, but no single score dominates every decoder and every metric. That restraint makes the empirical story more credible.

The evaluation has three layers. First, score quality: with a fixed candidate pool, can the score rank correct answers above incorrect ones, measured by per-question AUROC and top-k accuracy. Second, decoding effectiveness: once the score is plugged into best-of-N, SMC, or MCMC, does it improve single-answer accuracy over vanilla decoding. Third, aggregation effectiveness: when many samples are available, does score-weighted consensus beat majority vote or simple best-of-N selection.
