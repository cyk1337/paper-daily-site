The setup is clean: for a target layer l, predict router logits g_l from the previous k expert-selection states S_{l-k:l-1}, and compare against a common baseline that uses only S_{l-1}. The gain directly measures how much older history helps once the most recent selection is already available. The analysis proceeds in stages. EIPC compares different history representations: fused expert outputs, provenance vectors that preserve expert identity slots, and identity-shuffled controls. The result is that preserving expert identity is much more predictive than using fused outputs. EPD then decomposes provenance into path identity versus contribution content, showing that the useful signal is overwhelmingly in the selection path, not in the expert-output content. With that established, RMO tests the main question: how much value remains in older selection history beyond the previous layer? The controls are thoughtful. Separate PCA transforms are applied to recent state and older history, and the baseline is padded to the same dimensionality with zeros so the comparison is not confounded by input size. The authors also run a preregistered replication on JetMoE, replace ridge probes with small MLPs, add a parameter-matched recent-only MLP, and perform residual prediction: first predict both target logits and older history from recent state, then test whether history residuals still predict logit residuals.
