9:T5b6,Echo is a hybrid model: most layers are SSM blocks (Mamba-2 for from-scratch LM training), while attention layers are replaced by Spectral Koopman Attention (SKA); the design also replaces standard SwiGLU FFNs with Koopman-operator-based alternatives.

SKA’s central reframing is that content-addressed retrieval can be written as kernel ridge regression, whose solution depends only on additive second-order sufficient statistics—so you can stream them without storing per-token K/V.
- Per-head linear projections produce keys/queries/values with Koopman rank r.
- A sequence-max normalization m=max_{s≤T}||z_s||_2 (frozen after prefill) preserves relative token norms and avoids amplifying low-norm noise, while preventing scale drift between prefill and decode.
- Maintain three additive statistics: a regularized Gram matrix G, a cross-temporal covariance M, and a value–key covariance C_v. Each new token updates them via rank-1 additions.
- Compute the closed-form ridge solution B*=C_v \tilde G^{-1}, then fit/whiten a Koopman operator; spectral modes guide which bindings to retain, and retrieval is implemented via a power-iterated filter.

The claimed reason it avoids the SSM memory cliff is structural: the state is an exact sufficient statistic for the retrieval computation, not a lossy recurrent bottleneck subject to multiplicative decay.
