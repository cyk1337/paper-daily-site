9:T44c,GRAS combines two changes. First, it improves the guided proposal. Prior GILC-style methods correct clean-token logits with a straight-through reward gradient, but the gradient is often estimated from a single noisy sample. For differentiable rewards, GRAS uses a Gumbel-Rao / Rao-Blackwellized reveal estimator to analytically average part of the reveal randomness and reduce variance. For non-differentiable rewards, it uses a leave-one-out baseline to reduce particle-level reward noise. These proposal changes add no denoiser calls. Second, it changes the search stage. Standard SMC/TDS-like resampling often uses a fixed temperature, although the spread of values differs across denoising steps. GRAS introduces AMC, an adaptive-temperature resampling rule that standardizes per-step values into group-relative advantages and lets a single scale parameter control selection pressure.
