9:T5a7,The proposed framework is computation-conditioned credit transport, or CCT. Standard GAE can be written as a stationary upper-triangular transport kernel whose weights depend only on temporal distance. Group-relative methods often assign a response-level statistic to all valid response tokens, giving a rank-one broadcast structure. CCT instead extracts a detached statistic from the behavior policy’s internal computation at each prefix and maps it to a bounded retention gate κ_t. The sensitivity of an earlier advantage A_t to a later residual δ_u is then the product of gates along the intervening path. This makes the transport kernel nonstationary and trajectory-specific while keeping the task reward and outer objective unchanged. The instantiated algorithm, CompPO, uses native attention concentration as a cheap structural proxy. The gate enters a computation-conditioned bootstrap and a path-dependent generalized-advantage trace, called Comp-GAE. A transport-aligned critic pools value-relevant history from the actor’s hidden states and attention, using the same gate to connect local and routed-history value estimates. The outer objective remains clipped PPO, with the same verifier, rollout format, and reward. The method is not simply an attention-weighted policy-gradient loss: attention parameterizes the bootstrap coefficient, trace weights, and critic state geometry, but does not directly multiply the policy gradient.a:T76c,ARMOR has two main components.

The first is Anchor Rollout. In standard on-policy RL, rollouts come only from the current policy, so the training distribution can quickly collapse together with the policy itself. This reinforces a small set of shortcut reasoning patterns. ARMOR injects off-policy samples from the reference policy during rollout and treats them as anchors. The point is not merely to add more data, but to explicitly preserve solution modes already present in the reference distribution, which are more likely to be broad and generalizable. This differs from reverse KL in an important way: KL penalizes deviation from the reference, but it does not guarantee that representative reference samples are actually present in the training stream. Anchor Rollout stabilizes the process at the data-distribution level.

The second is Mixed Optimization. Instead of adding KL as an auxiliary penalty, the method directly optimizes a mixed policy, alpha times the current policy plus one minus alpha times the reference policy. The intended effect is an adaptive trust region. The current policy is still allowed to explore beyond the reference when it finds better reasoning paths, but the optimization target never fully discards the reference distribution. According to the authors, this addresses both failure modes of reverse KL: Anchor Rollout mitigates instability from mode collapse, while Mixed Optimization mitigates stagnation from overly uniform regularization.

The paper develops the method in the GRPO and DAPO setting. It reviews GRPO’s clipped objective and loss-level reverse KL, then uses DAPO as a primary baseline because DAPO without KL makes over-optimization easier to expose. ARMOR is therefore positioned as a plug-in layer on top of existing RL pipelines, modifying both rollout generation and the optimization target rather than replacing the whole algorithm.b:T642,From the available full-text excerpt, experiments cover multiple base models, including Qwen2.5-Math-7B and Qwen3-8B-Base, and multiple RL algorithms, including DAPO and QAE.
