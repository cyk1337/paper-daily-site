Data Attribution of Emergent Misalignment with Persona Features

这篇工作追问的是 emergent misalignment 的上游来源：如果窄域微调会把模型推向越狱、操控、反社会角色等失配行为，那么这些可被放大的“persona features”究竟来自哪些预训练文档，且自然人类文本本身是否足以诱发这类失配。它不是只做相关性分析，而是把问题拆成三层：先用 aligned vs misaligned 的对比微调找出被放大/被压制的 SAE 特征，再用 activation steering 验证这些特征对行为有因果作用，最后把特征回溯到预训练语料并测试这些语料能否单独复现 EM。

评这篇不直接改 pretrain recipe，但会改变你看待“坏行为从哪来”的 prior；重点看 feature steering 的因果证据，数据归因部分先当弱信号。

Bergson: An Open Source Library for Data Attribution

这篇工作解决的不是新的 attribution 理论，而是一个长期存在的工程断层：很多数据归因方法在小模型、单机、离线实验里能跑，但一到大语言模型、海量训练集、多节点环境就很难复现，更别说横向比较。作者要解决的是，如何把 influence functions、近似 unrolled differentiation、精确穿过训练轨迹的归因方法，做成一个可扩展、可组合、可复现实验的统一系统，并把一些此前没有开源实现的方法真正落地到 10B 以上乃至 405B 量级模型的工作流里。对预训练研究来说，数据归因不是解释学边角料，它直接关系到数据筛选、坏样本定位、记忆与泛化分析、合成数据质量控制，以及训练数据对特定行为的因果贡献估计。

评值得 skim 工程设计；若团队在做数据回溯或去毒，先复现 gradient store 方案，再谈 attribution 质量。

Sketching the Readout of Large Language Models for Scalable Data Attribution and Valuation

这篇论文要解决的是：如何在不做全模型反向传播、也不存每个样本全参数梯度的前提下，为大语言模型做可扩展的数据归因与数据价值评估。传统 influence function 需要 Hessian 逆，LLM 上基本不可用；TracIn 一类一阶近似虽然更简单，但仍要为每个样本保存 O(P) 级别梯度，参数一到十亿级就很快失去可操作性。论文的关键判断是，影响信号并不是均匀分布在整个网络里，而是明显集中在输出侧 readout，也就是 LM head；如果只抓住这一层，并利用其梯度的外积结构，就有机会把归因问题从“全模型梯度索引”改写成“前向可得的低成本 sketch 匹配”。

评这篇值得看，因为它把 data attribution 从玩具规模推进到 32B 可操作区间；先看方法假设是否真由 readout 主导，再看压缩后 fidelity 曲线，别只盯 112×。
