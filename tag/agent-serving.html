Practical Online KV Cache Compaction for LLM Agents: An Empirical Study

论文研究的是 agent 场景下的在线 KV cache 压缩，而不是普通长上下文静态压缩。难点不在于“怎么压缩一个已知文档”，而在于 agent 的上下文是边交互边增长的：推理轨迹、工具调用、环境反馈会持续追加进上下文，压缩某一轮时，未来会怎么读这段信息还不知道。于是离线场景里常见的 query-aware 压缩信号在这里不再天然可用。论文要回答的是：在在线 agent 循环里，什么样的 proxy query 能以足够低的额外开销指导 KV 压缩；不同压缩家族在这种不完美信号下谁更稳；延迟压缩是否值得。

评只看 proxy query 对比和 TE/AM 失效案例；它不会改预训练方向，但会改变 agent 长轨迹 serving 的默认压缩策略。
Yujian Liu,Jiabao Ji,Li An,Rohit Jain,Gungor Polatkan,Siyu Zhu,Shiyu Chang
