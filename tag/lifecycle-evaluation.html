HarnessRisk: A Lifecycle-Oriented Benchmark for Agent Harness Safety

这篇工作要解决的问题不是“模型会不会被提示注入”这么窄，而是更完整的：当 LLM 作为 agent 部署在真实 harness 中时，安全性到底由哪些生命周期环节共同决定，以及现有评测为什么会系统性漏掉 harness 自身带来的风险。论文把风险面从单次运行时交互，扩展到配置、插件/能力扩展、持久状态写入、高风险动作授权、以及事后恢复六个阶段。核心问题因此变成：在一个带工具、文件、持久记忆和执行环境的 agent 系统里，如何用统一协议评估“任务完成”和“安全约束”之间的张力，并区分风险究竟发生在什么环节。

评将 Agent 安全评测从单纯的 prompt 注入扩展到了整个系统执行脚手架（harness）的生命周期，对于构建和评估生产级 Agent 系统非常有价值。
