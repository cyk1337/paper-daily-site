9:Ta1d,方法叫 BPCO（Best-Practice Critic Optimization）。它由五个关键部件组成。

第一，用 DPPO 替代标准 PPO clipping。标准 PPO 用概率比值裁剪，低概率 token 的微小绝对变化也可能触发 clipping，而高概率 token 可以承受更大的绝对变化；在大词表 LM 中，这会让不同 token 的更新几何很不均匀。DPPO 把约束改成 sampled token 概率的绝对变化上界，相当于让每个被采样 token 共享同一 absolute-probability trust region，更适合语言模型的长尾词分布。

第二，把 critic 输出限制在 reward range 内。论文考虑的是 outcome reward，回报天然有已知范围。若 value head 仍是无界线性层，训练早期很容易出现超范围预测，随后 GAE 和 value loss 都会被放大。作者将 value prediction bounded 到 reward 支持集，使 critic 的函数类与任务先验一致，减少无意义外推。

第三，critic 直接拟合 Monte Carlo return，而不是常见的 bootstrap target。由于中间 reward 全为 0、终局才给分，且 γ=1 的设置很常见，此时用 bootstrap target 的收益并不大，却会把旧 critic 的误差传播到新 critic。BPCO 直接用观测到的最终回报训练 value，相当于在 outcome-only 场景里主动放弃一部分低方差，换取更少偏差和更稳定的 critic 学习。

第四，policy update 不做 batch-wise advantage normalization。作者的论点很直接：当策略逐渐收敛时，真实 advantage 的尺度本来就应该变小；若每个 batch 都强行归一到单位方差，就等于持续放大残余噪声，容易造成后期训练抖动甚至过更新。BPCO 保留 raw advantage scale，让优化器看到“信号正在衰减”这件事。

第五，使用 length-adaptive GAE。固定 λ 在短回答和长回答上对应的 terminal reward 传播形状不同，导致 credit assignment 随长度系统性偏移。作者设计按 response length 调整的 λ，使不同长度样本上终局奖励向前传播的权重分布更一致。

除此之外，论文还强调一个 critic-only 的额外自由度：privileged critic input。因为 critic 只在训练时使用，可以额外看到 reward-defining information，例如数学题参考答案、官方解、或开放式任务的 rubric，而 policy 仍只看原始 prompt。这样不会改变最优 value function 的定义，但会显著降低 value approximation 难度。这个点和传统 RLHF/GRPO 的差别很大：group-relative estimator 很难自然利用这类只在训练时可见的信息。a:T7b2,实验分三层。

第一层是 controlled sanity test。作者构造了一个小而可解的数据设定，用“能否稳定拟合”来隔离优化问题，而不是把失败归因于任务难度。这里最有信息量的结论是：bounded value head、MC target、去掉 advantage normalization、以及 length-adaptive GAE 都能单独改善稳定性；把这些组件叠加后，critic baseline 从容易发散或震荡，变成可持续下降并收敛的训练曲线。这个部分更像训练病理分析，建议认真看。

第二层是数学推理主实验。数据规模是 40.3K problems，并在两个 30B-A3B 的 MoE 模型上评估。文章的主张不是“critic 远超 group-based RL”，而是更克制：BPCO 相比原始 critic baseline 在不同模型和数据规模上都更稳、更强；同时在只用每个 prompt 一个 response 的条件下，性能可以追平或超过 group-based baseline。这里真正重要的是 sample efficiency 叙事：GRPO 需要每 prompt 多条 rollout 才能形成组内相对优势，而 BPCO 用单条 rollout 就能构造 token-level advantage。

第三层是 privileged information 实验，包括数学任务里给 critic 参考答案，以及 rubric-reward 任务里给 critic rubric。结果显示 privileged input 往往能加快 critic 学习，但对最终 policy 的收益并不总是单调增加；当 critic 过拟合训练分布时，value 更准不一定转化成更好的 policy improvement。这个观察很重要，因为它提醒人们：critic 监督更强，不等于 actor 更新一定更好，关键还要看 value error 的分布是否与 policy improvement 方向一致。

First, it replaces standard PPO clipping with DPPO. Standard PPO clips the probability ratio, which means low-probability sampled tokens can be clipped by tiny absolute probability changes while high-probability tokens tolerate much larger ones. In large-vocabulary language models, this creates uneven update geometry. DPPO instead clips the absolute probability change of the sampled token, giving a common absolute-probability trust region.

Second, it bounds value predictions to the reward range. In outcome-reward settings, the return support is known. An unconstrained linear value head can easily overshoot that range, especially early in training, which then destabilizes both value fitting and downstream advantage estimates. Bounding the value head injects a simple but strong task prior.

Third, it trains the critic on Monte Carlo returns rather than bootstrapped targets. Because intermediate rewards are zero and the terminal reward carries the whole signal, the variance reduction from bootstrapping is limited while the bias from critic self-reinforcement can be severe. BPCO therefore prefers direct supervision from observed outcomes.

Fourth, it removes batch-wise advantage normalization in the policy update. The argument is that as the policy improves, the residual advantage scale should naturally shrink. Forcing every batch to unit scale erases that information and can keep magnifying noise late in training. BPCO preserves the raw advantage magnitude.

Fifth, it introduces length-adaptive GAE. With a fixed lambda, terminal reward is propagated backward with a length-dependent profile, so short and long responses receive systematically different credit assignment. The adaptive schedule is designed to make the effective weighting of terminal reward more consistent across response lengths.

A notable extra feature is privileged critic input. Since the critic is discarded at inference time, it can condition on reward-defining information unavailable to the policy, such as a reference answer, official solution, or grading rubric. This does not change the ideal value function for a prompt, but it can make that function much easier to approximate. That is a meaningful advantage over group-relative estimators, which do not naturally exploit such side information.c:T650,The empirical section has three layers.

The first is a controlled sanity test on a small solvable setup. This is arguably the most informative part of the paper because it isolates optimization pathologies from task difficulty. The ablations show that bounded value prediction, Monte Carlo targets, removing advantage normalization, and length-adaptive GAE each improve stability, and their combination turns a fragile critic baseline into a trainable one.

The second layer is the main mathematical reasoning evaluation on a 40.3K-problem dataset, using two 30B-A3B mixture-of-experts models. The claim is measured rather than inflated: BPCO consistently improves over the critic baseline across scales, and with only one rollout per prompt it matches or exceeds a group-based baseline. The key point is sample efficiency and token-level credit assignment, not merely final accuracy.

The third layer studies privileged information. In math, the critic can see a reference answer; in a rubric-reward task, it can see the grading rubric. This often accelerates critic learning, but the policy gain is task-dependent and can weaken when the critic overfits. That is a useful result: a more accurate critic is not automatically a more useful critic for policy improvement.

The hard numbers explicitly stated in the paper include the 40.3K math dataset, two 30B-A3B MoE models, and single-rollout comparisons against group-based training.
