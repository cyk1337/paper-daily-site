18:T816,PLRM 的核心是一个变分式 latent reasoning 框架。论文先明确了传统 CoT-SFT 的三个优点：一是 next-token 预测天然是随机的，可以采样多条轨迹；二是每个中间 token 都提供密集监督；三是 teacher forcing 允许并行训练。作者认为，很多 latent reasoning 方法虽然减少了语言冗余，却丢掉了其中至少一部分，尤其是随机性和分布建模能力。

为此，PLRM 不再把 latent step 当成一个确定向量序列，而是把每一步 latent reasoning state 建模成条件分布。训练时，posterior 网络从问题 x 和 verbalized CoT 中构造目标 latent distribution；prior 网络只看问题条件，去预测这些 latent 分布。这个训练目标是 JEPA 风格的 predictive objective：不是逐 token 重建文本，而是在潜空间里让 prior 对齐 posterior 所定义的目标表示。这样做有两个直接好处。第一，它鼓励 latent state 保留对求解有用的核心推理信息，而不是去拟合语言表面的措辞差异。第二，它保留了 teacher-forced、可并行的训练结构，因为 posterior 可以从完整 CoT 提供监督信号。

论文进一步指出，同一道题可能对应多条有效 CoT，因此目标 latent 分布天然可能是多峰的。如果只用单高斯 prior，容易把多条推理路径压成一个平均态，既不利于采样，也不利于表达不确定性。为此作者引入 mixture-based prior，用混合分布去拟合多模态 latent target，而不是把所有轨迹揉成一个 unimodal Gaussian。这个设计是全文最关键的技术点：它不是简单给 latent 加噪声，而是明确把 reasoning trajectory 当作分布对象来学。

从方法定位看，PLRM 与 Coconut、CODI、Sim-CoT 这类确定性 latent reasoning 的差别，在于它把“潜空间推理”从 sequence compression 推向了 distribution modeling；与一般随机 latent model 的差别，在于它借助 posterior-prior 配对和 JEPA 式目标，试图缓解训练不稳与 posterior collapse。19:T85b,PLRM is a variational latent reasoning framework. The paper starts by identifying three useful properties of standard CoT-SFT: next-token prediction is stochastic and supports trajectory sampling; every intermediate token provides dense supervision; and teacher forcing enables parallel training. The authors argue that many latent reasoning methods reduce linguistic overhead but lose at least part of this package, especially stochasticity and distributional modeling.

PLRM therefore models each latent reasoning step as a conditional distribution rather than a deterministic vector. During training, a posterior network constructs target latent distributions from the input problem and its verbalized CoT trace. A problem-conditioned prior then learns to predict those latent distributions without access to the CoT. The objective is JEPA-like: instead of reconstructing text token by token, the model aligns the prior with posterior-defined latent targets. This has two intended effects. First, it encourages latent states to preserve reasoning-relevant information while discarding incidental variation in verbalization. Second, it retains a teacher-forced, parallelizable training structure because the posterior can provide supervision from full CoT traces.

A central observation is that a single problem may admit multiple valid CoTs, so the target latent distribution can be genuinely multimodal. A unimodal Gaussian prior would tend to average these trajectories together, which is bad for both sampling and uncertainty representation. To address this, the paper introduces a mixture-based prior that can model multimodal latent targets. This is the key technical move: the method is not merely injecting noise into latent CoT, but explicitly treating reasoning trajectories as a distribution to be learned.

Relative to deterministic latent reasoning methods such as Coconut, CODI, and Sim-CoT, PLRM shifts the goal from sequence compression to distribution modeling. Relative to generic stochastic latent models, it uses posterior-prior coupling and a JEPA-style predictive objective to improve stability and reduce collapse.1a:T70d,The visible full text already gives a fairly clear experimental message. The evaluation covers mathematical and commonsense reasoning, with especially strong results reported on GSM8K-Aug-NL and CommonsenseQA. Those tasks are a good fit for the paper’s hypothesis because many CoT tokens there serve verbalization and discourse coherence rather than core reasoning. The claim is that PLRM substantially outperforms existing stochastic latent reasoning baselines while remaining competitive with deterministic latent reasoning methods under more efficient training.

A particularly important experiment is the introduction of HiddenBranch, a dataset derived from ProofWriter where each problem admits multiple reasoning paths and answers. This is designed specifically to test distributional reasoning rather than single-trajectory imitation. The reported result is that PLRM outperforms both all stochastic latent baselines and CoT-SFT on this setting. That matters because it suggests token-level language supervision is not automatically superior when the real challenge is to model a distribution over valid trajectories.

The provided text does not include exact model sizes, latent dimensionality, number of mixture components, training-token counts, or precise scores, so numeric claims should be verified directly from the tables. The most important ablations to inspect are likely: deterministic versus stochastic latent transitions, unimodal versus mixture prior, the role of posterior-guided target distributions, and the trade-off between number of latent steps and performance or efficiency. DA-DLM 的核心改动，是在每个去噪步构造一个 position-oriented DAG，而不是直接输出各位置独立分布。这个 DAG 不是 DAT 在 NAT 里那种大而自由的无位置约束图，而是显式绑定到输出位置。每个输出位置对应一个 node group：
- 如果该位置的 token 在更早去噪步已经被固定，那么这个位置在当前 DAG 中就是一个单节点 anchor；
- 如果该位置还未确定，就为该位置展开多个候选节点，表示该位置当前可能的局部模态。

然后只允许相邻位置的 group 之间建立 transition。这样一来，最终不是对每个位置各选一个 token，而是在整张 DAG 上选一条穿过各位置 group 的路径。路径分数同时考虑节点发射分数和相邻候选之间的转移分数，于是同一步里多个 token 的选择被耦合起来。已经固定的 token 作为 anchor 被钉在图上，能对邻近未决位置形成结构性约束。这一点是作者区别于直接照搬 DAT 的关键：DLM 是迭代式的，前几步已确定 token 的“锚定作用”必须保留，否则 successive denoising 容易漂。

During inference, the model starts from a fully masked block, predicts all masked positions in parallel, and then fixes a subset of tokens according to a schedule or confidence rule. The key limitation is that those per-position predictions are independent.

DA-DLM replaces that factorized prediction with a position-oriented DAG constructed at every denoising step. This is not the same as directly importing DAT from NAT. DAT uses a large DAG with relatively unconstrained transitions for one-shot generation. DA-DLM instead binds the graph explicitly to output positions.

Each output position corresponds to a node group. If a token at that position has already been fixed in an earlier denoising step, the group collapses to a single anchor node. If the position is still unresolved, the model expands it into multiple candidate nodes representing local alternatives. Transitions are only allowed between adjacent position groups. Generation within the step is therefore no longer a set of independent token choices. It becomes a path selection problem through the DAG, where the path score combines node scores and transition scores. This couples the token decisions made in the same denoising step.

The anchor mechanism is the critical adaptation to iterative denoising. Previously fixed tokens are pinned into the graph and structurally constrain nearby unresolved positions. That is the main reason the authors do not simply reuse DAT as-is. In DLMs, the denoising process should progressively converge as more tokens become fixed. Without explicit anchoring, successive steps can drift rather than refine.

Conceptually, the method does two things. First, it changes the denoising objective at each step from factorized marginals to a structured joint selection problem over a local dependency chain.
