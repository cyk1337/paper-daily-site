Second, mask states remain separate from the normal vocabulary, so the model still knows which positions are corrupted. That preserves the clean/noise separation that makes MDMs stronger than uniform-state diffusion.

The probabilistic formulation is developed explicitly, and the resulting ELBO has a clean interpretation. One term is the usual clean-token reconstruction objective: predict the original token from a corrupted state. The second term is an intra-mask identification objective: once a position has entered the mask subspace, the model must also identify which mask it belongs to. This is not a cosmetic addition. It is exactly what allows the model to exploit the information carried by the multi-mask terminal state. Without learning to distinguish masks, the extra entropy would exist formally but would not be useful for generation.

The second major technical contribution is the consistency-distillation construction for the discrete setting. In continuous diffusion, one can often move from a stochastic SDE to a deterministic probability-flow ODE while preserving marginals. There is no direct analogue for finite-state jump processes. The paper addresses this by introducing a low-entropy coupling based on shared Gumbel noise across time points. This creates strongly coupled discrete trajectories and enables a stable consistency target. Importantly, the target is not a naive requirement that outputs at different times should match. That is a more principled target because it respects the conditional structure of the discrete stochastic process.

The base decoder uses block diffusion decoding: the sequence is partitioned into blocks, each block receives a fixed denoising budget, and high-confidence tokens can be committed across all unlocked blocks to increase parallel progress per step. In ETE, lookahead is triggered when the model remains uncertain over masked positions, and a one-step rollout estimates which tentative token commitment is most likely to unlock more confident predictions in the next state.

AdaLook adds two key mechanisms. First, it introduces adaptive rollout depth. Instead of always using a fixed 2-step or 3-step lookahead, the decoder decides whether another rollout step is worthwhile by examining the variance of candidate scores at the current frontier. If candidate futures are already similar, deeper rollout is unlikely to pay off; if they remain well separated, extra exploration may still be useful. This addresses the mismatch between heterogeneous decoding states and a globally fixed rollout depth.

Second, AdaLook allows branch re-evaluation and re-expansion at intermediate rollout states. A naive multi-step rollout follows each hypothesis along a predetermined path until the preset depth is reached. AdaLook instead checks after every rollout step whether each branch still needs expansion. Branches that have become sufficiently resolved are prioritized for selection. If all branches remain uncertain, the highest-scoring branch is chosen and its decoding state becomes the starting point for the next round of lookahead. The gain does not come from searching deeper in a brute-force sense, but from making depth and branching conditional on the evolving uncertainty pattern.

Algorithmically, this is closer to a lightweight confidence-driven adaptive tree search than to fixed-depth beam search. 从消融角度，最值得注意的是 warmup、bucketization、reward estimate reliability 这几项。论文的论证链条是：纯 reward guidance 早期不稳，纯 confidence 后期近视，因此需要一个从 confidence 到 reward-aware 的渐进切换。理论部分用 empirical-Bernstein rate 解释在线 bucketized score 对 exact DPRM score 的跟踪误差来源，包括 bucket coarsening bias、warmup bias 和 nonstationarity。也就是说，作者并不把近似误差藏起来，而是明确指出性能取决于 reward estimate 的方差控制和状态分布漂移。28:T72b,The method formulates token ordering as a sequential control problem over partially revealed states, with a terminal reward defined on the completed generation. The exact controller is derived via a Doob h-transform: starting from the host model's proposal distribution over reveal actions, DPRM reweights that proposal by an h-function tied to expected future reward. Intuitively, the policy no longer asks only which token is currently most confident, but which reveal action is most promising for the final outcome.

Because the exact conditional expectation is too expensive to compute for every candidate at every step, the paper introduces a practical approximation stack. First, it uses a stagewise Soft-BoN approximation, effectively a soft best-of-N selection at each reveal stage. The authors prove O(1/N) convergence in terminal KL to the exact DPRM target, giving a clean approximation guarantee as the sample budget grows. Second, they introduce an online bucketized controller. Candidate actions are grouped into buckets, and reward estimates are accumulated at the bucket level rather than per action. This reduces variance and improves sample efficiency, at the cost of some coarsening bias. Third, the controller uses a warmup schedule: it begins with confidence-driven ordering when reward estimates are unreliable, then gradually shifts toward reward-aware guidance as online estimates stabilize.

This differs from prior approaches in a precise way. Random masking ignores state-dependent control. Confidence-based policies rely on local certainty. Teacher-forced progressive masking improves train-test alignment but still uses confidence-like heuristics in practice.
