18:Tb5f,技术方案可以分成四部分看。

第一部分是理论分析。作者先分析中间状态 s = αe_i + βz 的解码竞争关系。若用欧氏距离，候选 token 的得分会分解成一个随信号缩小而衰减的对齐项，以及一个与当前状态无关的静态范数项。问题就在这里：当 α 变小，即便 β=0、状态方向仍完全对准源 token，低范数 token 也可能因为静态范数优势而“反超”。这不是语义替换，而是度量退化。于是作者转到方向空间，用 cosine / directional ranking 来定义竞争，得到 pairwise crossing 的阈值条件：候选是否超过源 token，取决于有效噪声是否大于两者的语义分离。这个阈值理论把 token identity metric 从经验统计量还原成了大量 pairwise crossing 的聚合结果。

第二部分是 noising geometry。既然问题来自 norm decay，作者就不再沿普通连续高斯轨迹做 corruption，而是设计了 spherical noising。做法是把状态看成沿球面 geodesic 向一个 mask-biased endpoint 插值。这样可以尽量保持向量范数稳定，把竞争关系限制在方向空间里发生，避免欧氏几何下的伪竞争。这里的关键不是“球面”这个词本身，而是它服务于一个更明确的目标：让 corruption 过程和 token competition 的真实判据一致。

第三部分是时间调度，也就是 Semantic Retention Scheduling。Competition Threshold Theory 说明，大量 identity crossing 只会在接近高噪声端才发生。若仍用常规时间参数化，训练的大部分步数都浪费在身份几乎不变的区间，真正困难的身份转移区间反而预算很少。作者因此按 logarithmic rank decay 重新分配时间步，把更多 denoising budget 放到 identity 快速变化的区间。这不是简单的 loss-aware resampling，而是直接围绕 token rank / identity decay 设计 schedule。

第四部分是模型实例化，即 LLaCO。它基于预训练 backbone 适配到连续表示空间，包含 embedding directional adapter 和 timestep-conditioned modulation。前者负责把离散 token embedding 映射到适合方向竞争的连续空间，后者让 backbone 在不同噪声阶段采用不同调制。推理时，模型做 sequential blockwise denoising，并沿 spherical geodesic 逐步把连续语义轨迹翻译回离散 token。这里仍保留 blockwise 生成而不是一次性全序列并行，说明作者在生成质量与并行性之间做了折中：先把连续扩散的语义轨迹建稳，再逐步释放并行生成潜力。

DA-DLM 的核心改动，是在每个去噪步构造一个 position-oriented DAG，而不是直接输出各位置独立分布。这个 DAG 不是 DAT 在 NAT 里那种大而自由的无位置约束图，而是显式绑定到输出位置。每个输出位置对应一个 node group：
- 如果该位置的 token 在更早去噪步已经被固定，那么这个位置在当前 DAG 中就是一个单节点 anchor；
- 如果该位置还未确定，就为该位置展开多个候选节点，表示该位置当前可能的局部模态。

然后只允许相邻位置的 group 之间建立 transition。这样一来，最终不是对每个位置各选一个 token，而是在整张 DAG 上选一条穿过各位置 group 的路径。路径分数同时考虑节点发射分数和相邻候选之间的转移分数，于是同一步里多个 token 的选择被耦合起来。已经固定的 token 作为 anchor 被钉在图上，能对邻近未决位置形成结构性约束。这一点是作者区别于直接照搬 DAT 的关键：DLM 是迭代式的，前几步已确定 token 的“锚定作用”必须保留，否则 successive denoising 容易漂。

从机制上看，这个设计做了两件事。第一，它把 DLM 每步的预测目标从 factorized marginals 变成了一个局部链式依赖上的联合选择问题。第二，它让 DAG 随去噪过程演化：随着步数推进，anchor 越来越多，未决位置越来越少，图会逐渐收缩，模型把容量集中到剩余不确定区域。这个动态图结构很适合 DLM 的 iterative refinement，而不适合一次性 NAT 生成。

论文的思想来源是 DAT，但改造点很明确：DAT 面向单步生成，允许更自由的转移；DA-DLM 面向 iterative denoising，因此采用 position-oriented DAG 来强化已固定 token 的约束，并让图结构与当前 mask 状态同步变化。这个差异不是实现细节，而是任务结构决定的。29:T90a,The method is built on BD3LM. In the baseline, generation is autoregressive across blocks, while each block is generated by masked diffusion. During training, only masked positions contribute under the SUBS parameterization. During inference, the model starts from a fully masked block, predicts all masked positions in parallel, and then fixes a subset of tokens according to a schedule or confidence rule. The key limitation is that those per-position predictions are independent.

DA-DLM replaces that factorized prediction with a position-oriented DAG constructed at every denoising step. This is not the same as directly importing DAT from NAT. DAT uses a large DAG with relatively unconstrained transitions for one-shot generation. DA-DLM instead binds the graph explicitly to output positions.

Each output position corresponds to a node group. If a token at that position has already been fixed in an earlier denoising step, the group collapses to a single anchor node. If the position is still unresolved, the model expands it into multiple candidate nodes representing local alternatives. Transitions are only allowed between adjacent position groups. Generation within the step is therefore no longer a set of independent token choices. It becomes a path selection problem through the DAG, where the path score combines node scores and transition scores. This couples the token decisions made in the same denoising step.

The anchor mechanism is the critical adaptation to iterative denoising. Previously fixed tokens are pinned into the graph and structurally constrain nearby unresolved positions. That is the main reason the authors do not simply reuse DAT as-is. In DLMs, the denoising process should progressively converge as more tokens become fixed. Without explicit anchoring, successive steps can drift rather than refine.

Conceptually, the method does two things. First, it changes the denoising objective at each step from factorized marginals to a structured joint selection problem over a local dependency chain. Second, it lets the graph evolve with denoising: as more positions become anchors, fewer candidate groups remain, and the graph shrinks toward the residual uncertainty. That dynamic graph is well matched to iterative refinement and is the main architectural idea of the paper.2a:T6f6,The evaluation covers language modeling, open-ended generation, and summarization. The headline findings have two parts. First, DA-DLM consistently outperforms the BD3LM baseline across all settings. Second, the gains are larger when fewer denoising steps are used, which is exactly where the independence problem should hurt the most. That alignment between motivation and empirical behavior is important.

A particularly useful result is that on summarization, DA-DLM matches the autoregressive baseline while retaining the parallel decoding advantage. This suggests that the method is not only making open-ended text look smoother. It is also recovering sequence-level consistency in conditional generation.

For this paper, the most informative curve is not a single average score but how quality degrades as denoising steps are reduced. If DA-DLM flattens that degradation curve, then it is addressing a core structural issue rather than making a small improvement in a comfortable high-step regime.
