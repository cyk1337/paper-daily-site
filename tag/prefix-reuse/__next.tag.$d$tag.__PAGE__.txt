5:T720,The method, Distinct Leaf Enumeration (DLE), treats truncated decoding as traversal of a pruned generation tree. At each prefix, only tokens surviving a truncation rule remain in the active set. A full completion corresponds to a leaf with probability given by the product of truncated conditional probabilities along the path. Standard self-consistency samples from this tree with replacement, so it repeatedly revisits the same prefixes and leaves. DLE instead deterministically enumerates distinct leaves, prioritizing unexplored high-probability branches and guaranteeing no duplicate full traces.

This is importantly different from several nearby ideas. It is not beam search: beam search keeps multiple partial hypotheses at every step and is known to suffer from degeneration and low diversity as beam width grows. DLE does not optimize a beam frontier; it enumerates leaf-level completions in the truncated tree. It is also not sampling without replacement in the probabilistic sense, because it does not aim to preserve a target sampling distribution. And unlike tree-of-thought style methods, it does not add verifier calls, reflection steps, or extra model evaluations. It remains a single-model decoding procedure with a different traversal policy.

A second key contribution is prefix reuse. Because DLE expands a shared tree rather than independently resampling complete traces, it never regenerates an already explored prefix. This gives both an algorithmic gain and a systems gain: more of the budget goes to novel branches, and fewer new tokens need to be decoded for the same number of candidate completions. The paper also introduces coverage of the truncated search space as an analysis metric, arguing that better probability-mass coverage explains downstream gains more directly than raw sample count.6:T62d,The experiments are organized around three claims: DLE increases coverage, improves downstream performance under equal budget, and reduces redundant generation. The paper first establishes that redundancy is real. In code generation, around 20% of prefix tokens are repeated across sampled traces, and qualitative examples show multiple identical completions among only a handful of samples.

On the algorithmic side, DLE is compared against stochastic self-consistency under matched token budgets. The central result is that DLE covers more of the truncated search space, especially previously unvisited high-probability branches. That increased coverage is then linked to better task outcomes on constrained reasoning tasks such as math and code. The excerpt provided does not include the full result tables, but the paper’s main empirical claim is clear: at equal token budgets, deterministic distinct-leaf exploration outperforms repeated stochastic sampling.

On the systems side, DLE generates fewer new tokens because shared prefixes are reused rather than regenerated. This matters most in memory-bound settings, where avoiding repeated decode over common prefixes can translate into lower latency or more completed candidates under the same serving budget. The paper is careful not to claim universal superiority over all search methods; the claim is narrower and more practical: if one already uses truncated sampling for self-consistency, replacing random
