Scalable Frequency- and Length-Aware Subdocument Deduplication for Large Language Model Pretraining

大规模预训练语料里“子文档级重复”（模板、导航栏、版权段、引用、重复代码块、版本演化带来的长片段复用）普遍存在。现有做法要么停留在文档级去重，难以清掉局部重复；要么用 suffix array 做可变长子串匹配但通常分 shard 处理，导致跨 shard 重复不可见、去重结果对 sharding 配置敏感；即便用哈希能全局计数，常见的 keep-one/keep-k 又无法根据重复频率与长度的异质性做自适应保留。论文要解决的是：在 corpus scale 上，如何可扩展地做子文档去重，并且让“检测重复”和“保留多少份拷贝”解耦、可控、对 sharding 不敏感。

评这篇值得认真看，因为它把“找重复”和“留几份”拆开了；如果实验里真做了 shard-invariant 计数和 retention 曲线，应该立刻纳入内部数据管线对照。

Pruned BPE: Post-training Visibility Pruning and Token Reallocation for Byte Pair Encoding

这篇工作处理的是 BPE 词表分配里的一个老问题：BPE 的训练目标是逐步构造高频 merge，但语言模型真正看到的是最终编码后的可见 token 集。两者并不一致。很多 merge token 在训练过程中有用，只是作为更长 token 的中间节点存在；等最终编码完成后，这些 token 几乎不会真正出现在语料里。标准 BPE 仍然把它们放进模型可见词表，等于把有限的词表预算花在低暴露、低训练频次的 token 上。论文要解决的不是“怎么剪小词表”，而是“在保持可见词表大小不变的前提下，如何把可见词表从中间构造节点里解耦出来，重新分配给更值得暴露给模型的 token”。

评这个点抓得准：BPE 确实把不少词表浪费在“只参与构造、不该暴露给模型”的节点上；建议立刻做 internal ablation，看 token 数下降能否换成真实 pretrain gain。
Kenny Shao

Discriminative Axis, Not Data Volume: What a Contrastive Corpus Teaches an Audio Embedding

这篇工作要回答的不是“多加数据是否有用”，而是更尖锐的问题：在对比学习的多模态音频嵌入里，某个属性究竟在什么条件下才会被表示出来。作者抓住了一个很干净的反例：给模型加入大规模 lexical speech 语料后，零样本关键词识别大幅上升，但语音情感识别明显下降。两者都属于 speech，都在同一个共享嵌入空间里评测，因此“更多语音数据会带来更全面的语音理解”这个直觉在这里失效。全文的核心结论是，决定属性是否进入表示的关键不是数据量，也不是 caption 里有没有把该属性写出来，而是训练语料是否把这个属性变成了区分 batch 内负样本所必需的判别轴。

评反常识的对比学习机制发现，直接挑战数据堆量的默认思路，重点看§3因果干预实验，结论可迁移到多模态预训练数据构造
