Meta-Task: Turning Terminal Task Synthesis into a Terminal Task for Scalable Agent Training

大规模训练终端操作Agent需要大量多样、可验证的终端任务和高质量交互轨迹，但现有任务合成方法存在两个核心缺陷：一是纯LLM分阶段生成缺乏真实执行环境反馈，生成任务的内部一致性和可执行性差；二是从现有代码仓库挖掘的任务多样性不足、扩展性受限，难以覆盖广泛的终端操作场景。
