9:T4b3,WiSP implements routing-aware expert paging as a drop-in mechanism. It does not modify the serving engine, kernels, model weights, or numerical precision, and therefore preserves byte-identical outputs. The system uses an indirection already exposed by the engine to map each MoE layer to a small GPU scratch space that holds only the currently resident experts. Experts are paged between host memory and GPU memory based on routing behavior, so the GPU keeps a cache of likely useful experts rather than transferring an entire layer.

The more interesting part is memory allocation. The paper argues that expert pages and the KV cache must be managed jointly. To do that, it introduces MV-WSA, which allocates VRAM by equalizing marginal latency benefit per byte while enforcing a minimum KV budget for request admission. The method is implemented both as an offline configurator and as an online controller. The paper also evaluates routing-based prefetching and finds that in low-concurrency decode it helps little, because there is not enough compute to hide PCIe transfer time.
