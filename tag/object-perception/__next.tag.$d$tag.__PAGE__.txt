9:T5bb,The method is straightforward. The authors build MissingBench-Verified, a 118-image benchmark composed of real photos and carefully selected internet images. Each image is paired with a target element to remove. Most edits are produced with the image editing model Nano Banana 2, and the rest are manually edited with an eraser tool. All edited images are then human-verified to filter out unnatural or failed edits. The evaluation prompt is a three-way multiple-choice question asking whether the queried item is clearly visible, visible but hard to see, or not visible, with structured JSON output including reasoning and final answer.

There are four main evaluation settings. Direct query asks the model to judge visibility on its own. Pre-answer tool injection inserts a simulated perfect detector result before the model answers; the detector always reports the queried item as undetected with low confidence. This tests whether external evidence can steer the model. Post-answer tool injection provides the same evidence after the model has already answered, probing confirmation bias. Thinking with images gives the model access to basic image-processing tools such as cropping, brightness and contrast adjustment, and binarization, to test whether active inspection helps. The paper also varies reasoning effort for GPT-5.2 and includes OWLv2 and LLM-Det as detector-style references, though those comparisons are more sanity checks than direct task matches.a:T6ff,The main result is consistent across models: ten leading VLMs perform poorly on images where essential parts were removed. No model exceeds 75% accuracy on the edited set, and four out of ten fall below 50%. The lowest reported accuracy is 44.1% for Claude Sonnet 4.6. Some models show a strong existence bias. Qwen 3.5 Flash, for example, chooses the 'clearly visible' option in 51.7% of cases, which is even higher than its correct 'not visible' rate of 47.5%.

Tool injection helps only partially. In the pre-answer setting, Kimi K2.5 and Qwen 3.5 Plus and Flash improve by about 14.4% to 16.9%, but overall performance remains modest. The post-answer setting is more revealing because it tests whether models revise an already formed belief. Qwen 3.5 Plus shows the largest gain at 24.5%, but most models improve only slightly, and some even dip a bit, though the authors caution against over-interpreting small changes given the dataset size. Even with a simulated perfect detector, most models still remain below 75% not-visible accuracy; Gemini 3.1 Pro Preview is the only one reported above that threshold, reaching 82.2% in the post-answer setting.

On the original unedited images, models generally identify the queried object or part correctly, which matters because it shows the task itself is not inherently ambiguous. The failure is concentrated in the missing-part condition. The think-with-images setting, tested on only a few models, does not appear to reliably solve the problem. NegAwareQwen also performs poorly, suggesting that narrow finetuning on easier negative cases does not transfer well to this harder visual-negation setup.
