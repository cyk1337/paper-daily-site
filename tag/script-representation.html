The Latin Substrate: How Language Models Represent and Mediate Script Choice

这篇论文研究多脚本语言在 LLM 内部是如何被表示和生成的，尤其关注一个更细的问题：当同一种语言可以写成 Latin 和非 Latin 脚本时，模型在内部是否通过某种共享的“拉丁化”中间表示来完成脚本选择与转写。作者要回答的不只是“模型会不会 transliteration”，而是脚本信息在层间如何形成、是否可线性操控、由哪些具体模块负责，以及 Latin 与非 Latin 脚本在机制上是否对称。

评值得看 logit-lens 和 steering 实验；latent romanization 若稳，会影响多语 tokenizer 与 script balancing 的诊断方式。
Daniil Gurgurov,Alan Saji,Katharina Trinley,Josef van Genabith,Simon Ostermann
