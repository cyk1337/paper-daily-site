Raven: High-Recall Sequence Modeling with Sparse Memory Routing

线性时间序列模型（包括状态空间模型SSM、线性Transformer、滑动窗口注意力SWA）在长上下文记忆上存在根本性的写记忆权衡：SSM类模型每步对全状态做稠密写入，不同token的信息相互干扰，难以精准召回久远的特定token；SWA类模型做稀疏写入，但只保留固定窗口内的显式token表示，一旦内容滑出窗口就会完全丢失。现有线性模型的设计始终停留在这两个极端，缺少介于“稠密写入全局记忆”和“稀疏写入固定窗口”之间的中间方案，导致长距离召回能力薄弱，上下文长度外推性能差。

评把 SSM 与 SWA 的记忆写入机制做了干净的插值，应立刻在内部长程 recall ablation 中复现，看路由稀疏度的 scaling。
Arshia Afzal,Aviv Bick,Eric P. Xing,Volkan Cevher,Albert Gu
