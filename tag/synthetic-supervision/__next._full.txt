17:T439,MAGE is a two-stage, model-agnostic framework that plugs into existing unlearning objectives (e.g., reverse-optimization style methods like GA/NPO, or alternative-response training like WHP/IDK):
1) Internal Memory Mining: starting from a lightweight anchor for the target entity, MAGE iteratively probes the LLM to elicit target-related facts/relations and organizes them into a weighted local memory graph. The weights represent estimated memorization strength/credibility derived from the model’s outputs (e.g., stability/consistency signals), used to filter noise and keep strongly memorized content.
2) Scoped Supervision Construction: sample informative paths from the memory graph and compile them into a scoped forget set, plus a companion neighbor set (similar distribution but unlearning-irrelevant) to reduce collateral damage; optionally include a general retain set to preserve overall utility.
The novelty is not a new loss, but a corpus-free pipeline that reconstructs and “compiles” internal memorization into training supervision with explicit scope
