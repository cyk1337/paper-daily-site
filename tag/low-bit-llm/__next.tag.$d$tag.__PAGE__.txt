9:T429,QUASAR separates reconstruction into quantization and dequantization. Quantization maps full-precision weights to discrete codes while treating the clipping range as a searchable variable. Dequantization maps those codes back to reconstructed weights using learned scales, and optionally offsets for asymmetric quantization. The reconstruction objective is not plain L2 error; it is a Hessian-weighted, loss-aware reconstruction error inspired by second-order PTQ. To make this usable inside QAT, QUASAR approximates the Hessian diagonal with an exponential moving average of squared gradients, giving per-parameter saliency scores. For a small set of candidate clipping ranges, it fixes the discrete code assignment, solves the dequantization parameters in closed form by saliency-weighted least squares, and chooses the candidate with the smallest loss-aware reconstruction error. The analysis decomposes the QAT convergence bound into initialization, minibatch noise, and reconstruction error; only the last term is directly controlled by the reconstruction map.a:T60e,JacQuant keeps the hard quantizer QΔ(·) in the forward pass and replaces STE’s identity Jacobian in the backward pass with a learned sensitivity map B(W). If q = QΔ(W) and v = ∇qℓ is the gradient with respect to the quantized weights, JacQuant uses ∇Wℓ ≈ B(W)v instead of ∇Wℓ ≈ Iv. The surrogate B(W) is constrained to be diagonal or block-diagonal; in the default grouped setting, each quantization group gets a single scalar gain bg. This is intentionally low-capacity. The goal is not to model the full Jacobian, but to capture the most important local fact: in bin interiors the effective gain should be closer to 1, while under clipping or saturation it should shrink toward 0. The paper proposes two inexpensive estimators. JacQuant-Probe injects random Gaussian perturbations and measures Q(W+δ)−Q(W), then fits a one-step slope per group. JacQuant-Dither uses subtractive dithering to embed hard quantization into a smoothed stochastic model and estimates the mean sensitivity under that model. The surrogate is refreshed only occasionally and reused across many QAT steps, so the runtime overhead stays small. The theory follows the same smoothed view: during code-preserving phases, if B(W) tracks the mean sensitivity, the update corresponds to a well-defined target gradient. The paper then gives standard non-convex convergence guarantees and linear rates under a PŁ condition.
