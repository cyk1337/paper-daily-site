9:T461,The method treats response correctness as a binary classification problem. For each query-response pair from a fixed black-box LLM, the feature set includes: (1) one or more existing uncertainty scores, and (2) neighborhood-derived features computed from a labeled reference set. The reference set is embedded, k-nearest neighbors are retrieved for each query, and statistics such as neighbor correctness and cosine similarity are added as features. A lightweight classifier is then trained to predict the probability that the current response is correct.

A key design choice is that the paper does not insist on a single learner. Instead, it compares simple classifiers and concludes that the best learner is task-dependent. This is important: the paper is not claiming a universal parametric confidence model, but a supervised calibration layer over existing UQ signals. Relative to standard zero-shot UQ, the shift is clear: uncertainty scores are treated as imperfect features, not as final confidence estimates.
