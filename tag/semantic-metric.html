Beyond BLEU: A Semantic Evaluation Method for Code Translation

这篇工作解决的是 code translation，尤其是 binary lifting / decompilation 场景里的评测失真问题：BLEU、CodeBLEU 这类字符串或结构相似度指标，并不能判断翻译后的程序是否语义等价。对代码任务来说，真正重要的是执行行为是否一致，而不是表面文本是否像。

评代码翻译评估不能使用BLEU，语义执行得分的评估方法可直接复用进代码LLM训练的评测流程
