这篇论文要拆开一个过去被端到端指标混在一起的问题：自演化 Agent 的收益，到底来自模型能写出更好的 harness 更新，还是来自任务执行模型能更好地使用这些更新。论文把前者定义为 harness-updating，把后者定义为 harness-benefit，并用固定权重、只更新外部 prompt、skill、memory、tool 等 harness 的设定做系统分析。

评反常识发现值得注意：弱模型更新 harness 的质量并不比强模型差多少——只看核心实验图即可，setup 相对干净。

SIA: Self Improving AI with Harness & Weight Updates

这项工作研究自动自我改进中的一个接口问题：现有系统通常只改 agent 的 harness/scaffold，例如 prompt、工具调用、重试逻辑和答案解析；另一类 test-time training 则只更新模型权重，harness 固定。SIA 试图把两者放在同一个闭环里，由一个反馈 agent 同时决定如何改 scaffold，以及如何用任务反馈更新模型的 LoRA 权重。

评将 Agent 脚手架搜索与模型权重微调结合的思路很自然，值得关注其在不同领域（特别是 GPU kernel 优化这种 hard task）上的具体实现和收益分配。
