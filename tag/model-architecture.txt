18:T415,Tiered Language Models use a secret key as a permutation specification over selected parameter positions. In the public configuration, the released weights are used normally. In the keyed configuration, the same weights are partially permuted, creating an alternative computation graph. This cannot be retrofitted to an already trained model, because arbitrary parameter permutation destroys learned computation. The training recipe has two stages. First, asymmetric joint pretraining trains both public and keyed configurations on public data, while shaping gradient flow so the public configuration relies less on parameters that will later be rearranged. Second, private fine-tuning updates the rearrangeable parameters through the keyed configuration on private data, with regularization to preserve public behavior. Compared with prompt passwords, authorization is moved out of the input space. Compared with adapters, the key contains no learned weights.
