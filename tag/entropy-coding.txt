19:T941,技术上，论文提出一个两层式 sequential KV compression 框架。

第一层是 probabilistic prefix deduplication。传统 prefix sharing 只在多个请求拥有完全相同前缀时复用 cache；作者想做得更激进：即使两个 session 的 token 前缀不完全相同，只要它们在模型概率空间里足够接近，也可以视作“语义等价前缀”，共享一个前缀表示，再只存各自相对共享中心的增量。这里用到 PLT（Probabilistic Language Trie）中的 trie metric，形式上是 d_T(s,s') = -log P(common-prefix relation / probabilistic overlap) 一类的概率距离。关键不是字符串相等，而是“在模型先验下，这两个前缀是否落在相近的预测状态里”。这比 exact prefix matching 更强，因为它试图消除跨 session 的近似冗余。

第二层是 predictive delta coding。对单个 session 内的每个 KV 向量，不直接存原向量，而是先用模型基于历史前缀预测当前位置的 KV，再只编码真实 KV 与预测 KV 的残差。作者给出的理论主张是：这个残差的熵上界由 token-level surprisal 控制，而不是由每个向量各维度的独立熵控制。换句话说，如果模型对下一个 token 很有把握，那么它对下一个内部状态也应有较强可预测性，剩余需要编码的信息会更少。

论文还强调这两层与 TurboQuant 一类 per-vector quantization 是正交的。也就是说，先做 sequential compression，再对残差做量化，或者反过来组合，理论上都可叠加。作者进一步声称其渐近行为更好：上下文越长，模型条件分布越尖锐，预测越准，序列式压缩的收益越大；而逐向量量化的压缩率通常不随上下文长度改善。

从方法判断看，这篇论文的亮点主要在理论 framing，而不是工程细节已经闭环。它把“KV 是语言模型状态序列”这个事实推到了压缩目标的中心位置，这是对现有量化文献的一个有力反问。但也要看到，文中很多关键步骤依赖较强假设：例如模型能否稳定预测下一位置所有层的 KV，近似语义前缀共享是否会引入检索和误差控制成本，PLT 距离在真实 serving 系统里如何高效维护。这些问题决定了它更像一篇方向性论文，而不是已经成熟的部署方案。1a:T8e8,The proposed framework has two layers.

The first is probabilistic prefix deduplication. Standard prefix sharing only reuses KV cache when two requests have exactly the same token prefix. This paper proposes a softer notion: if two prefixes are close in the model’s probability space, they may be treated as semantically equivalent for caching purposes. The tool used here is the PLT (Probabilistic Language Trie) metric, which defines a probability-aware distance between token sequences. Instead of exact string identity, the criterion is whether two prefixes induce sufficiently similar predictive states under the model prior. The system then stores a shared centroid plus per-session deltas, aiming to remove inter-session redundancy beyond exact prefix matching.

The second is predictive delta coding. Within a single session, the cache does not store the raw KV vector at each position. It stores only the residual between the true KV and a model-based prediction of that KV from the preceding context. The central theoretical claim is that the entropy of this residual is upper-bounded by token-level surprisal, rather than by the marginal entropy of each vector component. Intuitively, if the model is already a strong predictor of the next token, it should also be a strong predictor of the next internal state, leaving only a small residual to encode.

A key design point is composability. The authors do not position sequential compression as a replacement for methods like TurboQuant, but as an orthogonal layer that can sit above or below per-vector quantization. They also claim better asymptotic behavior: as context grows, the conditional distribution sharpens and sequential compression should improve, whereas per-vector quantization has a largely fixed compression ratio.

The strongest part of the paper is the reframing. It puts the sequential nature of KV states at the center of the compression problem. The weaker part, at least from the provided text, is practical closure. Several assumptions are nontrivial: accurately predicting multi-layer KV states, maintaining approximate-prefix indices efficiently, and controlling the error introduced by probabilistic sharing.
