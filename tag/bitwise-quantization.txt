19:T5ed,UniAR is a single-tokenizer, autoregressive unified model.
1) Multi-level feature fusion tokenizer: it fuses features from multiple layers of a pretrained vision encoder so shallow layers contribute textures/colors while deeper layers contribute semantics, aiming to serve both discriminative and generative needs.
2) Lookup-free bitwise quantization: continuous features are mapped to binary vectors (e.g., 64-bit) without an explicit codebook. Discrete codes are defined by bit patterns rather than nearest-neighbor lookup in a learned codebook.
3) Parallel bitwise prediction over 2×2 grids: instead of predicting long per-pixel token sequences, it predicts multi-level binary vectors in parallel within each 2×2 spatial block, reducing AR sequence length and claiming ~32× visual compression.
4) DiT-based visual decoder with resolution upsampling: the decoder conditions only on visual tokens (no text prompt) and supports high-resolution reconstruction; the paper claims that 1024×1024 generation requires predicting only 256 visual tokens.
5) Training recipe: three stages (large-scale multimodal pretraining, SFT on curated data, RL for generation). The tokenizer and decoder are frozen throughout; the decoder is only used during RL to decode images for reward computation.
