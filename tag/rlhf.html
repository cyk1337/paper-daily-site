Rethinking Critic Learning in PPO: Understanding and Mitigating Value Flattening

这篇工作讨论 PPO 用在长链推理 LLM 时的一个 critic 失效模式：真实的状态价值会在回答中间位置发生明显变化，但 critic 预测往往过于平滑。作者把它称为 Value Flattening。问题不只是 value loss 拟合不准，而是 critic 没有捕捉“当前前缀已经让成功概率发生变化”的局部信号，导致 token-level advantage 失去细粒度信用分配能力。

评极其重要的 RLHF 机制分析，指出了 PPO Critic 在长序列下失效的根本原因（隐式方差惩罚+冗余更新），提出的 SP$^3$O 极其简单且易于在内部 RL pipeline 中复现，必读。
