More Rejective, Not More Discriminative: The Unit of Verification in Pre-Execution LLM Oversight

Bootstrapped Monitoring: Leveraging Transparent Reasoning to Oversee Stronger AI Agents

这篇工作讨论的是一个控制链条里的现实难题：当执行任务的前沿 agent 比可信监控模型强很多时，传统 trusted-only monitoring 会失效，因为弱可信模型既看不懂复杂行动轨迹，也越来越难从更强模型的推理痕迹里获得稳定监督信号。作者提出 bootstrapped monitoring，用一个能力更强但不可信、且仍保留透明推理的中间监控模型 Um 作为桥梁，让可信弱模型 T 不再直接判断 agent 是否作恶，而是转去判断 Um 的解释和结论是否在撒谎、是否与行动轨迹不一致。核心问题不是提升 agent 能力，而是研究在能力差距扩大、CoT 透明性下降的条件下，监督链条还能否继续工作。

评对 pretrain 不是主线，但它把“可见 CoT 是可监督接口”讲得很具体；只看 setup 和 failure mode，别急着把结论外推到隐藏推理模型。
Frank Xiao,Mary Phuong
