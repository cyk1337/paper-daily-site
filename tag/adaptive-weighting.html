Uncovering and Mitigating Aggregation-Induced Reward Hacking in Multi-Reward Reinforcement Learning

这篇工作研究的是多奖励 RL 微调里的一个结构性问题：把多个奖励维度用固定权重压成单一标量后，训练信号会丢失维度信息，导致策略过早学会“容易拿分”的维度，而长期忽略真正困难但更关键的维度。作者把这个现象定义为 aggregation-induced reward hacking，其中包含两个机制：profile aliasing，即不同奖励组合被映射成同一个标量；shortcut lock-in，即训练被稠密、容易、波动小的奖励牵着走，最后卡在次优行为模式里。

评多奖励 RL 的静态加权确实常被低估，建议只读故障定义和权重更新消融，看看能否复现到内部 RLVR。
Yu Yuan,Yaoyou Fan,Lili Zhao,Guangting Zheng,Kai Zhang,Lu Pan,Ke Zeng,Qi Liu

SCOPE: Signal-Calibrated On-Policy Distillation Enhancement with Dual-Path Adaptive Weighting

在推理对齐中，on-policy RL 的奖励稀疏（仅结果级正确/错误），导致 token 级信用分配困难、收敛慢。OPD 通过引入教师模型的 token 级 KL 监督缓解该问题，但现有 OPD 往往对所有 rollout 施加“同等强度”的蒸馏信号，忽视了不同轨迹上监督信号质量的巨大差异：错误轨迹上教师可能并不可靠；正确轨迹上强蒸馏会压制学生的有效多样推理路径并诱发 mode collapse。

评按轨迹“信号质量”自适应调蒸馏强度这点比又一版OPD更像真修bug；只看权重机制与对Pass@k/多样性的ablation，决定是否值得内部复现。
Binbin Zheng,Xing Ma,Yiheng Liang,Jingqing Ruan,Xiaoliang Fu,Kepeng Lin,Benchang Zhu,Ke Zeng,Xunliang Cai
