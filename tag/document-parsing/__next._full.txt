19:T4a5,Proposes PaDoc, a layout-grounded parallel document parser built on a region-sufficiency assumption: conditioned on the full page image and a region's layout specification, content generation for that region is independent of content from other regions. The joint parsing distribution is factorized into a serial layout prediction stream, and parallel content generation branches spawned immediately after each layout is predicted, reducing logical decoding depth from the sum of all region content lengths to the longest single layout-content path. During training, an ancestor attention mask restricts each content branch to attend only to the shared page image and historical layout prefix, with no access to sibling region content. This is implemented with packed variable-length sequences, requiring no auxiliary prediction heads or extra losses, and retaining the standard next-token prediction objective. During inference, PaDoc runs on vLLM with global shared KV cache for the page image and layout prefix, decoding each region content branch as a concurrent request. The first is Progressive Curriculum Loss, designed to stabilize deep look-ahead training. Instead of assigning a constant or hand-decayed weight to every prediction depth k at position t, the model uses an adaptive weight ω_{t,k}. This weight combines two constraints. The Sequential Confidence Constraint uses the softmax confidence of preceding look-ahead predictions to estimate whether the trajectory up to depth k is still trustworthy. If an earlier step is already uncertain or off-track, supervision for deeper predictions is down-weighted. This suppresses the classic failure mode where distal targets keep backpropagating through a path that has already collapsed. The Retrospective Target Constraint adds another filter based on consistency with the target trajectory, further reducing noisy supervision from unreliable deep predictions. Together, these terms create an implicit easy-to-hard curriculum: the model first learns stable short-horizon prediction and only gradually receives stronger supervision on deeper horizons.

The second component is Confidence-Gated Dynamic Drafting for inference. Standard MTP usually fixes the drafting depth K, but fixed K is suboptimal for document parsing because entropy varies sharply across layouts, tables, formulas, and plain text spans. P-MTP instead decides online how far to draft based on cumulative joint confidence. If the predicted path remains reliable, the model keeps extending the draft; if confidence drops below a threshold, it truncates early. This directly optimizes the useful quantity αK, where α is the acceptance rate, rather than maximizing K in isolation. The paper also keeps the MTP branch lightweight, using a shared module that recurrently produces multiple look-ahead predictions, so the extra overhead γ stays small enough for real wall-clock gains.
