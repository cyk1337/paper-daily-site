18:T44b,The analysis extends a latent-task view of ICL. When the target task is inside the pretrained task support, the paper studies several instruction structures, including fixed supported instructions, fixed unsupported instructions, mixed instructions, and per-demonstration varying instructions. The key statement is conditional: under a fixed model-induced reference extension, a fixed unsupported instruction contributes a bounded continuation cost, while informative demonstrations keep adding task evidence. With enough demonstrations, task identification can dominate the fixed instruction shift. In contrast, if every demonstration introduces its own off-support instruction shift, the shift cost can accumulate with the number of examples, and convergence depends on whether evidence grows faster than this accumulated cost. For unsupported target tasks, the paper does not assume direct posterior selection of a zero-prior task. It instead studies execution along a trajectory of supported subtasks and bounds final error by accumulated step-level errors through a pathwise Lipschitz argument.19:T5e9,No new architecture is proposed; instead the paper builds an analysis model. Data is assumed to arrive in groups (tasks), each task being generated by a sparse set of latent factors. Tasks share factors, and task similarity is modeled via latent-factor overlap (illustrated as a bipartite task–factor graph). Under this view, inference-time learning is modeled as: shared components are carried by internal representations of inputs/outputs, while the task-specific mapping between these representations must be learned at inference time by an inner learner.
From this setup, the paper argues for:
- Rich representation (“gather broadly”): if representations only capture what is minimally sufficient for iid generalization, many new tasks become unreachable; open-world adaptation needs a broader feature basis that supports recombination of latent factors.
- Predictive disentanglement (“group predictively”): beyond richness, representations should be partitioned into matched low-dimensional groups across inputs and outputs, and prediction should occur within aligned groups. This reduces the effective degrees of freedom the inner learner must fit for a new task, improving sample efficiency.
