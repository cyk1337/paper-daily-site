b:T426,A minimal Turing-complete tape automaton F (Brainfuck family, five instructions) is fixed, and all ~1.5 billion programs of length L≤13 are exhaustively enumerated under a bounded universal (Levin–Solomonoff) prior. Because enumeration is exact, the map from program behavior to prior mass is a sufficient statistic, and the posterior predictive for any few-shot context is computed in closed form. To remove output-polarity bias, F is complement-symmetrized into sF; each task is paired with its bitwise complement twin, on which the optimum scores identically, so the original-twin gap isolates the model's own inductive bias. Ground-truth certification uses GPU-accelerated enumeration, an independent pure-Python reference, and exact cross-checks (byte-for-byte agreement of per-output program counts, witness re-execution, bit-identical posterior agreement). Models are scored with a bounded symmetric divergence against the optimal posterior, summarized by a difficulty-aware score and facet profile across induction, continuation, and abduction tasks.c:T40a,The work has three parts. Second, it shows that Transformers can implement these classes in context. This is different from standard generalization. The focus is not only whether a rule transfers, but how examples are assigned to a common internal type in the first place.

When later evidence shows that H was too coarse, the model must perform shattering: refine the original shared type into more specific subtypes without destroying valid prior rules. To test this, the paper builds controlled exception-learning tasks with two exposure orders. In general-to-specific settings, the model first sees a broad rule and later receives exceptions; success requires shattering. In specific-to-general settings, the model first sees fine-grained cases and later benefits from forming a broader abstraction; success reflects lifting.

The study evaluates this across in-context learning, LoRA, and full fine-tuning. The paper also gives a gradient-alignment argument for why lifting is attractive during learning: if examples share positive cross-gradient interactions, a shared update direction is efficient, making a common latent structure more likely to emerge. This is not a mechanistic proof, but it ties the hypothesis to optimization dynamics in a meaningful way.10:T6f3,The paper has two parts: an explicit construction and a training-based validation. In the construction, the prompt contains N in-context examples from a simple linear regression problem plus a query input x, and the model must output the least-squares prediction. The architecture is deliberately tiny: an input linear map, two transformer blocks, a flatten layer, and an output linear map. Each block uses multi-head linear self-attention, layer normalization, and a residual connection. The central issue is how to realize the denominator in the least-squares formula. Products and sums over context examples are easy to obtain with linear attention, but the closed-form estimator also requires division by the sample variance. The authors build on earlier observations that layer normalization can approximate division, and arrange the input representation so that LN effectively performs the required normalization on selected channels. This yields a small circuit that approximates the closed-form least-squares predictor rather than an iterative optimizer.

The second part asks whether training actually finds this circuit. The authors train the same architecture to predict the least-squares target and add an L1 regularizer. The role of L1 is to bias learning toward a sparse, interpretable solution closer to the hand-designed construction, instead of one of many functionally equivalent but opaque parameterizations. They then compare the trained parameters with the theoretical construction and argue that the learned model mainly uses the closed-form computation rather than a gradient-descent-like procedure. This is the distinctive part of the paper: not just showing existence, but proposing an interpretable circuit and checking whether optimization recovers it.11:T416,The experiments are small and diagnostic.
