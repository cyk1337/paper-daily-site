Distributional Alignment as a Criterion for Designing Task Vectors in In-Context Learning

这篇工作讨论的是 ICL task vector 该如何评估、以及如何据此改进提取方法。已有 task vector 方法都试图把 demonstrations 对模型行为的影响压缩成一个隐藏状态方向或偏移量，再在 zero-shot 推理时注入进去，以减少长上下文 ICL 的推理成本。但过去主要只看下游准确率，这个指标太晚、太粗，既解释不了为什么某种提取方式更好，也很难指导方法设计。作者把问题重新表述为：如果 task vector 真的是 demonstrations 效应的压缩表示，那么用它做推理时，模型的 next-token 分布应尽量接近真实 ICL 的分布。核心问题因此变成如何定义这种分布对齐指标，并据此构造更好的 task vector。

评这篇不在于 LTV 本身，而在于把 task vector 评估从 accuracy 拉回 token distribution；若你关心 ICL 压缩，只看 d_NTP 定义和相关性图就够了。
