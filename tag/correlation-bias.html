Beyond Memory Majority: Latent-Source Reasoning for Multi-Agent Memory Arbitration

这篇工作讨论的是长时程 multi-agent 系统里的 memory arbitration，但它解决的问题更偏 agent memory，而不是 LLM 基座训练。作者指出，现有方法通常把检索到的多条 memory 当成独立证据，通过投票或加权来决定答案；问题在于，不同 agent 写下的 memory 可能来自同一个上游事实源、共享同一偏差，或者只是彼此转述，于是系统把相关证据重复计数，形成 false majority。论文把这个现象定义为 Memory Correlation Bias。核心问题因此不是“如何检索更多 memory”，而是“如何按有效独立证据源而不是表面条目数做仲裁，并在必要时补回缺失的独立证据”。

评对多智能体协作中的“信息茧房/回音室”效应进行了形式化建模（Memory Correlation Bias），其解耦相关证据的思路对设计更鲁棒的 Multi-Agent 架构有启发。
Chenchen Lin,Wenhao Yuan,Xuehe Wang,Edith Cheuk Han Ngai
