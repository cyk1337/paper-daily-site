SpecRoll: Fast-Slow Verifier-Feedback Adaptation for Speculative Reinforcement Learning Rollouts

这篇工作处理的是 RL post-training 里一个很具体但很关键的瓶颈：GRPO 这类 group-based RL 需要反复生成长 rollout，而 rollout 生成仍是逐 token 的主耗时。把 speculative decoding 直接搬到 RL 里并不顺，因为 target policy 在训练中持续漂移，静态 drafter 很快过时；如果像 FastGRPO 那样在线训练一个独立 drafter，又会引入额外反向传播、优化器状态、同步和 KV cache 成本。论文要解决的核心问题，是在不改变目标采样分布、不过多增加训练系统复杂度的前提下，让 speculative rollout 能适应 RL 中的非平稳策略，并在 wall-clock 上稳定提速。

评RL训练rollout加速的实用方案，重点看Reflex模块的无反向传播隐状态修正设计，可直接复现到内部RLHF pipeline

EfficientRollout: System-Aware Self-Speculative Decoding for RL Rollouts

这篇论文解决的是 on-policy RL 训练中的 rollout 生成延迟问题。常规自回归采样必须逐 token 解码，长回答和尾部样本会拖慢整个 batch；但直接把 serving 场景的 speculative decoding 搬到 RL rollout 中并不稳定，因为目标 policy 在训练中持续变化，固定 drafter 会过期，同时大 batch 初期往往处在 compute-bound 区间， speculative verification 可能反而变慢。

Accelerating RL Post-Training Rollouts via System-Integrated Speculative Decoding

RL 后训练的主要耗时正在从反向传播转向 rollout 生成。论文关心的是：能否把 speculative decoding 作为一种不改变采样分布的系统原语，接入真实 RL 训练循环，而不是只在静态推理服务里做加速。
