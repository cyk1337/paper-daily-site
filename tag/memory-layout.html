Physically Partitioned KVCache Format for CPU--GPU Load Balancing in MoE Inference

这篇工作处理的是单卡 MoE 长上下文推理里一个很具体但长期被数据结构掩盖的问题：当 KV cache 被迫溢出到 CPU 内存后，同一份 spilled KV 同时服务两种互相冲突的使用方式——要么搬回 GPU 做 attention，要么直接在 CPU 上原地计算。前者要求 pinned 且逻辑连续，后者更适合 unpinned 且按 head 友好的布局。现有 KV cache 抽象把 cache 当成单一物体，只提供存取语义，不表达“哪些字节未来归 CPU 算，哪些字节未来归 GPU 载入”，于是任何动态 CPU/GPU 负载均衡都要靠事后重排、复制和辅助 buffer，开销会随着上下文长度迅速放大。在 MoE 场景里，这个问题更尖锐，因为 FFN 阶段本身就要占用 CPU 和 PCIe 去处理 spilled experts，原本 dense 模型里常见的 attention/FFN overlap 不再免费，GPU-centric 和 CPU-centric 两条路线都会在长上下文下暴露单侧瓶颈。

评值得只读系统设计与评测：核心 insight 是“写入时定物理驻留，把搬运问题改成调度问题”；先看 layout 图和吞吐-延迟曲线，别被特定硬件/实现绑架。
Enda Yu,Dezun Dong,Xiangke Liao
