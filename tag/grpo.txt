18:T6cd,The method has two layers. First, a diagnostic framework. In each trajectory, the agent retrieves candidate pages, inspects page images, writes source-linked findings into working memory, and finally outputs both a final answer and terminal memory. A frozen reader then sees only the question plus terminal memory and produces a memory-only answer. An official judge scores both the final answer and the memory-only answer against the gold answer, yielding binary indicators for answer correctness and memory answerability. This produces a four-cell analysis, with special attention to P_mmc, the fraction of answer-correct cases whose terminal memory is still not answerable. The key design choice is that memory quality is defined functionally—whether it preserves enough information for answering—rather than stylistically.

Second, the training algorithm AWM-GRPO. All compared agent variants share the same Qwen3-VL-4B policy, retrieval harness, tools, memory schema, prompts, and optimizer; only post-training and reward differ. For each sampled trajectory, the policy emits a final answer and terminal memory; the frozen reader answers from memory alone; the judge scores both outputs. GRPO then ranks trajectories using not only final-answer correctness but also memory-only answerability, preferring trajectories that both solve the task and leave behind answerable memory. This differs from answer-only GRPO, which optimizes the end result but is indifferent to the quality of the stored state. It also differs from direct memory supervision: instead of imitating a gold summary, the method supervises memory indirectly through its ability to support answering, which is closer to the actual role memory plays in an agent loop.19:T57a,The experimental setup is carefully controlled. The AWM-Agent variants use the same 4B backbone, the same RAG Top-3 retrieval harness, the same tools, and the same memory schema, so the observed differences are attributable to training signals rather than system changes. The paper first establishes the diagnostic gap: on a fixed 500-example answerable subset of MMLongBench-Doc, even under an evidence-page-given setting where gold evidence pages are supplied, 42.5% of correctly answered examples still fall into MMC. That is an important result because it shows the problem is not merely retrieval failure; it is failure to write sufficiently specific evidence into memory.

On end-task performance, AWM-GRPO outperforms RAG Top-3 by 8.1 points on MMLongBench-Doc and 11.9 on LongDocURL, beats SFT by 4.7 and 4.4 points, and improves over answer-only GRPO by 2.3 and 2.7 points. The paper also reports memory-quality diagnostics: on MMLongBench-Doc, AWM-GRPO reduces the memory-missing-correct rate by 2.7 points relative to answer-only GRPO. That matters because it shows the gain is not just a stronger answer policy; terminal memory itself becomes more usable. A controlled memory comparison further shows that replacing terminal memory with more complete, question-specific memory improves reader performance, which supports the causal motivation behind optimizing the memory artifact directly.1a:T460,For a quick pass, focus on three parts. First, read the introduction and the section defining memory-only answerability and MMC. That is where the paper’s real contribution sits: it adds a missing evaluation axis rather than merely proposing another agent. Second, inspect the AWM-GRPO training loop and pay attention to the division of labor between the frozen reader and the official judge. The important question is why the authors supervise memory through answerability instead of direct text matching. Third, read the diagnostic results, especially the evidence-page-given analysis and the four-cell breakdown, because those results justify the whole method.

If time is limited, a good order is Figure 1 and Table 1, then the diagnostic section, then the main results table, and finally the reward details. Around 20–30 minutes should be enough for the main idea. The deeper questions worth thinking about are whether reader/judge bias can distort the reward, and how easily this framework transfers to text-only agents, coding agents, or long-context summarizers where intermediate state quality also matters.1b:Ta1d,方法叫 BPCO（Best-Practice Critic Optimization）。它由五个关键部件组成。

第一，用 DPPO 替代标准 PPO clipping。标准 PPO 用概率比值裁剪，低概率 token 的微小绝对变化也可能触发 clipping，而高概率 token 可以承受更大的绝对变化；在大词表 LM 中，这会让不同 token 的更新几何很不均匀。DPPO 把约束改成 sampled token 概率的绝对变化上界，相当于让每个被采样 token 共享同一 absolute-probability trust region，更适合语言模型的长尾词分布。

第二，把 critic 输出限制在 reward range 内。论文考虑的是 outcome reward，回报天然有已知范围。若 value head 仍是无界线性层，训练早期很容易出现超范围预测，随后 GAE 和 value loss 都会被放大。作者将 value prediction bounded 到 reward 支持集，使 critic 的函数类与任务先验一致，减少无意义外推。

第三，critic 直接拟合 Monte Carlo return，而不是常见的 bootstrap target。由于中间 reward 全为 0、终局才给分，且 γ=1 的设置很常见，此时用 bootstrap target 的收益并不大，却会把旧 critic 的误差传播到新 critic。BPCO 直接用观测到的最终回报训练 value，相当于在 outcome-only 场景里主动放弃一部分低方差，换取更少偏差和更稳定的 critic 学习。

第四，policy update 不做 batch-wise advantage normalization。作者的论点很直接：当策略逐渐收敛时，真实 advantage 的尺度本来就应该变小；若每个 batch 都强行归一到单位方差，就等于持续放大残余噪声，容易造成后期训练抖动甚至过更新。BPCO 保留 raw advantage scale，让优化器看到“信号正在衰减”这件事。

第五，使用 length-adaptive GAE。固定 λ 在短回答和长回答上对应的 terminal reward 传播形状不同，导致 credit assignment 随长度系统性偏移。作者设计按 response length 调整的 λ，使不同长度样本上终局奖励向前传播的权重分布更一致。

除此之外，论文还强调一个 critic-only 的额外自由度：privileged critic input。因为 critic 只在训练时使用，可以额外看到 reward-defining information，例如数学题参考答案、官方解、或开放式任务的 rubric，而 policy 仍只看原始 prompt。这样不会改变最优 value function 的定义，但会显著降低 value approximation 难度。这个点和传统 RLHF/GRPO 的差别很大：group-relative estimator 很难自然利用这类只在训练时可见的信息。1c:T7b2,实验分三层。

First, it replaces standard PPO clipping with DPPO. Standard PPO clips the probability ratio, which means low-probability sampled tokens can be clipped by tiny absolute probability changes while high-probability tokens tolerate much larger ones. In large-vocabulary language models, this creates uneven update geometry. DPPO instead clips the absolute probability change of the sampled token, giving a common absolute-probability trust region.

Second, it bounds value predictions to the reward range. In outcome-reward settings, the return support is known. An unconstrained linear value head can easily overshoot that range, especially early in training, which then destabilizes both value fitting and downstream advantage estimates. Bounding the value head injects a simple but strong task prior.

Third, it trains the critic on Monte Carlo returns rather than bootstrapped targets. Because intermediate rewards are zero and the terminal reward carries the whole signal, the variance reduction from bootstrapping is limited while the bias from critic self-reinforcement can be severe. BPCO therefore prefers direct supervision from observed outcomes.

Fourth, it removes batch-wise advantage normalization in the policy update. The argument is that as the policy improves, the residual advantage scale should naturally shrink. Forcing every batch to unit scale erases that information and can keep magnifying noise late in training. BPCO preserves the raw advantage magnitude.

Fifth, it introduces length-adaptive GAE. With a fixed lambda, terminal reward is propagated backward with a length-dependent profile, so short and long responses receive systematically different credit assignment. The adaptive schedule is designed to make the effective weighting of terminal reward more consistent across response lengths.

Since the critic is discarded at inference time, it can condition on reward-defining information unavailable to the policy, such as a reference answer, official solution, or grading rubric. Training uses a DAPO-style GRPO objective without KL penalty. Each run uses 500 steps, learning rate 1e-6, 64 prompts per step, and 8 rollouts per prompt. Rewards consist of a binary correctness reward plus two auxiliary rewards, each weighted at half of correctness: a format reward and a reasoning-language reward. The reasoning-language reward is instantiated either as English reasoning or native-language reasoning. A key implementation detail is that auxiliary rewards are only granted when the final answer is correct, which prevents the model from gaming language or format rewards at the expense of solving the problem. The paper notes that preliminary runs in low-resource languages could otherwise collapse or overfit to formatting.

缓解方法是 Rubric Dropout。训练时对每个 prompt 的 rubric，随机丢弃一部分 criterion，再用剩余 criterion 计算 reward。这样策略在不同 step 面对的是不断变化的子 rubric，无法稳定利用某个固定 criterion，尤其是那些跨 prompt 重复出现的模板化 criterion，比如“结构清晰”“语言明确”。这个设计的优点是简单：只改 reward function 一行，不增加 judge 调用次数，只有一个超参数 f，即 dropout fraction。

关键实现点在于和 GRPO 的兼容。GRPO 依赖同一 prompt 的多条 rollout 之间 reward 可比较。如果每条 rollout 用不同子 rubric，group-relative advantage 就会被污染。作者因此采用 group-shared masking：同一个 rollout group 共享一张 dropout mask。附录里给出推导，说明在这种设置下 reward normalizer 会在 advantage 中抵消；在 group standardization 之前，dropout 主要表现为对期望 advantage 的缩放，以及对依赖单一 criterion 的更新起到方差正则作用。这个解释很重要，因为它说明 Rubric Dropout 不是在“加噪声碰碰运气”，而是在系统性削弱对单一可利用 criterion 的过拟合。

作者还把 Rubric Dropout 与 POW3R 风格的 criterion reweighting 做了对比。后者试图按训练 usefulness 重加权 criterion，但在这里反而更容易把优化压力集中到少数可利用 criterion 上，因此可能加剧 hacking。全文实验也支持这一点。32:T866,The method has two parts: an in-loop measurement protocol and a mitigation.

For measurement, every 20 training steps the model is evaluated on an OOD benchmark using two judges: the training-time proxy judge and a stronger gold judge from a different family. The cross-family choice is important because it reduces the chance that the observed gap is just shared bias. If the proxy judge were merely biased, the gold curve would be shifted but not necessarily turn downward while the proxy keeps improving. The paper uses two independent train-to-eval pairs: RubricHub-Medical to HealthBench-Hard, and RubricHub-Science to ResearchQA.

The mitigation is Rubric Dropout. At each training step, a random fraction f of the rubric criteria is dropped before computing reward. The policy therefore never sees exactly the same rubric twice, which makes it harder to exploit any fixed criterion, especially generic templates repeated across prompts such as “well-organized” or “clear language.” The appeal is operational simplicity: one line in the reward function, one hyperparameter, and no extra judge calls.

The crucial systems detail is GRPO compatibility. In GRPO, multiple rollouts for the same prompt must be scored on a comparable basis. If each rollout were graded with a different sub-rubric, the group-relative advantage would be corrupted. The paper solves this with group-shared masking: one dropout mask per rollout group. The appendix shows that under this scheme the reward normalizer cancels out of the advantage, and before group standardization the main effect of dropout is to rescale expected advantage while acting as a variance regularizer against updates that rely too heavily on any single criterion. That makes the method more than just noise injection; it is a targeted way to reduce overfitting to exploitable proxy features.

The paper also compares Rubric Dropout with POW3R-style criterion reweighting. The argument is that reweighting can inadvertently concentrate optimization pressure on a smaller set of exploitable criteria, which may worsen hacking rather than reduce it. That is strong evidence that the standard rubric-RL recipe can over-optimize the proxy out of distribution.
