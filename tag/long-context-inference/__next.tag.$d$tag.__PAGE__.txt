First, the method is training-free: no finetuning, no memory tokens, no modified attention pattern, no learned compression. Second, past information remains uncompressed in the cache, so long-range retrieval still relies on content-based addressing rather than summary vectors. Third, the method occupies a different point from streaming approaches: it accepts linearly growing cache in exchange for preserving access to the full history.
