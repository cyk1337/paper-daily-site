9:T572,MoHGE combines architectural, routing, and systems ideas. First, experts are partitioned into groups; experts within the same group share the same size, while different groups have different hidden dimensions. This creates a tiered capacity structure, where smaller groups can handle easier patterns and larger groups can absorb harder contexts. Second, routing is hierarchical. A group-level gate first selects the top candidate groups, and an expert-level gate then chooses experts within those groups. This is better aligned with heterogeneous capacity than a single flat gate over all experts, because the model first decides how much capacity to use and only then which expert instance to activate. Third, the paper introduces two balancing losses. The Group-Wise Auxiliary Loss regulates how often different capacity groups are selected, aiming for a better match between token complexity and expert size while avoiding collapse to a single group. The Intra-Group Experts Auxiliary Loss balances usage among experts inside each group. On the systems side, the All-size Group-decoupling Allocation strategy spreads experts from every group across all GPUs, instead of concentrating large experts on a subset of devices.
