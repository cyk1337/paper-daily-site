TreeWY: Speculative Verification for Gated DeltaNet Hybrids

TreeWY 解决的是混合架构模型在 speculative decoding 中的 Gated DeltaNet 回滚问题。GDN 层不像 softmax attention 那样保留逐 token KV cache，而是把前缀压到固定大小的 recurrent state 里。普通解码时这很省内存，但验证 draft token 或 draft tree 时，系统需要回滚到被接受节点的状态。现有做法通常为每个 draft 位置保存完整 recurrent state，树状 draft 又无法共享这些快照，导致验证阶段的瞬时显存随 draft 节点数快速增长。

评只看推导和内存模型；若团队押注 DeltaNet/线性注意力混合模型，TreeWY 值得做一次内部复现。
