17:T465,Architecture: a Looped Transformer that reuses the same Transformer stack for multiple passes over the hidden states. The paper emphasizes a two-pass configuration as the best trade-off.
Training findings:
- Training from scratch with the looped architecture outperforms upcycling (pretrain standard → convert to loop), suggesting representations should adapt to layer reuse early in pretraining.
- Increasing the number of passes yields diminishing returns while slowing training and hurting stability.
- KV-cache sharing across passes halves cache memory but reduces performance gains; they keep the full non-sharing loop.
Pretraining: 28T tokens from scratch; the data mixture increases math/code/synthetic QA weights (exact ratios/filters need verification in the full data section).
Post-training (dominant part): executable trajectory SFT from a hybrid pool of real + synthesized environments with execution/rubric filtering; multi-stage RL including mixed-mode RLHF over Think/Non-Think, length-controlled reasoning RL, and agentic RL with outcome + process rewards for denser credit assignment in long trajectories.18:T503,Index-1.9B is a Llama-style decoder-only Transformer with RoPE, SwiGLU, and RMSNorm. The authors choose a relatively deep 36-layer configuration after a depth-versus-width study at fixed parameter count. The base model has 1.9B non-embedding parameters and is trained on 2.8T tokens, with a Chinese-to-English ratio of about 4:5, 6% code, and roughly 10% curated books, encyclopedias, papers, and STEM material. A Warmup-Stable-Decay schedule is used, and the curated subset is upweighted during the decay phase. Data cleaning relies mainly on heuristic rules; classifiers are used conservatively for hard cases, with labels bootstrapped from a larger Index-Large model. Deduplication combines Spark-based global MinHash with exact substring duplicate detection based on suffix-array tooling, allowing repeated spans at arbitrary positions inside documents to be found. The tokenizer is a compact 65,029-token SentencePiece BPE tokenizer. Chinese vocabulary is trained separately with a shorter maximum piece length, the vocabulary is kept small to reduce embedding overhead, and the usual Llama-style prepended whitespace is removed. The report also identifies unusually large LM-head gradients and rare-token oscillation as stability issues, then compares stabilization mechanisms.19:T432,Three main components:
1) Execution Subagent interface: the main agent delegates terminal work to a subagent with only a Terminal tool, a turn budget, and a system prompt enforcing structured summaries. The design choice is to isolate verbose intermediate outputs rather than forcing the main agent to ingest them.
2) Terminus-4B: Qwen3-4B post-trained for this role. Stage-1 SFT on internal telemetry trajectories teaches command selection, error interpretation, and summary formatting.
3) RL with GRPO plus a subagent-centric rollout framework: rollouts are constructed so each candidate starts from the same problem state while minimizing reliance on a strong main agent (they even use vanilla Qwen3-4B as the main agent during rollouts). Rewards come from a rubric-based LLM judge that scores candidates against reference trajectories across multiple quality/failure dimensions (e.g., capturing the key error lines, avoiding vague or hallucinated summaries, not getting stuck in unproductive command loops), yielding denser training signals than success/failure rewards.1a:T6bc,1) SeqCond Attention (SCA): represent the prefix embeddings as samples from a discrete random variable X and summarize the prefix via the empirical characteristic function φX(θ)=E[e^{i⟨θ,X⟩}]. Instead of φX itself, SCA maintains its spectral gradient ∇θφX, argued to be more informative since X enters multiplicatively.
2) Readout: the current token produces a spectral query wt(θ); the layer output is a complex Hermitian inner product between wt and the prefix summary S1:t(θ), acting like “querying a compressed spectral memory” rather than a KV list.
3) Expressiveness: in the continuous/integral limit, they construct queries that can exactly retrieve any individual past token from the summary (Theorem 1), extend to recovering weighted distributions, and show softmax attention as a special case (Corollary 4). The guarantees rely on Fourier inversion in a distributional sense; practical performance depends on discretization (finite learned spectral points) and approximation error.
4) Hybrid stack: a 24-layer decoder-only model interleaving 16 SCA layers with 8 standard Transformer blocks (pre-norm, RoPE, GQA). The design intent is that most tokens only need incremental state updates (handled by SCA), while occasional global competition/routing is handled by attention.
5) Training: pretrain on 350B FineWeb-Edu + 250B SYNTH tokens plus additional SYNTH-style CoT/instruction distillation from multiple teachers. Post-train with RL; they report a GRPO failure mode for small models at low success rates and propose (i) gradient-balanced GRPO that rescales negative-advantage gradients, and (ii) scored
