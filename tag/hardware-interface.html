Previewing the Model Hardware Standard

MHS 解决的是 AI agent 操作真实实验室和制造设备时缺少统一硬件接口的问题。现有设备通常有各自的驱动、厂商软件和隐性操作知识，导致多设备编排需要大量定制集成，也难以把安全边界和设备语义稳定暴露给模型。

评如果你做 tool-use/embodied agent，知道 MHS 这件事有必要；但它不是训练方法论文，读标准边界定义即可，不必深挖。
