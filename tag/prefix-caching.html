A Policy-Driven Runtime Layer for Agentic LLM Serving

这篇工作讨论的是 agentic LLM serving 的系统分层问题：现有两层栈里，上层 agent framework 知道 agent 身份、角色和调度图，下层 serving engine 知道请求到达、KV block 访问、batching 和延迟事件，但很多真正影响成本和时延的策略需要同时看到这两类信息。作者认为这不是某个缓存算法的小修小补，而是架构缺了一层，导致 prefix caching、batch shaping、speculative execution、fairness、tool-result memoization 等策略都只能靠临时 patch。

评读架构图和九个 policy mapping；性能数字缺失时别过度买账，但这个系统边界是对的。
