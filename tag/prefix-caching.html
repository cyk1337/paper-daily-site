CacheRoute: Planned Prefix-Affinity Routing for Large-Scale LLM Serving

在大规模 LLM serving 中，prefix KV-cache 只有在“相同前缀的请求回到仍持有该前缀的同一目的地”时才省掉 prefill。常规的 cache-blind 负载均衡会把同一前缀打散到多台机器，导致回访间隔变长、前缀变冷；而固定 affinity（例如一致性哈希）虽然保住局部性，却把 key 的流量偏斜直接映射成单机排队，p99 被最热目的地拖垮。论文要解决的是：在多租户、强 key-skew、且每个 key 有可复用上下文的真实工作负载下，如何同时获得高 KV 命中率与可控的尾延迟/容量。

评不是 pretrain 论文，但把“KV 命中率高就一定更快”这个直觉讲得更干净；看反例 workload 和何时关闭 affinity 的判据，比主结果更值钱。
Huang Cheng

A Policy-Driven Runtime Layer for Agentic LLM Serving
