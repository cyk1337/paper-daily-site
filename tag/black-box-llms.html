Measuring Black-Box Confidence via Reasoning Trajectories: Geometry, Coverage, and Verbalization

论文要解决的是黑盒 CoT 推理的置信度估计问题：只有文本 API 输出，没有 logits、hidden states 或检索证据时，怎样用更少采样次数判断一次推理是否可靠。常见的 self-consistency 依赖多次采样投票，成本随 K 线性增长，而且只看最终答案分布，忽略了推理轨迹在语义空间中是否逐步靠近某个候选答案。

评通过分析CoT轨迹的几何收敛性来估计黑盒模型置信度，视角新颖，对理解CoT推理过程和设计更好的解码策略有启发。
Marc Boubnovski Martell,Josefa Lia Stoisser,Kaspar Märtens,Jialin Yu,Robert Kitchen,Philip Torr,Jesper Ferkinghoff-Borg
