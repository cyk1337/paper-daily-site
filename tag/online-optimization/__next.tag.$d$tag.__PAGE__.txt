9:T43b,OP-Mix combines on-policy domain adapters with linear adapter interpolation. For each data domain, the method trains one LoRA adapter starting from the current model. This adapter approximates the update direction induced by training on that domain at the model’s current state. Candidate mixtures are then simulated by linearly interpolating these domain LoRAs, using the interpolated adapter as a proxy for the loss surface under full mixture training. A user-defined objective aggregates evaluation metrics, with maximization metrics negated so that mixture search can be posed as minimization. Compared with proxy scaling-law approaches that train many smaller models on sampled mixtures, OP-Mix needs only one adapter per domain and stays on-policy with the model being trained. When a new domain is introduced, the algorithm trains another domain adapter and refits the mixture, instead of rebuilding the whole proxy-model grid.
