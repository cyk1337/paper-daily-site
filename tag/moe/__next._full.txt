1b:T523,Analysis is performed in the frozen-weight, single-forward-pass setting that matches real same-weight self-distillation workflows. An exact blockwise output decomposition is derived, splitting output differences between teacher and student passes at each MoE block into two exactly additive terms: the routing mismatch term (output difference from applying different gate values to identical hidden states), and the dense-like content term (output difference from shifted hidden states applied to identical gates, the same type of content shift that appears in dense models). Three per-token, per-layer metrics are defined: routing factor (norm of the routing mismatch term as a share of MoE block output), backbone share (norm of MoE block output as a share of residual stream), and residual exposure (norm of the routing mismatch term as a share of residual stream, equal to routing factor multiplied by backbone share), which represents the effective magnitude of routing mismatch visible to all downstream layers. Systematic measurements are run across 7 open-weight MoE checkpoints spanning two domains, causal relationships are validated via interventions that scale the weight of always-on shared experts, and causal A/B patching is used to directly connect the two decomposed terms to final output behavior.1c:T7e9,Palmyra x6 keeps the GLM-5.2 GlmMoeDsa architecture unchanged and fine-tunes the weights. The inherited base has 744B total parameters and about 40B active parameters per token. It combines sparse MoE feed-forward layers, Multi-head Latent Attention, a DeepSeek Sparse Attention indexer, DSA IndexShare, rotary embeddings, and a next-n multi-token prediction head. IndexShare is not just an implementation detail: serving requires an inference stack that can reuse sparse-attention selected indices across layers.

The training set consists entirely of synthetic agent/tool-use trajectories. Prompts come from internal Writer subject-matter experts and some external task suites. The six broad categories are financial research with search, data analysis and coding, clinical/medical agent tasks, MCP tool suites, long-horizon multi-tool simulated environments, and RAG over realistic document collections.

The data pipeline adapts self-distillation fine-tuning to multi-turn tool use. A successful reference trajectory is converted into a sanitized strategy demonstration. It preserves the reasoning outline and tool order, but removes the final answer, masks numbers and dates, and hides tool-call arguments. The student then receives this strategy in its system prompt and must solve the task again using live tools. A verifier checks the result against the reference answer, while a cheating filter rejects rollouts that exploit the demonstration instead of actually using tools.

Training uses Anchored SFT rather than plain SFT. The motivation is to reduce the mismatch introduced by supervising the model on trajectories it would not naturally produce. The recipe search compared 12 SFT and ASFT runs over objectives, KL anchor strengths, learning rates, epochs, and six data recipes. The selected recipe is ASFT with KL weight K=0.1 on a 12-dataset primary mix. The final Palmyra x6 run keeps the objective and data fixed, changes the base model, and switches the optimizer for 2-D weight matrices from Adam to Muon.1d:T412,The experimental design tries to keep causal attribution clean. The recipe-development phase runs a 12-run matrix covering SFT versus ASFT, KL weight, learning rate, epoch count, and data mixture. The final model changes only two controlled factors relative to the chosen recipe: the base model and the optimizer.

The report gives concrete rollout constraints for data generation: up to 30 turns per trajectory, temperature 1.0, top-p 0.95, a 50,000-token generation cap, and up to 6 attempts per task. The first turn must call a tool. A trajectory is abandoned if it exceeds 20 tool calls, 4 consecutive calls to the same tool, 3 tool errors, or 3 identical repeated calls.

Public benchmarks are treated as sanity checks; the primary selection signal comes from internal enterprise-style evaluations.1e:T40e,The central move is to replace an answer contrast with a condition contrast. Standard contrastive activation addition often compares conforming and nonconforming forced answers under the same nudged prompt. That direction can mix sycophancy with answer identity and option-position artifacts. THESIS-MoE instead builds matched nudged and no-nudge prompts for the same question. Holding the forced answer fixed, it compares activations with and without the user’s stated belief. The resulting difference estimates a belief-induced shift. The paper then defines a continuous signed belief-push metric and uses it to localize the shift along an MoE granularity ladder: full attention blocks, MoE blocks, individual heads, and individual experts. For intervention, it compares fixed unconditional subtraction, analytic conditional subtraction, and learned conditional gating. Matched bundles are split by item identifier into train, development, and test splits. Diagnostic prompts are used for behavior measurement, while forced-answer prompts are used to estimate directions and train learned gates. The paper reports results on three open-weight MoE models and three seeds. Fixed subtraction reduces sycophancy but consistently creates a removal-retention trade-off across granularities. The provided full-content excerpt does not include exact model names, parameter counts, or benchmark deltas.20:T427,FreeBalance performs pre-routing online balancing through residual workload prediction. The key observation is that the input to an MoE router can be approximated well enough from the residual representation produced by the preceding layer. So, before the current router executes, the system feeds that residual into the corresponding router to obtain a lightweight prediction of the upcoming expert workload. This prediction is used only for scheduling, not for model execution. Based on the predicted load, FreeBalance adjusts expert-device mapping and starts expert-weight migration immediately, overlapping migration with pre-routing computation stages, especially attention. To avoid over-migration, the method includes a cost model that limits how many experts can be moved given the available overlap window. In other words, it does constrained balancing rather than chasing the most even load at any cost. The route-mediated fraction, RMF, is defined as a ratio of sums rather than an average of per-sequence ratios. Specifically, excess_total = L(Y_QF) - L(Y_CC), excess_compute = L(Y_QP) - L(Y_CC), excess_route = excess_total - excess_compute, and RMF = sum(excess_route) / sum(excess_total). The token-level attribution is also well designed. For each decoded token, the top-k route set is recorded at every layer under clean and quantized compute. If the scoring layer’s route set changes, the token is labeled jump. If the scoring layer is unchanged but some upstream layer changed, it is labeled nonlocal. Otherwise it is pure flux. This partition lets the authors separate direct local route flips from upstream route perturbations that propagate through later representations, and from route-weight changes that do not alter the selected set.
