ADWIN: Adaptive Windows for Horizon-Aware On-Policy Distillation

标准同策略蒸馏（OPD）需要基于学生生成的完整轨迹执行参数更新，存在两个核心缺陷：一是每次更新都被完整轨迹的生成阻塞，训练效率低；二是学生自回归生成的轨迹后半段往往偏离教师偏好的合理分布，后半段的监督信号边际价值很低，甚至会引入噪声。

评ADWIN在OPD中引入自适应滚动窗口的思路对优化RL训练计算效率有实际启发，建议看核心方法§3和实验对比图表。

BPPO: Binary Prefix Policy Optimization for Efficient GRPO-Style Reasoning RL with Concise Responses

BPPO 研究 GRPO 式 reasoning RL 中是否需要对同一 prompt 下的所有 completion 都做策略更新，并提出只更新最短正确样本和最短错误样本的 prefix 来降低训练成本和响应长度。

评读梯度相似性分析和长度分布即可；若实验干净，它会影响 GRPO 采样预算怎么花，而不是只调超参。
