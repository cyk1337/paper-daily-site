Designing Transformers for Continuous Diffusion Language Models

这篇论文要解决的问题很明确：连续扩散语言模型（continuous diffusion language models, CDLMs）的研究近两年主要在生成过程、表示空间、训练目标上推进，但承担实际去噪计算的 Transformer backbone 设计并没有被系统研究。很多工作直接沿用 causal LLM 或图像 DiT 的架构习惯，而这两类模型的归纳偏置都不完全适合 CDLM。CDLM 既要从噪声连续状态中恢复离散 token，又要在不同噪声水平下稳定调制网络计算，还常常要处理 self-conditioning 和 codebook / vocabulary interface 的梯度路径。作者的问题不是“再提一个 diffusion LM”，而是更基础的：在固定 CDLM 公式、固定训练目标、固定采样器的前提下，什么样的 Transformer 设计更适合连续语言生成。

评这篇该读，因为它不是又一个 diffusion LM 报分，而是在问 CDLM 的 backbone 应该长什么样；先看架构 ablation，尤其 normalization 和 self-conditioning 两块。

Improving Few-Step Language Flows with Untied Self-Conditioning

这篇论文解决的是 few-step flow-based language model 在采样步数很少时质量急剧下滑的问题，而且作者把原因定位得很具体：不是简单的“步数少所以误差大”，而是 previous-prediction self-conditioning 在训练和推理之间存在一个被忽视的结构性失配。训练时，自条件输入 m 是从当前 noisy state 直接做一次 detached 预测得到，中间没有 solver 更新；推理时，上一时刻预测 p_{k-1} 一方面已经被 solver 折叠进新的 latent，另一方面又作为显式 self-conditioning 输入再次送入模型。于是 latent 通道和 self-conditioning 通道之间出现训练中不存在的耦合与冗余，而且步长越大，这个问题越严重。作者进一步指出，这个失配同时伤害了两件事：self-conditioning 输入本身的信息增益，以及 solver update 对一步内平均预测的近似质量。

评应立刻看方法和少步 ablation；它把 flow LM 的质量问题定位到 solver/self-conditioning 耦合，而不是泛泛调采样器。
Bocheng Li,Linli Xu

Low Perplexity is Repetition: A One-Dimensional Self-Conditioning Attractor in Continuous Diffusion LMs

这篇工作处理的是一个被主流指标掩盖的连续 diffusion language model 失真问题：带 self-conditioning 的连续 DLM 在采样时会进入强重复的循环状态，而社区常用的 Gen-PPL 不但没有识别这个问题，反而会因为重复文本在外部 AR scorer 下概率更高而给出更低分。论文不是停留在“样本看起来重复”这一层，而是把问题定位到 self-conditioning 反馈回路的动力学：模型每一步把上一步的 clean estimate 再喂回去，形成一个收缩系统；在 ELF 这类模型里，这个系统沿某一个主方向存在一个近似一维的 contractive attractor，轨迹一旦被吸进去，就会朝着高度自预测、也就是高度重复的状态收敛。核心问题因此有两层：一是评价失真，二是训练后推理动力学中的结构性退化。

评必须读：它会改变对 diffusion LM 指标的 prior，Gen-PPL 低不够用，应复现重复剥离和 ACE 方向分析。

Simple Self-Conditioning Adaptation for Masked Diffusion Models

这篇工作解决的是 masked diffusion language modeling 里的一个具体但关键的训练—采样错位：标准吸收式 masked diffusion 在每一步都会预测当前位置的 clean token 分布，但如果该位置在 reverse update 后仍保持 masked，模型刚刚得到的 clean-state 估计就被直接丢弃。于是下一步它还得从 mask token 重新猜一遍，而不是在上一步估计的基础上继续修正。这会削弱跨步 refinement，尤其在低步数采样时更明显，因为每一步都需要做更大的去噪推进。

评做 diffusion LM 的可以读：它抓住了“masked token 每步从零猜”的真问题，但像是局部补丁，先看方法节和主表，别急着改 prior。
