a:T459,TensorBench is built on Scorch, an open-source compiler-based tensor framework with roughly 11k lines of Python and a 450-line C++ runtime header. Scorch extends PyTorch with dense and sparse tensor support and lowers computations through a three-level IR pipeline: CIN to LLIR to JIT-compiled C++. The benchmark contains 199 tasks: 194 feature additions and 5 refactorings. Tasks span user-facing APIs, sparse tensor formats, IR changes, scheduler optimization passes, code-generation features, and runtime components. Many tasks require edits to shared compiler machinery such as sparse-format handling, iteration lattices, IR lowering, scheduling, code generation, and runtime kernels. Evaluation is behavior-based rather than patch-similarity-based. The harness applies the agent’s unified diff in a fresh Docker container, builds the C++ runtime, and runs the full test suite, including inherited randomized regression tests and any tests added by the agent.
