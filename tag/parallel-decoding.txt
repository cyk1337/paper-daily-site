18:T4d0,The paper defines an independent-update sampler. At each step, the network emits a distribution for each writable position; the scheduler selects a group R based only on such per-position distributions; the sampler then draws each position in R independently. This abstraction covers absorbing-state masked diffusion, remasking diffusion, and the terminal phase of uniform-state diffusion. The main theoretical claims are sharp. If the positions in R are conditionally dependent given the frozen tokens, the divergence incurred by that step is at least the total correlation of the group. No set of per-position distributions can certify group independence, because two joint distributions may share identical one-position marginals while allowing different combinations of values. The states created by a dependent parallel write are also states where the standard per-position masked cross-entropy objective does not determine the needed joint conditionals. A further reachability result shows that simply writing one position at a time can also fail under hard constraints when the rest of the sequence pins a token. The technical message is precise: confidence measures sharpness of a marginal, not independence among positions.19:T8a6,方法叫 EB-Decode，核心由两个可学习模块组成。

第一部分是 Learnable Block Size, LBS。作者的观察是，token entropy 沿位置分布常呈现类似 staircase 的结构，说明相邻甚至非连续位置上，可能存在一批难度接近、语义上也相对一致的 token，它们适合被视作同一批次提前解码。与固定长度 block 或基于分隔符的启发式切分不同，LBS 用一个轻量网络读取每个位置的统计量，主要包括 token entropy、位置信息以及语义相关特征，在线预测 block grouping。论文强调它既支持 contiguous block，也支持 non-contiguous grouping，这一点比传统“滑窗式并行”更灵活。其目标不是做语法 chunking，而是做 difficulty-aware clustering：把收敛速度相近的 token 放在一起，避免 easy token 被 hard token 拖慢。

第二部分是 Learnable Parallel Sampling, LPS。现有 confidence-based decoding 的问题在于：只有当 token 置信度超过阈值时才 finalize，而很多 token 在更早步骤就已经预测正确，只是概率还没高到阈值，因此会被继续 remask 和重复预测。LPS 试图学习一个 position-aware 的 finalize policy。它利用每个位置在当前 step 的 entropy、位置编码、step index 等特征，预测该位置是否已经“足够收敛”，从而允许早于传统阈值进行定稿。因为 LBS 已经把难度相近 token 组织成 block，LPS 可以在 variable-length block 上执行并行 finalize，而不是受固定 block 边界限制。

从机制上看，这篇论文不是改 dLLM 主干模型，也不是重新训练一个新的 diffusion objective，而是在 decoder 侧外挂两个轻量路由/决策网络。这样做的好处是兼容现有 dLLM 和已有 KV-cache pipeline，代价则是需要额外训练这两个小网络，并且其泛化能力会受所用 backbone、任务分布和采样设置影响。与已有方法相比，区别主要有三点：一是 block size 从 heuristic 变成 learned；二是 early finalization 从固定 confidence threshold 变成 learned policy；三是 block 组织和 finalize 决策是联动的，而不是各自独立的后处理规则。1a:T7f5,The method, EB-Decode, has two main components.

The first is Learnable Block Size (LBS). The authors observe that token entropy across positions often follows a staircase-like pattern, suggesting that some positions—contiguous or even non-contiguous—share similar uncertainty and semantic coherence. Instead of using fixed-size blocks or heuristic boundaries such as delimiters, LBS uses a lightweight network to predict block groupings on the fly from token-level statistics, including entropy, positional information, and semantic cues. The goal is not syntactic chunking. It is difficulty-aware grouping: easy tokens should not be delayed by harder ones simply because they happen to sit in the same fixed block.

The second is Learnable Parallel Sampling (LPS). Standard confidence-based decoding finalizes a token only when its confidence exceeds a threshold. The paper argues that this wastes computation because many tokens become correct well before their confidence reaches that threshold. LPS learns a position-aware finalization policy using per-token features such as entropy, position, and denoising step. It predicts which positions have already converged enough to be finalized early. Because LBS already organizes tokens into variable-length groups, LPS can operate under adaptive blocks rather than fixed boundaries.

A key design choice is that the paper does not modify the diffusion LM backbone or training objective. Instead, it adds lightweight decision modules on top of the decoder loop. This makes the method easier to integrate with existing dLLMs and compatible with KV-cache pipelines. The trade-off is that these auxiliary networks need to be trained, and their robustness may depend on the backbone, task distribution, and sampling setup. Relative to prior work, the main differences are: learned rather than heuristic block sizing, learned early finalization rather than fixed confidence thresholds, and joint handling of grouping and finalization rather than treating them as separate post-hoc rules.1b:T62b,The evaluation covers three diffusion LLMs and four representative benchmarks. The headline result is a 3.53× to 18.76× throughput improvement over the vanilla decoder while maintaining comparable accuracy, with only about 6.21% routing overhead. When combined with a KV-cache pipeline, EB-Decode provides an additional 1.20× speedup.

The motivation is grounded in a real deployment gap. The paper cites that LLaMA3-8B-Instruct reaches 48.0 tokens/s on an A100-PCIe 40GB GPU, while LLaDA-8B-Instruct reaches only 3.5 tokens/s. It also notes that reducing denoising steps from 1,024 to 256 can drop accuracy from 83.5% to 54.1%. EB-Decode is meant to avoid this blunt speed-quality trade-off by freezing already-converged tokens instead of simply cutting the number of steps.

The most informative ablations are likely the following. First, LBS-only and LPS-only variants, which show whether the gain comes mainly from better grouping or from more aggressive early finalization. Second, comparisons among fixed blocks, heuristic adaptive blocks, and learned blocks, which test the paper’s central claim about heterogeneous token difficulty. Third, experiments combining EB-Decode with KV caching, which clarify whether the method replaces or complements existing systems optimizations. According to the paper, it complements them. The provided full-text excerpt does not include all detailed tables, so it would be unsafe to invent per-benchmark numbers, but the main empirical message is clear: the gains are primarily in throughput, and quality degradation is kept modest.1c:T575,This is a skim paper rather than a line-by-line read. Start with the introduction and make sure the two core observations are clear: token difficulty is heterogeneous, and many tokens are effectively correct before they cross the confidence threshold. First, the representation. Instead of a multi-codebook RVQ codec, the model uses X-Codec2, which produces a single stream of discrete tokens via fused semantic and acoustic encoders followed by FSQ quantization. The vocabulary size is 6561 and the frame rate is 50 Hz. This matters because block diffusion is much cleaner on a single token stream than on several parallel codebook streams.

Second, the training objective. A speech token sequence is partitioned into contiguous blocks. The paper uses block size B = 32, which corresponds to about 0.64 seconds at 50 Hz. During training, only the target block is corrupted by masking tokens with probability controlled by a continuous diffusion time t, using a linear schedule alpha_t = 1 - t. The model receives the noised target block together with previous clean blocks, plus text and speaker conditioning, and learns to reconstruct the original tokens in the target block. This is the conditional speech analogue of masked discrete diffusion / BD3-style block denoising, rather than standard next-token prediction.

Third, the attention pattern. The model uses staircase attention. Tokens inside the current target block attend bidirectionally, which supports joint reconstruction and local acoustic consistency. The current noised block can attend to previous clean blocks, which preserves sequential dependencies across time. Previous clean blocks themselves follow causal structure. This is the key architectural choice: within-block prediction behaves like masked infilling, while across blocks the model still respects temporal order. Compared with fully parallel diffusion, this should help alignment. Compared with AR codec LMs, it reduces decoding steps by predicting all tokens in a block in parallel.

Conditioning includes text and a speaker prompt for zero-shot voice transfer. A notable design choice is the absence of explicit duration modeling. First, it builds confidence-induced clusters (CICs). At a denoising step, the decoder computes token-level confidence for masked positions and merges adjacent high-confidence masked tokens into maximal contiguous spans. Each span becomes a candidate update unit. The underlying assumption is simple but important: neighboring confident positions are often supported by the same local context and can be committed together. Second, CLAD estimates dependencies between clusters. Instead of training an auxiliary module, it reuses self-attention maps from the same forward pass, aggregates token-level interactions into inter-cluster dependency scores, and constructs a conflict graph. To keep the graph sparse, it retains only mutually strongest inter-cluster dependencies. This pruning is important; otherwise the graph becomes too dense and the decoder turns overly conservative. Third, CLAD selects a maximum-weight set of non-conflicting clusters for parallel commitment. Cluster weights come from aggregated confidence.
