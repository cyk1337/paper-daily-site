9:T423,The method reformulates the output projection plus top-k selection as maximum inner product search. Rows of the output embedding matrix are treated as token vectors, and the final hidden state is used as the query. Instead of evaluating all logits, the system retrieves likely high-score tokens using an approximate nearest-neighbor index. The authors evaluate FAISS-backed options and choose HNSW because it offers the best latency–recall trade-off in this high-dimensional embedding space. The index is built post-training from the static output embeddings and can be distributed with the checkpoint. At inference time, the HNSW ef parameter controls the speed–accuracy trade-off. To reduce harmful misses, the implementation explicitly scores selected special tokens, common punctuation, and structural words. Retrieved logits can be scattered into a sparse full-vocabulary tensor, which keeps the method compatible with existing decoding pipelines.
