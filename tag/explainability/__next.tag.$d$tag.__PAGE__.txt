c:T701,The method is a four-stage, model-driven pipeline. First, the target LLM predicts labels for the task examples, and those model predictions are used as the labels to be explained. This choice is deliberate: the goal is to explain the model’s own decision process, not ground-truth task structure. Second, the system performs differentiative concept extraction. It iteratively identifies human-readable concepts that distinguish the model-predicted classes, then maps each example into a concept vector describing the inferred state of each concept. The concepts are not pre-specified attributes; they are induced from the task through the model. Third, the paper introduces an MCMC-inspired counterfactual expansion procedure. Instead of generating isolated edits, it builds chains of counterfactual texts. Each step proposes a change targeting one concept while trying to keep the rest of the context stable, and a rejection mechanism filters out unfaithful candidates that alter too much beyond the intended intervention or break concept consistency. This is the most substantive part of the paper. It is inspired by proposal-and-accept/reject logic from MCMC, though it is better viewed as a structured counterfactual search procedure than a strict sampling algorithm. Fourth, causal discovery is run on the expanded concept dataset to recover a directed graph over concepts and the final prediction. The learned graph is meant to approximate the causal organization of the model’s inference process, not the causal structure of the external world. Compared with prior counterfactual explanation work, the key difference is the global graph objective. Compared with mechanistic interpretability, the target is not neurons or circuits but dependencies among human-interpretable concepts.d:T50d,The evaluation uses three LLMs and three classification settings: sentiment analysis, disease diagnosis, and an LLM-as-a-judge classification task, spanning both natural and synthetic data. Since there is no ground-truth causal graph for the latent reasoning process, the paper evaluates two properties instead. The first is predictive fidelity: whether the discovered parent set of each node predicts that node better than alternative concept sets. The second is expansion utility: whether the counterfactual augmentation improves graph stability and accuracy relative to using only observed data. The reported findings are that the MCMC-style expansion yields more stable graph topology, and both the data distribution and graph structure show convergence behavior as the counterfactual chains grow. A notable qualitative result is the model-to-model contrast: on structured synthetic tasks, different LLMs converge to similar explanatory concepts, while on naturalistic tasks they develop distinct latent heuristics. That observation is useful for foundation-model analysis because similar task performance does not imply similar internal conceptual organization.
