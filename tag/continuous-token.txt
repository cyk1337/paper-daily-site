18:T43f,PlaidQ is a 0.7B continuous diffusion language model for code completion. Instead of predicting the next token left to right, it predicts all masked completion positions in parallel through a denoising process in continuous token-embedding space. The diffusion codebook is separate from the vocabulary projection used for categorical reconstruction. A pretrained autoregressive model is repurposed as a bidirectional denoiser, giving the diffusion model a strong code prior and better convergence than training from scratch. The large vocabulary creates a memory bottleneck because dense reconstruction would materialize a large probability tensor; SWVR addresses this with an exact streamed kernel that matches the dense loss and gradients without storing the full tensor. The training recipe also uses a hybrid Muon–AdamW optimizer.
