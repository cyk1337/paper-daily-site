LEEPS: Latent-Guided Explore-Exploit Prompt Sampling for Efficient RLVR in Large Language Models

LEEPS 解决的是 RLVR/GRPO 训练中的 rollout 浪费：太简单或太难的 prompt 会产生全对或全错的 group reward，组内 advantage 为零，生成开销已经花掉，但几乎没有有效学习信号。

评只看采样策略和 budget 分配即可；若实验干净，可作为内部 RLVR prompt scheduler 的低成本 ablation。

Breaking Entropy Bounds: Accelerating RL Training via MTP with Rejection Sampling

在 LLM 的 RL 后训练中，用 MTP（multi-token prediction）做推测解码以加速 rollout 时，acceptance rate 往往随 RL 过程显著下降，导致端到端加速有限。论文要解决的是：acceptance rate 为什么会掉、掉的主因是什么、以及如何在不做“RL 期间在线训练 MTP”的高开销方案下，把 acceptance 稳住并拿到可观加速。

评这篇会改你对“spec decode 在 RL 里只是工程问题”的看法；先看熵-接受率关系和 rejection sampling ablation，值得尽快在内部 RL pipeline 复现。

DARTS: Distribution-Aware Active Rollout Trajectory Shaping for Accelerating LLM Reinforcement Learning

RL 训练中 rollout 阶段耗时占总训练时间 70% 以上，核心瓶颈在于 rollout 轨迹长度存在严重的长尾分布——少量 prompt 产生超长轨迹，既浪费算力又在同步 on-policy 系统中阻塞整个批次。现有方法（Tail Batching、Partial Rollout）仅从 prompt 间调度层面缓解长尾，未从分布本身的根源解决问题。论文进一步发现，即便同一 prompt 内部也存在 intra-prompt 长尾，且长尾中大量是冗余无效的 verbose 轨迹。

评这类 rollout 长尾是真训练痛点；skim 方法和效率表，若无 reward 退化应进内部 RL pipeline ablation。
Yujie Wang,Siwei Chen,Longzan Luo,Xinyi Liu,Xupeng Miao,Fangcheng Fu,Bin Cui

Selective Rollout: Mid-Trajectory Termination for Multi-Sample Agent RL

这篇论文解决的是 agent 场景下 GRPO 多样本 rollout 成本过高的问题：很多同一 prompt 下的多条轨迹最终奖励完全相同，组内 reward variance 为零，advantage 全为零，训练没有梯度贡献，但 rollout 计算已经付出。

评这是 agent RL 里少见抓住真成本中心的工作；先看零方差组占比和 early-stop 偏差分析，若数字站得住，内部 GRPO 管线应立刻加这个 ablation。
Zhiyuan Zhai,Xin Wang
