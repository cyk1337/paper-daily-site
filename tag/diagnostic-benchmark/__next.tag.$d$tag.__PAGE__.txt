b:T6c0,The setup is intentionally simple and controlled. The authors compare two end-to-end input pathways on the same family of tasks. The text-only pathway receives a serialized textual form of the 2D object. The vision-augmented pathway receives the exact same underlying content rendered in a task-faithful 2D layout, then processed by a visual encoder attached to the same language backbone. Task definitions, instances, prompts, train/test splits, and evaluation criteria are held fixed, so the comparison is centered on how structure is exposed to the model.

A useful concept in the paper is structural isomorphism: an input representation is structurally isomorphic when it preserves the relations that govern the computation, such as row-column correspondence or local neighborhood structure. Under 1D serialization, those relations are no longer explicit and must be reconstructed from token order, delimiters, and formatting conventions before the actual task can be solved. The paper also includes a limited within-visual ablation where the 2D layout is disrupted; performance drops there as well. That does not fully eliminate confounds such as modality-specific pretraining or encoder differences, but it strengthens the claim that layout preservation itself contributes to the gain.

Relative to prior work on tables, documents, or visual-text compression, the novelty is in using visual rendering as a diagnostic instrument rather than for compression or context extension. The paper is careful not to claim that visual input is generally better than text. The claim is narrower: for tasks whose computation directly depends on 2D structure, preserving that structure in the input can materially change model behavior.c:T54b,The experimental signal is more about consistent trends than headline numbers. Across all three tasks, the visual pathway outperforms the textual pathway, and the gap often widens as task size increases. In matrix transpose, the text pathway shows more row-column misalignment as matrices grow. In Game of Life, errors exhibit spatial patterns, suggesting unstable recovery of local neighborhood relations. LU decomposition is especially informative because it requires chained dependencies over 2D positions, which appear more fragile after serialization. An important observation is that the textual errors are not merely random; they are often spatially structured, which is exactly what the serialization-friction hypothesis would predict.
