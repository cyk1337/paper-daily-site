HiFloat4 Format for End-To-End Reinforcement Learning Post-Training of Large Language Models

这篇工作处理的是一个很具体但很硬的工程研究问题：能不能把 LLM 的 RL post-training 真正做到端到端 FP4，也就是 rollout policy 和 training policy 的前向、反向都在 4-bit 下运行，而不是只把一部分路径降精度。难点不在“4-bit 会不会有误差”这种泛泛层面，而在 RL 场景里 rollout 与 training 是耦合的：rollout 生成的轨迹决定训练信号，若 rollout 侧量化失真改变了采样分布，训练侧即便更高精度也未必能补回来。作者的核心发现是，FP4 RL 的主要退化来源不是训练侧量化噪声，而是 rollout activation 的量化下溢和由此带来的 rollout–training mismatch。

评反常识发现价值很高——RL量化退化主因在rollout激活而非训练侧，精度不匹配反而更差，重点看§3的消融分析。

Stable FP4 Training via Transposition-Invariant Block Quantization

现有基于1D分块微缩放的FP4训练方案存在结构性缺陷：前向与反向传播过程中张量发生转置时，同一数值会被划分到不同的缩放块，被分配不一致的缩放因子，导致梯度偏差与训练不稳定，无法支撑大模型的端到端稳定FP4训练。

评明确了FP4训练不稳定的核心根源是转置缩放不一致，2D块量化的思路可直接复现到内部低精度训练ablation，重点看§3的转置不变性推导。

The Silent Freeze: Predicting When Low-Precision Training Stops Learning

这篇工作研究的是一个很具体、但在低精度预训练里常被忽略的问题：模型并不是因为梯度消失、优化失败或数值爆炸才停止学习，而是因为参数更新在目标精度下小于该参数当前数值的 half-ULP，更新被舍入掉，导致对应坐标虽然梯度仍非零，却再也无法移动。作者把这种现象称为 silent freeze。关键点不只是“会冻结”，而是冻结条件是逐坐标、确定性的，并且可以仅用一条高精度训练轨迹加目标 mantissa 位数，在不运行低精度训练的前提下预测冻结何时发生。论文要解决的核心问题，就是把这种看似训练动力学问题的现象，还原成一个由浮点表示粒度直接决定、可提前预报的停止学习机制。

评直接改变对低精度训练稳定性的认知，应立刻在内部 fp8/bf16 训练配方中加入半 ULP 冻结检查。

GNMR: Runtime Stability Control for Low-Precision Large Language Model Training

GNMR 解决的是低精度 LLM 训练中的运行时稳定性控制问题。现有 FP8、FP4、activation quantization、优化器状态压缩等方案通常把精度选择当成静态 recipe 或离线校准问题，但训练中的不稳定往往是局部、短暂、非平稳的：某个 attention 或 FFN 算子可能只在少数 step 出现梯度或激活异常，其他层仍然安全。该工作要回答的是：在已有低成本路径和高保真恢复路径之间，训练系统如何在线判断哪些局部单元需要临时回退到高精度，并且把额外开销限制在固定预算内。

评低精度训练稳定性的轻量落地方案，无需修改内核或数值格式，可直接接入现有预训练流水线开展内部测试

HiFloat4 Format for Language Model Pre-training on Ascend NPUs

大模型预训练受限于算力与显存带宽，低精度训练是关键路径。FP4（4-bit 浮点）可显著提升吞吐与降低带宽，但极低精度带来数值不稳定，尤其是梯度量化在存在 outlier 时会因 block scaling 由最大值主导而产生系统性偏置与大量下溢为 0，破坏反传与优化。本文要解决的问题是：在华为 Ascend NPU 上，HiFloat4（HiF4）这种分层缩放 FP4 格式能否实现端到端大规模 LLM 预训练，并相对 MXFP4 以更少的稳定化“辅助手段”获得更小的 loss gap 与更低的性能开销。

评真正有用的是它把 FP4 训练稳定性拆成“需要多少高精度护栏”这条账，能直接指导你评估端到端加速是否兑现；建议对照 MXFP4 的消融表逐项抄作业。
