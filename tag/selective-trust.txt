19:T5eb,Two pillars.
(1) MIST-1000 benchmark: each item is instantiated into four matched variants where the question, answer space/type, gold answer, and a plausible wrong answer are held fixed; only the surrounding context changes: clean (no added context), misleading (context nudges toward the plausible wrong answer), correct-context (context supports the gold), and irrelevant (natural related text that does not contain the answer). The dataset contains 1,000 items (800 adapted from existing QA/math/reasoning benchmarks, 200 newly written longer scenarios) with a two-pass human QA process to control ambiguity, leakage, and plausibility.
(2) Metrics + training:
- SC2W (signal-induced correct-to-wrong): computed on the subset of items the model answers correctly in the clean condition, measuring how often misleading context flips them to wrong—separating susceptibility from base competence.
- SCOPE (Selective Context Preference Optimization): a signal-counterfactual preference framework. It mines the critical failures from a base model: cases where the model is correct in clean but wrong under misleading context. For each, it forms a preference pair (truth-consistent response preferred over signal-following response).
