19:T4b4,SaeRL treats SAE activation space as the coordinate system for data engineering and maps three intrinsic properties to three operations:
1) Quality → filtering: train an SAE-based quality probe to filter a raw pool toward the target reasoning distribution (arguing surface heuristics like length/TeX ratio/step count are insufficient).
2) Difficulty → curriculum: train a regressor (ElasticNet) on SAE representations to predict a continuous difficulty score; then build curricula as local easy-to-hard trajectories within each SAE-space cluster (a deliberate choice over a single global curriculum to preserve skill/topic coherence).
3) Diversity → batching: cluster samples in SAE space, interleave batches across clusters to increase coverage, and apply “moderate batch mixing” by swapping a small tail portion between nearby batches—aiming to improve diversity without destroying within-batch coherence (important for stable RL gradients).
The motivating section supports the premise with probes: SAE features predict topic labels (DeepMath, including 82 leaf topics) well above a majority baseline; SAE-based difficulty prediction remains positively informative under distribution shift.1a:T6a9,The base model is an 8B single-stream DiT latent diffusion model using FLUX.2 VAE. A notable design choice is the text encoder: instead of a larger T5-style encoder or a full LLM, the system uses Ministral-3 3B, with the claim that it still supports long and complex prompts while reducing memory cost. The most important part is the data pipeline. In pretraining, the authors use a bottom-up construction strategy: starting from a massive raw image pool, they train a 10,000-way fine-grained image classifier and use those categories for balanced sampling, aiming to preserve long-tail concepts rather than letting dominant visual categories overwhelm the distribution. They then run a strong VLM to generate richer captions, including structural descriptions and visible text, so the model sees more explicit supervision for instruction following and world knowledge. For quality control, they train an aesthetic scorer, ERNIE-Image-Aes, and use it to clean the corpus. In post-training, they switch to a top-down pipeline with highly consistent data for high-demand scenarios, and diversify annotations to cover different user prompt styles, reducing caption-model bias. Preference alignment is done with an improved DPO variant; the practical claim is that if both the base model and reward model are strong, only a few DPO steps are needed, which helps avoid reward hacking. For acceleration, they train ERNIE-Image-Turbo with only 8 NFEs. To reduce capability drift during fast-model training on subsets, they introduce MT-DMD, where multiple expert variants provide supervision jointly. The more useful empirical lessons are qualitative but concrete: adding detailed image descriptions early in training improves both instruction following and retention of world knowledge; 10k-category balancing helps preserve long-tail concepts; and DPO should be applied lightly when the reward model is already strong, otherwise distribution drift becomes more likely.
