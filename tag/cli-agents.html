GUI vs. CLI: Execution Bottlenecks in Screen-Only and Skill-Mediated Computer-Use Agents

AgentMeter: Evaluating Model-CLI Matching for CLI-Based Local Task-Solving Agents

这篇工作要解决的问题不是“哪个 agent 模型更强”，而是更贴近部署现实的“哪个 model–CLI 组合更合适”。在本地任务求解场景里，CLI 不是中性的外壳，它会改变 prompt 组织、上下文回放、工具输出序列化、文件访问方式、终止条件和重试行为，因此同一个模型接到不同 CLI 后，成功率、token 消耗和账单成本都可能明显变化。现有 benchmark 多半把评估对象默认成模型本身，主要看 pass rate，难以回答部署时真正关心的匹配问题：在不同任务难度下，哪个组合既能做成事，又不会因为低效轨迹和昂贵失败把成本拉高。

评读 metric 定义和 24 配置表即可；它提醒 agent 分数常是模型×CLI 的交互项，不是模型常数。
Han Chi,Jiaxin Qi,Yan Cui,Baisheng Lai,Jianqiang Huang
