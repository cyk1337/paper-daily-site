LLMs Need Encoders for Semantic IDs Too

这篇工作处理的是生成式推荐里一个很具体但长期被低估的问题：Semantic ID 不是普通离散 token，而是带层级前缀语义的结构化“模态”。同一个层级 code 在不同前缀下语义不同，如果像普通词表扩展那样给每个 code 只分配一个静态 embedding，模型就必须在自回归训练里自己恢复 prefix-conditioned meaning、合法组合约束和流行度分布。这在 billion-scale item catalog 上会变成一个组合稀疏问题：前缀空间指数增长，中间层还有 hourglass 现象，导致很多 prefix-code 组合训练曝光不足，最终拖累最深层 SID 预测、整条 SID 检索和 SID-text 对齐。

评将推荐系统的 Semantic ID 视为一种新模态并设计专属 Encoder，对探索 LLM 跨模态统一表示（尤其是离散结构化数据）有一定启发。
