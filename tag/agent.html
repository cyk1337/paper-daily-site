A Control System, a Dataset, and a Recipe for Making Frozen LLM Agents Learn a Domain

生产环境中的LLM agent通常由冻结基座模型加外围harness（提示模板、工具集、记忆/检索层、规划策略、验证策略等）构成。现有harness优化方法要么需要昂贵的代码搜索循环，要么允许无约束的自修改代码，不可审计，也无法适配纯黑盒LLM API的部署场景。需要一种更受限、可审计、样本高效的在线harness配置优化方法，实现冻结LLM agent的领域适配。

评Meta 做的冻结模型 harness 在线 RL 方案，对理解后训练时代基座与系统边界有启发，重点看奖励设计部分。
