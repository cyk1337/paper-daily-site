b:T636,The method, Reinforced Reference Game (RRG), trains an MLLM to alternate between two roles. As a speaker, it observes the target concept and generates a description. As a listener, it uses that description to identify the target from a candidate set. The speaker is optimized with GRPO using the game outcome as reward.

Three design choices matter. First, the candidate set is deliberately hard. Hard positives are different views or states of the same concept, which penalizes descriptions that rely on unstable cues such as background or object state. Hard negatives are visually similar items from the same semantic class, which forces the speaker to mention truly distinguishing attributes. Second, the objective is not to improve generic caption quality, but to compress the description into the subset of attributes that are both stable and discriminative. Third, the reward is verifiable and task-grounded: success is defined by whether the listener can recover the target, not by matching a reference sentence.

Relative to prior personalization methods, the distinction is clear. It avoids per-concept test-time optimization, unlike methods that learn concept-specific representations on the fly. It is less dependent on raw image reasoning than retrieval-plus-reasoning approaches, because it tries to distill the concept into a cleaner textual representation. It also differs from template-based description methods by learning the description policy rather than prescribing a format, and from generic RL personalization by using a sharper reward tied to reference-game success.c:T52c,Experiments are conducted on MyVLM, Yo’LLaVA, and PerVA, covering personalized captioning and VQA.
