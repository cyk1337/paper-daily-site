- L0 (repository archive): defines the repository boundary and preserves provenance (metadata, directory structure, file paths, retained revision). Only the latest commit on the default branch is kept to fix a stable snapshot.
- L1 (standardized natural code): scalable filtering/cleaning/normalization plus near-deduplication. The pipeline routes processing by 80 language categories and 160 extensions (including special filenames like Makefile), using extension-specific cleaning profiles and extension-partitioned near-dedup.

It combines file-role supervision (to distinguish implementation vs tests/config/docs, etc.) with language-specific heuristic cues, trains relevance/quality models, reuses precomputed semantic embeddings to reduce cost, and applies role/quality constraints during selection.
- L3 (task-oriented synthesis): converts each L2-selected implementation into a structured programming exercise, generating aligned fields (task statement, analysis, solution, and test candidates).
