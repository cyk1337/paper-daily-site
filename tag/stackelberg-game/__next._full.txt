19:T4fa,The paper formulates antidistillation as a bilevel optimization problem in a Stackelberg-style game. The defender releases outputs drawn from an admissible perturbation set around clean traces. The attacker trains a student model on those outputs. The defender wants to maximize the student’s evaluation loss on clean data while keeping the released output useful to legitimate users. Compared with classical data poisoning, two aspects change. First, the student architecture is often unknown, so the defense should not rely on gradients from a fixed proxy model. Second, the model provider is the party injecting the perturbation, while the distiller is the attacker. The paper then argues that detectability is a core constraint: if poisoning is easy to identify, the attacker can filter, resample, or paraphrase around it. TraceGuard follows from this view. It is a black-box, training-free method that perturbs sentences near key branching tokens in the reasoning trace. The motivation comes from interpretability observations that thought anchors and high-entropy tokens can disproportionately influence later reasoning paths.
