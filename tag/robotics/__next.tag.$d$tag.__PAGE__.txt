9:T48f,ALPS uses a two-stage recipe. Stage 1 trains a ViT-B/16 from scratch with fixed sinusoidal positional embeddings and raw final-layer patch tokens. The same tokens are supervised by four objectives: image-text contrastive learning, autoregressive captioning, pixel reconstruction, and dense correspondence. The contrastive loss uses both web captions and sentences sampled from longer synthetic captions, with separate softmaxes so that captions for the same image are not treated as negatives. The caption decoder predicts the full synthetic caption from image tokens and previous text. A lightweight convolutional decoder reconstructs images from clean and noisy tokens with L1, SSIM, and image-gradient losses. Dense correspondence adds local spatial supervision across crops and scales. Stage 2 then performs cross-view self-distillation: a student sees an augmented view and predicts frozen Stage-1 teacher patch tokens at corresponding locations in a clean view.
