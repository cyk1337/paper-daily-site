18:T442,Its relevance to pretraining is mainly through training mechanics rather than language modeling objectives. The contribution is not a new LM loss, but a different answer to the memory wall: change the gradient pathway itself instead of only compressing or recomputing activations. That matters for three reasons. First, it pushes local learning from a mostly empirical idea toward a gradient-estimation framework with theory, at least for deep linear networks and residual nonlinear networks near the right regime. Second, the locality definition is operationally meaningful for large-model training: only one block’s activations need to be kept at a time. Third, the LLM finetuning results suggest that first-order local gradient surrogates can beat zeroth-order methods under similar memory budgets, which is a useful signal for low-memory adaptation. The limitation is equally important: the evidence is not yet large-scale from-scratch LLM pretraining. So this is better viewed as a promising training paradigm candidate than as a drop-in replacement for standard pretraining recipes.19:T77d,The method, ProxyProp, partitions a deep transformer into gradient-isolated blocks. For block l, instead of waiting for gradients to flow through all downstream blocks, the method attaches a local proxy network that takes the block output h_l and predicts the final network output. The proxy is trained by distillation against the global model output. The block update is then computed by backpropagating through the proxy, not through the actual downstream stack.

The central idea is not merely to add an auxiliary head. The proxy is meant to estimate the downstream input-output Jacobian seen from that block. In deep linear networks, the paper argues that an optimal linear proxy implicitly recovers the expected linear map from the current representation to the final output, making the local gradient exact. For nonlinear residual networks, the analysis depends on residual parameterization: when skip connections dominate, the downstream mapping is close to identity plus a small perturbation, so the proxy-induced gradient error can be bounded; at initialization, the local gradient can even match the true gradient exactly. This is the main reason the method is positioned for modern residual transformers rather than arbitrary deep architectures.

Operationally, each block can be updated immediately after its forward pass, satisfying the decoupled or unlocked learning setup. Memory savings come from avoiding full-network activation storage and retaining only the local computation graph for one block plus its proxy. Compared with classic local-loss training, ProxyProp is trying to predict the effect of the remaining network on the final output, rather than forcing each block to solve the task directly. Compared with zeroth-order methods such as MeZO, it still uses gradient information, but obtains it through a local surrogate, which is why it can be more compute-efficient at similar memory cost.1a:T672,The experiments appear to have two main parts. The first is supervised learning with vision transformers, used as a controlled setting to study the memory-accuracy trade-off under different block partitions. The reported takeaway is that ProxyProp dominates prior local learning baselines across partition choices: for a given memory budget it achieves better accuracy, or for a given accuracy it uses less memory. The important pattern to inspect is how performance degrades as the model is split into more blocks and locality becomes stronger. The claim is that ProxyProp degrades more gracefully, which would support the gradient-approximation story.

The second part is memory-efficient LLM finetuning. Here the comparison to MeZO is the key result. The paper states that ProxyProp achieves better downstream performance at comparable memory cost, even when MeZO is allowed roughly 8x more compute time. That is a meaningful comparison because zeroth-order optimization is often considered when memory is extremely constrained, but it suffers from high variance and slow convergence.

The currently available text does not expose enough full tables to restate every concrete number with confidence, such as exact ViT sizes, datasets, partition counts, or the LLM parameter scales and task suite. When reading the full experimental section, three details are worth checking carefully: whether memory accounting includes optimizer state and proxy overhead, whether runtime is reported as wall-clock or FLOPs, and whether the LLM finetuning updates all parameters or only PEFT-style modules. That last point changes the practical significance a lot.1b:T404,For a skim, start with the definitions in the introduction: locality, decoupling, and unlocked training. Those tell you what class of methods the paper is actually competing with. Then go straight to the theory sections on two claims: why the proxy gives exact gradients in deep linear networks, and why the error remains controlled in nonlinear residual networks under residual parameterization and skip-dominant regimes. Those sections carry most of the paper’s intellectual weight.

In the experiments, focus on three items: the accuracy-memory curves as the number of blocks changes, the ablation on proxy design, and the fairness of the LLM finetuning comparison against MeZO. A useful reading question is whether the gains come mainly from a better local target or from enabling a more favorable memory/parallelism regime. That distinction determines whether ProxyProp should be thought of primarily as an optimization method or as a systems-facing training alternative.
