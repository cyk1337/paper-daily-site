9:T813,方法上有两个核心动作。第一是目标构造。作者没有直接沿用父 subword tokenizer 的所有切分，而是围绕 grapheme cluster 设计了两类监督：一种是 every-cluster target，即保留每个 grapheme 边界；另一种是 retained-parent target，即只保留那些本来就与 grapheme 边界重合的父 tokenizer 切分。这样做的原因很明确：grapheme 边界是跨编码可表示的、对 span-preserving edit 稳定，而且正好能把“编码是否在首符号暴露了 cluster continuation 所需信息”这个问题单独拎出来。第二是编码设计与对照。作者采用已有的 UBE（Universal Byte-Level Encoding）：对 1-byte 和 2-byte UTF-8 标量保持不变，对更长的标量改写成 UTF-16 little-endian 的两个字节。这样对原本需要 3-byte UTF-8 的 codepoint，首个符号从 UTF-8 的‘4 个高位 + 长度前缀’变成了‘8 个低位’，在同一 256-codepoint page 内通常足以直接区分具体字符。为了把“更短序列”与“字节顺序”拆开，作者又构造了 UBE-BE：路由方式和总长度与 UBE 相同，但把 UTF-16 code unit 内部字节顺序反过来。这样如果 UBE 好、UBE-BE 不好，就能说明收益不是简单来自 stream 变短，而是来自 low byte first 让判别信息更早出现。

实验对象是小型 causal boundary predictor，在 matched FineWeb-2 文本上训练，在 FLORES-200 的多语种面板上评估。作者把错误分成 scalar ends 上的平衡误差，以及 scalar 内部的 false cuts；后者可以用规则 mask 去掉，不改变 scalar end 的判定，因此主分析集中在真正有意义的边界决策上。论文还构造了一个很强的诊断实验：找出那些左上下文完全相同、下一个 scalar 落在同一 256-codepoint page、但边界决策相反的成对样本。对这类样本，若编码首符号不携带足够信息，模型再怎么学也无法在一符号 lookahead 下全对；这使得“可学性”与“表示可区分性”被清楚地分开了。a:T773,最关键的结果有三组。第一，在 17 种语言的 FLORES-200 面板上，针对 every-cluster target、只允许 one-symbol lookahead 时，UTF-8 在 scalar ends 上的 balanced error 是 8.76%，UBE 降到 0.06%，而同长度控制 UBE-BE 仍有 8.62%。这个结果很硬，因为它几乎直接说明收益来自字节顺序，而不是仅仅因为 UBE 把 3-byte UTF-8 压成了 2 个符号。第二，在作者构造的 17,204 对“相同左上下文但应作相反决策”的样本上，UBE 的训练后预测器在每个 seed 都能全部答对；UTF-8 和 UBE-BE 做不到，因为两者在关键位置看到的首符号相同，信息先天不足。第三，在 Korean 和 Chinese 这类 grapheme 边界基本等于 scalar end 的语言里，问题不再是 cluster continuation，而是 retained-parent task 中“哪些字符边界要保留为 subword 边界”。在 one-symbol lookahead 下，UBE 相对 UTF-8 的总 retained-parent error 分别下降 72.91% 和 35.29%；在另外 8 个脚本上，下降幅度在 67.32% 到 99.55% 之间。作者还指出，当某脚本主要 Unicode block 落在单一 256-codepoint page 内时，UBE-BE 与 UTF-8 会比较接近，这与“low byte first 在页内直接暴露字符身份”的机制一致。

The first is target construction. Instead of inheriting all parent tokenizer boundaries, the authors define grapheme-aware supervision in two forms: an every-cluster target that keeps every grapheme boundary, and a retained-parent target that keeps only those parent-tokenizer cuts already aligned with grapheme boundaries. Grapheme clusters are chosen because their boundaries are representable across encodings, stable under span-preserving edits, and directly isolate the continuation-vs-new-cluster distinction that encoding order can obscure.

The second component is the encoding comparison. The paper uses Universal Byte-Level Encoding (UBE), which keeps one- and two-byte UTF-8 encodings unchanged but rewrites longer scalars as UTF-16 little-endian bytes. For codepoints that would take three bytes in UTF-8, UBE shortens them to two symbols and, more importantly, exposes the low byte first. Within a known 256-codepoint page, that first symbol often identifies the codepoint directly. To separate stream-length effects from byte-order effects, the authors introduce UBE-BE, a big-endian control with the same routing and stream length as UBE but reversed byte order inside each UTF-16 code unit. This is a strong control: if UBE wins over both UTF-8 and UBE-BE, the gain cannot be explained by shorter streams alone.

They train small causal boundary predictors on matched FineWeb-2 text and evaluate on a multilingual FLORES-200 panel. If the upcoming bytes can be copied from recent context, they are old information; if they cannot, new information is entering the stream, and that is where a patch should start. Formally, for each position t, m_t is the length of the longest prefix of the future byte stream that appears within the previous 128 bytes, capped at 16. Novelty is defined as -m_t, so shorter matches mean higher novelty. Since m_t depends on future bytes, it cannot be used directly online. The authors therefore build a causal approximation: a lookup table indexed by the previous two bytes, storing the average value of -m_t observed under that context. The table is fit on 4 MB of raw text in seconds on CPU, with backoff to one-byte context and then the global mean for rare contexts. At inference time, patching is just a table lookup plus thresholding to hit a target patch rate.

Several design choices are notable. The method needs no labels, no reference model, and no loss-based ablation signal, making it cheaper than both entropy patching and the earlier dependence-table approach. It changes the routing principle from surprisal-seeking to novelty-seeking. The paper also evaluates two variants: nov, fit on GSM8K and MATH training solutions, and novc, fit on a raw pretraining-corpus sample, to test whether the effect depends on math-specific fitting. Baselines include BLT’s entropy threshold, the prior dependence table, and a hand-written syntax+entropy rule.
