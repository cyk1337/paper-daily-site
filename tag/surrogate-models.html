Surrogate Fidelity: When Can Open LLMs Explain Closed Ones?

这篇工作讨论的是一个解释性研究里长期被默认、但很少被正面检验的问题：当闭源前沿模型只能通过 API 访问时，研究者能否用开源模型作为 surrogate，去解释闭源模型的行为与内部机制？作者把这个问题形式化为 surrogate fidelity，也就是“在 surrogate 模型上测到的量，能多大程度预测 target 模型上的对应量”。他们特别强调，很多人默认“如果两个模型预测相近，那么解释也大致可迁移”，但全文实验表明这个假设并不稳，尤其在 attribution 层面经常失效。

评只看 attribution fidelity 和 access-validity inversion 的实验；它会降低用开源模型解释闭源模型的信心。
Philippe Chlenski,Zachariah Carmichael,Ayush Warikoo,Chia-Tse Shao,Yingxiao Ye,Aobo Yang,Vivek Miglani,Nehal Bandi

Elicitation Matters: How Prompts and Query Protocols Shape LLM Surrogates under Sparse Observations

这篇论文研究的不是如何让 LLM 做 surrogate 更准，而是一个更基础的问题：在稀疏观测下，优化器真正从 LLM 那里“拿到”的 surrogate belief 到底是什么，以及这个 belief 会如何被 prompt 文本和 query protocol 改写。作者指出，在低数据、目标函数仍高度欠定的场景里，只看点预测误差或 calibration 不够，因为真正影响 Bayesian optimization 或实验设计的是：模型的不确定性是否跟“仍有多少与样本一致的函数可能性”对齐，以及新增证据后这种不确定性是否按合理方式更新。

评这篇不改 pretrain，但会改你看待“模型不确定性”的方式；重点读 uncertainty-alignment 定义和顺序敏感实验，别把 elicitation 当纯包装。
Ge Lei,Samuel J. Cooper
