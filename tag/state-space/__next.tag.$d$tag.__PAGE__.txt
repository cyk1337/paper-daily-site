b:T6bc,1) SeqCond Attention (SCA): represent the prefix embeddings as samples from a discrete random variable X and summarize the prefix via the empirical characteristic function φX(θ)=E[e^{i⟨θ,X⟩}]. Instead of φX itself, SCA maintains its spectral gradient ∇θφX, argued to be more informative since X enters multiplicatively.
2) Readout: the current token produces a spectral query wt(θ); the layer output is a complex Hermitian inner product between wt and the prefix summary S1:t(θ), acting like “querying a compressed spectral memory” rather than a KV list.
3) Expressiveness: in the continuous/integral limit, they construct queries that can exactly retrieve any individual past token from the summary (Theorem 1), extend to recovering weighted distributions, and show softmax attention as a special case (Corollary 4). The guarantees rely on Fourier inversion in a distributional sense; practical performance depends on discretization (finite learned spectral points) and approximation error.
