CLBench-V: Evaluating Multimodal Context Learning from Grounding to Knowledge Acquisition

这篇工作要解决的不是一般的多模态问答，而是更细一层的“多模态上下文学习”评测问题：当模型在推理时拿到一段包含文档页、图表、表格、网页截图、多图证据等在内的上下文，它到底是在哪一步失效的。现有 benchmark 多半只看最终答对没有，或者只覆盖纯文本 context learning，难以区分模型是没有找到证据、找到了但不会用，还是明明上下文里定义了新知识却仍被预训练先验带偏。CLBench-V 试图把这三类失败拆开，并在统一框架下评估多模态模型从 grounding 到新知识获取的完整链条。

评多模态ICL评测的新基准，三维度能力拆解可用于模型失效定位，只看任务设计与维度划分部分即可

Agentic Context Learning with Self-Discovered Specification

上下文学习（context learning）要求 LLM 从长上下文中学习并应用全新的任务特定知识，但前沿模型严格通过率仍低于 24%。传统假设认为失败源于内容检索不足，但实验显示检索、反思、验证等 12 类方法几乎无增益，核心瓶颈实际是「局部规范获取」——模型需要从上下文中发现并遵守查询隐含、低显著度、分散分布的行为约束（格式、边界处理、标签、完整性条件等），而非仅提取与查询相关的事实内容。

评失败分析有信息量：上下文学习的瓶颈不在检索而在隐式规范提取，对预训练数据设计与ICL机制研究有参考，重点看失败分析章节。

From Context to Skills: Can Language Models Learn from Context Skillfully?
