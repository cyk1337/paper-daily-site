9:T503,Agent^2 RL-Bench is introduced with a “training structure coverage” principle: 6 tasks across 3 levels, each level adding a structural requirement not present before. Each instance is defined by (task description D, base model M0, training data T, evaluation oracle O, time budget τ). Within τ, an agent A can iteratively implement training, run experiments, and submit candidate models via a grading API; the run score is the best improvement over M0 achieved within budget (best-within-budget), mirroring real post-training iteration.
Level 1: static rule-based tasks with deterministic verification (e.g., GSM8K, HumanEval) to test data construction + supervised training.
Level 2: static but judge-based, non-deterministic rewards (e.g., AlpacaEval), requiring optimization under noisy signals.
Level 3: fully interactive environments (ALFWorld, WebShop, DeepSearchQA) requiring environment interaction, trajectory collection, and closed-loop online RL within a fixed 12-hour budget.
