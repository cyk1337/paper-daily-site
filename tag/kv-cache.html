PeekKV: The First Content Token Already Knows Which Heads Matter

TideKV: Delayed KV Eviction via Layer-Wise Chunked Prefill for Memory-Efficient Long-Context LLM Inference

这篇工作处理的是长上下文推理里一个很具体但常被忽略的问题：不是最终保留多少 KV cache，而是 prefill 阶段如何把 KV cache 建出来而不在中途爆显存。现有方法大致分两类。像 SnapKV 这类 post-prefill 压缩方法，要先让整段 prompt 在每一层完整跑完，再做选择，因此构建峰值显存仍然很高；像 KeyDiff 这类在线驱逐方法，虽然更早释放显存，但会在该层尚未看完整个 prompt 时就删 token，导致选择依据带有明显短视性。TideKV 想解决的就是这个 visibility-residency trade-off：既保留“看完整个 prompt 再决定保留谁”的全局可见性，又把 prefill 期间未压缩 KV 的驻留范围压到单层级别，从而把峰值显存降下来。

评prefill 峰值显存常被 KV 压缩论文绕开；这个 layer-major schedule 的设定干净，值得在长上下文 serving 中复现。

Virtual Head Attention

这篇论文解决的是长上下文 LLM 注意力设计里的一个老问题：KV cache、训练/预填充 FLOPs、模型质量三者很难同时兼顾。GQA 质量好，但 KV cache 大；把 KV 头数继续压低到 GQA-2，cache 会明显变小，但 query heads 共享同一组 K/V 后，多头多样性掉得很厉害；MLA 能压 cache，但质量常常掉；MFA 质量接近 GQA，却要付出明显更高的训练和 prefill 计算。作者要做的不是在三角形里选一个点，而是试图改写这个约束：在只保留 2 个 KV heads 的前提下，把 query 侧和输出侧做最小改动，尽量把 GQA-8 的表达能力补回来，同时保持低 cache 和更低 FLOPs。

评应立刻复现小规模 ablation；线性可折叠这点干净，若质量曲线稳，会改变 GQA/MLA 取舍。
Xibo Ding,Guoxia Wang,Jinle Zeng,Jiabin Yang,Sirui Tao,Chao Yang,Dianhai Yu

AbridgeKV: Compressing Long Reasoning into the KV Cache of Learned Pause Tokens

AbridgeKV 解决的是长推理解码中的生成端 KV cache 膨胀问题：CoT 越长，cache 越大，吞吐被显存而不是算力限制；简单丢弃历史 KV 会让模型在未适配的缓存分布上继续生成，常表现为更长输出和准确率下降。

评这篇不改 pretrain，但会改你对长 CoT serving 的默认做法：别再把 KV eviction 当免费午餐，先看它为何必须训练期显式教模型做“自压缩”。

RoLaQ: Joint Rotation and Range Calibration for 2-Bit KV Caches in Multi-Head Latent Attention

这篇工作处理的是 MLA 架构下 2-bit KV cache 量化的一个特有难点：在 Multi-Head Latent Attention 里，缓存的不是分开的 K/V，而是一个被所有头共享的 content latent。这个 latent 经过不同投影同时生成 content key 和 value，所以同一份量化误差会同时扰动 attention matching 和 value readout。已有 KV cache 量化方法大多针对标准 MHA/GQA，默认 K 和 V 可分开处理；直接套到 MLA 上，误差方向、尺度和重建增益之间的耦合没有被建模，2-bit 下精度掉得很明显。RoLaQ 要解决的就是：在冻结主模型参数的前提下，怎样为 MLA 的共享 latent 学到一个更适合 2-bit 量化的旋转基和量化范围，让误差尽量落在对 K/V 联合投影不敏感的方向上，同时控制重建响应。

评只看量化误差分解和校准目标即可；若内部有 MLA serving，值得复现 2-bit latent KV 的 ablation。
Shiyu Ji,Peng Ling,Chen Lin,Shupeng Li,Yixuan Wang,Qingfu Zhu,Wanxiang Che

Close Enough is Nowhere Near: Fidelity-Consumability Decoupling in KV Caches

这篇论文研究一个很具体但容易被误判的问题：在两个冻结 Transformer 之间，能否直接把发送方的 KV cache 放进接收方的 cache 槽位，让接收方复用发送方已经读过的上下文。作者的结论是否定的，障碍主要在接收方。接收方只能稳定读取它自己会产生、或足够落在其“可容忍集合”内的 cache；几何相似度高，并不等于可被消费。

评这个负结果值得扫：直接传 KV cache 的 prior 基本被打穿，重点看 tolerable set 和 competitive attention。
Adam Deng,Shicheng Liu,Yada Zhu

Augment the Cache, Replace the Activation: A 2x2 Study of Internal-State Sharing

这篇论文研究冻结 LLM 之间共享内部状态时，应该传什么、怎么接入。作者把问题拆成一个 2x2：carrier 是 activation 还是 KV cache，fusion 是 replace 还是 augment。核心结论是：cache 不适合直接替换，activation 更适合替换；cache 如果要共享，更适合以追加上下文的方式接入。

评比“传 cache”更像可扩展设计空间；扫 2x2 结果即可，重点是 carrier 进入位置这个变量。

When the KV Cache Is Slower Than the GPU: Scaling Remote KV Tiers for Context-Parallel Prefill

这篇工作讨论的不是“KV cache 能不能省算力”，而是一个更实际的问题：在当前高端 GPU 上，远端 KV tier 什么时候会比直接重算更慢，甚至把整个长上下文 serving 系统拖入排队失稳。论文聚焦于一个真实生产部署：GLM-5.3 的分离式 prefill/decode serving，prefill 侧采用 8 卡 context parallelism。作者发现，把 LMCache 的远端 L2 tier 打开后，中位 TTFT 几乎不变，但长 prompt 的 p99 明显恶化。核心原因不是单点实现细节，而是一个系统级错配：GPU prefill 吞吐已经高到让“远端读 KV”不再天然便宜；再叠加 PCP 的 rank lockstep、同步加载路径和单线程 Valkey 后端，remote hit 反而比 miss 更贵，命中越多越容易形成队列积压。

评长上下文服务相关，先看瓶颈分解图；若只有缓存系统 microbench，没有端到端 prefill，就降权处理。
Muhammad Ibrahim
