Towards Load-Aware Prefill Deflection for Disaggregated LLM Serving

在解耦式 LLM 服务架构中（prefill 和 decode 分别运行在独立 GPU 池），突发且重尾的工作负载导致 prefill 节点饱和、请求排队，而 decode 节点因受内存带宽限制存在计算余量未被利用。实测表明在 2P2D 集群上，prefill 执行本身仅占 P95 TTFT 的 2-23%，其余时间消耗在排队和节点间 KV-cache 传输上。

评做 serving 的人该看，做 pretrain 的人只需记住一个结论：解耦后 TTFT 常死在排队和 KV 搬运，不在 prefill FLOPs；读摘要和实验首图就够。
Shrikara Arun,Anjaly Parayil,Srikant Bharadwaj,Renee St. Amant,Victor Rühle

Beyond Prediction: Tail-Aware Scheduling for LLM Inference

这项工作解决 LLM 在线推理调度中的尾延迟问题。现有系统常用输出长度预测来近似 SJF 或 SRPT，以降低平均响应时间。但 reasoning workload 的 decode 长度高度不稳定，分布会随时间和请求类型变化，预测驱动策略在 bursty arrival、分布漂移和 GPU KV cache 压力下容易失效，也很难直接控制 P90 到 P99 的 TTLT。

评推理调度方向的扎实工作，尾延迟优化思路对 pretrain 研究员理解 serving 约束反哺训练配置有参考，重点看 §3 优先级设计与 §5 尾延迟分解。
Yueying Li,Yuanfan Chen,Jiayang Chen,Esha Choukse,Haoran Qiu,G. Edward Suh,Rodrigo Fonseca,Ziv Scully,Udit Gupta
