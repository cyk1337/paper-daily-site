Variable-Length Tokenization via Learnable Global Merging for Diffusion Transformers

扩散模型的视觉 tokenizer 通常是固定压缩率，导致“质量-算力”只能靠换模型/换 tokenizer 版本来适配不同预算。已有 variable-length tokenizer 多用 nested dropout 截断有序 token 序列，带来跨长度的表示/分布漂移（同一图像在不同 token 数下的相似性结构变化很大），使得单个 diffusion transformer 难以在多长度 latent 上共享一个稳定的 score/denoiser。论文要解决的是：如何设计一种可变长度视觉 tokenizer，使不同长度下的 latent 表示尽量对齐，从而让同一个扩散模型真正实现可控的 token 数（算力）与生成质量折中。

评值得看 tokenizer 设计而非生成指标；重点查 cross-length alignment 实验是否排除了容量和训练预算混杂。
