18:T519,The method has three parts. First, the paper detects context anxiety from reasoning traces. Instead of simple keyword matching, it uses a panel of LLM judges to classify whether a trace semantically expresses claims like 'this exceeds my context window' or 'I cannot finish within token limits.' This lets the authors separate anxiety-driven failures from capability-driven failures and successful attempts. That distinction is central to the paper. Second, it measures token-use calibration. After producing an answer, the model is asked to estimate how many tokens were required to complete the solution. This estimate is compared with the true token count through a winsorized token ratio. The point is not whether the model knows tokenizer internals; it is whether the model’s perceived generation effort is systematically biased. Third, the paper tests whether the behavior is mutable. It builds a distilled SFT dataset from the target model and stronger teacher models, keeping only successful reasoning traces that do not exhibit context anxiety. The student is then fine-tuned on these traces. The intervention is designed to teach alternative long-horizon reasoning strategies that complete the task without self-abandonment, rather than simply injecting more answers or more test-time compute.19:T413,The main task is Tower of Hanoi, with shortest-path grid search used as a second validation setting. This miscalibration is associated with a 15% drop in accuracy and, even when the model succeeds, a 54% increase in token usage, indicating that anxiety hurts both success rate and efficiency. The effect appears even in models built for long contexts and adaptive generation length, so it is not reducible to a small context window. On the intervention side, lightweight SFT reduces context anxiety by more than 50%, which supports the claim that the phenomenon is a modifiable behavioral policy rather than a hard capability limit.
