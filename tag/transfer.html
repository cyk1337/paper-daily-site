EVOKE: Eliciting World Knowledge in Agents for Transferable Decision-Making

A helps B while B hurts A: directed transfer in instruction-tuning mixture

这篇论文研究固定指令微调预算下，如何选择源任务类型来提升一个没有训练样本的目标任务。核心问题不是“多任务是否有用”，而是源任务对目标任务的迁移是否有方向、是否可能为负，以及能否用少量试验在训练前预测一个混合配方的效果。

评只看实验设计和 transfer map 预测误差；它不会改写 SFT recipe，但会提醒别用“相似任务互助”这种偷懒假设。

PhantomEnvironments: Training LLM Agents in Fictional Worlds

这篇工作要解决的问题不是“怎样把搜索 agent 再调好一点”，而是更前面的训练瓶颈：RL 训练 LLM agent 时，环境从哪里来。一个可用环境需要同时满足三件事：能产生长轨迹交互、终局奖励可验证、还能低成本大规模扩展。现有两条路各有硬伤：基于真实语料和人工标注的环境贵、更新慢、容易把 agent 绑死在固定知识快照上；基于 LLM 合成的环境虽然便宜一些，但会带来 hallucinated reward、benchmark contamination、API 成本和生成器能力上限。作者提出的问题很具体：如果完全不用人和 LLM，只靠规则生成一个虚构世界环境，RL 训练出来的搜索能力能否迁移到真实世界多跳检索任务；以及这种迁移到底学到的是“知识记忆”还是“可泛化的搜索技能”。

评这篇值得看，因为它在动摇“agent RL 必须贴近真实世界数据”的 prior；先看 transfer 主结果和 budget scaling，若 setup 干净，内部可立刻试规则环境做 tool-use 训练。

PATH-Bench: Path-Dependent Evaluation of Lifelong Agents

现有终身LLM智能体的评测基准不控制任务历史的内容与顺序，无法衡量累积经验的路径依赖效应（包括正向迁移、负向干扰、遗忘等）；同时传统终身学习指标需要反复重测全任务集，计算成本过高，不适用于包含多步推理、工具调用的LLM智能体评测。

评把“记忆/技能库”带来的路径依赖做成可控评测，能直接暴露 agent 的迁移-遗忘权衡；只看任务构造方法和 transfer/forgetting 定义即可。
