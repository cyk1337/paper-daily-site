a:T52f,SkillGate introduces two disjoint credit channels within a single policy-gradient update. The task channel uses the usual group-normalized outcome advantage, but removes the entire skill-read tool call from its support. In other words, task success or failure no longer directly updates the tokens that name the chosen skill. The selector channel applies an action-local advantage only to the token span corresponding to the chosen skill name. That selector signal is positive only when the trajectory issued a single read and the selected skill matches the oracle-correct one; it is then centered within the prompt group to reduce between-group difficulty effects. Two implementation details matter. First, rollout-time span attribution records the exact token span of each skill-read action so the support partition is exact in practice. Second, length-invariant reweighting gives equal batch-level loss weight to the two channels and equal share to each read action, preventing selector learning from weakening on longer trajectories. This differs from finer reward shaping: the paper is not slicing the same reward more finely, but separating two decisions that are justified by different evidence. It also differs from pre-execution retrieval methods, because the target here is the policy’s own in-episode skill choice.b:T4ac,The paper first audits the failure mode, then validates the method. In the audit, it analyzes 12,800 on-policy trajectories from a standard outcome-only RL run and reports three key findings. First, share: the median token share of the selected-skill name is only 0.14% of a trajectory, and this shrinks further with horizon. Second, sign: about two in five of those tokens receive negative advantage; on the longest trajectories, a correct choice is punished more often than rewarded. Third, value: within matched prompt groups, making the correct read is still worth +11.2 points in task success, so the decision is important despite receiving weak and noisy credit. The method is then evaluated on five agent benchmarks. The headline number in the provided text is trial success improving from 47.0% to 53.2%. The gains appear concentrated in long-horizon settings with similar-looking candidate skills and noisy downstream execution, which matches the proposed diagnosis. The most important ablations are likely the ones isolating support partitioning, local selector advantage, and length-invariant weighting.
