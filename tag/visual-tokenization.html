LLaVA-OneVision-2: Towards Next-Generation Perceptual Intelligence

这篇工作要解决的不是一般意义上的“视频看得更准”，而是多模态大模型在固定视觉 token 预算下，如何更合理地表示长视频。现有 LVLM 大多仍是 frame-centric：均匀抽帧，或高低分辨率混采。这样做简单，也兼容图像 backbone，但它把视频当成离散帧集合，弱化了压缩视频里天然存在的预测结构：哪些时刻信息增量大，哪些区域只是可预测的延续。LLaVA-OneVision-2 试图把 token 分配从“按时间均匀切”改成“按码流信息密度分配”，让模型把预算集中在事件转折、运动残差高、bit-cost 高的片段与区域，从而提升长视频理解和细粒度时序定位。

评值得看的是视觉 tokenizer 思路，不是榜单；先读 codec-stream tokenization 和 3D RoPE 设计，判断它能否迁移到统一多模态 pretrain。

MUSE: Resolving Manifold Misalignment in Visual Tokenization via Topological Orthogonality

这篇工作讨论的是统一视觉 tokenizer 里一个很具体、也很关键的矛盾：同一套离散或连续视觉表征，既要服务高保真重建/生成，又要服务语义理解，但这两个目标在训练时往往互相拉扯。文中把问题归因为 manifold misalignment：语义目标希望表征对纹理、背景、局部扰动保持不变，倾向于压缩掉无关变化；重建目标则要求保留空间布局和高频细节，倾向于展开表征空间。若两者直接在同一参数通道里联合优化，就会出现梯度冲突，最终形成“重建强则理解弱、理解强则重建差”的零和局面。作者进一步指出，现有统一 tokenizer 往往缺少一个中间层次的结构表征：像素目标过于贴近表面细节，语义目标又过于抽象，真正能连接二者的是结构信息，例如部件关系、空间邻接、轮廓拓扑。

评视觉 Tokenizer 领域的重要进展，通过正交解耦缓解了重建与感知的冲突，值得关注其对多模态预训练的潜在影响。
