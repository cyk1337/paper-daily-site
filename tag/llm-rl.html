Le Critique: Privileged Value Functions for LLM Reinforcement Learning

LLM 强化学习中，以 GRPO 为代表的 group-relative 方法通过同一 prompt 采样多条响应来估计优势，优点是不需要单独的 critic 模型、工程简单；缺点是只有序列级信用分配、训练会被最慢的 rollout 拖慢（straggler 效应）、异步场景下 off-policy 程度更高。基于价值函数的方法（如 PPO）理论上能提供 token 级优势并缓解上述问题，但工程复杂度高，且 critic 拟合不好时性能反而不如无 critic 方法，因此在实践中被边缘化。

评值得看 value 设计和吞吐分析；若实验 setup 干净，它会改变“LLM RL 不值得上 critic”的默认判断。
Siddarth Venkatraman,Matthieu Dinot,Laurence Aitchison

ARMOR: Stabilizing On-Policy LLM RL with Off-Policy Anchor Samples

这篇论文聚焦一个现在很实际的问题：LLM 在 on-policy RL，尤其是 reasoning RL 里，经常出现“训练 reward 持续上升，但验证集性能先停滞再下降”的过优化现象。作者认为这不是传统意义上 reward model 错了，而是在可验证奖励下，策略仍会收缩到少数训练集上高回报但泛化差的解题模式。标准 reverse KL 常被当作稳定器，但论文指出它在这里有两个根本缺陷：一是 mode-seeking，保不住参考策略分布中的多样性；二是惩罚过于均匀，会压制探索，导致训练后期改进停滞。

The Mirage of Optimizing Training Policies: Monotonic Inference Policies as the Real Objective for LLM Reinforcement Learning

ARCA: Adapter-Residual Credit Assignment When Token Signals Degenerate

核心问题是：在 LoRA 等参数高效微调条件下，常见的 token-level credit assignment 信号可能失效。许多 RL 后训练方法默认把轨迹级 reward 重新分配到 token 上，但这些方法通常假设 policy 可以充分更新。ARCA 指出，LoRA 把 policy 限制在 reference model 附近的低秩子空间内，导致基于输出分布差异的 salience 信号，例如 surprisal、entropy reduction、policy divergence，在轨迹内归一化后变成近似均匀，或集中到少量与任务无关的位置。

评精准指出了 LoRA 做 RL 时 token 级别 reward 信号退化的问题，并用 adapter 残差做 credit assignment，对做 post-train 的人很有启发。
Rodney Lafuente-Mercado
