1) Non-identifiability (Theorem 3.2): there exist task pairs with identical probe activations (Zi = Zj) but orthogonal head updates, hence zero head Fisher alignment. The missing piece in representation-only metrics is the logit-space error vector e; head updates depend on the joint geometry of (a, e), not a alone. The paper provides concrete instantiations: disjoint label blocks under a shared-output embedding, and dense-vocabulary “verbalizer shift” where a fixed prefix keeps activations constant but changing the label token changes error geometry.
2) Key identity (Theorem 4.2): in a shared output coordinate system, head Fisher alignment equals a cosine similarity between kernel mean embeddings of the joint (a, e) distribution. This turns Fisher-matrix comparison into a distributional embedding problem and yields an explicit decomposition into activation geometry, error geometry, and their coupling.
3) FisherSketch: a one-pass streaming random-feature estimator (using SRHT-style projections) that directly estimates the product-kernel cosine without materializing K×K error moments or paying O(mK) per-sample projections. The pipeline has three stages. First, for each training pair, the instruction-tuned model runs once offline to produce token-level confidence scores q_t on the reference response. Second, these scores are used to reweight the token-level negative log-likelihood when training the adapter on the base model: tokens that the instruction model finds uncertain contribute less, while tokens it supports confidently contribute more. The motivation is that many target tokens are stylistic, formatting-related, or otherwise substitutable, and forcing the base model to fit them equally can inject noisy updates that later merge poorly into the instruction model. Third, the learned adapter is merged into the instruction-tuned model using a standard merge operator such as LoRA merging. Relative to Shadow-FT, Chat Vector, and related base-train-then-merge methods, the novelty is not in the merge rule but in using the instruction model during training to shape the learning signal.
