17:T499,MetaEvolve combines (i) trajectory-aware data synthesis, (ii) evolution-aware RL, and (iii) inference-time evolutionary search.
- Data synthesis: starting from ~25k coding problems, sample multiple candidate programs per problem (example: 10). Apply a two-stage diversity filtering to keep problems/solution pools where attempts are sufficiently different, using simple structural proxies (e.g., character length and line count differences) to ensure the history contains learnable variation.
- Evolution-aware RL: train the model on inputs that explicitly include the current solution, performance feedback, and a history of prior attempts; the target is an improved program. Rewards are verifiable via execution and include continuous runtime signals in addition to correctness, making “working vs. better-working” optimizable.
- Inference-time loop: keep the same multi-round generate-and-evaluate loop at test time, so the model is trained under a distribution closer to how it will be used.
