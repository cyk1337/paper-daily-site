Memory Grafting: Scaling Language Model Pre-training via Offline Conditional Memory

如何把“条件记忆（conditional memory）”扩到很大规模，同时不把训练成本也按参数量一起放大。以 Engram 为代表的 n-gram 哈希记忆在推理侧很省（O(1) 查表、吞吐损失小），但训练侧需要从零学习巨大的记忆表，记忆参数占比过高时训练效率会明显下降。论文要解决的是：能不能把记忆表从“要训练的参数”变成“可复用的知识载体”，把主要成本挪到一次性的离线计算。

评应读方法和消融：若收益在同算力下成立，外部 frozen memory 会改变预训练容量扩展的默认做法。
