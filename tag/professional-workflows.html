Workflow-GYM: Towards Long-Horizon Evaluation of Computer-use Agentic tasks in Real-World Professional Fields

Workflow-GYM 关注 GUI agent 的长程真实工作流评测：现有 GUI benchmark 多数偏短任务、通用软件和简单操作，难以判断 agent 是否能在专业软件中完成有经济价值的端到端任务。它把问题设定为：只给自然语言目标，不给中间提示，agent 需要在已配置好的专业软件环境中规划、操作、纠错，并产出可验证结果。

评填补了专业领域长周期GUI Agent评测的空白，30%的低成功率表明当前模型在复杂长序列决策上仍有巨大提升空间，值得关注其任务构造和评测指标。
