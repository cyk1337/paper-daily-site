Re-evaluating Confidence Remasking in Masked Diffusion Language Models

这篇论文要解决的不是“如何再发明一个 remasking 方法”，而是一个更基础也更关键的问题：在 masked diffusion language model 里，训练后、基于 token confidence 的 remasking 到底什么时候真的有用。已有工作把 remasking 作为对 masked dLLM 早期决策错误的自然补救，因为一旦 token 被 unmask，标准 masked diffusion 解码就不能再改它。问题在于，早期结果往往把 remasking 的收益和更强的 confidence-based unmasking 混在一起，没有把额外延迟成本、解码策略、采样温度、block size 等因素拆开。作者重新评估代表性方法 WINO，结论很明确：在标准设置下，post-hoc confidence remasking 的增益远小于先前印象，很多时候几乎没有净收益；只有在特定解码条件下，它才会表现出可见帮助。

评这是 diffusion LM 里该读的“去泡沫”论文：它提醒你很多 decoding 改进只是在宽松设定下成立，建议立刻按它的 protocol 重查内部结果。
