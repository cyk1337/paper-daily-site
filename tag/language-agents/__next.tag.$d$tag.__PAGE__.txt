a:T4c0,EVAF (Echo-Valence Attractor Field) is framed in the complementary learning systems (CLS) spirit: a fast working-memory state and a slow parametric store with selective consolidation.
- State geometry: the prefix hidden state s(t) is treated as fast working memory constrained to a per-token product manifold (motivated by high-dimensional thin-shell concentration). This is used to make “echo/attractor” effects more measurable.
- Dual-gate selectivity: consolidation is triggered by a combination of surprise (novelty) and valence (value/emotional tag), mirroring the CLS idea that only salient novel events shape the slow store.
- Algorithmic ingredients: the paper positions itself as reusing continual-learning components (e.g., replay, EWC-style anchoring, PEFT updates) but focusing on characterizing the consolidation decision and its signatures.
- Evaluation protocol: a test–retest setup intended to distinguish retrieval/context carryover from true parametric change by repeatedly probing behavior/representations over time.

First, it controls task relationships through two types of streams: naive streams and compositional streams. Naive streams simply order tasks without carefully structuring reusable dependencies. Compositional streams are deliberately designed so that earlier tasks expose reusable sub-solutions, evidence, or workflows that later, more complex tasks can compose. This makes transfer testable rather than anecdotal.

Second, the paper introduces a two-pass evaluation protocol and targeted metrics such as Plasticity Gain, Stability Gain, and Generalization Gain. The excerpt provided here does not include the full formulas, but the intent is clear: plasticity measures adaptation to new tasks, stability measures retention under growing memory, and generalization measures whether experience transfers beyond directly repeated cases. This is a much better fit for continual learning than a single average score.

Third, the authors evaluate non-parametric memory designs and introduce MemProbe, a probing method for analyzing which memory components help, which ones interfere, and how discriminative the benchmark itself is. A notable design choice is the strict setting: memory is built without ground-truth guidance, and the agent must synthesize memories from its own trajectories. That keeps the benchmark closer to realistic online agents rather than offline supervised memory construction.c:T41e,The experiments span coding, deep research, and language reasoning domains. The main findings are threefold. First, naive streams have weak discriminative power: performance differences among memory designs get compressed, making many methods look similar. Second, compositional streams amplify plasticity differences and make transfer effects much easier to detect. Third, stability remains a clear bottleneck. Even when a memory design achieves meaningful transfer gains in compositional streams, it can still induce cognitive interference or outright degradation in naive and held-out settings.
