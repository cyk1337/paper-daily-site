9:T6cb,The proposed method is Adaptive Log-Space (AL) quantization, embedded in a broader analysis of optimizer-state heterogeneity. The authors first observe that many non-negative optimizer states, especially second moments and confidence accumulators, are heavy-tailed, vary in dynamic range across blocks, and often contain exact zeros. Standard blockwise linear quantization can collapse small positive values to zero, which destroys the distinction between dormant state and weak but nonzero history. AL addresses this by fitting a logarithmic interval to the positive values within each block while reserving code zero exclusively for exact zero, yielding the invariant q = 0 if and only if x = 0. This preserves true zeros and prevents positive second moments from being quantized away into zero. The design is not a single uniform low-bit policy. Non-negative states can use AL8 or AL16, signed momentum is encoded separately, and CAME confidence states may use higher precision than second moments. A second key idea is topology-aware grouping. The paper shows that quantization blocks should align with the optimizer’s state topology: cutting across Adafactor row/column factors or mixing unrelated statistics in one block can amplify update error. The study covers four optimizer paths—dense AdamW, factored Adafactor, confidence-guided CAME, and projected-state APOLLO—and evaluates not only state reconstruction but also update-domain fidelity, temporal drift, and error propagation through inverse square roots, factor reconstruction, confidence modulation, and projected scaling. The implementation includes both a Python reference path and fused CUDA kernels, with separate checks for algorithmic and numerical consistency.a:T5a3,The experiments are organized into controlled diagnostics and end-to-end pretraining runs. In the diagnostic part, the authors trace optimizer states from language-model pretraining and compare their value ranges, exact-zero patterns, and temporal behavior. They then evaluate how different quantization schemes affect both state reconstruction and update error. The conclusions are deliberately nuanced rather than universal. For dense AdamW, AL8 is competitive with the evaluated 8-bit AdamW baseline. For CAME, confidence states are more precision-sensitive than second moments, so using too low a precision there hurts update fidelity more noticeably. For Adafactor, protecting sensitive tensors and matching quantization granularity to row/column factor topology is materially better than coarse uniform blocking. For APOLLO, projected-space states exhibit yet another error-propagation pattern, reinforcing the point that they should not be treated as ordinary dense arrays. The end-to-end validation uses 20K-step TinyLlama-1.1B pretraining and 100K-step GPT-2 pretraining. The paper’s overall conclusion is bounded: AL8 can match existing 8-bit baselines on several paths, but a single low-precision recipe is not sufficient for all structured optimizer states. - Forward sensitivity (transport): define q_t=\partial S_t/\partial \alpha for a source-strength parameter \alpha. The recurrence includes (a) injected source perturbations d_t (teacher-induced gradient changes) and (b) feedback through \partial G/\partial S because past perturbations alter w_t and therefore future gradients.

Compute the costate p_T=(\partial O/\partial S_T)^\top and propagate it backward to obtain a per-step “future value” \lambda_t capturing how valuable a state perturbation at time t is for the final behavior.

1) Key observation (linear-layer gradients lie in activation span): for a linear layer, the weight gradient is G_W = X^T G_out, hence it lies in the span/column space of input activations X. Therefore, if activations are approximated in a rank-r subspace, gradients admit an optimal rank-r representation in the same subspace.
2) Compress activations while keeping forward exact: OASIS does not modify forward-pass computation. It only projects and stores intermediate activations for backward:
- Store \tilde X_t = X_t U_t (N×r) instead of X_t (N×d).
- Perform gradient/optimizer computations in the low-rank space and project updates back via U_t.
3) Joint low-rank gradients and optimizer states: since gradients are kept as (r×m), Adam’s first/second moments can be stored and updated in the same low-rank space, reducing memory from O(dm) to O(rm) per layer.
4) Online subspace learning (core novelty): U_t cannot be fixed because activation distributions drift as parameters change. The paper uses Oja’s rule (streaming PCA) to update U_t incrementally without repeated exact eigendecomposition.
5) Projection-aware state updates: when U_t changes, low-rank momentum/variance states must be transformed to remain consistent with the new basis; otherwise optimization becomes unstable. Following LDAdam, they apply projection-aware alignment of optimizer states after subspace updates.
6) Cost/benefit: per layer, activation storage drops Nd→Nr; gradients and optimizer states drop dm→rm. Extra overhead comes from maintaining U_t and projections, aiming for large peak-memory savings with acceptable throughput/accuracy.e:T4e9,(must_read: deep reading)
