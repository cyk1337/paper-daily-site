5:T773,TriRoute 的核心是一个共享 controller。对每个 layer、每个 token，它同时输出三类决策。第一是 attention mode，候选包括 skip、local-window、full，决定该 token 在当前层使用多少注意力分辨率。第二是 FFN expert routing，在 E 个专家中选稀疏子集，并引入一个 null expert，把 MoD 式的 FFN skip 视为专家选择的特例，而不是额外分支。第三是 KV bit-width，决定该 token 自己写入 cache 时用 2/4/8/16 bit 中哪一档，从而影响未来 token 检索它时的保真度。这个设计的关键不是把三件事并排放在一起，而是共享同一份 token 表征，让路由器学到“什么 token 值得在哪些资源上花钱”。

训练上有三块技术处理。其一，三类决策的离散空间异质性很强：expert routing 是大类别稀疏选择，attention mode 和 bit-width 是小规模但代价差异很不均匀的分类。作者采用按轴定制的 straight-through / Gumbel-Softmax 松弛，并做温度退火，尽量让梯度尺度可比。其二，作者强调 cross-axis collapse cascade：如果 attention router 先学会大面积 skip，下游 FFN router 看到的输入分布会退化，进一步失去区分能力，bit router 也会变得无意义。为此论文设计了 coupling-aware balancing objective，不只做单轴 load balancing，而是抑制一个轴塌缩后拖垮其他轴。其三，预算控制采用统一可微 cost model，把 FLOPs 和 KV memory 合成单一成本，再用在线 Lagrangian dual 调节，使目标平均预算 C* 成为唯一外部旋钮。这样用户不需要分别调 expert sparsity、depth sparsity 和 quantization ratio。论文还探索 shared vs separate routers，以及 token/per-head/per-layer-group 的路由粒度，最后发现 attention 用 per-head routing，而 FFN 与 bit routing 用 token-level，是较好的折中。6:T71b,TriRoute uses a shared controller that emits three coordinated decisions for every token at every layer. First, it chooses an attention mode: skip, local-window, or full. Second, it performs sparse FFN expert routing over E experts, with a null expert that recovers MoD-style FFN skipping as a special case. Third, it selects the bit-width used when the token writes its own key/value to the cache, choosing among 2, 4, 8, and 16 bits. The key idea is not just to place three routers side by side, but to let them share token representations so the model can learn which tokens deserve which kinds of resources.

Training this system is nontrivial because the routing spaces are heterogeneous. Expert routing is a large sparse categorical problem, while attention mode and bit-width are small categorical choices with highly uneven sensitivities. The paper uses per-axis straight-through / Gumbel-Softmax relaxations with temperature annealing to keep gradients usable. A second technical issue is cross-axis collapse. The authors argue, and empirically show, that collapse in one axis can induce collapse in the others: if attention routing becomes overly skip-heavy, the FFN router sees degraded inputs and loses discrimination, which then makes bit allocation less meaningful. To address this, they introduce a coupling-aware balancing objective rather than relying only on standard single-axis load balancing. Third, they define a unified differentiable cost model that combines FLOPs and KV memory, and enforce a target average budget with an online Lagrangian controller. This gives a single external budget knob. The paper also studies design choices such as shared versus separate routers and routing granularity, finding that per-head attention routing with token-level FFN and bit routing is a good trade-off.7:T51f,The experiments span decoder-only models from 160M to 1.3B parameters, trained at compute-optimal token budgets. The main empirical claim is Pareto improvement: at matched inference FLOPs and memory, TriRoute outperforms the best independently tuned combination of MoD, MoE, and KV quantization. The paper also emphasizes better preservation of tail-case accuracy, especially on rare or semantically important tokens, which is exactly where isolated sparsity methods often fail. Several ablations are important. Shared routing generally beats fully separate routers, indicating that the three axes do carry exploitable correlations, although interference appears at very high sparsity. Routing granularity matters as well: attention benefits from per-head decisions, while FFN and bit-width routing do not obviously need finer granularity than token level. Another key result is that the coupling-aware balancing loss improves training stability; without it, one routing axis can collapse early and drag the others down. The unified budget controller also appears to produce smoother cost-quality trade-offs than tuning three mechanisms independently.
