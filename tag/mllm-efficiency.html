An AI4AI Framework for Visual Token Pruning

这篇工作解决的是 MLLM 视觉 token 剪枝策略设计过度依赖人工经验的问题。现有方法往往要手工设定 token 重要性、预算分配、约束选择和重组规则，设计空间大，而且不同 backbone、不同 token budget、不同任务下都要重新调。作者的问题设定不是再发明一个固定剪枝启发式，而是：能不能让 LLM 自动搜索并组合出有效的视觉 token 剪枝算法，同时保证生成的策略满足约束、可执行、可迁移。

评只看搜索状态表示和消融；若结果干净，它比又一个视觉 token heuristic 更值得内化到推理效率工具箱。
Zhen Liu,Wenli Huang,Wei Song,Yuhan Liu,Zhiqin Yang,Jingwen Fu

ERA: Entropy-Guided Visual Token Pruning with Rectified Attention for Efficient MLLMs

现有免训练MLLM视觉token缩减方法存在两个核心缺陷：一是token重要性评估仅采用单一或简单组合准则，忽略不同注意力头的专属显著性模式；二是剪枝/合并操作会触发“注意力logit坍缩”——视觉token的累计注意力logit被系统性低估，导致注意力分布向系统/指令token偏移，损害生成质量。

评做MLLM推理优化的研究员重点看注意力logit坍缩的分析和LAR修正模块，其他方向可跳过。
Yuhao Wang,Mu Qiao,Haiwen Diao,Yunzhi Zhuge,Pingping Zhang,Xindong Zhang,Lei Zhang,Huchuan Lu
