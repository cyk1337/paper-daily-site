Deeper is Not Always Better: Mitigating the Alignment Tax via Confident Layer Decoding

这篇工作讨论的是一个很具体、但过去默认不被质疑的设定：自回归 LLM 在生成下一个 token 时，为什么一定要用最后一层的 logits。作者沿着全文的分析给出一个更细的结论：深层表示并不总是单调变好，很多 token 在中后层已经形成了较稳定、对推理更有利的语义判断，但最后几层会把这个判断往更泛化、更保守、或更符合对齐偏好的方向推偏。论文把这种层间演化概括为 Guess–Refine–Perturb：前层先做粗猜，中间层完成语义收敛，末层对一部分 token 发生扰动。核心问题因此不是“能否早退以节省算力”，而是“在不改模型、不重训的前提下，怎样在每个生成步选择更可靠的输出层，减少末层扰动带来的 alignment tax 和 reasoning degradation”。

评推翻“最后一层解码最优”的领域默认假设，末层对齐扰动的发现应立刻加入预训练-后训练接口的内部ablation，重点看Fig2的层熵变化曲线。

PR2: Predictive Routing Replay for MoE-Based LLM Reinforcement Learning
