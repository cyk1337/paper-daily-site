a:T7eb,AdaLook is built on top of the Explore-then-Exploit (ETE) decoding framework. The base decoder uses block diffusion decoding: the sequence is partitioned into blocks, each block receives a fixed denoising budget, and high-confidence tokens can be committed across all unlocked blocks to increase parallel progress per step. In ETE, lookahead is triggered when the model remains uncertain over masked positions, and a one-step rollout estimates which tentative token commitment is most likely to unlock more confident predictions in the next state.

AdaLook adds two key mechanisms. First, it introduces adaptive rollout depth. Instead of always using a fixed 2-step or 3-step lookahead, the decoder decides whether another rollout step is worthwhile by examining the variance of candidate scores at the current frontier. If candidate futures are already similar, deeper rollout is unlikely to pay off; if they remain well separated, extra exploration may still be useful. This addresses the mismatch between heterogeneous decoding states and a globally fixed rollout depth.

Second, AdaLook allows branch re-evaluation and re-expansion at intermediate rollout states. A naive multi-step rollout follows each hypothesis along a predetermined path until the preset depth is reached. AdaLook instead checks after every rollout step whether each branch still needs expansion. Branches that have become sufficiently resolved are prioritized for selection. If all branches remain uncertain, the highest-scoring branch is chosen and its decoding state becomes the starting point for the next round of lookahead. The gain does not come from searching deeper in a brute-force sense, but from making depth and branching conditional on the evolving uncertainty pattern.

Algorithmically, this is closer to a lightweight confidence-driven adaptive tree search than to fixed-depth beam search. The method exploits the parallel update nature of DLMs and reframes token commitment as a dynamic planning problem over short future trajectories.b:T47c,From the available full text, the main empirical claim is clear: simply increasing lookahead depth does not improve the accuracy-versus-decoding-step trade-off, whereas AdaLook consistently outperforms prior one-step lookahead decoding. In the warm-up stage, every test query receives a small fixed budget. In the adaptive stage, additional compute is focused only on unresolved queries. The key step is that the model no longer simply resamples from the original distribution. Instead, it retrieves semantically similar solved examples from the evolving pool and prepends them as in-context demonstrations before generating new responses. As more questions are solved, the pool grows, and the effective conditional distribution for later generations changes over time. This creates a single loop that couples compute allocation with distribution adaptation. Relative to prior work, the method avoids per-query search procedures and does not require a separately trained verifier or policy. Relative to difficulty-based allocation alone, it aims to improve the quality of each additional sample, not just the quantity.
