Beyond Accuracy: Prefix-Invariant Realizations of Low-Precision Fast Matrix Multiplication

这篇工作讨论的不是“快矩阵乘法准不准”，而是“它会不会破坏因果语言模型最基本的前缀不变性”。在线性层里，激活矩阵的行对应不同 token 位置。若用 Strassen 一类 fast matrix multiplication，在精确算术下，不同行之间的混合项会严格抵消；但在低精度实现里，这些混合项会先经历量化、缩放和舍入，抵消不再精确，于是后续 token 的信息可能泄漏到前面 token 的输出。这样一来，某个位置的 logits 不再只依赖其允许看到的 prefix，而会依赖本不该看到的后文。对多选题 likelihood scoring、packed serving、批量打分这类场景，这不是小数值误差，而是语义层面的错误来源。论文要解决的核心问题，就是如何判断并构造一种低精度 fast matmul realization，使它在保留乘法节省的同时，严格继承经典逐行算子的 prefix invariance。

评只看 prefix-invariance setup 和 OpenBookQA 表；这是 kernel 语义 bug，不是一般量化误差。
Shuxiao Xie,Shuyang Xie,Yuan Cao,Dezhi Ran,Wei Yang,Tao Xie
