18:T4b5,CHIAR-Former is a 4-layer hybrid transformer. For each token, the model computes spectral entropy from the DCT power spectrum of its representation and routes the token to one of three operators: DCT spectral mixing, RBF kernel mixing, or full self-attention. Low-entropy tokens are treated as smooth and sent to DCT mixing. High-entropy tokens are treated as complex and sent to attention. Mid-range tokens are initially assigned to an RBF kernel branch implemented with random Fourier features.

The paper provides a theoretical motivation for this partition: low-entropy tokens admit bounded DCT truncation error, medium-entropy tokens can be handled by kernel approximation, and high-entropy tokens benefit from dynamic cross-token projection. Relative to FNet, the key difference is selective rather than universal spectral mixing. Relative to Mixture-of-Depths or LayerSkip, the model does not skip computation but changes the operator type while preserving depth. The most important technical outcome, however, is that learned routing collapses: the router repeatedly rejects the RBF branch. The authors then embrace that result and build a DCT+Attention-only variant as the effective architecture.19:T410,The headline number is on WikiText-103: the DCT+Attention variant reaches validation perplexity 36.54 versus 66.6 for a full-attention baseline, while using 62.5% fewer attention FLOPs. If the setup is fully matched, that is a large gain. Because the gain is so large, the first thing to verify is baseline fairness: same parameter budget, same training schedule, same context length, same optimizer, and same data exposure.

The broader experimental claim is more interesting than the single best result. The paper reports evaluations on four datasets and finds a clear operating regime: spectral routing helps more on larger, naturalistic text corpora, but loses to full attention on small datasets and synthetic pattern-matching tasks. That boundary condition is informative. The most important ablations are likely: three-way routing versus DCT+Attention-only, sensitivity to entropy thresholds, and whether routing collapse is stable across seeds and datasets.
