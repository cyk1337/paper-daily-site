9:T894,技术上，论文先把“realization”定义清楚：同一个 fast matrix multiplication 算法，系数、量化方式、缩放策略、执行顺序不同，量化后行为会很不一样。作者分析的是两层 Strassen 在 FP8 下的 realization。已有稳定性准则通常只看系数幅值，例如误差上界参数或期望误差指标；但这些准则对 sign variants 不敏感，而 sign flip 在精确算术下不改变算法，在低精度下却会显著改变量化后的行为。作者先用这一点说明，现有准则不足以筛掉会破坏 prefix invariance 的 realization。

随后论文给出一个结构性结果：如果要求每个中间乘积在形成时就不能混入“未来行”信息，那么任何 realization 都会退化到经典乘法次数，无法保留 fast algorithm 的乘法节省。也就是说，想省乘法，就必须允许中间量跨行混合；问题不在于是否混合，而在于这种混合能否在最终输出前被无舍入地精确消掉。

基于这个观察，作者构造了 certified realization。做法不是在浮点值上直接混合，而是先对每个 token row 独立量化成整数 codes，之后 fast algorithm 的块和、块乘、抵消都在有界整数域里完成。因为整数求和不发生舍入，只要中间范围受控，跨行混合项就能被精确抵消。缩放因子则延后到整数乘加之后，再按 classical int8 operator 的方式应用。作者设计了一个 certificate，检查两件事：一是整数计算全过程不会溢出、因此保持精确；二是最终缩放与累加顺序可与 classical int8 完全对齐。凡是通过 certificate 的 realization，输出都与 classical int8 bit-for-bit 相同，因此自动继承其 row-local 性质和 prefix invariance。

Existing stability criteria typically depend only on coefficient magnitudes, for example through rounding-error bounds or expected-error surrogates. But sign variants of the same exact algorithm share those magnitude-based scores, even though sign flips can materially change quantized behavior. This already suggests that common criteria are too coarse for selecting realizations that preserve causal semantics.

The authors then prove a structural limitation. If one insists that every intermediate product feeding an output row must itself avoid dependence on later rows, then one is forced back to the classical multiplication count. In other words, any realization that keeps the fast multiplication savings must allow intermediate cross-row mixing. The real question is whether that mixing is undone exactly before the final output is formed.

Their certified construction answers yes by moving the cancellation into bounded integer arithmetic. Each token row is quantized independently into integer codes. The fast algorithm then mixes, multiplies, and cancels these integer codes rather than floating-point values. Since integer sums do not round, cross-row terms can cancel exactly as long as intermediate ranges remain bounded. Scaling factors are applied only afterward, aligned with the classical int8 operator. The certificate checks two things: that the integer computation remains exact throughout, and that the final scaling and accumulation can be matched to classical int8 in the same order. Any realization that passes the certificate is bit-for-bit identical to the classical int8 operator with the same codes and scales. Because the classical int8 operator is row-local, certified realizations inherit prefix invariance automatically.

A notable result concerns the 512 sign variants of two-level Strassen. Under ordinary FP8 block scaling, these variants can behave wildly differently after quantization. Under the certified int8 construction, all 512 pass the certificate and produce identical output bits.
