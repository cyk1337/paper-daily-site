18:T6d9,The framework has three main components. (1) Stochastic Condition Masking, SCM. During training, the aligned modality set is randomly partitioned into clean conditions and noisy targets. The targets are generated through the diffusion denoising process, while the conditions are provided as observed inputs. This forces the same text-to-video backbone to handle text-only, visual-only, and hybrid conditioning, instead of specializing to a fixed mapping. The key point is that the task definition itself is randomized, so one model can cover Text→X, X→X, and Text&X→X. (2) Decoupled Gated LoRA, DGL. Different modalities have different output distributions. Sharing one adapter across them causes interference, while full fine-tuning risks damaging the pretrained video prior. The paper assigns an independent LoRA to each modality and activates it only when that modality is a generation target. Condition modalities do not trigger their LoRA branches. This keeps adaptation localized to the output side that actually needs distributional adjustment. (3) Cross-Modal Self-Attention, CMSA. The model shares keys and values across modalities while keeping modality-specific queries. Shared K/V encourages all modalities to read from a common spatiotemporal context, improving alignment; separate Q preserves modality-specific retrieval behavior. Compared with fully separate attention, this increases dense cross-modal interaction. Compared with fully shared attention, it retains modality specificity.
