iCoder-27B: Recursive AI-Led Development of Frontier Industrial Coding Model

这篇工作要回答的问题不是“agent 能不能帮忙做研究”，而是更难的版本：在开发一个可发布、前沿竞争力的工业代码模型时，人类最少需要介入到什么程度，agent 才能主导完整研发闭环。这里的难点不在单个实验自动化，而在数据构建、训练目标、后训练、评测、资源分配和失败诊断彼此耦合，前一阶段的决策会改变后一阶段的搜索空间。论文把这个问题具体化为一个真实模型开发案例：让 Codex GPT-5.6-Sol 在人类只提供“高密度先验、低频干预”的前提下，主导 iCoder-27B 的研发。

评别把它当“自动科研已成”来读；真正该看的是 agent 如何接管数据与 RL 闭环，以及人类先验被压缩成什么接口，这对 post-train 体系设计有参考价值。
