Simthesizer: An Agent-Driven Simulation Framework for LLM Serving Systems

这篇论文解决的是 LLM serving 系统模拟器跟不上真实 serving 形态变化的问题。传统模拟器通常假设一次请求对应一条固定、单体的推理流水线，但现在的 serving 已经出现 agentic workflow、外部工具调用、动态分支、prefill/decode 解耦、speculative decoding、KV cache 量化、混合 Mamba/Transformer 等机制。每加入一种机制，旧模拟器往往需要改执行引擎，维护成本高，也难以校准真实系统行为。

评读方法不读宣传：动态图抽象可能适合 internal serving what-if 模拟，agent 生成部分要看约束是否足够硬。
