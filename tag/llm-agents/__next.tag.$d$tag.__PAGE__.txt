- Task representation: tool-use tasks are encoded as Python programs (environment state, databases, tools, goals). This makes compositional mutation feasible and preserves compatibility with existing harnesses, but introduces risks of format/underspecification artifacts.
- Proposer: implemented via AlphaEvolve, a gradient-free evolutionary search operator. A practical point is that it can leverage strong closed-source LLMs as proposers via API calls, since no gradients/weights are needed.
- Solver: the target model under evaluation; each candidate mutated task is attempted N times to estimate an empirical completion rate.
- Fitness shaping: reward targets “hard but solvable” by pushing completion rates toward ~50%, motivated by maximal variance / maximal discriminative power near 0.5 (akin to learnability sampling).
- Feedback generator: summarizes failure reasons from execution traces plus the ground-truth solution, producing exploitable signals for the proposer’s next mutations.
- Post-filtering: an LLM judge (Gemini 3.6 Flash) removes trivial failures (format mismatches, ambiguous instructions, near-paraphrases), which is crucial to prevent evolution from exploiting loopholes.

Each agent b controls block xb and has a cheap local objective Lb that ignores interactions. Define the true conditional change fb(u;x)=F(x with xb←u)-F(x). The key construct is a correction term Rb capturing the interaction effects missing from Lb; agents instead optimize a corrected surrogate \hat{f}_b(u;x)=Lb(u)+\hat{R}_b(u;x), where \hat{R}_b approximates Rb and is anchored so \hat{R}_b(xb;x)=0.
Protocol: (1) parallel private search—each agent proposes an update u_b by optimizing \hat{f}_b with other blocks frozen; (2) exact verification—coordinator evaluates true global deltas via F; (3) compatibility-based merging—build a dependency graph over proposals and select a non-interfering subset (via coloring) to merge, guaranteeing non-increasing F. Extension: even interfering proposals may be merged if the coordinator verifies that their joint application yields a larger decrease; the convergence rate then depends on the realized joint improvement rather than worst-case interference.
Theory: linear convergence up to an explicit error floor determined by correction approximation error; the floor vanishes with exact corrections. - Policy: propose actions given current observation and goal.
- World model: generate the next visual observation (an imagined image) conditioned on the action.
- Reasoner/evaluator: compare imagined futures in language space and decide which action/plan to execute.

Two-stage training:
1) Supervised fine-tuning with interleaved trajectories that explicitly teach the model to treat imagined observations as valid context for continued planning. The paper uses three planning formats: (i) linear rollout (single imagined trajectory), (ii) counterfactual branching (branch on alternative actions at a step and reject failing branches), and (iii) forward thinking (imagine and compare longer candidate plans before committing).
2) Agentic RL using GRPO with only a binary success reward. No extra demonstrations are provided; RL shapes how the model allocates imagination and comparison—when to explore another plan, how many alternatives to branch, and where branching matters—while keeping generated images as context during planning.

A key design choice is “single model, shared interface” instead of separate policy and world models, so imagined vs. real observations can be swapped seamlessly and RL can directly sculpt the reasoning/search strategy rather than only the action distribution.d:T432,Benchmarks include Maze2D, Sokoban, Pacman, and PushT, trained on easier instances and evaluated on harder settings excluded from training.

Second, after the base model emits a tool call, a validator checks the tool name, required fields, and argument structure, returning structured error information rather than a binary valid/invalid flag.
