Learning Personalized Memory Gating from Delayed One-Sided Feedback

这篇工作研究的是个性化 memory gating：在长期用户—LLM 交互里，系统从每轮对话抽取很多候选事实，但存储预算和上下文预算有限，必须决定哪些事实值得留下。已有方法多用对所有用户共享的启发式规则，或者从长上下文数据里学一个统一策略，难点在于不同用户对“什么值得记”差异很大，而且真正可靠的监督信号是延迟出现、且只对已存入的事实可见的。论文把这个问题明确建模为 one-sided delayed feedback 的 apple tasting 问题：未存入的事实永远看不到反事实收益，已存入的事实只有在未来被检索并被回答使用时，才暴露出效用信号。

评将Agent记忆写入抽象为带延迟反馈的bandit问题，理论框架干净，对做Agent长期记忆系统的研究员有参考价值。
