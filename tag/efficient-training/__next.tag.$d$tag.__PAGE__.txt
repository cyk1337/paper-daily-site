c:T5ae,The first component is offline top-K logit distillation. For each token position, the teacher’s top-K probabilities and indices are cached once, with K=100 in the main setup. Importantly, the retained mass M is not renormalized to 1. Instead, the forward KL is rewritten exactly for a truncated teacher distribution: the loss decomposes into a teacher-entropy term, a cross term over the retained support, and an M log Z term that depends on the student’s full-vocabulary log-normalizer. This means the implementation only needs to gather student logits on the top-K support plus compute a scalar logsumexp over the vocabulary, rather than materializing dense teacher and student distributions. The paper discusses three mathematically equivalent offline variants, differing only in how densely they instantiate tensors. The second component is a fused, chunked KL loss. Borrowing from recent fused CE kernels, the authors fuse the output projection with the loss and chunk along the sequence dimension so that dense B×S×V tensors are never materialized. Because the target is a sparse teacher rather than a one-hot label, the gradient differs from standard CE: support tokens subtract teacher mass, while off-support tokens only enter through the truncated mass M times the student softmax. This yields a sparse forward-KL kernel whose peak memory scales roughly linearly with sequence length, enabling longer-context distillation on a single GPU.d:T6ec,The method, One-Step-Train (OST), starts from the classical leave-one-out and influence-function view of data valuation. Exact LOO is too expensive because it requires retraining per sample. Influence functions avoid retraining but require inverse-Hessian computations, which are unstable and costly in large non-convex models. OST replaces both with a prospective one-step approximation: start from a fixed checkpoint, apply a single gradient step on one candidate sample, and estimate the resulting change on a validation anchor set. Under first-order approximation, the utility reduces to a gradient alignment score between the sample gradient and the validation gradient, avoiding Hessian inversion entirely.

Several design choices matter. First, scoring is done with a lightweight proxy model rather than the target model, which makes the method deployable. Second, the validation anchor set defines what counts as useful, so OST is target-conditioned rather than a universal quality score. Third, the paper studies which proxy checkpoint to use and finds a non-monotonic effect: around 5% warm-up works best, while fully converged proxies absorb synthetic noise and hallucinations, degrading ranking quality. Fourth, OST produces a ranking rather than a hard filter, so practitioners can choose top-k subsets under different compute budgets.

Compared with heuristic selectors such as DEITA, OST is closer to actual optimization objectives. Compared with LLM-as-a-Judge, it avoids external preference leakage and much of the inference cost. Its limitations are also clear: the approximation is local and first-order, it ignores higher-order sample interactions, and its quality depends on proxy-target alignment and on how representative the validation anchors are.e:T503,The experiments are built around multimodal mathematical reasoning with the Qwen family, especially Qwen3-VL-style SFT settings. The router is a two-layer MLP that reads the current hidden state of each token and emits a sigmoid halting probability. This probability softly gates the residual update of the next block: when the gate is high, the token largely skips that layer’s attention and FFN update; when it is low, the model behaves like a standard Transformer. 2) Key insight: the practical difficulty in Muon’s polar approximation is not the need for exact orthogonality. The original Muon already tolerates fairly inexact orthogonalization (e.g., mapping singular values only roughly into [1-ε,1+ε] with ε up to ~0.3). The real issue is that the input momentum matrix can be ill-conditioned with an unfavorable singular-value spectrum, slowing NS convergence. Muon2’s second-moment preconditioning empirically improves the spectrum/conditioning, which:
- speeds up NS convergence to a practically sufficient orthogonalization;
- improves directional alignment of the finite-iteration update with the “true” orthogonalized direction.
3) Metric shift: the paper argues that orthogonality error metrics (e.g., \|Q^TQ-I\|) alone do not capture what matters for optimization; directional alignment and finite-iteration utility are more relevant.
4) Muon2-F: a memory-efficient variant using a factorized second-moment preconditioner to avoid storing full second-moment tensors, retaining most of Muon2’s gains under large-scale memory constraints.
