Learning What to Forget: Improving LLM Unlearning via Learned Token-Level Importance

这篇工作处理的是 LLM unlearning 里一个很实际但常被粗糙处理的问题：给定一条需要遗忘的样本，真正承载待删除知识的 token 只占一部分，很多 token 只是通用语言结构。如果对整条 forget sample 一视同仁地施加 forget loss，就会把结构性 token 也一起压低，结果是 retain 能力受损，但目标知识未必删得更干净。作者要解决的核心问题是：能不能不依赖外部标注、辅助模型或启发式规则，而是直接从 forget objective 与 retain objective 的冲突关系中，学出 token 级别的“该忘程度”。

评不是 pretrain 主线，但把 unlearning 写成 retain/forget 冲突分解这点很干净；先看理论定义和消融，若大模型实验不扎实就当目标设计信号。

Filter, Then Reweight: Rethinking Optimization Granularity in On-Policy Distillation

这篇工作讨论的是 on-policy distillation 里的监督粒度问题：学生模型在自己生成的轨迹上接受教师监督时，不同 rollout 的可学性不同，不同 token 的信息量也不同；如果仍然对所有轨迹、所有 token 一视同仁地做全轨迹 KL 或 PPO 风格蒸馏，会把大量低质量、低可靠性的信号混进优化里。论文要解决的是，如何同时在 trajectory level 和 token level 做选择性优化，而且避免现有方法常见的硬筛选带来的不连续和信息浪费。

评这是典型“训练信号颗粒度”论文，不是范式突破；如果你在做 RL/SFT 蒸馏接口，重点看过滤准则和 soft weighting 是否真比 hard mask 更稳。

When Are Teacher Tokens Reliable? Position-Weighted On-Policy Self-Distillation for Reasoning

在利用特权教师模型进行在线自蒸馏（OPSD）时，现有方法通常假设教师在所有生成的 token 处都同样可靠，或仅通过局部熵来调整监督权重。但这混淆了教师的“不可行不确定性”（分支导致错误）与“良性多样性”（多种正确解法），导致在错误分支上过度监督或在正确分支上监督不足。

评值得扫方法和可靠性诊断；若位置权重确实赢过熵，推理蒸馏里的 token weighting 先验要更新。
