18:T87f,The proposed method, QuantWM, is a training-free 2-bit KV-cache quantization framework. Its goal is not merely to reduce Key/Value reconstruction error, but to explicitly preserve attention logits and temporal consistency. It builds on the centroid-residual representation used in QVG: each Key is assigned to a BF16 centroid, and only the residual is quantized to low bitwidth. The paper argues that QVG is limited because centroid selection is driven mainly by K-means geometry, which optimizes feature-space distance rather than downstream impact on QK^T.

The first component is QSAC, quantization-sensitivity-aware clustering. Instead of selecting centroids purely by Key-space clustering quality, QSAC jointly considers Query sensitivity and residual dynamic range, aiming to reduce the effect of INT2 residual quantization on attention logits. Intuitively, some Key directions may have small Euclidean error but still be highly dangerous if they align with Query-sensitive directions and alter token ranking. QSAC tries to avoid such residual structures already at the clustering stage.

The second component is PSAC, principal-subspace attention compensation. Even with better clustering, Key quantization error can still be amplified along dominant Query directions and distort logits. PSAC extracts the principal Query subspace and uses low-rank projections to represent and compensate the Key error components along those sensitive directions during inference. The idea is not to fully reconstruct Keys, which is unrealistic at 2 bits, but to correct the error components that matter most for attention allocation. This is a different philosophy from simply increasing quantization fidelity: it accepts that full preservation is impossible and spends the available budget on the subspace that most affects retrieval behavior.

The overall design is coherent: QSAC makes Keys more quantization-friendly before compression, and PSAC compensates the most harmful attention shifts after compression. Because the method is training-free, it is intended as a practical drop-in replacement for existing KV-cache compression pipelines in video generation and world models.19:T53a,The experiments cover several representative models, including LingBot-World-v2, Matrix-Game-2, LongCat-Video, HY-World 1.5, and Causal-Forcing, which suggests the authors are aiming for architecture-agnostic evidence rather than a single-model result. The headline outcome is that QuantWM substantially reduces temporal flickering, blur, and artifacts under 2-bit KV quantization while maintaining strong benchmark performance on metrics such as VBench. It also achieves up to 6.20x KV-cache memory compression with limited inference overhead.

The most important evidence comes from the diagnostic ablations. The paper separates Key-only and Value-only quantization and shows that most degradation comes from Keys. It then compares reconstruction errors and finds that Keys can have smaller numerical error than Values despite causing worse output quality. That result supports the paper's central claim: KV quantization should not be judged mainly by reconstruction magnitude, but by its effect on attention logits and token ranking. The method components are built directly around that diagnosis. Even without all table values in the provided text, the experimental story is clear: the goal is not just to preserve benchmark scores, but to fix temporal-consistency failures that benchmarks under-measure but humans notice immediately.1a:T423,The method uses hRoPE, a hierarchical rotary positional encoding. Position is represented as three coordinates: p1 for paragraph index, p2 for sentence index inside a paragraph, and p3 for token index inside a sentence. Each level receives its own independent rotary channel group, so paragraph, sentence, and token displacements are not collapsed into a single scalar. The frequency base for each axis is calibrated from corpus statistics using the 99th-percentile coordinate range plus a safety margin, so low-frequency channels remain non-wrapping over typical ranges. The central experimental move is a counterfactual intervention: keep the tokens and lower-level coordinates fixed, modify only the paragraph coordinate p1, and measure cross-paragraph attention. A density-matched random-label channel with the same architecture is used as a control. This is important because an arbitrary extra positional axis can also compress attention; the diagnostic quantity is therefore not compression itself, but compression depth relative to the random control.1b:Tac2,LoGo 的核心设计是每层同时有 local 和 global 两个分支，但两者不是两套完全独立的大模块。所有 token 都先走 local attention，只看一个受限窗口；global 分支只对被选中的 query 激活，被选中的 token 再把 local/global 输出做融合，未选中的 token 直接绕过 global 分支。这样做的关键点有四个。

第一，动态分配单位是 token，而不是层或头。论文把 attention span 当作 attention budget 的代理变量：一个 token 是否需要全局上下文，可以由当前隐藏状态预测。具体做法是用一个轻量 gate 为每个 token 产生标量偏好分数，表示它对 global span 的需求。

第二，路由不是固定阈值，而是自适应阈值控制全局激活比例。作者设定 target global ratio，在每个 batch 或序列内根据 gate 分数确定阈值，把 top-ratio 的 token 送入 global 分支。这样可以把计算预算直接绑定到“有多少 token 走全局”，而不是让 gate 自由漂移导致预算失控。相比用连续权重软混合，这种二值路由更容易把理论 FLOPs 节省转成真实 kernel 加速。

第三，训练时用了 progressive mask，也就是文中说的 P-mask。问题在于如果一开始就做硬路由，gate 还没学到有意义的偏好，容易让训练不稳定，或者过早把重要 token 切掉。LoGo 在训练早期延迟引入稀疏路由，先让 local/global 结构和 gate 有一个较平滑的学习阶段，再逐步过渡到目标稀疏度。这一点很像 conditional computation 里常见的 warmup/annealing 思路，但这里作用在 attention routing 上。

第四，只稀疏 global queries，不稀疏 KV。也就是说，所有 token 的 key/value 仍然保留在全局可见集合里，只是并非每个 query 都去访问它们。这样被选中的 token 仍然拥有精确的 full-context attention，而不是近似检索或压缩记忆；代价则主要按被选中 query 数量下降。这个设计比同时稀疏 query 和 KV 更稳，因为不会破坏信息可达性，也避免了额外的 memory selection 误差。

从与现有方法的区别看，静态 inter-layer hybrid 是某些层全局、某些层局部；intra-layer hybrid 是某些头全局、某些头局部；它们都把预算结构写死了。LoGo 则让同一层内不同 token 走不同 span。与 CoLT5、SMA 这类动态模块激活方法相比，LoGo 直接把“是否需要长程上下文”作为路由目标，而不是切换不同 attention 模块或受限 span 模块。工程上，作者还实现了 query-sparse Triton kernel，把只对部分 query 做 global attention 的结构真正映射到运行时加速，而不是停留在 FLOPs 账面节省。1c:Ta3b,LoGo builds each attention layer from coupled local and global branches. Every token always receives local attention over a restricted window. A lightweight gate predicts, for each token, whether global span is worth paying for. Selected tokens additionally go through the global branch and fuse local/global outputs; unselected tokens bypass the global branch entirely.

There are four important design choices.

First, the routing unit is the token. The paper explicitly uses attention span as a proxy for attention budget: if a token likely depends on long-range retrieval, it should be allowed to access the full sequence; if it is locally predictable, local context is enough. This differs from static layer-wise or head-wise span assignment.

Second, routing is controlled by an adaptive threshold tied to a target global ratio. Instead of using a fixed threshold or unconstrained soft gating, LoGo selects roughly the top fraction of tokens for global attention. This keeps compute predictable and directly links routing decisions to budget. It also makes it easier to convert FLOP savings into real speedups, because the global branch becomes query-sparse in a hard, structured way.

Third, training uses progressive masking (P-mask). Hard sparse routing from the start would make optimization brittle because the gate is initially untrained and may suppress important tokens too early. LoGo therefore delays the full sparse regime and gradually introduces routing sparsity after the gate has learned more meaningful preferences. This is a training-stability device, and it is one of the more important parts of the method.

Fourth, LoGo sparsifies only global queries, not keys or values. All KV states remain globally available, so any selected token still performs exact full-context attention rather than an approximation over compressed memory. This is a conservative but sensible design: it reduces compute without damaging information accessibility.

Relative to prior work, static inter-layer hybrids assign some layers to global attention and others to local attention; intra-layer hybrids assign some heads to global and others to local. Both impose a fixed per-token budget. LoGo instead lets different tokens in the same layer take different span routes. Compared with dynamic module activation methods such as CoLT5 or SMA, LoGo directly routes based on span demand rather than swapping among attention modules with the same restricted context. So the offset is not a free learned bias; it is induced by the sequence itself. This turns the layer from consensus-seeking to transition-seeking.

The kernel has two parts: a static frustrated coupling term over the attended token itself, and a delayed coupling term over successors. Both are expanded over harmonics n=1..N, with per-coordinate complex coefficients; the default uses N=3. In polar form, magnitudes are harmonic gains and phases are frustration angles, which makes the layer unusually interpretable relative to standard value mixing. The construction strictly contains several special cases: standard Kuramoto attention when N=1, w0=1, w1=0; Daido-style harmonic coupling for real coefficients; and pure successor coupling when w0=0.
