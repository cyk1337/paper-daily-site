CalibForge: Adversarial Solver Calibration for Scaling Learnable Terminal Tasks

这篇工作解决的不是“如何生成可执行 terminal 任务”，而是更难的一层：如何把任务构造成对某一类求解器来说“可学但不平庸”的训练样本。仅靠 executable validation 只能证明任务能跑、能验收，不能判断它对当前 agent 是太简单、太难，还是刚好处在能提供学习信号的区间。CalibForge 把这个问题形式化为 solver-relative learnable zone：任务必须被至少一个求解器真实解出，同时又不能被目标 solver 设定下全部轻松解出。论文的核心是在任务合成阶段引入基于 solver 行为的多轮对抗式校准，让“任务难度是否合适”从事后经验判断，变成可观测、可操作、可迭代优化的构造目标。

评做agent后训练数据合成的研究员重点看§3的两种校准策略，难度控制方法可迁移到数学/代码等其他任务合成场景

Meta-Task: Turning Terminal Task Synthesis into a Terminal Task for Scalable Agent Training

大规模训练终端操作Agent需要大量多样、可验证的终端任务和高质量交互轨迹，但现有任务合成方法存在两个核心缺陷：一是纯LLM分阶段生成缺乏真实执行环境反馈，生成任务的内部一致性和可执行性差；二是从现有代码仓库挖掘的任务多样性不足、扩展性受限，难以覆盖广泛的终端操作场景。

评把数据合成变成可执行任务的闭环思路对Agent后训练数据工程有直接参考，重点看§3生成-执行-验证的循环设计与失败案例。
