c:T442,LivingArena implements a bidirectional, multi-round game between two models. In each round, the asker must output a structured tuple: question q, gold answer a*, and verification logic v*. A three-judge model panel then performs:
1) Validation: strict veto rule—any INVALID vote rejects the item. Rejection triggers a self-harm penalty for the asker (-1) and ends the round, discouraging ambiguous/unverifiable prompts.
2) Grading: if validated, the answerer sees only q and produces response r. Judges compare r against a*; majority vote decides correctness.
Scoring rewards the asker only when the question is validated and the opponent answers incorrectly; otherwise the answerer is rewarded. Each pair plays in both directions to remove role bias.
