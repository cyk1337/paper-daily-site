Aborted but Not Forgotten: KV-Cache Retention Breaks Rollback Consistency in Language Agents

论文讨论的是有状态 LLM Agent 中一个容易被忽略的服务层一致性问题：应用层认为某个分支已经 rollback 或 abort，清除了 transcript，但推理服务仍复用旧的 KV cache。结果是模型实际 attention 到的状态和应用层记录的状态不一致，已被拒绝的内容仍可能影响后续决策。

评这不是 pretrain 论文，但会直接改你对 stateful serving 的默认假设；只看 rollback consistency 定义和 same-token/different-cache audit 就值回时间。

EVAF: A Test-Retest Protocol for Selective Parametric Consolidation

评探讨了 Agent 经验的参数化巩固（Continual Learning / LoRA 更新），对理解模型如何内化知识有启发，可关注其测试协议。

ACCORD: Action-Conditioned Contextual Grounding for Language Agents

ACCORD 处理的是 LLM agent 在执行欠指定用户指令时的环境 grounding 问题。用户常省略具体实体、约束和当前状态，agent 如果只依赖指令和自身先验，就会在写操作前缺少必要证据，或忽略工具返回中已经存在的关键信息。

评值得看 failure taxonomy 和 action 前 probing 设计；方法不深，但会影响你写 agent 数据合成的状态字段。

AGENTCL: Toward Rigorous Evaluation of Continual Learning in Language Agents

这篇工作要解决的是：如何严格评测 language agent 的 continual learning，而不是把“长上下文记忆”或“任务流平均分”误当成持续学习。作者认为，现有 benchmark 的核心缺陷有两个：一是任务流之间的关系没有被控制，导致你看不清 agent 到底是在复用经验，还是只是碰巧遇到相似任务；二是指标太粗，只报平均成功率，无法拆开 plasticity、stability、generalization 之间的取舍。因此 AgentCL 试图把“任务关系控制”和“针对性指标”同时补上。

评值得看指标定义和任务序列设计；这类评测能暴露 Agent 后训练的遗忘问题，但别直接外推到预训练。

Policy and World Modeling Co-Training for Language Agents

现有语言智能体的RL训练仅优化动作的奖励最大化，不学习动作对环境的实际影响，导致长周期任务中鲁棒性差；而已有世界建模方法需要额外模拟器、独立训练阶段或推理时额外计算，显著增加了训练与部署成本。

Training Language Agents to Learn from Experience

现有语言 Agent 的 reflection 多用于同一任务实例内的自我纠错，缺少对“经验能否沉淀成可迁移策略”的评测和训练框架。这项工作把问题改成跨任务在线改进：Actor 每轮只能尝试一批新的未见任务，Reflector 必须根据过去轨迹生成新的 system prompt，让 Actor 在未来未见任务上表现更好。

评读 ICT 定义和 held-out family 设置即可；它更像 agent 后训练信号实验，不会直接改 pretrain recipe，但可借鉴经验蒸馏接口。
Yuval Shalev,Zifeng Ding,Mateja Jamnik
