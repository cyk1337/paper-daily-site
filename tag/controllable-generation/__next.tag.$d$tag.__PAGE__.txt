A single learnable expert token τ_c is prepended to the model's response and supervised by a hard composition classification objective, so that it acts as an explicit intent anchor. On the perception side, τ_c activates the specialized experts and distills the inferred compositional intent into itself; on the generation side, the same τ_c is reused as a global conditioning signal that steers denoising / generation to match the reference layout.

To break content-composition entanglement without paired data, a self-supervised structural bottleneck is applied: reference images are pixelated and converted to grayscale to retain only global layout cues while suppressing semantic appearance.
