Lost in Context: Addressing Context Anxiety in Large Language Models

这篇论文研究的不是模型“不会做题”，而是模型在长程推理任务里错误地判断自己“做不完”，于是提前放弃、绕路、或者生成更低效的解法。作者把这种现象定义为 context anxiety。更具体地说，核心问题是：当前 reasoning model 对完成任务所需 token 的自我估计存在系统性失准，这种失准会诱发行为层面的退缩，而不是能力层面的失败。

评看实验设计和失败案例即可；若 setup 干净，它会改变“长程失败=能力不足”的默认解释。
Ifueko Igbinedion,Jillian Ross,Etienne Ricardez,Sertac Karaman,Eric So

Utilizing and Calibrating Hindsight Process Rewards via Reinforcement with Mutual Information Self-Evaluation

LLM 文本智能体在环境交互式 RL 中普遍面临外部奖励稀疏：只有少数关键动作获得非零回报，导致样本效率低。用模型自评（PRM/生成式过程奖励）提供稠密奖励虽直观，但未经校准会产生系统性偏置（例如过度奖励 inventory），反过来诱导策略学到“刷奖励”的坏习惯并降低任务成功率。
