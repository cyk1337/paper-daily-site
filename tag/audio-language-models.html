Audio Token Attention Is Predictable Before the Language Model Runs

这篇工作处理的是音频语言模型里一个很具体但很关键的瓶颈：音频 token 太长，既占 prefill 计算，也占上下文窗口，而现有 token pruning 方法大多依赖语言模型前几层的注意力来做裁剪，这对图像常常够用，但对音频不够。全文给出的核心观察是，音频 token 在语言模型早期层仍然被明显关注，而且此时它们的最终重要性排序还没有稳定下来，所以“先跑几层再裁”会错过最有价值的节省点。作者要解决的问题不是一般性的压缩，而是：能不能在语言模型尚未处理音频之前，仅凭音频编码器输出，就预测哪些 token 未来会在整个语言模型中持续获得高注意力，从而提前做安全裁剪。

评发现音频 token 的注意力在输入阶段就高度可预测，提供了一种非常轻量级的 early-exit/pruning 思路，对多模态模型的推理优化有参考价值。

When Audio-Language Models Fail to Leverage Multimodal Context for Dysarthric Speech Recognition

这篇工作检验一个很具体但很关键的问题：现有音频-语言模型在不改参数的前提下，能否像文本 in-context learning 那样，利用临床上下文去改善构音障碍语音的识别。作者关心的不是一般 ASR 精度，而是“额外文本上下文是否真的被模型吸收并转化为更低 WER”。全文给出的结论很明确：对冻结的现成模型，答案基本是否定的。即便提供诊断标签、言语严重度、发声质量描述、完整临床画像，模型大多也不会稳定受益，很多时候反而更差。真正缺的不是 prompt engineering，而是训练分布里几乎没有“异常语音 + 临床描述 + 转写”这种联合样本，导致模型没有学会把这类文本条件映射到声学歧义消解上。

评一个很好的 negative result，证明当前的 Audio-LM 在 zero-shot 跨模态 context 融合上做得很差，需要显式的 SFT 才能激活这种能力。
