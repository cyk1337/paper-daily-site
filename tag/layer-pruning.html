Ghosted Layers: Unconstrained Activation Alignment for Recovering Layer-Pruned LLMs

层剪枝把一段 Transformer block 直接删掉，会让“下一层收到的 hidden state 分布”偏离它在预训练时见过的分布，导致性能显著掉点。问题是：在不做再训练（training-free）的前提下，能否用一个足够一般的补偿模块，把剪枝边界处的激活对齐到原模型，从而恢复性能；并解释为什么现有的线性补丁方法恢复不彻底。

评可 skim：只看闭式 alignment 推导和剪枝比例表；它不会改变 pretrain prior，但能补一条干净的压缩校准 baseline。

Understanding Performance Collapse in Layer-Pruned Large Language Models via Decision Representation Transitions

这篇论文想解释 layer pruning 中常见的“性能断崖”：为什么隐藏表示和原模型仍然相似，最终选择题准确率却会突然崩掉。

评结论有点反直觉：真正脆弱的不是“出答案”的后段，而是前面看似沉默的层；先看指标定义和 phase 划分，若成立，会改变你做 layer drop 的 prior。
