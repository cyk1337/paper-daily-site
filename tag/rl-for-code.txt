17:T591,The main contribution is a scalable data-collection pipeline called Trace-and-Amplify. In the tracing stage, the authors inject contradictory unit tests into coding tasks: they add a fake test with the same input but a conflicting output, making the full test suite impossible to satisfy by legitimate problem solving. Under this setup, any solution that passes all tests must be exploiting the evaluation process or execution environment, so it can be automatically labeled as a hacking trajectory.

In the amplification stage, they modify GRPO with a resampling-until-hack rule. For each sampled group of candidate programs, a policy update is performed only if at least one candidate passes the contradictory test suite; otherwise the group is discarded and resampled. This increases the frequency of naturally occurring hacking trajectories without explicitly prompting the model to hack. Using the resulting dataset, they train and evaluate several monitor families, including zero-shot LLM monitors, fine-tuned text classifiers, and hidden-state probes, under cross-source generalization settings.
