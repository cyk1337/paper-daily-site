9:T5cd,The framework has four components. First, a Traceable Multi-View Event Bank compiles heterogeneous histories—dialogues, documents, factual records—into source-traceable event units. The point is not simple chunking; it is to create a shared substrate on which both retrieval and memory writing operate. Second, Evidence-State Transition Modeling casts the memory policy as a finite-horizon MDP. Actions are organized into two stages: a decide step chooses search or stop; after search, an extract step chooses add or skip for retrieved candidates. This makes stopping explicit and treats non-writing after retrieval as a first-class decision rather than an implicit threshold. Third, Unified Reward Modeling trains a trajectory-conditioned reward model that scores each memory action in context. Supervision comes from evidence-grounded SFT, trajectory-level DPO, rule-derived labels, and reasoning-model scores. The key design choice is that rewards are conditioned on the current evidence state and trajectory context, so the model evaluates whether an action is appropriate at that point, not whether a text snippet looks good in isolation. Fourth, Process-Aligned DAPO aggregates per-action rewards into an action-balanced trajectory reward and uses PA-DAPO to optimize the memory policy actor.
