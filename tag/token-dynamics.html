From Attention Masks to Inert Zero-Vector Tokens: OAttention and O-Closure for Token Dynamics

这项工作讨论 attention 模型里的零向量 token 是否能成为真正“不参与计算”的状态。标准 attention mask 控制的是 query-source 关系，但零向量本身并不会自然惰性化：零 query 会得到可见 value 的平均，零 key/value source 仍会向 softmax denominator 加入 exp(0)。

评提出了一种基于 token 范数动态调节注意力权重的 OAttention，将零向量视为惰性 token，设计很 clean，值得关注其在稀疏或长上下文场景的潜力。
Heyang Gong

Why do Large Language Models Fail in Low-resource Translation? Unraveling the Token Dynamics of Large Language Models for Machine Translation

这篇工作要回答的不是“LLM 翻译好不好”，而是“LLM 在低资源、尤其非英语中心翻译里为什么会失败”。全文把问题拆成两个层面：一是不同语言对上的性能落差是否系统性存在；二是这种落差是否与模型内部对目标语言 token 的可用性和激活程度有关。作者关心的不是传统 MT 模型的数据稀缺问题，而是通用 LLM 在多语生成时，词表覆盖、语言表示和推理式解码之间的关系。
