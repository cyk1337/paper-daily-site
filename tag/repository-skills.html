Repo2Skill-Evo: Repository Skills Go Stale in Silence

当 LLM agent 把“仓库特定的过程性知识”外化成可复用的 skill（例如该跑哪个脚本、该调用哪个 API、遵循什么约定）后，仓库版本迭代会让 skill 在没有显式信号的情况下悄然过期（silent staleness）。论文要解决的是：如何系统性评测并量化 agent 维护这些 versioned skills 的能力，以及失败主要卡在什么环节（定位受影响文件 vs 在文件内选择正确编辑）。

评读任务定义和错误分析即可；它提醒外部 memory 不是免费午餐，版本漂移会把技能变成隐性负资产。
