Parallel-SFT: Improving Zero-Shot Cross-Programming-Language Transfer for Code RL

论文研究代码 RL 后训练中的跨编程语言零样本迁移：只在源语言上做 RL，模型是否能把代码生成或代码验证能力迁移到目标语言。作者发现 Llama-3.1 在源语言上 RL 后，源语言性能会提升，但目标语言常常没有收益，甚至下降。

评不是基座预训练论文，但它把一个常被忽略的接口讲清了：RL 迁不出去，很多时候不是 credit assignment，而是 SFT 没先把跨语言语义空间对齐；读方法和表征分析两节就够。
Zhaofeng Wu,Shiqi Wang,Boya Peng,Anuj Goyal,Melanie Kambadur,Sebastian Ruder,Yoon Kim,Chloe Bi

Parallel-SFT: Improving Zero-Shot Cross-Programming-Language Transfer for Code RL

在代码 RL 后训练里，模型在源编程语言（如 Python/C++）上通过 RL 获得的提升，为什么很难零样本迁移到目标编程语言（低资源 PL），甚至会退化？论文把问题定位为：RL 阶段学到的改进过度贴合源语言表面形式，缺少跨语言可复用的“语义对齐”初始化。

评值得看的不是“代码跨语言”本身，而是它把一个常见脏现象说清了：RL 不会自动抽象出共享技能，初始化表示没对齐时还会负迁移；先看 Parallel-SFT 的数据构造和 ablation。
Zhaofeng Wu,Shiqi Wang,Boya Peng,Anuj Goyal,Melanie Kambadur,Sebastian Ruder,Yoon Kim,Chloe Bi
