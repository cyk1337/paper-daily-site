Phase 1 is independent judgment: a panel of jurors from diverse model families each read the problem and reasoning trace independently, and output a structured defect list including description, affected step IDs, severity, and supporting evidence. This ensures no anchoring effect and decorrelated judgment biases across jurors. Phase 2 is consensus building, with two available modes: Consolidation mode passes the original trace and all Phase 1 verdicts to a judge model to produce a unified consensus. Deliberation mode uses a moderator to run multi-turn debates between jurors, who discuss defect points until consensus is reached or discussion stalls.
