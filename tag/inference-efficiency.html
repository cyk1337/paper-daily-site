STAR-Pro 解决的是 LVLM 推理时视觉 token 过多的问题，重点不是重新训练模型，而是在不改权重的条件下做视觉 token 裁剪。论文指出两个常见做法各有硬伤：在进入 LLM 前一次性裁剪会损失视觉特征覆盖；在 decoder 内某一层根据注意力裁剪，又会因为视觉 token 重要性随层深变化而误删后续层需要的证据。

评这类工作对预训练本身帮助有限，但它点破了一次性视觉token裁剪的两个常见错觉；只看分析部分和分阶段设计，别太在意最终榜单。

FastE: Readout-Triggered Token Compression for LLM Embedding Inference

面向 final-readout 的 LLM embedding 模型（用 EOS/专用 readout token 的最后一位隐状态做 embedding），长前缀会让推理成本很高。现有 token pruning/merging 往往固定在某些层做压缩，或依赖模态特征；但 embedding 场景的关键是“readout state 如何随深度吸收 prefix states”。论文要回答并利用一个现象：prefix states 在浅层更不可替代、在深层更可压缩（depth-dependent prefix redundancy），能否用一个在线信号自动决定何时开始压缩、以及保留哪些 token，从而在不训练的情况下加速 embedding 推理。

评不是 pretrain 论文，但“readout 越深越能替代前缀状态”这个现象值得记；先看方法图和压缩触发曲线，别急着相信跨任务泛化。
