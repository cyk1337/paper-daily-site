Sliding-window beats linear attention

这篇论文解决的是一个很具体、也很容易被忽略的问题：把已预训练的 Transformer 改造成 linear attention 是否真的优于一个更简单的基线。近年的 linearization 工作通常强调固定推理内存、避免 KV cache 增长，并通过少量 post-training 恢复性能。但作者指出，这些方法没有和训练免费的 Sliding Window Attention 加 attention sinks 做充分直接比较。论文的核心问题不是提出新的注意力结构，而是检验一个更朴素的假设：在不改权重、不做额外训练、不引入专用 linear kernel 的情况下，只把推理时 attention mask 改成局部窗口加前几个 sink token，是否已经能达到甚至超过 post-trained linear attention。

评这会改变我对 linear-attention retrofit 的默认信任；应立刻把 SWA+sinks 加进内部长上下文 ablation。
