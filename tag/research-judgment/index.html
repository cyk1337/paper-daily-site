Sci$Π$vot: Benchmarking Principal-Investigator Judgment at Pivotal Moments of Scientific AutoResearch Agents

这篇工作要解决的不是“科学 agent 能不能跑实验”，而是更难也更接近真实研究瓶颈的问题：在长期 AutoResearch 流程里，模型能否在关键分叉点做出像 PI 一样的研究判断。作者观察到，自动化执行、写代码、跑实验并不是主要短板，真正限制自治的是对项目状态的诊断、对下一步实验信息价值的判断，以及在错误假设出现时能否及时改方向。论文把这种能力定义为 PI Judgment，并试图把它从模糊的人类直觉，变成可评测、可训练的对象。

评值得看 case 构造和错误分布；它测的是科研判断的反事实选择，比又一个科学 QA benchmark 更接近 agent 失控点。

ForeSci: Evaluating LLM Agents for Forward-Looking AI Research Judgment

这项工作构造 ForeSci，用来评测 LLM agent 是否能在严格历史时间截断下，根据当时已有文献做前瞻性 AI 研究判断，例如选择研究方向、识别瓶颈、规划项目或判断投稿定位。

评时间切分做得像样，能当“研究型 agent”评测底座；只需看任务构造与泄露控制，模型结果别过度解读。
