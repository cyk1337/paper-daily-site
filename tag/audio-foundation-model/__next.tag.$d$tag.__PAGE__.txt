The transformer input is a single concatenated token sequence [zt; r1; ...; rK] with full self-attention across target and references. References are distinguished by lightweight slot identity embeddings (one learned vector per reference slot, added to all tokens of that reference) rather than speaker encoders/adapters. A single holistic natural-language prompt describes the whole scene and refers to voices as “reference 1/2/...”.

Core technical contribution: identifying the “reference shortcut” in reference-conditioned flow matching. Under the commonly used logit-normal timestep distribution, training mass concentrates on low-to-moderate noise where zt still preserves speaker cues; the model can pick the correct reference by acoustic similarity, achieving low loss while ignoring text-based role binding. Since generation starts from pure noise, this shortcut is unavailable at test time. The authors localize the shortcut with a probe trained on frozen audio features, showing robust reference–target matching across the low/moderate noise range, and then run noise-schedule ablations showing binding metrics improve monotonically as training shifts to higher noise. Second, generation is decomposed into a semantic encoder, an LLM backbone, and an autoregressive flow-matching head. The LLM handles long-range text-to-content planning, while the flow head renders local acoustic detail for each latent patch. The flow head uses full-history conditioning instead of only local context, which is meant to reduce drift in long utterances. Third, the post-training stage adapts reward-free self-correction, in the spirit of SOAR, to the flow head. The acoustic DiT is trained on its own off-trajectory inference errors without requiring a reward model or an external teacher.
