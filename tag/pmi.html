Anti-Self-Distillation for Reasoning RL via Pointwise Mutual Information

这篇论文解决 reasoning RL 中 on-policy self-distillation 在数学推理上收益不稳定的问题。标准做法让同一个模型在带有 verified solution 或环境反馈的 privileged context 下充当 teacher，再用逐 token KL 拉近 student。论文指出，在数学题中，这个 teacher 会更确信那些已由答案暗示的结构词和可验证陈述，却降低对 Wait、Let、Maybe 等探索性推理 token 的支持。结果是蒸馏信号削弱了多步搜索所需的 deliberation。

评值得看的是它对 self-distill 失败机制的 token 级拆解，不是方法名本身；先看 PMI 分析和 entropy gate，若 setup 不干净就把结论当弱信号。
Guobin Shen,Xiang Cheng,Chenxiao Zhao,Lei Huang,Jindong Li,Dongcheng Zhao,Xing Yu
