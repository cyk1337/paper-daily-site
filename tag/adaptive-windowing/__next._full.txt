17:Ta2f,方法核心是 PPOW：把 drafter 视为在固定长度 speculative window 上采样动作的 policy，用 window 级 reward 做强化学习更新，而不是只做 token 监督。论文的设计分三层。

第一层是 window-level RL formulation。给定当前前缀，drafter 一次生成长度 K 的候选 window，target 按标准 speculative decoding 做并行验证，得到 accepted prefix 长度 k。训练目标不再是每个 token 的 CE，而是最大化整个 window 的期望回报。这个 formulation 直接对应实际验证机制，优点是 credit assignment 与真实吞吐更一致；代价是 reward 稀疏、方差更大。

第二层是 reward 设计。作者用了两个互补信号。其一是 Cost-Aware Speedup Reward，主奖励围绕 accepted prefix 长度构造，同时把 drafter 相对成本纳入考虑。这样不是盲目追求更长 window，而是追求单位代价下更高加速收益。这个点很关键，因为 speculative decoding 的真实收益取决于 target 节省的步数减去 drafter 额外开销。其二是 Distribution-Based Proximity Reward，作为辅助奖励，在 accepted prefix 很短、主奖励过于离散时，给那些虽然没被完整接受、但分布上仍接近 target 偏好的 window 一部分 credit。论文强调这不是简单回到 token CE，而是保留 window 级训练框架下的“软接近度”信号，用来缓解早期 mismatch 导致的零碎反馈。

第三层是 Adaptive Divergence-Aware Windowing，简称 ADAW。作者观察到并非所有训练 window 都同样有信息量：很多容易位置即使继续优化，对整体 acceptance bottleneck 帮助有限。于是他们用 confidence-weighted 的 draft-target divergence 来挑选更值得训练的窗口，优先关注那些更可能成为 acceptance bottleneck 的位置。这里的直觉是，如果 drafter 在高置信位置仍与 target 明显偏离，那么这个位置更可能在验证时早早截断 accepted prefix。相比均匀采样窗口，这种 prioritization 把训练预算集中到真正限制吞吐的局部。

从与已有方法的区别看，MEDUSA、Hydra、EAGLE、HASS、GRIFFIN 这类工作主要在 drafter 架构、head 设计、特征利用或监督训练上做文章；蒸馏方法则强调分布对齐。PPOW 的不同点不在 drafter 结构，而在优化目标：它把 speculative decoding 当成一个有明确系统回报的序列决策问题。论文实验里以 EAGLE family 的 feature-based drafter 为底座，也说明该方法更像一个可叠加的训练层，而不是替代现有 drafter 架构。18:T936,The core method, PPOW, treats the drafter as a policy over fixed-length speculative windows and optimizes it with window-level reinforcement learning rather than pure token supervision. The design has three main pieces.

First, a window-level RL formulation. Given a prefix, the drafter samples a K-token speculative window. The target model then performs standard speculative verification and returns an accepted prefix length k. Training maximizes expected reward over the whole window, not per-token likelihood. This aligns the optimization target with the actual verification mechanism. The benefit is better alignment with realized speedup; the cost is sparser and higher-variance feedback.

Second, reward design. PPOW uses two complementary rewards. The main one is a Cost-Aware Speedup Reward, built around accepted-prefix length while accounting for the relative cost of the drafter. This is important because speculative decoding only helps if target-side savings exceed drafting overhead. The auxiliary one is a Distribution-Based Proximity Reward, which gives partial credit to windows that remain close to the target model's preferences even when the accepted prefix is cut short early. The point is not to fall back to token CE, but to provide a softer signal inside the same window-level framework when the main reward is too sparse.

Third, Adaptive Divergence-Aware Windowing (ADAW). The paper argues that not all windows are equally informative during training. Many easy windows are not the true bottlenecks for acceptance. ADAW prioritizes windows with large confidence-weighted draft-target divergence, under the intuition that high-confidence disagreements are more likely to create early truncation points. Compared with uniform sampling, this focuses training budget on the positions that most constrain realized throughput.

Relative to prior work such as MEDUSA, Hydra, EAGLE, HASS, and GRIFFIN, the novelty is not a new drafter architecture. Those lines mainly improve heads, features, or supervised alignment. PPOW instead changes the optimization target itself, treating speculative decoding as a sequential decision problem with a system-level reward. The experiments use an EAGLE-style feature-based drafter as the base, which suggests the method is intended as a training layer that can sit on top of existing drafter designs.19:T6b7,From the provided full text, the experimental findings fall into three buckets.

First, end-to-end speculative performance. PPOW improves realized speculative efficiency over supervised baselines, with gains reflected in longer accepted prefixes and better throughput rather than only better token-level fit. The paper stresses that the benefit is more visible when there are hard-to-draft positions, because those are exactly where early mismatches waste most of a speculative window.

Second, ablations on rewards and training strategy. The Cost-Aware Speedup Reward moves optimization toward actual acceleration. Adding the Distribution-Based Proximity Reward improves stability when accepted-prefix signals are sparse, especially early in training, which supports the claim that pure prefix-based rewards are too brittle on their own. ADAW outperforms uniform window treatment, consistent with the idea that training should focus on acceptance bottlenecks rather than spread effort evenly.

Third, analytical evidence. The appendix motivates the notion of acceptance bottlenecks and the experiments show that improvements in token-level imitation do not map linearly to speculative speedup. That empirical decoupling is the central justification for the method.
