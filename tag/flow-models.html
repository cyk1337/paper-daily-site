Stitched Value Model for Diffusion Alignment

这篇工作解决的是 diffusion/flow 模型对齐中的一个老问题：奖励定义在干净图像 x0 上，但训练时或推理时真正需要评估的是噪声中间态 zt 的“未来回报”，也就是 value function。现有做法要么用 Tweedie 近似，从 zt 先估计一个干净样本再打分；要么做 Monte Carlo rollout，从 zt 采样多条去噪轨迹再平均奖励。前者便宜但高噪声时偏差大，后者更准但成本高。作者要解决的核心问题是：能不能不从头大规模训练 noisy-latent value model，而是把已经很强的像素空间 reward model 迁移到 noisy latent 上，并且迁移成本足够低、泛化足够好。

评只看 value stitching 的训练目标和消融；clean reward 接到 noisy latent 的做法，可类比 RLVR 里的信号错位。

Continuous Adversarial Flow Models

Flow Matching（FM）在视觉生成中常出现“无 guidance 时样本偏离数据分布（out-of-distribution）”的问题。作者认为根因之一是 FM 训练使用固定的欧氏 MSE 速度匹配损失，有限容量模型在这种度量下会产生不符合数据流形的泛化。问题是：能否在连续时间流模型中引入对抗式、可学习的判别准则，以更好地对齐真实数据分布，同时保持连续时间 ODE 生成框架？

评只需看对抗判别损失如何插进连续时间FM训练与稳定性ablation；若成立，后训练给现有FM加个判别器可能是低成本增益。
