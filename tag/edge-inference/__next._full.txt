17:T73e,AURA-Mem can be summarized as a frozen backbone plus a constant-size recurrent memory plus an action-driven write gate. There are four main ingredients. First, the model wraps a fixed-size memory around a frozen vision-language-action backbone, replacing the linearly growing KV cache with an O(1) state. Second, it introduces a learned action-utility write gate. The trigger is not perplexity, recency, or generic reconstruction error; it is whether the current observation would change the next action. If the new input is not useful for action selection, the memory does not write. Third, the training objective is an action-information bottleneck rather than observation reconstruction. The action-chunk loss is backpropagated through the gate decision so that the memory learns to retain what matters for acting well, not what best preserves token-level fidelity. Fourth, the method includes explicit write-rate control during training via a target write rate rho and a penalty weight gamma, allowing the model to move along an accuracy-versus-write-bandwidth frontier. The paper also instantiates the approximate information state framework empirically by measuring epsilon and delta for the learned memory and reporting an action-sufficiency certificate. The full value-loss bound remains loose because the Lipschitz-related term is too large at current scale, but the attempt is still notable: it turns 'is this compressed state sufficient for control?' into something measurable. Relative to SSM-style recurrent models, AURA-Mem does not write every step. Relative to KV-cache compression methods, it does not approximate a growing cache; it commits to constant memory from the start. Relative to Tensor Cache, it differs simultaneously in write trigger, training objective, write-rate conditioning, and the measured action-sufficiency analysis.18:T4c4,The main empirical claim is not superior task accuracy, but a better write-bandwidth frontier at matched performance. On memory-dependent synthetic benchmarks, AURA-Mem achieves 4.98x to 9.19x fewer memory writes than a write-everything dense baseline while maintaining statistical parity with the best O(1) baseline, fixed_size_state; the paired bootstrap confidence interval includes zero at N=64. The paper is careful about this framing: the result is reduced writes without collapsing task success, not universal accuracy dominance. On the theory-measurement side, the shipped checkpoint reports epsilon_mean = 0.0021 and epsilon_q95 = 0.0076. However, once the L_V term is included, the full bound is still vacuous, so the practically informative quantity is the measured epsilon rather than the final value-loss certificate. The experiments compare against several families: bounded-state models that write every step, KV-cache compression or eviction methods, and the structurally related Tensor Cache. If your interest is persistent inference on edge hardware or long-horizon agents, the results are meaningful.
