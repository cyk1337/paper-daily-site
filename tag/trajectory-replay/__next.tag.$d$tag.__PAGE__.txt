9:T731,The framework has three main parts. The first is environment reconstruction. Starting from public terminal-agent trajectories, the system replays file operations and restores each file to its pre-edit state, so the resulting workspace starts unsolved. Because trajectories usually reveal only a partial view of the original workspace, replay alone produces incomplete environments. A completion agent then fills in missing files and dependencies while trying not to leak the solution. This design choice is important: it avoids generating environments from scratch, which often hurts realism, and it also avoids requiring access to the original repository, which may be unavailable.

The second part is task expansion. The framework does not only recover the original user intent; it also synthesizes new tasks over the reconstructed environment. Breadth expansion links related environments and creates cross-workspace tasks, such as porting a feature from one project to another or connecting two components. Depth expansion turns a single-round task into a multi-round interaction. After one round is completed, a user agent issues grounded follow-up requests based on the changed workspace, or asks for fixes when a round fails. This yields stateful, evolving tasks rather than static instructions.

The third part is verification and data generation. For each new task, an agent writes a verifier inside the container, and only trajectories whose tests pass are kept. Qwen3.7-Max is then used as a teacher to solve tasks again in these reconstructed environments, and the resulting trajectories are used to train Qwen3.5-27B. The key point is the data-generation paradigm: reconstruct the environment first, then let a stronger model produce fresh, verifiable solutions, instead of treating historical trajectories as final supervision.a:T476,The reported scale is substantial. From public terminal-agent trajectories, the pipeline produces 37.3k task-sufficient environments, meaning the reconstructed workspaces are complete enough to support execution and verification rather than being partial artifacts.

Using newly generated queries over these environments and teacher rollouts from Qwen3.7-Max, the authors train Qwen3.5-27B and report gains of 11.9 points on Terminal-Bench 2.1 and 13.8 points on the multi-round benchmark EvoCode-Bench v2 MT@4. This suggests the data is useful not only for single-round repair tasks but also for interactive multi-turn coding agents.

The most important experimental takeaway is the ablation: re-solving tasks in reconstructed environments clearly outperforms imitating the original raw trajectories. That result supports the paper’s central thesis that trajectories are most valuable as partial observations of environments, not as immutable demonstrations.
