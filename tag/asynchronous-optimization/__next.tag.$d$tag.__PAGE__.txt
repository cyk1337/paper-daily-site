9:T5e2,The framework partitions a global cluster into M independent learners. Each learner keeps its own model replica θ_m and runs an inner optimizer, such as AdamW, on its local data shard for H steps. Synchronization is expressed through the DiLoCo outer update: the difference between a learner’s current parameters and a reference parameter state is treated as an outer gradient, and an outer optimizer aggregates these updates. Earlier DiLoCo synchronized all learners every H steps. Streaming DiLoCo split parameters into P fragments, synchronized different fragments at different offsets, and allowed a small communication delay τ to reduce peak bandwidth. Decoupled DiLoCo removes the blocking barrier. Learners can continue training without waiting for all other learners to reach the same synchronization point. A central synchronizer asynchronously receives learner updates and sends reconciled parameter updates back. The design deliberately trades strict consistency for availability and partition tolerance. The main algorithmic question becomes how to control parameter drift through H, fragment size, delay, update scheduling, and the outer optimizer. Compared with elastic SPMD, it does not simply resize a still-synchronous job after a failure; it limits the failure blast radius to the affected learner.
