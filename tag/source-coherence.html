Does More Retrieved Evidence Help Visual Retrieval-Augmented Generation with Diffusion Language Models?

这篇工作研究的是一个很具体、但对新型语言建模范式很关键的问题：在视觉 RAG 里，给 diffusion language model 提供更多检索证据，为什么会出现“检索覆盖更高，但最终答案更差”的反常现象。传统 AR-RAG 的直觉是 top-k 越大，答案页被召回的概率越高，生成器就更容易答对；但在多模态 DLM 中，多个页面会同时进入并行去噪过程，所有未决 token 位置共享这些视觉条件。这样一来，若不同页面分别支持不同但各自自洽的答案，模型在位置级并行提议时会把不兼容的信息拼接起来，生成一个没有任何单一页面支持的混合答案。论文把这个问题刻画为 source-coherence loss，即并行去噪破坏了“答案应来自同一潜在证据源”的耦合约束。

评这篇值得看机制，不是看 RAG trick：它说明 DLM 的并行去噪会放大多源冲突，先读 latent-source analysis 和 first-step 分布那部分。
Jiankun Wang,Yisen Gao,Ziwei Zhang,Xingcheng Fu,Jiaxin Bai,Chen Gao
