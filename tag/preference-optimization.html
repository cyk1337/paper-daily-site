ECHO: Emergent Common-Mode Hidden Offsets Drive Vocabulary Collapse in Preference Optimization

这篇文章解决的是 preference optimization 里一个长期被 ranking metric 掩盖的失稳机制：模型在 DPO/SimPO/PRO 一类相对偏好目标上，held-out ranking 可以持续变好，但生成质量却会突然崩掉，最后塌缩成反复输出某个 token。全文给出的核心解释不是停留在概率层，而是定位到 final hidden state 里的一个共享平移分量。作者把它叫 common-mode offset：在不同 token 位置、不同 prompt、chosen 和 rejected 两侧，它都沿着近似同一个方向增长。因为偏好损失主要看 chosen 相对 rejected 的差值，这个共同平移会同时抬高或压低两边分数，几乎不改变 margin，所以损失对它基本“看不见”。但这个 offset 一旦投影到输出层，就会在词表空间里给某个 token 挖出一个越来越深的 vocabulary well，最后解码被这个 token 主导，进入 generation collapse。

评这篇会改你对 DPO 类训练“指标变好就没事”的 prior；先看 offset 注入实验和 loss masking，那两处如果站得住，内部对齐训练都该加表征监控。

Context Blindness in DPO: Mitigating Object Hallucination in MLLMs via Context-Calibrated Preference Optimization

这篇工作盯住的不是“如何再造一批更好的偏好数据”，而是一个更基础的问题：现有 DPO 类目标在训练 MLLM 抗幻觉时，是否真的学会了利用额外上下文来增强对正确回答的偏好。论文给出的结论是否定的。作者把这种现象称为 context blindness：即便输入里加入了有助于 grounding 的上下文，标准 DPO 的优化形式也不会显式奖励“有上下文时偏好边际更大”，因此模型学到的偏好常常对上下文不敏感。这一点直接关系到 object hallucination，因为很多幻觉并不是模型不会比较好坏回答，而是它没有把视觉或补充文本上下文真正纳入偏好判断。

评读 CPG 定义和 ablation 即可；它提醒偏好数据加上下文不等于训练信号真的依赖上下文。
Byungoh Ko,Jinyoung Park,Jongha Kim,Jeehye Na,Jaewon Cho,Hyunwoo J. Kim
