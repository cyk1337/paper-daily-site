9:T467,The proposed method is likelihood-array regression, or LAR. For each target token, a fixed scoring language model evaluates the token under a sequence of nested left-context windows rather than only under the full prefix. These evaluations form a structured array indexed by context length and relative token position, with additional features derived from the model’s predictive distribution. Arrays from documents of different lengths are aligned onto a common domain. LAR-1 learns additive contributions from individual cells to the class log odds and aggregates them over tokens and context lengths. LAR-2 adds within-path second-order features for the same target token, including same-context quadratic terms and products across different context lengths. Basis expansions and random squared projections produce finite-dimensional representations, which are estimated with ridge logistic regression.
