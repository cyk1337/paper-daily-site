GRIP: Grounded Reasoning via Information-Restricted Premises

GRIP 处理的是 RAG 中的证据未被有效使用问题。作者把它定义为 query dominance：模型虽然接收了检索文本，但内部证据表示高度可由 query 预测，生成时更接近 P(Y|Q) 而不是 P(Y|Q,E)。这类问题不能只靠更强检索器或更长上下文解决，因为高容量 query 通路会让证据通路退化成 query 的压缩副本。

评结论值得复现：它挑战“证据编码越强越好”的直觉；只看瓶颈设计、MI 诊断和消融即可。

The Ebb and Flow of Multimodal Focus: Scheduling Visual Relay Windows for Grounded VLM Reasoning

这篇论文解决的是 VLM 推理中一个较隐蔽的问题：视觉证据进入语言模型层之后，并不会稳定地服务于后续生成。模型可能看到了图像，也可能在早期对齐了问题和视觉内容，但中间层的视觉信息整合时间不足、位置不匹配，或者后期生成时证据锚定变弱，都会导致回答看似合理但缺少视觉支撑。论文把这个问题具体化为“视觉证据在层深方向如何被接力、何时交给语言侧生成”的机制问题。

评多模态注意力跨层三阶段规律直接改变对VLM对齐位置的认知，应立刻在内部多模态预训练ablation中验证VRW阶段的对齐损失效果。
