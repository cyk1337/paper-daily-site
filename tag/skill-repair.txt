18:T560,ReSkill decomposes repair into explicit components. Given a failed rollout, a frozen language model generates a set of failure hypotheses, a set of candidate local patches, and a coverage matrix indicating which hypotheses each patch addresses. The outer repair procedure maintains weights over active hypotheses, selects a patch by weighted coverage, applies it to the external skill set, and retests the edited skill set in the environment. If the retest still fails, the new failed trajectory is used to update the hypothesis set and their weights for the next round.

Two design choices matter. First, model weights remain frozen throughout; only the external skill set is edited. That makes repairs local, inspectable, and reversible. Second, repair state is maintained across rounds in structured form rather than compressed into a fresh natural-language reflection each time. This separates diagnosis, patch generation, patch selection, and feedback integration, reducing the noise that comes from asking the model to do all of them in one generation.

Relative to one-shot reflection methods such as Reflexion-style repair, ReSkill behaves more like an explicit credit-assignment loop over hypotheses and edits. The language model proposes structured repair factors, but the outer procedure decides which local edit to trust based on coverage and environment feedback.19:T444,The evaluation uses two interactive settings: ALFWorld for grounded household interaction and TextCraft from AgentGym for symbolic crafting. Together they form six benchmark–model combinations. Under fixed repair budgets, ReSkill improves final repair success by an average of 3.7 and 3.3 percentage points over two competitive repair baselines. The gains are moderate, but meaningful in a budgeted multi-round repair setting, where avoiding wasted edits matters.

From the analysis, the method helps most when failures have multiple plausible causes and when the first repair attempt reveals a new failure mode that should change which hypotheses are prioritized next. Because model weights are unchanged, the improvements are better interpreted as evidence for the repair procedure itself rather than for additional learned capability.

The limitations are also clear. The gains are not large, and the environments are still relatively controlled.
