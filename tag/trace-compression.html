Compress-Distill: Reasoning Trace Compression for Efficient Knowledge Distillation

这篇工作讨论的是一个很实际的蒸馏问题：大推理模型生成的 chain-of-thought 太长，拿它做监督既贵，又会把学生模型也教得很啰嗦。作者关心的是，能不能先把 teacher trace 压缩，再拿压缩后的 trace 做蒸馏，从而在训练成本、推理长度和最终准确率之间找到一个更好的折中。全文的答案比较克制：可以明显省算力和 token，但不是免费午餐；在他们测试的范围内，raw trace 始终给出最高准确率，compression 更像一种工程上的 cost-quality trade-off，而不是更优监督信号。

评读结果表和截断消融；它给蒸馏预算一个硬边界：省 token 可以，别指望白拿准确率。
Maxime Griot,Paul Steven Scotti,Tanishq Mathew Abraham
