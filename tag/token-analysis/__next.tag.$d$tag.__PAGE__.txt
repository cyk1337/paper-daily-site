9:T4eb,The work proceeds from mechanistic characterization to an RL-free replacement.
Mechanistic findings via token-level comparisons across multiple model families and RL algorithms:
- Only ~1–3% of token positions are meaningfully altered by RL.
- The token promoted by RL is always within the base model’s top-5 candidates, indicating reranking rather than novel token invention.
- Edits concentrate at high-entropy decision points (branching tokens).
Causality is tested with oracle interventions: correcting the specific token at those positions recovers a large fraction of RL’s gains, while random corrections/locations do not.
Predictability: the decision points can be located without an RL-trained model using the base model’s own token entropy peaks.
Low-dimensionality: the full correction is claimed to be representable with a tiny fraction of parameters.
Based on this, ReasonMaxxer is introduced:
- Sample a small set of rollouts from the base model.
- Use entropy gating to select decision points.
- Apply an advantage-weighted contrastive loss only at gated positions, while anchoring all other tokens to the base distribution to prevent global distribution shift.
