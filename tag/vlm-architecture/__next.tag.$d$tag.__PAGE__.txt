注入分两种：G-inject 只通过 caption→image 的 rectified flow 目标训练；U-inject 只通过 image→text 的 language modeling cross-entropy 训练。训练时用 LoRA，rank 32，且把 LoRA 放置位置作为受控变量。关键实验轴是“entry point”——新概念被写入解码器哪一层、哪一类子模块。作者系统比较了写入共享路径、私有生成分支、非导出载体、读出层等不同位置，并引入 alignment probe 来测量该层是否已经把概念表示成两任务共用的语义格式。

The main platform is BAGEL-7B-MoT, a 28-layer Mixture-of-Transformers model with hidden size 3584. Each layer contains a shared text/understanding expert and a private generation expert. Understanding uses only the shared expert, while generation uses both shared and private branches. To isolate architectural transfer from supervision overlap, the authors create 56 novel concepts. Each concept is an Objaverse 3D asset rendered from 60 training views and 20 held-out views, paired with a pseudo-word screened so that the frozen model shows no stable visual or lexical behavior for it. Concepts are split into seven groups of eight, with evaluation done against fixed-difficulty retrieval banks.

There are two injection routes. G-inject trains only the caption-to-image direction using a rectified-flow objective. U-inject trains only the image-to-text direction using language-model cross-entropy. Training uses rank-32 LoRA, and the placement of LoRA is itself a controlled variable. The central experimental axis is the entry point: the exact layer and submodule where the new concept is written into the decoder. The paper compares writing into the shared pathway, the private generation branch, non-exporting carriers, and readout layers, and uses an alignment probe to test whether a given depth already represents concepts in a semantic format usable by both tasks.

Three findings stand out. First, the cross-task channel is real but asymmetric. Generation-only training lets the model match the concept name on the understanding side, but not reliably produce the name. Understanding-only training can also support drawing the concept on the generation side. Second, multiple-choice probes overestimate generation-to-understanding transfer because they can be solved by elimination. When evaluation is changed to production, with all candidate names removed from context, only conditions that actually computed LM cross-entropy can produce the name. Third, entry point gates usability, but the right location is not sufficient by itself: the concept must enter at a depth where both tasks already share a semantic code. The alignment probe predicts exportability across configurations, but maximizing the probe score alone does not guarantee transfer.
