FM-Bench: A Benchmark for Long-Horizon Management with Competing Agents

这篇工作要解决的是 agent 评测里的一个空缺：现有 benchmark 往往只覆盖长时程，或者只覆盖竞争环境，但很少同时考察“长期决策 + 多智能体竞争 + 累积后果 + 资源约束”。作者把这个问题具体化为 management：让一个 LLM agent 在信息不完全、对手会适应、早期决策会改变后续世界状态、且成绩与财务要同时达标的环境里，持续经营一个组织。论文用 20 个游戏年、约 340 到 400 个决策停点的足球俱乐部经营环境来承载这个定义，并试图用完全确定性的评分机制替代 LLM judge 或人工打分。

评极具野心的长周期 Agent 评测基准（20年跨度，数百次决策），摆脱了 LLM-as-a-Judge 的主观性，通过确定性引擎评估累积决策后果，是研究 Agent 长期规划和强化学习的绝佳测试床。
Tianyou Wang,Chongyang Gao,Kezhen Chen,Chen Dong,Yinghao He,Donghan Li,Wangcheng Xu,Hongjiu Zhang,Chi Li
