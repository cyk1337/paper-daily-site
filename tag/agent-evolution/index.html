VeriEvolve: Evaluator-First Evolution for Tool-Using Agents

这篇工作处理的不是“如何让 agent 搜得更好”，而是更前面的瓶颈：在真实、带状态的工具使用任务里，缺少一个可扩展、可执行、可冻结的 fitness signal。对文件系统、数据库、仓库这类 CRUD 任务，正确性往往体现在最终环境状态，而不是最终自然语言回复。人工 verifier 可靠但昂贵，LLM judge 易扩展但不够确定。论文要解决的是：能否先由 agent 自己从任务指令和初始环境中合成任务相关的 challenge states 与 executable evaluator，再用这个 evaluator 去驱动后续 workflow 演化，并在发现 false positive 后继续修 evaluator。

评提出 Evaluator-First 的 Agent 进化框架，通过合成反事实测试用例来迭代评估器，对构建高质量的 Agent 训练反馈信号有启发。
