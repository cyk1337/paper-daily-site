18:T463,KPI (Key Path Identification) refines a standard SAE-steering pipeline. Starting from a set of ‘positive’ SAE features correlated with the target behavior (faithfulness), it builds an interaction graph among these features using a small development set. Nodes are candidate positive features; edges represent activation/causal dependencies across layers (and potentially within-layer interactions), motivated by the observation that a strongly steering feature often requires upstream features to activate it. KPI then defines key features via graph structure—high indegree features are treated as bottlenecks/aggregators—and constructs key paths by anchoring on a key layer with strong steering effect and tracing back through preceding layers’ key features. Steering is applied only on features along these key paths, aiming to remove redundant features that dilute the intervention. The paper further connects the intervention to attention dynamics: key-path steering increases attention to context-provided ‘golden answer’ tokens and shows a gradual formation of knowledge-selection behavior across depth.19:T4eb,They train BatchTopK sparse autoencoders on residual-stream activations of the CosyVoice3 LM backbone (Qwen2.5-0.5B, 28 layers, d_model=896). The model consumes BPE-tokenized text prompts and autoregressively generates 25Hz discrete speech tokens. SAEs are trained on ~250M tokens (Emilia) with dictionary size 16,384 and k=50 active features per token, across multiple layers.
A key contribution is modality-aware auto-interpretation for mixed sequences. For each SAE feature, they collect top-activating positions and route evidence based on whether activations occur in the text-prefix segment or the speech-token segment: text evidence is a marked token window; audio evidence is a 1-second waveform clip centered on the activating speech token; mixed features receive both. Labels are generated by an LLM (Gemini 3.0 Pro) and validated via a held-out detection-style protocol (shuffled positives/negatives; AUROC and balanced accuracy).
For causal tests, they steer generation through the SAE latent space: encode residual states at speech-token positions, shift selected feature activations by a signed, normalized amount with strength α, decode back into the residual stream, and continue generation (leaving text inputs and speech prompts unchanged).1a:T41f,Layer sweeps show a strong depth-dependent modality shift: early/mid layers contain many mixed features; layers 16–20 are dominated by audio-modal features; the final hidden state reverts to a mostly text-modal subspace. This supports the claim that the backbone forms acoustically grounded directions mid-network rather than merely carrying text features forward.
Auto-interpretability is quantified (layer-20 case study): text-modal features are easiest to validate (AUROC 0.921), audio-modal are above chance (AUROC 0.653), and mixed features are hardest (AUROC 0.558), with similar trends across layers.
Qualitatively, features correspond to phonemes, laughter, accent cues, breaths, stuttering, prompt attributes, etc. Steering demonstrates causality: e.g., targeted interventions increase laughter probability from 0.02 to 0.79, flip perceived speaker gender, and control speech rate while largely preserving content. The provided excerpt truncates later parts of the results (e.g., details of acoustic probes and additional quantitative metrics).1b:Ta2e,The analysis has three layers: logit-lens observation, representational probing, and mechanistic localization.

First, the authors use the logit lens to inspect intermediate next-token distributions during transliteration. They find that when the model is producing a non-Latin output, middle-to-upper layers often transiently predict romanized subwords before committing to the final script. In other words, the model often does not move directly from source script to target script. It appears to pass through an intermediate representation aligned with Latinized forms. The paper turns this into a quantitative phenomenon, latent romanization, and studies it across scripts and models rather than relying on a single anecdotal example.

Second, the paper analyzes representations of the same language written in different scripts. Script identity becomes increasingly linearly separable in deeper layers. Based on this, the authors construct simple linear steering directions that flip the output script while largely preserving semantic content. Two points matter here. One is that script choice can be manipulated with a low-complexity linear intervention, suggesting that script identity is explicitly encoded in later layers. The other is a strong directional asymmetry: steering toward non-Latin scripts is more reliable than steering toward Latin. This supports the paper’s main hypothesis that Latin is not a compact target cluster but a more diffuse representational region.

Third, the authors localize a small set of late-layer attention heads that causally mediate script generation. With activation patching on only a few heads, they can redirect the output script on natural prompts, and the same heads transfer across unrelated languages and writing systems. This suggests that script choice is not uniformly distributed across the network. Instead, part of it is concentrated in a small number of routing components in later layers. The asymmetry appears again at the mechanistic level: non-Latin generation depends on compact, identifiable mechanisms, whereas Latin generation is more distributed and harder to control through a small intervention.

From a pretraining perspective, the paper is effectively arguing for a joint effect of data frequency, tokenization convenience, and representational sharing. Latin script is more common in pretraining corpora and often easier for tokenizers to encode cleanly, so it becomes a natural shared substrate. Non-Latin scripts then require additional late-stage routing to write the shared semantic content back into a specific surface form.1c:T783,A representative qualitative example uses Llama-2-13B to visualize transliteration from Malayalam to Devanagari. The model choice is deliberate: its tokenizer makes Devanagari visually legible in logit-lens plots, whereas more byte-fragmented tokenizers such as Llama-3 obscure the transition. That detail is informative on its own, because it shows how tokenization affects the observability of internal mechanisms.

The main empirical findings come in several forms. First, quantitative logit-lens analysis supports latent romanization: romanized pieces of the target word appear in intermediate layers before the final target script emerges. Second, representations of the same language in different scripts become more separable in deeper layers, implying that script identity is not fully disentangled from the start but is progressively made explicit later in the network. Third, linear steering can reliably flip output script while preserving meaning to a large extent, and the steering directions transfer to unseen languages and writing systems. However, the transfer is asymmetric: moving toward non-Latin scripts is easier than moving back toward Latin. Fourth, mechanistic probing identifies a small number of late attention heads whose patching is sufficient to change output script on natural prompts, and these heads transfer across languages, suggesting a relatively general script-routing mechanism.
