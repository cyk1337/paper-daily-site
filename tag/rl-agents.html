PhantomEnvironments: Training LLM Agents in Fictional Worlds

这篇工作要解决的问题不是“怎样把搜索 agent 再调好一点”，而是更前面的训练瓶颈：RL 训练 LLM agent 时，环境从哪里来。一个可用环境需要同时满足三件事：能产生长轨迹交互、终局奖励可验证、还能低成本大规模扩展。现有两条路各有硬伤：基于真实语料和人工标注的环境贵、更新慢、容易把 agent 绑死在固定知识快照上；基于 LLM 合成的环境虽然便宜一些，但会带来 hallucinated reward、benchmark contamination、API 成本和生成器能力上限。作者提出的问题很具体：如果完全不用人和 LLM，只靠规则生成一个虚构世界环境，RL 训练出来的搜索能力能否迁移到真实世界多跳检索任务；以及这种迁移到底学到的是“知识记忆”还是“可泛化的搜索技能”。

评这篇值得看，因为它在动摇“agent RL 必须贴近真实世界数据”的 prior；先看 transfer 主结果和 budget scaling，若 setup 干净，内部可立刻试规则环境做 tool-use 训练。
Anmol Kabra,Swathi Saravana Selvam,Albert Gong,Chao Wan,Christian Belardi,Dongyoung Go,Katie Z. Luo,Kilian Q. Weinberger

Multi-Channel Mitigation of Source-Trust Shortcuts in Fact-Checking RL Agents

在检索增强的事实核查系统中，模型容易产生“来源信任捷径（Source-Trust Shortcuts）”，即模型的最终裁决（verdict）过度依赖证据来源的可靠性标签，而忽略了证据本身的文本内容。

评揭示了 RLHF/GRPO 容易让模型学到 spurious correlation（过度依赖 metadata 标签），并给出了 data augmentation 的解法，做 RAG 和 RL post-training 的同学必看。
Jianchang Su,Yiwei Yang,Wei Zhang
