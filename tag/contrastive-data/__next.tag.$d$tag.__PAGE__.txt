9:T521,The central object is a contrastive forget set. Each forget unit pairs the same question under a deception-triggering context c+ and a neutral context c-, using the model’s own responses. A tuple is kept only when the model’s behavior flips while its apparent belief is preserved, so the dataset records realized deceptions without human annotation. The paper then analyzes why existing unlearning objectives are incomplete. Suppression objectives such as NPO reduce the likelihood of the deceptive continuation but do not specify where probability mass should go, so the model may produce other bad continuations. Target-based objectives, such as counterfactual distillation, copy the neutral-context behavior into the pressured context, with a fixed point close to πθ(·|x,c+) = π0(·|x,c-). They remove deception well, but cause context blindness: the model behaves as if the system prompt or user pressure were absent, losing benign instruction following, secret-keeping, and explicit recognition of the pressure in its reasoning. Pact addresses this by using targets that keep the honest answer and reasoning while explicitly acknowledging the pressure or instruction and stating that it should not change the answer.
