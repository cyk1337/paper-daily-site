Scaling Scientific Discovery Environments for Turn-Level Agentic RL

这项工作要解决的是科学数据分析 Agent 的训练接口问题：真实科学数据很多，但通常只有静态数据文件，缺少可执行环境、可验证目标和跨 turn 的过程监督。结果是 Agent 只能靠提示词或通用多轮数据学习分析流程，很难学到什么时候查数据、什么时候选统计方法、什么时候修正假设、什么时候提交结论。

评可过程验证环境比最终答案 RL 更接近可扩展监督；只看 SciThèque/DiscoPO 设计和 verifier 噪声处理。

GUI vs. CLI: Execution Bottlenecks in Screen-Only and Skill-Mediated Computer-Use Agents

评这篇的 setup 比结论更值钱；看任务匹配和 verifier 设计，可校准 GUI/CLI agent 评测。

Tmax: A simple recipe for terminal agents

如何在长时序、强交互、奖励稀疏且评测严格的“终端（terminal）代理”场景里，给开源权重模型提供一套可复现、稳定的 RL 后训练配方，并配套足够难、足够大、可用于 RL 的环境数据，从而把小模型的 terminal agent 能力推到可用水平。

评把“terminal agent 怎么做数据+怎么做 outcome-only RL”讲成可复现配方，适合直接照着复现；但提升可能主要来自数据生成与评测对齐，别把算法增益想太多。
