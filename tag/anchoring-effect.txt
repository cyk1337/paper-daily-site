18:T44c,The design decomposes the repair packet into four retry conditions with matched budgets. In resample, the model sees only the original prompt again. In placebo, it sees its failed program plus a content-free notice that it was wrong. In feedback, it also receives the actual failing input, expected output, and observed output. In reflect, it is asked to diagnose the failure in prose before rewriting the code. This separates the value of another draw, self-exposure, diagnostic feedback, and verbal reflection. Retry attempts use temperature 0.8; the authors explicitly avoid greedy retry because it would return byte-identical programs and make resampling meaningless. Each trajectory allows up to k=8 attempts, and pass@1 for all k≤8 is read from the same trajectory. Paired contrasts are tested with exact McNemar tests, task-level bootstrap intervals, and Holm correction.
