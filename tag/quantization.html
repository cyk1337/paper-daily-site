这篇论文解决的是 VLM 在边缘设备上做端到端低比特量化时的激活动态范围问题。视觉 token 和文本 token 的分布差异很大，视觉激活有更宽的动态范围和离群值，文本激活更集中。标准 microscaling / block floating-point 格式用一个共享 exponent 覆盖一个 block，遇到视觉离群值时会让共享 exponent 被离群值主导，导致同 block 内较小元素下溢，注意力图和跨模态融合被破坏。

评针对 VLM 异常值的创新量化格式，反转了共享指数的常规做法，做量化和端侧部署的研究员值得看其格式设计和硬件映射。
