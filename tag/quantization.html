Squeezing the Cache, Preserving the Truth: Monotonic Equipotential Allocation with Geodesia-KV

Minima-KV: Retention-Preserving KV Cache Compression with Mixed-Format Paged Attention

这篇工作处理的是长上下文推理里的一个很具体、也很工程化的瓶颈：KV cache 不只是占显存，它还直接限制并发、batching 和带宽利用率。已有方法通常在三条路里选一条：统一量化、重要性驱动的淘汰、或者结构化压缩。问题在于，统一量化对所有 token 一视同仁，浪费比特；淘汰会引入不可逆的信息丢失，未来注意力一旦回跳就可能出错；结构化压缩如果需要频繁重建，运行时开销又会吃掉收益。Minima-KV 想解决的是：能不能在 paged attention 运行时里做一个“保留式”的分层 KV 管理，让旧 token 降精度而不是被删除，同时又不引入一个同尺寸 dense shadow cache，保持 decode 路径可部署、可图捕获、可混合格式执行。

评这是典型值得 skim 的系统 paper：方法不改训练范式，但 mixed-format + online-softmax merge 很干净，先看压缩比和 LongBench/RULER 退化是否真在你能接受的区间。
Sergii Kozyrev,Davyd Maiboroda
