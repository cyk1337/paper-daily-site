9:T5eb,DRIFT (Decoupled Rollouts and Importance-Weighted Fine-Tuning) is built on the claim that the KL-regularized RL objective is equivalent (or yields an equivalent gradient) to a weighted supervised learning objective when trajectories are reweighted by exponentiated rewards/returns.

1) MDP formulation: state is the full interaction history; feedback is deterministic lightweight text (e.g., “Incorrect, please try again”); reward is verifiable 0/1 correctness; discounting penalizes delayed success.

2) Equivalence to weighted SFT: under KL regularization to a reference policy, the optimal policy’s density ratio relative to the reference is proportional to exp(return). Therefore, trajectories sampled from the reference can be used for learning if each trajectory (or each turn) is weighted by an importance weight derived from exp(discounted return).

3) Two-stage pipeline:
- Offline rollout stage: collect multi-turn trajectories under a fixed reference policy (high-throughput, parallelizable).
- Importance-weighted fine-tuning stage: perform trajectory-weighted maximum likelihood training using the derived weights, avoiding repeated on-policy rollouts during optimization.

4) Practical considerations: the approach can suffer from high-variance or extremely sparse weights if the reference rarely produces successful correction trajectories; in practice this typically requires weight temperature, clipping, or other stabilization tricks (to be verified in the implementation details/ablations).a:T5fb,The starting point is fixed-reference KL-regularized reward maximization: maximize expected verifier reward while penalizing KL from π_ref. The optimizer is a Boltzmann target policy, proportional to π_ref multiplied by exp(r/β), where β controls the strength of the KL regularizer. A weighted SFT objective, however, induces a policy proportional to q w, where q is the rollout sampler and w is the sample weight. Matching weighted SFT to the RLVR optimizer requires q w to equal the Boltzmann target, so w must be proportional to π*/q. In the reference-sampled case q = π_ref, this uniquely gives the prompt-normalized Boltzmann density ratio exp(r(x,y)/β) / Z(x). The proposed BOLT procedure precomputes reference rollouts, verifier scores, Monte Carlo normalizers, and Boltzmann weights, then trains with standard multi-epoch SFT. The finite-data analysis separates a support gap from ordinary learning errors. For a one-shot sampled set S_N, even the best support-restricted replacement pays β log(1 / π*(S_N | x)) if the sampled support misses target mass. Other terms include partition-function estimation error, effective-sample-size variance, empirical generalization, optimization error, and parametric approximation. In binary-verifier settings, rare correct samples create a temperature–coverage–variance tradeoff, with roughly 1/p reference samples needed when the reference pass probability is p.
