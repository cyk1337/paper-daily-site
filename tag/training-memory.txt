Ember is built on two core design choices: 1) Remove Adam's first-moment EMA entirely and use instantaneous gradients — ablation shows this change improves performance while saving V×D memory; 2) Leverage the observation that row-wise gradient energy of token interfaces is an unbiased estimator of token occurrence probability p_i, and row-wise Fisher scales with p_i², so full V×D second-moment buffers are unnecessary. Key differences from prior work: Adafactor uses similar second-moment factorization but has more hyperparameters and is not purpose-built for token interface geometry; Muon only applies to linear layers and relies on singular value decomposition, making it unsuitable for embedding tables.1a:T846,Gefen has two main components.

The first is shared second-moment estimation. The paper starts from a theoretical analysis on a two-layer MLP and studies when two parameters with a large mixed Hessian entry should also have similar squared-gradient magnitudes. The key result is that, under feasible Hessian bounds, increasing the magnitude of the mixed Hessian contracts the admissible ratio of squared gradients toward 1. This gives a clean design principle: parameters that are strongly coupled in curvature are natural candidates for sharing Adam’s second-moment estimate. Since explicit Hessian computation is intractable in large models, Gefen uses the structure of the first-step squared gradients as a proxy. For each parameter tensor, it flattens the tensor, enumerates proper divisors p of the tensor length n, reshapes g0^2 into consecutive blocks of size p, and computes an intra-block heterogeneity score E(p). Small E(p) means the squared gradients within each block are similar, so replacing element-wise v with one shared scalar per block should incur limited distortion. Larger p gives more aggressive sharing and lower memory, so the method selects p by balancing compression against heterogeneity. An important empirical observation is that E(p) is not necessarily monotonic in p; some larger divisors align better with real structural patterns such as attention heads or channel groups. That is why automatic search can outperform hand-written grouping rules.

The second component is first-moment compression. Instead of using a generic low-bit quantizer, Gefen reuses the same block partition and quantizes the first moment m with a learned codebook. The assignment is solved exactly with dynamic programming. Two design choices matter here. First, the codebook is learned rather than manually specified. Second, reusing the same partition avoids introducing another independent block-size hyperparameter. In effect, Gefen is a joint optimizer-state compression scheme: structured sharing for v and codebook-based quantization for m, both built around an automatically inferred block structure.1b:T6d7,The main empirical claims are threefold. First, memory: Gefen reduces optimizer-state memory by about 8× relative to AdamW, corresponding to roughly 6.5 GiB saved per 1B parameters. That is the headline systems result. Second, quality retention: across both LLM and non-LLM models, the method maintains performance comparable to AdamW, with some settings showing slight gains. The introduction explicitly states that Gefen achieves the lowest memory footprint among compared methods while keeping quality and throughput comparable or better. Third, the automatic grouping mechanism appears to capture real structure rather than arbitrary compression. Beyond the toy theory, the appendix shows similar behavior in real tensors, including attention and convolutional layers, where the discovered partitions produce more homogeneous squared gradients within blocks.

The most relevant baselines are AdamW, Adam-mini, and quantized optimizer variants. Adam-mini reduces memory through manually specified sharing patterns, but requires architecture information such as the number of attention heads and depends on tensor naming. Gefen removes that dependency. Quantized optimizers often rely on hand-crafted codebooks and an extra block-size hyperparameter; Gefen replaces those with a learned codebook and exact dynamic programming. Another practical point is overhead: the grouping pattern is inferred once from the first-step gradient rather than recomputed throughout training, so the method avoids a large recurring cost.
