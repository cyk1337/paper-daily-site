9:T9c6,方法由两个部分组成：CQS Divide 和 Stream-CQSA。

CQS Divide 是一个组合式分解。作者把 attention 看成 token 两两交互构成的完全图，然后用 cyclic quorum sets 的构造，把完整序列划分成若干 subsequences，使得所有 token pair 的交互在这些 subsequences 内被“恰好覆盖一次”。关键不是随便切块，而是要保证重组后与 full attention 完全等价。论文先把序列分成 c 个 chunk，再构造 c 个由 l 个 chunk 组成的 subsequences，并要求每个 chunk pair 只在一个 subsequence 中出现。由覆盖条件可得 c=l(l-1)+1，因此可用的 c 取值是 1,3,7,13,21,...。作者重点展开了最小非平凡情形 l=3,c=7，用 cyclic 的 interest set，例如 (0,1,3)，生成 7 个子序列。这个构造对应于把完全图 Kc 分解成若干 Kl 子图，和 Steiner system 有直接关系。

在具体计算上，每个 subsequence 从全局 Q/K/V 中 gather 出对应子张量，独立计算局部 attention 的 softmax 分子 Num_i 和分母 Den_i。然后把这些局部结果 scatter 回全局 token 坐标，累加成全局 Num 与 Den，最后做一次逐 token 归一化 O = Num ⊘ Den。这样做的关键点在于 softmax 不是直接对局部输出求平均，而是把 numerator / denominator 分开累积，因此重组后与全序列 softmax 完全一致。反向传播也沿同样的分解进行：先从全局输出梯度构造各子问题的 dNum_i、dDen_i，再求 dQ_i、dK_i、dV_i，最后 merge 回全局坐标。

Stream-CQSA 则是在这个精确分解之上做调度。因为每个 subsequence attention 都是独立任务，系统可以根据显存预算决定一次加载多少 chunk、何时 materialize 哪部分 QKV、何时释放中间结果。作者强调它是 memory-adaptive scheduling framework：把原本逻辑上单体的 attention 变成可调度任务集合，用更多时间换更低峰值显存。递归应用 CQS Divide 后，子问题还能继续细分，因此理论上可以适配任意小的可用内存。

和 FlashAttention 一类方法相比，区别不在于 kernel 更快，而在于问题设定不同。FlashAttention 优化的是在 full QKV 已经在显存中的情况下，减少中间矩阵 materialization 和 IO；Stream-CQSA 处理的是 full QKV 根本放不下时怎么办。和 sparse / low-rank / kernel attention 相比，它不做近似，输出与 exact attention 一致，但代价是更多调度开销和重复 gather/scatter。a:Tae4,The method consists of a combinatorial decomposition, CQS Divide, and a scheduling framework, Stream-CQSA.

CQS Divide starts from a graph view of attention: full self-attention corresponds to all pairwise token interactions, i.e., a complete graph over tokens. The goal is to partition the sequence into subsequences such that every token-pair interaction is covered exactly once across the set of subsequence attentions. The construction is based on cyclic quorum sets. The sequence is first split into c chunks. Then c subsequences are built, each containing l chunks, under the condition that every chunk pair appears in exactly one subsequence. This yields the coverage constraint c = l(l-1)+1, so valid chunk counts are 1, 3, 7, 13, 21, and so on. The paper focuses on the smallest nontrivial case, l=3 and c=7, using a cyclic interest set such as (0,1,3). In graph terms, this is a decomposition of K_c into K_l subgraphs, closely related to Steiner systems.

The exactness comes from how softmax is recomposed. For each subsequence, the method gathers the corresponding Q_i, K_i, and V_i from the global tensors and computes local softmax numerator and denominator terms, Num_i and Den_i. These are then scattered back into global token coordinates and accumulated into global Num and Den, followed by a final token-wise normalization O = Num ⊘ Den. This is the key idea: the method does not average local attention outputs directly, which would be wrong under softmax. Instead, it accumulates numerator and denominator separately, preserving exact equivalence to full attention. The backward pass mirrors the same decomposition, constructing local gradient terms from the global upstream gradient and then merging dQ_i, dK_i, and dV_i back into full-sequence coordinates.

Stream-CQSA builds a memory-adaptive execution framework on top of this decomposition. Since each subsequence attention is independent, the system can schedule them according to an arbitrary memory budget: load only the necessary chunks, compute a subset, accumulate partial results, and release memory before moving on. Because CQS Divide is recursively applicable, the workload can be subdivided further when memory is tighter. The result is a time-for-memory trade-off that enables exact attention under memory budgets where full QKV materialization would otherwise be impossible.

Compared with FlashAttention-style methods, the difference is not a faster kernel but a different problem setting. FlashAttention assumes full QKV is available and optimizes IO and intermediate storage. Stream-CQSA addresses the case where that assumption already breaks.
