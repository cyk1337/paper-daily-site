EnvOS: Auditing Computer-Use Agents When the World Moves On : Phenomenon-Based Task Construction, Certification, and Evidence-Based Evaluation

这篇工作处理的不是“如何让 computer-use agent 更强”，而是一个更基础的问题：当环境会在任务执行中途发生真实状态变化时，怎样构造一个可解释、可审计、可归因的评测与训练环境。作者指出，动态环境下的失败来源至少有三类：一是 agent 决策真的错了；二是预设的环境变更没有按设计触发，或触发时机不对；三是 grader / verifier 把本来正确或错误的轨迹判反了。若这三者不分开，benchmark 分数和 RL 中的可验证奖励都会被污染。论文聚焦的现象是 stale authoritative information：模型先看到一个任务相关值，之后底层权威记录发生变化，模型在后续步骤里是否会基于过期信息做决定。关键难点不在于“加一个扰动”，而在于证明这个扰动确实发生、任务仍然可解、模型确实接收到了应有观察、最终判分也有证据支撑。

评读 EnvOS 的 certification 流程即可；动态环境评测的脏活讲得实在，成功率数字别过度外推。
