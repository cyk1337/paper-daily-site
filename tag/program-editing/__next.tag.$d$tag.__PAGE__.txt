9:T7dd,Hill Sampling is intentionally minimal. Start from an initial program x0. At each round, sample N candidate edits from a frozen LLM conditioned on the current incumbent xt. Execute each candidate with the verifier, obtain rewards, and replace the incumbent if the best candidate in the round matches or exceeds the best reward seen so far. The algorithm stores the incumbent’s historical best reward rather than re-evaluating it every round, which is important when execution is stochastic. Equal-reward replacements are allowed to preserve some structural diversity. There is no archive, no crossover, no explicit diversity objective, and no parameter update. The main knobs are decoding temperature, samples per round, and number of rounds.

The paper is stronger because it does not stop at introducing the method. It systematically compares three exploration families. First, repeated sampling, where all generations are drawn independently from the same starting point. Relative to that baseline, Hill Sampling adds exactly one persistent state: the best-so-far program fed back into context. Second, evolution strategies applied directly to LLM weights. The authors build a large-scale ES pipeline and separate standard ES learning from a zero-learning-rate variant that keeps only random weight perturbations. This isolates exploration from learning. Third, they test common add-ons such as diversity encouragement, solution combination, extra exploration mechanisms, and code-execution feedback. The conclusion is that none of these are necessary to obtain strong results in this setting.

Mechanistically, Hill Sampling treats the LLM as a conditional editor rather than a one-shot generator. The incumbent acts as a moving scaffold. Future samples are drawn near the current best program instead of restarting from the original problem statement. That creates a simple local search process in context space, not in parameter space. The paper’s main contribution is showing how far that alone can go.a:T79c,The evaluation covers three verifiable mathematical optimization problems with three open-weight models: circle packing with gpt-oss-20b, sums/differences of finite sets with OLMo-3.1-32B-Instruct, and Erdős’ minimum-overlap problem with Mistral-Small-3.1-24B-Instruct. The emphasis is practical wall-clock performance, not only sample efficiency.

The headline result is on circle packing: Hill Sampling reaches the best published result in under five hours on eight H100 GPUs. On the Erdős minimum-overlap problem, it surpasses the AlphaEvolve algorithmic-discovery reference within 12 hours. The abstract is truncated, but the body makes the qualitative outcome clear: one new published best result and strong competitive performance on the other tasks.

The ablations are the most informative part. Hill Sampling substantially outperforms repeated sampling, showing that best-so-far conditioning is the main source of gain. Standard ES often improves mean return while reducing maximum return, which directly supports the paper’s framing that mean-oriented updates can be misaligned with discovery objectives. Setting the ES learning rate to zero removes learning but keeps random weight perturbations; this sometimes preserves maximum return better than learned ES, yet still underperforms plain token-sampling randomness from the unperturbed model. That is a useful boundary condition for claims about nearby experts in pretrained weight space: even if such experts exist, searching for them may be less effective than output-space exploration when exact verification is available.

The paper also compares Hill Sampling with N=64 and N=512 under the same total sampling budget, changing the trade-off between more frequent incumbent updates and larger within-round candidate sets. Even without all table values here, the setup is worth attention because it probes whether iterative conditioning matters more than wider one-shot search.b:T514,For a quick read, focus on three parts. First, the opening motivation where the paper distinguishes maximizing best-found reward from improving average sample quality. That framing explains nearly every later result. Second, the formal definition of Hill Sampling in the methods section, especially the stored incumbent reward, equal-reward acceptance, and the budget-matched N=64 versus N=512 variants. Third, the ES and model-noise comparison, which addresses a broader question than the benchmark itself: should test-time exploration happen in token space or weight space?

If you have 20–30 minutes, read in this order: the main algorithm figure, the primary result tables for the three tasks, the ES comparison plots, then the discussion. The key is not the benchmark details but the way the authors strip a complex discovery pipeline down to one necessary mechanism.

Two points are worth deeper thought. One is whether Hill Sampling depends on the locality and compositionality of program editing; the same recipe may transfer less cleanly to natural-language proofs or unverifiable reasoning. The other is the tension between max return and mean return.
