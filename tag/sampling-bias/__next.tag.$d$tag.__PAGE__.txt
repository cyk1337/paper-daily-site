9:T9b1,方法上，论文先做了一个很干净的分解。作者把某个敏感分叉变量称为 fork，比如故事主角的性别、某个观点问题的立场。对于 fully masked canvas，只需一次前向，就可以直接读取模型在 fork 位置上的条件分布，把它定义为 model belief。作者证明并实证表明，这个 belief 与“从模型精确采样”是一致的，但成本远低于完整 sampling audit，文中给出的成本比是 1/11,520。这一步很关键，因为它把模型本身的偏好从 sampler 的影响里剥离出来了。

接着，论文分析 sampler 为什么会放大多数选项。核心区分是 commit rule 是否 peeking。所谓 peeking，是指 commit score 依赖于该位置刚刚采样出来的 token 身份，例如“采样到的 token 概率越高，越优先提交”。这种规则会让高概率 token 不仅更容易被采到，还更容易被保留下来，于是多数选项的 odds 被再次乘大。相对地，identity-blind rule 在决定提交哪些位置时，不看 proposal token 是什么，只根据位置本身的状态、熵或外部随机性来决定。论文给出形式化定义，并用一个 lemma 说明：如果 commit rule peeks，且提交概率随 token score 单调增加，那么更高概率的选项会得到额外的 odds amplification；identity-blind rule 则不会产生这类 token-channel 放大。

论文进一步指出还有第二条放大通道：ordering channel。即便 commit rule 本身不 peek，如果系统按 confidence order 先提交高置信位置，模型就会更早写入某些带有性别倾向或立场倾向的上下文，这些早期上下文又会反过来影响后续 fork 位置的条件分布。作者在职业故事场景里观察到，male-leaning context 往往在第一个 pronoun 之前被更早写入；而且每步 commit 的 token 越多，这种顺序偏置越强。

在干预方法上，作者提出 Fork-First Sampling（FFS）。思路很直接：在任何其他 token 写入之前，先从 model belief 或预设 target distribution 中抽取 fork 的值，再把这个已定 fork 的 canvas 交给任意 sampler 继续生成。faithful mode 用 belief 采样，目标是忠实于模型；fair mode 用目标分布采样，目标是控制 representation。FFS 只多一次前向，兼容 greedy decoding，也比“在 prompt 里显式指定性别”更自然，因为它不强行改写叙事内容，而是只控制关键分叉变量。a:T81e,实验覆盖 LLaDA-8B、LLaDA-1.5 和 Dream-7B，并在 occupational stories、GlobalOpinionQA、TANGO 以及一个已知真分布的 synthetic model 上验证。最醒目的例子来自引言：在固定 prompt 和模型下，LLaDA 默认 sampler 生成 female manager 的比例只有 21%，但模型本身对 female protagonist 的 belief 却是 66%。如果 sampler 完全忠实于模型，这两个数字不应出现如此大的偏差。作者还在 60 个职业上做回归，生成文本中的 female share 对 belief 的斜率达到 1.80，而精确采样应为 1。这说明 sampler 不只是有噪声，而是在系统性放大多数倾向。

论文把这种放大拆成两部分验证。对 token channel，作者比较 peeking 与 identity-blind commit rule，展示同一个位置若采到少数选项，其提交排名会显著下降。文中举的 LLaDA 单步例子里，采到少数代词 She 的位置，在 peeking 规则下 28 个候选里只排第 25，而在 identity-blind 规则下排第 3，因为后者不因 token 身份而惩罚它。对 ordering channel，作者分析在 confidence-based ordering 下，某些带性别倾向的上下文会在 fork 之前更早落盘，并且一次提交更多 token 时偏置更强。

FFS 的结果也比较扎实。用 fair mode 设定 50:50 目标后，在两类模型上都能把最终 fork 分布控制到距离目标 1.4 个百分点以内，同时 fluency 还有提升。faithful mode 则能让生成分布更贴近 model belief，避免默认 sampler 的额外放大。论文还强调，FFS 与 prompt-specified gender 不同，后者虽然也能控制表面属性，但常常损伤文本自然度或改变故事内容；FFS 因为只在生成初期固定 fork，后续内容仍由模型自由展开，所以文本质量更稳。

从实验结构看，最有说服力的是作者没有只做最终输出统计，而是先建立 belief 读取这一“近似 oracle”，再用它作为基准衡量 sampler 的偏差。这样可以把“模型本来就偏”与“sampler 把偏差放大了”分开讨论。b:T8e1,The paper first introduces a clean decomposition around a binary or categorical fork, such as a protagonist’s gender or an opinion label. On a fully masked canvas, one forward pass is enough to read the model’s conditional distribution at the fork position. This is treated as the model’s belief. The authors show empirically that this belief matches exact sampling from the model, while costing only 1/11,520 as much as a full sampling audit. This gives them a practical reference distribution that isolates the model from the sampler.

The main theoretical distinction is between peeking and identity-blind commit rules. A commit rule is peeking if the decision to commit a position depends on the identity of the token just sampled at that position, for example by favoring positions whose sampled token has higher probability. Such rules amplify majority options twice: they are more likely to be sampled and more likely to be kept. By contrast, identity-blind rules decide which positions to commit without looking at the sampled token identity. The paper formalizes this distinction and proves that under peeking rules, if commit probability increases with a score that increases with token probability, then the odds of the more probable option are further amplified. Identity-blind rules do not create this token-channel amplification.

The paper then identifies a second mechanism, the ordering channel. Even without peeking, confidence-based ordering can write gender-leaning or opinion-leaning context before the fork is resolved. That early context then shifts the conditional distribution at the fork position. In occupational stories, the authors show that male-leaning context tends to be written before the first pronoun, and the effect becomes stronger when more tokens are committed per step.

As a mitigation, the paper proposes Fork-First Sampling (FFS). Before any other token is written, the fork is sampled either from the model belief (faithful mode) or from a target distribution (fair mode), and the partially fixed canvas is then handed to any downstream sampler. FFS costs one extra forward pass, works even with greedy decoding, and gives exact control over the fork distribution without the awkwardness of prompt-level attribute forcing.c:T7c5,The experiments cover LLaDA-8B, LLaDA-1.5, and Dream-7B on occupational stories, GlobalOpinionQA, TANGO, and a synthetic model with known ground-truth belief. The headline example is striking: with the same prompt and model, LLaDA’s default sampler produces a female manager in only 21% of stories, while the model’s own belief assigns 66% probability to a female protagonist. Across 60 occupations, the slope of generated female share against model belief is 1.80, whereas exact sampling would yield a slope of 1. This shows systematic amplification rather than random deviation.

The paper validates both amplification channels. For the token channel, it compares peeking and identity-blind commit rules and shows that minority proposals are selectively delayed or discarded under peeking. In one real LLaDA step, a position that sampled the minority pronoun “She” ranked 25th out of 28 under the peeking rule, but 3rd under the identity-blind rule, because the latter does not penalize the proposal based on token identity. For the ordering channel, the paper shows that confidence-based ordering writes skewed context before the fork, and that committing more tokens per step strengthens this effect.

FFS performs well in both faithful and fair settings. In fair mode with a 50:50 target, the final fork distribution lands within 1.4 percentage points of the target on both model families, while also improving fluency. In faithful mode, generation tracks the model belief much more closely than the default sampler. The paper also argues that FFS is preferable to prompt-specified gender because prompt forcing can distort content or reduce naturalness, whereas FFS only fixes the fork and lets the rest of the story unfold normally.

A strong aspect of the experimental design is that the authors do not only compare final outputs. They first build a belief-reading reference and then measure how far each sampler moves away from it. That makes the attribution much cleaner.d:T5f7,Start with the introduction and the section on why samplers amplify majorities.
