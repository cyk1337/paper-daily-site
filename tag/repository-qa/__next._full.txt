18:T435,The system uses MCTS to organize repository exploration. It first parses the repository into a queryable representation, including directories, files, classes, functions, and code spans. At inference time, it builds a search tree where each node stores the current evidence and reasoning state. The action space covers semantic search, structural navigation, targeted code inspection, and stopping. Four agents operate in each iteration: a Perception Agent summarizes the current state and missing evidence; a Planning Agent proposes candidate actions; an Execution Agent runs the selected action over the indexed repository; and an Evaluation Agent scores the new state and propagates value estimates back through the tree. Compared with ReAct, the key difference is multi-trajectory exploration. ReAct follows one path and can accumulate early mistakes; DeepRepoQA keeps multiple branches alive and uses value estimates to balance exploration and exploitation.
