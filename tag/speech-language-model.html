Do Factual Recall Mechanisms Carry over from Text to Speech in Multimodal Language Models?

这篇工作问的是一个很具体但重要的问题：文本 LLM 中已经较清楚的“事实回忆”内部机制，到了语音输入的多模态语言模型里，是否还以相同方式存在。作者不是看最终答对率，而是看事实关联在模型内部哪里被编码、哪里被传递、哪些层和位置对正确答案最有因果作用。对象是 SpiritLM 这类把离散语音 token 与文本 token 统一送入 Llama2 骨干的模型，因此问题可以进一步拆成两层：一是语音输入能否触发与文本输入相似的 factual recall 回路；二是这种能力来自语音侧独立学到的机制，还是主要借用了文本骨干里已有的知识回忆结构。

评如果你把语音 token 当“另一种文本”来训，这篇会提醒你这个 prior 过于乐观；先看方法设定和 text-vs-speech 的 mediation 差异，足够决定后续是否复现。
