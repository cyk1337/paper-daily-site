18:T611,SMET has three main components. The first is optimizer-state warm-up for regrown parameters. When a connection is activated, its weight may be initialized reasonably, but its Adam moments are effectively newborn. Applying the same optimizer rule as for mature parameters creates a cold-start problem: the update magnitude and direction are not calibrated by historical statistics. SMET introduces a controlled warm-up phase so that newly activated weights do not inject abrupt disturbances into training immediately after topology changes. The second component is density-aware learning-rate scaling. Warm-up improves stability but also makes updates more conservative. In sparse regimes, the effective parameterization and gradient statistics differ from dense training, so simply reusing the dense learning-rate recipe slows progress. The density-aware scaling compensates for this and better matches optimization to the active parameter budget. The third component is a memory-efficient sparse optimizer implementation. Instead of keeping dense tensors plus binary masks, SMET stores gradients and optimizer states only for active parameters. This is important because many sparse-training implementations save parameters sparsely but still pay dense-state memory costs. The method supports both unstructured and block sparsity, which matters for eventual practicality. A useful aspect of the paper is that it frames the instability as a general DST issue across pruning/regrowth variants, rather than something tied to one specific sparse algorithm.19:T518,The experimental story is centered on training dynamics and scaling behavior. The paper first shows that existing DST methods exhibit clear post-update loss spikes during LLM pretraining, and that these spikes are strongly associated with newly regrown weights. With optimizer warm-up, the spikes are substantially reduced, which supports the causal diagnosis. It then compares SMET against prior DST baselines across model sizes and sparsity levels, showing that the gains become more pronounced at larger scales and higher sparsity. The abstract states that SMET can maintain only marginal degradation at high sparsity on larger models, which is the key practical claim. Another important result is memory efficiency: by storing gradients and optimizer states only for active weights, SMET reduces actual training memory beyond what masked dense implementations can offer. For each input token x, each tree performs D hard binary routing decisions from root to leaf, evaluating exactly one node per level; thus each tree activates a single path and the layer activates exactly P×D nodes. Each node has (1) routing parameters (w_in, b_in) producing a scalar logit used for a hard left/right decision, with stop-gradient used around the discrete decision; and (2) output parameters (w_out) producing a contribution vector. The layer output is the sum of the output vectors from all visited nodes along the path (internal nodes both route and contribute). Compared to MoE, there is no separate router network, no top-k expert aggregation, and sparsity is hierarchical/structured.
