a:T653,The method converts chat-style interaction into a table of parallel token streams, where each column corresponds to a role or channel such as user, system, assistant, thinking, or an auxiliary monitoring stream. At each step, the model attends to the history of all streams and predicts the next token for multiple output streams in one forward pass. Instead of concatenating all roles into one sequence with delimiter tokens, the model performs joint conditional generation over structured streams.

The important detail is that this is not just batched decoding of several independent sequences. The streams are coupled through interdependent attention. The paper frames the change as an instruction-tuning modification: existing message-based data can be transformed into aligned multi-stream supervision, and additional stream annotations can be synthesized from existing chat models. Empty cells are explicitly modeled and can be skipped at inference time to reduce KV-cache growth. The setup also distinguishes input streams, which can receive live external tokens, from output streams, which are generated by the model. That is what enables overlapping reading, thinking, and acting.

Compared with standard chat tuning, the structural information is no longer encoded only through role markers and sequence order. It is built into the tensor layout and attention pattern. The paper also argues that auxiliary internal streams are useful because they do not need to serve as user-facing explanations. They can therefore expose intent or situational awareness more directly than a public chain-of-thought channel.b:T50c,The empirical focus is on system behavior rather than perplexity. The paper reports large reductions in time-to-first-token and lower end-to-end latency by overlapping reading, reasoning, and acting. It also claims that throughput remains close to standard decoding because inference is often memory-bound, so predicting multiple streams in one pass does not linearly multiply latency. Task performance is said to remain largely preserved despite the format change.

Security experiments center on prompt-injection robustness. By explicitly separating system, user, and self-generated content into different streams, the model is better able to track provenance, which improves robustness in long and mixed-source contexts.
