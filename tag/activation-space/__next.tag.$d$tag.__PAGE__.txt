9:T4e4,Activation-Supported Parameter Decomposition represents a target weight matrix W using rank-1 components. Each component has a read direction v_c, a write direction u_c, and a context-dependent gate g_{t,c}(X). The read direction specifies what information is consumed from the input activation, the write direction specifies the output direction being produced, and the gate determines when the component is active at a token position. Pure parameter decomposition is underdetermined because many decompositions can represent the same matrix. ASPD constrains this ambiguity using the model’s actual activation distribution. Instead of optimizing expensive pairwise interventions between all activation features and all parameter components, it uses a shared sparse representation that both defines activation features and gates the corresponding weight components. A local internal reconstruction objective asks the learned components to reconstruct W x at the output of the analyzed matrix, avoiding reliance on final-output effects alone.
