The Handoff Tax: Continuing Non-Native Trajectories in LLM Agents

这篇工作研究的是长程 coding agent 里的一个很实际、但此前缺少系统量化的问题：当任务执行到一半，把一个模型切换成另一个模型，会产生多大的质量和成本损失。论文把这种损失称为 handoff tax。更具体地说，接手模型需要继续一条“非原生轨迹”——包括前一个模型的语言风格、工具调用习惯、错误假设、无效探索和中间代码编辑。核心问题不是单纯比较强模型和弱模型谁更好，而是分析：在长轨迹 agent 中，模型能力切换本身是否破坏了原本应有的 cost–quality tradeoff，以及这种破坏主要来自哪些被继承的信息。

评量化了 Agent 路由/级联策略中常被忽视的 'handoff tax'，证明了跨模型 context 传递的损耗，对设计 multi-agent 或动态路由系统的研究员是重要的 empirical 警示。
Roy Ganz,Mor Shpigel Nacson,Adi Kalyanpur,Ron Litman
