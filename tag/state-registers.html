Streaming Multi-Agent Autoregressive Diffusion Model with World State Registers

现有自回归视频扩散世界模型将观测历史作为条件上下文传递，无法在多智能体、多视角场景下维护一致的共享世界状态。每个生成步都需要从帧历史重新推断世界信息，既难以保证跨智能体的几何与逻辑一致性，也无法覆盖未被观测到的世界状态变化。

评建议看 register 更新和 MoT 分工；这类显式 latent state 可能比堆长上下文更适合多视角世界模型。
