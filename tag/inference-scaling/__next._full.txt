18:T497,All methods are built on a shared primitive, solve(x, c), which makes one model call with optional prior context and extracts an answer. The baseline is a single solve call. Grow performs additive recursion by extending one reasoning path; Prune performs reductive recursion by decomposing the problem, solving subproblems, and recomposing; Branch samples multiple alternative traces and selects or aggregates among them. A practically important contribution is the explicit finalization step inside solve. Some modern reasoning models produce hidden deliberation before visible output; if the token budget is exhausted during hidden reasoning, the API may return successfully but with empty visible content and a length stop. Treating that as a wrong answer unfairly penalizes methods that make more calls. The paper therefore adds a finalization mechanism to salvage budget-exhausted traces into explicit answers when possible.
