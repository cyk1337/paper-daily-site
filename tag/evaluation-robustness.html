Spurious Prompts: Can Irrelevant Prompts Steer Large Language Models?

这篇工作研究一个很少被正面拆开的现象：LLM 是否会被与任务语义无关的 prompt 稳定操控。更具体地说，作者关心的不是 prompt wording 的常规敏感性，也不是更清楚地描述任务能否提升效果，而是那些刻意避开任务词汇、领域线索和常见推理提示的“无关提示”，是否仍然能显著改变模型行为，甚至提升准确率或诱导系统性偏置。

评读实验设计和失败案例：它会削弱对 prompt 语义解释的信心，也提醒 eval prompt 可能藏着非语义捷径。

How Sensitive Are Safety Benchmarks to Judge Configuration Choices?

这篇工作研究的是一个常被当作实现细节、但会直接改写安全结论的问题：安全 benchmark 里用 LLM judge 判定“有害/无害”时，judge prompt 的配置到底有多敏感。作者不是比较不同 target model 的安全性，而是固定评测对象与测试集，专门隔离 judge prompt wording、prompt structure、persona framing 这些因素，测量它们会把 headline harmful rate 推动到什么程度。更关键的是，他们把 judge model 固定为同一个 Claude Sonnet 4-6 做主实验，因此能把波动明确归因到 prompt 本身，而不是 judge 模型差异。

评这篇会直接影响你怎么看对齐实验表格：judge prompt 不是噪声，而是主效应；做 RL 或 safety ablation 前先把评测方差量出来。
