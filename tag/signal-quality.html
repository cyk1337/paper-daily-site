When Teachers Mislead: Spurious-Signal-Aware On-Policy Distillation

这篇论文处理 on-policy distillation 中的一个信号质量问题：teacher 的高置信 token 监督可能来自语言先验、格式偏好或套路化推理模板，而不是来自当前输入。

评值得扫方法部分：它把“teacher 高置信”拆成 grounded 与 spurious，两者对蒸馏梯度的差别可迁移到 RLVR 数据筛选。

RLCSD: Reinforcement Learning with Contrastive On-Policy Self-Distillation

这篇工作解决 RLVR 和 on-policy self-distillation 中的 token 级信用分配问题：只用最终 reward 太稀疏，而用带正确答案提示的自蒸馏信号又容易学到风格变化，而不是学到真正和正确性相关的 token。

评这篇值得看，不是因为又多了个 RL 变体，而是它把 OPSD 的脏信号拆开了；先看 token 分析和长度分布，若成立，内部 RL recipe 应立刻补这个对照。
