1) Setting: study multi-class linear in-context classification in the hard no-margin regime, aiming for an algebraically identifiable inference rule.
2) Identifiability obstacle: task symmetries (permuting examples, feature coordinates, or class labels) are not enforced layer by layer in standard training, so learned weights encode accidental asymmetries that obscure the underlying algorithm.
3) Layerwise symmetry enforcement (identifiability protocol): at each layer, conjugate the attention block by a random block permutation over feature and label coordinates (apply P, run attention, then apply P^T). This forces each layer to implement the same computation in every symmetric coordinate system, acting as a structural denoiser that collapses weights onto a low-dimensional interpretable manifold. Functional equivalence is checked via output alignment and query/context sensitivity fingerprints.
4) Closed-form layerwise recursion: with symmetry enforced, the forward pass becomes readable. Let X_ℓ be training-token features and Y_ℓ their label vectors at depth ℓ. Each iteration forms an affinity/attention matrix from a mixed feature–label Gram structure (feature similarity + label agreement), then uses the same weights to propagate updates to both X_ℓ and Y_ℓ. The query token is updated analogously by attending to the training set and accumulating class evidence across layers.
5) Mechanistic interpretation: the resulting computation is a coupled feature–label dynamical system (coupled mean-shift-like), where representation geometry and label geometry co-evolve. In a label-driven regime, the dynamics preserve class structure and monotonically amplify inter-class separation (margin amplification): a few labeled points anchor classes, and performance is driven by geometric separation.
6) Generalization across tasks: the recursion predicts success in semi-supervised ICL (unlabeled points sharpen geometry), label-noise regimes, and prototype/Voronoi settings when clusters are well separated. Retraining on these tasks recovers the same symmetry-aligned weight structure and the same coupled dynamical motif (with task-specific schedules).19:T8a4,（must_read 级别：详细技术分析）
1）对象与记号：将 Transformer 表示为对残差流 X∈R^{T×D} 的映射。定义标准 block：Attn+MLP+残差+可选 norm。定义 k-stacked block S_k = B_k∘…∘B_1。
2）循环结构（cyclic recurrence）：把一段固定序列的 k 个层重复 l 次，记为 (k⊗l)-Recurrent block；整体模型可含 prelude/coda（sandwich），记为 (p,k,c) 或具体步数 (p,k⊗l,c)。
3）Input injection：每次 recurrence 开始时将原始输入 X 与当前隐状态 Z 拼接后线性投影再进入循环块（一次 recurrence 注入一次），形成 (p,k⊗l,c)_I。该设计用于缓解“循环后期丢失输入信息/漂移”。
4）核心动力学命题（论文主线）：反复应用共享的循环块会逼近某种稳态。作者从“固定点/收敛”出发，指出在循环递推下长期行为必然落入两类之一：
   - 渐近消失（vanishing contribution）：循环中各组件 block 的有效更新趋近于 0，模型后期几乎不再改变残差流（等价于计算饱和/停止）。

1) Setup/notation: a Transformer maps residual-stream matrices X∈R^{T×D} through attention+MLP blocks with residual connections and optional norms. Define a k-stacked block S_k = B_k∘…∘B_1.
2) Cyclic recurrence: repeat a fixed sequence of k layers for l recurrences, denoted (k⊗l). Full models may include non-tied prelude and coda stacks (sandwich), denoted (p,k,c) and instantiated as (p,k⊗l,c).
3) Input injection: at the start of each recurrence, concatenate the original input X with the current latent Z and project back to D before applying the k-layer stack, yielding (p,k⊗l,c)_I. Injection is intended to prevent drift / loss of input signal across many recurrences.
4) Core dynamical claim: repeated application of a shared recurrent block tends toward a steady-state behavior. The authors argue this implies one of two asymptotic regimes:

5) Empirical finding: under certain architectural conditions, the stable k-cycle arises in practice in trained looped models; strikingly, similar cyclic behavior can also appear in randomly initialized (untrained) Transformers, suggesting an architectural inductive bias.
