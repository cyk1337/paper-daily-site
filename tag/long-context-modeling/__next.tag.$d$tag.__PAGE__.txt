The pipeline works as follows: 1) Curate high-quality Python repositories (≥15 GitHub stars, ≥5 contributors); 2) Use LSP's type- and scope-aware analysis, paired with package manager-resolved dependencies, to recursively fetch implementations of imported classes and functions across repository boundaries; 3) Concatenate these dependencies in call order to form high-density long code contexts up to millions of tokens in length. Two corpora are built from this pipeline: the ~6.2B-token cross-repository long-context code dataset, mixed with other long-text data to form the ~50B-token OctoLong-LCFT corpus for mid-training long-context continued pretraining; and the ~10B-token OctoLong-SFT mix (open instruction data + agent data) for supervised fine-tuning. The key difference from prior work: existing cross-document long-context construction relies on weak correlation signals with low context coupling, while single-repository code serialization is limited by repository boundaries.
