Are Arithmetic Heuristic Neurons Form-Invariant? A Mechanistic Analysis of Symbols, Text, and Code in LLMs

这篇工作要回答两个更细的机制问题。第一，LLM 里负责算术的“启发式神经元”是否跨表达形式共享，也就是同一个加减乘除问题写成符号表达式、自然语言题目、或 Python 代码时，模型是否调用同一批神经元。第二，跨格式性能波动到底来自“电路不同”，还是“电路相同但激活状态不同”。这个问题重要，因为很多数学鲁棒性工作只看到表面现象：换个表述模型就掉点，但并不知道问题出在抽象、路由、还是最终计算模块。作者把焦点放在 MLP 神经元层面，而不是只看 attention pattern 或整体表征相似度，因此结论更接近可干预的机制解释。

评这篇不一定改训练 recipe，但会影响你对“模型学到的是模板还是抽象算法”的判断；先看共享神经元识别和跨格式激活迁移实验是否干净。
Sharath Naganna,Tanvir Ahmed Sijan,Uddipta Kalita

How Do LLMs Cite? A Mechanistic Interpretation of Attribution in Retrieval-Augmented Generation

RAG 系统中模型给出的引文可能只是“看起来对”，但未必真的是在生成回答时读取并使用了被引文档——这种 citation faithfulness（忠实引用）问题无法从输入输出表层判断，需要从模型内部机制层面解释模型“什么时候、为什么、由哪些组件决定发出一个引文标记”。

评这篇不改 pretrain recipe，但会改你对“citation=grounding”的先验；只看机制定位和干预结果，别把它外推到所有 RAG 场景。
Ian van Dort,Maria Heuss
