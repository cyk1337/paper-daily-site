9:T44c,AdaExploreBench models environment dynamics as latent rules mapping input fields to an intervention score.
- Setup: each case provides field values; the agent selects one of four ordered actions (increasing intervention strength).
- Latent rule: a subset of fields (factors) with directional effects determines a score s∈[-1,1]; a fixed utility function maps s to action utilities, enabling calibrated evaluation.
- Rule families: additive, conjunctive, disjunctive, and lexicographic dynamics, yielding diverse but controlled hypothesis structures.
- Protocol: in the default setting, the agent decides when/what/how many queries to make to gather evidence. Rule drift occurs without announcement during interaction.
- Sequential batching: evaluation cases are presented in small batches so agents can notice drift either via further probing or via degraded performance, producing an in-process performance curve.
- Scalable synthesis: an LLM-assisted pipeline generates a field catalog (semantics, ranges, sampling distributions) plus cross-field feasibility constraints and dynamics constraints.a:T68c,The study is built around strict control of variables. The authors select 100 harmful request cores from published benchmarks and wrap each with 9 published attack families, yielding 900 attacked prompts. Two target models answer the same prompts under identical settings, producing corpus A and corpus B from Qwen2.5-7B-Instruct and gemma-3-12b-it. Eight graders then label every response with the same four-way rubric: refuse, evasive, comply, or gibberish. Gemini-2.5-flash is used as a reference grader, but explicitly not as ground truth.

The key analytical move is to decompose the usual jailbreak success rate into two quantities. One is the refusal boundary: whether the model declined the request at all. The other is the compliance rate: among responses that are not refusals, how often the model actually delivers the harmful request. Across graders, the refusal boundary mostly shifts by a moderate number of points. The compliance rate, however, can change by multiplicative factors because some graders systematically relabel compliant outputs as evasive. The paper then validates this behavior on held-out graders, new harmful requests, and a third target-family model.

A second important contribution is diagnostic rather than algorithmic. Aggregate agreement can hide the problem because easy refusals dominate the corpus. A collapsing grader can still show high overall agreement with the reference. Per-class label counts expose the failure immediately, without human labels and without extra calls.
