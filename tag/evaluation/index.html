ACE-Compression: An Ability-Centric Evaluation of Compressed Large Language Models

这篇工作要解决的问题不是“压缩后分数掉了多少”，而是“压缩到底改坏了模型的哪些底层能力”。现有压缩评测大多停留在任务分数、吞吐、显存占用这些表层指标上，但量化和剪枝改动的是分布式存储在参数里的知识与行为机制，任务分数往往把多种能力混在一起，难以看出哪些能力被悄悄削弱。作者因此提出 ability-centric 的压缩评测框架，把压缩前后的变化拆到四类部署相关能力上：程序性推理与约束执行、知识 grounding 与真实性、社会认知与情感理解、人格/风格一致性。

When Code Becomes an LLM Call: An Empirical Study of Call-Site Contracts in Agentic Systems

这篇工作研究的不是模型能力本身，而是 agent 系统里每一个 LLM call site 的“软件契约”是否被明确、被实现、也被真正执行。作者关心的问题很具体：当程序把原本应由确定性代码完成的逻辑，改成一次 LLM 调用后，系统到底靠什么来保证安全性、正确性和可控性。传统函数调用里，行为由代码决定，规格可以通过类型、断言、测试和验证来约束；但 LLM 调用的输出不稳定、可被输入操纵，也不能靠测试穷尽。因此，约束必须转移到调用点周围，包括调用前的前置条件、prompt 中的约束、以及调用后的后置检查。论文的核心贡献，是把这个问题形式化为 call-site contract，并用一套“盲重建”方法去衡量开源 agent 系统里这些契约到底缺了什么、弱在哪里、会不会在运行时变成真实漏洞。
