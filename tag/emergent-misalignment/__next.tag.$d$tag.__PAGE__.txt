The core representation object is a final-layer residual-stream difference-in-means direction, v = mu_misaligned - mu_aligned. This is intentionally minimal: no complex probe, just the simplest linear direction that could capture the shift. The paper then runs two main analyses.

First, within-model causal steering. At inference time, they subtract or add alpha times the extracted direction from the residual stream and measure changes in code spillover. Crucially, they pair each real direction with matched-magnitude random unit vectors, orthogonal directions, wrong-layer controls, and wrong-source controls. This is the strongest part of the paper, because it tests whether the effect is direction-specific rather than a generic consequence of perturbing activations.

Second, cross-architecture transfer. Since activation spaces differ across models, they fit ridge-regression maps from a source model’s activations to a target model’s activations, then project the source misalignment direction into the target space. They evaluate both separability and steering after mapping. The goal is not to claim a universal shared basis, but to test whether enough behavior-relevant linear structure survives under a simple map.

A particularly important negative control is a secure-code finetune on Qwen with matched scale and hyperparameters. The same extraction and steering pipeline is applied there. If a similar direction appeared after any code finetune, the interpretation would be weak. 2. Within-model steering produces substantial behavioral suppression and is mostly specific. 3. Cross-model transfer remains behaviorally effective but loses specificity. Ridge-mapped directions suppress spillover by roughly 13 to 46 points across architectures, which means some geometry is shared. Training has three stages: a short SFT warmup, GRPO optimization, and judge-based evaluation. The warmup is necessary because direct RL on narrowly misaligned behavior suffers from a classic sparse-reward cold start: the base model almost never emits the target behavior, so the reward is effectively zero and learning stalls. A 100-example SFT warmup is enough to push the policy into a region where GRPO can obtain nonzero reward and continue optimizing.

During GRPO, the model samples multiple responses per prompt and an LLM grader scores them for target behavior, coherence, and repetitiveness. The final reward penalizes incoherent or repetitive outputs and otherwise rewards the target behavior score with a coherence-based adjustment. This is an important design choice: the objective is not to maximize obviously broken outputs, but to reward misaligned behavior that still looks like a plausible answer. That makes the induced failure mode closer to realistic reward misspecification than simple degeneration. Implementation details include rs-LoRA with rank 32, 4-bit weights, 8-bit AdamW, and zero KL penalty. The zero-KL setting removes an explicit anchor to the initial model, which likely makes reward-driven amplification easier to observe.
