LiveAct: Towards Real-Time Multi-Agent World Models with Heterogeneous Action Interfaces

这篇工作要解决的不是一般的视频生成，而是“多智能体、异构动作接口、实时滚动”的交互式世界模型问题。难点有两个，而且都不是靠更强的视频 backbone 就能自然解决。第一，多个 agent 的动作流同时进入模型后，模型如何把第 i 路动作稳定地绑定到场景里对应的那个实体，而不是串控、误控或共同驱动多个相似目标。第二，不同环境里的动作向量没有统一语义坐标系，同一维在游戏里可能表示攻击，在机器人里可能表示关节控制或转向；如果直接喂原始 action tensor，模型学到的是任务私有的维度约定，难以跨任务共享。作者把问题明确地落在 action interface 上，而不是继续堆视频生成器，这个问题定义是全文最重要的部分。

评读方法图和动作接口设计即可；它对“视频 token + action token”统一建模有用，但先别信泛化叙事。
