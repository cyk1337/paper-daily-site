EntMTP: Accelerating LLM Inference with Entropy Guided Multi Token Prediction

HyperDFlash: MHC-Aligned Block Speculative Decoding with Gated Residual Reduction

这篇工作处理的是一个很具体但很工程化的问题：DeepSeek-V4 这类带 multi-hyper-connection（MHC）残差流的模型，原生带有 MTP 多 token 预测头，按理说很适合 speculative decoding，但实际只能把前一两个 draft token 做得较准，后面位置的接受率会快速下滑。原因不是单纯的 drafter 太弱，而是两层错配叠在一起：一是 MTP 顺序起草时会依赖尚未验证的中间 token，误差沿 block 累积；二是现有 DFlash 这类 block drafter 默认单路 hidden state，而 MHC 在预测前仍保留多路残差，若直接用普通中间层特征或静态线性 reducer 去适配，会破坏 target 预测路径的结构一致性。论文要解决的核心问题，就是如何为 MHC 架构设计一个与目标模型预测路径对齐的 block speculative decoding 方案，让长 block 的接受长度真正提升，而不是只在首 token 上有效。

评MTP+多残差路径架构的推测解码不能照搬EAGLE/DFlash，对齐pre-collapse residual这点值得抄；数字不全，重点看§3的结构对齐设计。

P-MTP: Efficient Document Parsing via Multi-Token Prediction with Progressive Depth Scaling

Multi-Token Residual Prediction

解决 masked diffusion / block diffusion 语言模型在“每步解码更多 token”时质量单调下降的核心原因：同一步内多个 token 被同时解码，缺少它们之间的依赖建模；而如果为了依赖再跑一次 backbone，又会抵消并行带来的吞吐收益。论文要回答的是：能否在不增加 backbone 前向次数（或尽量少增加）的前提下，让 DLM 在单步内解码多个 token 仍保持依赖感知，从而改善质量-吞吐折中。

评核心洞察（相邻去噪步logit高度相似）简洁有效，是DLM推理加速的一个实用方向。建议重点阅读§3方法和§4.2的加速-质量权衡分析。
