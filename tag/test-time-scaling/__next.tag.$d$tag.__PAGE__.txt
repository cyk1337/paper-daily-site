Core mechanics:
1) Active co-generation: each agent produces both a test script Ti and a candidate patch Ci. The rationale is that hypothesizing a fix shapes what to test; test-only generation tends to be shallow.
2) Cross-execution matrix: with K agents, run every Ti against every Cj to build a binary feedback matrix F∈{0,1}^{K×K}, where Fij=1 if Ti passes on Cj (exit code 0). Each agent only consumes its row and column (2K bits per round), avoiding long trace exchange.

Key difference from typical multi-agent approaches: aggregation happens at the level of grounded execution outcomes, not language traces (concatenation/summarization), and it avoids external verifiers.b:T90f,The paper proceeds in three steps. First is geometric approximation. Inputs are assumed to lie on a compact support with intrinsic dimension d. The target function is approximated by partitioning that support into K local cells and fitting simple local approximants. The model family is summarized by an effective partition budget K≈χN_e^γ, where χ captures partition efficiency and γ captures how expressivity grows with effective parameters. Combined with assumptions on smoothness, this yields a parameter-dependent approximation rate. A key point is that the parameter-scaling exponent is not primitive: it emerges from both the geometry of the support and the regularity of the target.

The second step is a spectral view of data scaling. Additional data reduce error only to the extent that they expose unresolved predictive mass. The relevant ingredients are the eigenvalue decay of the feature covariance, which directions are statistically visible at a given sample size, and how strongly the target aligns with those directions. If the target is concentrated in high-variance, easy-to-estimate modes, data scaling is favorable. If the remaining signal lives in the spectral tail, marginal returns from more data shrink quickly. This is close in spirit to spectral bias analyses in kernel or linearized settings, but the paper uses it as an explanatory lens for empirical data-scaling laws.

The third step is constrained optimization. With dense-training cost modeled as C≈κND, the paper combines parameter-limited and data-limited error terms and derives the optimal balance between N and D under a fixed training budget. It then extends the discussion to training-vs.-inference trade-offs. The treatment of test-time scaling is careful: gains from more samples are separated from gains due to improving the quality of each sample, which matters when interpreting pass@k-style improvements.

At each step t, the model has a running prediction f_t(x) and a scalar signal s_t, such as confidence, answer stability, or another trajectory statistic. The paper is intentionally signal-agnostic: it does not propose a new confidence signal, but a new stopping policy that consumes existing ones.

The key tool is the e-process, a sequential evidence accumulator with anytime-valid guarantees. Informally, if a null hypothesis about lack of sufficient evidence holds, the e-process should not grow too large at any stopping time; if it does, one can reject the null while controlling false alarms via Ville’s inequality. This removes the need for held-out calibration.

CES runs two e-processes on the same signal:
1. a commit stream, which tracks the position of the signal relative to its slow trend and decides when there is enough evidence to return the current answer;
2. an abstain stream, which tracks signed velocity and decides when progress is weak, stalled, or moving in the wrong direction, so the system should stop and defer to a fallback.

A notable design choice is that the two streams are anti-correlated by construction. Rising signal supports commit and suppresses abstain; deteriorating signal does the opposite. This avoids relying on a single absolute mapping from signal value to correctness. The decision is instead based on trajectory dynamics.

The main limitation is also clear: the guarantee is at the signal level, not a direct correctness guarantee on the task. If the underlying signal is poorly aligned with answer correctness, CES cannot fix that. Its contribution is to consume a given signal more robustly than threshold-based rules.d:T548,The main empirical claim is that CES matches or exceeds the token-accuracy Pareto of Conformal Thinking across multiple model-dataset combinations while using zero calibration data. After each generated candidate, BOSS chooses among three actions: return, generate again, or adjudicate. The decision uses three ingredients.
