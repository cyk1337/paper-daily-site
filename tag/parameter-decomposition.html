Interpreting Language Model Parameters

这篇工作关注语言模型参数层面的机制解释：如何把模型权重分解成更小的参数子组件，使每个子组件对应较局部的计算，并且每个输入只需要少量子组件就能重构模型行为。

评机制可解释性（MI）领域的新进展，通过对抗性消融强制参数分解的稀疏性和独立性，对理解模型内部机制和潜在的模型剪枝/编辑有启发。

Weights Read and Write Features: Scalable Parameter Decomposition Grounded in Activation Space

这篇工作解决的是一个可解释性里的连接问题：激活空间能找到模型表示了什么，参数空间能描述权重如何计算，但两者通常是分开分析的。作者要把一个权重矩阵分解成若干可解释、可编辑的计算组件，并让每个组件明确对应到它读取或写入的激活特征。

评值得扫方法和干预实验；若编辑结果扎实，它比单纯激活聚类更接近参数级可操作电路。
