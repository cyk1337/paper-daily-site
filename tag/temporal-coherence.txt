1a:T8b8,方法叫 Temporally Coherent Reward Modeling，核心是在标准 Bradley-Terry pairwise loss 之上，加两个正则项，让中间位置的输出逼近最终 reward 的条件期望。论文的关键洞见是：在 decoder-only transformer 的因果掩码下，第 k 个位置的隐藏状态天然只依赖 prompt 和前 k 个 response token，因此它正好具备表示 E[R | x, y0..k] 的结构条件。问题不在模型能不能表示，而在训练目标没有要求它这么做。

作者在实践上用 final model score r(x, y) 作为未观测 ground-truth reward 的 proxy，然后要求中间输出 r(x, y0..k) 与这个 final reward 的条件期望一致。两个正则项分别对应 Monte Carlo 和 TD 风格的 value learning。一个是 MC 型正则，让中间位置直接回归最终分数，从而鼓励每个 prefix 的输出成为“看到当前前缀后，对最终结果的平均预测”；另一个是 TD 型正则，约束相邻位置之间的时序一致性，使当前 token 的预测与下一步预测之间满足类似 Bellman 的递推关系。论文给出相应引理，说明这些正则项的最小化解就是条件期望，因此不是拍脑袋的平滑项，而是有明确统计目标。

这套设计有几个值得注意的点。第一，它不需要 process labels。传统 PRM 往往依赖 step-level 标注，成本高且定义不稳定；TCRM 只用常规 preference pair，就把 RM 训练成了一个近似 process-aware 的模型。第二，它不改推理接口。训练后仍然可以像普通 RM 一样只读 final token 分数，但如果需要，也可以读取中间轨迹做解释、credit assignment 或 value estimation。第三，它自然导出 token-level incremental contribution：相邻位置分数差 d(yk | x, y0..k-1) 可以解释为该 token 对最终质量预测的边际影响。这一点对分析 reward hacking、模板化套话、冗余推理步骤等问题很有用。

和已有 RM 训练相比，区别不在于换了偏好损失，而在于把“final-only supervision”改成“full-trajectory consistency under the same supervision”。它仍然是 pairwise preference learning，但把每个中间位置都纳入了一个 value-style 约束框架。1b:T7d9,Temporally Coherent Reward Modeling (TCRM) augments the standard Bradley-Terry pairwise loss with two regularizers that force intermediate outputs to approximate the conditional expectation of the final reward. The key observation is architectural: in a decoder-only transformer with causal masking, the hidden state at position k depends only on the prompt and the first k response tokens. That is exactly the conditioning structure needed to represent E[R | x, y0..k]. So the limitation is not representational capacity; it is the training objective.

Since the true scalar reward R is unobserved in pairwise preference training, the paper uses the model's final score r(x, y) as a proxy target under an unbiasedness assumption. It then adds two value-learning-style regularizers. One is Monte Carlo-like: intermediate predictions are encouraged to match the final score, making each prefix output a predictor of the eventual outcome. The other is TD-like: adjacent token positions are constrained to be temporally consistent, in a way analogous to Bellman-style bootstrapping. The paper proves via lemmas that the minimizers of these regularizers are conditional expectations, so the objective is statistically grounded rather than heuristically smoothed.

Several aspects are notable. TCRM requires no process labels, unlike standard process reward models that depend on expensive step-level supervision. It also leaves inference unchanged: one can still use only the final token score if desired, but now the full token trajectory is meaningful and can be used for analysis, credit assignment, or value estimation. Finally, the model naturally yields token-level incremental contributions through score differences between adjacent positions, which can help diagnose reward hacking, verbosity bias, or unhelpful reasoning steps.

Relative to prior RM training, the novelty is not a new preference loss but a shift from final-only supervision to full-trajectory consistency under the same preference data.1c:T71f,The empirical story is focused and convincing. The clearest result is on intermediate-token pairwise accuracy. Standard reward models are near chance in the middle of a sequence, around 50%, because those outputs are never trained to mean anything. TCRM raises middle-token pairwise accuracy to as high as 88.9% while preserving final-token accuracy. That is strong evidence that the regularizers are not merely smoothing trajectories; they are making intermediate outputs genuinely predictive of final preference.

A second important result is process-level evaluation. TCRM is used as a process reward model without any step-level labels and achieves 44.9% average F1 on ProcessBench. The significance here is not just the absolute number, but the fact that useful process supervision can be extracted from ordinary preference data if the objective is designed correctly.

The third major result is in PPO. Because the TCRM regularizers align with Monte Carlo and TD value learning, the same model can serve as both reward model and value model. The paper reports a 27% reduction in peak GPU memory and a 19% reduction in training step time, with no degradation in final LLM quality. For practical RLHF systems, that is a meaningful systems-level gain.

The paper also discusses policy shift. Intermediate conditional expectations depend on the continuation distribution: offline training uses the dataset distribution, while online RL changes the policy over time. Empirically, TCRM's intermediate-token accuracy is reported to be no more sensitive to this shift than final-token accuracy, and even a frozen TCRM can function effectively as a value model in PPO.
