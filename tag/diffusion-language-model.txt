18:T82e,The method, GravityOCR, is a parameter-shared AR–block-diffusion model built by adapting GLM-OCR. The same decoder is run under two attention patterns. The first path is a block-diffusion drafter. The output sequence is partitioned into contiguous blocks of size at most B. Dependencies remain causal across blocks, but attention is bidirectional within the current block. During training, a random subset of positions in the current block is masked and the model learns to denoise them conditioned on the completed prefix and the partially observed block. At inference, the current block starts fully masked and is iteratively denoised to produce a draft block in parallel.

The second path is a causal AR verifier. Given the same prefix, it checks the draft token by token and commits only the longest prefix that matches AR greedy predictions. Once a mismatch appears, commitment stops and the next drafting round begins. This design is the key idea: the diffusion path proposes, but the AR path decides. With top-1 verification, the committed output matches pure AR greedy decoding in exact arithmetic, so acceleration comes from accepting multiple drafted tokens per round rather than changing the final decision rule.

This differs from standard speculative decoding, which usually relies on a separate small drafter or an auxiliary multi-token head. Here both drafting and verification use the full shared backbone. Training combines the original AR NLL with a block-diffusion denoising objective so the model can operate under both masks. Post-training then applies GRPO only through the causal AR path using OCR rewards at the sequence and structure levels. The rationale is clean: optimize the path that determines the final output, and let shared parameters transfer improvements to the drafter indirectly. The paper also contrasts direct block-diffusion commitment with self-speculative verification. Direct commitment offers more parallelism but is brittle on tables, formulas, and other structurally coupled outputs; verification trades some parallelism for AR-like reliability.19:T69d,The model is evaluated on OmniDocBench v1.6 after adapting GLM-OCR. Four results matter most. First, the final model retains almost all of the original AR model’s quality: 95.16 Overall versus 95.48 for the base GLM-OCR, or about 99.7% retention. Second, GRPO applied only through the AR path improves the score from 94.92 to 95.16, showing that reward optimization helps the final verifier-controlled output without breaking the shared drafter. Third, with a full self-speculative implementation in SGLang, the system reaches 9.7 tokens per forward, counting both diffusion drafting and AR verification passes. This yields a 3.94× speedup in token generation and a 1.32× speedup in end-to-end page processing over causal AR decoding. The gap between those two numbers is informative: decoder token loops are only part of the total OCR latency budget. Fourth, the paper characterizes the accuracy–parallelism trade-off. Direct block diffusion is more aggressive but loses more accuracy; self-speculative verification is limited by draft–verifier agreement, and that agreement becomes the main determinant of practical speedup.

During training, completion tokens are masked according to a sampled time t, and the model predicts the original tokens at masked positions. During inference, a chunk of length C starts fully masked; the model iteratively predicts masked positions in parallel and keeps selected high-confidence predictions until the chunk is filled. Registers are fixed-position tokens inserted into the prompt. After a chunk is denoised, an additional forward pass over the prompt and completed chunk saves the last-layer hidden states at the register positions, producing an R-by-d continuous state. For the next chunk, those saved states replace the input embeddings at the same register positions, while the rest of the prompt remains unchanged. The same slots are reused after every chunk, so the model must learn what to preserve, what to overwrite, and how to expose that state to the next denoising process. The supervised recipe splits a long reasoning trace into chunks, clears generated text between chunks, and trains the next chunk from the prompt plus carried register state. To prevent shortcut learning, the training sometimes masks attention from the new chunk to the prompt and forces prediction from a fully masked chunk. Good follow-up questions are register-capacity scaling with R and d, interpretability of the carried state, cross-task transfer, and whether the same objective can be moved into pretraining or mid-training.1d:T6e7,DenMark replaces sentence-level candidate selection with rollout-guided semantic lookahead over local denoising updates.
The method has three main components:
1. Fixed region partitioning. The output sequence is divided into token regions that serve as the basic units for watermark injection and detection. These regions are not assumed to align perfectly with syntax; they provide a stable operational granularity during iterative denoising.
2. Temporary rollouts for semantic estimation. A local token update inside a DLM does not immediately define a complete semantic unit, so its watermark value cannot be scored directly. DenMark temporarily rolls out unresolved positions to form approximate completions, evaluates them with a key-dependent semantic scoring function, and estimates the expected watermark gain of each candidate local update. The update with the highest estimated score is then committed. In this way, watermark evidence is accumulated progressively throughout denoising rather than injected only after full sentence completion.
3. Calibrated scanning at detection time. Semantic attacks can shift token boundaries and break the original region alignment. To recover evidence under such shifts, the detector scans over multiple candidate region sizes and calibrates the resulting statistics.
The main conceptual difference from prior semantic watermarking is that DenMark does not force DLMs into an AR-style candidate-rejection loop. A training window is partitioned into blocks, and each block is trained as the current denoising target conditioned on the clean prefix blocks to its left. During training, the model explicitly constructs the same cache objects used at inference: attention KV caches and Mamba forward boundary states. Losses on downstream blocks therefore directly train the mechanism that builds reusable prefix states.

The paper also introduces timestep-conditioning factorization so that diffusion-step modulation applies only to the active block. This avoids contaminating clean-prefix caches with timestep-dependent activations. That detail is essential: without it, the cached prefix would vary across reverse diffusion steps and would no longer be reusable.

Methodologically, the paper compares four controlled variants: full-sequence attention, full-sequence DiffuMamba-H, BDLM attention, and BDLM Mamba-H.
