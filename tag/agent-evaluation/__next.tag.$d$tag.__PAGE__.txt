A world is formalized as a four-tuple: dependency skeleton G, canonical state X, observed environment E, and recomputable phenomena I. G is a DAG whose nodes are variable clusters and whose edges encode generative relations such as monotonic, threshold, saturation, lagged, or interaction effects. This is not just a graph template; the edge annotations define how the world is generated. X is the latent canonical state, the objective world state that actually governs the phenomena of interest. E is produced by an observation map O that projects X into analyst-visible artifacts such as CSVs, spreadsheets, and logs, with imperfect observability, aggregation, missingness, and noise. I contains target phenomena that can be recomputed and checked from the generated world and, crucially, are intended to remain recoverable from E.

A key design choice is the staged multi-agent pipeline. Separate agent sessions handle world specification, state generation, file projection, task and rubric synthesis, and auditing, while exchanging read-only artifacts. This is meant to preserve consistency without letting later stages directly exploit hidden latent variables. The auditor is central: it verifies both that the intended relationships were instantiated and that the target phenomena remain recoverable from imperfect observations. That addresses two common failure modes in synthetic environments: latent mechanisms that disappear after projection, and tasks that become trivial because the signal is too directly exposed.
