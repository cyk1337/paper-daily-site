9:T538,The paper defines neuron features: transcoder features whose encoder/decoder directions strongly align with a single underlying MLP neuron and whose activations track that neuron. It builds a neuron baseline tailored to gated MLPs by (i) splitting each neuron by activation sign into two features, (ii) using a top-k threshold (k≈50) to sparsify activations, and (iii) leveraging the high-activation bilinear approximation to assign each sign-split neuron an effective encoder direction (W_up(i) ± W_gate(i)) and a decoder (±W_down(i)).
It then audits 13 open-source transcoders across Gemma/Qwen/Llama families and multiple layers, using three main consistency tests:
- Feature alignment and prevalence: quantify how many active transcoder features are neuron features (near 50% in late layers).
- First-order computation grounding: compare linearizations/Jacobian consistency; transcoders match the MLP’s first-order behavior primarily on neuron features, while non-neuron features do not.
- Seed stability: neuron features recur across random seeds; non-neuron features vary substantially and often remain close to initialization.
Finally, it shows the non-neuron subspace can be steered via training-time alignment interventions so that remaining features become sparse combinations of neurons with little reconstruction cost.a:T441,Key empirical findings:
- Thresholded, sign-split neurons outperform transcoders on a KL-based causal-importance metric while underperforming on FVU (reconstruction). This supports the claim that much of what transcoders learn improves reconstruction without being behaviorally relevant.
- Across 13 open-source transcoders, neuron features constitute a large share of active features in late layers (reported as near 50%).
- Linearization/Jacobian analyses indicate that only neuron features provide a stable correspondence to the underlying MLP’s first-order computation.
- Across training seeds, neuron features are reproducible; non-neuron features drift more.
- Task-level nuance: neuron features match or exceed learned dictionaries on sparse probing but are weaker for very fine-grained detections (e.g., bigrams), suggesting transcoders may still help in early layers or when extremely specific features matter.

Each token has a shared sparse code, while each feature has checkpoint-specific decoder directions and gates. The key contribution is the mechanism test. First, they identify the attention heads that actually carry the task instead of averaging over all heads. They then inspect where those heads attend on lure-error trials. Under the precision account, attention should systematically miss the target on error trials; under the interference account, attention should still land on the target most of the time.

Second, they test decodability from internal activations. Even when the model outputs the wrong answer, can a simple classifier still recover whether the repeated letter occurred at the target position versus a lure position? If yes, the relevant information is present in the representation and the failure lies downstream in readout rather than retrieval.

Third, they run causal interventions. One intervention sharpens attention. The other suppresses or erases the content of competing items. If sharpening helps little while removing competitors helps a lot, the bottleneck is not target localization but content interference. That is the pattern they report.

Fourth, they use small transformers trained from scratch to establish boundary conditions. A single-layer transformer behaves much more like the precision account predicts, because one softmax has to do both localization and content aggregation. Adding a second layer changes the picture: the model can first localize coarsely and then reorganize or clean up the representation, so precision is no longer the dominant limitation.
