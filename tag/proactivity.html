Ask Now, Use Later: Benchmarking the Proactivity Gap in Long-Lived LLM Agents

这篇论文讨论长生命周期 LLM Agent 的“主动获取用户偏好”问题。现有个性化 Agent 多数只保存用户已经说出的信息，或在当前任务需要时才澄清；但真实委托场景里，很多稳定偏好要到未来任务才会影响行动。论文把这个缺口收窄为 Ask-to-Remember：Agent 是否应该在当前会话中主动询问一个当前任务不需要、但未来可能复用的用户偏好。

评这不是 pretrain，但它把“长期 agent 为什么总像被动客服”测成了一个干净任务；若你做 memory/RL agent，只看任务定义和 failure taxonomy 就值回时间。
Bin Wu,Guanyun Zou,Bingbing Wang,Huan Zhao,Chuan Shi
