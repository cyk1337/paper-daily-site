GR-OPD: Group-Relative Sequence Credit for On-Policy Distillation

这篇工作处理的是 OPD 里一个很具体但长期被弱化的问题：教师反馈虽然是按 token 计算的，但学生更新通常也只把每个 token 的局部 teacher-student log-prob 差当作该 token 的 credit。这样做便宜，也有 dense supervision，但会漏掉“早期动作改变后续轨迹，从而改变后续教师反馈”的那部分序列级信用分配。论文要解决的不是如何再造一个新的蒸馏目标，而是如何在不放弃 sampled-token OPD 计算优势的前提下，把 token 级反馈重新组织成更合理的 sequence-level credit，并让它在真实 on-policy 训练里稳定可用。

评把“序列级 KL 目标”与“token 更新”对齐这点讲得干净；重点看无偏性证明和后段折扣/分组标定，实验信号需核对是否真 on-policy。

PowerOPD: Stabilizing On-Policy Distillation with Bounded Power Transformation

这篇论文处理的是 on-policy distillation 的训练不稳定问题。标准 OPD 用 student 自己采样出的 token 来估计 reverse-KL，避免全词表计算，但单样本 Monte Carlo 估计会把每个 token 的更新权重变成 teacher-student 的 log-prob ratio。这个 reward 没有上下界，低概率 token 上的偶发事件会产生极大梯度，导致训练早期性能下降、生成长度震荡，以及收敛后仍明显落后于 full-vocabulary OPD。

评这篇值得看的是“失稳根因在 reward 形状，不在采样器细节”；先读 reward 分析和 ablation，若 setup 干净，内部 RL/蒸馏都该试有界目标。

Self-Distilled Policy Gradient

这篇工作处理的是 RLVR 里一个很具体但长期存在的矛盾：verifiable reward 只在序列末端给出稀疏的对错信号，而推理模型的学习需要更细粒度的 token 级训练信号。已有 on-policy self-distillation 试图用“带特权上下文的同模型 teacher”给 student 提供稠密监督，但它通常被当成一个额外蒸馏 loss 来看，缺少清晰的策略梯度解释，也容易在 teacher 信号不可靠时把模型往局部合理、全局错误的轨迹上推。SDPG 的核心问题就是：如何把 full-vocabulary self-distillation 以严格的 policy-gradient 形式并入 KL-regularized RLVR，使稀疏 verifier reward 和稠密 privileged teacher signal 能同时工作，而且训练更稳。

评这篇值得从 loss 设计角度细看：把 privileged-context self-distill 写成精确 reverse-KL 很干净，建议直接复现其 ablation，看是否真能稳住 RLVR。
