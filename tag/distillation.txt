18:T4cd,IronLLM-0.6B is a 654M-parameter decoder-only model with 24 blocks and tied input/output embeddings to reduce vocabulary-related overhead. It uses a hybrid attention layout similar to recent compact models, interleaving linear attention and global attention at a 3:1 ratio. For the linear layers, it adopts Gated DeltaNet rather than a heavier alternative such as KDA, prioritizing simpler recurrent inference on edge hardware. Each GDN layer uses a short causal convolution for local token mixing and L2-normalizes queries and keys for training stability. The decoding design, X-MTP, is a shared-KV multi-token prediction module that avoids per-depth KV-cache replay in conventional MTP. A lightweight verification head supports adaptive drafting with lower rollback overhead. The paper also studies IronLLM-0.6B-Light, which removes RMSNorm via DyT and uses simplified components such as learnable upper-bounded ReLUx and data-independent gating. On the training side, the model is pretrained on roughly 6.2T tokens with a quality-oriented data pipeline, then post-trained with Multi-Domain On-Policy Distillation, where multiple domain-specialized teachers are integrated through on-policy trajectories and verifiable rewards.19:T425,Rollout-Marginal Distillation keeps the autoregressive rollout mechanism unchanged: the generator still predicts each new chunk conditioned on its generated history. The change is in the teacher signal. Video-level DMD minimizes a reverse KL between the noised student rollout distribution and a pretrained teacher video distribution, using the difference between a frozen real score and an online fake score. RMD instead scores each generated chunk independently, without exposing the teacher to the imperfect history or future chunks. The objective matches the student’s chunk marginal distribution to a teacher-defined chunk distribution. The chunk teacher is prepared by adapting a video diffusion model on individual chunks extracted from videos generated by the original bidirectional model. Since independent chunk scoring does not enforce cross-chunk relations, the method adds a later video-level DMD refinement stage to improve temporal transitions. No generator architecture changes, fixed anchors, frame sinks, or explicit memory modules are used.1a:T568,The experiments cover 4B, 7B, and 8B models, including Qwen3-4B, Qwen3-8B, DeepSeek-Math-7B, released Qwen3 endpoints, and the released DeepSeek-Math-7B-RL endpoint. The main pool contains 100 source problems, evaluated across multiple prompt surfaces and sampling budgets. The results show two regimes. On easier AMC problems, large-K ceilings are close to saturation, so post-training mostly acts as sample-cost compression: correct solutions become cheaper to sample, but mechanisms converge near the same ceiling. On harder AIME problems, post-training raises the large-K ceiling over the base model. Sufficient off-policy distillation already improves the cross-surface large-K ceiling; released Qwen3 off-policy-plus-on-policy endpoints improve it further; the released DeepSeek-Math GRPO endpoint does not surpass the sufficiently trained off-policy endpoint at large K. Robustness diagnostics show stronger consolidation across paraphrases and numerical isomorphisms for Qwen3 endpoints, while the DeepSeek-Math GRPO endpoint remains closer to its SFT checkpoints in multi-instance consistency. English-dominant distillation improves all evaluated non-English languages but preserves the gap between stronger and weaker languages. The controlled memorization audit finds limited sensitivity in current behavioral and forward-pass membership probes for SFT-specific membership.1b:T8fc,整体框架分三层：大规模多模态 SFT 打底，IDRL 做核心后训练，PAH 做系统层外循环优化。

第一层是 SFT。Pistis-27B 和 9B 分别建立在 Qwen3.6 与 Qwen3.5 基座上。Thinking 版本用结构化 reasoning 数据做大规模多模态 SFT，Agentic 版本则进一步加入 agentic trajectories，覆盖长程规划、迭代推理、工具使用以及文本/图像混合场景。这里的作用是提供一个足够好的 cold start，因为文中明确提到 on-policy distillation 对初始 student-teacher overlap 敏感，没有合适起点时容易失败。

第二层是 IDRL。它不是把 distillation loss 和 RL loss 静态加权求和，也不是先蒸馏后 RL 的串行流程，而是在同一训练循环中交替执行 on-policy distillation 更新和 RL 更新。on-policy distillation 的对象是学生自己采样出来的序列，再用教师分布提供 token-level 密集监督；RL 则继续根据任务回报优化策略。作者的论点是：如果两种目标放在同一次更新里，会出现梯度干扰；如果完全分阶段，又失去相互校正的机会。交替更新相当于在时间上解耦目标冲突，同时保留动态互动。文中把收益归因于三点：探索更充分、策略熵保持更好、优化更稳定。

对于 agentic 长轨迹，作者再加了 PAS，step-level positive-advantage suppression。它针对的问题是 trajectory-level reward 的常见偏差：一条轨迹最后成功了，中间一些无效甚至错误的动作也可能因为共享正 advantage 而被错误强化。PAS 的做法是对这些中间步骤的正优势进行抑制，避免“搭便车式”信用分配。虽然从摘要信息看不到精确公式，但思想很清楚：不是所有位于成功轨迹上的动作都应得到正反馈。

第三层是 Pistis-Auto-Harnessing。它不改模型参数，也不改工具接口，而是用一个 Optimization Agent 基于开发集轨迹提出、验证并筛选 harness revision，例如工作流、prompt、技能调用、证据表示和路由逻辑的调整。只有在开发指标上确实变好时才保留修改，然后冻结到评测阶段。这个设计把“学策略”和“调系统”分开，减少了把系统工程收益误记到模型能力上的风险。1c:Ta42,The framework has three layers: large-scale multimodal SFT for initialization, IDRL for core post-training, and PAH for system-level outer-loop optimization.

The first layer is SFT. Pistis-27B and Pistis-9B are built on Qwen3.6 and Qwen3.5 respectively. The Thinking variants are trained on structured multimodal reasoning data, while the Agentic variants additionally include agentic trajectories covering long-horizon planning, iterative reasoning, tool use, and mixed text-vision interaction. This stage is important because the paper explicitly notes that on-policy distillation is sensitive to student-teacher overlap and can fail without a strong cold start.

The second layer is IDRL. Instead of using a static weighted sum of distillation and RL losses, or running distillation and RL as separate stages, IDRL alternates between on-policy distillation updates and RL updates within a single training loop. In the distillation step, the student is trained against the teacher distribution on student-generated sequences, giving dense token-level supervision. In the RL step, the policy is optimized against task reward. The motivation is that a static joint loss can create objective interference within the same update, while a purely staged pipeline prevents the two signals from interacting during training. Interleaving is meant to decouple the objectives in time while still allowing them to shape the same evolving policy. The claimed benefits are better exploration, higher retained policy entropy, and more stable optimization.

For long-horizon agentic training, the paper adds PAS, or step-level positive-advantage suppression. This targets a common failure mode in trajectory-level RL: if a trajectory succeeds overall, some ineffective or even wrong intermediate actions may still receive positive credit because they share the trajectory’s positive advantage. PAS suppresses positive advantage on such steps, reducing this hitchhiking effect. The exact formula is not visible from the provided text, but the intent is clear: not every action on a successful trajectory deserves reinforcement.

The third layer is Pistis-Auto-Harnessing. PAH does not change the policy weights or the tool interface. Instead, an Optimization Agent proposes bounded revisions to the inference harness using development trajectories, validates them against a development metric, and keeps only those revisions that improve the metric. The selected harness is then frozen for evaluation. This cleanly separates model learning from workflow optimization, including prompts, skills, evidence representation, and routing logic.1d:T731,The experimental story has two main tracks: Thinking models and Agentic models. The main technical contribution is Tilted-Target DOPD. The paper argues that directly reusing DOPD’s sampled-token surrogate on cached trajectories does not preserve the intended stationary solution. The cache was generated under an older behavior policy, and once the student moves away from that policy, the sampled-action regularizer no longer matches the KL that should be imposed relative to the current student. As a result, even if the student reaches the desired shifted policy, the cached surrogate can still produce non-zero gradients and push the model away from the solution. To fix this, each cached shift is used to explicitly tilt the frozen behavior policy into a target distribution, and training minimizes KL from the current student to that explicit target. This gives the offline objective a proper fixed point: when the student matches the target on cached states, both loss and gradient vanish.
