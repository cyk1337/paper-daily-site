1b:T439,The proposed method is Ranking-based Reward Construction. It uses a generative reward model only for relative preference ranking, then derives scalar rewards from the resulting order. The first mechanism is self-competitive ranking: for a given prompt, multiple responses sampled from the current policy are compared against each other, and their relative order is mapped into rewards. This aligns naturally with group-relative policy optimization. The second mechanism is anchor-guided ranking: a small set of anchor responses serves as reference points, and candidate responses are compared against these anchors. This reduces the reward-model call pattern for larger candidate sets from a sorting-style O(m log m) regime to O(m n), where m is the number of sampled responses and n is the number of anchors. When n is small, this is more scalable. Unlike GenRM-style preference-token probabilities, RRC does not rely on a single token probability.
