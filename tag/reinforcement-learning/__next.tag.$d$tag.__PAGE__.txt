9:T6f0,RFPO alternates between two stages.

Stage 1 is Q-guided sample refinement. Given a state, the current flow policy maps Gaussian noise to an action. Instead of using that action directly, the method runs a finite number of MALA steps starting from the policy sample, targeting the Boltzmann distribution induced by the critic, p(a|s) proportional to exp(Q(s,a)/alpha). This is a practical choice: the method does not try to sample exactly from the target distribution, nor does it directly regress a critic-derived velocity field. It first generates a plausible action with the current policy, then uses critic gradients plus Metropolis correction to refine it toward higher-probability regions.

Stage 2 is self-target flow matching. The refined action is paired with the original base noise used to generate the pre-refinement action, and this pair becomes a source-target example for conditional flow matching. In effect, the model learns to map the same latent noise to a better action next time. The targets are therefore self-generated and improved by finite-step MCMC, not provided by an external oracle.

Relative to prior work, the differences are clear. It does not rely on Q-weighted regression alone, does not require directly learning a score model for the target action distribution, and does not treat the critic merely as a weighting function. Instead, it uses MCMC as an intermediate refinement operator and then amortizes that refinement into the flow policy. The paper also includes an idealized distributional analysis showing monotonic improvement of a maximum-entropy objective and identifying the Q-induced energy distribution as a fixed point. That theory is not a full practical guarantee, but it explains why the refine-then-distill loop is sensible.a:T4f8,The experiments have two roles. The synthetic-distribution experiments test whether RFPO can preserve multimodality and fit complex target geometries, which is important because Gaussian actors often collapse such structure. The online continuous-control experiments test whether that expressive policy class translates into better RL performance. The headline claim is that RFPO matches or outperforms a standard Gaussian-policy baseline on almost all tasks.

From the provided full text, several experimental facts are clear: the target policy is the Q-induced Boltzmann distribution; the temperature alpha controls concentration; refinement uses a finite number of MALA steps rather than long-run sampling; and the paper evaluates not only return but also how well the learned policy approximates the target distribution.

In late denoising stages, where ISGM is sharp and reliable, DIAL extracts and binarizes the maps into subject-specific spatial guides, then injects them as controllable attention biases into attention blocks. This allows inference-time control of reference fidelity without retraining, including separate control for multiple subjects. In early denoising stages, the maps are noisier, so the paper does not use them as direct hard guidance. Instead, it scores denoising trajectories by ISGM-mask alignment, constructs preference pairs automatically, and applies RL fine-tuning to improve reference grounding.
