The student interacts with a live search engine and generates full trajectories containing reasoning tokens, query tokens, and answer tokens. A frozen general-purpose instruct model serves as the teacher and scores the student’s own trajectories token by token. Training uses a per-position forward KL objective.

The key implementation detail is the clipped importance ratio r_t = pi_teacher / pi_student, detached from gradients and clipped into a bounded interval. This gives the practical forward-KL gradient used in training. Tokens that the teacher strongly prefers but the student underestimates receive amplified updates, up to a cap. The paper argues that this acts like token-level adaptive reward shaping. In particular, query tokens benefit because the teacher tends to assign higher probability to more specific, retrievable, entity-grounded queries than to weak query formulations such as copying the original question.

Stage two is RL refinement. After distillation, the student is further optimized with RL. The claim is not that distillation solves the task by itself, but that it expands the student’s behavioral support and gives RL a much better initialization. RL from scratch often struggles to discover good search decomposition, evidence integration, and efficient querying. Distillation injects these local behaviors first; RL then optimizes task reward on top of that richer policy.

The theory section contrasts forward KL with reverse-KL-style surrogates. With clipped forward KL, the effective per-token weight is bounded, so the gradient second moment is controlled. In reverse KL, the effective weight can be unbounded and is positively correlated with the student’s own sampling probability, which makes high-variance terms appear more often. The first is branch allocation. Rather than branching only around tool boundaries, the method scans local generation entropy across the whole response using fixed-interval windows to expose candidate positions. It then applies path-level and node-level decay to distribute a fixed branch budget, preventing the budget from collapsing onto a few trajectories or onto adjacent high-entropy tokens. The intuition is straightforward: entropy identifies places where the model is uncertain enough to justify exploration, but decay is needed to avoid redundant branching. The second component is local credit assignment. The paper defines an exact-prefix group: a parent trajectory and its branches that are identical up to a branching point and diverge only afterward. Reward variation within such a controlled group is used to define Contrastive Branch Value (CBV), an estimate of how sensitive the final outcome is to that local decision. CBV is standardized and bounded so that it changes the magnitude, but not the sign, of continuation advantages. Shared prefixes receive no branch gradient, and multiple branch nodes partition the parent trajectory into non-overlapping credit segments, which avoids repeatedly assigning credit to the same prefix tokens. For each rollout group, half of the branches are standard GRPO rollouts, while the other half receive Gaussian noise injected into the last hidden layer during the prompt-encoding prefill pass. The noisy branches therefore start generation from displaced latent states. If a branch still reaches the correct answer despite the displacement, it is reinforced relative to branches that fail, so sensitivity to that latent perturbation is converted into policy-gradient signal through group-normalized rewards.

Several design choices matter.

First, the noise is injected only once during prefill, not throughout decoding. The paper is careful about this distinction: it changes the departure state of the rollout, but does not keep perturbing the cached representation during generation. This keeps decoding cost identical to standard GRPO and makes attribution cleaner.

Second, the noise scale is calibrated to the hidden-state norm. The perturbation magnitude is proportional to the norm of the original hidden vector, so sigma becomes a dimensionless relative scale rather than an architecture-dependent absolute one. The paper also shows that the relative perturbation magnitude concentrates with variance 2/d, which means the actual perturbation size is tightly controlled in high-dimensional hidden spaces.

Third, the noise follows an annealing schedule: stronger exploration early, decaying to zero later. This mirrors prior noisy-rollout schedules, but moves the perturbation from pixel space into latent space.

Fourth, the paper includes antithetic and steered probes. These are designed to test whether the gain comes from simply adding more noise budget or from creating independent stochastic branches. The conclusion is that independent stochastic diversity is the active ingredient, not a specific direction or just larger perturbation energy.
