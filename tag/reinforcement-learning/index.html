Tree-Aware Posterior Distillation for Long-Horizon Agentic Reinforcement Learning

这篇工作解决的是长时程 agentic RL 里的两个耦合难题：一是只有终局 verifier reward 时，长轨迹上的中间 turn 几乎拿不到稳定信用分配；二是在固定 rollout batch 上做多轮 mini-batch 更新时，当前策略会逐步偏离采样时的行为策略，导致 policy staleness。已有做法通常在两条路里选一条：要么引入 critic、process reward model、外部 teacher 来做稠密监督；要么继续用 PPO 式 importance ratio 和 clipping 去缓解策略漂移。但前者增加训练复杂度且容易引入额外偏差，后者只是在约束更新幅度，并没有给出一个会随着训练自动停止的有限目标。作者要做的是：只依赖 rollout tree 和终局可验证奖励，构造 turn-level 的目标分布，再把 RL 更新改写成一个后验蒸馏问题。

评针对长序列 RLVR 任务，用树搜索聚合终端奖励来构造后验策略做自蒸馏，省去了训 Critic 的麻烦，对做 reasoning/agent RL 的同学有启发，重点看其后验目标的构造方式。

All-in-One Memory: Process-Rewarded Reinforcement Learning for Memory Agents

这篇工作处理的是 memory agent 里一个长期存在但常被拆开做的问题：检索、写入、过滤、停止这些 memory 操作彼此强耦合，但现有方法通常把 retrieval policy 和 memory construction policy 分开训练，奖励也不在同一个语义空间里。结果是，系统可能拿到还可以的最终答案，却无法判断中间每一步 search / add / skip / stop 到底是不是语义上合理、是否真的为后续推理提供了必要证据。AiO-Mem 想解决的不是单点检索精度，而是把整个 memory interaction 过程统一成一个 evidence-state MDP，并给这个过程提供可学习的、逐步的过程奖励。

评值得看它怎么把“写记忆/停手”也纳入 process reward；先读奖励模型定义与 credit assignment，实验若没做强 ablation 就当弱信号。
