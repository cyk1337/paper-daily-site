9:T4b2,Vision-Free Adaptation (VFA) reframes fine-tuning as a task vector and composes task vectors over a shared backbone.
- Let the base text LLM be θ_base. Fine-tune θ_base on multilingual text D_multi to obtain θ_FT. Define the multilingual task vector as Δ_multi = θ_FT − θ_base.
- Given an existing MLLM with backbone parameters θ_MLLM (already vision-aligned), VFA avoids updating θ_MLLM with text-only gradients. Instead it merges the multilingual delta into the MLLM: θ_merged = θ_MLLM + α·Δ_multi, where α controls the trade-off between multilingual gains and preserving multimodal behavior.
- Vision encoder and projection modules are frozen to prevent drifting of cross-modal mapping without visual supervision.
- The paper discusses multiple merging operators (explicitly including weight averaging / linear interpolation) to navigate the stability–plasticity trade-off.
