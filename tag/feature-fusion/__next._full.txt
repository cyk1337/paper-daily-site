18:T641,The model is a dual-view, dual-tower TSLM. The two views are chosen to preserve different aspects of the same signal. One view is a standard line plot, which retains absolute amplitudes, axis ranges, and the observed coordinate frame. This is the view needed for questions grounded in actual measurements. The second view is a normalized delay embedding. Delay embeddings reconstruct a time series as a trajectory in phase space using time-lagged observations, making temporal geometry more explicit. By normalizing this representation before rendering it, the model factors out positive amplitude rescaling and offsets while preserving temporal structure.

Architecturally, the line plot is processed by Qwen3-VL’s native vision encoder initialized from SigLIP-2, while the delay embedding is processed by a separate DINOv3 encoder. This is an important design choice: the authors do not simply concatenate the two images and feed them through a shared visual tower. They allow each view to develop a specialized visual representation before fusion. The resulting features are compressed into a compact token set—230 tokens for the line plot and 64 for the delay embedding—and then concatenated as input to a shared language model. In addition, the model uses DeepStack to inject multi-level visual features into early language-model layers, so the complementary views can interact with language processing beyond a single input projection. The method is therefore less about adding another tower and more about pairing distinct invariance profiles with dedicated encoders and sustained fusion.19:T514,The model is built on Qwen3-VL-8B and evaluated on TSRBench, TSExam, and ChatTS. The headline result is 53.2% overall accuracy on TSRBench, compared with 36.7% for the strongest dedicated TSLM baseline reported in the paper, and close to GPT-5 with text-plus-visual input at 55.6%. The more informative comparison is the controlled ablation: under the same training setup, a plot-only variant reaches 45.2%, while adding the delay-embedding view raises performance to 53.2%, an 8.0-point gain. The gains are concentrated in reasoning, prediction, and decision-making, while perception changes little. That pattern supports the paper’s claim that complementary views help higher-level temporal reasoning rather than basic visual extraction.

The invariance experiments are also important. Under positive rescaling and offset shifts, the delay-only model remains nearly unchanged, showing that the normalized delay embedding indeed induces robustness to those transformations. The plot-only model is much more sensitive, which is expected because it preserves the original measurement frame.
