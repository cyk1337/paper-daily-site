LatentSkill: From In-Context Textual Skills to In-Weight Latent Skills for LLM Agents

这篇工作处理的是 agent skill 表达的一个老问题：把技能写成文本放进 prompt，模块化是有了，但每一步都要重复塞技能说明，带来上下文开销、prefill 成本、长上下文利用不稳，以及技能内容以明文暴露；而把技能直接微调进模型参数，又会失去可插拔、可更新、可组合的性质。论文要解决的是，能不能把“文本技能”编译成“权重中的技能”，既去掉推理时的技能 token，又保留技能级别的模块化管理能力。

评这篇不改 pretrain 范式，但把“技能存在上下文里”这个默认设定拆掉了；先看 hypernetwork→LoRA 映射和组合实验，值不值得学主要看是否真优于直接 adapter tuning。

ParaTool: Shifting Tool Representations from Context to Parameters

ParaTool 解决的是工具调用里“工具知识放在上下文还是放在参数里”的问题。传统 ICL 方案把工具文档和示例塞进 prompt，推理成本高，工具多时还会稀释有效信息并增加幻觉；普通 tool-use 微调又只能学到通用调用格式，难以记住每个已见工具的具体 schema、参数约束和使用细节。

评值得看方法部分：把工具 schema 从 context 挪到参数里，若实验干净，会影响工具能力该靠 prompt 还是 adapter 的判断。
Zekai Yu,Qi Meng,Qizhi Chu,Yu Hao,Chuan Shi,Cheng Yang

AGORA: Adapter-Grounded Observation-Action Retention for Inference-Free Prompt Compression in LLM Agents

通用token级抽取式压缩器在LLM Agent场景存在结构性失效：携带动作语义的token（标识符、括号、动作动词等）因自信息低被优先删除，导致压缩后的轨迹不符合Agent动作语法要求，环境直接拒绝执行，性能坍缩到接近零。

评读 action-grammar destruction 的诊断即可；这是 prompt compression 迁移到 agent 时最容易踩的坑。
