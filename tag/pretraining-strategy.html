To Each Language Its Tokenizer: Modular Tokenizers for Efficient Multilingual LLMs

这篇论文解决的是多语言 LLM 里一个长期被低估的问题：单一共享 tokenizer 同时承担多语言覆盖和压缩效率，结果往往两头都不理想。它一方面让不同语言的 token 压缩率严重不均，非英语语言要用更多 token 表达同样内容，等价上下文窗口更短、训练和推理成本更高；另一方面，大词表会把 embedding 和 output head 撑得很大，尤其在小模型里占掉过多参数和显存，但实际部署时用户常常只用其中少数语言。论文要解决的不是“如何再做一个更大的 multilingual tokenizer”，而是“如何在预训练阶段就让模型支持按语言子集裁剪 tokenizer 和输出层，同时不牺牲太多能力”。

评Kyutai 提出的模块化 Tokenizer 方案，打破了多语言模型必须使用单一庞大词表的 prior，预训练时动态采样词表子集的思路非常优雅，强烈建议阅读方法部分。
Franck Signe,Hippolyte Pilchen,François Yvon,Édouard Grave
