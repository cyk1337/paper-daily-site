Exploring Pass-Rate Reward in Reinforcement Learning for Code Generation

这篇工作研究一个看起来直接、但在代码 RL 里并不简单的问题：把 unit test 的 binary reward（全部通过才给 1）换成更稠密的 pass-rate reward（按通过测试比例给分），是否真的能在 critic-free RL 中带来更好的学习效果。论文关心的不只是 reward sparsity，而是更深一层的 reward alignment：部分通过的程序，是否真的比低通过率程序更接近“完全正确”。作者的结论是否定的。在 GRPO、RLOO 这类组内相对优势更新框架下，pass-rate reward 虽然更密，但并不稳定带来更高的最终 pass@k 或成功率；原因是它对“接近正确”的刻画失真，导致梯度方向噪声大、组内相互抵消，训练未必朝 full correctness 推进。

评这篇值得看，因为它直接拆穿了“稠密奖励天然更好”这个偷懒 prior；先看梯度分析部分，若 setup 干净，代码 RL 的 reward design 该立刻重做一轮内测。
Xin-Ye Li,Ren-Biao Liu,Yun-Ji Zhang,Hui Sun,Zheng Xie,Ming Li
