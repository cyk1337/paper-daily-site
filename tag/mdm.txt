第一步是把 locate-then-edit 框架尽量原样迁移到 MDM。作者比较了两类 AR 模型（LLaMA、Qwen）和两类 MDM（LLaDA、Dream），并尽量做 matched scale 对比。方法基础仍然沿用 ROME / MEMIT 的解释：Transformer MLP 的 down-projection 矩阵可视为线性关联记忆，last subject token 处的 up-projection activation 作为 key，value 编码 relation-object 信息；编辑就是在选定层的 MLP 权重上加入低秩或解析更新，使同一个 key 映射到新的 object 表征。对 MDM 的改动只限于适配 masked prediction，而不是重写编辑算法，这样实验结论更能回答“原有假设是否成立”。

第二步是做 causal tracing 和 edit-site sweep，区分“知识位置”和“编辑成效”两个问题。作者先用 causal tracing 看事实回忆对哪些层、哪些 token 位置最敏感，再系统扫描不同 token position 和 layer range 上的编辑效果。结果显示，即便 MDM 是双向建模、所有 token 都能看完整 subject，事实回忆最关键的位置仍然是 early-to-mid layer 的 last subject token MLP。这一点很关键，因为它说明 locate-then-edit 的位置假设并不是 AR 专属产物，而更像是 Transformer 在实体-关系检索上的一个稳定机制。

第三步是诊断并修复 MDM 的 multi-token breakdown。作者发现单 token target object 上，MDM 和 ARM 的编辑效果接近；但一旦目标 object 跨多个 token，MDM 性能明显下降。论文给出的解释很有说服力：标准 locate-then-edit 只在一个“理想状态”上拟合编辑，也就是模型在预测目标 token 时的某个内部表示。AR 解码是左到右的，生成时会自然经过这个被拟合的状态，所以编辑能生效。MDM 则从 fully masked 输出开始，经过多轮去噪，依次经历一系列不同的 partial-mask states；原始编辑更新没有针对这些中间状态做鲁棒化，因此多 token object 的后续 token 会在不匹配的状态分布下被生成，导致编辑逐步失效。

First, the authors transfer locate-then-edit to MDMs with minimal changes. They compare two AR models (LLaMA and Qwen) and two MDMs (LLaDA and Dream) at matched scale. The underlying editing view remains the same as in ROME and MEMIT: the MLP down-projection is treated as a linear associative memory, the up-projection activation at the last subject token serves as the key, and the value encodes relation-object information. Editing modifies the selected MLP weights so that the same key maps to a new target object representation. For MDMs, the algorithm is adapted only as needed for masked prediction, not redesigned from scratch. This is important because it allows the paper to test whether the original assumptions survive the paradigm shift.

Second, the paper disentangles localization from effectiveness. It uses causal tracing to identify which token positions and layers are causally responsible for factual recall, and then performs systematic sweeps over edit positions and layer ranges. The main result is strikingly consistent: even though MDMs are bidirectional and every token can attend to the full subject, factual recall still concentrates in the early-to-mid-layer MLPs at the last subject token, just as in AR models. That means the canonical edit site from AR knowledge editing is not merely an artifact of left-to-right training.

Third, the paper diagnoses and repairs the multi-token failure mode in MDMs. For single-token target objects, editing performance is comparable between ARMs and MDMs. But as the target object spans more tokens, MDM performance drops sharply. The explanation is tied to generation dynamics. Standard locate-then-edit fits the update at a single internal state. In an AR model, left-to-right decoding naturally passes through that fitted state when generating the edited token sequence. In an MDM, generation starts from a fully masked output and proceeds through multiple denoising steps, traversing a chain of partial-mask states that the edit was never optimized for. As a result, later tokens in a multi-token object are generated under mismatched internal conditions, and the edit degrades.

To address this, the authors propose a simple correction that makes the edit robust to those intermediate partial-mask states. The excerpt does not expose every formula, but the conceptual move is clear: instead of fitting the edit to a single idealized state, the update is constrained to remain effective across the family of states encountered during denoising. The second set evaluates editing performance for single-token versus multi-token target objects. The pattern is clear: MDMs perform comparably to ARMs when the edited object is a single token, but degrade systematically as object length increases.
