Inverting the Bellman Equation: From $Q$-Values to World Models

这篇论文讨论的是一个很基础、也很少被讲透的问题：一个看起来“纯 model-free”的 value-based agent，到底有没有在内部学到环境动力学，也就是 world model。传统看法把 model-free 和 model-based 分成两条路，原因在于 value equivalence：不同的转移核可能导出相同的 value function 和最优策略，所以仅凭单一任务上的 Q 值，通常无法唯一恢复环境。作者要解决的核心问题是：如果 agent 不是只为一个 reward 训练，而是在足够丰富的一组 goals 或 reward functions 上训练，那么这些 Q-values 是否已经隐式编码了唯一且准确的转移模型 P；如果是，怎样把它从 Q 中反推出去。

评不是 LLM 论文，但它在动摇一个老 prior：足够丰富的 value learning 可能已经学出 world model；先看理论命题和恢复条件，再决定要不要借到 latent reasoning 上。
Alistair Letcher,Mattie Fellows,Alexander D. Goldie,Jonathan Richens,Jakob N. Foerster,Oliver Richardson

Reward Models Are Secretly Value Functions: Temporally Coherent Reward Modeling

这篇工作要解决的是 RLHF 里 reward model 的一个结构性浪费：标准 Bradley-Terry 训练只用最终 token 的分数做偏好学习，把中间所有位置的输出都丢掉了。这样训练出来的 RM 在 final score 上可以工作，但 token-level 输出通常是噪声，既不能解释生成过程中哪一步在加分、哪一步在减分，也不能自然承担 value estimation 的角色。论文的核心命题是：如果 reward model 真在估计“一个回答最终会有多好”，那么它在任意中间位置的输出，都应该表示在当前 prefix 条件下对最终 reward 的条件期望。换句话说，RM 不该只在 EOS 位置有意义，它应该沿时间维度保持一致，像 value function 一样对 partial response 给出 coherent prediction。

评把 RM 当 value function 来训是对的方向，且“只加正则不改 pipeline”很可复现；优先看正则推导与中间 token 指标是否真能外推到 RL 稳定性。
