注入分两种：G-inject 只通过 caption→image 的 rectified flow 目标训练；U-inject 只通过 image→text 的 language modeling cross-entropy 训练。训练时用 LoRA，rank 32，且把 LoRA 放置位置作为受控变量。关键实验轴是“entry point”——新概念被写入解码器哪一层、哪一类子模块。作者系统比较了写入共享路径、私有生成分支、非导出载体、读出层等不同位置，并引入 alignment probe 来测量该层是否已经把概念表示成两任务共用的语义格式。

核心发现有三层。第一，跨任务通道确实存在，但双向不对称：只学生成的模型，在理解侧可以做名称匹配，却不能稳定地产生名称；只学理解的模型，则可以在生成侧画出该概念。第二，multiple-choice probe 会高估 generation→understanding 的迁移，因为模型可能靠排除法选对；一旦改成 production-style 评测，即把候选词从上下文中全部移除，只有真正经过 LM cross-entropy 训练的条件才会产出名称。第三，entry point 决定可用性，但“位置对”还不够，必须该层已经处在共享语义格式中。alignment probe 能预测哪些配置会导出，但把 probe 指标硬推到很高本身并不自动带来迁移，说明相关性不等于充分因果。作者还做了 activation edit，直接在闭式形式下最大化同一个 alignment 项，发现它能拿到训练增益的大约 80%，但只在很窄的层窗口内有效，这进一步支持“中层共享语义空间”这个解释。d:T9c9,The experimental design is unusually clean. The main platform is BAGEL-7B-MoT, a 28-layer Mixture-of-Transformers model with hidden size 3584. Each layer contains a shared text/understanding expert and a private generation expert. Understanding uses only the shared expert, while generation uses both shared and private branches. To isolate architectural transfer from supervision overlap, the authors create 56 novel concepts. Each concept is an Objaverse 3D asset rendered from 60 training views and 20 held-out views, paired with a pseudo-word screened so that the frozen model shows no stable visual or lexical behavior for it. Concepts are split into seven groups of eight, with evaluation done against fixed-difficulty retrieval banks.

There are two injection routes. G-inject trains only the caption-to-image direction using a rectified-flow objective. U-inject trains only the image-to-text direction using language-model cross-entropy. Training uses rank-32 LoRA, and the placement of LoRA is itself a controlled variable. The central experimental axis is the entry point: the exact layer and submodule where the new concept is written into the decoder. The paper compares writing into the shared pathway, the private generation branch, non-exporting carriers, and readout layers, and uses an alignment probe to test whether a given depth already represents concepts in a semantic format usable by both tasks.

Three findings stand out. First, the cross-task channel is real but asymmetric. Generation-only training lets the model match the concept name on the understanding side, but not reliably produce the name. Understanding-only training can also support drawing the concept on the generation side. Second, multiple-choice probes overestimate generation-to-understanding transfer because they can be solved by elimination. When evaluation is changed to production, with all candidate names removed from context, only conditions that actually computed LM cross-entropy can produce the name. Third, entry point gates usability, but the right location is not sufficient by itself: the concept must enter at a depth where both tasks already share a semantic code. The alignment probe predicts exportability across configurations, but maximizing the probe score alone does not guarantee transfer. The activation-edit experiment sharpens this point further: directly optimizing the same alignment term in closed form recovers about 80% of the trained gain, but only within a narrow layer window.e:T484,Several numbers matter. The practical method, writing the concept mid-stack with an alignment objective and no generative gradient, acquires the concept while causing only a 0.1% relative loss in general text-to-image ability. The standard generative recipe causes a 41% loss, which is a large gap and suggests that naive generative fine-tuning is a poor way to inject new concepts into a unified model. The activation-edit intervention recovers roughly 80% of the trained gain, but only in a narrow depth range, which makes the entry-point claim concrete rather than rhetorical. The alignment probe is tested across 36 configurations and predicts which settings export across tasks. Across four architectures or settings, the effective window tracks whether the understanding pathway encodes semantic concepts at that depth, not simply backbone family or scale. The most important qualitative result is the dissociation between matching and production: generation-only training supports recognition-like matching on the understanding side, but not true name production without lexical cues; understanding-side LM training is what creates producible names.f:T406,Refinement via Regeneration (RvR): treat refinement as another round of conditional generation rather than instruction-driven local editing. Two mechanisms enlarge the effective modification space:
1) Data/supervision: build training pairs from independently generated T2I samples under the same prompt with different alignment quality, instead of true editing pairs. The target (better-aligned) image is not required to be a pixel-consistent edit of the source (worse-aligned) image, so the model is rewarded for semantic correction even if it requires global restructuring.
2) Pipeline: rely on semantic ViT representations only, enabling broad revisions guided by semantics rather than appearance preservation.
