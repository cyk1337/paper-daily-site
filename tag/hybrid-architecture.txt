19:T458,The method starts from the state space duality view of Mamba-2. Under SSD, a selective SSM layer can be interpreted as structured causal attention: the recurrent state behaves like a compressed KV cache, the update writes token-dependent content into the state, and the readout decodes the value needed by the current token. The key observation is that Mamba-2 decodes token-conditioned values from this state, but does not explicitly decode token-conditioned keys. DART adds a state-memory attention branch on top of the Mamba-2 scan. Chunk state contributions produced by the chunked scan are treated as compressed memory slots. The model decodes both keys and values from these state memories, attends to them with the current query, and adds the retrieved state readout back to the Mamba-2 output through a gated residual correction. The design avoids reconstructing a full token-level KV cache, while giving the model a more selective retrieval path than a single recurrent readout. The implementation reuses the Mamba-2 chunked scan and computes the new attention branch with a FlashAttention-style kernel.1a:T785,The paper introduces two variants. The base version is a Dirichlet-process cache. For each incoming representation, the model compares it to existing memory-slot keys. If the nearest slot is farther than a threshold, it allocates a new slot; otherwise it merges the input into the nearest slot and updates the corresponding key/value. This is the DP-means rule, the small-variance MAP limit of a Dirichlet-process mixture, but used here as an online write operator rather than latent-variable inference. Readout remains content-based, so the model retains some of the retrieval behavior of attention while avoiding per-token storage.

The second variant is a surprise-adaptive Dirichlet-process cache. A fixed concentration works for stationary streams, but not when novelty arrives in bursts. The paper therefore adapts the concentration using a surprise signal derived from recent allocation rate. When novelty rises, the cache becomes more willing to open new slots; when the stream becomes predictable again, the effective budget tightens and memory consolidates. The two variants share the same allocate-on-novelty and read mechanism. They differ only in whether concentration is fixed or dynamically scheduled.

The distinctions from prior work are carefully drawn. This is not clustered or routing attention, which approximates full softmax within a bounded context and usually uses a fixed number of clusters. It is not Memorizing Transformer, kNN-LM, or other external-memory systems that still store token-level entries. It is also not fixed-budget sparse caching such as StreamingLLM or H2O, where capacity is controlled by eviction. The closest family is novelty-gated memory such as Titans or EM-LLM, but here novelty is defined by a DP-means-style distance threshold rather than a purely learned write gate. The novelty is therefore in the synthesis and in where it sits on the SSM-to-attention design spectrum.1b:T575,From the available full text, the experimental agenda is clearly controlled rather than large-scale language-model pretraining. The text repeatedly scopes claims to a controlled setting, which suggests synthetic sequence tasks, copy or retrieval tasks, and diagnostics similar in spirit to Zoology-style recall-throughput evaluation rather than full frontier-scale LM training.

第一，架构层面，attention 层和 Mamba 层都按 block 边界缓存。对 attention 层，缓存对象仍是标准 KV；对 Mamba 层，缓存的是每层在 block 边界处的 forward recurrent boundary state。这样，已完成 block 不需要在每个 reverse diffusion step 重新跑一遍。

第二，作者没有采用全序列双向 Mamba，而是把 reverse-direction scan 限制在当前 block 内。原因很直接：如果反向扫描跨过 clean prefix，那么反向状态会依赖当前 block 的 noisy 内容和 diffusion timestep，prefix 就不再是稳定缓存。把反向扫描裁到 active block 后，prefix 只需要 forward scan，天然可复用；当前 block 仍然保留局部双向 mixing，避免退化成纯因果 denoiser。

第三，训练目标采用 all-block objective。一个训练窗口被切成多个 block，同一窗口内每个 block 都轮流作为“当前去噪目标”，其左侧 clean blocks 作为条件前缀。关键不只是 block-wise loss，而是训练时显式构造与推理一致的 prefix caches：attention KV 和 Mamba forward states 都在训练图里被真实建立，后续 block 的 loss 会直接反向训练这些缓存状态的构造过程。这样，模型学到的不是抽象的 prefix 表示，而是推理时真正要复用的状态。

第四，论文还处理了 diffusion timestep conditioning 与缓存冲突的问题。timestep modulation 只作用于当前 active block，而不污染 clean-prefix cache。否则 prefix hidden state 会依赖当前 reverse step，缓存就失效。这个 factorization 看起来像工程细节，实际上是 block diffusion 与 cacheable recurrent mixer 能否兼容的必要条件。

第五，作为对照，作者系统比较了四类模型：full-sequence attention、full-sequence DiffuMamba-H、BDLM attention、BDLM Mamba-H。这里的价值在于把“block factorization”和“mixer 替换”两个变量拆开，而不是只和一个弱基线比较。1e:T8b1,The proposed model is BDLM Mamba-H, a block diffusion Mamba-attention hybrid with partial bidirectionality. The key design choice is simple but consequential: bidirectional mixing is retained only inside the current active denoising block, while completed prefix blocks are represented through cacheable forward states.

At the architectural level, attention layers cache standard KV tensors at block boundaries, and Mamba layers cache forward recurrent boundary states. This lets completed blocks remain fixed conditioning context across reverse diffusion steps, instead of being recomputed every time.

The main departure from prior full-sequence DiffuMamba-style models is the restriction of the reverse-direction Mamba scan. A reverse scan over the whole denoising window would make prefix states depend on the current noisy block and on the diffusion timestep, which destroys cache reuse. By limiting the reverse scan to the active block, the model keeps local bidirectional context where denoising needs it, while preserving a stable forward-only prefix representation.

Training is built around an all-block objective. A training window is partitioned into blocks, and each block is trained as the current denoising target conditioned on the clean prefix blocks to its left. The important part is not merely summing block losses. During training, the model explicitly constructs the same cache objects used at inference: attention KV caches and Mamba forward boundary states. Losses on downstream blocks therefore directly train the mechanism that builds reusable prefix states.

The paper also introduces timestep-conditioning factorization so that diffusion-step modulation applies only to the active block. This avoids contaminating clean-prefix caches with timestep-dependent activations. That detail is essential: without it, the cached prefix would vary across reverse diffusion steps and would no longer be reusable.

Methodologically, the paper compares four controlled variants: full-sequence attention, full-sequence DiffuMamba-H, BDLM attention, and BDLM Mamba-H.
