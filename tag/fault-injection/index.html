Tool-Calling LLM Agents Under Realistic MCP Faults: Scale Does Not Purchase Fault Tolerance

这篇工作要回答的是：基于 MCP 调用外部工具的 LLM agent，在真实工具故障下到底有多脆弱，以及更大的 backbone 是否真的更抗故障。它针对的是当前 agent 评测里的一个结构性缺口：大多数 benchmark 默认工具返回正确、及时、格式合法的结果，但真实系统里常见的是超时、错误值、schema 漂移、间歇性失败和重试级联，这些问题往往发生在模型之外，却直接决定 agent 的端到端表现。

评不是 pretrain 论文，但它把“scale 会顺带修好 agent 系统脆弱性”这个想当然直接打掉；读实验设计和 fault taxonomy 就够，值得拿来约束内部 tool-use eval。
Antonio Ken Iannillo,Joshua Segun Owotogbe,Roberto Natella,Francesco Avallone,Kristina Kudryavtseva,Indika Kumara

Deterministic LLM Inference Across GPU Kernels: Power-of-Two INT8 Quantization Scales and the Limits of Tolerance-Based Conformance

这篇文章处理的是一个很工程、但对大模型推理复现性很关键的问题：两个实现同一 W8A8 INT8 GEMM 接口的 GPU kernel，是否可以被当作可互换的“等价实现”。前作已经证明答案是否定的，并把差异定位到 epilogue，也就是 scale 乘法和最终舍入，而不是 INT32 accumulator。本篇进一步补上两个缺口：一是已有 conformance suite 到底能不能真的抓到错误；二是 power-of-two quantization scales 能否在不明显伤害模型质量的前提下，把跨 kernel 推理变成 bitwise deterministic。

评别把“容差测试过了”当成kernel可互换：这篇用fault injection把盲区钉死了；只看故障分类+结论表就够，能直接改你的conformance策略。
Teng-Ruei Chen
