18:T809,TuringViT has three main components. The first is architectural. It introduces Turing Linear Attention (TLA) as the dominant attention operator, replacing most softmax-attention layers with a linear-complexity alternative. TLA is not just a generic linearized attention block. It adds sequence-length-aware normalization and an input-dependent output gate, aiming to remain stable when the number of visual tokens varies widely while preserving local and high-frequency visual responses. The model does not remove full attention entirely; instead, it inserts a small number of standard softmax MHA layers periodically for explicit token-token interaction and global routing. This hybrid design is pragmatic: linear attention handles most of the cost, while sparse full attention recovers some of the expressivity.

The second component is data: VISTA-Curation. For image-language data, the pipeline filters low-quality images, generates multiple caption candidates, and then selects the best one using relative image-text scoring plus textual informativeness ranking. For video-language data, it decomposes raw videos into compact clips, samples representative frames, filters clips by semantic and motion consistency, and fuses local frame details with global temporal semantics into better captions. The key idea is not just “more cleaning,” but converting noisy image-text and video-text corpora into more grounded and discriminative supervision.

The third component is training. Instead of pretraining at a fixed resolution and later adapting to dynamic resolution, TuringViT is trained with variable resolutions and aspect ratios from the start. To keep this affordable, the first 80% of training caps the maximum image size at 512, and the later stage removes that cap and introduces larger images and video data. The logic is straightforward: learn robust generic visual representations early, then spend the expensive part of the budget on high-resolution and temporal modeling later. The linear-attention backbone makes this schedule feasible.19:T5c2,The experiments are designed to support three claims. First, under similar or lower resource budgets, TuringViT matches or exceeds strong open-source ViT baselines, suggesting that the hybrid linear-attention design does not significantly compromise representation quality. Second, VISTA-Curation delivers strong data efficiency: the paper claims it can outperform leading open-source ViT baselines using only about 10% of the data scale, which implies that better supervision density can offset a large amount of raw data volume. Third, under dynamic resolution and long visual sequences, TuringViT shows a much flatter latency curve than standard softmax-based ViTs, with scaling closer to linear as sequence length grows. That matters for high-resolution images, multi-image inputs, and video.

The paper’s central claim is the combination of lower cost, less data, dynamic-resolution support, and strong performance.1a:T933,The method is a two-pass video understanding framework with two key behavioral designs. In the first pass, the model watches the full video at low temporal and spatial fidelity. Visual and audio tokens are interleaved and fed to the LLM together with the question. The output is structured: an initial answer A^(1), a short reasoning trace R^(1), and a temporal localization prediction T = [t_start, t_end]. The localization acts as a policy decision that determines which segment will be revisited at higher fidelity.

In the second pass, the model re-encodes only the localized segment using higher frame rate or resolution, while retaining the first-pass global context and the interaction trace from the first pass. It then produces a refined final answer. The two main design choices are there to make this new re-watch behavior compatible with the pretrained model’s existing answering prior.

The first is re-answer. The authors argue that an instruction-tuned video LLM has an answer-first tendency: given a question and a coarse video view, it naturally tries to answer immediately. Forcing the model into a strict locate-then-reason pattern creates a mismatch with that prior and can destabilize learning. Re-answer avoids this by letting the model answer first in the initial pass, then revise the answer after re-watching. This makes temporal localization an add-on capability attached to the existing QA behavior rather than a replacement for it.

The second is re-ask. Under causal attention, question tokens from the first pass cannot directly attend to newly observed high-fidelity frames in the second pass. That weakens question adherence exactly when the model is supposed to use the new evidence. The fix is simple: inject the query again during the second pass so the question can directly interact with the revisited segment. Mechanistically, this matters because otherwise the second pass mostly extends the first-pass hidden-state trajectory instead of re-conditioning on fresh evidence.

Training-wise, the paper avoids CoT cold-start and CoT-based SFT. It starts from an instruction-tuned base model and directly optimizes re-watch behavior with DAPO-based RL.
