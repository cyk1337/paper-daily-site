The paper studies several configurations: pure Local, pure Meta, and mixed Local+Meta variants. Two groups of variables are explored systematically. The first is quantitative: the ratio between Meta and Local experts in the whole model, and the ratio between Meta and Local experts among the activated experts in each layer. The second is topological: whether every layer contains both types, whether only some layers use shared experts, and whether part of the original hierarchical organization is retained.

The key point is that this is not just naive parameter tying. The sharing is embedded inside sparse MoE routing. Each layer still performs top-k expert selection, but the candidate set can now include experts from a cross-layer shared pool rather than only layer-private experts. This changes the storage-retrieval structure without increasing the activated expert count. A shared expert can be trained by tokens arriving from multiple depths, which may improve parameter reuse and encourage more general expert functions. At the same time, compute per token remains close to the original MoE budget.

The paper’s mechanism story is also more specific than a pure compression argument. The authors interpret Meta Experts as introducing more flexible residual-like paths across depth. In a standard hierarchical stack, hidden states interact across layers through forward residual connections only. With shared experts, shallow and deep layers can access the same expert within a single forward pass, which the paper describes as an activation-level backward residual connection. The term is conceptual rather than literal backpropagation, but the intended point is clear: parameter updates and representation access become less strictly layer-local. This differs from Looped Transformers, which also reuse parameters across depth but do so by increasing recurrence and serial depth.
