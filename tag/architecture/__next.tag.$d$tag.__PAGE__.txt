9:T4b6,MDLMPE explicitly conditions positional representations on the denoising state. It starts from a binary availability sequence indicating which positions contain revealed tokens and which positions are masked or attention-invalid. For each target token, a target-centered Gaussian weighting is applied to represent the spatial distribution of visible evidence around that token. For an attention pair, the two centered views are averaged into a joint distribution, so the attention relation can depend on both relative distance and the surrounding availability pattern.

The distribution is then projected through a cosine basis to produce features. The method injects these features through two paths. Token-level features are added to the token representation. Pair-level features are mapped by a lightweight MLP into angular offsets for RoPE. This keeps the relative-position geometry of RoPE, but makes the rotations responsive to the current mask pattern. 2) Architecture (Metis prototype):
- Inspired by Fast Weight Programming: introduce fast-changing weights/states integrated into the backbone.

- Intuition: local memory acts like writable short-term state; hyper memory controls/stabilizes how state is written/read (akin to gating or a hypernetwork-style controller).

- Memory reconstruction objective: enforces that the memory state actually compresses and retains past information (an upper bound on what can be stored/recovered).
- Memory operation objectives: supervise or self-supervise the desired state transitions for write/update/forget/read, so the model learns procedures, not just storage.
- Regularization objective: improves robustness under complex scenarios, mitigating drift, contamination, or uncontrolled accumulation.
