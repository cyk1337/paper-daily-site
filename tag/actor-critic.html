Hybrid Advantage Estimation with Unified Critic for VLM Agentic Reinforcement Learning

这篇论文解决 VLM 多轮 Agent 强化学习中的信用分配问题。现有方法通常在两种粒度之间二选一：token-wise RL 把每个 token 当作动作，适合细粒度语言生成；turn-wise RL 把一整轮输出当作动作，更容易利用环境反馈。但多轮任务同时需要轮内生成质量和跨轮策略调整，单一粒度容易造成训练信号不匹配。论文关注的典型失败是模型只看最近观察，忽略过去动作和失败反馈，反复输出已经失败的动作。

评读理论推导和 ablation 即可；若 unified critic 真稳，会影响多轮 RLVR 的 credit assignment 设计。
Wenxuan Zhang,Yuhui Wang,Donggang Jia,Xiaoqian Shen,Jian Ding,Ivan Viola,Jürgen Schmidhuber,Mohamed Elhoseiny

Bringing Value Models Back: Generative Critics for Value Modeling in LLM Reinforcement Learning

LLM 后训练 RL 中的核心瓶颈是长序列生成的 credit assignment：奖励通常只在序列末端给一个标量，导致难以判断哪些中间 token/决策真正促成了最终成功。经典 actor-critic 依赖 value function 做细粒度 advantage 估计，但在 LLM 规模下“判别式（discriminative）一发标量预测”的 value model 往往难训、不稳、效果不随规模可靠提升，实践中被 GRPO/RLOO 等 value-free 方法替代，从而把序列问题近似成 contextual bandit，牺牲精细归因能力。

评改变“value-free 足够”的直觉：生成式 critic 让 credit assignment 可表达且可校准；建议重点看 value 训练稳定性与长序列增益那几张表。
Zikang Shan,Han Zhong,Liwei Wang,Li Zhao
