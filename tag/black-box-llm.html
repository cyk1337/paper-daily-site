Diagnosing Multi-step Reasoning Failures in Black-box LLMs via Stepwise Confidence Attribution

这篇工作处理的是黑盒 LLM 多步推理里一个很具体但长期缺位的问题：当最终答案错了，究竟是哪一步开始偏了；当答案对了，哪些中间步骤是真正承载正确推理的关键锚点。已有方法要么依赖逐步人工标注训练 step verifier，要么让另一个 LLM 充当裁判逐步打分。前者成本高，后者会把 judge model 的偏置和不稳定性一并带进来。作者把问题改写成 stepwise confidence attribution：只利用模型生成的多条推理轨迹和最终答案正确性，在黑盒条件下给每个 reasoning step 分配置信度。关键难点不在于找字面相似，而在于区分‘正确推理的合法多样性’和‘真正导致失败的偏离’。同一道题的正确解法可能顺序不同、表述不同、细节粗细不同，但通常会经过一些共享的逻辑中间态；错误轨迹则会在这些逻辑锚点附近发生漂移。

评如果你在做 reasoning trace 过滤或过程监督，可以读；先看方法假设是否把“多数结构”误当“正确结构”，这会决定它是工具还是噪声源。
Xiaoou Liu,Tiejin Chen,Dengjia Zhang,Yaqing Wang,Lu Cheng,Hua Wei
