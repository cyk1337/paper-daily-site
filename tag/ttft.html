TokTier: Exact Stateful Tokenization for Agentic LLM Serving

TokTier 解决的是 agentic LLM serving 中一个容易被低估的前端瓶颈：KV prefix cache 已经避免了模型重复处理长前缀，但 tokenizer 仍然在每次请求时重新扫描完整 transcript。编码 agent 的请求模式会放大这个问题，因为大多数调用只是向已有会话追加一小段工具结果，但请求文本会携带完整历史。难点在于 tokenization 不是简单可拼接的，追加少量文本也可能改变旧文本尾部的 token 边界，因此不能只按 byte prefix 复用旧 token IDs。

评不是预训练论文，但它把一个常被忽略的 serving 真瓶颈讲清楚了；只看 exactness contract 和 stable-boundary 机制，足够启发 tokenizer/serving 接口设计。
