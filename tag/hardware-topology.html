The KV Cache Is the New Memory Wall

论文解决的是长上下文自回归推理中的真实瓶颈定位问题：decode 阶段不是主要受算力限制，而是受 HBM 带宽限制；随着上下文长度增长，限制资源会从模型权重读取转向 KV cache 读取。已有 KV 压缩、淘汰、分页、共享、卸载方法很多，但实验设置、硬件、上下文长度、batch size、质量指标互不一致，导致结果难以比较，也难以判断哪类方法适合哪种服务场景。

评极其扎实的长上下文推理系统分析，给出了 H100/B200/MI300X 上 KV Cache 撞墙的精确数学推导，做长文本模型设计和 Serving 的必读。
