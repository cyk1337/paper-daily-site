18:T4ab,The key idea is to rewrite attention statistics so they can be accumulated or recovered within FlashAttention’s computation path.
- The paper distinguishes statistics (per-head quantities returned by kernels) from features (host-side aggregations used by a classifier).
- Using FlashAttention’s online softmax state (running max m, normalizer ℓ, accumulated output O) and the stored LSE, it classifies statistics into four exact computation tiers:
  (1) accumulate inside the tiled pass with bounded state (near-free),
  (2) a fixed number of post-pass sparse lookups by re-evaluating a few scores and recovering weights via LSE,
  (3) a second tiled pass over scores (still avoiding dense materialization),
  (4) statistics that truly require dense materialization.
- Implementation: Triton kernels extending FlashAttention-2 forward to emit the statistics needed by five published detectors (Lookback Lens, LLM-Check, RAUQ, INTRYGUE, SinkProbe), packaged as an attention backend for integration.
