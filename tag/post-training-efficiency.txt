17:T5d2,The method, VIGOR (VarIance Guided Online Rollout allocation), starts from an analysis of GRPO under binary rewards. The key observation is that the magnitude of the learning signal is governed by within-group reward variance. If all sampled responses for a prompt are either all correct or all incorrect, the group-relative advantage carries little discriminative information. If the group contains a mix of successes and failures, GRPO gets a meaningful comparison signal. Based on this, VIGOR replaces uniform rollout allocation with iterative refinement. Each prompt first receives a small initial number of rollouts. The algorithm estimates group-level reward variance from these partial samples, selects the prompts with the highest variance, and allocates additional rollouts only to them. This repeats until a fixed total budget is exhausted. The distinction from DAPO-style approaches is important: VIGOR does not first over-generate a larger pool and then filter. It allocates budget online during generation, which avoids paying extra rollout cost purely for selection. Compared with methods that improve utilization through stale rollouts or auxiliary signals, it leaves the GRPO objective unchanged and only changes where the rollout budget goes. The paper also provides a theoretical speedup analysis under a Pareto reward-variance model, arguing that the benefit of iterative refinement grows rapidly with the number of refinement rounds when informativeness is heavy-tailed.18:T40d,The evaluation covers both math reasoning and coding RLVR. The main result is consistent: VIGOR reaches the same accuracy with fewer rollouts, with up to 2.3x rollout-efficiency improvement on Qwen2.5-3B.
