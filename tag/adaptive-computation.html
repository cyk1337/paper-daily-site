Looped World Models

这篇工作处理的是世界模型里一个很具体但长期存在的矛盾：长时程预测通常需要更深的计算，才能在每一步状态转移上做足够细的推断；但把模型直接做深，会同时抬高参数量、部署成本和训练难度，而且 rollout 越长，误差越容易累积。作者把这个问题改写成“单步转移是否可以通过共享参数的迭代细化来完成”，也就是不靠堆更多独立层，而是对同一个 latent transition operator 反复应用，让模型在固定参数预算下增加‘内循环深度’。论文的关键点不只是把 looped transformer 搬到 world model，而是把环境动力学中的重复作用规律，与共享更新算子的迭代 refinement 对齐，并进一步处理了循环深度增加后数值不稳定的问题。

评将参数共享循环Transformer迁移至世界建模，迭代隐深度作为正交scaling轴的结论对test-time compute研究有参考，重点看scaling实验部分。

Fixed-Point Masked Generative Modeling

这篇工作解决的是 masked generative model（MGM）在训练和采样两端都偏贵的问题，而且它盯住的不是“采样步数太多”这一层，而是更细的一层：每个去噪步内部都要跑一遍完整的双向 Transformer，导致每一步的计算深度固定、参数不共享、低预算采样时质量掉得很快。作者的判断是，现有工作要么改 sampler，要么做固定深度的高效骨干，但都没有解决“不同去噪阶段难度不同，却被迫分配相同 denoiser 计算量”这个问题。于是论文提出把 fixed-point / DEQ 风格的共享层引入 masked generation，让 denoiser 的有效深度可以随求解迭代数自适应变化，同时再补上两个 MGM 特有的机制，去处理跨步输入离散变化带来的不稳定。

评定点迭代+三态重用的思路值得做 masked/diffusion LM 的人借鉴，看 §3 和 §4 方法部分即可，实验因摘要截断暂无法评估。

Same Signal, Opposite Meaning: Direction-Informed Adaptive Learning for LLM Agents

LLM Agent 的自适应测试时计算（adaptive test-time compute）中，现有置信度/不确定性/难度门控方法均假设信号方向固定（如熵越高越需要额外计算），但实际同一信号在不同（环境、模型骨干）组合下效用方向可能反转——高熵在某些场景表示额外计算有益，在另一些场景反而有害。方向错误的门控会因精确选中有害状态而劣化性能。

评看跨环境和跨 backbone 的方向反转表；它会修正“高不确定性就多算”的朴素 prior。
