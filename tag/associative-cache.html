Parallel Causal Associative Fields: Gated Sparse Memory for Long-Context Language Modeling

这篇工作要解决的是：在长上下文语言建模里，如何保留类似 attention 的“按内容直接访问过去局部事件”的能力，同时避免全量 causal self-attention 的二次复杂度，也不把整段历史压进一个固定维状态里。作者把问题拆成两部分：一是如何找到可能相关的过去记录，二是如何把这些记录转成当前 token 的预测。PCAF 的出发点是把这两件事从标准 attention 里拆开，不再对所有历史 token 做稠密打分，而是先用离散或语义路由找到一个很小的候选集合，再只在这些候选上做连续打分和概率混合。

评只看记忆写入/检索设计和gate消融；小数据小模型不改prior，但可作为attention替代原语备查。
