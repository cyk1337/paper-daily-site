18:T4bd,The method has three main pieces. First, the task is framed in the CiteGuard environment, where the model can take bounded actions such as search, inspect, request more context, and select a paper. This turns citation recovery into a sequential decision problem under an interaction budget, rather than a one-shot generation task. Second, the authors build CiteAlign, a 7,607-instance dataset from recent computer science literature, with temporally separated splits so that evaluation targets are relatively recent and less likely to be memorized. They also construct a controlled 709-instance benchmark subset for stable comparison. Third, they fine-tune Qwen3-4B with GRPO for tool-using citation recovery. The training objective is tied to recovering the true cited paper, not merely generating plausible reference strings. A key design choice is to separate target retrieval from final selection, which lets the authors localize where RL helps. Compared with standard RAG-style supervised fine-tuning, this setup trains search behavior in an open retrieval space. Compared with pure imitation learning, GRPO allows the model to discover better query reformulation and stopping strategies through interaction.19:T8e4,方法核心是 TSCG，一个确定性的 tool-schema compiler。输入是标准 JSON schema，输出是 token-efficient 的结构化文本表示；不需要访问模型参数，不做微调，也不做运行时搜索。作者把整个系统拆成 8 个可组合算子，并按固定顺序组成 10 步 pipeline。设计思路很明确：不是学习一个 schema rewriter，而是把若干已知的 transformer 读取偏好编码成规则。

几类关键算子分别对应不同机制。第一类是纯压缩型变换，如 delimiter 选择、删除 filler token、把冗长结构短语替换成紧凑分隔符。这部分利用的是 BPE 非单调性和 tokenizer 差异，例如某些符号在特定 tokenizer 下比自然语言短得多。第二类是重排型变换，如把输出约束前置到 prompt 开头，利用 attention sink；把多步操作按拓扑顺序排列，保证因果可达性。第三类是增强型变换，如在结尾追加 closure block，或按 fragility 分数复制关键语义原子，利用 recency bias 和首尾位置优势。

论文里一个值得注意的点是，它没有把所有算子都当成“越多越好”。作者明确区分了 token-reducing、structure-preserving、token-expanding 三类操作，并给出形式化定义与语义保持条件 sem(τ(p)) ⊇ sem(p)。更重要的是，他们证明了若只看一组压缩算子，well-formed schema 上可保证至少 51% 的 token 压缩。这个理论结果不复杂，但足够说明该系统不是经验拼装。

方法上的另一个亮点是 format-versus-compression 分解。作者比较 JSON baseline 与文本 baseline，发现准确率与 token 数的相关性在 JSON 表示下很强，R²=0.88；换成文本表示后几乎消失，R²=0.03。这个结果支持他们的主张：决定性因素是 representation change，而不是简单缩短 prompt。也就是说，模型不是单纯“上下文太长看不过来”，而是“看不懂这种结构”。

从预训练研究视角看，TSCG 的真正价值不在规则本身，而在它把 schema 理解问题拆成了 tokenizer 友好性、位置布局、因果可访问性、关键原子冗余保护这几个可分析维度。这些维度都可以反过来指导数据合成和预训练格式设计。1a:T837,TSCG is a deterministic compiler that converts JSON tool schemas into a compact structured-text format. It is model-agnostic, requires no finetuning, and does not rely on runtime search. The system is built from eight composable operators arranged in a fixed pipeline. The design philosophy is to encode known transformer reading biases into deterministic rewrites rather than learn a schema rewriter.

The operators fall into three groups. Token-reducing operators compress the schema by choosing tokenizer-friendly delimiters, removing filler phrases, and replacing verbose structural language with compact symbolic forms. These exploit BPE non-monotonicity and tokenizer-specific token counts. Structure-preserving reordering operators move critical constraints to the beginning of the prompt to exploit attention sink effects, and reorder multi-step operations topologically so prerequisites are causally accessible. Token-expanding operators add redundancy near the end of the prompt or duplicate fragile semantic atoms to exploit recency bias and boundary-position advantages.

A strong point is that the paper does not treat all operators as uniformly beneficial. It formalizes semantic preservation, distinguishes reducing vs. reordering vs. expanding transforms, and proves a >=51% compression guarantee on well-formed schemas for the reducing subset. More importantly, the paper isolates representation change from raw compression. On JSON baselines, accuracy is strongly correlated with token count (R²=0.88), but on text baselines that correlation nearly disappears (R²=0.03). That result supports the central claim: the dominant effect is not just shorter context, but a representation that the model can actually parse.

From a pretraining perspective, the deeper value is the decomposition itself. The paper turns schema understanding into analyzable dimensions: tokenizer friendliness, positional layout, causal accessibility, and redundancy allocation for fragile semantic atoms. Those dimensions could inform data formatting and serialization choices in future pretraining pipelines.1b:T6df,The empirical section is broad enough to be credible. The authors build TSCG-Agentic-Bench with roughly 19,000 API calls, 12 models, and 5 scenarios, covering 4B–32B models plus three frontier systems. The headline result is that several small models recover from near-collapse under raw JSON schemas to usable tool-calling accuracy under TSCG. The most visible example is Phi-4 14B: from 0% to 84.4% accuracy at 20 tools, and 90.3% at 50 tools.

On efficiency, the compiler preserves 52%–57% token savings even at 100 tools, so the compression benefit does not vanish at larger catalog sizes. On heavier real-world MCP schemas, the method still yields about +5.0 percentage points, suggesting the gains are not limited to lightweight synthetic catalogs. The paper also reports external validation on BFCL with 108%–181% ARR improvements.

The ablations are the most informative part. Some operators are clearly scale-sensitive. CFL and CFO help at smaller catalog sizes but become harmful beyond around 43 tools, which suggests positional anchoring and reordering can start competing for limited attention budget in long contexts. CCP, despite being theoretically motivated, shows no measurable gain in an 11-model ablation while adding about 85–306 tokens; the authors explicitly acknowledge this. That makes the paper more trustworthy. Another useful finding is the model-specific operator-response taxonomy: operator-hungry, operator-sensitive, and operator-robust.
