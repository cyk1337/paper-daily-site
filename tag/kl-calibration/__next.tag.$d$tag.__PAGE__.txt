9:T444,The paper first defines a Reward-Resolution Protocol to separate unlearnable numerical jitter from credible cardinal gaps. It uses bounded binning, a dead zone, and zero-gap skipping. Gaps below the trusted reward resolution are merged before group-relative updates. If a group has no credible gap, both reward and KL updates are skipped for that prompt, preventing noise from being written into the policy. The main operator is MaxNorm-AC, a minimal intervention that only replaces the within-group scale denominator. It uses the maximum absolute raw advantage, combined with a reward-resolution floor, as the denominator, and freezes the resulting loss weight for the current optimization step. This preserves credible cardinal gaps while bounding reward amplification, the effective-KL imbalance, and the tail of prompt-level batch weights. MaxNorm-RLOO is one instance that attaches this bounded-scale operator to the RLOO numerator.
