Actions Speak Louder than Words: Measuring Cross-Lingual Policy Retention in Tool-Using Agents

这篇工作解决的是一个此前几乎没被正面测量的问题：多语言 tool-using agent 在语义等价任务上，跨语言后是否还保留同一套行动策略，而不是只看最终答案是否一致。对 agent 来说，真正决定成本、时延、失败模式和可审计性的，是中间 action trace，不是最后一句答案。难点不在收集轨迹，而在如何把“跨语言策略差异”从长度偏置、空轨迹、随机重合、解码噪声和模型自身不稳定性里分离出来，得到可解释的 retention 指标。

评这篇会直接改你做 multilingual agent eval 的 protocol；先看五个 confound 的拆解，再看 greedy 下仍不保策略这一条，值得内部 benchmark 立刻照抄。
Sourabrata Mukherjee,Kalika Bali,Sunayana Sitaram

Think in English, Answer in Korean: Efficient Adaptation of Multilingual Tool-Using Agents

研究如何在不重新预训练的情况下，把一个已完整后训练的 111B 英文强模型适配成韩英企业级工具调用 Agent，并满足实际显存和部署约束。

评可只看训练 recipe 和失败模式；它是后训练工程文，不会改变预训练 prior，但多语工具奖励设计有复用价值。
