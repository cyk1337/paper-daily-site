19:T4f5,The method, LACL-GUI, is a length-aware contrastive RLVR framework. It starts from the observation that GUI trajectory quality depends not only on final success but also on efficiency and closeness to success. For successful trajectories, the method prefers shorter executions by assigning stronger optimization pressure to concise solutions and down-weighting redundant ones. For failed trajectories, it defines divergence length, measuring how long a failed trajectory stays aligned with a reference successful trajectory before deviating. Failures that diverge later are treated as more informative negatives and are suppressed less aggressively. The key design choice is how these preferences are injected: not by changing the success/failure labels or moving the decision boundary, but through outcome-preserving, zero-mean logit modulations inside a contrastive/classification objective. This lets the method reshape optimization pressure within the positive set and within the negative set while keeping the original binary supervision intact. Conceptually, the paper builds on the motivation behind REAL-like methods: classification objectives avoid GRPO’s gradient pathologies, and LACL-GUI adds finer trajectory structure without sacrificing that stability.1a:T4d3,JAMEL formulates exploration as a POMDP with an intrinsic novelty objective.
- Latent memory construction: each step’s (observation, action) is serialized into an input x_i and passed through a frozen vision-language model F_φ; the EOS hidden state becomes a single latent “memory token” for that step. The history becomes a sequence of such tokens.
- Memory injection: a learned linear aligner W projects memory tokens into the policy LM embedding space; the projected tokens are prepended as a prefix to condition action generation.
- Supervision via novelty: define a binary novelty reward indicating whether the current step discovers behavior not covered by the agent’s own history. In GUIs, novelty is instantiated via deterministic code coverage signals.
- Training pipeline: collect interaction data and apply rejection fine-tuning to bias learning toward trajectories/actions that yield higher novelty, thereby jointly improving exploration and making the latent memory useful.
