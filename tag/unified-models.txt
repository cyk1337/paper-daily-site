18:T6fd,ReasonUni is built on a unified multimodal model with a shared discrete token space, instantiated in the paper with an X-Omni-style pure AR architecture. Images are quantized into visual tokens by a visual tokenizer, text remains language tokens, and visual inputs and outputs share the same semantic codebook. This gives one backbone two conditional policies: understanding p(theta)(T|V) and generation p(theta)(V|T). The paper’s critique of prior reconstruction methods is that they mostly supervise the model to describe what is already present. That encourages copying and preservation, but does not force explicit reasoning about intended edits, structural changes, or invariances. ReasonUni changes the training problem into reasoning-driven editing. Given a source image, an edit instruction, and a target image, the model first generates a textual description of the desired target state, then generates the target image conditioned on that description. The intermediate text is therefore not just a caption; it is a reasoning-bearing representation of the post-edit world state. To jointly optimize both stages, the paper introduces TreeGRPO. For the same input, the model samples multiple reasoning paths, each treated as a branch. Under each branch, it samples multiple generated images as leaves. Rewards are then used at two levels: leaf rewards are aggregated to produce a more reliable branch-level signal for the understanding module, and within-branch normalization guides the generation module under a fixed target-state description. The key idea is structured credit assignment. A reasoning path is judged by the distribution of images it induces, which reduces the noise of single-sample feedback and lets image-level rewards shape the intermediate reasoning process.19:T4dd,From the provided full-text sections, the paper reports consistent gains on both understanding and generation benchmarks relative to UAE, X-Omni, and related baselines. The deeper questions are whether the intermediate reasoning text becomes a useful latent scaffold or just a training-time crutch, and whether pure AR image-token generation will eventually cap the quality ceiling of this unification route.1b:T6bb,UNO turns the understanding branch into an explicit teacher for the generation branch. The setup is based on a BAGEL-like unified model, where an understanding expert handles visual understanding and language interaction, and a generation expert handles image synthesis. In the baseline design, information flows mostly one way: generation is conditioned on understanding features, but receives little direct semantic pressure. During post-training, UNO freezes the understanding expert and feeds it intermediate noisy generative representations, so understanding objectives can backpropagate directly into the generative pathway. Two complementary supervision signals are added. The first is language supervision via captioning, which injects high-level semantic abstraction and improves concept discrimination and instruction alignment, but is sparse and may miss local detail. The second is visual understanding supervision via regression with metaquery tokens, which provides denser structural and fine-grained visual information by matching the generative representation to the understanding expert’s visual semantic space. Together, these losses mean the generation branch is no longer shaped only by low-level denoising or flow objectives; it is also constrained by higher-level semantics and mid-level structure. The key idea is not a new heavy module but a new supervision path: the frozen understanding expert becomes a semantic organizer for the generative representation.
