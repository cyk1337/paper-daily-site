b:T452,The contribution is a structured design space for inference-time cross-lingual exploration rather than a single new algorithm. The core move is to treat “reasoning language / answering language” as exploration axes: translate the query into one or multiple candidate languages, run independent reasoning paths in each language to elicit parametric facts, then aggregate candidates back into the target language.
They claim four inherent dimensions governing cross-lingual exploration (details are in the main method section; from the provided content and cited prior work, these dimensions plausibly include: reasoning vs answering language, pivot vs non-pivot routing, which prompt components are translated, and multi-path sampling/aggregation).
A key stance is to move beyond an English-only pivot: some culturally/localized facts are more accessible in their native language.
