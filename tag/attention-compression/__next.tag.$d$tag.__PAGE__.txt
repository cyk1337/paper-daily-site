9:T82a,The main idea is to treat evicted tokens as residual attention statistics rather than as deleted states. Softmax attention can be written as a numerator–denominator ratio: the numerator sums exp(logit) times value, and the denominator sums exp(logit). Standard eviction keeps only a subset of tokens and effectively sets the omitted side to zero in both terms. ResKV instead splits the fixed cache budget into two parts: a main cache that stores selected tokens exactly, and a residual cache that stores compact residual entries approximating the aggregate contribution of omitted tokens.

There are three key design choices. First, residual entries participate in the same softmax normalization as the exact main-cache tokens. They are not a post-hoc correction added after attention. This shared-softmax formulation allows each residual entry to restore both denominator mass and numerator mass. Second, selected main-cache tokens remain exact; omitted information is not folded into them. This avoids the retained-memory perturbation common in merging-based approaches. Third, the method includes adaptive residual control at two stages. During cache construction, a validation proxy decides whether a given layer/head should receive residual budget based on held-out attention-output reconstruction. During decoding, a dynamic gate scales residual logits according to the sharpness of the main-cache attention. If the main cache already forms a sharp retrieval peak, residual mass should not blur it; if attention is diffuse, residual entries are more likely to help.

The paper also evaluates both query-aware and query-agnostic construction. The latter is more realistic because compression must happen without access to future queries. This matters in practice, since some compression methods look strong only when they can use future-query information. Conceptually, ResKV sits between eviction and merging: it neither deletes omitted tokens outright nor folds them into retained tokens, but gives omitted mass its own compact representation that remains an attention participant.a:T681,The evaluation spans multiple long-context benchmarks, multiple backbones, and several representative compression baselines. On efficiency, the paper claims negligible additional memory overhead and stable throughput at long context lengths, suggesting that the residual mechanism does not impose a large serving penalty. Ablations focus on three components: the validation proxy, the dynamic gate, and the shared-softmax formulation.
