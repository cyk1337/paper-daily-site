19:T4ef,GROW replaces trajectory-level policy-gradient RL with advantage-weighted flow-matching regression. For each prompt, the current policy samples a group of utterances. Each utterance is scored by two rewards: intelligibility and speaker similarity. Each reward is standardized within the group, then combined into a signed group-relative advantage. This advantage directly reweights the standard flow-matching loss, so samples above the group mean are reinforced and those below it are downweighted. Two design choices matter. First, the group-mean reward baseline turns reward weighting into advantage weighting, which removes prompt-level scale variation and amplifies subtle but meaningful differences among samples from the same prompt. Second, a Wasserstein-2 velocity penalty anchors the updated velocity field to a frozen pretrained reference, limiting drift and helping preserve naturalness. Compared with Flow-GRPO-style methods, GROW keeps deterministic ODE sampling, avoids ODE-to-SDE conversion, and does not require per-step likelihood evaluation. The paper also argues against purely positive exponential weighting: in bounded, tightly clustered TTS rewards, it does not provide enough contrast and can be dominated by the shared imitation component.1a:T433,Experiments are run on LibriSpeech-PC test-clean and the English and Chinese Seed-TTS test sets in a zero-shot setting. The main metrics are WER, speaker similarity, and UTMOS for naturalness. Averaged over the three test sets, GROW reduces WER from 2.016 to 1.558, an absolute drop of 0.458, and increases speaker similarity from 0.676 to 0.715, an absolute gain of 0.039, while keeping UTMOS at roughly the pretrained level. The paper reports that these gains surpass the DiTAR-GRPO baseline overall. On efficiency, GROW with 10-NFE training rollouts reaches performance comparable to its own 32-NFE setting, and is about 2.9× faster to train than the 32-NFE DiTAR-GRPO baseline. At matched training-rollout NFE, GROW is still about 1.1× faster. All final evaluations use 32 NFE to keep inference quality comparable. Ablations cover rollout NFE, CFG, reward weighting variants, and reward composition. 第一层是表示。作者使用 X-Codec2，而不是传统多码本 RVQ codec。X-Codec2 通过语义编码器和声学编码器融合后，用单阶段 FSQ 量化成单一 token 流，词表大小 6561，帧率 50 Hz。这样每秒约 50 个 token，避免了多 codebook 并行流给 LM 建模带来的复杂性。对 block diffusion 来说，单流离散序列比多流 RVQ 更自然。

第二层是生成目标。作者把长度为 L 的 codec 序列切成连续 block，block size 设为 32，对应约 0.64 秒音频。训练时只对目标 block 内 token 做 masked corruption，mask 概率由连续时间步 t 控制，采用线性日程 α_t = 1 - t。模型输入由两部分拼接：当前被噪声污染的 block，以及之前已经“干净”的历史 block。模型学习在文本条件和说话人条件下恢复当前 block 的原始 token。这个目标继承了 MDLM/BD3-LM 的思路，但这里是条件生成，不是无条件文本 LM。

第三层是注意力结构。作者采用 staircase attention。它不是简单的双向或因果注意力，而是分三种关系：同一目标 block 内双向注意，保证局部声学一致性；当前 noised block 可以看之前 clean block，保证跨块顺序依赖；历史 clean block 内保持因果结构。这个设计的目的很明确：块内需要像填空一样联合恢复，块间又不能完全失去时间顺序。相比 fully parallel diffusion，它更容易维持文本-语音对齐；相比纯 AR，它把一个 block 内的 token 预测并行化，显著降低解码步数。

从全文描述看，条件信息包括文本和 speaker prompt。文本侧应通过编码器或嵌入序列提供跨模态条件，speaker prompt 则提供说话人特征以支持 zero-shot voice cloning。作者强调不使用显式 duration model，这一点很关键，因为很多非 AR TTS 的稳定性来自外部时长约束，而这里希望由 block-wise sequential dependency 自行学出对齐。

First, the representation. Instead of a multi-codebook RVQ codec, the model uses X-Codec2, which produces a single stream of discrete tokens via fused semantic and acoustic encoders followed by FSQ quantization. The vocabulary size is 6561 and the frame rate is 50 Hz. This matters because block diffusion is much cleaner on a single token stream than on several parallel codebook streams.

Second, the training objective. A speech token sequence is partitioned into contiguous blocks. The paper uses block size B = 32, which corresponds to about 0.64 seconds at 50 Hz. During training, only the target block is corrupted by masking tokens with probability controlled by a continuous diffusion time t, using a linear schedule alpha_t = 1 - t. The model receives the noised target block together with previous clean blocks, plus text and speaker conditioning, and learns to reconstruct the original tokens in the target block. This is the conditional speech analogue of masked discrete diffusion / BD3-style block denoising, rather than standard next-token prediction.

Third, the attention pattern. The model uses staircase attention. Tokens inside the current target block attend bidirectionally, which supports joint reconstruction and local acoustic consistency. The current noised block can attend to previous clean blocks, which preserves sequential dependencies across time. Previous clean blocks themselves follow causal structure. This is the key architectural choice: within-block prediction behaves like masked infilling, while across blocks the model still respects temporal order. Compared with fully parallel diffusion, this should help alignment. Compared with AR codec LMs, it reduces decoding steps by predicting all tokens in a block in parallel.

Conditioning includes text and a speaker prompt for zero-shot voice transfer. A notable design choice is the absence of explicit duration modeling. The paper is effectively testing whether blockwise sequential dependence plus cross-modal conditioning is enough to learn alignment without an external duration scaffold.

Relative to prior work, it differs from VALL-E style AR codec LMs by replacing next-token prediction with masked denoising over codec tokens; it differs from continuous-space flow/diffusion TTS such as Voicebox or F5-TTS by staying entirely in discrete token space; and it is closest to BD3-LM, but extended to conditional speech generation with speaker conditioning and speech-specific block structure.1d:T5ca,The main reported setup is a 0.6B-parameter model trained on 20K hours of speech. The paper positions this against autoregressive codec LM systems that commonly use 60K to 250K hours, so the claimed data reduction is roughly 3x to 12x. The codec frame rate is 50 Hz and the block size is 32 tokens, or about 0.64 seconds of audio.
