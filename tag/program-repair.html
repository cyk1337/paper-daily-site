SWE-Proof: Can Language Models Resolve Real-World Issues with Machine-Checked Proofs?

这篇工作要解决的是：能不能把真实软件仓库中的自然语言 issue，转成带机器检查证明的 coding benchmark，从而用“形式验证”替代不完备的隐藏测试集。问题的关键不只是给代码加证明，而是如何在大代码库、模糊需求、跨文件依赖的现实条件下，构造一个可操作的验证 oracle。已有 verified code generation 多半针对小型独立题目，且把形式化规格当输入；SWE-Proof 面对的是 SWE-bench 这类真实仓库问题，规格并不存在，需要从 ground-truth patch 反推出可验证的 formal spec，并处理未修改依赖函数的语义摘要。

评读 Benchproofer 过滤流程和 verifier 失败案例；它比又一个 SWE 排行更接近可训练的可靠 correctness signal。
