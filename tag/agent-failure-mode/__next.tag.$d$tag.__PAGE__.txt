9:T560,The method has three parts. First, the paper defines a confabulated reflection operationally: a reflection is considered confabulated if it fails to mention the correct target object for the task. In ALFWorld, the target object can be recovered from the gamefile metadata, so this can be checked automatically from existing logs. Second, the authors introduce Reflection Repetition Rate (RRR), a log-based metric that measures how often later reflections are near-duplicates of earlier ones using SequenceMatcher similarity, with 0.85 as the duplication threshold. Environments with RRR >= 0.5 are treated as having frozen reflective memory, meaning the memory stops evolving and starts repeating itself. Third, they validate causality through ablations and propose a mitigation. Frozen environments are split into memory-harmful cases, where removing memory helps the agent solve the task faster, and task-hard cases, where the agent still fails without memory. The mitigation replaces open-ended self-diagnosis with programmatic feedback extraction: instead of asking the model to explain failure freely, the system parses trajectory-level signals tied more closely to environment facts and converts them into constrained feedback.
