Nemotron-Labs-Diffusion-Image: Advancing Masked Discrete Diffusion for High-Resolution Image Synthesis

这篇工作处理的是离散图像生成里两个很具体、也很关键的问题。第一，标准 masked discrete diffusion model 在采样时一旦把某个 token 解开，就不能再改，缺少类似连续 diffusion 的逐步纠错能力；而图像 token 之间依赖很强，按位置独立采样会把早期错误一路带到最后。第二，高保真图像生成需要更大的离散码本，但码本一大，单个 code 在训练集里出现得更稀，one-hot 交叉熵给到的监督就过于尖锐，语义相近但不完全相同的 code 被当成同样错误的负例，导致生成模型更难学。

评离散扩散的两个核心痛点（unmask后不可改、大词表稀疏）和文本MDLM完全一致，重点看§3的token-editing机制，可直接复用到文本离散扩散预训练的ablation
