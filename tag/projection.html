Locally Coherent, Globally Incoherent: Bounding Compositional Incoherence in Multi-Component LLM Agents

这篇论文讨论的是 multi-component LLM agent 的组合一致性问题：每个子组件单独看都可以是局部 coherent 的，组合起来却可能违反基本概率公理。作者把这种现象叫作 locally coherent, globally incoherent。它要解决的不是单个模型的校准，也不是常见的 self-consistency，而是当 planner、retriever、forecaster、tool caller 等不同模块分别给出局部概率判断后，系统级聚合结果是否仍然对应某个合法联合分布。论文给出的核心对象是 compositional residual ε*，即组合后的概率向量到 joint coherent polytope 的 L2 距离，并把它作为运行时可计算的系统级失真证书。

评把“多组件 agent 概率拼接会坏掉”量化成可在线算的 ε* 并给出投影修复，够工程化；只读定义+修复算法与 §5 的失效率统计。
Anany Kotawala

Dr. Post-Training: A Data Regularization Perspective on LLM Post-Training
