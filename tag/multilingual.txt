18:T7fe,The paper is a controlled empirical study built around five pretraining variants. The starting point is an 86M-parameter model trained on four languages in four scripts. From there, mpixel 8l adds four more languages in an already seen script, allowing the authors to test language diversity while holding script familiarity fixed. mpixel 8s adds four languages in previously unseen scripts, testing script diversity. mpixel base combines both expansions and reaches sixteen languages. mpixel large scales capacity from 86M to 307M to test whether larger models mitigate multilingual interference.

The data comes from FineWeb and multilingual FineWeb2. A notable design choice is to allocate equal numbers of image patches per language rather than equal numbers of documents or text tokens. That is the right unit for a pixel LM and makes compute more comparable across scripts. Each language receives roughly 7.5B image patches, with a maximum sequence length of 512 patches.

A technically important part is the multilingual rendering strategy. The paper does not use one universal rendering rule. It defaults to grapheme-aware bigrams to avoid splitting diacritics from base characters. For CJK, where wide characters make bigrams inefficient, it renders one character per patch. For Arabic and Hebrew, where bigram rendering can break ligatures and visual order can distort word structure, it uses word-level rendering in logical order. This is partly an engineering contribution, but for pixel LMs it directly affects redundancy, effective context length, and cross-lingual sharing.

The analysis goes beyond downstream scores. The authors use ABX discrimination to study cross-lingual alignment and probing to locate sentence-level and word-level information across layers. One interesting finding is that the larger 307M model appears to reserve more layers for visual processing, suggesting that extra capacity first relieves front-end representational pressure rather than immediately translating into stronger language-level alignment.19:T6c2,The evaluation covers five tasks and 83 languages: sentence classification, dependency parsing, named entity recognition, natural language inference, and English GLUE as a high-resource reference. Results are broken down into pretraining languages, unseen languages in seen scripts, and languages in unseen scripts. That split is essential because the average can hide very different transfer regimes.

There are four main empirical conclusions. First, scaling acts locally. Adding more languages within a known script mostly helps those added languages and nearby languages in the same script regime. Adding new scripts mostly helps the newly covered scripts. Second, transfer to unseen scripts emerges with multilingual pretraining, but additional scaling in language count, script count, or model size does not keep improving it. That suggests a threshold effect from shared visual structure rather than a smooth scaling law. Third, pixel LMs also suffer from the curse of multilinguality: as more languages are added, performance on the shared original languages drops, and larger capacity partially mitigates that drop. Fourth, on low-resource languages that are typologically distant from XLM-R’s pretraining languages, mpixel outperforms subword and character baselines, which supports the case for pixel-based modeling on the long tail.

The representation analysis adds nuance. Cross-lingual alignment weakens as more languages are added, yet generalization can still occur through shared script structure. The larger model also appears to allocate more depth to visual processing. The paper is less about chasing a single benchmark score and more about answering the four scaling questions with controlled comparisons.1a:T50d,The paper combines community-authored data with a layered evaluation pipeline.
- Dataset: 6,191 original riddles written by community members in their native languages, spanning 62 communities, 51 languages, 45 countries, explicitly supporting many-to-many language–locale mappings.
- Validation: each riddle is verified by native speakers other than the author to ensure cultural grounding and appropriate difficulty.
- Task: open-ended answer generation (not multiple-choice), intentionally stressing compositional reasoning (combining clues) and abductive reasoning (selecting the best explanation among plausible candidates).
- Scoring protocol (core engineering contribution): for 170,520 model responses across 28 model configurations, they use (1) deterministic rules for trivial cases (exact match / empty / “I don’t know”), (2) large-scale native-speaker labeling of unique answers with a fine-grained error taxonomy, and (3) a calibrated two-LLM “jury” validated against human labels to score most remaining answers; unresolved cases are excluded from accuracy.
The design choice is pragmatic: open-ended cultural tasks need human anchors, but full human scoring is too expensive, so they amortize human effort over unique answers and use validated LLM judging for scale.1b:T689,The pipeline begins with outlet identification. The authors use State Media Monitor as the source of media organizations and their control labels. The original seven-level typology is collapsed into controlled versus independent for analysis, while the released dataset retains the finer labels. They then map media assets to web domains in two stages: an LLM is prompted to propose URLs in context, and humans manually verify or correct them. The resulting inventory contains 640 state media outlets, 1,910 assets, and 1,183 unique URLs spanning 173 countries.

Instead of crawling the web independently, the paper extracts pages directly from existing LLM pretraining corpora, namely English FineWeb and FineWeb-2. This design choice is important. It makes the dataset reflect content that models are plausibly trained on, rather than a generic snapshot of the web. It also enables year-by-year and language-by-language audits over a corpus that has already undergone quality filtering and deduplication.

The analysis has three layers. First, a corpus audit quantifies the prevalence of state media in English and multilingual web data, including temporal trends, language distributions, and the balance between controlled and independent outlets. Second, a content study uses Russian and Ukrainian state media as a case study, applying decontextualized fact extraction and information pursuit to compare coverage patterns and territorial narratives. Third, a system-level analysis places these sources into a RAG setup on the BorderLines territorial-dispute benchmark to test how retrieval over state media affects model responses across languages and target audiences.1c:T605,Four findings stand out. First, in English web crawls, the share of state media pages coming from editorially controlled outlets rises sharply over time, from 39% in 2013 to 93% in 2025. This suggests that the English-language state media slice entering open-web corpora has become increasingly dominated by more tightly controlled sources.

Second, in several low-resource languages, state media accounts for a nontrivial share of all web data. The paper reports values up to 17.8% for Uyghur. For multilingual pretraining, this is important because when the total amount of web text is small, source concentration can have a much stronger effect on the learned distribution.

Third, the Russia-Ukraine case study shows that the issue is not merely ideological disagreement. Russian English-language state media covers international affairs broadly, while Ukrainian state media is more focused on Ukrainian affairs. On topics such as Crimea, the extracted factual claims and narrative framing diverge in systematic ways. On the tokenizer side, the authors propose both modular BPE and modular Unigram schemes. The objective is to train a large multilingual tokenizer from which one can extract subtokenizers for any language or language subset. The challenge is not simply concatenating language-specific vocabularies. A naive union would break consistency in token IDs, merge rules, or token probabilities, and the extracted subsets would not necessarily preserve monolingual-like compression. The paper therefore designs the tokenizer training process so that language-specific components remain extractable while preserving byte-level fallback and lossless detokenization. The fact that the framework works for both BPE and Unigram is important; it suggests the idea is not tied to one tokenizer family.

On the model side, the key idea is to expose the model during pretraining to many different subtokenizer combinations. These subtokenizers are sampled and used to form batches, so the same backbone learns to read and predict text under varying token inventories. In each case, the input embedding and output prediction operate only on the active sub-vocabulary. At deployment time, this allows the system to load only the rows of the embedding/output matrices relevant to the target language subset, instead of the full multilingual vocabulary. The efficiency gain comes from two places: shorter sequences for the target languages and a smaller softmax/output layer.

Compared with standard multilingual tokenization, the difference is threefold. First, conventional approaches bind language coverage and output-layer cost into one fixed vocabulary; this framework decouples shared training from specialized deployment.
