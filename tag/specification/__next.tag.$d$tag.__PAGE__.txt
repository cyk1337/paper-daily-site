9:T551,The key move is to decompose identifier hints into two orthogonal design choices. Identifier selection decides which program entities are revealed: edited files, new functions, classes, attributes, and so on. Identifier projection decides how much of each selected entity is exposed: name, signature, location, semantic description, behavioral guidance, etc. Existing benchmark hint schemes often entangle these choices, making comparisons hard to interpret.

Within this framework, the paper proposes DefUse for selection and Declaration for projection. DefUse targets identifiers that sit on the interaction boundary between implementation and tests, rather than disclosing every new component in the reference solution. This is a narrower objective: remove hidden interface mismatch, not reveal internal design. Declaration then exposes declaration-level attributes of those entities, such as names, signatures, and locations, while avoiding semantic descriptions or implementation hints that would move closer to the reference design.

The paper also introduces an LLM-based assessment layer to score whether a hint attribute is necessary for task resolution, whether it discloses reference-solution information, and whether it guides behavior beyond interface clarification. That judge is used as a complement to execution-based success, not a replacement.a:T42f,The experiments span five repository-level coding benchmarks across Python and Java, evaluated with three language models. The paper’s emphasis is not on a single best score, but on controlled comparisons between selection policies and projection policies.

The main empirical finding is that higher solve rates can coincide with greater disclosure of implementation choices. In other words, some hint schemes improve benchmark performance not merely by removing unfair ambiguity, but by leaking parts of the solution. The controlled setup shows that both axes matter: which identifiers are selected and which attributes of those identifiers are projected can each materially change measured task resolution.

Attribute ablations further separate the effects of names, signatures, locations, and semantic descriptions.
