Self-Pruned Key-Value Attention: Learning When to Write by Predicting Future Utility

这篇工作处理的是长上下文解码里的一个老问题：KV cache 的瓶颈已经越来越像内存带宽问题，而不是算力问题。现有方法大多只在“读”的时候做稀疏化，或者在预填充后做事后驱逐；前者省 FLOPs 但不省显存，后者容易出现训练-推理失配，因为模型表征并没有为被裁剪的缓存而适配。作者要解决的是：能不能在写入 KV cache 的时候就学会“哪些 token 值得进入长期记忆”，并且只用标准 next-token 训练信号完成联合学习，而不依赖额外监督或冻结模型后的校准。

评Meta提出的动态KV剪枝方案训练成本低，适配现有模型，做推理优化的团队可参考§3的联合训练方法做内部验证。

End-to-End Autoregressive Image Generation with 1D Semantic Tokenizer

该工作解决的是 AR 图像生成中的 tokenizer-生成器错配问题。传统 2D grid tokenizer 保留空间结构，但和单向 next-token factorization 不完全匹配；已有 1D tokenizer 更适合 AR，却常为压缩率牺牲重建质量；两阶段训练又让 tokenizer 只优化重建，无法直接接收生成质量的反馈。

评打破了 AR 图像生成两阶段训练的 prior，端到端联合优化 tokenizer 和生成模型，对多模态统一建模极具启发，必读。
