5:T41d,Standard MoE-LoRA writes the adapted weight as W = W0 + Σ g_i B_i A_i, where A_i projects from d dimensions to rank r and B_i maps back. With scalar gates g_i, the router controls magnitude but not orientation; the spatial contribution of each expert is fixed by B_i A_i. A more expressive alternative would be W = W0 + Σ B_i G_i A_i with an r×r transformation G_i per expert, but a fully general G_i is still relatively expensive.

RotMoLE constrains G_i to be a rotation-style transform. For rank 2, a single angle θ_i defines a 2D rotation matrix directly. For r > 2, the method uses a small number of extra parameters to define a temporary rotation plane for each expert, then constructs an r×r rotation matrix R_i within that plane. The final form becomes W = W0 + Σ g_i B_i R_i A_i. The point is to add directional flexibility without paying for a full unconstrained transformation. The extra parameter count stays small: on the order of dn for rank 2 and (d+r)n for higher ranks, rather than learning large dense transforms for each
