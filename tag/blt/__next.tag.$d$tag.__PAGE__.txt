a:T47f,The main experimental tool is Byte Latent Transformer, because it can vary compression rate without changing vocabulary size. BLT first aggregates byte-level inputs into latent tokens with a local encoder, applies a global Transformer over those latent tokens, and then uses a decoder to predict bytes. This separates compression rate from vocabulary size and avoids the confounding present in subword tokenizers, where token boundaries, vocabulary, parameter count, and compression are coupled. The authors modify the original BLT setup by removing byte n-gram hash embeddings, since such n-grams can span more bytes than a latent token and would interfere with controlled compression. They also adjust the scaling of local modules, favoring width over depth. The scaling analysis then fits laws that include compression rate, comparing data measured in tokens with data measured in bytes. Additional subword-tokenized Transformer experiments test whether the trends are specific to BLT. Multilingual experiments use parity, the byte-length ratio of parallel sentences across languages, to explain shifts in optimal data ratios and compression rates.b:T4a3,The experimental sweep is substantial: 988 BLT models are trained, ranging from 50M to 7B parameters, across multiple target compression rates. The paper explicitly compares this range with common subword regimes, including a popular BPE tokenizer at about 4.57 bytes per token on English DCLM-like text and SuperBPE at about 6.16 bytes per token. The key empirical finding is that, along the compute-optimal frontier, parameter count scales with training data measured in bytes rather than tokens. Equivalently, increasing compression should reduce the optimal tokens-per-parameter ratio. The experiments also show that compression is not free. Higher compression shortens the global sequence and reduces Transformer FLOPs, but each latent token must represent more bytes, increasing local modeling burden and prediction difficulty. This leads to an optimal compression region under a fixed compute budget rather than a monotonic preference for maximum compression. The subword experiments are used as a sanity check against the BLT-only interpretation, while the multilingual experiments show that byte parity matters when transferring English-derived scaling rules to other languages.c:T526,The starting point is BLT: a local encoder processes bytes, an entropy-based patcher forms variable-length byte patches, a global model operates over latent patch representations, and a local decoder emits bytes. The paper introduces three mechanisms. BLT-D trains the decoder with both the standard next-byte prediction loss and a masked-byte prediction loss over corrupted fixed-size byte blocks. These blocks are derived from dynamically segmented patches but may cross patch boundaries, forcing the decoder to model future bytes beyond the average patch length. At inference time, a block of byte positions is initialized as masked and multiple positions are iteratively revealed per decoder step, reducing calls to the decoder, encoder, and global model. BLT-S is a self-speculative variant for standard BLT: the lightweight local decoder drafts bytes past the usual patch boundary, and the full BLT computation verifies the draft. Because rejected drafts roll back to the first mismatch, it preserves the output of standard autoregressive BLT while reducing expensive global evaluations. BLT-DV uses BLT-D’s dual training objective: diffusion decoding proposes a byte block, and the same model, run with causal masks, verifies it autoregressively.
