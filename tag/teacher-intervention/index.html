PIVOT: Progressive Intervention via Online Teacher Correction

这篇工作处理的是 RLVR 在高难推理任务上的一个老问题：当学生策略几乎采样不到正确解时，只有 outcome-level 的二值 verifier reward，组内所有 rollout 都是 0，GRPO 一类方法就没有有效优势信号，训练会停在“不会做所以学不到”的状态。作者进一步指出，单独引入 teacher 也不够，因为 teacher 信号有两种不同作用：一类是把训练轨迹拉到更可能成功的区域，解决“采不到正样本”；另一类是给局部 token 提供稠密监督，解决“即使有好轨迹，学生也未必学得会”。如果只做前者，teacher 轨迹可能偏离学生分布，难以模仿；如果只做后者，学生已经走偏时，局部蒸馏也救不回来。论文的核心问题就是：怎样把 teacher 纠错同时用于轨迹构造和 token 监督，让 RLVR 在 hard reasoning 上真正获得可学习信号。

评探讨了在 RL 阶段如何优雅地引入 teacher 信号（干预+KL监督）来解决 sparse reward 问题，对当前做 reasoning RL (如 R1-Zero 范式) 遇到瓶颈的团队很有参考价值。

ATI-OPD: Adaptive Teacher Intervention for Stable Long-Sequence On-Policy Distillation

这篇工作处理长序列 on-policy distillation 的训练不稳定问题：学生模型在自己生成的长推理前缀上逐步偏离教师模型，导致教师对后续 token 的监督质量下降，进而放大学生已有偏差。

评只看方法图和分歧检测细节；前缀修补比后缀降权更像是在修数据分布，这个 prior 值得进长推理蒸馏 ablation。

From Dissonance to Orchestration: Teacher Intervention in On-Policy Distillation

这篇论文研究 on-policy distillation 中教师何时、介入多深才有利于学生学习。核心矛盾是：教师接管生成可以修正学生早期推理错误，提高 rollout 质量；但教师生成的前缀会把训练分布推离学生当前策略，增加 off-policy 负担。只看生成答案是否更准，并不能决定教师介入策略。

评深入探讨了 On-Policy Distillation 中教师干预的 trade-off，提出的动态干预策略对优化 RL/SFT 数据合成流程有启发，建议关注其策略分歧分数的计算方法。
Yuhao Wang,Ruiyang Ren,Yinan Zhang,Ruiqing Zhang,Jing Liu,Chunyan Miao
