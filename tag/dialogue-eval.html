Dialogue SWE-Bench: A Benchmark for Dialogue-Driven Coding Agents

这篇工作要解决的问题很明确：现有 SWE-Bench 一类代码 agent 评测，把任务设成“拿到完整 issue 后自主修复仓库”，但真实使用里，问题描述常常不完整，用户会不断补充、纠正、拒绝方案。于是现有 benchmark 测到的主要是自治修复能力，而不是交互式澄清、需求对齐、边做边问的能力。论文把 repository-level 软件修复任务重写成 dialogue-driven setting，核心不是再造一个 coding benchmark，而是把“对话是否帮助 agent 获得缺失规格、减少误解、最终产出可通过测试的 patch”变成可自动评测的问题。

评把“交互式澄清”从 demo 拉回可自动评测，方向是对的；读数据构造+user simulator 设计即可，别太相信 3-14% 的绝对数（模拟器偏置风险）。
Brendan King,Jeffrey Flanigan
