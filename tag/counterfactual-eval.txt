18:T61d,The method has two layers. The first is PriVE-Bench, a counterfactual benchmark built around prior-versus-evidence conflicts. Each example contains an original image and a counterfactual image. The original conforms to common expectations, while the counterfactual violates a canonical attribute, count, part, or modality expectation. The benchmark spans five domains: object existence, counting, fashion attributes, industry/common-object attributes, and medical modality consistency. Each item defines both a visually correct answer and a prior-consistent biased answer, so model outputs can be categorized as correct, biased, or other rather than only correct or incorrect.

The second layer is PriVE-Tools. Instead of evaluating a free-form visual agent, the paper converts common visual operations into controlled evidence conditions: bounding-box overlays, crops, zoom panels, and contour overlays. The key design choice is to keep the underlying image, question, correct answer, biased answer, and scoring rubric fixed while changing only the evidence presentation. That isolates whether the evidence view itself helps the model use visual information.

The evaluation protocol includes original-only, counterfactual-only, and paired-image inputs, and supports yes/no, multiple-choice, and open-ended questions. Metrics include accuracy, prior-following error rate, and other-response rate. Third, tool-derived evidence views are model-dependent: in the reported evaluations, closed-source VLMs benefit more consistently from crops and zoom panels, while several open-source models show weak or even negative aggregate effects.

The important interpretation is that the bottleneck is not only visual access. In many cases, the relevant evidence is made more explicit, yet the model still does not revise its answer.
