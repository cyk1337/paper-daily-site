PACE: Periodic and Channel-Aligned Encoding of Four-Bit Recurrent States

这篇工作处理的是线性注意力语言模型在推理阶段的一个很具体、但很影响部署的问题： recurrent state 要为每个并发序列各存一份，显存占用会随并发数线性增长。已有状态量化方法通常在每个生成 token 后都把状态重新量化一次，四比特下误差会持续注入并沿递推累积，所以精度掉得明显，往往需要升到 8-bit 或做额外微调。PACE 的核心问题不是“如何发明一种更复杂的量化器”，而是“如何改变状态被量化的时机和分组方式，让 4-bit 在不训练的前提下也能可用”。

评如果你在看线性注意力/状态空间 LM 的 serving，这篇值得读；核心不是新量化公式，而是“少量化几次比每步都量化更干净”这个误差模型，先看方法图和误差分析即可。

Low-Bit Recurrent States in Hybrid Language Models

这篇论文研究 hybrid language model 中固定大小 recurrent state 的低比特量化问题。不同于 KV cache，recurrent state 的量化误差会在后续 token 中持续传播；衰减慢的通道会保留误差更久，衰减快的通道会更快消散。因此，简单按当前范围做均匀量化会把 bit 分给不该优先保护的通道。
