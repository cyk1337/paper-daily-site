9:T4bd,DecoMoE applies structured compression along two dimensions. The Sample-Adaptive Visual Boundary predicts, for each input, the layer at which full visual-token propagation can stop. A lightweight gate reads hidden states at candidate sparse layers; if triggered, it removes the whole visual-token block before self-attention in that layer, turning subsequent computation into text-only processing. The gate is trained with supervision from forced-exit correctness and first-token negative log-likelihood while keeping the multimodal backbone frozen. The Routing-Calibrated Expert Prefix compresses expert computation. It first calibrates expert importance offline using text-token routed mass, orders experts layer by layer with a Mean-Mass criterion, and physically reorders router outputs and expert parameters so that important experts form a contiguous prefix. At inference time, each layer keeps the shortest prefix that covers a target fraction of the current activated routed mass, and native token-wise Top-k routing is restricted to that prefix.
