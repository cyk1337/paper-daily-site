第二层是把优化器行为统一解释为“记忆时间尺度”问题。论文把 momentum 的 EMA 和记忆窗口联系起来：固定 β 对应固定 memory horizon；β 越接近 1，历史梯度保留越久。weight decay 则从参数遗忘的角度进入分析：在 decoupled weight decay 下，参数本身也像是对历史更新做指数衰减平均，因此 weight decay 也对应一个参数级 memory window。这样一来，momentum、二阶矩 EMA、weight decay、learning-rate decay 都可以放到“训练过程中系统记忆如何变化”的框架下讨论。

The second layer is a memory-timescale interpretation of optimization. Constant momentum implies a fixed effective memory window over past gradients. Weight decay is treated analogously, but at the parameter level: under decoupled weight decay, parameters forget past updates exponentially, so weight decay also defines a memory timescale. This framing lets the paper discuss momentum, second-moment averaging, weight decay, and learning-rate decay in a common language of memory and forgetting over training time.

The third layer is recipe adaptation. Several findings stand out. Preferred learning-rate schedules are not invariant across OT; short and long horizons may favor different schedules, and the preference can reverse. Optimal weight decay is not constant either; empirically it scales roughly like sqrt(OT). For fixed-memory optimizers, longer horizons generally prefer longer momentum memory, but the optimal learning rate then decreases, so memory and LR must be tuned jointly. The paper also introduces a momentum cooldown rule for ADANA during terminal learning-rate decay. The intuition is simple: if the learning rate is shrinking while the optimizer memory keeps growing, the optimizer can become overly anchored to stale gradient information late in training. Bounding the memory timescale in the cooldown phase improves final performance, especially when combined with log-time weight decay.
