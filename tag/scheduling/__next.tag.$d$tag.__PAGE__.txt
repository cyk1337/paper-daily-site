It tracks per-rank token memory footprints in real time, uses semaphores to control KV cache preemption priority, and actively pins KV caches for multi-turn tasks expected to resume soon, eliminating redundant prefill overhead from cache eviction during idle periods; 2) Resource-Aware Ref-Actor Pipelining (RA²P), which abandons fixed ref-actor execution modes on training nodes and dynamically switches between two modes based on current ready backlog size and data arrival interval: decoupled streaming mode places ref and actor on separate GPUs for large backlogs and fast arrival to avoid weight swapping thrashing, while colocated aggregation mode lets ref and actor share GPU memory for small backlogs and slow arrival to reduce cross-node communication. Request-level pause/resume is expensive because pausing a request forces a decision about its KV state: keep it resident and consume memory, or evict it and later pay restoration cost. In branch-parallel decoding, sibling branches share the request’s prefix KV, while each branch’s private KV only covers the tokens generated on that branch so far, typically much smaller than the shared prefix. Therefore, deferring a branch for one step mostly means withholding compute from that branch; it does not require reclaiming the shared prefix and usually does not require evicting the branch-local KV. Re-admission in a later step is cheap. On top of this structural property, the paper introduces TAPER. The controller first guarantees single-token progress: every active request contributes exactly one token to the next step. Additional branches are then treated as opportunistic width and admitted only if the predicted branch externality fits within the current batch’s slack budget. This requires a per-step latency/externality predictor and a greedy planner that chooses which extra branches to admit. The utility interface is pluggable, so the planner can target different objectives such as throughput, goodput, or SLO attainment. Compared with eager admission, TAPER does not realize all available branch parallelism by default. Compared with fixed caps, it does not rely on a static width k. The main idea is to move admission control to decode-step granularity and exploit the cheap reversibility of branch deferral.d:T534,The evaluation uses Qwen3-32B under mixed workloads and compares TAPER against IRP-OFF, IRP-EAGER, and fixed-width baselines.
