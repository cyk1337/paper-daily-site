RuBench: A Repository-Level Agentic Coding Benchmark with Natively Authored Russian Task Specifications

这篇工作要解决的问题很明确：现有 repository-level coding agent benchmark 几乎默认任务描述是英文，而真实用户常用母语、且表达方式更像客户需求而不是 GitHub issue。RuBench 试图测量的不是“模型会不会修代码”这一泛问题，而是“产品级 coding agent 在真实仓库中，面对原生俄语、客户式需求描述时，能否正确恢复意图并完成修复”。

评把“非英语自然任务陈述”做成 repo-level、用回归测试硬判定，这个评测缺口真实存在；只看数据构建与污染论证部分，结果排名别太当真。
Evgeny Shilov

Forecasting Scientific Progress with Artificial Intelligence

这篇工作要解决的问题不是“模型会不会做科学问答”，而是更难的一层：在严格时间截断下，模型能否基于某个时点之前可获得的知识，去预测之后会不会出现某项科学进展、会以什么机制实现、何时实现。作者认为现有工作大多评估 scientific reasoning 或 hindsight explanation，却没有真正评估 temporally grounded scientific forecasting。CUSP 的目标就是把这个能力拆成可验证、可量化、可控知识边界的评测任务。

评读数据构造和 temporal cutoff 设计即可；它是评测资产，不会直接改训练 recipe。
