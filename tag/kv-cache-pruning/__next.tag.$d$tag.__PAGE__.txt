9:T463,VisCache is a two-stage coarse-to-fine, training-free framework.
1) Input-stage temporal filtering: a lightweight vision-language “scout” model selects prompt-relevant keyframes before running the main VLLM. Selection uses Maximal Marginal Relevance (MMR) to balance query relevance and diversity, aiming to keep semantic coverage with fewer frames.
2) In-model KV pruning (PruneKV): a layer-aware visual KV compression algorithm.
- Layer-wise budget allocation: instead of uniform pruning, it uses a parabolic schedule—retain more visual tokens in early layers (fine-grained spatial details) and progressively fewer in deeper layers (more abstract semantics), evicting KV entries beyond a truncation threshold.
- Asymmetric K/V handling: keys are treated as routing/indexing signals and can be dropped more aggressively; values carry content, so values corresponding to pruned keys are fused into retained values via weighted aggregation to reduce hard information loss.
