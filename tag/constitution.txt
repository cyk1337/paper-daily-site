18:T43a,The method has two stages. First, Model Spec Midtraining trains the model on synthetic documents generated from a Model Spec, using Claude Opus 4.6 to produce documents that discuss, explain, and unpack the spec. This stage is intended to teach the model what kind of assistant it should be and why the rules matter. Second, standard alignment fine-tuning trains the model on demonstrations of spec-aligned behavior. The difference from ordinary AFT is that AFT only shows behavior and can leave the intended latent value ambiguous, while MSM installs a semantic frame that determines how the same demonstrations should generalize. It also differs from deliberative alignment at inference time: MSM changes the model’s trained tendencies rather than only asking the model to reason over rules during deployment. The paper further uses MSM as an empirical tool for Model Spec science, testing which spec properties affect generalization. Specs that explain the values behind rules or provide more detailed subrules outperform broad guidance such as having good values and judgment.19:T480,The experiments cover three main settings.
