Kolibri: A Sovereign European Model on the Pareto Frontier

Kolibri 解决的不是单点技术问题，而是一个完整的基座模型设计问题：在欧洲主权部署、德英双语、受监管行业适配这些约束下，如何做出一个开源、可部署、训练成本可控、同时在质量与效率上都站得住的中大规模 MoE 模型。论文真正要回答的是一组相互牵连的预训练问题：数据如何配比，tokenizer 如何兼顾德语形态学，MoE 稀疏度如何选，混合注意力如何在长上下文与解码效率之间取平衡，训练流程如何从 pretrain 接到 mid-train 和 long-context extension，并最终把这些选择整合成一个 Pareto 上可解释的系统。

评把它当“MoE+高德语占比+多阶段训练”的可落地配方看：重点抄数据配比/长上下文扩展与RL闭环，别只盯榜单。

EXAONE 4.5 Technical Report

在工业级真实场景中，LLM 需要同时具备强语言能力、强推理能力与视觉理解能力；但 VLM 面临“高分辨率带来海量视觉 token → 计算/吞吐瓶颈”和“压缩视觉 token 又会显著掉点”的矛盾。论文要解决的是：在不牺牲视觉信息密度的前提下，把视觉能力高效、稳定地接入一个已具备双模式（非推理/推理）的 32B 语言底座，并保持可部署的推理效率与多语种能力。

评重点翻训练配方与视觉token吞吐优化细节：能直接对照你们的VLM工程取舍；但作为tech report，结论更像系统集成经验，别当因果证据。
