Automatic processing is fast, stimulus-driven, and robust to interference. Controlled processing is more context-dependent and more sensitive to lag and disruption. To operationalize this for LLMs, the authors run two experiments.

Experiment 1 is semantic categorization. Models receive a zero-shot prompt and classify a concrete noun as living or nonliving. Each target word appears four times within a session, with a fixed number of filler trials between repetitions, producing lag conditions of 1, 3, 7, and 15. The authors measure a log-probability margin for the classification decision and define priming as the change from the first exposure to later exposures. This isolates the processing benefit of repetition from raw task accuracy.

Experiment 2 is cloze completion, where weakly constraining contexts test whether repeated exposure helps open-ended retrieval of the target word. This is closer to real generation behavior than binary classification.

The strongest part of the paper is the set of mechanistic probes. First, prior response context is removed to see whether priming survives. If base models retain facilitation, that suggests partial word-level reactivation rather than full dependence on the original context. Second, classification labels are remapped to test whether priming transfers beyond a specific output template. Third, attention heads associated with prior-occurrence retrieval are identified and ablated to test whether priming depends on those circuits. These probes support the interpretation that base-model priming is more stimulus-driven, while instruct-model priming depends more on contextual reevaluation.

This is different from standard probing work.
