6. 证据预算与 verifier：在两个语言模型 verifier 上，作者用“claim 需要多少 bits、evidence 提供多少 bits”的比较恢复了 Trace Budget adjudicator，区分支持证据与不足证据的 AUROC 达到 0.91。这里虽然不是预训练实验，但对 reasoning verifier 和 evidence sufficiency 分析有直接启发。a:T8b0,The core result is an exact decomposition of expected code-length gain from memory. For both context memory and fine-tuned weights, the expected savings split into three terms: (1) information stored about the query, (2) a prior-repair term that corrects the model’s output prior even when the memory does not directly encode query-specific evidence, and (3) decoding loss, which measures how much predictive value is left unused by the decoder given the stored memory. This decomposition is the paper’s main contribution because it cleanly separates what is stored from how well the model reads it out.

On the context side, the value of a context subset is defined by deleting that subset and rerunning the model, yielding an exact leave-one-out valuation for held-out queries. This only requires predictive probabilities and the ability to rerun with partial context, so it applies beyond transformers to occupancy networks, stereo networks, kriging-style learners, and TabPFN-like in-context tabular models.

On the weight side, fine-tuning is treated as writing information into a bounded parameter state. The paper derives capacity-based ceilings for what such a state can save. The decision logic is asymmetric but useful: if measured context gain exceeds the ceiling of any weight state with a given capacity, context is certified as the better channel; if a fine-tuned model exceeds the ceiling of any window-limited context memory, weights are certified as better. A particularly interesting result is that when the relevant evidence fits in context, fine-tuning can add at most the context decoder’s decoding loss. In other words, parameter updates only buy what the context pathway failed to decode, not arbitrary extra information.

The paper also introduces an anytime-valid test for the practical case where exact information terms are unavailable. It accumulates held-out evidence sequentially and controls error at any stopping time. The appendix goes further and writes a transformer KV cache exactly as a form of weight write with query-dependent addressing, which strengthens the claim that context state and parameter memory can be analyzed in one framework rather than merely compared by analogy.b:T95e,The experiments span language, vision, fluid dynamics, and tabular learning. A key methodological choice is the lexical-versus-semantic split. The authors explicitly argue that growing vocabulary is not evidence of broadening conceptual exploration. They therefore track both surface-level diversity and semantic movement across long trajectories. The study spans 10 foundation models, including both open- and closed-weight systems. For five primary models, they run three independent 1,000-round simulations each, and they report 73 tested conditions overall.

The intervention suite is broad: decoding settings and algorithms, prompt variants, memory and retrieval changes, population size and model composition, reduced safety-oriented alignment, sycophancy-targeted activation steering, diversity-oriented RL, multi-agent orchestration, and exogenous semantic perturbations. This breadth is important because the paper is trying to rule out easy explanations. The claim is not merely that a default setup collapses, but that many plausible fixes fail to restore sustained, coherent semantic expansion.

The mechanistic section is the most interesting part. The authors combine transcript-level distributional analysis with white-box attention-head diagnostics. Their proposed explanation is that autoregressive feedback reinforces historically dominant representations. In other words, the system keeps reconditioning on its own high-probability semantic traces, which gradually traps it in a narrower region of concept space. That is a stronger and more structural claim than saying the models are simply sycophantic or over-aligned.11:T46e,The clearest empirical result is a robust lexical-semantic dissociation across 73 conditions. Cumulative vocabulary keeps increasing, yet semantic displacement within a run converges and semantic separation across independent runs remains limited. So the system continues to produce new wording without genuinely moving into new conceptual territory.

A second headline result is that none of the 13 intervention families reliably restores broader and coherent semantic exploration. This includes interventions that many practitioners would expect to help, such as decoding changes, memory modifications, orchestration changes, and attempts to reduce alignment-related conservatism.
