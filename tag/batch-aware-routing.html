BASE: Batch-Aware Selection of Experts Using Predicted Removal Error for Efficient MoE Decoding

这篇工作处理的是 MoE 在批量自回归解码里的一个很具体、也很实际的问题：单 token 稀疏路由并不自动带来 batch 级别的低成本。每个 token 只激活少数专家，但一个 batch 里不同请求选到的专家往往不同，导致该步解码需要加载的专家并集迅速变大。此时瓶颈不再是单 token 的 FLOPs，而是每步从 HBM 向片上 SRAM 搬运多少个专家权重。论文把问题明确化为：在固定 batch expert budget 下，应该为整个 batch 加载哪些专家，才能让 MoE 层输出偏离原始全路由结果最小。

评针对 MoE serving 的痛点（batch 膨胀导致的 I/O 瓶颈）提出了基于预测误差的 batch-aware 路由策略，做 MoE 推理优化的同学值得一看。
Ali Abbasi,Justin Shi,Soheil Kolouri
Vanderbilt UniversityMoEefficient decodingbatch-aware routingarXivPDF
