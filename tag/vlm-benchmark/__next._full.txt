19:T5f0,The contribution is a dynamic curation pipeline plus a four-scenario evaluation protocol.
1) Dynamic parametric filtering: collect heterogeneous KB-VQA samples S0 with x=(q,v,K,a). Query a set of strong open(-ish) VLMs as gating models (Gemma3-27B, Qwen-2.5-VL-32B, InternVL3-38B, VL-Rethinker-72B) in a parametric setting (q,v only, no external knowledge). Use an external judge (GPT-4o with a SimpleQA-style prompt) to label each response as CORRECT / INCORRECT / NOT ATTEMPTED, mapped to Accuracy / Hallucination / Deflection. Keep only items that all gating models fail, yielding S1 intended to be genuinely retrieval-dependent.
2) Context augmentation: for each retained item, attach gold context K(x)^+ and distractor context K(x)^-. If negatives are not provided by the source, mine them via retrieval: build a Wikipedia text index, retrieve with EVA-CLIP, segment passages, and rerank with Contriever; for visual negatives, retrieve top-10 similar non-gold images from an image index.
3) Quality control: enforce solvability with gold context and difficulty/robustness under distractors (details/thresholds appear later in the full paper).
4) Evaluation protocol: define four complementary settings—parametric, oracle (gold context), realistic (retrieved mixed context), adversarial (distracting/contradictory context)—to separate memorization, upper-bound grounding, real-world RAG robustness, and adversarial susceptibility, while explicitly tracking hallucination vs deflection rather than accuracy alone.1a:T4b0,TraversalBench is a controlled benchmark where each instance contains (1) a single continuous polyline, (2) a unique start marker, and (3) markers placed at path vertices; the task is to output the ordered marker sequence encountered from start to finish. Difficulty is explicitly balanced along four interpretable axes:
1) Self-intersection count, discretized by thresholds {0,1,2,4,6,9,13} with finer granularity near zero crossings.
2) Tortuosity, discretized by thresholds {1.0,1.3,2.0,3.0,4.5,6.5,9.0} into six bins spanning near-straight to highly meandering paths.
3) Vertex count (sequence length / path length), with multiple point-count settings to separate length effects.
4) Confounding lines: nearby non-target segments that increase distractor structure without altering the target path.
Generation targets cells in the joint tortuosity×intersection grid, then applies render-aware acceptance constraints (segment length, nonlocal clearance, vertex-to-segment separation) so difficulty is driven by the intended structural factors rather than rendering artifacts.
