18:T8e7,LGM 的方法由三段组成，逻辑比较完整。

第一段是 latent memory disentanglement。作者不直接对原始文本建图，而是先用 backbone LM 的多层 hidden states 表示每条历史 interaction 和当前 query，再把这些 dense representation 映射到共享低维空间。之后引入 sparse autoencoder，把稠密表征分解成稀疏概念激活。这样做的意图有两层：一是把显式偏好和隐式行为线索投到同一概念坐标系里，便于后续关联；二是用稀疏性降低噪声和混叠，让每条记忆不再只能作为整段文本被检索，而是能以概念级别参与组合。

第二段是 query-conditioned latent graph construction。这是和 GraphRAG 最不同的地方。LGM 不维护一个固定全局图，而是根据当前 query 与 memory 的概念共激活情况，动态构造潜图并决定边权。也就是说，同一批历史记忆在不同 query 下会形成不同的连接拓扑。随后作者用 relational GNN 在这个激活子图上做消息传播，把分散在多条历史中的弱证据聚合成紧凑 graph state，同时得到节点级 relevance score。这里的 neuro-symbolic 味道主要体现在：symbolic 的部分是概念节点和关系结构，neural 的部分是概念抽取、边权生成和图上传播都可微。

第三段是 graph-conditioned reasoning。传播后的 latent graph state 不直接作为最终答案，而是被映射成一小组 memory prefix tokens，用来条件化下游生成。这样可以避免把大量原始历史文本重新塞回上下文。为了防止 latent 推理脱离事实，作者又加了 evidence-reconstruction objective，要求压缩后的状态仍能重建或对齐支持性证据，抑制多步传播中的 information collapse。全文强调 selection、association、aggregation、utilization 这几个阶段是端到端联合优化的，而不是先检索、再建图、再生成的松耦合流水线。

和常见 RAG 相比，LGM 的关键差异不是“多了个图”，而是把图构造从文本空间移到了 query-conditioned latent concept space；和静态 GraphRAG 相比，它的图不是预先固定的；和单纯 memory summarization 相比，它保留了可追溯的节点相关性和证据重建约束。19:T40f,The paper addresses long-term memory use in personalized agents, but not through the usual prompt replay or retrieval-only framing. Its central question is whether long interaction histories can be disentangled and organized in latent space before generation. The authors argue that existing approaches break down in two ways. Flat retrieval scores memory fragments independently and misses distributed evidence across sessions. Structured memory systems such as GraphRAG build graphs, but those graphs are usually query-agnostic and static, so they cannot adapt relations to the current request. Raw textual memories are also entangled by nature: one interaction may mix topic, preference, sentiment, and behavioral cues. Replaying all of this at the text level is expensive, noisy, and hard on context length and KV cache. The core problem is therefore how to perform query-aware memory disentanglement and relational reasoning without repeatedly replaying the full textual history, while still staying faithful to the original evidence.1a:T96b,LGM consists of three tightly connected stages.

The first is latent memory disentanglement. Instead of building structure directly over raw text, the method extracts multi-layer hidden states from a backbone LM for each historical interaction and for the current query, then maps them into a shared low-dimensional space. A sparse autoencoder is applied to decompose these dense representations into sparse concept activations. This serves two purposes: it places explicit preferences and implicit behavioral evidence into a common concept space, and it reduces entanglement so that memories can participate at the concept level rather than only as whole text chunks.

The second stage is query-conditioned latent graph construction, which is the main departure from GraphRAG. LGM does not maintain one persistent global graph. Instead, it dynamically constructs a latent graph based on concept co-activation between the query and the memory pool, with edge weights determined on demand. The same historical memory bank can therefore induce different graph topologies for different queries. A relational GNN then propagates signals over the activated subgraph, aggregating weak clues scattered across sessions into a compact graph state and producing node-level relevance scores. The neuro-symbolic aspect comes from combining symbolic structure at the concept-and-relation level with differentiable concept extraction, edge formation, and message passing.

The third stage is graph-conditioned reasoning. The resulting latent graph state is mapped into a compact set of memory prefix tokens that condition downstream generation, avoiding raw-text replay. To keep latent reasoning anchored to actual evidence, the model adds an evidence-reconstruction objective, which penalizes information loss and helps prevent collapse during multi-step propagation. The paper emphasizes that memory selection, association, aggregation, and utilization are optimized end to end rather than as a loosely coupled retrieve-then-generate pipeline.

Compared with standard RAG, the key difference is not merely adding a graph, but moving graph construction from text space into a query-conditioned latent concept space. Compared with static GraphRAG, the graph is dynamic. Compared with memory summarization, the method preserves node relevance and introduces an explicit faithfulness constraint through evidence reconstruction.1b:T5a5,The experiments cover PersonaMem, PrefEval, and the implicit-preference split of PersonaMem-v2, using Qwen2.5-7B, Gemma3-4B, and Qwen3-4B as backbones. The main result is that LGM achieves the best average accuracy under the main backbone settings, with the largest gains on implicit-preference and long-context cases. That pattern is consistent with the method: these are exactly the settings where success depends on combining weak evidence distributed across sessions rather than retrieving one obvious memory fragment.

The paper also stresses efficiency. Relative to methods that rely on repeated text replay or multiple LM calls over structured memories, LGM sits on a favorable frontier in LM calls, token usage, and time to first token. In other words, the gains are not presented as a pure compute-for-accuracy trade.

From the full-text description, the ablations likely test the contribution of each module. Removing the sparse autoencoder should make the concept space noisier and hurt implicit preference inference. Replacing the dynamic graph with a static one should weaken multi-hop evidence integration. Removing the evidence-reconstruction objective should make latent propagation drift and reduce faithfulness. The excerpt provided does not include the full numeric tables, so exact percentages should not be fabricated, but the paper clearly positions itself around a dual objective: higher accuracy and lower inference cost.1c:T4c0,This is a skim paper. 1. TypeCompact: in-place budget reduction with type-specific fidelity policies instead of uniform summarization.
