AViTS: Adaptive Spatiotemporal Token Selection for Efficient Dynamic-Resolution Generation

这篇工作处理的是动态分辨率 DiT 推理里的一个具体瓶颈：从低分辨率阶段切到高分辨率阶段时，是否有必要把所有 latent token 一起上采样并进入高分辨率计算。作者的判断是否定的。全文给出的证据是，低分辨率去噪过程中 token 重要性在空间和时间两个维度都高度不均匀：一部分 token 与文本条件强相关，另一部分 token 在跨步演化中变化更剧烈、对后续更新更敏感。若仍然统一上采样全部 token，会把算力浪费在语义边缘区域和已趋于稳定的区域上，同时还可能在阶段切换时引入细节不一致。论文要解决的核心问题，就是在有限高分辨率预算下，如何更可靠地识别“应该优先升采样”的 token，并把高分辨率计算集中到这些位置。

评读方法动机即可：token级预算分配比统一上采样更合理，但这是DiT推理工程，不要误读成通用LM训练结论。
