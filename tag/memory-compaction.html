Governance Decay: How Context Compaction Silently Erases Safety Constraints in Long-Horizon LLM Agents

这篇论文讨论长程 LLM Agent 中的一个安全失效面：上下文压缩会把原本在上下文里的治理约束压掉，导致模型在压缩前遵守规则、压缩后执行违规工具调用。问题不在模型权重变化，也不依赖越狱提示，而在 Agent harness 的记忆管理策略通常只优化任务连续性，没有把组织策略、运行时规则、长期 memory 这类非 system-channel 约束当作必须保留的状态。

评这篇不改预训练范式，但它把“memory compaction 是安全边界”说得很清楚；只看 benchmark 设计和那组 0%→30%→59% 的对照就够，适合拿来约束你们的长程 agent 训练设定。
