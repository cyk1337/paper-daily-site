Affix Cache for Diffusion Large Language Models

这篇工作解决的是 diffusion LLM 推理里的一个具体瓶颈：如何像 AR 模型那样复用缓存，但又不被双向注意力带来的 stale KV 问题拖垮。AR 模型的 prefix cache 之所以好用，是因为历史 token 的表示不会被未来生成 token 反向影响；而 DLLM 在每一步去噪时做全局双向注意力，连共享 prompt 或中间固定片段的 KV 都会随着待生成 token 的变化而变化。直接复用会掉质量，完全重算又太贵。ACache 的问题定义很清楚：在保证生成质量的前提下，只重算真正关键的 affix tokens，其余共享 span 的 cache 尽量复用。
