b:T7df,The method has two key layers. First is the modeling choice: memory is a separate parametric policy π_mem rather than a memory bank. The input is the current context x=(q,o), where q is the task specification and o is the environment observation. The output is either a short textual guidance m inserted into the downstream agent context, or an abstention decision. This decouples specialization from execution: a smaller model can specialize as memory, while a larger frontier agent remains the executor.

Training is done in two stages. Stage one is experience distillation. The authors build an offline experience bank E={(x,m)} and train π_mem with supervised learning to reproduce reusable guidance from context. This compresses the experience bank into the memory model parameters. Stage two is adaptation distillation, where reinforcement learning optimizes the memory policy directly against downstream task outcomes.

The main technical point is the decision-content decoupled objective built on GRPO. For the same context, the training procedure constructs structured counterfactual rollouts that compare at least two branches: generate guidance versus abstain. Within the generate branch, different candidate guidance contents are also compared. This lets the learning signal be decomposed into a decision-level advantage for whether memory should be generated, and a content-level advantage for what the guidance should say. Without this decomposition, a standard sequence-level policy gradient would conflate two failure modes: generating when it should not, and generating the wrong content when it should. That decomposition is the most important idea in the paper.

From a systems perspective, Mem-π is not an always-on helper. It is a selective intervention policy with abstention as a reliability mechanism. The paper explicitly argues that under weak grounding, ambiguity, or OOD contexts, bad generated memory can harm the downstream agent. That makes abstention central rather than optional.c:T60a,The evaluation spans four agent benchmarks: WebArena, WorkArena, LifelongAgentBench, and ALFWorld, covering web navigation, enterprise workflow tasks, terminal tool use, and text-based embodied environments. The headline result is that adaptive memory generation consistently beats retrieval-based memory baselines on all four benchmarks, with roughly 20% average relative improvement over the base agent and nearly 50% relative gain on WebArena. The pattern suggests that generated memory is especially useful when tasks are long-horizon, multi-stage, and strongly context-dependent, where experience recomposition matters more than nearest-neighbor reuse.

The most informative ablations are likely threefold. First, the two-stage training pipeline: supervised distillation alone can produce plausible guidance, but RL is needed to align memory generation with actual task success. Second, the decision-content decoupling: removing it should lead to over-generation or unstable abstention behavior. Third, comparisons against retrieval memory, always-on generated memory, and the no-memory base agent clarify that the gain comes from selective generation rather than merely adding another model.

The paper emphasizes relative gains more than scale. It is not trying to win by sheer parameter count or data volume. The interesting evidence is in trigger rates, abstention rates, guidance length, and the measured harm from bad guidance.
