18:T5aa,The proposed method is NR-SAE, a native-router sparse autoencoder. Each routed expert owns a small dictionary. When the frozen MoE router selects an expert for a token, the corresponding dictionary is opened; dictionaries for unselected experts are not scored. This differs from global SAEs over the summed MoE output and from approaches that learn a separate auxiliary router for the SAE.

The paper tests the factorization at two seams. In the reconstructive seam, the SAE receives a selected expert’s raw output yt,s and reconstructs it. In the predictive seam, a transcoder receives the common MoE input xt and predicts the selected expert’s output. The first setting tests whether expert outputs admit expert-local dictionaries; the second tests whether these dictionaries can capture the expert’s computation from its input.

The controls are carefully designed. Layout A is the native router-addressed design: 128 experts, each with a 512-feature bank; with eight routed experts per token, a token sees 4,096 candidates and selects 32 slots. Layout F matches A in total stored features and parameters but uses rank banks with many more candidates per bank. Layout B matches A in visible candidate count but groups by routing rank rather than expert identity.
