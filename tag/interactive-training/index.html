Agent World Model in the Wild: Computer-Use Agent Environment Synthesis

这篇工作要解决的不是“如何再做一个电脑操作 benchmark”，而是更前面的供给问题：如果想用在线交互和 RL 训练通用 computer-use agent，训练环境从哪里来，怎样大规模生成，怎样保证任务真的可做、足够难、奖励可信，而且不把训练直接放到真实互联网和真实个人电脑上。作者把问题定义为可执行个人电脑世界的合成：环境里同时有 GUI、CLI、MCP 服务和本地文件，任务需要跨接口完成，而不是只在浏览器或单一工具调用接口里做短流程操作。

评把它当“交互式agent预训练数据工厂”看：重点读环境可执行性约束与接口统一那几节；若规模/真实性不足，结论就只是demo。
