Two datasets are used: BaseFakepedia, where the passage consistently asserts a false fact, and CUB NQ, built from retrieved web text with only the first entity mention replaced, making passages internally inconsistent. Evaluation is carefully filtered so that only items remain where the model does not produce the passage answer either without the passage or with the passage alone; this makes the no-suffix flip rate exactly zero by construction. The retained set sizes are 248/254/180 on BaseFakepedia and 152/56/129 on CUB NQ for Llama/Mistral/Gemma. The paper compares optimized suffixes against natural-language instruction suffixes, context-aware decoding, activation steering, and random-string controls. The main result is that on items each model resists, optimized suffixes flip nearly all answers on the counterfactual benchmark and most on retrieved text. They are the strongest context-only method on five of six model–dataset pairs, outperform context-aware decoding, and approach activation steering despite requiring no inference-time internal intervention. Another important result is limited generalization: a suffix optimized only for the first-turn question does not automatically transfer to multi-hop questions or later dialogue turns unless those targets are explicitly included in the optimization objective.a:T432,The study tests the hypothesis in both pretraining and supervised fine-tuning. In pretraining, the token budget, data, model configuration, and optimization setup are fixed, while the training context window is varied. Coherent document span length serves as a proxy for the amount of available relevant information. This design separates longer-context learning from simply seeing more tokens. In supervised fine-tuning, the context length is fixed and the amount of task-relevant context is directly controlled, isolating relevance from length. The theoretical account treats language modeling as compression with two predictive channels: information stored in parameters and information supplied in context. When context offers a lower-complexity solution, less task information needs to be encoded in the weights to reach the same risk threshold. The mechanistic analyses then connect this to lower-complexity contextual solutions, a shift in update pressure from feed-forward networks toward attention modules, and stronger reliance on context tokens at inference time.b:T452,The contribution is a structured design space for inference-time cross-lingual exploration rather than a single new algorithm. The core move is to treat “reasoning language / answering language” as exploration axes: translate the query into one or multiple candidate languages, run independent reasoning paths in each language to elicit parametric facts, then aggregate candidates back into the target language.
They claim four inherent dimensions governing cross-lingual exploration (details are in the main method section; from the provided content and cited prior work, these dimensions plausibly include: reasoning vs answering language, pivot vs non-pivot routing, which prompt components are translated, and multi-path sampling/aggregation).
A key stance is to move beyond an English-only pivot: some culturally/localized facts are more accessible in their native language.
