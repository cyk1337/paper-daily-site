18:Tb07,方法上分成两半。第一半在已发布的大模型权重上做“精确重排”实验。作者先对 Huginn-3.5B、Ouro-1.4B、Ouro-2.6B 做 topology audit：给所有 normalization module 打桩，统计不同 loop count 下每个模块的调用次数，以此判断某个 norm 是在 loop 内部每步调用，还是只在 readout 路径上调用。审计结果显示，Ouro 的 model-level normalization 每个 loop step 都会调用，等价于存在 loop-boundary normalization；Huginn 则只在最终 readout 前调用。随后作者对 Ouro 做一个非常克制的改动：把这个 model-level norm 限制到最后一个 loop step 才执行。这样 readout path 保持 bit-identical，参数不变，而且在 r=1 时该改动严格是恒等映射，可作为实现正确性的检查。这个设计很重要，因为它把变化限制在“重新进入下一轮 loop 的状态”上，尽量排除了别的混杂因素。

第二半是因果实验：从头训练小规模 looped 模型，把是否使用 boundary normalization 作为训练前就固定的拓扑开关。模型规模从 19M/6 层到 76M/24 层，两个任务家族，normalization 轴上每个配置 16 个独立 seed，总计 50 个模型。统计上以 training seed 为分析单位，使用精确 rank test 和 Cliff’s delta，而不是只报单次曲线。这个设计回答的是：如果训练和推理始终一致，那么 boundary normalization 到底有没有帮助。

机制分析上，作者没有停在 accuracy，而是同时跟踪四类信号：每个 loop step 的 state norm、readout entropy、logit margin、输入到预测的 mutual information。结果显示，去掉已训练模型中的 boundary norm 后，性能会在少数 loop step 内崩掉，但 state norm 只变化到最多 2.021 倍，远不到“尺度发散”能解释的程度；相反，readout entropy 会从 0.786 bits 飙到 12.470 bits，随后又回落，因为输出头开始把概率质量压到答案字母表之外，最后甚至塌成单一 token。作者进一步做了一个很有说服力的诊断：冻结 loop 主体后只重拟合 readout，损失只能恢复到约三分之一；若连最后一个 block layer 一起重拟合，则几乎能把损失全部找回。这说明问题不只是最后线性头的校准，而是 loop 末端表示与读出接口一起发生了错位。

论文还有一个方法学点：比较 loop depth 和 stack depth 时，若按绝对 K 比，会系统性偏向训练 loop count 更大的配置，因为它虽然看起来“更深”，但推理 compute 其实不等价。作者主张按 budget overshoot K/r0 比较，这同时也是等 compute 的比较方式。在这个口径下，looping 相对 stacking 的优势在 circuit 任务上检测不到，在 hops 任务上也会缩小而不是扩大。19:Tb48,The study has two complementary halves. The first uses released large-model checkpoints and performs an exact topology intervention without retraining. The authors instrument every normalization module in Huginn-3.5B, Ouro-1.4B, and Ouro-2.6B, counting calls under different loop counts to determine whether a given normalization acts inside the loop or only on the readout path. This audit shows that Ouro applies its model-level normalization once per loop step, creating a loop-boundary normalization, while Huginn applies the corresponding module only once before readout.

They then modify Ouro in a tightly controlled way: the model-level normalization is restricted to the final loop step only. This keeps the readout path bit-identical, adds no parameters, and is exactly the identity when r=1, which serves as an implementation check. That intervention isolates the effect on the state that re-enters the next loop iteration while minimizing confounds.

The second half is causal: small looped models are trained from scratch with the topology fixed in advance, with and without boundary normalization. The models range from 19M parameters at 6 layers to 76M at 24 layers, across two task families, with 16 independent seeds per configuration on the normalization axis and 50 models overall. The unit of analysis is the training seed, and the paper uses exact rank tests and Cliff’s delta rather than relying on single runs.

Mechanistically, the paper goes beyond accuracy and tracks four signals: per-step state norm, readout entropy, logit margin, and input-to-prediction mutual information. This is where the argument becomes convincing. Removing boundary normalization from a model trained with it causes rapid collapse within a few loop steps, but state norm changes by at most 2.021x across the grid, which is far too small to support a residual-growth explanation.
