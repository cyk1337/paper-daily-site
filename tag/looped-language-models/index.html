Agreement rather than normalisation keeps depth reusable in looped language models

这篇论文在追问一个很具体、但对 looped LM 成败很关键的问题：循环复用深度时，为什么训练预算之外的 loop step 还能继续可用？已有直觉通常把原因归到 loop 边界处的归一化，认为它能防止状态尺度失控，从而让重复应用同一层栈保持稳定。作者把这个解释拆成两个可检验的命题：一是“边界归一化本身必需”，二是“训练时的 loop 拓扑和推理时的 loop 拓扑必须一致”。论文的核心贡献，是把这两个常被混在一起的因素分开，并证明真正决定可复用性的不是归一化，而是训练—推理 loop 拓扑的一致性；一旦一致，边界归一化不但不是收益，反而会把模型更紧地绑在训练时的特定 loop 深度上。

评这篇会改你对 looped LM 稳定性的 prior：别再把锅先甩给 norm growth，先查 train-test loop mismatch；建议直接看 Ouro 干预实验和多 seed 从训结果。
Ivan Viakhirev,Kirill Borodin,Maxim Abramov,Grach Mkrtchian

Do Halting Heads Really Save Compute in Looped Language Models?

这篇工作检验的是：looped language model 里的 halting head，是否真的能把“预测上更少的迭代数”转成“实际推理时更少的计算”。作者发现，现有做法里这两者经常不是一回事。问题有两层。第一层是训练目标错位：常见的 mixture loss 训练 halting head 时，让头部看到的是各个 iteration 状态的混合表示，而不是推理时真正决定停下来的那个单一步状态，因此 head 学到的 expected halting steps 很低，但按标准 exit rule（累计停机概率过阈值）执行时，token 仍会跑到接近最大迭代数。第二层是系统层面的 batching：即便单 token 早停成立，批量生成时整批要等最慢 token，平均 token 迭代数并不等于真实 wall-clock compute。论文要解决的不是“能否做自适应深度”这个抽象问题，而是更具体地回答：halting head 的训练、停止规则和批处理执行之间到底哪里失配，失配有多严重，怎样评估才不误导。

评这篇值得看，因为它把 early-exit 里最容易自欺的两个指标都拆穿了；先读 stopping objective 和 batched cost 那两段，很多已有结论要重算。
Tsung-Han Wu,Minsuk Heo,Kenny Tan

Towards Looped Models Done Right, Part I: Topology, Input Injection, Recurrent-State Design

这项工作研究 looped language model 应该如何设计。Looped model 通过重复使用同一组 Transformer blocks，把“存储参数量”和“逻辑计算深度”分开：显存和参数存储接近小模型，前向计算路径接近深模型。已有 Ouro 和 Huginn 两条设计路线效果不同，但它们同时改变了循环位置、输入注入方式、循环状态初始化和状态组织，难以判断收益来自哪里。作者把这些因素拆成三个轴：iteration envelope、input injection、latent-state organization，并在相同参数量、相同逻辑深度、相同 token budget 下逐项消融。

评这篇该认真看：它把 looped LM 里最脏的混杂变量拆开了，若 setup 真匹配，Huginn 的 sandwich 设计应立刻进内部 ablation。

LoopCD: Loop-wise Contrastive Decoding for Improving Reasoning in Looped Language Models

这篇工作关注 Looped Language Model 的一个很具体但很关键的问题：模型通过共享权重的多轮 latent refinement 做“隐式推理”时，并不是所有 token 都会随着 loop 次数增加而稳定变好。作者发现，少量 reasoning-critical token 会出现 loop instability：有的 token 过早自信，后续修正失败；有的 token 在不同迭代间来回摆动；这些局部不稳定会沿着推理轨迹传播，最后拖垮答案。论文要解决的就是，能否不改训练、不加外部模型，只利用 LoopLM 自己在不同 loop 里的内部动态，在推理时把这些 hard token 处理得更稳。

评针对 LoopLM (Latent Reasoning) 的一种 inference-time 对比解码方法，通过对比不同迭代深度的 logits 来提升推理稳定性，对研究 latent reasoning 机制有启发。
Byeongho Yu,Junhyuk So,Eunhyeok Park
