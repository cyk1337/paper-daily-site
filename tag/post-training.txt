18:T734,The paper builds on OPD and OPSD. In standard OPD, the student samples on-policy trajectories and an external teacher provides next-token logits at each generated prefix. The student is trained by matching these dense token-level targets. OPSD removes the external teacher by using a second copy of the same initial checkpoint as a privileged teacher. The teacher sees the problem, the ground-truth solution, and the student-generated prefix; the student only sees the problem. This transfers gold-conditioned local guidance to the student.

The limitation is that prior OPSD keeps the teacher frozen. The authors probe fixed incorrect trajectories and show that a frozen gold-conditioned teacher often prefers EOS at incorrect endpoints rather than tokens that initiate reflection or correction. Meanwhile, the student’s tendency to reflect increases during training, making the frozen teacher less suitable for later on-policy prefixes.

Dynamic Co-Evolution addresses this by updating the privileged teacher across rounds. After each training update, the resulting checkpoint initializes both the next student and a detached gold-conditioned teacher. The teacher is still frozen within a round, which preserves a stable target, but it is refreshed between rounds so that revision behaviors learned by the student can become part of the next round’s supervision. This is more adaptive than a permanently frozen teacher and more stable than a fully online teacher.

Self-Refined Concise Learning addresses the cost side of stronger revision. More self-checking and backtracking can improve correctness but also inflate output length. SRCL trains on answer-verified, shorter rewrites of the same on-policy responses. DCE improves the ability to recover from mistakes; SRCL encourages the model to keep that ability while using fewer tokens.19:T5fe,The experiments use Qwen3 models at 8B, 4B, and 1.7B scale and evaluate Average@12 on four competition-level math reasoning benchmarks. Compared with OPSD, DCE improves Average@12 by 35.41, 37.15, and 12.98 percentage points at 8B, 4B, and 1.7B respectively. Matched-budget controls indicate that the gains are not explained by longer generations alone.

SRCL is most visible under constrained inference budgets. Under the lowest tested 8K evaluation budget, DCE+SRCL reaches 35.07% Average@12 with a mean of 7,500 output tokens per response. It outperforms the OPSD test-time-scaling control by 6.60 percentage points while generating about 692 fewer tokens per response.

The teacher-behavior probes are central. On fixed incorrect Qwen3-8B trajectories from AIME 2024, AIME 2025, and AIME 2026, the frozen gold-conditioned teacher assigns 94.5% average probability to EOS at incorrect endpoints and only 22.0% to observed reflection cues such as “Wait”. After DCE, the privileged teacher’s endpoint EOS probability drops from 90.4% to 41.3%, while its probability on observed reflection tokens rises from 32.8% to 77.4%. This shows that the local supervision changes direction: from stopping at a wrong endpoint toward checking and revising.

Ablations compare per-round teacher updates with frozen, EMA, and periodic alternatives. Updating the teacher every round performs best, suggesting that teacher refresh frequency is a substantive training variable in reasoning self-distillation rather than an implementation detail.1a:T457,The method uses a closed-testing construction. An independent proposal split nominates one candidate-specific floor c_k for each policy. A fresh certification split then runs an exact binomial test for H_k: P(S_k < c_k) ≥ α. Rejecting this null certifies that the candidate’s lower α-quantile is at least the proposed floor. Holm’s step-down procedure controls the family-wise error rate at δ across candidates. The selected policy is the certified candidate with the largest floor; the procedure abstains if no certified floor exceeds a predeclared operating threshold. The guarantee allows arbitrary within-unit dependence across candidates, such as correlated judge scores on the same prompt, while requiring i.i.d. evaluation units. Compared with matched-proposal Bonferroni, Holm gives a uniformly stronger rejection set on every dataset. Compared with exact COPS, it certifies a different statistical object, so uniform dominance is not claimed. The score map s_k is treated as a fixed measurable function; it need not be unbiased, Gaussian, asymptotically normal, or a mean off-policy estimator.1b:Tac4,方法上最重要的是“串行阶段化 + 奖励硬度排序 + 难度过滤”。完整流水线是 SFT → Reasoning RL → Coding RL → Instruction-Following RL → General Agent → Coding Agent → Search Agent → RLHF，全部基于同一个 GLM-4.5-Air-Base（106B total / 12B active）连续更新参数。

第一部分是 SFT。作者把它当成 capability-building stage，而不是格式对齐。SFT 的作用有两个：一是建立广泛能力下限，二是统一输出格式，尤其是 native <think> chat format 和多轮交互模板。这里隐含的判断是，如果 SFT 没把能力面铺开，后续 RL 只能在狭窄分布上做局部修补，容易出现 reward overfitting。

第二部分是多阶段 RL。Reasoning RL 和 Coding RL 先做，因为奖励最硬，分别依赖可验证答案或执行/测试信号，属于 RLVR。Instruction-Following RL 虽然用了 rubric-based judge，但被放在 agent 阶段之前，因为作者观察到 instruction following 离模型原有聊天能力更近，judge 可被利用的空间较小。General/Coding/Search Agent 三个阶段再把工具使用、环境交互和长轨迹决策加进来。最后才做 RLHF，用偏好型软奖励去修整开放式质量。

第三部分是 difficulty filtering。作者反复强调，训练样本要落在“可学但未掌握”的区间：已经会做的 prompt 要丢掉，大多数阶段里始终不会做的 prompt 也丢掉。这样做不是简单提纯数据，而是在 on-policy RL 中构造自动 curriculum，避免梯度浪费在零优势样本或纯噪声样本上。相比只按题目元数据分桶，这种基于当前策略表现的过滤更贴近真实学习边界。

第四部分是基础设施设计。作者明确指出，多轮 agent RL 需要 token-in/token-out rollouts，也就是把模型生成和环境返回都作为在线轨迹的一部分，而不是离线拼接。为了稳定 RL，他们使用大 batch 和 Rollout Routing Replay；后者的作用是缓解长轨迹、多环境、异步 rollout 带来的分布抖动。另一个关键点是从 SFT 到 agent 阶段保持 chat template 一致，避免模板漂移把能力变化和格式变化混在一起。对于 coding/search agent，还需要长时间稳定运行的 sandbox/service，否则 reward 噪声会直接污染策略更新。

和常见做法相比，这篇工作的区别不在单个算法，而在把“为什么先做这个、后做那个”讲得很具体。很多工作把 IF、agent、RLHF 混在一起做多目标优化；这里则明确按 reward 可验证性和被攻击风险排序。很多工作也做 hard example mining，但这里是按当前 policy 的成功带宽做动态过滤，更接近 RL 里的 learnability control。1c:T927,The central design is a serial pipeline with explicit stage responsibilities, reward-hardness ordering, and difficulty filtering. The full sequence is SFT → Reasoning RL → Coding RL → Instruction-Following RL → General Agent → Coding Agent → Search Agent → RLHF, all applied to the same GLM-4.5-Air-Base checkpoint (106B total, 12B active MoE).

SFT is treated as the capability foundation. Its role is not only to align output style, but to establish broad competence and normalize the model’s interaction format, including the native <think> template and multi-turn chat behavior. The implicit claim is that if SFT does not already cover the capability surface, later RL will overfit narrow reward channels rather than build robust skills.

The RL stages are ordered by reward reliability. Reasoning RL and Coding RL come first because they rely on hard verification signals such as exact answers, execution, or tests. Instruction-Following RL uses a rubric-based judge, but it is still placed before the agent stages because instruction following is close to the model’s native chat behavior and therefore less exposed to severe reward gaming. General Agent, Coding Agent, and Search Agent then introduce tool use and environment interaction. RLHF is deliberately last, since open-ended preference rewards are the easiest to exploit.

A key mechanism is difficulty filtering. The training prompts are restricted to a productive band: prompts the current policy already solves are removed, and in most stages prompts it never solves are also removed. This turns on-policy RL into an automatic curriculum over learnable examples. Compared with static hard-example mining, the filter is policy-dependent and tracks the current learning frontier.

The authors use token-in/token-out rollouts for multi-turn on-policy RL, large batches for stability, and Rollout Routing Replay to reduce variance and distributional jitter from long trajectories and asynchronous environments. They also emphasize strict chat-template consistency from SFT through agent stages, plus reliable sandbox services for long coding and search episodes. The paper’s novelty is less about a new optimizer or reward formula, and more about making the sequencing logic and systems constraints explicit.1d:T5b0,The most useful experimental contribution is the stagewise analysis rather than the final leaderboard. The second layer is IDRL. Instead of using a static weighted sum of distillation and RL losses, or running distillation and RL as separate stages, IDRL alternates between on-policy distillation updates and RL updates within a single training loop. In the distillation step, the student is trained against the teacher distribution on student-generated sequences, giving dense token-level supervision. In the RL step, the policy is optimized against task reward. The motivation is that a static joint loss can create objective interference within the same update, while a purely staged pipeline prevents the two signals from interacting during training. Interleaving is meant to decouple the objectives in time while still allowing them to shape the same evolving policy. The claimed benefits are better exploration, higher retained policy entropy, and more stable optimization.

For long-horizon agentic training, the paper adds PAS, or step-level positive-advantage suppression. This targets a common failure mode in trajectory-level RL: if a trajectory succeeds overall, some ineffective or even wrong intermediate actions may still receive positive credit because they share the trajectory’s positive advantage. PAS suppresses positive advantage on such steps, reducing this hitchhiking effect. The exact formula is not visible from the provided text, but the intent is clear: not every action on a successful trajectory deserves reinforcement.

The third layer is Pistis-Auto-Harnessing. PAH does not change the policy weights or the tool interface.
