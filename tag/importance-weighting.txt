18:T5eb,DRIFT (Decoupled Rollouts and Importance-Weighted Fine-Tuning) is built on the claim that the KL-regularized RL objective is equivalent (or yields an equivalent gradient) to a weighted supervised learning objective when trajectories are reweighted by exponentiated rewards/returns.

1) MDP formulation: state is the full interaction history; feedback is deterministic lightweight text (e.g., “Incorrect, please try again”); reward is verifiable 0/1 correctness; discounting penalizes delayed success.

2) Equivalence to weighted SFT: under KL regularization to a reference policy, the optimal policy’s density ratio relative to the reference is proportional to exp(return). Therefore, trajectories sampled from the reference can be used for learning if each trajectory (or each turn) is weighted by an importance weight derived from exp(discounted return).

3) Two-stage pipeline:
- Offline rollout stage: collect multi-turn trajectories under a fixed reference policy (high-throughput, parallelizable).
- Importance-weighted fine-tuning stage: perform trajectory-weighted maximum likelihood training using the derived weights, avoiding repeated on-policy rollouts during optimization.
