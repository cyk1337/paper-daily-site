LeVLJEPA: End-to-End Vision-Language Pretraining Without Negatives

LeVLJEPA 解决的是视觉-语言预训练中过度依赖 contrastive negatives 的问题。CLIP、SigLIP 这类方法主要通过 batch 内负样本学习全局图文对齐，适合零样本分类和检索，但对 patch-level dense visual features 的监督是间接的。许多 VLM、dense prediction 和机器人系统真正使用的是冻结视觉编码器的 patch token 序列，而不是单个 pooled image embedding。论文的核心问题是：不用负样本、温度参数、动量教师或 teacher-student schedule，是否可以端到端训练一个图文编码器，并得到更适合下游 VLM 使用的 dense visual representation。

评将 JEPA 范式成功扩展到端到端图文预训练，去掉了动量编码器和负样本，证明了非对比预测学习在多模态特征提取上的潜力，强烈建议关注其训练稳定性和正则化细节。
Lukas Kuhn,Giuseppe Serra,Randall Balestriero,Florian Buettner

What Does the Caption Really Say? Counterfactual Phrase Intervention for Compositional Data Selection in Vision-Language Pretraining

这篇论文解决的是 CLIP 式图文预训练中的数据选择粒度问题：一个 image-text pair 的全局相似度高，并不意味着 caption 里的对象、属性、关系短语都被图像支持。全局过滤能去掉粗错配，但在高相似度样本池里会进入饱和区，继续按 pair-level score 筛选不再稳定提升组合泛化。

评看方法和 ablation 即可；它把“图文相似度”拆到短语级，值得检验能否迁移到内部 VLM 数据过滤。
Hyejin Go,Semi Lee,Hyesong Choi

TIPSv2: Advancing Vision-Language Pretraining with Enhanced Patch-Text Alignment

统一式视觉-语言预训练模型在“全局图文对齐”与“局部/patch级语义对齐（grounding）”之间长期存在张力：即便TIPS、SigLIP2等已引入空间感知训练，模型在像素/patch与文本概念的精确对齐上仍明显不足，且出现“大模型patch-text对齐反而弱于小模型”的反常现象。论文要解决的核心问题是：如何在不牺牲全局对齐能力的前提下，系统性提升预训练阶段的patch-text alignment，并解释/修复规模增大导致的局部对齐退化。

评patch 蒸馏学生反超教师这点会改你对“局部对齐受限于容量”的 prior；建议复现其 iBOT++/head-only EMA 配方做内部 ablation。

On The Application of Linear Attention in Multimodal Transformers

多模态 Transformer（尤其视觉 token + 文本 token）序列更长，标准 softmax attention 的 O(N^2) 计算/显存开销成为扩展瓶颈。线性注意力（Linear Attention, LA）虽在单模态中被研究较多，但在多模态预训练（如 CLIP/OpenCLIP 范式）里能否在保持性能的同时获得可观效率收益仍缺少系统验证。

评看训练吞吐-精度曲线与分辨率/序列长度的 scaling 部分即可；若结果站得住，LA 可能是多模态预训最便宜的算力杠杆。
