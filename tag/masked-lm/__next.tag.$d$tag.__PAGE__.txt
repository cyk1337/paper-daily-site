第二层是 AGDO 框架。核心做法是先从 valid attention score 中构造 attention-guided denoising order，再把这个顺序用于 post-training。这里的 valid attention 可以理解为：只统计指向当前可见、已解码或未被 mask 的上下文 token 的注意力，从而估计某个 masked token 当前是否已经拥有足够支撑它被恢复的上下文。AGDO 不是按固定位置顺序解码，也不是简单 blockwise，而是按 attention 支撑度决定谁先被 unmask。

在 SFT 阶段，AGDO-SFT 用 attention-guided order 构造训练样本和预测目标，减少训练-推理错配。除此之外，作者还引入 attention-based reweighting，对 attention-critical token，也就是在依赖图中更像 hub、对其他 token 预测更关键的 token，赋予更高损失权重。这样做的理由很直接：这些 token 一旦预测错，会沿后续 denoising step 传播错误。

在 RL 阶段，AGDO-RL 建立在已有 dLLM 的 GRPO/mean-field 近似路线之上，但同样把 attention-guided order 和 token reweighting 纳入优化。也就是说，它不是只在 sample-level 上根据最终 reward 调整，而是让 credit assignment 更偏向那些对后续推理链条更关键的 token。和 diff-GRPO、wd1 这类方法相比，区别不在 RL 框架本身，而在于它把 policy optimization 的作用位置从“随机选中的 masked token”改成了“按 attention 依赖组织起来的 token 子集”。a:T71e,The method has two layers. On Dream-v0-Instruct-7B, the authors trace final-layer attention along the denoising trajectory and report two main findings: attention is sparse and temporally stable across steps, and tokens that place more attention mass on already-denoised context exhibit more stable generation probabilities. This suggests that masked tokens are not equally predictable at a given step, which directly challenges fully random masking.

Second is AGDO, an attention-guided denoising and optimization framework. It derives an attention-guided denoising order from valid attention scores, where the key idea is to estimate whether a masked token already has enough support from currently visible or denoised context. Instead of decoding by position or by random selection, AGDO unmasks tokens according to attention-supported readiness.

AGDO-SFT uses this order during supervised fine-tuning, reducing the mismatch between training and inference trajectories. On top of that, it introduces attention-based reweighting: tokens that act more like attention hubs receive larger loss weights because mistakes on them are more likely to propagate through later denoising steps.

AGDO-RL extends the same principle to reinforcement learning. It stays within the recent dLLM RL line based on GRPO-style optimization with mean-field approximations, but changes where optimization pressure is applied. Rather than treating randomly masked positions as the optimization target, it organizes token-level credit assignment around attention-induced dependencies and emphasizes attention-critical tokens.
