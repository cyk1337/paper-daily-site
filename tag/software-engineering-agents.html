SpecBench: Evaluating Specification-Level Reasoning for Software Engineering LLM Agents

现有 SWE agent 基准（如 SWE-Bench）默认“规格说明是完美的”，只测从明确需求到代码实现的能力，无法覆盖真实工程里最难也最关键的阶段：在需求不完整/有歧义/有冲突时，识别规格缺陷并推动规格走向可实现、可验证的一致版本。SpecBench 要评测的就是这种 specification-level reasoning：给定初始 RFC 提案、当时的代码库快照、以及此前的 RFC 历史，模型能否指出提案中哪些地方会导致实现风险或社区不可接受。

评将 SWE Agent 的评测从“写代码”前置到了“写 RFC/需求规约”，这是一个更接近真实高级工程师工作流的 Benchmark，值得关注其评测指标设计。
