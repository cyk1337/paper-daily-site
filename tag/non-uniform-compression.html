Tangram: Unlocking Non-Uniform KV Cache for Efficient Multi-turn LLM Serving

这篇工作解决的不是“如何设计更好的 KV 压缩算法”，而是一个更实际的问题：非均匀 KV cache 压缩在算法上已经显示出比均匀压缩更好的精度-压缩权衡，但一旦放进真实多轮 serving 系统，就会因为内存布局、调度和 kernel 执行三方面的不匹配而失去收益。具体说，现有 vLLM / SGLang 一类系统默认所有 attention head 的 KV 长度一致；而非均匀压缩让不同 head 保留不同长度，结果带来页碎片、运行时回收开销、GPU workload 不均衡，最终使“理论上省下来的 KV”无法转化成吞吐提升。Tangram 的核心问题就是：怎样把 head-wise heterogeneous KV cache 变成一个可被高吞吐 serving 系统稳定利用的对象。

评针对长上下文推理的 KV Cache 优化系统，提出了确定性预算分配等实用技巧，对关注 Serving 效率的研究员有参考价值。
Hyungmin Kim,Minsoo Kim,Hongseok Kim,Jungwook Choi
