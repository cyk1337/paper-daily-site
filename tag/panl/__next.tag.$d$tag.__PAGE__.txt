9:T53d,The paper frames confidence using the first-order versus second-order distinction from decision neuroscience. In a first-order account, the same signal determines the chosen response and confidence in that response. The LLM analogue is token log-probability. Under greedy decoding, this signal is tied to the selected answer and therefore gives a weak account of why the model would later judge its own answer as wrong. A second-order account introduces a partly independent evaluative variable. The paper focuses on the post-answer newline token, or PANL. Prior work by Kumaran et al. 2026 found that PANL caches a confidence representation that causally drives verbal confidence and dissociates from generation-time log-probabilities. This work tests whether the same representation supports error detection and self-correction. The experimental paradigm is verify-then-correct: generate an answer, elicit or measure confidence and verification behavior, then allow a correction attempt. The analysis asks whether verbal confidence predicts error detection beyond log-probabilities, whether PANL activations predict error detection beyond verbal confidence, and whether PANL predicts which errors can be corrected. Causal evidence comes from activation patching and joint ablation, including settings where answer information is corrupted.a:T4d4,The findings are reported across Gemma 3 27B and Qwen 2.5 7B, on TriviaQA and MNLI. Behaviorally, verbal confidence predicts verification outcomes much better than token log-probabilities, which argues against a pure first-order account. Representationally, PANL activations still predict error detection after controlling for verbal confidence, indicating that the internal evaluative signal is not fully exposed in the model’s verbal report. The strongest result is on correctability: PANL predicts which erroneous answers will be successfully revised, while behavioral signals, including log-probability and verbal confidence, fail to do so reliably. Activation patching shows a causal role: PANL signals can rescue error detection when answer information is corrupted. Joint ablation suggests that the evaluative signal is shared across PANL and the last answer token, but PANL isolates it more cleanly because it occurs after the full answer has been produced and can attend back over the question-answer pair. The provided text does not include exact AUCs, accuracies, or effect sizes, so the result should be read as a convergent behavioral, representational, and causal argument rather than as a single-number benchmark claim.b:T414,Read carefully. Start with the introduction’s definition of first-order and second-order confidence, especially the distinction between X_act and X_eval in Figure 1. Then inspect the verify-then-correct setup, because the separation between detecting an error and successfully correcting it is the key design choice. For the probing results, focus on the control variables: generation log-probabilities, verbal confidence, and PANL activations should be compared by incremental predictive value. The causal section is the most important part to read in detail: activation patching tests sufficiency, while joint ablation clarifies how PANL differs from the last answer token. If time is limited, prioritize the main result tables, the causal intervention figures, and the appendix discussion linking the mechanism to recall versus recognition.
