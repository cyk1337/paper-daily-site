Settle: Learning When to Stop Reasoning

Settle 解决的是推理模型“答案已经稳定但仍继续生成”的计算浪费问题。目标不是让模型学更短的固定解法，而是让模型在当前 reasoning prefix 已经足够支持稳定答案时，主动生成已有的 end-of-reasoning token。

评读方法和 MATH-500 Pareto 图即可；它像一个干净的 stop-token 蒸馏，不改变预训练 prior 但能省推理预算。

From Solo to Social Learning: Characterizing Recursive Social Improvement in LLMs

这篇文章研究的是一个很具体但容易被忽视的问题：当一群 LLM agent 都能通过修改 skill file 来自我改进，而且每个 agent 只优化自己的任务和回报时，允许它们互相观察、复制、再修改彼此的技能，整体群体能否比各自单独摸索更快、更省 token、或者在同等 token 下达到更高性能。作者把这个问题定义为 recursive social improvement。难点不在于“能不能抄作业”，而在于探索、观察、执行三者共用同一预算时，社会学习会不会因为搭便车而削弱独立探索，最后让群体并不比 solo learner 更强。

评值得看失败分析；它削弱了“多 agent 互抄技能会自然自举”的 prior，重点读 token budget 分解。
Kunal Jha,Max Kleiman-Weiner,Natasha Jaques
