9:T780,AnySearch formulates budget-aware search as a resource-constrained sequential decision problem. The state contains the interaction history h_t and remaining budget b_t. The action space has three actions: reason internally, call the search tool, or answer and terminate. Budget is charged only on external search calls, since search latency and retrieved-document tokens dominate cost relative to internal reasoning tokens.

The method uses a two-phase curriculum. Phase I is a scaffolded learning stage. The model receives explicit budget-state injection and structured reasoning prompts that encourage it to think about whether a search is necessary, how much budget remains, and how to allocate it. Budgets decay linearly during training so the policy sees a range of budget regimes instead of overfitting to a single point.

Phase II removes the scaffold entirely. Training inputs now match inference conditions: the model is given only the total budget and must autonomously manage allocation. To make this work across budgets, the paper introduces adaptive budget sampling. Rather than sampling budgets uniformly, it focuses more on budget levels where the current policy is weak, while retaining uniform smoothing for coverage. This is important because the target is not peak performance at one budget, but a stable performance curve over many budgets.

The reward is a composite objective combining answer accuracy and budget efficiency. Efficiency is measured with both absolute and relative signals. A key detail is the adaptive weighting of the efficiency term based on query difficulty, which prevents the policy from becoming overly conservative on hard questions. Without this, a strong efficiency reward would push the model toward under-searching; too weak a reward would collapse back to wasteful search. The paper’s solution is effectively a difficulty-aware trade-off controller inside RL training.a:T660,The evaluation spans 7 benchmarks and 3 backbone models. The main result is consistent improvement over baselines across all tested budget levels, together with generalization to budget values not seen during training. That unseen-budget result is more important than a single average score, because it suggests the model learned a transferable budget-allocation behavior rather than memorizing a few discrete budget settings.

The baselines include fixed-budget RL search agents, reward-shaping methods that try to reduce redundant tool use without an explicit budget interface, and BATS-style approaches that rely on an external budget tracker. AnySearch improves not only answer quality but also tool productivity, meaning each search call yields more useful information on average. It also achieves the lowest total token consumption, which indicates the gain is not coming from replacing search with excessive internal reasoning tokens.

The ablations address three central questions. First, whether the scaffold is truly internalized: after removing explicit budget tracking and structured prompts, performance remains strong, which supports the internalization claim. Second, whether the two-phase curriculum is necessary: removing either the scaffolded phase or the scaffold-free adaptation phase hurts cross-budget robustness. Third, whether each reward component matters: removing relative efficiency, absolute efficiency, or adaptive weighting degrades the accuracy–efficiency trade-off.
