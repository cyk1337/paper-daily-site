18:T507,CRAFT (Consensus Reasoning knowledge graph Aggregation for Flaw-aware Traces synthesis) is a multi-sample post-processing framework that turns multiple candidate traces into a single higher-quality trace via a consensus reasoning graph.

Module I: Generate K diverse candidate traces per problem and extract consensus terms using TF-IRF weighting. These terms act as anchors to reduce surface-form variance across traces.

Module II: Build a per-trace Reasoning Knowledge Graph (RKG) where nodes are reasoning steps and directed edges encode logical relations. Aggregate per-trace graphs into a consensus graph G* and filter anomalous steps/structures using z-score-based deviation filtering. The same mechanism is intended to catch (a) step-internal flaws, which tend to diverge semantically/structurally from the majority, and (b) step-wise flaws, where redundant branches (overthinking) or missing backbone steps (underthinking) are exposed by comparing each trace to the group consensus. The design is explicitly motivated by group-relative comparison ideas (akin to GRPO).
