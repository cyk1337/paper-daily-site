9:T6b7,WaveFilter is a training-free KV-cache filtering framework built around multi-scale analysis with the discrete wavelet transform (DWT). The intuition is that not all cached tokens are equally useful in long contexts. A good system should first locate relevant regions cheaply, then refine the selection locally.

The method appears to operate in two stages. First, it performs coarse filtering. At the initial step, WaveFilter applies DWT to the cache representation to obtain a compressed multi-scale view of the sequence. The goal is to reduce cache length, suppress high-frequency noise, and preserve lower-frequency global structure. The current query then attends to this compressed representation to identify an initial set of important regions or tokens. Second, it performs fine filtering. Starting from those coarse candidates, the method uses multi-scale recursive filtering to progressively map back to finer temporal scales and identify the final critical tokens. These selected tokens are then used to construct a sparse KV cache dynamically for the current attention computation.

The main distinction from prior DLM cache methods is not a new cache update rule, but a front-end token selection mechanism that can sit on top of existing cache strategies. Methods such as Fast-dLLM and Elastic-Cache can accelerate short-text generation, but they struggle in long contexts because token retention becomes hard to tune. WaveFilter uses wavelet-based multi-scale structure to make that search cheaper: first global localization in a compressed domain, then recursive refinement in the original domain.
