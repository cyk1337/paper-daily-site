Multi-Draft On-Policy Distillation for Diffusion Drafters

这篇工作解决的是并行 diffusion drafter 做 speculative decoding 时，一个很具体但此前处理得不够好的训练目标错配问题。并行 drafter 在一个 block 内同时预测多个 token，每个位置都只看公共上下文，不看同一 block 内前面采样出的 token；但 verifier LLM 在打分时是自回归的，会条件化在这些前缀上。于是同一个 drafter 位置的预测，会因为不同 sampled prefixes 对应到不同 verifier target。若把这些 target 分开蒸馏，训练会错误压低那些“在某些前缀下很合理、在另一些前缀下不合理”的 token，最终损害 acceptance length。

ProVe: Proposer-Verifier Decoding

这篇工作解决的是一个很具体但很关键的推理问题：当大模型已经能在一次前向里提出一个长度为 B 的候选 token block 时，推理加速里“由小模型起草、大模型验证”的传统 speculative decoding 分工是否还合理。作者的答案是否定的。论文把角色反过来：让大模型一次性提出整段候选，再用一次额外前向去判断这段里有多少前缀可以安全提交。核心矛盾不在于能不能提出 block，而在于提出之后如何决定提交长度。MARS 这类 block proposer 只靠 proposer 自己的置信度做提交，代价低，但会明显少提交通常其实已经与 AR greedy 一致的前缀；ProVe 关注的就是如何用一次验证 pass 把这部分“未被利用的可提交前缀”找回来，从而把 serial decoding 的步数真正降下来。

评反转了推测解码的常规设定，让大模型自己做 proposer 并通过微调实现 block prediction，思路清奇，值得关注其训练 recipe 和实际加速比。

Mentored Decoding: Faster Inference meets Boosting

这项工作研究有损 speculative decoding 为什么既能提高吞吐，又可能改善输出质量。标准 speculative decoding 要严格保持目标模型分布，因此接受率被 drafter 与 target 的分布差异限制住。Mentored decoding 放宽这一点：允许输出分布在受控散度内偏离 target，以换取更高接受率。核心问题是给出这个折中关系的形式化刻画，并解释“两个模型组合后质量高于 target”在什么条件下成立。

评将推测解码与 Boosting 理论联系起来，解释了为什么 drafter 能提升 target 模型质量，理论推导值得一看。
Vivien Tran-Thien,Richard Nock
