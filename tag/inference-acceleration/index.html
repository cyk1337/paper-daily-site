Early-Bird Decoding: Accelerating Diffusion LLMs with Learnable Block Sizes and Parallel Sampling

这篇工作处理的是 diffusion LLM 推理阶段一个很具体、也很关键的瓶颈：现有并行去噪解码虽然摆脱了 AR 的逐 token 串行约束，但实际部署时仍然要跑很多 denoising steps，很多 token 明明在较早阶段就已经“预测对了”，却因为置信度阈值没到、或固定 block 策略限制，不能被提前定稿，导致重复计算很多无效步。作者进一步指出，问题不只是阈值设得保守，而是现有方法默认各位置 token 难度近似均匀，用固定 block 或简单启发式边界去组织并行解码，这和自然语言中 token 难度高度异质的事实不匹配。论文要解决的核心，就是如何在不明显伤害质量的前提下，自动找出“可以一起更早定稿”的 token 组，并把这些 token 在达到传统 confidence threshold 之前就安全地 finalize 掉。

评如果你在跟 diffusion LM，这篇该看；不是范式突破，但它直指“并行生成却不快”这个老问题，先看方法图和 latency table，质量是否稳住比加速倍数更关键。
