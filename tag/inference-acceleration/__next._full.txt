The first is Progressive Curriculum Loss, designed to stabilize deep look-ahead training. Instead of assigning a constant or hand-decayed weight to every prediction depth k at position t, the model uses an adaptive weight ω_{t,k}. This weight combines two constraints. The Sequential Confidence Constraint uses the softmax confidence of preceding look-ahead predictions to estimate whether the trajectory up to depth k is still trustworthy. Together, these terms create an implicit easy-to-hard curriculum: the model first learns stable short-horizon prediction and only gradually receives stronger supervision on deeper horizons.

The second component is Confidence-Gated Dynamic Drafting for inference. Standard MTP usually fixes the drafting depth K, but fixed K is suboptimal for document parsing because entropy varies sharply across layouts, tables, formulas, and plain text spans. If the predicted path remains reliable, the model keeps extending the draft; if confidence drops below a threshold, it truncates early. This directly optimizes the useful quantity αK, where α is the acceptance rate, rather than maximizing K in isolation. The paper also keeps the MTP branch lightweight, using a shared module that recurrently produces multiple look-ahead predictions, so the extra overhead γ stays small enough for real wall-clock gains.
