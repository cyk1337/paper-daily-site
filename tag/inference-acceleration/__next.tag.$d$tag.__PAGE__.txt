第一部分是 Learnable Block Size, LBS。作者的观察是，token entropy 沿位置分布常呈现类似 staircase 的结构，说明相邻甚至非连续位置上，可能存在一批难度接近、语义上也相对一致的 token，它们适合被视作同一批次提前解码。与固定长度 block 或基于分隔符的启发式切分不同，LBS 用一个轻量网络读取每个位置的统计量，主要包括 token entropy、位置信息以及语义相关特征，在线预测 block grouping。论文强调它既支持 contiguous block，也支持 non-contiguous grouping，这一点比传统“滑窗式并行”更灵活。其目标不是做语法 chunking，而是做 difficulty-aware clustering：把收敛速度相近的 token 放在一起，避免 easy token 被 hard token 拖慢。

第二部分是 Learnable Parallel Sampling, LPS。现有 confidence-based decoding 的问题在于：只有当 token 置信度超过阈值时才 finalize，而很多 token 在更早步骤就已经预测正确，只是概率还没高到阈值，因此会被继续 remask 和重复预测。LPS 试图学习一个 position-aware 的 finalize policy。它利用每个位置在当前 step 的 entropy、位置编码、step index 等特征，预测该位置是否已经“足够收敛”，从而允许早于传统阈值进行定稿。因为 LBS 已经把难度相近 token 组织成 block，LPS 可以在 variable-length block 上执行并行 finalize，而不是受固定 block 边界限制。

从机制上看，这篇论文不是改 dLLM 主干模型，也不是重新训练一个新的 diffusion objective，而是在 decoder 侧外挂两个轻量路由/决策网络。这样做的好处是兼容现有 dLLM 和已有 KV-cache pipeline，代价则是需要额外训练这两个小网络，并且其泛化能力会受所用 backbone、任务分布和采样设置影响。与已有方法相比，区别主要有三点：一是 block size 从 heuristic 变成 learned；二是 early finalization 从固定 confidence threshold 变成 learned policy；三是 block 组织和 finalize 决策是联动的，而不是各自独立的后处理规则。b:T7f5,The method, EB-Decode, has two main components.

The first is Learnable Block Size (LBS). The authors observe that token entropy across positions often follows a staircase-like pattern, suggesting that some positions—contiguous or even non-contiguous—share similar uncertainty and semantic coherence. Instead of using fixed-size blocks or heuristic boundaries such as delimiters, LBS uses a lightweight network to predict block groupings on the fly from token-level statistics, including entropy, positional information, and semantic cues. The goal is not syntactic chunking. It is difficulty-aware grouping: easy tokens should not be delayed by harder ones simply because they happen to sit in the same fixed block.

The second is Learnable Parallel Sampling (LPS). Standard confidence-based decoding finalizes a token only when its confidence exceeds a threshold. The paper argues that this wastes computation because many tokens become correct well before their confidence reaches that threshold. LPS learns a position-aware finalization policy using per-token features such as entropy, position, and denoising step. It predicts which positions have already converged enough to be finalized early. Because LBS already organizes tokens into variable-length groups, LPS can operate under adaptive blocks rather than fixed boundaries.

A key design choice is that the paper does not modify the diffusion LM backbone or training objective. Instead, it adds lightweight decision modules on top of the decoder loop. This makes the method easier to integrate with existing dLLMs and compatible with KV-cache pipelines. The trade-off is that these auxiliary networks need to be trained, and their robustness may depend on the backbone, task distribution, and sampling setup. Relative to prior work, the main differences are: learned rather than heuristic block sizing, learned early finalization rather than fixed confidence thresholds, and joint handling of grouping and finalization rather than treating them as separate post-hoc rules.c:T62b,The evaluation covers three diffusion LLMs and four representative benchmarks. The headline result is a 3.53× to 18.76× throughput improvement over the vanilla decoder while maintaining comparable accuracy, with only about 6.21% routing overhead. When combined with a KV-cache pipeline, EB-Decode provides an additional 1.20× speedup.

The motivation is grounded in a real deployment gap. The paper cites that LLaMA3-8B-Instruct reaches 48.0 tokens/s on an A100-PCIe 40GB GPU, while LLaDA-8B-Instruct reaches only 3.5 tokens/s. Instead of dropping an excluded source expert or rerouting it to a similar target expert without correction, ExFold projects the source contribution onto a retained target expert. The method is motivated by two empirical findings: many experts produce directionally aligned outputs on the same inputs, but their output magnitudes differ substantially. Directional alignment makes substitution plausible; magnitude mismatch makes naive rerouting inaccurate. Based on this, each layer is calibrated with two matrices from a single frozen forward pass on unlabeled text. The scalar-projector matrix stores directed source-to-target scaling factors. The projection-loss matrix measures reconstruction loss for folding one expert into another. At inference time, retained experts are selected according to the phase budget: K_pre dominant experts per token for prefill, and D dominant experts per batch for decode. Every excluded expert is then assigned to the minimum-loss retained target, and its contribution is folded into that target by absorbing the scalar projector into the router weight. This gives one shared folding operator across both phases. Compared with token-wise sparsification, the method does not only reduce executed experts; compared with expert-set consolidation, it does not bake compression into a fixed submodel; compared with similarity-based rerouting, it explicitly corrects scale mismatch.
