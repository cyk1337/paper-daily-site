Open-UniMo: Towards Unified Motion-Language Understanding and Generation in the Open World

这篇工作要解决的不是一般的 text-to-motion 或 motion captioning，而是更难的统一建模问题：在开放世界、长时序、弱对齐的 motion-language 数据上，如何让一个单一模型同时做好动作生成和动作理解。作者指出现有路线有三处结构性短板。第一，很多方法把 motion 当成挂在 LLM 旁边的辅助模态，结果表示空间被文本主导，跨模态交互不对称。第二，纯 next-token autoregressive 目标对长动作序列并不友好，动作的时间演化是连续过程，局部 token 误差会沿序列累积。第三，开放世界数据的动作分布更复杂，过去几百级别的 motion codebook 容量不够，tokenizer 重建误差会直接传到生成质量和理解质量上。Open-UniMo 的核心问题因此可以概括为：在统一 token 接口下，怎样提升 motion 作为一等模态的表示容量与训练信号质量，并让双向任务在同一模型里形成真正的语义闭环，而不是两个方向各自凑合可用。

评值得扫 tokenizer 和训练配方部分；若 motion token 真能和文本词表稳定共训，会影响非文本模态接入 LM 的设计选择。

PhysBrain 1.5: From Vision-Language Models to Physical Foundation Models

这篇工作要解决的是 embodied foundation model 里一个长期分裂的问题：视觉理解、动作生成、未来状态预测通常由不同模型或不同头分别处理，监督形式也不一致，导致共享表示难以形成。PhysBrain 1.5 试图把 physical loop 里的三个环节——观察、行动、环境变化——都写成离散 token 序列，用同一个自回归接口统一学习。对基座研究员来说，核心问题不是机器人应用本身，而是：能否把语言、轨迹、未来视觉状态都压进统一词表和统一损失框架，让不同监督共同更新同一套主干参数，并从人类交互视频中获得可迁移的 embodied pretraining 信号。

评将动作和视觉目标离散化并统一到 next-token 预测框架中，是 VLM 向具身智能扩展的典型范式，值得关注其 tokenizer 设计和联合训练策略。

ATLAS: Agentic or Latent Visual Reasoning? One Word is Enough for Both

这篇工作处理的是一个很具体但一直没有被很好统一的问题：视觉推理里，模型往往需要在中间步骤对图像做操作，例如放大局部、补辅助线、标注文字、更新棋盘状态。直接生成中间图像，代价高且通常要求统一生成架构；走 agent 路线，用代码或工具调用去操作图像，又会把一个简单视觉动作展开成很长的文本或程序，推理链变长，外部执行也带来延迟；走 latent reasoning 路线，把中间视觉过程塞进隐变量，虽然紧凑，但训练上常引入递归依赖，不再兼容标准自回归并行训练，而且监督往往绑定在少数任务上，泛化不稳。ATLAS 想解决的核心问题，就是能否用一种仍然保持标准 AR VLM 训练和推理接口的方式，把“中间视觉操作”压缩成可学习、可扩展、可被 RL 直接优化的离散推理单元。

评Meta 试图用离散 token 统一 agentic tool use 和 latent reasoning，思路很巧，值得看它怎么设计这个 functional token 的训练目标和 routing 机制。

Image Generators are Generalist Vision Learners

这篇工作要回答一个很直接的问题：图像生成预训练能不能像语言模型预训练那样，学到足够通用的表征，使同一个生成模型在少量额外监督下转成强视觉理解模型，而不牺牲原有生成能力。作者不是去证明“生成模型也能做几个理解任务”，而是试图证明 image generator 本身就是 generalist vision learner，只是还缺少像 LLM instruction tuning 那样的对齐步骤，让它按可评测格式输出视觉任务结果。

评将感知任务统一为图像生成，验证了生成式预训练在视觉领域的通用性，对多模态统一建模有启发，重点看任务转化方式和微调策略。
