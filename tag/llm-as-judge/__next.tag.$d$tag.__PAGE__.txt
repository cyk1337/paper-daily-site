First, it uses a paired design with a dual reference: the unmodified model is sampled twice for each prompt, and each optimized arm is compared against the mean of the two reference outputs. Second, it uses an exchangeability null: the two unmodified samples are exchangeable, so their judged difference should have expectation zero, and its spread estimates measurement noise on the same prompt distribution. Third, it includes an implementation null: strict speculative decoding with the standard rejection rule should exactly match the full model’s output distribution, so any measured degradation would indicate an implementation or measurement issue. The lower layer is Active Statistical Inference (ASI), and the upper layer is the paper’s Failure-Space Analysis (FSA) for annotation-policy design. ASI combines judge predictions on all examples with human labels on a sampled subset to estimate the human-defined factual accuracy rate (FAR). Intuitively, the judge acts as an auxiliary signal rather than a replacement target, and the sampled human labels correct the residual. Because the sampling probabilities are known, the estimator remains anchored to the human target and admits valid uncertainty estimates.

The more interesting contribution is FSA. Instead of reducing annotation policy to “sample low-confidence judge outputs,” the paper analyzes the structure of factuality-specific judge failures and turns that structure into predictive signals. The feature space includes at least four families: (1) judge-output features, such as claim-level verdict patterns and uncertainty cues; (2) evidence-quality features, such as incompleteness, temporal mismatch, conflict, or only indirect support; (3) task and input strata, such as query type and answer characteristics; and (4) answer-rubric alignment features, capturing cases where humans tolerate paraphrase or inference but the judge applies a more literal verification rule.

These features are used to estimate residual-risk regions, i.e., where judge-human disagreement is likely to be large. That residual-risk estimate is then converted into an ASI sampling policy, assigning higher inclusion probabilities to examples more likely to need human correction. This is an important design choice. The paper does not train a more complex replacement judge; it keeps the target fixed and improves the sampling design.
