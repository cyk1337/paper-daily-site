第一步是现象隔离。作者比较 released VLM 与对应 reference LLM 的文本能力差距，并引入 text-only further-training 对照，以及共享 base LLM 的 VL-versus-text matched trajectory，说明损失不是一般继续训练都会发生，而是和视觉模态适配强相关。损失最明显的不是开放式知识问答，而是那些对表面 token 格式、答案边界、最终输出规则很敏感的任务。

第二步是机制诊断。作者把问题归因到 attention-sink corruption。现代 LLM 往往会把大量注意力质量集中到少数早期位置，这些位置的 hidden state 又被少数高幅值固定特征维度主导，形成 sink。论文的假设是，这种 sink 有助于稳定每个位置对关键表面 token 的注意力分配，从而支撑格式敏感任务。VL fine-tuning 会扰动 query/key 投影 Wq、Wk；由于 logit shift 会随输入幅值放大，这种扰动在 sink 位置被特别放大，导致 per-head sink collapse。作者进一步分析不同 QK normalization 设计的差异：如果是 per-head QK-RMSNorm，可以直接去掉对原始输入幅值的显式依赖；如果只是 layerwise normalization，则每个 head 的尺度仍受整层能量分配影响，弱 head 会被进一步压缩，因此到 VL 训练开始前，某些 backbone 的 per-head sink 已经偏弱。

It does not modify DPO itself. Instead, it scores each preference pair, removes high-risk samples, and trains on a selected low-risk subset.

The analysis starts from the DPO gradient and identifies three sample-level features that govern the stability-plasticity trade-off.

The first is the length-normalized log-probability margin under the reference model, namely how much the initial model already prefers the chosen response over the rejected one. The paper argues that very large margins are risky: those samples add little new alignment information because the base model already strongly prefers the chosen answer, yet they still induce parameter updates that can further distort the model. Small-margin samples are more informative boundary cases and tend to produce less unnecessary drift.

The second is the token-length difference between chosen and rejected responses. Large length gaps can make preference learning partially collapse into learning a length bias, because sequence log-probabilities are token-accumulated quantities. Even with normalization, asymmetric gradients can remain. The paper treats this as a stability-related risk factor.

The third is the cosine similarity between TF-IDF representations of preference samples and those of a general benchmark or SFT-like corpus. This is used as a plasticity-oriented signal. If a preference sample is too similar to the general corpus, it may contribute little genuinely new alignment information while still causing repeated updates in already-covered regions. Samples that are more distinct are treated as more likely to carry useful alignment signal. The use of TF-IDF, rather than dense semantic embeddings, appears motivated by cost and interpretability.

BALIGN converts these three features into normalized risk scores and aggregates them into a composite risk score. High-risk samples are filtered out, and a predefined proportion of low-risk samples is retained for training. Conceptually, this differs from methods such as EWC, anchoring, KL regularization, or freezing-based strategies. Those methods constrain parameter movement during training. BALIGN instead tries to remove the data most likely to cause unproductive movement before training begins. 第二步是 LP-SFT 损失。对每个位置 t，先用 base model 的分布构造一个自适应 preservation set。直观上，集合大小由该位置的熵 regime 决定，目标是覆盖 base model 认为“局部合理”的若干替代 token，而不是机械取固定 top-k。然后把监督标签 token y_t 从这个集合里移除，避免 preservation loss 与 CE 在标签 token 上拉扯。最后只在这个集合内部做 locally normalized KL：先把 student 和 base 在 preservation set 上的概率重新归一化，再最小化 KL。这样保留的是候选替代 token 之间的相对排序和相对比例，而不是要求 student 维持这些 token 的原始总质量。

这个局部归一化是方法的关键。若直接做全分布 KL，student 为了拟合标签 token 需要把概率质量向标签集中，而 KL 会惩罚这种必要迁移；若只做 top-k token matching 但不归一化，又会把“保留结构”和“保留总质量”混在一起。LP-SFT 通过去掉标签 token + 局部归一化，把两件事拆开：CE 负责学目标答案，local KL 负责少破坏非标签候选的局部几何结构。

First, the authors study the frozen base model’s next-token distribution using top-K truncation and renormalization, with K=30 by default. They compute Shannon entropy and Renyi-2 entropy, and interpret them through effective support size. The key observation is that the entropy histogram is multimodal, with peaks near ln 1, ln 2, ln 3, and so on. This suggests that many token positions fall into discrete uncertainty regimes: some are nearly deterministic, while others naturally admit a small set of plausible alternatives. That motivates an adaptive preservation mechanism rather than a fixed top-k rule.

Second, they introduce LP-SFT. At each token position, they build an adaptive preservation set from the base model’s next-token distribution. The set size is guided by the local entropy regime, so the method preserves a variable number of plausible alternatives depending on how uncertain the base model is at that position. Crucially, the supervised target token is removed from this set to avoid direct conflict with the cross-entropy objective. The preservation loss is then defined as a locally normalized KL divergence: both the student and base distributions are renormalized only over the preservation set, and KL is computed within that local simplex.

This local normalization is the core design choice. A full-distribution KL would penalize the student for moving probability mass toward the supervised label, even when that movement is exactly what SFT should do. A non-normalized top-k matching loss would still entangle two different goals: preserving relative structure and preserving total mass. LP-SFT separates them. Cross-entropy learns the target token; local KL preserves the geometry among plausible non-label alternatives.

Relative to prior work, this is closer to structure-preserving regularization than to standard distillation, label smoothing, or preference optimization. Label smoothing injects a hand-crafted prior rather than using the base model’s actual local uncertainty. Full KL distillation preserves too much and conflicts more strongly with adaptation. Forgetting-aware SFT methods often operate at the sample or task level, whereas LP-SFT works at token level with position-wise adaptivity.15:T611,The experimental story is about trade-offs rather than a single headline metric. The paper compares LP-SFT against vanilla SFT and recent SFT-enhancement baselines, reporting both pass@1 and pass@k style metrics. The main claim is that LP-SFT improves or at least preserves pass@1 while retaining better pass@k and higher generation diversity, which is exactly what one would expect if the method preserves alternative valid continuations instead of collapsing them.

The ablations are the most informative part. Removing the step that excludes the label token from the preservation set makes the regularizer conflict more directly with cross-entropy and hurts performance or stability. Replacing locally normalized KL with ordinary KL or other non-local variants tends to over-constrain the student toward the base distribution and weakens target-domain adaptation. Using a fixed-size preservation set is generally worse than the entropy-guided adaptive set, which supports the claim that the multimodal entropy structure is not just an analysis artifact but a design signal.

The abstract does not expose the full numeric table, but the full paper emphasizes improved overall trade-offs across pass@1, pass@k, and diversity-related measures.
