18:T6d8,The method organizes each logical KV page into a three-tier lifecycle: Recent, Anchor, and Stale. Recent and Anchor pages are stored in FP8, while Stale pages are stored in a 3-bit TQ3 format. Recent covers fresh tokens needed for local coherence and ongoing reasoning. Anchor is reserved for globally important regions such as system prompts, attention sinks, retrieved evidence, or structural headers. Stale holds older non-anchor content that should not be dropped. The key contribution is not merely mixed precision, but integrating mixed precision into the paged-attention runtime itself. Every live-request page remains addressable; pages are not evicted. Format-specific kernels compute partial attention statistics on different physical formats, and the outputs are merged through a stable global softmax merge, instead of reconstructing a unified dense cache first. The paper also keeps key/value asymmetry explicit: key distortion changes routing, while value distortion changes retrieved content, so the codec and kernel interfaces preserve separate treatment for K and V even if a deployment uses the same nominal tier for both. The controller uses page age, structural metadata, attention statistics, layer/head sensitivity, K/V role, and current memory pressure to decide transitions. Attention-based promotion is built on globally normalized page mass, not raw local scores, so pages from different physical partitions remain comparable. On the engineering side, the paper adds an ownership protocol, fallback paths, dense-shadow and physical-byte instrumentation, and a CUDA-graph-compatible heterogeneous decode path. That makes the contribution primarily a runtime integration story rather than a new compression formula in isolation.19:T5fa,The main evaluation is on Qwen3.6-27B using a single 96GB NVIDIA RTX PRO 6000 Blackwell GPU. The paper first explains the compression opportunity from the model structure: Qwen3.6-27B has 64 language layers arranged as 16 groups of three Gated DeltaNet layers followed by one full-attention layer, so only 16 layers contribute attention KV. Each such layer has 4 KV heads with head dimension 256. Under this setup, the theoretical BF16 attention-cache cost is exactly 2.00 GiB per 32K-token sequence and 8.00 GiB per 128K-token sequence. Minima-KV reports 18.3 KiB of attention KV per live token in deployment accounting, which is a 3.50x reduction relative to BF16 and a 1.75x reduction relative to FP8. On quality, the paper reports profile-separated evidence. The clearly stated results include parity with the dense control on 16K RULER NIAH, less than 1% regression on 4K RULER NIAH, and LongBench v2 evaluation up to 64K context. One important caveat is highlighted by the authors: Qwen3.6 also has a separate per-sequence Gated DeltaNet recurrent state, which is not counted as compressed attention KV. That means the concurrency gain from KV compression is bounded by other fixed per-sequence allocations. This is an important systems point, because raw KV compression ratio does not translate directly into throughput gain.
