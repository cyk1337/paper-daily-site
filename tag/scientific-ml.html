Automating ML for Science: Can Frontier Agents Climb Scientific Hills in the Wild?

这篇工作要回答一个具体问题：当前 frontier coding agents 能不能在真实科学机器学习任务里，从已发表最佳模型出发，通过读论文、改代码、跑实验和迭代，把指标稳定往上推。难点不在于让 agent 完成一个干净的编程题，而在于科学 ML 代码库通常不规整，评测容易被污染，指标改进可能来自合理建模，也可能来自选择性汇报、测试集泄漏、度量操纵或硬编码。论文把问题定义为 automated scientific hill-climbing，并重点处理“可度量进步”和“防止评测游戏化”之间的张力。

评把“agent能做科研吗”落到可复现的长链路评测与轨迹诊断；结论不意外，但失败模式清单适合拿来做内部agent评测对照。
Ming Zhong,Stacy Li,Nicholas Carlini,Matthew Jagielski
