Remembering Distinct Items, Not Tokens: A Learnable Dirichlet-Process Cache Between State-Space Models and Attention

这篇工作处理的是固定状态序列模型与全注意力之间的一块空白地带。S4、Mamba 这类固定状态或选择性递归模型，推理便宜、缓存常数级，但内容寻址式召回能力受限，长程复制和精确回忆通常被状态维度卡住；标准 attention 则通过为每个 token 保留 key-value 项来解除这个上限，但代价是计算和缓存都随序列增长。作者要解决的问题不是再做一个近似 attention，也不是做固定预算 eviction，而是设计一种“按新颖性分配”的稀疏记忆：只有当输入足够新时才开新槽，否则并入已有槽，使记忆规模更接近 distinct items 的数量，而不是 token 数量。核心问题因此可以表述为：能否在不退回每 token 存储的前提下，为深层递归/状态空间骨干补上一种可学习、可增长、内容可检索的中间态记忆机制，从而改善关联召回与长序列效率的矛盾。

评长上下文架构的新思路，用DP-means做稀疏KV缓存的分配规则，可在内部长上下文ablation中尝试替换现有滑动窗口缓存，重点看§3的缓存算子设计。

Training Hybrid Block Diffusion Language Models with Partial Bidirectionality

这篇工作处理的是一个很具体、也很难绕开的系统问题：长上下文生成时，AR 解码主要受内存带宽限制，而不是算力限制。单 token 解码每一步都要读取越来越大的 KV cache，context 越长，吞吐越差。已有两条路分别缓解这个问题：一条是用 Mamba/SSM 这类线性时间 mixer 减少 cache 访问；另一条是用 block diffusion 一次并行生成一整个 block，提高每步产出 token 数。但把两者直接拼起来并不自然。像 DiffuMamba 这类全序列双向 denoiser 依赖反向扫描，反向状态会依赖当前 noisy token，因此无法像 prefix cache 一样复用。论文要解决的核心问题，就是如何设计一种既保留 block diffusion 并行生成优势、又能像 Mamba 一样原生缓存前缀状态的混合语言模型，并且让训练目标与推理时缓存对象严格对齐。
