这篇工作要解决的是：语言模型表征的 intrinsic dimensionality（ID）到底反映了语言本身的复杂性，还是被数据集构造方式，尤其是词汇多样性，系统性扭曲了。

评如果你平时拿 ID 给层表示下结论，这篇会逼你先做数据控制；不是 pretrain 方法论文，但它直接提醒很多 representation claim 可能是 dataset artifact。
