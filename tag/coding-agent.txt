17:T451,DiDPO extends group-relative advantage from the trajectory level into the internal structure of a code diff.

Using a CodeAct-like interaction loop, each action yields an edit (add/del/none) and the environment provides an outcome reward (e.g., tests pass/fail). Instead of treating the whole response/diff as one credit carrier, DiDPO:
1) Aligns diffs across multiple rollouts for the same task by finding highly similar sub-diffs that recur across trajectories.
2) Uses these recurring sub-diffs as anchors to induce sub-diff boundaries within larger diffs, aiming to isolate functional regions.
3) Groups aligned sub-diffs and computes a local group-relative advantage (diff-level advantage), then combines it with the trajectory-level advantage and assigns it back to the tokens responsible for generating those sub-diffs.

To avoid anchors that are too broad (mixing functions) or too narrow (hard to aggregate), it introduces a groupability score to select anchors that balance semantic scope and group mass. The method remains critic-free and claims no additional rollouts beyond the sampled group.18:T41b,The main evaluation runs on the full Python slice of SWE-bench Pro (266 tasks) under the official capped-budget protocol. SuperScout resolves 159/266 tasks, slightly above the best single fixer's 158/266, at a total cost per solve of $0.230 versus $1.274 for the strongest model — roughly a 5x reduction. The searcher's total GPU cost across the evaluation is only $1.13, negligible in the overall budget. A pre-hoc audit replays published per-task outcomes on three SWE benchmarks: solve-set containment ranges from 0.773 to 0.941 across model pairs, and 0.90–0.93 even among frontier-only pools, confirming heavy nesting. None of the learned routers tested (k-NN, logistic, MLP, clustering, language-rule baselines) reliably beats always calling the strongest model. A paired calibration study on 100 fresh tasks shows the handoff redistributes rather than adds solving ability: it lifts the three cheaper fixers while slightly hurting the strongest, and hidden-state features improve cost-aware routing, whereas the handoff text alone does not.19:T484,The benchmark contains 102 web pages across 16 vertical domains, covering two complementary task types: Macro-Level Regional Reconstruction, which requires agents to reconstruct a missing semantic region from visual reference and integrate it into the existing page structure; and Micro-Level Localized Modification, which requires agents to fix fine-grained structural and stylistic defects without disrupting unrelated content. A Reverse-Corruption Trajectory Engine is used to construct evaluation data: starting from a complete golden page, the engine iteratively injects deterministic structural and stylistic defects, then reverses the corruption sequence to produce a repair trajectory. The target state for each turn is uniquely defined, enabling reproducible multi-turn evaluation without costly turn-level human annotation. A dual-axis evaluation protocol is applied: a 5-dimensional VLM-based rubric measures target region fidelity for regional reconstruction tasks, while deterministic pixel-grounded alignment metrics are used for localized modification. Both evaluation streams explicitly measure content preservation outside the edit region.1a:T86b,The system starts from a merged PR and reconstructs the corresponding task condition on a healthy descendant revision of the same repository. The lifecycle is formalized as follows: a historical source patch P_s transforms V_pre into V_post; Change2Task starts from a healthy modern base H, applies a task patch D to create a task state C, and records a restoration patch G that returns C to a restored state H'. The goal is behavioral restoration, not textual identity.

The framework has four main stages. First, it extracts task evidence from the PR: description, implementation patch, and executable checks. From this it derives target checks, regression checks, and a source change profile. The source change profile later serves as a fidelity constraint, ensuring that the reconstructed task remains close to the original maintenance intent and edit footprint. Second, it selects a healthy modern base revision, preferring explicitly declared healthy or target revisions and otherwise resolving an accessible descendant in the repository lineage.

Third, it reconstructs the task using a three-level escalation strategy. Level 1, Patch Reversal, handles cases where the historical patch still maps cleanly to modern code. Level 2, Code Mapping, is used when files, symbols, or APIs have moved but correspondence can still be established. Level 3, Agent Reconstruction, is invoked when direct mapping is too weak and an agent must re-create the change in the modern repository. This staged design is sensible: use the cheapest and most deterministic reconstruction first, and escalate only when repository evolution breaks direct transfer.

Fourth, the system validates the full lifecycle. Healthy, task, and restored states must satisfy their respective checks, and the task is verified for provenance, behavior, scope, and restoration. Objectives are expressed through task adapters, which define the expected output, executable oracle, and edit scope for task types such as Bug Fix, Feature Addition, Test Generation, API Migration, and Security Repair. That adapter abstraction makes the framework broader than a bug-fix-only benchmark generator.1b:T4f6,The evaluation focuses on reconstruction yield, fidelity, agreement with historical tasks, and environment-efficiency gains. From 1,130 eligible changes, the system finalizes 900 paired tasks, which is a strong yield given the validation requirements. On 621 matched Bug Fix candidates, Change2Task reconstructs 500 tasks, compared with 387 for SWE-smith PR Mirror, indicating better coverage when transferring historical changes to modern code.

For quality, the corpus reaches 0.894 task-weighted source change profile fidelity, measuring how well the reconstructed task preserves the original PR’s change scope and structure. More importantly, matched agent evaluation shows up to 98.0% outcome agreement between historical and reconstructed cases while preserving agent ranking. That means the reconstructed tasks are not merely superficially similar; they behave similarly enough to maintain comparative evaluation signals.

On efficiency, reusing 388 modern bases reduces environment time by 58.4%, storage by 71.2%, and end-to-end expenditure by 10.8%.
