9:T7da,The work has three technical layers. The first is dataset construction. The authors build a benchmark of 317 manually verified knowledge reversals across medicine, law, software, and platform policy. Each case is grounded in dated official sources and includes a clear validity boundary between what used to be correct and what is correct now. This is more precise than generic knowledge-conflict datasets because the temporal transition is explicit.

The second layer is behavioral evaluation. The paper measures poisoning in a strict way: only cases where the same model is correct without retrieval but becomes wrong after seeing outdated evidence count as stale-document poisoning. That isolates the net harm introduced by retrieval. The experiments compare neutral retrieval prompts with prompts that explicitly instruct the model to follow the document, separating natural deference from instruction-amplified deference.

The third layer is temporal-applicability and internal-mechanism analysis. On 50 source-verified reversals, the authors hold the historical evidence text fixed and vary only the evaluation date. This tests whether the model changes its trust in the same evidence when it moves from valid to superseded. Models react only modestly to date changes alone, but respond much more strongly when the validity boundary is made explicit. That means the problem is not simply missing date tokens; it is a failure to map dates into applicability judgments. Causal interventions further show that information about when evidence applies can directly change the final answer, while matched control interventions do little. Attention analysis suggests that some components contribute early to this evidence-arbitration process.

The paper also evaluates a fixed hybrid reranker that combines semantic relevance, recency, and supersession cues. It reduces poisoning when metadata are reliable, showing that part of the problem can be mitigated on the retrieval side, though not fully solved there.a:T643,The evaluation covers 12 models: six API models and six open-weight models ranging from 4B to 72B parameters. Cross-domain behavioral experiments focus on Qwen2.5 and Llama-3.1 at both small and large scales. Temporal-applicability experiments include Qwen2.5-7B/72B and Llama-3.1-8B/70B. Causal analyses focus on the 72B and 70B models.

Three result groups matter most. First, outdated retrieval flips otherwise correct answers even without explicit document-following instructions: 30% for Llama and 37% for Qwen. So the failure is not just a prompt-engineering artifact; the models already over-defer to retrieved evidence. Second, explicit instructions to follow the document raise those flip rates to 66% and 75%, showing that instruction following amplifies the selective-trust failure. Third, matched up-to-date evidence is followed almost universally, which means the models are not generally bad at using retrieval. They are bad at deciding when retrieved evidence should no longer be trusted.

The paper also finds that recent medical reversals are harder than long-established ones, suggesting that near-boundary temporal drift is especially difficult. In the fixed-evidence, changed-date setup, changing the evaluation date alone produces only limited behavioral adjustment, whereas making the validity boundary explicit causes much larger answer changes. That contrast is central because it separates date awareness from applicability reasoning.
