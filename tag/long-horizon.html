这项工作处理长程 LLM agent 强化学习里的稀疏奖励归因问题：终局成功或失败只给出轨迹级信号，但策略更新发生在每个动作响应上。GRPO 这类 critic-free 方法把同一个 outcome advantage 分配给整条轨迹，容易奖励成功轨迹里的无效动作，也会惩罚失败轨迹里的有用动作。已有 step-level 方法尝试用重复状态或历史匹配构造局部比较，但对 rollout 之间共享的转移结构利用不足，也缺少一个机制来判断局部 step credit 是否有足够证据支撑。

评Agent RL 的 credit assignment 题，先读方法图和 advantage 构造；若实验环境够干净，值得复现到内部长程工具任务。
Hongxi Yan,Ziyue Huang,Shichao Fan,Qingjie Liu

OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution

OpenART 解决的是 agent 安全评测中的“环境持久化”问题。传统评测多看单轮提示、短任务或可重置环境，但真实 agent 会反复读写同一工作区、记忆、工具状态和权限配置。早期看似无害的状态修改，可能在几十步之后触发安全失败。OpenART 把评测单元从单个 prompt 转到可执行、可演化的环境。

评值得扫方法和任务统计；它提醒 agent eval 不能只看单轮成功率，状态污染会改变风险曲线。
