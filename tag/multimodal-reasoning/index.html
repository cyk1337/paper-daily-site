Beyond the Sequentiality Bottleneck: A Hybrid Diffusion-Autoregressive Framework for Efficient Multimodal Reasoning

这篇工作要解决的不是单纯“让 diffusion LM 也能做推理”，而是更具体的一件事：在多模态推理里，AR 模型的逐 token 生成把搜索、规划、验证都绑在一条串行链上，导致推理成本随思维链长度线性累积，而且一旦前面某一步偏了，后面只能在错误前缀上继续展开。作者把这件事概括为 sequentiality bottleneck。DLM 有并行细化和多轨迹生成的优势，但标准 diffusion 训练只学数据分布，不学“朝正确答案收敛”的目标导向推理，所以生成的 reasoning trajectory 往往流畅但不够可验证。CoRAL 的核心问题，就是如何把 DLM 的并行规划能力和 ARM 的语义一致性、答案综合能力拼成一个可用的推理系统，并且让 planner 学到 outcome-aware 的推理轨迹，而不是只学表面语言模式。

评值得看，但先别把它当“DLM 取代 AR”的证据；重点读 planner/executor 分工和 reward-guided denoising，看看是否真有 clean speed-quality gain。

DRT: Dense Reasoning Trace for Efficient and Grounded Multimodal Reasoning

这篇工作要解决的是多模态 CoT 的表达空间问题。作者认为，当前 MLLM 的推理轨迹主要写在自然语言里，导致两个直接后果：一是 token 冗余很高，推理成本大；二是随着轨迹变长，模型越来越容易盯着自己生成的文字，而不是回到图像证据，造成视觉 grounding 变弱。论文的核心问题不是单纯“怎么少输出一点 token”，而是“能不能把推理从自然语言表达空间迁到更紧凑、更结构化的 trace 空间，同时保持甚至提升正确性和 grounding”。

评值得扫方法和奖励设计；若结果成立，它会削弱“CoT 必须是长自然语言”的默认假设。
Wan Xu,Yuanfan Guo,Kevin Han,LaLa Chen,Wangmeng Zuo
