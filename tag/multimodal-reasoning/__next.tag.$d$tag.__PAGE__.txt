9:T769,The method defines Visual Information Gain, or VIG, at each reasoning position. Conceptually, VIG measures how much the image reduces uncertainty about the token generated at that position, conditioned on the question and prior context. The paper motivates this as a conditional mutual information quantity, but the practical implementation uses an entropy difference computed from two forward passes of the same policy: one pass with the image, and one pass with visual tokens removed. If the image makes the predictive distribution much sharper, the token is treated as visually grounded and receives a higher VIG score. If the entropy barely changes, the token is likely recoverable from text context alone and is treated as filler.

These token-level scores are aggregated over the <think> span into a sequence-level reward, which is then combined with standard answer-accuracy and format rewards inside GRPO. A key design choice is that the method never rewards shorter chains directly. Shorter reasoning emerges because the policy learns to keep tokens that earn visual support and drop tokens that do not. This is different from length penalties, which can suppress both useless and necessary reasoning. It is also different from trace distillation, which depends on external compressed chains and inherits teacher bias.

Another notable choice is the use of entropy reduction rather than only the log-probability gap for the sampled token. Entropy reduction captures whether the image globally resolves uncertainty at that step, not just whether it happens to boost the chosen token. In that sense, the reward is closer to a token-level grounding diagnostic than a simple preference score. Methodologically, this is a post-training RL contribution rather than a new pretraining objective, but the signal itself is general and could plausibly inspire pretraining-time multimodal objectives.a:T664,The evaluation spans three Qwen3-VL-Thinking model sizes, six main multimodal reasoning benchmarks, and an additional test on R1-Onevision-Bench. The paper emphasizes the accuracy-efficiency Pareto frontier rather than reporting accuracy alone. On Qwen3-VL-8B-Thinking, VIG reaches 64.92% average accuracy and 52.42 ACC per 1k tokens. Relative to the strongest compression baseline, ThinkPrune, it improves accuracy by 2.37 points and efficiency by 39.4%.

The qualitative example in the introduction is also informative. On a simple geometry problem, the base model spends 823 reasoning tokens and still answers incorrectly. An L1-style length penalty reduces the chain to 412 tokens and recovers the correct answer. VIG solves the same problem in 105 tokens by directly reading the visual label and applying the correct relation. That example supports the paper’s claim that the issue is not merely verbosity, but visually disengaged reasoning.

From the available full text, the main empirical story is built around three comparisons. First, VIG is compared against base, plain GRPO, L1, ThinkPrune, and TALE, showing that a visual-dependence reward outperforms purely textual compression signals. Second, the gains persist across model sizes, suggesting the effect is not tied to one checkpoint. Third, on R1-Onevision-Bench, the method ranks first overall and first or tied-first in three of five subject categories, which argues against narrow benchmark overfitting. The model first produces a fixed-length continuous latent trajectory and then generates the answer conditioned on the image, question, and latent states. Training has two stages. The first stage, Utility-Aware Latent Distillation SFT, trains a teacher with a visual bottleneck attention mask: answer tokens cannot directly attend to image tokens, and question tokens are also blocked from image tokens to avoid indirect leakage. The second module is Implicit Generative Prediction. Given a causal antecedent, the model must generate the consequent future video. This tests whether the model can enact its putative reasoning in the pixel domain over time. The key idea is to separate “knowing” from “rendering.” A model may answer causal questions correctly yet fail to generate a causally valid rollout, or it may generate something visually plausible without robust explicit causal understanding. That decomposition is more informative for world-model claims than standard fidelity metrics such as FVD or static multimodal QA benchmarks.f:T82f,The method has three main components.

First, DeltaV introduces update-centric visual modeling. Instead of generating a full intermediate image at each reasoning step, the model conditions on historical visual states and predicts only the visual update tokens needed to represent the change from the previous state. The motivation is straightforward: allocate modeling capacity to changed regions and changed semantics, rather than repeatedly encoding static background or already established structure. In this formulation, interleaved multimodal reasoning becomes visual state transition modeling rather than image-by-image generation.

Second, the paper proposes the TSIM Router. Different reasoning steps involve very different amounts of visual change, so a fixed number of update tokens per step is inefficient. The router uses temporal similarity to determine how many tokens should be allocated to each update. The procedure groups samples into TSIM intervals based on change magnitude, fits a reconstruction-quality-versus-token curve for each interval, and stops allocating tokens once the marginal reconstruction gain falls below a threshold. As a result, highly similar states receive few tokens, while larger transitions receive more. The key idea is not a complicated routing network, but an explicit coupling between token budget and state-change magnitude.

Third, the authors build StructCoT, a 1.05M-sample dataset spanning 44 task domains. Their argument is that existing interleaved multimodal reasoning datasets are too narrow, often centered on mazes, puzzles, or visual search, and therefore insufficient for learning general update-centric reasoning behavior. In this setup, the data asset is tightly coupled to the modeling choice: without enough diverse state transitions, the model cannot learn a robust update policy.

At a higher level, DeltaV is not just a token compression trick. It changes the supervision target inside a unified model from reconstructing the full current image to predicting the incremental visual evidence that causes the next reasoning state.10:T5e6,The provided excerpt does not include the full result tables, so the exact gains cannot be quoted reliably.
