5:T46f,The authors extend activation patching to VLMs. Because VLMs inject visual information differently, they implement model-specific adapters for direct visual-token concatenation, MLP projectors, and cross-attention based integration. For each image-question pair, they run a clean pass, a corrupt pass, and a patch pass. The corrupt pass injects 3σ Gaussian noise into visual tokens at layer 0, reducing visual evidence to near chance. The patch pass restores one layer-component activation from the clean run. The indirect effect is measured by the final-token logit gap between the correct and incorrect answer. Components are selected by comparing normalized indirect-effect distributions between correct and hallucinating samples, using Welch’s t-test, Benjamini-Hochberg correction, and a Cohen’s d threshold. Positive-effect components are assigned to the visual grounding pathway; negative-effect components are assigned to the hallucination pathway.
