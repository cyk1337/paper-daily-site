S2T-RLHF: Hierarchical Credit Assignment for Stable Preference-Based RLHF

这篇工作针对 RLHF 里一个很核心但长期没有处理干净的问题：偏好奖励通常只在整段回答级别给一个标量，而策略更新发生在 token 级，导致 credit assignment 含糊、梯度方差大、训练不稳，尤其在长回答上更明显。作者进一步指出，问题不只是“奖励太稀疏”，而是“奖励粒度和语言语义结构不匹配”。如果把一个本来只在 response 级定义、且带噪声的偏好信号，强行细化到 token 级，未必更好，反而可能把 reward model 的局部误差放大，造成长度偏置、奖励集中和 collapse。论文要解决的，是如何在不重训 reward model、也没有 token 级标注的前提下，构造一种更稳定的层次化 credit assignment。

评只看方法动机和稳定性实验；若结果扎实，应复现“句子粒度优于 token 粒度”这个 RLHF 信号设计 prior。
Wei Chen,Guanghui Zhu,Yafei Li,Limin Wang,Yihua Huang
