18:Taa6,方法由三个关键部件组成。

第一，训练目标。作者采用 uniform token replacement 而不是 mask corruption。也就是每个位置以概率 1-α_t 被替换成词表中的均匀随机 token，而不是替换成特殊 [MASK]。这样得到的输入始终是一份“完整草稿”，错误 token 没有显式标记，模型必须同时学会两件事：当当前位置本来就对时要保留，当它错时要修复。训练时在所有位置上监督 clean-token posterior，等价于让 denoiser 在完整但带噪的草稿上做全位置重建。

第二，单次前向的上下文评估。直接拿 denoiser 对当前 token 的概率给草稿打分会有偏差，因为在 uniform corruption 信道下，观察到 token x_i 本身会显著提高 x_i 为真的后验概率，即便把该位置拿掉后，周围上下文其实更支持另一个 token。作者用已知的 corruption process 做 Bayes 校正，把“观察到自身 token 带来的证据”除掉，再重归一化，恢复出该位置的 cavity conditional，也就是 p(x_i | c, z_{-i}, t) 这一类“给定条件和其他 noisy token，但不看自己”的分布。然后把草稿每个位置真实 token 的负对数 cavity conditional 相加，得到 cavity energy。这个量不是精确联合似然，而是一个噪声平滑后的 pseudo-likelihood 型能量分数，但足够用于候选草稿之间的比较。

第三，推理算法 propose-read-retain。推理不是标准 diffusion ancestral sampling，也不是每轮完全重启。流程是：保留当前最优草稿；对其做部分 re-noise，避免陷入局部最优，同时保留部分结构；用同一个 denoiser 对所有位置并行预测 clean token，直接形成 candidate draft；再用一次新的前向、在固定 read noise level 下计算 candidate 的 cavity energy；若能量更低则接受，否则保留旧草稿。所有 proposal pass 和 scoring pass 都计入固定预算，最后返回最低能量的草稿。这里有两个设计很关键：一是“提案”和“评估”分开，避免用生成时的同一组 logits 给自己背书；二是 retain best draft，而不是每轮独立采样，这使得搜索更像局部修订而不是盲目重启。

和已有方法相比，差异主要在三点。相对 MDLM/UDLM 一类离散 diffusion，作者不依赖 reverse transition 逐步采样，而是把 denoiser 的 clean-token 预测直接当作修订操作。相对普通 non-autoregressive refinement，作者补上了一个有理论依据的整稿评分机制，而不是默认并行替换一定更好。相对 energy-based LM，这里的能量不是单独训练的打分器，而是从 denoiser 的后验结构中解析出来的。19:T477,For pretraining and alternative language-modeling paradigms, the contribution is meaningful in three ways. First, it moves diffusion-style language modeling away from schedule-driven ancestral denoising toward a draft-refinement loop where the denoiser acts as both editor and evaluator. Second, it introduces cavity energy, which turns a denoiser trained under uniform corruption into a contextual whole-draft scoring mechanism resembling noise-smoothed pseudo-likelihood. That is relevant beyond this paper: masked LM, any-order LM, energy-based LM, and draft-based reasoning all face the same issue of scoring partially self-supported token configurations. Third, it identifies and fixes a subtle but important failure mode: denoiser confidence on an observed token mixes contextual support with evidence from seeing that token itself. If that self-token evidence is not removed, the model can prefer internally stable but wrong drafts. This is not a drop-in replacement for mainstream large-scale AR pretraining, but it is a serious step in the line of work that tries to challenge next-token decoding with alternative generation dynamics.1a:T9f4,The method has three main components.

1) Training under uniform corruption. Instead of mask corruption, each token is independently replaced with a uniformly sampled vocabulary token with probability 1-α_t. The noisy input is therefore always a complete draft: every position contains an ordinary token, and wrong positions are unmarked. The denoiser is trained to reconstruct the clean sequence at every position. This forces it to learn both preservation and repair: keep a token when it is already supported, change it when the surrounding draft suggests it is wrong.

2) One-pass contextual evaluation via cavity correction. A naive score based on the denoiser probability of the current token is biased, because under the known corruption channel, observing token x_i itself is strong evidence in favor of x_i, even if the rest of the draft would support another token. The paper derives a correction that divides out this self-token likelihood and renormalizes, recovering the cavity conditional: the distribution of x_i given the condition and all other noisy draft tokens, but not the observed token at position i itself. Summing the negative log cavity probabilities assigned to the draft tokens yields cavity energy. This is not an exact joint likelihood; it is a learned, noise-smoothed pseudo-likelihood-style energy. But it is enough to rank candidate drafts.

3) Propose-read-retain inference. Inference starts from random tokens. 这个设计有几个关键点。第一，cross-problem control 的作用是消掉“给模型额外看一段解答文本”带来的通用风格偏移，只保留与当前题目相关的 peer-induced change。没有这个参照，模型可能学到的是 generic solution-format bias，而不是题目局部推理信息。第二，取最小支持幅度而不是平均，是为了抑制错误 peer 带来的过强偏移，属于一种保守的交集式蒸馏。第三，学生训练时只看题目和自己的前缀，不看 peer；peer 只在训练时用于构造 teacher，因此推理时没有额外开销。这一点和 privileged-information distillation 的设定一致。

The key idea is not to imitate any single peer solution. Instead, SRD measures how different same-problem peers consistently shift a frozen model’s token distribution relative to a shared control.

For a problem x, the current policy samples K trajectories. When training on a student-generated prefix, the method selects M same-problem peers and one cross-problem solution as a control. A frozen copy of the initial model predicts next-token distributions under two conditions: the student prefix plus a same-problem peer, and the student prefix plus the cross-problem control. Their difference is a peer-induced residual shift. SRD then aggregates these residuals conservatively: it keeps only coordinates whose direction agrees across peers, and sets the retained magnitude to the smallest supporting magnitude among those peers. This shared residual is added back to the frozen model’s distribution under the original student input, producing a teacher target. The student is trained with forward KL on that target.

Three design choices matter. First, the cross-problem control removes generic distribution shifts caused by simply appending a solution-like text, so the retained residual is more problem-specific. Second, the minimum-supported magnitude acts as a conservative intersection rule, reducing the influence of noisy or wrong peers. Third, peers are used only to construct the teacher during training; the student itself conditions only on the problem and its own prefix, so inference cost does not increase.

Compared with RLVR or GRPO, SRD needs no reward and no answer-level ranking. Compared with standard on-policy distillation, it does not rely on an external stronger teacher. Compared with prior on-policy self-distillation, it does not require reference answers.
