H-Scale: Hessian-Guided Scale Refinement for NVFP4 Sub-Byte LLM Inference

NVFP4（Blackwell 原生支持的 4-bit 浮点）采用极细粒度 micro-block（如 group size=16）+ 每组 FP8 局部 scale 的设计。精度损失的关键不再只是“权重量化值怎么选”，而是“每组 scale 怎么校准”。论文要解决的是：在不改推理算子、不引入额外推理开销的前提下，如何更好地为每个 16 元素组选择硬件合法的 scale，从而显著缩小 NVFP4 与 BF16 的精度差距。

评只看 scale 搜索目标和校准激活近似；若内部要上 Blackwell FP4，应复现实验而不是只信 PTQ 曲线。
Hao Yu,Zheng Li,Dayiheng Liu,Jianwei Zhang

Evaluating CUDA Tile for AI Workloads on Hopper and Blackwell GPUs

这篇论文评估 NVIDIA CUDA Tile 在 Hopper 和 Blackwell GPU 上是否适合 AI 工作负载，尤其是 GEMM、融合多头注意力和端到端 LLM 推理。核心问题很工程化：CuTile 能否在减少 kernel 开发成本的同时，接近或超过 cuBLAS、Triton、WMMA、FlashAttention-2 等成熟实现的性能。

评只看 attention 与 GEMM 两组表即可；CuTile 不是预训练方法，但 Blackwell kernel prior 需要更新。
Divakar Kumar Yadav,Tian Zhao,Deepak Kumar
