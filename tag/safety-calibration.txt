18:T5de,Blindspot is built as a live simulation framework rather than a fixed set of pre-generated trajectories. Each scenario specifies an initial world state, available tools, policies, user objectives, and safety-relevant conditions. A User Agent interacts with a Target Agent over multiple turns, and in adaptive attacks the next user action is generated conditioned on the target agent’s actual behavior and the current attack state. The Target Agent acts in a stateful tool environment where tool calls, outputs, and resulting state transitions are explicitly recorded. This matters because the benchmark can judge what the agent actually executed, not just what it claimed in text. The current release includes 22 attack families and 35 scenarios across 7 domains, with 25 core-domain and 10 cross-domain scenarios. The dataset contains more than 2,500 long-horizon trajectories with an average length of 14.7 turns. The adjudication protocol is a major design point. Instead of a binary success/failure label, the benchmark defines five trajectory-level outcomes: Safe Completion, Correct Refusal, Unsafe Completion, Over-Refusal, and Indeterminate. These labels are assigned through an evidence-grounded pipeline that combines policy checks, authorization checks, tool-execution traces, environment-state validation, semantic judges, and human review when needed. Second, long-horizon tool environments reveal failure modes that are largely invisible in one-shot benchmarks, especially attacks involving intent hijacking, objective drift, memory poisoning, and indirect prompt injection. Third, repeated-run robustness matters: the same model can behave inconsistently across rollouts, which is a serious deployment concern for agents.
