EMBER: Efficient Memory via Budgeted Evidence Retention for Long-Horizon Agents

论文处理的是长周期 Agent 的“预查询记忆保留”问题：在未来问题未知、原始历史不能在查询时完整回看的条件下，系统应该预先保留哪些源证据。难点不在于能否把日志存下来，而在于查询时可用的检索和上下文 token 有预算；如果写入阶段漏掉关键证据，后续只能扩大检索范围或把更多历史塞回模型。
