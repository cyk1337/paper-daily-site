WHALE: A Simple Recipe for Joint Harness-Weight Optimization

这篇工作处理的是 agent 系统里一个常被拆开看、但实际强耦合的问题：模型权重和外部 harness 代码需要联合优化。这里的 harness 不是简单 prompt，而是决定上下文拼接、工具暴露、错误处理、控制流和终止条件的可执行程序。单独训权重，容易被一个差 harness 卡住；单独搜 harness，又可能因为当前模型能力不够而搜不到有效结构。论文要解决的不是“如何做更强 agent”，而是“在权重更新和 harness 搜索时钟不同、反馈噪声不同的情况下，怎样做稳定、预算可控、可归因的联合优化”。

评将模型权重微调与 Agent 脚手架（harness）搜索结合起来交替优化，思路很 clean，对于关注 Agent post-training 和系统协同设计的预训练研究员值得一读。
Haechan Kim,Yoonho Lee,Gisang Lee,Chelsea Finn,Kangwook Lee
