9:T429,QUASAR separates reconstruction into quantization and dequantization. Quantization maps full-precision weights to discrete codes while treating the clipping range as a searchable variable. Dequantization maps those codes back to reconstructed weights using learned scales, and optionally offsets for asymmetric quantization. The reconstruction objective is not plain L2 error; it is a Hessian-weighted, loss-aware reconstruction error inspired by second-order PTQ. To make this usable inside QAT, QUASAR approximates the Hessian diagonal with an exponential moving average of squared gradients, giving per-parameter saliency scores. For a small set of candidate clipping ranges, it fixes the discrete code assignment, solves the dequantization parameters in closed form by saliency-weighted least squares, and chooses the candidate with the smallest loss-aware reconstruction error.
