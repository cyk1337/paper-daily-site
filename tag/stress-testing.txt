18:T478,The method is an iterative editing/search loop with three roles: an LLM prompt editor, a target model, and an LLM-as-judge hallucination scorer.
- Start from source-grounded seed prompts.
- At each round, the editor rewrites the prompt conditioned on (i) the target’s latest answer and (ii) the judge’s category-specific severity score plus explanation.
- From round 2 onward, the target is also given feedback on its previous response and instructed to reduce hallucination, creating an adversarial dynamic where the editor adapts to the target’s attempted self-correction.
- A run retains the prompt associated with the highest-severity response.

Hallucinations are operationally split into intrinsic (task-internal misinterpretation/reasoning errors) and extrinsic (unsupported additions beyond the provided source). The judge is prompted with few-shot examples and produces a 0–100 integer severity score.
