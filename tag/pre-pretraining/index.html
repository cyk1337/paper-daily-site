Rethinking Pre-pretraining

这篇论文重新检验 synthetic pre-pretraining，即先用合成分布训练模型，再进入自然语言预训练，是否真的比把同等算力直接用于自然语言更划算。核心问题不是“合成数据有没有用”，而是“把合成数据前置成一个独立 PPT 阶段，能否在 compute-matched 条件下提供可保留、可迁移的归纳偏置”。作者特别关注两个容易混淆的点：一是既有工作中 PPT 增益是否来自额外算力；二是增益是否对初始化、自然语言数据量、token/parameter ratio 等训练配置敏感。

评这篇直接动摇“先学合成再学语言”这个小圈子 prior；先看初始化复现实验和 881M/50B 那组，若你内部还在配 PPT 预算，应立刻停下来重算账。
Alexander Stern,Tim Rocktäschel,Acyr Locatelli,Laura Ruis

Synthetic Pre-pretraining Survives Scale, but Not as a Grammatical Prior

这项研究检验 synthetic pre-pretraining 是否在更接近真实预训练的条件下仍然有效，并追问它为什么有效。已有工作认为，在正式预训练前先用 Dyck 语言等非自然语言序列 warm-up，可以给模型提供可迁移的语法先验。但过去实验通常停留在 1B 以下模型、不到 2B token 的短预训练、以及单一 web text 语料，无法判断这种收益是否只是小规模或早期训练现象。

评这篇应进 internal ablation：PPT 的收益能撑到 7B/100B token，但 grammar-prior 解释要降权。
Atsuki Yamaguchi,Tatsuro Inaba,Joel Niklaus,Michal Štefánik,Aline Villavicencio,Nikolaos Aletras

Logic Before Language: Pre-pretraining on Formal Derivations Fosters Skill Acquisition and Compressibility

这篇论文问的是：在自然语言预训练之前，先用更结构化的符号任务初始化 Transformer，是否能稳定提升后续语言学习效率。作者认为 Dyck 括号语言、排序、集合操作这类 pre-pretraining 任务太窄，只覆盖局部结构或过程模式；形式逻辑推导同时包含变量绑定、量词、关系依赖、规则组合和长程约束，更接近语言模型需要学到的抽象结构。

评把 symbolic PPT 推到 100B token 是少见的干净 setup，重点读加速曲线与 compressibility 指标，对数据 curriculum 有直接 ablation 价值。
Jo-Ku Cheng,Nikolaos Aletras,Marco Valentino
