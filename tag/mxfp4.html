TORQ: Two-Level Orthogonal Rotation for MXFP4 Quantization

这篇工作处理的是一个很具体但很现实的问题：MXFP4 这类 block floating-point 4bit 格式在硬件上已经开始成为低比特推理的主流候选，但把它直接用于 LLM 激活量化时，精度下降往往明显，原因并不只是“4bit 太低”，而是激活分布与 MXFP4 的表示结构存在两层错配。第一层是 block 之间的能量分布极不均匀，少数高方差 block 决定了共享指数，导致同 block 内大量小值被压成 0；第二层是 block 内部的数值分布与 e2m1 codebook 的理想假设不匹配，真实激活大量集中在 0 附近，造成 codebook 使用塌缩，很多码字几乎闲置。论文的核心问题不是一般性的“如何做 W4A4”，而是“如何让激活分布主动适配 MXFP4 这种共享指数浮点格式的几何结构”。

评把MXFP4掉点拆成“跨block方差/码本利用”两类结构问题，这个诊断值得抄；只看方法动机与消融，别期待预训练启示。
Zukang Xu,Xing Hu,Dawei Yang
