Competing Learning in Hybrid Architectures

这篇论文研究混合架构里一个很具体但此前没有被讲清的问题：当模型同时包含 recurrence/linear mixer 和 softmax attention 时，层之间并不会自然形成理想分工。作者发现存在一种“Competing Learning”现象：谁先学会某类检索功能，谁就会通过损失下降和梯度抑制，削弱其他层继续学习同类功能的信号。在常规数据分布下，现代 recurrence 层往往比 attention 更早学会 retrieval，于是 attention 没有真正长成擅长长程检索的模块，最终导致混合架构的分工失衡。

评这篇会改你对 hybrid layer“自然分工”的 prior：先看 attribution 和中途冻结实验，若 setup 干净，内部做一次 recurrence/attention 抢功能复现很值。
