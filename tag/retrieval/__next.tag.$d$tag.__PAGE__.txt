9:T518,EvalMem abstracts heterogeneous memory systems into an encoding–retrieval–generation pipeline. The tested system first runs natively: it processes dialogue history, updates its memory store, retrieves context, and generates an answer. EvalMem then diagnoses the completed run using benchmark annotations. The Encoding Examiner checks whether the target fact is present in the memory store. The Retrieval Examiner checks whether the system’s native retriever returns usable evidence. The Generation Examiner tests whether the model can answer when given oracle evidence. An Attribution Agent merges these decisions into an 11-code multi-label defect set, allowing coupled failures while avoiding retrieval blame when the source fact is absent from the store. The framework also separates POS queries, where the system should remember and retrieve a fact, from NEG queries, where the correct behavior is refusal due to insufficient evidence. To make store-level diagnosis more reliable, the Encoding Examiner uses a recall-first agentic RAG routine that searches the original memory store with both the query and the source evidence. The paper also introduces DynaMem-Bench for on-policy dynamic evaluation and MemWiki, a search-friendly auxiliary structure built from a system’s own memory export.a:T8e8,方法上，这篇文章做得比较扎实，重点不在模型创新，而在协议设计和误差定位。

第一，作者在两个域上统一了评测协议。数学部分使用 MathNet-Retrieve：500 个 query，对 117,088 条完整语料全库排序，不做 shortlist。每个 query 都有唯一 gold source problem，同时 benchmark 还人为放入一个 lexical 相近但结构不同的 near-miss。作者同时报告 strict Hit@k（只认 gold）和 lenient Hit@k（gold 或 near-miss 都算），这个差值正好用来量化“模型是不是被表面相似项吸走了”。

第二，trajectory 部分没有沿用原 benchmark 的 pooled relevance，而是把 336 条 ALFWorld 轨迹全部按 task type 重新穷举标注，并进一步定义两层 disguise：定义(i)要求同 task type 但 target object 不同；定义(ii)再额外要求 receptacle 也不同，尽量去掉最容易驱动 lexical similarity 的 token。这里的设计很关键，因为它把“程序相同”与“对象词相同”拆开了。

第三，作者专门研究 lexical control 的符号翻转。他们引入一个便宜的 lexical reranker，观察它在两个域里的效果方向：在数学里它会伤害结构检索，因为它把 near-miss 顶上去；在轨迹里它反而能提升结果，因为 benchmark 构造仍保留了某些表面线索。随后又做 token-class ablation，去定位究竟是哪些 token 类别在驱动这个现象。

第四，作者分析了 LLM reranking 的 judge dependence。不是只看“加了 reranker 后有没有提升”，而是换三个独立训练的 judge，看恢复方向是否稳定、效应量是否可迁移。结论是方向大体一致，但幅度、tier profile、甚至哪个 judge 更强，都会随域和 query style 改变。这说明 reranker/judge 的结论可移植性很差。

第五，文章还做了 contamination probe 和 downstream null analysis。前者检查 reranking 增益是否集中在知名竞赛题上；后者在一个刻意构造的坏检索条件下比较 oracle retrieval 与 adversarial retrieval，发现下游几乎无差异，并进一步把原因定位到答案截断与评测解析问题，而不是 retrieval 真没作用。这个部分虽然偏评测卫生，但很有现实意义。b:T873,最关键的结果在数学检索。重 disguise 条件下，两个 production embedders 的 strict Hit@1 都是 0.0%，bootstrap 95% CI 也是 [0.0, 0.0]。但正确答案通常并没有消失，而是“在 top-10 里几乎总能找到”。这说明问题不是召回不到，而是排序头部被 lexical near-miss 占据。作者进一步统计 miss 的构成：在 95.2% 到 99.8% 的 miss 中，排在正确答案前面的候选在词面上比 gold 更接近 query。这基本把失败机制钉死在 surface-form bias 上。

轨迹检索的结果更微妙。只要 gold 定义排除了 query 中的 literal object 和 receptacle token，embedding retrieval 就会掉到 chance 以下。这个现象比“性能下降”更强，因为它说明模型不仅没抓住结构，反而系统性偏向错误的表面匹配项。

lexical reranker 的实验是全文最有信息量的对照之一：同一个 lexical control，在数学上伤害 retrieval，在 trajectory 上提升 retrieval。作者通过 token-class ablation 说明，这不是偶然噪声，而是 benchmark 中哪些 token 被保留、哪些被 disguise 的结果。

LLM reranking 部分，作者发现三个 judge 在“是否有恢复趋势”上方向一致，但效应量并不稳定；其中一个 judge 在同一域内跨 query style 时，增益会下降超过三分之一。也就是说，judge 排名本身都不稳。

污染分析里，reranking 的收益更多集中在知名竞赛题；在 6 个 judge-by-candidate cell 中，只有 1 个在 bootstrap 下能自信拒绝零效应，其余更多是方向一致但统计强度不足。这个表述比较克制，没有把 contamination 说得过头。

First, the authors enforce a shared evaluation protocol across two domains. In mathematics, they use 500 queries from MathNet-Retrieve against the full 117,088-item MathNet corpus, with no shortlist. Each query has exactly one gold source problem, plus a planted lexical near-miss that is structurally different. They report both strict Hit@k, which counts only the gold, and lenient Hit@k, which also counts the near-miss. The gap between the two is a direct measure of surface-form attraction.

Second, for ALFWorld trajectories they do not rely on pooled relevance from the source benchmark. Instead, they exhaustively label all 336 corpus items by task type and define two disguise regimes: same task type but different target object, and then same task type with both object and receptacle changed. This is important because it separates procedural similarity from literal token overlap.

Third, they study a lexical-control sign flip. A simple lexical reranker is applied in both domains. In math it hurts structural retrieval by promoting the planted near-miss; in trajectories it helps because the benchmark still preserves some surface cues. Token-class ablations are then used to identify which token categories drive the effect.

Fourth, they analyze judge dependence for LLM reranking. Instead of reporting a single reranking gain, they compare three independently trained judges and ask whether the recovery direction, effect size, and judge ranking are stable across domains and query styles. The answer is largely no for effect size portability.

Fifth, they add a contamination probe and a downstream null analysis. The contamination probe checks whether reranking gains concentrate on well-known competition problems. The downstream analysis compares oracle and adversarial retrieval under a deliberately bad retrieval condition and then traces the null result to truncation and evaluation artifacts rather than to retrieval being inherently useless.d:T7f3,The strongest result is in mathematics. Under the heaviest disguise tier, strict Hit@1 is 0.0% for both production embedders, with bootstrap 95% confidence intervals of [0.0, 0.0]. But the gold item is usually still retrievable: it is almost always somewhere in the top 10. So the failure is not recall collapse; it is head-of-list ranking being captured by lexical near-misses. The mechanism is quantified directly: in 95.2% to 99.8% of misses, the item ranked above the gold is more lexically similar to the query than the correct answer.

The trajectory results are subtler but arguably more revealing. Once the gold definition excludes the literal object and receptacle tokens from the query, embedding retrieval falls below chance. That is stronger than a simple degradation result: it indicates systematic attraction toward the wrong surface match.

The lexical reranker experiment is one of the most informative controls in the paper. The same lexical signal damages retrieval in mathematics and improves it in trajectories. Token-class ablations support the claim that this is driven by benchmark construction, not by noise.

For LLM reranking, the recovery direction replicates across three judges, but the effect size does not transport cleanly. One judge loses more than a third of its gains across query styles within the same domain. So even judge ranking is unstable.

In the contamination probe, reranking gains are concentrated on well-known competitions. Out of six judge-by-candidate cells, only one is confidently non-null under bootstrap resampling, while the others are directionally consistent but weaker statistically.

In the downstream study, oracle and adversarial retrieval are effectively indistinguishable. A complete-answers-only analysis then shows that the headline 69.5% zero-shot accuracy is largely a truncation proxy, leaving almost no effective headroom for retrieval to matter.
