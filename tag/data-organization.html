Beyond Rephrasing: Book-Level Organization Improves Synthetic Textbook Data for Mid-Training

现有合成教科书数据研究大多将收益归因于生成内容本身或局部改写风格，未系统研究「相关内容是否被组织为连贯的书籍级文档」这一独立变量——包括生成阶段的全局结构规划，以及训练阶段是否保留完整书籍的文档边界、连续位置编码和文档内注意力（而非拆分为独立段落）。

评受控消融做得干净，把“合成书有用”归因到文档级组织而非内容，应立刻在自己的 mid-training 数据里复现这个边界条件。
Jiawen Tao,Miao Peng,Yaoming Li,Xiaokun Yuan,Mengzhou Wu,Wenhan Yu,Guoan Wang,Nuo Chen,Tong Yang,Maxm Pan

SDO: Structure-Aware Data Organization for Efficient LLM Post-Training

后训练阶段的数据组织通常是一次性静态预处理：基于 embedding 的分组在训练前固定，无法随训练中样本实际被暴露的程度调整，导致部分样本被重复更新、另一些样本欠优化，mini-batch 内还可能混入语义无关样本造成梯度冲突。

评关注训练过程中的 data curriculum 和 batching 策略，提出基于 embedding 相似度和动态曝光反馈的 batch 构造方法，对优化 SFT/Mid-train 数据采样效率有一定启发。
Jinliang Gao,Ning Yang,Hai Wang,Baili Xiao,Pin Lyu
