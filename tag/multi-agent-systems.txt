18:T56c,OptiMAS builds all agents on a shared ReAct-style execution primitive. Each agent alternates between thought, action, and observation. Multi-agent coordination is implemented through a proactive assign-deliver protocol: a parent agent delegates a subtask as a tool call, the sub-agent solves it, and the result is returned as a structured observation. This removes the need for a fixed workflow while still keeping execution structured.

The optimization scope covers prompts, role definitions, skill descriptions, tool access, model choices, and the directed collaboration graph among agents. To avoid unstable free-form code generation, tools are selected from a predefined macro-library. The collaboration graph is constrained to be a DAG, which helps prevent uncontrolled recursive delegation.

The main departure from search-based MAS evolution is the optimization loop. A candidate MAS runs on training tasks, producing full interaction trajectories and task-level metrics. These are converted into a textual loss signal for an agentic optimizer, which induces textual gradients and edits the MAS configuration. A dual-track memory mechanism stores, validates, and retrieves optimization insights across a long evolution horizon. The central contribution is not a new prompt template, but a continuous, memory-supported optimization process for evolving the whole MAS configuration.19:T73a,CAMA has two main components: correlation-aware evidence decoupling and missing-evidence recovery.

The first component is query-conditioned latent-source arbitration. Instead of treating each retrieved memory as an independent vote, the method maps memories into latent evidential factors or slots. The intuition is that multiple memories may express the same underlying source of evidence, just through different agents, timestamps, or phrasings. CAMA uses neural dependency inference to estimate whether memories are redundant under the current query, and combines this with provenance-based symbolic priors derived from source chains, dependency links, or write traces. Hypothesis support is then aggregated at the latent-factor level rather than the raw-memory level, reducing repeated counting of the same evidence.

The second component is sequential evidence recovery. The paper argues that the initial retrieval set is itself biased: similarity-based retrieval tends to over-select correlated memories and miss independent evidence that could overturn a false majority. CAMA therefore does not restrict arbitration to the initial top-K slice. Instead, it learns a recovery policy that, under a budget, decides whether to expand retrieval or trace provenance/dependency links to acquire additional independent evidence. This is a sensible design because it treats the current evidence set as a biased sample rather than a complete basis for decision-making.

Methodologically, this is not a new LLM architecture. It is a combination of evidence aggregation, symbolic provenance, and sequential retrieval policy for multi-agent memory arbitration. The main novelty is making dependence modeling query-conditioned and latent-source based, rather than relying on static heuristics such as agent identity, timestamp, or semantic similarity alone.1a:T4fe,The experiments are designed to show that CAMA suppresses false majorities caused by correlated memories and outperforms standard baselines on long-term multi-agent memory benchmarks. The baseline families appear to include majority voting, confidence or relevance weighting, and retrieval-augmented reasoning methods. The qualitative result is straightforward: when memories share sources or propagate through the system, conventional aggregation overestimates support for a hypothesis, while CAMA is better able to recover the correct arbitration by grouping correlated evidence and recovering missing independent evidence.
