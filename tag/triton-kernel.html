Realizing Native INT8 Compute for Diffusion Transformers on Consumer GPUs: A Fused INT8 GEMM Kernel for Ideogram 4.0

这项工作解决的是 diffusion transformer 在消费级 Ampere GPU 上 W8A8 INT8 推理没有真正使用 INT8 tensor cores 的问题。现有“INT8”路径把权重和激活量化后又反量化成 bf16，再执行 bf16 matmul，因此速度反而可能慢于 FP8 或 NF4 路径。

评揭示了消费级显卡上 W8A8 推理变慢的底层原因（框架实现未真正调用 INT8 Tensor Core），并给出了 Triton 融合算子解法，做推理优化的工程师值得一看。

Rotation-Aligned Key Channel Pruning for Efficient Vision-Language Model Inference

这篇论文解决 VLM 推理时视觉 KV cache 过大的问题。视觉输入通常被编码成数百到数千个 token，图像、视频和多图场景会让 KV cache 成为主要显存瓶颈。现有方法多做视觉 token pruning，但直接丢 token 会伤害文档理解、细粒度感知和 grounding 等任务。作者转向另一个压缩轴：在保留更多视觉 token 的同时压缩 Key 的 channel 维度。
