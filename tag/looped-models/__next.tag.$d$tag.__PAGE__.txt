9:Tc54,方法核心是把 looped model 训练成一个带 recurrent state 的条件去噪器，再把推理解释为概率流 ODE 的积分过程。

先看问题设定。输入是条件 c，输出是离散序列 x。传统 looped model 维护隐藏状态 z_i，并用共享参数的更新函数 f(z_i, c) 反复迭代，再用头部 g(z_i) 解码答案。难点在于实际训练常用 stop-gradient 的 per-step loss，导致第 i 步的损失不会回传到更早状态 z_{<i}，于是早期步骤没有动力去准备后续计算。

作者的改法是：不给每一步都要求“直接答对最终答案”，而是给每一步分配一个不同噪声水平下的局部去噪任务。具体做法是从真实解 x 构造一条从高噪声到低噪声的中间状态轨迹 x_t，并让第 i 步 recurrence 负责在对应噪声水平上预测去噪方向，也就是 velocity / denoising target。关键不只是多噪声训练，而是两点耦合设计：
1) progressively decreasing noise levels：随着 recurrence 时间推进，任务从粗糙恢复走向精细恢复，天然形成“先搭框架、再修细节”的计算分工；
2) shared noise across adjacent objectives：相邻时间步看到的是同一底层噪声样本在不同噪声强度下的版本，因此目标之间是 temporally associated 的。这样即便梯度只覆盖局部，模型也会倾向于学出能在相邻步骤之间延续的隐藏状态，而不是每步都重新开始。

在形式上，作者采用 categorical continuous flow matching 的监督版本。模型输出的是定义在概率单纯形上的 velocity field，而不是直接输出离散 token。隐藏状态 z 与当前噪声化样本、条件 c 一起决定这个 velocity。训练时优化局部 denoising / flow matching 目标；推理时从噪声初始化，通过数值积分沿 learned probability flow 逐步运输到解分布附近，再做 rounding 得到离散答案。

这个 formulation 有几个重要区别。

和标准 diffusion/flow model 不同：这里不是单次前向网络在连续时间上求解，而是把 recurrent hidden state 显式并入动力系统。也就是说，ODE 的速度场不仅依赖当前 x_t 和 c，还依赖一个会跨步累积计算的内部状态 z_i。这样“流”负责提供平滑、局部一致的训练信号，“loop”负责存储和滚动中间计算。

和已有 looped reasoning 方法如 TRM 相比：作者不再要求每一步都直接预测最终解，也不依赖长程 BPTT 去塑造 recurrence，而是通过噪声调度把不同步骤的职责拆开。训练信号更局部，但目标之间更连续。

和在 recurrence 中直接注入随机噪声以获得多样性的方法相比：looped flows 的随机性来自概率运输过程本身。作者指出，Euler integration 下可以得到多个有效预测，这意味着模型天然支持一题多解，而不是靠每步加噪声硬造随机性。

The paper offers a concrete training interface for hidden-state deliberation: instead of relying on long-horizon backpropagation, it uses flow-style local denoising objectives that are temporally aligned across recurrent steps. For pretraining researchers, the significance is threefold.

First, it targets a core question in test-time scaling: how to make extra inference steps actually perform additional computation rather than repeat a shallow transformation.

Second, it reframes multi-step reasoning as probability flow integration. That gives a clean separation between training and inference: training uses local denoising targets, while inference can scale compute by refining the temporal grid or using better numerical solvers.

Third, it provides a mechanistic claim, not just a benchmark gain: long-range useful computation can emerge from local objectives if adjacent objectives are properly coupled through noise levels and shared noise. That is a meaningful idea for latent reasoning, non-AR language modeling, and recurrent world-model-style architectures.b:Taa0,The core idea is to train a looped model as a recurrent conditional denoiser and then perform inference by integrating a probability flow ODE.

In the standard setup, a looped model maintains a hidden state z_i, updates it recurrently with shared parameters, and decodes a prediction from each state. The practical problem is that training often uses stop-gradient per-step losses, so the loss at step i does not shape earlier states z_{<i}. Early updates therefore have little incentive to build representations that will help later updates.

Looped flows changes the target. Instead of asking every recurrent step to directly predict the final answer, it assigns each step a local denoising task at a different noise level. Starting from the ground-truth solution x, the method constructs noisy intermediate states x_t along a path from high noise to low noise. The recurrent model is trained to predict the denoising direction, or velocity, appropriate for the current noise level.

Two design choices are essential.
1) Noise levels decrease progressively across recurrent time. This creates a natural division of labor: earlier steps solve coarser subproblems, later steps refine them.
2) Adjacent objectives share the same underlying noise realization. This temporally associates neighboring denoising tasks, so even with only local gradients, the hidden state is encouraged to carry forward useful computation rather than restart from scratch at each step.

Formally, the paper uses a supervised version of continuous flow matching for categorical outputs. The model predicts a velocity field on the probability simplex rather than directly outputting discrete tokens. The velocity depends on the noisy current state, the conditioning input, and the recurrent hidden state. Training optimizes local denoising / flow-matching losses. Inference starts from noise and integrates the learned probability flow toward the solution distribution, then rounds to a categorical answer.

This differs from standard diffusion or flow models because the recurrent hidden state is part of the dynamics. The flow provides smooth, locally consistent supervision; the loop stores and accumulates intermediate computation over time. It also differs from prior looped reasoning methods such as TRM, which typically ask each step to predict the final answer directly and therefore suffer more from local-training mismatch. Here, the recurrence is shaped indirectly through a sequence of aligned subproblems.

A particularly interesting aspect is the credit-assignment shift: instead of solving temporal credit assignment with long BPTT, the method translates it into a noise-scale curriculum plus coupling between adjacent objectives.c:T780,The evaluation covers six reasoning benchmarks. The headline result is that looped flows outperforms prior looped models on five of them and remains competitive on the sixth. The paper explicitly reports that, using the same architecture as TRM, performance improves from 44.6% to 58.8% on ARC-AGI-1 and from 7.8% to 12.2% on ARC-AGI-2. Those are meaningful gains because ARC-style tasks are sensitive to compositional generalization and internal multi-step computation.

The stability results are just as important as the benchmark numbers. Prior looped models can become unstable when unrolled longer, sometimes failing even on simple problems. Looped flows is reported to learn more stable recurrences, with performance improving more reliably as inference computation increases. That directly supports the claim that the method trains recurrent computation rather than merely fitting local predictions.

The ablations indicate that each component matters. Based on the paper’s framing, the important ones are:
1) removing the progressively decreasing noise schedule hurts performance, suggesting that coarse-to-fine task allocation is useful;
2) removing shared noise weakens temporal alignment between adjacent objectives and reduces the usefulness of recurrent state transfer;
3) replacing flow-based inference with more direct step prediction reduces the benefit of extra inference compute;
4) the choice of numerical integrator affects final accuracy, which implies the model is genuinely using the learned continuous flow rather than treating it as a training-only wrapper.

Another notable result is that inference can use a finer temporal grid than training. This means the model is not just memorizing a fixed discrete program length; it learns a computation trajectory that can be interpolated at test time.
