9:T6bb,UNO turns the understanding branch into an explicit teacher for the generation branch. The setup is based on a BAGEL-like unified model, where an understanding expert handles visual understanding and language interaction, and a generation expert handles image synthesis. In the baseline design, information flows mostly one way: generation is conditioned on understanding features, but receives little direct semantic pressure. During post-training, UNO freezes the understanding expert and feeds it intermediate noisy generative representations, so understanding objectives can backpropagate directly into the generative pathway. Two complementary supervision signals are added. The first is language supervision via captioning, which injects high-level semantic abstraction and improves concept discrimination and instruction alignment, but is sparse and may miss local detail. The second is visual understanding supervision via regression with metaquery tokens, which provides denser structural and fine-grained visual information by matching the generative representation to the understanding expert’s visual semantic space. Together, these losses mean the generation branch is no longer shaped only by low-level denoising or flow objectives; it is also constrained by higher-level semantics and mid-level structure. The key idea is not a new heavy module but a new supervision path: the frozen understanding expert becomes a semantic organizer for the generative representation.
