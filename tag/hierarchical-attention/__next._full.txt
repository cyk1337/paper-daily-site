18:T457,The paper starts from a naive Block Sparse Attention construction. Naive BSA computes full attention, aggregates token-level attention mass within each chunk, and selects the top-K chunks with the largest mass. This is too expensive to use as an efficient method, but it provides a full-attention-derived target pattern for chunk selection. HiLS approximates this pattern without the full-attention pass. It appends a landmark token to each chunk and uses it to form a trainable chunk summary key. The query-summary scoring function is motivated as a first-order Taylor approximation to the chunk mass induced by full attention. The second component is a hierarchical factorization of attention. A query first allocates mass across retrieved chunks, then computes token-level attention independently within each selected chunk, and finally fuses the chunk-specific outputs using the retrieval scores. The important distinction from prior sparse attention methods is that the chunk score is not merely a pre-selection heuristic.
