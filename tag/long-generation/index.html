RIFT: KV Cache Compression for Draft Models with Complementary Compressibility Training

这篇工作处理的是 speculative decoding 在长输入、长输出场景下的一个很具体但常被低估的问题：draft model 的 KV cache 在固定预算下怎么压缩，才能尽量维持与 target model 的对齐。已有 selection-based 压缩方法多在 prefill 阶段一次性选出“重要”历史 token，例如 SnapKV 这类做法；问题在于生成继续推进后，早先选出的 prompt token 会逐渐失去相关性，而新生成前缀的重要性快速上升。作者把这种现象定义为 decode staleness。它不是简单的压缩误差，而是压缩策略与生成过程之间的时间失配：静态选择在 decode 早期可能有效，但随着 output length 增长，draft 看到的上下文越来越偏离 target 真正依赖的上下文，接受长度随之下降。论文要解决的核心就是：在固定 KV 预算下，如何同时保留远端 prompt 信息和近期 decode 信息，并降低训练时全缓存、推理时压缩缓存之间的失配。

评不是 pretrain 论文，但它把“长输出下 KV 压缩目标会随 decode 漂移”说得很对；先看方法图和 latency-quality 曲线，若你做 speculative serving，这个假设应立刻纳入内部 ablation。

Moment-KV: Momentum-Based Decode-Time KV Cache Compression for Long Generation

长文本生成任务中，KV Cache 的线性增长导致严重的显存瓶颈。现有压缩方法多针对 Prefill 阶段，或在 Decode 阶段使用简单的滑动窗口/最近性启发式策略，忽略了注意力机制的动态时序特征（即重要 token 的注意力可能短暂下降后恢复），导致关键 token 被过早驱逐。

评思路不新到改写范式，但“prefill 别乱压、decode 用时间聚合做保留”这个判断很实在；先看 attention dynamics 分析和压缩率-质量曲线。

Hybrid Policy Distillation for LLMs

这篇论文讨论的是 LLM 蒸馏里一个很实际但常被拆开看的问题：蒸馏效果不是只由“选 forward KL 还是 reverse KL”决定，而是由散度方向、优化方式、以及 on-policy / off-policy 数据来源共同决定。现有做法往往只固定其中一个轴，例如离线 SFT、离线 FKLD、或者先 SFT 再做 on-policy distillation，但这些组合各有明显缺陷：forward KL 覆盖模式多，却容易把学生拉向过平滑分布；reverse KL 更偏 mode-seeking，生成质量可能更好，但在 teacher-student 差距大时不稳定；纯离线训练有 train-test mismatch，纯 on-policy 又贵且容易把 teacher 评估预算耗在低质量 student rollout 上。论文要解决的核心问题，是如何在一个统一框架里同时利用 forward / reverse KL 的互补性，并把轻量 on-policy 信号并入蒸馏，而不失去 one-hot 监督的训练效率。

评不是预训练主线，但统一 KD 目标这件事讲得比较干净；只看目标推导和长生成 ablation，能学到蒸馏里 forward/reverse KL 到底各自补什么坑。
Wenhong Zhu,Ruobing Xie,Rui Wang,Pengfei Liu
