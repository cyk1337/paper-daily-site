9:T556,PeekKV introduces a one-token peek on the decode path. After prefill, the system briefly continues generation before compressing the cache. It skips format tokens and inspects attention-related signals only at the first content token. The paper argues that this single observation is enough because head activity is relatively stable across subsequent content tokens.

From that one decode step, PeekKV derives two signals. The first is a head-group score, used to allocate KV budgets across groups of heads in proportion to their estimated importance. The second is an output-perturbation score, denoted as Δo, which measures how much retaining or removing a token affects the output of a given head group. This score is then used to decide which historical tokens each group should keep.

This two-level design is the key distinction. Unlike HeadKV, DuoAttention, or RazorAttention, PeekKV does not assume a fixed set of retrieval-style heads should always receive large budgets. Unlike AdaKV, it does not infer decode requirements from prefill attention. It reads the signal directly from the decode path, which is the central methodological claim. The runtime allocation also adapts across workloads: retrieval-heavy tasks naturally route budget to induction/retrieval-like heads, while code generation or tool-use workloads can shift budget toward other heads.a:T59f,The evaluation spans four public benchmarks covering long-context retrieval, text generation, and code generation. The headline model in the paper is Llama-3.1-8B-Instruct. Two reported numbers stand out: on RULER, PeekKV preserves 95.7% of full-cache accuracy at a 10% memory budget; on LongBench, it preserves 95.9% at only a 1.5% budget. The paper also reports that AdaKV, which uses prefill-time adaptive allocation, underperforms the static alternative on 10 out of 12 workload categories in their measurements, supporting the claim that prefill-based signals are misaligned.

The more informative part of the experiments is the diagnosis. First, head activity varies most strongly around the prefill/decode transition and on format tokens; after filtering those, content-token decoding is much more stable. Second, the identity of important heads is workload-dependent: retrieval heads dominate recall-heavy tasks, but non-retrieval heads can dominate tool-calling or code-generation outputs. Third, ablations indicate that head-budget allocation alone or token retention alone is weaker than combining both. Fourth, the overhead analysis shows that the one-token peek mainly delays compression by a few decode steps, so peak memory briefly remains at full-cache level, but the extra runtime cost is limited. Post-trained models preserve a large part of their base model’s profile but tend to spread more overall, and this effect is not specific to rising serial demand. They start from 21 hand-written neutral prompts in single languages and define the objective around the target language probability at the first generated token. They then introduce LIHA, a head-level attribution score computed via activation patching between a clean target-language prompt and a corrupted foil-language prompt. This identifies attention heads whose activations causally push the model toward the correct response language.

Next, they run Edge Attribution Patching over source-head to destination-layer edges. EAP uses a first-order Taylor approximation to estimate the effect of replacing an upstream clean activation with its corrupted counterpart, allowing many edges to be scored with one backward pass per sample. Because this is only an approximation, they cap the candidate set at 2,000 edges per model and then run exact activation patching on each candidate edge. Only edges with sign agreement between EAP and exact patching are retained. The surviving edges are assembled into a DAG, interpreted as the verified first-token broadcasting circuit. Finally, they validate the graph with boundary ablations: removing in-graph edges should hurt language identification, while removing out-of-graph edges should not.

The structural findings are more interesting than the raw scores. Four standalone models show a recurring deep-layer hub topology, where a small number of late heads appear to broadcast language identity forward. The Pythia models also show more explicit multi-hop routing chains. By contrast, Qwen2.5-1.5B Base and Instruct fail the same necessity/irrelevance separation and also have the weakest EAP-to-exact correlation.
