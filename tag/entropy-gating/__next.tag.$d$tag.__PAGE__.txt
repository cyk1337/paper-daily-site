a:Ta05,方法上有三个关键部件。

第一是 bitstream 表示。作者先把语义 token 编码成固定宽度二进制序列，每个 token 用 m 个 bit 表示。LM1B 上用 T=128、m=15；OpenWebText 上用固定 1024 个 code token、m=16。扩散不是在词嵌入或 simplex 上做，而是在这些 bit 的连续模拟值上做 variance-exploding Gaussian corruption。这样做的直接好处是输出头不再需要对整个词表做分类，而是对 bit 做紧凑预测；如果把 m 个 bit patch 成一个 sequence element，语义长度 T 不变，但每步输出复杂度从词表大小 V 变成 log V 量级。

第二是 matched-filter residual parameterization。单个 bit 在高斯噪声下的后验是有解析形式的，因此网络没必要重复学习“独立 bit 在噪声下如何恢复”这种容易写出公式的部分。作者把这个解析 posterior 先算出来，再让网络只预测 contextual residual，也就是上下文依赖带来的偏移项。这个设计和很多 diffusion/flow 模型里“把容易的部分解析化、把模型容量留给相关结构”的思路一致，但这里落在 bit posterior 上，针对性很强。它的价值不只是省参数，更重要的是把学习目标从低层噪声恢复，转向 token 间依赖和语义约束。

第三是采样器。作者反复强调，真正把前沿推上去的是 stochastic churn，而不是单纯的 deterministic probability-flow ODE。确定性采样已经能给出还不错的 GenPPL，但会过度收缩，导致 token entropy 偏低。为了解决这个问题，他们在 entropy-rate sampling grid 上加入 EDM 风格的 Langevin-type 随机修正，并比较了 full-band stochasticity 等设置。直觉上，这个 grid 会把求解器分辨率集中在 bit 不确定性快速消解的区域，而随机扰动在这些区域也最有效，因此能在不增加 NFE 的情况下把样本分布从“过于保守”拉回更接近真实数据熵。这个点很重要，因为它说明 diffusion LM 的评估不能只看 GenPPL，必须同时看 entropy，否则容易把 mode-seeking 误判成建模进步。

First, the representation. Each semantic token is encoded as a fixed-width binary code of m bits, and diffusion is performed over continuous analog versions of those bits under a variance-exploding Gaussian corruption process. On LM1B the setup uses T=128 and m=15; on OpenWebText it uses a fixed 1024-code-token representation with m=16. The model denoises all positions in parallel from Gaussian noise. Compared with token-space or simplex-space diffusion, this changes the output layer fundamentally: instead of predicting over the full vocabulary, the model predicts compact bitwise quantities, reducing the output complexity from O(V) to O(log V) when bits are patched appropriately.

Second, the matched-filter residual parameterization. For an isolated bit corrupted by Gaussian noise, the posterior has a closed form. The model therefore does not need to spend capacity relearning that independent-bit denoising rule. The analytic posterior is computed explicitly, and the network predicts only the contextual residual on top of it. This is a targeted decomposition: the easy local denoising part is handled analytically, while the network focuses on dependencies induced by context and semantics. That is a stronger claim than a mere reparameterization trick, because it changes what the model is asked to learn.

Third, the sampler. This is the most consequential part of the paper. A deterministic probability-flow sampler is already competitive, but the authors show that it is over-contractive: it can improve GenPPL by shrinking sample entropy below the data distribution. To correct this, they introduce EDM-style stochastic churn with Langevin-like corrections, applied on an entropy-rate sampling grid. The intuition is that the grid allocates solver resolution to the region where bit uncertainty is actually resolved, and stochasticity is most useful in exactly that region. As a result, the model can move to a better GenPPL–entropy frontier without increasing the NFE budget.

Relative to prior work, the novelty is not just “continuous diffusion for language.” Earlier discrete DLMs focused on discrete transition kernels; recent continuous methods often diffuse over one-hot embeddings or simplex states. This paper instead moves to bit-level states, analytically factors out independent-bit posteriors, and treats entropy-preserving stochastic sampling as a core design principle.d:T719,The key experimental story is the movement of the GenPPL–entropy frontier, not a single best score.

On LM1B, the deterministic 256-NFE sampler reaches GenPPL 82.90 at entropy 4.30, already competitive with recent continuous DLMs. Adding full-band stochasticity improves this to GenPPL 59.76 at matched real-data entropy 4.31. The paper compares this against LangFlow at 92.24 and an autoregressive baseline at 66.70. So the gain is not achieved by collapsing entropy; it reaches the AR quality regime while maintaining healthy token entropy.

On OpenWebText, the deterministic sampler gives GenPPL 46.32 at entropy 5.13, and full-band stochasticity improves it to 27.06 at entropy 5.26. LangFlow is reported at 36.53 with entropy 5.25, using 1024 NFEs, whereas this method uses 256 NFEs. That suggests the improvement is not simply due to more solver steps.

The systems results are also notable. Relative to a matched token-space model, the bitstream setup yields a 1.6× reduction in peak memory and 2.3× higher training throughput at LM1B scale. At OpenWebText scale, the gains grow to 3.3× training throughput and a 19× reduction in generation memory footprint. This scaling trend is exactly what the architecture predicts: the larger the vocabulary and the longer the sequence, the more painful the dense vocabulary head becomes.

The most important ablation-level takeaway is that full-band stochasticity is the main driver of the improved frontier. Deterministic sampling can look good on GenPPL alone but tends to under-shoot entropy. The entropy-rate grid and stochastic correction appear to work as a coupled design, not as two unrelated tweaks.
