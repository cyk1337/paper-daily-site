5:T7a5,The method, Conditional Entropy Shaping (CES), is built on top of DAPO. The starting observation is that a small number of high-entropy tokens in a reasoning trace often act as forking points, where the trajectory could branch in different directions. Prior work often rewards such tokens uniformly to preserve exploration, but that also encourages already-correct trajectories to remain diffuse and verbose. CES changes this by making the shaping policy both conditional and bidirectional.

During training, the model first receives a response-level correctness signal. Token-level entropy is then used to reshape the advantage:
1. For correct trajectories, high-entropy tokens are penalized. The intuition is that if a path already leads to the right answer, the model should become more confident and direct at those branching points rather than keep exploring unnecessarily.
2. For incorrect trajectories, high-entropy tokens are rewarded. The intuition is that these branching points are exactly where more exploration is useful, since the current path failed.

This differs sharply from a plain length penalty. Length penalties only care about output size and cannot distinguish necessary deliberation from wasteful expansion. CES instead tries to intervene at the uncertain decision points. It also differs from uniform entropy encouragement, which assumes exploration is always beneficial. CES says exploration should depend on whether the current reasoning path is already successful.

Algorithmically, CES does not replace DAPO. It augments DAPO’s token-level advantage shaping with a correctness-by-entropy conditional term. DAPO itself is an engineering refinement of GRPO for stable long-CoT RL; CES adds a mechanism to control the exploration-versus-conciseness trade-off inside that framework. The paper emphasizes that this is token-level, conditional, and bidirectional, rather than a query-level hard router or a post-hoc pruning method.6:T634,The evaluation covers 12 math benchmarks. The main claim is that CES improves the average accuracy-efficiency trade-off over DAPO: it maintains or improves accuracy while reducing unnecessary reasoning length. The provided text does not include the full result tables, but the framing is clear that the gain is not merely shorter outputs; it is a better joint operating point on correctness and token cost.

The paper also reports two useful robustness checks. First, it evaluates a smaller 1.5B backbone, suggesting the method is not tied only to larger reasoning models. Second, it includes out-of-domain benchmarks, indicating that CES is learning a more general adaptive reasoning behavior rather than overfitting to a narrow training distribution.
