Reasoning Core: Designing Broad Procedural Data for Completion-Supervised Reasoning Training

这篇工作要解决的不是“程序化数据能不能用”这个粗问题，而是更具体的一层：什么样的程序化推理数据，经过怎样的任务设计、答案表示、难度控制和语义校验，才能在 completion-supervised 的训练范式下，稳定转化为有效的推理训练信号。作者指出，很多已有 procedural benchmark 或 RL 环境并不是为 SFT 设计的：题目渲染未必唯一决定答案，答案格式可能冗长或存在多解前缀分叉，难度分布也未必适合 teacher-forced 学习。结果是，同样的 token 预算，真正转化成可学习监督的比例差异很大。Reasoning Core 的目标，就是把“可验证”进一步推进到“可高效监督训练”。

评做推理数据合成的可重点看任务级分析部分，紧凑目标和难度校准的结论可直接用于内部数据生成 pipeline 优化。
Damien Sileo,Valentin Lacombe,Dimitri Kachler
