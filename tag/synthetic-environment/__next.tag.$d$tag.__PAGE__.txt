Each source symbol maps to one or more globally unique multi-character right-hand-side strings. Global uniqueness makes primitive contraction unambiguous: any substring matching a right-hand side maps back to exactly one source symbol. The environment supports two inverse primitive operations. Expansion replaces a symbol with one of its right-hand sides. Contraction replaces a matching substring with its source symbol. Each step is serialized with the relevant position, span, and rule, which makes trajectory-level auditing possible.

A Transformer is pretrained from scratch on primitive rewrite chains. The generator starts from an initial word, repeatedly samples valid primitive expansions or contractions, appends the serialized action, and uses the resulting word as the next input. Pretraining exposes the model to local grammar-consistent dynamics, but not to the non-primitive shortcuts analyzed later. A contraction weight ρ controls the pretraining distribution; the default is ρ=4. This locally upweights contraction moves when both directions are available, without directly fixing the realized contraction frequency or chain length.

Post-training uses a goal-directed contraction task. A prompt is produced by expanding a target symbol c* into a longer word w_prompt. The model sees only w_prompt and must generate a contraction trace whose final emitted symbol is c*. The reward is binary and depends only on the final answer. Since the grammar is exactly known, each generated trajectory can be classified into primitive rule use, valid non-primitive composition, and invalid rewrite. Valid composition has two forms: sequential composition, which collapses an ordered chain of primitive contractions into a macro step, and parallel composition, which combines independent primitive contractions in one emitted step. This taxonomy is the technical core of the paper because it turns the vague claim of “new reasoning strategy” into an auditable trajectory property.

The comparison with rejection fine-tuning is important. RFT selects successful samples and can copy shortcut-like rewrites, but many of these are spurious. RL, especially with GRPO-style same-prompt contrast, concentrates probability mass on valid reusable structure and suppresses invalid passenger actions.
