AdaCodec: A Predictive Visual Code for Video MLLMs

AdaCodec 解决的是视频 MLLM 的视觉接口低效问题。现有模型通常把视频采样成一组 RGB 帧，再把每帧独立编码成视觉 token。相邻帧中大量背景、物体和布局是重复的，导致 token 数随帧数近似线性增长，并在长视频场景下形成覆盖范围、细节密度和延迟之间的冲突。

评如果你关心 unified LM 的视觉 token 预算，这篇值得扫；重点看它是否真利用时序可预测性做“新信息编码”，而不是换个名字做更强压缩器。
