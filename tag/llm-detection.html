LLM Detection as an Intervention: Downstream Impact under Strategic User Behavior

这篇工作研究的不是如何做更好的 LLM detector，而是把 detector 当作一种制度性干预后，会怎样改变用户行为，并进一步影响下游指标。核心问题是：一旦检测器不完美，用户就会策略性调整自己对 LLM 的使用比例，以及对文本做多少“去检测化”后处理。这样一来，检测器优化的表面指标和真实目标之间会出现偏差，甚至产生反直觉结果，比如检测上线后，部分用户反而更依赖 LLM，或者整体输出质量下降。

评对齐与检测政策研究的理论视角，结论反直觉但模型高度简化，作为安全策略思考的参照即可，不必深读。
Meena Jagadeesan,Tatsunori Hashimoto,Jon Kleinberg
