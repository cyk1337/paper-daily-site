9:T851,作者先定义 teacher-forced prompt offset：对两段不同 prompt 接同一 continuation，逐 token 比较 hidden states 的差异。因为 continuation 相同，hidden state 差异可以视为 prompt 单独留下的 imprint。再定义 decodability ratio，把这个 imprint 的大小和不同 continuation 自身带来的 hidden-state spread 做比较，用来判断 prompt 信息是否还可读。

经验上，作者发现 offset 随生成步数 t 近似按 t^{-α} 衰减。训练后的 Pythia 模型在较深层通常 α≈0.55–0.7；未训练但架构相同的模型 α≈0.2–0.5，而且随深度增加反而更慢。这说明训练后的模型更快忘掉 prompt。与此同时，continuation spread 基本不增长，β≈0，因此 decodability 的衰减率和 imprint 本身几乎一致，可以用单一指数 α 概括遗忘速度。

理论部分给出一个条件 no-hair 定理。对有限深度 pre-LN Transformer，在 pre-norm 激活非退化等较弱条件下，prompt offset 的上界是 O(P(log t)^{L-1}/t)，prompt 对下一 token 分布的条件影响也以同阶消失。作者还构造了可精确求解的 uniform-attention 线性 relay 模型，证明 t^{-1} 上界是可达到的，而不是松的形式结果。

机制分析是全文最有意思的部分。作者把 attention 对 offset 的贡献拆成 direct path 和 relay path。direct path 是当前位置 query 直接读 prompt token；relay path 是当前位置读前面 continuation token，而这些 continuation token 自身已经携带 prompt 信息。随着生成继续，真正维持 prompt 影响的主要不是 direct read，而是 relay。训练过程压制的正是这条 relay 通路，因此遗忘速度加快。论文还指出，只看 attention 权重会误判，因为权重本身不能反映信息是否真的沿着 value/residual 路径被传递和保留。

在干预实验里，作者通过对 prompt 加 log t 级别的 logit bias 补偿均匀注意力稀释，发现可以部分消除甚至反转遗忘。这支持了“稀释 + relay 抑制”这一解释，而不是把遗忘简单归因于上下文太长。a:T918,The central observable is the teacher-forced prompt offset. Take two different prompts followed by the same continuation, run the model under teacher forcing, and measure the hidden-state difference token by token. Because the continuation is identical, the difference isolates the residual effect of the prompt. The paper also defines a decodability ratio by comparing the imprint magnitude against the spread induced by varying continuations, which captures whether the prompt signal still stands out enough to be read off.

Empirically, the offset decays approximately as t^{-alpha}. In trained Pythia models, deeper layers typically show alpha around 0.55–0.7. In untrained models with the same architecture, alpha is smaller, around 0.2–0.5, and often decreases with depth, meaning slower forgetting. The continuation-induced spread is roughly flat, with beta near 0, so decodability decays at essentially the same rate as the imprint itself.

The theory section proves a conditional no-hair theorem. For finite-depth pre-LN transformers under mild non-degeneracy assumptions, the prompt offset is bounded by O(P(log t)^{L-1}/t), and the prompt’s conditional effect on the next-token distribution vanishes at the same rate. The authors also analyze an exactly solvable uniform-attention relay model, showing that the 1/t bound is asymptotically attainable.

The mechanism section is the strongest part of the paper. The attention contribution to the offset is decomposed into a direct path and a relay path. The direct path is the current query reading prompt tokens directly. The relay path is the current query reading continuation tokens that already carry prompt information. Long-range prompt influence is sustained mainly through relay, not through direct prompt reads. Training suppresses this relay channel, which explains why trained models forget faster. The paper further argues that attention weights alone are a poor diagnostic, because they do not tell you whether information is actually preserved through values and residual streams.

Finally, the intervention experiments add a log-t prompt bias to compensate for uniform-attention dilution. This can reduce or even reverse forgetting, supporting the dilution-plus-relay-suppression account rather than a vague “long context is hard” explanation.b:T725,The experiments compare trained and random-initialized models under teacher forcing on coherent text. The headline numbers are: trained models in middle and deeper layers show forgetting exponents alpha around 0.55 to 0.7, while untrained models are around 0.2 to 0.5 and often forget more slowly at greater depth. The theoretical 1/t rate is an upper bound; real models usually decay more slowly but still follow a stable power law rather than an exponential. The continuation spread exponent beta is close to 0, except for untrained Qwen, so prompt decodability is governed mainly by imprint decay.

For mechanism validation, the direct-plus-relay decomposition reproduces the measured alpha within 0.06 across layers and training stages. That is a strong result: the decomposition is not just qualitative storytelling but quantitatively tracks the observed forgetting rate. In training dynamics, the paper finds that forgetting emerges within the first billion training tokens in Pythia, before attention sinks appear. This suggests prompt amnesia is an early training phenomenon rather than a late byproduct of a specific attention pattern.

The intervention section shows that mild log-t compensation improves instruction adherence, but with a small perplexity cost and a tendency toward instruction echoing. In multi-turn dialogue, adherence also trends upward, but the gain is not much larger than what one gets from a constant bias with the same mean. That implies the benefit comes mostly from allocating more attention to the instruction, not from any uniquely privileged shape of the log-t schedule.

The main empirical takeaways are threefold: prompt forgetting is approximately power-law, training speeds it up rather than slowing it down, and attention maps are not a reliable proxy for retained prompt information.c:T440,This is a good skim paper, but it rewards careful reading of a few sections. Then read Section 4 for the theoretical result; the key point is that under fairly general pre-LN assumptions, prompt influence decays no slower than order 1/t, and uniform attention attains that bound.
