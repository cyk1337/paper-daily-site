PilotTTS: A Disciplined Modular Recipe for Competitive Speech Synthesis

当前语音合成（TTS）系统的发展趋势是数据集规模越来越大（数十万到数百万小时）、架构越来越复杂（多码本tokenizer、多阶段训练流水线、多个专用子模型），这给资源有限的团队构建有竞争力的TTS系统带来了巨大障碍。论文旨在提供一条更简洁、可复现的路径，用公开可用的组件和适度的数据量构建有竞争力的TTS系统。

评值得扫数据处理和 Q-Former conditioning；音频 LM 里少见的是可复现 recipe，而不是模型新意。

Guiding LLM Post-training Data Engineering with Model Internals from Sparse Autoencoders

在 RL post-training 的数据工程里（选哪些样本、怎么排 curriculum、怎么组 batch），主流做法依赖外部信号（偏好标注、verifier、pass rate、启发式难度等），成本高且覆盖不全。论文要解决的问题是：能否直接用模型内部表征（尤其是 SAE 提取的稀疏特征激活）来刻画“多样性/难度/质量”三类内禀数据属性，并把它们落成可执行的数据工程操作，从而提升 RL 训练效率与最终效果。

评值得读方法和消融：若 SAE 信号真能稳定迁移，RL 数据选择不必只靠 reward 和外部标签。

ERNIE-Image Technical Report

这篇技术报告解决的是开放文本生成图像模型里一个很现实的组合问题：在不把参数规模继续无节制做大的前提下，怎样同时提升复杂指令遵循、长文本渲染和审美质量，并把模型做成可开源、可部署、可继续微调的工业级系统。它不是在提出新的生成范式，而是在 latent diffusion + DiT 这条主线上，把数据构造、标注增强、采样平衡、偏好对齐和蒸馏加速串成一套完整 recipe。

评百度 ERNIE-Image 的技术报告，重点看其 pretrain 和 post-train 阶段的数据清洗和构造 pipeline，对做多模态生成的同学有工程参考价值。

Programming with Data: Test-Driven Data Engineering for Self-Improving LLMs from Raw Corpora

领域语料微调/持续补数通常是开环：评测发现模型缺陷，但无法定位到训练数据哪里缺、该补什么。论文要解决的是：让“训练数据构造”和“评测”共享同一套可追踪的知识表示，从而把数据工程变成可迭代修复的闭环流程。
