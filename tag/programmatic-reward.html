Synthesize and Reward -- Reinforcement Learning for Multi-Step Tool Use in Live Environments

这篇工作处理的是多步 tool use 训练里的一个老问题：离线合成数据、静态 API 缓存、以及粗糙的 sequence-level reward，三者叠加后，模型学到的往往不是“在真实环境里稳定完成任务”，而是“在伪环境里尽量多调工具”。全文真正聚焦的不是一般意义上的 agent，而是如何把 RL 训练信号和可执行、可验证、带状态的工具环境绑在一起，让模型在训练时就暴露于真实的状态依赖、参数约束、调用顺序约束和失败模式。作者指出现有方法常见三类偏差：一是环境不是真实 live execution，而是缓存响应或模拟器，缺少状态变化；二是合成 query 没有锚定服务器当前状态，导致轨迹表面正确、执行时却找不到实体；三是 reward 只看 recall 或覆盖率，会鼓励冗长调用。论文的核心问题因此可以概括为：怎样在低标注成本下，为多步工具调用构造一个既真实可执行、又能提供细粒度程序化奖励的 RL 训练闭环。

评对 RL for agent tool-use 训练有参考价值，重点看程序化奖励设计部分
