Every Token Needs Its Own Teacher: Multi-teacher Adaptive On-policy Self-distillation

这篇工作讨论的是 OPSD 里的 student-teacher mismatch，而且把问题进一步细化到了 token 级。已有 on-policy self-distillation 通常让 teacher 拿到某种“特权参考答案”，再对 student 自己采样出来的轨迹做蒸馏。问题在于，teacher 看得太多时分布会过尖，监督信号未必适合 student 当前状态。已有改进多半只在 response 级调节 reference exposure，也就是一整条回答共享同一个 teacher。作者要解决的是：同一条推理链内部，不同 token 所需要的 teacher 其实可能不同；如果仍用单一 teacher 监督整段生成，会把局部合适的指导和局部不合适的指导混在一起，降低训练效率甚至伤害推理表现。

评将蒸馏的粒度细化到了 token 级别，发现不同 token 需要不同强度的 teacher，这个 insight 对设计更精细的 RL/蒸馏 loss 有启发，建议看方法设计。
Yifu Luo,Chuang Ma,Zeyu Chen,Enkelejda Kasneci,Qi Chen,Gjergji Kasneci

WIDE: Boosting Adaptive LLM Inference via Token-level Dynamic Width Pruning

这篇工作解决的是 LLM 推理阶段动态剪枝里一个长期存在但一直没真正打通的问题：细粒度动态稀疏在算法上看起来更合理，因为不同 token 需要的计算量不同；但一旦把决策粒度从整层/整模块下推到 attention head group 和 FFN channel group，执行模式就会变得高度不规则，GPU 上很难拿到真实端到端加速。现有方法往往二选一：要么做静态结构化剪枝，部署友好但精度掉得快；要么做动态路由，质量保留更好，但实际吞吐收益有限。WIDE 的核心问题，就是如何把 token 级、宽度维的动态计算分配做成既能保精度、又能在 prefill 和 decode 两种场景下真正跑快的系统。

评动态稀疏方向少见的硬件落地友好方案，重点看两阶段训练设计和实际吞吐量数据，§3方法与§5实验值得读。
Haozhe Hu,Hao Wu,Peiran Yin,Chao Han,Yunpu Ma,Xiaoyu Shen
