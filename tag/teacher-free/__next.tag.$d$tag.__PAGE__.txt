9:Ta22,方法核心是“自参考的局部分支探索 + signed distillation”。在某个 on-policy 时间步 t_j，模型先按当前 ODE 预测得到一个确定性的下一状态；然后从同一个父状态出发，额外分出 K 个带噪声的 SDE 候选分支。每个分支只在当前步做随机探索，之后再用确定性 ODE 一路 rollout 到干净图像。这样做的目的很明确：把当前局部方向的好坏，转化为最终图像奖励的差异。

为了把终局奖励变成局部监督，作者同时从同一父状态做一条 deterministic ODE rollout 作为 baseline。每个分支最终得到的 reward 与 baseline reward 做比较，形成 normalized branch advantage。这样 advantage 不是绝对分数，而是“从当前状态出发，这个局部扰动比默认走法更好还是更差”。这一步很关键，因为它把不同 prompt、不同 reward 量纲、不同时间步上的分数差异压成了可比较的局部相对信号。

训练目标不是只拉近最好分支，而是 all-branch pull-push distillation。高 advantage 分支把当前 velocity field 拉向更优局部方向；低 advantage 分支则把模型从差方向上推开。相比只学 best-of-K，这种 signed objective 利用了更多探索样本，样本效率更高，也更像一个局部排序学习问题。但 signed update 容易不稳，尤其是“推开差分支”可能与“靠近好分支”方向冲突。为此作者加了 direction-aware attenuation：如果某个 repulsive update 会明显抵消 best branch 的主方向，就衰减其权重，避免训练在局部几何上自相矛盾。

另一个技术点是 SDE-variance normalization。因为不同时间步、不同噪声强度下，SDE 分支的位移尺度不同，若直接回归分支目标，loss 尺度会失衡。作者用 SDE 方差做归一化，使每步监督更接近统一量纲，并给出与 reward-tilted KL 最小化相关的解释：模型在每个局部状态附近，把概率质量往高奖励分支倾斜。

多目标部分也值得注意。已有一些 OPD 方法会为不同目标训练不同 teacher，再在 field level 做路由或融合。Self-OPD 不这么做。它先把多个 reward 归一化后在 scalar reward 层融合，只用融合后的分数对局部分支排序；真正回归的对象仍然是某条具体分支对应的 velocity target，而不是多个 teacher field 的线性组合。这样避免了不同目标梯度直接打架，也更符合“同一张图同时满足多个约束”的目标，而不是不同 teacher 各自擅长不同样本。a:T953,The method is built around self-referenced local branching plus signed distillation. At an on-policy step t_j, the current model first predicts the deterministic next state along the ODE trajectory. From the same parent state, it then spawns K stochastic SDE branches. Each branch explores only locally at the current step, after which it is rolled out deterministically to a clean image. The purpose is to evaluate whether a local directional perturbation leads to a better final sample.

A deterministic ODE rollout from the same parent state serves as a self-reference baseline. Final rewards from the K branches are compared against this baseline reward to produce normalized branch advantages. This is important because the signal becomes relative and local: not whether a sample is globally good, but whether a local move from the current state is better or worse than the default trajectory.

Training uses an all-branch pull-push distillation objective. Positive-advantage branches pull the velocity field toward better local directions, while negative-advantage branches push it away from poor ones. Compared with only regressing toward the best branch, this uses more of the sampled neighborhood and turns local exploration into a richer ranking signal. The downside is potential instability: repulsive updates can conflict with attractive ones. To address that, the paper introduces direction-aware attenuation, which downweights repulsion when it would substantially cancel the direction of the best branch.

Another key component is SDE-variance normalization. Since branch displacement scales vary across timesteps and noise levels, direct regression would produce poorly calibrated losses. Normalizing by SDE variance makes the per-step target more comparable across the trajectory and is connected in the paper to a reward-tilted KL view: locally shifting probability mass toward higher-reward branches.

For multi-objective alignment, Self-OPD avoids field-level fusion of multiple teachers. Instead, it normalizes and combines scalar rewards first, uses the composite reward only to rank branches, and still regresses toward a concrete trajectory-derived velocity target.
