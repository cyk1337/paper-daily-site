WorkFactory: Turning Professional Intents into Executable Work for Scalable Agent Training

如何把“职业意图（professional intents）”规模化地转成可执行、信息自洽、能产出可靠专家示范（teacher trajectories）的工作任务环境，用于训练工作型 agent；核心难点是：任务所需前提信息分散在多工件/多文件中，且在实例化与合成材料时容易出现缺失、矛盾或把关键中间推导结果直接泄露给 teacher，导致示范要么靠臆测、要么绕过关键能力点，监督信号变脏。

评不是 pretrain，但它把“任务能否执行”前置成数据问题，这点比多数 agent SFT 更干净；先看任务构造流程和失败修复机制。
