18:T51f,WorkFactory is a pipeline that makes task environments verifiably executable before collecting teacher trajectories.

1) Professional intent library: intents are derived from occupational hierarchies, skill documentation, and real deliverables, so the target output and audience are defined before instantiating materials.

2) Information Support Graph (backward planning): starting from the intended deliverable, the system plans dependencies at the level of information items (premises/conditions) and specifies where each supporting fact should appear across reused/synthesized artifacts, while explicitly leaving derived quantities for the solver.

3) Probe execution + execution-based repair: after materialization, an isolated probe attempts the task using only solver-visible inputs to detect support failures (missing/contradictory premises, broken dependencies). Repairs must restore support without changing the intended work or leaking key derivations.

4) Independent teacher collection: only tasks that pass probe+repair are assigned to a separate teacher agent to generate trajectories for SFT.
