Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution

这篇工作要解决的不是“哪个 agent 更强”，而是“同一个模型接到不同 harness 之后，系统层的可靠性差异该怎么被单独测出来”。现有 agent benchmark 大多只看最终任务是否完成，结果把模型能力、prompt 设计、工具接线、上下文管理、权限控制、状态持久化、日志可观测性这些因素混在一起。作者指出，任务成功并不等于 harness 工作正确，任务失败也不一定说明 harness 有问题。缺的不是又一个 outcome benchmark，而是一套能把 harness 作为独立被测对象、能做失败归因、还能保留各家原生运行方式的评测框架。

评读 §benchmark design 和 failure attribution；它提醒模型评测别把 harness 锅算到模型头上。
