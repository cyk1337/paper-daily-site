9:T453,The language model distribution p_LLM(y|x) is treated as a prior. A potential function Φ(y|x), indexed by a scalar threshold τ, defines a posterior distribution that favors completions in a high-confidence region according to cumulative claim-level factuality scores. Unlike post-hoc conformal filters, the method changes the sampling distribution itself. The calibration problem is handled off-policy: the authors choose τ using samples from the original LM prior, without drawing new samples from every candidate posterior. Two issues are central. First, the posterior normalizer Z^τ(x) can be poorly estimated when the prior puts little mass on the high-confidence region. The paper handles this by using an empirical posterior distribution with an explicit abstention path, effectively modeling a mixture with a fallback option. Second, a naive importance-weighted loss estimate is non-monotone in τ, which complicates conformal guarantees.
