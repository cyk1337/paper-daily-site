18:T522,The proposed method is Calibrated Importance Sampling, or CIS. Standard token-level correction uses the importance weight r = π_train(y_t|h_t) / π_infer(y_t|h_t). The paper argues that this ratio entangles two factors: the confidence of the sampled token and the actual discrepancy between the inference and training engines. It rewrites the ratio as a function of token confidence and an additive log-odds displacement ε_t. If the inference probability of the sampled token is p and the training engine shifts its log-odds by ε, the corrected probability can be written as sigmoid(logit(p)+ε), giving a ratio of roughly exp(ε)/(1-p+p exp(ε)). This shows why a fixed ratio threshold is poorly calibrated: the same ε produces a much larger ratio change for low-confidence tokens than for high-confidence tokens. CIS clips ε directly instead of clipping r. Since the measured ε distribution is approximately invariant across confidence buckets, a single threshold can be applied to the discrepancy component. When mapped back to the ratio, this becomes a confidence-dependent cap that is tighter for high-confidence tokens. The theoretical analysis shows that CIS bounds the second-moment term that can explode under exact importance correction, while introducing a bias controlled by the truncated excess.19:T8bd,The method partitions a sequence into non-overlapping segments and decomposes cross-segment information flow into two channels. The first is a differentiable local continuity channel, C_i, implemented as a fixed-size carried KV tail. This is the only recurrent interface state passed from one segment to the next, and it is used identically in training and inference. The second is a forward-only long-range conditioning channel, R_i, implemented as a retrieved KV prefix. It gives access to evidence beyond the carried-KV horizon, but it does not participate in state recursion and gradients do not flow backward through it.

Under this design, each segment uses the same forward operator at training and inference: outputs for the current segment depend on current tokens, the carried state C_{i-1}, and the retrieved prefix R_{i-1}. The crucial constraint is that only C defines the recursive state chain. R is auxiliary conditioning, not part of the recurrent state. Training uses TBPTT, but not as an approximation to full-attention learning. Instead, the objective itself restricts cross-segment credit assignment to the most recent K state transitions. Because the model is explicitly defined under this bounded recursion, TBPTT computes the exact gradient of the inference-consistent objective. The paper further claims that K=1 is sufficient and optimal in practice, which is a strong statement about how short the necessary differentiable horizon can be.

Architecturally, the design is realized with head- and layer-sparse long-range heads. A small subset of heads handles long-range retrieval or conditioning, while most heads support local state-carrying computation. The motivation is straightforward: if all heads are responsible for long-range dependency handling, the recurrent interface becomes too large and the execution semantics become harder to control. By confining long-range access to sparse substructures, the model keeps a clean boundary between local recurrent state and non-recurrent long-range evidence. The trade-off is explicit: the method does not try to preserve exact full-attention semantics. It defines a more restricted but deployment-aligned execution model and optimizes directly for that regime.1a:T4fa,From the provided full text, three main empirical claims are clear. First, the framework is validated on multiple long-context benchmarks and context lengths, showing strong performance under constrained execution. That suggests the consistency constraint does not collapse long-range capability even though state propagation is heavily restricted. Second, ablations on the truncation horizon show that TBPTT with K=1 is already sufficient and optimal. This is an important result because it implies that the useful differentiable cross-segment learning signal can be extremely short, which reduces both training cost and implementation complexity. Third, at 128K-context prefill, the method uses about 6× less memory than full attention. So the proposal is not only conceptually cleaner; it also yields substantial systems-level savings.

The details that matter most when reading the full paper are the segment length, how the retrieved KV prefix is constructed, how many heads are allocated to long-range access, and how the method compares against the common baseline of full-attention training with segmented inference.
