18:T6cb,The proposed method is Adaptive Log-Space (AL) quantization, embedded in a broader analysis of optimizer-state heterogeneity. The authors first observe that many non-negative optimizer states, especially second moments and confidence accumulators, are heavy-tailed, vary in dynamic range across blocks, and often contain exact zeros. Standard blockwise linear quantization can collapse small positive values to zero, which destroys the distinction between dormant state and weak but nonzero history. AL addresses this by fitting a logarithmic interval to the positive values within each block while reserving code zero exclusively for exact zero, yielding the invariant q = 0 if and only if x = 0. This preserves true zeros and prevents positive second moments from being quantized away into zero. The design is not a single uniform low-bit policy. Non-negative states can use AL8 or AL16, signed momentum is encoded separately, and CAME confidence states may use higher precision than second moments. A second key idea is topology-aware grouping. The paper shows that quantization blocks should align with the optimizer’s state topology: cutting across Adafactor row/column factors or mixing unrelated statistics in one block can amplify update error. The study covers four optimizer paths—dense AdamW, factored Adafactor, confidence-guided CAME, and projected-state APOLLO—and evaluates not only state reconstruction but also update-domain fidelity, temporal drift, and error propagation through inverse square roots, factor reconstruction, confidence modulation, and projected scaling. The implementation includes both a Python reference path and fused CUDA kernels, with separate checks for algorithmic and numerical consistency.19:T5a3,The experiments are organized into controlled diagnostics and end-to-end pretraining runs. In the diagnostic part, the authors trace optimizer states from language-model pretraining and compare their value ranges, exact-zero patterns, and temporal behavior. They then evaluate how different quantization schemes affect both state reconstruction and update error. The conclusions are deliberately nuanced rather than universal. For dense AdamW, AL8 is competitive with the evaluated 8-bit AdamW baseline. For CAME, confidence states are more precision-sensitive than second moments, so using too low a precision there hurts update fidelity more noticeably. For Adafactor, protecting sensitive tensors and matching quantization granularity to row/column factor topology is materially better than coarse uniform blocking. For APOLLO, projected-space states exhibit yet another error-propagation pattern, reinforcing the point that they should not be treated as ordinary dense arrays. The end-to-end validation uses 20K-step TinyLlama-1.1B pretraining and 100K-step GPT-2 pretraining. The paper’s overall conclusion is bounded: AL8 can match existing 8-bit baselines on several paths, but a single low-precision recipe is not sufficient for all structured optimizer states.
