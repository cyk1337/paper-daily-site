9:T4b0,TraversalBench is a controlled benchmark where each instance contains (1) a single continuous polyline, (2) a unique start marker, and (3) markers placed at path vertices; the task is to output the ordered marker sequence encountered from start to finish. Difficulty is explicitly balanced along four interpretable axes:
1) Self-intersection count, discretized by thresholds {0,1,2,4,6,9,13} with finer granularity near zero crossings.
2) Tortuosity, discretized by thresholds {1.0,1.3,2.0,3.0,4.5,6.5,9.0} into six bins spanning near-straight to highly meandering paths.
3) Vertex count (sequence length / path length), with multiple point-count settings to separate length effects.
4) Confounding lines: nearby non-target segments that increase distractor structure without altering the target path.
Generation targets cells in the joint tortuosity×intersection grid, then applies render-aware acceptance constraints (segment length, nonlocal clearance, vertex-to-segment separation) so difficulty is driven by the intended structural factors rather than rendering artifacts.
