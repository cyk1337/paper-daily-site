2) Highlight a common pitfall: auto-differentiating a Monte Carlo KL estimate ignores the dependence of the sampling distribution on θ, yielding an incorrect gradient (zero in expectation for the missing term).
3) Start from KL_sq: an MSE between log πθ and log π* (translation-invariant in log-prob space). Although it is a biased estimator of KL, on-policy its naive auto-diff gradient matches the true KL gradient in expectation; off-policy it remains a valid loss with the same global minimizer.
4) Generalize this construction to arbitrary f-divergences by building a family of translation-invariant surrogate losses L_f whose on-policy expected auto-diff gradients match those of the corresponding f-divergence, while preserving the same optimum off-policy.
5) Prove an inverse characterization: any convex, translation-invariant loss on log-probabilities corresponds to minimizing a specific f-divergence. This links “engineering-friendly losses” to “which divergence you are implicitly optimizing”.
6) Extend variance-reduction / normalization tricks (Vargrad, batch-wise normalization) to general f-divergences to handle the intractable partition function in RL objectives.
