9:T4e1,The proposed symbiotic architecture replaces the usual thin adapter with an injector. In a standard audio language model, the audio encoder produces embeddings, the adapter maps them into the LLM embedding space, and the LLM performs prefilling over the full audio sequence. Here, the injector directly writes audio-conditioned key/value tensors into the short-term memory of the LLM. Since it generates a KV cache for every LLM layer, the injector has the same number of layers as the backbone, but it can be much narrower. The injector is built from CNN-style LConv blocks rather than vanilla Transformer blocks. The rationale is that audio-to-cache conversion mostly needs local context, while the frozen Transformer backbone can handle global integration during generation. The LConv block uses depthwise 1D convolution between pointwise dense layers, with RMSNorm replacing the normalization used in Conformer-style modules for better stability under small-batch training. The described configuration uses 2048-dimensional inputs to the depthwise convolution, kernel size 15, max-pooling subsampling with stride 8, and separate affine projections into key and value spaces.
