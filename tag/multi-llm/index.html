Multi-LLM Systems Exhibit Robust Semantic Collapse

这篇工作研究的是：多个 LLM 在不接触外部环境、只依赖彼此历史对话继续生成时，语义空间会不会持续扩张，还是会逐步收缩到少数稳定模式。作者把这个现象定义为 semantic collapse，并且刻意把问题放在 inference-only、参数冻结、closed-loop 的设定下，目的是把它和“用合成数据递归训练导致模型崩塌”区分开。更具体地说，他们关心两层收缩：一是单条交互轨迹内部，语义位移越来越小，系统越来越围绕已有表征打转；二是不同随机初始化的独立轨迹之间，最终探索到的语义区域彼此并不远，缺少真正分叉的开放式探索。

评这篇不直接改 pretrain recipe，但会影响你看 synthetic data 和 multi-agent self-play 的风险模型；先看语义度量定义和 13 个干预为何都救不回来。
Weiyi Kong,Shiyang Lai,Jinghua Piao,James Evans

LatComm: Reusable Context Compression for Latent Communication between Large Language Models

LatComm 解决的是多 LLM 系统里的重复上下文计算问题：同一篇文档或同一段观察会被多个问题反复使用，但接收模型每次都要重新读完整文本。论文希望得到一种上下文表示，它要能在问题未知时预先编码、大小固定、可跨不同冻结 LLM 读取。

评不是 pretrain 论文，但若你在想 memory token 或跨模型 latent 接口，只看方法图和 12-dataset 成本/精度表就够；别把它误读成通用压缩结论。
Huawei Lin,Jinting Liu,Tan Yu,Weijie Zhao
