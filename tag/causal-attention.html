Dynamic Multi-Byte Prediction With Hierarchical Language Models

PARTREP: Learning What to Repeat for Decoder-only LLMs

这篇工作处理的是 decoder-only LLM 的一个结构性问题：因果注意力导致信息流不对称，序列后部 token 比前部 token 拥有更充分的上下文 grounding，因此模型会出现 premise order sensitivity、选项顺序偏置、lost-in-the-middle 等现象。已有工作发现把 prompt 完整重复一遍能缓解这个问题，但代价很高：KV cache 翻倍，prefill attention 计算接近四倍。论文要解决的是，能不能只重复一小部分真正关键的 token，保留大部分收益，同时把额外内存和计算压下来。

评只看 NLL 选 token 和缓存成本分析；它像廉价 context reordering，不改训练，但能暴露 causal attention 的位置偏置。
Andikawati P Widjaja,Yongjun Kim,Hyounghun Kim,Jaeho Lee
