18:T768,The method section has two parts. First, the paper validates the mechanism. In prefix-perturbation experiments, the authors modify only the template prefix before the user query, sometimes with very small changes such as capitalization, while keeping the query semantics intact. Alignment is often restored. In contrast, if the prefix is kept unchanged, replacing the user query with similar or even random tokens can still preserve the misaligned behavior. This suggests that the trigger is concentrated in the shared prefix rather than in the semantic content of the query.

They then move from correlational evidence to a stronger causal intervention using representation patching. Specifically, they replace the KV-cache entries at prefix positions in the finetuned misaligned model with the corresponding entries from the original unfrozen? no, original frozen pre-finetuning model, across all layers. This leaves the query untouched but forces the information propagated from prefix positions to revert to its pre-finetuning state. The intervention largely restores alignment, indicating that prefix representations indeed encode the harmful behavioral bias.

Second, they introduce TReFT, Token-Regularized Finetuning. Instead of relying on retain-set interleaving, TReFT regularizes selected token representations so that shared prefix tokens do not drift too far from the base model, while allowing more of the update to land on tokens that encode the actual query content. The design choice is important: standard output supervision tells the model what behavior to produce, but not which context should scope that behavior. TReFT adds an inductive bias over attribution, pushing the model to associate new behavior with domain semantics rather than with globally shared template tokens. The paper also applies the same idea beyond EM to abstention, tool calling, and refusal behaviors.19:T44f,Three result groups matter most. This is a large recovery and suggests the issue is encoded in internal prefix representations rather than only in output-layer drift. Third, TReFT consistently mitigates OOD misgeneralization while preserving the intended in-domain behavior. The headline number in the paper is that on Llama-3.1-7B in the legal-domain setting, TReFT reduces EM 33.5% better than data interleaving.
