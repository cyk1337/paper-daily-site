GQA-μP: The maximal parameterization update for grouped query attention

这篇工作处理的是一个很具体但很关键的问题：μP/Complete-P 这套超参迁移理论，到了 grouped-query attention（GQA）这种生产里常见的注意力结构上，原有做法会出现“坐标检查通过，但学习率迁移失败”的现象。论文要解决的不是再给一个经验修补，而是解释为什么旧理论在这里失效，并给出一套能覆盖低秩权重矩阵、深度缩放、weight decay 与 GQA 的统一推导框架。更细一点说，问题有两层。第一，过去 spectral μP 把谱范数条件当作推出 feature learning 的充分条件，但定义本身仍沿用较弱的 feature-learning 表述，导致一些实现虽然通过常规 coordinate check，却没有真正满足可迁移所需的算子尺度约束。第二，GQA 的某些权重天然低秩，经典谱范数刻画的是“最坏方向”的放大率，但训练时输入分布几乎不会落到这些方向上，于是谱范数给出的尺度与训练中真实看到的层输出尺度脱节，进而破坏学习率迁移。

评首次给出GQA架构的μP缩放规则，可直接复用降低调参成本，建议立刻复现到内部GQA模型的超参搜索流程中。
