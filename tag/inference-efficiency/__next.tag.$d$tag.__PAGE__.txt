9:T655,The design has three central pieces. First, the model uses a Causal Encoder-Decoder architecture. The encoder handles the causal prefill side, and decoder global KV is projected from the final encoder hidden states. This gives a cheaper prefill path and a stronger decode path, matching input-heavy agent workloads. Second, the paper introduces Compressed Sparse Attention 2, or CSA2. DeepSeek-V4 can be viewed as a sliding-window local-processing backbone plus compressed global context; V4.1-Flash keeps SWA in every layer but simplifies the global branch. CSA2 statically assigns layers to Full, Reindex, and Reuse modes. Full layers generate global KV and perform indexing. Reindex layers reuse global KV from a previous layer but use their own indexer Q to rescore shared indexer K and select fresh Top-K indices. Reuse layers reuse both global KV and Top-K indices. Each layer still keeps its own global Q and local SWA KV, so the method shares the expensive global cache components without collapsing all attention behavior into one shared layer. Third, the system combines FP4 global KV cache training with SWA Bounded Replay. FP4 global KV reduces runtime cache size with only small degradation. SWA Bounded Replay avoids persisting SWA KV to SSD by replaying only the most recent n_win tokens, rather than the L × n_win replay needed for exact reconstruction in the earlier design. Repair is 13–21 times faster than full re-prefill in this setting.b:T785,The method, Temporal Self-Distillation (TSD), runs the current model on-policy to produce a denoising trajectory. For a given position, if the token is only committed at a later timestep, the model’s predictive distribution at that final commit timestep is treated as the teacher. Earlier-timestep distributions at the same position are then trained to match that teacher. The target is therefore not the ground-truth one-hot token directly, but the model’s own eventual decision.

This design has several notable properties. First, it is on-policy: the supervision evolves with the model, instead of being frozen in an offline teacher-generated dataset. Second, it is cross-time rather than cross-model distillation: teacher and student are the same model evaluated at different denoising stages. Third, it is tightly aligned with fast decoding. If early distributions already resemble the eventual commit distributions, confidence-based parallel unmasking becomes much safer.

From the full text, TSD is added on top of the standard masked diffusion objective as an auxiliary temporal distillation loss, likely implemented as a KL-style objective with stop-gradient on the teacher side. The loss is defined only on positions that will eventually be committed, which keeps the supervision aligned with actual decoding behavior instead of imposing a blanket consistency constraint everywhere. The paper also emphasizes that TSD applies to both base and post-trained policies, which makes it look more like a general low-NFE alignment objective than a trick tied to a specific pretraining setup.

Compared with offline few-step distillation methods such as dParallel, TSD removes the separate teacher-training and trajectory-generation stage. Compared with decoding-only methods such as Fast-dLLM, it changes the model’s early-time predictive distributions themselves rather than only changing when tokens are committed.c:T567,The evaluation spans seven benchmarks across math, planning, and coding, with the main focus on the speed-quality Pareto frontier rather than peak quality at large NFE. First is Matryoshka-style training. Instead of training a compressor at one fixed K, the model samples K per training instance, so a single encoder learns to compress the same kind of context into different numbers of memory tokens. The underlying interface stays unchanged: an encoder LLM maps a context of length L into K continuous memory tokens, and a frozen decoder LLM consumes those soft tokens in place of the raw context. In practice, the encoder is usually a LoRA-adapted copy of the decoder. This makes the approach method-agnostic across ICAE, 500xCompressor, and SAC.

Second is inference-time budget selection. The paper proposes two strategies. Confidence-based cascade routing starts with the smallest, most aggressive budget and only retries with a larger K when the decoder is uncertain. This tends to preserve accuracy well, but may require multiple compression-decoding passes. The learned K predictor instead predicts the budget before compression, so inference runs in a single pass. That is more deployment-friendly because latency and throughput are easier to control.

An important empirical observation is that the accuracy-compression relation is not always monotonic at the instance level. Larger K can preserve distracting surface details and hurt the decoder, while K=1 can sometimes succeed where a larger budget fails. The practical claim is that removing dense exp and the temporary high-precision probability tile should reduce overhead in the softmax path once GEMMs are already low-bit accelerated.13:T703,The method starts by separating queries into two behavioral types. Local queries mostly attend to nearby tokens. Global queries, associated with TRTs, attend back to distant earlier context. The paper then shows that these global queries are not scattered arbitrarily in query-embedding space; they form a small number of similarity clusters. This motivates beacon queries: a compact set of representative queries intended to approximate future global revisiting patterns.

At eviction time, BeaconKV does not score historical KV entries using only recent queries. It also keeps a small set of beacon queries. A token is retained not only if it matters to the current local decoding state, but also if it is important to one of these representative global queries. This gives the system a way to protect tokens that may not look useful now, but are likely to be revisited later.

Because decoding is online, beacon queries cannot be obtained by offline clustering over the full query history. The paper therefore proposes Continual Farthest Point Sampling, an online procedure that incrementally selects geometrically diverse queries while keeping memory bounded. Intuitively, it maintains a compact cover of the query space seen so far. Compared with storing the full query history, this is memory efficient; compared with using only recent queries, it preserves information about potential future global attention patterns.

Methodologically, BeaconKV is training-free. It does not modify model weights and does not require distillation or calibration. Its main distinction from RPC and R-KV is not a better redundancy score, but an explicit treatment of future-query mismatch: future important queries may differ from recent ones, and a small representative set can partially bridge that gap.14:T537,The evaluation covers four open reasoning models: R1-Distill-Qwen-7B, R1-Distill-Llama-8B, Qwen3-4B, and Qwen3-14B.
