First, periodic rounding. During prefill, chunked kernels already update and write the recurrent state only once per chunk. The problematic regime is autoregressive decoding, where the kernel is invoked once per token and the state is quantized after every step. PACE introduces a decode buffer that stores recent keys and values for a small number of generated tokens, and only flushes them into the recurrent state every dP steps. This reduces how often quantization noise is injected. The paper derives a per-head retained-error bound showing that the surviving error increases with head decay and decreases with the rounding period. The argument is simple but useful: if the recurrence contracts errors between writebacks, less frequent rounding can outperform more frequent rounding even at the same bit width.

Second, channel-aligned grouping. The authors analyze the gated-delta state and find that large-magnitude entries are column-structured rather than randomly scattered. Intuitively, some delta-value channels stay large across many tokens, and the outer-product update writes that persistence into whole columns of the state. If quantization groups cut across columns, one large entry can dominate the shared scale and waste levels on many small entries. Grouping along the key axis, so that each group stays within a column, produces more homogeneous dynamic ranges. The paper supports this with max/RMS statistics and a channel-permutation experiment that ties the observed structure back to persistent delta channels.

Third, head-level mixed precision. PACE-4 quantizes all heads to 4-bit. PACE-4/8 keeps the quarter of heads in each layer that retain rounding error the longest at 8-bit, while the rest remain at 4-bit. This follows directly from the per-head decay analysis: some heads are much more sensitive to quantization than others, so uniform precision is wasteful.

The paper formulates the problem as a prefix MDP. A state contains the public context h, the current reasoning prefix xt, its token length kt, and the checkpoint index t. The control action is either Wait or Stop. Wait reveals the next chunk from the frozen reasoning model. Stop terminates the prefix process and invokes the reasoning model’s action-generation interface using the current prefix. The central training signal is prefix-level action agreement: whether the action generated from a partial prefix matches the reference action produced after full reasoning. This is a model-specific target, because the stopping policy is trained to preserve the behavior of a particular reasoning model rather than to follow a generic confidence heuristic.

Training is done offline from collected reasoning trajectories with action annotations at multiple prefix lengths. Because the outcomes of different stopping times are recorded, the paper can optimize an exact expected-return objective over stopping decisions. A discount factor gamma controls the tradeoff between preserving the full-reasoning action and saving reasoning tokens: smaller gamma favors earlier stopping, while gamma closer to 1 favors agreement with the full-reasoning reference. Importantly, gamma is also provided as a conditioning input, so one trained policy can be used at inference time under different budget preferences.

First, the paper includes a useful feasibility diagnostic. Reader agreement with the full-reasoning action increases as the prefix grows, and many decisions have a sufficient prefix that is substantially shorter than the full reasoning trace. Second, StreamStop outperforms fixed-length reasoning and heuristic stopping rules across models and environments in the agreement-versus-token tradeoff.
