具体做法分两部分。

第一部分是监督信号构造。作者对同一个样本运行 full-denoising decoding，得到一个无 cache 近似误差的参考轨迹。这个轨迹给出了每个 unresolved position 在未来何时会被提交，或者说它离“即将成为关键决策点”有多近。TraceQuery 不试图搜索最优轨迹，也不强行让推理时完全跟随 reference trajectory，而是把这个 full-denoising trajectory 当作 router 的训练标签：学习在当前解码状态下，对 unresolved positions 做 near-future relevance ranking。

第二部分是推理时的稀疏查询。在线推理时，模型不会对所有 unresolved positions fresh recompute，而是先从当前可廉价获得的 decoding-state signals 中提取特征，由一个轻量 router 预测哪些位置最值得查询。被选中的少量 candidates 才会重新计算表示；其余位置继续复用 cache。随后 backbone dLLM 只在这些 freshly evaluated candidates 中决定最终 commit 哪个位置或哪些位置。这里有一个很重要的拆分：router 只负责“算哪里”，backbone 仍负责“提交什么”。这样做比直接让 router 决定 commit 更稳，因为最终决策仍由原模型完成，避免轻量模块过度接管生成。

The method has two key components.

First, it constructs supervision from full-denoising trajectories. For a given example, the model is run in full-denoising mode, producing a reference trajectory without cache-induced approximation. This trajectory tells us which unresolved positions are likely to become important soon—effectively a notion of near-future relevance. TraceQuery does not try to search for an optimal trajectory, nor does it force inference to exactly follow the reference. Instead, it trains a lightweight router to rank unresolved positions according to how soon they matter along the full-denoising path.

Second, at inference time, the router uses inexpensive signals available from the current decoding state to select a small fresh-query set. Only those candidate positions are recomputed from scratch; all other unresolved positions continue to reuse cached representations. The backbone dLLM then makes the actual commit decision among the freshly evaluated candidates. This separation is important: the router decides where to spend computation, while the backbone retains control over what to commit. That design keeps the lightweight module from directly taking over semantic generation decisions.

The framework is described as applicable to both single-block and block-wise diffusion decoding. It is compatible with the general cache-based sparse decoding setup, but changes the objective. Instead of minimizing cache-induced representation error, it tries to maximize alignment with the near-future full-denoising trajectory. First, periodic rounding. During prefill, chunked kernels already update and write the recurrent state only once per chunk. The problematic regime is autoregressive decoding, where the kernel is invoked once per token and the state is quantized after every step. PACE introduces a decode buffer that stores recent keys and values for a small number of generated tokens, and only flushes them into the recurrent state every dP steps. This reduces how often quantization noise is injected. The paper derives a per-head retained-error bound showing that the surviving error increases with head decay and decreases with the rounding period. The argument is simple but useful: if the recurrence contracts errors between writebacks, less frequent rounding can outperform more frequent rounding even at the same bit width.

Second, channel-aligned grouping. The authors analyze the gated-delta state and find that large-magnitude entries are column-structured rather than randomly scattered. Intuitively, some delta-value channels stay large across many tokens, and the outer-product update writes that persistence into whole columns of the state. If quantization groups cut across columns, one large entry can dominate the shared scale and waste levels on many small entries. Grouping along the key axis, so that each group stays within a column, produces more homogeneous dynamic ranges. The paper supports this with max/RMS statistics and a channel-permutation experiment that ties the observed structure back to persistent delta channels.

Third, head-level mixed precision. PACE-4 quantizes all heads to 4-bit. PACE-4/8 keeps the quarter of heads in each layer that retain rounding error the longest at 8-bit, while the rest remain at 4-bit. This follows directly from the per-head decay analysis: some heads are much more sensitive to quantization than others, so uniform precision is wasteful.

The implementation side is also important. The paper includes Triton kernels for periodic decoding with packed 4-bit state, and it accounts for decode-buffer memory in the reported totals. That makes the evaluation more credible than papers that report only compressed state size while ignoring auxiliary buffers.12:T5db,The evaluation spans four hybrid linear-attention backbones ranging from 4B to 35B parameters. That directly validates the error-propagation story. The ablations are the most informative part. Period ablations show that the gain comes from less frequent decode-time rounding rather than from prefill behavior; prefill chunk length is fixed at 256 in the benchmark setup.
