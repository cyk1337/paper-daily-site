The central statistic is acceptance survival: the probability that the draft prefix up to position i is fully accepted. This quantity determines the expected number of committed tokens for a given horizon. The paper further decomposes survival in terms of conditional rejection hazards, namely the probability that position i is rejected given that all earlier draft positions were accepted. Once these hazards are estimated, the controller can evaluate the expected throughput of each horizon.

The main difficulty is partial feedback. If the system chooses a short horizon, it never observes verification outcomes for later positions. That surrogate has two properties that make the method practical:

2. It also yields a closed-form score for the increase in surrogate loss after applying that optimal compensation.

This leads to KV-Surgeon: at each step, evaluate every candidate entry by the residual error after optimal compensation, remove the best candidate, apply the compensating update to the surviving cache, and repeat. A final joint refit is still used after selection, but the important point is that compensation already influences which entries survive. The retained set is therefore selected with awareness of how well the remaining cache can absorb the deletion.

A notable strength of the formulation is that it is not purely attention-mass based. If verification rejects early inside that block, the target hidden states computed for later positions are not valid as reusable target caches because they depend on rejected tokens.
