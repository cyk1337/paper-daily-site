a:T429,QUASAR separates reconstruction into quantization and dequantization. Quantization maps full-precision weights to discrete codes while treating the clipping range as a searchable variable. Dequantization maps those codes back to reconstructed weights using learned scales, and optionally offsets for asymmetric quantization. The reconstruction objective is not plain L2 error; it is a Hessian-weighted, loss-aware reconstruction error inspired by second-order PTQ. To make this usable inside QAT, QUASAR approximates the Hessian diagonal with an exponential moving average of squared gradients, giving per-parameter saliency scores. For a small set of candidate clipping ranges, it fixes the discrete code assignment, solves the dequantization parameters in closed form by saliency-weighted least squares, and chooses the candidate with the smallest loss-aware reconstruction error. The analysis decomposes the QAT convergence bound into initialization, minibatch noise, and reconstruction error; only the last term is directly controlled by the reconstruction map.b:T596,The method has three main parts. First, compensation is moved from block level to individual linear layers. Instead of sharing one compensator across a Transformer block, the paper attaches separate compensators to each of the four linear layers. This matters because quantization error structure differs substantially across layers. The fitting is also sequential rather than one-shot: after compensating one layer, the compensated layer is inserted back into the model, and the next layer is solved using the true downstream input distribution under upstream quantization and compensation. This avoids train-deploy mismatch. Second, the core contribution is a numerically stable solver based on a truncated pseudoinverse. Rather than adding damping or ridge regularization to all directions, the method removes only the collapsed singular directions and preserves the remaining compensable subspace. That is the conceptual difference from prior stabilizers: they shrink everything; QuaSAR tries to delete only the directions that make the solution explode. Third, the compensation itself is compressed for deployment through low-rank factorization and compensation quantization, giving a practical accuracy-size tradeoff.
