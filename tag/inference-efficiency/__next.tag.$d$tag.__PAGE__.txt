First, the reduction rate is predictable: the paper derives a closed-form expression, so compute savings can be budgeted before deployment. That makes the approximation milder than a sliding window and more aligned with the intuition that low frequencies carry long-range positional information. It is not a pretraining recipe change by itself, but it should influence how people think about RoPE design, extrapolation, and inference-aware positional schemes.6:T824,The method starts from an exact observation: with RoPE, the query-key score can be written as a sum over 2D rotation-frequency pairs, and each pair has its own wavelength λ_r. High-frequency pairs have short wavelengths and can only discriminate relative position locally; low-frequency pairs have long wavelengths and remain informative at larger distances. Based on this, the paper defines a per-RoPE-wavelength distance window: for frequency pair r, keep its contribution only when the relative distance z is within w_r = min(k·λ_r, N); beyond that distance, drop that pair’s term from the score sum.

Three aspects are central.

First, the method prunes frequency terms, not tokens. It is frequency-level pruning rather than token-level pruning. As long as N < k·λ_max, the lowest-frequency components still span the full sequence, so every token remains reachable through at least those channels.

Second, it is designed to fit FlashAttention-style kernels. The paper argues that the window can be implemented as a slice along the reduction axis of online softmax, preserving the main kernel skeleton and numerical path. With the window disabled, the implementation is bit-identical to the stock kernel. That suggests a relatively clean deployment path rather than a full reimplementation of attention.

Third, the method has a single free parameter k, the number of retained periods. Larger k keeps more frequency terms and approaches full attention; smaller k gives more reduction. The default is k=2, and the paper derives a logarithmic closed-form reduction rate as a function of sequence length N. That predictability is a major distinction from dynamic sparse methods such as MInference.

The underlying modeling assumption is important: once a frequency pair has entered an aliasing regime at a given distance and can no longer uniquely discriminate position, its contribution to the attention score is treated as redundant. If token k is rejected by the target model, all later tokens are discarded even when many of them would have matched the target had the earlier local error been repaired. CURE tries to fix exactly those fragile points.

The mechanism starts by identifying Uncertainty Focal Points using the top-1 versus top-2 log-probability margin from the draft model. A small margin indicates local ambiguity and a higher chance that this position will trigger downstream rejection. The motivation is simple: if most tokens are already predictable, uniform tree expansion wastes target verification on positions that do not need repair.

Softmax attention can be written as a numerator–denominator ratio: the numerator sums exp(logit) times value, and the denominator sums exp(logit). Standard eviction keeps only a subset of tokens and effectively sets the omitted side to zero in both terms. ResKV instead splits the fixed cache budget into two parts: a main cache that stores selected tokens exactly, and a residual cache that stores compact residual entries approximating the aggregate contribution of omitted tokens.

There are three key design choices. First, residual entries participate in the same softmax normalization as the exact main-cache tokens. They are not a post-hoc correction added after attention. This shared-softmax formulation allows each residual entry to restore both denominator mass and numerator mass. Second, selected main-cache tokens remain exact; omitted information is not folded into them. This avoids the retained-memory perturbation common in merging-based approaches. Third, the method includes adaptive residual control at two stages. During cache construction, a validation proxy decides whether a given layer/head should receive residual budget based on held-out attention-output reconstruction. During decoding, a dynamic gate scales residual logits according to the sharpness of the main-cache attention. If the main cache already forms a sharp retrieval peak, residual mass should not blur it; if attention is diffuse, residual entries are more likely to help.

The paper also evaluates both query-aware and query-agnostic construction. The latter is more realistic because compression must happen without access to future queries. This matters in practice, since some compression methods look strong only when they can use future-query information.
