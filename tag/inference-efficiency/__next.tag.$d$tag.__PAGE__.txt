9:T6bb,CatchUp is a training-free framework for depth-aware visual-token re-admission. Instead of making a one-shot keep/drop decision, it re-evaluates query-conditioned visual relevance at selected decoder layers. At each routing layer, the model uses attention from the last text token to visual tokens as a relevance proxy, keeps only the selected visual tokens active, and defers the rest rather than deleting them. Between routing layers, only active visual tokens continue through the decoder, reducing attention, FFN, and KV-cache cost.

The key contribution is what happens when a deferred token becomes relevant again. Prior recoverable routing methods simply reinsert the old hidden state, which is stale. The authors first run an oracle analysis with full-token trajectories and show that replacing stale states with same-depth oracle states substantially improves grounding. This establishes that representation staleness is the real bottleneck. CatchUp then approximates the missed evolution using reference-to-current transition signals from semantically and spatially related active visual tokens. Intuitively, it borrows how nearby tokens changed from the reference depth to the current depth, and transfers that change to the returning token. So it does not replay all skipped layers; it estimates the missing state update from related tokens.

Compared with irreversible pruning, CatchUp can recover late-emerging evidence. Compared with recoverable routing without state correction, it explicitly addresses hidden-state mismatch at re-entry. The oracle replacement study is important because it validates the design target: the problem is not re-admission itself, but stale representations at the current depth.a:T614,The main experiments are built on LLaVA-1.5-7B, with referring-expression grounding and general multimodal benchmarks. The motivating analysis is one of the strongest parts of the paper. On 500 RefCOCO samples with 576 visual tokens and top-64 relevance sets, the average adjacent-layer volatility of the top-K visual token set is 28.85%, showing that query-relevant evidence changes substantially across depth. Using layer 2 as the early-selection reference, the late-emerging evidence ratio exceeds 50% by layer 7 and reaches 99.42% at layer 31. In other words, most tokens that matter later would be missed by an early irreversible selection.

On the main benchmarks, CatchUp achieves the best grounding retention among the compared efficient methods under matched routing budgets. Under matched prefill computation, it uses the fewest visual tokens and the smallest decoder KV-cache, while reducing end-to-end latency by 8.0% relative to dense inference. The paper emphasizes that the gain is not from more aggressive pruning alone, but from preserving accuracy better at the same budget.

The most informative ablation is oracle state replacement: if re-admitted tokens are given their full-token same-depth states, grounding performance improves markedly, confirming that stale states are the dominant issue in recoverable routing. Additional ablations indicate that semantic and spatial transition signals are complementary, and that routing frequency matters: too few routing points miss late evidence, while too many reduce the efficiency benefit.b:T781,The framework is sparse collaborative decoding. A draft model generates most tokens, and a stronger target model is invoked only at selected intervention points to generate a bounded corrective segment. That segment is appended to the visible context, and the draft resumes generation. The intervention is purely textual: no logits, hidden states, or parameters are shared. This makes the method compatible with black-box targets and clearly different from speculative decoding, which keeps target computation tightly coupled to generation.

The key technical question is the trigger policy. The paper first tests the most obvious signals: current-token entropy, negative log-likelihood, logit margin, top-k mass, and short-window velocity features. These turn out to be weak predictors of final correctness. The reason is intuitive: a model can be confidently wrong on a bad reasoning path, or briefly uncertain on a path that is still recoverable.

The authors then move to trajectory-level failure prediction. Instead of using a single token state, they summarize the confidence trajectory observed so far. Features are built from time series of entropy, NLL, margin, probability concentration, and temporal variation, then aggregated into means, extrema, percentiles, slopes, variances, and position-dependent summaries. A lightweight logistic predictor is trained using only draft correctness labels. At inference time, the system updates these trajectory features online and triggers the target when predicted failure risk crosses a threshold.

This creates an explicit trigger-timing tradeoff. Early calls have more leverage to redirect the trajectory but weaker evidence; late calls have stronger evidence but less room to help. The paper evaluates this learned online policy against fixed-position open-loop schedules, whole-example cascade routing, posthoc rewriting, self-consistency, and speculative decoding.c:T56d,Three results matter most. 第一部分是 Q Premix。设原始 query heads 为 Hq，压缩后物理 query heads 变成 Hq'，通常是原来的一半；KV heads 固定为 2，因此每个 KV group 会对应更多 query heads。Premix 在每个 KV group 内对 query 做一个接近恒等映射的线性变换，把较少的物理 query heads 扩展成更多“虚拟 query heads”。这里“接近恒等”很关键：如果一开始就做强混合，训练可能不稳定，也容易破坏原有注意力结构；近恒等初始化更像是在 GQA-2 的基础上逐步学出组内头部专门化。作者从训练后矩阵的直接可视化里观察到，Premix 学到的是 group-conditioned query specialization，也就是同组内不同虚拟头会形成有结构的差异，而不是无意义的线性扰动。

第二部分是 Linear Postmix。仅靠组内 Premix 还不够，因为 KV heads 只有 2，跨组的信息通道仍然受限。Postmix 在 attention 输出后施加一个低秩 identity-residual 变换 I + AB^T，其中秩 r 取 Hq'/2，例如 1.7B 模型里 r=4。这个设计的意图是用很小的额外参数和计算，把不同头、不同组之间的特征再融合一次。作者把它解释为 structured low-rank cross-head communication。与 MFA 通过增大 head dimension 来补容量不同，VHA 不去扩大每个头的宽度，而是在头之间做便宜的线性耦合，因此训练和 prefill FLOPs 不会上升，反而因为物理 query heads 减半而下降。

一个很漂亮的工程点是：Premix 和 Postmix 都是纯线性操作，没有非线性，也不依赖 token 位置或上下文状态，因此在推理时可以分别吸收到 WQ 和 WO 中。吸收后，线上模型就是一个标准 GQA-2 结构，完全复用现有 kernel 和 serving 优化，不引入额外 runtime overhead。这一点把它和很多“训练时好看、部署时麻烦”的注意力变体区分开了。

This immediately reduces both KV cache and attention compute, but it also removes a large amount of head diversity. VHA restores that diversity through two lightweight linear modules.

The first is Q Premix. Within each KV group, Premix applies a near-identity linear transformation to the reduced set of physical query heads, effectively expanding them into a richer set of virtual query heads. The near-identity design is important. It keeps the model close to a stable GQA-2 parameterization early in training, while allowing the network to gradually learn structured specialization among heads that share the same KV pair. The authors’ matrix inspection suggests that this is exactly what happens: Premix learns group-conditioned query specialization rather than arbitrary mixing.

The second is Linear Postmix. Even with better within-group query diversity, using only 2 KV heads still limits cross-group interaction. Postmix therefore applies a low-rank identity-residual transformation, I + AB^T, to the attention output. The rank is small, for example r = Hq'/2 and r = 4 at the 1.7B scale. This gives the model a cheap way to fuse information across heads and groups after attention, without increasing head dimension or introducing nonlinear runtime structure. The paper interprets this as structured low-rank cross-head communication.

A major engineering advantage is that both modules are purely linear. Premix can be folded into the query projection matrix WQ, and Postmix into the output projection WO at inference time. After folding, the deployed model is just a standard GQA-2 model. This means VHA inherits existing inference kernels and serving optimizations from frameworks such as vLLM and SGLang with zero additional runtime overhead.

Relative to prior methods, the distinctions are clean. Compared with standard GQA, VHA adds learnable compensation before and after shared-KV attention. Compared with MLA, it avoids a latent KV bottleneck. Compared with MFA, it does not increase head dimension and therefore avoids the large training/prefill FLOP increase.11:T705,The paper reports matched pretraining experiments at four scales under 4K context and 50B tokens: 0.6B, 1.7B, 4B dense, and 8B-A1B MoE. The hard part is multi-token selection, which is combinatorial. DropKV’s main idea is decoupling: replace the joint optimization over eviction sets with independent per-token perturbation scores. Intuitively, it uses single-token perturbation as a proxy for the multi-token objective, breaking the coupling between decisions and reducing the complexity to linear time.
