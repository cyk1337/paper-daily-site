This separates which positions receive supervision, how much they matter, and how the local prediction objective is computed. The resulting recipe combines mixed-horizon training, intra-block unmasking, and acceptance-weighted loss. Mixed horizons let one drafter support multiple inference block sizes. Intra-block unmasking exposes part of the block and asks the model to predict the rest, matching the conditional structure of block-diffusion drafting. Acceptance weighting reflects the prefix-survival probability that determines contribution to MAT. For inference, the paper writes throughput as G = MAT / T and uses this to choose target-conditioning depth, drafter depth, and block size. The implementation builds on DFlash: a frozen target model provides hidden states from selected layers; these features are concatenated, linearly fused, and used to condition a lightweight block-diffusion drafter.a:T7fb,The core idea is a quadratic surrogate for attention-output error, used inside an OBS-like iterative elimination procedure. Starting from single-head attention, the paper avoids optimizing the exact post-deletion output error because softmax renormalization makes the objective combinatorial and strongly coupled. Instead, it uses calibration queries to approximate the query distribution encountered during reuse of the fixed context, and derives a quadratic surrogate over the resulting output error.

That surrogate has two properties that make the method practical:
1. For each candidate deletion, it yields a closed-form optimal compensating update to the remaining cache entries.
2. It also yields a closed-form score for the increase in surrogate loss after applying that optimal compensation.

This leads to KV-Surgeon: at each step, evaluate every candidate entry by the residual error after optimal compensation, remove the best candidate, apply the compensating update to the surviving cache, and repeat. The next deletion is then chosen against an already compensated cache, not the original one. This is the key difference from methods such as CAOTE, OBCache, or attention-matching-style selection, which either estimate single-deletion damage with the rest fixed or postpone refitting until after subset selection.

The paper also presents a faster variant, KV-Surgeon-fast, which trades some quality for much lower offline construction cost. A final joint refit is still used after selection, but the important point is that compensation already influences which entries survive. The retained set is therefore selected with awareness of how well the remaining cache can absorb the deletion.

A notable strength of the formulation is that it is not purely attention-mass based. It also captures value redundancy: if an entry's value is already close to the current output, removing it may have limited effect even when its attention weight is nontrivial. This helps explain why the method improves over attention-only heuristics.b:T5f4,The evaluation is fairly broad: QuALITY, LongHealth, and Long Code Arena; dense and MoE models; model sizes from 4B to 30B; and compaction ratios from 5x to 100x. For a quadratic probe, that gradient is 2W_p x + w_p: input-dependent, but affine in x. Because the intervention is affine, it can be folded exactly into adjacent linear projections, attention projections, and certain normalization components as an offline weight update. The result is a standard checkpoint with no custom hooks or extra forward computation at inference time.

Relative to static steering, WAQS can represent curved concept boundaries rather than a single hyperplane. Relative to dynamic nonlinear steering, it avoids per-token recomputation. In that sense, quadratic probes are not just one convenient absorbable family; they are the maximal absorbable class under this formulation.

The key technical question is the trigger policy. The paper first tests the most obvious signals: current-token entropy, negative log-likelihood, logit margin, top-k mass, and short-window velocity features. These turn out to be weak predictors of final correctness. The reason is intuitive: a model can be confidently wrong on a bad reasoning path, or briefly uncertain on a path that is still recoverable.

The authors then move to trajectory-level failure prediction. Instead of using a single token state, they summarize the confidence trajectory observed so far. Features are built from time series of entropy, NLL, margin, probability concentration, and temporal variation, then aggregated into means, extrema, percentiles, slopes, variances, and position-dependent summaries. A lightweight logistic predictor is trained using only draft correctness labels. At inference time, the system updates these trajectory features online and triggers the target when predicted failure risk crosses a threshold.

This creates an explicit trigger-timing tradeoff. Early calls have more leverage to redirect the trajectory but weaker evidence; late calls have stronger evidence but less room to help. The paper evaluates this learned online policy against fixed-position open-loop schedules, whole-example cascade routing, posthoc rewriting, self-consistency, and speculative decoding.15:T56d,Three results matter most. 第一部分是 Q Premix。设原始 query heads 为 Hq，压缩后物理 query heads 变成 Hq'，通常是原来的一半；KV heads 固定为 2，因此每个 KV group 会对应更多 query heads。Premix 在每个 KV group 内对 query 做一个接近恒等映射的线性变换，把较少的物理 query heads 扩展成更多“虚拟 query heads”。这里“接近恒等”很关键：如果一开始就做强混合，训练可能不稳定，也容易破坏原有注意力结构；近恒等初始化更像是在 GQA-2 的基础上逐步学出组内头部专门化。作者从训练后矩阵的直接可视化里观察到，Premix 学到的是 group-conditioned query specialization，也就是同组内不同虚拟头会形成有结构的差异，而不是无意义的线性扰动。

第二部分是 Linear Postmix。仅靠组内 Premix 还不够，因为 KV heads 只有 2，跨组的信息通道仍然受限。Postmix 在 attention 输出后施加一个低秩 identity-residual 变换 I + AB^T，其中秩 r 取 Hq'/2，例如 1.7B 模型里 r=4。这个设计的意图是用很小的额外参数和计算，把不同头、不同组之间的特征再融合一次。作者把它解释为 structured low-rank cross-head communication。与 MFA 通过增大 head dimension 来补容量不同，VHA 不去扩大每个头的宽度，而是在头之间做便宜的线性耦合，因此训练和 prefill FLOPs 不会上升，反而因为物理 query heads 减半而下降。

一个很漂亮的工程点是：Premix 和 Postmix 都是纯线性操作，没有非线性，也不依赖 token 位置或上下文状态，因此在推理时可以分别吸收到 WQ 和 WO 中。吸收后，线上模型就是一个标准 GQA-2 结构，完全复用现有 kernel 和 serving 优化，不引入额外 runtime overhead。这一点把它和很多“训练时好看、部署时麻烦”的注意力变体区分开了。

从对比关系看，VHA 与 GQA 的区别是：GQA 直接让更多 query heads 共享同一组 K/V，而 VHA 在共享前后都加了可学习线性补偿；与 MLA 的区别是：VHA 不做 latent KV 压缩，因此避免了 latent bottleneck 带来的质量损失；与 MFA 的区别是：VHA 不通过增大 head dim 来换质量，因此不会显著增加训练和 prefill 计算。18:T834,实验覆盖面比较完整。作者在四个基础规模上做了 4K context、50B token 预训练：0.6B、1.7B、4B dense，以及 8B-A1B MoE。结果是 VHA 在所有规模上都超过标准 GQA baseline，提升范围约为 +0.05% 到 +0.81%。这里绝对数值看起来不大，但要注意比较对象已经是很强的 GQA，而且 VHA 同时把 KV cache 压下去了。

This immediately reduces both KV cache and attention compute, but it also removes a large amount of head diversity. VHA restores that diversity through two lightweight linear modules.

The first is Q Premix. Within each KV group, Premix applies a near-identity linear transformation to the reduced set of physical query heads, effectively expanding them into a richer set of virtual query heads. The near-identity design is important. It keeps the model close to a stable GQA-2 parameterization early in training, while allowing the network to gradually learn structured specialization among heads that share the same KV pair. The authors’ matrix inspection suggests that this is exactly what happens: Premix learns group-conditioned query specialization rather than arbitrary mixing.

The second is Linear Postmix. Even with better within-group query diversity, using only 2 KV heads still limits cross-group interaction. Postmix therefore applies a low-rank identity-residual transformation, I + AB^T, to the attention output. The rank is small, for example r = Hq'/2 and r = 4 at the 1.7B scale. This gives the model a cheap way to fuse information across heads and groups after attention, without increasing head dimension or introducing nonlinear runtime structure. The paper interprets this as structured low-rank cross-head communication.

A major engineering advantage is that both modules are purely linear. Premix can be folded into the query projection matrix WQ, and Postmix into the output projection WO at inference time. After folding, the deployed model is just a standard GQA-2 model. This means VHA inherits existing inference kernels and serving optimizations from frameworks such as vLLM and SGLang with zero additional runtime overhead.

Relative to prior methods, the distinctions are clean. Compared with standard GQA, VHA adds learnable compensation before and after shared-KV attention. Compared with MLA, it avoids a latent KV bottleneck. For a query q, the full-cache attention output is a = Σ_i p_i v_i. If a set J of tokens is evicted, the new output is a_-J and the shift is Δ(J) = a_-J - a. The paper derives how this perturbation depends on the total removed attention mass P_J and on value residuals relative to the original output. The single-token case is especially revealing: Δ({j}) = p_j / (1 - p_j) · (a - v_j). This immediately shows why attention-only scoring is incomplete. A token can have nontrivial attention but still be safe to remove if its value is close to the current output; conversely, a token with moderate attention can be important if its value points in a distinctive direction.

The hard part is multi-token selection, which is combinatorial. DropKV’s main idea is decoupling: replace the joint optimization over eviction sets with independent per-token perturbation scores. The paper calls this Decoupled Residual-Output Perturbation. Intuitively, it uses single-token perturbation as a proxy for the multi-token objective, breaking the coupling between decisions and reducing the complexity to linear time. The authors then prove a near-optimality result: under a cone condition, the decoupled proxy matches the NP-hard optimum up to a constant multiplicative factor. The cone condition roughly says that the relevant residual vectors do not cancel each other arbitrarily and lie within a bounded geometric cone. Importantly, the paper does not leave this as a purely formal assumption; it empirically checks the condition on Llama-3.1-8B, Mistral-7B-512K, and Qwen2.5-7B-1M.
