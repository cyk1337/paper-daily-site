a:T457,CADCON is a five-feature binary design-intent header (CIRCLE, NGON, THIN, TALL, MULTI_PART) prepended to CadQuery-style sketch-extrude programs (transpiled from DeepCAD histories). Qwen2.5-Coder-1.5B is LoRA-fine-tuned under this conditioning. Two methodological innovations carry the study: (1) Metric independence—adherence is re-scored by executable geometric assertions on the produced B-rep solid, sharing no code with the training-side regex extractor used to build header labels. The full evaluation matrix ({0%, 40%} prefix × {correct, wrong, masked} header × 3 seeds × both tokenizations) and all decision rules are pre-registered before scoring. (2) Causal control—a derangement-trained control group receives shuffled ground-truth headers (each program gets another program's header), so the header marginal distribution is byte-identical to standard training but the header↔program correlation is destroyed. If the control shows no performance drop under wrong headers, the harm can be attributed to the learned header→program mapping rather than a mechanical distribution-shift confound.b:T509,Four key findings: (1) A semantically wrong header hurts more than no header. The effect survives on the valid-geometry subset, ruling out a validity artifact. (2) The harm requires the learned header→program mapping. The derangement-trained control remains competent but shows no correct→wrong drop, while the standard model drops sharply. The apparent gain of a correct header shrinks substantially relative to the regex metric (text +31% vs +52% relative; token +4% vs +46%), quantifying metric circularity in conditioning claims.
