Recovering Policy-Induced Errors: Benchmarking and Trajectory Synthesis for Robust GUI Agents

这篇论文聚焦 GUI agent 的一个很实际但常被弱化的问题：模型犯错之后，能不能识别自己已经进入错误状态，并通过后续操作把任务拉回来。作者把这类问题定义为 policy-induced errors，也就是错误不是外部噪声注入造成的，而是 agent 自己在执行中因为错误 grounding、误判界面状态、选错子目标等动作一步步走出来的。现有 benchmark 更关注 grounding、规划或最终成功率，训练数据也多是人类演示或短程反思样本，因此对真实部署里常见的“长程、自诱发、组合式错误”覆盖不足。

评GUI Agent错误恢复的专门基准与数据合成方法，树状探索合成错误轨迹的思路可迁移到其他Agent训练数据生成，看§3数据合成部分即可。
Tianpeng Bu,Xin Liu,Qihua Chen,Hao Jiang,Shurui Li,Hongtao Duan,Lu Jiang,Lulu Hu,Bin Yang,Minying Zhang

LiteCoder-Terminal: Scaling Long-Horizon Terminal Environments for Learning Language Agents

这篇工作要解决的是 terminal agent 训练数据稀缺且来源受限的问题。现有做法大量依赖 GitHub issue、Stack Overflow 或现成仓库任务，这会带来三个限制：领域覆盖受外部语料分布约束，环境状态不可控，且很难针对模型的具体短板定向生成训练样本。作者提出一个 zero-dependency 的合成管线，试图不依赖外部仓库，直接从高层领域规范出发，自动生成可执行、可验证、可用于 SFT 和 RL 的 terminal 环境与专家轨迹。

评终端agent训练环境的合成框架和数据集，对agent研究有参考价值，但对预训练本身无直接启发。值得扫一眼方法和数据统计。
Xiaoxuan Peng,Kaiqi Zhang,Xinyu Lu,Boxi Cao,Yaojie Lu,Hongyu Lin,Xianpei Han,Le Sun
