AWM: Answerable Working Memory for Long-Document VQA Agents

这篇工作处理的不是长文档 VQA 里的检索问题，而是一个更细的训练与评测缺口：agent 在看过页面后写下的 terminal working memory，是否真的保留了足以支撑最终答案的证据。现有评测通常只看 final answer 对不对、有没有访问到证据页，但这两件事都不能保证 memory 本身可用。论文把这个缺口形式化为 memory-only answerability：只给问题和最终 memory，不给页面图像和轨迹，让一个冻结 reader 仅凭 memory 作答。如果 reader 不能答对，就说明 agent 虽然可能答对了，但它留下的 memory 并不具备可复用、可传递的证据价值。作者进一步把这种 failure 聚焦为 MMC（memory-missing correct）：final answer 正确但 memory-only answer 错误，说明 memory 质量是独立于最终答对与否的一条训练维度。

评可当作“中间状态也该可验证”的一个 RL 例子看，读 diagnostic 定义和 reward 设计即可；对 pretrain 本身没有直接动作项。
