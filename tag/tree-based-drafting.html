TreeFlash: Parallel AR-Approximation for Faster Speculative Decoding

这篇论文解决 one-shot speculative decoding drafter 的条件化不足问题。DFlash 这类方法一次前向生成整个 draft block，每个位置只条件化在原始 prefix 上，而不看 block 内已经草拟出的前一个 token。draft 深度越大，drafter 分布和 verifier 的自回归分布偏差越大；在 tree drafting 中，不同分支还会被迫共享后续 token 的边缘分布，树的质量进一步下降。

评推测解码的增量改进，核心近似自回归的设计有参考价值，只看方法部分即可
