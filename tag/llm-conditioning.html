On The Effectiveness-Fluency Trade-Off In LLM Conditioning: A Systematic Study

这篇工作研究的是：当我们用 prompting、activation steering、LoRA-SFT 等手段去给 LLM 注入或移除某个概念时，控制效果和生成质量之间到底如何权衡，以及这种权衡会不会随着模型训练范式变化而改变。论文不是只看“有没有把概念打进去/拿掉”，而是把 fluency、语法完整性、指令遵循一起纳入评估。更关键的一点是，它把 base model 和 instruction-tuned model 分开看，发现 activation steering 在 base 模型上常常有效，但到了 instruction-tuned 模型上明显失灵。这说明很多 steering 结论并不能直接从 base model 外推到实际部署更常见的 instruct model。

评条件控制方法的系统对比，发现训练范式与激活转向的交互效应有实用意义——指令调优削弱了激活转向效果。读 §3-§4 实验部分即可。
Iuri Macocco,Pau Rodríguez,Arno Blaas,Luca Zappella,Marco Baroni,Xavier Suau
