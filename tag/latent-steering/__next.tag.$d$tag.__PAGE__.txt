9:T491,SPS is a training-free latent steering framework. It does not update model weights. Instead, it builds a state-conditioned direction bank offline and injects retrieved steering directions during generation. The offline stage samples reasoning trajectories on a small calibration set and identifies high-uncertainty transitions, which are treated as likely branching points. At those states, the same model proposes multiple continuations using a higher proposal temperature. An LLM judge labels continuations as progress-making or non-progress-making. SPS then contrasts the hidden representations of these two groups to derive steering directions and stores them by prefix-state regions. During online inference, the method monitors the current reasoning prefix, retrieves a suitable direction from the bank, and applies it only at high-uncertainty transitions and at selected layers. Compared with temperature schedules, diverse prompting, or generic latent perturbation, SPS aims to steer exploration toward continuations that make measurable progress. Compared with training-time diversity methods, it avoids extra optimization, special losses, or RL reward design.a:T49c,They operate on Cross-layer Transcoders (CLTs), which learn a shared sparse dictionary spanning all layers (a cross-depth latent space), enabling analysis beyond single-layer SAEs.
They compare three latent-selection methods:
- ValSel: select latents with language-distinct activation magnitudes (mean activation differences), using an l-monolinguality score.
- FreqSel: select latents that activate more frequently for a target language, with a specificity threshold T and corpus/token coverage constraints (N%, M%).
- AnnSel: trace attribution graphs with Circuit Tracer, prune to high-importance paths, then filter latents by LLM-generated annotations that explicitly mention the target language (favoring interpretability).

- Target amplification (set target latents to mean nonzero activations from target-language data).
- Distractor zero ablation (zero latents for the context language or all non-target languages).
- Distractor direction ablation (remove residual projections along distractor latent directions; one-layer vs multi-layer).
