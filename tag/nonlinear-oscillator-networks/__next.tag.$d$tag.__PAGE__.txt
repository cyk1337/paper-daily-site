9:T4e3,The method has three main steps. First, the authors start from a continuous-time network of coupled oscillators arranged on a one-dimensional ring. In the original phase variables the system is nonlinear, but under the coordinate transform x_i = exp(i psi_i), the dynamics become complex-linear and admit an exact solution through a matrix exponential e^{Kt}. This yields an explicit discrete propagation operator D_tau = e^{K tau}. Second, when the coupling matrix has circulant structure, the operator can be diagonalized analytically by the Fourier basis, so each frequency mode evolves independently. This is exactly the form used by diagonal state space models. Third, they match this formulation to S4D-Lin: the diagonal recurrence matrix in S4D corresponds to mode-wise propagation in the transformed oscillator system, while the input term matches the discretized external drive. The nonlinear decoder is then interpreted as a nonlinear readout from otherwise linear latent dynamics.

What is distinctive here is that the paper is about equivalence and interpretation, not discretization tricks, fast convolution kernels, or optimization. The authors also argue that the analysis extends beyond S4D-Lin to a broad class of diagonalizable SSMs.a:T46d,The empirical section is not a benchmark-driven evaluation in the usual LLM sense. For a pretraining researcher, the main takeaway is not a performance gain but a decomposition of where computation comes from: linear propagation preserves and mixes spectral components, while the nonlinear readout turns them into useful representations.
