9:T6c0,PCAF has two parallel paths. The first is a local parametric causal LM that handles short-range composition and generalization. The second is an associative memory path that stores local causal successor records extracted from the context window. At inference for a position t, the model forms a query from the current context, uses a route to retrieve a bounded set of candidate records from hash buckets or learned semantic partitions, scores only those candidates with a key-query similarity, and converts the retrieved records into a sparse cache distribution over successor tokens.

Three design choices matter. First, the memory stores successor records rather than generic hidden states. This means retrieval directly produces evidence about what token followed a similar context before, making the memory path behave like an internal neural cache. Second, routing comes in two forms: exact context-hash routing and learned semantic routing. Exact routing is precise and cheap but brittle to surface-form mismatch; semantic routing allows hidden-state-near contexts to retrieve one another. Third, the final prediction is a learned mixture between the parametric LM distribution and the cache distribution. The gate lets the model rely on retrieval when the memory hit is informative, and fall back to the parametric path when retrieval is noisy or absent.

Relative to standard attention, PCAF does not compare against every previous token. Relative to recurrent or SSM-style models, it does not force all history through a single compressed state. Relative to external retrieval LMs, it keeps memory construction and access inside the current context window, with bounded top-K retrieval as the main complexity control.a:T59c,The main evaluation is full autoregressive pretraining rather than synthetic recall tasks. The reported datasets are WikiText-103 and PG-19. The main model is about 303M parameters, compared against matched dense Transformer and local-attention baselines. The paper reports lower perplexity for PCAF on both datasets, together with higher token throughput on a TPU v4-32 pod. That combination is important: the method is not presented as a pure systems tradeoff, but as a modeling change that improves quality at similar scale while also reducing effective compute.

The paper also includes smaller 41M-parameter multi-seed studies to isolate the effects of routing, cache capacity, and the learned gate. From the setup, these ablations are the right ones to inspect: whether the gate is necessary to prevent harmful retrieval, how exact routing compares with semantic routing, and how much benefit remains once top-K and memory capacity are varied. There is also RTX 3060 profiling, which is useful because many long-context alternatives look attractive in asymptotic terms but fail to translate into practical throughput.
