9:T7a2,方法名 MRTPO（Multi-Reward-to-Token Policy Optimization）。它保留 GDPO 的关键优点：对每个 reward 在 rollout group 内单独标准化，避免 reward collapse（不同 reward 组合被同一个 advantage 混掉）。核心变化在于：对每个 reward k，不再把该 reward 的 group-normalized advantage 均匀分给所有 token，而是先估计“哪些 token 与 reward k 相关”，再按相关性做归一化分配。

相关性估计来自 self-replay + privileged information：每个 verifier 在评估时依赖某些信息（例如：正确 SQL 的参考、执行错误信息、工具调用的规范/约束、指令中的某条约束文本等）。MRTPO 对同一条已采样的 response y 做两次 teacher-forcing 式的重放（replay）：一次在“包含 reward k 的 verifier 信息”的上下文下，一次在“移除该信息”的上下文下，得到每个位置 t 的 next-token 分布 p_t^{(+k)} 与 p_t^{(-k)}。用 token-wise Jensen–Shannon divergence 作为差异度 d_{k,t}=JSD(p_t^{(+k)}||p_t^{(-k)})，把它解释为该 token 对 reward k 的敏感度/相关性。然后把 reward k 的优势 A_k^{(j)}（来自 group 标准化）按 d_{k,t} 在 token 维度上归一化，得到 token advantage A_{k,t}^{(j)}，再把所有 reward 的 token advantage 聚合成最终 A_t^{(j)} 进入 PPO/GRPO 的 clipped surrogate objective。

与已有方法的区别：GDPO/SAW 等主要解决“每个 reward 在 response-level 贡献多少”（reward weighting / normalization），但仍是 token-uniform；OPSD 类自蒸馏方法是直接拟合带 privileged info 的 teacher 分布，目标函数形态不同，且不显式做多 reward 的 credit 分解。MRTPO 的关键取舍是：不需要额外生成（仍用同一条 response 重放），不需要 token 标注，不引入额外模型；代价是每个 reward 需要额外两次前向重放来算 JSD（计算开销随 reward 数 K 增长）。a:T4bb,MRTPO (Multi-Reward-to-Token Policy Optimization) keeps the standard PPO/GRPO clipped objective intact and changes only the per-token advantage A_t. For each reward k, it constructs two replay contexts for the same sampled response: one with the verifier’s information for reward k available (+k), and one with that information removed (-k). It then teacher-forces the response under both contexts to obtain next-token distributions p_t^(+k) and p_t^(-k) at every position t. Token relevance is measured as d_{k,t} = JSD(p_t^(+k) || p_t^(-k)). The group-normalized advantage for reward k is redistributed across tokens proportionally to d_{k,t} (with normalization over t), yielding reward-specific token advantages that are then aggregated across rewards.

Key distinctions: GDPO/SAW decide reward contributions at the response level but remain token-uniform; OPSD-like on-policy self-distillation fits a privileged teacher distribution directly rather than explicitly decomposing multi-reward credit.
