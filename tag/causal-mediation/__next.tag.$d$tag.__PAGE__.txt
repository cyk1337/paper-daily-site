a:T816,The paper extends causal mediation analysis, specifically causal tracing / activation patching, from text-only factual recall studies to a multimodal setting. The procedure follows the standard three-run setup. First, run the model on a clean prompt and cache hidden states. Second, corrupt the input and measure the drop in probability assigned to the correct object token. Third, rerun the corrupted input while restoring one selected activation from the clean run, and measure how much the correct answer probability recovers. This recovery defines the indirect effect of that component, and averaging across prompts yields AIE maps over layers, positions, and components.

The key adaptation is to make this work for speech-conditioned prompting. SpiritLM is well suited for that because it represents speech as discrete HuBERT tokens, text with the Llama2 tokenizer, and uses modality declaration tokens to interleave both streams in one autoregressive backbone. That makes speech tokens analyzable in the same intervention framework used for text tokens.

For data, the authors start from the Known dataset of factual prompts used in prior factual localization work and create speech counterparts for prompts, subjects, and objects. Audio is synthesized with MeloTTS, then checked through manual inspection and Whisper-small transcription. The reported prompt WER is about 19%, which is good enough to support the analysis but also important for interpretation: weaker speech-side localization may partly reflect synthesis / transcription / discretization noise, not only missing internal mechanisms.

The main comparison is between T→T and S→T. The paper examines whether the familiar text-LM pattern, where factual associations are often mediated by mid-layer MLP states, reappears under speech input. The answer is only partially yes. Text input produces clearer and stronger restoration hotspots, while speech input yields weaker and more diffuse causal traces, suggesting that the mapping from speech tokens to parametric factual knowledge is less direct.b:T5de,The experimental story is more about mechanism patterns than benchmark scores.

First, the study uses roughly 1,000 factual prompts from the Known dataset and augments them with speech versions. This keeps the analysis focused on controlled factual associations rather than open-domain QA noise.

Second, the speech data quality is explicitly checked. Whisper-small transcription of synthesized prompts gives a 19% WER. That number is not negligible, and it should be kept in mind when interpreting weaker S→T effects.

Third, the central result is that T→T reproduces clearer factual localization, consistent with prior text-only work, whereas S→T shows weaker but still detectable traces. In other words, factual recall mechanisms do carry over, but only partially. The signal is less concentrated and less robust under speech input.

Fourth, the paper is useful partly because of what it does not find. A unified backbone does not guarantee that speech inputs inherit the full factual retrieval pathway available to text inputs. From a pretraining perspective, this points to possible bottlenecks in speech tokenization, cross-modal alignment, and the objective used to mix speech and text during training.

The full text provided here does not include all tables and exact effect magnitudes, so the hard numbers that can be stated confidently are mainly the dataset size scale and the 19% WER. The rest is best read as a qualitative mechanistic pattern rather than a leaderboard-style result.c:T4d3,This is a skim paper. Read it as a mechanistic probe of multimodal pretraining, not as a new training recipe.

Start with the introduction to fix the scope: the target is factual recall mechanisms, not speech recognition quality. Then read the methodology carefully, especially the clean / corrupted / patched runs and the definition of indirect effect. Once that is clear, the result figures become much easier to interpret.

Pay close attention to the SpiritLM input format and the speech data construction pipeline. HuBERT discretization, modality tokens, and TTS-generated prompts are not implementation details here; they shape what the conclusions actually mean. When reading the result plots, the right question is not only which layer peaks, but whether speech causes the signal to become weaker, more diffuse, or shifted away from the canonical mid-layer factual pathway seen in text LMs.

About 30 to 40 minutes is enough for the main idea. If you want to go deeper, the natural follow-up questions are whether native speech-pretrained models would show even weaker localization, and whether stronger speech-text alignment or shared semantic tokenization could make speech-side factual recall look more like the text pathway.d:T91a,The study combines architecture-aware probing with several mechanistic interventions. The authors analyze two representative VLM families. LLaVA-1.5 serves as a clean baseline because CLIP ViT-L/14 patch tokens are mapped one-to-one into the LLM space through a small MLP. InternVL-3.5 adds two complications: token compression via pixel shuffle and dynamic multi-view processing with a global thumbnail plus local high-resolution tiles. This contrast lets the paper test whether the same localization mechanism survives under compression and multi-view fusion.

The dataset is a curated subset of COCO val, not raw COCO. The authors first correct annotation issues using prior semi-automatic procedures, then filter out tiny or dominant objects, low-resolution images, and ambiguous cases. The final set contains 3,560 images and 6,403 object annotations. They also build auxiliary controls to reduce context-only hallucinated detections. This matters because mechanistic claims are fragile under noisy labels.

The main tools are:
1. Token ablations to identify which visual tokens causally support class prediction and box prediction.
2. Controlled perturbations that preserve object extent while scrambling internal semantic arrangement, or alter context outside the object, to test whether localization depends on internal semantic layout or mainly on token support boundaries.
3. Positional decoding from intermediate representations to see how a 1D token sequence still carries enough signal for the LLM to reconstruct an approximate 2D grid.
4. Attention knockout to rank heads by causal importance for classification and localization.
5. Causal mediation analysis to separate heads that directly affect localization from heads whose effect is mediated through classification.

The central claim is a containerization mechanism: object-aligned tokens define a spatial container, and the semantic arrangement inside that container matters surprisingly little for the predicted box. In InternVL, the global view carries most of the spatial signal, while local crops mainly refine semantics and help small-object classification. The paper also argues for a sequential dependency: localization-critical processing depends on classification-critical heads, even though the dominant heads for the two tasks are largely distinct.e:T692,The most useful results are intervention-based rather than benchmark-based. The analysis covers LLaVA-1.5 7B and 13B, and InternVL-3.5 8B, on the curated COCO-derived set with 3,560 images and 6,403 object instances.

The main empirical findings are:
1. Localization information is genuinely encoded in visual tokens. Ablating object-aligned tokens strongly disrupts box prediction, while ablating irrelevant regions has much smaller effect.
2. Scrambling semantics inside an object while preserving its token support leaves localization relatively stable. This is the key evidence for the containerization claim.
3. In InternVL, removing the global thumbnail hurts localization more than removing local high-resolution tiles, whereas local tiles contribute more to fine-grained recognition and small-object classification. This suggests a division of labor: global view for spatial frame, local view for semantic refinement.
4. Positional decoding shows that the LLM can recover an approximate 2D layout from the linearized token stream using residual positional structure and strong corner anchors, even without an explicit preserved 2D grid.
5. Only a very small number of attention heads carry strong causal effects. In LLaVA, these heads appear mostly in early-to-mid layers; in InternVL, more in mid-to-late layers. Classification and localization heads are not the same, but localization causally depends on classification-relevant heads, supporting a staged pipeline of identify first, ground later.

The paper is not about pushing a task metric by a large margin, so the important evidence is the consistency of these trends across interventions, layers, and architectures.f:T487,Read it as a mechanistic case study, not as a new VLM method. Four parts deserve attention.

First, inspect the architecture setup carefully. The contrast between LLaVA and InternVL explains why head locations and view roles differ later.

Second, focus on the token ablation and controlled perturbation figures. These are the core evidence for the containerization hypothesis. Pay attention to how the paper isolates object extent, internal semantic arrangement, and background context.

Third, read the global-versus-local analysis in InternVL if you care about multimodal pretraining design. It gives a concrete answer to what high-resolution tiles are actually buying.

Fourth, study the attention knockout and mediation analysis. The important point is not merely that a few heads matter, but how classification-critical and localization-critical heads are distributed across layers and how the causal dependency is established.
