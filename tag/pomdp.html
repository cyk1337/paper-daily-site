STOCKTAKE: Measuring the Gap Between Perception and Action in LLM Agents with a Fair Oracle

这篇工作要解决的不是“LLM agent 在长周期决策里表现差”这个泛问题，而是更细的一层：在部分可观测、长期累积成本的任务里，失败到底来自没看懂世界，还是看懂了却没把判断落实成动作。现有 supply-chain / retail 一类 benchmark 往往只给最终成本，或者拿能看到特权信息的 oracle 当上界，因此把 state estimation failure 和 control failure 混在一起，无法定位 knowing-doing gap。STOCKTAKE 的核心设计，是构造一个可以计算“公平 oracle”的长周期 POMDP 基准，让参考策略和 agent 看到完全相同的观测流，从而把感知与行动两类失败拆开测。

评值得看评测设计；只读 oracle 构造和 rationale 诊断，别把供应链设定误读成通用能力结论。
Sagar Deb,Ashwanth Krishnan

Native Active Perception as Reasoning for Omni-Modal Understanding

这篇工作处理的是长视频与全模态理解里的一个老问题：现有多模态模型大多还是“被动看完再答”，计算量和上下文长度随视频时长增长，遇到小时级视频时成本很快失控。已有 agent 式方法虽然开始做选择性观察，但往往仍依赖全局预扫、外部工具链，或者保留稠密视觉缓存，因此没有真正把“推理复杂度”从“原始视频长度”里剥离出来。OmniAgent 想解决的是：能否让同一个原生 omni 模型在不依赖外部感知模块的前提下，把视频理解写成一个按需观察、边看边想、持续压缩记忆的决策过程，使推理成本更多取决于问题难度，而不是视频有多长。

评将多模态理解建模为主动感知POMDP，解耦长视频推理成本与时长，对统一多模态建模有参考，看§3.1即可。

Learning POMDP World Models from Observations with Language-Model Priors

现有基于LLM先验的世界模型学习方法（如WorldCoder、POMDP Coder）均依赖完全可观测假设或事后真实状态访问（post-hoc full observability），无法应用于遮挡环境、不完全信息博弈等严格POMDP场景。论文研究仅从观测-动作-奖励轨迹出发，能否利用LLM先验诱导出可执行的POMDP世界模型，而无需访问真实隐状态。
