The main supervision is progress-aligned recurrence. If a task requires d sequential operations and zj denotes the state or answer after the first j operations, then iteration k is trained to predict zk rather than the final answer zd. In forced depth, each batch contains a single task depth d and the model runs R=ceil(d/c) iterations. In hold, R is sampled from a heavy-tailed distribution and the target remains zd after the task is complete. Forced depth is the default.

The second main component is RMS norm anchoring. After each recurrent iteration, each token state is rescaled to match the RMS norm of its first-iteration state, using a stop-gradient reference. The paper formulates the problem as a prefix MDP. A state contains the public context h, the current reasoning prefix xt, its token length kt, and the checkpoint index t. The control action is either Wait or Stop. Wait reveals the next chunk from the frozen reasoning model. Stop terminates the prefix process and invokes the reasoning model’s action-generation interface using the current prefix. The central training signal is prefix-level action agreement: whether the action generated from a partial prefix matches the reference action produced after full reasoning. This is a model-specific target, because the stopping policy is trained to preserve the behavior of a particular reasoning model rather than to follow a generic confidence heuristic.

Training is done offline from collected reasoning trajectories with action annotations at multiple prefix lengths. Because the outcomes of different stopping times are recorded, the paper can optimize an exact expected-return objective over stopping decisions. A discount factor gamma controls the tradeoff between preserving the full-reasoning action and saving reasoning tokens: smaller gamma favors earlier stopping, while gamma closer to 1 favors agreement with the full-reasoning reference. Importantly, gamma is also provided as a conditioning input, so one trained policy can be used at inference time under different budget preferences.
