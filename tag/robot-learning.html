RotVLA: Rotational Latent Action for Vision-Language-Action Model

这篇工作处理的是 VLA 预训练里一个很具体但关键的问题：如何从异构机器人数据和无标注人类视频中学到一个统一、可迁移、又不容易退化的 latent action 空间。现有 LAM 多数走“相邻帧编码→离散量化→重建下一帧”的路线，优点是容易接到 token-based VLM，但缺点也很集中：一是 latent 容易退化成对目标帧的压缩编码，而不是动作；二是离散 codebook 对连续物理动作的表达不自然，容量也受限；三是 latent 空间缺少可组合的几何结构，难以承载跨 embodiment 的动作语义。RotVLA 的核心问题定义得很清楚：不用离散 token action，而是构造一个连续、可组合、带几何约束的 latent action 表示，并让它更像“动力学中的动作”而不是“重建中的捷径变量”。

评连续结构化隐动作空间的设计思路可迁移到多模态统一动作预训练，重点读§3的隐空间建模部分即可
