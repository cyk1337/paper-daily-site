18:T680,The method, Goggles, is a collection of small editor networks that operate only during backpropagation. The base model is frozen, and learning happens through LoRA adapters. Each LoRA-equipped module gets a corresponding editor. During SFT, the editor reads local signals available at that module and adds a residual to the gradients that update the LoRA parameters. The base weights remain untouched, and the forward pass is unchanged.

The editor takes detached local features such as the LoRA input activations, the gradient arriving at the module output, and the LoRA’s own output. This is important: the method is not trying to make the model “pay more attention” to textual disclaimers. It learns a transformation of the update itself, so that the same document content can induce different parameter changes depending on the intended epistemic frame.

Conceptually, this is close to a frame-conditioned learned update rule for LoRA, but it is more structured than generic learned optimization. It uses layer-local activations and gradients tied to the current sample, and it is trained once per base model, frame, and LoRA configuration. After training, the Goggles module can be reused on unseen documents. At inference time it disappears entirely, leaving behind a standard LoRA that can be merged and served normally.

Compared with prior approaches, the distinction is clear. It does not rely on textual framing surviving token-level optimization. It does not add an inference-time classifier head. It does not simply reweight losses globally. It intervenes at the parameter-writing stage, which is exactly where Negation Neglect appears to arise.19:T762,The experiments are organized around three questions: whether Goggles mitigates Negation Neglect, whether it generalizes beyond the training documents, and whether the induced frame survives further finetuning. All experiments use Qwen3-8B as the frozen base with LoRA adaptation. The baseline result stated early in the paper is already informative: when models are finetuned on documents with strong fictionality prefixes and suffixes, they correctly identify the relevant claims as fictional only about 9% of the time. That establishes how weak text-only framing is under SFT.

The main results show that Goggles substantially improves control over the model’s epistemic stance toward learned claims. The evaluation is not just surface instruction following. The authors probe whether the model treats the trained claims as true or fictional when queried later. They also test persistence under continued finetuning, including settings that push the model back toward believing the claim. The reported pattern is that Goggles leaves a more stable parameter-level imprint than textual disclaimers do.

Generalization is another important part of the story. A Goggles instance is not trained per document. It is trained once for a frame and then applied to unseen documents. The paper reports transfer across documents and across distinct epistemic frames, suggesting that the module is learning something closer to an update policy than to content-specific memorization.

The ablations examine which editor inputs and components matter. While the provided text fragment does not include the full numeric tables, the qualitative takeaway is that the gains come from gradient editing itself rather than from extra capacity or incidental training tricks.
