18:T894,方法设计相当克制，重点是把 provider、engine、sampling、prompt leakage 这些常见混杂因素尽量压掉。作者选用同一家族的三个官方 checkpoint：Qwen3-8B、14B、32B；每个模型在三种权重精度下服务：W4A16 AWQ、W8A16 FP8-Marlin、bf16。激活精度固定为 bf16，硬件、vLLM 版本、flags、sampling 参数、seed 集合都保持一致。这样形成一个近似单调的 weight-precision ladder，尽管不同 rung 同时也包含不同量化方法。

数据方面，作者没有用现成 benchmark，而是构造了两套 leak-checked prompt battery。第一套 cultural battery 有 218 个 country-eliciting prompts，覆盖 11 个 domain，外加 80 个 style-control prompts；每个 prompt 带有 construction-time 的 country_pull 标签，区分 none、weak、strong，且 43 个 strong pull 中有 30 个指向 Japan。第二套 recommendation battery 有 96 个 brand-blind 购车场景，覆盖 8 个 buyer domain，也带 brand_pull 标签。所有 prompt 都经过 generator lane、adversarial verifier lane 和程序化 leakage 检查，确保 prompt 文本不直接包含国家、城市、国籍、品牌或车型名。

分析上，作者把 prompt 作为统计单元，而不是 completion 作为独立样本。每个 prompt、每个精度采样 20 次，并在不同精度间复用同一组 seeds，尽量消除 RNG 差异。主要统计检验是 prompt-level 的 sign-flip permutation test，配合 prompt-cluster bootstrap 区间，并做 Holm 校正。指标设计也比较讲究：除了常规 lexical/style 指标，还专门测 within-prompt concentration，比如 first-mentioned entity 的 collision probability、bf16 top-5 entities 上的质量集中度、stereotype-set share，以及 semantic entropy 与 token entropy 的分离。这里的关键创新不是新模型，而是把“量化是否改变输出分布”这个问题操作化成一组可审计、可复现的分布级指标。

和常见量化论文相比，这篇文章刻意不把重点放在 accuracy drop，而是研究 valid-answer manifold 是否被压缩。这个视角更接近真实部署中的推荐、建议、草拟、默认选项生成。19:T8c6,实验规模不算大，但设计很干净。总共收集了约 7.1 万条 completion，按 prompt 和 seed 配对比较，整体计算成本约 80 美元。几个结果最值得记。

1. 8B 上的 int4 明显降低多样性。作者报告，在 recommendation 和 cultural 两套 battery 上，W4A16 相比 bf16 会提高同一 prompt 下两次采样命中同一首个实体的概率，也会把概率质量更多压到少数高频实体上。论文摘要已点出这一点：int4 在 8B 上减少 recommendation diversity 和 lexical diversity。也就是说，模型不是更“偏见”，而是更容易反复给出同一类默认答案。

2. 这种内容层面的集中效应到 14B 基本消失，32B 也未再出现同等强度的语义收缩。更大的模型主要表现为 stylistic drift，而不是 recommendation/country choice 的明显收缩。这是全文最重要的经验结论：量化行为效应强烈依赖规模。

3. 没有观察到 stereotype amplification。作者专门做了 stereotype direction 检验，结果显示量化没有把输出更系统地推向预设刻板集合。换言之，量化放大的不是“偏向某个敏感类别”的方向性偏差，而是“在有效答案空间里更集中地重复少数选项”的确定化倾向。

4. token entropy 上升，但 semantic entropy 下降。这个结果很有意思，也最容易被误读。若只看 token 分布，量化后表面上似乎更随机；但从实体选择、语义替代空间来看，模型实际上更集中。作者据此认为，量化带来的不是简单的 distribution sharpening，而更像是“语义备选减少，表面措辞变化增加”。这解释了为什么传统 token-level 指标可能漏掉部署行为变化。

5. 研究流程采用 declare-then-run。wave 1 在生成前预注册，wave 2 和 3 虽然是在看到 14B 结果后补充，但发生在 8B 和 32B 生成前，仓库历史可审计。对于这种容易被探索性分析污染的话题，这个设计提高了结果可信度。

论文给出的摘要没有列出所有具体效应值，但从全文叙述看，显著性主要集中在 8B 的 W4A16 vs bf16 对比；W8A16 更接近 bf16，14B/32B 的内容指标差异大多不再稳定显著。1a:T728,The experimental design is intentionally controlled. The authors use three official checkpoints from the same family—Qwen3-8B, 14B, and 32B—and serve each at three weight precisions: W4A16 AWQ, W8A16 FP8-Marlin, and bf16. Activations remain in bf16 throughout. Hardware, vLLM version, engine flags, and sampling settings are held fixed within each model, and the same seed set is reused across precision tiers. This creates a near-monotone precision ladder while minimizing provider and runtime confounds.

Instead of relying on existing benchmarks, the paper builds two custom prompt batteries. The cultural battery contains 218 country-eliciting prompts across 11 domains plus 80 style-control prompts, each annotated at construction time with a country-pull label (none, weak, strong). The recommendation battery contains 96 brand-blind car-buying scenarios across eight buyer domains, with analogous brand-pull labels. The prompts are generated, adversarially reviewed, and programmatically checked for leakage so that no country, city, nationality, brand, or model name appears in the prompt text.

The unit of analysis is the prompt, not the completion. For each prompt and precision tier, the model generates 20 samples with matched seeds across tiers. Primary inference uses prompt-level sign-flip permutation tests with cluster bootstrap confidence intervals and Holm correction. The metric suite is the real contribution here: beyond lexical and style measures, the authors quantify within-prompt concentration via first-entity collision probability, mass on the top-five bf16 entities, stereotype-set share, and a deliberate separation between token entropy and semantic entropy. The paper is less about proposing a new quantizer and more about operationalizing distributional behavior under serving-time compression.1b:T82e,The study collects about 71,000 paired completions at a total compute cost of roughly $80. The first component is Head-Local. Full-Head Mapping regresses each target KV head on the concatenation of all source KV heads from selected source layers. CacheBridge argues that this assumes an overly dense correspondence between models. Instead, each target head is restricted to a single architecture-indexed source-head block, while still allowing cross-layer aggregation. This reduces fan-in dramatically and cuts the coefficient count by the number of source heads, 8× in the reported setup. More importantly, it biases the mapping toward a subspace that better matches architectural locality, reducing harmful cross-head coupling when the source and target architectures differ.

The second component is Attn-Repair. The paper points out that held-out R² only measures coordinate-wise cache reconstruction, while continuation quality depends on how those errors propagate through the target model’s queries and attention computation. Two mappings with similar cache fit can therefore produce very different continuation drift. Attn-Repair reweights residuals according to their first-order effect on the receiver’s attention output. In other words, it emphasizes errors that actually matter for downstream attention behavior rather than treating all cache coordinates equally. An effective-sample-size floor prevents the weighting from collapsing onto a tiny subset of examples, while preserving the same online affine form.

The third component is Fused-Fit. Because different target layers may choose different source-layer supports, top-k support selection creates fragmented gather patterns. A generic fitter repeatedly materializes scattered tensors, centers them, and applies weights, so memory traffic becomes a major cost. Fused-Fit introduces a fused GPU kernel that constructs the weighted sufficient statistics directly in bounded panels for head-batched matrix multiplication. It does not change the ridge objective, the solver, or the deployed mapper artifact; it simply makes offline construction structure-aware and much more efficient.
