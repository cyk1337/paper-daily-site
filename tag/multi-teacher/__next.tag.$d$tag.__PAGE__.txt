5:T4c9,MOPD (Multi-Teacher On-Policy Distillation) is a 3-stage pipeline:
1) General SFT to obtain a shared initialization.
2) Domain-specialized RL in parallel, producing a set of frozen domain teachers (math via verifiable RL, SWE via executable sandbox agent RL, etc.).
3) On-policy distillation fusion: initialize the student from the SFT checkpoint; for each batch of prompts, the student generates its own trajectories (on-policy rollouts). Each trajectory is routed to the corresponding domain teacher, which runs a prefill on that exact trajectory to produce per-token distributions. The student is updated by minimizing per-token reverse KL (student || teacher) along the trajectory.
Key properties:
- On-policy training eliminates exposure bias by matching train-time and inference-time state distributions.
- Token-level distribution matching provides a dense, low-variance learning signal compared to trajectory-level rewards.
- Integration happens in policy space via prompt-to-teacher routing, avoiding weight-space arithmetic/averaging instabilities.
The paper also highlights practical knobs (top-k distillation, same-origin teachers for stability, multi-round refinement), which are worth checking in the ablations.6:T411,CoRD, or Collaborative Reasoning Decoding, treats each reasoning step as a high-level decoding unit. At each step, multiple teacher LRMs propose candidate next steps conditioned on the same current prefix. The system scores the resulting partial trajectories and extends promising ones. The method has three central components. First, prompt-guided step segmentation makes reasoning steps more consistent across teachers. Second, predictive perplexity scores a partial reasoning prefix by measuring how well the ground-truth answer is predicted given that prefix; this provides an early signal without waiting for a complete trace. Third, beam search maintains multiple candidate trajectories, which helps preserve paths that initially look weaker but later lead to useful self-correction or strategic shifts. Compared with S1- or LIMO-style curation, CoRD collaborates during generation rather than selecting after generation.
