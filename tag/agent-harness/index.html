MILO 要解决的是自动化发现 agent harness 的问题：在固定底座模型的前提下，搜索 prompt、工具、上下文管理、记忆、子代理、验证器、停止条件等控制流设计，使长程任务表现更好，同时控制 token 和延迟成本。
