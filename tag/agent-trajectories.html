ACC: Compiling Agent Trajectories for Long-Context Training

这篇工作处理的是一个很具体、但在 agent 训练里长期被忽略的问题：多轮 agent 轨迹里真正支撑最终答案的证据，大量存在于被 mask 掉的工具返回和环境观察中。标准 agent SFT 主要监督每一步的局部推理与工具选择，梯度大多停留在“下一步该调什么工具”这一层，难以把最终答案的监督有效传回到早期 observation 上。结果是，模型学会了局部决策，却没有真正学会把跨很多轮、分散在长上下文中的证据整合起来。ACC 要解决的就是这个 supervision blind spot：不增加人工标注，直接把 agent 轨迹编译成长上下文问答样本，让最终答案对中间 observation 形成直接监督。

评数据构造思路值得复现一版；重点看泄漏控制和轨迹过滤，别只看 long-context 分数涨幅。
