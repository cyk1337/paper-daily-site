Beyond Repeated Sampling: Learning Search Policies for LLM Reasoning

论文解决的是推理模型在训练和推理阶段共同面对的探索瓶颈：重复采样主要依赖 token 级随机性，容易产生相近解法，难以覆盖真正不同的解题思路。这个问题会直接限制 test-time scaling，也会限制 RL 训练，因为没有采到正确轨迹时，verifier 或 reward 也无法提供正信号。作者进一步指出，已有 concept-guided sampling 的收益很大程度来自较弱的重复采样基线，而不是稳定的语义级探索能力。

评Meta FAIR 对 Test-Time Scaling 的重要探索，用 RL 训练一个小模型来指导大模型的语义级搜索，改变了单纯依赖 temperature 采样的 prior，值得立刻跟进复现。
Ismail Labiad,Matthieu Kowalski,Marc Schoenauer,Rémi Munos,Julia Kempe
