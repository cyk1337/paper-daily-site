From Refuse to Richness: Rubric Rewards for Long-Form Hallucination Reinforcement Learning

SD-GRPO: Verifiable Segment Decomposition for Long-Form Vision-Language Generation

GRPO（Group Relative Policy Optimization）在多模态 LLM 上的粗粒度整体信用分配不适合长程视觉语言生成任务。GRPO 对每个完整输出只分配一个 scalar reward，并对所有 token 共享同一个 group-normalized advantage。这在数学题等整体可验证任务上有效，但在密集图像描述、科学图表说明、医学报告生成等长程 VL 任务中，单个 advantage 无法区分错误 token 和正确描述的 token，导致所有 token 无论实际贡献如何都获得相同的信用信号。

评只看方法和 ablation 即可；片段级 advantage 是干净改动，值得拿去想文本长 CoT 的 reward 分解。
Hyunwoong Kim,Seongeun Lee,Hannah Yun,Junhyun Park,Jonggwon Park

Think Through Uncertainty: Improving Long-Form Generation Factuality via Reasoning Calibration

评只看 claim 粒度校准的训练配方：把“事实优化”和“置信度校准”拆开能抑制 RL 过度自信，适合做 RAG/工具验证前的可拒答接口。
