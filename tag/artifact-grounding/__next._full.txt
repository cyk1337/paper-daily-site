18:T53d,The central idea is artifact-grounded agentic reinforcement learning. The authors build Webdev-World, an executable environment that exposes code editing, application execution, browser inspection, and on-demand skills through a shared interface while preserving project state across interactions. Rewards are defined through a weighted checklist derived from task requirements. An independent verifier builds, runs, and inspects the final application. Deterministic checks and visual assessments are aggregated into a terminal reward, gated by successful execution and rendering. To avoid relying only on sparse terminal rewards, the method also estimates intermediate requirement satisfaction from project and execution evidence, and uses changes in these estimates as progress and regression signals for stage-level credit assignment. A second important component is training across context windows. The system combines context compaction with message-tree sample construction: when the interaction history grows too long, the textual context is rewritten compactly while the true project state remains in the environment. The message tree preserves dependencies across rewrites so that different stages of the same long trajectory can still be used for training without repeatedly charging the policy loss for the same generated history.19:T47a,The main evaluations are on Webdev-Bench and Vision2Web. Webdev-Bench is introduced to test capability composition within a single project, including requested changes and preservation of specified existing behavior. On this benchmark, WebCoder-27B reaches a requirement satisfaction score of 72.8, compared with 64.8 for its Qwen3.8-27B base model and 65.1 for Claude-Opus-4.8. It also delivers a running application on all 40 tasks. On Vision2Web, WebCoder-27B achieves an average visual and functional score of 62.4 versus 41.1 for the base model, and is essentially on par with Claude-Opus-4.8 at 62.5. The more interesting takeaway is methodological: the paper argues that a single artifact-grounded reward can supervise heterogeneous frontend activities, that intermediate progress signals improve long-horizon credit assignment, and that context compaction plus message-tree training makes it possible to continue learning when trajectories exceed the model’s context window.
