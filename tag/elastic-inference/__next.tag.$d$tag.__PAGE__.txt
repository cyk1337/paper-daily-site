9:T733,The method has three main components. First, elastic expert dimensions. Each MoE expert is turned into a Matryoshka-style nested FFN: instead of training multiple independent experts at different widths, the same parameter tensors support several inner dimensions. During training, a target width D_k is sampled, and only the first D_k hidden channels are used in the expert’s SwiGLU computation. At inference, this allows deterministic slicing of the same checkpoint into smaller expert variants, reducing both parameter residency and activation cost. The paper also notes an important stability issue: shrinking the inner dimension changes the scale of the down-projected activations, which can disturb residual addition and RMSNorm statistics, so a compensation or rescaling mechanism is introduced. Second, adaptive sigmoid routing. Rather than top-k softmax routing, the router produces independent sigmoid gates for experts and compares them against a learned, task-conditioned threshold. This lets each token activate a variable number of experts. Harder tokens can use more experts, easier tokens fewer. Compared with top-k, this relaxes fixed-FLOP control but enables finer-grained compute allocation. Third, a dual-consistency objective. Because training sees multiple capacity views—different widths and different routing patterns—the model is regularized with an in-place self-distillation loss that aligns predictive distributions across these nested structures. The key point is that no external teacher and no post-training adaptation are required; the consistency signal is built into the original training run. In addition, the architecture includes a Direction-Aware Shared Expert computed in parallel, intended to capture translation-direction-specific shared patterns and reduce over-reliance on sparse experts alone.a:T54a,The experiments cover PhoMT for English–Vietnamese, WMT14 for English–German, multilingual OPUS-16, and a multi-domain German–English benchmark. This gives the method a reasonable spread across bilingual, multilingual, and multi-domain heterogeneity. At a high level, the full-capacity EDWARD-NMT improves over Transformer Big and is competitive with recent lightweight MoE baselines. The more interesting result is on extracted subnetworks: the smallest variant, EDWARD-NMT-S, is not separately trained but sliced from the same checkpoint, yet still outperforms a dense Transformer Base. That is the main empirical support for the “train once, deploy anywhere” claim.
