b:T510,The paper frames sensitivity as a forward-only “single-layer quantize and measure output shift” procedure:
- For each layer/module i, create a perturbed model where only i is quantized (weights/activations depending on the setting) while the rest remains high precision.
- Run forward passes on a representative calibration set and compare the resulting logits/probability distributions to the original teacher model.
- Use distributional divergence—emphasizing KL(student→teacher), with discussion of directionality—to score sensitivity. The key claim is that KL is more tightly connected to perplexity because perplexity is cross-entropy on the predictive distribution, whereas SQNR is an energy-based numeric distortion that can miss probability-mass reshaping after softmax.
- Evaluate metric quality via rank correlation (Kendall’s τ) between metric-induced layer rankings and true perplexity-degradation rankings.
- Allocate higher bit-width to the top-k most sensitive layers and lower bit-width elsewhere, yielding a post-training mixed-precision quantization pipeline without gradients.
The novelty is less about a new quantizer and more about a LM-objective-aligned, forward-only sensitivity “lens” that works for hybrid SSM–Transformer models where SQNR breaks
