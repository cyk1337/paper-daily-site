Does Multi-Agent Collaboration Pay When Agents Serve Users? Testing Agent Scaling in Dual-Control Settings

这篇论文要检验一个近来很流行、也很容易被误用的经验规律：多智能体协作是否只在单智能体能力较弱时才有收益，而当单智能体已经较强时反而会拖后腿。已有结论主要来自 autonomous benchmark，也就是 agent 独立完成任务、没有真实用户持续参与的环境。作者关心的是，这个规律一旦放到更接近部署现实的 dual-control setting 里是否还成立：用户会逐轮提供信息、改变目标、触碰策略边界，甚至自己也能操作环境。在这种场景下，MAS 的额外协调成本、对话接口约束和用户模拟器偏差都可能改变结论。论文的核心问题因此不是“MAS 好不好”，而是“从无用户环境中得到的 agent scaling 经验，能否迁移到有用户参与的服务场景”。

评只看实验设计和 token ledger；结论受 planner 未见 tool schema 影响，但能校准 multi-agent 是否真省 compute。
Ethan Yang,Xiangcheng Shi
