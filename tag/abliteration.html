Abliteration Is Not a Scalpel: Off-Target Effects of Refusal Removal on Decision Disposition Across Model Families

这篇工作检验一个被默认接受的前提：abliteration 只是去掉 refusal，不会改动别的行为倾向。作者关心的不是安全对齐本身，而是更细的“decision disposition”——在没有任何拒答触发的任务里，模型的风险偏好、乐观程度、措辞密度、置信表达会不会被这种权重手术顺带改掉。这个问题抓得很准，因为很多开源“uncensored”模型就是这样做出来的，但社区通常只看 jailbreak 成功率和少量能力 benchmark，很少测远离 refusal 场景的行为漂移。

评实验控制极干净，明确证明权重编辑的脱靶普遍性，做对齐/安全/模型编辑的看§3结果部分即可。
Aleksander Fafuła

Willing but Unable: Separating Refusal from Capability in Code LLMs via Abliteration

这篇论文研究的核心不是漏洞检测本身，而是一个更一般的模型行为分解问题：当安全对齐过的 code LLM 拒绝执行“注入某类漏洞”的指令时，拒绝到底是因为模型不会做，还是因为模型会做但被 refusal policy 截断了。作者用 abliteration 这个低秩权重编辑方法，尝试把 residual stream 中的 refusal direction 投影掉，从而把“愿不愿意做”和“有没有能力做”拆开测量。任务上选的是 Python 代码中的 CWE-89 SQL injection 注入，目的是验证：去掉拒绝后，模型是否真的能按规范把安全代码改成带指定漏洞的代码。

评abliteration在代码模型上解耦拒绝与生成能力的实证，可作为内部对齐方向ablation的参考，仅看实验结果部分即可。
Cristina Carleo,Pietro Liguori,Naghmeh Ivaki,Domenico Cotroneo

Open-Weight LLM Fine-Tuning Defenses are Susceptible to Simple Attacks

这篇论文问的是：面向 open-weight LLM 的“抗微调”安全防御，是否真的覆盖了主要威胁。作者指出，许多防御默认有害能力来自攻击者后续微调，但预训练模型里已经保留了大量有害知识；攻击者可能不需要训练，只要绕过拒答机制就能取出这些知识。

评应看威胁模型和 ASR 表；它提醒 open-weight safety 不能只防微调，预训练记忆本身就是攻击面。
Kevin Kuo,Chhavi Yadav,Virginia Smith
