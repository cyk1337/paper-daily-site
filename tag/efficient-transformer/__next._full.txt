18:Tac2,LoGo 的核心设计是每层同时有 local 和 global 两个分支，但两者不是两套完全独立的大模块。所有 token 都先走 local attention，只看一个受限窗口；global 分支只对被选中的 query 激活，被选中的 token 再把 local/global 输出做融合，未选中的 token 直接绕过 global 分支。这样做的关键点有四个。

第一，动态分配单位是 token，而不是层或头。论文把 attention span 当作 attention budget 的代理变量：一个 token 是否需要全局上下文，可以由当前隐藏状态预测。具体做法是用一个轻量 gate 为每个 token 产生标量偏好分数，表示它对 global span 的需求。

第二，路由不是固定阈值，而是自适应阈值控制全局激活比例。作者设定 target global ratio，在每个 batch 或序列内根据 gate 分数确定阈值，把 top-ratio 的 token 送入 global 分支。这样可以把计算预算直接绑定到“有多少 token 走全局”，而不是让 gate 自由漂移导致预算失控。相比用连续权重软混合，这种二值路由更容易把理论 FLOPs 节省转成真实 kernel 加速。

第三，训练时用了 progressive mask，也就是文中说的 P-mask。问题在于如果一开始就做硬路由，gate 还没学到有意义的偏好，容易让训练不稳定，或者过早把重要 token 切掉。LoGo 在训练早期延迟引入稀疏路由，先让 local/global 结构和 gate 有一个较平滑的学习阶段，再逐步过渡到目标稀疏度。这一点很像 conditional computation 里常见的 warmup/annealing 思路，但这里作用在 attention routing 上。

第四，只稀疏 global queries，不稀疏 KV。也就是说，所有 token 的 key/value 仍然保留在全局可见集合里，只是并非每个 query 都去访问它们。这样被选中的 token 仍然拥有精确的 full-context attention，而不是近似检索或压缩记忆；代价则主要按被选中 query 数量下降。这个设计比同时稀疏 query 和 KV 更稳，因为不会破坏信息可达性，也避免了额外的 memory selection 误差。

从与现有方法的区别看，静态 inter-layer hybrid 是某些层全局、某些层局部；intra-layer hybrid 是某些头全局、某些头局部；它们都把预算结构写死了。LoGo 则让同一层内不同 token 走不同 span。与 CoLT5、SMA 这类动态模块激活方法相比，LoGo 直接把“是否需要长程上下文”作为路由目标，而不是切换不同 attention 模块或受限 span 模块。工程上，作者还实现了 query-sparse Triton kernel，把只对部分 query 做 global attention 的结构真正映射到运行时加速，而不是停留在 FLOPs 账面节省。19:Ta3b,LoGo builds each attention layer from coupled local and global branches. Every token always receives local attention over a restricted window. A lightweight gate predicts, for each token, whether global span is worth paying for. Selected tokens additionally go through the global branch and fuse local/global outputs; unselected tokens bypass the global branch entirely.

There are four important design choices.

First, the routing unit is the token. The paper explicitly uses attention span as a proxy for attention budget: if a token likely depends on long-range retrieval, it should be allowed to access the full sequence; if it is locally predictable, local context is enough. This differs from static layer-wise or head-wise span assignment.

Second, routing is controlled by an adaptive threshold tied to a target global ratio. Instead of using a fixed threshold or unconstrained soft gating, LoGo selects roughly the top fraction of tokens for global attention. This keeps compute predictable and directly links routing decisions to budget. It also makes it easier to convert FLOP savings into real speedups, because the global branch becomes query-sparse in a hard, structured way.

Third, training uses progressive masking (P-mask). Hard sparse routing from the start would make optimization brittle because the gate is initially untrained and may suppress important tokens too early. LoGo therefore delays the full sparse regime and gradually introduces routing sparsity after the gate has learned more meaningful preferences. This is a training-stability device, and it is one of the more important parts of the method.

Fourth, LoGo sparsifies only global queries, not keys or values. All KV states remain globally available, so any selected token still performs exact full-context attention rather than an approximation over compressed memory. This is a conservative but sensible design: it reduces compute without damaging information accessibility.

Relative to prior work, static inter-layer hybrids assign some layers to global attention and others to local attention; intra-layer hybrids assign some heads to global and others to local. Both impose a fixed per-token budget. LoGo instead lets different tokens in the same layer take different span routes. Compared with dynamic module activation methods such as CoLT5 or SMA, LoGo directly routes based on span demand rather than swapping among attention modules with the same restricted context. First, scaling behavior. The authors train models from 200M up to 3.3B parameters and report that LoGo consistently matches or slightly improves over a standard Transformer on language modeling. This matters because many dynamic-routing ideas look promising only at small scale; once moved into real pretraining regimes, instability or routing overhead often erases the benefit. Here the evidence suggests token-level span allocation does not break backbone scalability.

Second, matched-budget comparisons at around 1.5B scale. Under matched parameter count and attention FLOPs, LoGo is compared against a standard Transformer and static inter-layer and intra-layer local-global hybrids. The main result is a better performance-compute trade-off: strongest language-modeling results among the compared variants, competitive short-context recall, and clearer gains on long-range retrieval after context extension. The emphasis is not just raw quality, but quality at the same budget.

Third, implementation and ablations. Kernel benchmarks show that the query-sparse Triton implementation delivers practical speedups that are close to the theoretical FLOP reduction at long sequence lengths. Ablations cover progressive masking, adaptive thresholding, the target global ratio, and compatibility with static hybrids. Two takeaways stand out: performance is reasonably robust across global ratios, and LoGo can be combined with static hybrids to reduce both memory and compute. In a single training step, a teacher path runs the maximum number of loops to produce a high-fidelity target, while a student path corresponds to a strict subset of the teacher’s forward trajectory (fewer loops / earlier exit). The student is distilled to match the teacher’s outputs/predictions at corresponding points, forcing the shared parameters to compress later-loop improvements into earlier loops. Because the student is a subset of the teacher computation and shares parameters, ILSD is designed to avoid extra parameter overhead and minimize additional training cost.
