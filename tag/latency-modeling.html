Beyond Accuracy and Cost: Latency-Aware LLM Query Routing for Dynamic Workloads

这篇工作处理的是一个很实际但常被拆开看的问题：在多模型、多实例的 LLM 服务池里，查询路由不能只看质量和价格，还要显式考虑请求到达时各实例的实时负载，以及连续批处理下 prefill/decode 混合工作负载带来的时延变化。现有 query router 大多把 latency 当成系统层的事，先选模型，再让 serving 框架做负载均衡；而系统层方法又默认模型选择已固定，不关心准确率和成本。论文要解决的，就是把 accuracy、cost、latency 三者放进同一个路由决策里，而且 latency 不是静态表格值，而是依赖当前队列状态、输出长度、batching/scheduling 策略和实例异构性的动态量。

评只看 latency estimator 和 routing objective；它提醒模型路由实验若不模拟 decode 队列，结论会偏乐观。
Shivam Patel,Akaash R. Parthasarathy,Ankur Mallick,Gauri Joshi
