Auditing Conformal Prediction for Language Models Under Inference-Time Model Shift

这篇工作讨论的不是如何改进 conformal prediction 本身，而是指出现有 LLM 不确定性评测里一个被忽略的失效源：校准时和部署时如果用了不同的推理配置，哪怕模型参数和任务分布都完全不变，split conformal 依赖的 exchangeability 也会被破坏，覆盖率保证不再可迁移。作者把这种现象定义为 inference-time model shift，强调它不同于传统 covariate shift 或 label shift，因为变化发生在“输入到预测分布”的生成机制上，例如量化方式、温度、数值精度，而不是数据分布本身。

Reasoning Models Can Control Their Chains of Thought When They Tell Themselves To

这篇工作研究的是 reasoning model 的 CoT controllability 到底有多强，以及现有评测是否低估了它。已有做法把“不要用某个词”“按某种格式思考”这类约束直接写在用户提示里，再看模型的思维链是否遵守。作者指出，这种 User-Instructed CoT 评测把“对最终回答的指令遵循”和“对思维链本身的控制”混在了一起：RLVR 和常见指令训练主要奖励最终答案，不会专门奖励模型去遵守关于 CoT 的用户约束，所以低分未必表示模型不会控制 CoT，更可能是模型在推理时把这类约束放在了较低优先级。论文要回答的核心问题不是‘模型能否控制 CoT’，而是‘当约束被放到 CoT 内部、成为模型自己的局部推理目标时，它是否其实能显著更好地控制 CoT’。

评这篇在修正“CoT 不可控”的测量口径：把约束放进 CoT 后可控性大幅上升；建议只读设定与失败案例，顺手复现自家模型。

Beyond Downstream QA: Rethinking How We Evaluate Agent Memory

这篇论文要解决的不是“如何做更好的 agent memory”，而是“如何判断 memory 到底好不好”。作者指出，现有 memory benchmark 几乎都用下游问答准确率来做代理指标，也就是看 agent 最后答得对不对。但这种外在评测把三个环节混在了一起：memory 是否正确写入和更新、retrieval 是否把对的内容取出来、generation 是否把取回的信息组织成正确回答。结果会出现两类系统性误判：一类是假阳性，memory 实际上已经错了，但强模型靠局部线索和推理把答案补对；另一类是假阴性，memory 其实是对的，只是 retrieval 没取到，最后却把责任算在 memory 头上。论文的核心问题，就是为 agent memory 建立一种 intrinsic evaluation：直接检查 memory store 内部状态与已知真值是否一致，从而把 memory 本身和 retrieval/generation 解耦。

评如果你在看 memory/RAG 论文，这篇能帮你避开“QA 提升=记忆更好”的错觉；否则读 abstract 和 benchmark 设定就够了。

CentaurBench: Benchmarking LLM Capabilities on Augmenting vs. Automating Real-World Work Tasks

这篇论文要解决的问题不是提升模型能力，而是重新定义一类更贴近真实使用方式的评测：很多工作场景里，模型并不是直接完成任务，而是给人类或较弱模型提供帮助。现有 benchmark 大多只测 automation，也就是模型独立产出最终结果的能力，却很少测 augmentation，也就是模型能否让另一个执行者做得更好。论文提出 CentaurBench，用统一框架在同一组真实工作任务上同时评估这两种能力，并检验二者是否一致。

评这篇不改 pretrain recipe，但会改你看 agent/eval 的口径：只看 automation 排名已经不够，读实验设计和相关性结果就够了。
Pattaraphon Kenny Wongchamcharoen,Kris Gulati,Min Min Fong,Abhishek Nagaraj
