Unlike AR models, the backbone uses bidirectional attention, so one forward pass already yields a full-context representation.

DLLM-JEPA constructs two views from the same input by sampling two noise levels tL < tH:
- a context view x_{tL}, lightly masked and information-rich;
- a target view x_{tH}, heavily masked and more abstract.

A gradient-carrying forward pass is run on the context view. From that pass, the model produces:
1. diffusion logits for the standard denoising loss;
2. a pooled embedding z_{tL}, used as the JEPA prediction-side representation.

The target view is processed in a second forward pass without gradient, producing z_{tH}. A JEPA loss then trains the context-side representation to predict the target-side representation. Because the target branch is stop-gradient, only one branch backpropagates each step. That is the source of the reported 33% FLOP reduction relative to LLM-JEPA.

Using different mask rates as the two views is more principled than ad hoc text augmentation because the diffusion schedule already defines a family of semantically aligned but information-varying views. The paper first defines a broad class of worlds: independent latent coordinates, positive pairs drawn from a stationary process, and additive-noise transitions. The forward theorem then specializes to z~N(0,I). Under stationarity, the only additive-noise transition that preserves the Gaussian marginal is the Ornstein-Uhlenbeck form z'=rho z + sqrt(1-rho^2) epsilon. The key proof idea is a spectral decomposition of the composed map h=f∘g under Gaussian measure. Intuitively, if h contains nonlinear components beyond degree one, those components are penalized by the alignment objective, while the Gaussian regularizer constrains the output distribution to remain standard normal. The optimum therefore retains only the linear component, yielding h(z)=Qz. The mechanism relies on the fact that different polynomial degrees decay differently under correlated Gaussian pairs, so alignment suppresses higher-order terms. The converse theorem is the more distinctive part: for the same class of stationary additive-noise worlds, if the latent distribution is non-Gaussian, one cannot guarantee linear identifiability for all such worlds. Gaussianity is therefore not just a convenient assumption for the proof; it is the unique distribution that supports this universal guarantee.
