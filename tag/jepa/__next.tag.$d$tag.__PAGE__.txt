Starting from a clean sequence x0, the forward process replaces each token with [MASK] independently with probability t, and the model learns to reconstruct the original tokens from the masked sequence xt. Unlike AR models, the backbone uses bidirectional attention, so one forward pass already yields a full-context representation.

DLLM-JEPA constructs two views from the same input by sampling two noise levels tL < tH:
- a context view x_{tL}, lightly masked and information-rich;
- a target view x_{tH}, heavily masked and more abstract.

A gradient-carrying forward pass is run on the context view. From that pass, the model produces:
1. diffusion logits for the standard denoising loss;
2. a pooled embedding z_{tL}, used as the JEPA prediction-side representation.

The target view is processed in a second forward pass without gradient, producing z_{tH}. A JEPA loss then trains the context-side representation to predict the target-side representation. Because the target branch is stop-gradient, only one branch backpropagates each step. That is the source of the reported 33% FLOP reduction relative to LLM-JEPA.

Several design choices are worth noting. Using different mask rates as the two views is more principled than ad hoc text augmentation because the diffusion schedule already defines a family of semantically aligned but information-varying views. Keeping the target branch gradient-free follows the usual JEPA/bootstrap logic for stability and efficiency. The paper also avoids a direct head-to-head comparison with LLM-JEPA as if they were identical settings, since one lives on block-causal AR attention and the other on bidirectional masked diffusion; otherwise architecture effects and objective effects would be entangled.

DLLM-JEPA increases hidden-state drift from the pretrained model, especially in middle transformer layers, yet reduces functional forgetting measured on Wikitext. That suggests JEPA is not acting like a simple stay-close-to-initialization regularizer. Instead, it appears to redirect adaptation toward more useful internal structure, especially in the middle layers often associated with compositional processing.
