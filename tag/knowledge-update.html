Time-Incremental Continued Pretraining of LLMs: Knowledge Updates Without Catastrophic Forgetting

这篇论文研究一个很实际的 continued pretraining 问题：模型知识截止后，能否用后续 web crawl 做时间增量更新，在吸收新知识的同时不损害已有知识和通用能力。作者指出，很多 continual learning 设置假设数据流彼此不重叠，但真实 web-scale 更新并不是这样。Common Crawl 等管线天然存在跨时间快照的 URL 重叠，且开源模型通常没有完整预训练语料可查，因此只能用时间戳近似定义“新数据”。

评应读实验设置和负迁移分析；它改变 CPT 默认会遗忘的先验，值得内部复现一版。
Fırat Öncel,Salman Hussain Ali,Mirco Ravanelli,Cem Subakan,Çağatay Yıldız

Supersede: Diagnosing and Training the Memory-Update Gap in LLM Agents

LLM agent 在多轮、多会话交互中需要维护会变化的事实；这项工作聚焦一个更窄的问题：当旧事实被新事实取代后，agent 是否能在受限自维护 memory 中保留当前值、丢弃过期值。

评这不是 pretrain 论文，但它把“长上下文够强就能替代记忆系统”这个 prior 拆得很干净；读实验设定和误差分解即可，适合拿来约束 memory-augmented LM 的训练目标。
Vedant Patel
