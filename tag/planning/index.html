Binary Discrete Diffusion: Candidate-Set Diffusion for Logic and Planning Tasks

这篇工作解决的是离散 diffusion LM 的一个结构性缺口：现有 masked diffusion 和 uniform diffusion 的中间状态过于贫乏，一个位置要么是单个 token，要么被替换成 mask/随机 token，无法显式表示“当前还有若干候选都可能成立”的不确定性。这个问题在逻辑、规划、约束满足这类任务上尤其明显，因为求解过程往往不是单调确定的，而是先缩小候选集、再因全局约束回溯重开、最后收敛到唯一解。论文把 diffusion 的状态从单个离散 token 改成 candidate set，用二值 membership 向量表示每个位置当前允许哪些 token，从而让反向生成过程可以做两类操作：删去不合理候选，或重新打开先前排除的候选。作者关心的不是再做一套搜索器或 verifier，而是直接改变 corruption process 本身，观察中间表示的变化能否让模型学到更合适的迭代计算。

评值得看建模定义和任务设置；它提醒 diffusion LM 的 state space 设计可能比 denoiser 架构更关键。

MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks

这篇工作要解决的不是“手机 GUI 自动化”本身，而是如何评测一类更接近真实移动端助手的 central planner：它需要在有状态的手机环境里，把自然语言请求转成可执行的多步计划，并在结构化工具、记忆检索、复合技能、以及必要时的 GUI 子代理之间做正确编排。现有 benchmark 要么偏静态 function calling，只看 API 匹配，不看运行时反馈和状态变化；要么偏视觉 GUI 操作，把问题压成点击和截图理解，弱化了系统级工具调用、权限约束、异常恢复和长程任务分解。MobilePA-Bench 试图补上这块空白，评测对象是“移动端规划代理”的决策与编排能力，而不是单纯的界面操作能力。

DART-SD: Diamond-topology Aware Retrieval and Tuning for Self-Distillation of Multi-Turn Tool-Calling Agents

这篇工作处理的是多轮 tool-calling agent 蒸馏里的一个结构性问题：现有 SFT/BC 把教师轨迹当成单条线性序列去模仿，RL 又常把奖励粗糙地摊到整条轨迹上，但很多真实任务包含多个可交换顺序的子目标，正确解空间不是一条路径，而是大量在中间状态汇合、再分叉的“菱形”状态图。在线性监督下，学生模型只要走了与教师不同但同样有效的前缀，就会被当成错误覆盖；在 RL 下，失败轨迹中的有效中间步骤也容易被误罚。论文要解决的核心问题，就是如何在这种多解、可交换子目标的环境里，避免拓扑信息塌缩，保留有效前缀，只在真正偏离成功区域的位置做纠偏。

评读图建模和自蒸馏部分；它把 tool-use 监督从 token 轨迹改成状态拓扑，值得借到 RL 数据生成里。
