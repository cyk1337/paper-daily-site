Chronicle: A Multimodal Foundation Model for Joint Language and Time Series Understanding

这篇论文要回答的核心问题很直接：文本和时间序列能不能从随机初始化开始，在同一个 decoder-only backbone 里联合预训练，而不是先训一个文本 LLM 再把时间序列硬接进去。现有多模态 time-series 工作大多是 post hoc adaptation，时间序列只能去适应一个从未见过时序数据的语言表征空间。作者想验证两件事：第一，联合训练是否真的能学到兼顾两种模态的共享表示，而不发生明显的负迁移；第二，这种联合训练出来的小模型，和各自领域内的强单模态 foundation model 相比，到底有没有竞争力。

评值得看训练配比和 alignment stage；“大部分单模态 batch 也能学出跨模态能力”若成立，会影响统一预训练的数据混合设计。
Paul Quinlan,Jeremy Levasseur,Qingguo Li,Xiaodan Zhu

Unified Pix Token And Word Token Generative Language Model

这篇工作想解决的是：现有多模态 LLM 依赖 CLIP/SigLIP 一类视觉编码器，把整张图先压成少量视觉特征，再交给语言模型，这种做法在细粒度视觉细节上容易丢信息，尤其是小字、数字、局部精确颜色与位置关系。作者试图绕开“先做视觉表征压缩”这一步，直接把图像像素离散成 token，并与文本 token 放进同一个生成式语言模型里统一建模，让模型像预测词一样预测像素。

评尝试抛弃 ViT encoder，直接把 pixel token 和 word token 放在一起做 AR 预训练，虽然实验规模很小，但这种 native multimodal 的极致扁平化思路值得扫一眼其 attention 近似设计。
Haun Leung,ZiNan Wang

Context Unrolling in Omni Models

这篇工作要解决的不是单一模态能力不够，而是统一多模态模型在推理时如何把不同模态当作中间工作空间来逐步展开。作者把这个现象称为 Context Unrolling：模型面对一个任务时，不直接从输入到答案，而是先生成或调用若干中间模态表示，例如文本推理、视觉 token、深度、相机位姿、视角变换结果，再把这些结果写回上下文，继续约束后续预测。核心问题因此变成：怎样通过原生统一预训练，让模型学会把图像、视频、3D 几何、隐藏视觉表征和文本当作可组合的推理原语，而不是彼此隔离的任务头。

评如果正文把 hidden representations 作为训练模态这件事讲清楚，这篇会直接影响统一多模态 pretrain 的配方；先看方法图和 ablation，别先信“会显式推理”的叙事。
