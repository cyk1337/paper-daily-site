18:T883,方法核心是 Binary Discrete Diffusion。每个位置的状态不再是词表中的一个 token，而是一个长度为 V 的二值向量，表示该 token 是否仍在候选集合中。干净样本对应 singleton set。论文给出两种连续时间 CTMC corruption：
1) binary symmetric diffusion：每个 membership bit 都可以从 0 变 1，也可以从 1 变 0。这样候选既能被删掉，也能被重新加入，适合需要回溯修正的任务。
2) binary absorbing diffusion：corruption 只增加候选，不删除候选；对应的 reverse 过程就是不断剪枝，直到每个位置只剩一个 token。

看起来状态空间是 2^V，但关键观察是每一步只需要考虑单 bit 翻转，所以每个状态只有 O(V) 个邻居。作者进一步推导出：只要模型输出常规的 V-way clean-token 预测，就能在 O(V) 时间内计算所有相邻 reverse rates，不需要枚举子集。训练仍沿用连续时间离散 diffusion 的 ELBO / path-space KL 框架，用 clean-conditioned reverse rates 作为监督目标。也就是说，模型并不需要额外的 candidate 标签、规则系统或 symbolic search，候选集动态是从最终解分布中隐式学出来的。

采样部分也不是简单照搬已有 discrete diffusion。因为状态变成候选集，作者设计了 candidate-aware sampling：包括基于 shared clean-token proposal 的精确 ancestral updates、适配 candidate-set 状态的 re-corrupt sampling，以及结合 Ψ-sampling 和 confidence-guided remasking 的 revision 规则。这里的关键不是只决定“哪些位置重采样”，还要决定“这些位置重新开放哪些候选”。这比传统 remasking 多了一层控制自由度。

和已有方法的区别可以概括为三点：
- 相比 masked diffusion：不是把不确定性压缩成一个 mask，而是显式保留多个假设；
- 相比 uniform diffusion：不是随机替换成另一个单 token，而是允许集合态，避免把多解不确定性硬编码成单点噪声；
- 相比 absorbing-style candidate pruning：symmetric 版本允许恢复候选，因此更接近真实的迭代推理，而不是单调收缩。19:T7bf,The method is Binary Discrete Diffusion. Instead of representing each position as one token from a vocabulary of size V, the state is a binary membership vector in {0,1}^V indicating which tokens are currently active candidates. A clean token is a singleton set.

The paper defines two continuous-time Markov corruption processes:
1) Binary symmetric diffusion: each membership bit can flip on or off. This allows candidate removal and later restoration.
2) Binary absorbing diffusion: corruption only adds candidates. The reverse process then progressively prunes the set toward a singleton.

Although the nominal state space is 2^V per position, each state has only V single-bit neighbors, which keeps local transitions tractable. A key derivation shows that all neighboring reverse rates can be computed in O(V) time from the model’s usual V-way clean-token prediction, without enumerating subsets. Training follows the continuous-time discrete diffusion ELBO / path-space KL framework, using clean-conditioned reverse rates as targets. Importantly, the model is trained only from clean solutions; it does not require candidate annotations, handcrafted deduction rules, or symbolic search.

The sampling side is also adapted to the new state space. The paper introduces candidate-aware sampling, including exact ancestral updates via a shared clean-token proposal, re-corrupt sampling adapted to candidate sets, and revision rules inspired by Psi-sampling and confidence-guided remasking. The extra degree of freedom is important: the sampler must decide not only which positions to revisit, but also which hypotheses to reopen.

Relative to prior kernels, the distinctions are clear:
- versus masked diffusion: uncertainty is not collapsed into a single mask token;
- versus uniform diffusion: uncertainty is not forced into one random token;
- versus absorbing-only pruning: the symmetric process supports non-monotonic revision, which is closer to actual iterative reasoning.1a:T668,The main evaluation uses three structured reasoning/planning tasks with exact solve-rate metrics: Sudoku-Extreme, Boxoban, and graph coloring. The comparisons are controlled for architecture, training budget, and sampler tuning, and evaluation uses direct single-attempt generation without verifier-guided reranking. That setup matters because it isolates the quality of the learned generative process itself.

The central empirical pattern is consistent: binary symmetric diffusion outperforms uniform diffusion, and both outperform masked diffusion and binary absorbing diffusion. The gap between binary symmetric and uniform grows in harder regimes, including low-clue Sudoku, longer-horizon Boxoban, and graph coloring beyond the training graph size. This directly supports the paper’s claim that candidate-set states are better suited to globally constrained iterative refinement.

The paper also includes text-side checks on Text8, TinyStories, and OpenWebText. Binary diffusion remains competitive with established kernels, suggesting that the richer state representation does not immediately break generic language modeling. Still, the text results are better read as feasibility evidence than as proof that this is already the best general-purpose pretraining objective.

Among the ablations, the most informative one is symmetric versus absorbing. Performance drops when the model is restricted to monotonic pruning, which indicates that the ability to reopen candidates is not cosmetic; it is central to the method. The paper also emphasizes finite inference budgets, which is the practically relevant regime for diffusion LMs.1b:T514,Start with the introduction.
