In the sub-2-bit regime, this is a more efficient use of bits than simply bypassing quantization for selected weights.

The method has three main components.

First, a ternary base representation. Following PT2-LLM-style formulations, each quantization group uses a scale α and bias β, and weights are mapped to one of three values: {β-α, β, β+α}. This gives a compact ternary approximation for all weights.

Second, a salient residual design called column-semi sparse salient weight. QTEA first selects important columns, then keeps only a sparse subset of high-impact entries within those columns under a 1:4 semi-structured sparsity pattern. These retained entries act as residual corrections to the ternary base. This is a useful compromise: more regular than unstructured salient-weight preservation, but more bit-efficient than storing full salient columns.

Third, the paper modifies GPTQ-style column-by-column quantization in two ways. It adds column-wise rescale refinement, which alternates between updating a per-column rescale factor and the ternary assignment so that the ternary base better matches the local weight distribution after Hessian-aware error propagation. It also introduces error decay. The motivation is that GPTQ’s error propagation is order-dependent: early columns can spread their error over many later columns, while late columns have little room left, so using the same propagation strength everywhere can overcompensate near the end. Error decay gradually weakens propagation along the column order to reduce this imbalance.

Overall, QTEA is a combination of ternary base quantization, structured residual compensation, and a refined column-wise optimization procedure tailored to ultra-low-bit settings.c:T5c7,The main experiments are on Qwen3-14B and Llama3-8B.
