17:T5bd,The pipeline has three components: generate positive traces, generate negative traces, and train with preference optimization.

1) Positive traces:
- A strong model (primarily GPT-4o) generates step-by-step reasoning traces conditioned on the question and multiple tables.
- Output is tightly constrained: a markdown table of steps, and each step must explicitly reference which table (TABLE1/TABLE2) it uses, discouraging unsupported leaps.
- Positives are validated to lead to the gold answer. Instead of brittle string matching, they use an LLM judge for semantic equivalence (Gemini 2.0 Flash is mentioned) to handle formatting/alias variations.

2) Negative traces:
- Generate fluent, plausible rationales that contain factual or logical errors.
- Key design choice: positives and negatives are generated by heterogeneous LLMs. Their ablations reportedly show that using the same generator for both weakens the contrastive signal and makes it easier for the learner to exploit stylistic cues.

3) Training with CPO (Contrastive Preference Optimization):
- Fine-tune open-weight LLMs on (positive, negative) preference pairs.
- They also run DPO on the same pairs and report CPO performs better in this setup.

The main trade-off is scale vs noise: synthetic traces can be large and diverse, but only if you invest in validation and filtering; otherwise hallucinations become supervision.
