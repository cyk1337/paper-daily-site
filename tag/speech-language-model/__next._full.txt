5) Representation alignment: add an intermediate-layer contrastive (InfoNCE) objective to pull speech/text hidden states into a shared space; ablations indicate mid-layer alignment is notably better than embedding-level or late-layer alignment.19:T816,The paper extends causal mediation analysis, specifically causal tracing / activation patching, from text-only factual recall studies to a multimodal setting. The procedure follows the standard three-run setup. First, run the model on a clean prompt and cache hidden states. Second, corrupt the input and measure the drop in probability assigned to the correct object token. Third, rerun the corrupted input while restoring one selected activation from the clean run, and measure how much the correct answer probability recovers. This recovery defines the indirect effect of that component, and averaging across prompts yields AIE maps over layers, positions, and components.

The key adaptation is to make this work for speech-conditioned prompting. SpiritLM is well suited for that because it represents speech as discrete HuBERT tokens, text with the Llama2 tokenizer, and uses modality declaration tokens to interleave both streams in one autoregressive backbone. That makes speech tokens analyzable in the same intervention framework used for text tokens.

For data, the authors start from the Known dataset of factual prompts used in prior factual localization work and create speech counterparts for prompts, subjects, and objects. Audio is synthesized with MeloTTS, then checked through manual inspection and Whisper-small transcription. The reported prompt WER is about 19%, which is good enough to support the analysis but also important for interpretation: weaker speech-side localization may partly reflect synthesis / transcription / discretization noise, not only missing internal mechanisms.

The main comparison is between T→T and S→T. The paper examines whether the familiar text-LM pattern, where factual associations are often mediated by mid-layer MLP states, reappears under speech input. The answer is only partially yes. Text input produces clearer and stronger restoration hotspots, while speech input yields weaker and more diffuse causal traces, suggesting that the mapping from speech tokens to parametric factual knowledge is less direct.1a:T5de,The experimental story is more about mechanism patterns than benchmark scores.

First, the study uses roughly 1,000 factual prompts from the Known dataset and augments them with speech versions. This keeps the analysis focused on controlled factual associations rather than open-domain QA noise.

Second, the speech data quality is explicitly checked. Whisper-small transcription of synthesized prompts gives a 19% WER. That number is not negligible, and it should be kept in mind when interpreting weaker S→T effects.

Third, the central result is that T→T reproduces clearer factual localization, consistent with prior text-only work, whereas S→T shows weaker but still detectable traces. In other words, factual recall mechanisms do carry over, but only partially. The signal is less concentrated and less robust under speech input.

Fourth, the paper is useful partly because of what it does not find. A unified backbone does not guarantee that speech inputs inherit the full factual retrieval pathway available to text inputs. From a pretraining perspective, this points to possible bottlenecks in speech tokenization, cross-modal alignment, and the objective used to mix speech and text during training.

The full text provided here does not include all tables and exact effect magnitudes, so the hard numbers that can be stated confidently are mainly the dataset size scale and the 19% WER. Read it as a mechanistic probe of multimodal pretraining, not as a new training recipe.

Start with the introduction to fix the scope: the target is factual recall mechanisms, not speech recognition quality. Then read the methodology carefully, especially the clean / corrupted / patched runs and the definition of indirect effect. Once that is clear, the result figures become much easier to interpret.

Pay close attention to the SpiritLM input format and the speech data construction pipeline. HuBERT discretization, modality tokens, and TTS-generated prompts are not implementation details here; they shape what the conclusions actually mean. When reading the result plots, the right question is not only which layer peaks, but whether speech causes the signal to become weaker, more diffuse, or shifted away from the canonical mid-layer factual pathway seen in text LMs.
