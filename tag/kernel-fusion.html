Faster Than Flash: Exploiting Attention Sparsity for Efficient Long-Context Decoding

论文解决的是长上下文自回归解码中的内存带宽瓶颈，重点不是训练阶段的长序列计算，而是每生成一个 token 都要从 HBM 重新读取大段 KV cache 的问题。已有训练-free 稀疏注意力通常把“选择重要 token/block”和“执行注意力计算”拆成两个阶段：selector 依赖额外 metadata 做重要性估计，computer 再按索引取数计算。这带来两个具体代价：metadata 本身占内存和带宽；自适应选择策略如果接近 top-p，又需要全局 softmax 或同步，抵消稀疏带来的收益。

评稀疏注意力常死在“选块元数据+同步”上，这篇把 selector/compute 融成 kernel 才像真解法；重点看 top-delta 与带宽测量。

TileFuse: A Fused Mixed-Precision Kernel Library for Efficient Quantized LLM Inference on AMD NPUs

这篇工作解决的是一个很具体但长期被忽视的问题：边缘端 NPU 明明有不错的能效，却很难直接运行社区常用的量化 LLM，尤其是 AWQ 这类已经广泛分发的 W4A16 / W8A16 权重。问题不在于单纯算力不够，而在于现有 NPU 软件栈封闭、低层可编程性不足，以及量化格式、数据布局、DMA 流水和 tile 级执行方式之间不匹配。结果就是，用户往往得为了硬件去改模型或改量化方案，而不是把现成量化模型直接部署上去。TileFuse 试图把这个链条打通：让 AMD XDNA2 NPU 直接吃下 AWQ 风格权重，并把它真正接进端到端 LLM 推理流程。

评不是预训练论文，但很适合做小模型/端侧路线的人看：重点看它如何避免为硬件专有量化格式改模型，这个接口问题常被训练侧低估。
Wesley Pang,Gregory Hyegang Jun,Feiyang Liu,Deming Chen

Ada-MK: Adaptive MegaKernel Optimization via Automated DAG-based Search for LLM Inference

在毫秒级强时延约束的线上场景（广告系统）里，LLM decode 阶段存在大量 kernel launch 与算子间 HBM 往返，导致端到端时延被 launch overhead 和内存流量主导；MegaKernel 虽能通过算子融合与 persistent kernel 缓解，但在 NVIDIA Ada（L20）这类共享内存更小、缺少原生 TMA 的 GPU 上，很难同时做到“足够快、可移植、且无运行时动态调度抖动”。

评只看系统假设和性能表即可；对预训练没直接动作，但能提醒小 batch decode 的真实瓶颈不在 FLOPs。
