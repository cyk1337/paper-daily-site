Unifying Depth and Width Pruning for LLMs via Binary Knapsack Optimization

结构化剪枝在 LLM 上常见两类问题：只做 depth（删层/删块）很难精确命中目标压缩比；只做 width（删头/删通道）容易造成不规则张量形状、实际加速有限。更关键的是，多数方法用贪心局部决策，忽略跨层依赖，导致性能波动大、对校准集分布敏感。论文要解决的是：能否把 depth 与 width 统一成一个可控预算的全局选择问题，并在给定重要性估计的前提下给出“有保证”的最优选择，同时把压缩比命中率做成可量化指标。

评不是会改写 pretrain prior 的工作，但它把 pruning 从 heuristic 拉回到资源分配问题，这点很干净；先看 CRAFT 定义和主表，别被平均精度迷惑。
