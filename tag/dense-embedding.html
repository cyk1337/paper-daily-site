DiffRetriever: Parallel Representative Tokens for Retrieval with Diffusion Language Models

这篇工作要解决的不是“检索能不能用 LLM 做”，而是一个更具体也更关键的问题：把语言模型当 retriever 时，单个代表 token 往往过于压缩，多 token 表示理论上更接近 late-interaction 检索器，但在自回归模型里，多 token 需要逐步生成，编码延迟随 token 数线性增长，而且先前工作里效果也不稳定。作者想验证，瓶颈到底是“多 token 表示本身没用”，还是“AR 顺序生成把这个想法做坏了”。他们给出的答案是后者：如果换成 diffusion LM，用并行 masked-position prediction 一次性读出 K 个代表位置，多 token 检索就能稳定带来收益。
