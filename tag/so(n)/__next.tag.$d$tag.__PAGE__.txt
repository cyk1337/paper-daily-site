第二层是 triplet frame learning。作者不用传统两帧重建，而是取三帧 I_t, I_{t+1}, I_{t+2}（文中也允许更一般的 first-second-third transition），分别编码前两段转移，再利用 SO(n) 的闭包性用矩阵乘法组合两个 latent action，去监督从第一帧到第三帧的 latent action。这个设计的关键不是多看一帧，而是把“动作可组合”写进训练目标里。若 latent 只是目标帧压缩码，组合关系通常不成立；只有当它更接近真实 transition factor 时，这个约束才容易满足。因此 triplet objective 实际上是在用代数结构压制 trivial reconstruction shortcut。

在 VLA 部分，作者把预训练好的 latent action model 接到一个 VLM backbone 上，用 flow-matching latent action head 预测连续 latent action，而不是做离散 token 分类。下游微调时，再把 action head 扩展成 unified flow-matching action head，同时建模 latent action 和 robot action，并通过 causal attention 让 robot action 生成条件化在 latent action 上。这里 latent action 被当作 planner，robot action 是 embodiment-specific executor。这个分层设计解释了为什么它能做 cross-embodiment 迁移：先在共享 latent 层对齐，再在具体动作层适配。b:T7ed,The method has two layers. First is the rotational latent action model. The authors keep the inverse-dynamics / forward-dynamics skeleton of latent action models, but replace hard VQ-style quantization with SoftVQ so the latent remains codebook-structured yet continuous. They then constrain the latent action to live on SO(n), representing each action as an n-by-n rotation matrix. Instead of forcing the network to directly output an orthogonal matrix, which would be too restrictive, the model predicts an unconstrained matrix M, computes its SVD M = UΣV^T, and projects it to the nearest rotation matrix. This is a practical compromise: expressive learning dynamics first, geometric structure at the representation layer.

Second is triplet frame learning. Rather than supervising only pairwise reconstruction, the model uses three frames and encodes two consecutive transitions. Because SO(n) is closed under matrix multiplication, the two latent actions can be composed to predict the latent action from the first frame to the third. This is the key idea. The objective does not merely add another frame; it writes compositionality directly into training. If the latent is just a hidden code for the target frame, the composition relation will usually fail. If it captures transition dynamics, the relation becomes natural. In that sense, the triplet objective is a structural regularizer against trivial reconstruction solutions.

On top of the pretrained latent action model, RotVLA attaches a VLM backbone with a flow-matching latent action head to predict continuous latent actions instead of discrete action tokens. During downstream adaptation, the head is extended into a unified flow-matching action head that denoises both latent actions and robot actions. Robot action generation is causally conditioned on latent actions, so the latent space acts as a planner while the robot action head acts as an embodiment-specific executor.
