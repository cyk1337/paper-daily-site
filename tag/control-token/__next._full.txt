18:Ta15,技术方案的关键是实验控制做得很严。作者设定攻击者只能控制一次 tool result 的字节内容，不能改系统提示、用户任务、工具 schema 或服务配置；防守方唯一能控制的是 tokenizer 如何把这些字节映射成 token id。围绕这一点，论文构造了几组条件。

第一组是 Reserved：在注入的 tool 输出里伪造 chat template marker，并让这些 marker 以模型原生的 reserved token id 进入上下文。第二组是 Split：字节完全相同，解码后日志里看到的字符串也完全相同，但通过 tokenizer 设置把这些 marker 编成普通 subword 序列，而不是 reserved id。这样就把“同样文本、不同 token id”直接对比出来。第三组是 Matched：因为 Split 往往会比 Reserved 多出 7 到 33 个 token，单纯多 token 也可能改变行为，所以作者在普通文本别处人为加入同样数量的额外 token，同时保留 marker 的 reserved id。这样 Split 与 Matched 在字节和 token 数上匹配，只差 marker 是否保留 reserved representation。作者把 Split 与 Matched 的攻击成功率差定义为 identity gap，用来估计 reserved representation 本身值多少钱。

这个设计比已有工作更强的地方在于，它不是把 marker 改写成别的文本，也不是把特殊 token 粗暴拆成单字符，而是在字节固定的前提下只改 token id。这样可以真正回答“权威来自文本还是来自表示”。

论文进一步往前走了一步，不只停留在现象层面。作者分析了 embedding 层，发现 marker 的 subword embedding 平均值不能替代 reserved token 的向量；但在 Llama-3.1 上，embedding 空间里某个最近邻普通 token 的向量却能近似替代它。基于这一点，作者还构造了 adaptive attacker：搜索非保留 token 里哪些 token 向量最接近 reserved marker，结果确实能找到替代性很强的普通 token。这说明攻击权威并不神秘，它相当程度上压缩在一个学习到的输入向量里，而不是来自复杂的高层模板解析。

另一个重要分析是 base 与 instruction-tuned 配对比较。作者在每个 base / instruct 对上都观察到，instruction-tuned 版本对 reserved marker 的偏好更强。这说明后训练阶段反复在真实对话边界上看到这些控制 token，会把“这是高权限边界”的语义进一步写进表示里。这个结论对 chat model 的训练 recipe 很关键，因为它把安全问题直接连到了 post-training 数据分布和模板设计。19:T95e,实验主要在 InjecAgent 和 AgentDojo 上做。攻击成功定义为：模型下一次生成里调用了攻击者指定的工具。InjecAgent 覆盖 direct harm 和 data stealing 两类 case；AgentDojo 用来验证多轮 agent loop 下结论是否仍成立。所有配置在温度 0 下重复 3 到 5 次，以减小 serving engine 非确定性带来的偶然波动。

最关键的结果是 fixed-bytes 对比。对 Llama-3.1、GLM-4.5 和 Seed-OSS-36B，把伪造 marker 从 reserved id 改成普通 subword 后，InjecAgent 上的攻击成功率下降 39 到 66 个百分点，而且这个差距在 AgentDojo 的多轮环境里依然存在。也就是说，攻击的大头不是“看起来像模板”，而是“模型真的收到了保留 token”。Qwen3-8B 是一个重要例外：在这个模型上，marker 文本本身已经足够强，reserved 与 split 的差异很小。作者解释说，这不是 reserved representation 不重要，而是原始 readout 已经接近 100%，出现了天花板效应；此前 Deng 等人的单字符拆分实验之所以得到 100.00% 到 99.99% 的近零差异，主要就是因为测量点已经饱和。

Matched 控制实验也很关键。结果显示，额外 token 数本身带来的攻击代价接近 0，因此 Reserved 与 Split 的差异几乎都可以归因于 reserved representation，而不是长度变化或异常分词扰动。这一点把机制解释钉得很牢。

向量层面的实验给出更细的证据。作者发现 subword 平均向量不能复现 reserved marker 的效果，说明简单的“文本组合语义”解释不够；但最近邻普通 token 可以在某些模型上近似替代，说明攻击权威在 embedding 空间里是局部可迁移的。再往前，adaptive attacker 搜索到的正是这类邻近 token，证明防守如果只依赖“禁用 special token 重编码”并不稳固。

最后，论文还系统检查了 Hugging Face 上下载量前 400 的 chat 模型 tokenizer 配置，统计到 67 种不同配置，其中 33 种标准 mitigation 只会重编码声明为 special 的 token，却不会处理 tool 协议 token，例如 <tool_response>。作者进一步验证，这个遗漏在 tool channel 上确实会留下同类风险。这部分很有工程含义，因为它说明现有防护不是理论上不完备，而是在主流 serving 栈里就会漏掉一半左右的配置类型。1a:T97e,The technical contribution is a tightly controlled experimental design. The attacker is allowed to control only the bytes of one tool result. They cannot modify the system prompt, user task, tool schema, or serving configuration. The defender controls only the tokenizer call, and therefore the mapping from bytes to token ids. Around this setup, the paper defines three key conditions.

Reserved keeps the forged chat-template markers as native reserved token ids. Split keeps the bytes identical and therefore the rendered text identical, but forces those same marker strings to be encoded as ordinary subwords rather than reserved ids. This is the core fixed-bytes contrast: same bytes, different ids. Because splitting reserved markers also increases token count, the paper adds Matched, which preserves the reserved ids but injects the same number of extra tokens elsewhere in ordinary text. Split and Matched therefore share bytes and token count, differing only in whether the forged markers retain their reserved representation. The attack-success-rate difference between them is defined as the identity gap.

This design is stronger than prior work because it does not rewrite the marker text and does not rely on crude character-level splitting. It changes only token identity while holding the visible string fixed. That directly answers whether the authority comes from text or representation.

The paper then goes beyond behavioral measurement. It analyzes the embedding layer and shows that the average of the marker's subword embeddings does not substitute for the reserved token vector. However, on Llama-3.1, the nearest ordinary token in embedding space can approximate the reserved marker's effect. An adaptive attacker that searches for non-reserved tokens near the reserved marker indeed finds such substitutes. This is an important mechanistic result: a large part of the authority is concentrated in a learned input vector, not in a high-level parser over template syntax.

Another strong component is the base-versus-instruct comparison. Across every tested base/instruction-tuned pair, the instruction-tuned checkpoint shows a stronger preference for the reserved marker. That suggests post-training repeatedly reinforces the semantics of these control tokens as high-authority boundaries. For chat-model training recipes, this is a direct link between formatting conventions and downstream vulnerability.1b:T94e,The main evaluations use InjecAgent and AgentDojo. Attack success is defined as whether the model's next generation contains the attacker-named tool call. InjecAgent covers both direct-harm and data-stealing cases, while AgentDojo checks whether the same effect persists in a multi-turn agent loop. Each configuration is run three to five times at temperature 0 to reduce noise from serving-engine nondeterminism.

The headline result is the fixed-bytes contrast. On Llama-3.1, GLM-4.5, and Seed-OSS-36B, replacing forged reserved markers with ordinary subwords lowers attack success on InjecAgent by 39 to 66 percentage points. The gap remains visible in AgentDojo's multi-turn setting. This means the attack is not driven mainly by 'looking like a template'; it is driven to a large extent by the model actually receiving reserved token ids. Qwen3-8B is the notable exception. There, the marker text itself already carries most of the attack, and the reserved-versus-split gap is small. The paper argues this is largely a ceiling effect because the readout is already near 100%, which also explains why prior character-splitting experiments reported almost no difference.

The Matched control is critical. The cost of extra tokens alone is close to zero, so the Reserved-versus-Split gap is not explained by length or unusual segmentation. That substantially strengthens the causal claim that the reserved representation itself carries the effect.

The embedding experiments add mechanistic evidence. Subword-vector averaging fails to reproduce the reserved marker's authority, so a simple compositional-text explanation is insufficient. But a nearest-neighbor ordinary token can sometimes approximate it, which implies the authority is locally transferable in embedding space. The adaptive-attacker experiment confirms this by finding non-reserved tokens that behave similarly.

Finally, the paper audits tokenizer configurations for the 400 most-downloaded chat models on Hugging Face. Among 67 distinct tokenizer setups, 33 leave tool-protocol tokens such as <tool_response> untouched under the standard mitigation that only re-encodes declared special tokens. The paper then shows the same reserved-token effect exists on that tool channel as well. This is operationally important because it turns a conceptual weakness into a concrete deployment gap in common serving stacks.1c:T624,This is a must-read paper, and it is worth reading in the order of problem decomposition, controls, mechanism, and deployment consequences.

Start with the introduction and Figure 1. The core observation is simple but easy to miss: the exact same string, such as <|im_start|>, can be one reserved token or several ordinary subwords. The request body, logs, and audit trail are identical; only the token ids differ. That framing carries the whole paper.

Next, read the method section carefully, especially the definitions of Reserved, Split, and Matched, and the identity-gap metric. This is the most important part to understand. Many prompt-injection papers do not separate byte content, token count, and token identity cleanly. Here they are disentangled with unusual care.

In the experiments, prioritize three result blocks. First, compare Llama-3.1, GLM-4.5, Seed-OSS-36B, and Qwen3-8B to understand why Qwen is an exception and why that does not invalidate the main claim. Second, inspect the Matched control to verify that extra tokens are not the driver. Third, read the base-versus-instruct comparisons, because they connect the vulnerability directly to post-training.

If time allows, continue to the embedding analysis and adaptive-attacker section. The most interesting question there is whether the authority of a reserved marker behaves like a discrete symbolic privilege or like a dense region in representation space. End with the tokenizer audit, which grounds the mechanism in real deployment practice.
