Multi-Head Recurrent Memory Agents

这篇论文研究 recurrent memory agent 在超长上下文下为什么会失效。核心发现是：主要瓶颈不是模型没有把关键信息写进 memory，而是写进去之后在后续反复更新中被覆盖掉。作者把问题拆成 memory capture 和 memory retention 两个环节，指出 retention 才是随上下文长度增长而快速退化的环节。

评长上下文 memory agent 常把问题归咎于摘要能力不够，这篇更像是在说“写坏旧记忆”才是主因；先看诊断定义和 ablation，再决定要不要跟。

Erase-then-Delta Attention: Decoupling Erase and Write Addresses in Delta-Rule Linear Attention

Delta-rule 线性注意力/递归记忆模型里，“纠错(erase/correct)”与“写入(write)”被同一个写地址 key 绑定：模型只能在当前写入地址上做 delta 纠错，无法在写新内容到地址 A 的同时，主动去地址 B 删除过期信息。结果是遇到变量重赋值、事实更正、上下文切换这类需要“定点删除”的场景时，只能依赖全局/通道级衰减去慢慢忘，容易残留干扰。

评这篇值得看方法和主表：它不是又一个线性注意力小修小补，而是在 memory update rule 上加了“独立擦除”自由度；先查收益是否来自更干净的记忆管理，而不是额外参数或训练技巧。

AURA: Action-Gated Memory for Robot Policies at Constant VRAM

这篇工作讨论的是一个很具体、也很现实的问题：把 Transformer 式 KV-cache 直接搬到长时运行的机器人策略里，内存占用和写带宽都会随时间线性增长，最后瓶颈不在算力，而在显存和写入。数据中心里的短请求可以 reset，cache 成本能被摊薄；机器人却是在一个几乎不重置的连续 episode 中运行，控制步数越长，历史越长，cache 越大。作者要解决的核心问题，是如何在固定显存下，为 embodied policy 提供一个常数大小、低写频率、又足够保留决策相关历史信息的记忆机制，并且这个记忆不是为重建过去服务，而是直接为“下一步动作是否正确”服务。

评值得 skim 门控训练目标；“按 action utility 写记忆”比又一个压缩 KV 更像可迁移的长程记忆假设。
