The Test Oracle Problem in Synthetic LLM-as-Judge Corpora: Disappearance, Distortion and a Validation Protocol

这篇论文讨论的是 synthetic LLM-as-judge 语料构建里的一个很具体但很容易被忽视的问题：当研究者用一个 LLM 生成“错误答案/幻觉答案”作为 judge 的负样本时，如果生成环节本身悄悄退化，后续所有关于 judge 偏差的统计分析都可能建立在坏刺激上，而且常规的稳健性检查未必能发现。作者把这个问题上升为 test oracle problem：对于一条自动生成的负样本，是否存在便宜、机械、逐条可执行的正确性检查。如果没有，那么语料构建流程就天然缺少 item-level 审计能力。

评值得 skim；它不是大模型方法，但会改变你对合成 judge 数据“统计显著即可用”的信任。
Serkan Ballı
