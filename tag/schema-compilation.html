TSCG: Deterministic Tool-Schema Compilation for Agentic LLM Deployments

这篇工作处理的不是“模型不会用工具”这个泛问题，而是一个更具体、也更工程化的瓶颈：生产环境里工具定义通常以 JSON Schema 形式注入上下文，但 JSON 的结构冗余、字段嵌套和 tokenizer 不友好表示，会让中小参数模型在工具目录稍大时迅速失效。论文把问题界定为 protocol mismatch，而不是单纯的 prompt compression：同样的语义，如果换一种更适合自回归模型读取的表示，工具调用准确率会显著恢复。这个界定比“压缩 token”更重要，因为作者后面用实验说明，性能提升主要来自表示形式变化，而不只是上下文变短。

评读 §4 的分解实验即可；它提醒工具调用失败常是接口表示问题，不一定要先上 SFT。
Furkan Sakizli
