评MDLM 评测应立刻加 NFE 和温度控制；这篇会改变对 remasking 论文收益的可信度判断。

VoidPadding: Let [VOID] Handle Padding in Masked Diffusion Language Models so that [EOS] Can Focus on Semantic Termination

Masked Diffusion Language Model（MDLM）在 instruction tuning 时常沿用 AR 的做法：用重复的 [EOS] 做 padding。由于 MDLM 是双向条件建模，padding token 会进入训练目标并在推理时参与上下文，导致 [EOS] 同时承担“语义终止符”和“长度/填充符”两种角色。论文指出这会在大 block decoding 下触发 [EOS] overflow：尾部高置信 [EOS] 被写入上下文后进一步抬高邻近 [EOS] 概率，形成自强化，最终输出过短且充满 [EOS]。要解决的是：把终止语义与 padding 长度信号解耦，让 [EOS] 只表达语义终止。

评应立刻复现：它把 MDLM 长度建模的锅从解码器挪到训练格式，setup 简单且收益大。

Attention-Discounted Adaptive Sampler for Masked Diffusion Language Models

这篇工作处理的是 masked diffusion language model 在并行解码时的一个具体薄弱点：模型可以在一步里同时揭掉多个 mask，但“单点置信度高”不等于“这些位置适合一起提交”。现有 Top-k、Fast-dLLM、EB-Sampler 这类 training-free sampler，主要控制每一步揭多少 token，排序依据却大多还是逐位置分数，如最大概率、margin 或 entropy。论文指出，真正导致低步数区间质量掉得快的，不只是模型本身预测错，而是 joint dependence error：若两个位置的预测彼此耦合，同时提交会放大错误。作者要解决的不是重新训练模型，也不是重新设计完整 decoding framework，而是在不改 stopping rule 的前提下，把“位置间相容性”引入 subset construction。

评读方法和 ablation 即可；它把 MDLM 加速问题从“揭示几个”推进到“哪些 token 可一起提交”。
