18:T59c,OPID builds a strictly on-policy self-distillation pipeline by rewriting each completed trajectory into hierarchical natural-language “skills”, then using the same policy to rescore the same sampled outputs under skill-augmented context.

1) Hindsight skill extraction: from each finished on-policy trajectory, generate:
- Episode-level skills: global workflow summaries / failure-avoidance rules (coarse but broadly applicable).
- Step-level skills: state-conditioned guidance at pivotal timesteps (precise but sparse).

2) Critical-first skill routing: identify critical timesteps and inject step-level skills there; otherwise fall back to episode-level skills. This targets the granularity trade-off in long-horizon interaction: global guidance is stable but too coarse at decision bottlenecks; local guidance is accurate but should not be applied everywhere.

3) Skill-based self-distillation advantage: take the routed skill text as privileged context appended to the interaction history. Using the old policy, compute token-level log-prob shifts for the same on-policy response between (a) original context and (b) skill-augmented context. This shift acts as a dense preference/advantage signal and is combined with the episode-level outcome advantage for policy optimization.

4) Inference: no analyzer, no retrieval, no skill memory. Skills are training-only scaffolding whose effect is distilled into the policy parameters.19:T583,SAVE (Self-supervised reward model improvement via Value-Anchored On-policy feEdback) augments the RM with a prompt-level value head and uses advantage-based pseudo-preferences derived from on-policy rollouts.

1) Value-anchored RM: the model predicts both a scalar reward R(x,y) and a prompt-specific value V(x), where V(x) estimates the expected reward under the current sampling policy for that prompt. V(x) serves as an adaptive baseline.

2) Advantage-derived supervision: for each on-policy response y, compute an RM advantage A(x,y)=R(x,y)-V(x). Responses are split into positive-advantage and negative-advantage sets, yielding pseudo preference pairs (x, y_pos, y_neg).

3) Ambiguity filtering with a curriculum threshold: samples with small |A| are treated as ambiguous and filtered out. This is meant to control bootstrapping noise and avoid reinforcing uncertain or near-tie comparisons.

4) Contrastive/ranking objective: the RM is updated with a contrastive preference loss on the constructed pairs, analogous in spirit to Bradley–Terry training but with labels induced by advantages rather than human/judge preferences.
