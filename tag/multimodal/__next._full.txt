18:T42f,A-RSI has two main components. The first is a programmatic multimodal task pipeline. A base model writes fixed templates for task families such as geometry, charts, tables, and counting. Each template defines admissible parameters, sampling, image rendering, question construction, and answer computation. An instance is generated from a shared underlying configuration, and the reference answer is computed from that same configuration. The pipeline applies checks and audits, but it does not claim a formal proof for every rendered question. The second component is a training-log controller. The Solver is trained on the active pool with GRPO, using correctness, format, and termination rewards. After each training window, the controller checks how many prompts still have within-group reward variation, together with logged training accuracy. When the specified condition fires, the entire active pool is replaced while the model weights are kept. The Specific-Capability tier isolates reasoning, planning, long-context information extraction, and retrieval. The Multi-Stage tier examines iterative editing, visual goal interpretation, diagnosis and repair, and evidence synthesis. The Commission-Level tier covers complete visual commissions such as visual argumentation, example-driven transfer, scientific visualization, and workspace-based design. A shared harness manages stage transitions, tool execution, and completion checks.1a:T554,The theory defines a world as a finite set of states, with each modality providing an injective rendering of those states. A JEPA in each modality is trained on positive pairs whose underlying world states are sampled from a symmetric positive-pair distribution. For JEPAs with whitened second-order anti-collapse, the optimum is the spectral embedding of the positive-pair kernel. If multiple modalities share the same positive-pair distribution over world states, and the optimum is unique up to rotation, then each modality solves the same spectral embedding problem in different coordinates. Their representations therefore match up to a rotation, which the authors call the Platonic Representation Theorem. When the positive-pair distributions differ, misalignment is bounded by the mismatch between those distributions. The paper also analyzes nuisance variables: if positives preserve more of a modality-specific nuisance direction than the k-th world direction, a k-dimensional embedding will spend capacity on that nuisance, and no rotation can align it away. Good-view JEPAs use two observations of the same scene as positives; bad-view JEPAs form positives by corrupting or continuing a single observation. Next-token prediction is placed in the latter class, with prefix-continuation pairs and the softmax log-partition acting as an anti-collapse term.1b:T682,The empirical results test the good-view claim across text, image, and video settings. With matched texts and encoders, good views usually produce the strongest alignment, from 145k Flickr captions to text associated with 940M web images, with both trained-from-scratch and frozen image encoders. Alignment follows a scaling law in the fraction of good views and the number of samples seen; the fitted law predicts 85 new runs with error comparable to rerunning the same configuration with another seed.
