When Can Conditional Flow Matching Replace Pointwise Negative Log-Likelihood?

澄清 conditional flow matching（CFM）何时可以替代端点负对数似然（NLL），以及何时不能把 CFM 差值当作 log-likelihood ratio 使用。

评这篇会直接修正“CFM≈NLL、CFM 差值≈log-ratio”的偷懒 prior；做 diffusion/flow LM 或 alignment 的人应先看定理和 residual 分解，再决定 loss 怎么写。

Token-Level Likelihood-Array Regression for Membership Inference and AI-Generated Text Detection

论文解决的是基于语言模型 likelihood 的两类审计任务：判断文本是否进入过某个模型的训练集，以及判断文本是否由 AI 生成。现有方法通常把 token-level likelihood 压缩成少数几个手工分数，主要依赖 full left context 下的 next-token log probability。论文的问题是：不同上下文长度、不同 token 位置、不同 likelihood 特征中的检测信号如何被系统建模，而不是提前压缩掉。

评这不是提性能的paper，但对训练数据泄露怎么从token似然里冒出来讲得更细；只看方法和误差界，实验先当弱信号。

Conservation Laws for Diffusion Models

这篇工作要解决的不是“如何再造一个 diffusion loss”，而是一个更基础的问题：对任意 memoryless noising path，diffusion 模型训练时用的局部去噪目标，究竟和数据分布上的全局 likelihood / cross-entropy 是什么精确关系。已有结果主要分裂在两端：连续高斯噪声有 I-MMSE 关系，离散 masked/noising 有各自的专门推导，但缺少一个统一框架来覆盖离散与连续 diffusion，也缺少对 mismatched setting 的刻画——也就是实际训练里 denoiser 不是精确后验，而是有限容量模型时，cross-entropy 如何由沿噪声路径的局部信息导数精确表示。论文给出的答案是一个 generalized GEXIT conservation law：数据-模型 cross-entropy 可以写成沿噪声轴积分的局部信息论导数，而且在 memoryless channel 下，这些导数只依赖边缘后验而不需要完整联合后验。

评扩散模型似然的统一理论框架，直接改变Diffusion LM训练目标的设计思路，应立刻在离散扩散预训练ablation中验证局部训练推论。
Ziv Aharoni,Henry D. Pfister
