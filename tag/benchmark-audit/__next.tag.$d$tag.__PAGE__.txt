First, it improves prompt quality. The authors identify ambiguous prompts in the original benchmark and rewrite them to be more distinctive, while also introducing a templated prompting scheme that better matches model-specific prompting practices. The point is not to make the task easier in an artificial way, but to reduce variance caused by poor prompting so the score better reflects model capability.

Second, it changes metric aggregation. The original Physics-IQ score is defined at the dataset level, which means samples can contribute unevenly and failure modes are hard to localize. The paper introduces a sample-level Physics-IQ Verified score so that each sample and each metric can be analyzed more directly and aggregated more fairly. This improves interpretability and statistical hygiene.

Third, it cleans artifacts in the ground-truth videos. The authors show that many reference videos contain spurious activations unrelated to the target physical phenomenon, such as incidental motion or visual noise that can trigger IoU- or MSE-based metrics. They therefore clean the references so the metrics respond more selectively to the intended physical effect. This is a pragmatic benchmark-repair strategy: clean the measurement target before redesigning the entire metric stack.b:T50f,The most important result is not that one model scores higher than another, but that model rankings change materially once the benchmark is corrected. The authors evaluate six image-to-video models under both the original and the verified protocols and find that models respond differently to the benchmark fixes, leading to substantial ranking shifts. That means the noise in the original benchmark is not harmless random noise; it can systematically favor some models over others.

The scale of the benchmark issues is also nontrivial. The paper reports that the refinement removes measurement errors in 57.6% of all samples, affects 29.8% of videos, and corrects more than 34.8% of prompts judged to be highly ambiguous. The benchmark itself contains 66 physical experiments, each recorded from 3 viewpoints and repeated twice, for a total of 396 videos. Each 8-second video is split into a 3-second conditioning segment and a 5-second continuation to be predicted. The evaluation still uses the original four metrics—Spatial IoU, Spatiotemporal IoU, Weighted Spatial IoU, and MSE—but revisits how they should be aggregated and what reference signal they should operate on. First is a six-state control-decision taxonomy: Act, Ask, Refuse, Stop, Confirm, and Recover. This is useful because it does not collapse behavior into a binary do/don’t-do decision. Instead, it isolates the main branching points that matter in deployment. Ask handles ambiguity or missing information, Confirm handles risky or irreversible actions, Recover handles tool failures or observation errors, and Stop handles proper termination. Second is a nine-category trajectory-failure taxonomy covering tool-use failures, observation failures, recovery failures, safety failures, efficiency failures, and related categories. The key idea is that final failure is only the surface symptom; the trainable and diagnosable unit is where the trajectory went wrong. Third is a benchmark coverage audit over 15 agent benchmarks along six evaluation axes, designed to show what each benchmark measures and what it leaves out, rather than to create another aggregate leaderboard. Fourth is a controlled synthetic measurement setup: a Control split with 684 items, a Trajectory split with 400 items, and a Security split with 258 items, totaling 1,342 items, evaluated on a fixed set of eight models under taxonomy-aware versus taxonomy-blind prompting. The point is not to release a public benchmark, but to demonstrate that with the same models and the same items, changing the evaluation axis and prompt framing can change the conclusion. A notable design choice is that the paper avoids building a complex judge model or a large automatic trajectory scorer.
