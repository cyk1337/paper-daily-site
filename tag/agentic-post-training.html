Priming Base Models for Agentic Post-Training: An Open Midtraining Recipe

这项工作解决的是 base model 到 agentic post-training 之间缺少公开、可复现实证配方的问题。常规预训练多在 4K–8K 短上下文上做，几乎看不到真实 agent 交互；SFT 又主要依赖合成 chat 数据，阶段过长会削弱后续 RL 的可训练性。软件工程 agent 真正需要的信号，包括整仓库、PR 演化、commit history、build log、长 agent trace，往往是几十万 token 级别，既不适合普通短上下文预训练，也不适合直接塞进长 SFT。论文把 midtraining 定义为这个缺口中的独立训练阶段：在收敛 base model 上，用长上下文和自然软件工程数据先把模型“预热”到适合 agentic post-training 的状态。

评应立刻对照内部 midtrain ablation；它把“长上下文自然代码数据”放到 SFT/RL 之前，改变 agent recipe 的默认切分。
