18:T48b,CURATEEVO represents the curation strategy as executable code and evolves it over multiple epochs using failed trajectories as feedback.

Pipeline (as described in the provided full text excerpt):
1) Run the current agent on a held-out dev set and collect failed trajectories (e.g., wrong, too long, useless).
2) Extract failure modes from these trajectories.
3) Rewrite the curation code to better target the observed failures by combining:
- augmentation (generate/add data targeting failure modes),
- filtering (remove low-utility/noisy trajectories),
- refinement (repair partially useful trajectories),
- plus efficiency edits such as pruning redundancy and truncating overly long trajectories.
4) Execute the evolved code on a fixed raw corpus to produce three training assets in parallel: SFT data, RL data, and an inference-time memory bank.
