19:T938,模型是一个单 block 的 Universal Transformer，每一步都对完整序列做双向注意力，序列形式为若干 memory tokens 加原始 Sudoku token 序列。块内采用 pre-norm attention + SwiGLU FFN，并加入每步 learned positional embedding、RoPE、QK normalization。作者还用了一个较少见的 DerfNorm 设计，用 erf(alpha*x+s) 取代标准归一化层，目的是减少归一化对递归动态的干扰，但全文的核心结论并不依赖这个点。

真正的技术重点有三个。第一，memory tokens 被当作可学习寄存器，而不是普通前缀 token。作者系统扫了 token 数量，发现 81-cell Sudoku 上存在明显阈值：T=0 必败，T=4 处于临界区，T=8 开始稳定成功，T=8 到 32 基本进入平台区，再增大到 T=64 则因注意力稀释而退化。这说明 memory token 的作用不是“多一点上下文更好”，而是需要足够数量来承载中间状态，但过多又会稀释对问题 token 的注意力。

第二，作者把 ACT 失败归因到 router initialization trap。标准零偏置会让初始 halting probability 约为 0.5，Graves 的正偏置建议会更高到约 0.73，这两种都会让 token 在 1 到 2 步内过早停止。作者反过来采用 deep-start 初始化，把 halting bias 设为 -3，使初始 p 约为 0.05，等价于默认先跑满 K=18 步，再让模型学会在哪些位置提前停。这个设计背后的判断很清楚：对需要深计算的任务，先深后浅比先浅后深更容易优化，因为浅策略几乎不给“深度有用”这件事留下探索空间。

第三，作者做了较细的训练动态诊断。他们记录每步 router probability、step-weight 分布、router gradient norm 和注意力质量，发现能从 shallow-halt 中逃出的 run 往往伴随 router 梯度 10 到 45 倍的尖峰；而失败 run 的 router 梯度长期低于 0.04，说明 halting 子网络几乎被冻结。这个分析把“ACT 不稳定”从经验现象推进到更可操作的诊断框架。

和已有方法相比，这篇文章不是提出新的递归架构，而是在现有 UT+ACT 框架里指出：memory state 与 halting initialization 是两个一阶因素。它也顺带说明，其他能解 Sudoku 的递归模型如 TRM、HRM 依赖的是不同机制，不能据此反推 UT 不需要显式 memory。1a:T9ca,The model is a single Universal Transformer block applied recurrently up to K=18 steps. At each step, the sequence is composed of learned memory tokens followed by the Sudoku tokens, and the whole sequence attends bidirectionally. The block uses attention plus SwiGLU, with per-step learned positional embeddings, RoPE, and QK normalization. The paper also uses a normalization-free variant called DerfNorm, but that is not the main source of the reported effect.

There are three technical points that matter. First, memory tokens are treated as persistent learned registers rather than generic prefix tokens. The authors sweep the number of memory tokens and find a sharp threshold: T=0 always fails, T=4 is borderline, T=8 reliably works, T=8 to 32 forms a broad plateau, and T=64 degrades because attention gets diluted. This is a stronger claim than “more tokens help.” It suggests a minimum state budget is needed for recursive computation, while too many state slots hurt token-to-problem interaction.

Second, the paper identifies an ACT router initialization trap. With zero bias, the initial halting probability is around 0.5; with the positive bias recommended in earlier ACT work, it is even higher, around 0.73. Both settings make tokens halt after roughly 1–2 steps. The proposed fix is a deep-start initialization with bias -3, giving p about 0.05. That means the model starts by using nearly the full depth budget and only later learns where to stop early. The rationale is simple and convincing: on tasks that truly need depth, starting shallow prevents the model from ever seeing evidence that deeper computation helps.

Third, the authors instrument the training dynamics in detail. They log per-step router probabilities, step-weight distributions, router gradient norms, and attention mass. Successful runs escaping the shallow-halting regime are associated with 10x to 45x spikes in router gradient norm, while failed runs keep router gradients near zero for the entire training trajectory. This turns ACT instability from a vague empirical complaint into a more diagnosable optimization phenomenon.

Relative to prior work, the paper does not introduce a new recursive architecture. Instead, it isolates two first-order factors inside the existing UT+ACT setup: explicit memory state and halting initialization. It also makes clear that success of other recursive models on Sudoku does not imply that UT can do without memory, because those models rely on different mechanisms.1b:T797,The main experiments are on 81-cell Sudoku-Extreme. The model has about 3.2M parameters, hidden size 512, 8 attention heads, vocabulary size 11, and a maximum of K=18 recurrent steps. The study systematically varies memory-token count, ACT versus fixed depth, initialization scheme, and random seed.

The central result is the memory threshold. Across all tested seeds and settings, no-memory configurations never achieve non-trivial performance. T=4 is only marginally viable. T=8 is the first reliably successful setting, and T=8 to 32 stays on a stable plateau, with a representative exact-match result of 57.4% ± 0.7%. At T=64, performance drops, which the authors attribute to attention dilution.

The ACT versus fixed-depth comparison is also informative. With memory tokens, fixed-depth reaches 53.4% ± 9.3% exact match, but with high variance. ACT improves this to 56.9% ± 0.7%, indicating much better reliability. With lambda warmup, the model reaches about 57.0% ± 1.1% while using 34% fewer ponder steps, so ACT provides both compute savings and lower variance in this setting.

For the initialization trap, the authors analyze 15 runs and show that with bias=0, all runs start with p around 0.48–0.52 and halt after about 2 steps. By roughly 3k training steps, they settle into a shallow-halting pattern with average halt around 5–7. Only rare runs escape, and those escapes coincide with large spikes in router gradient norm. Switching to bias=-3 converts previously failing configurations into successful ones and changes the learning curve from abrupt phase transitions to smoother improvement.

They also test whether this is merely a DerfNorm artifact. Under a matched configuration, DerfNorm can escape and reach 50.6% EM, while RMSNorm stays stuck at 0.0% EM with halt around 3.5. That supports the claim that the main issue is the interaction between ACT and initialization, not a quirk of one normalization choice.1c:T482,This is a skim paper, but it is worth reading selectively. Start with the introduction and the section on the router initialization trap. That is where the paper’s main argument becomes clear: standard ACT initialization is poorly matched to tasks that require deep iterative computation. Then look at the memory-token sweep tables and figures, especially the transitions at T=0, 4, 8, 32, and 64. Those results carry most of the paper’s weight.

If time is limited, focus on three things. First, the ACT formulation and output weighting, because the model does not simply take the last recurrent state.
