评值得看失败案例和 judge 相关性分析；它提醒 memory self-improvement 不是免费 RL，奖励噪声会被检索放大。

评作为长horizon记忆消融testbed有参考价值，适合关注agent memory的人看setup；不是评测资产本身，对pretrain直接启发有限。
