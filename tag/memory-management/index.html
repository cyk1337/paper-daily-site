RedKnot: Efficient Long-Context LLM Serving with Head-Aware KV Reuse and SegPagedAttention

长上下文LLM服务中KV缓存是核心瓶颈，现有系统采用统一的token级KV管理和稠密布局，与实际工作负载中注意力头级的稀疏性结构不匹配，导致位置无关KV缓存复用率低、短上下文下占比过半的FFN开销无法被注意力侧优化覆盖、稀疏KV掩码触发FlashAttention慢路径，实际收益远低于理论预期。
