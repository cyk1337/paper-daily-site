RSI-Anything: Unlocking Recursive Self-Improvement with World Models

递归自我改进依赖外部反馈成本高，而 world model 又会随着 policy 演化而失真；这篇工作要解决的是如何用可适配的 world model 支撑跨版本的持续改进。

评想看的是“world model 会不会随 policy 漂移而失效”这个点，不是 RSI 口号；先看 code repair 那组 ablation，若 adaptation 真比静态 verifier 稳，就能借鉴到 self-play/RL 数据选择里。
