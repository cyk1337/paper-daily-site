b:T43f,The method is straightforward. The authors start from an existing thinking-oriented base model, Qwen3-30B-A3B-Thinking-2507, and apply a single SFT stage on a compact but deliberately hard dataset. The dataset is produced with three modifications to the trajectory synthesis pipeline. First, they enlarge the source graph used for task generation, so each synthetic query is conditioned on a richer evidence subgraph with more possible reasoning paths and stronger multi-hop requirements. Second, they expand the tool set available to the ReAct-style agent, encouraging more diverse interaction patterns and broader functional coverage. Third, they apply strict low-step filtering: any trajectory solvable in fewer than a threshold number of tool calls is discarded. This raises the minimum difficulty floor and removes shallow lookup-style examples. The final training set contains only around 10k high-difficulty trajectories.
