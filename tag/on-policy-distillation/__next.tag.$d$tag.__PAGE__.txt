For the who question, each prompt comes with a rubric made of criteria, verifiers, and weights. Instead of collapsing the rubric into a single scalar reward and discarding structure, the method scores both the student rollout and each candidate expert answer with the same criterion-specific verifier. An expert is allowed to teach a criterion only if it shows a verified advantage over the student on that criterion for the current sample. This is a local, sample-specific notion of expertise, not a fixed domain prior.

For the which question, even an eligible expert does not supervise the whole sequence. The method identifies positions where the expert disagrees with the student and applies distillation only on those tokens through a sparse mask. The intuition is simple: if the student already matches the expert, there is little value in forcing additional imitation; the useful signal lies where the expert would actually change the student’s local decision.

Training remains inside an on-policy RL loop. The base policy update uses a rubric-based GRPO-style objective on the student’s own rollouts. At an on-policy step t_j, the current model first predicts the deterministic next state along the ODE trajectory. From the same parent state, it then spawns K stochastic SDE branches. Each branch explores only locally at the current step, after which it is rolled out deterministically to a clean image. The purpose is to evaluate whether a local directional perturbation leads to a better final sample.

A deterministic ODE rollout from the same parent state serves as a self-reference baseline. Final rewards from the K branches are compared against this baseline reward to produce normalized branch advantages. This is important because the signal becomes relative and local: not whether a sample is globally good, but whether a local move from the current state is better or worse than the default trajectory.

Training uses an all-branch pull-push distillation objective. Positive-advantage branches pull the velocity field toward better local directions, while negative-advantage branches push it away from poor ones. Compared with only regressing toward the best branch, this uses more of the sampled neighborhood and turns local exploration into a richer ranking signal. The downside is potential instability: repulsive updates can conflict with attractive ones. To address that, the paper introduces direction-aware attenuation, which downweights repulsion when it would substantially cancel the direction of the best branch.

Another key component is SDE-variance normalization. Since branch displacement scales vary across timesteps and noise levels, direct regression would produce poorly calibrated losses. Normalizing by SDE variance makes the per-step target more comparable across the trajectory and is connected in the paper to a reward-tilted KL view: locally shifting probability mass toward higher-reward branches.

For multi-objective alignment, Self-OPD avoids field-level fusion of multiple teachers. Instead, it normalizes and combines scalar rewards first, uses the composite reward only to rank branches, and still regresses toward a concrete trajectory-derived velocity target. 和最接近的 CREDIT 相比，区别主要有三点。其一，CREDIT 用 unrelated batch queries 做对比，语义变化和其他 nuisance factors 混在一起；CROP 用 paraphrase/counterfactual 配对，把“语义不变的表面改写”和“关键条件改变”分开。其二，CROP 在固定 rollout 上比较条件分布，强调 controlled contrast；其三，最终分数是 counterfactual sensitivity 减 paraphrase sensitivity，显式做了语义校准，而不是把任何输入敏感都当成高价值监督。论文还强调，CROP 不是在估计严格因果意义上的 token causal effect，而是在预算受限 OPD 里构造一个可操作、模型内部、对比受控的 relevance proxy。2a:T7e8,CROP, short for Counterfactual Relevance for On-Policy Distillation, builds a token relevance score from controlled prompt contrasts. For each original prompt x, the method constructs an offline matched triplet: the original prompt x, a meaning-preserving paraphrase x_para, and a counterfactual prompt x_cf that changes one task-relevant condition. The student first generates a rollout y from its current policy on the original prompt. CROP then keeps that realized rollout fixed and rescoring is performed under all three prompts on the same response prefixes. This is an important design choice: the comparison is over conditional next-token distributions along the same trajectory, rather than over independently sampled responses, which reduces variance from trajectory mismatch.

At each token position, CROP measures how much the model’s next-token distribution changes under the counterfactual prompt and subtracts how much it changes under the paraphrase prompt. Intuitively, sensitivity to the counterfactual captures dependence on task semantics, while sensitivity to the paraphrase captures dependence on superficial wording. The resulting score is a calibrated relevance proxy rather than a generic input-sensitivity measure. Tokens are then selected globally under a fixed batch-level budget, and only those selected sampled tokens receive the teacher distillation loss. The teacher target and the OPD objective remain unchanged; only the allocation of supervision changes.

Distribution shift is computed with a top-K JSD plus a residual bucket. This is a practical compromise: full-vocabulary divergence is expensive, but top-K alone can ignore tail mass. Compared with CREDIT, the closest prior work discussed by the authors, CROP uses controlled original/paraphrase/counterfactual triplets instead of unrelated batch queries, and explicitly subtracts paraphrase sensitivity from counterfactual sensitivity. That makes the signal more targeted to semantic dependence rather than generic prompt variation.2b:T5e7,The empirical setup includes two teacher-student settings evaluated within the same budgeted OPD framework. For a token-selection method inside distillation, that is a meaningful gain.

The most convincing evidence comes from matched token-selection controls. Under the same supervision budget, selecting the highest-relevance tokens consistently outperforms random selection, while selecting the lowest-relevance tokens performs substantially worse. This matters because it validates the ranking induced by the relevance score itself, not just the end-to-end training recipe.

Ablations show that counterfactual sensitivity is the primary signal and paraphrase calibration adds further benefit. In other words, semantic sensitivity already identifies useful supervision locations, and subtracting paraphrase sensitivity removes positions that react to wording changes rather than task content. The paper also adapts CREDIT into the same selector framework for a cleaner comparison.

It also assumes that a meaningful task-relevant counterfactual can be defined for the prompt.
