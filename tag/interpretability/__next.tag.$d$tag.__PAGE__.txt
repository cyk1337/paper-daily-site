Prior work reduced the rank of the LM head in the forward pass and observed worse training. But that intervention simultaneously changes: the space of representable logits, the decoder parameterization and conditioning, the number and arrangement of trainable parameters, and the rank of the gradient returned to the hidden state. It therefore cannot identify whether the damage comes from the backward channel.

Here, the model still computes ordinary full-rank logits, and the LM head still receives its ordinary parameter update. Only the gradient sent back to the hidden state is replaced by a lower-rank version derived from the best rank-r approximation of the current head. The hidden gradient is RMS-matched to the exact gradient so that any effect is not confounded by gradient scale.

A second key piece is the explicit decomposition of the logit gradient into the component visible to the current hidden state and the orthogonal residual g_perp. The latter does not affect the current hidden state because it lies outside the column space of W, but it generally does contribute to the gradient of W itself. That means it changes the LM head, which in turn changes future predictions and future feedback subspaces. So “invisible to the current hidden state” is not the same as “discarded by training.”
