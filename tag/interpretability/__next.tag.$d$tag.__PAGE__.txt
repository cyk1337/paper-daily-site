9:T6af,The work has two main components. The first is the benchmark. The authors build two synthetic fine-tuning tasks, atomic function bindings and compositional routing rules. A pretrained LM is then fine-tuned on datasets containing only fictitious facts, so the supporting fine-tuning documents are the only possible source of the target knowledge. This gives unambiguous attribution ground truth. They then vary one axis at a time: how many documents repeat the same fact, how many total facts are present, whether lexical distractors are added, and related dataset properties.

The second component is algorithmic diagnosis. Token-level attribution analysis shows that causal evidence inside a document is concentrated in a small number of tokens. Standard methods often average or sum scores over the whole document, which dilutes the signal with irrelevant background text. The paper studies two underexplored design choices. First, it replaces cross-entropy with token-level negative log-odds. The motivation is that cross-entropy gradients vanish when the target token is already predicted with high confidence, hiding the most informative evidence. Negative log-odds removes this confidence suppression and surfaces the relevant tokens more clearly. Second, instead of aggregating over all tokens, the method scores a document using only the top-k token attributions. This explicitly matches the empirical observation that evidence is sparse and localized.

Importantly, these changes are tested across multiple gradient-based attribution methods, including TRAK, EK-FAC, and Grad-Dot. The contribution is therefore about a shared bottleneck in the attribution pipeline, not a narrow tweak to one estimator.a:T552,The main empirical result is the dilution phenomenon. The central finding is that training converges to two solution classes. One is effectively single-stage: the second attention layer can be ablated with little or no effect, so most of the sorting logic is implemented without meaningful second-layer participation. The other is genuinely two-stage: both layers matter, and ablating the second layer hurts performance. This second class generalizes almost perfectly to longer sequences.

The mechanistic analysis of the two-stage solution has two main components. First is cross-layer specialization. The two layers are not redundant; they appear to divide labor, especially on cases where adjacent sorted numbers have small gaps. The paper defines the gap as the difference between consecutive sorted elements and argues that small-gap cases are relatively rare at K=16 but become increasingly common as sequence length grows. A model that does not learn to handle these cases robustly can look perfect in-distribution and still fail under length extrapolation. Second is a hinting mechanism. The first layer appears to narrow the set of plausible next tokens or provide a structured intermediate signal, and the second layer then selects among these candidates. As the number of possible candidates grows with input length, this staged procedure is more stable than a flatter one-layer-style selection rule.

The paper also studies why one algorithm emerges instead of the other. A key result is that layer-wise initialization scale can strongly bias training toward the single-stage or two-stage solution.
