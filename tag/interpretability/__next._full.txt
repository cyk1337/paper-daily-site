18:T5be,The method extends prior layer-wise surprisal analysis in two important ways. First, it uses the MECO L2 eye-tracking corpus and splits readers by LexTALE vocabulary proficiency into high- and low-proficiency groups, instead of averaging across readers. Second, it introduces Predictive Depth, a summary statistic for how predictive power is distributed across layers. The point is not only to identify the single best layer, but to characterize whether the predictive mass is concentrated in shallower or deeper layers.

Operationally, the authors take several base LLMs, apply Logit Lens to hidden states from each layer, and compute token-level surprisal layer by layer. They then use those surprisal signals to predict two word-level gaze measures: first-pass gaze duration (FPGD), which reflects earlier processing, and total gaze duration (TGD), which includes rereading and later integration. The central claim is not simply that deeper layers are better, but that the preferred depth profile depends on both reader proficiency and the temporal scope of the gaze measure.

The model choice is sensible for the question. They use base rather than instruction-tuned models because the goal is to probe pretraining-induced linguistic representations, not alignment-modified output behavior. The model set spans Gemma 3, Qwen 2.5, OLMo 2, and Llama 3.1 across multiple sizes, which helps test whether the pattern is family-robust rather than tied to one architecture.19:T5e0,The main findings visible from the full text are fourfold. First, across 12 tested LLMs, lower-vocabulary readers tend to show deeper Predictive Depth for FPGD, meaning that later-layer surprisal better explains their early reading-time behavior. This is consistent with compensatory processing accounts in reading theory, where less proficient readers rely more on broader context. Second, the proficiency gap is much smaller for TGD. Once the measure includes later fixations and rereading, deeper contextual integration appears important for both groups, reducing the between-group contrast. Third, TGD is generally associated with deeper Predictive Depth than FPGD across proficiency groups, which fits the interpretation that the two gaze measures reflect different stages of processing. Fourth, a leave-one-out analysis over texts shows that selecting an internal layer usually gives small but consistent gains over the final layer on unseen texts.

The experimental design is clean in the sense that the same texts, readers, and models are reused while only proficiency grouping and gaze measure vary. The limitations are also clear: the corpus contains only 12 texts of roughly 100–200 words, so external validity is limited; the predictive gains are weak to modest rather than large; and LexTALE captures vocabulary proficiency, not the full space of language ability. The provided full-content excerpt does not include the complete numerical tables, so no exact coefficients are claimed here.1a:T4e4,Activation-Supported Parameter Decomposition represents a target weight matrix W using rank-1 components. Each component has a read direction v_c, a write direction u_c, and a context-dependent gate g_{t,c}(X). The read direction specifies what information is consumed from the input activation, the write direction specifies the output direction being produced, and the gate determines when the component is active at a token position. Pure parameter decomposition is underdetermined because many decompositions can represent the same matrix. ASPD constrains this ambiguity using the model’s actual activation distribution. Instead of optimizing expensive pairwise interventions between all activation features and all parameter components, it uses a shared sparse representation that both defines activation features and gates the corresponding weight components. A local internal reconstruction objective asks the learned components to reconstruct W x at the output of the analyzed matrix, avoiding reliance on final-output effects alone. This differs from activation-only SAE work and parameter-only decomposition by giving each component an explicit read-write interpretation and making these components composable into parameter-level circuits.1b:T570,The dataset is 2WikiMultihopQA, where each item already contains several type-matched candidate entities with short profiles. The pipeline keeps only cases where the model first makes a choice, then—when explicitly asked—names a rejected rival and a missing attribute, and that attribute is indeed absent from the rival profile while being available as a real sentence in a sibling profile from the same item. Repairable attributes include birth date, death date, parentage, and director information. The intervention has five conditions. R0 is an unedited re-ask to verify reproducibility under greedy decoding. R1 appends the relevant fact sentence to the named rival. R2 appends a length-matched irrelevant sentence to that same rival. R3 appends the relevant sentence to a third option the model never mentioned. R4 appends the irrelevant sentence to that unmentioned option. This separates content effects from placement effects. A notable design choice is that the inserted sentence need not be true of the target entity: the tested claim is only that the profile omitted the attribute, so any sentence stating that attribute falsifies the model’s earlier complaint. The paper also spends nontrivial effort on integrity gates, deterministic subject substitution, exclusion of cases where the rejected option is actually the gold answer, and validation of the string-rule pipeline.1c:T5a0,There are three runs: Part A uses three open 7B–8B instruct models with four options; Part B adds three more checkpoints, still with four options; Part C returns to the Part A model roster but uses six options. A useful preliminary result is that contrastive rejections appear spontaneously in only 20.8% of items, but rise to 72.5% when directly elicited, while accuracy stays flat at 68.4% vs 68.2%. So asking surfaces the explanation without materially changing task performance. Another important statistic is that about 32% of specific rejections name a defect that the profile already contains, which immediately limits how literally one should read the model’s stated reasons. The headline result from the largest run is that supplying the named fact at the named rival changes the model’s choice more than a length-matched irrelevant control does, with odds ratio 3.57, 95% CI [1.54, 8.26], Holm-corrected p=0.0210. This supports the claim that the stated reason sometimes does causal work. But the signal is mixed rather than universal. The paper also highlights disagreement between two instruments: free-text choice and forced single-token probability. In one example, adding the relevant sentence flips the model’s final choice, yet the local token probability for that option barely moves and can even be lower than under the irrelevant control. That makes Section 5 important: the two readouts are not interchangeable.1d:T423,The method uses hRoPE, a hierarchical rotary positional encoding. Position is represented as three coordinates: p1 for paragraph index, p2 for sentence index inside a paragraph, and p3 for token index inside a sentence. Each level receives its own independent rotary channel group, so paragraph, sentence, and token displacements are not collapsed into a single scalar. The frequency base for each axis is calibrated from corpus statistics using the 99th-percentile coordinate range plus a safety margin, so low-frequency channels remain non-wrapping over typical ranges. The central experimental move is a counterfactual intervention: keep the tokens and lower-level coordinates fixed, modify only the paragraph coordinate p1, and measure cross-paragraph attention. A density-matched random-label channel with the same architecture is used as a control. This is important because an arbitrary extra positional axis can also compress attention; the diagnostic quantity is therefore not compression itself, but compression depth relative to the random control.1e:T5b4,The paper uses classic Contrastive Activation Addition as a causal probe rather than proposing a new steering method. It compares explicit CoT models and COCONUT-style latent-CoT variants of Llama-3.1-8B and Llama-2-7B, trained on the same ProSQA data, with the latent variants using five continuous thoughts. A task direction is built from contrastive activations, then injected into the residual stream at inference time.

The analysis is carefully split into two parts. First, representation displacement: the authors estimate an independent stance coordinate and measure how far the intervention moves hidden states along that coordinate, normalized by its standard deviation. Second, output response: they evaluate both generation-level steering success with an LLM judge and a judge-free token-level metric, the change in stance margin at the first generation step, computed from target-stance versus original-stance token sets.
