Controllable User Simulation

这篇论文讨论可控用户模拟器的因果有效性问题。常见做法是用完整对话轨迹事后标注一个控制变量，例如“用户很沮丧”或“订票成功但忘记护照号”，再用这个标签训练模拟器生成逐轮用户回复。论文指出，这类标签往往依赖生成训练数据的旧 agent 的未来行为。把它作为推理时的控制条件，会把未来信息泄漏到当前用户行为里，导致模拟器在评测新 agent 时不再服从真实的条件用户分布。

评不是 pretrain 论文，但它把 simulator 评测里的“标签泄漏”讲成了因果偏置；若你做 RL/agent 数据闭环，只看理论部分和 failure case 就够。
Guy Tennenholtz,Ofer Meshi,Amir Globerson,Uri Shalit,Jihwan Jeong,Craig Boutilier
