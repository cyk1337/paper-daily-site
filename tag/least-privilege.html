When Lower Privileges Suffice: Investigating Over-Privileged Tool Selection in LLM Agents

在多工具可用且权限等级不同的 agent 场景里，LLM 往往会选择“权限更大但非必要”的工具（或在轻微失败后过早升级权限）。论文要回答的是：当低权限工具已足够完成任务时，主流 LLM agent 是否具备“最小权限”偏好；这种偏差在什么条件下被放大；以及能否用可操作的训练/对齐手段把它压下去而不明显伤害任务成功率。

评这篇不是 pretrain，但结论对 post-train 很扎实：安全对齐不会自动学会 least privilege，做 tool-use 的团队应直接复现 benchmark 和 failure-induced escalation 设置。
Kaiyue Yang,Yuyan Bu,Jingwei Yi,Yuchi Wang,Biyu Zhou,Juntao Dai,Songlin Hu,Yaodong Yang
