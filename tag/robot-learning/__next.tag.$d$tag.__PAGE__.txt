The two primary axes are scalability and robot alignment. Real-robot data is directly aligned with the platform that produced it and has high physical fidelity, but it is expensive to collect and reset. UMI-style data removes the robot from the collection loop while retaining end-effector-centric manipulation signals, making it more scalable than robot demonstrations and more actionable than ordinary video. Human ego/exo video captures task structure, affordances, and hand-object interaction, but lacks robot-native action labels. Simulation provides controllable state-action trajectories, with transfer limited by assets, task coverage, and sim-to-real gaps. First is the rotational latent action model. The authors keep the inverse-dynamics / forward-dynamics skeleton of latent action models, but replace hard VQ-style quantization with SoftVQ so the latent remains codebook-structured yet continuous. They then constrain the latent action to live on SO(n), representing each action as an n-by-n rotation matrix. Instead of forcing the network to directly output an orthogonal matrix, which would be too restrictive, the model predicts an unconstrained matrix M, computes its SVD M = UΣV^T, and projects it to the nearest rotation matrix. This is a practical compromise: expressive learning dynamics first, geometric structure at the representation layer.

Second is triplet frame learning. Rather than supervising only pairwise reconstruction, the model uses three frames and encodes two consecutive transitions. Because SO(n) is closed under matrix multiplication, the two latent actions can be composed to predict the latent action from the first frame to the third. This is the key idea. The objective does not merely add another frame; it writes compositionality directly into training. If the latent is just a hidden code for the target frame, the composition relation will usually fail. If it captures transition dynamics, the relation becomes natural. In that sense, the triplet objective is a structural regularizer against trivial reconstruction solutions.

On top of the pretrained latent action model, RotVLA attaches a VLM backbone with a flow-matching latent action head to predict continuous latent actions instead of discrete action tokens. During downstream adaptation, the head is extended into a unified flow-matching action head that denoises both latent actions and robot actions. Robot action generation is causally conditioned on latent actions, so the latent space acts as a planner while the robot action head acts as an embodiment-specific executor.
