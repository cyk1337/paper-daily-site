5:Ta28,方法上最关键的是 two-tower 设计。作者从同一个预训练 Nemotron-3-Nano-30B-A3B checkpoint 复制出两份网络。context tower 保持原始 AR 结构并冻结，负责对 prompt 和已提交 token 做因果建模，持续维护每层的 KV cache 以及 Mamba state。denoiser tower 则是可训练的 diffusion 模块，针对当前待生成 block 的 [MASK] 初始化序列做 T 步迭代去噪。

生成过程是 block-wise autoregressive。序列被按块生成：过去块一旦“提交”，就进入 context tower 的干净历史；当前块在 denoiser 中反复细化，直到 token 变干净后再提交。这样既保留了跨块的 AR 因果结构，又允许块内并行生成。

架构创新主要有四点。第一，layer-aligned cross-attention。denoiser 的第 i 层直接访问 context tower 第 i 层的表示，而不是只读最后一层 hidden state。作者的理由很直接：两塔从同一 checkpoint 初始化，同层表示处在相近抽象层级，逐层对齐比“末层广播”更自然，也让 denoiser 在不同深度都能拿到条件信息。第二，块内 bidirectional attention。当前 noisy block 内部取消因果 mask，使 token 彼此双向可见；但对过去 clean blocks 仍保持因果约束。这让 denoiser 更像条件填空器，而不是被迫按 AR 方式在块内单向传播。第三，time conditioning。作者把图像 diffusion transformer 常用的 adaLN-single 引入语言去噪器，用 timestep 生成 scale/shift/gate，对每层做调制。额外参数只有约 1.5M，在 30B 骨干上几乎可以忽略，但能显著改善采样质量。第四，Mamba 层的条件接入。attention 层通过 cross-attention 读 context KV；Mamba-2 层则用对应 context tower 的 Mamba state 作为初始状态。也就是说，两塔的耦合不只发生在 attention 子层，而是覆盖了混合骨干里的两类主要计算单元。

论文还讨论了几个设计取舍。作者测试了 parameter-free 的 bidirectional Mamba：同一组预训练 Mamba 权重分别做左右两个方向扫描，再平均输出。这个设计几乎不增参数，但会把 SSM FLOPs 近似翻倍。实验显示收益很小，所以最终保留 causal Mamba，只在 attention 上做双向块内建模。MoE routing 基本沿用骨干已有机制，噪声感知主要通过 adaLN 调制进入专家路由前的表示，而不是重写路由器。推理时只有 context tower 维护跨块 cache，因此序列长度相关内存与 AR 基线同阶；额外成本主要是固定的第二塔权重和当前块去噪计算。6:Tac7,The central idea is a two-tower architecture built from two copies of the same pretrained Nemotron-3-Nano-30B-A3B checkpoint. The context tower is frozen and remains a causal AR model over the prompt and previously committed tokens. It maintains per-layer KV caches and final Mamba states. The denoiser tower is trainable and performs masked diffusion over the current block, starting from a block of [MASK] tokens and refining it over T denoising steps.

Generation is block-wise autoregressive. Past blocks are committed and become clean causal context. The current block is refined in parallel inside the denoiser. Once the block is sufficiently clean, it is committed, the context tower consumes it causally, and generation moves to the next block. This preserves AR structure across blocks while enabling parallel generation within a block.

There are four notable design choices. First, layer-aligned conditioning: denoiser layer i attends to context-tower layer i, rather than conditioning only on the final hidden state. Since both towers start from the same pretrained checkpoint, same-depth layers are expected to live at similar representational levels, making aligned cross-attention a sensible pairing. Second, bidirectional attention inside the noisy block: tokens under refinement can attend to one another without a causal mask, while still attending causally to past clean blocks. This turns the denoiser into a conditional infilling module rather than a left-to-right decoder. Third, timestep conditioning via adaLN-single: the denoiser is modulated by the diffusion timestep using scale/shift/gate parameters generated from t. The added parameter cost is tiny, about 1.5M on top of the 30B backbone, but it improves sampling quality. Fourth, Mamba-state conditioning: attention layers consume context KV caches, while Mamba-2 layers are initialized from the corresponding context-tower Mamba states. So the coupling spans both attention and state-space components of the hybrid backbone.

The paper also studies design trade-offs. A parameter-free bidirectional Mamba variant is tested by running the same pretrained Mamba weights left-to-right and right-to-left and averaging outputs. It nearly doubles SSM FLOPs and yields only marginal gains, so the final model keeps Mamba causal and uses bidirectionality only in attention. MoE routing is inherited from the backbone, with noise awareness entering through timestep-conditioned activations rather than a redesigned router. At inference time, only the context tower keeps sequence-length-dependent cache state across blocks, so cache scaling remains comparable to the AR baseline; the extra cost is mainly the fixed second tower and the iterative denoising compute for the current block.7:T7ff,The experimental story has three main parts. First, this is a large-scale validation rather than a toy setup. The backbone is Nemotron-3-Nano-30B-A3B, a 52-layer hybrid model with 23 Mamba-2 layers, 6 self-attention layers, and 23 MoE layers. TwoTower is trained on top of this 30B-class model with about 2.1T additional tokens, compared with roughly 25T tokens used to pretrain the original backbone. So the work is not retraining a diffusion LM from scratch; it is converting a strong AR asset into a diffusion-capable generator with a moderate extra budget.

Second, the key result is the quality-throughput trade-off. The model retains most of the AR baseline’s quality while delivering substantially higher decoding throughput. The mechanism is important: at the default operating point, the model commits multiple tokens per refinement step early in decoding, rather than advancing by exactly one token as in AR decoding. The wall-clock gain therefore comes from block-wise parallel progress, not from lower per-step complexity alone.

Third, the ablations support the final recipe. Timestep conditioning improves sampling quality. Layer-wise aligned conditioning is better motivated than using only the last hidden state, and the paper presents it as a meaningful architectural choice rather than a cosmetic one. Bidirectional Mamba brings only small gains relative to its extra FLOPs, which justifies the final decision to keep Mamba causal. Another useful engineering takeaway is that a frozen context tower is already strong enough to provide the conditional signal; most of the extra training is spent on learning how to denoise given AR representations, not on relearning language knowledge.
