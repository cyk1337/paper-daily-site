The recurrent backbone follows the HRM-Text line and contains two separate stacks, L and H, each with 16 Transformer layers. Parameters are shared across invocations within each stack, but not between L and H. In the default H2L3 schedule, each L or H symbol denotes a full module call, so a model that stores only two 16-layer stacks performs 128 Transformer-layer calls in one forward pass. The model combines module-level recurrence with model-level recurrence over a unified vision-language state. Visual tokens use 2D spatial RoPE, while text tokens are assigned synchronized 2D coordinates that behave like standard 1D RoPE. The architecture alternates intra-segment attention with abstract-mediated communication: patch tokens interact mainly within their segment, while cross-segment information flows through the abstract-token channel. This avoids dense patch-to-patch attention over all frames. A lightweight selector controls the downstream interface, exposing either abstract-only tokens or abstract tokens plus top-K patch tokens.
