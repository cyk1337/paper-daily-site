1a:T78b,ViGOS explicitly decomposes the student output into two stages: a visual description first, then reasoning plus final answer. The supervision is decomposed accordingly. The visual-description segment is supervised by an image-only perception teacher, which has access to the image but not the reference answer. This forces token-level targets in the early segment to be grounded in visual evidence. The later reasoning and answer segments are supervised by a privileged reasoning teacher that can see the reference answer, but only after the student has already produced the visual description. This preserves answer-guided dense supervision where it is useful, while preventing privileged information from directly shaping the early perceptual claims.

The method also uses a reference teacher for invalid rollouts. The rationale is practical: once the student trajectory has drifted into an invalid format or broken task constraints, continuing segmented on-policy supervision may amplify noise. The reference teacher is then used to restore output structure and reduce format drift. This is a stability-oriented compromise between strict on-policy learning and controllable supervision.

A notable aspect is that the paper does more than prompt the model to “describe before reasoning.” It changes the supervision graph of OPSD so that different token spans are scored by teachers with different information access. The paper also introduces PALR, the Privileged Answer Leakage Rate, to quantify how much of the teacher correction on a fixed student rollout is attributable to the privileged answer rather than the image. The point of PALR is not a single headline number, but a way to make shortcut risk analyzable. Relative to vanilla OPSD, the main innovation is teacher-context assignment rather than a new loss. The central empirical result is that ViGOS largely retains the benchmark improvements of vanilla OPSD on standard tasks, while performing better on prior-sensitive evaluations where genuine image dependence matters.

The most informative ablations are the obvious ones. First, a direct comparison against vanilla OPSD tests whether the shortcut problem is real in practice. Second, removing the image-only perception teacher checks whether privileged supervision alone causes the model to regress toward weaker grounding. Third, removing the explicit visual-description interface probes whether the benefit comes from staged supervision or merely from output templating.
