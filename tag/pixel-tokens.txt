18:T7cc,The method has three main components. First, Pix Token Embedding. Each RGB pixel value is mapped to a discrete token id. With 8-bit RGB, the theoretical vocabulary is about 256^3 possible pixel values, plus padding. Each pixel value gets its own learnable embedding, and an image is flattened into a sequence in raster order. This sequence is then fed into the same generative model that also handles text tokens. The authors argue that this is closer to token-based language modeling than ViT patch embeddings, because ViT patch tokens are produced by projection rather than by a discrete vocabulary with dedicated embeddings.

Second, Color Folding. A direct 256^3 vocabulary is too expensive in both embedding parameters and output classification. To make the setup trainable, the paper introduces a color-space folding scheme that reduces the number of distinct pixel tokens while preserving the pixel-level formulation. This is effectively a hand-designed color quantization mechanism built into the tokenizer. It differs from learned visual tokenizers because it does not learn a codebook from data; it compresses the RGB space structurally.

Third, Global Conditional Attention Approximation. Since a pixel sequence has length H×W, full self-attention is prohibitively expensive. The paper proposes an approximate attention mechanism intended to let long pixel-token sequences participate in contextual modeling at manageable cost. From the available full text, this looks more like an engineering approximation for long-sequence attention than a fundamentally new attention formulation.

The paper also includes image unsupervised pretraining, where the model is trained directly on image data to learn pixel patterns before broader multimodal use. Relative to mainstream approaches, the key distinction is clear: this is neither vision-encoder-plus-LLM nor learned-discrete-visual-tokenizer-plus-AR-transformer.
