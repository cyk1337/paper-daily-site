WaveFilter: Enhancing the Long-Context Capability of Diffusion LLMs via Wavelet-Guided KV Cache Filtering

这篇工作处理的是 diffusion LLM 在长上下文推理中的一个效率瓶颈。DLM 由于要做多步迭代去噪，推理成本本来就高；一旦上下文变长，KV cache 虽然能减少重复计算，但缓存本身会迅速膨胀，已有方法在长文本场景里常出现两类问题：要么保留太多 token，吞吐下降明显；要么压得太狠，关键信息丢失，生成质量下滑。论文要解决的核心问题是：在 DLM 的长上下文推理里，如何以训练外、低开销的方式，从超长 KV cache 中更准确地筛出对当前去噪步骤真正重要的 token。

评读 Fig/ablation 就够；若只是在长上下文上调 cache 过滤阈值，价值会低于题名暗示。
Jinnan Yang,Yan Wang,Zhen Bi,Kehao Wu,Xiaojie Li,Jungang Lou,Zechao Li,Jing Liu
