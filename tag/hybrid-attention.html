Morphing into Hybrid Attention Models

现有将预训练Transformer转换为混合注意力架构（部分层保留全注意力，其余替换为线性注意力）的层选择方法存在三类缺陷：一是固定排布规则忽略预训练模型各层的功能异质性；二是逐层单独扰动/替换的打分方法，未考虑全局混合配置下的层间依赖——功能相关层联合转换会放大性能退化，功能重叠层同时保留会带来收益递减；三是逐层打分需要多次单步扰动，选择开销高，难以扩展到深层大模型。该问题本质是预算约束下的组合子集优化，现有启发式方法均未有效处理。

评只看方法和消融即可；它把 hybrid 层选择从局部打分改成全局组合搜索，这个 setup 比常见规则更干净。

HydraHead: From Head-Level Functional Heterogeneity to Specialized Attention Hybridization

这篇论文解决的是长上下文模型中 full attention 和 linear attention 如何混合的问题。常见 layer-wise hybrid 按层替换注意力机制，但层级粒度太粗；作者观察到同一层内部不同 attention heads 的功能差异很大，尤其是长上下文精确检索只依赖少数关键 heads。因此，更合理的混合单位可能是 head，而不是 layer。

评这篇值得看，因为它把 hybrid attention 的设计粒度从 layer 改到 head，确实可能改变你做长上下文架构搜索的 prior；先看分析图和 ablation，别先信总分。

ConSA: Controllable Sparsity in Hybrid Attention via Learnable Allocation

这篇论文解决的是混合注意力结构中 FA/SWA 如何分配的问题。已有 Mistral、Gemma 2 一类模型多用手工交错规则，LoZA 一类方法用校准分数再排序，但都很难在给定稀疏率下稳定找到合适的层或头分配。ConSA 把问题改写成带约束的离散结构搜索：在指定 SWA 占比时，学习每个层或 KV-head 应该保留 full attention 还是改成 sliding-window attention。

评不是范式突破，但把 hybrid attention 从拍脑袋规则改成可学习约束优化，这点很实用；只看 learned pattern 和 head-wise ablation 就够。
