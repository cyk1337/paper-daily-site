Cache geometry (layer count, sequence length, dtype) is held fixed across arms, and only the content is replaced. Six arms are defined: True (cache from the paired example), Deranged (cache from a different example in the same batch via a fixed-point-free permutation, preserving the marginal cache distribution exactly), Zero (all entries zeroed), Random (Gaussian entries moment-matched per example, layer, and K/V tensor to the true cache), Intact-no-private (sender processes the example with private facts replaced by irrelevant counterparts, used only in the calibrated regime), and Direct-text reference (private information passed verbatim to the receiver). Tasks are split into two regimes: a calibrated regime with procedurally generated sender-private facts unrecoverable by the receiver, and a natural regime using standard benchmarks (GSM8K, ARC-Challenge, MedQA) where the receiver can solve alone. The proposed Orthogonal Backfill (OBF) compensates for this by extracting a low-rank residual from the discarded KV states and injecting it into the retained KV states.

Conceptually: (i) choose which KV tokens to keep (any eviction/importance policy can be plugged in); (ii) compute a low-rank residual representation of the discarded states, with an orthogonality/de-correlation constraint relative to the retained subspace to avoid simply duplicating what is already preserved; (iii) “backfill” this orthogonal residual into the kept KV tensors so that the transmitted cache carries extra information in its vector values while keeping the same number of cached positions (i.e., no extra communication length).
