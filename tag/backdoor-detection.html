SpecGuard: Inference-Time Backdoor Detection For Free

这篇工作处理的是一个很实际的部署安全问题：当服务方拿到第三方微调、适配器或频繁更新的 LLM 时，即便做过离线审计，模型仍可能在上线后因某个隐藏触发器而激活后门。难点不在于“能不能检测”，而在于“能不能在推理时持续监控，而且几乎不增加服务成本”。已有运行时方法要么依赖触发器形式假设，要么需要额外生成、输入扰动或辅助模型，和低时延 serving 的要求冲突。SpecGuard 的核心问题就是：能否直接利用推理栈里已经存在的信号，在 query 级别检测后门激活，而不增加额外 target-model 计算。

评巧妙利用推测解码（Speculative Decoding）中 target 和 draft 模型的接受率差异来做后门检测，白嫖了推理加速的副产物，思路很清奇。

ToxScreen: Detecting Whether an LLM Has Been Poisoned

评读设定和数据构造即可；它把后门检测从玩具触发器拉到更干净的威胁模型，适合做安全回归集。
