How LoRA Remembers? A Parametric Memory Law for LLM Finetuning

这项工作想回答一个更可量化的问题：LoRA 到底能把多少精确文本写进参数里，以及这种“逐字记忆”在训练和解码时如何失效。它把问答中的 question 当作 key，把 answer 当作需要写入的内容，只在 answer token 上计算 loss、token accuracy 和 exact match，从而尽量剥离理解、检索和指令跟随因素。

评定量分析 LoRA 记忆容量的机制研究，p > 0.5 的相变结论有趣，对理解微调动态有启发，建议看 §4 的相变分析。
