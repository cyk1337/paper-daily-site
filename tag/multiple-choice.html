Stuck on "A": Diagnosing and Repairing Interface Injury in Attention-to-KDA Linearization of a 0.6B Language Model

这篇工作研究的不是“线性化能不能把困惑度做回来”，而是“把全注意力 LLM 改造成 KDA 线性注意力后，究竟坏在什么地方”。作者把 Qwen3-0.6B-Base 的 28 层里 21 层替换成 KDA，发现即便通过逐层 hidden-state 对齐和端到端 KL 蒸馏，语言建模损失已经接近教师，多项选择能力却仍接近随机。全文给出的核心诊断是：模型未必丢了全部知识，而是损伤了把内部知识映射到选项接口上的能力，也就是论文所说的 interface injury。这个问题比一般的“能力退化”更细，因为标准 CE / PPL / KL 指标几乎看不出来。

评这篇不是看 KDA，而是看 failure analysis：PPL/KL 好看不代表接口没坏，做架构替换或蒸馏时应立刻加这种 option-rotation 诊断。
Ronglong Bao

The Hard Decision Layer: Evidence for Committed Inference in Transformers

这篇工作要回答的问题很具体：Transformer 在做多项选择推断时，究竟在哪一层“把答案定下来”。已有 early exit 或 layer pruning 工作更多是在做外部控制，或者事后裁剪；这篇文章关心的是模型内部是否天然存在一个稳定的决策边界。作者在 MCQA 场景下提出 Hard Decision Layer（HDL）：从这一层开始，候选答案的相对排序会突然稳定，后续层主要是在放大已有偏好，而不是继续改写答案次序。论文试图说明，这不是 learned router、不是微调副产物，而是标准 Transformer 推理过程里可重复观察到的结构性现象。

评这是个值得带着怀疑去看的机制 paper：若 HDL 定义和基线干净，它会改变你对“后层都在持续推理”的直觉；先看层间排名稳定性的图和微调不变性实验。
Ashwath Vaithinathan Aravindan,Mayank Kejriwal
