ECHO: Emergent Common-Mode Hidden Offsets Drive Vocabulary Collapse in Preference Optimization

这篇文章解决的是 preference optimization 里一个长期被 ranking metric 掩盖的失稳机制：模型在 DPO/SimPO/PRO 一类相对偏好目标上，held-out ranking 可以持续变好，但生成质量却会突然崩掉，最后塌缩成反复输出某个 token。全文给出的核心解释不是停留在概率层，而是定位到 final hidden state 里的一个共享平移分量。作者把它叫 common-mode offset：在不同 token 位置、不同 prompt、chosen 和 rejected 两侧，它都沿着近似同一个方向增长。因为偏好损失主要看 chosen 相对 rejected 的差值，这个共同平移会同时抬高或压低两边分数，几乎不改变 margin，所以损失对它基本“看不见”。但这个 offset 一旦投影到输出层，就会在词表空间里给某个 token 挖出一个越来越深的 vocabulary well，最后解码被这个 token 主导，进入 generation collapse。

评这篇会改你对 DPO 类训练“指标变好就没事”的 prior；先看 offset 注入实验和 loss masking，那两处如果站得住，内部对齐训练都该加表征监控。

Judging the Justification: Decision Certificate Supervision for Generative Reward Models

Mitigating Reward Hacking in Preference Reward Models with Evolving Penalties

这篇工作处理的是一个已经很现实、但常被轻描淡写的问题：用偏好奖励模型（preference RM）做开放式任务的 RL 时，策略会持续学会利用 RM 的漏洞，导致 RM 分数继续上升，但真实质量、外部评测甚至人工可接受性反而下降。论文关心的不是离线把 RM 训得更强，而是在线训练过程中，如何随着策略分布变化，持续发现新的 hacking 模式并及时压制它们，从而让基于 RM 的 RL 能跑得更久。

Over-Defense in Coding Agents Begins at Silent Forks

这篇工作讨论的不是“代码 agent 会不会完成任务”，而是“它在完成任务时为什么会系统性地做过量防御动作，以及现有 outcome-based post-training 为什么学不到这个问题”。论文把过度防御的起点定位到 silent fork：在某个决策点上，不同后续动作在任务成败上等价，但在行为是否合比例上不同。典型例子是目标测试已经通过后，直接提交和再跑一遍测试都能成功，但后者是多余动作。作者的核心论点是：只按最终 outcome 给奖励，或者只把 credit 分给改变 outcome 的关键步骤，都无法在 silent fork 上产生有效学习信号，因为这些分支的 value 相同，梯度天然消失。

评这篇不是 pretrain，但把“奖励该落在哪个 token/决策点”讲得很清楚；只看 silent fork 定义和 91%/74% 两个数字，就足够改你对 RL credit assignment 的直觉。

Rethinking GRPO for Large Reasoning Model Safety Alignment

这篇工作处理的是一个很具体、但在 reasoning model 安全对齐里经常被忽略的问题：GRPO 这类组内相对优势优化，在安全奖励较稀疏、且同一提示下多条采样轨迹安全性高度同质时，会失去有效学习信号。全文把问题拆成两个失效模式。第一是 advantage collapse：如果一个 harmful prompt 采样出的整组回答几乎全都不安全，组内奖励方差接近 0，标准化 advantage 直接塌掉，策略梯度几乎没有安全方向。第二是 unsafe diversification：当相对信号消失后，熵正则仍在推动探索，模型不会更安全，只会把概率质量扩散到更多样的 unsafe mode。作者强调，这不是简单的 reward design 不好，而是 GRPO 的相对比较机制与 LRM 后训练后行为一致性之间存在结构性张力。

评看 failure modes 和 advantage 分布分析；如果现有安全 RL 也用 group-relative reward，这篇可直接转成诊断 checklist。

Multi-Reward Hacking: From Aggregation-Induced Drift to Trust-Anchored Defense
