a:T718,STAGE is not a new reward model and not a new PPO or DPO loss. It is an active-set controller wrapped around PPO. The method has four main components. First, cumulative retention: at stage k, only the active set P_k contributes to the scalar reward, but once an objective is admitted it remains active in all later stages. This differs from strict sequential curricula that drop old objectives when moving to a new one. Second, probing-based ordering: before the main run, the method performs a short probing phase with all preference dimensions active. It measures early reward gain and volatility for each dimension, then defines a difficulty score that favors low gain and high variance, producing a hard-to-easy admission order. In the paper’s example, creativity, reasoning quality, and numerical sensitivity fall into the harder cluster, while helpfulness, clarification, QA behavior, and ethical compliance are easier. Third, stability-guided admission: within each stage, the controller tracks the batch-mean normalized reward for every active objective and its running maximum within that stage. The gap between current reward and stage-best reward defines a deviation signal, which is then aggregated over a window. A new objective is admitted only when recent deviations are small enough, or when a patience budget is exhausted. The goal is to avoid introducing a new conflicting objective before the current active set has stabilized. Fourth, adaptive weighting: within the active set, weaker objectives receive more weight so that easy or already-strong dimensions do not dominate the PPO reward. 缓解方法是 Rubric Dropout。训练时对每个 prompt 的 rubric，随机丢弃一部分 criterion，再用剩余 criterion 计算 reward。这样策略在不同 step 面对的是不断变化的子 rubric，无法稳定利用某个固定 criterion，尤其是那些跨 prompt 重复出现的模板化 criterion，比如“结构清晰”“语言明确”。这个设计的优点是简单：只改 reward function 一行，不增加 judge 调用次数，只有一个超参数 f，即 dropout fraction。

作者还把 Rubric Dropout 与 POW3R 风格的 criterion reweighting 做了对比。后者试图按训练 usefulness 重加权 criterion，但在这里反而更容易把优化压力集中到少数可利用 criterion 上，因此可能加剧 hacking。全文实验也支持这一点。16:T866,The method has two parts: an in-loop measurement protocol and a mitigation.

The cross-family choice is important because it reduces the chance that the observed gap is just shared bias. If the proxy judge were merely biased, the gold curve would be shifted but not necessarily turn downward while the proxy keeps improving. The mitigation is Rubric Dropout. At each training step, a random fraction f of the rubric criteria is dropped before computing reward. The policy therefore never sees exactly the same rubric twice, which makes it harder to exploit any fixed criterion, especially generic templates repeated across prompts such as “well-organized” or “clear language.” The appeal is operational simplicity: one line in the reward function, one hyperparameter, and no extra judge calls.

The crucial systems detail is GRPO compatibility. In GRPO, multiple rollouts for the same prompt must be scored on a comparable basis. If each rollout were graded with a different sub-rubric, the group-relative advantage would be corrupted. The paper solves this with group-shared masking: one dropout mask per rollout group. The appendix shows that under this scheme the reward normalizer cancels out of the advantage, and before group standardization the main effect of dropout is to rescale expected advantage while acting as a variance regularizer against updates that rely too heavily on any single criterion. That makes the method more than just noise injection; it is a targeted way to reduce overfitting to exploitable proxy features.

The paper also compares Rubric Dropout with POW3R-style criterion reweighting. The argument is that reweighting can inadvertently concentrate optimization pressure on a smaller set of exploitable criteria, which may worsen hacking rather than reduce it. It uses a generative reward model only for relative preference ranking, then derives scalar rewards from the resulting order. The first mechanism is self-competitive ranking: for a given prompt, multiple responses sampled from the current policy are compared against each other, and their relative order is mapped into rewards. This aligns naturally with group-relative policy optimization. The second mechanism is anchor-guided ranking: a small set of anchor responses serves as reference points, and candidate responses are compared against these anchors. This reduces the reward-model call pattern for larger candidate sets from a sorting-style O(m log m) regime to O(m n), where m is the number of sampled responses and n is the number of anchors. When n is small, this is more scalable. Unlike GenRM-style preference-token probabilities, RRC does not rely on a single token probability. Unlike approaches that suppress reasoning and emit only labels, it can preserve the generative judge’s textual reasoning process.1a:T584,CVPO has two components.
(1) Trajectory level: Value-Variance Adaptation. A value model estimates token-level V(s_t) along each generated trajectory. The variance of these values (or a closely related advantage-variance proxy) is used as an intrinsic randomness / exploration indicator: high variance implies more exploratory, low variance implies rigid generation. The paper sketches a bound showing the policy-gradient norm can be upper-bounded by a term involving advantage variance under a bounded ∥∇ log π∥ assumption, motivating variance-aware control of update magnitude. Based on this, CVPO modifies advantage computation by scaling/reweighting trajectories according to their value-variance, with different handling for different reward types (e.g., sparse correctness vs denser rewards), aiming to extract more informative gradients from otherwise homogeneous outcomes.
(2) Prompt level: Dynamic Curriculum Learning. It maintains a moving estimate of prompt difficulty and dynamically reweights/samples prompts to counter difficulty drift, allocating more training budget to prompts that remain challenging at the current stage.

First, policy decomposition. For N rewards, PRISM does not train one policy to maximize all of them jointly. It trains N positive policies, each dedicated to one reward, plus one global negative policy that captures undesirable behavior across rewards. The design choice is deliberate: desirable behavior is often reward-specific, while failure modes can often be pooled under a shared “do not do this” branch.

Second, efficient parameter sharing. PRISM does not instantiate N+1 separate full models. It uses one shared LM and conditions different sub-policies with different prefix tokens. This keeps training and serving practical while preserving a shared representation backbone.

Third, policy composition. At rollout and inference time, PRISM combines sub-policies by taking a weighted sum of their logits, producing a mixture policy. The merge weights become an explicit preference-control interface. Unlike reward weights, these coefficients act on already-optimized policy distributions rather than on raw reward scales, which is the authors’ main argument for improved robustness and interpretability.

Optimization is built on GRPO. Each reward mainly updates its corresponding positive branch, while the negative branch absorbs failure signals across rewards. Relative to linear scalarization, adaptive reward weighting, or constrained/Lagrangian formulations, the novelty is not in the policy-gradient estimator but in moving composition from reward space to policy space.
