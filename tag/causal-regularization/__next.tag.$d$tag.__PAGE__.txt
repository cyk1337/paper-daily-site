9:T4c8,1) Causal graph: define a DAG with prompt X, response Y, latent intent W (a sufficient statistic of prompt intent), latent artifact Z (context-free factors, assumed independent of X/W), and reward R. The goal is to strengthen the causal influence W→R rather than merely blocking artifact→R.
2) Anti-causal representation learning: assume an additive decomposition y = f(w) + g(z) in embedding space. With multiple responses per prompt, shared components are attributed to intent, while idiosyncratic artifacts vary and cancel in expectation.
3) CARP + SAS: extract a sparse code u from response embeddings via an SAE-style encoder u = TopK(P y). Train a prompt decoder x̂ = L u + b to reconstruct the prompt embedding from u. The reconstruction quality defines a Semantic Alignment Score (SAS), intended to capture prompt-dependent information.
4) SAS-regularized RM: incorporate SAS as a regularizer in pairwise RM training so the RM prefers features predictive of the prompt embedding, suppressing prompt-independent shortcuts.
5) Theory: Theorems (1/2) argue SAS isolates intent-related components while compressing artifact influence under the stated assumptions (multiple responses per prompt, independence,
