SeDeM: Selective Decompression of Hidden-State Memories for Long-Context Question Answering

这篇工作解决的是长上下文问答里的一个结构性问题：现有 context compression 方法虽然能降低 prefill 和 KV cache 成本，但很多 soft compression 方案把“压缩存储”和“解码条件”绑在同一组 memory token 上，导致高压缩率下信息容易漂移，decoder 也被迫直接从过于紧凑的记忆槽里生成答案。作者要做的是把这两件事拆开：先把上下文压成可复用的 query-independent memory，再只对与问题相关的 memory 做选择性解压，把恢复后的 hidden states 注入 decoder 中间层，而不是让 decoder 直接吃压缩后的 memory token。
