Maglev: Sliding Recurrent Memory

这篇工作处理的是长上下文语言建模里一个老问题：全注意力 Transformer 记忆能力强，但推理成本随上下文增长；滑窗注意力推理便宜，但没有真正的长期记忆；传统 recurrent/SSM 虽然有固定状态，但更新形式受限，且往往难以兼顾 Transformer 的非线性表达和大规模并行预训练。作者想要的是三件事同时成立：每个 token 都能写入一个可持续的潜在记忆；推理时记忆大小固定、KV cache 有界；训练时仍然能像普通 Transformer 一样并行。Maglev 的核心问题就是如何在不做顺序展开训练的前提下，得到一个 token-wise、非线性、可部署的 recurrent Transformer。

评train-full/deploy-recurrent的蒸馏思路不新，但memory consistency对齐设计和预训练benchmark对比值得看§3方法和§4实验，关注是否在长上下文上真正缩小与全注意力的gap。

PI-Mem: Pushing Long-Context Reasoning to 3.6M Tokens with Parallel-Iterative Memory

这篇工作处理的是超长上下文推理里的一个老问题：基于 recurrent memory 的方法虽然把计算从全局注意力里解放出来，但它们通常按 chunk 串行更新 memory，早期证据容易被后续无关内容覆盖，而且延迟会随 chunk 数线性增长。PI-Mem 试图同时解决这两个问题：既减少 memory overwrite，又把跨 chunk 处理改成并行。

评读方法图和 RL 退出奖励即可；若 3.6M 评测不是合成检索题，这会影响长上下文预训练预算判断。
