Trace as State: Reasoning Traces as Conditional States for Long-Context Transformers

这篇工作处理的是长上下文 Transformer 的一个结构性限制：模型按因果顺序读入上下文，但很多任务所需的“任务状态”是在读到后面时才确定的，于是这些后验得到的状态无法反过来影响前面 token 的表征。作者把这个问题形式化为 conditional state update task：如果条件 z 先给，处理器只需沿着一条已知状态轨迹更新；如果条件 z 后给，处理器在最坏情况下需要保留“所有可能条件下序列会如何作用”的信息，内存需求可出现指数级差距。基于这个分析，论文提出把第一遍推理得到的 reasoning trace 当作任务状态的文本代理，在第二遍中放到长上下文之前，让模型带着状态重读上下文，而不是像常规做法那样把 trace 接在上下文后面。

评这篇会改变我对长上下文失败的归因：先复现 Trace Append 对照，确认收益来自状态前置而非多一次思考。

TwinKV: A Composable Repair Pass for KV Cache Eviction via Pairwise Key Redundancy

这篇工作处理的是长上下文推理里的一个老问题：KV cache 太大，必须做 eviction，但现有方法大多默认“被高注意力看到的 token 更重要”，或者用“离全局 key 均值更远”来近似重要性。论文先用 leave-one-out 因果探针直接检验这个前提，发现 attention magnitude 与 token 对最终答案的真实边际贡献几乎不相关，在其长文问答设定上 Spearman ρ = -0.004，p = 0.96。也就是说，很多 eviction 方法依赖的打分信号并不对应真正的因果必要性。作者因此把问题改写为：在固定预算下，怎样识别“删掉后还能被上下文中其他位置恢复”的冗余 token，并用这个结构性信号修补已有 eviction 决策。

评只看 leave-one-out probe 和 TwinKV swap 规则；attention 分数近似无因果信号这个数值得在内部长上下文压缩里复验。
Hong Chen,Yudong Zeng,Yongwei Huang,Zuhao Ouyang,Junyan Zhang,Xuming Hu

Evaluating Language Models in Realistic Conversational Contexts

这篇工作要解决的不是“模型会不会聊天”，而是“怎么把长对话评测做得可信”。现有对话评测大多沿用摘要、翻译、短问答里的指标，偏向词面重合、事实正确或单轮偏好判断，难以覆盖多轮对话里更关键的性质：语气是否稳定、角色是否一致、上下文是否延续、回答是否自然推进任务。作者指出，很多近年的对话评测又依赖 LLM-as-a-judge 或合成数据，这会把评测误差、分布偏差和数据泄漏问题一起带进来。UPHELD 的核心目标，是构造一个以真实长对话为中心、带密集人工标注、能专门检验 conversational coherence 的评测基座。

评如果你做对话后训练或 judge，这套数据值得收；若你做 pretrain，只需看 benchmark 设计和人类标注协议，不必细读全部指标表。
Ilija Subasic,Andrew Rabinovich,Zhao Chen

DEEPCHART: How Far are LLMs from Faithful Data-Science Chart Generation?

这篇工作评测 LLM 在真实数据科学场景中生成忠实图表的能力。难点不在于画出看起来合理的图，而在于从长文档和多模态报告中抽取分散证据，计算图表所需的派生量，再把这些数值准确渲染出来。错误的抽取或计算可能被最终图表外观掩盖，形成 hidden hallucination。

评这不是预训练论文，但评测拆得干净；只看任务分解和错误归因，能帮你判断长上下文模型到底坏在检索、计算还是渲染。
Jiahui tang,Kuicai Dong,Dexun Li,Hongchao Gu,Haocheng Yu,Wei Han,Chen Zhang,Yong Liu,Hao Wang,Enhong Chen
