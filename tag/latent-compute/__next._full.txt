18:Tb27,方法名叫 Hidden Decoding。核心做法是把原始序列中的每个 token 沿 sequence 维度扩展成 n 个 stream，然后在一次标准前向里处理这条更长的序列，但只对最终 stream 施加 next-token loss。这样，中间 stream 提供的是“隐藏计算”，不是额外可见 token。它和 chain-of-thought 或 test-time visible reasoning 的区别在于：额外计算发生在隐状态里，不增加训练目标里的显式文本监督。

这套设计有两个关键点，缺一不可。

第一，per-stream embedding replication。若只是简单复制同一个 token n 次，多个 stream 的初始状态几乎相同，模型很难学出有分工的内部计算。作者为每个 stream 复制一套词嵌入表，把 token x_i 扩成 (E1(x_i), E2(x_i), ..., En(x_i))。continued pretraining 过程中，这些 embedding table 会逐渐分化，让不同 stream 承担不同的表示角色。这个设计很像给“同一个 token 的多步内部思考”提供不同起点，否则 sequence expansion 很容易退化成重复计算。

第二，persistent intermediate KV。此前一些 length-scaling 方案，比如 PHD，为了不让推理成本爆炸，会把中间重复 token 的 KV 设为 transient，只在当前 token 内部起作用，不作为后续位置的上下文保留。这样虽然便宜，但中间计算不能跨位置积累，能力上更像局部 refinement。Hidden Decoding 反过来保留所有 stream 的 KV，让前面位置在中间 stream 上形成的计算结果，能被后面 token 继续访问。作者认为，只有这样，中间 stream 才不只是“当前 token 的额外层数”，而是能形成真正可持续的 latent computation。

问题随之而来：如果对 nL 长序列做全连接注意力，成本会从原来的 O(L^2) 变成 O(n^2 L^2)，在长上下文和大模型上不可接受。为此论文提出 Stream-Factorized Attention。做法是把跨 stream 的信息交换限制在少数层：大多数层只在各自 stream 内做注意力，只有少数“交换层”允许 stream 间通信，而且这些层沿用 base model 原本的注意力模式，比如 sliding-window 或 full attention。这样，绝大多数层避免了对整个 nL 序列做稠密注意力，额外成本更接近对 n 的线性增长，而不是平方增长。

从建模角度看，这个方法和 recurrent-depth Transformer 的差异很明确。looped 模型是在深度维度重复使用同一组 block，计算图有显式回环；Hidden Decoding 则把额外计算摊平到序列维度，仍然保持一次标准前向，因此天然兼容现有的并行训练栈。和普通 token repetition 也不同，它不是把重复 token 当作可见上下文噪声，而是通过独立 embedding、持久 KV 和受控跨 stream 交互，把重复位置变成内部计算槽位。19:T7e9,实验分两部分，分别验证“能否扩到大规模”和“扩展因子 n 是否形成新的 scaling”。

第一部分是大规模能力验证。作者训练了 WeLM-HD4-80B 和 WeLM-HD4-617B，其中 HD4 表示每个 token 扩成 4 个 stream。对照组分别是同 backbone 的 WeLM-80B 和 WeLM-617B。结果上，80B 版本在九个共享 benchmark 上全部提升，文中点名的增益包括 SciCode 45.8→50.0，PHYBench 69.8→73.8。617B 版本同样在九个共享 benchmark 上全部提升，包括 GPQA Diamond 89.1→91.2，HLE 33.6→35.4，FrontierMath 49.0→51.0。这里一个重要细节是：这些比较使用的是相同的、较早期的 SFT-only post-training recipe，没有引入 RL。这样做的好处是把变量控制得更干净，说明增益主要来自 continued pretraining 阶段的 Hidden Decoding，而不是后续对齐流程差异。

第二部分是 expansion factor 的 scaling 实验。作者在 80B 上做 progressive expansion，把 n 从 2 提到 4 再到 8。结果显示 MMLU 单调提升，85.0→86.7→87.5；Pile-test BPB 从 0.386 降到 0.378。前者说明下游能力随隐藏计算增加而继续增长，后者说明语言建模损失也同步改善，不只是 post-train 指标偶然上涨。对预训练研究者来说，BPB 的下降很关键，因为它表明 Hidden Decoding 不是单纯把推理 benchmark 做高，而是在基础建模质量上也有收益。

从论文叙述看，作者还做了若干设计消融，重点应包括：是否必须保留 intermediate KV、是否必须使用 per-stream embedding、跨 stream 交换层的密度如何影响效果与成本、以及 Stream-Factorized Attention 相比全量跨 stream attention 的效率收益。虽然你给出的全文片段没有完整表格，但这些消融是判断方法是否真的抓住机制的关键。若某个组件去掉后性能明显回落，说明 Hidden Decoding 的有效性不是“把序列拉长”这么简单，而是依赖于可持续的多流内部状态。1a:Ta0f,Hidden Decoding expands each input token into n streams along the sequence dimension, processes the expanded sequence in one standard forward pass, and applies the next-token loss only to the final stream. The intermediate streams act as hidden computation rather than visible reasoning tokens.

Two design choices are central.

First, per-stream embedding replication. If the same token were simply repeated n times with the same embedding table, the streams would start from nearly identical states and the extra computation could collapse into redundant processing. The paper therefore replicates the vocabulary embedding table into n stream-specific tables, so token x_i becomes (E1(x_i), E2(x_i), ..., En(x_i)). During continued pretraining, these tables can diverge and give different streams different representational roles.

Second, persistent intermediate KV states. Some earlier length-scaling approaches keep repeated-token KV transient so that intermediate computation helps only within the current token and does not persist as context for later positions. That keeps inference cheaper, but it limits the extra computation to local refinement. Hidden Decoding instead retains the KV of all streams, allowing latent computation accumulated at earlier positions to remain available to later tokens. This is the paper’s key argument for why sequence expansion can become capability scaling rather than mere local smoothing.

The resulting challenge is attention cost. Full attention over an nL-length sequence would scale as O(n^2 L^2), which is not viable for long contexts and large models. The paper introduces Stream-Factorized Attention to control this. Most layers attend only within each stream, while cross-stream communication is allowed only in a subset of layers. Those exchange layers follow the base model’s original attention pattern, such as sliding-window or full attention. This avoids dense attention over the entire expanded sequence in most layers, making the added cost much closer to linear in n than quadratic.

Relative to recurrent-depth Transformers, the distinction is sharp. Looped models reuse depth and create explicit recurrence through the same blocks, which clashes with pipeline execution. Hidden Decoding flattens extra computation into the sequence dimension and preserves a standard single-pass training graph. Relative to naive token repetition, it adds the ingredients needed to make repeated positions useful as latent compute slots: stream-specific initialization, persistent memory, and controlled cross-stream mixing.1b:T659,The experiments test two claims: scalability to frontier-scale models and capability gains from increasing the expansion factor.

For large-scale validation, the paper trains WeLM-HD4-80B and WeLM-HD4-617B, where HD4 means four streams per token. Each is compared against a matched non-HD backbone. The 80B model improves on all nine shared benchmarks, with reported gains including SciCode 45.8 to 50.0 and PHYBench 69.8 to 73.8. The 617B model also improves on all nine shared benchmarks, including GPQA Diamond 89.1 to 91.2, HLE 33.6 to 35.4, and FrontierMath 49.0 to 51.0. An important experimental choice is that these comparisons use the same early SFT-only post-training recipe, without RL. That makes the comparison cleaner and supports the claim that the gains come from continued pretraining with Hidden Decoding rather than from downstream alignment differences.

For scaling with expansion factor, the paper runs a progressive study on the 80B model, increasing n from 2 to 4 to 8. MMLU improves monotonically from 85.0 to 86.7 to 87.5, while Pile-test BPB drops from 0.386 to 0.378. The BPB result matters: it shows that Hidden Decoding improves the underlying language-modeling objective, not only reasoning benchmarks after post-training.

The full paper likely includes ablations on persistent KV, stream-specific embeddings, the density of cross-stream exchange layers, and the efficiency trade-off of Stream-Factorized Attention versus denser alternatives.
