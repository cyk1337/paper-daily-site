Predicting Task Difficulty Without Rollouts

这篇工作研究的是一个评测与训练管线里的前置问题：在不做 rollouts、不运行完整 agent 交互的前提下，仅根据任务描述和少量静态元信息，能否预估一个 agent 任务有多难。作者关心的不是单个模型的 uncertainty 校准，而是跨 benchmark、跨 agent 配置地定义“任务难度”这一潜变量，并检验这种 ex ante 预测能否替代昂贵的实测试跑。问题之所以重要，是因为长时程 agent benchmark 的验证成本越来越高，很多任务一次评测就要消耗大量环境交互和模型调用；如果难度不能预估，benchmark 构造、课程学习和数据筛选都会变得很低效。

评无rollout任务难度预测的实用结论，token熵信号可直接用于数据课程与推理计算分配，看§3特征分析即可
Stefan Krsteski,Charlotte Meyer

TRE: Training-Free Hallucination Detection for Diffusion Language Models

D-LLM 的幻觉检测不能直接照搬自回归 LLM 的不确定性指标，因为扩散式生成同时有空间维度的多位置更新和时间维度的多步去噪。TRE 解决的是：不训练额外检测器、不做多次采样，只用单次生成过程里的熵信号判断幻觉风险。

评扩散 LM 可靠性方向的小而实的工作，核心思路（用去噪过程熵信号做无训练检测）值得做 D-LLM 的人参考，重点看方法节。
Pengcheng Weng,Yanyu Qian,Yue Tan,Yixin Liu
