Third, the solver is amortized: the network learns reusable branched transport structure across batches and tasks instead of solving a fresh BOT instance each time.

Stage 2 is self-target flow matching. The refined action is paired with the original base noise used to generate the pre-refinement action, and this pair becomes a source-target example for conditional flow matching. In effect, the model learns to map the same latent noise to a better action next time. The targets are therefore self-generated and improved by finite-step MCMC, not provided by an external oracle.

Second, it reframes multi-step reasoning as probability flow integration. That gives a clean separation between training and inference: training uses local denoising targets, while inference can scale compute by refining the temporal grid or using better numerical solvers.

Third, it provides a mechanistic claim, not just a benchmark gain: long-range useful computation can emerge from local objectives if adjacent objectives are properly coupled through noise levels and shared noise. In the standard setup, a looped model maintains a hidden state z_i, updates it recurrently with shared parameters, and decodes a prediction from each state. The practical problem is that training often uses stop-gradient per-step losses, so the loss at step i does not shape earlier states z_{<i}. Early updates therefore have little incentive to build representations that will help later updates.

Looped flows changes the target. Instead of asking every recurrent step to directly predict the final answer, it assigns each step a local denoising task at a different noise level. Starting from the ground-truth solution x, the method constructs noisy intermediate states x_t along a path from high noise to low noise. The recurrent model is trained to predict the denoising direction, or velocity, appropriate for the current noise level.

Two design choices are essential.
1) Noise levels decrease progressively across recurrent time. This creates a natural division of labor: earlier steps solve coarser subproblems, later steps refine them.
2) Adjacent objectives share the same underlying noise realization. This temporally associates neighboring denoising tasks, so even with only local gradients, the hidden state is encouraged to carry forward useful computation rather than restart from scratch at each step.

Formally, the paper uses a supervised version of continuous flow matching for categorical outputs. The model predicts a velocity field on the probability simplex rather than directly outputting discrete tokens. The velocity depends on the noisy current state, the conditioning input, and the recurrent hidden state. Training optimizes local denoising / flow-matching losses. Inference starts from noise and integrates the learned probability flow toward the solution distribution, then rounds to a categorical answer.

This differs from standard diffusion or flow models because the recurrent hidden state is part of the dynamics. The flow provides smooth, locally consistent supervision; the loop stores and accumulates intermediate computation over time. It also differs from prior looped reasoning methods such as TRM, which typically ask each step to predict the final answer directly and therefore suffer more from local-training mismatch. Here, the recurrence is shaped indirectly through a sequence of aligned subproblems.

A particularly interesting aspect is the credit-assignment shift: instead of solving temporal credit assignment with long BPTT, the method translates it into a noise-scale curriculum plus coupling between adjacent objectives.22:T780,The evaluation covers six reasoning benchmarks. At an on-policy step t_j, the current model first predicts the deterministic next state along the ODE trajectory. From the same parent state, it then spawns K stochastic SDE branches. Each branch explores only locally at the current step, after which it is rolled out deterministically to a clean image. The purpose is to evaluate whether a local directional perturbation leads to a better final sample.

A deterministic ODE rollout from the same parent state serves as a self-reference baseline. Final rewards from the K branches are compared against this baseline reward to produce normalized branch advantages. This is important because the signal becomes relative and local: not whether a sample is globally good, but whether a local move from the current state is better or worse than the default trajectory.

Training uses an all-branch pull-push distillation objective. Positive-advantage branches pull the velocity field toward better local directions, while negative-advantage branches push it away from poor ones. Compared with only regressing toward the best branch, this uses more of the sampled neighborhood and turns local exploration into a richer ranking signal. The downside is potential instability: repulsive updates can conflict with attractive ones. To address that, the paper introduces direction-aware attenuation, which downweights repulsion when it would substantially cancel the direction of the best branch.

Another key component is SDE-variance normalization. Since branch displacement scales vary across timesteps and noise levels, direct regression would produce poorly calibrated losses.
