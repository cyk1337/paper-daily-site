Automatic or Controlled? Repetition Priming Reveals Divergent Processing in Base LLMs, Instruct LLMs, and Humans

这篇论文研究的是一个很具体但很有机制意味的问题：当同一个词在上下文中再次出现时，LLM 到底是在重用先前表征，还是重新按当前语境评估它。作者用 repetition priming 这个经典心理语言学范式，比较 base model、instruct model 和人类在重复词处理上的差异，想回答的不是“哪个更强”，而是 post-training 是否改变了模型默认的信息处理模式。

评这篇会改你对 instruction tuning 的 prior：它不只是改偏好，还在改 token 复用的计算风格；先看 Qwen 家族的尺度趋势和 context removal 结果。
