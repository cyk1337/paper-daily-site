For each Transformer block, hooks capture the input and output hidden states, excluding the beginning-of-sequence position because it behaves as an activation outlier and attention sink. A block receives a low BI score if it changes the direction of its input representation only slightly on the calibration corpus. Low-BI blocks are candidates for depth pruning.

The study evaluates Qwen2.5-1.5B-Instruct, Llama-3.2-1B, and Gemma-2-2B on English, Hindi, Marathi, and Tamil Wikipedia text. Calibration and evaluation articles are disjoint. Every selector receives the same 150-chunk budget. A monolingual selector uses 150 chunks from one language, while multilingual selectors use 50 chunks each from English, Hindi, and Marathi. Tamil is excluded from selector construction to test held-out cross-script transfer.

Three multilingual aggregation rules are compared: raw-mean BI, rank-mean, and minimax-rank. Raw averaging preserves score magnitudes; rank-based rules remove cross-language scale differences. It first builds a merge set from a general corpus by collecting frequent contiguous n-grams of length 2 to 4. At inference time, merge candidates are selected with a longest-match rule when spans overlap. For each selected span, UMIM takes the static token embeddings and uses a lightweight single-layer attention module to produce one surrogate embedding, which replaces the original multi-token embeddings at the input layer.

The merge module is trained with predictive distillation. The pretrained LM is frozen, and only the merge module is updated so that the next-token distribution under compressed inputs matches the distribution under the original uncompressed sequence. The context-independent design makes the module reusable, but it is also a limitation: the same n-gram receives the same surrogate wherever it appears, which may be brittle for ambiguous phrases or spans whose role depends strongly on surrounding context. - Selector produces block-level scores per query.
- During training, these scores are injected as additive biases inside the attention softmax (logit space), directly reallocating attention mass.
- Four design choices highlighted as necessary for effective end-to-end learning:
  1) Add gates inside the softmax (logit space), not as post-softmax output scaling.
  2) Normalize gate scores across blocks (e.g., softmax over blocks) to represent calibrated relative importance.
  3) Keep gates continuous during training rather than collapsing to binary Top-K indicators, so the model learns both selection and priority.
  4) Update only selected blocks (sparse updates) to reduce training cost while maintaining comparable final quality.
