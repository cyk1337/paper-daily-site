9:T482,The proposed method is UMIM. It first builds a merge set from a general corpus by collecting frequent contiguous n-grams of length 2 to 4. At inference time, merge candidates are selected with a longest-match rule when spans overlap. For each selected span, UMIM takes the static token embeddings and uses a lightweight single-layer attention module to produce one surrogate embedding, which replaces the original multi-token embeddings at the input layer.

The merge module is trained with predictive distillation. The pretrained LM is frozen, and only the merge module is updated so that the next-token distribution under compressed inputs matches the distribution under the original uncompressed sequence. The context-independent design makes the module reusable, but it is also a limitation: the same n-gram receives the same surrogate wherever it appears, which may be brittle for ambiguous phrases or spans whose role depends strongly on surrounding context. The method is applied to both prompt compression and autoregressive decoding context compression, with rollback used to replace multi-token KV-cache entries by single-step surrogate states.a:T4fa,The key mechanism is to interpret selector scores as log-space gates and add them to attention logits (qK^T) before the softmax, so gradients from the LM loss flow into the selector:
- Selector produces block-level scores per query.
- During training, these scores are injected as additive biases inside the attention softmax (logit space), directly reallocating attention mass.
- Four design choices highlighted as necessary for effective end-to-end learning:
  1) Add gates inside the softmax (logit space), not as post-softmax output scaling.
  2) Normalize gate scores across blocks (e.g., softmax over blocks) to represent calibrated relative importance.
  3) Keep gates continuous during training rather than collapsing to binary Top-K indicators, so the model learns both selection and priority.
  4) Update only selected blocks (sparse updates) to reduce training cost while maintaining comparable final quality.
- Instantiated in the open-source block-sparse setting of SeerAttention-R, replacing layer-wise attention distillation with pure LM-loss optimization.
- Systems piece: custom Triton kernels fuse gate addition into FlashAttention-style tiled qK^T computation to avoid materializing the full attention matrix, which would be prohibitive for long contexts.b:T5eb,The proposed module is the Homeostatic Background Processor (HBP). It is a low-dimensional dynamic field defined over the transformer’s module graph. The field evolves over the iterations of an adaptive-depth reasoner according to PDE-like dynamics on the graph Laplacian, including damped-wave / forced Klein–Gordon dynamics, a diffusive limit, and a KdV-type variant. The field then modulates control variables such as halting thresholds, block gains, and memory gates.

The key design choice is that HBP does not carry task content. It is meant to govern computation, not to reason. That gives the architecture a two-layer structure: the main network handles representation and inference, while the homeostatic field allocates effort. The graph-based formulation means the controller operates at the module level rather than the token level. The explicit dynamics are important because they allow the authors to discuss stability, dissipation, and certifiable behavior in a way that standard learned halting heads do not.

The paper is careful about scope. It does not claim broad superiority over existing adaptive-compute methods. The title already signals the point: certifiability, not superiority. Read as an architectural proposal, the contribution is a controlled dynamical system for metacognitive regulation. In an LLM context, the closest analogy would be a separate controller for test-time scaling, pondering, or module routing, rather than leaving all such decisions to an opaque learned policy.c:T4db,The experiments are small-scale proof-of-concept studies. Given the framing, the most important results are likely not raw accuracy gains but behavioral diagnostics: smoother internal control trajectories, more interpretable stopping behavior, and better extrapolation of compute allocation under distribution shift. First, the paper adopts the earlier observation that magnitudes of trained Transformer linear weights are well summarized by a Weibull distribution, with a shape parameter k that stays nearly constant across layers and models, around 1.2. That reduces the training-side movement to the scale parameter λ. Second, on the data side, the authors use bigram conditional entropy D = H(next|prev) as a training-free measure of local next-token predictability. To normalize against a matched randomization baseline, they define a predictability margin (Hr - D), where Hr is the entropy reached by matched-budget shuffling. Third, they fit an empirical law
λ^2 - λ0^2 = C0(η) + C1(η)(Hr - D)^0.59,
where learning rate η only affects the two coefficients C0 and C1. A notable claim is that the exponent 0.59 is not chosen by directly fitting the growth curve; it is tied to an independently measured data-side saturation exponent p ≈ 1.69 through 1/p.

The paper is careful about scope. It does not claim D is a universal currency across corpora. The law is established within a fixed corpus while moving along a corruption gradient that changes the next-token mapping. The authors also extend the analysis from whole-model λ to per-block λ. The Weibull shape k remains nearly uniform, but the scale response is heterogeneous and concentrated in feed-forward blocks. Because k is stable, the second moment <w^2> = λ^2 Γ(1 + 2/k) is approximately additive, which lets pooled λ^2 be approximated by a parameter-count-weighted average of blockwise λ^2.e:T4b7,The main empirical results are fairly specific. The paper explicitly distinguishes this collapse result from direct predictive accuracy: the stricter per-learning-rate prediction has R^2 around 0.82. On scope tests, mapping-rich text remains broadly compatible with the relation, while code is systematically over-predicted, which motivates the authors' proposal that redundancy is a second data dimension missing from D.
