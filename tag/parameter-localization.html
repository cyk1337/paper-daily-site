LMs as Task-Specific Knowledge Bases: An Interpretability Analysis

这篇论文要回答的问题很直接：语言模型参数里的“知识”是否像知识库那样具有 task-invariant 的单一事实表示。也就是，同一个事实被不同任务形式查询时，模型是否调用同一份内部存储。作者用行为分析和机制分析给出的答案是否定的：同一事实往往以任务相关的方式被编码，知识与任务格式在参数空间里纠缠，而不是干净地共享一个 source of truth。

评这篇会动摇“参数即统一知识库”的直觉，值得读；先看行为不共现和参数定位两组结果，若成立，会影响你对 data mixture 与 eval 解释的 prior。

LLM Parameters for Math Across Languages: Shared or Separate?

这篇工作要回答的是：多语言数学推理能力差异，究竟来自一套共享的数学参数回路在不同语言上的不同激活，还是来自语言各自依赖的独立参数子网。作者不是只看性能差，而是沿着 mechanistic localization 的路线，直接在参数层面提取各语言的“math-associated parameters”，再比较这些参数集合在不同语言之间的重合度、层内分布和功能作用。

评这篇不会直接改你的 recipe，但会影响你对 multilingual parameter sharing 的先验；重点看中间层重叠和英语占用更大参数子集这两个结论。
