LLM Explainability with Counterfactual Chains and Causal Graphs

这篇工作要解决的问题不是常见的“给单个样本做事后解释”，而是试图为分类型 LLM 推断过程构造一个全局、概念层级的因果图。目标是回答：模型在做判断时，究竟把输入文本压缩成了哪些人可理解的概念，这些概念之间如何组织，最后又怎样共同决定预测。难点有两个。第一，LLM 的“概念状态”并不直接可见，需要从文本和模型输出中自动抽取。第二，因果发现依赖足够好的变量覆盖，但真实数据里概念组合通常很稀疏，直接在观测样本上学图会很不稳。

评把“反事实数据增广”当成因果发现的稳定器这个点值得抄作业；但概念抽取与状态定义很容易把 prompt/标注偏差写进图里，结论当弱信号看。
Nirit Nussbaum-Hoffer,Nitay Calderon,Liat Ein-Dor,Roi Reichart

CausaLab: A Scalable Environment for Interactive Causal Discovery Toward AI Scientists

现有的因果推理基准测试往往存在“因果鹦鹉（Causal Parrot）”问题，即 LLM 可能仅靠记忆训练数据中的因果事实或语言线索来回答问题，而无法真正像科学家一样通过交互式实验来发现未知的因果机制。

评揭示了 LLM '预测准但机制错' 的幻觉现象，对评估模型真正的 reasoning 和 generalization 能力非常有价值，评测设计很严谨。

CausaLab: A Scalable Environment for Interactive Causal Discovery Toward AI Scientists

CausaLab 要评估的不是 LLM 是否会回答因果常识题，而是 LLM agent 能否在一个陌生、可交互的环境里，通过观测和干预恢复可迁移的因果机制，并用该机制预测新样本。

评值得扫 Table 里 accuracy-F1 裂口；它给 AI scientist 评测加了机制约束，比只看最终答案更难糊弄。
