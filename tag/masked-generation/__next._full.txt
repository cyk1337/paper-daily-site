18:T4e7,The method, VIG-Sampler, is built on two empirical observations. First, candidate tokens that place stronger attention on image tokens tend to be both better grounded in the visual input and more useful for predicting the remaining masked tokens. Based on this, the sampler uses token-level image attention as the ordering score, prioritizing visually informative tokens over high-confidence but semantically weak ones. Second, when multiple tokens are decoded in parallel, their individual information gains do not add up cleanly because some of them are redundant. The paper argues that this redundancy is reflected in similar token-to-image attention distributions. VIG-Sampler therefore adds a similarity-based penalty during subset selection: if a candidate attends to the image in a way that is too similar to already selected tokens, its priority is reduced. This gives a simple two-part design: image-attention-based ranking for grounding, plus attention-similarity penalty for complementary information. Compared with certainty-based samplers, it avoids locking in punctuation, copulas, or other frequent low-content tokens too early. Compared with text-only info-gain samplers, it explicitly injects visual evidence into the decoding trajectory.19:T833,方法的关键是把“部分 mask 的离散序列”嵌入连续空间，再在这个空间上定义从部分 mask 状态到干净序列的随机插值与速度场学习。具体地，MLFM 使用 Brownian bridge 作为 stochastic interpolant，连接 embedded partially masked sequence 与 embedded clean sequence。这样做有两个好处。其一，连续状态在所有位置上联合演化，不需要像传统 MDM 那样在反向过程里对 masked positions 做条件独立分解，因此 few-step 时能更自然地表达位置间依赖。其二，在 Brownian bridge 的边界，插值退化回嵌入后的 partially masked sequence，这与预训练 MDM 的输入形式对齐，于是可以直接用已有 MDM 权重做 warm start，而不是从头训练一个 flow LM。训练上，模型学习的是条件速度场，目标与 flow matching / stochastic interpolant 系列方法一致，但 conditioning 结构保留了 any-position generation：未 mask 的 token 作为已知上下文，mask 的位置由连续流逐步推向干净 token embedding。推断上，论文提出两项关键机制。第一是新的 classifier-free guidance 形式。与常见 CFG 直接在条件/无条件预测间线性外推不同，这里为了隔离 clean tokens 对速度场的贡献，会在 reference velocity 中对 clean tokens 再加噪，从而更稳定地估计“条件信息带来的修正量”。第二是 online token promotion：如果某个位置的 posterior mode 概率达到 1-ε，就立即把该位置提交为 clean token，并用其干净 embedding 替换连续状态。这样一来，已解决 token 不必等到最后一步才固定，而是能在后续步骤中立刻作为上下文参与其它位置的生成。这个设计与 MDM 的逐步 unmasking 有相似之处，但不同点在于：MDM 的反向转移通常仍在离散空间逐步采样，MLFM 则是在连续耦合动力学中做“提前离散化”的局部提交。论文真正新颖的地方不只是把 mask 加进 flow，而是把 masking 变成 flow 过程中的结构性边界条件和采样控制机制。1a:T7c7,The core idea is to embed partially masked discrete sequences into a continuous space and learn a conditional flow from those partially observed states to clean token sequences. MLFM uses a Brownian bridge as the stochastic interpolant between an embedded partially masked sequence and the embedded clean sequence. This choice is important for two reasons. First, the latent state evolves jointly across positions, so the model is not forced into the position-wise independence approximation used by standard masked diffusion models. That makes few-step generation better aligned with the true dependency structure of language. Second, at the boundary of the Brownian bridge, the interpolant reduces to the embedded partially masked sequence, which matches the input structure of pretrained MDMs. This enables warm-start adaptation from a large masked diffusion model instead of training a flow LM from scratch. Training follows the stochastic-interpolant / flow-matching view: the network learns a conditional velocity field that transports the continuous latent state toward clean token embeddings while conditioning on observed, unmasked tokens. Inference adds two mechanisms. The first is a new form of classifier-free guidance. Rather than only contrasting conditional and unconditional predictions, the method noises clean tokens inside the reference velocity so that the contribution of clean context can be isolated more cleanly. The second is online token promotion: once the posterior mode at a position exceeds a confidence threshold of 1-ε, that token is immediately committed and its clean embedding is inserted into the state. This means resolved tokens become usable context for later denoising steps instead of remaining noisy until the end. That is the main behavioral difference from standard FLMs, which keep decoding all positions throughout generation, and from standard MDMs, which iteratively unmask in discrete space but still rely on factorized reverse transitions.1b:T4ce,The experiments adapt a pretrained 1028M-parameter MDM from Nie et al. The paper positions this as the first scaling of flow-based language models to instruction-following and reasoning-style downstream generation. Empirically, MLFM improves over SMDM and similarly sized autoregressive baselines on MT-Bench, and shows encouraging, though still early-stage, performance on GSM8K.
