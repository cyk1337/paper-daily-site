Adapting the Interface, Not the Model: Runtime Harness Adaptation for Deterministic LLM Agents

这篇工作处理的不是“如何把 agent 模型再训好一点”，而是一个更靠近系统接口的问题：在确定性、规则约束很强的环境里，很多失败并不来自模型缺少推理能力，而来自模型与环境之间的运行时接口不匹配。具体表现包括：观察组织方式不利于决策、工具契约描述不清、模型输出的动作在语义上对但在执行层面不可落地、环境反馈没有被转成恢复信号、轨迹进入重复或停滞后缺少调节机制。论文要解决的是，能否只利用训练轨迹，把这些反复出现的接口级失败沉淀成稳定的 runtime harness 干预项，在不改模型参数、不改评测环境的前提下，提升冻结 agent 在未见任务上的表现。

评不微调模型仅优化运行时harness的思路很有启发性，重点看§3的四类干预策略设计。
Tianshi Xu,Huifeng Wen,Meng Li
