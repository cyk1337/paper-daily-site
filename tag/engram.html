Does Engram Do Memory Retrieval in Autoregressive Image Generation?

这篇论文检验 Engram 这类 hash-keyed O(1) 记忆模块在自回归图像生成中是否真的做了内容寻址式检索。问题不只是“加模块是否提升 FID”，而是要区分三种可能机制：表项内容被正确检索、gated side-pathway 带来额外表达能力、或者模块只起到正则化作用。

评这篇的负结果比方法更有用；看 ρ sweep 和 gate-clamp，能校准“LLM 记忆模块可直接迁移到视觉 AR”的先验。
Jinghao Wang,Qiyuan He,Chunbin Gu,Pheng-Ann Heng
