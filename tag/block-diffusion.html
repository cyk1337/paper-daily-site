Beyond Block Boundaries: Multi-Block Editing for Diffusion Large Language Models

这篇工作处理 block diffusion language model 的边界退化问题。block diffusion 为了控制注意力成本，会按固定 block 从左到右生成，并在 block 内并行去噪。问题是 block 尾部 token 缺少未来 block 的右侧上下文，一旦当前 block 被提交，错误会成为后续 block 的固定条件，后面即使出现了可纠错的上下文也无法回改。

评块扩散 dLLM 边界误差问题的训练无关解法，思路干净，重点看 MBE 的注意力窗口设计和编辑策略，适合做内部扩散 LM 解码侧 ablation 参考。

Adaptive Block Diffusion: Resolving Training-Inference Mismatch in Diffusion Language Models

现有结构化扩散语言模型（如MDLM、Block Diffusion）为平衡并行解码效率与局部生成精度，采用固定前缀-窗口的去噪配置完成训练，导致训练时覆盖的有限配置集合，与推理时需要适配任意前缀长度、任意去噪窗口大小的需求存在支撑集不匹配。固定配置训练的模型仅学到特定场景下的去噪模式，在未见过的离训练网格（off-grid）配置下会出现困惑度骤升、生成不稳定的问题。

评应读方法和实验设置：它把 DLM 的解码策略泛化问题归因到训练配置 support，值得在内部 DLM ablation 里复现。

DFlare: Scaling Up Draft Capacity for Block Diffusion Speculative Decoding

Block diffusion speculative decoding 依赖“draft 一次性预测整块 token、target 并行验证”的范式，速度取决于 acceptance length（每次验证能接受多少 draft token）。现有 DFlash 在两点上卡住：一是 draft 加深后收益递减；二是 target knowledge injection 采用“少数 target 层 → 单一融合表示 → 所有 draft 层共享”的窄瓶颈，导致各层输入同质、难以分工，进一步让加深无效。论文要解决的是：如何在几乎不增加开销的前提下扩大 conditioning 带宽，让更深的 diffusion draft 真正变强，从而提升 acceptance length 与端到端加速比。
