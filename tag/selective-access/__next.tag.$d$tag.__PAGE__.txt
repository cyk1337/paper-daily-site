5:T65c,SATFormer keeps the same high-level idea as prior value-residual architectures: later layers can reuse the first-layer value projection V1. The change is in how access is controlled. ResFormer uses a layer-wise scalar λ_n, so every token and every head in a layer receives the same amount of V1. SATFormer replaces that with an input-dependent gate α_t,j^(n), computed from the normalized hidden state x_t^(n) at layer n and position t through a single linear projection W_alpha^(n) that outputs one gate per KV head. A ReLU is applied so the gate is non-negative and can become exactly zero. The resulting gate modulates, for each token and each KV head, how much of V1 is mixed into the current layer’s value computation. The design is intentionally minimal. The gate is token-wise and head-wise because token dependence alone would ignore head specialization, while head dependence alone would force uniform access across the sequence. The controller is just a linear projection, not an extra MLP or routing module, to keep parameter and runtime overhead negligible. And the architecture uses one early pathway rather than dense layer aggregation, avoiding the memory and bandwidth costs of DenseFormer-style designs. The paper’s main claim is not that SATFormer has much larger representational capacity, but that selective access is the right granularity for exploiting early features. The mechanistic analysis supports this: gate activations are sparse, depth-dependent, head-specific, and token-specific, suggesting that V1 is used as a structured retrieval pathway rather than a permanently open residual shortcut.6:T502,The empirical study spans models from 130M to 1.3B parameters. The main result is consistent improvement over both vanilla Transformers and ResFormer in validation loss across all tested scales, with stable gains in zero-shot evaluation. The headline numbers reported in the paper include an average zero-shot accuracy gain of about +0.67 over ResFormer at 1.3B, and roughly +1.5 points over ResFormer on retrieval-intensive evaluations. Against heavier dense alternatives such as MUDDFormer, SATFormer matches or exceeds performance while running at about 1.8x the throughput. That efficiency point matters: many cross-layer reuse methods look attractive in isolation but become less compelling once memory traffic and throughput are accounted for. The ablations are also important. One set shows that the V1 pathway itself is functionally necessary; removing it hurts language modeling. Another set replaces the input-dependent gate with coarser or more static controls, showing that the gain is not just from extra parameters but from conditional token/head-level access.
