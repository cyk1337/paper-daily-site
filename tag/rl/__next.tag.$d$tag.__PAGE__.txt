The second layer is IDRL. Instead of using a static weighted sum of distillation and RL losses, or running distillation and RL as separate stages, IDRL alternates between on-policy distillation updates and RL updates within a single training loop. In the distillation step, the student is trained against the teacher distribution on student-generated sequences, giving dense token-level supervision. In the RL step, the policy is optimized against task reward. The motivation is that a static joint loss can create objective interference within the same update, while a purely staged pipeline prevents the two signals from interacting during training. Interleaving is meant to decouple the objectives in time while still allowing them to shape the same evolving policy. The claimed benefits are better exploration, higher retained policy entropy, and more stable optimization.

For long-horizon agentic training, the paper adds PAS, or step-level positive-advantage suppression. This targets a common failure mode in trajectory-level RL: if a trajectory succeeds overall, some ineffective or even wrong intermediate actions may still receive positive credit because they share the trajectory’s positive advantage. PAS suppresses positive advantage on such steps, reducing this hitchhiking effect. The exact formula is not visible from the provided text, but the intent is clear: not every action on a successful trajectory deserves reinforcement.

The third layer is Pistis-Auto-Harnessing. PAH does not change the policy weights or the tool interface. Instead, an Optimization Agent proposes bounded revisions to the inference harness using development trajectories, validates them against a development metric, and keeps only those revisions that improve the metric. 训练上有两个关键设计。其一是 paired current-policy counterfactual rollouts。对一部分 prompt，强制当前策略分别在 TH 和 NT 下各生成一次回答，得到同一 prompt 下的成对反事实样本。然后比较两种模式的 utility，构造跨模式 credit。因为两条回答都来自当前策略，而不是旧策略、规则标签或外部教师，所以路由监督会随着策略能力一起更新，缓解 non-stationary target 问题。

其二是 hierarchical counterfactual credit assignment。论文采用一种“分离式 token 级赋值”规则：在最初的路由 token 上，不使用模式内 advantage，而是用经过截断或边界控制的跨模式 utility 差值来替换；在后续回答 token 上，只用该模式内部的 GRPO 优势做更新。这样路由 token 学的是“选 TH 还是 NT”，回答 token 学的是“在已选模式下怎么答得更好”，两类梯度不再混在一起。相比把整条序列统一做 policy gradient，这种做法更贴合层级决策结构。

Formally, the policy first samples a mode m in {TH, NT} for a prompt x, then generates a response z conditioned on x and m. The routing objective is defined with an efficiency margin b: thinking is preferred only if its estimated utility exceeds no-thinking by at least b; ties go to NT. This margin is a reward-space prior that biases toward the cheaper mode when quality is similar.

The first key mechanism is paired current-policy counterfactual rollouts. For selected prompts, the current policy is forced to answer once in TH and once in NT. This produces paired responses under both modes for the same prompt, allowing direct cross-mode utility comparison. Because both rollouts come from the current policy, the routing target tracks the model’s evolving capabilities instead of relying on fixed labels, heuristics, or a teacher.

The second mechanism is hierarchical counterfactual credit assignment. The paper uses a disjoint token-level rule. At the initial routing token, the usual within-mode advantage is replaced by a bounded cross-mode utility credit. For the response tokens, only within-mode GRPO advantage is used. This means the routing token learns which mode to choose, while the response tokens learn how to answer well within the chosen mode. Compared with sequence-level policy gradients over the whole output, this better matches the hierarchical structure of the decision process.

The third mechanism is a paired-to-self-routed curriculum. Early in training, the method keeps enough paired prompts so both modes continue to receive evidence and updates. Later, control is gradually transferred to autonomous self-routing. The purpose is to prevent early mode bias from collapsing exploration before the value of both modes is estimated reliably.

Relative to prior adaptive-reasoning methods such as Thinkless, HGPO, and TON, the paper’s main distinction is that it does not rely on extra dual-mode SFT or hybrid fine-tuning before RL.
