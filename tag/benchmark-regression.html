What Aggregate Scores Miss: Measuring Item-Level Regressions in Commercial LLM API Migrations

这篇工作要解决的问题很具体：商业 LLM API 版本迁移时，聚合 benchmark 分数会掩盖多少真实的 item-level 回归。对依赖闭源 API 的系统来说，迁移通常不是可选项，而是供应商退役旧模型后的被动升级。此时真正重要的不是平均分是否上涨，而是旧版本上稳定通过的具体测试项，在新版本上是否出现了可重复的失败。论文把这个问题表述为 backward compatibility 的 item-level 测量问题，并进一步处理了一个关键难点：LLM 输出有随机性，单次采样下的对错翻转并不能直接当作回归，需要估计每个 item 的通过概率变化，并用置换检验校准整套分类流程的假阳性。

评提醒我们在评估模型迭代（如 Continual Pretraining 或 SFT 更新）时，不能只看总分，细粒度的 regression 分析对于保证模型质量至关重要。
Xiaonan Xu,Wenjing Wu
