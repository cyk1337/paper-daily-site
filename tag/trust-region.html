Deconstructing Off-Policy Ratios: Entropy-Scaled Trust Regions for Asynchronous Reinforcement Learning

这篇工作处理的是异步 RL 在大模型后训练里的稳定性问题。异步训练通过并行 rollout 生成和策略更新显著提高吞吐，但也带来 stale/off-policy 数据：用于更新的轨迹并不是由当前策略完整生成的，长轨迹里甚至可能跨越多个权重版本。现有方法通常按 importance ratio 的绝对大小统一裁剪或屏蔽 token，默认“大 ratio 就不可信”。作者指出这个前提在异步 agentic RL 里并不成立，因为 ratio 的自然尺度随 token entropy 系统变化。低熵位置的大 ratio 往往只是近零概率放大的采样噪声，高熵位置的大 ratio 反而可能是异步更新带来的真实探索信号。核心问题因此变成：如何在不重建精确行为策略的情况下，区分应当抑制的 off-policy 噪声和应当保留的有效探索。

评应读；它改变 importance-ratio clipping 的默认先验，异步 RL 系统要复查低熵 token 的噪声放大。

Stale but Stable: Staleness-Adaptive Trust Regions for Stabilizing Asynchronous Reinforcement Learning

这篇论文处理异步 RL 训练中的 staleness 问题：rollout 用旧策略生成 token，trainer 用新策略更新参数，二者之间的实际 mismatch 会随 lag、推理引擎实现差异、低精度数值和 MoE routing 等因素变得长尾化。固定 PPO clip 半径无法区分可靠 token 和高 staleness token，容易在后期训练中放大训练-推理分布偏移。

评异步RL的陈旧性是大模型RLHF的实际痛点，SAT的信任域收缩思路值得在内部RL训练pipeline中测试。

Beyond Uniform Token-Level Trust Region in LLM Reinforcement Learning

RLVR（带可验证奖励的强化学习）中 PPO/GRPO 风格的 token-level trust region 对所有位置使用统一的 divergence 阈值，与 LLM 的自回归结构存在两点本质冲突：(1) 均匀阈值忽略自回归非对称性——早期 token 偏离会导致后续整个序列分布漂移，因此静态阈值对早期偏离约束不足、对后期探索过度限制；(2) 孤立评估 token-level divergence 忽略累积前缀漂移，不考虑当前条件历史已经偏离 rollout 策略多远。

评指出了LLM RL训练中信任域设计的普遍误区，累积前缀调整的思路可以直接迁移到内部RLHF/RLVR流水线。
