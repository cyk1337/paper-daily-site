Sandboxed Coding Agents are Competitive Omni-modal Task Solvers

论文研究一个直接的问题：面对视频、音频和跨模态任务，是否一定需要原生 omni-modal 模型，还是文本+图像 coding agent 通过沙盒工具也能完成相当一部分任务。作者的结论是，在许多当前 benchmark 上，工具化 agent 可以把多模态理解转化为证据抽取、检索和程序化处理，因此表现可以接近甚至超过直接吃音视频流的模型。

评读实验设置优先；若 compute 和工具权限公平，它会改变对 native VLM 必要性的部分 prior。
Dongping Chen,Xuanao Huang,Zhihan Hu,Qingyuan Shi,Dianqi Li,Tianyi Zhou
