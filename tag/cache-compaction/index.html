The KV-Surgeon: Compensation-Aware Offline KV-Cache Compaction

这篇工作处理的是离线 KV-cache 压缩里最关键、也最容易被简化错的问题：删掉哪些 cache entry，不能只看单个 token 被删后的局部误差，因为注意力的 softmax 归一化会让所有保留下来的项一起变化。已有方法大多把“删除一个条目”的影响当成独立事件来打分，或者先选子集、再做 refit。这样会漏掉两个重要因素：一是删除决策之间存在耦合，二是剩余 value 可以通过补偿更新来吸收一部分误差。论文要解决的，就是如何在可承受的离线成本下，把“删除 + 补偿”联合起来做，而不是分成两个割裂步骤。

评读方法推导和消融即可；softmax 重归一化导致删除耦合，这个 prior 应纳入内部 KV 压缩实验。
Moritz Wagner,Christophe Roux,Max Zimmer,Sebastian Pokutta

ARC-KV: Amortizing Anchor Search for Reconstruction-Based KV Cache Compaction

长上下文推理的 KV cache 压缩不能只看保留哪些 token；重建式方法效果更好，但 OMP 式逐上下文 anchor search 代价太高，尤其不适合可复用长前缀的在线服务。

评只看方法图和 compaction-cost 表就够；对预训练没直接作用，但长上下文 serving 预算会反过来影响训练目标选择。
Zheyu Shen,Guanhua Wang,Dezhan Tu,Mengchi Zhang,Yanjia Li,Adnan Aziz,Chunqiang Tang,Ang Li
