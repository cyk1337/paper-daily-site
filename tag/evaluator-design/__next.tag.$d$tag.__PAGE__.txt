9:T42b,The paper starts from a probability-allocation view: given a prompt and a set of responses sampled from the current policy, the directional gain from shifting probability mass from one response to another equals the evaluator score gap between them. This motivates response-set-conditioned evaluation rather than prompt-only evaluation. DynamicRubric implements this principle with two components. DR-Generator takes a prompt and a set of sampled responses and produces weighted binary rubric items tailored to the actual differences within that set. DR-Verifier applies each rubric item to every response, producing yes/no judgments that are aggregated into response-level scores. Training alternates between adapting the generator to response sets from the current policy and optimizing the policy using the resulting scores.
