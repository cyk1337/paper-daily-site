Multi-Segment Attention: Enabling Efficient KV-Cache Management for Faster Large Language Model Serving

这篇论文解决的是长上下文 LLM serving 中的无损 KV cache 管理问题。现有系统通常按 LRU、访问频率、位置或重计算成本决定哪些 KV block 留在 GPU 上，但很少直接建模这些 block 对 GPU attention kernel 延迟的影响。论文的核心观点是：不同位置、不同驻留状态的 KV block 对 attention 执行效率并不等价，eviction policy 应该感知这种计算层面的不对称性。

评看 MSA 和 eviction cost model；它提醒长上下文优化不能只算 token 命中率，还要算 kernel 形状。
