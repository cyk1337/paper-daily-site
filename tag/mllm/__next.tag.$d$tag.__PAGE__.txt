9:T918,StepPrune models token selection as an autoregressive policy over subsets, P(S|X)=∏t πθ(at|a<t,X). The action space contains all visual tokens plus a learned STOP action. The policy selects tokens one step at a time, conditioned on the image, the text prompt, and the previously selected tokens. The first time STOP is chosen, the episode ends, so the retained token count becomes input-adaptive rather than a manually fixed hyperparameter.

The selector is implemented as a cross-modal pointer-style decoder. This is the key departure from one-shot top-K ranking. Once one token has been selected, the value of nearby or redundant tokens should decrease, while complementary evidence may become more valuable. A sequential policy can model that changing marginal utility; independent scoring cannot.

Training is nontrivial because argmax-based subset selection is discrete. The paper introduces a trajectory-aware differentiable surrogate built around a variance-preserving noise gate. Aggregated pointer probabilities are used to smoothly interpolate each visual token between its original representation and isotropic Gaussian noise. High-probability tokens remain close to the original signal; low-probability tokens are pushed toward noise. This creates a differentiable pathway from the language-modeling objective back to the selector. To prevent the model from reconstructing masked information through neighboring tokens, the method adds a locally masked denoiser that limits cross-token leakage.

A second practical issue is selector overhead. Pure token-by-token decoding can become expensive for long visual prefixes, especially with AnyRes, dynamic-resolution, or multi-tile representations. To reduce recurrent selection latency, StepPrune allows grouped sequential selection: each pointer step selects a small group of tokens instead of exactly one. The paper uses five tokens per step as a default trade-off. This keeps the history-conditioned nature of the policy while making the selector scalable enough to be useful in practice.

So the main distinction from standard pruning baselines is not just a better scoring function. Based on this diagnosis, the paper proposes Residual Fallback Quantization (RFQ). Unlike threshold-based outlier fallback methods, which detect large values and route them through a higher-precision path, RFQ uses a fully low-bit and differentiable decomposition. It first quantizes the activation into a primary FP4 representation, then explicitly computes the quantization residual and sends that residual through a secondary low-bit quantization path for reconstruction. Conceptually, the approximation is q(x) + q_res(x - q(x)), rather than a hard split between normal values and outliers.

This design has several practical advantages. It is differentiable and suitable for end-to-end training. It avoids threshold tuning, which is difficult when outlier behavior varies by module and evolves during training. It does not require full-precision fallback, making it more compatible with true FP4 execution. And because it models the current quantization error directly, it is better aligned with dynamic training-time activation statistics than PTQ-style calibration methods.

Methodologically, RFQ sits between static PTQ smoothing and mixed-precision QAT fallback.
