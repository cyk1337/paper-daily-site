1）Local Approximation Error，记作 E_l：表示第 l 层压缩本身造成的信息损失。
2）Layer-wise Structural Sensitivity，记作 S_l：表示该层扰动经由后续网络被放大的程度，通常可由梯度范数或相关敏感度指标近似。

有了这个分解，系统设计就对应两条线。

第一条线是降低 E_l。作者认为现有 merging 方法的主要问题是忽略了 RoPE。RoPE 会对 query/key 施加位置相关旋转，导致 token 在旋转后的空间里不再适合直接按原始相似性做合并。于是他们把 token aggregation 放到 Pre-RoPE 的“安全区”，即在位置旋转之前进行聚合。为了避免简单合并导致注意力质量守恒被破坏，方法还引入 attention-conserving logit bias，在物理合并 token 时尽量保持原有注意力质量分布。这里的直觉是：不是只保留 token 数量，而是尽量保留被这些 token 支撑的注意力质量。

第二条线是管理 S_l。作者不满足于知道哪些层敏感，而是把 memory management 写成动态资源调度问题：在总内存固定、希望达到近似 O(1) 占用的前提下，按层分配不同 KV budget。具体做法是利用 offline gradient priors 估计各层敏感度，然后把更多预算留给高敏感层，从低敏感层更激进地回收内存。这样做的含义是，压缩不再是所有层一刀切，而是层感知的非均匀分配。

整体上，这是一个 hybrid framework：Pre-RoPE aggregation 负责减少局部误差，sensitivity-aware budget allocation 负责抑制误差放大。它是 training-free、model-agnostic 的，不需要重新训练底座模型。和已有方法相比，区别主要有三点：一是给了一个明确的误差分析，而不是纯经验规则；二是把合并位置前移到 RoPE 前；三是预算分配按层敏感度动态调度，而不是固定比例压缩。19:T8f8,The method starts from a first-order Taylor analysis. Let the final model output be O and the attention output at layer l be A^(l). The model is abstracted as O = G(A^(0), ..., A^(L-1)). Compressing the KV cache at layer l introduces a local perturbation ΔA^(l). Under a small-perturbation assumption, the final output deviation can be approximated by a first-order multivariate Taylor expansion, yielding two factors:

1) Local Approximation Error E_l: the information loss caused directly by compression at layer l.
2) Layer-wise Structural Sensitivity S_l: how strongly perturbations at layer l are amplified by the rest of the network, estimated through gradient-based signals or related sensitivity measures.

This decomposition drives two design components.

The first component minimizes E_l. The authors argue that many existing merging methods ignore the effect of RoPE. Since RoPE applies position-dependent rotations to queries and keys, the post-RoPE space is no longer a clean space for similarity-based token merging. Their solution is to perform token aggregation in a Pre-RoPE 'safe zone,' before positional rotation. To avoid losing attention mass during physical token consolidation, they introduce an attention-conserving logit bias so that the merged representation better preserves the original attention distribution.

The second component manages S_l. Instead of using a uniform compression ratio across layers, the paper formulates memory management as a dynamic resource scheduling problem under a fixed memory budget. Offline gradient priors are used to estimate layer sensitivity, and more KV budget is assigned to high-sensitivity layers while low-sensitivity layers are compressed more aggressively. In other words, compression becomes layer-aware rather than uniform.

Overall, the framework is hybrid: Pre-RoPE aggregation reduces local approximation error, and sensitivity-aware budget allocation controls downstream error amplification. It is training-free and model-agnostic, so it does not require retraining the base model. Compared with prior work, the differences are clear: an explicit error decomposition instead of pure heuristics, merging before RoPE rather than after it, and non-uniform layer-wise budget scheduling instead of fixed-ratio compression.1a:T5e1,The headline result is explicit in the paper: on Qwen2.5-VL-3B, Video-MemComp improves overall accuracy from 62.3% to 64.1% while limiting the average KV cache to 6,000 tokens per layer, reducing KV-cache memory by more than 90%. This is the paper’s 'less is more' result: removing redundant or harmful history can improve accuracy rather than merely preserving it.

The evaluation is conducted on benchmarks including MLVU, Video-MME, and EgoSchema, and across multiple MLLM architectures. The experiments support four main claims. First, under very low memory budgets, the method can match or even surpass the full-cache baseline. Second, the gains come from both parts of the design: Pre-RoPE aggregation lowers local approximation error, while layer-wise budget allocation reduces error accumulation. Third, layer sensitivity is highly non-uniform, so uniform compression across layers is suboptimal. Fourth, RoPE-aware handling matters; merging after RoPE performs worse.

The most informative ablations are likely the following: with and without Taylor-guided sensitivity, with and without the Pre-RoPE safe zone, with and without the attention-conserving logit bias, fixed versus dynamic budget allocation, and accuracy-memory curves under different cache budgets. Even without reproducing every table entry, the main message is clear: the method does not rely on extra training to recover performance; it improves memory efficiency by making compression itself more principled at inference time.1b:T654,Read this paper by first understanding the analytical motivation, then the engineering choices.

Start with the introduction and the beginning of the method section. The first-order Taylor expansion is not there as a formal theorem; it is there to produce an actionable surrogate objective that separates local compression loss from layer sensitivity. Once that framing is clear, the rest of the method becomes easy to follow.

Then read the Pre-RoPE aggregation section carefully. Two questions matter: why the post-RoPE space is a poor place for token merging, and how the attention-conserving logit bias compensates for changes in attention mass after merging. This is the most distinctive engineering idea in the paper.

After that, read the layer-wise budget allocation section. The key issue is not the optimizer details, but how offline gradient priors are estimated, how budgets are assigned, whether calibration data is needed, and whether sensitivity is stable across samples. This part is highly transferable to long-context text LMs.

In the experiments, prioritize the main table, the memory-accuracy tradeoff curves, and the ablation tables.
