The paper groups vision tasks into structured visual understanding, dense geometric prediction, segmentation, and multi-view visual geometry. Text generation is used for symbolic outputs such as categories, attributes, OCR strings, spatial references, and camera parameters. Image generation is used for dense outputs such as masks, depth, normals, and point maps, where the target is naturally aligned with the input image grid. Mixed tasks can emit both. This is an important design choice: instead of forcing everything into a serialized token stream, the model uses the modality that best matches the target structure. Second, data protocol. Third, model instantiation. SenseNova-Vision is built on top of Bagel rather than a new architecture. That makes the contribution primarily about task formalization, supervision conversion, and unified training.
