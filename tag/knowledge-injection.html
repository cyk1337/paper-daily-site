Scaling Laws for Hypernetwork-Based Knowledge Injection in Large Language Models

这篇工作研究的不是一般意义上的知识编辑，而是更接近“训练时知识内化”：给定一个固定事实库 Ω，用一个超网络把这批事实压缩成目标模型可插拔的固定 LoRA 适配器，并要求模型在推理时不再访问原始事实库。核心问题有两个。第一，超网络做大规模知识注入到底能不能稳定工作，而不是只在小规模编辑场景里有效。第二，这种能力如何随超网络宽度、深度、目标模型规模、注入事实数量而变化，是否存在可预测的 scaling law，以及它与 LoRA 微调、全量微调相比在 ID 与 OOD 上各自处于什么位置。

评看 scaling setup 是否真的解耦 target 能力；若实验干净，LoRA 注入容量曲线可作为 continual pretrain 的弱替代信号。

KoCo: Conditioning Language Model Pre-training on Knowledge Coordinates

标准LLM预训练把异质语料“拍平”为同一token流来做NLL，缺少对文本在现实知识体系中“来源/表达形态/时效性”的显式上下文化，导致学习效率与可靠性受限；论文要解决的是：能否用一种覆盖web规模、可自动标注、与主题无关的“知识坐标”作为条件变量，把预训练从P(x)改为P(x|T)，从而更快收敛、提升下游并降低幻觉。

评把“数据来源/时效”做成可规模化的条件坐标而非粗暴过滤，若30%收敛加速站得住会直接影响数据管线动作；建议重点核查其对照（URL前缀/selection）是否足够干净。
Yudong Li,Jiawei Cai,Linlin Shen
