AdaMem: Learning What to Remember for Personalized Long-Horizon LLM Agents

这篇工作讨论的不是“怎样存更多记忆”，而是“在长期个性化交互里，什么值得被写进记忆”。作者认为现有 LLM memory agent 大多默认一个统一写入规则：只要对话里出现事实，就尽量提取并保存。这个假设在短任务里问题不大，但在真实长周期场景里会导致 memory bloat：无关细节不断累积，占用检索预算和上下文窗口，最终让真正重要的信息更难被召回。更关键的是，记忆价值是角色相关、用户相关的。同一句对话，对商务助理和健身伙伴的重要性完全不同。AdaMem 试图解决的核心问题，就是如何让记忆写入策略从“尽量全记”变成“按用户偏好有选择地记”，并且能从反馈中持续修正。

评这篇不是基座论文，但把 agent memory 的关键矛盾从 retrieval 转到 write policy，方向是对的；先看 memory policy 定义和 rollback 机制。
Xingyu Chen,Rui Wang,Zhaopeng Tu,Liefeng Bo
