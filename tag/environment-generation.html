CodeMidas: Scaling Agentic Coding RL Environments from Code Itself

这篇工作解决的是：如何不依赖 issue、commit、现成测试或文档，而是直接从开源代码里抽取“已实现功能”，把它改造成可用于 coding agent 强化学习的可执行环境。难点不在于生成一个题目描述，而在于同时满足三件事：任务要覆盖真实软件工作、奖励要足够可靠、环境要能规模化构造。已有做法大多绑在开发痕迹上，任务分布受仓库记录质量限制，也容易偏向修 bug 或补测试这类窄分布。CodeMidas 试图把“代码本身”变成任务来源，用原始实现的可观察行为来反推规范、构造 verifier，并把目标实现从代码库里挖掉，形成一个真实但可验证的 RL 训练环境。

评展示了如何利用 Agentic workflow 从纯代码中逆向工程出高质量的 RL 验证环境，为代码大模型的后训练数据合成提供了一条极具扩展性的新路径。

Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments

这篇工作解决的是代码 agent post-training 里一个很实际的瓶颈：轨迹很多，但可执行、可复用、可验证的环境很少。单条 trajectory 只是一次冻结演示，质量受原始 policy 上限约束，也很难重新验证；而环境可以被更强模型反复求解、生成更多任务、提供执行反馈。作者抓住的核心点是，已有 terminal agent 轨迹里的工具调用历史，其实已经暴露了原始工作区的大量结构信息，因此可以把“轨迹”还原成“环境”，再把环境变成可扩展的数据资产。

评将静态 trajectory 逆向工程为可执行环境的思路非常巧妙，对解决 Agent 训练数据稀缺和环境构建成本高的问题有重要启发，值得关注其具体实现细节。
