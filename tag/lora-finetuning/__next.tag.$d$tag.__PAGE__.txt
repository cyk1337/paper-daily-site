c:T401,DeltaServe is not a new standalone serving stack but a host-agnostic co-serving layer added to existing inference engines through a compact hook interface; the only required host capability is multi-LoRA batching, already supported by modern engines. The key observation is that the LoRA fine-tuning forward pass is structurally identical to inference prefill, so fine-tuning forward work can be folded into inference batches instead of competing as a separate workload. The design has three main pieces: (1) a CUDA-graph-aware latency model, calibrated offline and refined online, that predicts at batch granularity how admitting fine-tuning will affect TTFT and TPOT; (2) an SLO-aware admission scheduler that admits, throttles, pauses, and resumes fine-tuning as inference load fluctuates; and (3) a decoupled backward executor that moves the long backward pass off the inference critical path to avoid blocking token-level latency.
