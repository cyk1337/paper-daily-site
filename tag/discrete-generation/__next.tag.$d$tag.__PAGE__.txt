DLLM-JEPA 的关键构造是：从同一个输入采样两个噪声级别 tL < tH，形成两个 view。
- context view x_{tL}：低噪声，保留大部分 token；
- target view x_{tH}：高噪声，信息更残缺。

模型对 context view 做一次带梯度前向，得到两类输出：
1. diffusion logits，用于标准 masked denoising loss；
2. pooled embedding z_{tL}，作为 JEPA 的预测端表示。

对 target view 再做一次无梯度前向，得到目标 embedding z_{tH}。随后用 JEPA loss 让 context-side 表示去预测 target-side 表示。因为 target 分支 stop-gradient，所以每步只有一次带梯度前向，而不是像 LLM-JEPA 那样两路都反传；这就是 33% FLOPs 节省的来源。

从设计取舍看，这个方案有几个值得注意的点：
1. 为什么用不同 mask rate 作为两视角，而不是随机 span corruption 或外部数据增强？因为 diffusion schedule 已经定义了语义一致、信息量不同的 view family，天然适合做“同一语义、不同可见度”的预测；
2. 为什么 target 分支不回传梯度？这是 JEPA/Bootstrap 类方法常见做法，用来稳定训练并减少计算；
3. 为什么作者强调与 LLM-JEPA 不是直接 apples-to-apples 比较？因为一个建立在 AR block-causal attention 上，一个建立在 bidirectional masked diffusion 上，结构约束不同，直接横比容易把架构差异和目标函数差异混在一起。

In vision, JEPA avoids low-level reconstruction bias by predicting latent representations rather than pixels. This paper shows that masked diffusion LMs are structurally better suited than AR LMs for that idea.

Three takeaways matter. First, the diffusion noise level itself can serve as a view generator, so language JEPA does not need externally paired data. Second, a bidirectional backbone simplifies the computation graph and cuts training FLOPs by 33% relative to LLM-JEPA’s two-gradient-view design. Third, the benefit seems not to be “smaller drift from the pretrained model,” but more structured drift: hidden states move farther from the initialization while functional forgetting is reduced. That is a useful observation for anyone thinking about regularization, continued pretraining, or representation shaping in non-AR LMs.

Starting from a clean sequence x0, the forward process replaces each token with [MASK] independently with probability t, and the model learns to reconstruct the original tokens from the masked sequence xt. Unlike AR models, the backbone uses bidirectional attention, so one forward pass already yields a full-context representation.

DLLM-JEPA constructs two views from the same input by sampling two noise levels tL < tH:
- a context view x_{tL}, lightly masked and information-rich;
- a target view x_{tH}, heavily masked and more abstract.

A gradient-carrying forward pass is run on the context view. From that pass, the model produces:
1. diffusion logits for the standard denoising loss;
2. a pooled embedding z_{tL}, used as the JEPA prediction-side representation.

The target view is processed in a second forward pass without gradient, producing z_{tH}. A JEPA loss then trains the context-side representation to predict the target-side representation. Because the target branch is stop-gradient, only one branch backpropagates each step. That is the source of the reported 33% FLOP reduction relative to LLM-JEPA.

Several design choices are worth noting. Using different mask rates as the two views is more principled than ad hoc text augmentation because the diffusion schedule already defines a family of semantically aligned but information-varying views. Keeping the target branch gradient-free follows the usual JEPA/bootstrap logic for stability and efficiency. The paper also avoids a direct head-to-head comparison with LLM-JEPA as if they were identical settings, since one lives on block-causal AR attention and the other on bidirectional masked diffusion; otherwise architecture effects and objective effects would be entangled.

A particularly interesting part is the representation analysis. DLLM-JEPA increases hidden-state drift from the pretrained model, especially in middle transformer layers, yet reduces functional forgetting measured on Wikitext. That suggests JEPA is not acting like a simple stay-close-to-initialization regularizer. Instead, it appears to redirect adaptation toward more useful internal structure, especially in the middle layers often associated with compositional processing.
