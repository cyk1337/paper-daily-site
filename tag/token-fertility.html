The African Language Tax: Quantifying the Cost, Latency, and Context Penalty of Tokenizing African Languages in Frontier LLMs

这篇工作关注的不是多语言能力本身，而是 tokenizer 在不同语言上的结构性不公平，尤其是非洲语言在前沿 LLM 中被切得更碎，导致同样语义需要更多 token，进而带来更高 API 成本、更长延迟和更短有效上下文。论文要解决的核心问题是：这种“tokenization tax”在非洲语言上到底有多大，能否用严格可复现的并行语料测量方法，把它从抽象讨论变成可量化、可比较、可部署决策使用的指标。

评建议读结果表；它把 tokenizer fertility 从公平性口号落到成本和上下文预算，可反查内部词表盲点。
Olaoye Anthony Somide
