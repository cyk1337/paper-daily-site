Dense Process Supervision for Search Agents via Fact Utility Estimation

这篇工作解决的是搜索型 agent 用 RL 训练时的 credit assignment 问题。现有方法多用 outcome reward，只在最终答案正确与否上给奖励，但搜索、检索、证据整合这类任务的关键难点恰恰在中间步骤：一次检索、一次信息抽取、一次证据写入，到底有没有帮助，往往不能从最终成败直接看出来。全文的核心切入点是把中间过程从“原始文本历史”改写成“显式事实集合”，再估计这些事实对成功结果的后验效用，用它给每一步提供更密集的训练信号。

评提供了一种为 Agent 搜索任务构建 step-level reward 的新思路（基于事实效用估计），对做 RL/PRM 的研究员有启发，关注其 reward 构造逻辑。
Rongzhi Zhu,Xiangyu Liu,Yi Liu,Shuo Zhang,Ruirui Zhang,Rui Wu,Tao Jiang,Zequn Sun,Wenhao Xu,Wei Hu

Diagnosing Search Behavior and Failure Modes in Long-Horizon Search Agents
