When EOS Tokens Disagree: Understanding Length Inflation in On-Policy Distillation

这篇工作研究 on-policy distillation 里的 length inflation，但切入点很具体：学生模型和教师模型对“停止生成”这件事，可能把概率质量放在不同的 EOS token 上。即便两者声明的 stopping set 相同，学生偏好的终止 token 和教师偏好的终止 token 也可能不同。由于 sampled-token OPD 只对学生实际采样到的 token 打分，学生原本会停下来的 EOS token 可能持续收到负蒸馏信号，而教师偏好的另一个 EOS token 又因为学生几乎采不到，无法有效学到，结果就是学生越来越不愿意停，响应长度不断膨胀，甚至耗尽 generation budget。

评揭示了蒸馏中 EOS token 不匹配导致长度膨胀的坑，做 post-train 和蒸馏的必看，建议直接在内部 pipeline 中加上 EOS 聚合的逻辑。
Yuxiao Yang,Tianrun Yu,Shangzhe Li,Kaixiang Zhao,Xuchao Zhang,Chetan Bansal,Huaxiu Yao,Taylor W. Killian,Weitong Zhang
