18:T469,LatentSift replaces the first-stage LLM-based execution-free verifier in a hybrid SWE verification pipeline. The standard pipeline scores all K trajectories with an EF verifier, keeps a subset, then applies regression tests, LLM-generated tests, and a final EF selection step. LatentSift instead collects hidden states while the policy is generating candidates, adding no extra LLM tokens. It represents each trajectory through three channels: reasoning states, environment-observation states, and function-call states. During training, states from successful and unsuccessful trajectories are stored in positive and negative banks. At inference time, candidate states are compared with these banks, step-level distance margins are aggregated, and channel-level ranks are fused conservatively so that a candidate must look good across the behavioral channels. A separate linear scorer trained on policy hidden states produces a learned trajectory score. The final filtering score combines normalized ranks from the distance branch and the learned scorer, then retains half of the candidates for the remaining verification stages.19:T43b,The system implements agentic meta-reasoning: reasoning about the agent’s own computation before dispatching more computation. Workers perform task-level work. A controller maintains a compact account of the run, proposes possible next computations, evaluates their value under the remaining budget, and sends selected assignments to workers with only the relevant retrieved artifacts. Full outputs are stored in persistent memory as artifacts with stable identifiers. The controller’s private state is rewritten at each control cycle and does not have to include the full history. Each cycle has four stages: state update, option generation, option evaluation, and dispatch. The design differs from a simple ReAct-style loop or direct-control agent because control is not a single next-action prediction conditioned on the accumulated transcript. Control itself is an agentic process with memory access and intermediate outputs. The artifact graph records which artifact was used to produce which later artifact, giving a structural trace of branching, reuse, and failure modes.1a:T432,The evaluation spans IMO ProofBench-Advanced, ARC-AGI-2, LongCoT-mini, and ProgramBench, covering proof search, abstract reasoning, long-horizon reasoning, and program reconstruction. The models include Gemini 3.1 Pro, GPT-5.5, and Opus 4.8. The main budgets are 100 model calls for the reasoning benchmarks and 1200 calls for ProgramBench. Baselines include production coding agents, research harnesses, and a Direct Control Agent that keeps workers and available actions fixed while replacing the controller with a single-step decision over accumulated history. At the main budgets, meta-reasoning has higher point estimates in all 12 matched comparisons, with average gains of about 3.6 to 4.2 score points by benchmark. On ProgramBench with GPT-5.5, mean per-problem test-pass rate reaches 71.5%, compared with 58.0% for Codex and 63.7% for direct control. Scaling curves show continued improvement with larger budgets, while direct control tends to plateau. Artifact-graph analysis shows more reuse of earlier work and more runs in which a correct candidate is present.1b:T445,The central concept is strategic diversity: substantive variation in how a problem is approached, not lexical variation or embedding-space distance. The paper proposes two ways to generate strategically diverse self-training data using the model itself. The first adapts Verbalized Sampling: the model lists multiple possible approaches with estimated probabilities, and each approach is then used as a hidden instruction for generating a full response. The second method, Groot, asks the model to build a hierarchical decision tree over approaches and samples distinct root-to-leaf paths. This is natural for competitive programming, where solutions branch by algorithm, data structure, and implementation choices. For story planning, where narrative decisions are interdependent and less hierarchical, the unstructured VS-style approach is more suitable. Compared with high-temperature IID sampling, both methods force the model to commit to different approaches before producing the final answer, so they change the strategy distribution rather than only perturbing token-level realization.1c:T7dd,Hill Sampling is intentionally minimal. Start from an initial program x0. At each round, sample N candidate edits from a frozen LLM conditioned on the current incumbent xt. Execute each candidate with the verifier, obtain rewards, and replace the incumbent if the best candidate in the round matches or exceeds the best reward seen so far. The algorithm stores the incumbent’s historical best reward rather than re-evaluating it every round, which is important when execution is stochastic. Equal-reward replacements are allowed to preserve some structural diversity. There is no archive, no crossover, no explicit diversity objective, and no parameter update. The main knobs are decoding temperature, samples per round, and number of rounds.

The paper is stronger because it does not stop at introducing the method. It systematically compares three exploration families. First, repeated sampling, where all generations are drawn independently from the same starting point. Relative to that baseline, Hill Sampling adds exactly one persistent state: the best-so-far program fed back into context. Second, evolution strategies applied directly to LLM weights. The authors build a large-scale ES pipeline and separate standard ES learning from a zero-learning-rate variant that keeps only random weight perturbations. This isolates exploration from learning. Third, they test common add-ons such as diversity encouragement, solution combination, extra exploration mechanisms, and code-execution feedback. The conclusion is that none of these are necessary to obtain strong results in this setting.

Mechanistically, Hill Sampling treats the LLM as a conditional editor rather than a one-shot generator. The incumbent acts as a moving scaffold. Future samples are drawn near the current best program instead of restarting from the original problem statement. That creates a simple local search process in context space, not in parameter space. The paper’s main contribution is showing how far that alone can go.1d:T79c,The evaluation covers three verifiable mathematical optimization problems with three open-weight models: circle packing with gpt-oss-20b, sums/differences of finite sets with OLMo-3.1-32B-Instruct, and Erdős’ minimum-overlap problem with Mistral-Small-3.1-24B-Instruct. The emphasis is practical wall-clock performance, not only sample efficiency.

The headline result is on circle packing: Hill Sampling reaches the best published result in under five hours on eight H100 GPUs. On the Erdős minimum-overlap problem, it surpasses the AlphaEvolve algorithmic-discovery reference within 12 hours. The abstract is truncated, but the body makes the qualitative outcome clear: one new published best result and strong competitive performance on the other tasks.

The ablations are the most informative part. Hill Sampling substantially outperforms repeated sampling, showing that best-so-far conditioning is the main source of gain. Standard ES often improves mean return while reducing maximum return, which directly supports the paper’s framing that mean-oriented updates can be misaligned with discovery objectives. Setting the ES learning rate to zero removes learning but keeps random weight perturbations; this sometimes preserves maximum return better than learned ES, yet still underperforms plain token-sampling randomness from the unperturbed model. That is a useful boundary condition for claims about nearby experts in pretrained weight space: even if such experts exist, searching for them may be less effective than output-space exploration when exact verification is available.

The paper also compares Hill Sampling with N=64 and N=512 under the same total sampling budget, changing the trade-off between more frequent incumbent updates and larger within-round candidate sets. Even without all table values here, the setup is worth attention because it probes whether iterative conditioning matters more than wider one-shot search.1e:T514,For a quick read, focus on three parts. First, the opening motivation where the paper distinguishes maximizing best-found reward from improving average sample quality. That framing explains nearly every later result. Second, the formal definition of Hill Sampling in the methods section, especially the stored incumbent reward, equal-reward acceptance, and the budget-matched N=64 versus N=512 variants.
