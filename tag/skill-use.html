Skill-Use: Can LLMs Actually Use Skills in Agentic Harnesses?

在“渐进披露（progressive disclosure）”的 agent harness 里，技能（skill）通常只以“名称+短描述”先暴露给模型，完整步骤需要模型主动检索后才能执行。现有评测多看最终任务成败或技能文档质量，无法回答一个更基础的问题：模型是否能自己判断该用哪个技能、主动触发检索、并按技能步骤执行且不越界。该论文要评测的就是这种端到端的“技能使用能力”，并把失败拆成可定位的三个环节。

评值得扫 metric 定义；它把 agent skill failure 拆得更干净，读 §benchmark/score 即可，不必期待预训练结论。
