9:T513,Marginal Advantage Accumulation (MAA) is introduced as an architectural layer on top of existing batch distillation.
- Structural requirements:
  1) Alignability: semantically equivalent operations must be recognized and merged across batches.
  2) Comparability: signals must be on a consistent scale across batches to be additively accumulated.
- Alignability mechanism: represent the memory bank as a set of items with stable IDs; each op is keyed by (type, anchor id, content embedding). New candidates are merged into an existing op unit when semantic similarity exceeds a threshold, preventing evidence fragmentation due to paraphrases.
- Comparability mechanism (core): use an outer-loop difference signal per batch. An LLM judge estimates an expected utility u(M,B) in [0,100] for memory M on batch B. For each candidate op_i, form M_i and compute δ_i = u(M_i,B) − u(M,B). The differencing is intended to cancel batch-specific difficulty/distribution effects and isolate the marginal contribution of the op.
- Accumulation: for each op unit k, aggregate signed δ_{k,t} over batches via EMA, yielding a persistent evidence score used to retain/suppress operations.
