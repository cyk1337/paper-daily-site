9:T43b,The system implements agentic meta-reasoning: reasoning about the agent’s own computation before dispatching more computation. Workers perform task-level work. A controller maintains a compact account of the run, proposes possible next computations, evaluates their value under the remaining budget, and sends selected assignments to workers with only the relevant retrieved artifacts. Full outputs are stored in persistent memory as artifacts with stable identifiers. The controller’s private state is rewritten at each control cycle and does not have to include the full history. Each cycle has four stages: state update, option generation, option evaluation, and dispatch. The design differs from a simple ReAct-style loop or direct-control agent because control is not a single next-action prediction conditioned on the accumulated transcript. Control itself is an agentic process with memory access and intermediate outputs.
