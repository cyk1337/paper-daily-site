First, it constructs minimal same-question trajectory interventions: same-final deletes all search actions while preserving the answer and citations; fake-ID replaces a citation with a nonexistent corpus ID; adaptive laundering replaces it with a real passage that the agent never retrieved. Second, it draws a strict information boundary: attack generation is label-free and accesses only the question, logged trajectory, and corpus, never gold answers or support annotations; if reward computation uses annotated signals, that selection is reported as an oracle upper bound rather than a candidate-visible attack. Third, it enumerates the full 2^3 lattice over three detectors—retrieval-use, membership in retrieved evidence, and fake IDs—and reports paired reward margins to identify an inclusion-minimal repair instead of claiming victory from a large detector bundle. The provenance field matters because it keeps the system evidence-grounded rather than turning it into an opaque symbolic store.

Second, External Key-Value Injection (KVI): capsules are compiled, using a frozen base model, into tensors that are isomorphic to the model’s internal key/value states. Instead of appending knowledge as text, the method injects it directly into the Transformer attention mechanism so that external knowledge participates in the same softmax competition as endogenous memory. This is the central conceptual move of the paper.

Third, dual-channel graph-guided retrieval: at inference time, the system retrieves relevant capsules through graph-guided multi-hop traversal and uses two channels in parallel. Structured relational knowledge is injected through KVI, while textual evidence is still placed in the prompt for grounding and interpretability. The intended division of labor is clear: injected memory provides compact relational bias, while retrieved text provides readable evidence and semantic anchoring.

Relative to vanilla RAG, the differences are both representational and mechanistic. Knowledge is normalized into explicit relational units rather than left as raw passages, and it is injected at the memory level rather than through context expansion. Relative to trainable memory adapters, the paper emphasizes a training-free, backbone-preserving setup.
