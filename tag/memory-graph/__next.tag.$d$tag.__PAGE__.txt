a:T559,GMT keeps the standard decoder-only Transformer scaffold (residual stream + causal self-attention) and swaps the FFN with a graph-structured memory cell. The memory consists of learnable centroids (prototype states) and a learnable directed transition matrix over centroids.

For each token representation, the cell performs:
1) Source routing: compute a soft assignment over centroids to form an estimated source memory state (distributional rather than hard slotting). The paper mentions “gravitational” routing, suggesting a bias toward nearby centroids to stabilize training.
2) Graph-mediated target selection: combine the learned transition graph with token-conditioned signals to produce a target centroid distribution/state. The key modeling choice is that the update is explicitly mediated by source→target transitions on the graph, rather than a single-shot dense MLP transform.
3) Gated displacement readout: output a displacement vector (target minus source in centroid space) and gate it into the residual stream, serving the role of the per-token nonlinear update normally provided by the FFN.
