在此基础上，作者先给出 SPO（Scaled Policy Optimization）。SPO 的想法很直接：既然不稳定主要来自 stale negative samples 更新过强，就手工缩小负优势项的权重。它能缓解问题，但规则是人工设定的，不能根据每个 response 在当前策略下的实际尺度自适应。

真正的主方法是 ASymPO。它做的是 response-level 的 asymmetric normalization：仍然只使用当前策略对整条 response 的 log-probability / NLL 尺度，但对正优势和负优势项采用不对称缩放，使得在 group-relative zero-sum advantages 条件下，正负两侧的 response-level loss contribution 可以被精确配平。直观上，当前策略下已经“很难”的 response，也就是 NLL 很大的样本，会被自动降权；而不是像 naive current-policy objective 那样让这些样本直接把梯度拉爆。文章还把 ASymPO 与 behavior-corrected GRPO、GPG、naive current-policy training 做了目标层面的对照：behavior-corrected 方法通过 ratio clipping 间接控制尺度，ASymPO 则直接在 current-policy objective 上做尺度归一。

从方法取舍看，ASymPO 放弃了对真实 behavior distribution 的显式校正，因此它不是 importance sampling 的无偏替代；它追求的是在异步大系统里，用更简单的接口换取足够稳定、足够高效的优化。这个设计目标很清楚，也和论文标题一致。b:T786,The paper first formalizes the instability. It defines a response-level average token NLL under the current policy and introduces a loss-balance quantity, Δθ, that measures whether positive- and negative-advantage responses contribute comparable total loss mass. The central argument is that behavior-corrected methods are stable not only because they are more principled statistically, but because they impose a shared behavior-policy reference scale and use clipping to bound deviation from that reference. Once that reference is removed, zero-sum advantages no longer imply balanced optimization pressure.

The first method is SPO, Scaled Policy Optimization. SPO is intentionally simple: it weakens the contribution of negative-advantage responses, motivated by the empirical observation that stale negative samples are the main source of instability. This helps, but the scaling rule is manually designed and does not adapt to the actual current-policy scale of each response.

The main method is ASymPO. It performs asymmetric response-level normalization using only quantities available from the current policy on the learner side. The intuition is straightforward: if a response already has a very large current-policy loss scale, its contribution should be moderated automatically rather than allowed to dominate the batch. Under zero-sum group-relative advantages, ASymPO is designed to exactly balance positive and negative response-level loss contributions. This is the conceptual difference from behavior-corrected GRPO or PPO-style clipping. Those methods control scale indirectly through behavior-policy ratios and clipping; ASymPO controls scale directly inside a current-policy-only objective.

The trade-off is explicit. ASymPO is not trying to be an unbiased off-policy correction. It is a stability-oriented objective for asynchronous systems where infrastructure simplicity is part of the design target.c:T627,The experiments cover asynchronous mathematical-reasoning post-training across three model families. The main empirical message is consistent with the theory: naive current-policy training is unstable in asynchronous settings; SPO improves stability but remains limited; ASymPO is more robust and can match or approach behavior-corrected baselines while using a much simpler rollout-learner interface.

4. ablations from SPO to ASymPO, showing that adaptive response-level normalization is better than a fixed manual weakening of negative terms.
