Where To Look? : Causal Tracing of Vision Encoders in VLM

这篇工作要回答的不是“VLM能不能答对”，而是“答对时到底依赖了哪些视觉表征”。更具体地说，它检验视觉编码器里对最终图文匹配分数有因果作用的 token，是否真的落在与文本查询对应的目标区域上。论文针对一个长期被默认成立、但很少被直接验证的假设：强视觉语言性能是否意味着模型内部已经形成了空间上对齐的因果表征。作者给出的答案是否定的——至少在他们分析的 CLIP 及更大 VLM 上，很多高因果贡献 token 并不位于目标框内，说明“会看”“会用”“会定位”并不是同一件事。

评值得扫方法和核心图；若因果 token 常在目标外，VLM 对齐 loss 可能学到的是场景捷径而非局部 grounding。

评读表征分析部分即可；若 setup 真公平，它能校准 connector 位置选择，不必太在意榜单分数。

Large Language Models are Universal Reasoners for Visual Generation

这篇工作处理的不是“图像生成质量不够”这个泛问题，而是统一多模态生成系统里的一个更具体缺口：同一个 LLM 作为视觉理解器时，往往能较可靠地判断一张图是否满足复杂提示词；但作为生成控制器时，却不能把这种理解能力稳定转化为生成约束，尤其在计数、空间关系、属性绑定、物理合理性这类组合语义上容易失真。作者把它定义为 understanding-generation gap。关键点在于，问题不只是文本条件不强，而是生成阶段缺少一个显式的“中间可检验对象”和“基于该对象的纠错信号”，导致模型只能把所有约束一次性压进扩散条件里，难以把验证能力转成可执行的生成指导。

评读框架图和消融即可；它把 LLM 放在 draft-critique-control 环里，比单纯加大条件编码器更像可复用接口。
