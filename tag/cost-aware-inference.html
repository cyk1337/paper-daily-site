EASy: Towards Efficient LLM-Based Agentic System

这篇工作解决的是异构 LLM agent 系统里的一个老问题：如何让 orchestrator 不只追求任务成功率，还能在真实约束下同时考虑执行器能力、调用成本、延迟和中间反馈，学会做动态、分阶段、可泛化的调度决策。现有 router 往往是轻量分类器或打分器，适合单步分发，不擅长处理长程依赖、任务分解、并行执行和执行后再规划；固定工作流则更难适应任务过程中不断变化的上下文。EASy 把这个问题表述成一个可训练的 sequential decision problem：给定一组能力和成本不同的 executors，由 LLM orchestrator 在 milestone 级别做分解、规划、分配和重规划，并用强化学习直接优化性能与效率的折中。

评只看 RL reward 和 unseen-executor 实验；若成本记账干净，它可作为 agentic test-time compute 分配的弱基线。
Junnan Liu,Linhao Luo,Thuy-Trang Vu,Gholamreza Haffari
