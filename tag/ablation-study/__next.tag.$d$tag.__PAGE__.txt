5:T44c,The design decomposes the repair packet into four retry conditions with matched budgets. In resample, the model sees only the original prompt again. In placebo, it sees its failed program plus a content-free notice that it was wrong. In feedback, it also receives the actual failing input, expected output, and observed output. In reflect, it is asked to diagnose the failure in prose before rewriting the code. This separates the value of another draw, self-exposure, diagnostic feedback, and verbal reflection. Retry attempts use temperature 0.8; the authors explicitly avoid greedy retry because it would return byte-identical programs and make resampling meaningless. Each trajectory allows up to k=8 attempts, and pass@1 for all k≤8 is read from the same trajectory. Paired contrasts are tested with exact McNemar tests, task-level bootstrap intervals, and Holm correction. The proposed mechanism is anchoring: once the failed program is in the context, the next sample tends to stay near it and perform local edits, while blind resampling can explore a different region of the solution space.6:T464,The main experiments use Qwen2.5-Coder Instruct at 1.5B, 3B, and 7B, quantized as Q4_K_M and run locally on a single 6GB consumer GPU. MBPP+ with 378 tasks is the primary benchmark. HumanEval+ with 164 tasks is secondary and is treated as underpowered because each cell has only about 32–75 failing tasks, compared with 110–164 on MBPP+. On MBPP+, blind resampling reaches the highest pass rate at 1.5B and 3B, and is statistically tied with the best condition at 7B. The diagnostic content of execution feedback is not detectable: feedback minus placebo is +0.000, +0.026, and +0.008 across the three model sizes, with no significant effect. Self-exposure is harmful at smaller scales: placebo minus resample is -0.061 at 1.5B with p=0.006, and -0.069 at 3B with p<0.001. The abstract also reports that blind resampling uses 2.5–5.5 times fewer tokens than self-repair-style conditions. Reflection weakens the anchor but does not pay for itself. Additional checks rule out prompt length, quantization, and model family as sufficient explanations, and suggest that the penalty is governed by baseline model capability.7:T586,The system wraps an IRED energy-based diffusion reasoning model with a Modern Hopfield trajectory memory. The main task is connectivity-2: given an Erdős–Rényi graph G(N=12, p=0.2), predict its all-pairs reachability matrix. The base model is IRED’s 32-channel GraphEBM, trained for 30k steps with 10 diffusion timesteps and an MSE denoising objective on ±1-scaled targets, with energy-landscape supervision and inner-loop optimization enabled.

Retrieval keys are produced by a 3-layer GIN. The encoder uses a label-ordered readout instead of sum pooling, because the retrieved reachability matrix must preserve the node-label alignment of the query graph. A learned per-position ID embedding is added to avoid collapses in degree-symmetric cases. The key encoder is trained with supervised contrastive learning for 3000 steps; target-nearest neighbors are defined by Hamming agreement over reachability entries.

The main contribution is the five-arm ablation: oracle, best-constant, per-query-random, shuffled, and aligned. The best-constant arm estimates how much can be gained by a favorable fixed initialization. The per-query-random arm tests whether stochastic perturbation alone helps. The shuffled arm keeps the value distribution and retrieval mechanics but permutes key-value pairings. The aligned arm keeps the correct pairing. The aligned-minus-shuffled gap isolates graph-aligned value reuse.8:T4b5,CHIAR-Former is a 4-layer hybrid transformer. For each token, the model computes spectral entropy from the DCT power spectrum of its representation and routes the token to one of three operators: DCT spectral mixing, RBF kernel mixing, or full self-attention. Low-entropy tokens are treated as smooth and sent to DCT mixing. High-entropy tokens are treated as complex and sent to attention. Mid-range tokens are initially assigned to an RBF kernel branch implemented with random Fourier features.

The paper provides a theoretical motivation for this partition: low-entropy tokens admit bounded DCT truncation error, medium-entropy tokens can be handled by kernel approximation, and high-entropy tokens benefit from dynamic cross-token projection. Relative to FNet, the key difference is selective rather than universal spectral mixing. Relative to Mixture-of-Depths or LayerSkip, the model does not skip computation but changes the operator type while preserving depth. The most important technical outcome, however, is that learned routing collapses: the router repeatedly rejects the RBF branch. The authors then embrace that result and build a DCT+Attention-only variant as the effective architecture.9:T410,The headline number is on WikiText-103: the DCT+Attention variant reaches validation perplexity 36.54 versus 66.6 for a full-attention baseline, while using 62.5% fewer attention FLOPs. If the setup is fully matched, that is a large gain. Because the gain is so large, the first thing to verify is baseline fairness: same parameter budget, same training schedule, same context length, same optimizer, and same data exposure.

The broader experimental claim is more interesting than the single best result. The paper reports evaluations on four datasets and finds a clear operating regime: spectral routing helps more on larger, naturalistic text corpora, but loses to full attention on small datasets and synthetic pattern-matching tasks. That boundary condition is informative.
