1) 问题形式化：每轮在候选集合 A_x（k<=20，且用上下文验证的 single-token label 绑定）里选择 n=min(b,k) 个互异动作，输出被 grammar G_x 约束为一个 JSON array：forced syntax token 与“动作槽位”交替出现；槽位处还要 mask 掉已选动作以保证 distinct。传统 grammar-constrained decoding 需要对每个 emitted token 做一次依赖 forward，关键路径 D_serial = n + m_syn（文中 n=3 时约 9）。

2) 可达状态很浅：当 horizon n 有界时，串行 greedy 控制器在后续只会访问“前缀状态”（prefix states）。以 n=3 为例，一旦 a1 固定，后续只需要咨询 (a1) 以及 (a1,c) 这类前缀（c!=a1），总数是 O(k) 而不是指数。

3) 两步执行图：
- Root prefill：对 prompt + 开头 forced syntax 做一次前向，得到 slot-1 logits，并缓存 KV；用与串行相同的规则选出 a1。
- Tree-causal probe：把所有需要的前缀 continuation（每个 continuation 都是“串行解码在该前缀下会生成的 forced token 序列”，包括语法 token 与槽位位置）拼接成一个 batch-like 的长序列，在一次 forward 里计算。关键是构造 block-causal attention mask：每个“行”（一个前缀）只能 attend 到共享的 prompt KV 和它自己的祖先 token；同时使用与串行一致的 position ids，使得每个位置看到的 token ids / position ids / 可见祖先集合与串行完全一致。

4) Policy-exact 理论：
- Prefix-state lemma：若 tree-packed 与 serial 在某个前缀 ρ 上的 token ids、position ids、ancestor-visible attention set、参数一致，则每层 hidden state 一致，从而 logits 一致。

- Setup: At each round, candidates are bound to context-verified single-token labels (k<=20). The grammar forces a JSON array of exactly n=min(b,k) distinct labels, interleaving forced syntax tokens with label slots that mask already-used labels.

- Key observation: With bounded horizon n (deployment uses n=3), the serial greedy controller can only visit a small set of reachable prefix states. After fixing a1, the remaining consulted states are essentially (a1) and (a1,c) for c!=a1, i.e., O(k) states.

- Execution:

  Prefix-state equivalence lemma: if token ids, position ids, ancestor-visible attention set, and parameters match for a prefix, hidden states (hence logits) match layer-by-layer.
