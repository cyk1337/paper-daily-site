9:T933,The method is a two-pass video understanding framework with two key behavioral designs. In the first pass, the model watches the full video at low temporal and spatial fidelity. Visual and audio tokens are interleaved and fed to the LLM together with the question. The output is structured: an initial answer A^(1), a short reasoning trace R^(1), and a temporal localization prediction T = [t_start, t_end]. The localization acts as a policy decision that determines which segment will be revisited at higher fidelity.

In the second pass, the model re-encodes only the localized segment using higher frame rate or resolution, while retaining the first-pass global context and the interaction trace from the first pass. It then produces a refined final answer. The two main design choices are there to make this new re-watch behavior compatible with the pretrained model’s existing answering prior.

The first is re-answer. The authors argue that an instruction-tuned video LLM has an answer-first tendency: given a question and a coarse video view, it naturally tries to answer immediately. Forcing the model into a strict locate-then-reason pattern creates a mismatch with that prior and can destabilize learning. Re-answer avoids this by letting the model answer first in the initial pass, then revise the answer after re-watching. This makes temporal localization an add-on capability attached to the existing QA behavior rather than a replacement for it.

The second is re-ask. Under causal attention, question tokens from the first pass cannot directly attend to newly observed high-fidelity frames in the second pass. That weakens question adherence exactly when the model is supposed to use the new evidence. The fix is simple: inject the query again during the second pass so the question can directly interact with the revisited segment. Mechanistically, this matters because otherwise the second pass mostly extends the first-pass hidden-state trajectory instead of re-conditioning on fresh evidence.

Training-wise, the paper avoids CoT cold-start and CoT-based SFT. It starts from an instruction-tuned base model and directly optimizes re-watch behavior with DAPO-based RL.
