Visual Information-Guided Parallel Decoding for Diffusion Multimodal Large Language Models

这篇工作处理的是 diffusion multimodal LLM 在并行解码时的一个关键缺口：已有 token selection 规则大多只看语言侧的不确定性、置信度或信息增益，却没有把图像证据直接纳入“先解哪些 token”的决策。对 dMLLM 来说，早期被解出的 token 会立刻成为后续条件上下文；如果这些 token 虽然在语言上高信息量、但没有视觉依据，就会把后续生成带到错误的语义轨道上。论文要解决的不是训练目标，而是推理阶段的 decoding policy：如何在不增加训练、不增加额外 forward 的前提下，让并行解码既保留信息增益，又更强地受图像约束。

评看 sampler 定义就够；如果做 MDLM/LLaDA 多模态化，它提醒解码顺序不能只看文本置信度。

Masked Language Flow Models

这篇工作要解决的是非 AR 语言建模里一个很核心的张力。Masked diffusion model 适合 any-position 并行生成，但在 few-step 采样时通常把多个 masked 位置的反向转移做位置独立分解，这个近似恰好在最想要速度的区域最不可靠。Flow language model 则把离散 token 序列搬到连续空间里做联合流动，能避免这种位置独立假设，也有机会蒸馏成少步甚至一步生成；但标准 FLM 在生成时往往需要对所有位置持续解码，不擅长“部分已确定、部分待推理”的迭代式语言生成。论文的核心问题就是：能否把 MDM 的 any-position 条件结构和 FLM 的连续耦合建模合在一起，既保留并行生成能力，又让模型在多步推理任务里逐步确定 token，而不是每一步都重解整句。

评这篇会直接影响你对“flow LM 是否注定不适合复杂文本生成”的 prior；先看它如何把 masking 嵌进 continuous flow，再检查 few-step 结果是否真比 MDM 干净，值得尽快复现小规模版。
Iskander Azangulov,Kianoosh Ashouritaklimi,Leo Zhang,Simon Vary,Patrick Rebeschini
