UpgradeBench: A Decision-Centric Benchmark for Upgrading Fine-Tuned LLM Specialists

这篇工作讨论的是一个很现实但过去几乎没有被系统测量的问题：当组织已经在某个开源基座上训练出一批 task-specific specialist，新的 base model 发布后，到底该继续用旧 specialist、直接迁移 adapter、用旧 specialist 蒸馏新 base，还是重新训练？现有迁移论文通常只测某一对模型之间的 transfer，而没有沿着真实 release sequence 去衡量这个决策问题。UpgradeBench 要解决的是“base-model upgrade tax”的测量：不同升级策略在质量、训练成本和时间上的差距到底有多大，哪些任务值得迁移，哪些任务干脆冻结旧模型更划算。

评适合看作 posttrain 资产折旧评测；读 release 序列实验即可，别把新 base 更强等同于 specialist 必然升级。
Ye Chen,Weining Zhang
