Each channel has an up-projection key, which controls activation, and a down-projection value, which determines the output direction. In a sparsely upcycled MoE, experts are initialized from the same pretrained FFN, so the same channel index remains comparable across experts. The authors use this to measure whether co-activated experts write similar value directions at aligned positions. They find that co-activated experts are partially aligned rather than fully redundant; removing aligned positions changes the preferred experts; and tokens with larger shared coverage need fewer residual experts to reconstruct the original output.
