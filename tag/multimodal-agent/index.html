Defending Against Dormant Poisoning Attacks Across Language and Multimodal Agents

这篇论文处理的是 dormant poisoning 在 agent 场景下的防御问题。已有工作多研究单轮 QA：模型在发布时表现正常，但经过看似无害的下游微调后，会激活预埋的有害行为。作者把这个问题推进到更危险也更现实的设定：语言 agent 和多模态 agent 的输出不是普通文本，而是可执行动作；因此一旦 dormant behavior 被激活，风险会直接落到发消息、泄露隐私、点击恶意页面、在网页中输入敏感信息等具体行动上。全文要解决的核心问题有两个：一是 dormant poisoning 是否会在 agent 和 multimodal agent 中同样成立，并扩展到未见过的有害动作；二是在没有外部安全参考答案、也没有可信干净参考模型的情况下，如何在 benign downstream fine-tuning 过程中抑制这种激活，同时尽量不损伤下游效用。

评不是基座训练论文，但它抓住了一个很实在的接口问题：发布态安全行为能否反过来当防御监督；只看 threat model、Safety Buffer 构造和多行为共存实验就够了。
