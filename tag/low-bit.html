REAL-Q: E2E LLM Quantization via Dynamic Gradient Descent

这篇工作解决的是 LLM 后训练量化里一个很具体但长期存在的问题：主流 GPTQ 系方法为了保留列级闭式求解，会把真实的端到端量化损失近似得过于粗糙，既忽略上游已量化层带来的输入扰动，也忽略下游任务损失对不同输出通道的非均匀敏感性；同时 Hessian 在整层内被冻结，随着列逐步量化，优化目标已经变了，求解器却还在用旧信息。作者把这个问题概括为 information misalignment。

评这篇不改 pretrain，但对“二阶 PTQ 足够好”的 prior 有实质修正；先看方法图和消融，重点判断动态更新的收益是否只在超低比特才成立。

GaugeQuant: Online Learning of Quantization-Optimal Bases from LLM Symmetries

这篇论文解决的是低比特量化中的一个具体但重要的问题：Transformer 在全精度下有一批不改变输出的连续对称自由度，但这些自由度会显著影响量化后的误差。常规 PTQ 在模型训练完成后，用校准集寻找较好的旋转或缩放来缓解 activation outlier；GaugeQuant 的目标是在训练过程中直接学习一个更适合量化的内部基，而不是等模型冻结后再补救。

评做低比特训练或量化感知预训练的团队应立刻复现正则项+stop-gradient的组合，它把“量化友好基”从后处理问题变成了训练内原生问题。
Miguel P. Bento,João Seabra

Robust Ultra Low-Bit Post-Training Quantization via Stable Diagonal Curvature Estimate

在超低比特（如2–4bit）权重量化的PTQ场景中，基于Hessian的误差补偿（如GPTQ利用逆Hessian的非对角项做跨通道传播）在小校准集下会因曲率估计噪声而失效，导致生成质量/零样本精度显著下降；如何在“校准数据极少”的约束下获得更稳定的曲率权重并实现鲁棒PTQ。

评看失败分析：GPTQ在小校准集下非对角曲率噪声爆炸，退回稳定对角估计反而救2-3bit；对你做低成本评测/推理很实用但不新颖。
