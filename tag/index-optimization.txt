A group is aggregated into a single proxy query, which traverses the prefix once and selects a shared candidate set of size c. Then there are two variants. PIVOT-Refine rescoring: each query re-scores only the shared candidate set and picks its own top-k. This changes per-query work from O(L) to O(c), where k < c << L. Importantly, PIVOT preserves the DSA interface and leaves the downstream Sparse MLA operator unchanged, making it a drop-in replacement.
