9:T6cd,The method has two layers. First, a diagnostic framework. In each trajectory, the agent retrieves candidate pages, inspects page images, writes source-linked findings into working memory, and finally outputs both a final answer and terminal memory. A frozen reader then sees only the question plus terminal memory and produces a memory-only answer. An official judge scores both the final answer and the memory-only answer against the gold answer, yielding binary indicators for answer correctness and memory answerability. This produces a four-cell analysis, with special attention to P_mmc, the fraction of answer-correct cases whose terminal memory is still not answerable. The key design choice is that memory quality is defined functionally—whether it preserves enough information for answering—rather than stylistically.

Second, the training algorithm AWM-GRPO. All compared agent variants share the same Qwen3-VL-4B policy, retrieval harness, tools, memory schema, prompts, and optimizer; only post-training and reward differ. For each sampled trajectory, the policy emits a final answer and terminal memory; the frozen reader answers from memory alone; the judge scores both outputs. GRPO then ranks trajectories using not only final-answer correctness but also memory-only answerability, preferring trajectories that both solve the task and leave behind answerable memory. This differs from answer-only GRPO, which optimizes the end result but is indifferent to the quality of the stored state. It also differs from direct memory supervision: instead of imitating a gold summary, the method supervises memory indirectly through its ability to support answering, which is closer to the actual role memory plays in an agent loop.a:T57a,The experimental setup is carefully controlled.
