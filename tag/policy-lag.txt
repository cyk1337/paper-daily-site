18:T521,The generation process is formulated as a token-level MDP. The state is the prompt plus the generated prefix, transitions are deterministic token appends, and the verifier reward is observed only at the terminal position. Under ordinary value regression on stale trajectories, the squared-loss minimizer follows the Bellman operator of μ, so repeated critic updates converge toward V^μ. The actor, however, needs advantages based on V^π. The induced bias is position dependent: it is largest near the beginning of a response because the remaining suffix is generated under the stale policy.

BRACE modifies the value target rather than only the actor objective. It uses a k-capped correction horizon, applying importance correction only over the next k policy tokens after each position. This avoids multiplying π/μ ratios over an entire long sequence. Beyond that local window, it attaches an anchored Monte Carlo tail with a constant weight, so the terminal reward still reaches every position. The design separates local policy-mismatch correction from long-range reward propagation.
