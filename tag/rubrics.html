EvoRubrics: Dynamic Rubrics as Rewards via Adversarial Co-Evolution for LLM Reinforcement Learning

基于 rubric 的 RL 奖励在开放式生成任务（无标准答案可验证）中会随策略改进而逐渐饱和和被 hack：静态评价标准无法匹配不断变强的 policy，而现有动态 rubric 方法要么依赖外部强模型、粒度粗糙，要么仍绑定可验证答案，无法在训练步粒度上实时随策略演化。

评奖励随策略共同演化这个 setup 值得看，但最容易奖励漂移；先读训练稳定性和 hacking 分析，别只看总分。
Hongxin Ding,Baixiang Huang,Yue Fang,Weibin Liao,Zheng Li,Jinyang Zhang,Zhijing Wu,Junfeng Zhao,Yasha Wang

Support Vector Rubrics: Closing the Gap Between Self-Generated and Human Rubrics

这篇工作处理的是 LLM judge 里一个很具体但很关键的问题：自动生成 rubric 时，模型往往写出的是“好答案通常应具备什么”，而不是“这两个候选答案究竟差在哪里”。前者偏描述性，后者才是偏好学习和奖励建模真正需要的判别性标准。论文把 RubricBench 上自生成 rubric 与人工 rubric 之间二十多个点的准确率差距，解释为目标错配而不是 judge 本身不会判断。要解决的核心问题因此不是提升 judge 的语言能力，而是如何从 preference data 中学到一套靠近决策边界、能稳定迁移、且在推理时不依赖候选答案内容的 rubric 机制。

评值得 skim；把 rubric 当判别边界而不是说明书，这个 prior 应放进 reward/eval 数据管线的 ablation。
Mengyuan Sun,Yu Li,Zhuohao Yu,Shikun Zhang,Wei Ye
