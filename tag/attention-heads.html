Head-Aware Key-Value Compression for Efficient Autoregressive Image Generation

这篇工作处理 AR 图像生成里的 KV cache 开销问题。高分辨率图像会被展开成很长的视觉 token 序列，生成 1024×1024 图像时 KV cache 可超过 50GB。已有 LineAR 类方法发现视觉 token 主要关注相邻空间区域，因此保留少量行缓存即可。但它给每个 attention head 分配相同预算，忽略了不同 head 的注意力模式差异。

评将 LLM 中常见的 Head-aware KV Cache 压缩思路迁移到了自回归图像生成（AR Vision）中，验证了视觉 token 同样存在局部/全局注意力头的异质性，做 AR Vision 效率优化的可看。

Pyramid Forcing: Head-Aware Pyramid KV Cache Policy for High-Quality Long Video Generation

这篇论文解决的是自回归视频生成中的长程退化问题：生成时间变长后，外观漂移、运动变弱、身份模糊会逐步积累。作者指出，问题不只是历史信息太多或太少，而是现有 KV cache 策略把所有 attention head 当成同一种历史依赖模式处理，导致该保留的长程锚点、周期性运动信息和局部连续性被混在一起压缩。

评读 head 分类和 ragged-cache 实现；它把“所有头同一缓存窗口”这个默认设定拆开了，值得对长上下文 LLM 做同类探针。
