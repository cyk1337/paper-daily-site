9:T4eb,BrowserForge has four main components. First, open-web URL sourcing and cleaning: candidate URLs are drawn from Common Crawl and filtered into a large pool of real, reachable, publicly accessible websites. This replaces fixed website whitelists with the open web itself as the source of diversity. Second, parallel browser sandbox orchestration: a cluster manager schedules hundreds of browser sandboxes through a shared work queue, turning web interaction collection into a high-throughput process. Third, a Proposer–Solver synthesis loop: a Proposer agent inspects a rendered page and proposes an executable task, and a Solver agent attempts the task and records the trajectory. Structured page information such as the accessibility tree is used only during synthesis as an auxiliary signal; it is not part of the deployed agent’s inference input. Fourth, verification and cleaning: rule-based and model-based filters remove invalid or low-quality trajectories, and the surviving reasoning traces are rewritten into a unified chain-of-thought format.
