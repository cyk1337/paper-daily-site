Each prompt states two relationships among three entities and asks for an implied relationship. To reduce reliance on memorized entity semantics, the same tasks are tested with synthetic entity names. For mechanism, the paper analyzes open-weight Transformer activations over the tokens that express the relationships, forming an activation tensor over token positions and layers. It then uses causal mosaic experiments that manipulate internal activations to test how structure and identity are represented. The central claim is that models build an abstract representation of relational structure, combine it approximately additively with entity identity, and bind entities to roles in that structure. For multi-step inference, the evidence points to storage of observed pairwise links that are composed retrospectively at query time, rather than full precomputation of all implied relations during context processing.19:T620,NCE has three core components. First, it organizes the running context into addressable blocks. Each block is named by dedicated address tokens, and some blocks such as system prompts or tool declarations can be locked. Second, it defines an executable editing grammar inside the model vocabulary. The grammar includes address tokens plus operator tokens such as drop, rewrite, and append, together with composition rules for forming valid edits. A task-agnostic runtime maps each well-formed edit to exactly one context-state transition. This is the key design choice: edit semantics are not explained in the prompt or delegated to external tool schemas, but anchored in the model vocabulary and a fixed executor. Third, it builds supervision with a two-teacher pipeline. An offline teacher reads the full trajectory and assigns each block a release point, meaning the earliest turn after which the block can be safely edited because its role in the task has ended. An online teacher only sees the current context plus those release annotations and decides when and how to edit. The crucial training detail is evolving-context distillation: after an edit is generated at the end of a turn, the runtime executes it before constructing the next turn’s input and labels. This avoids conditioning future supervision on text that the model has already deleted or rewritten. That combination matters: the gains are not coming from simply retaining more context. Against a tool-call editing baseline trained on the same edits, NCE is ahead by 5.2 to 8.0 points, which is the paper’s strongest evidence that native editing grammar has value beyond generic context editing. The gains transfer to Qwen3.6 as well, with an average success-rate increase of 4.5 points and a 15% reduction in average token usage. Recall reads from the same memory and injects the retrieved representation into the current hidden state. Exit stops the inner loop and emits the next token through the language-model head.
