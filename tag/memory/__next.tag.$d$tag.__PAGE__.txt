9:T445,The paper starts from the setting where the task horizon H is much larger than the context window C, process lifetime P, human attention interval A, and component failure interval F. It derives seven bottlenecks: Autonomy, Horizon, State, Resilience, Delegation, Correctness, and Cost. The proposed architecture has four abstractions. A level is a time-scale layer that keeps a bounded file summarizing the layer below and sends sparse directives downward. A tick is one autonomous action cycle: read state, reason, act, and write state back. A protocol is a named file or channel with specified writer, reader, cadence, and check. A tier is an intelligence level, including judgment models, labor models, and deterministic processes. Cascaded intelligence routes work upward when the cost of being wrong justifies a stronger model or human attention. Downward channels carry steering, while upward channels carry compressed state, back-pressure, escalation lines, and kill verdicts. The design avoids relying solely on longer context; it makes external state explicit, bounded, and auditable.a:T56b,The paper has three technical layers. First, it reframes memory retrieval as an implicit non-parametric policy and the stored utility score as a proxy reward. Under this view, writing high-scoring episodes and reusing them later is a form of policy improvement in memory space. The Echo Gap is then defined as a systematic mismatch between self-assessed reward and true success, amplified by retrieval frequency.

Second, the paper provides a diagnosis through the Error-Independence Assumption (EIA). The key claim is that a stronger verifier is not sufficient if its errors are correlated with the original self-grading bias. The recoverable benefit of correction depends on two quantities: how well verifier scores align with true utility, and how decorrelated verifier errors are from the original bias. This is the most useful conceptual contribution: correction requires not just more capability, but a different error channel.

Third, the paper proposes mitigation through per-memory de-inflation rather than global calibration. A label-blind global remapping of scores cannot identify which specific memories are overvalued. Instead, the authors argue for memory-specific demotion using auxiliary signals that are less likely to share the same bias. They instantiate this idea with an answer-free de-inflation method and test it in a Memento-style retrieve–inject–write loop.b:T55b,The experiments are split into bank-level diagnosis and end-to-end behavioral impact. At the memory-bank level, the paper shows that incorrect episodes are systematically over-rewarded across the studied model families and factual memory banks, and that the inflation correlates with future reuse. This is not mere random judge noise. More capable re-graders are often better on average, but their residual errors can still align with the original self-grading bias, which limits their corrective value.

At the agent level, the paper evaluates a faithful memory loop on BIRD text-to-SQL. The agent retrieves similar past episodes, injects them into context, solves the current task, and writes the new episode back without access to ground-truth labels at write time. Final evaluation uses official execution accuracy. The reported result is that self-graded write-back progressively corrupts the memory bank, while the proposed de-inflation method consistently improves over the self-graded baseline across random seeds. This shows that the Echo Gap is not only a scoring artifact; it translates into measurable behavioral degradation.
