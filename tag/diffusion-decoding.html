AngelSpec: Towards Real-World High Performance Inference with Speculative Decoding

投机解码在真实线上负载里呈现强异质性：不同请求分布（高熵对话 vs 低熵代码/数学）、不同并发与硬件条件下，"同一种 drafter 结构 + 固定验证深度"很难同时做到高接受率与低端到端延迟。论文要解决的是：如何把 speculative decoding 从“单一 drafter 追平均”推进到“面向负载分布与在线资源约束的端到端方案”，同时给出可复现实验与训练基础设施。

评这篇不改 pretrain prior，但会改你对 spec decode 的工程 prior：别再找万能 drafter，先按任务熵和续写可预测性分桶；重点看训练分流和 DFly 设计。

BlockPilot: Instance-Adaptive Policy Learning for Diffusion-based Speculative Decoding

这篇工作处理的是 diffusion-based speculative decoding 里一个此前被当作静态超参数的问题：block size 应不应该对所有样本固定。现有方法通常沿用训练时的固定 block size，在推理时对所有输入一刀切；但全文的实验表明，不同样本的最优 block size 差异明显，而且这个选择会直接影响 acceptance length、target model 验证开销和最终 wall-clock speedup。论文要解决的核心问题不是再造一个更强的 draft model，而是在不改 target / draft / verifier 主体框架的前提下，学习一个样本自适应的 decoding policy，让每个输入在 prefilling 之后选择更合适的并行生成粒度。

评这类工作不改 pretrain，但会影响你对离散 diffusion 解码瓶颈的判断；只看自适应 block size 的证据和收益曲线，别把它误读成新建模范式。
Hao Zhang,Yiming Hu,Yong Wang,Mingqiao Mo,Xin Xiao,Xiangxiang Chu
