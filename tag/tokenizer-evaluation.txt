- Define the set of valid tokenizations T(x) for a string x, including the canonical tokenization T_canon(x).

- Construct alternative token sequences composed of valid vocabulary tokens that decode to the exact same surface string, isolating distribution shift purely in token segmentation.

- A multilingual sweep over 27 languages spanning diverse scripts, 6 downstream tasks, and 3 recent model families.
