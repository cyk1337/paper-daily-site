Measuring the Serving Stack Instead of the Model: Hidden Confounds in Local Tool-Use Evaluation

这篇论文要解决的不是工具调用能力本身，而是工具调用评测里的一个隐藏测量误差：本地 agent 评测通常把“模型是否会正确选择并发出工具调用”当成模型能力，但在实际栈里，请求先经过 serving layer，是否接受 tools= 参数、是否把 schema 渲染进 prompt、是否把输出解析成结构化 tool_call，往往由服务端模板和配置决定，而不是由模型权重决定。结果是，评测可能测到的是 Ollama、llama.cpp、vLLM、SGLang 这些 serving stack 的协议行为，而不是模型的 tool-use 能力。

评非常务实的避坑指南，做 Agent/Tool-use 评测的同学必看，提醒我们 0 score 往往是 infra 没对齐而不是模型真不行。
Lijuan Tang,Yuemeng Zheng
