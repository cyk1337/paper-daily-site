b:T7ab,The paper has three technical layers. First, it runs a systematic empirical study over seven open-source VLMs and six benchmarks. It compares two TTC families: response selection methods based on handcrafted textual features, and confidence-based aggregation methods such as majority voting. The experiments separate chain-of-thought from non-CoT prompting, and also distinguish repeated sampling from a single model versus multi-model ensembles. The empirical result is clear: feature heuristics fail in VLMs because linguistic style, confidence wording, or response length do not reliably track visual correctness. Majority voting gives only small but consistent gains, and only when CoT is used.

Second, the paper provides a dependence-based analysis of voting. The key point is that voting assumes some degree of diversity across samples. If predictions are positively correlated, repeated samples do not reduce error nearly as much as the independent-vote intuition would suggest. In VLMs, repeated outputs from one model share the same visual encoder, alignment biases, and decoding tendencies, so the resulting dependence is structurally hard to avoid. This explains why single-model TTC is weak.

Third, the paper proposes ETTC, an entropy-based aggregation rule. Instead of simply counting final answers across all models, ETTC first forms an answer distribution within each model from multiple responses, then uses the entropy of that distribution as a confidence signal. Lower entropy means the model is more internally consistent on that example. This matters in heterogeneous ensembles: plain majority voting can let several weaker but correlated models dominate a stronger one, while ETTC uses confidence concentration to prioritize more reliable predictions. In the single-model case, ETTC reduces to majority voting, so it is backward compatible with standard self-consistency. Unlike learned judges or reward models, ETTC remains inference-only.c:T58e,From the provided full text, the evaluation covers seven open-source VLMs and six benchmarks, with two ensemble settings: a cross-family setup using similarly sized but architecturally different models, and a same-family setup with different scales. The main findings are: feature-based response selection does not improve accuracy; single-model majority voting yields only modest gains and only under CoT prompting; without CoT, aggregation is largely ineffective. In multi-model ensembles, ETTC consistently beats standard majority voting and in some cases surpasses the best individual model in the ensemble. That last result is the most important empirical point: smaller models can help stronger ones if the aggregation rule can exploit sample-level reliability instead of flattening all votes.
