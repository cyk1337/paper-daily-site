ECHO: Efficient Causal Self-Recursion Beyond Auxiliary Multi-Token Prediction

这篇工作要解决的是：现有 multi-token prediction（MTP）虽然能给预训练提供更密的监督，也能服务 speculative decoding，但它通常只是挂在主干模型外面的辅助头。这样有两个直接问题。第一，多步未来 token 的监督大多被 horizon-specific 的辅助模块吸收，真正负责 next-token 生成的 backbone 只得到间接收益，所以长程规划能力提升有限。第二，想把监督深度做深，代价会线性上升：每多一个 horizon，就多一套模块和一轮计算，因此大规模训练里往往只敢做 depth-1 draft。ECHO 的目标，是把多步未来预测从“外挂辅助任务”改成“主干自身递归执行的训练方式”，让未来监督直接落到 backbone 上，同时把更深 horizon 的训练成本压到可接受范围内。

评这篇会直接影响你怎么看 MTP：如果监督真落在 backbone 比外挂 head 更有效，就该立刻做 internal ablation；先看 DDS 成本曲线和 reasoning/code 的饱和对比。

NITP: Next Implicit Token Prediction for LLM Pre-training

这篇工作要解决的不是“下一个 token 预测是否有效”这个大问题，而是一个更具体、也更容易被忽略的问题：标准 NTP 只在输出 logit 空间用 one-hot 标签监督模型，导致最后层隐藏状态的几何结构约束很弱。只要目标 token 的 logit 足够高，隐藏表示在大量与目标方向正交的子空间里如何分布，损失几乎不敏感。作者把这类自由度称为训练目标的结构性盲区，并进一步指出，这种弱约束会让表示在训练中逐步滑向低秩、各向异性的退化形态。论文的核心问题因此可以表述为：如何在不放弃 NTP 主目标、也不引入外部教师模型的前提下，为 next-token pretraining 增加对隐藏表示几何的直接监督，让模型不仅“猜对 token”，也学到更稳定、更有表达力的内部表征。

评这类“给 AR 加表征监督”的工作少而且可能真改训练几何；建议先看 loss 定义、stop-grad 细节和等算力对比，若 clean 应立刻做小规模复现。
