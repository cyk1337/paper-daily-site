18:T515,For each output position, the model runs an internal decision process over a hidden state h, a fast-weight memory M, and a counter of Think steps. The latent policy chooses among Think, Recall, and Exit. Think applies a shared Transformer block again, increasing effective depth without adding new block parameters, and writes the resulting state into memory. Recall reads from the same memory and injects the retrieved representation into the current hidden state. Exit stops the inner loop and emits the next token through the language-model head. This differs from external-memory agents, where memory is usually read back as text or context, and from looped latent-reasoning models, where the loop has no native memory read action. The training method, Counterfactual Policy Distillation, branches every allowed action for one step at each latent state, including Exit, and scores the branch by the change in the gold token log-probability. The resulting cost-charged, signed gain supervises the action policy. In addition, recall improvements on positive-advantage trajectories are differentiated through the fast-weight memory, assigning credit to earlier Think writes.
