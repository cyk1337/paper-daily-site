AgentTrace: Execution-Level Fingerprinting of Black-Box LLM Agents

黑盒 LLM Agent 往往隐藏基础模型、系统提示和编排层。传统基于文本风格、n-gram、困惑度或水印的溯源方法容易被提示改写、工具格式约束和代理层掩盖。该工作试图通过可观测执行轨迹识别 Agent 背后的基础模型。

评有点意思，信号不在文本而在 tool-failure trajectory；对 tokenizer 和 agent 接口研究都值得看，但先把它当安全侧现象学，不要急着上升成模型本质。
Gejian Zhao,Hanzhou Wu,Xinpeng Zhang

Agents that Matter: Optimizing Multi-Agent LLMs via Removal-Based Attribution

论文要解决的是多智能体 LLM 系统里的 credit assignment：当系统表现变好或变差时，如何把贡献或责任归因到具体 agent、角色和交互结构上，而不是只看整体成功率。

评值得看 §3 的形式化和 LOO 对比；它给 agent 系统调参一个干净基线，也提醒别用自省 judge 代替真实 ablation。
Mingyu Lu,Yushan Huang,Chris Lin,Su-In Lee
