PersistentKV: Page-Aware Decode Scheduling for Long-Context LLM Serving on Commodity GPUs

在长上下文 LLM 推理的 decode 阶段，由于算术强度低，性能瓶颈往往在于 KV-cache 的访存和调度。现有的单一最优 kernel（如 FlashInfer）在面对低并发、长上下文或混合序列长度的 serving 场景时，可能无法充分利用 GPU 资源。

评只看调度设计和混合长度实验即可；它不改变模型训练，但能提醒长上下文效率瓶颈已从 kernel 转到 page-level scheduling。

Ragged Paged Attention: A High-Performance and Flexible LLM Inference Kernel for TPU

在 TPU 上做高性能 LLM 推理时，服务端工作负载往往是动态且“ragged”的（prefill/decode 混合、序列长度不齐、KV cache 频繁更新）。XLA 更偏静态图优化，TPU 的 tiled/packed 内存布局也让细粒度切片与 KV 写入变得昂贵。论文要解决的是：在 JAX/XLA 生态里，给出一个能稳定处理 ragged 批次、同时接近硬件上限的 TPU 原生 attention 推理 kernel。

评如果你关心 TPU 上的大模型 serving，这篇该看；重点读 kernel 设计和 workload specialization，别把它误读成算法创新，价值主要在系统约束下把 paged attention 做对。
Jevin Jiang,Ying Chen,Blake A. Hechtman,Fenghui Zhang,Yarong Mu

IceCache: Memory-efficient KV-cache Management for Long-Sequence LLMs

长序列 LLM 推理中，KV-cache 随序列长度线性增长，GPU 显存成为主要瓶颈；现有“CPU offload + GPU 保留子集”的方法在“选哪些 token 留在 GPU”上不够精准、更新机制不够强，导致长生成（如 CoT、多步推理、长摘要）中命中率下降、性能与准确率显著退化。

评只看 GPU/CPU 分层策略与长生成退化曲线；方法未必通用，但能给你一个可复现的 offload 基线和命中率诊断框架。
