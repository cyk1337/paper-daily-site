9:T4f3,T-DIG reformulates diverse image-set generation as a conditional generation problem. Given a base prompt and a free-form textual axis of variation, the system should produce K images that differ along that axis while staying aligned with the original prompt. The key design choice is to leave the text-to-image model frozen and instead train an LLM policy that expands the base prompt into K axis-conditioned prompts, or into edit instructions in the editing mode. Those prompts or edits are then executed by a frozen image generator or editor. Training uses GRPO. The reward has two parts: a text-conditioned diversity reward based on TPIPS, which measures whether the image set actually differs along the requested axis, and a baseline-relative alignment penalty that discourages drifting away from the original prompt just to gain diversity. The full system is interactive: users can inspect default samples, receive suggested axes, specify set size and diversity strength, and either regenerate or edit an existing set. 系统前端的 PE 模块不是简单 prompt rewrite。它会根据任务类型路由到不同的 guidance 流程，必要时检索知识和视觉参考，再生成详细的内容与布局规范。关键点在于它输出的布局描述与 DiT 训练时使用的条件接口兼容，因此不是“用自然语言尽量说清楚”，而是“产出模型真正学过的可执行规范”。这也是它和通用 generator-agnostic prompt agent 的主要区别。

The generator is designed around a unified text-conditioning pathway: ordinary natural-language prompts and explicit layout specifications are both fed through the same textual interface, instead of using separate text and layout encoders. This keeps the interface simple and flexible, but it also requires the model to learn from supervision at different levels of structure and granularity.

The pretraining recipe has three notable components. First, broad data retention. The report argues against overly aggressive aesthetic filtering, because information-dense graphics, UI-like images, posters, and text-heavy visuals contain the exact signals needed for long-text rendering and layout following. Second, multi-granularity and structure-aware textual supervision. The model is trained not only on generic captions but also on finer and more structured textual signals that describe content, local elements, spatial relations, and layout constraints. The point is not merely to add more text tokens, but to cover both semantic content and placement instructions. Third, progressive-resolution training. Lower resolutions help the model learn global composition and alignment first, while later higher-resolution stages improve text legibility and local layout fidelity. For long-text rendering, this curriculum is more stable and more compute-efficient than training at full resolution from the start.

The prompt enhancement module is more than prompt rewriting. It routes requests to task-specific guidance, retrieves knowledge and visual references when needed, and outputs detailed content and layout specifications that are compatible with the generator’s training interface. That compatibility matters: the enhancer is not just making prompts longer, it is producing conditions in a form the backbone has actually learned to follow. This is the main difference from generator-agnostic prompt agents.d:T73a,The evaluation is split between backbone rendering ability and end-to-end system performance.
