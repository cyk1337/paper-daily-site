19:T745,The benchmark has three main design components. First is a three-stage task construction pipeline. Stage 1 collects egocentric videos with explicit spatial and temporal cues, so the visual stream is not decorative but task-relevant. Stage 2 builds a tool library and a database that contains both visible information from the video and invisible but contextually necessary information outside the video. This creates an intentional information gap: the model cannot solve the task from perception alone and must query tools. Stage 3 designs tasks that require four ingredients to succeed: understanding entities, actions, or temporal cues in the video; retrieving hidden but relevant information through tools; performing logical reasoning; and updating database state through tool actions. This is stricter than standard VQA or tool-use benchmarks because success depends on environment state change, not only on a textual answer.

Second is the simulated user environment. Instead of a fixed script, the authors use an Actor-Evaluator-Summarizer setup. The Actor generates user responses, the Evaluator checks them against four binary criteria for naturalness and task alignment, and the Summarizer maintains interaction state for subsequent turns. The benchmark supports three interaction modes: Dynamic Easy, Dynamic Hard, and Static, allowing evaluation under different levels of interaction complexity.

Third is the evaluation protocol. EgoBench uses joint validation: process-level tool-call coverage plus result-level database state equivalence. Because tasks are designed to require both tool invocation and state modification, this deterministic protocol avoids the ambiguity of judging free-form text outputs. For agent benchmarking, this is a strong design choice: it makes failures easier to localize and supports automated large-scale evaluation.1a:T424,EgoBench contains 1,045 tasks across four daily scenarios: dining, kitchen operations, food ordering, and retail. The authors benchmark eight video-MLLMs. The best model achieves only 20.19%, 16.75%, and 21.34% average success across the three interaction modes, aggregated over the four scenarios. Even in retail, the strongest scenario for the top model, the average success rate is only 30.62%.

The error analysis is one of the more useful parts. Failures are decomposed into five categories: multimodal perceptual misinterpretation, hallucination, structural non-compliance, logical fallacies, and risky operations. That breakdown matters more than the headline score because it helps separate perception failures from action-format failures and reasoning failures. The excerpt provided does not include the full per-model tables, but the setup strongly suggests that structural non-compliance and perceptual grounding errors are major bottlenecks: once a tool call is malformed or a visual reference is misread, the whole multi-step trajectory collapses.1b:T434,This is a skim paper.
