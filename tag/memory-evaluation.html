RENDER: Controlling Reader-Facing Evidence in LLM Memory Evaluation

在记忆和 RAG 系统的评测中，提供给模型的上下文形式（如原始对话、摘要、结构化记录）通常被视为无关紧要的实现细节，但实际上这种表面形式的差异会极大地影响模型的回答准确率，导致评测结果混淆了模型能力和上下文呈现方式的影响。

评这不是在讲更强记忆，而是在提醒你很多 memory/RAG 结论可能被 prompt rendering 污染；读实验设计和主表就够，适合拿来重审内部 benchmark。
Yuan Si,Simeng Han,Daming Li,Jialu Zhang
