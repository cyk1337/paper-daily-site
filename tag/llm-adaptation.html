Frustratingly Simple Black-Box Adaptation of Language Models via Logit Bias

这篇工作研究一个很受限但现实的问题：当模型只能通过 API 调用、拿不到权重、梯度和隐藏状态时，能否只靠一个对全词表共享、且在每个解码步都固定加到 logits 上的向量，完成有用的模型适配。论文关心的不是通用能力提升，而是这类黑盒部署场景下的最小控制原语是否足以实现稳定的行为修正，例如缩短输出、改善格式、在小规模私有分布上做轻量适配。全文的关键点是把这个问题写成 KL 正则化的 RL：最优策略天然是 prefix-dependent 的，而作者研究的是一个极弱的近似族——context-independent 的固定 logit bias，进而分析这种近似什么时候有效、误差来自哪里、如何在黑盒条件下估计和学习。

评方法极简且有理论支撑，§3的推导和§4的实验设计值得参考，可用于内部轻量适配的快速验证。

Beyond LoRA vs. Full Fine-Tuning: Gradient-Guided Optimizer Routing for LLM Adaptation

在不同任务与数据规模下，LoRA 与全参微调（FFT）各自有明显优势与失败模式，但现有方法通常只能“二选一”或用静态/逐层的 rank 调度去折中，导致要么容量不够（知识注入类任务），要么过拟合/遗忘（小数据或需要保守更新的任务）。论文要解决的是：能否在一次训练里，让同一个模型在“需要高容量时像 FFT、需要强正则时像 LoRA”之间连续切换，同时避免自适应 rank 带来的优化器冷启动与训练不稳定。

评读 optimizer routing 设计和消融即可；它可能改进适配流程，但还没动到预训练目标。

Skill Neologisms: Towards Skill-based Continual Learning

论文讨论的是如何在不更新模型权重的前提下，为已训练好的 LLM 增加可复用、可组合的新技能。目标不是学习一个任务前缀，而是学习一种“技能词”：模型在上下文中看到这个新 token 后，能更稳定地调用某类程序性能力，并且能和已有技能或其他独立学到的技能组合。

评看 compositionality 实验和 token 分析；若结果稳，它会改变“新技能必须改权重或塞上下文”的默认取舍。
