VeryTrace: Verifying Reasoning Traces through Compilable Formalism and Structured Verification

思维链（Chain-of-Thought，CoT）多步推理中早期的逻辑、计算或隐含假设错误会静默传播到后续步骤，生成看似合理但错误的输出。现有缓解方案存在本质权衡：端到端验证仅检查最终答案，推理链失效时无细粒度诊断；自一致性投票法需要多次高成本采样，无法定位单条推理链的错误原因；形式化证明器（Lean、Coq等）验证严格，但需要领域专家手动形式化，无法跨领域通用。目前缺乏能提供步骤级验证粒度、同时支持跨领域泛化的推理过程验证框架。

评针对推理verifier的实用设计思路，混合可执行检查与LLM审计，适合RLVR研究者参考，重点看§3 DSL设计和§4验证流程即可。
Ninghan Zhong,Ahmet Ege Tanriverdi,Kaan Kale,Sriram Vishwanath

ReaComp: Compiling LLM Reasoning into Symbolic Solvers for Efficient Program Synthesis

这项工作处理的是程序归纳中的推理成本问题：LLM 在 Programming by Example 任务上可以靠 Best-of-K、迭代反馈等 test-time scaling 得到较好结果，但在长程序和组合性更强的样例上会出现大量重复搜索、循环和 token 浪费。ReaComp 的目标不是让 LLM 在测试时继续多想，而是把少量推理轨迹离线编译成可复用的符号求解器。测试时先用符号求解器做结构化搜索，必要时再回退到 LLM。

评值得看方法循环和 PBEBench-Hard 结果；它提醒 test-time scaling 不总是该留在 token 空间里做。
