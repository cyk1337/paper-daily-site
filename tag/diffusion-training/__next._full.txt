18:T554,BlendFusion is an automated pipeline built on Blender/BlenderProc and path tracing to produce high-quality image–caption pairs:
1) Object-centric camera placement: for each mesh object, compute its AABB center; place cameras on a horizontal orbit with azimuth sampled every 45° (8 views) and fixed elevation at 0° (eye-level). Each camera uses a look-at transform toward the object center. To enforce consistent framing, the camera distance is adapted using the object’s projected bounding-box size so the object occupies a fixed vertical fill fraction f (set to 2/3), yielding scale-normalized compositions across objects.
2) Rendering: physically based path tracing in Blender for geometry/lighting consistency.
3) Robust filtering: heuristic rules plus vision-language-model-based filtering to remove low-quality/failed renders (e.g., heavy occlusion, poor framing, artifacts).
4) Diversity-aware sampling/deduplication: remove near-duplicates and maintain diversity so the dataset is not dominated by similar views.
5) Automatic captioning: generate captions for the retained images to form final image–caption pairs.
