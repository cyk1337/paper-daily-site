WebRider: Persona-Conditioned Intent Controllers for Live-Web Assistance

这篇工作处理的不是“网页任务能否做完”，而是“代理是否沿着用户委托的方式把任务做完”。作者指出，现有 live-web agent 评测几乎都只看最终答案或任务完成率，忽略了执行过程中的策略约束：要核验哪些证据、遇到不确定性时是否该追问、哪些偏好必须进入排序、什么时候应该停止而不是继续猜。问题的难点在于，这类委托策略不是静态标签，而是会贯穿浏览、点击、检索、澄清、停止、回答整个闭环；而且 live web 页面持续变化，最终答案即便看起来合理，也可能是在违反用户 policy 的情况下得到的。作者把这类可审计的委托策略形式化为 intent contract，并把核心问题定义为：如何在动态网页环境中，让 agent 在每一步都保持对 contract 的忠实执行，而不是只在终点上“看起来答对了”。

评读 abstract 的 99.2/38.8 缺口和 intent contract 设计即可；它会影响 agent reward 怎么写。

MemPrism: Task-Conditioned Relational Memory Views for Long-Horizon Agents

这篇论文讨论的是长程 agent memory 里的一个更细的失败类型：信息已经被存下来了，也被取回来了，但呈现方式不适合当前决策，因此 agent 仍然用不好。作者把这个问题称为 representation mismatch，并把它和更常见的 storage failure、retrieval failure 区分开。核心问题不是“记忆有没有”，而是“同一段历史在当前子任务下应该以什么关系结构被组织出来”。例如，检测循环需要把重复动作和结果对齐，状态跟踪需要按实体聚合同一对象的变化，失败分析需要把动作和环境反馈连起来，依赖分析则需要把相隔很远的事件串起来。固定的时间线、摘要或向量检索结果，往往只能支持其中一类关系，不能覆盖所有决策需求。

评读方法图和 memory ablation 即可；它把“存得多”改成“按任务重排”，比多数向量记忆论文更干净。
