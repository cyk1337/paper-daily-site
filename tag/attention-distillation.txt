18:T653,The paper first formalizes two kinds of cross-modal attention in autoregressive MLLMs:
- Prompt-to-Vision (P→V): prompt tokens query visual tokens during instruction encoding.
- Response-to-Vision (R→V): response tokens query visual tokens during decoding.

Instead of proposing a loss immediately, the authors begin with an empirical characterization. They measure how teacher-student similarity in each attention type relates to downstream performance. The main finding is that R→V similarity matters, while P→V similarity contributes little.

Based on this, they propose TRAG, Token-level Response-visual Attention Guidance. The method discards prompt-phase attention supervision and focuses entirely on response-phase visual attention. More importantly, it does not apply a uniform KL loss over all response tokens. The loss is modulated by the entropy of the teacher’s attention distribution for each token.

The intuition is straightforward. Some generated tokens require sharp, localized visual grounding, such as object names or attributes. Others rely on diffuse scene-level context or mostly linguistic priors, such as function words. Teacher attention entropy acts as a token-wise indicator of this distinction. Low-entropy teacher attention suggests precise grounding and should induce stronger, sharper alignment; high-entropy attention suggests broader coverage and should not force the student into an artificially peaky pattern.
