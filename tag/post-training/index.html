Every Token Needs Its Own Teacher: Multi-teacher Adaptive On-policy Self-distillation

这篇工作讨论的是 OPSD 里的 student-teacher mismatch，而且把问题进一步细化到了 token 级。已有 on-policy self-distillation 通常让 teacher 拿到某种“特权参考答案”，再对 student 自己采样出来的轨迹做蒸馏。问题在于，teacher 看得太多时分布会过尖，监督信号未必适合 student 当前状态。已有改进多半只在 response 级调节 reference exposure，也就是一整条回答共享同一个 teacher。作者要解决的是：同一条推理链内部，不同 token 所需要的 teacher 其实可能不同；如果仍用单一 teacher 监督整段生成，会把局部合适的指导和局部不合适的指导混在一起，降低训练效率甚至伤害推理表现。

评将蒸馏的粒度细化到了 token 级别，发现不同 token 需要不同强度的 teacher，这个 insight 对设计更精细的 RL/蒸馏 loss 有启发，建议看方法设计。
