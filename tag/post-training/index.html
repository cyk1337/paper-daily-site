这篇论文要解决的是长程机器学习工程任务中的训练信号分配问题。MLE agent 不是一次性写代码，而是在一个可执行环境里反复设计实验、运行代码、读取反馈、修改方案，并在预算内提交结果。难点在于，每次实验结果往往对应前面多步决策，而一条长轨迹里混有探索、修复、退化和偶然有效的操作。直接做整轨迹 SFT 会把坏决策也学进去；只做单步 RL 又无法训练模型组织长程实验的能力。MLExpert 试图训练一个模型自己管理实验流程，而不是依赖外部工作流或搜索规则替它安排步骤。

评针对长周期复杂任务（MLE）的后训练方法，核心看点是如何从长轨迹中提取有效监督信号（credit assignment），对训练复杂推理和规划能力的 Agent 很有启发。

Mosaic: Multi-Session Agentic Reinforcement Learning

这篇工作处理的是一个训练设定错配问题：现有 agentic RL 大多默认一条 rollout 只在单一连续上下文里展开，因此整条轨迹只有一个 session，回报和 advantage 也自然按单 session 处理。但真实的长程 agent 推理已经越来越依赖 context compaction、subagent forking 这类机制，一条轨迹会被切成多个 session，甚至出现分支。此时如果还把整条轨迹的 outcome reward 直接广播到所有 session 和 token，上游训练信号就会过于粗糙：既分不清哪些 session 真正带来了收益，也无法约束 agent 学会更节制、更有效地分配 session。论文要解决的核心问题，就是如何在不引入 critic 的前提下，为 multi-session agentic RL 设计更细粒度、同时又保持稳定的优势估计与优化目标。

评读设定和 advantage 分解即可；它抓住了 agent RL 真训练会遇到的 session credit assignment 坑。

AutoSFT: An Agentic System for Automated Data Research in Supervised Fine-Tuning

这篇工作处理的是一个很具体、也很现实的问题：如果把 SFT 数据研究完整交给 agent，它能不能像有经验的数据工程师那样，不只会“挑数据”或“调比例”，而是能在一个闭环里完成更完整的数据配方搜索。作者把这个问题拆得很清楚：现有自动化系统通常只开放一种数据控制方式，比如从固定池里选样本，或调用生成器补数据；但真实的数据研究远不止这些，还包括类别重配比、坏样本裁剪、样本修复、替换过长回答、补齐缺失能力、以及数据顺序安排。论文先证明单 agent 在这个空间里会明显塌缩，只反复做比例调整；然后再问，什么样的系统结构才能让自动化研究真正覆盖这些动作。

评这篇不是新对齐算法，而是把“数据工程动作空间”讲清了；如果你关心 pretrain/post-train 闭环，先看单 agent 为什么塌到只会调配比。

Failure Is the Mother of Success: Recovering Supervision with Grounding Hindsight

这篇工作处理的是 verifier-based reasoning RL 里的一个老问题，但切得很准：当同一道题采样出的整组 rollout 全部失败时，GRPO 这类组相对优势方法没有训练信号，最难的题反而最学不到。论文关心的不是“如何让模型多试几次”，而是“如何把失败轨迹本身变成可验证、可迁移的监督”。约束也设得很严格：不能把参考答案泄露给策略，不能直接相信模型自写的反思，不能只是给原失败轨迹重打分，因为那会把错误 token 也一并抬高。作者要解决的是，在只看最终答案 verifier 的设定下，怎样从 all-fail group 中恢复出真正有用的学习信号。

评只看方法和筛选准则即可；它提醒 RLVR 别把全失败 batch 当垃圾，关键是 admission 是否真能挡住答案泄漏。
