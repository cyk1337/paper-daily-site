WIRL also uses local progress rewards, asynchronous rollout collection, and policy correction to handle expensive experiments and policy drift during online learning.19:T887,方法名叫 Mosaic，核心是两层优化信号。

第一层是 session-aware trajectory-level advantage estimation。普通 broadcasting 做法是先按任务内 rollout group 的 outcome reward 做 GRPO 式标准化，再把同一个 trajectory advantage 广播给所有 token。Mosaic 认为这样忽略了 session 使用效率，于是在“相同 outcome”内部再看 session count 的相对排序。直观上，若两条轨迹都成功，使用更少 session 的那条应得到更高 advantage；若两条都失败，反而不应简单惩罚 session 多的轨迹，因为失败样本仍需要探索空间。论文因此设计了一个有界调制项，用 session 数在同 reward 组内的 rank 去修正 trajectory-level advantage。这里有两个关键约束：一是调制不能打乱由 outcome reward 决定的主排序，二是调制幅度要受控，避免 session 偏好压过任务成败本身。作者强调它的作用不是替代 outcome signal，而是拉开 homogeneous-reward group 内部的 advantage 间距，提高学习信号分辨率。

第二层是 session-level advantage shaping。作者把每个 session 对最终 outcome 的边际贡献视作一种 immediate reward。做法上，是比较包含该 session 与不包含该 session 时的 outcome 增益，得到 session-level marginal gain；然后按 session type 分开做 group-relative normalization，再把这个 shaping signal 与上面的 trajectory-level advantage 结合。之所以要按 session type 分开归一化，是因为不同类型 session 的边际收益分布不同，例如压缩 session、主 agent session、fork 出来的子 agent session，其长度、功能和对最终成功率的贡献尺度都不一样，混在一起标准化会让某些类型的信号被系统性放大或压小。

整体上，Mosaic 形成了一个层级目标：trajectory-level signal 负责长期、全局、结果导向的优化；session-level shaping 负责局部、短程、边际贡献导向的优化。并且整个方法保持 critic-free，仍沿用 group-relative 的思路，而不是额外训练 value model。这是它和 PPO-style token/value advantage 路线的主要区别。1a:T45f,This is not a pretraining paper in the narrow sense, but it matters for the pretrain-to-post-train interface, especially for long-context agents, tool-using systems, and reasoning models with explicit context management. Its contribution is meaningful in three ways. First, it treats session structure as part of the optimization problem rather than an implementation detail. That is important because modern agent execution increasingly departs from the single-context assumption used during RL training. Second, it proposes a hierarchical, critic-free advantage design, which fits the current preference for GRPO-like large-scale RL pipelines that avoid training an additional value model. Third, it explicitly encodes an efficiency preference: successful trajectories should ideally use fewer sessions, while unsuccessful ones should retain room for exploration. That idea is relevant beyond this benchmark, including memory agents and systems with context rewriting. Still, the scale of contribution is best viewed as a solid improvement in agent RL objective design, not a shift in core language model pretraining.1b:T8d3,Mosaic introduces a two-level optimization signal.

The first component is session-aware trajectory-level advantage estimation. In the standard broadcasting setup, one computes a GRPO-style normalized trajectory advantage from outcome rewards within a rollout group, then assigns that same advantage to all tokens across all sessions. Mosaic argues that this ignores session efficiency. It therefore refines the trajectory-level signal using the relative ranking of session counts within trajectories that share the same outcome. Intuitively, if two trajectories both succeed, the one using fewer sessions should receive a larger advantage. If both fail, however, extra sessions should not be penalized in the same way because failed samples still serve exploration. The paper implements this through a bounded modulation term based on session-count ranking inside homogeneous-reward groups. Two design constraints are central: the modulation must not overturn the primary ordering induced by outcome reward, and its magnitude must remain controlled so that session preference does not dominate task success. The point is not to replace outcome supervision, but to increase advantage resolution within reward-tied groups.

The second component is session-level advantage shaping. Each session is assigned an immediate shaping signal based on its marginal contribution to the final outcome. Concretely, the method estimates a session-level marginal outcome gain, normalizes it with group-relative statistics separately for each session type, and combines this shaping term with the trajectory-level advantage. The type-conditioned normalization is important because different session types have different gain distributions. A compaction session, a main-agent session, and a forked subagent session differ in length, function, and contribution scale. Pooling them into one normalization scheme would distort the signal.

Together, these two components form a hierarchical objective: the trajectory-level term provides a global, long-horizon, outcome-oriented signal, while the session-level shaping term captures local marginal effects. The method remains critic-free throughout, staying closer to GRPO than to PPO-style value-based token advantage estimation.1c:T6a1,Experiments are conducted on BrowseComp with Qwen3.5-4B as the base model, under two representative multi-session settings: context compaction and subagent forking. Mosaic outperforms both single-session and multi-session agentic RL baselines.
