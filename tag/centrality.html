Hubs or Fringes: Pretraining Data Selection via Web Graph Centrality

这篇工作解决的是预训练数据选择里一个很具体但长期被忽略的问题：现有方法大多把文档当独立样本，用内容分类器、质量打分器或 mixture optimization 来决定采样比例，却几乎不利用网页之间的链接结构。作者提出的问题不是“哪些网页写得更像高质量文本”，而是“网页在整个 web graph 里的结构位置，是否对应不同类型的可迁移知识，从而影响模型学到的能力”。更进一步，他们想要一个不依赖标注、不训练额外打分模型、能在 web 规模上运行的数据选择方法。

评这篇会直接影响你做 web-scale mixture 的先验：先看它是否在固定 token budget 下稳定优于 learned scorer，再决定要不要把图结构信号接进内部数据管线。
Vedant Badoni,Danqi Chen,Xinyi Wang
