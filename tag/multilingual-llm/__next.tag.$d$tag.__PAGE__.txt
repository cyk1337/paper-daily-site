9:T628,The method is Distribution-aware Language Neuron selection (DLN). For each MLP neuron in an autoregressive Transformer with GLU feed-forward blocks, the authors collect continuous activation values for each language instead of reducing them to a binary active/inactive statistic. They then estimate per-language activation distributions and compute pairwise overlap coefficients between languages. Small overlap means the neuron separates those languages well. The resulting pairwise structure is clustered to recover language groupings.

This leads to two neuron types. Single-language neurons (SLNs) are neurons whose activation distribution for one language is separated from the rest. Multi-language neurons (MLNs) are neurons that support a cluster of languages that are similar to each other but separated from other languages. This is a broader and more faithful definition than entropy over positive activation rates, because it captures cases where all languages are mostly positive but occupy different regions, and cases where the informative regime is negative.

A useful detail is the intervention site. The paper evaluates both the usual gate activation site and the gate-up product site, the latter being closer to the effective contribution written back to the residual stream in GLU blocks. Baselines based on activation probability degrade substantially there, while DLN remains selective. The main innovation is therefore not a heavy model component, but a better neuron selection criterion built on continuous distributions and pairwise language relations.a:T4dc,Main experiments are conducted on Llama-3.1-8B and SmolLM3-3B-Base using two held-out corpora, with three additional models in the appendix. In other words, the model often does not move directly from source script to target script. It appears to pass through an intermediate representation aligned with Latinized forms. The paper turns this into a quantitative phenomenon, latent romanization, and studies it across scripts and models rather than relying on a single anecdotal example.

Second, the paper analyzes representations of the same language written in different scripts. Script identity becomes increasingly linearly separable in deeper layers. Based on this, the authors construct simple linear steering directions that flip the output script while largely preserving semantic content. Two points matter here. One is that script choice can be manipulated with a low-complexity linear intervention, suggesting that script identity is explicitly encoded in later layers. The other is a strong directional asymmetry: steering toward non-Latin scripts is more reliable than steering toward Latin. This supports the paper’s main hypothesis that Latin is not a compact target cluster but a more diffuse representational region.

Third, the authors localize a small set of late-layer attention heads that causally mediate script generation. With activation patching on only a few heads, they can redirect the output script on natural prompts, and the same heads transfer across unrelated languages and writing systems. This suggests that script choice is not uniformly distributed across the network. Instead, part of it is concentrated in a small number of routing components in later layers. The asymmetry appears again at the mechanistic level: non-Latin generation depends on compact, identifiable mechanisms, whereas Latin generation is more distributed and harder to control through a small intervention.
