It decomposes total variance in binary success observations into the agent main effect (the true general capability signal), independent main effects for each facet, pairwise interaction effects between facets, and residual variance. Three independent variance estimators are used to cross-validate results: Henderson Method-I, restricted maximum likelihood implemented via lme4, and a Bayesian binomial generalized linear mixed model run on GPU. Building on the G-study (variance component estimation), a D-study (decision study) translates variance components into a budget frontier of minimum tasks, steps, and judges required to meet target reliability thresholds (generalizability coefficient Eρ² ≥ 0.85 for relative ranking decisions, dependability coefficient Φ ≥ 0.90 for absolute threshold decisions such as SLA gates).
