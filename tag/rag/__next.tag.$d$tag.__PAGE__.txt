9:T407,F²DR evaluates DeepSearch along three axes. The Content axis checks whether retrieved information covers key knowledge points and is factually grounded. The Trajectory axis evaluates the search process, including intent understanding, search atomicity, planning consistency, gap resolution, planning comprehensiveness, and iterative novelty, while penalizing redundant reasoning and plan-execution mismatch. The Answer axis combines subjective criteria such as intent match, coherence, and conciseness with objective coverage of core information. For benchmark construction, the authors sample complex queries from an enterprise search platform, extract requests that invoke deep thinking, and use DeepSeek-V3 to remove trivial or single-hop cases. They then run a full DeepSearch pipeline with DAG-based planning and reflection, search engines and MCP tools for evidence acquisition, and cross-turn evidence aggregation for final response generation. Preference pairs are filtered for discriminability and then checked by humans.a:T54f,The benchmark uses roughly 5,000-token retrieved contexts with paired factual edits. Direct questions ask for the edited fact itself, while derived questions require a two-hop inference through unchanged downstream text. The evaluation covers Llama, Qwen, and Mistral model families, plus a 1,099-item distance-controlled variant where the answer-carrying text is moved 250 tokens downstream. At the main budget K=32, all methods nearly saturate on direct cases, but derived cases separate the policies. EditLocal recovers 0.94–1.01 of the post-edit answer margin on held-out data, with flip rates of 0.95–1.00, outperforming alternatives by 0.46–1.00 margin recovery after Holm correction with p ≤ 3×10^-9. The result depends on adjacency: moving the answer-carrying text 250 tokens downstream drops EditLocal recovery to 0.01–0.09, and stale-query attention helps only for one model family. The transplant diagnostic is also misleading for deployment: causal ranking recovers 0.92–0.97 of the margin under clean-state transplant, but only 0.01–0.21 when the same positions are actually recomputed at K=8. Answer-relevant edits almost always break the stale cache, with base rate at least 0.988, and cheap features poorly predict severity, with best out-of-fold rho of 0.17. Repair is 13–21 times faster than full re-prefill in this setting.b:T4bd,The method has three main pieces. First, the task is framed in the CiteGuard environment, where the model can take bounded actions such as search, inspect, request more context, and select a paper. This turns citation recovery into a sequential decision problem under an interaction budget, rather than a one-shot generation task. Second, the authors build CiteAlign, a 7,607-instance dataset from recent computer science literature, with temporally separated splits so that evaluation targets are relatively recent and less likely to be memorized. They also construct a controlled 709-instance benchmark subset for stable comparison. Third, they fine-tune Qwen3-4B with GRPO for tool-using citation recovery. The training objective is tied to recovering the true cited paper, not merely generating plausible reference strings. A key design choice is to separate target retrieval from final selection, which lets the authors localize where RL helps. Compared with standard RAG-style supervised fine-tuning, this setup trains search behavior in an open retrieval space. Compared with pure imitation learning, GRPO allows the model to discover better query reformulation and stopping strategies through interaction.c:T802,The model consists of a compressor C_phi and a compression-aware decoder G_theta. For each retrieved document d_i, the method appends m_i = floor(L_i / tau) special compression tokens, runs an encoder over the full sequence, and uses the final hidden states at those compression-token positions as the compressed continuous representation. These compressed document embeddings can be precomputed offline for the corpus, so online serving only needs retrieval plus decoding over the compressed sequences.

The main novelty is the training recipe rather than the architecture. Stage I, Pure Distillation (PD), differs from standard KD in a simple but important way: it trains only on examples where the uncompressed RAG teacher is correct. Standard distillation would also transfer the teacher’s mistakes. PD uses the teacher only where it provides reliable supervision, giving the compressed model a strong initialization without forcing it to internalize the teacher’s failure modes.

Stage II, Hard Exploration (HE), is the key step. Reinforcement learning is applied only to queries on which the uncompressed RAG fails. This is a targeted exploration strategy. Instead of spending RL budget on the full data distribution, including easy cases already handled well by imitation, the method concentrates optimization on the subset where imitation is provably insufficient. The intended effect is not just error correction. It is to encourage the compressed model to discover computation patterns better suited to dense compressed inputs, and therefore capable of surpassing the token-based teacher.

Methodologically, this is a selective optimization recipe: use high-confidence supervision to enter a good basin, then use exploration only on high-value hard cases. Relative to prior soft-compression work, the differences are threefold: distill only correct teacher responses, apply RL only on teacher-failure cases, and explicitly allow the compressed model to deviate from the teacher rather than treating the teacher as the final upper bound.d:T61b,The evaluation covers five open-domain QA benchmarks and, importantly, extends retrieval depth beyond the common top-5 setting to a much wider range from top-5 to top-30. That matters because both the cost of uncompressed RAG and the challenge of compression grow with retrieval depth. The headline result is that DEX-Comp achieves performance comparable to, and in some settings better than, the uncompressed RAG baseline while using 16× compressed context and delivering about 4× to 24× inference acceleration. It also outperforms prior soft-compression baselines.

The ablation logic is one of the stronger parts of the paper. Distillation alone yields a competent compressed model, but it does not reliably break the teacher ceiling. RL over the full dataset is less efficient and less stable because it wastes exploration budget on examples that do not need it. The PD+HE combination performs best, supporting the claim that “correct-only imitation” and “teacher-failure-only exploration” are complementary. The paper also reports generalization across datasets and backbone models, which suggests the recipe is not tied to one specific compressor-decoder pair.
