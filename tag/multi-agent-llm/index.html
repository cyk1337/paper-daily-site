Close Enough is Nowhere Near: Fidelity-Consumability Decoupling in KV Caches

这篇论文研究一个很具体但容易被误判的问题：在两个冻结 Transformer 之间，能否直接把发送方的 KV cache 放进接收方的 cache 槽位，让接收方复用发送方已经读过的上下文。作者的结论是否定的，障碍主要在接收方。接收方只能稳定读取它自己会产生、或足够落在其“可容忍集合”内的 cache；几何相似度高，并不等于可被消费。

评这个负结果值得扫：直接传 KV cache 的 prior 基本被打穿，重点看 tolerable set 和 competitive attention。
Adam Deng,Shicheng Liu,Yada Zhu

Augment the Cache, Replace the Activation: A 2x2 Study of Internal-State Sharing

这篇论文研究冻结 LLM 之间共享内部状态时，应该传什么、怎么接入。作者把问题拆成一个 2x2：carrier 是 activation 还是 KV cache，fusion 是 replace 还是 augment。核心结论是：cache 不适合直接替换，activation 更适合替换；cache 如果要共享，更适合以追加上下文的方式接入。

评比“传 cache”更像可扩展设计空间；扫 2x2 结果即可，重点是 carrier 进入位置这个变量。
Adam Deng,Shicheng Liu,Yada Zhu
