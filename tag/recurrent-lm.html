SANE: State Anomaly Neutralization for Stable Extreme-Context Delta-Rule Models

WriteSAE: Sparse Autoencoders for Recurrent State

这篇文章解决的是：对 Mamba-2、RWKV-7、Gated DeltaNet 这类矩阵状态/混合递归语言模型，传统 residual-stream SAE 无法直接解释模型真正写入 recurrent state 的内容，因为这些模型每个 token 写入的是 rank-1 外积形式的矩阵更新，而不是一个普通向量特征。作者要做的是构造一种与原生写入形状匹配的 SAE，使得“解释”和“干预”都发生在 cache write 这一层，而不是事后在 residual 上读影子信号。

评读方法和 logit-shift 推导；若还在评估 Mamba/RWKV，这比残差 SAE 更贴近真实状态写入，但规模仍偏小。
