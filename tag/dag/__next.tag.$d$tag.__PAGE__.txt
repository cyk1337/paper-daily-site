9:T8f9,方法建立在 BD3LM 上。先回顾基线：BD3LM 按 block 自回归，block 内用 masked diffusion 去噪；训练时只在被 mask 的位置上做 SUBS 参数化下的 token 预测；推理时从全 mask 开始，反复预测所有 mask 位置，再按 schedule 或置信度固定一部分 token。问题在于，这一步里各位置预测是独立的。

DA-DLM 的核心改动，是在每个去噪步构造一个 position-oriented DAG，而不是直接输出各位置独立分布。这个 DAG 不是 DAT 在 NAT 里那种大而自由的无位置约束图，而是显式绑定到输出位置。每个输出位置对应一个 node group：
- 如果该位置的 token 在更早去噪步已经被固定，那么这个位置在当前 DAG 中就是一个单节点 anchor；
- 如果该位置还未确定，就为该位置展开多个候选节点，表示该位置当前可能的局部模态。

然后只允许相邻位置的 group 之间建立 transition。这样一来，最终不是对每个位置各选一个 token，而是在整张 DAG 上选一条穿过各位置 group 的路径。路径分数同时考虑节点发射分数和相邻候选之间的转移分数，于是同一步里多个 token 的选择被耦合起来。已经固定的 token 作为 anchor 被钉在图上，能对邻近未决位置形成结构性约束。这一点是作者区别于直接照搬 DAT 的关键：DLM 是迭代式的，前几步已确定 token 的“锚定作用”必须保留，否则 successive denoising 容易漂。

从机制上看，这个设计做了两件事。第一，它把 DLM 每步的预测目标从 factorized marginals 变成了一个局部链式依赖上的联合选择问题。第二，它让 DAG 随去噪过程演化：随着步数推进，anchor 越来越多，未决位置越来越少，图会逐渐收缩，模型把容量集中到剩余不确定区域。这个动态图结构很适合 DLM 的 iterative refinement，而不适合一次性 NAT 生成。

论文的思想来源是 DAT，但改造点很明确：DAT 面向单步生成，允许更自由的转移；DA-DLM 面向 iterative denoising，因此采用 position-oriented DAG 来强化已固定 token 的约束，并让图结构与当前 mask 状态同步变化。这个差异不是实现细节，而是任务结构决定的。a:T90a,The method is built on BD3LM. In the baseline, generation is autoregressive across blocks, while each block is generated by masked diffusion. During training, only masked positions contribute under the SUBS parameterization. During inference, the model starts from a fully masked block, predicts all masked positions in parallel, and then fixes a subset of tokens according to a schedule or confidence rule. The key limitation is that those per-position predictions are independent.

DA-DLM replaces that factorized prediction with a position-oriented DAG constructed at every denoising step. This is not the same as directly importing DAT from NAT. DAT uses a large DAG with relatively unconstrained transitions for one-shot generation. DA-DLM instead binds the graph explicitly to output positions.

Each output position corresponds to a node group. If a token at that position has already been fixed in an earlier denoising step, the group collapses to a single anchor node. If the position is still unresolved, the model expands it into multiple candidate nodes representing local alternatives. Transitions are only allowed between adjacent position groups. Generation within the step is therefore no longer a set of independent token choices. It becomes a path selection problem through the DAG, where the path score combines node scores and transition scores. This couples the token decisions made in the same denoising step.

The anchor mechanism is the critical adaptation to iterative denoising. Previously fixed tokens are pinned into the graph and structurally constrain nearby unresolved positions. That is the main reason the authors do not simply reuse DAT as-is. In DLMs, the denoising process should progressively converge as more tokens become fixed. Without explicit anchoring, successive steps can drift rather than refine.

Conceptually, the method does two things. First, it changes the denoising objective at each step from factorized marginals to a structured joint selection problem over a local dependency chain. Second, it lets the graph evolve with denoising: as more positions become anchors, fewer candidate groups remain, and the graph shrinks toward the residual uncertainty. That dynamic graph is well matched to iterative refinement and is the main architectural idea of the paper.b:T6f6,The evaluation covers language modeling, open-ended generation, and summarization. The headline findings have two parts. First, DA-DLM consistently outperforms the BD3LM baseline across all settings. Second, the gains are larger when fewer denoising steps are used, which is exactly where the independence problem should hurt the most. That alignment between motivation and empirical behavior is important.

A particularly useful result is that on summarization, DA-DLM matches the autoregressive baseline while retaining the parallel decoding advantage. This suggests that the method is not only making open-ended text look smoother. It is also recovering sequence-level consistency in conditional generation.

From the structure of the paper, the most important ablations are likely to be: step-count sensitivity, to show that the advantage widens in low-step regimes; DAG design ablations, to test whether position orientation and anchors are necessary; and task generalization, to show gains beyond a single metric such as perplexity. For this paper, the most informative curve is not a single average score but how quality degrades as denoising steps are reduced. If DA-DLM flattens that degradation curve, then it is addressing a core structural issue rather than making a small improvement in a comfortable high-step regime.
