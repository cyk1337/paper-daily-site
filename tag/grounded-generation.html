The Bottleneck Is Retrieval, Not Reading: Diagnosing Evidence-Based Generation with RAG for Long Context Question Answering

这项工作要拆开长上下文问答中的两个失败源：模型没有拿到证据，还是拿到了证据但没有读对。普通 RAG 评测只看答案正确性，会把检索失败、引用错误、阅读失败混在一起，因此很难判断瓶颈在 retriever 还是 reader。

评这篇不是在卷新 RAG 技巧，而是在把“检索差还是阅读差”这个老混账拆干净；只看评测设定和错误分解就够，适合拿来校正你对 long-context vs RAG 的 prior。
Debopriyo Banerjee,Owais Aijaz,Ahmer Tabassum,Zhuohan Xie,Preslav Nakov,Veselin Stoyanov

GRACE: Step-Level Benchmark for Faithful Reasoning over Context

这篇工作要解决的是：在有外部上下文约束的文本推理里，模型的 CoT 过程是否逐步忠实于证据，而不是只看最终答案对不对。现有 hallucination 或 faithfulness 评测大多停留在 response level，最多判断整段回答有没有问题，无法定位是哪一步开始偏离上下文，也无法区分偏离是逻辑跳步、约束违背，还是凭空捏造证据。论文把这个问题形式化为 step-level context faithfulness：给定 references、question 和 reasoning trace，对每一步判断 faithful / unfaithful，并在出错时给出错误类别和解释。

评首个步骤级上下文推理忠实性的人工标注基准，错误分类法自数据驱动聚类得到，读§3的分类体系和标注示例即可。
Hoang Pham,Dong Le,Anh Tuan Luu

Precision Is Not Faithfulness: Coverage-Aware Evaluation of Grounded Generation with a Complete Oracle

现有无参考忠实度评测指标仅测量断言的准确率（precision），会奖励模型少说话拿高分，无法衡量模型对相关事实的覆盖率（recall）。

评现有忠实度评测的盲区对对齐工作影响很大，做生成质量评测的研究员可重点看其完整oracle的实验设计与precision-recall tradeoff分析。
