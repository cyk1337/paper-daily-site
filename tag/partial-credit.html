PartHackBench: Certified Equal-Progress Stress Tests for Partial-Credit Tool-Agent Evaluation

这篇工作解决的是一个评测设计问题：长程 tool agent 在非单调环境里，常常会先完成一些中间里程碑，随后又把它们撤销、覆盖，或者这些进展其实不该归因给被评测 agent，但很多 partial-credit evaluator 仍会把这些“历史上出现过”的状态记分。这样得到的高分，并不对应终态下真实保留下来的任务进展。论文的关键点不是再做一个更复杂的 judge，而是先构造一种“等进展对照”协议：只有当 honest 轨迹和 adversarial 轨迹在最终状态谓词、以及标准化归因向量上逐项完全一致时，才允许比较 evaluator 分数差。这样一来，分数膨胀就不能再被“对手其实做了更多真实工作”解释掉。

评做 agent eval 的人该看：它把“评分被 hack”与“对手确实做得更多”分开了；读方法和结果表就够，别把数字外推到通用 agent 能力。
Hongye Yang,Zhihao Xie,Shengjun Xiong
