9:T521,The method defines a Bayesian model over hypotheses h.
- Representation: each hypothesis is a pair (natural-language description, Python implementation). Language provides a compressible, flexible concept description; code provides an executable semantics.
- Prior p(h): favors shorter NL descriptions (an Occam/MDL-like bias implemented in the language channel).
- Likelihood p(e_t|h): scores how well the program’s execution matches the observed evidence at time t.
- Inference: exact posterior p(h|e_{1:t}) is intractable, so they use LLM-augmented Sequential Monte Carlo (LLM-SMC-S). Maintain K particles; for each new observation, use an LLM prompt as a bottom-up proposal q(h_{t+1}|e_{1:t+1}, particles), then importance-weight by prior×likelihood and resample; optionally “revise” particles to better fit new evidence.
- Inquiry: because the particle set encodes posterior uncertainty, the agent can choose questions/experiments that best discriminate among particles (information-gain style), closing the induction–inquiry loop.
