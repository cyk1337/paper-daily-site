Inducing Reasoning Primitives from Agent Traces

这篇工作处理的问题不是“怎样再造一个更强的 agent”，而是“怎样把 agent 在成功轨迹里反复出现、但每次都临时发挥的 reasoning move 提炼成可复用的中间表示”。作者观察到，ReAct 类 agent 在同一任务族上会不断重复类似步骤，例如核对时间线、比较候选人、检查约束冲突，但这些步骤只存在于 scratchpad 里，既不稳定，也不会在部署时沉淀为可调用结构。论文要解决的是：在没有人工设计任务分解、没有手写领域工具的前提下，能否仅从成功的 ReAct traces 中自动诱导出一组 typed reasoning primitives，并让原来的 agent 在测试时通过调用这些 primitives，比它原先逐题即兴推理更稳定、更准确。

评看方法和消融即可；有用点是轨迹可压缩成技能库，但它还不是可直接迁移到预训练的算法。
Zhihan Lei,Jiarui Yan,Joshua Momo,William W. Cohen
