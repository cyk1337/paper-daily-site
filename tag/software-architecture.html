Architecture as Capability Equalizer for Coding Agents

这篇文章研究的核心不是 coding agent 能不能写代码，而是同样的信息内容，用什么架构规格表示形式喂给 agent，会不会系统性影响生成质量，而且这种影响是否依赖模型能力。作者把“架构文档”当作一种输入表示问题来处理，考察 prose、Mermaid+约束+ADR、OpenAPI、C4/Structurizr DSL、TypeScript interface contracts 五种等信息量格式，对不同能力层级模型的作用差异。

评揭示了 prompt 格式（架构规范）与模型能力之间的有趣交互：强模型不在乎格式，弱模型极度依赖接近代码的格式。对 coding agent 的 prompt 工程和数据合成有指导意义。
Arquimedes Canedo
