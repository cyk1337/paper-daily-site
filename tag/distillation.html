GRAFT: Adaptive DLM-Based Draft Tree Construction with Target-Distilled Edge Scoring

这篇工作处理的是 DLM drafter 下的树式 speculative decoding 怎么真正把“一次前向得到的多位置分布”变成高质量 draft tree。问题不在于能不能拼出树，而在于现有 DDTree 这类做法把每个 future position 的高概率 token 当作独立候选，再按边际概率组装路径，缺少父子兼容性建模。结果是 target 真正会接受的 token 可能已经在树里，但挂在了错误父节点下，导致验证时走不到那条路径。另一个问题是固定 node budget：不同 decoding round 的难度不同，额外节点带来的 accepted length 增益和 verification cost 的权衡也不同，固定预算会在容易轮次浪费验证算力，在困难轮次又给得不够。
