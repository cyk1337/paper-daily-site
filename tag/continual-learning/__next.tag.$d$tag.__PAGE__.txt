9:T404,Boundary-Calibrated Intervention Transfer, or BCIT, stores each update as a state-bound record: the source context, the observed source evidence, prespecified applicability conditions and named hard conflicts, and provenance links for the model, data, configuration, and evaluation artifacts. The decision is made for a pair consisting of one candidate and the current context. A non-compensable conflict leads to rejection. Insufficient or unresolved evidence triggers a bounded validation run from the current parent. Only candidates satisfying a frozen authorization rule receive the full training budget. A fully trained child is still subject to a separate promote-or-rollback rule. The system may generate a small number of new atomic proposals when progress stalls, but those proposals have no fabricated source evidence and cannot skip validation. The main distinction from simple experience replay is that an update is not labeled globally as good or bad; its evidence remains tied to the context where it was observed.a:T4b8,The proposed framework is Adaptive Functional Metaplasticity, or AFM. At each protected update, AFM first computes the endpoint that the same learner would have accepted from the exact same pre-update state without any retention constraint. This endpoint is used only as a counterfactual reference and is not installed. AFM then identifies the component of that update that is compatible with protected functional behavior and stores only an accepted fraction in the ordinary parameters. A key distinction is made between persistent adaptation, finite deployed protection, and population behavior: matching protected outputs on a finite set does not imply that the unrestricted learning has been stored, nor that behavior is preserved on unseen inputs. The framework includes bounded sketches of behavioral sensitivity, multiple metaplastic timescales, a rank-timescale controller, task-free observable routing, a guarded finite functional shield, and function-preserving renewal of dormant structure.
