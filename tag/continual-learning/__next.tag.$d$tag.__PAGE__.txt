9:T8b3,方法是一个“多钥门控 + LoRA 增量更新 + 可回滚”的持续学习框架。
- 学习载体：冻结 base 参数 θ0，仅训练 LoRA adapter。流式 claims 以 chunk 到达；每个 chunk 先筛选可学样本，再用“新样本 + 过去接受过的 replay”训练一个候选 adapter，最后通过统计回归测试决定 commit 或 rollback（图 1 的流程）。
- Key 1（surprise key）：用当前模型对 claim 目标 token 的平均 NLL（nats/token）作为 surprise sθ(c)。超过阈值 τ=1.0 才进入候选集，意图是只学“模型预测不好的新信息”。
- Key 2（verifier key）：外部 judge 对每个 distinct claim 判真/假（有时附带“可信来源句子”）。这是最直接的抗投毒手段，但成本高且上限由 judge 质量决定。
- Key 3（regression test + rollback）：训练候选 adapter 后，在一套“无关旧知识回归集”上测量相对 θ0 的退化（论文用 preference margin 的损失变化来度量），按批次 b=25 评估，若退化超过阈值则回滚本次更新。核心假设是“坏更新会伤到旧知识”。论文发现对定点事实谎言，这个假设不成立。
- Key 4（prior-conflict key，免 judge）：用 base 模型 θ0 的贪心答案 ŷ 与 claim 的对数似然差（gap）衡量“与原始信念冲突程度”。gap 大的 claim 被 hold back 而不是直接学。作者强调必须用 θ0 而不是当前 adapter 来算 gap：用当前 adapter 会因近期学习导致过度自信，误拦大量真 claim（pilot 中拦了 46% 真 claim）。
- evidence route（证据通路）：针对 prior-conflict key 拦下的样本，如果存在“可信来源句子”，则走证据核验以恢复合法更新；但该机制依赖 trusted-source 假设，若来源可被植入则失效。

- Streaming protocol: claims arrive in chunks; each claim must pass active “keys” (gates). Accepted claims plus replayed previously accepted claims train a candidate adapter. A post-update test decides whether to commit or roll back.
- Surprise key: compute mean token NLL sθ(c) on the claim target; learn only if sθ(c) exceeds a threshold (τ=1.0 nats/token), intended to capture novelty.
- Verifier key: an external judge labels each distinct claim true/false (optionally with a trusted source sentence). This directly targets truth but adds cost and inherits judge errors.
- Regression test + rollback: after training the candidate adapter, evaluate a regression suite on unrelated prior knowledge using a margin-based loss change relative to θ0; if degradation exceeds a threshold, roll back. The paper finds this is largely insensitive to targeted factual lies.
- Prior-conflict key (judge-free): measure a contradiction “gap” between the likelihood of the claim and the base model’s greedy answer ŷ under θ0. Large gaps are held back for review. A key engineering detail is computing the gap under θ0 rather than the current adapter; otherwise the adapter’s recency-induced overconfidence blocks many true claims.
- Evidence route: for claims blocked by prior-conflict, allow recovery if corroborated by a trusted source sentence; this works only under a trusted-source assumption and fails if sources can be planted.

1) Instruction compilation into a requirement graph 𝒬: an LLM-based compiler decomposes the instruction into requirements (info to acquire or outcomes to achieve), dependency edges, per-requirement evidence rules for verification from GUI observations, and optional branch conditions.

2) Task Advancement State (online): maintains each requirement’s status (unresolved/established), known values, evidence, and object bindings. 4) Plug-in design: TAM augments a fixed base policy by providing bounded memory context; it does not retrain the policy itself.e:T7dd,HERD has two coupled components: an evolving harness and a constrained recursive distillation step.

On the harness side, the system does not simply cache raw examples. Instead, it maintains two forms of external state. First, it refines textual skills that summarize reusable patterns from the current and past tasks. Second, it stores a bounded set of high-residual examples that those skills fail to explain well. This split is deliberate. Storing only examples wastes context budget and scales poorly with stream length; storing only abstract skills loses tail cases and exceptions. HERD treats the harness as a selective, fast-learning layer that keeps both abstraction and residual evidence.

On the parametric side, the model is updated by distillation rather than direct supervised finetuning on the raw task stream. The student starts from the previous checkpoint and is trained to match the behavior of the prior system when that system is equipped with the current harness. In effect, the harness organizes and filters experience first, and only then is that experience written into the weights. This is meant to reduce noise and lower drift compared with ordinary SFT.

The central technical idea is drift-constrained distillation with dual anchors. One anchor is the previous checkpoint, which limits per-stage movement and protects short-term retention. The other is the original base model, which limits cumulative drift across many stages and helps preserve broad general capabilities. The paper presents this as the key to recursive stability: the challenge is not merely learning stage t, but still behaving sensibly after stage 20 or 25.

Relative to standard continual finetuning methods such as replay, regularization, or LoRA-based sequential updates, HERD inserts an explicit external selection layer before weight updates. Relative to pure retrieval or prompt-memory approaches, HERD aims to deploy only the consolidated weights, so inference does not inherit an ever-growing context cost.f:T7c9,The main evaluation uses TRACE+17, a 25-stage task stream composed of 8 TRACE tasks and 17 Super-NaturalInstructions tasks. The headline result is that HERD reaches a final mean of 0.706 over all seen tasks at the end of the stream, outperforming all baselines and beating the non-parametric methods by 27 points. That gap is important because it supports the paper’s core claim that a harness alone does not scale as a long-term learner under bounded context. At the same time, HERD’s acquisition score is 0.713, statistically indistinguishable from the plasticity floor set by Seq-LoRA, so the method does not buy stability by simply refusing to learn new tasks.

For forgetting, HERD reports 0.010, roughly half or less than every weight-updating baseline except SDFT. The paper notes that SDFT suffers generation collapse, which is an important caveat: low forgetting numbers can be misleading if the model’s outputs degenerate. On general tests, HERD drops by only 6.3 points, whereas other baselines lose around 20.0 to 25.5 points, suggesting that the cumulative-drift control from the base-model anchor is doing real work.
