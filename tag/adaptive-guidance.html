Mem-$π$: Adaptive Memory through Learning When and What to Generate

这篇工作处理的是 agent memory 的一个老问题：现有方法大多把记忆做成检索库，推理时从过往轨迹里取相似片段，再塞回上下文。但 agent 场景里的“有用经验”往往不是一条静态片段，而是要根据当前任务、环境状态和执行阶段重新组织成一条短而准的提示。检索式 memory 容易出现三类失配：一是取回内容和当前上下文只部分相关；二是经验过于具体，迁移不到新情境；三是 memory 总是被调用，错误提示会直接干扰下游 agent 行为。Mem-π 的核心问题因此不是单纯“如何生成记忆”，而是同时学习两个决策：什么时候该给 memory，什么时候该 abstain；以及一旦要给，应该生成什么样的 guidance 才能提高最终任务成功率。

评只看 RL abstention 设计即可；把记忆改成生成器是干净想法，但离预训练还隔着 Agent 外环。

Mem-π: Adaptive Memory through Learning When and What to Generate

解决长程 LLM agent 中“记忆该何时用、用什么形式用”的问题：相比从外部记忆库检索静态片段，如何按当前上下文按需生成更贴合任务的指导信息。

评对 pretrain 本身帮助有限，但“生成式记忆+可 abstain”这个接口设计值得记一下；读方法图和 RL objective 就够，不必深挖 benchmark。
