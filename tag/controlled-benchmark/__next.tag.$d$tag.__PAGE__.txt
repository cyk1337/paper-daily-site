9:T433,BedBench comprises 13 procedurally generated tasks over voxel-based 3D objects (10–15 connected unit cubes, rendered from two opposite views) and simple geometric scenes. Key design choices:
1) Ask both individual-judgment questions and exact-answer questions on the same underlying objects, enabling within-family comparisons.
2) Add consistency checks across questions (e.g., compare “most common colors” against the model’s own reported color distribution), plus a control where the model is given its own counts as text to isolate reasoning/consistency from visual readout.
3) Filter ambiguous instances at generation time using projection/silhouette distinguishability constraints and visibility checks, so errors are less attributable to underspecified views.
4) Include image-dependence controls: no-image runs, best-constant baselines, and MCQ layout artifact checks.
5) Use frozen-feature probes at the LM input interface to test whether exact counts are linearly/cheaply recoverable from visual features, separating “can’t see” from “can’t use.”a:T59b,Evaluates 12 open-weight VLMs (across Qwen3.5, Gemma4, GLM-4.6V-Flash, Kimi-VL-A3B; dense and MoE) and 4 frontier models (GPT-5, Grok-4.20, Gemini-3-Flash/3.1-Pro). Default is 100 instances per task (300 for T11/T13). Human reference: 30 participants, one instance per task.
Representative results highlighted in the paper:
- Exact structured counting is the clearest failure: on T5 (Color Distribution), humans reach 93.3% while the best VLM is 7.2%.
- Fine-tuning can raise T5 to 68.6%, yet consistency remains poor: T7 (most common colors) is only 35.0% when answered from images, but 74.2% when the model is given its own T5 counts as text—suggesting a breakdown in using visually grounded quantities consistently.
- “Thinking” helps selective judgments but not exact answers: T4 improves by +13.9pp on average, while T5 stays around 0.7–1.0%; larger reasoning budgets can even hurt T1 (Volume) and T11 (Projection), and perceptual misreads persist through the chain.
- Features may contain the answer: a probe at Qwen3.5-27B’s LM input recovers exact counts on 65.0% of objects vs 3.0% end-to-end VLM accuracy, pointing to readout/binding issues.
- Accuracy can be inflated by shortcuts: some scores persist without images; in a fixed-layout MCQ, one model hits 100% by always choosing the third option.
Metrics include exact match, MAE/RMSE for numeric errors, and P/R/F1 for binary tasks, plus best-constant baselines.b:T5bd,The setup is intentionally simple so that the analysis is identifiable. The authors define a context-free grammar over unary scalar arithmetic programs with operators such as +, -, *, /, sin, cos, exp, log, and sqrt, and cap AST depth at L=6. They then brute-force enumerate valid programs and reduce the set by removing invalid or redundant forms.

The central idea is a dual-manifold representation. A syntactic manifold captures structural distance between program trees, while a semantic manifold captures behavioral distance based on function outputs over sampled inputs. This lets the authors quantify not only whether a test sample is unseen, but how far it is from the training set structurally and behaviorally.

Using these spaces, they define two generalization regimes. Density generalization keeps test samples within the same support but changes how densely regions are covered during training. Support generalization moves test samples outside the training support, especially in syntax, to test genuine extrapolation. They then compare multiple data-selection strategies: sampling from a single distribution, maximizing syntactic diversity, maximizing semantic diversity, and jointly covering both spaces. The strongest result is that joint semantic-plus-syntactic coverage yields better OOD behavior than optimizing either axis alone. That is a useful analogue to pretraining data mixture design: the geometry of support matters, not just sample count.c:T5d0,There are four main empirical findings.

First, performance degrades predictably with OOD distance, especially in syntactic space. As test programs move farther from the training set structurally, pass@k drops substantially. The paper suggests that syntactic distance is a stronger predictor of failure than semantic distance alone.

Second, training-set construction has a large effect on generalization. The authors report that models trained from a single distribution achieve roughly 10% pass@1, while a deliberately diversified training set spanning both semantic and syntactic spaces reaches about 19% pass@1. In this controlled setting, that is a meaningful gain because contamination is largely ruled out.

Third, support generalization remains difficult even with more compute. Scaling improves results consistently, but the gains remain roughly log-linear rather than showing a sharp transition into robust extrapolation. The model gets better at interpolation and near-boundary generalization, but not at systematic out-of-support reasoning.

Fourth, the paper includes robustness checks across split constructions and distance definitions, which helps show that the conclusions are not artifacts of one particular partitioning scheme.
