Residual Decoder Adapter: ID-Preserving Tokenizer Adaption for Autoregressive Text Rendering

视觉自回归（AR）模型在文本渲染任务上表现不佳（如笔画模糊、形状扭曲），其根本原因在于离散视觉 Tokenizer 的重建能力有限，丢失了细粒度的文本细节。而重新训练 Tokenizer 成本高昂，且会导致已训练的 AR 模型失效。

评值得看的是“保持 token space 不变的 tokenizer 后置升级”这条路；先读方法图和文字渲染对比，确认是否牺牲整体重建。

TextAlign: Preference Alignment for Text Rendering with Hierarchical Rewards

Qwen-Image-VAE-2.0 Technical Report

这项工作解决的是高分辨率图像生成中的视觉 latent tokenizer 问题：如何把 VAE 的空间压缩率从常见的 f8 提高到 f16 / f32，同时不牺牲重建质量，尤其是不牺牲文字、表格、版面这类细粒度信息，并且让下游 DiT 仍然容易训练。核心矛盾在于，压缩率越高，latent token 越少，扩散模型训练越便宜；但信息瓶颈更强，重建更差。增加 latent channel 可以缓解重建问题，却会让 latent 分布更复杂，降低 diffusion convergence。论文把这个矛盾明确拆成三个目标：compression、reconstruction fidelity、diffusability。

评应读架构与消融；它把 VAE 当生成模型的预训练接口优化，不只是追重建 PSNR，值得内部复现实验。

TextGround4M: A Prompt-Aligned Dataset for Layout-Aware Text Rendering

这项工作解决的是文生图模型的文字渲染与布局对齐问题：模型不仅要生成正确的文字内容，还要把 prompt 中指定的多个文本片段放在正确空间位置。现有数据通常只有 OCR 文本或框，缺少“prompt 中哪段指令对应图中哪段文字和位置”的显式对齐。

评不是基座 pretrain 主线，但数据接口设计很干净；若你做统一 AR 多模态，重点看 span token 这套最小侵入式训练改法。
