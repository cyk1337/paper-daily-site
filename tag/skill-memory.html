Self-Play Meets Skill Evolution: Self-Evolving Search Agents that Pose, Solve, and Remember

要解决的是：零数据 self-play 的搜索型 agent 虽然能自生成训练题并用可验证奖励学习，但“经验是瞬时的”——失败只通过梯度影响参数，不会以可复用的形式显式改变后续练习；而 skill/memory 类方法能沉淀程序性经验，却往往来自固定任务分布，无法与自适应课程闭环耦合。论文试图把“自生成课程”和“可演化的技能记忆”做成同一个在线闭环，让失败能被提炼成技能并持续塑形后续 self-play 数据分布。

评值得扫方法图和 ablation；失败写回技能库这个闭环，比普通 self-play 更接近可复用 RL 数据引擎。
Zenghuang Fu,Zhaoyang Li,Qiuyuan Ai,Haoyu Wu,Minghui Wu,Chenxu Zhao,Ante Wang,Guannan He,Changwei Wang

CODESKILL: Learning Self-Evolving Skills for Coding Agents

CODESKILL 解决的是编码 Agent 如何从历史交互轨迹中学习可复用技能，并把这些技能维护成一个能持续服务后续任务的技能库。关键点不是再训练下游编码 Agent，而是学习一个“技能管理策略”：决定从哪些轨迹证据中抽取什么、抽象到什么粒度、何时合并或删除已有技能。

评值得扫方法和实验设置；skill bank 的 RL 管理比 prompt 规则干净，但先看是否真跑真实仓库任务。
