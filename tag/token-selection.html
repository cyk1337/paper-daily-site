AViTS: Adaptive Spatiotemporal Token Selection for Efficient Dynamic-Resolution Generation

这篇工作处理的是动态分辨率 DiT 推理里的一个具体瓶颈：从低分辨率阶段切到高分辨率阶段时，是否有必要把所有 latent token 一起上采样并进入高分辨率计算。作者的判断是否定的。全文给出的证据是，低分辨率去噪过程中 token 重要性在空间和时间两个维度都高度不均匀：一部分 token 与文本条件强相关，另一部分 token 在跨步演化中变化更剧烈、对后续更新更敏感。若仍然统一上采样全部 token，会把算力浪费在语义边缘区域和已趋于稳定的区域上，同时还可能在阶段切换时引入细节不一致。论文要解决的核心问题，就是在有限高分辨率预算下，如何更可靠地识别“应该优先升采样”的 token，并把高分辨率计算集中到这些位置。

评读方法动机即可：token级预算分配比统一上采样更合理，但这是DiT推理工程，不要误读成通用LM训练结论。

Which Tokens Matter? Adaptive Token Selection for RLVR with the Relative Surprisal Index

基于可验证奖励的强化学习（RLVR，以GRPO为代表）训练中，两类主流token重要性判断方法存在经验上的矛盾：一类主张仅在高熵token位置更新（80/20规则），另一类主张压制低概率采样token的梯度以避免训练不稳定，但两类方法都能取得实证收益，说明单独使用位置熵或采样token概率都无法准确识别能提供有效学习信号的token，缺少一个有理论依据的统一token级重要性度量。

评应立刻看 RSI 定义和 token-level 消融；它可能改变 RLVR 里“高熵优先”这个过粗 prior。

Not All Disagreement Is Learnable: Token Teachability in On-Policy Distillation

这篇论文处理的是 on-policy distillation 里的一个细粒度问题：学生模型在自己生成的前缀上接受教师 token 分布监督，但高 teacher-student KL 并不一定意味着这个 token 位置真的能学到东西。作者要区分两类分歧：一种是教师把概率质量重新分配到学生已经认为可能的候选 token 上，更新容易被学生吸收；另一种是教师主要支持学生当前预测支撑集之外的 token，KL 很大，但局部更新效果弱。

评修正了蒸馏中“高分歧token优先训练”的常见误区，可教性指标设计精巧，做蒸馏或模型压缩的可直接复用其固定上下文诊断方法。
