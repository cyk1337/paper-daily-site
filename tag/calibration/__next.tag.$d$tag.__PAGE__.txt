For each Transformer block, hooks capture the input and output hidden states, excluding the beginning-of-sequence position because it behaves as an activation outlier and attention sink. A block receives a low BI score if it changes the direction of its input representation only slightly on the calibration corpus. Low-BI blocks are candidates for depth pruning.

The study evaluates Qwen2.5-1.5B-Instruct, Llama-3.2-1B, and Gemma-2-2B on English, Hindi, Marathi, and Tamil Wikipedia text. Calibration and evaluation articles are disjoint. Every selector receives the same 150-chunk budget. A monolingual selector uses 150 chunks from one language, while multilingual selectors use 50 chunks each from English, Hindi, and Marathi. Tamil is excluded from selector construction to test held-out cross-script transfer.

Three multilingual aggregation rules are compared: raw-mean BI, rank-mean, and minimax-rank. Raw averaging preserves score magnitudes; rank-based rules remove cross-language scale differences. The selected blocks are physically bypassed, and no recovery training is applied, which isolates the effect of block selection.a:T4a0,The method defines a three-action controller over trust, fallback, and expand. Trust emits the current evaluator-preferred answer, fallback emits a conservative answer that avoids further continuation, and expand buys one more unit of inference before the controller acts again. The same framework covers both width expansion and revision expansion.
For terminal actions, the target value is success probability minus compute cost. For expand, the ideal target is the Bellman continuation value. In practice, the system learns one confidence head per action: trust and fallback estimate terminal answer success, while expand estimates a rollout-based continuation-success surrogate. These predictions are then post-hoc calibrated, and an optional uncertainty penalty is applied near brittle decision boundaries. The theory gives two main results: local action selection is stable when score error is smaller than the compute-adjusted action gap, and regret accumulates along the realized expansion path.
