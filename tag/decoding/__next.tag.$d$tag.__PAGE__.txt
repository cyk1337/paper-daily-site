- Injection: replace position-indexed i.i.d. Gumbel perturbations with a smooth, locally auto-correlated Gumbel field (SAC). The field is constructed via a Gaussian copula so that each coordinate keeps Gumbel marginals (under the paper’s assumptions) while introducing controlled local dependence across neighboring positions.
- Rationale: diffusion decoding refines multiple positions in parallel; independent high-frequency perturbations across neighbors can conflict with local consistency during iterative updates, causing oscillations or incoherence.
- Mechanistic analysis: quantify “latent perturbation roughness” via a local-difference energy and show how positive low-lag dependence reduces this roughness (the paper provides an analytic form contrasting i.i.d. vs SAC).
- Detection: a SAC-aware detector using covariance-aware filtering plus native-sample calibration to manage false positives. A global-offset scan is added as a coarse synchronization recovery tool under mild token–signal misalignment.

Instead of monitoring a fixed region or using schedule-dependent heuristics, CVC re-extracts and relocates the current candidate answer span at every denoising step. It then requires both high confidence on that span and sustained argmax identity stability across multiple steps. Only when the candidate answer itself has remained stable does the decoder allow a global fill-and-stop. The key change is that the stopping rule verifies the object of interest, the answer candidate, rather than a proxy statistic.

The second component is BWEC, Block-Wise Early Commit, which decides where local commitments may happen during decoding. The authors argue that non-final blocks usually contain intermediate reasoning text, so they can be handled with a cheaper local confidence rule. BWEC therefore applies only to non-final blocks. The final block, and any global termination decision, remains under CVC. This separation is meant to preserve the speed benefits of adaptive sampling while preventing local confidence signals from prematurely freezing the answer region.

A central analytical premise is that candidate stabilization is highly task-dependent. The base decoder uses block diffusion decoding: the sequence is partitioned into blocks, each block receives a fixed denoising budget, and high-confidence tokens can be committed across all unlocked blocks to increase parallel progress per step. In ETE, lookahead is triggered when the model remains uncertain over masked positions, and a one-step rollout estimates which tentative token commitment is most likely to unlock more confident predictions in the next state.

AdaLook adds two key mechanisms. First, it introduces adaptive rollout depth. Instead of always using a fixed 2-step or 3-step lookahead, the decoder decides whether another rollout step is worthwhile by examining the variance of candidate scores at the current frontier. If candidate futures are already similar, deeper rollout is unlikely to pay off; if they remain well separated, extra exploration may still be useful. This addresses the mismatch between heterogeneous decoding states and a globally fixed rollout depth.

Second, AdaLook allows branch re-evaluation and re-expansion at intermediate rollout states. A naive multi-step rollout follows each hypothesis along a predetermined path until the preset depth is reached. AdaLook instead checks after every rollout step whether each branch still needs expansion. Branches that have become sufficiently resolved are prioritized for selection. If all branches remain uncertain, the highest-scoring branch is chosen and its decoding state becomes the starting point for the next round of lookahead. The gain does not come from searching deeper in a brute-force sense, but from making depth and branching conditional on the evolving uncertainty pattern.

Algorithmically, this is closer to a lightweight confidence-driven adaptive tree search than to fixed-depth beam search. 第一层是公平比较。作者指出，早期 WINO 结果缺少一个关键 baseline：强 confidence-based unmasking 本身，例如 Fast-dLLM。若不和这种强基线比较，很容易把“更聪明地决定先解哪些 token”带来的收益误记到 remasking 头上。于是论文在相同模型、相同解码预算下，直接比较 Fast-dLLM 与 Fast-dLLM+WINO，考察 remasking 的边际贡献。

第二层是机制诊断。作者追问：为什么 remasking 常常没用？他们的解释不是 remasking 选错了位置，而是更深一层——模型在这些被挑出来重做的位置上，往往提不出比原 token 更好的候选。也就是说，confidence 能发现“不太确定”，却不等于模型具备“重新采样后会更好”的能力。对于 absorbing masked diffusion，这个问题尤其自然，因为训练过程只学习从部分 mask 状态恢复原 token，并没有显式训练“撤销已作决定并在更完整上下文下重选”的行为。

第三层是解码条件依赖性。作者把评估扩展到 stochastic generation，考察温度采样、不同 block size、以及 learned Bernoulli unmasking policy。这里的核心观察是：remasking 的效果高度依赖 unmasking policy。若底层 unmasking 已经是偏确定性的 confidence policy，remasking 的空间很小；若 unmasking policy 本身更随机、更容易引入局部错误，remasking 才更可能修正这些错误。相应地，WINO 在 learned Bernoulli policy 上的收益明显大于在 deterministic Fast-dLLM 上的收益。

这篇论文还有一个重要点是把质量和多样性一起看。作者指出，confidence-based unmasking 已被发现会导致 diversity collapse，而 remasking 在 stochastic setting 下虽然能提高 pass@1，减少部分随机错误，但会进一步压缩样本多样性。也就是说，它改善的是单样本命中率，不一定改善采样分布质量。这个取舍对 diffusion LM 很关键，因为并行生成的一个卖点就是在给定延迟下提供更灵活的采样，而不是把输出进一步推向近似贪心。16:T883,实验部分的主线很清楚：重新比较 WINO 与强基线，并把评估从标准 greedy 扩展到 stochastic decoding。

在标准采样设置下，也就是短 block length、greedy decoding 或接近确定性的解码条件，WINO 与 Fast-dLLM 基本持平。作者的结论不是“完全无效”，而是“边际收益可以忽略，尤其一旦把 remasking 带来的额外 latency 算进去”。这点很重要，因为 diffusion LM 的核心卖点之一就是吞吐和并行度；如果一个修正机制带来额外步数，却没有换来稳定质量提升，那它在系统层面就站不住。

机制实验进一步支持上述判断。作者检查了被 remask 的位置在下一轮是否真的会被替换成更优 token，发现很多情况下模型并不能提出更好的替代项。这说明瓶颈不在 confidence estimator，而在底层 reverse model 的条件建模能力。换句话说，remasking 只是在暴露模型不会 revision，而不是自动赋予 revision 能力。

在 stochastic generation 下，结果更复杂。使用非零温度时，WINO 可以修复一部分采样噪声导致的错误，因此 pass@1 有提升；但与此同时，多样性下降更明显，延续并加重了 confidence-based unmasking 已知的 diversity collapse。这个现象说明 remasking 更像一个“去随机化”装置：它能把明显偏离高概率模式的 token 拉回来，但代价是样本分布更窄。

当 WINO 与 learned Bernoulli unmasking policy 结合时，收益明显大于与 deterministic Fast-dLLM 结合时。作者据此认为，remasking 的有效性不能脱离 unmasking policy 单独讨论。若前者是后验修正，后者决定了前面到底制造了多少可修正错误。

The value of the paper is not a new algorithm but a correction to an emerging narrative: masked dLLMs do not become reliably self-correcting just by adding a training-free remasking heuristic. The key point is that remasking only helps if the underlying model can actually propose a better replacement token after the position is masked again. If the reverse model lacks that conditional revision ability, remasking mostly adds steps without adding quality. First, it estimates a language-prior subspace. The authors collect blind hidden states, meaning hidden states produced when visual information is removed or weakened, and treat them as samples dominated by language priors. They then run SVD on this bank and extract a low-rank prior subspace. This is a meaningful departure from prior work: instead of assuming priors are a single bias vector, the paper models them as a low-dimensional subspace in representation space.

Second, at each decoding step, the current hidden state is decomposed into two parts: the component inside the prior subspace and the orthogonal residual. Only the projected prior component is modified. The orthogonal component is preserved as much as possible. This is the key mechanism for avoiding the blunt global translation used by logit-level suppression methods.

Third, the attenuation is adaptive. MGAP does not always suppress the prior component with the same strength. It first detects vision-language conflict, then scales the suppression accordingly. Strong conflict leads to stronger attenuation; aligned vision-language evidence leads to weaker intervention. This directly matches the paper’s claim that priors have a dual role.
