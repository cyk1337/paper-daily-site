Open-MOPD: Diagnosing and Fixing Capability Imbalance in Multi-Teacher On-Policy Distillation

这篇工作处理的不是“怎么把多个 teacher 接到一个 student 上”这么宽泛的问题，而是更具体的：在 multi-teacher on-policy distillation 里，即便路由完全正确，student 也常常学不会把多个 RL 专家的能力稳定整合起来。作者把这个现象定义为 capability integration gap，并用一个可控设定把它从路由误差里剥离出来：同一个 3B student，三类 domain teacher（math、code、instruction following），oracle routing，统一评测。全文最重要的发现是，瓶颈不主要来自常见直觉里的梯度冲突，而来自 token 级优化预算在不同 domain 之间被系统性扭曲。M-OPD 的损失按 token 聚合，真正决定谁被优化得更多的不是 prompt 数，而是 gradient token volume。短回答任务，尤其 instruction following，虽然 prompt 占比不低，但因为输出短、奖励衰减快、rollout reuse 带来 stale reward，最终几乎拿不到有效更新，导致能力整合明显失衡。

评应优先看诊断实验；“不是梯度冲突而是 token 预算错配”会改变多教师蒸馏的排查顺序。

Cross-Tokenizer On-Policy Distillation via Byte-Prefix Marginalization

这项工作解决的是跨 tokenizer 的全词表 on-policy distillation 问题。标准 OPD 在学生生成的轨迹上查询教师，并让学生匹配教师的 next-token 分布，但它默认师生共享 tokenizer。现实中更常见的情况是，Qwen、GLM、MiniMax 等模型族 tokenizer 不同，教师 token 和学生 token 的边界、词表坐标都不一致。已有方法要么只在候选集合上传递一部分概率质量，要么用 rank matching 把概率分给字节内容并不对应的学生 token，要么退化成 sequence-level KD，无法提供密集的 full-vocabulary token-level 监督。论文要构造一个在学生词表上的教师目标分布，同时满足三个条件：覆盖学生词表、按 byte 内容对齐、保留教师概率总质量。

评这不是小修小补；cross-tokenizer distillation 以前很多做法 target 就不对，建议直接看方法定义和误差分解，内部蒸馏实验应尽快补这个对照。

AdaFlash: Adaptive Speculative Decoding via On-Policy Distilled Diffusion Drafters

这篇工作处理的是 diffusion drafter 用于 speculative decoding 时一个很具体、但此前没有被讲透的问题：单步并行起草虽然便宜，但 bidirectional attention 带来的全局耦合会让 draft 质量方差明显变大。这个方差有两层表现。第一层是 domain-level variance：同一个 diffusion drafter 在不同任务域上的 acceptance rate 波动比 AR drafter 更大，静态蒸馏好的 drafter 一旦遇到分布偏移，速度收益会迅速掉下去。第二层是 token-level variance：同一条 draft 序列里，不同位置 token 的接受概率差异很大，固定 candidate length 会让 target model 花不少验证算力在低接受概率 token 上。论文要解决的不是“如何再做一个更快的 speculative decoding”，而是“如何让 diffusion drafter 在真实 serving 场景里更稳、更自适应，不因为方差问题把理论并行优势吃掉”。

评对扩散式draft模型的诊断（方差问题）比方法本身更有价值；做推测解码的看§3的问题分析即可，方法属增量。
