When EOS Tokens Disagree: Understanding Length Inflation in On-Policy Distillation

这篇工作研究 on-policy distillation 里的 length inflation，但切入点很具体：学生模型和教师模型对“停止生成”这件事，可能把概率质量放在不同的 EOS token 上。即便两者声明的 stopping set 相同，学生偏好的终止 token 和教师偏好的终止 token 也可能不同。由于 sampled-token OPD 只对学生实际采样到的 token 打分，学生原本会停下来的 EOS token 可能持续收到负蒸馏信号，而教师偏好的另一个 EOS token 又因为学生几乎采不到，无法有效学到，结果就是学生越来越不愿意停，响应长度不断膨胀，甚至耗尽 generation budget。

这篇工作处理的是 flow matching 图像生成模型的对齐训练问题：怎样在没有外部 teacher 的情况下，仍然获得类似 on-policy distillation 那种逐步、低方差、可稳定优化的监督信号。已有两条路各有明显缺口。直接做 RL，奖励通常只在完整去噪结束后给出，credit assignment 很长，梯度方差大，多目标时尤其不稳；做 teacher-based OPD，又需要为每个目标单独准备专门 teacher，成本高，而且 student 始终受 teacher 上界和偏置限制。Self-OPD 想解决的就是这个夹缝问题：保留 step-wise supervision 的稳定性，同时去掉 teacher 依赖，并让单模型能在同一张图上同时满足多个奖励目标。

评将强化学习中的优势函数概念引入流匹配模型的自我蒸馏，无需教师模型的设定很干净，对探索连续时间生成模型的 post-training 有启发。

OPDSearch+: On-Policy Distillation with RL Refinement for Search-Augmented Reasoning

这篇工作处理的是一个很具体、也很现实的问题：怎样把搜索增强推理能力从大模型迁移到 3B 级小模型，同时避免两类常见成本。第一类成本是数据成本。多轮 search trajectory 依赖在线检索返回，轨迹和检索器、索引版本强绑定，难以像普通 SFT 数据那样一次采完反复复用。第二类成本是教师成本。已有 OPD 往往需要先把教师做任务特化训练；如果直接拿现成 instruct 模型当教师，又会遇到 teacher-student 分布错位，学生在自己采样出来的轨迹上训练不稳，而且容易被教师上限卡住。作者要解决的不是单纯“更好模仿教师”，而是让蒸馏先把学生策略推到一个更适合后续 RL 优化的区域，再由 RL 超过教师和纯 RL 起点。

评揭示了 on-policy 蒸馏（即使是未针对任务微调的教师）如何作为 RL 的良好初始化，重塑策略分布以避免局部最优，对后训练中 RL 探索的初始化有启发。

Beyond Imitation: Filtering On-Policy Distillation by Reasoning Progress

这篇工作处理的是 reasoning 场景下 on-policy distillation 的一个具体失配：OPD 默认把“更像 teacher 的 token 分布”当成“更有助于解题推进”的代理信号，因此对所有 teacher 反馈一视同仁地做 token-level 蒸馏。但全文给出的核心观察是，这两个量并不等价。学生某一段推理即使偏离 teacher 的表述路径，也可能显著提高后续得到正确答案的概率；反过来，贴近 teacher 的局部输出也未必真的在推进求解。问题不在于 teacher 信号完全无用，而在于它在中间推理步骤上存在局部不可靠性。如果继续把这种不可靠监督均匀施加到整条轨迹，模型会被压回 teacher 的表面轨迹，抑制本来有效但风格不同的推理路径。

评指出了蒸馏推理能力时 Teacher Reward 与真实 Reasoning Progress 之间的 misalignment，其提出的双重排序过滤机制对构建高质量 RL/SFT 数据有参考价值，建议看其过滤策略的具体实现。
