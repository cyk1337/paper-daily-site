BiLoCo: Binary Low-Rank Corrections for Post-Training Quantization

在 Blackwell 等支持原生 FP4 Tensor Core 的 GPU 上，直接做 FP4 的 post-training quantization（尤其是 weight+activation 都量化）仍有明显精度缺口；而现有的“低比特残差 + 高精度低秩修正”（如 SVDQuant 的 BF16 rank-32）虽然能补精度，但修正分支也占用 Tensor Core，与主 FP4 GEMM 争抢同一硬件资源，且每个 rank 的存储/带宽成本偏高。论文要解决的是：在不牺牲太多延迟的前提下，用一种更适配 decode 硬件瓶颈（weight-traffic bound、CUDA cores 空闲）的修正形式，把 FP4 PTQ 的精度拉回去。

评这篇值得看的是 representation 和 kernel path 一起改：把 low-rank correction 变成可并行的加减而不是再抢 tensor core；先看方法图和 latency/memory 表。
David Jin,Beshr IslamBouli,Tarushii Goel,Han Guo,Yoon Kim
