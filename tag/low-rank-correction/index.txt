18:T51b,BiLoCo approximates each weight matrix as W ≈ R + \sum_{i=1}^{r} \alpha_i (v_i u_i^T), where R is the NVFP4-quantized residual and u_i, v_i are binary sign vectors in {±1} (bit-packed), plus per-component scalar coefficients \alpha_i. Inference then replaces multiply-accumulate in the correction with sign-controlled add/subtract accumulations, which maps naturally to CUDA cores.

A key algorithmic issue is that the optimal sign-vector decomposition is not given by SVD. The paper fits rank-one components greedily (following prior sign-decomposition work): initialize signs randomly, alternate updates of u and v for a few steps, compute the best scale \alpha for that component, subtract it from the residual, and repeat. After all components are fitted, it re-solves all \alpha jointly via least squares to account for overlap/correlation among components, then quantizes the remaining residual to NVFP4.

On the systems side, the implementation is a fused single kernel on Blackwell: the main NVFP4 GEMM runs on Tensor Cores; the binary correction is computed on CUDA cores within the same launch; the correction is added in the GEMM epilogue.
