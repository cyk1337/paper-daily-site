5:T473,HERALD is built around two observations. First, at the start of a block, all target positions are [MASK] tokens. Their pre-RoPE embeddings are identical, and their query vectors differ mainly by positional rotation. A single center-position [MASK] query can therefore approximate the B-query selection for the whole block. This makes full-cache attention feasible on the CPU, where the KV cache already resides, and avoids transferring the entire cache over PCIe. Second, step-0 logits provide a cheap semantic proxy for the block that is still being denoised. Taking argmax over all B positions yields a draft block whose KV can be used as approximate prefix context for selecting the next block’s sparse KV entries. This breaks the dependency that would otherwise force retrieval for block N+1 to wait until block N is finalized. The system uses a dual-stream pipeline with double-buffered sparse KV pools: the GPU denoises the current block using one sparse pool, while the CPU scans the full KV cache in DRAM with a fused online-softmax and top-k kernel, then transfers the selected entries into the idle GPU pool for the next
