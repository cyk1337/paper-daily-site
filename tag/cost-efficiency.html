Trading Human Curation for Synthetic Augmentation in RLVR

评合成任务替代率的量化结论直接改变RL训练数据规模化的成本结构，应立刻在内部RL数据管线中做验证

Uno-Orchestra: Parsimonious Agent Routing via Selective Delegation

这篇工作要解决的不是单纯的“给每个 query 选一个模型”，也不是传统多 agent 里“先规划、再手工分配执行器”的老问题，而是把两件事合成一个统一决策：面对一个复杂任务，系统应不应该拆解、拆到多深、每个子任务交给哪个模型、调用哪种 primitive、花多少预算，这些决策如何在同一个目标下联合优化。作者指出，现有 routing 方法大多停留在 query 级单次派发，无法利用复杂任务中的并行和层次结构；而层级式 agent workflow 虽然会拆任务，但子任务到执行器的映射通常是 prompt 规则、人工设计或绑定某个强模型，导致质量与成本的关键取舍没有被端到端学习。

评只看策略定义和 cost/accuracy 曲线；若 worker 真实成本核算干净，可作为后训练路由数据的设计样板。
