9:T4f0,The method is deliberately simple. It follows a read-compute-feedback-reread procedure. In the first pass, the model reads the original task and long context, then produces one or more reasoning traces. These traces are not assumed to be fully correct; they are treated as an observable textual proxy for latent task state. In the second pass, the collected traces are serialized as text T and prepended before the long-context block C. The model then rereads the context and answers. This is trace as state. The critical control is trace append: the second pass uses exactly the same trace text, but places it after the long context. That makes the comparison unusually clean. Both conditions have the same information content, similar token budget, and the same two-pass structure; the only difference is whether the trace can influence contextual encoding during rereading. The theoretical section provides the conceptual backbone. Using causal state update processors with finite working memory, the paper shows a worst-case exponential separation between condition-first and condition-last orders. The result is not a tight theorem about practical Transformers, but it serves as a strong design principle for causal sequence models operating on long contexts.a:T431,The empirical study spans 3 frontier models and 3 long-context benchmarks, yielding 27 reported model-task-metric combinations.
