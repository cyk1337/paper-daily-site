b:T42b,The method introduces a sleep-like consolidation step triggered when the context window fills up.
- Wake phase: the model runs normally with a limited KV cache plus SSM-style fast weights (e.g., GDN / Mamba-like outer-product or delta-rule updates).
- Sleep phase: the model stops consuming new tokens and performs N offline recurrent forward passes over the accumulated context. Across these passes, fast weights inside SSM blocks are updated recursively via a learned local update rule, effectively turning “memory writing” into an iterative computation.
- After consolidation, the KV cache is cleared and the model resumes wake-time prediction with updated fast weights; crucially, prediction remains single-pass (no looping at inference time).
Training is end-to-end: gradients are backpropagated through the sleep procedure to optimize post-sleep task performance. The conceptual distinction from prior looped/depth-recurrent models is that recurrence is used for consolidation (writing/organizing memory), not for increasing compute at each prediction step.c:T451,They model consolidation as an iterative lossy rewrite loop.
