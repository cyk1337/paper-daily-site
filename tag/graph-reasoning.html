GRAIN: Bridging Name and Narrative Shifts in Real-World Graph Reasoning through Invariance-Rewarded Agentic RL

这篇工作关注的是一个很具体但常被 benchmark 掩盖的问题：LLM 在图推理里并不只是“不会做算法”，更常见的是在把自然语言叙述解析成图结构这一步就已经不稳了。只要节点命名方式变了，或者任务从标准模板换成真实叙事文本，模型性能就会明显波动。也就是说，模型学到的往往是表面模式，而不是对底层拓扑结构的稳定抽取与表示。GRAIN 要解决的核心问题，就是如何让单个 LLM 在 name shift 和 narrative shift 下仍能稳健地完成 language-to-graph 的语义解析，并把后续计算交给确定性图算法。

评关注 LLM 在结构化推理中对表面 pattern 的过拟合问题，其提出的 Structure Invariance Reward 对如何用 RL 提升 LLM 的抽象提取能力有一定启发。
