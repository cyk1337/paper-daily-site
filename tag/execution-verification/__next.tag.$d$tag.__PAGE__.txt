第二层是 PRPO，Peer-Relative Policy Optimization。每一侧不是单个 policy，而是 N 个 LoRA adapter 组成的同角色种群，挂在同一个 frozen base 上，LoRA 参数量约为基座的 0.1%，便于低成本维护多策略与权重重组。每一轮固定一个条件 ω=(scenario, frozen opponent committee, decoding budget)，让同角色策略在相同条件下比较。作者把 same-role peers 放进 advantage baseline，而不是放进 opponent pool、reward shaping 或 learned critic。直观上，这样做的目的是让某个 policy 的得分反映“在同样对手、同样任务、同样预算下，它比同伴好多少”，从而把对手强弱波动和样本难度波动从梯度信号里扣掉。文章把这种收益称为 matched-population advantage，并给出 advantage variance 的闭式分析。为避免种群退化，训练中还有 tournament 机制：淘汰最弱 adapter，并从较强策略重播种，维持策略多样性。

The first is an execution-verified training environment. The authors instrument known weakness classes into containerized copies of real repositories and only admit a site if an existing exploit harness can actually fire. This yields samples with executable ground truth: not merely that a vulnerability class is present, but that there exists a reachable exploit path. Red edits a reference diff that already completes a development task and passes tests. On vulnerable scenarios, Red must introduce one reachable weakness of the target class while preserving functionality. On clean scenarios, Red makes a similarly sized edit that introduces no weakness. Blue acts as an LLM code reviewer: it must classify the patch and localize the entry point, critical operation, and trace, which makes the output actionable rather than purely binary.

The second layer is PRPO, Peer-Relative Policy Optimization. Each side is a population of LoRA adapters over one frozen base model, with adapter size around 0.1% of the base parameters. A training round fixes a condition consisting of the scenario, a frozen committee of opposing policies, and a decoding budget. Same-role policies are then compared under identical conditions. The key idea is to place the population inside the policy-gradient baseline rather than in the opponent pool, reward shaping, or a learned critic. Intuitively, a policy is rewarded for outperforming peers that faced the same task, same opponents, and same budget, which removes some variance due to opponent strength and instance difficulty. The paper calls this the matched-population advantage and provides a closed-form analysis of the resulting advantage variance. To avoid strategic collapse, the population is maintained with a tournament mechanism that retires weak adapters and reseeds them from stronger ones.

An important design choice is that the game is non-zero-sum. Red cannot win by producing broken code that fails to build or fails tests. Rewards are execution-verified, so Red must generate patches that are functional, exploitable, and difficult for Blue to detect. That makes the training signal much closer to realistic code-agent deployment.b:T69a,The experimental program is organized around five questions: whether the attacker is reliable enough to train against, whether co-evolution beats static training, whether the detector transfers to unseen applications and languages, whether weight updates are necessary, and whether a population helps under a fixed verifier budget.
