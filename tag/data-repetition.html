Scaling Domain Data Repetition in LLM Pretraining

这篇论文研究一个很实际的预训练数据配比问题：模型规模变大时，训练 token 数通常按 tokens-per-parameter ratio 同步增加，但高质量领域数据很难同比例扩张。如果不重复使用这些领域数据，它们在 mixture 中的占比会被通用数据稀释；如果重复太多，又可能过拟合。论文要回答的是，在固定 TPP 的 LLM 扩展设置下，不同领域数据应该重复多少次。

评应立刻把 domain repetition 纳入 mixture sweep；低 loss 领域可多重复这一点会改变常规去重直觉。
Jingwei Li,Xinran Gu,Rui Dai,Xintong Hao,Chengyin Xu,Yan Wu,Shuran Zheng,Jingzhao Zhang

Internal Data Repetition Destroys Language Models

预训练已进入数据受限阶段，即便经过激进去重，语料中仍残留精确重复、近重复、模板化内容与语义冗余页面。此前关于数据重复伤害的对照研究早于Chinchilla缩放定律，采用固定token总量训练不同规模模型，导致大模型欠训练、小模型过训练，且用“有效参数量”衡量重复损失，与当下以FLOPs为核心的训练效率度量体系不匹配。在计算最优训练范式下，需要系统量化精确文档重复带来的性能损失，在固定重复数据占比的前提下分离重复总量与重复结构的影响，定位对性能伤害最大的重复配置，并给出可互操作的量化伤害度量。

评应立刻对内部去重策略做同款消融；中等重复最伤这个结论会改变 data recycling 的默认假设。
Jessica Chudnovsky,Joshua Kazdan,Noam Levi,Rylan Schaeffer,Yegor Denisov-Blanch,Bo He,Mehmet Donmez,Sanmi Koyejo,David Donoho

Less Data, Faster Training: repeating smaller datasets speeds up learning via sampling biases

大模型领域长期存在“数据越多效果越好”的共识，但近期多个研究观测到反直觉的“小-大差距”现象：在相同计算量下，使用更小的数据集多轮重复训练，比使用更大的单轮数据集能更快达到目标性能，该现象无法被现有基于SGD梯度方差、课程学习、分布偏差的理论解释。

评会改变我对“重复数据只是坏事”的 prior；应先读机制实验，再决定是否在内部数据去重 ablation 里复现。
Jingwen Liu,Ezra Edelman,Surbhi Goel,Bingbin Liu
