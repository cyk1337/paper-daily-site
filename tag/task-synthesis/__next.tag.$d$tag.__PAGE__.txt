The pipeline has four main parts. First, an authoring agent works in a draft sandbox with web search, shell execution, and file editing. It researches concrete engineering issues from documentation, GitHub repositories and issues, and Stack Overflow, looking for reproducible problems such as dependency conflicts, version-specific bugs, configuration pitfalls, and edge cases. Second, it jointly writes the task instruction, execution environment, and verification tests, then performs structural validation and self-solving so the candidate is executable, checkable, and solvable by the system itself.

Third, the candidate enters calibration. The paper defines two retention criteria. Multi-solver calibration seeks disagreement in a heterogeneous solver pool: at least one solver must pass and at least one must fail. Contrastive calibration is stricter: a designated stronger solver must pass while a designated weaker solver must fail. In both cases, learnability is defined relationally, not by an absolute difficulty score. Fourth, if the criterion is not met, the authoring agent revises the task and revalidates it before another probing round. Importantly, revision is not limited to wording tweaks. The agent may revisit external research, change the technical direction, rewrite the environment, modify tests, or alter constraints.

Two design choices matter. First, the feedback includes not only verified pass/fail outcomes but also full trajectories. That gives the authoring agent actionable evidence about why a task failed or succeeded, which can be used to reduce noise, sharpen constraints, or introduce steps that better separate strong and weak solvers. Second, the loop is adversarial but constrained: retention always requires at least one real successful solve, so the system does not drift toward pathological or unsolvable tasks. Compared with one-shot authoring plus validation, or with single-solver scoring, this adds a behavior-driven revision loop. That is the key difference, because learnability is treated as something that can be actively shaped rather than passively measured.b:T76d,The most informative results come in three layers.
