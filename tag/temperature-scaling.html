Generative Criticality in Large Language Model Temperature Scaling

这篇工作研究的不是提升模型性能，而是试图回答一个更偏基础分析的问题：当我们调节采样温度时，LLM 生成文本在表示空间里是否会出现类似统计物理相变的结构变化。作者想建立一套可计算的“场论式”描述，把 token embedding 序列看成一维链上的连续自旋变量，然后定义 susceptibility、order parameter 和 intrinsic dimension 这类量，观察它们是否在某个临界温度附近出现突变或峰值。

评用统计物理场论解释 Temperature 带来的生成相变，视角非常新颖，建议关注其定义的序参量和 $T_c$ 临界点现象。

Rethinking the Role of Temperature in Large Language Model Distillation

核心问题是：LLM 蒸馏中 RKL 优于 FKL 的常见结论，是否被 τ=1 的默认温度设置误导。已有比较通常忽略 distillation temperature，而温度正是软化 teacher 分布、暴露非最高概率 token 信息的关键变量。该工作指出，温度对 FKL 和 RKL 的作用并不对称：FKL 会从更软的 teacher 分布中获得更多 non-dominant token 信号，RKL 则更多表现为梯度尺度变化。

评重新审视了蒸馏中的 KL 散度选择，指出高温下 FKL 优于 RKL，改变了蒸馏 loss 的 prior，值得在做模型压缩或小模型对齐时参考。
Hoang-Chau Luong,Lingwei Chen
