9:T48f,ALPS uses a two-stage recipe. Stage 1 trains a ViT-B/16 from scratch with fixed sinusoidal positional embeddings and raw final-layer patch tokens. The same tokens are supervised by four objectives: image-text contrastive learning, autoregressive captioning, pixel reconstruction, and dense correspondence. The contrastive loss uses both web captions and sentences sampled from longer synthetic captions, with separate softmaxes so that captions for the same image are not treated as negatives. The caption decoder predicts the full synthetic caption from image tokens and previous text. A lightweight convolutional decoder reconstructs images from clean and noisy tokens with L1, SSIM, and image-gradient losses. Dense correspondence adds local spatial supervision across crops and scales. Stage 2 then performs cross-view self-distillation: a student sees an augmented view and predicts frozen Stage-1 teacher patch tokens at corresponding locations in a clean view. One component, Schema-Guided Action Adaptation, addresses heterogeneous control spaces. Instead of feeding raw action vectors directly, each control dimension is converted into a semantic token defined by its schema, while the synchronized numeric value is injected through affine modulation. This decouples semantic meaning from task-specific vector layouts. The design is motivated by the fact that the same tensor dimension can mean entirely different things across environments, so raw vectors are a poor shared interface.

The second component, Agent-Aware Spatial Modulation, addresses stream-to-agent binding. From an agent description, the model derives an agent-specific spatial gate that selectively updates visual tokens associated with the intended entity. Each branch attends only to its corresponding action stream. The point is to prevent action leakage across agents in a shared latent space, especially when entities overlap, look similar, or interact closely.

For efficient rollout, the paper keeps the full HAI while transferring a bidirectional video teacher to a blockwise causal generator. This uses teacher forcing for AR tuning and distribution matching distillation for streaming video. The paper also introduces causal temporal alignment between raw actions and compressed video latents, plus a global latent offset so action windows advance consistently with cached rollout. For a pretraining-oriented reader, these ablations matter more than the headline demo quality.d:T560,Agima (Agentic Imagination) trains one omni model to play three roles:
- Policy: propose actions given current observation and goal.
- World model: generate the next visual observation (an imagined image) conditioned on the action.
- Reasoner/evaluator: compare imagined futures in language space and decide which action/plan to execute.

Two-stage training:
1) Supervised fine-tuning with interleaved trajectories that explicitly teach the model to treat imagined observations as valid context for continued planning. The paper uses three planning formats: (i) linear rollout (single imagined trajectory), (ii) counterfactual branching (branch on alternative actions at a step and reject failing branches), and (iii) forward thinking (imagine and compare longer candidate plans before committing).
2) Agentic RL using GRPO with only a binary success reward. No extra demonstrations are provided; RL shapes how the model allocates imagination and comparison—when to explore another plan, how many alternatives to branch, and where branching matters—while keeping generated images as context during planning.

A key design choice is “single model, shared interface” instead of separate policy and world models, so imagined vs. real observations can be swapped seamlessly and RL can directly sculpt the reasoning/search strategy rather than only the action distribution.e:T432,Benchmarks include Maze2D, Sokoban, Pacman, and PushT, trained on easier instances and evaluated on harder settings excluded from training.

Reported highlights:
- With SFT alone, Agima generalizes from two-box to four-box Sokoban. Under sparse real feedback (real observation every 5 actions), it reaches 40% success vs. 2% for an action-only planner fine-tuned from the same backbone.
- “Forward thinking” improves long-horizon planning in Pacman even when trained on the same instances as linear rollouts, suggesting gains come from comparison/selection behavior rather than more data.
- GRPO further improves success and yields emergent planning organization not seen in SFT: e.g., in forward thinking it often imagines one plan first and only explores a second if the first is predicted to fail; in counterfactual branching it increases branching and concentrates it on critical irreversible decisions.
