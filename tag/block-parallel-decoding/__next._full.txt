18:T8da,方法核心是提出 BDLM Mamba-H：一个面向 block diffusion 的 Mamba-attention hybrid，其中“部分双向性”只保留在当前 active denoising block 内，而已完成 prefix 只通过可缓存的前向状态参与条件化。具体做法有几个关键点。

第一，架构层面，attention 层和 Mamba 层都按 block 边界缓存。对 attention 层，缓存对象仍是标准 KV；对 Mamba 层，缓存的是每层在 block 边界处的 forward recurrent boundary state。这样，已完成 block 不需要在每个 reverse diffusion step 重新跑一遍。

第二，作者没有采用全序列双向 Mamba，而是把 reverse-direction scan 限制在当前 block 内。原因很直接：如果反向扫描跨过 clean prefix，那么反向状态会依赖当前 block 的 noisy 内容和 diffusion timestep，prefix 就不再是稳定缓存。把反向扫描裁到 active block 后，prefix 只需要 forward scan，天然可复用；当前 block 仍然保留局部双向 mixing，避免退化成纯因果 denoiser。

第三，训练目标采用 all-block objective。一个训练窗口被切成多个 block，同一窗口内每个 block 都轮流作为“当前去噪目标”，其左侧 clean blocks 作为条件前缀。关键不只是 block-wise loss，而是训练时显式构造与推理一致的 prefix caches：attention KV 和 Mamba forward states 都在训练图里被真实建立，后续 block 的 loss 会直接反向训练这些缓存状态的构造过程。这样，模型学到的不是抽象的 prefix 表示，而是推理时真正要复用的状态。

第四，论文还处理了 diffusion timestep conditioning 与缓存冲突的问题。timestep modulation 只作用于当前 active block，而不污染 clean-prefix cache。否则 prefix hidden state 会依赖当前 reverse step，缓存就失效。这个 factorization 看起来像工程细节，实际上是 block diffusion 与 cacheable recurrent mixer 能否兼容的必要条件。

第五，作为对照，作者系统比较了四类模型：full-sequence attention、full-sequence DiffuMamba-H、BDLM attention、BDLM Mamba-H。这里的价值在于把“block factorization”和“mixer 替换”两个变量拆开，而不是只和一个弱基线比较。19:T8b1,The proposed model is BDLM Mamba-H, a block diffusion Mamba-attention hybrid with partial bidirectionality. The key design choice is simple but consequential: bidirectional mixing is retained only inside the current active denoising block, while completed prefix blocks are represented through cacheable forward states.

At the architectural level, attention layers cache standard KV tensors at block boundaries, and Mamba layers cache forward recurrent boundary states. This lets completed blocks remain fixed conditioning context across reverse diffusion steps, instead of being recomputed every time.

The main departure from prior full-sequence DiffuMamba-style models is the restriction of the reverse-direction Mamba scan. A reverse scan over the whole denoising window would make prefix states depend on the current noisy block and on the diffusion timestep, which destroys cache reuse. By limiting the reverse scan to the active block, the model keeps local bidirectional context where denoising needs it, while preserving a stable forward-only prefix representation.

Training is built around an all-block objective. A training window is partitioned into blocks, and each block is trained as the current denoising target conditioned on the clean prefix blocks to its left. The important part is not merely summing block losses. During training, the model explicitly constructs the same cache objects used at inference: attention KV caches and Mamba forward boundary states. Losses on downstream blocks therefore directly train the mechanism that builds reusable prefix states.

The paper also introduces timestep-conditioning factorization so that diffusion-step modulation applies only to the active block. This avoids contaminating clean-prefix caches with timestep-dependent activations. That detail is essential: without it, the cached prefix would vary across reverse diffusion steps and would no longer be reusable.

Methodologically, the paper compares four controlled variants: full-sequence attention, full-sequence DiffuMamba-H, BDLM attention, and BDLM Mamba-H. This is useful because it separates the effect of block factorization from the effect of replacing attention with Mamba-style recurrent mixing.1a:T78a,The empirical story has two parts: quality and throughput.

For quality, the authors first run a controlled 87M-parameter study on DCLM with tuned hyperparameters. The headline result is C4-en validation perplexity: BDLM Mamba-H reaches 61.6, compared with 76.5 for BDLM attention, 83.7 for full-sequence DiffuMamba-H, and 87.6 for full-sequence attention. This is the strongest evidence in the paper. It suggests that the gain is not coming from Mamba alone or from block diffusion alone, but from the combination of cache-aligned block factorization, local bidirectionality in the active block, and training that directly supervises reusable prefix states.

The models are then scaled to 350M parameters, comparing BDLM attention and BDLM Mamba-H under a Complete(d)P-style learning-rate transfer rule. At this scale, BDLM Mamba-H remains comparable to BDLM attention in perplexity, which is important because it shows the throughput gains are not bought by a large quality collapse.

For throughput, training throughput is measured at 8192 context on 8×A100-80GB, while inference throughput is measured with a 700M randomly initialized model on 1×A100-80GB at batch size 1. As generation length increases, BDLM Mamba-H overtakes both BDLM attention and full-sequence DiffuMamba-H. At 65K context, it reaches 19.7× the throughput of full-sequence DiffuMamba-H. At 262K, it is still 3.7× faster than BDLM attention. The trend matches the intended mechanism: as the prefix grows, attention cache traffic becomes increasingly expensive, while Mamba boundary states remain compact.

The most meaningful ablation insight is structural rather than cosmetic. Restricting reverse scans to the active block is necessary for stable caching, and the all-block objective is necessary to train the exact recurrent boundary states reused at inference. The paper’s experimental design supports the claim that both pieces matter together.1b:T584,Start with the introduction and the main method figure to fix the problem setting.
