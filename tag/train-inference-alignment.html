CForce: Boosting Parallel Decoding for dLLMs via Consistency Forcing

这篇工作解决的是 diffusion LLM 在高并行解码下的一个核心瓶颈：早期去噪阶段的预测不可靠，尤其在 aggressive threshold decoding 时，模型会一次性提交很多 token，但这些 token 当时可用上下文还很弱，错误一旦提交就会向后传播，导致速度上去了、质量却明显掉。作者认为，dLLM 的加速问题不能只理解为“减少 denoising step 数”，更关键的是“让早期阶段在高并行承诺下也更可靠”。这个问题在 edit-capable dLLM 上更突出，因为后期 token-to-token refinement 阶段拥有更丰富上下文，也可能修正早期草稿；如果训练时没有显式利用这种后期信息去约束早期预测，推理时就会出现训练-推理错位：模型被要求在最难、信息最少的阶段做高置信提交，但训练目标并没有专门优化这一点。

评应优先看；dLLM 的瓶颈不是并行步数本身，而是早期轨迹错配，值得在内部 LLaDA/MDLM ablation 复现。

Spec-AUF: Accept-Until-Fail Training under Train-Inference Misalignment for Masked Block Drafters

这篇工作处理的是 speculative decoding 里一个很具体但很关键的训练—推理错配问题：对于 masked/block-style drafter，训练时通常对整个 block 的每个位置都做交叉熵监督，但推理时 target verifier 只会接受从左到右连续正确的最长前缀，一旦前面某个 token 错了，后面即使预测对也全部作废。也就是说，现有 full-block loss 奖励了很多对吞吐没有贡献的“后缀正确”。作者提出 AUF（Accept-Until-Fail），目标是让训练信号更贴近 verifier 的 prefix contract。

评解决block drafter训练-推理错位的思路干净直观，做推测解码的话重点看§3方法设计即可。

When to Commit? Towards Variable-Size Self-Contained Blocks for Discrete Diffusion Language Models

离散扩散语言模型（dLLM）采用分块半自回归解码时存在两个耦合问题：一是训练阶段用全序列上下文做降噪，推理阶段块提交后无法利用未来上下文的训练推理不匹配；二是固定块大小或标点启发式的块边界选择逻辑无法保证块语义独立，容易提前提交依赖未来上下文的token，导致后续块的错误传播。
