18:T4d7,MME-Safety is built around a four-dimensional annotation scheme: risk scenario, harm severity, image stealth level, and text stealth level. The risk taxonomy covers nine categories, including illegal activities, hate speech, malware generation, physical harm, economic damage, fraud, pornographic content, privacy violations, and politically sensitive content. Harm severity is represented in four tiers, from no harm to high harm, with a 0–10 consequence scale. Image stealth has three levels: explicit harmful objects or embedded malicious text; harmful visual elements that require inference; and visually neutral images whose risk appears only with the text. Text stealth follows a parallel three-level structure: explicit harmful requests, euphemistic reformulations, and benign-looking text that becomes harmful only when paired with the image. The dataset is curated from MM-SafetyBench and SIUO with manual screening to ensure that each image-text pair actually conveys the intended malicious signal. The evaluation framework goes beyond binary attack success by measuring response reliability, actual risk exposure, and the structure of defensive behavior, such as risk identification, refusal, and safe alternative suggestions.19:T566,The contribution is a benchmark and annotation protocol rather than a new model. VidOmni-Bench contains 500 videos spanning five predefined complexity types: Static World, Body Motion, Hand-Object Interaction, Crowd Action, and Multi-Scene Dynamics. These are balanced across three duration buckets, from very short clips to videos up to 90 minutes. That design is important because complexity and duration are treated as separate axes instead of being entangled.

The caption source is also deliberate. Instead of relying on human-written dense ground-truth captions, the authors use five different Video-LLMs to generate dense descriptions: InternVL3.5, Qwen3-VL, video-SALMONN 2+, Keye-VL 1.5, and Gemini 3 Flash. This yields 2,500 video-caption pairs. Human annotators then verify each sentence in a two-stage process and assign binary labels. Sentences that are plausible but unsupported by the video are retained as hard negatives. This makes the benchmark harder to game than synthetic negative construction, because the negatives come from realistic model hallucinations rather than obviously corrupted text.

Conceptually, the benchmark measures grounded verification rather than stylistic generation. It requires checking object states, actions, background changes, scene transitions, and temporal consistency, which makes it a stronger test of video evidence integration.1a:T42a,The experimental findings are straightforward. Current Video-LLMs frequently hallucinate events during dense caption generation, so their outputs are not reliably grounded in the video. They also perform poorly when used as verifiers, struggling to reject plausible but incorrect event descriptions. In addition, failure patterns vary substantially across complexity types and duration ranges, which suggests that current weaknesses are heterogeneous rather than reducible to one single bottleneck.

The paper also includes dataset statistics showing that VidOmni-Bench requires broader video inspection than prior benchmarks and provides denser event coverage. Of the 500 videos, 433 contain audio, which means some examples may implicitly test audiovisual grounding as well. The qualitative conclusion is still clear: long duration, fine-grained interactions, and multi-scene dynamics significantly stress current Video-LLMs in event-level verification.1b:T47b,The benchmark separates structural multiplicity from provenance multiplicity. A provenance atom represents an underlying evidential origin, and a mapping π(p)=e assigns each graph path p to its source evidence e. GraphEcho-Syn contains 800 fictional claims across biomedicine, materials, agriculture, and economics. Each claim has five supporting and five refuting evidence atoms, and each atom can be represented by up to five three-hop graph paths. The key interventions keep the claim, evidence wording, path templates, and path lengths fixed while changing whether five paths come from one source or five distinct sources. Conditions such as 1S5P and 5S5P therefore isolate path redundancy from independent corroboration. The agent environment exposes the current node, visited nodes, neighbors, short previews, and remaining walk budget. A walk action reveals a neighbor’s full content; a stop action returns the final judgment. The paper also trains a provenance-aware post-trained model, PAPT, using synthetic supervision, and compares it with cheaper controls such as metadata display, instructions, preprocessing, and reward ablations.1c:T44f,ERPBench runs agents against a live self-hosted ERPNext instance. Scoring is state-grounded: graders inspect database fields rather than trusting the UI. The task suite has three tiers. T1 covers single-record edits, selections, toggles, and simple creation. T2 adds 6–9 field records and relational-field coordination. Each scenario specifies an initial world state, available tools, policies, user objectives, and safety-relevant conditions. A User Agent interacts with a Target Agent over multiple turns, and in adaptive attacks the next user action is generated conditioned on the target agent’s actual behavior and the current attack state. The Target Agent acts in a stateful tool environment where tool calls, outputs, and resulting state transitions are explicitly recorded. This matters because the benchmark can judge what the agent actually executed, not just what it claimed in text. The current release includes 22 attack families and 35 scenarios across 7 domains, with 25 core-domain and 10 cross-domain scenarios. The dataset contains more than 2,500 long-horizon trajectories with an average length of 14.7 turns. The adjudication protocol is a major design point. Instead of a binary success/failure label, the benchmark defines five trajectory-level outcomes: Safe Completion, Correct Refusal, Unsafe Completion, Over-Refusal, and Indeterminate. First, model safety is not captured by a single scalar: some models reduce unsafe completion at the cost of high over-refusal, while others remain helpful but cross safety boundaries once authorization, tool state, or external content changes over time. Second, long-horizon tool environments reveal failure modes that are largely invisible in one-shot benchmarks, especially attacks involving intent hijacking, objective drift, memory poisoning, and indirect prompt injection. Third, repeated-run robustness matters: the same model can behave inconsistently across rollouts, which is a serious deployment concern for agents. The main experimental value is therefore diagnostic rather than leaderboard-centric.1f:T666,The main artifact is the ImpossibleRubrics benchmark. Instead of storing fixed rubrics, it stores task environments: each example contains a closed evidence packet, a question designed to pressure the model toward a confident answer, and a machine-checkable oracle certificate specifying which claims are permitted and which are prohibited. This design matters because a fixed-rubric benchmark would be vulnerable to memorization and would not truly test rubric generation quality. By keeping environments and certificates, the benchmark can evaluate newly generated rubrics from arbitrary models. The evaluation protocol is adversarial but structured. A rubric generator first produces a rubric from the task and evidence. A fixed attacker then writes an answer intended to score highly under that rubric, regardless of whether it remains faithful to the evidence. An honest baseline answer is also prepared. A literal judge scores both answers using the generated rubric, while the oracle certificate independently checks for violations.
