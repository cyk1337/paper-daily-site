PAR: Progress-Aligned Recurrence for Length Generalization in State Tracking

这项工作解决的是 looped / recurrent language model 在状态跟踪任务上的长度外推问题：模型在短操作序列上训练，测试时需要执行长得多的操作链。关键困难不是单步规则学不会，而是递归迭代时缺少“第 k 次循环应完成第 k 步任务”的对齐关系，导致早期循环被迫预测最终答案，或者隐藏状态在多次复用共享块后发生尺度漂移。论文把失败模式拆成两类：目标不对齐和状态漂移，并围绕这两点提出 PAR。

评这篇会改你对 test-time recurrence 的 prior：问题不只是算力不够，而是监督目标和状态尺度都错了；建议立刻复现它的 progress target 与 norm anchoring 消融。

Claim Laundering: When Agent Decision Models Trust Records Over Reality

这篇文章研究 agent decision model 的一个具体失真：当环境观测和 agent 自己写下的行动记录发生冲突时，模型更相信记录而不是现实。作者把这种现象称为 claim laundering。问题并不抽象，它直接对应很多 agent 的常见失败模式：某一步其实没有生效，但日志里写成“已完成”，于是后续决策层在单次前向里把这个错误当成既成事实，提前停止、继续推进，或者做出不可逆购买。

评只看实验设计和 probe/patching 结果；它提醒 agent 训练日志本身可能是污染源。
