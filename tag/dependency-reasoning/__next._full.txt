18:T575,MEME defines a 2D taxonomy: entity scope (single vs. multi-entity) × temporal dynamics (static vs. evolving), then instantiates six tasks that intentionally avoid already-covered easy variants:
- Exact Recall (single/static, verbatim fidelity)
- Aggregation (multi/static, cross-session coverage)
- Tracking (single/evolving, full revision history)
- Deletion (single/evolving, stop reporting removed facts)
- Cascade (multi/evolving, propagate updates through explicit dependency rules)
- Absence (multi/evolving, recognize uncertainty when upstream changes invalidate a dependent fact without a replacement rule)

Data is generated from a DAG knowledge graph with explicit conditional rules, enabling gold answers by construction. A key methodological step is an “in-context solvability” check: feeding gold facts directly to the answering LLM to confirm the tasks are solvable in principle, isolating failures to memory write/retrieve/update mechanisms.

The main diagnosis is retrieval-time failure: stale values outrank update events (notably in vector retrieval), or tool/graph/sparse retrieval fails to surface the right evidence, so the answering LLM defaults to the earlier value.
