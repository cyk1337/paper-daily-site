9:T82c,The contribution is an evaluation framework rather than a new optimizer. On the continuous side, the authors use standard synthetic functions including Branin, Hartmann-3, Hartmann-6, Ackley, and Rastrigin. Domains are normalized to [0,1]^d and objectives are converted to maximization. A key design choice is that they do not only test the canonical form of each function. They also create disguised variants by applying bijective transformations to the input domain and output range, specifically to reduce the chance that the model exploits memorized patterns tied to familiar function names, coordinate systems, or known optima. This is one of the most important parts of the paper because it separates optimization behavior from benchmark recognition.

The LLM is treated as a batch policy. At each step, the prompt contains previously queried points, their objective values, and the remaining budget, and the model proposes q candidates with q in {1,2,4}. They compare single-turn prompting, where each round is reconstructed from scratch, against multi-turn interaction, where the model keeps the conversation and can reflect on prior reasoning. The total oracle budget is fixed at N=120, with 2d initial points, so comparisons across batch sizes are budget-matched. Performance is measured with regret, especially simple regret.

For the discrete setting, they use the PMO molecular optimization benchmark. Here the model proposes molecules in SMILES form and deterministic oracles score them. This setting is naturally aligned with language models: SMILES is a discrete sequence representation with local compositional semantics, so the model can leverage priors from pretraining about symbolic patterns, local edits, and constraint-aware generation. The paper’s deeper point is that LLM optimization behavior is strongly representation-dependent. In numerical spaces, the model has to infer geometry from tabulated histories, which is not a native strength of language pretraining. In molecular string spaces, the task is much closer to structured generation and guided rewriting.a:T5bf,From the full text provided, the continuous experiments use a fixed total budget of N=120, batch sizes 1, 2, and 4, and 2d initial points, across standard functions ranging from low to moderate dimensionality. The authors evaluate both canonical and disguised versions of the objectives. The main empirical takeaway is not a single headline number but a pattern: frontier LLMs can sometimes rival strong classical baselines such as Gaussian-process Bayesian optimization with expected improvement, yet their performance is brittle. It changes materially with task transformations, dimensionality, and batch size. In other words, the models are not consistently reliable numerical optimizers.

The molecular results are stronger. On PMO oracles, the frontier reasoning models are reported to be highly sample-efficient and to frequently outperform specialist methods while using only a fraction of the oracle evaluation budget. That budget efficiency is the important result in a black-box optimization setting.

The model family under study is Anthropic’s Sonnet 4.6, Opus 4.8, and Opus 5, which allows the paper to compare generations within a single frontier reasoning family. The quantization format is frozen (bit-width, scale, zero-point, grid layout, inference kernels). The only variables are the integer codes assigned to weights.

The objective follows reconstruction-based PTQ, with an explicit focus on activation mismatch: at inference, a layer sees activations produced by a quantized prefix. Similar to GPTAQ, it uses activation-aware reconstruction by collecting activations from (i) the full-precision model and (ii) the partially-quantized model to obtain \tilde{X}, then optimizes reconstruction under the more realistic activation distribution.

Optimization is backprop-free: instead of STE/gradient descent, it performs iterative discrete updates over integer codes (a coordinate-style local search). Updates are accepted only if they reduce the overall reconstruction loss, yielding monotonic loss decrease and finite termination (a finite number of accepted updates). The offline budget is controlled by the number of sweeps T, and the per-sweep cost is argued to be comparable to a GPTAQ pass.
