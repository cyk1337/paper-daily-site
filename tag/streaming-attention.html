Windowed-MTP: Removing the Full-Context Draft-KV Tax at Million-Token Context

这篇工作解决的是长上下文 speculative decoding 里一个被低估的瓶颈：内置 MTP/NEXTN draft head 在百万 token 上下文下并不“便宜”。虽然 target verify 端越来越多采用 hybrid 或 linear attention 来压低长上下文成本，但很多原生 draft head 仍然对全量 KV cache 做 full attention。结果是 draft 每走一步都要线性读取整段上下文，context 越长、draft 越深，这部分 draft-KV read tax 越重，甚至会把 speculative decoding 的净收益吃掉，在低 acceptance 的难任务上比不做 speculation 还慢。论文的核心问题不是如何提高 acceptance，而是如何去掉这个 full-context draft tax，同时保持 exact speculation 的正确性。

评指出 MTP 在长上下文下的隐性税，是部署前沿模型必踩的坑；training-free 无损修复应立刻在内部长上下文 serving 栈里复现。
Alagappan Valliappan

Towards Tight Bounds for Streaming Attention

这篇工作研究的是 streaming attention 的空间复杂度边界，也就是：在不能保存完整 KV cache 的条件下，注意力到底能被压缩到什么程度，同时还能近似原始 softmax attention。它关心的不是提出一个工程启发式，而是把 KV cache 压缩问题形式化成一个近似问题，并尽量把上界和下界收紧。更具体地说，作者试图回答此前理论工作留下的空白：不同温度区间、不同误差要求下，attention 近似所需的内存规模是否已经接近最优，哪些地方还能改进，哪些地方已经有不可突破的下界。

评如果你做 KV-cache 压缩，这篇该读；不是因为它能立刻提速，而是它在收紧可达边界，能帮你判断现有 heuristic 到底是没调好，还是问题本身就难。
Justin Y. Chen,Ying Feng,Piotr Indyk,Michael Kapralov,Ekaterina Kochetkova,Boris Prokhorov

TTKV: Temporal-Tiered KV Cache for Long-Context LLM Inference

这篇工作处理的是长上下文推理里一个很实际的系统瓶颈：KV cache 随上下文长度线性增长，最终不只是显存不够，而是 HBM 放不下后必须溢出到 DRAM，导致 host-to-GPU 传输成为 decode 延迟主因。已有方法通常只做一件事：要么压缩 KV，要么做 offloading；但两者单独使用都不够，直接叠加又常常把精度、传输量和延迟的矛盾放大。论文要解决的核心问题，是如何把“KV 压缩”和“分层存储”联合设计，让长上下文下真正减少跨层流量和端到端解码延迟，同时尽量不伤模型质量。

评这是典型“系统想法可能对、论文证据未必够”的 KV 分层工作；先看内存层次设计和质量-带宽权衡曲线，没有硬件实测就别太当真。
Gradwell Dzikanyanga,Weihao Yang,Hao Huang,Donglei Wu,Shihao Wang,Wen Xia,Sanjeeb K C
