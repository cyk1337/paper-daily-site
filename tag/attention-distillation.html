Token-level Response-visual Attention Guidance for Multimodal LLMs Knowledge Distillation

这篇工作讨论的是多模态大模型蒸馏里一个很具体但常被处理得过于粗糙的问题：到底应该蒸馏哪一类跨模态注意力。已有方法通常把 prompt-to-vision attention 当成主要监督信号，但作者通过系统分析发现，真正和下游性能强相关的不是“模型在读指令时怎么看图”，而是“模型在生成每个 response token 时怎么看图”。换句话说，关键监督信号发生在解码阶段，而不是输入理解阶段。进一步地，不同 response token 对视觉证据的依赖差异很大，统一地对所有 token 施加同一种 attention distillation loss 会把监督做平。

评推翻了MLLM蒸馏用prompt-to-vision注意力的常规做法，注意力信号选择的结论可直接复用到内部多模态蒸馏ablation，重点看§3相关性分析

StreamKL: Fast and Memory-Efficient KL Divergence for Boosting Attention Distillation

这篇论文解决 attention distillation 中 KL 散度计算的长上下文瓶颈。常规做法需要先显式生成 teacher/student 两个 attention 矩阵，再做 KL reduction，额外显存和 IO 都是 O(N_Q N_K)。在 64K、128K 甚至更长上下文下，这一步会先于模型本身成为训练瓶颈；例如 64K×64K、32 个头、BF16 下，仅两个 attention 分布就需要约 512GB 显存。

评做长上下文注意力蒸馏或稀疏LLM训练的团队可参考，算子设计能直接复用，需关注反向重计算的精度与速度 trade-off
