Very long examples triggered degraded long-context behavior with looping, and some samples silently dropped the reasoning trace while still translating the question and final answer. This is not just a preprocessing footnote; it shows that preserving long reasoning traces in multilingual data creation is itself a nontrivial bottleneck.

The second component is a controlled SFT comparison. Using Qwen/Qwen3-8B-Base, they train for each target language two specialists under matched token budgets of about 10B SFT tokens per language. In the native regime, input, CoT, and answer are all in the target language. The key design choice is supervision parity: same base model, same scale, same task mix, only the language of the reasoning trace changes.

The third component is weight-space analysis followed by Layer Swap. The authors compare per-language SFT updates relative to the shared base model and find that update directions align tightly in the middle layers across languages, while divergence is larger near the input and output ends. This differs from generic model merging or parameter averaging. The method relies on a depth-wise functional hypothesis rather than a global interpolation assumption.
