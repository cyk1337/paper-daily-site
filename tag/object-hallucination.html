TruthLens: Object Hallucination Detection via Self-Evaluating Truthfulness Scores in LVLMs

这篇工作解决 LVLM 的物体幻觉检测问题，重点不是再训练一个外部 verifier，而是让模型自己的 LM head 暴露每个物体 token 的真实性信号。核心观察是：真实物体 token 和幻觉物体 token 在隐藏状态里可分，但经过 LM head 映射到词表概率后，这种可分性明显减弱。

评把'LM head丢失可分性'做成可训练探针的思路值得VLM对齐者借鉴；看§3方法和探针可视化即可，数字别太当真。
