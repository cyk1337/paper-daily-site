9:T590,The authors instantiate continuous diffusion language modeling with LangFlow and speculative drafting with DSpark. DSpark’s Markov and recurrent-head variants are adapted into standalone generators: they no longer receive target-model features and are not verified or corrected by a target LM. The task is unconditional single-block OpenWebText generation at block lengths 16, 128, and 1024. Because there is no semantic prompt or prior block, each model must choose content and maintain the dependencies induced by that choice. LangFlow repeatedly refines continuous representations for the whole sequence, allowing positions to exchange information before tokens are finalized. The DSpark-style models compute backbone features once and rely on a lightweight output head: the Markov head conditions only on the previous sampled token, while the recurrent head carries a hidden state over the generated history. The analysis identifies a concrete limitation of the Markov interface: information about an earlier choice may no longer be recoverable from the immediately preceding token, restricting the class of distributions the head can represent. Recurrent memory removes that particular access bottleneck, although learning to use the memory remains empirical.
