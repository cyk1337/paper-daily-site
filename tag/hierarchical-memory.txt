Instead of training the model to emit EOS or silence decisions frame by frame, SVeD uses single-pass perplexity verification to determine whether the current moment warrants a response. The conceptual move is important: silence becomes a derived state rather than a supervised prediction target. This avoids the optimization pathologies of EOS-heavy training while keeping the model focused on meaningful video-language generation.

The second component is a hierarchical memory mechanism for long-horizon streams. The paper criticizes pure sliding-window approaches on three grounds: context saturation is inevitable, FIFO eviction destroys distant but important history, and evicted information becomes unrecoverable. LiveStarPro therefore introduces layered memory with explicit retrieval, separating recent context from longer-term stored information so that the system can recall events far outside the active window. The excerpt does not expose the full memory schema, but the intended design is clear: not all frames should remain in the prompt; some should be compressed, indexed, and retrievable.
