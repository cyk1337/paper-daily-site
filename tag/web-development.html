WebGrader: Training LLMs for Web Development with Self-Evolving Programmatic Grader

这篇论文解决的是 web 开发 RL 的 reward 构造问题。自然语言网站需求通常没有配套的浏览器交互脚本和状态断言，人工写测试成本高，VLM/GUI grader 又可能在没有观察到关键状态前给出判断。WebGrader 试图把开放式网站需求自动转成可执行、可复放、带证据的浏览器测试，用作 RL reward。

评读 verifier skill 自演化和错误奖励分析；若 reward hacking 控得住，可借鉴到代码 RLVR。
Boshui Chen,Huiping Liu,Shaolei Zhang
