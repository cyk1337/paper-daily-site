18:T592,Cola2 uses a two-level hierarchy. The upper level dynamically segments text into semantic spans and compresses each span into continuous latents. The lower level uses a block-causal masked diffusion decoder to realize text. There are four key mechanisms. First, semantic segmentation is dynamic rather than fixed-size chunking, so the latent sequence can be shortened while better tracking semantic boundaries. Second, the compression rate is controlled by an auxiliary-loss-free negative-feedback mechanism, reducing dependence on manually tuned loss weights. Third, representation learning combines reconstruction and generation supervision: reconstruction encourages recoverable span-level information, while generation supervision makes the latents predictive beyond local copying. Fourth, representation learning is decoupled from prior fitting. The token-prediction loss is backpropagated through the latents into the encoder, allowing the encoder and decoder to co-adapt. The Diffusion Transformer prior learns the current latent distribution with Flow Matching, but its gradients do not update the encoder. At inference time, generated text is re-encoded block by block under a fixed span layout, keeping latent history aligned with the actual text context. Classifier-free guidance controls the strength of latent conditioning, giving a runtime knob between semantic adherence and autonomous context-based generation.19:T414,The paper reports two main experimental tracks. The first is a controlled five-task scaling study up to roughly 210B tokens, used to test the scaling behavior of the core design. The results are described as competitive and not saturated, suggesting that the hierarchical latent bottleneck does not immediately limit performance at this scale. The second is a separate pretraining run on 346.03B source tokens. It reaches a 60.10 average over eight tasks and outperforms Llama-3-8B on HellaSwag and StoryCloze while using over 43 times fewer reported tokens. This comparison should be read carefully because data mixture, training recipe, and evaluation setup matter, but it indicates that the hierarchical framework can preserve strong decoder capability on commonsense completion and narrative coherence tasks. The boundary-aware causal mask allows each byte in the current segment to attend to previous segments, while preventing attention to other bytes inside the same predicted segment.
