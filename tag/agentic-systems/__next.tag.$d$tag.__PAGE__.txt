9:T5f1,The most interesting part is the three-stage analysis pipeline. Stage I identifies 496 LLM call sites across 40 open-source agentic systems, decomposes each reply into typed outputs, and traces where those outputs flow. The point is not just to inspect prompts, but to see whether outputs reach control flow, tool arguments, code execution, permission checks, or other high-impact sinks. Stage II reconstructs two contracts for each call site. The expected contract is inferred by an agent that never sees the code and only reasons from the functional role of the call and its surrounding context. The implemented contract is extracted by another agent that sees the code but never sees the expected contract. This separation is the key methodological move: missing checks leave no trace in code, so adequacy cannot be measured by code reading alone. A code-independent reference is needed. Stage III then validates the identified gaps dynamically: whether they lie on a threat chain, whether they can be triggered at runtime, and whether adding the missing constraint as code-level enforcement blocks the exploit. The workflow is multi-agent but not fully automatic in a loose sense; three reviewers audited every step, producing 17,428 judgments with Gwet’s AC1 between 0.91 and 0.99. The paper also distills ten recurring gap patterns that explain 99% of the observed deficiencies. Methodologically, the contribution is a practical framework for specification-independent auditing of LLM call sites, not a new model.a:T565,The empirical scope is strong for this kind of systems study: 40 popular open-source agentic systems, 13.4M lines of code, four programming languages, six task domains, 496 call sites, 917 typed outputs, 5,017 implemented constraints, and 2,699 expected constraints. The headline numbers are telling. First, 48% of LLM outputs flow into control flow or execution, so a large fraction of outputs are behavior-changing rather than merely user-facing text. Second, 71% of outputs are consumed only by programs or other models, which means humans often do not provide a final safety check. On enforcement, programs implement 78% of their constraints in code, but 67% of prompt-phase constraints are merely requested from the model rather than enforced. On adequacy, 63% of expected constraints are unmet. Even though 82% of call sites perform some checks before and after the call, only 5.3% satisfy the full contract. That is the paper’s sharpest result: having checks is very different from having sufficient checks. The runtime validation closes the loop. Among 114 gaps that lie on a threat chain, the authors identify 60 exploit mechanisms, 38 of which can be triggered in practice. When the missing expected constraint is enforced in code, all 38 exploits are blocked. The task is binary intervention timing: given a prefix of a multi-party conversation, decide whether an assistant should speak now or remain silent. The dataset contains about 16,000 synthetic conversations expanded into roughly 173,000 token-level decision points, with only about 13% positive intervention labels, so the class imbalance is severe. The paper compares several training routes. One is direct decision-token SFT, which tends to produce a stronger classifier but suppresses reasoning. Another is a masked objective that preserves the model’s native reasoning, but only on cases the model already solves correctly; this means it receives little useful signal on failure cases and therefore struggles to improve beyond the base reasoning policy. A third route is think-mode RL, optimizing either accuracy or a behavioral faithfulness reward. The authors point out a key limitation of group-relative RL objectives: when all sampled rollouts agree, there is no learning signal, even if they all agree on the wrong answer. That leaves many confidently wrong prompts untouched. For auditing, the paper combines activation probes with behavioral interventions. Probes test when the decision becomes decodable in the hidden states, while interventions remove or replace parts of the generated reasoning to see whether the final action changes, which is a more causal test of whether reasoning matters.
