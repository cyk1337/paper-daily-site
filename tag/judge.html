AutoVerifier: Residual-Guided Non-Parametric Optimization for Reference-Based Answer Verification

这篇论文处理的是 reference-based answer verification 里的一个老问题：候选答案和参考答案是否等价，往往不只是字符串匹配或符号化简的问题，还隐含了题目语境、评分标准、数值容差、单位表达、近似形式是否可接受等“判题偏置”。现有 rule-based verifier 把逻辑写死，覆盖有限；model-based verifier 覆盖更广，但判定标准埋在模型行为里，不透明、不可编辑，也难以稳定复用。论文把这些隐含标准明确称为 verifier inductive biases，并试图从 verifier 的残差错误中自动归纳出来，再以可审计、可回放验证的形式沉淀为规则或 prompt 更新。

评如果你在做 RLVR 或 judge-based eval，这篇值得看；不是因为方法多新，而是它把 verifier bias 从黑盒误差变成可审计对象，先读 rule card 和 replay validation。

Beyond Compilation: Evaluating Faithful Natural-Language-to-Lean Statement Formalization

自然语言到 Lean 的“陈述形式化”任务里，Lean 编译通过只能说明类型/语法正确，不能保证语义忠实。论文要解决的是：如何在没有形式等价证明的前提下，规模化评估“编译通过但语义跑偏”的失败，并把失败归因到常见 pipeline 组件（起草模型、Mathlib/上下文检索、elaboration 反馈与修复）上。

评这篇不是在提更强模型，而是在拆穿一个坏指标。做 formalization、tool use 或 judge 设计的人都该看那 29-point gap 和人工校准细节。
