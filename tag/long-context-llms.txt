18:T7e1,方法从注意力输出扰动的精确表达式出发。对给定 query q，完整 cache 下的注意力输出是 a=Σ_i p_i v_i。若删去索引集合 J，对应输出变成 a_-J，扰动是 Δ(J)=a_-J-a。作者先写出这个扰动与被删 token 的总注意力质量 P_J 以及 value residual 的关系。单 token 情况下有一个很直观的式子：Δ({j}) = p_j/(1-p_j) · (a - v_j)。这说明删一个 token 的影响不只取决于它的 attention weight p_j，也取决于它的 value 向量和当前输出 a 的偏差。如果 v_j 很接近 a，即便 attention 不低，删掉它也未必伤害大；反过来，一个 attention 中等但方向独特的 value 可能更关键。

难点在于多 token 联合删除时，最优集合选择是组合问题。DropKV 的核心是 decoupling：把联合扰动最小化近似成独立的 per-token 评分，再按分数保留或删除。论文里称之为 Decoupled Residual-Output Perturbation。直观上，它用单 token 扰动代理多 token 选择，把原本互相耦合的决策拆开，从而把复杂度降到线性级别。作者进一步给出 near-optimality 保证：在 cone condition 下，这个 decoupled proxy 与原 NP-hard 最优解只差一个常数因子。这里的 cone condition 可以理解为被选 value residual 在几何上不会严重相互抵消，方向大致处于同一锥体内。这个条件不是纯理论摆设，作者在 Llama-3.1-8B、Mistral-7B-512K、Qwen2.5-7B-1M 上做了经验验证。

工程实现上，DropKV 的另一个重点是 kernelization。很多 query-aware 或 output-aware 方法理论上合理，但需要显式构造大 attention matrix，prefill 阶段内存开销很大。作者用 fused Triton kernels 在线计算 eviction scores，避免 materialize attention matrix，把 128K 长度下 scoring kernel 的 scratch memory 从约 9GB 压到约 17MB。这个量级差异很关键，因为它决定方法能否在真实长上下文服务里启用，而不是只在离线实验里成立。19:T87b,The method starts from the exact perturbation of the attention output. For a query q, the full-cache attention output is a = Σ_i p_i v_i. If a set J of tokens is evicted, the new output is a_-J and the shift is Δ(J) = a_-J - a. The paper derives how this perturbation depends on the total removed attention mass P_J and on value residuals relative to the original output. The single-token case is especially revealing: Δ({j}) = p_j / (1 - p_j) · (a - v_j). This immediately shows why attention-only scoring is incomplete. A token can have nontrivial attention but still be safe to remove if its value is close to the current output; conversely, a token with moderate attention can be important if its value points in a distinctive direction.

The hard part is multi-token selection, which is combinatorial. DropKV’s main idea is decoupling: replace the joint optimization over eviction sets with independent per-token perturbation scores. The paper calls this Decoupled Residual-Output Perturbation. Intuitively, it uses single-token perturbation as a proxy for the multi-token objective, breaking the coupling between decisions and reducing the complexity to linear time. The authors then prove a near-optimality result: under a cone condition, the decoupled proxy matches the NP-hard optimum up to a constant multiplicative factor. The cone condition roughly says that the relevant residual vectors do not cancel each other arbitrarily and lie within a bounded geometric cone. Importantly, the paper does not leave this as a purely formal assumption; it empirically checks the condition on Llama-3.1-8B, Mistral-7B-512K, and Qwen2.5-7B-1M.

The implementation side is equally important. Many query-aware or output-aware methods require materializing large attention matrices, which makes prefill expensive. DropKV uses fused Triton kernels to compute eviction scores on the fly, avoiding attention-matrix materialization. At sequence length 128K, this reduces scoring-kernel scratch memory from about 9 GB to about 17 MB. That difference is large enough to determine whether a method is usable in real long-context serving rather than only in offline experiments.1a:T53c,The experiments cover three long-context models: Llama-3.1-8B, Mistral-7B-512K, and Qwen2.5-7B-1M. The main benchmarks are RULER and LongBench, with cache budgets of 5% and 10%, which are fairly aggressive compression settings. The headline result is that DropKV achieves the best accuracy among both query-aware and output-aware eviction baselines while also delivering the lowest latency. More notably, in matched-batch prefill it is reported to be faster than the dynamic-cache baseline, which suggests the method is not merely trading quality for speed; the kernel design is removing a real prefill bottleneck.

The most striking engineering number is the memory reduction: at n = 128K, scratch memory for score computation drops from roughly 9 GB to roughly 17 MB. The paper also empirically validates the cone condition to support the relevance of its approximation guarantee on real models.

When reading the experiments closely, three comparisons matter most. First, compare against attention-only methods to see where value-aware scoring helps most.
