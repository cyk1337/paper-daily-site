18:T99c,系统由两部分组成：一个从零预训练的 5B single-stream DiT 生成器，以及一个 intention-aware 的 prompt enhancement 模块。生成器部分的关键设计是把自然语言描述和显式布局规范放进同一条文本条件通路，而不是分成独立的 layout encoder 和 text encoder。这样做的好处是接口统一，模型既能吃普通 prompt，也能吃结构化布局文本；代价是训练时必须让模型学会把不同粒度、不同结构的条件都映射到同一个条件空间。作者为此设计了三类 recipe：

第一，broad data retention。报告强调不是过度清洗到只剩高美学图像，而是保留更广泛的数据分布，尤其是包含文本、版式、界面、海报、信息卡片等复杂图形样本。对于信息密集型生成，过强的审美筛选会损失真正需要的训练信号。

第二，multi-granularity and structure-aware textual supervision。模型不仅看普通 caption，还看更细粒度、更结构化的文本监督，包括长文本内容、局部元素描述、空间关系、布局约束等。这里的核心不是简单增加 token 数，而是让监督信号覆盖“画什么”和“放哪里”两类信息。论文特别强调 unified text-conditioning pathway，因此结构化布局最终也是以文本形式表达给 DiT，而不是额外的几何控制分支。

第三，progressive-resolution training。为了兼顾全局布局和局部文字可读性，训练采用渐进式分辨率策略。低分辨率阶段先学整体构图和条件对齐，高分辨率阶段再强化文字边缘、细节和局部排版。对于长文本渲染，这比一开始就全分辨率训练更稳，也更省资源。

系统前端的 PE 模块不是简单 prompt rewrite。它会根据任务类型路由到不同的 guidance 流程，必要时检索知识和视觉参考，再生成详细的内容与布局规范。关键点在于它输出的布局描述与 DiT 训练时使用的条件接口兼容，因此不是“用自然语言尽量说清楚”，而是“产出模型真正学过的可执行规范”。这也是它和通用 generator-agnostic prompt agent 的主要区别。

如果从方法定位看，这篇工作更像“预训练 backbone + specification layer + benchmark”的系统工程。真正值得看的是作者如何把 layout control 作为预训练条件建模问题来处理，而不是只靠后处理或外接控制网络。19:T7f6,MOSS-Image consists of a pretrained 5B single-stream diffusion transformer and an intention-aware prompt enhancement module. The generator is designed around a unified text-conditioning pathway: ordinary natural-language prompts and explicit layout specifications are both fed through the same textual interface, instead of using separate text and layout encoders. This keeps the interface simple and flexible, but it also requires the model to learn from supervision at different levels of structure and granularity.

The pretraining recipe has three notable components. First, broad data retention. The report argues against overly aggressive aesthetic filtering, because information-dense graphics, UI-like images, posters, and text-heavy visuals contain the exact signals needed for long-text rendering and layout following. Second, multi-granularity and structure-aware textual supervision. The model is trained not only on generic captions but also on finer and more structured textual signals that describe content, local elements, spatial relations, and layout constraints. The point is not merely to add more text tokens, but to cover both semantic content and placement instructions. Third, progressive-resolution training. Lower resolutions help the model learn global composition and alignment first, while later higher-resolution stages improve text legibility and local layout fidelity. For long-text rendering, this curriculum is more stable and more compute-efficient than training at full resolution from the start.

The prompt enhancement module is more than prompt rewriting. It routes requests to task-specific guidance, retrieves knowledge and visual references when needed, and outputs detailed content and layout specifications that are compatible with the generator’s training interface. That compatibility matters: the enhancer is not just making prompts longer, it is producing conditions in a form the backbone has actually learned to follow. This is the main difference from generator-agnostic prompt agents.1a:T73a,The evaluation is split between backbone rendering ability and end-to-end system performance. For rendering, the authors introduce LongLongTextBench, focused on long-form English and Chinese text generation. On this benchmark, MOSS-Image reaches a Mean-6 score of 96.3, outperforming Qwen Image 2512 at 64.9 by 31.4 points. That result supports the effectiveness of the pretraining recipe, especially the long-text supervision and progressive-resolution schedule.

For end-to-end generation, the paper introduces RealLayoutArena, which evaluates complex graphic generation from short design requests using blind pairwise human comparisons. The judgment combines instruction following, content completeness, text readability, and visual organization. MOSS-Image obtains 1698.70 Elo, ranking second overall behind GPT Image 2 and ahead of Seedream 5.0 Pro.
