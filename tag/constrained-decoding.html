The Parser Already Knows: Lightweight Bias Correction in Constrained Decoding

这篇工作处理的是语法约束解码里的一个老问题：局部 masking 能保证输出合法，但会系统性扭曲原始 LM 的条件分布。原因不在于模型不会生成合法序列，而在于每一步只看“当前 token 是否可接受”，没有把“这个 token 会不会把后续高概率合法续写堵死”计入概率。已有做法要么用在线重采样恢复全局分布，但推理代价高；要么再训练一个可解析的代理模型去近似 LM 的合法序列分布，但建模误差和工程复杂度都不小。作者要解决的是：能不能在不改 base LM、不做在线 resampling 的前提下，用极轻量的方式补偿 masking 带来的分布偏差。

评不是 pretrain 论文，但问题定义很干净：硬约束会改分布。只看方法和消融，想想类似校正能否迁到 tool-use 或 verifier decoding。

Hydra: Efficient, Correct Code Generation via Checkpoint-and-Rollback Support

评方法有新意——异步编译检查+检查点回滚比现有逐token约束解码或事后修复更高效。值得看方法和实验部分了解实际开销对比。
