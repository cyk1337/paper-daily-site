18:T6e6,The core method is residual-guided non-parametric optimization. The system starts from a fixed base verifier and iteratively improves it around observed mistakes. At each round, the current verifier is replayed on a construction pool, and disagreements with labels are collected as residuals. Recurring residual patterns are then abstracted into rule cards. Each card records a missing verifier bias together with support examples, counterexamples, applicability conditions, and abstention conditions. This is a key design choice: instead of directly updating model parameters, the method converts recurring failure modes into explicit knowledge units.

A rule card can follow one of two promotion paths. If the missing bias can be expressed as deterministic comparison logic—such as numerical tolerance handling, unit normalization, scientific notation conversion, or specific symbolic equivalence rules—it goes through code audit and replay validation, and if accepted becomes a code module. A code module is a deterministic verifier unit that returns Correct, Incorrect, or Abstain. If the bias cannot be fully codified and still requires model judgment, it is incorporated into the fallback verifier prompt rather than compiled into code. At inference time, the system first runs the module library; cases that can be decided explicitly are handled there, and only unresolved cases are sent to a fixed model-based fallback verifier.

What distinguishes this from prior work is not simply adding tools, but turning verifier improvement into a closed loop: residual discovery, rule-card drafting, replay validation, and promotion into either executable modules or prompt guidance. It sits between hand-maintained rule libraries and opaque judge-model behavior.19:T545,The paper evaluates on four reference-based verification benchmarks. The headline result is 93.05% macro accuracy, outperforming the reported rule-based, model-based, scientific, and tool-augmented baselines included in the study. The more informative result is the component ablation: compared with a prompt-only setting, adding code modules yields an additional +1.76 macro-accuracy gain. That suggests the benefit is not merely better prompting; explicit comparison logic is covering verifier blind spots that prompting alone does not fix. In addition, direct module decisions reduce fallback model calls by 32.13%, so the system improves both accuracy and inference efficiency.

The experiments are most convincing when read as evidence for two claims. First, recurring residuals do contain reusable verifier biases that can be extracted. Second, splitting those biases into deterministic modules versus prompt-level guidance works better than relying on a single prompt-only or model-only verifier. A careful reader should still pay attention to the relationship between the construction pool and the evaluation benchmarks: if they are too similar, rule extraction becomes easier.
