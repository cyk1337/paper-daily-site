9:T647,Uncheatable Eval treats a language model as an ideal lossless compressor. For a document s, tokenized by the evaluated model's own tokenizer into x1:T, the model assigns conditional probabilities to observed tokens. The ideal arithmetic-coding length is -sum log2 p(x_t | x_<t), which is next-token NLL in bits. The compression rate divides this ideal code length by the original UTF-8 size, 8 times the number of bytes. Lower CR means better prediction. The UTF-8 denominator provides a common text-level scale across different tokenizers, although each score remains a property of the model-tokenizer pair.

The data pipeline is a central part of the benchmark. It periodically collects recently published fiction, source code, scientific papers, news, encyclopedia articles, documentation, and related sources, covering 14 text categories. The curation pipeline applies quality filters, removes near-duplicates with MinHash locality-sensitive hashing, and normalizes Unicode with NFC. The non-English encyclopedia subset is sampled in a language-balanced way. Because tokenizers produce different token counts for the same text, each sample is checked with a diverse set of tokenizers and truncated to fit a shared token budget.

Within each category, CR is aggregated as a byte-weighted ratio of total ideal code length to total original byte size. The Overall score is an unweighted arithmetic mean over category rates. This prevents large categories from dominating the final number, but it also means the Overall score reflects a balanced category mixture rather than a natural web-text distribution.a:T4fa,The paper evaluates 80 models across 14 text categories, including attention-based, hybrid, and recurrent families. A main finding is that compression rate scales systematically with model size and is well fit by a power law with an additive constant. This mirrors the shape of pretraining scaling laws, but on a dynamic held-out compression metric rather than training loss or task accuracy.

A separate analysis on longer scientific documents covers 54 models and studies how CR changes as more preceding context becomes available. The results show different context-use patterns for attention-based, hybrid, and recurrent models. This is a useful long-context diagnostic because it measures prediction improvement within real documents as context accumulates, rather than relying on short prompted tasks.

The paper also compares compression of technical text with zero-shot MMLU accuracy and finds a strong association. This suggests that predictive ability on technical corpora is statistically related to knowledge-heavy task performance.
