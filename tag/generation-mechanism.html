Neither Parallel Nor Sequential: How DiffusionGemma Actually Commits Tokens

这篇论文要回答一个很具体但常被默认跳过的问题：开放的 diffusion language model 在真实推理时，到底按什么顺序“提交”token。论文研究的不是训练算法，而是一个已发布 checkpoint 的解码行为：google/diffusiongemma-26B-A4B-it，一个基于 Gemma 4 的 masked discrete diffusion MoE 模型，25.2B 总参数、3.8B 激活参数、8-of-128 expert routing。作者指出，DLM 常被描述成并行、非自回归解码器，但“架构允许并行”和“模型实际并行提交”不是一回事。真实提交顺序由模型、sampler、停止准则共同决定，需要直接测量。

评直接推翻扩散 LM 并行/块 AR 的二元 prior，所有做非 AR 文本建模范式的人都应立刻复现其 instrumentation 方法。
Ali Asaria,Tony Salomone,Deep Gandhi

Continuous Language Diffusion as a Decoder-Interface Problem

Generative Criticality in Large Language Model Temperature Scaling

这篇工作研究的不是提升模型性能，而是试图回答一个更偏基础分析的问题：当我们调节采样温度时，LLM 生成文本在表示空间里是否会出现类似统计物理相变的结构变化。作者想建立一套可计算的“场论式”描述，把 token embedding 序列看成一维链上的连续自旋变量，然后定义 susceptibility、order parameter 和 intrinsic dimension 这类量，观察它们是否在某个临界温度附近出现突变或峰值。

评用统计物理场论解释 Temperature 带来的生成相变，视角非常新颖，建议关注其定义的序参量和 $T_c$ 临界点现象。
Huajian Ruan,Jinyang Li,Xingyu Guo,Lingxiao Wang
