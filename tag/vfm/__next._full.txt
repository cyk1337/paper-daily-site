18:T52b,DecQ keeps the VFM encoder frozen and introduces a small set of learnable detail-condensing queries as an auxiliary pathway.
- The frozen VFM provides the main semantic latent tokens.
- A handful of learnable queries attend (cross-attention) to intermediate VFM features and pass through condenser modules to compress low-level information into a compact set of “detail tokens”.
- Tokenizer training updates only the decoder and the query/condenser components, using reconstruction-oriented losses (L1, perceptual/LPIPS, adversarial/GAN as in RAE setups). Because the VFM is frozen, the pretrained semantic space is preserved.
- Generation-time integration: the diffusion/flow-matching transformer is trained to jointly denoise/predict both image patch latents and the detail queries. Empirically, modeling the queries as part of the generative state improves generation quality rather than merely improving reconstruction.
- Layer-selection insight: condensing from shallow VFM layers mainly helps reconstruction; condensing from deeper layers helps generation; combining both yields the best balance.
