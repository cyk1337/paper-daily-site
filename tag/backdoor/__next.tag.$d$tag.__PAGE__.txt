9:T74f,The method has two main components. The first is a heuristic poisoning strategy. Instead of teaching the model a fixed trigger-target lookup table, the poisoned data is designed to make the model treat the trigger as a semantic control signal. In effect, the model is encouraged to prioritize information carried by the trigger when the trigger is present, rather than memorizing one malicious caption per trigger. The paper explicitly frames this as exploiting the VLM's native zero-shot generalization: the model is pushed to generalize from seen poisoned patterns to unseen target-caption semantics at inference time.

The second component is trigger steganography, denoted TS(·). Given an arbitrary target caption z, TS maps z into a stealthy visual trigger, either as norm-controlled noise or as a semantically meaningless patch. The key idea is dynamic trigger synthesis: the trigger is generated from the desired target text at inference time, rather than being fixed during poisoning. The excerpt suggests that this mapping is built around the representation of a vanilla trigger in the visual feature space. That is, the attack first identifies a trigger representation that reliably activates the backdoor, then embeds target-text information into that representation while keeping the perturbation visually subtle.

Conceptually, this is the main departure from one-to-one and N-to-N backdoors. In standard settings, the target set is fixed during poisoning. Here, target selection is decoupled from poisoning and moved to inference time. The hard part is making the model generalize to unseen target semantics while keeping the trigger stealthy and preserving benign utility. Poisoned agents emit plausible evidence cues; each cue is insufficient alone, while cues from distinct peers jointly indicate that the hidden activation threshold has been reached. BCBI constructs counterfactual boundary pairs where task, role, round, and surrounding context are matched, but peer evidence moves from just below to just above the threshold.
