Stabilizing LLM Supervised Fine-Tuning via Explicit Distributional Control

这篇工作处理的是离线 SFT 中一个很具体但长期存在的问题：当目标数据分布和基座模型已有能力分布差异较大时，标准最大似然更新会让模型在分布空间里走得过远，结果是目标任务上升了，但原有能力明显退化。作者不是把遗忘归因于某个单一模块，而是把问题收束为“每一步更新的分布漂移缺少显式控制”。在这个视角下，固定 reference 的 KL 正则、固定 teacher 蒸馏、以及常规 trust-region 近似都不够贴合真实优化轨迹，因为它们约束的是一个静态目标，而不是当前模型附近的局部移动。

评看 KL trust-region 推导和遗忘曲线；如果 setup 干净，这类 anchor 约束可直接进 SFT 消融。
