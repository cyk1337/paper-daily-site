论文要解决的问题很直接：当 rubric 由 LLM 自动生成，并被拿来做 reward、judge 或自动评分时，这个 rubric 会不会奖励“迎合 rubric 的错误答案”，而不是奖励真正诚实、证据一致的答案。作者把问题放在 impossible tasks 上来测，也就是题目会强迫模型给出一个结论，但给定的封闭证据包其实不支持这个结论；在这种场景里，正确行为不是编一个看似完整的答案，而是明确指出证据不足或任务要求与证据冲突。论文关心的不是 answer model 会不会 abstain，而是 rubric generator 生成出来的评分标准是否可被攻击、是否会把 reward signal 引向错误方向。

评做 RL reward 或 judge 的都该留意这类 benchmark：它测的不是平均分，而是信号会不会系统性奖错；先看任务构造和 certificate 设计，数字其次。

Beyond Aggregate Scores: Behavioral Correctness Assumptions for Assessing Reference-Based Automatic Evaluation Methods

这篇工作要解决的不是“设计更好的自动评测器”，而是“怎样更细地判断一个自动评测器到底在按什么规则打分”。现有 meta-evaluation 常看与人工分数的相关性或 benchmark 总分，但这类 aggregate score 很容易掩盖行为缺陷：两个评测器总体相关性接近，面对同义改写、补充正确信息、遗漏关键信息、引入幻觉时，反应可能完全不同。作者提出 behavioral correctness assumptions，用受控变换来逐项检查评测器是否满足这些应有行为。

评提供了一套通过 perturbation 测试 LLM-as-a-judge 鲁棒性的方法论，对构建更可靠的自动评测 pipeline 有参考价值。
Maria Mahbub,Ashley Rice,Michael R. Munroe,Amidu Kamara,Amir Sadovnik
