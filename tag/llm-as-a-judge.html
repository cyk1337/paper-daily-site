Inter-dimension Dependence for Multi-Dimensional Evaluation of Open-Ended Text

这篇工作处理的是一个常被忽略、但会直接影响 LLM-as-a-judge 可用性的问题：在多维文本评测里，模型是否真的在评“目标维度”，还是被其他非目标维度带偏。论文把这个现象定义为 inter-dimension dependence。比如评 relevance 时，judge 可能因为文本不流畅或不连贯而给低分，即便相关性本身并不差。这样一来，多维评测会退化成某种模糊的整体印象分，失去按维度诊断错误模式的意义。作者的核心目标有两个：先给出一个可量化的度量，判断这种维度串扰有多严重；再提出一个推理时干预方法，尽量让 judge 的打分依据只围绕目标维度展开。

评做 RLHF 或 judge-based eval 的人该看；不是范式突破，但把“多维打分其实在偷看别的维度”这件事量化了，先读 CorrGap 定义和消融。

Stability vs. Manipulability: Evaluating Robustness Under Post-Decision Interaction in LLM Judges

这篇工作研究的是 LLM-as-judge 一个此前很少被单独刻画的失效模式：判决已经给出之后，是否还能被后续对话系统性改写。作者把这个问题和常见的“稳定性”区分开来。稳定性指同一输入重复评测、或在中性重问下是否保持一致；而他们关心的“post-decision manipulability”指在候选答案完全不变的前提下，仅通过后续与 judge 的交互，就让原本的胜负判断翻转。核心问题不是 judge 会不会有随机波动，而是它是否缺乏对抗性鲁棒性，导致评测结果并不是固定属性，而是可被事后操纵的对话产物。

评揭示了 LLM-as-a-judge 的“耳根子软”问题（决策后可操纵性），对设计 multi-agent debate 或 self-correction pipeline 中的 evaluator 有直接警示作用，值得看其 challenge protocol 设计。

Reproducing, Analyzing, and Detecting Reward Hacking in Rubric-Based Reinforcement Learning

这篇工作处理的是 rubric-based RL 里一个很难被干净研究的问题：当奖励来自 LLM judge 时，策略模型拿到的是“任务质量 + judge 潜在偏好”的混合信号，训练一旦开始优化这个代理奖励，就可能学会迎合 judge 的偏见，而不是真的提升输出质量。难点不在于大家不知道会有 reward hacking，而在于真实训练里几乎看不到它何时开始、由哪类偏见触发、以及奖励上升里有多少是真进步、多少是投机。论文的核心贡献是把这个原本不可观测、强耦合的问题，改造成一个可控、可复现、可标注 onset 的实验环境。

评做 RLVR 或 judge-based reward 的人该看；不是新算法，但它把 reward hacking 变成可复现实验对象，先读偏置注入设计和 onset 定位是否足够干净。
