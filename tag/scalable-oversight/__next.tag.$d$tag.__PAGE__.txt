b:T5e1,The work has two main components. First, the evaluation protocol. Preference datasets are grouped by broad categories such as helpfulness or harmlessness, with multiple datasets per category differing in prompts, response styles, annotation procedures, and dataset artifacts. For a source dataset, the weak supervisor is trained on gold labels, then used to produce soft preference labels for a disjoint student split. The strong student is trained only on these weak labels. A same-capacity strong ceiling model trained on gold labels serves as the upper bound. Evaluation is done both on the source test split and on other datasets from the same category, zero-shot. This separates source-domain fitting from true preference transfer.

Second, Representation Anchoring. The paper argues that weak-supervised fine-tuning can induce a representational failure mode: instead of preserving the strong model’s broadly transferable preference features, training drifts toward source-domain features favored by the weak supervisor. Anchor adds a regularizer that keeps the student’s internal representations closer to those of the pretrained strong model while still allowing adaptation to weak labels. The key point is where the regularization acts: not on output logits alone and not merely on parameter norms, but on representation space.
