The Explainability Illusion: Must ViTs Exhibit Patch-Decoding Interpretability?

这篇工作问的是一个被默认接受、但其实很少被严格检验的前提：ViT 中间层 patch token 的零样本解码，是否天然对应可解释的局部语义。更具体地说，很多工作会把某层 patch token 直接送入分类头或对比投影头，得到每个 patch 对目标类别的分数图，并把它当成模型在该位置“看到了什么”的证据。论文用大量真实模型、可控合成实验和一个可证明的 toy 构造说明，这个前提并不稳。相同的 Transformer 架构，在不同任务、损失、数据分布和训练随机性下，可以收敛到 aligned explainability、inverted explainability，甚至完全不可解释的内部表示。因此，token-decoding explainability 不是 Transformer 的结构性性质，而是训练条件诱导出的脆弱副产物。

评对 ViT 可解释性的祛魅，揭示了 token decoding 并非 Transformer 的固有属性，对于理解模型内部机制和避免过度解释有警示作用。
Ronen Schaffer,Hila Manor,Tomer Michaeli
