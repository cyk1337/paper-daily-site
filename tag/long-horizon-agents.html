The Compaction Cliff in Long-Running AI Agent Memory

SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents

这篇工作处理的是长时程 agent 中一个被低估但很实际的问题：当技能库很大、技能只能按需读取时，policy 需要在轨迹中途先从候选技能名和简介里选一个再继续执行。现有做法通常把“选对技能”和“后续执行好任务”都放进同一个 outcome-only RL 信号里训练。论文指出这在结构上就不成立，尤其在长轨迹里更明显。原因不是 reward 稀疏这么简单，而是 skill selection 这一步只对应极少数 token，却继承整条轨迹的 broadcast advantage，导致两类问题同时出现：一是 loss 权重占比随轨迹变长迅速稀释；二是 credit sign 经常错，因为技能选对了，但后续执行失败时，选择技能的 token 反而会被负向更新。作者把这个现象定义为 selector credit starvation，并把它作为 in-policy skill selection 学不会的主要原因。
