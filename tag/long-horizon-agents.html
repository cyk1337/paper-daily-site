The Compaction Cliff in Long-Running AI Agent Memory

这篇工作处理的是长会话 agent 在有限上下文预算下的记忆保真问题，尤其是“安全规则”和“普通经历日志”被同一种压缩策略对待时，会出现规则措辞被改写、限定条件丢失、最终失去可执行性的结构性失败。作者把这个现象定义为 Compaction Cliff：在多轮 compaction 后，真正需要逐字保真的约束类知识，比可容忍摘要化的背景信息衰减得更快。论文进一步指出，这不是单一 prompt 写得不够好，而是现有 production agent 常见的 type-blind memory management 在 compaction、decomposition、retrieval 三个操作上都没有区分知识类型，因此无法同时满足不同知识的保真要求。

评只看实验设置和安全规则保留曲线；它把“摘要压缩够用”这个 Agent prior 打得很具体。

SkillGate: Training In-Policy Skill Selection in Long-Horizon Agents

这篇工作处理的是长时程 agent 中一个被低估但很实际的问题：当技能库很大、技能只能按需读取时，policy 需要在轨迹中途先从候选技能名和简介里选一个再继续执行。现有做法通常把“选对技能”和“后续执行好任务”都放进同一个 outcome-only RL 信号里训练。论文指出这在结构上就不成立，尤其在长轨迹里更明显。原因不是 reward 稀疏这么简单，而是 skill selection 这一步只对应极少数 token，却继承整条轨迹的 broadcast advantage，导致两类问题同时出现：一是 loss 权重占比随轨迹变长迅速稀释；二是 credit sign 经常错，因为技能选对了，但后续执行失败时，选择技能的 token 反而会被负向更新。作者把这个现象定义为 selector credit starvation，并把它作为 in-policy skill selection 学不会的主要原因。

评值得看问题定义和 credit 审计；若结果站得住，会改变长程 Agent 里“只靠 outcome RL 训工具选择”的默认做法。

MemPrism: Task-Conditioned Relational Memory Views for Long-Horizon Agents

这篇论文讨论的是长程 agent memory 里的一个更细的失败类型：信息已经被存下来了，也被取回来了，但呈现方式不适合当前决策，因此 agent 仍然用不好。作者把这个问题称为 representation mismatch，并把它和更常见的 storage failure、retrieval failure 区分开。核心问题不是“记忆有没有”，而是“同一段历史在当前子任务下应该以什么关系结构被组织出来”。例如，检测循环需要把重复动作和结果对齐，状态跟踪需要按实体聚合同一对象的变化，失败分析需要把动作和环境反馈连起来，依赖分析则需要把相隔很远的事件串起来。固定的时间线、摘要或向量检索结果，往往只能支持其中一类关系，不能覆盖所有决策需求。

评读方法图和 memory ablation 即可；它把“存得多”改成“按任务重排”，比多数向量记忆论文更干净。

Joint Agent Memory and Exploration Learning via Novelty Signals

在开放式 GUI 探索中，LLM agent 需要“记住自己试过什么”才能避免重复并持续探索；但保留完整轨迹代价高，而潜变量(latent)记忆又缺少逐步监督信号。论文要解决的是：如何用无需人工标注的 novelty 信号，把“记忆学习”和“探索策略学习”绑在一起训练，让 latent memory 变得可用。

评建议扫方法和实验信号定义；把 coverage 当记忆监督很干净，但离通用 Agent 还差跨域 novelty。
