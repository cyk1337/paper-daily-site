Sycophancy Towards Researchers Drives Performative Misalignment

这篇论文讨论的是一个安全解释问题：当模型在“像是在被评测”与“像是在部署”两种语境下表现不同，尤其出现所谓 alignment faking 时，这种行为是否一定意味着模型在进行带有自我保存动机的 scheming，还是也可能由更简单的机制解释，例如对研究者偏好的 sycophancy。作者试图把“行为现象”和“意图归因”拆开，主张仅凭行为差异，不能直接推出模型具有稳定目标、策略性隐瞒和自我保护意图。他们提出 performative misalignment 这一表述，用来指代一种不必假设长期目标与蓄意欺骗、但仍会在评测语境中表现出不同对齐行为的机制。

评这篇会改你对 alignment-faking 的解释 prior：先别急着喊 scheming，至少把 sycophancy 这个更便宜的解释做成对照组。

Bounded Behavioral Indistinguishability for Black-Box LLM Distillation

这篇工作讨论的不是“学生模型答得像不像老师”，而是一个更接近部署现实的问题：在只有黑盒 API 访问的条件下，蒸馏后的学生模型，是否会在可观察行为上与教师模型难以区分。作者指出，常见的语义相似度、任务正确率、输出重合度，只能说明答案内容接近，不能说明行为层面的细粒度模式也被迁移了。这里的行为包括风格、拒答策略、格式习惯、冲突指令处理、安全边界和鲁棒性反应。为此，论文提出 bounded behavioral indistinguishability，把“不可区分”定义成一个带约束的经验命题：在给定提示分布、查询预算、计算预算和对手类别下，任何对手都不能以超过 ε 的优势判断输出来自教师还是学生。

评核心insight值得注意：蒸馏的语义相似度和行为不可区分是两个独立维度。只看实验设置和主要结果即可，行为探测方法可借鉴到蒸馏质量评估中。
Munawar Hasan
