18:T697,The paper is methodologically careful rather than algorithmically flashy. The dataset contains 225 temporal facts across six domains: FDA, finance, sports, people, SEC, and chemical. A common cutoff of 2026-02-16 is used, and changes announced or effective before that threshold are excluded, making the benchmark genuinely post-cutoff. Each item has both an outdated value and a current value, enabling both open QA and claim-check evaluation.

The evaluation has two layers. One is a deployed setting with the proprietary model Luna under its native web search. The other is controlled retrieval: Luna plus six open-weight configurations all receive the same frozen top-10 Brave search menu, with a common search/open/find tool interface. The ground-truth page is guaranteed reachable by preserving its organic rank when present or inserting it at a seeded position otherwise. This design isolates model behavior from retrieval variance.

A key contribution is the behavioral decomposition of reading depth from tool traces: snippet-only episodes, opened-but-not-cited episodes, and integrated episodes where the model cites a page it actually opened. This makes it possible to localize failures to shallow evidence use rather than retrieval miss. The paper also evaluates citation faithfulness, counting cases where the cited page contradicts the answer. Finally, it runs two controlled analyses: directly supplying the source page to test whether failures come from navigation, and layer-wise readouts to test whether retrieved values enter the model’s internal state. The mechanistic result is subtle: the retrieved value is promoted, but the stale value is not suppressed enough.19:T617,The main empirical picture is clear. Search helps all models: under frozen retrieval, enabling search improves claim-check accuracy by 27 to 42 points, and open-question accuracy reaches 85.8% to 95.4%. So the retrieval menu is useful; the issue is not simple retrieval failure. What varies sharply is reading behavior. With the same search results, models answer 2.6% to 76.0% of episodes without opening any page. In its native deployed search, Luna stays snippet-only in 53.6% of episodes.

Those shallow episodes are much less reliable. Pooled across seven configurations, snippet-only episodes produce stale answers 6.4% of the time, versus 1.3% when the model cites a page it opened. Unfaithful citations are also concentrated in snippet-only behavior, again at 6.4%. This is one of the most useful findings in the paper: many failures come from acting on snippets as if they were sufficient evidence.

The controlled interventions sharpen the diagnosis. Providing the source page directly removes some errors, showing that part of the problem is tool use and page selection. But some failures remain. In those residual cases, layer-wise analysis shows that the retrieved value does influence internal predictions, so the model is not simply ignoring evidence. Instead, stale parametric knowledge remains too strong.
