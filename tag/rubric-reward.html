QUBRIC: Co-Designing Queries and Rubrics for RL Beyond Verifiable Rewards

LongTraceRL: Learning Long-Context Reasoning from Search Agent Trajectories with Rubric Rewards

这篇工作要解决的是：如何把长上下文推理的 RL 训练信号做得既难、又密。现有 long-context RL 数据通常有两个明显短板。第一，干扰文档不够像真问题，很多是随机采样的无关文本，模型只要做粗粒度过滤就能过关，学不到真正的证据定位与跨文档整合。第二，奖励几乎只看最终答案对不对，导致模型即便中间检索链条错了、靠猜测或捷径碰巧答对，也会拿到正反馈。论文针对这两个问题同时下手：一边构造更高混淆度的训练上下文，一边把奖励从结果级推进到中间实体级，让 RL 真正约束长链推理过程。

评读数据构造和 reward 设计；高混淆 distractor 的来源更干净，适合作为长上下文 RL 内部数据配方参考。

Not Every Rubric Teaches Equally: Policy-Aware Rubric Rewards for RLVR

基于评分规则（rubric）的强化学习后训练中，传统静态加权求和的奖励聚合方式混淆了人类设定的准则重要性与该准则当前作为优化信号的有效性，导致大量训练压力被分配到已饱和或完全不可达的准则上，无法为当前策略提供有效梯度。

评这篇不是算法大改，但它把 rubric reward 里最常见的错觉讲对了：人类权重不等于训练信号强度，建议先看方法定义和 ablation。

Visual Preference Optimization with Rubric Rewards

论文要解决的是：在VLM对齐中，DPO/在线DPO的效果高度依赖偏好对数据质量，但现有偏好对构造多依赖“结果式/粗粒度”信号（如最终对错、幻觉计数）或离策略扰动（改图/注入幻觉），导致(1)与目标策略分布不匹配、(2)无法稳定区分细粒度视觉推理差异（grounding、覆盖度、推理链条错误）。作者希望用一种可复用、低成本、无需训练新RM的方式，让开源judge在多模态偏好标注上产生更细的可解释监督，从而提升on-policy偏好学习的有效性。

评只看 rubric 生成与在线数据流水线：核心增量在把偏好标注的信噪比工程化抬高，结论更像数据科学经验而非新优化理论。
