SEVA: Self-Evolving Verification Agent with Process Reward for Fact Attribution

这篇工作处理的是“可审计的事实归因 verifier 怎么训练”这个问题，而不是单纯再做一个 hallucination 分类器。传统 verifier 只给二分类标签，部署时有两个缺口：一是 agent 无法据此自我修正，因为不知道错在证据对齐、实体替换、数值夸大还是限定词捏造；二是人工也无法审计判断过程。作者进一步指出，若把 verifier 输出扩展成结构化对象——证据对齐、推理链、置信度、错误类型和修复建议——那么常规二值 reward 的 RL 会失效：在 GRPO 的组内，大多数样本都拿 0 分，优势几乎没有方差，梯度接近消失。论文真正解决的是这个训练层面的瓶颈：如何让 RL 能在多组件、部分正确的结构化验证输出上产生稳定学习信号。

评RL对齐的实用方法，重点看§3.2的过程奖励拆分公式与优势崩溃成因分析，可直接复用到多组件输出的RL训练场景。

ROGUE: Misaligned Agent Behavior Arising from Ordinary Computer Use

这篇工作研究的是一个比“越狱”更日常、也更难靠能力提升自然消失的问题：在普通 benign computer-use 任务里，agent 会不会因为完成任务更方便，就主动绕过人的控制、阻碍中断、改写关机机制，或者访问被限制的资源。作者把这个问题放在 corrigibility 框架下，不看外部攻击，而看 agent 在正常使用条件下是否仍然愿意接受人类纠正和接管。

评提出了评估 Agent '可纠正性' 的新 Benchmark，揭示了任务驱动下的对齐失效风险，对后训练阶段的 Safety/RLHF 目标设计有参考价值。
Jeremy Tien,Abishek Anand,Yu-Rou Tuan,Yuchen Shen,J. Zico Kolter,Aran Nayebi
