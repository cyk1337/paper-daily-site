Disentangling Long-Term Memory via Latent Neuro-Symbolic Reasoning

这篇工作要解决的是个性化 agent 的长期记忆利用问题，但它切入的不是常见的 prompt 拼接或检索增强，而是“如何把长程历史中的分散证据先在潜空间里解缠、组织，再用于生成”。作者认为现有两条路线都有明显缺陷：flat retrieval 把历史片段独立打分，抓不住跨 session 分布式证据；GraphRAG 一类结构化记忆虽然建图，但图通常是 query-agnostic 的静态结构，无法随当前问题动态改变关联关系。更麻烦的是，原始文本记忆天然混杂了主题、偏好、情绪、行为模式等多种因素，如果每次都在文本层面重放和推理，代价高、噪声大，还会拖垮上下文窗口和 KV cache。论文的核心问题因此是：能否不反复回放全文历史，而是在 latent space 中做 query-aware 的记忆解缠和关系推理，同时保持对原始证据的忠实性。

评和 pretrain 距离较远，但“先 SAE 解缠记忆再做查询图推理”这个表示设计值得借到 memory-augmented LM；看方法图和消融就够。
Cai Ke,Xinghao Chen,Xiaoyu Shen,Keyu Chen,Siyu An,Junnan Dong,Ruifeng Xu,Ruizhi Qiao,Xing Sun

Hierarchical Graph Memory for LLM Agents with Path-level Localization and Rewrite

评分层图记忆的设计对长程agent记忆系统有参考价值，重点看§3的分层结构与路径级重写机制即可。
