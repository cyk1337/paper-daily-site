Learning Agent Execution for KV-Cache Management in Agentic Serving

多 agent 服务中存在大量可复用的固定上下文，但现有 KV-cache 管理主要依赖 prefix caching 和 recency 策略，无法根据 agent 执行语义保留真正会再次命中的 cache，导致重复预填充计算。

评这是 serving 论文，不改 pretrain prior；但把 cache policy 从 recency 改成 execution semantics 很干净，做 agentic inference 的人应先看方法和系统指标表。

Leyline: KV Cache Directives for Agentic Inference

Agentic LLM 在多轮交互中会主动修改历史（如重试失败的工具调用、删除过期输出），这打破了传统 KV Cache 仅支持“追加（append-only）”的假设，导致每次修改都需要重新计算未改变的前缀（prefill），严重影响推理吞吐量。

评只看问题设定和 directive API；若实验弱也有用，因为它抓住了 agent serving 不是 append-only 的真问题。
