The framework has two stages.

Stage one is hindsight-skill supervised fine-tuning. The model is trained to analyze completed trajectories and produce natural-language skills that summarize reusable workflows, decisive observations, and failure-avoidance rules. These skills are not meant as user-facing summaries. They are privileged training-time signals that compress trajectory-level hindsight into a compact, conditionable representation.

Stage two is the self-evolving OPD loop. The current policy collects trajectories on-policy in the environment. The same model then acts as an analyzer and generates hindsight skills for those completed trajectories. Next, the sampled action sequence is kept fixed. The model re-scores those already-taken actions under two contexts: the original context and a skill-augmented context. The probability shift between the two is treated as a dense token-level distillation signal that indicates how hindsight would have changed the policy’s preference over the observed decisions. Training then jointly optimizes the standard outcome-based RL objective and this OPD objective.

Three design choices are central. First, the method is on-policy because useful hindsight depends on the states and failure modes induced by the current policy; a static offline skill bank would quickly become mismatched. Second, the actor and analyzer are the same evolving model, so decision-making ability and trajectory-analysis ability improve together instead of relying on a frozen teacher. Third, skills are used only during training, not at inference time, because the goal is to internalize hindsight into the policy parameters rather than depend on external memory or extra prompts.

Relative to nearby work, SEED is related to verbal reflection, episodic memory, and self-distillation, but it differs in a precise way. It does not keep reflection text as persistent inference-time context. It uses hindsight text only as privileged context during training to produce dense supervision. It also differs from pure outcome-based RL by providing decision-level credit signals, and from standard teacher-student distillation by using the same policy under a more informed hindsight-conditioned view rather than an external stronger teacher.f:T773,The paper evaluates SEED on long-horizon agent settings including embodied interaction, web navigation, and search-based tasks. Budget allocation is defined over these anchors (roots and internal prefixes).

The guiding principle is mixed-reward contrast construction: allocate more budget to anchors whose descendant continuations are likely to contain both successes and failures, because such anchors can generate sibling trajectories with opposite terminal outcomes, yielding stronger contrast for credit assignment under outcome-only rewards.

The framework has two stages:
1) Global root allocation over a large prompt pool: decide which prompts get zero vs positive rollout budget, favoring prompts with non-extreme success probabilities to increase terminal reward variance.
2) Local tree expansion: given collected rollouts, score encountered prefix nodes and allocate additional continuation branches to prefixes likely to produce outcome-diverse descendants.

It uses windowed-FIFO scheduling to handle trajectory-length variance, prefix-tree merging to share common prefixes, and inference kernels aligned with the serving stack to reduce rollout cost. M2.7 also shows an early self-evolution setup, where the model triages failed training runs, edits its own agent scaffold, and is evaluated through multi-round self-improvement on ML-engineering tasks.18:T74d,The method, AKBE, explicitly probes the model’s knowledge boundary during training. For each question, it runs dual-path rollouts under the current policy: one path with tool access and one path without tools. The two outcomes are then compared to infer whether the question is inside the model’s current parametric knowledge boundary and, if tools are needed, what the minimum effective tool-use pattern looks like.

The paper defines four cases. If the with-tool path is correct and the no-tool path is wrong, the sample is Tool-dependent: the model genuinely needs tools. In this case, AKBE reinforces the correct trajectory with the minimum number of tool calls, not just any successful tool-using trajectory.

If both with-tool and no-tool paths are correct, the sample is Efficiency: tools were unnecessary. AKBE then reinforces the no-tool correct trajectory to suppress redundant calls.

If the with-tool path is wrong but the no-tool path is correct, the sample is Hallucination: tool use hurt performance, likely by injecting misleading evidence or derailing reasoning. AKBE again reinforces the no-tool correct trajectory.

If both paths are wrong, the sample is Both-wrong, and no extra boundary-guided supervision is applied beyond the base RL objective.

Two design choices matter. First, the supervision is on-policy, because the dual-path rollouts come from the current model. This lets the boundary estimate evolve with training rather than relying on static labels. Second, AKBE does not modify the reward function. Instead, it adds an auxiliary loss on top of standard agentic RL, which is how it avoids the usual reward-shaping failure mode. Relative to prior efficiency-oriented methods, the novelty is not merely reducing tool calls, but estimating, per instance, whether tools are needed at all and what the minimal necessary usage should be.19:T564,The paper reports experiments on seven QA benchmarks with two backbone models, comparing standard agentic RL against AKBE and other efficiency-oriented baselines. The headline numbers are: +1.85 average accuracy improvement, 18% fewer tool calls, and 25% higher tool productivity. The authors emphasize that this is not an accuracy-efficiency tradeoff; in most settings, both improve together.

The more informative parts of the evaluation are the analyses. One is compatibility: AKBE can be plugged into multiple agentic RL algorithms rather than being tied to a single trainer. Another is training dynamics: the distribution of samples across Tool-dependent, Efficiency, and Hallucination categories changes over training, suggesting that the knowledge boundary is not static and is itself reshaped by RL. A third is category-level attribution: Efficiency supervision mainly removes redundant calls, Hallucination supervision reduces harmful tool reliance, and Tool-dependent supervision teaches more economical tool-use patterns when tools are genuinely needed.
