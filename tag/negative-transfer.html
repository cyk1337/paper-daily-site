From Raw Experience to Skill Consumption: A Systematic Study of Model-Generated Agent Skills

这篇工作要解决的不是“如何再发明一种 skill extraction 方法”，而是一个更基础也更缺失的问题：模型生成的、面向领域的 agent skills，到底能不能稳定带来收益；如果能，收益来自 skill 生命周期的哪一段；如果不能，失败是出在经验生成、技能抽取，还是推理时消费技能的方式。作者把问题从单点方法比较，改成了对完整 lifecycle 的系统拆解：target agent 先在训练任务上产生原始轨迹，extractor 从这些成功/失败轨迹中提炼结构化技能，再把技能回灌给同一个 target，在测试任务上看相对 no-skill baseline 的增益。核心关切不是某个 benchmark 上的绝对分数，而是“经验能否被压缩成可复用程序知识，并在同域新任务上重新兑现”。

评不是pretrain论文，但对“经验蒸馏成可复用训练信号”有现实提醒；只看负迁移分析和extractor-consumer交互那几节。
