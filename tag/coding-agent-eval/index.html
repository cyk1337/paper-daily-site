SWE-at-Scale: Scalable Issue Synthesis from Historical Bug Fixes

SWE 代码代理评测需要大量“可执行、可验证、贴近真实开发”的 repo 级任务，但真实 issue/bug 的自然产出速度慢、人工整理成本高；现有合成方法多依赖通用 LLM 的先验知识 + prompting，容易模式单一、机械性强。论文要解决的是：能否把历史真实 bug fix 反过来当监督信号，训练一个可复用的“注入 bug 的模型”，从而持续规模化地产生更真实、更难的 SWE 任务。

评把“修复提交”当作可挖的机制信号来反演生成 bug，这个数据生成 prior 比纯提示合成靠谱；建议重点看任务验证闭环与失败案例，别只看数量。

Coding-Agent Benchmarks Should Match Their Users' Task Flows

评别把 issue 任务当“真实交互”的代理，这篇用真实 IDE 会话把分布差异量化了；只看任务类型转移统计和 SWE-TaskFlow 变换定义就够。
