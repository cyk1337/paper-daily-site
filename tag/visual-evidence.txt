18:T605,The paper proceeds in three stages. First, it uses controlled referent-disambiguation settings to show that process failure is real and separable from perception. A model can enumerate all candidate objects and their attributes, yet still commit to a single unsupported answer. Second, the authors propose SRT, a family of structured process-prior interventions applied at inference time. SRT has three steps: State extraction, which explicitly surfaces observable states relevant to the question; Relevance checking, which tests whether those states are tied to the current decision boundary; and Target commitment, which delays the final answer until the previous checks are completed. This is more constrained than generic chain-of-thought because it specifies how evidence should be filtered and when commitment is allowed. Third, the paper introduces VPAC-Bench, a benchmark built around nine real-image process families. Each image is annotated not only with an activity stage but also with the nearby stage transition boundary, such as setup→active or active→finished. That structure lets the authors ask when a process prior helps: the key finding is that effectiveness depends on alignment between the supplied prior and the image’s actual decision boundary. Generic process prompts are not reliably helpful, and a misaligned prior can be worse than the default baseline.
