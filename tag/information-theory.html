Conservation Laws for Diffusion Models

这篇工作讨论的不是“怎样让多智能体更会辩论”，而是一个更基础的问题：在多 LLM 决策里，投票和辩论这两类常见聚合协议，究竟能保留多少来自各 agent 私有信息的有效证据。作者把问题放进 Blackwell informativeness 框架里，形式化比较不同聚合方式对应的信息结构，结论是：无论是多数投票，还是把多轮 debate 的最终输出再拿来决策，它们都可以看成对联合私有信息的一种 garbling，也就是带噪压缩；因此它们在信息论意义上不可能比“直接基于所有 agent 后验做 pooled posterior 决策”更优。论文进一步把这个上界落到多选 QA，提出 MA-PoP，用各 agent 的答案后验直接做乘积聚合，近似恢复 pooled posterior。

评用 Blackwell 信息论框架证明了多 Agent 投票/辩论的次优性，并给出了逼近贝叶斯后验上限的实用方法，做 Multi-Agent 聚合的同学值得看理论推导部分。
Zheng Zhang,Cuong C. Nguyen,Kevin Wells,Gustavo Carneiro

Tail-Aware Information-Theoretic Generalization for RLHF and SGLD

经典信息论泛化界（如基于KL互信息）通常依赖损失/奖励的有界性或次高斯尾部（MGF存在）。但在RLHF、鲁棒学习、随机优化等现代流程中，奖励/损失/梯度噪声常呈重尾（MGF可能不存在），导致KL工具可能“看起来信息很小但泛化/稳定性被极端事件主导”，从而界变得失效或空泛。本文要解决：在次Weibull（含0<θ<1重尾）条件下，如何构造仍然有效、可用于期望与高概率的、算法依赖的信息论泛化与稳定性分析框架，并落地到RLHF与SGLD。

评会改变“KL 小就安全/能泛化”的 prior：重尾下 KL 界可能空；建议立刻把 Rényi/尾部参数约束纳入 RLHF 监控与 ablation。
Huiming Zhang,Binghan Li,Wan Tian,Qiang Sun
