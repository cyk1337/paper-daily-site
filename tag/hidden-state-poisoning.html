Hidden State Poisoning Attacks against Mamba-based Language Models

该工作指出 Mamba / Mamba-2 这类 SSM 语言模型存在一种架构相关的长上下文脆弱性：短触发串可以把 recurrent hidden state 中已有信息部分覆盖，导致模型在后续查询时无法恢复前文信息。这个攻击被称为 Hidden State Poisoning Attack，核心不是让模型被提示词说服，而是让模型的状态更新机制遗忘早先内容。

评应立刻看攻击构造和 RoBench-25；若结论站得住，SSM 长上下文路线需要把“状态可擦写性”当成架构风险而非普通鲁棒性问题。
Alexandre Le Mercier,Chris Develder,Thomas Demeester
