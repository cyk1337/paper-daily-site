b:T6ff,方法叫 Windowed-MTP。核心思想是把 StreamingLLM 风格的 sliding window + attention sink 只应用在 draft head 上，而 target verify 仍然保留全上下文注意力。这样 draft 每一步只读取 W + sink 个 token 的 KV，而不是整段 S 长度上下文；例如 1M context 下 4K window 只占 0.4%。

为什么这能做到“lossless by construction”？因为 speculative decoding 的接受与否始终由 full-attention target 决定。windowing 只会改变 draft 提出的候选 token，不会改变 target 的验证规则，因此不会改变最终采样分布。论文还专门做了 greedy output diff，验证 windowed draft 与 native full-attention draft 的最终输出没有系统性分歧，超出范围的差异只来自 verifier 既有的 bf16 非确定性。

作者还给了一个逐步 latency model，把一次 speculative iteration 分成 γ 次 draft forward 和一次 verify forward，并分析在不同 acceptance length、draft depth d=γ+1、context length S 下，什么时候 native deep draft 会从加速退化到与 dense baseline 持平，甚至变成负收益。这个模型的意义在于，它不是只报告“快了多少”，而是解释为什么在长上下文、低 acceptance、verify 变便宜时，draft attention 会成为主导项。

机制分析部分也做得比较扎实。作者没有停留在“窗口够小也没掉速”这种经验结论，而是看了 window-size dose-response、每个 draft position 的 conditional acceptance 分解，以及 in-run decision-invariance probe。结论是：windowing 大多数时候并不改变 draft 的 top-1 proposal，保留了与 full-attention draft 相近的 acceptance profile，因此速度收益来自每步成本下降，而不是靠牺牲 acceptance 换吞吐。c:T6a0,The method, Windowed-MTP, applies a StreamingLLM-style sliding window plus attention sink to the draft head only, while leaving the target verifier at full attention. As a result, each draft forward reads only W + sink tokens from KV instead of the full context length S. At 1M context, a 4K window is only 0.4% of the sequence.

The key point is why this remains lossless. In speculative decoding, the target verifier always decides which proposed tokens are accepted. Windowing changes only the draft proposals, not the acceptance rule. Therefore the final output distribution remains identical to standard exact speculation. The paper validates this with greedy output diffs, showing no systematic divergence beyond the verifier’s existing bf16 nondeterminism.

The authors also provide a per-step latency model. One speculative iteration is decomposed into γ draft forwards plus one verify forward, and the model explains when a deeper native draft stops helping: long context increases draft KV reads, low acceptance reduces amortization, and cheaper verify phases expose the draft cost instead of hiding it. This is useful because the paper does not merely report speedups; it explains the regime in which native MTP collapses from accelerator to liability.

The mechanistic analysis is also stronger than usual. The paper studies window-size dose response, conditional acceptance by draft position, and an in-run decision-invariance probe. The conclusion is that windowing usually preserves the draft’s top-1 proposal and closely tracks the full-attention acceptance profile. The gain therefore comes from reducing per-step draft cost, not from trading away acceptance for throughput.d:T730,The experiments span three architecture families, including at least a dense Qwen-122B model, a hybrid Nemotron model, and a third model with a different attention design. The main operating point is 1M context with batch size 1.

First, the paper quantifies the long-context draft-attention tax. At γ=6, i.e. d=7, the draft phase alone adds about +92% to +138% on top of the bare verify cost per decode step, nearly doubling step latency. This directly falsifies the assumption that the draft is negligible at million-token context. More importantly, on hard low-acceptance workloads the shipped native draft can become net-negative: at d=7 it reaches only 0.80× the no-speculation dense baseline on Qwen-122B code QA and 0.97× on the hybrid Nemotron. Increasing draft depth to d=9 does not rescue the situation.

Windowed-MTP then delivers a fairly consistent reduction. At 1M context, it cuts per-speculative-iteration cost by about 28%–44% relative to native MTP, and the gain is largely input-invariant. Its magnitude tracks the fraction of draft cost attributable to windowable attention. The paper also measures that the draft KV pool is about 7.7%–11% of total KV across the three models; after windowing, all but W + sink of that draft KV becomes dead state and can be reclaimed into a compact ring buffer with no quality or speed penalty.

On acceptance behavior, windowing preserves the draft top-1 proposal 86%–94% of the time, and the resulting acceptance profile tracks full-attention draft within confidence intervals across the sweep. Residual differences exist, but they are small, depend on input and draft depth, and are always outweighed by the per-step latency reduction. Second, the analysis is split by regime. The table of contents makes clear that the authors treat a high-temperature regime and a low-temperature regime separately. Intuitively, when temperature is high, softmax is smoother and more amenable to low-degree approximation; when temperature is low, the kernel becomes sharper, local geometry matters more, and compression becomes harder. It has three components. First, Tier Layout: KV cache is split into a fast tier in HBM and a slow tier in DRAM, corresponding to short-term and long-term memory. The design assumption is that recent tokens are more latency-sensitive and should remain in high-bandwidth, high-precision storage. Second, Tier Content: different temporal regions of the cache are stored with different fidelity. Recent and frequently accessed tokens stay in full precision, while older tokens moved to the slow tier are further compressed using differential quantization and sparsification. The key point is that time is the organizing principle for both storage placement and compression budget. Third, Tier Interaction: to avoid decode-time stalls from DRAM access, the paper uses streaming attention so that transfer from the slow tier overlaps with computation. Instead of fetching all remote KV first and then computing attention, the system pipelines communication and computation to hide PCIe costs.

Relative to methods such as KIVI, KVQuant, and DiffKV, TTKV is not just a standalone quantization scheme. Relative to ShadowKV-style offloading, it is not only an access-pattern optimization. Its main distinction is that it jointly decides which tokens deserve low latency and which tokens deserve high precision. The underlying empirical claim is that recent tokens form the active working set, while only a small subset of distant tokens remains highly relevant.
