The key constraint is progressive disclosure: the agent starts with (q,E,m) and must decide to retrieve the skill file to access p.
Metrics are decomposed into:
- Trigger: whether the agent retrieves the relevant skill given only metadata.
- Compliance: whether it follows the procedure after retrieval (procedure-level adherence, not output formatting).
- Boundary: whether it avoids explicitly forbidden operations/shortcuts.
A gated aggregate SU score credits execution only if Trigger succeeds, preventing “accidental success without using the skill” from inflating results.
Benchmark construction emphasizes verifiability: real skills curated from community repositories; tasks designed to leave observable traces; tempting but forbidden shortcuts to stress Boundary;
