AutoTrainess: Teaching Language Models to Improve Language Models Autonomously

这篇工作要解决的问题是：让语言模型代理自主完成一轮又一轮的 post-training 改进时，为什么单靠通用 coding agent + 原始 CLI 环境不够，以及怎样把人类训练工程师积累的流程、约束和经验显式注入 agent 的行动空间。作者认为，自主训练不是单纯“会写代码”就够了，它还要求代理能稳定地做数据构造、训练作业启动、评测、日志记录和多轮迭代规划；而这些环节里大量失败来自接口过于原始、动作语义不清、训练细节容易出错。

评值得看，但别把它当“模型会自己炼丹”了；重点是把训练经验做成受约束接口，这对自动化 post-train 比再堆 agent prompt 更靠谱，先看 action design 和 failure cases。
