训练数据单位是 semantic-value quadruple：(x+, xp+, x-, xp-)。其中同一场景下，x+ 与 xp+ 是同价值的释义改写，x- 与 xp- 是对立价值的释义改写。监督信号围绕这个结构展开。第一类是 reconstruction，防止塌缩，保证 (zs, zv) 还能重构原始 hidden state。第二类是 swap consistency：在同场景、异价值的样本之间交换 value code，保持 semantic code 不变，要求重构后的表示对应“同语义、换价值”的状态；同时还要求 paraphrase 下 value code 稳定。第三类是 regularization，包括 topic de-confounding 和 decorrelation，前者通过 adversarial suppression 压制 zv 中的话题捷径，后者减少 zs 与 zv 的冗余耦合。推理时不直接生成文本，而是先在表示空间做编辑：固定 zs，把 zv 替换成目标 value prototype 或目标 value code，得到重构差分 Δh，再把这个 residual delta 注入原模型继续解码。

第一组是 matched split probes。作者把 learned codes 与任意等维切分、以及若干 ablation 做对比，检查 zs 是否更能预测场景/语义而更少泄露 value，zv 是否更能预测 value 而更少携带 topic。这个实验用来证明分解不是参数量或维度分配带来的假象，而是训练目标真的塑造了选择性表示。

第二组是 2×2 ablation，用来拆开 one-way mixing 与 inference-time gating/编辑机制的作用。也就是区分：性能提升到底来自训练时的语义到价值单向混合，还是仅仅来自推理时更温和的门控注入。作者强调有一个 matched mixing-by-gating ablation，说明他们专门控制了“模型容量和编辑形式相近，但没有 stop-gradient 单向结构”的对照。这一点很关键，因为很多 disentanglement 论文最后其实只是多了个更灵活的编辑器。

第三组是 steering 效果比较。对比对象包括 dense steering、sparse steering、direct prompting 等。结论是：在相近 value alignment 水平下，这个 semantic–value interface 能更好保留原场景语义，并减少 benign refusal。也就是说，它改善的是 trade-off，而不是单纯把 alignment 指标拉高。

第四组是输出层评估。除了自动指标，作者还用了 non-generative fidelity metrics 和 human ratings，去判断编辑后回答是否仍保留人物、事实、数量、约束和任务。这个选择是合理的，因为只看生成文本与参考答案的 lexical overlap，无法判断“价值变了但事实没变”这种细粒度目标。

This reflects the authors’ view that value recognition is context-dependent and therefore should be semantically grounded. At the same time, value-related losses are prevented from flowing back into the semantic encoder through that path, so the semantic channel is not reshaped to serve value discrimination.

Training uses semantic-value quadruples: two paraphrases with one target value under the same scenario, and two paraphrases with a contrasting value under the same scenario. The losses are organized into three groups. Reconstruction prevents collapse and keeps the latent pair tied to the original hidden state. Swap consistency is the main structural supervision: within a scenario-matched opposite-value pair, value codes are swapped while semantic codes are held fixed, encouraging the decoder to represent “same scenario, different value framing.” Additional paraphrase consistency encourages value stability across rephrasings. Regularization includes topic de-confounding, implemented adversarially to suppress topic shortcuts in zv, and decorrelation-style penalties to reduce redundancy between zs and zv.

At inference time, the model does not overwrite the hidden state directly. Instead, it fixes zs, edits or replaces zv with a target value code or prototype, reconstructs the edited hidden state, computes a residual delta, and injects that delta back into the frozen backbone. Compared with dense or sparse steering baselines, the differences are clear: it explicitly learns an editable interface rather than assuming a pre-existing linear direction; it allows value recognition to depend on semantics rather than enforcing strict independence; and it applies edits as reconstruction deltas, which are intended to be more local and less destructive than direct activation replacement.1b:T8b7,The experimental design is the strongest part visible from the provided full text, even though the excerpt does not include all tables and exact numbers. The method is evaluated on two instruction-tuned backbones, and the evaluation is not limited to whether value alignment succeeds. It also measures semantic preservation, benign refusal, and representational leakage.

The first block of experiments uses matched split probes. The learned codes are compared against arbitrary equal-size partitions and ablated variants to test whether zs better captures scenario semantics with less value leakage, and whether zv better captures values with less topic information. This matters because it checks whether the factorization is genuinely selective rather than a byproduct of dimensionality or extra parameters.

The second block is a 2x2 ablation that separates the effect of one-way mixing during training from the effect of gating or editing at inference time. The paper explicitly mentions a matched mixing-by-gating ablation, which is important: it controls for the possibility that gains come merely from a more flexible editor rather than from the asymmetric semantic grounding itself.

The third block compares downstream steering quality against dense steering, sparse steering, and direct prompting. The reported conclusion is that, at comparable value alignment, the proposed interface preserves semantics better and reduces benign refusals. So the gain is in the trade-off frontier, not simply in maximizing alignment.

The fourth block uses output-level assessments beyond standard generation metrics, including non-generative fidelity measures and human ratings. That choice is sensible because lexical overlap is a poor proxy for the target behavior here: the desired edit changes normative framing while preserving facts and constraints.

The excerpt does not expose the appendix tables, so I cannot reliably restate exact parameter counts, latent dimensions, layer choices, or effect sizes. What is clear is that the paper reports consistent improvements in the alignment-preservation trade-off on two backbones, and that architecture-matched ablations support the necessity of the one-way semantic-to-value design.1c:T6b4,Start with the introduction, especially the distinction between values and surface style. The paper is careful about defining values as context-dependent normative priorities rather than generic stylistic attributes, and that framing explains why a naive style-transfer factorization is not enough.

Then focus on the method section: the quadruple construction, the one-way semantic-to-value mixing path, the exact placement of stop-gradient, and the swap-consistency objective. This is the conceptual center of the paper. The key question to keep in mind is why the value encoder should read semantics, but the semantic encoder should not be shaped by value losses. If that asymmetry makes sense to you, most of the method follows naturally.

In the experiments, prioritize three things: the leakage or split-probe results, the 2x2 ablation isolating one-way mixing, and the preservation-versus-alignment trade-off plots. Those are more informative than any single scalar score. If time is limited, read the main experimental conclusions first, then inspect the appendix for loss weights, layer selection, prototype construction, and failure cases.

Three follow-up questions are worth thinking about. First, whether this interface is specific to values or can generalize to other steering dimensions such as toxicity, helpfulness, persona, or political stance. Second, whether editing a single layer and token position is expressive enough for long-range normative behavior, or whether a multi-layer interface would be needed. Third, whether the quadruple supervision pipeline scales to broader and noisier value spaces.
