SonicSampler: Unified Tile-Aware Kernels for LLM Sampling and Speculative Verification

论文解决的是 LLM serving 中采样阶段的系统瓶颈。现有优化多集中在模型 forward，但实际生成还包含 grammar mask、重复惩罚、logit bias、temperature、top-k/top-p/min-p、token selection，以及 speculative decoding 的验证逻辑。这些步骤常被拆成多个 kernel，带来 launch 开销和中间显存读写；同时很多实现假设 batch 内采样策略一致，难以适配 continuous batching 下的混合请求，也不利于 CUDA Graph。

评做 serving/Triton kernel 的人值得细看两阶段 top-k 与 fusion 策略；对预训练本身无直接方法论贡献，但工程参考价值高。
Pragaash Ponnusamy,Shivam Sahni,Jue Wang,Tri Dao

AVQ-Attention: Adaptive Vector-Quantized Attention

这篇论文解决的是高效注意力里的一个具体问题：VQ-attention 虽然把复杂度从 O(N^2) 降到 O(MN)，但它对整个 key 空间使用固定、均匀的码本容量，导致高注意力区域量化过粗、低注意力区域又浪费表示预算。作者要做的是让码本容量随输入和注意力分布自适应分配，在不回到二次复杂度的前提下，把算力集中到真正重要的区域。

评只看方法和 kernel 设计即可；若误差-吞吐曲线干净，值得在长上下文 attention ablation 里复现。
Winfried van den dool,Patrick Forré,Amir Habibian,Yuki M. Asano,Max Welling
