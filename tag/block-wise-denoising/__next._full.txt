18:T46c,The model uses a block diffusion factorization. A sequence is split into contiguous blocks. Previous blocks are kept clean and used as prefix context, while the current block is corrupted with an absorbing [MASK] process and denoised in parallel. The conditional distribution for each block is trained with a weighted cross-entropy over masked positions, with weights induced by the diffusion noise schedule. This design interpolates between AR generation and fully parallel diffusion. The main method is block-size curriculum learning. Training starts with small blocks, where the model sees a generation problem closer to AR and can learn coherent reasoning trajectories. It then gradually increases the block size so the model adapts to coarser parallel denoising. This differs from fixed small-block training, which limits inference parallelism, and from direct large-block training, which is brittle for reasoning.
