Mage-VL: An Efficient Codec-Native Streaming Multimodal Foundation Model

论文要解决的是流式视频输入和现有 VLM 架构之间的效率错配：主流 VLM 依赖静态图像预训练编码器和均匀抽帧，能够做离线图像/视频问答，但在连续视频流里会重复编码大量静态背景，视觉 token 和计算量随时长快速增长，难以低延迟响应动态事件。

评用无标注视频的运动信息做稀疏token化，仅用1/10级别的数据就追上强监督编码器，这个数据效率结论值得多模态预训练团队参考，重点看Mage-ViT编码设计部分。

Cosmos 3: Omnimodal World Models for Physical AI

Cosmos 3 试图解决一个统一建模问题：如何让同一类基座模型同时处理和生成语言、图像、视频、音频与动作序列，并服务于 embodied agent 和物理世界建模。它不是单独做 VLM、视频生成器、语音模型或机器人策略模型，而是把这些能力放进一个 omnimodal world model 训练框架中。
