9:T44d,Sniper is a two-stage structured pruning framework (depth then width).
- Mixed-granularity decomposition: each layer is represented by attention block A_l and MLP block M_l, plus a composite item T_l meaning “keep the whole layer”. A mutual-exclusion constraint prevents selecting T_l together with its sub-blocks.
- Depth pruning as 0/1 knapsack: each component x has weight w(x) (parameter count) and value v(x) (importance). Given a parameter budget C, maximize total value under the capacity constraint. The solver uses dynamic programming; to make it tractable for large C, parameter counts are discretized by a factor α, reducing complexity to O(N·⌊C/α⌋).
- Importance estimation: an iterative marginal-contribution scheme where v(x) is derived from the divergence in output logits when removing x on a calibration batch.
- Width pruning stage: applied after the depth-selected backbone to fine-tune the final model to match the target compression ratio closely.
