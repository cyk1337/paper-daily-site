9:T54c,A two-phase auditing pipeline.
Phase 1 (candidate discovery): define forced-choice behavior via the logit margin between the gold option and the strongest competing option, plus auxiliary measures (entropy, gold/wrong probabilities). Encode residual-stream activations with pretrained Gemma Scope SAEs, pool feature activations over specific spans (max-pooling over tokens), and rank features using L1-regularized logistic probes for several binary targets (e.g., Wrong vs Correct, low vs high margin, wrong-high-confidence variants) and ridge regression for continuous targets (margin/entropy). Complement probes with statistical audits (Pearson/Spearman correlations, bootstrap mean-difference intervals, mutual information estimates).
Artifact-risk screening: for sufficiently supported features, explicitly test confounds tied to evaluation structure (answer letter, prompt template, answer permutation, topic/content cues). Convert each confound score to within-run percentiles and filter out high-risk features.
Phase 2 (causal evaluation): perform feature steering/interventions and measure distributional shifts in margins and actual answer flips (wrong→correct), with random-active feature controls.
