AgentStream: How Well Do Self-Evolving LLM Agents Perform Under Streaming Tasks?

这篇工作处理的不是“如何做更强 agent”，而是一个更基础的评测问题：自演化 agent 在真实流式任务环境里到底表现如何。现有工作大多把每个任务独立评测，agent 在一个 benchmark 上积累的经验不会带到下一个 benchmark，这会高估某些 self-evolution 方法的稳定性，也看不出跨域迁移、经验污染和顺序效应。论文要解决的是，如何把不同 agent benchmark 组织成可控任务流，并系统比较不同自演化机制在不同流式场景下是增益还是退化。

评读任务流定义和方法×模型×场景交叉表即可；它测的是独立评测掩盖的经验干扰。

The Blind Curator: How a Biased Judge Silently Disables Skill Retirement in Self-Evolving Agents

研究对象是自进化 Agent 中的技能退役机制在 LLM judge 有偏时如何失效。关键点不是 judge 有噪声，而是 false-pass bias：真实失败被判为通过。对于依赖失败样本来合成新技能、统计旧技能贡献的系统，这类偏差会让 curator 看不到该退役的证据。

评做 self-improving agent 或 judge-based RL 的人该看；它提醒你 false-pass 不是普通噪声，而是会把“坏技能淘汰”这条反馈链直接剪断，先看机制图和阈值实验即可。
