9:T4af,The authors formalize search as a candidate graph G(C,E), where nodes are partial candidates and directed edges encode dependencies. A candidate is represented as a set of literals, and each round expands and verifies leaf candidates. A binary verifier indicates whether a candidate remains consistent with the target. There are N agents, each verifying up to m candidates per round and sharing verification results with d neighbors. The key dynamical variable is A_t, the total number of active incorrect candidates across agents. When A_t decays to zero, the system reaches the absorbing solved state; when it grows or persists, the search process remains active and unsuccessful. The paper introduces four search types: needle, chain, hierarchical, and factorizable search. These classes differ in how much a verification result from one branch can prune other branches. The theoretical analysis derives task-dependent critical degrees d_c. Factorizable search benefits most from communication because local evidence can be reused across otherwise separate parts of the search space. Needle-like search benefits less because a discovered fact usually provides little reusable pruning information.a:T543,FlowMAS models workflow construction as trajectory generation with a GFlowNet. A state corresponds to a partially built workflow topology, actions extend the topology, and a terminal state is a complete workflow. The GFlowNet is trained so that terminal workflows are sampled in proportion to their rewards, which encourages a distribution over high-reward candidates rather than a single optimized graph.

The paper adds two components on top of a vanilla GFlowNet. The information-guided module uses Partial Information Decomposition to estimate how different operators contribute unique, redundant, and synergistic information toward the task. This gives more structured credit assignment than a single scalar textual critique. The curiosity-driven module rewards structural novelty, pushing the generator to explore underrepresented workflow patterns and reducing collapse to a few templates.

Compared with search-based systems such as ADAS and AFlow, FlowMAS learns a reusable topology generator instead of repeatedly searching a large tree. Compared with textual-gradient methods such as OneFlow and DebFlow, it aims for finer-grained structural feedback. Compared with VAE, graph diffusion, or MLP-based generators, the paper argues that GFlowNets are a better fit for discrete graph-like objects with reward-driven diversity requirements.b:T56c,OptiMAS builds all agents on a shared ReAct-style execution primitive. Each agent alternates between thought, action, and observation. Multi-agent coordination is implemented through a proactive assign-deliver protocol: a parent agent delegates a subtask as a tool call, the sub-agent solves it, and the result is returned as a structured observation. This removes the need for a fixed workflow while still keeping execution structured.

To avoid unstable free-form code generation, tools are selected from a predefined macro-library. The collaboration graph is constrained to be a DAG, which helps prevent uncontrolled recursive delegation.
