9:T56c,LRT selects a source layer l_src and defines the recurrent memory at position t as m_t = h_t^{l_src}. When processing position t, the model uses the usual causal attention and KV cache, and additionally injects m_{t-1} into the current-token computation. This creates a pathway that standard KV-cached Transformers do not have: layer l at the current position normally attends only to past states from the same layer, while LRT allows early or middle computation at the current position to access a high-level representation already computed for the previous token. The paper studies two lightweight injection mechanisms. KV Projection routes the memory through the attention key-value pathway. Residual Injection adds it as a residual signal to layer representations. The default model combines both and uses shared projections to keep parameter growth small. For training, the paper introduces interleaved parallel training. A full-sequence initialization forward first builds a shared memory buffer. Then disjoint interleaved position subsets are refined in parallel and written back to the buffer. Later subsets can consume memories updated by earlier subsets.
