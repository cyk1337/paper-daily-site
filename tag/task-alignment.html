Disentangling Linguistic Relatedness from Task Alignment in Cross-Lingual Transfer

这篇论文想分清一个常被混在一起的问题：跨语言微调后的收益，到底来自语言亲缘性带来的知识迁移，还是来自模型学会了目标任务的输入输出格式。作者用阿拉伯语方言微调，再在希伯来语、阿姆哈拉语、马耳他语，以及日语、韩语、法语上做零样本阅读理解，专门检验“闪米特语族内部迁移”是否真实存在。

评结论会修正多语微调的归因；只看实验设计和 CoT ablation，语言学解释先降权。
Ahmed Haj Ahmed,Ruochen Zhang,Alvin Grissom

No More, No Less: Task Alignment in Terminal Agents

这篇论文评测 terminal agent 在执行任务时能否选择性使用环境信息：该跟随的 cue 要用，不相关的 distractor 要忽略。核心问题不是普通的任务完成率，也不是简单的 prompt injection 防御，而是 agent 在 README、日志、注释、配置文件等混杂信息里判断哪些内容服务于用户目标。

评专注Agent指令对齐的基准工作，对预训练研究员仅可作为后训练对齐效果的评测参考，读基准设计部分即可。
Sina Mavali,David Pape,Jonathan Evertz,Samira Abedini,Devansh Srivastav,Thorsten Eisenhofer,Sahar Abdelnabi,Lea Schönherr
