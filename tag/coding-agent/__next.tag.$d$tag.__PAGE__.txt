The judge design is equally important. The agent and the judge run in separate sandboxes. The agent has no network access beyond a driver that forwards model calls and patch submissions, preventing trivial recovery of the original code. The other targets under-checking: when immediate submission would skip a required check, the method also creates pairs on that side, so the model does not simply learn to check less. The second layer is PRPO, Peer-Relative Policy Optimization. Each side is a population of LoRA adapters over one frozen base model, with adapter size around 0.1% of the base parameters.
