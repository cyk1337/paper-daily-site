1) TaskPilot: an online, policy-adaptive task synthesis loop. Starting from real repository snapshots, it generates candidate tasks, runs rollouts with the current checkpoint to estimate learnability, keeps tasks within a target difficulty window (neither unsolved-always nor saturated), and uses policy feedback to adjust tasks toward that window. Training proceeds in iterations: when a checkpoint saturates on validation, it triggers a new synthesis/calibration round, so the task distribution co-evolves with the policy. 关键做法有三层。

第一层，是把 speculative decoding 反过来。作者引入一个小型开源 draft model q，对黑盒 agent p 已经生成出的 token 序列做 teacher-forced scoring。也就是给定前缀 (x, y<t)，让 q 输出下一个 token 分布，再去读 agent 实际生成 token yt 在 q 下的概率。这样一次前向就能得到整条轨迹的 token-level 信号，不需要访问 p 的 logits，也不需要重复采样。文中提到至少提取了三类逐 token 信号，摘要截断处能确认其中包括 cross-likelihood 以及 draft 自己的 argmax 与 agent token 的偏差类信息；从方法描述看，核心是利用 q 与 p 在局部条件分布上的一致性/不一致性来近似失败风险。

第二层，是 phase-aware feature extraction。作者观察到 agent 轨迹不是同质 token 流，而是明显分成 reasoning phase 和 action phase。reasoning 段自由度高、熵高、语言噪声大；action 段受工具调用语法、参数格式、代码片段结构约束更强，熵低，但也更直接决定执行是否成功。如果像 HTC 那样把整段 token 概率简单平均，reasoning 段会淹没 action 段中真正与失败相关的信号。SU 因此按 harness 的消息结构把 token 标成 reason/action 两类，分别统计特征，再送入校准器。这个设计不是简单 feature engineering，而是在利用 agent 轨迹的生成机制差异。

第三层，是轻量校准。作者没有训练复杂判别器，而是用线性 calibrator 把 phase-aware 特征映射成“下一步 action 会通过验证”的概率。这样做有两个好处：一是样本效率高，便于跨 agent 迁移；二是输出可直接作为 gate/routing/human intervention 的决策分数。部署时，SU 插在 code generation 和 execution 之间。如果预测失败概率高，就先 veto 当前 action，触发更便宜的 replan，而不是进入 execute-fail-retry 循环。

和已有方法相比，区别主要有三点：一，不需要白盒访问；二，不需要多次采样；三，不把轨迹当作均质序列，而是显式建模 reasoning/action 两阶段。作者还强调 draft model 的训练目标并不敏感，说明这里更重要的是 draft 作为一个通用语言先验和局部一致性探针，而不是某种专门蒸馏出来的精确替身。b:T991,The method, Speculative Uncertainty (SU), operates on a fixed lookback window of the most recent k=3 agent steps. Each step contains a reasoning span followed by an action span. The target is a calibrated probability that the current action will satisfy a verifiable objective Ω before execution; in the coding setting, Ω is whether execution succeeds without exceptions.

The first ingredient is reverse speculative scoring. A small open-weight draft model q is run in teacher-forcing mode over the black-box agent trajectory produced by model p. For each token, q conditions on the prefix and assigns probability to the token actually emitted by p. This yields token-level cross-likelihood style signals in a single forward pass, without access to p’s internals and without repeated sampling. The method relies on disagreement between q’s local distribution and p’s realized tokens as a proxy for downstream failure risk.

The second ingredient is phase-aware feature extraction. The paper argues that agent trajectories are structurally heterogeneous. Reasoning spans are high-entropy and linguistically noisy; action spans are lower-entropy, more syntax-constrained, and more directly tied to execution success. If one averages token scores over the whole trajectory, as in prior holistic calibration approaches, the action-relevant signal gets diluted by the reasoning phase. SU therefore separates reasoning and action tokens using the harness structure and computes features for each phase independently before calibration.

The third ingredient is a lightweight calibrator. Rather than training a heavy classifier, the paper uses a linear calibration layer to map phase-aware features to a failure likelihood. This keeps the method sample-efficient and easier to transfer across agents. In deployment, SU is inserted as a gate between code generation and execution: if the predicted failure risk is high, the system triggers a cheaper replan instead of entering an execute-fail-retry loop.

Relative to prior work such as trajectory calibration with white-box log-probabilities, the differences are clear: no white-box access, no repeated sampling, and explicit modeling of reasoning versus action phases. The paper also notes that the exact draft-model training objective matters little, which suggests the draft is acting more as a generic language prior and consistency probe than as a tightly matched student of the target agent.c:T6d2,The evaluation is conducted on two agentic coding benchmarks, explicitly including SWE-Bench Verified and DA-Code, with additional zero-shot transfer to an out-of-distribution benchmark. The deployment policy is a pre-execution veto gate: if SU predicts high failure likelihood, the action is blocked and the agent replans.

The headline deployment result is a reduction of per-call execution error rate by 6 to 8 percentage points, alongside a 14% to 19% reduction in average token cost. This is important because the method is not merely improving a calibration metric; it is reducing the expensive retry loop that dominates practical agent cost.

A central ablation concerns phase awareness. The paper’s main claim is that treating the trajectory as a homogeneous token stream weakens the signal, because the high-entropy reasoning portion overwhelms the action-specific failure cues. The reasoning/action split appears to be one of the main contributors to performance over prior holistic scoring baselines.

Another useful result is that the draft model need not be large or highly specialized. A distilled 4B draft is reported to be sufficient, the training objective of the draft matters little, and a draft-calibrator setup trained on one agent transfers to other agents substantially better than an untrained baseline. That makes the method more plausible as a reusable deployment component rather than a benchmark-specific fit.

The most informative parts of the experimental section are likely not the absolute calibration numbers alone, but the transfer results: across agents, across benchmarks, and across draft-model choices.
