First, the current policy interacts with live GUI environments at an elevated sampling temperature to collect states from its own execution distribution. Second, without further environment interaction, the system samples G thought-action candidates for each collected state, scores them with a Process Reward Model using binary step-level rewards, and updates the policy with GRPO. This design decouples slow stateful environment rollout from batched model optimization. The agent follows a ReAct-style format, conditioning on the task instruction, previous thoughts and actions, and recent visual observations. The visual window is set to w=1, keeping only the latest screenshot to reduce multimodal context cost. Compared with filtered behavior cloning, the method introduces negative learning signals and does not force exact imitation of demonstrations.
