9:T4ec,Cord is “confidence-anchored residual decoding.” Instead of replacing confidence decoding with a full token-level planner, it keeps the base confidence ranking (top-2 margin) and learns bounded geometric corrections:
- Residual families: (i) generation direction bias (left-to-right, right-to-left, etc.), (ii) proximity-to-revealed-context (local continuation vs non-local seeding), and (iii) two-sided infilling preference (positions bracketed by revealed context).
- A lightweight prompt-conditioned network outputs a low-dimensional coefficient matrix; state features of the partially revealed response modulate how residuals apply over time, enabling within-rollout phase changes (seed anchors early, fill locally later).
- Training avoids step-wise discrete actions. For each prompt, Cord samples a single coefficient matrix that deterministically induces the entire state-dependent reveal trajectory, then receives a sequence-level reward. This reframes learning as a contextual bandit in a low-dimensional continuous space, sidestepping temporal credit assignment and reducing variance.
- The dLLM backbone stays frozen; only ~0.53M policy parameters are trained. When coefficients are zero, Cord exactly reduces to the original confidence decoder.a:T5be,The method, CLAD, has three main components. First, it builds confidence-induced clusters (CICs). At a denoising step, the decoder computes token-level confidence for masked positions and merges adjacent high-confidence masked tokens into maximal contiguous spans. Each span becomes a candidate update unit. The underlying assumption is simple but important: neighboring confident positions are often supported by the same local context and can be committed together. Second, CLAD estimates dependencies between clusters. Instead of training an auxiliary module, it reuses self-attention maps from the same forward pass, aggregates token-level interactions into inter-cluster dependency scores, and constructs a conflict graph. To keep the graph sparse, it retains only mutually strongest inter-cluster dependencies. This pruning is important; otherwise the graph becomes too dense and the decoder turns overly conservative. Third, CLAD selects a maximum-weight set of non-conflicting clusters for parallel commitment. Cluster weights come from aggregated confidence. This turns each denoising step into a constrained combinatorial selection problem rather than independent token ranking. Relative to token-level dependency-aware methods such as DAPD and DAWN, the key difference is not merely using attention at cluster level. The deeper change is the two-stage decomposition: define locally reliable span candidates first, then resolve global compatibility among them.b:T4d7,The evaluation covers mathematical reasoning and code generation, using pretrained MDLMs from the LLaDA and Dream families on four benchmarks. The main result is a 1.77× to 8.47× speedup over vanilla decoding while keeping task accuracy broadly comparable in most settings. Against token-level dependency-aware baselines such as DAPD and DAWN, CLAD improves throughput in most evaluated cases. The reported gains appear to come from two sources: cluster-level commitment reduces the number of denoising iterations, and attention-based compatibility modeling limits the quality drop that would otherwise come from aggressively committing multiple spans at once. The key ablation to look for is the separation between the two ingredients: using CICs without conflict filtering should improve speed but hurt accuracy more, while token-level dependency modeling without cluster grouping should leave parallelism underexploited. The paper also stresses that sparsifying the conflict graph is necessary for efficiency; otherwise the overhead of cluster selection would eat into the decoding gains.
