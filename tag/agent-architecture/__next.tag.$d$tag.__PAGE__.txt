第二块是 Adapter Protocol。作者定义了一个六方法接口，把不同 memory backend 统一到同一行为契约下。即便某个系统没有原生 supersede，也可以用 add+delete 组合实现并接受同样测试；没有某个 primitive 的系统则记为 N/A，而不是硬算失败。这个设计避免了把“接口缺失”和“实现错误”混在一起。

The first is ForgetEval. Forgetting is decomposed into five structural families: supersession, decay, amnesia, purge, and drift. On top of that, the benchmark adds ten adversarial attack categories such as substring traps, prefix collisions, paraphrase supersession, negation traps, temporal qualifiers, identifier obfuscation, and cross-lingual variants. Each case is a deterministic dataclass with setup facts, distractors, mutations, a final query, and must-contain / must-not-contain constraints. A case passes if the top-10 recall blob satisfies those constraints. Importantly, scoring is deterministic string matching rather than LLM judging.

The second component is the Adapter Protocol. It defines a six-method behavioral interface that allows heterogeneous memory backends to be compared under the same contract. Systems without a native supersede primitive can still implement it compositionally via add plus delete. Missing primitives are marked as N/A rather than counted as failures. This avoids conflating interface absence with implementation failure.

The third component is the architectural comparison across thirteen system configurations. These are grouped into regimes such as no-deletion, deterministic, vec-only, inscribe-time LLM, KG abstraction, joint, and mutation-time LLM hook. The key finding is that these regimes provide complementary coverage rather than a simple ranking. Deterministic primitives handle lexical and temporal cases well but fail on canonicalization. Inscribe-time LLMs normalize aliases and paraphrases at write time, so they recover canonicalization failures, but they cannot interpret later deletion intent. Mutation-time LLM hooks instead parse deletion intent at update time and map it to precise mutations while leaving the recall hot path unchanged. Two different backends converge to similar performance once they share the same narrow JSON-shaped mutation hook, suggesting that control-plane interface design matters more than the storage substrate.b:T6c0,Four experimental results stand out. Instead of concatenating all roles into one sequence with delimiter tokens, the model performs joint conditional generation over structured streams.

The important detail is that this is not just batched decoding of several independent sequences. The streams are coupled through interdependent attention. The paper frames the change as an instruction-tuning modification: existing message-based data can be transformed into aligned multi-stream supervision, and additional stream annotations can be synthesized from existing chat models. Empty cells are explicitly modeled and can be skipped at inference time to reduce KV-cache growth. The setup also distinguishes input streams, which can receive live external tokens, from output streams, which are generated by the model. That is what enables overlapping reading, thinking, and acting.

Compared with standard chat tuning, the structural information is no longer encoded only through role markers and sequence order. It is built into the tensor layout and attention pattern. Security experiments center on prompt-injection robustness. From a pretraining researcher’s perspective, the key open questions are whether the gains hold across scale, how much the training data construction depends on teacher-generated supervision, whether the serving-side cache and scheduling advantages survive real deployment constraints, and whether benchmark improvements come from the multi-stream structure itself or from richer supervision.e:T737,The method is a compositional scaffold with explicitly separable components. The authors evaluate three agents: a base LLM, a version augmented with context graphs, and a full version that adds dynamic behaviors on top. Context graphs are inspired by statechart-style control structure. They organize problem solving as typed state machines, with the goal of improving reasoning quality inside a fixed hypothesis space by reducing erratic exploration, missing tests, and unstable evidence integration. Dynamic behaviors act more like runtime monitors. They watch for evidence that cannot be explained within the current representational frame and trigger state-space expansion, adding new causal dimensions or rule types when needed.

The important design choice is not the scaffold itself but the ablation logic. The paper is built to test whether the two components make orthogonal contributions. Context graphs are supposed to help after the correct post-switch hypothesis space is available. Dynamic behaviors are supposed to improve reasoning eligibility by detecting that the old space is no longer sufficient. The claim is therefore causal and modular: one component should not substitute for the other.

On the evaluation side, the paper extends the classical blicket detector paradigm. In the standard setting, the agent must infer which objects activate a machine and what rule governs activation. The new hidden moderator condition changes the causal rule mid-experiment, forcing the agent to realize that the old variable set is no longer enough. The benchmark also includes order-sensitive and stochastic conditions, and the authors explicitly report that the current scaffold does not reliably help there. That negative result is part of the contribution because it defines the scope of the method rather than overstating generality.f:T57a,The evaluation covers 1,085 trials. The main result is not a single accuracy number but a decomposition of where gains come from. The authors report that the two scaffold components contribute in different ways: context graphs improve reasoning quality within the post-switch hypothesis space, while dynamic behaviors improve reasoning eligibility by detecting regime changes and preventing premature commitment to outdated hypotheses. The full architecture is therefore needed for the hidden moderator condition, where hypothesis-space restructuring is essential.

A second important result is the boundary analysis. In the order-sensitive and stochastic conditions, the scaffold provides no reliable benefit. That makes the paper more credible, because it shows the architecture is not a generic 'workflow boost' but a targeted intervention for a specific structural failure mode. The proposed reasoning-eligible accuracy metric is also useful: it tries to separate failures caused by never reaching the right hypothesis space from failures that persist even after the correct space is available.
