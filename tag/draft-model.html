CURE: Local Uncertainty Repair for Block-Parallel Speculative Decoding

这篇工作解决的是 block-parallel speculative decoding 的一个具体痛点：并行 draft 虽然便宜，但一旦某个位置出错，后面整段候选都会因为前缀校验而被连带拒绝，形成 error propagation cascade。作者的观察是，错误并不是均匀分布的，往往集中在少数高不确定 token 上。如果能只在这些局部位置做修复，而不是对整段做密集树扩展，就有机会在不把 verifier 成本推高太多的前提下，提高接受长度和端到端吞吐。

评只看错误定位和 resynchronization 机制；若实验补全，局部不确定 token 这个诊断可迁移到 draft-model 训练。
Aofan Liu,Jingxiang Meng,Fangxin Liu,Yongbiao Chen

DFlare: Scaling Up Draft Capacity for Block Diffusion Speculative Decoding

Block diffusion speculative decoding 依赖“draft 一次性预测整块 token、target 并行验证”的范式，速度取决于 acceptance length（每次验证能接受多少 draft token）。现有 DFlash 在两点上卡住：一是 draft 加深后收益递减；二是 target knowledge injection 采用“少数 target 层 → 单一融合表示 → 所有 draft 层共享”的窄瓶颈，导致各层输入同质、难以分工，进一步让加深无效。论文要解决的是：如何在几乎不增加开销的前提下扩大 conditioning 带宽，让更深的 diffusion draft 真正变强，从而提升 acceptance length 与端到端加速比。

Draft-OPD: On-Policy Distillation for Speculative Draft Models

Draft-OPD 解决的是训练型 speculative decoding draft model 的离线训练瓶颈。常规 SFT 学的是 target model 生成的固定轨迹，但推理时 draft model 的接受长度由它自己提出的 token block 决定，两者状态分布不一致，导致继续 SFT 很快进入平台期。

Speculative Decoding Across Languages

解决 speculative decoding 在非英语场景加速效果差的问题：小 draft 模型多语能力弱、tokenization 偏置导致 acceptance rate 低，从而 speed-up 接近 1 甚至为负。论文比较三种提升跨语言 acceptance 的策略，并检验是否能从“翻译（训练域）”泛化到“故事生成（新域）”。

评这篇不改算法范式，但把一个常被忽略的坑讲清了：多语 speculative decoding 的瓶颈常在 draft 分布失配；只看实验设计和跨任务泛化表就够。

SpecBlock: Block-Iterative Speculative Decoding with Dynamic Tree Drafting

这篇工作处理的是 speculative decoding 里一个很具体但很关键的矛盾：树式草稿如果想让 target 一次验证接受更多 token，就需要 draft tree 既有足够覆盖率，又不能让 drafter 本身变成新的时延瓶颈。EAGLE-3 这类自回归 drafter 的问题是路径一致性好、接受长度高，但树每加一层都要多一次串行 drafter forward，drafter 延迟会吃掉不少收益；并行多位置 drafter 则把多步预测压到一次 forward 里，但不同深度位置彼此看不到对方，拼成树后会产生大量不连贯路径，target 验证预算被浪费。SpecBlock 的核心问题就是：能不能在少量 drafter 调用下，仍然保留路径内依赖，让 draft tree 既便宜又更容易被 target 接受。

评投机解码 drafter 设计有实用新意；先看 block 内依赖机制和 acceptance/latency 分解，不必读训练细节。
