Compute Globally, Materialize Locally: The Memory Contract of Sparse Event-KV

这篇工作要回答的不是“KV cache 能不能当记忆”这种泛问题，而是一个更细、更关键的 serving 问题：当系统只保留一小部分历史事件对应的 KV 行、并把真正写入信息的源事件删掉之后，被保留的下游事件 KV 是否仍然携带了由已删除上游观测计算出来的状态。作者把这个现象定义为 semantic materialization。核心难点在于，普通准确率无法区分三种来源：答案是否直接写在保留文本里、模型是否靠先验或排除法猜对、还是 KV 行里真的保留了不可见的上游状态。论文因此设计了 donor-pair 因果对照：两段历史在所有被服务的 token 与位置上完全一致，只改变一个已被删除的源事件中的值，看最终回答是否跟着这个被删值变化。这样测到的就是“被保留 KV 行是否独立承载了已消失输入的计算结果”。

评这个结果会改变 KV eviction 的默认心智模型；先看 omission setup，再决定是否内部复现实验。
Zefeng Cai,Zerui Cai
