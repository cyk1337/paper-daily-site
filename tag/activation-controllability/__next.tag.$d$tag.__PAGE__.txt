9:T449,The Activation Controllability Benchmark asks a model to copy a fixed neutral sentence exactly while an embedded instruction tells it what to do internally, such as thinking about a concept or suppressing it. Trials are kept only when the copy is correct, reducing confounds from different output text. The measurement reads the residual stream. For each concept and layer, a concept direction is built by taking the residual at the last token of a prompt like “Tell me about {concept}” and subtracting the mean residual for unrelated words. During generation, token residuals are projected onto this direction. The benchmark uses raw projection rather than only cosine similarity, so changes in residual norm are also captured. Six measures define controllability: Engage, Suppress, Dial Rank, Temporal Control, Coverage, and Layer Targeting. Most use a signal-detection d′ effect size; Dial Rank uses Spearman correlation to test monotonic control over requested intensity.
