DeltaV: Thinking with Visual State Updates in Unified Large Multimodal Models

这篇工作要解决的问题是：统一大多模态模型在 interleaved multimodal reasoning 中，为什么引入中间视觉状态后仍然低效且不够好。作者认为瓶颈不在“模型会不会生成图像”，而在于现有方法把每一步视觉推理都当成一次完整图像生成。对于连续的推理轨迹，相邻视觉状态往往高度相似，真正推动推理的是少量关键变化。若每一步都重建整张图，训练信号会被大量不变内容稀释，计算也会被冗余视觉 token 吃掉。论文的核心问题因此是：能否把中间视觉状态建模成状态更新，而不是整图重生成，从而让统一模型更适合做多步视觉推理。

评多模态统一建模中用增量视觉更新替代全图生成的思路可复用在多步推理场景，重点看§3的TSIM路由器设计和StructCoT数据集构造细节。
Pengjie Wang,Linger Deng,Zujia Zhang,Shaojie Zhang,Zhenbo Luo,Pei Fu,Jian Luan,Xiang Bai,Yuliang Liu
