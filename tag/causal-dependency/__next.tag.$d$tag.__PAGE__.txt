9:T463,KPI (Key Path Identification) refines a standard SAE-steering pipeline. Starting from a set of ‘positive’ SAE features correlated with the target behavior (faithfulness), it builds an interaction graph among these features using a small development set. Nodes are candidate positive features; edges represent activation/causal dependencies across layers (and potentially within-layer interactions), motivated by the observation that a strongly steering feature often requires upstream features to activate it.
