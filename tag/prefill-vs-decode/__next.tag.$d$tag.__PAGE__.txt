9:T41b,The method is simple and well structured. The authors profile an API model over a grid of input and output token lengths, estimate and subtract network latency as much as possible, and fit generalized linear models to explain inference time. The resulting picture is intuitive: decode scales roughly linearly with generated tokens, while prefill requires both linear and quadratic terms in input length, matching the expected algorithmic behavior of attention-heavy inference.

For energy, the paper uses a local-equivalence strategy. Since API power cannot be measured directly, the same open-weight model is deployed locally under several hardware and software configurations. For each local setup, the authors fit a pair of GLMs: one for compute time and one for energy. They then compare the API time GLM to the local time GLMs, select the locally measured setup whose time behavior is most similar, and use its paired energy GLM as a grounded estimator of API energy.
