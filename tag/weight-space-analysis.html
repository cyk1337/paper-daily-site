WARP: Weight-Space Analysis for Recovering Training Data Portfolios

这篇论文研究如何只从 released weights 中恢复一个 fine-tuned model 的训练数据领域配比。它不是做单样本 membership inference，而是估计训练语料在不同 domain 上的全局 mixture，例如 web、code、science 或若干已知文本集合的采样比例。输入假设是有 base model、fine-tuned model，以及可从候选数据源中采样少量 probe examples。

评从权重空间反推训练数据配比的思路新颖，对分析闭源模型训练配方有实用价值，重点看模型插值生成伪检查点的设计。
