1a:T694,The method is DEPT, short for Document Embedding Preservation Tuning. The setup is a single decoder-only LLM that both generates expansion text and encodes expanded queries and candidate documents into a shared embedding space. Naive end-to-end contrastive learning updates all shared parameters and therefore changes generation behavior, query representations, and document representations at once. DEPT argues that only the query path should remain highly adaptable, while the document path should act as a stable retrieval target. To implement that, the method combines four pieces. First, a Document Embedding Preservation loss keeps current document embeddings close to cached embeddings from the initial model, reducing target drift. This makes it harder for the retrieval objective to improve by simply moving documents. Second, the method fits a fixed whitening transform on cached document embeddings, because raw LLM embeddings are often anisotropic and poorly suited for cosine retrieval. Training and retrieval then happen in this whitened coordinate system. Third, because document embeddings remain near the cached reference, the same cached index can be reused for online hard-negative mining during training and for index reuse at inference. Fourth, the paper uses straight-through expansion training so that retrieval supervision can influence the generated expansion despite the discrete generation step. Compared with prior work such as InPars, Promptagator, ExpandR, and UniRAG, the novelty is not merely using one model for both tasks, but directly optimizing expansion under the final retrieval loss while controlling the instability caused by shared parameters.1b:T539,Experiments cover two LLM backbones and five retrieval tasks. The main result is that DEPT achieves the best average retrieval quality among the compared query-expansion paradigms while preserving generation quality and compatibility with cached indexing. Several findings matter. First, naive end-to-end contrastive training does improve retrieval, but it hits a bottleneck because the same updates that help ranking also distort the fluent explanatory behavior that made LLM-based expansion useful. DEPT alleviates that by stabilizing the document side. Second, the long-expansion variant gives the best average retrieval performance, while a keyword-style short-expansion variant remains competitive under tight generation budgets. Third, whitening and preservation work together: without preservation, the fixed whitening space and cached index would drift out of sync more quickly; without whitening, the geometry of raw LLM embeddings hurts cosine retrieval. Fourth, the paper explicitly checks that generation ability is retained, which is important because retrieval-only optimization can otherwise collapse expansions into unreadable but embedding-friendly token sequences.
