18:T484,The benchmark contains 102 web pages across 16 vertical domains, covering two complementary task types: Macro-Level Regional Reconstruction, which requires agents to reconstruct a missing semantic region from visual reference and integrate it into the existing page structure; and Micro-Level Localized Modification, which requires agents to fix fine-grained structural and stylistic defects without disrupting unrelated content. A Reverse-Corruption Trajectory Engine is used to construct evaluation data: starting from a complete golden page, the engine iteratively injects deterministic structural and stylistic defects, then reverses the corruption sequence to produce a repair trajectory. The target state for each turn is uniquely defined, enabling reproducible multi-turn evaluation without costly turn-level human annotation. A dual-axis evaluation protocol is applied: a 5-dimensional VLM-based rubric measures target region fidelity for regional reconstruction tasks, while deterministic pixel-grounded alignment metrics are used for localized modification. Both evaluation streams explicitly measure content preservation outside the edit region.19:T5f3,The paper first builds Comp-11, a large-scale instruction dataset covering 11 professional composition patterns (rule of thirds, leading lines, centered composition, etc.) for both perception and generation training.

On the architecture side, it introduces Composition-specific Mixture-of-Experts (C-MoE): a dedicated set of MLP experts is instantiated on top of an existing MoE-based unified multimodal backbone, and only these new parameters are optimized during training, preserving the model's original general competence. A single learnable expert token τ_c is prepended to the model's response and supervised by a hard composition classification objective, so that it acts as an explicit intent anchor. On the perception side, τ_c activates the specialized experts and distills the inferred compositional intent into itself; on the generation side, the same τ_c is reused as a global conditioning signal that steers denoising / generation to match the reference layout.

To break content-composition entanglement without paired data, a self-supervised structural bottleneck is applied: reference images are pixelated and converted to grayscale to retain only global layout cues while suppressing semantic appearance. This is complemented by model-side mechanisms including a customized attention mask that prevents generation queries from over-attending to the perturbed reference image tokens, and cross-attention refinement for better text faithfulness, which together reduce content leakage from the reference.1a:T745,The benchmark has three main design components. First is a three-stage task construction pipeline. Stage 1 collects egocentric videos with explicit spatial and temporal cues, so the visual stream is not decorative but task-relevant. Stage 2 builds a tool library and a database that contains both visible information from the video and invisible but contextually necessary information outside the video. This creates an intentional information gap: the model cannot solve the task from perception alone and must query tools. Stage 3 designs tasks that require four ingredients to succeed: understanding entities, actions, or temporal cues in the video; retrieving hidden but relevant information through tools; performing logical reasoning; and updating database state through tool actions. This is stricter than standard VQA or tool-use benchmarks because success depends on environment state change, not only on a textual answer.

Second is the simulated user environment. Instead of a fixed script, the authors use an Actor-Evaluator-Summarizer setup. The Actor generates user responses, the Evaluator checks them against four binary criteria for naturalness and task alignment, and the Summarizer maintains interaction state for subsequent turns. The benchmark supports three interaction modes: Dynamic Easy, Dynamic Hard, and Static, allowing evaluation under different levels of interaction complexity.

Third is the evaluation protocol. EgoBench uses joint validation: process-level tool-call coverage plus result-level database state equivalence. Because tasks are designed to require both tool invocation and state modification, this deterministic protocol avoids the ambiguity of judging free-form text outputs. For agent benchmarking, this is a strong design choice: it makes failures easier to localize and supports automated large-scale evaluation.1b:T424,EgoBench contains 1,045 tasks across four daily scenarios: dining, kitchen operations, food ordering, and retail. The authors benchmark eight video-MLLMs. The best model achieves only 20.19%, 16.75%, and 21.34% average success across the three interaction modes, aggregated over the four scenarios. Even in retail, the strongest scenario for the top model, the average success rate is only 30.62%.

The error analysis is one of the more useful parts. Failures are decomposed into five categories: multimodal perceptual misinterpretation, hallucination, structural non-compliance, logical fallacies, and risky operations. That breakdown matters more than the headline score because it helps separate perception failures from action-format failures and reasoning failures. The excerpt provided does not include the full per-model tables, but the setup strongly suggests that structural non-compliance and perceptual grounding errors are major bottlenecks: once a tool call is malformed or a visual reference is misread, the whole multi-step trajectory collapses.1c:T434,This is a skim paper. Start with the introduction and make sure the benchmark’s three-way coupling is clear: egocentric perception, tool use, and dynamic interaction. Then read the task construction section carefully, especially the three-stage pipeline, to judge whether shortcut solutions are truly blocked. After that, inspect the Actor-Evaluator-Summarizer user simulator and the four binary criteria used to constrain user responses. Then read the joint validation section to understand how tool-call coverage and database-state equivalence are combined. Finish with the main results and the error taxonomy.

If time is limited, 20–30 minutes is enough: Figure 1, the task-generation section, the evaluation protocol, the main results table, and the error analysis are the key pieces. The two deeper questions worth thinking about are whether this deterministic evaluation style can scale to more open-ended agent settings, and how the benchmark’s explicit split between visible video information and external database information shapes the observed failure modes.1d:T6d9,The main contribution is DistractionBench. The benchmark is built around controlled temporal distractions: insert an unrelated short clip, often an advertisement, into a main video, or concatenate multiple action segments, then ask whether a subject from the main video participated in an event that only occurred in the distracting segment.

There are four subtasks. InjectedAds pairs a long video with an ad clip to mimic inserted commercials. Concat-Easy concatenates two UCF101 clips to control length and position. Concat-Hard concatenates five clips to increase event mixing difficulty. NaturalAds uses real YouTube videos with sponsored segments and manually written questions, providing a more realistic gold-standard setting.

Each video comes with three question types. BoE questions combine a subject from the main content with an object or event appearing only in the distracting segment, directly probing cross-segment misbinding. Yes-bias questions combine the same subject with an object absent from the entire video, controlling for a generic tendency to answer “Yes.” No-bias questions ask about facts that truly occur in the video, controlling for poor understanding or excessive denial. This design is important because it separates bag-of-events errors from generic hallucination and response bias.

Evaluation is based on whether the model output contains “Yes” or “No,” following prior hallucination benchmarks. The metric is simple and somewhat coarse, but it supports large-scale comparison. The paper also studies distraction position and frame sampling budget, which helps distinguish failures caused by missing frames from failures caused by weak temporal/entity binding even when the relevant content is observed.1e:T583,The benchmark evaluates 11 VideoLLMs, including Aria 23.9B, LLaVA-Video 7B, LLaVA-OneVision 0.5B and 7B, Molmo2 4B and 8B, Qwen3VL 8B, Qwen3.5 9B, Gemma4 31B, Phi4-Multimodal, and InternVL3.5 8B. Models support between 8 and 256 frames. Uniform sampling is used by default, and for low-frame models the setup ensures that at least 25% of sampled frames come from the advertisement segment so the distraction is not accidentally missed.

Dataset sizes are moderate but meaningful: InjectedAds has 256 videos and 768 QA pairs; Concat-Easy and Concat-Hard each have 450 videos and 2,700 QA pairs; NaturalAds has 150 videos and 450 QA pairs. The paper argues that the benchmark is longer and larger than prior video hallucination QA sets.

The central empirical result is that BoE hallucination rates are consistently much higher than Yes-bias rates across all subtasks and model families. That matters because it shows the effect is not just a generic affirmative bias. The paper also studies two additional factors: where the distraction is placed and how many frames are sampled. The likely pattern, consistent with the paper’s framing, is that more frames help somewhat but do not eliminate the issue, while more complex or strategically placed distractions worsen cross-segment mixing. This supports the claim that the problem is not only coverage, but also weak temporal grounding and subject-event binding.1f:T437,The method applies conformal prediction to VLM judges. Instead of using only the predicted score, it extracts the log-probabilities over all rating tokens at the scoring position and uses that K-dimensional distribution as the feature representation. A conformal calibration procedure then turns the point prediction into a prediction interval with target coverage guarantees. Because the labels are discrete Likert scores, the paper applies boundary adjustment to map continuous intervals back to valid integer score ranges.
