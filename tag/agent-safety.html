StepJack: Benchmarking Computer-Use Agent Safety Against Multi-Step Indirect Prompt Injection

这项工作评测 computer-use agent 在更隐蔽的间接提示注入下是否仍能拒绝有害目标。已有 CUA 安全评测通常把完整攻击指令放在一个网页或文档里，模型只要识别出单点恶意 payload 就可能拒绝。StepJack 关注的是另一类威胁：攻击目标被拆成多个看似无害的子步骤，并沿着 agent 的浏览路径分散在多个页面中。

评这不是 pretrain 论文，但评测设定很干净：它说明 agent 安全 prior 建在单步攻击上过于乐观；读攻击生成流程和主表即可，足够指导内部 red-team 设计。
Zhuoxin Zhan,Akbar Rafiey,Avery Ma,Leila Pishdad,Layla El Asri
