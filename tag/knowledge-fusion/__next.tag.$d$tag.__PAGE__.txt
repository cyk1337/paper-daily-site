9:T425,DFM adds two components to a frozen LLM: a causal chunk-level memory predictor and memory cross-attention modules inserted into selected decoder layers. Training sequences are divided into non-overlapping chunks. For a target chunk, the previous chunk is encoded and used to retrieve top-K neighboring chunks from a corpus datastore. A frozen text encoder converts those retrieved chunks into dense embeddings, ordered by retrieval rank, forming the target memory matrix. During training, the predictor generates memory slots from prior context, and the same predicted memory is shared by all token predictions within the chunk. The fusion module uses cross-attention to inject the predicted memory into hidden states. The added modules are trained jointly with a language-modeling loss and a memory-prediction loss, while the backbone remains frozen.
