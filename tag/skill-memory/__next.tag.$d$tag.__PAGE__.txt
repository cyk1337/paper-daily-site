b:T4d0,SESA (Self-Evolving Skill-Augmented Agent) integrates tool-augmented search self-play with an evolving skill memory.
- Two policies: a challenger/proposer generates problems with verifiable targets; a solver uses a search tool to answer. Parameters are separated.
- Skill memory B: a bounded, non-parametric bank of human-readable skills. Each entry stores a description, trigger conditions, avoidance cues (common confusions/anti-patterns), reusable query templates, and usage statistics (retrieval/helpful/hurt counts) for maintenance.
- Asymmetric access: only the solver can retrieve skills; the challenger cannot, preventing strategy leakage that would collapse the self-play game.
- Four-stage loop: (1) memory priming with a small initial set; (2) asymmetric self-play where retrieval is active during training rollouts; (3) frontier shaping to keep generated problems near the solver’s competence boundary; (4) failure distillation that converts informative failed rollouts into deduplicated skills written back to memory.
