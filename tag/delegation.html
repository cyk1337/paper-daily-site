Knowing When to Ask for Help: Bayesian Self-Escalation in Hierarchical LLM Agents

这篇工作讨论的不是常见的“先路由再生成”或“生成完再校验”，而是更细的一层：小模型在推理进行到一半时，能否根据自己已经暴露出的失败迹象，及时把任务交给更强模型。核心问题有两个。第一，如何把“是否该中途升级”写成一个可计算、可学习、可分析的决策问题，而不是靠经验阈值或原始熵拍脑袋。第二，什么信号才真正决定这种机制是否有效。作者给出的答案是：关键不在原始不确定性指标，而在一个在线更新、经过标注轨迹学习和校准的 competence posterior，也就是“当前这条轨迹最终会不会做对”的后验概率估计。整篇文章围绕这个后验展开，把中途升级 formalize 成 Bayesian optimal stopping。

评把“生成中升级”讲成可证明的最优停止问题是亮点；先看理论假设是否贴近LLM轨迹、再看实证是否真比熵阈值稳。
Nadeem Shaikh

WebRider: Persona-Conditioned Intent Controllers for Live-Web Assistance

这篇工作处理的不是“网页任务能否做完”，而是“代理是否沿着用户委托的方式把任务做完”。作者指出，现有 live-web agent 评测几乎都只看最终答案或任务完成率，忽略了执行过程中的策略约束：要核验哪些证据、遇到不确定性时是否该追问、哪些偏好必须进入排序、什么时候应该停止而不是继续猜。问题的难点在于，这类委托策略不是静态标签，而是会贯穿浏览、点击、检索、澄清、停止、回答整个闭环；而且 live web 页面持续变化，最终答案即便看起来合理，也可能是在违反用户 policy 的情况下得到的。作者把这类可审计的委托策略形式化为 intent contract，并把核心问题定义为：如何在动态网页环境中，让 agent 在每一步都保持对 contract 的忠实执行，而不是只在终点上“看起来答对了”。

评读 abstract 的 99.2/38.8 缺口和 intent contract 设计即可；它会影响 agent reward 怎么写。
Zhi Li,Tao Zhou,Yeqing Li,Eugene Ie,Demetri Terzopoulos

Capability Self-Assessment: Teaching LLMs to Know Their Limits

现代 LLM 系统性地高估自身能力——即使在它们无法可靠解决的问题上，模型也倾向于选择回答而非放弃。这种能力自我评估（Capability Self-Assessment, CSA）的缺失导致过度生成幻觉和计算浪费。现有校准/置信度估计工作不把自我评估视为独立的能力学习问题，而指令微调/拒答工作常把行为混入特定任务。

评值得扫实验设计，尤其 RL vs SFT 的能力保持；若结果稳，内部路由和拒答训练应加入 CSA ablation。

Recursive Agent Optimization

LLMs Corrupt Your Documents When You Delegate

这篇工作要回答的不是“模型能不能完成一次编辑任务”，而是“当用户把一段较长、较专业、需要多轮修改的文档工作委托给 LLM 时，模型能否在长链条操作里保持文档完整性，不持续引入细小但累积的破坏”。作者把问题定义为 delegated work 下的 document fidelity：模型既要执行编辑指令，又不能在未被要求的地方删改、漂移、格式损坏或语义失真。难点在于，这类任务很难做大规模自动评测，因为多数专业文档没有标准参考答案，且真正风险来自多轮交互后的误差累积，而不是单轮成功率。

评把“长程编辑会越改越坏”做成可复现实验，适合拿来做内部 agent/编辑器回归测试；重点看指标定义是否把“必要改写”误算成腐化。
Philippe Laban,Tobias Schnabel,Jennifer Neville
