RubricRM: Generative Reward Modeling via Dynamic Rubrics for Image Generation and Editing

这篇工作解决的是视觉生成对齐里的 reward model 设计问题：现有图像生成/编辑 reward model 大多输出单一标量，或者使用固定评价维度，导致两个问题同时存在——一是解释性弱，二是对不同指令的任务敏感性不够。现实里，不同 prompt 或编辑指令需要的评价标准并不一样。写实 prompt 更看重物理合理性，创意 prompt 更看重新颖性，编辑任务还要额外考虑保真与局部修改一致性。RubricRM 试图把“评价标准本身”也变成模型输出的一部分，先为当前输入动态生成 rubric，再按 rubric 对候选图像做分维度打分和偏好判断。

评将 LLM 评测中常用的 Rubric 概念引入视觉 Reward Model，并结合 GRPO 进行训练，对多模态对齐和细粒度 Reward 建模有一定参考价值。
Zijian Kan,Wei Wang,Long Luo,Bing Zhao,Xuan Ren,Weixu Qiao,Wenbo Li,Hu Wei,Lin Qu
