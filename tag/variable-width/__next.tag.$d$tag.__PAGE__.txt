9:T404,The proposed Variable-Width Transformer changes the model dimension by layer. The best-performing profile is ×-shaped: wide at the bottom, narrow in the middle, and wide again near the top. The implementation detail that matters is the residual stream. Instead of inserting learned projections between layers, the model keeps a fixed global residual dimension equal to the widest layer. Each block reads from and writes to a layer-specific slice of this residual stream. When a layer is narrower, unused coordinates bypass the block. When a later layer expands, those coordinates are restored from the most recent layer that actively processed them; if no such value exists, the coordinate is zero-padded. This parameter-free resizing avoids projection bottlenecks and keeps the skip path closer to a standard residual stream.
