1b:T4df,The method, Block-GTQ, is built on TurboQuant-MSE but replaces uniform per-head bit allocation with integer bit allocation over RoPE 2D blocks inside each layer and KV head. The starting point is the RoPE attention logit q^T R_Δ k, which decomposes into a sum of 2×2 rotated block terms. This makes key-cache quantization naturally block-sensitive: quantization error in different blocks perturbs future logits by different amounts. The paper defines a label-free block energy score from Q/K activation statistics to estimate how important each block is for future query-key interactions. It then combines this score with the TQ-MSE empirical error law, where squared error scales roughly as 4^{-b}, to compute the marginal gain of assigning one more bit to a block. Under a fixed average-bit budget, bits are allocated greedily as integers. Blocks with the same assigned width are then encoded using the original TQ-MSE local quantizer, so the implementation remains lightweight. Values are still quantized with uniform TQ-MSE because V does not enter the RoPE key-logit computation. The paper also implements a packed-cache serving path so the compressed K/V codes are used in an actual inference pipeline rather than only in offline analysis.1c:T57c,The evaluation has three layers. First, mechanism validation: on a ten-model diagnostic panel, Block-GTQ is compared against uniform TQ-MSE at matched K-only budgets. At both 2 and 3 bits per dimension, it reduces per-layer RoPE-logit MAE by 32% to 80%, and wins all 367/367 layer comparisons at each budget. This indicates a broad structural improvement rather than gains from a few favorable layers.
