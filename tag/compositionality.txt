1) 子集干预（subset intervention）定义
- 对每个输入 x，在某层某 token 位置取激活 h_x。
- SAE 给出 top-K 活跃特征集合 N_x，以及每个特征的解码贡献 δ_i(x)=z_i(x)d_i（文中用 D_x 作为 K 个贡献列向量的矩阵）。
- 构造一个“固定底座”激活 h_x^0 = h_x - Σ_{i∈N_x} δ_i(x)，它包含未选特征贡献 + 重构残差等所有固定内容。
- 对任意子集 S⊆N_x，构造干预激活 ~h_x(S)=h_x^0 + Σ_{i∈S} δ_i(x)。这样 S=N_x 时恢复原激活，S=∅ 时只保留底座。
- 选一个标量行为读出 ψ（例如某类输出概率、某个评分器输出、某个行为指标），定义 set function g_x(S)=ψ(F(~h_x(S)))。

2) 低阶可加近似与 SAE Additivity Residuals（SAR）
- 用“至多 r 阶交互”的函数类 𝒜_r(N) 去近似 g_x(S)：r=1 只允许单特征效应相加；r=2 允许加入 pairwise 项；更高阶同理。
- 在子集分布 μ 下做 L2 投影 Π_r g_x，定义 SAR_r 为归一化后的剩余能量：直观上就是“用 r 阶模型解释不了的行为方差占比”。

1) Subset intervention as a set-function
- For input x, take an activation h_x at a fixed layer/token.
- Select top-K active SAE features N_x with decoded contributions δ_i(x)=z_i(x)d_i.
- Define a fixed remainder h_x^0 = h_x - Σ_{i∈N_x} δ_i(x), which keeps everything else constant (unselected content + reconstruction residual).
- For any subset S⊆N_x, intervene with ~h_x(S)=h_x^0 + Σ_{i∈S} δ_i(x).
- For a scalar behavioral readout ψ, define g_x(S)=ψ(F(~h_x(S))). This isolates behavioral changes attributable to the retained selected contributions.

2) SAE Additivity Residuals (SAR)
- Approximate g_x using function classes that include interactions up to order r: r=1 (additive main effects), r=2 (additive + pairwise terms), etc.
- Under a subset distribution μ, take the L2(μ) projection Π_r g_x and define SAR_r as the normalized residual energy (variance not explained by order ≤r).
- Define Δ_2 = SAR_1 − SAR_2 and ρ_2 = Δ_2 / SAR_1 to quantify how much of the first-order residual is recovered by pairwise structure.

3) Why independent subset sampling matters
- With independent inclusion of each feature (a product measure μ), SAR admits an exact interaction decomposition: SAR_r equals the normalized energy of interactions above order r. This gives SAR a clean statistical meaning rather than a heuristic score.

4) Coordinate choice vs subspace: sum-preserving random rotations
- Construct orthogonal Q with Q·1=1 and rotate the K contribution vectors: D'_x = D_x Q.
- This preserves the selected subspace span(D_x) and the total contribution (sum of columns), keeping the downstream network and fixed remainder unchanged.
- Compare SAR and ordering metrics between learned SAE coordinates and these matched rotations to isolate the effect of coordinate system.
