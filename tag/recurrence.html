T^2MLR: Transformer with Temporal Middle-Layer Recurrence

这篇工作要解决的不是“让 Transformer 多想几步”这么泛的问题，而是一个更具体的架构瓶颈：标准自回归解码把每一步的高维中间计算都压回 token 空间，再由下一个 token 重新展开，导致跨时间持续存在的潜在推理状态很难保留。已有 latent reasoning 方法通常把递归信号放在输入嵌入或最终层附近，离真正承载抽象推理的中间层较远；另一类 depth looping 方法虽然能增加单 token 计算，但推理成本会随循环次数上升。T^2MLR 的目标是把“跨 token 持续的连续推理状态”直接安放在中间层，并且尽量不破坏标准 teacher-forcing 预训练和低开销推理。

评这篇会直接动摇“AR 推理状态只能靠 token 传递”的 prior，先看 recurrence 插入位置和 retrofit 实验；若结果稳，内部应立刻做中层状态通路 ablation。
Ziyang Cai,Xingyu Zhu,Yihe Dong,Yinghui He,Sanjeev Arora

KV-Fold: One-Step KV-Cache Recurrence for Long-Context Inference

这篇工作讨论的是一个很具体的推理问题：不改模型、不再训练，能不能把标准 decoder-only Transformer 的 KV cache 直接当作跨 chunk 的递归状态，用分块方式处理超长上下文，同时尽量保留对早期 token 的精确访问能力。它针对的是现有长上下文方案里的一个老矛盾：全量注意力在超长序列上算不动，流式窗口和压缩缓存又会丢信息，尤其不适合需要精确回忆远距离细节的场景。

评一种极其简洁的免训练长上下文扩展方法，核心看点是其证明了这种简单的 KV-Cache 累加在深层循环中不会崩溃（drift 饱和），对长文本推理系统设计有启发。
Alireza Nadali,Patrick Cooper,Ashutosh Trivedi,Alvaro Velasquez
