18:T930,方法由三个互相配合的组件组成，核心思想是同时重做 support 设计、拟合目标和构建路径，但不改变在线接口仍为闭式仿射映射。

第一部分是 Head-Local。Full-Head Mapping 的做法是：对每个目标层、目标 KV 头，从选定源层的所有源 KV 头拼接后做回归。作者认为这隐含了一个过强假设，即不同模型之间头的对应关系是全局稠密的。CacheBridge 改成 architecture-indexed 的局部支持：每个目标头只从一个源头块接收输入，但仍允许跨层聚合。这样做的直接效果是把每个目标头的 fan-in 从“所有源头”缩到“一个局部块”，系数数量按源头数成倍下降，文中是 8× 缩减。更重要的是，这个约束把映射偏置到更符合架构对应关系的子空间，减少了在架构差异较大时的错误耦合。

第二部分是 Attn-Repair。作者指出，传统 held-out R² 只衡量 cache 坐标重建，而生成质量取决于这些误差经过目标模型 query 与 attention 组合后的放大或抵消。因此相同的 KV 拟合误差，可能对应完全不同的续写漂移。Attn-Repair 的做法是按残差对接收模型 attention 输出的一阶影响来重加权，相当于让拟合更关注那些会真正改变后续注意力计算的方向，而不是平均对待所有 cache 坐标。为了避免权重过度集中到极少数样本，作者加入 effective-sample-size floor 来限制退化，但不改变在线映射形式。

第三部分是 Fused-Fit。由于不同目标层会选择不同源层支持，top-k layer 选择会造成碎片化 gather，通用拟合器在构建加权充分统计量时会反复做 scattered materialization、centering 和 weighting，内存流量很大。Fused-Fit 用新的 fused GPU kernel 在有界 panel 内直接构建 head-batched 矩阵乘法所需统计量，保持同样的 ridge solver 和同样的最终 mapper artifact，只是把离线构建过程做成结构感知的高效实现。这个部分没有改变数学目标，但大幅改善了 mapper construction 的时间和内存行为。

整体上，CacheBridge 不是提出新的在线推理协议，而是在“离线拟合、在线仿射应用”这个框架内，把支持结构、目标函数和实现路径都改得更贴近真实 continuation quality。19:T9b6,CacheBridge combines three components and keeps the online deployment interface unchanged: an offline-fitted affine mapper that can be applied directly at handoff time.

The first component is Head-Local. Full-Head Mapping regresses each target KV head on the concatenation of all source KV heads from selected source layers. CacheBridge argues that this assumes an overly dense correspondence between models. Instead, each target head is restricted to a single architecture-indexed source-head block, while still allowing cross-layer aggregation. This reduces fan-in dramatically and cuts the coefficient count by the number of source heads, 8× in the reported setup. More importantly, it biases the mapping toward a subspace that better matches architectural locality, reducing harmful cross-head coupling when the source and target architectures differ.

The second component is Attn-Repair. The paper points out that held-out R² only measures coordinate-wise cache reconstruction, while continuation quality depends on how those errors propagate through the target model’s queries and attention computation. Two mappings with similar cache fit can therefore produce very different continuation drift. Attn-Repair reweights residuals according to their first-order effect on the receiver’s attention output. In other words, it emphasizes errors that actually matter for downstream attention behavior rather than treating all cache coordinates equally. An effective-sample-size floor prevents the weighting from collapsing onto a tiny subset of examples, while preserving the same online affine form.

The third component is Fused-Fit. Because different target layers may choose different source-layer supports, top-k support selection creates fragmented gather patterns. A generic fitter repeatedly materializes scattered tensors, centers them, and applies weights, so memory traffic becomes a major cost. Fused-Fit introduces a fused GPU kernel that constructs the weighted sufficient statistics directly in bounded panels for head-batched matrix multiplication. It does not change the ridge objective, the solver, or the deployed mapper artifact; it simply makes offline construction structure-aware and much more efficient.

Taken together, CacheBridge does not propose a new online protocol. It refines the existing offline-fit / online-affine-transfer framework by redesigning support structure, fitting objective, and construction path around actual continuation quality.1a:T70b,The evaluation covers three transfer directions, with two difficult Ministral 3 directions and one Qwen3 direction being the most informative. The paper first uses Full-Head Mapping to expose model sensitivity. Under the same 500-sequence calibration protocol and the same 8×128 KV interface, transfer to Qwen3 32B remains close to the target baseline, 79.2% versus 80.2%. But the two Ministral 3 directions targeting 14B drop sharply to 52.2% and 44.4%. This shows that the existence of a linear transfer path does not mean dense all-head mapping is the right inductive bias.
