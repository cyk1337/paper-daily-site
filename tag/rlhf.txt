18:T711,The method is simple, but the framing is sharp. In standard multi-reward GRPO, the total reward is the sum of reward components, and the advantage is computed by centering and dividing by the within-group standard deviation of that total reward. The paper expands this variance term into the sum of all pairwise covariances among reward components. This reveals the issue: covariance mixes two effects, dependence and scale. If one reward has large variance, or if large-scale rewards are strongly positively correlated with others, they can inflate the denominator and shrink the advantage for the whole group.

CorrGRPO keeps the numerator unchanged: it still uses the centered total reward, so the relative weighting of reward components in the objective is preserved. The change is only in the denominator. Instead of covariance-based normalization, it uses Pearson-correlation-based normalization. In effect, each covariance term is divided by the corresponding component standard deviations, removing scale dependence. The diagonal terms of the resulting correlation matrix give equal footing to all reward components with nonzero within-group variance, while off-diagonal terms capture only the strength and direction of dependence. This lets the normalization remain sensitive to whether rewards reinforce or conflict with each other, without letting large numerical scales dominate.

An important practical point is that CorrGRPO does not redefine reward aggregation and does not require a new critic. It only changes advantage scaling, so it can be inserted into existing GRPO pipelines with low implementation cost. It is also conceptually different from manual reward reweighting or simple reward rescaling, because it modifies the normalization statistics rather than the reward objective itself.19:T526,The experiments cover three naturally multi-reward domains: code generation, tool calling, and agent security, using models from 0.5B to 8B parameters. The paper compares CorrGRPO against standard GRPO and related variants, and reports improvements in code accuracy and training efficiency, tool-call accuracy, and the utility–security tradeoff for agents. It also claims an expansion of the empirical Pareto frontier between competing reward objectives.

The most important empirical story is not a single benchmark number. First, in heterogeneous-reward settings, CorrGRPO is more robust because small-scale rewards are no longer drowned out by the covariance structure of large-scale rewards. Second, in tradeoff-heavy settings such as agent security, correlation-based normalization better preserves the distinction between conflicting rewards, which improves the balance between task utility and safety. Third, in code and tool-use tasks where rewards are partly positively correlated, standard GRPO can over-shrink updates when large-scale rewards dominate the denominator, while CorrGRPO avoids that failure mode. 第一部分是 SFT。作者把它当成 capability-building stage，而不是格式对齐。SFT 的作用有两个：一是建立广泛能力下限，二是统一输出格式，尤其是 native <think> chat format 和多轮交互模板。这里隐含的判断是，如果 SFT 没把能力面铺开，后续 RL 只能在狭窄分布上做局部修补，容易出现 reward overfitting。

第二部分是多阶段 RL。Reasoning RL 和 Coding RL 先做，因为奖励最硬，分别依赖可验证答案或执行/测试信号，属于 RLVR。Instruction-Following RL 虽然用了 rubric-based judge，但被放在 agent 阶段之前，因为作者观察到 instruction following 离模型原有聊天能力更近，judge 可被利用的空间较小。General/Coding/Search Agent 三个阶段再把工具使用、环境交互和长轨迹决策加进来。最后才做 RLHF，用偏好型软奖励去修整开放式质量。

第三部分是 difficulty filtering。作者反复强调，训练样本要落在“可学但未掌握”的区间：已经会做的 prompt 要丢掉，大多数阶段里始终不会做的 prompt 也丢掉。这样做不是简单提纯数据，而是在 on-policy RL 中构造自动 curriculum，避免梯度浪费在零优势样本或纯噪声样本上。相比只按题目元数据分桶，这种基于当前策略表现的过滤更贴近真实学习边界。

第四部分是基础设施设计。作者明确指出，多轮 agent RL 需要 token-in/token-out rollouts，也就是把模型生成和环境返回都作为在线轨迹的一部分，而不是离线拼接。为了稳定 RL，他们使用大 batch 和 Rollout Routing Replay；后者的作用是缓解长轨迹、多环境、异步 rollout 带来的分布抖动。另一个关键点是从 SFT 到 agent 阶段保持 chat template 一致，避免模板漂移把能力变化和格式变化混在一起。对于 coding/search agent，还需要长时间稳定运行的 sandbox/service，否则 reward 噪声会直接污染策略更新。

和常见做法相比，这篇工作的区别不在单个算法，而在把“为什么先做这个、后做那个”讲得很具体。很多工作把 IF、agent、RLHF 混在一起做多目标优化；这里则明确按 reward 可验证性和被攻击风险排序。很多工作也做 hard example mining，但这里是按当前 policy 的成功带宽做动态过滤，更接近 RL 里的 learnability control。1c:T927,The central design is a serial pipeline with explicit stage responsibilities, reward-hardness ordering, and difficulty filtering. The full sequence is SFT → Reasoning RL → Coding RL → Instruction-Following RL → General Agent → Coding Agent → Search Agent → RLHF, all applied to the same GLM-4.5-Air-Base checkpoint (106B total, 12B active MoE).

SFT is treated as the capability foundation. Its role is not only to align output style, but to establish broad competence and normalize the model’s interaction format, including the native <think> template and multi-turn chat behavior. The implicit claim is that if SFT does not already cover the capability surface, later RL will overfit narrow reward channels rather than build robust skills.

The RL stages are ordered by reward reliability. Reasoning RL and Coding RL come first because they rely on hard verification signals such as exact answers, execution, or tests. Instruction-Following RL uses a rubric-based judge, but it is still placed before the agent stages because instruction following is close to the model’s native chat behavior and therefore less exposed to severe reward gaming. General Agent, Coding Agent, and Search Agent then introduce tool use and environment interaction. RLHF is deliberately last, since open-ended preference rewards are the easiest to exploit.

A key mechanism is difficulty filtering. The training prompts are restricted to a productive band: prompts the current policy already solves are removed, and in most stages prompts it never solves are also removed. This turns on-policy RL into an automatic curriculum over learnable examples. Compared with static hard-example mining, the filter is policy-dependent and tracks the current learning frontier.

The infrastructure section is unusually important. The authors use token-in/token-out rollouts for multi-turn on-policy RL, large batches for stability, and Rollout Routing Replay to reduce variance and distributional jitter from long trajectories and asynchronous environments. They also emphasize strict chat-template consistency from SFT through agent stages, plus reliable sandbox services for long coding and search episodes. The paper’s novelty is less about a new optimizer or reward formula, and more about making the sequencing logic and systems constraints explicit.1d:T5b0,The most useful experimental contribution is the stagewise analysis rather than the final leaderboard. The final Rufus-Air model outperforms the official GLM-4.5-Air release on every reported benchmark except Arena-Hard v2 Creative Writing, and is competitive with similarly sized open models such as INTELLECT-3 and Nemotron-3-Super. It leads on instruction-following and most alignment and agentic rows, ties Nemotron-3-Super on Terminal-Bench 2.1, trails on a few Tau2 domain rows, and is weaker on creative writing.

More importantly, each stage is evaluated against the checkpoint it starts from, not only against the final model. That design is critical in multi-stage post-training because later stages overwrite the same parameters. Without stagewise comparisons, it is hard to tell whether a gain comes from the intended stage or from accidental carryover.

At each step the model emits a token and may receive an environment observation; the terminal reward is a function of the complete trajectory. The conditional reward prediction is defined as V_i = E[R | F_i]. The paper then imposes three regularity conditions on token credit: Completeness, which requires total credit to explain the deviation of the final reward from its initial prediction; Prefix Consistency, which prevents future tokens from rewriting the accumulated credit of an already generated prefix; and Neutrality, which requires no systematic over- or under-crediting from the current information state. These conditions yield a unique representation, essentially the martingale difference V_i - V_{i-1}. The same construction can be aggregated to coarser units such as turns. The paper uses this representation to reinterpret OPD, RLOO, and GAE-style actor-critic methods. Under an ideal teacher, OPD is equivalent in expectation, up to scale, to the policy-gradient update induced by the unique credit. RLOO uses a response-level signal, but its expected policy-gradient contribution matches that of the token-level credit. Under bounded rewards, token-level credit is approximately sparse, which helps explain the sensitivity of GAE-based actor-critic methods in long trajectories. The proposed algorithm, PACT, uses an Actor-then-Critic update order so that critic training can apply importance sampling correction toward the updated policy. It also trains the critic with BCE rather than MSE, which is better matched to binary or bounded outcome rewards.20:T5c5,The method starts from a unified gradient view. For a group of responses under the same prompt, positive weights increase the likelihood of preferred responses, negative weights suppress dispreferred ones, and magnitudes determine update strength. GVPO uses the analytical solution of KL-constrained reward maximization to design these weights. The obstacle is the partition function in the closed-form solution, which would require an intractable expectation over all possible responses. The key condition is that if the assigned weights within a prompt group sum to zero, the partition function cancels across compared responses. GVPO then defines the response weight as the difference between two centered distances: one from implicit rewards induced by the current and reference policies, and one from actual rewards. The authors provide two interpretations. First, the GVPO gradient matches the gradient of a mean-squared-error objective between implicit-reward and actual-reward centered distances. Second, the loss can be decomposed into a group-relative advantage term, a covariance term between current and reference policies that constrains excessive policy drift, and a current-policy variance term that encourages moderate entropy. Compared with GRPO, it avoids uncontrolled importance-sampling ratios. Compared with DPO, it claims a unique optimum aligned with the KL-constrained reward-maximization solution, without relying on the Bradley-Terry preference model.21:T595,The authors use Monte Carlo continuations as a diagnostic estimate of intermediate state values.
