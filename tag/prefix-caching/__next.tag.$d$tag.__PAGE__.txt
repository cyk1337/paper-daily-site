b:T532,The central proposal is an agent runtime layer inserted between the framework and the engine. This layer owns the cross-cutting metadata neither neighbor has on its own. It exposes four policy-agnostic primitives: observe, to ingest events from either side; score, to return priorities for ranking decisions; predict, to forecast future agent activity; and act, to trigger off-critical-path side effects such as prefetching or warming. The paper frames these as an observe→score→predict→act loop, with agent identity as the shared key.

The main instantiation is CacheSage for KV caching. The idea is that multi-agent workloads often reuse a recurring system-plus-tools prefix across sessions, but reactive caches evict those blocks before the next relevant session arrives. CacheSage learns an online first-order Markov transition matrix over agents within a workload. That model is used in two ways: for score, it estimates survival probability to guide eviction; for predict plus act, it triggers cross-session prefetch when a future agent call is likely. The design keeps state bounded, at no more than 20 KB per workload, and falls back gracefully to LRU when the learned signal is weak.
