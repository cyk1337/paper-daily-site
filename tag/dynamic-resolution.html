AViTS: Adaptive Spatiotemporal Token Selection for Efficient Dynamic-Resolution Generation

这篇工作处理的是动态分辨率 DiT 推理里的一个具体瓶颈：从低分辨率阶段切到高分辨率阶段时，是否有必要把所有 latent token 一起上采样并进入高分辨率计算。作者的判断是否定的。全文给出的证据是，低分辨率去噪过程中 token 重要性在空间和时间两个维度都高度不均匀：一部分 token 与文本条件强相关，另一部分 token 在跨步演化中变化更剧烈、对后续更新更敏感。若仍然统一上采样全部 token，会把算力浪费在语义边缘区域和已趋于稳定的区域上，同时还可能在阶段切换时引入细节不一致。论文要解决的核心问题，就是在有限高分辨率预算下，如何更可靠地识别“应该优先升采样”的 token，并把高分辨率计算集中到这些位置。

评读方法动机即可：token级预算分配比统一上采样更合理，但这是DiT推理工程，不要误读成通用LM训练结论。

TuringViT: Making SOTA Vision Transformers Accessible to All

这篇工作要解决的是一个很现实的问题：很多 VLM 和 VLA 系统都依赖现成的强视觉编码器，但真正想为自己的场景训练一个高水平、可动态分辨率、还能处理视频的 ViT，门槛仍然很高。难点不只在模型结构，也在数据和训练流程。标准 softmax attention 在高分辨率和长视觉序列下成本过高；公开可复现的数据清洗 recipe 不够成熟；而固定分辨率预训练再做后续适配，又会带来预训练-下游使用方式不一致的问题。TuringViT试图把这三件事一起解决：更省的注意力、更高质量的数据整理、以及原生动态分辨率预训练。

评这篇别当普通ViT论文看，重点是“原生动态分辨率预训练”这件事；先看 encoder recipe 和 data curation，若实验干净，值得搬到自家VLM栈里复现。

video-SALMONN-R$^3$: Learning to ReWatch, ReAsk, and ReAnswer for Efficient Video Understanding

这篇工作解决的是视频大模型在算力受限下如何获得“先粗看、再回看”的能力，而且不依赖昂贵的 CoT 冷启动标注。更具体地说，现有视频 LLM 往往只能低帧率、低分辨率地看完整视频，因此容易错过关键细节；两阶段 re-watch 是合理方向，但已有方法要么拆成多个模型，信息传递损失大、开销高，要么依赖带动作轨迹的 CoT SFT，数据成本高，而且会破坏原有视频理解能力。论文想做的是：从一个已经 instruction-tuned 的视频 LLM 出发，直接用 RL 学会 temporal localization 和二次观看，再把这项新能力接到原模型已有的答题能力上，而不是用大量 CoT 监督重塑整个行为模式。

评将 RL 引入多模态长视频理解的端到端训练，无需 CoT 数据即可实现 dynamic resolution/frame rate，对 VLM post-training 很有启发，值得关注其 RL setup 和 reward 设计。
