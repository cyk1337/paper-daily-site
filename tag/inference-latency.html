Memory-Bound but Not Bandwidth-Limited: The Physical AI Inference Gap in Batch-1 LLM Decode

这篇工作要回答的不是“batch-1 decode 是否受内存限制”，而是更细的一层：在物理 AI 常见的单流、低并发、逐 token 解码场景里，为什么更高 HBM 带宽的 GPU 并没有按带宽比例带来更低延迟。传统估算把每步解码时间近似成需要搬运的权重与 KV cache 总量除以峰值 HBM 带宽，即认为这是一个纯粹的 memory-bandwidth-bound 问题。作者用实测指出，这个说法在慢卡上大体成立，但在 H100 这类快卡上已经不够用了：真正限制短上下文 batch-1 decode 的，不是显存带宽本身，而是每层 kernel 的 CPU launch overhead。这个差异会直接改变硬件选型、量化收益判断，以及 attention kernel 优化的优先级。

评只看测量表和 bandwidth-utilization 分析即可；它会修正“batch-1 decode 买 HBM 就行”的直觉。
Josef Chen
