第二块是 Adapter Protocol。作者定义了一个六方法接口，把不同 memory backend 统一到同一行为契约下。即便某个系统没有原生 supersede，也可以用 add+delete 组合实现并接受同样测试；没有某个 primitive 的系统则记为 N/A，而不是硬算失败。这个设计避免了把“接口缺失”和“实现错误”混在一起。

第三块是 13 种系统配置的架构比较。作者把它们归成几类：无删除、deterministic、vec-only、inscribe-time LLM、KG abstraction、joint、mutation-time LLM hook。论文的关键观察是三种 placement regime 呈现互补覆盖，而不是简单强弱排序。deterministic primitive 对 lexical/temporal 类问题足够，但在 canonicalization 上几乎失效；inscribe-time LLM 能在写入时把别名、改写、跨表述归一化，因此 canonicalization 类能做到 100%，但它无法理解后续删除意图；mutation-time hook 则在删除时调用 LLM，把自然语言删除命令映射到精确 mutation，因此能处理 intent-aware deletion，同时保持 recall hot path 不变。两种不同 backend 只要共享这个窄 JSON mutation hook，整体表现会收敛到接近的水平，这说明关键不是底层存储形态，而是控制面接口设计。18:T7fb,The work has three main components. The first is ForgetEval. Forgetting is decomposed into five structural families: supersession, decay, amnesia, purge, and drift. On top of that, the benchmark adds ten adversarial attack categories such as substring traps, prefix collisions, paraphrase supersession, negation traps, temporal qualifiers, identifier obfuscation, and cross-lingual variants. Each case is a deterministic dataclass with setup facts, distractors, mutations, a final query, and must-contain / must-not-contain constraints. A case passes if the top-10 recall blob satisfies those constraints. Importantly, scoring is deterministic string matching rather than LLM judging.

The second component is the Adapter Protocol. It defines a six-method behavioral interface that allows heterogeneous memory backends to be compared under the same contract. Systems without a native supersede primitive can still implement it compositionally via add plus delete. Missing primitives are marked as N/A rather than counted as failures. This avoids conflating interface absence with implementation failure.

The third component is the architectural comparison across thirteen system configurations. These are grouped into regimes such as no-deletion, deterministic, vec-only, inscribe-time LLM, KG abstraction, joint, and mutation-time LLM hook. The key finding is that these regimes provide complementary coverage rather than a simple ranking. Deterministic primitives handle lexical and temporal cases well but fail on canonicalization. Inscribe-time LLMs normalize aliases and paraphrases at write time, so they recover canonicalization failures, but they cannot interpret later deletion intent. Mutation-time LLM hooks instead parse deletion intent at update time and map it to precise mutations while leaving the recall hot path unchanged. Two different backends converge to similar performance once they share the same narrow JSON-shaped mutation hook, suggesting that control-plane interface design matters more than the storage substrate.19:T6c0,Four experimental results stand out. Human agreement is strong, with Fleiss' kappa of 0.958 on a 100-case, 10-annotator audit.

Second, the paper shows a clear decoupling between recall quality and forgetting ability. MemPalace scores 60/150 on Memora, indicating strong recall, yet gets 0/385 on adversarial forgetting. That is the cleanest evidence in the paper that retrieval success says little about controllable forgetting.

The reported cost is about $0.17 per 385-case run, with the recall hot path unchanged.
