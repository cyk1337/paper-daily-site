Local Inference of LLMs on Long Contexts: A Data Systems Perspective

这篇工作要解决的不是“长上下文模型能不能在本地跑”这个泛问题，而是更具体的一层：在单用户、长上下文、decode 主导的本地推理场景里，真正限制性能的瓶颈到底是什么。现有讨论常把问题归结为显存不够，于是默认需要量化、压缩或复杂的 offloading；但作者沿着编译后 GPU kernel 这一层往下看，发现容量只是表层约束，很多性能损失来自内核实现、资源利用和执行组织方式不匹配单用户 decode 负载。换句话说，问题不是 GPU 被压垮了，而是现有软件栈没有把 GPU 用好，尤其没有针对“batch 很小、序列很长、逐 token 解码”的工作负载做专门设计。

评长上下文落地的“真瓶颈”常被显存叙事掩盖；这篇如果 profiling 做得干净，能直接指导 KV/attention 设计取舍，优先看瓶颈分解图表。
Mattias Dürrmeier,Alberto Lerner
