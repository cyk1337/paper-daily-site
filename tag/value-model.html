Stitched Value Model for Diffusion Alignment

这篇工作解决的是 diffusion/flow 模型对齐中的一个老问题：奖励定义在干净图像 x0 上，但训练时或推理时真正需要评估的是噪声中间态 zt 的“未来回报”，也就是 value function。现有做法要么用 Tweedie 近似，从 zt 先估计一个干净样本再打分；要么做 Monte Carlo rollout，从 zt 采样多条去噪轨迹再平均奖励。前者便宜但高噪声时偏差大，后者更准但成本高。作者要解决的核心问题是：能不能不从头大规模训练 noisy-latent value model，而是把已经很强的像素空间 reward model 迁移到 noisy latent 上，并且迁移成本足够低、泛化足够好。

评只看 value stitching 的训练目标和消融；clean reward 接到 noisy latent 的做法，可类比 RLVR 里的信号错位。

Length Value Model: Scalable Value Pretraining for Token-Level Length Modeling

这篇论文要解决的是生成长度的 token 级建模问题。现有长度控制多依赖 prompt、序列级长度惩罚，或生成前的长度预测器；这些方法只能在整段回答层面施加约束，不能描述生成过程中每一步离结束还有多远，也难以捕捉中途从短回答转向长推理的动态变化。

评不是 pretrain 论文，但把长度控制做成 token-level value head 这件事很干净；只看方法节和 LIFEBench 主表，判断能否接到你们的 decoding stack。

Bringing Value Models Back: Generative Critics for Value Modeling in LLM Reinforcement Learning

LLM 后训练 RL 中的核心瓶颈是长序列生成的 credit assignment：奖励通常只在序列末端给一个标量，导致难以判断哪些中间 token/决策真正促成了最终成功。经典 actor-critic 依赖 value function 做细粒度 advantage 估计，但在 LLM 规模下“判别式（discriminative）一发标量预测”的 value model 往往难训、不稳、效果不随规模可靠提升，实践中被 GRPO/RLOO 等 value-free 方法替代，从而把序列问题近似成 contextual bandit，牺牲精细归因能力。

评改变“value-free 足够”的直觉：生成式 critic 让 credit assignment 可表达且可校准；建议重点看 value 训练稳定性与长序列增益那几张表。
