For any given right transport path — fixed, parameterized, or generated by an input-dependent controller — the state reduces to standard HiPPO in a path-aligned moving coordinate frame, preserving the original online memory operator semantics while adding right-action transport. For the efficient scan constraints of Mamba-style selective SSMs, a restricted group-local realization is derived: channels are partitioned into small transport groups, left dynamics remain diagonal over the state dimension and tied within groups, right transport is group-local and controller-compatible, ensuring exact block-affine scan and recurrent decoding with complexity on par with production selective SSMs. A simultaneous-reducibility collapse criterion is provided to guide non-trivial transport parameterization, avoiding degenerate forms equivalent to static channel mixing plus independent SSM banks.8:T431,Built on channel-wise gated delta / DPLR-style recurrence (diagonal per-channel decay plus low-rank delta updates), the baseline delta rule treats the memory matrix S_t as an associative map and performs a corrective update so that the readout at the current key k_t, i.e., S^T k_t, moves toward v_t.

Erase-then-Delta Attention (EDA) decouples where to erase from where to write:
1) Erase step: select an independent erase address and apply a targeted suppression along a learned erase direction, explicitly cleaning stale content at that address.
2) Delta step: perform the standard delta-style corrective write at the current write key k_t, preserving the desirable “correct-what’s-stored” behavior.

Conceptually, EDA separates three signals: (i) address-agnostic diagonal/channel decay, (ii) independently addressed erasure, and (iii) write-coupled delta correction. The authors report that the learned erase and write addressing becomes nearly orthogonal, suggesting the erase path is not merely stronger forgetting but a distinct conditional cleanup mechanism.9:T73e,AURA-Mem can be summarized as a frozen backbone plus a constant-size recurrent memory plus an action-driven write gate. There are four main ingredients. First, the model wraps a fixed-size memory around a frozen vision-language-action backbone, replacing the linearly growing KV cache with an O(1) state. Second, it introduces a learned action-utility write gate. The trigger is not perplexity, recency, or generic reconstruction error; it is whether the current observation would change the next action. If the new input is not useful for action selection, the memory does not write. Third, the training objective is an action-information bottleneck rather than observation reconstruction. The action-chunk loss is backpropagated through the gate decision so that the memory learns to retain what matters for acting well, not what best preserves token-level fidelity. Fourth, the method includes explicit write-rate control during training via a target write rate rho and a penalty weight gamma, allowing the model to move along an accuracy-versus-write-bandwidth frontier. The paper also instantiates the approximate information state framework empirically by measuring epsilon and delta for the learned memory and reporting an action-sufficiency certificate. The full value-loss bound remains loose because the Lipschitz-related term is too large at current scale, but the attempt is still notable: it turns 'is this compressed state sufficient for control?' into something measurable. Relative to SSM-style recurrent models, AURA-Mem does not write every step. Relative to KV-cache compression methods, it does not approximate a growing cache; it commits to constant memory from the start. Relative to Tensor Cache, it differs simultaneously in write trigger, training objective, write-rate conditioning, and the measured action-sufficiency analysis.a:T4c4,The main empirical claim is not superior task accuracy, but a better write-bandwidth frontier at matched performance.
