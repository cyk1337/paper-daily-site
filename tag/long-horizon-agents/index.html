Context Language Models

这篇工作解决的是长时程 agent 中一个越来越关键的问题：上下文管理现在大多由外部 harness 决定，模型自己并不真正“会管理上下文”。标准 LM 只能不断 append token，遇到长任务、多代理协作、长时间运行时，就会依赖摘要、检索、压缩等人工设计策略。作者提出的问题是，能否把 context management 变成模型原生能力，让模型自己决定保留什么、删除什么、如何重写上下文，而不是把这些策略硬编码在系统外层。

评不必追逐分数，重点看“上下文作为可编辑状态”这个接口；它可能影响以后 agent 预训练数据格式。
