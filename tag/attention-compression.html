ResKV: Reconstructing Omitted Attention Contributions for Fixed-Budget KV Cache Compression

这篇工作处理的是长上下文推理里的一个很具体但很核心的问题：在固定 KV cache 预算下，如何压缩历史 token，又尽量不丢掉它们对注意力的贡献。现有 eviction 方法把未保留 token 直接删掉，连同它们在 softmax 分母里的归一化质量和在分子里的 value 贡献一起消失；而 merging 方法虽然能保留部分信息，但会改写被保留的精确记忆，把“该原样保留的 token”和“被压缩的 token”混在一起。ResKV 试图解决的就是这个两难：既保留一部分 token 作为 exact memory，又用剩余预算显式重建被删 token 的聚合注意力贡献。

评读方法图和 residual softmax 公式即可；这个方向对长上下文预训练的 serving 假设有用，但需等完整数值。
