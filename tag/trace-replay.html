Benchmarking LLM Serving Systems for Agentic AI Workloads with XPerf

这篇工作解决的是：如何在 agentic AI 负载下，稳定、可复现地评测 LLM serving 系统。难点不在单次请求，而在 agent 的控制流由模型输出驱动，天然带有分支和反馈；同一个用户请求，哪怕随机种子固定，也可能因为解码细微差异走出完全不同的执行图，导致 LLM 调用次数、每次调用的输入输出长度、工具调用穿插方式都显著变化。论文给出的直接证据是：在相同请求上重复运行 mini-SWE-agent + gpt-oss-120b，平均 LLM 调用次数可相差 70%。这意味着如果还用传统的独立请求或多轮对话压测 serving，测到的不是 agent 真实负载，而是一个被大幅简化后的代理问题。

评推理系统论文，但和 agent-era 模型训练目标有关；只看 workload taxonomy 和 replay 误差分析。
Michael Wang,Yikang Yue,Shaobo Li,Yirui Eric Zhou,Chen Wang,Jian Huang
