STEEL: Sparsity-Aware Fused Attention for Energy-Efficient Long-Sequence Inference on AMD's XDNA NPU

这篇工作解决的是：如何把长上下文 prefill attention，尤其是 FlashAttention 这一类 IO-aware 算法，真正落到 AMD XDNA 这类显式数据搬运、空间数据流驱动的 NPU 上，并在因果掩码导致的负载不均下仍保持高吞吐和低能耗。问题不在于再发明一种 attention 公式，而在于把已有算法重写成适合 NPU tile 阵列执行的数据流程序。对这类硬件，算子性能往往不是由 FLOPs 决定，而是由片上缓冲、tile 间同步、DMA 调度和流水线失衡决定。作者抓住的核心矛盾是：标准 FlashAttention 的分块计算在 GPU 上天然受益于 SIMT 和高带宽内存，但在 XDNA 上如果直接照搬，会被 causal mask 造成的三角形工作量分布拖垮，前后级 tile 等待严重，能效优势也出不来。

评端侧长上下文会受这种 kernel 约束；skim dataflow 和 causal-mask placement，性能数字缺失前别过度外推。

TileFuse: A Fused Mixed-Precision Kernel Library for Efficient Quantized LLM Inference on AMD NPUs

这篇工作解决的是一个很具体但长期被忽视的问题：边缘端 NPU 明明有不错的能效，却很难直接运行社区常用的量化 LLM，尤其是 AWQ 这类已经广泛分发的 W4A16 / W8A16 权重。问题不在于单纯算力不够，而在于现有 NPU 软件栈封闭、低层可编程性不足，以及量化格式、数据布局、DMA 流水和 tile 级执行方式之间不匹配。结果就是，用户往往得为了硬件去改模型或改量化方案，而不是把现成量化模型直接部署上去。TileFuse 试图把这个链条打通：让 AMD XDNA2 NPU 直接吃下 AWQ 风格权重，并把它真正接进端到端 LLM 推理流程。

评不是预训练论文，但很适合做小模型/端侧路线的人看：重点看它如何避免为硬件专有量化格式改模型，这个接口问题常被训练侧低估。
Wesley Pang,Gregory Hyegang Jun,Feiyang Liu,Deming Chen
