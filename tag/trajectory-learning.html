DART-SD: Diamond-topology Aware Retrieval and Tuning for Self-Distillation of Multi-Turn Tool-Calling Agents

这篇工作处理的是多轮 tool-calling agent 蒸馏里的一个结构性问题：现有 SFT/BC 把教师轨迹当成单条线性序列去模仿，RL 又常把奖励粗糙地摊到整条轨迹上，但很多真实任务包含多个可交换顺序的子目标，正确解空间不是一条路径，而是大量在中间状态汇合、再分叉的“菱形”状态图。在线性监督下，学生模型只要走了与教师不同但同样有效的前缀，就会被当成错误覆盖；在 RL 下，失败轨迹中的有效中间步骤也容易被误罚。论文要解决的核心问题，就是如何在这种多解、可交换子目标的环境里，避免拓扑信息塌缩，保留有效前缀，只在真正偏离成功区域的位置做纠偏。

评读图建模和自蒸馏部分；它把 tool-use 监督从 token 轨迹改成状态拓扑，值得借到 RL 数据生成里。
Hangrui Xu,Jiarui Wang,Yang Yang,Chuanbo Zhu,Fangda Chen,Ziqi Wu,Jingming Cai,Yan Song

MAD-OPD: Breaking the Ceiling in On-Policy Distillation via Multi-Agent Debate

在 on-policy distillation（OPD）里，学生模型沿着自己的采样轨迹学习，但监督信号来自教师分布；当教师在学生访问到的“困难状态”上出错或过度自信时，学生会被锁死在单教师能力上限，并在多步 agentic 任务中因误差累积而训练不稳定。论文要解决的是：如何在 OPD 框架内获得比单教师更可靠的逐 token 监督，并给出与任务结构匹配的 divergence 选择原则，从而把 OPD 扩展到长轨迹的 agentic 场景。

评值得看方法和消融；若 debate 教师真能越过单教师 ceiling，可直接影响后训练蒸馏数据生成策略。
Jianze Wang,Ying Liu,Jinlong Chen,Xuchun Hu,Qilong Zhang,Yu Cao,Jun Wang,Hua Yang,Yong Xie,Qianglong Chen
