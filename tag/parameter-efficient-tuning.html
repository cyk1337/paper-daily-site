TokenMem: Faithful Knowledge Injection for Frozen LLMs

TokenMem 解决的是冻结 LLM 在 RAG 知识冲突场景下不服从外部权威知识的问题。标准 RAG 把检索文本和用户问题拼接后送入同一条 self-attention 路径，外部知识 token 和模型已有上下文 token 共享同一个 softmax 归一化。论文认为这会造成注意力预算竞争：当模型参数中的先验很强时，检索证据即使正确、甚至被系统指定为权威，也可能被压制。作者用 Knowledge Compliance 衡量这种可控性，即在外部 passage 与参数记忆冲突时，模型是否按 passage 作答，而不是按参数记忆作答。

评通过外挂 Cross-Attention 旁路解决 RAG 知识冲突，思路干净且参数极小（<10M），值得关注其两阶段 Curriculum 训练策略。

Latent Personal Memory: Represent personal memory as dynamic soft prompts

这篇工作处理的是个性化 LLM 里的一个老问题：怎样在不改动基座模型的前提下，把用户长期历史压缩成可持续更新、推理成本稳定、且能随问题动态调用的记忆表示。现有几条路各有明显短板。全量上下文拼接准确但推理代价随历史长度快速上升；RAG 和文本记忆把信息保存在离散文本里，适合精确事实回忆，但很难抽象用户偏好演化，也会随着记忆库增长带来检索和上下文拥塞；LoRA 这类 per-user 参数适配会改动模型行为，存在泛化能力受扰动的风险；静态 soft prompt 又表达力不足，无法根据当前问题选择性激活不同记忆。LPM 的目标很明确：把“用户长期历史”表示成一小组可学习 latent slots，再由共享投影网络按当前输入动态生成 soft prompts，让冻结的 LLM 在几乎恒定的推理开销下利用个体记忆。

评把“记忆”做成latent slots→动态soft prompt，直接给出参数量/KV-cache的量化账本；建议重点看128K对比与LoRA等价性是否干净。
