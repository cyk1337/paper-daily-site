9:T624,SkillGym is built around a skill-to-task pipeline. The input is a registry of human-written skills spanning 12 major categories and 63 sub-categories. A key design choice is contrastive validation. Under a reference agent configuration, the system runs tasks with and without the target skill and keeps tasks that show empirical skill dependence. This matters because many tasks associated with a skill document may still be solvable by generic capability alone. Without this filtering step, the resulting supervision would overstate the contribution of the skill itself.
