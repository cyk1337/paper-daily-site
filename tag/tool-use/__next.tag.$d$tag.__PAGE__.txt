c:T698,DART-SD has three main components. First, it builds an Interaction-State Transition Graph from teacher rollouts. Nodes are not single actions; they are cumulative interaction states, defined by the task-relevant information acquired so far. To make this possible, the method introduces information atom abstraction: tool outputs are canonicalized, semantically equivalent responses are mapped to the same atom, and non-informative outputs such as status-only or empty responses are collapsed away. This lets trajectories with different action orders but the same acquired information land on the same node, which naturally captures the diamond topology induced by order-independent sub-goals. Second, for a failed student rollout, the method performs success-reachable projection and identifies the Critical Topological Breakpoint. Instead of cutting by timestep, it asks whether each cumulative student state still lies in the region from which success is reachable in the empirical graph. The CTB is the point where the rollout leaves that success-supported region. Third, starting from a recovery anchor near the CTB, the method retrieves a success-supported continuation from the ISTG and applies localized supervision only to the recovery segment, while preserving the valid prefix. Training is progressive self-distillation: the student rolls out, exposes its current capability boundary, receives CTB-guided local correction, and gradually extends the length of valid interaction prefixes. Compared with vanilla SFT, supervision is localized. Compared with RL, the method does not rely on sparse reward propagation; it uses explicit graph structure extracted from teacher behavior.d:T47e,The study evaluates on five benchmarks and two model scales. A naive trace-similarity metric fails for five reasons: short traces look artificially similar, empty traces score perfectly, unrelated traces overlap by chance, same-language reruns are not identical, and without a within-language baseline the quantity is not identifiable.

The estimator addresses each issue explicitly. Every language-task cell is run twice with identical decoding settings and token budgets, changing only the serving seed. Same-language agreement, I_within, compares the two replicates in one language. Cross-language agreement, I_cross, compares traces across languages, also cross-seed. The normalized retention metric is \tilde{I}=I_cross/I_within, which measures how much of a model’s own reproducible policy survives a language change. Comparisons are length-matched in both directions, pairs are dropped if either trace is empty, and uncertainty is estimated with task-level bootstraps. This design makes language the only systematic difference while keeping decoding noise symmetric.

The top layer maintains an explicit state containing the goal, hard constraints, soft preferences, blocking conditions, evidence ledger, progress, and next intention. The middle layer is deliberately narrower.
