PithTrain: A Compact and Agent-Native MoE Training System

这篇论文要解决的不是新的 MoE 算法，而是一个训练系统设计问题：现有大规模 MoE 训练框架主要为人类工程师和吞吐优化，代码规模大、层次深、依赖大量隐式注册和编译扩展，导致 AI coding agent 很难高效理解、操作和扩展。作者把这类成本定义为 agent-task efficiency，简称 ATE，并提出一个问题：能不能从一开始就把训练框架设计成 agent-native，在不明显牺牲训练效率的前提下，显著降低 agent 完成真实训练系统任务的时间、token 消耗和试错成本。

评不是在改 pretrain 算法，而是在改“研究迭代速度”的瓶颈；先看 ATE 定义和 benchmark 设计，吞吐结论先别全信，系统规模与任务覆盖要细查。
Ruihang Lai,Hao Kang,Haozhan Tang,Akaash R. Parthasarathy,Zichun Yu,Junru Shao,Todd C. Mowry,Chenyan Xiong,Tianqi Chen
