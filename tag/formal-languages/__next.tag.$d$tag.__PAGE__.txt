9:T451,The testbed is Dyck-1 and Shuffle-k (k=2/4/6/8), where correct continuation depends on stack-like memory. The model is an encoder-only transformer with a causal mask for next-token prediction, but the output is multi-label: it predicts the set of valid next tokens as a k-hot vector via a sigmoid head, trained with MSE.
Method pipeline:
1) Train a fully converged LM on Shuffle-k.
2) Train linear probes to predict stack depth at each position from hidden states; use a control probe with randomized labels and report selectivity to argue the feature is genuinely encoded.
3) Extract a principal “stack direction” from the probe weight matrix W using SVD; take the top right singular vector w.
4) Perform causal intervention at inference by ablating that direction: h ← h − (h·w)w. Compare against ablating random directions as a control.
The design choice of using the top singular vector (instead of a single class weight) aims to capture the most shared discriminative direction across depth classes, and random-direction ablations help rule out trivial damage-from-any-ablation explanations.a:T489,The paper combines a formal-language/logic characterization with empirical validation.
