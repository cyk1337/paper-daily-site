Litespark Inference on Consumer CPUs: Custom SIMD Kernels for Ternary Neural Networks

这篇工作解决的是 ternary neural network 在消费级 CPU 上“理论上很便宜、实际却跑不快”的落地问题。权重若只取 {-1,0,+1}，前向计算本应接近乘法消失，只剩加减和跳过，但现有框架仍把它当成普通 dense 浮点矩阵乘来执行，导致 ternary 模型的结构优势没有兑现。作者的目标不是提出新的 ternary 训练方法，而是把 BitNet 一类模型在 Apple Silicon、Intel、AMD 的通用 CPU 上真正跑起来，并把吞吐和内存收益做成可复用的软件栈。

评如果你在看 1.58-bit/ternary 路线，这篇该读：不是又一个量化口号，而是把“训练出的离散权重”真正落到 CPU kernel；先核对 baseline 是否公平。
Nii Osae Osae Dade,Tony Morri,Moinul Hossain Rahat,Sayandip Pal
