Soft Token Alignment for Cross-Lingual Reasoning

这项工作处理多语言推理中的一致性问题：语义相同的不同语言 prompt，模型可能给出不同推理路径和不同答案。作者把问题定位在生成后段的离散 token 选择上：中间层语义可能已经对齐，但最终层要落到具体语言和文字系统，概率分布被压成某个离散 token 后，推理轨迹开始分叉。

评想做“跨语言推理一致性”时，这个soft-token对齐损失比对齐离散token更像正解；但要重点审计对齐配对与解码控制，否则提升可能是评测噪声。

Distributional Alignment Games for Answer-Level Fine-Tuning

答案级微调（ALFT）需要优化模型生成正确最终答案的边际概率，但推理轨迹到答案的映射通常不可微，且推理轨迹的组合空间过大，直接计算边际概率梯度不可行，现有REINFORCE类梯度估计器方差过高，训练难以稳定。

评这篇该当作“目标函数论文”来读，不必先信它能立刻提分；先看博弈等价是否真的把 answer-only 训练讲清了，若成立，会直接影响你对 latent reasoning 后训练接口的设计。
