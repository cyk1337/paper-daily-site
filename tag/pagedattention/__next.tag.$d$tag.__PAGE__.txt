9:T5fb,The method has three main components. First, Cascade Cache organizes the KV lifecycle into three tiers instead of treating the cache as a monolithic buffer. Tier 1 is a dense cache for recent tokens, preserving local dependencies and attention sinks with contiguous high-fidelity storage. Tier 2 is a sparse cache where older tokens are retained selectively using head-adaptive budgeting. Tier 3 is a condensed cache where even older blocks are further compressed through eviction or weighted merging to satisfy hard memory limits. The key idea is to turn 'recent dense, older sparse, oldest condensed' into a unified pipeline. Second, Logits Calibration maps heterogeneous importance scores into a shared probability space so that Top-p style budgeting can be applied consistently across heads and across different selection criteria. This is meant to make the retained-token pattern better match the raw attention distribution, rather than relying on fixed Top-k thresholds that are hard to compare across heads. Third, System-aware Index Regularization rewrites discontinuous logical selections into a more regular physical layout using memory rewriting and sparse loading. Together with a head-wise block table and metadata management, this makes dynamic head-adaptive selection compatible with CUDA Graph execution and block-based memory systems.
