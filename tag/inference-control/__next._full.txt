19:T574,The paper formalizes prompt steering as an activation intervention on the same generated suffix tokens. It introduces two notions of the prompt-induced intervention: (i) an accumulated effect up to layer l (Δ_PS_acc), and (ii) a layer-local effect (Δ_PS_loc) obtained by “neutralizing” the steering-prompt token activations while propagating the steered suffix, isolating per-layer net changes.
Empirically, the prompt-induced intervention is strongly non-uniform across token positions: a few positions receive large shifts while many are barely affected. This contradicts the common Const family (ActAdd/CAA/ITI/ReFT-R1-style) that applies the same scalar coefficient α everywhere.
Based on this, the paper proposes Prompt Steering Replacement (PSR): keep a rank-1 direction z_attr but replace the constant α with token-specific coefficients α_i predicted from the current activations (a small, interpretable gating/regression module). PSR is trained to imitate the activation changes and/or behavioral effects produced by successful prompt steering, effectively distilling an implicit prompt mechanism into an explicit intervention.
