CONTRAMEM: Learning Self-Evolving Procedural Memory from Contrasting Multi-Model Trajectories

自主计算机使用 Agent 在长周期任务中容易出现程序性失败（如误读状态、工具语义错误），而现有的无需训练的程序性记忆构建方法难以提取可复用的逻辑，且容易继承单一模型的盲点。

评一种通过对比多轨迹来免训练提取 Agent 程序性记忆的方法，对构建 Agent 系统或合成高质量后训练数据有一定启发。

Procedural Memory Distillation: Online Reflection for Self-Improving Language Models

这篇工作处理的是 RLVR / self-distillation 训练里一个很具体但常被忽略的问题：现有方法把每次 rollout 当成独立 episode，用 verifier 或偏好信号更新一次策略后就丢弃过程信息，导致模型无法系统性积累“哪些解题程序反复有效、哪些失败模式持续出现、哪些模式能跨题迁移”这类跨 episode 的程序性知识。论文要解决的不是单次 credit assignment，而是如何把训练过程中不断出现的重复尝试，转成可持续更新、又能最终写回模型参数的 procedural memory。

评后训练RL方法的扎实改进，过程记忆蒸馏的思路对预训练中数据复用与知识沉淀有启发，重点读方法部分的三层记忆设计。
