Not Every User Says It All: Training Tool-Using Agents Beyond Ideal Simulated Users

这篇工作研究的是一个此前被默认忽略的问题：工具使用型 agent 的训练和评测，通常都建立在“用户会把关键信息一次性、清楚、完整说出来”的强用户假设上，但真实用户常常信息不全、表达残缺、甚至沟通链路会丢失内容。作者关心的不是单纯把用户做得更难，而是更精确地问：当任务、用户知识、目标和奖励都不变，只是用户说出的内容有一部分没有被 agent 听到时，现有 RL 训练是否还能学到更稳健的交互策略。全文给出的答案比较明确：在这种受控的弱用户设定下，标准 GRPO 训练并不能让 agent 更好地服务弱用户，甚至“让模型多问一点”也不是有效补救；真正缺的是逐步识别信息缺口并把 credit assignment 落到具体交互状态上的训练信号。

MASIF: Implicit Failures for Process Observability in Multi-Agent Systems

这篇工作研究的是多智能体系统里的“隐性失败”问题：局部步骤已经出错，但这个错误被后续修补、绕过，或者暂时没有决定最终成败，因此不会被只看最终 outcome 的评估框架捕捉到。现有 failure attribution 大多只追问“哪一步导致了最后失败”，而这篇文章关心的是另一层过程信号：成功轨迹里也可能充满局部错误，失败轨迹里也可能没有明显局部失误。作者想回答的不是单一因果归因，而是 MAS 在执行过程中如何吸收、传播、掩盖错误，以及这些过程信号能否转化为训练信号。

评看 IF taxonomy、counterfactual replay 和 IF-GRPO；它提醒过程奖励别只盯最终成功轨迹。

Rethinking GRPO for Large Reasoning Model Safety Alignment

这篇工作处理的是一个很具体、但在 reasoning model 安全对齐里经常被忽略的问题：GRPO 这类组内相对优势优化，在安全奖励较稀疏、且同一提示下多条采样轨迹安全性高度同质时，会失去有效学习信号。全文把问题拆成两个失效模式。第一是 advantage collapse：如果一个 harmful prompt 采样出的整组回答几乎全都不安全，组内奖励方差接近 0，标准化 advantage 直接塌掉，策略梯度几乎没有安全方向。第二是 unsafe diversification：当相对信号消失后，熵正则仍在推动探索，模型不会更安全，只会把概率质量扩散到更多样的 unsafe mode。作者强调，这不是简单的 reward design 不好，而是 GRPO 的相对比较机制与 LRM 后训练后行为一致性之间存在结构性张力。

评看 failure modes 和 advantage 分布分析；如果现有安全 RL 也用 group-relative reward，这篇可直接转成诊断 checklist。
