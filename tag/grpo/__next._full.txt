18:T40d,LIRSeg introduces learnable latent tokens in place of explicit CoT. Training has two stages. The first stage performs supervised spatial alignment, grounding the latent tokens in object-relevant visual regions so that they encode spatial evidence rather than serving as generic placeholders. The second stage applies RL with segmentation rewards to refine these tokens under a compact token budget. Since latent tokens do not inherit the representational diversity of pretrained language tokens, the authors add three mechanisms to avoid collapse and weak exploration: extreme-advantage sampling to emphasize informative reward signals, decoupled exploration–stability updates to separate exploratory changes from representation-preserving updates, and latent diversity amplification to keep different latent tokens from converging to the same role. Compared with Seg-Zero, PixelThink, and DR2Seg, the key change is not shorter textual reasoning; it is the removal of textual reasoning in favor of visually grounded latent computation.19:T86a,实验主干基于 Qwen2.5-VL-3B-Instruct 与 PMC-VQA。SFT 使用 10k 训练题、1.5k 验证题、2k clean test，且作者检查了训练集与 clean test 在图像内容和 image-question 对上的无重叠。三个 SFT 配置的最佳 checkpoint 都出现在半个 epoch。最关键的 clean-test 结果是：仅语言侧 LoRA 的 M1-L，correct-image accuracy 只提升 +1.10 个百分点，95% paired bootstrap CI 为 -0.85 到 +3.05，统计上并不稳；但 visual-benefit events 减少 2.40 个点，image sensitivity 下降 5.60 个点，同时样本级别上出现 155 个新获得的视觉收益案例和 203 个丢失案例。这说明净准确率几乎不变时，底层决策机制已经明显重排。作者还发现扩大适配范围到 merger 或 vision encoder 并没有带来更好的 held-out 视觉效用，反而 clean-test accuracy 更低，说明在这个数据量和任务设置下，更多视觉参数可训练并不等于更好地学会用视觉。GRPO 部分，标准 answer-only GRPO 在 2000 prompt trajectory 上持续优化，但验证集选出的 M2-500 在 clean test 上几乎不改准确率，说明 reward 在被优化，但收益没有转移到最终任务指标。证据目标部分，M3 与 M4 的差异揭示了一个重要现象：如果用 canonical option token 来计分，得到的是一种“选项支持度”信号；如果沿真实生成 token path 计分，学到的则更接近实际解码行为。作者又做了 500/1000/2000 prompt exposure 的 dose-matched 比较，发现 evidence score 的提升里既有训练暴露量带来的 acquisition，也有从训练集到验证集的 transfer，而且不同 score component 的变化方向并不一致。换句话说，看到 evidence objective 变好，不能直接推断模型更会看图，还要问是哪个 token、哪一段路径、在哪个数据子集上变好。全文的 paired transition 分析是亮点，因为它把 aggregate 指标拆回到单题层面的 gained/lost visual-benefit cases，能看清楚模型是在“把原来依赖图像的题做成了不依赖图像也能答对”，还是“真的学会了更多视觉证据”。1a:T56b,The paper has three technical layers. First, it defines a controlled evaluation protocol with three conditions per question: Correct image (C), NoImage (N), and Shuffled image (S). From these, it derives metrics such as visual-benefit rate (VBR), visual-harm rate (VHR), and image sensitivity (IS), which are more informative than plain accuracy because they test whether the answer depends on the image in the right way. Second, it compares different SFT adaptation scopes on Qwen2.5-VL-3B-Instruct: M1-L applies LoRA only to language-model attention projections; M1-ML also trains the multimodal merger; M1-VML further adapts the vision encoder. This isolates whether opening more of the visual pathway actually improves held-out visual utility. Third, it studies RL-style objectives. Standard answer-only GRPO is initialized from M1-L to form M2. Then two evidence-objective variants are introduced: M3 uses canonical option-token scores, while M4 scores tokens along the actual generation path. This is an important implementation-level distinction. The paper shows that the meaning of the reward changes depending on which token path is scored, and it uses matched-dose comparisons to separate objective effects from simple training exposure effects. A supplementary SLAKE experiment further examines how native-answer token learning interacts with generation and stopping behavior.1b:T6ef,The main experiments use Qwen2.5-VL-3B-Instruct on PMC-VQA, with 10k training questions, 1.5k validation questions, and a 2k clean test set with no image-content or image-question overlap with training. All selected SFT checkpoints occur at half an epoch. The most important result is that M1-L, the language-only LoRA SFT setup, changes correct-image accuracy by only +1.10 percentage points on the clean test, with a 95% paired bootstrap confidence interval of -0.85 to +3.05. Yet visual-benefit events decrease by 2.40 points and image sensitivity drops by 5.60 points. At the paired-example level, the model gains 155 visual-benefit cases but loses 203, showing substantial internal redistribution despite a small net accuracy change. Expanding adaptation to the merger or vision encoder does not help; broader multimodal adaptation lowers clean-test accuracy, suggesting that more trainable visual components do not automatically translate into better visual use under this data regime. For RL, standard answer-only GRPO continues to optimize its reward, but the validation-selected checkpoint M2-500 leaves clean-test accuracy nearly unchanged. The evidence-objective analysis is the most nuanced part: M3 and M4 behave differently because canonical option-token scoring and generation-path-aligned scoring capture different signals. Dose-matched comparisons at 500, 1000, and 2000 prompt exposures show that improvements in evidence scores mix together training-dose effects, score acquisition, and transfer, and that different score components move for different reasons. The paired transition analysis is especially useful because it reveals whether the model is truly learning to use visual evidence or merely becoming correct in a way that is less image-dependent.1c:T4a1,TalkMesh places agents on a sparse communication graph. Each agent uses a frozen base model M with two LoRA adapters: a confidence head V and a talk policy T. Inference has five stages. First, agents independently sample proposals, matching the independence assumption of self-consistency. Second, V scores each proposal using the sigmoid of the Yes-versus-No logit gap under a fixed verification prompt. Third, the highest-confidence agent becomes the speaker and emits a hint capped at 112 tokens. 在此基础上，作者推导了两个分配规律。其一是 compute-optimal suffix allocation law：给定某个前缀和动作，suffix rollout 数应按该动作的 continuation variance 与单位成本来分配，而不是平均分。其二是 marginal branching law：是否在某个前缀继续加一个新分支，取决于该前缀的 occupancy、score-weighted value uncertainty，以及新增分支的预期信息增益相对计算成本的比值。作者把这个量具体化为 EPIG，expected predictive information gain about the gradient。直观上，它不是问“这里模型是否犹豫”，而是问“如果我在这里多看一个分支，能否显著减少我对梯度方向的未知”。

This yields two distinct sources of estimator error. The first is decision uncertainty: variance induced by which action a is taken at prefix h, weighted by the score function and the action value Q_h(a). The second is continuation uncertainty: variance in the suffix return after the action has already been fixed. This decomposition maps cleanly to two compute operations. Adding a new branch reduces decision uncertainty. Adding more suffix rollouts under an existing branch reduces continuation uncertainty.

From this view, the paper derives two allocation laws. First, a compute-optimal suffix allocation law: suffix samples should be distributed according to continuation variance and cost, rather than uniformly across branches. Second, a marginal branching law: whether to add another branch at a prefix depends on occupancy, score-weighted value uncertainty, and the expected reduction in gradient-estimation error relative to compute cost. The operational quantity is EPIG, expected predictive information gain about the gradient. The key distinction is that entropy only measures whether branches can differ, while EPIG measures whether those differences matter for the gradient estimator.

Algorithmically, EPIG-Tree still uses entropy, but only as a proposal mechanism. Entropy cheaply filters candidate branching points, while EPIG decides where compute is actually spent. This is a practical compromise: exact information-gain evaluation everywhere would be too expensive. Compared with prior tree-based LLM RL methods such as entropy-triggered branching or segment-level tree modeling, the novelty is the objective function.
