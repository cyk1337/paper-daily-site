在每一层，作者取最终 prompt token 的 residual activation，分别对 analogy 与 literal 两组求均值，做 difference-in-means，得到该层的 Analogy Vector。推理时在指定层把该向量按系数 α 加到残差流上，观察输出风格是否朝类比解释偏移。这里有两个技术点比较关键。第一，作者系统比较了七组 matched base/instruct 模型，覆盖 Gemma-2、Llama-3.1、Qwen-2.5，参数规模 2B 到 32B，用同一套提取与干预流程来比较“方向是否存在”和“方向是否可用”。第二，他们发现高系数干预会出现 mode collapse，原因不是语义方向本身失效，而是 lexical entanglement：向量里混入了明显的词汇触发成分，尤其是 “Imagine” token 的 unembedding 方向约占总范数的 10%，会把模型硬推向模板化开头。为此作者把向量投影到与该 token 方向正交的子空间，范数只下降 1%–5%，说明主体信号仍是语义性的，而不是单纯的词触发。

更有意思的是作者提出的“behavioral accessibility”框架。不是只看能否提取出方向，而是看该方向注入后，模型分布是否真的发生可传播、可利用的变化。这里他们用两类信号来刻画：一类是输出质量和 analogy score 的提升；另一类是干预前后 token 分布的 KL divergence。后者被作者解释为 wiring diagnostic：即使模型最终没生成高质量类比，只要 KL 明显上升，说明这条方向至少接入了生成路径；如果 KL 很低，则更像是几何上有痕迹，但没有被行为电路有效读取。a:T926,The method follows the representation-engineering line of work, but moves from near-binary behaviors such as refusal to a continuous generative style. The authors build a paired dataset of 1,000 concepts, each eliciting both a literal explanation and an analogical explanation. The source is ELI5-style community QA data, filtered in two stages with an external LLM: first to keep only mechanism-like concepts suitable for structural analogy, then to assign each item to one of eight domains for near-balanced sampling. The final split is 600/100/300 for train/validation/test.

For each layer, they collect the residual activation at the final prompt token and compute a difference-in-means vector between analogy and literal examples. This yields a layer-wise Analogy Vector. At inference time, they add the vector with coefficient alpha to the residual stream before the attention and MLP blocks, then measure whether the output shifts toward analogical explanation style.

Two technical details matter. First, they run the same extraction-and-steering pipeline on seven matched base/instruct pairs from Gemma-2, Llama-3.1, and Qwen-2.5, spanning 2B to 32B parameters. This lets them compare not just whether the direction exists, but whether it is behaviorally usable. Second, they identify a concrete failure mode at high steering strength: lexical entanglement. The vector partially aligns with the unembedding direction of the token “Imagine,” which accounts for about 10% of the vector norm and can force templated generations. They remove this by orthogonalizing the steering vector against that token direction. The norm drops by only 1%–5%, suggesting the main signal is semantic rather than lexical.

The paper argues that extracting a direction is not enough; one must test whether the intervention actually enters the model’s generation circuitry. To measure this, they use both output-side quality metrics and KL divergence between steered and unsteered token distributions. They interpret KL as a wiring diagnostic: even if the final generations are not yet good analogies, a substantial KL shift indicates that the direction is connected to the decoding pathway. Good follow-up angles include layerwise behavior of k*, sensitivity to tokenizer or architecture choice, and whether SAE correspondence really indicates shared semantic basis functions rather than merely shared discriminative directions.12:T734,TIRE has three modules: Physical Knowledge, Top-Down Formula Instantiation, and Teacher Distillation, all tied together by program-based verification.

The first module represents reusable physics knowledge as formula records. These records are not treated as plain text snippets; they encode the physical relation, variable semantics, and applicability conditions needed for downstream instantiation. The dataset is grounded in 3,051 such records extracted from PHYSICS and SciBench.

The second module is the core design choice: top-down instantiation. A formula is translated into an executable program, validated through Program Validation, then instantiated with concrete parameter values that satisfy the formula’s validity conditions. The program is executed to obtain a reference answer y*. This ordering matters. Instead of asking an LLM to jointly invent a scenario, choose a law, assign values, and solve it, TIRE first constructs a valid physical instance and only then verbalizes it as a natural-language problem. That sharply narrows the error surface.

The third module is teacher distillation. A teacher model generates reasoning traces, but those traces are not trusted by default. TIRE keeps only traces whose final answer matches the execution-derived reference via Answer Verification. This turns the teacher into a language explainer rather than the source of truth. That is a notable departure from many synthetic CoT pipelines, where the teacher’s full output is directly used as supervision.

The broader design logic is clear: separate semantic generation from numerical correctness, and let deterministic execution define the target whenever possible. The framework does not fully solve realism or coverage of complex multi-law physics problems, but it substantially improves controllability and label reliability.13:T556,The paper builds TIRE-19k, a dataset of 19,144 examples spanning 9 physics subfields, grounded in 3,051 formula records. Each example contains a natural-language question, an execution-derived reference answer, and an answer-verified teacher reasoning trace.

Empirically, the authors evaluate on 3 backbones and 4 benchmarks. Under equal training-data budgets, TIRE-19k outperforms existing physics reasoning datasets both in-domain and on out-of-domain generalization. The important point is that the gain is shown under matched data volume, which supports the claim that the improvement comes from data construction quality rather than simply more samples.

The ablations are the most informative part. They show that:
1. top-down formula instantiation is better than direct text-based generation;
2. reliable execution is critical, because removing the execution anchor increases supervision noise;
3. the framework works with multiple teachers, so the benefit is not tied to one specific teacher model;
4. GRPO after SFT yields additional gains, suggesting that execution-grounded data is also a good starting point for RL-style post-training.
