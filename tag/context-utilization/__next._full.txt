The process runs a fixed small number of recursive evidence selection rounds: in each round, attention scores are computed on a prompt that includes the evidence pool accumulated in prior rounds. Scores are aggregated across selected attention heads, from the last w=8 cue tokens near the query. High-relevance token spans from the original context are added to an ordered evidence pool, which is inserted into the prompt for the next round. Because attention is computed from a model state that already contains prior selected evidence, later rounds can surface multi-hop information related to previously found spans.
