LLaCO: Continuous Diffusion for Large Language Models with Competition-Aware Semantic Scheduling

这篇工作处理的是连续扩散语言模型里一个很基础、但过去一直没有被讲透的问题：中间噪声状态到底在什么时候失去原始 token 身份，为什么这种身份衰减会在时间轴上被严重压缩到接近纯噪声端的一小段区间。作者指出，过去常用的欧氏距离视角把“谁先超过源 token”这件事看错了。原因不是语义真的已经被替换，而是 embedding 范数衰减带来了静态范数惩罚，导致低范数 token 在几何上出现虚假的 overtaking。真正决定竞争关系的不是欧氏距离，而是方向空间里的相对语义分离与有效噪声幅度之间的比较。论文把这一点形式化为 Competition Threshold Theory：只有当噪声沿方向空间足够大，超过源 token 与候选 token 的语义分离阈值时，候选才会真实地取代源 token。由此进一步解释了为什么高维 embedding 空间里，大多数竞争 crossing 都集中在极高噪声区间，进而造成训练信号在时间上严重挤压。

评这篇值得认真看：它不是在调 schedule，而是在给连续 diffusion LM 的时间参数化补机制解释；先看 CTT 推导和 identity decay 曲线，再决定要不要复现。

Who Gets Unmasked? Sampler-Induced Bias in Diffusion Language Models

这篇工作解决的是 diffusion language model 的一个被忽略但很关键的问题：生成偏差不只来自模型本身，还来自 sampler 如何决定“先提交哪些位置”。在 dLLM 里，每一步不仅要决定某个 masked position 写什么 token，还要决定哪些位置现在就 commit。很多常用 sampler，尤其是会根据“采样到的 token 概率有多高”来决定是否提交的位置选择规则，会偏向更可能的多数选项。结果是，最终生成文本里谁出现、以什么比例出现，并不忠实反映模型本身的分布。论文把这种额外偏差定义为 sampler-induced bias，并试图把“模型相信什么”和“采样器把这种信念放大成什么”明确拆开。

评这篇会改你对 dLLM 解码的 prior：很多偏差不是 model bias 而是 sampler bias，做任何 dLLM 对比前都该先检查 commit rule；先看 belief 对 exact sampling 的那组验证。

LED: Improving Masked Diffusion Language Models by Lookahead Editing

这篇论文要解决的是 diffusion LM 里一个很核心的结构性矛盾：masked diffusion model（MDM）训练简单、目标干净、优化稳定，但一旦 token 被 commit 就不能再改，计算表达能力受限；uniform diffusion model（UDM）允许 token 在去噪过程中反复改写，表达力更强，但训练目标里会引入依赖模型本身的 schedule matching 项，优化明显更难。论文的问题不是单纯再做一个更快的 dLLM，而是试图同时拿到两边的优点：保留 MDM 的 mask-based transition 和易训练性，同时引入类似 UDM 的 iterative revision 能力。

评diffusion 文本里少见的“解码机制”实质改动：把迭代修订塞回 MDM 日程；先看理论对 MDM/UDM 取舍的刻画，再核对质量-算力曲线是否真划算。

Trust but Verify: Designing Region-Inhomogeneous Forward Dynamics for Discrete Diffusion

离散扩散语言模型几乎都采用absorbing forward process（token→[MASK]并吸收），导致“条件上下文”在整个反向轨迹中被当作绝对真值：一旦上下文被检索/转写/代码等噪声污染，模型会把错误上下文当作100%可信并复制传播。论文要解决的是：如何让离散扩散在条件生成/infilling时具备“可疑度”（graded trust），既能在干净上下文下不退化，又能在上下文被污染时检测、修复或至少抑制错误扩散。

评离散扩散里“context 永远真”确实是硬伤，这篇至少给了一个可实现的 forward 设计与采样补丁；只当工程启发，别把启发式 sampler 当理论结论。
