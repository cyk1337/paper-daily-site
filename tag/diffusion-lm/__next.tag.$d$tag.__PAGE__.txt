9:T61a,The paper formulates score mismatch as a perturbation of the reverse rate matrix in the continuous-time Markov chain underlying discrete diffusion. This differs from the continuous diffusion case, where mismatch is often expressed as a perturbation of the reverse Gaussian mean. The analysis gives a non-asymptotic KL upper bound between the target distribution and the sampler distribution. The bound separates the intrinsic sampling error from an additional bias term induced by using the training-distribution score for a mismatched target distribution. The mismatch term is tied to a Bregman divergence associated with score entropy, rather than a plain L2 score error.

The paper then applies the framework to Conditional SEDD. The common hard-clamping procedure resets observed coordinates to their fixed values at each reverse step. The analysis shows that this operation is not universally equivalent to the true conditional reverse process. Under an absorbing rate and fixed non-MASK observations, the hard-clamp score matches the true conditional score on unobserved coordinates, so no extra score-mismatch bias appears in the bound. Under a uniform rate, this equivalence generally fails.

For coordinate-wise set constraints, the paper uses a mixture over feasible assignments. Once an assignment is chosen, the fixed-observation sampler can be reused. 第二部分是 likelihood shortcut 的梯度路由与校准。LangFlow / Plaid 这类连续语言模型通常会通过 codebook 或 embedding matrix，把连续状态和离散词表联系起来。LangDiT 保留了这种 likelihood shortcut，但不让 shortcut 的 embedding matrix 直接承受全部梯度，而是对其做 detach，避免训练过度依赖这条捷径，导致 token embedding 学成“为 shortcut 服务”的几何结构，而不是为 denoising backbone 服务。作者还对 shortcut 做了 gated 设计和 calibration，意思是 shortcut 不是无条件强加到 logits 上，而是根据置信度或训练状态控制其影响强度。这个点很关键，因为在 CDLM 里 shortcut 往往既有帮助也有风险：它能更快把连续状态映射回词表，但也可能让模型绕过真正的上下文建模，形成脆弱的局部匹配。

第三部分是 confidence-gated training self-conditioning。Self-conditioning 在 diffusion 模型里常见，但直接把上一步预测强行喂回去，容易在训练早期引入错误累积，尤其语言离散空间里错误 token 分布会很尖。作者不是简单地开或关 self-conditioning，而是按模型当前预测置信度做门控，只在更可信的时候让先前预测更强地影响当前去噪。这个设计背后的逻辑是：self-conditioning 的收益来自跨步一致性，但前提是前一步信息足够可靠；否则它会把噪声放大成偏置。

The first set of changes concerns normalization and noise conditioning inside the backbone. LangDiT uses backbone RMSNorm for hidden-state scale control and query-key RMSNorm for direct control of attention-logit scale. This is a sensible adaptation to CDLMs, where the input distribution changes substantially across noise levels. If attention logits drift in scale as noise varies, optimization becomes harder and denoising quality degrades. The model also uses wider noise conditioning, giving the noise signal more capacity to modulate computation. That choice reflects a real property of language diffusion: high-noise denoising behaves more like global hypothesis formation, while low-noise denoising behaves more like local correction, so the network benefits from stronger conditional modulation.

The second set of changes concerns the likelihood shortcut. In LangFlow- and Plaid-style models, a shortcut path often maps continuous states to vocabulary logits through the codebook or embedding matrix. LangDiT keeps this shortcut but changes how gradients flow through it. The embedding matrix on the shortcut path is detached, which prevents the model from overfitting the embedding geometry to the shortcut itself. Without this, the shortcut can become an overly dominant path that weakens the burden on the contextual denoiser. The shortcut is also gated and calibrated rather than added in an unconditional way. This is important because the shortcut is useful but dangerous: it can accelerate token recovery, but it can also encourage brittle local matching instead of robust contextual denoising.

The third component is confidence-gated training self-conditioning. Self-conditioning is common in diffusion models, but naively feeding previous predictions back into the model can be harmful in language, especially early in training when token predictions are unreliable and errors are sharp in the discrete space. LangDiT therefore gates self-conditioning by confidence, allowing previous predictions to influence the current denoising step more strongly only when they are trustworthy enough. The intuition is simple: self-conditioning helps when it stabilizes cross-step consistency, but hurts when it amplifies noisy guesses.

算法上，第一步是把 residual learning 明确成 on-policy rollout。训练时不再依赖离线预生成的 residual states，而是用当前模型在线生成 denoising trajectory：每一步模型接收当前 partially denoised block 以及上一步 residual context，输出新的 token 分布和新的 residual，再继续 rollout。这样训练看到的状态与推理时一致，避免 exposure mismatch。论文强调，若用离线 residual 监督，模型学到的是“如何利用别的策略生成的 residual”，而不是“如何利用自己会生成的 residual”。

第二步是稳定化 residual pathway。作者观察到在共享优化器下，residual 分支比 backbone 更容易快速漂移，导致训练不稳。ORL 因此对 residual pathway 做了 rescaling，使其更新节奏与 backbone 更接近；同时引入基于 rollout entropy 的 supervision gating：当某些位置已经足够 confident，就不再继续强行 sharpen，避免过度收缩导致错误被放大。这里的设计不是简单 regularization，而是在控制“哪些状态值得继续 refinement”。

第三步是提出 adjacent entropy-contraction objective。仅用最终 token 监督，模型知道每一步应该朝最终答案靠近，但不知道每一步应该推进多少。作者发现很多基线在 denoising steps 上 entropy 几乎不下降，因此虽然最终能收敛到正确 token，单步信息增益却很小，TPF 提升有限。ORL 直接要求相邻步骤之间的预测分布熵收缩，也就是后一步要比前一步更确定，但这种收缩又受前述 entropy gating 约束，避免在已经低熵的位置继续盲目压缩。这个目标抓住了 DLM 的核心：每次前向不仅要“更对”，还要“更敢提交”。

系统上，ORL 不是把 on-policy 训练当成概念验证，而是实现了可扩展的 trajectory pipeline。论文描述了异步捕获 residual states、根据显存压力决定保留还是 offload、把不规则长度和不同阶段的轨迹状态打包成稠密 batch，以及用 compute-aware scheduler 平衡 GPU 上 rollout 与训练的负载。文中还提到专门的 staircase attention/packing 设计，用来处理逐步解 mask 带来的非规则计算图。这部分很重要，因为没有这些工程设计，exact on-policy residual learning 很难在大模型上跑起来。10:T87a,论文的实验重点围绕三个问题展开：on-policy 是否必要、entropy-contraction 是否真的提升 refinement speed、以及系统实现是否能把这种训练跑到足够大规模。

Its contribution is not just another diffusion decoding heuristic. It reframes residual context as a training paradigm: the learning distribution must follow the model's own rollout states, and the objective must explicitly reward uncertainty reduction across steps rather than assuming final-token supervision will automatically produce faster refinement. That matters because DLMs differ from AR LMs in a fundamental way. They are not only learning what token should appear, but also how much progress should be made per forward pass. If that second part is left implicit, a model may reach decent final quality while making very little information gain per step, which defeats the point of parallel generation.

From a pretraining perspective, the paper is valuable for three reasons. First, it extends on-policy learning beyond RL or post-training into the generative modeling objective itself. Second, it introduces entropy contraction as a direct proxy for refinement speed, which is closer to the real optimization target of parallel decoding than plain token-level supervision. Third, it treats trajectory-dependent training as a joint algorithm-systems problem, which is likely necessary for any serious scaling attempt in diffusion or any-order language modeling.12:T9a0,ORL has two tightly coupled components: an on-policy learning algorithm and a trajectory-aware training system.

On the algorithmic side, the first move is to train on exact model-generated residual trajectories. Instead of relying on offline residual states, ORL rolls out the current model online. At each denoising step, the model takes the current partially denoised block together with the residual context from the previous step, produces a new predictive distribution and a new residual state, and continues the rollout. This aligns the training distribution with the inference distribution. The key claim is that learning to consume someone else's residuals is not the same as learning to consume your own.

The second ingredient is stabilization of the residual pathway. The authors observe that under a shared optimizer, the residual branch can drift much faster than the backbone. ORL therefore rescales the residual pathway so that its effective update pace better matches the backbone. It also applies entropy-based supervision gating: positions that are already sufficiently confident are not pushed to sharpen further. This prevents over-contraction and reduces the risk of amplifying early mistakes.

The third ingredient is the adjacent entropy-contraction objective. Final-token supervision tells the model where each intermediate state should end up, but not how much progress each step should make. The paper shows that under standard supervision, entropy often stays nearly flat across denoising steps, and tokens-per-forward barely improves. ORL explicitly encourages the predictive distribution at step t+1 to be lower-entropy than at step t, subject to the gating mechanism above. This directly optimizes refinement speed: each forward pass should not only be more correct, but also more decisive.

On the systems side, ORL implements exact on-policy residual learning at scale. It asynchronously captures residual states off the decoding critical path, uses memory-adaptive transport to decide whether states stay resident or are offloaded, packs irregular trajectory states into dense training batches, and uses a compute-aware scheduler to balance rollout and training workloads across GPUs. The paper also mentions specialized staircase-style attention and packing to handle the irregular structure induced by progressive unmasking. These details are not peripheral; they are what make the training recipe practical beyond toy settings.13:T9ba,The experiments are organized around three questions: whether on-policy learning is necessary, whether entropy contraction improves refinement speed, and whether the resulting training pipeline is scalable.

The paper first provides a useful qualitative observation: intermediate residual predictions often already contain strong signals of the final tokens before commitment. That supports the idea that residual context is a meaningful computational state rather than a noisy byproduct. It then presents a key negative result: with ordinary intermediate supervision alone, entropy remains almost flat across denoising steps and tokens-per-forward barely increases. This is one of the most important empirical findings in the paper, because it shows that final correctness does not automatically translate into faster parallel refinement.

In the main comparisons, ORL improves the speed–quality Pareto over offline residual learning, non-on-policy variants, and versions without entropy contraction.
