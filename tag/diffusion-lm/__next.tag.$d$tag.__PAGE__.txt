9:T57b,A BDLM splits a length-L sequence into B contiguous blocks of size M=L/B. Blocks are generated left to right, while tokens inside a block are denoised in parallel. During training, each target block b is corrupted at a sampled diffusion time and denoised conditioned on the clean prefix x(<b). The total objective is a sum over per-block losses. The paper exploits this structure. In conventional implementations, training builds a length-2L representation containing a clean copy and a corrupted copy, then applies a block-causal attention mask. Under context parallelism, both clean and corrupted K/V are sharded and communicated. The mismatch is that clean prefixes are shared by many later blocks, while corrupted K/V are local to one block. Block parallelism assigns each complete corrupted-block computation to a rank, keeping that block’s corrupted Q/K/V, activations, and gradients local. This removes block-specific cross-rank communication. The drawback is replication of long overlapping clean prefixes. Context-sharded block parallelism fixes this by sharding the clean sequence across the same ranks: each rank owns clean K/V shards that can serve all local block computations whose prefixes include those shards, and backward contributions are accumulated at the shard owner. The first is Learnable Block Size (LBS). The authors observe that token entropy across positions often follows a staircase-like pattern, suggesting that some positions—contiguous or even non-contiguous—share similar uncertainty and semantic coherence. Instead of using fixed-size blocks or heuristic boundaries such as delimiters, LBS uses a lightweight network to predict block groupings on the fly from token-level statistics, including entropy, positional information, and semantic cues. The goal is not syntactic chunking. It is difficulty-aware grouping: easy tokens should not be delayed by harder ones simply because they happen to sit in the same fixed block.

The second is Learnable Parallel Sampling (LPS). Standard confidence-based decoding finalizes a token only when its confidence exceeds a threshold. The paper argues that this wastes computation because many tokens become correct well before their confidence reaches that threshold. LPS learns a position-aware finalization policy using per-token features such as entropy, position, and denoising step. It predicts which positions have already converged enough to be finalized early. Because LBS already organizes tokens into variable-length groups, LPS can operate under adaptive blocks rather than fixed boundaries.

A key design choice is that the paper does not modify the diffusion LM backbone or training objective. Instead, it adds lightweight decision modules on top of the decoder loop. This makes the method easier to integrate with existing dLLMs and compatible with KV-cache pipelines. The trade-off is that these auxiliary networks need to be trained, and their robustness may depend on the backbone, task distribution, and sampling setup. TDES, or Target-Distilled Edge Scoring, addresses parent-child mismatch. DDTree is effectively parent-agnostic: a child token contributes the same score regardless of which parent path it extends, because scoring is driven by per-position token probabilities. GRAFT instead learns an explicit edge scorer distilled from target-model traces. The scorer takes candidate parent-child pairs from adjacent positions, together with contextual features, and predicts how compatible that transition is with the target model. Tree assembly then uses these edge scores, rather than only the product of marginal token probabilities, to select target-compatible paths under a node budget.

Mechanistically, this is a lightweight structural predictor that compresses local target preferences into a cheap model. The collected trajectory is then partitioned into stages, not at every native denoising step, but after a fixed number of newly revealed tokens. The loss has two main components. The first is Confidence Adaptive KL Divergence (CAD), used to align distributions on still-masked positions. Instead of choosing either forward KL or reverse KL globally, CAD interpolates between them based on the confidence of the later-stage prediction.
