18:T57e,The starting point is a continuous flow language model over categorical sequences. Tokens are represented as one-hot vectors, the source distribution is Gaussian noise, and the model learns a denoiser along a continuous path from noise to data. Existing flow-map language models learn the solution operator X_{s,t}, often parameterized through a two-time denoiser δ_{s,t}, so that generation can jump directly from s=0 to t=1 in one forward pass. In the synchronous version, all token positions share the same scalar time, so every position denoises at the same rate.

Asynchronous FMLMs replace this scalar time with tokenwise times τ_i. Each τ_i measures the denoising progress of position i. A scheduler controls how these tokenwise times evolve. The schedule may be prescribed, or it may be learned and state-adaptive, in the spirit of masked diffusion samplers that decide which positions should be resolved earlier. The technical step that makes this well-defined is to treat the tokenwise times as part of the dynamical state. The model then follows a coupled flow over token representations and their time variables. The paper shows that this coupled process defines a valid flow map and derives distillation objectives for learning it. The resulting one-step model predicts both token evolution and time evolution, internalizing an ordering that would otherwise require multiple sampling steps.19:Tb5f,技术方案可以分成四部分看。

第一部分是理论分析。作者先分析中间状态 s = αe_i + βz 的解码竞争关系。若用欧氏距离，候选 token 的得分会分解成一个随信号缩小而衰减的对齐项，以及一个与当前状态无关的静态范数项。问题就在这里：当 α 变小，即便 β=0、状态方向仍完全对准源 token，低范数 token 也可能因为静态范数优势而“反超”。这不是语义替换，而是度量退化。于是作者转到方向空间，用 cosine / directional ranking 来定义竞争，得到 pairwise crossing 的阈值条件：候选是否超过源 token，取决于有效噪声是否大于两者的语义分离。这个阈值理论把 token identity metric 从经验统计量还原成了大量 pairwise crossing 的聚合结果。

第二部分是 noising geometry。既然问题来自 norm decay，作者就不再沿普通连续高斯轨迹做 corruption，而是设计了 spherical noising。做法是把状态看成沿球面 geodesic 向一个 mask-biased endpoint 插值。这样可以尽量保持向量范数稳定，把竞争关系限制在方向空间里发生，避免欧氏几何下的伪竞争。这里的关键不是“球面”这个词本身，而是它服务于一个更明确的目标：让 corruption 过程和 token competition 的真实判据一致。

第三部分是时间调度，也就是 Semantic Retention Scheduling。Competition Threshold Theory 说明，大量 identity crossing 只会在接近高噪声端才发生。若仍用常规时间参数化，训练的大部分步数都浪费在身份几乎不变的区间，真正困难的身份转移区间反而预算很少。作者因此按 logarithmic rank decay 重新分配时间步，把更多 denoising budget 放到 identity 快速变化的区间。这不是简单的 loss-aware resampling，而是直接围绕 token rank / identity decay 设计 schedule。

The main theoretical distinction is between peeking and identity-blind commit rules. A commit rule is peeking if the decision to commit a position depends on the identity of the token just sampled at that position, for example by favoring positions whose sampled token has higher probability. Such rules amplify majority options twice: they are more likely to be sampled and more likely to be kept. By contrast, identity-blind rules decide which positions to commit without looking at the sampled token identity. The paper formalizes this distinction and proves that under peeking rules, if commit probability increases with a score that increases with token probability, then the odds of the more probable option are further amplified. Identity-blind rules do not create this token-channel amplification.

The paper then identifies a second mechanism, the ordering channel. Even without peeking, confidence-based ordering can write gender-leaning or opinion-leaning context before the fork is resolved.
