5:T4dc,MindGames is built on TextArena, a text-only multi-agent environment with a gym-style interaction loop. A deterministic simulator maintains hidden state, renders an observation for the current player, receives a textual action, updates the state, and returns terminal rewards. The benchmark includes four games chosen to span different information and incentive structures: Colonel Blotto for hidden-information opponent modeling, Iterated Prisoner’s Dilemma for trust and betrayal under communication, Codenames for cooperative inference with constrained signaling, and Secret Mafia for deception and social deduction under partial observability. Evaluation is conducted through online matchmaking with TrueSkill ratings and full trajectory logging. Beyond the live arena, the paper introduces MG-Ref, a frozen reference pool of selected submissions plus a deterministic offline tournament protocol, so new agents can be rated offline with metrics compatible with the main benchmark. The competition was split into a Social Deduction Track and a Generalization Track, each with Unlimited and Efficient (<= 9B open-weight) divisions. The main empirical contribution is not a model comparison table but an evaluation audit across environments. The paper finds that IPD and Colonel Blotto provide relatively interpretable signals, Codenames mixes strategic quality with error avoidance, and Secret Mafia suffers from a pronounced error-survival confound, where rankings can reflect robustness to failures or the ability to exploit opponent breakdowns as much as genuine strategic reasoning. The authors also summarize recurring design patterns among strong submissions, including structured prompting, explicit memory, and code or state-tracking support, and they document common failure modes such as poor rule adherence, broken state tracking, and weak credit assignment. The key result is that benchmark reliability varies substantially by environment, so a single aggregate leaderboard should not be read as a clean measure of social
