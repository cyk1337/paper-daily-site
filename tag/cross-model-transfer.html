CacheBridge: Efficient Cross-Model KV Cache Transfer

这篇工作解决的是多模型系统里一个越来越实际的问题：当请求从一个 LLM 切换到另一个 LLM 时，接收模型无法直接复用发送模型的 KV cache，因为 cache 是模型内部表示，和架构、层、头、维度都绑定。于是目标模型必须对共享前缀重新 prefill，长上下文下这会带来明显延迟。已有的 closed-form 方法 Full-Head Mapping 试图用离线拟合的仿射映射把源模型 cache 直接转成目标模型 cache，但它默认每个目标头都从所有源头做全连接回归，导致三个问题：对架构差异很敏感、KV 重建误差和真实续写质量不一致、映射器存储和应用成本随支持层数快速增长。CacheBridge 要解决的就是如何在保持“训练自由、在线仍是仿射映射”的前提下，把跨模型 KV 转移做得更准、更便宜、更稳定。

评这不是 pretrain 论文，但问题很真；若你关心多模型 serving，只看它如何把 full-head 映射收缩成架构对齐版本，别被系统包装分散注意力。
Xingyu Qu,Siyuan Lu,Zhiyu Chen,Sheng Wang,Tao Lin

Cross-Model Memory Transfer via Target-Side Reader Adaptation

论文研究一个很具体的问题：Engram 式 hashed external memory 从源模型迁移到目标模型时，真正可复用的是冻结的 memory table，还是源模型与 memory 共同适配出来的接口。作者把问题定义为 cross-model frozen-memory transfer：源模型训练 memory 后导出并冻结，再接到不同目标模型上，只训练一个轻量 reader，看目标模型能否从固定 memory 中读出有用信号。

评只看 memory transfer 消融即可；若 reader 适配真能跨 backbone 稳定工作，值得进内部 memory-LM ablation。
