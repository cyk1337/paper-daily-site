SpecDrop: Parameter-Free Category-Conditioned Routing for Modular Specialization

这篇文章研究的是模块化网络里一个常被混在一起的问题：专家是否能学出真正的 specialization，究竟取决于路由器本身，还是取决于训练信号与划分类别之间是否对齐。作者的结论很明确：在很多场景里，瓶颈不在 learned router，而在 partition granularity 和 category clarity。也就是说，如果每个训练样本天然对应一个清晰类别，哪怕不用可学习路由，只用固定的按类 dropout，也能诱导出模块分工；如果样本本身跨域、跨技能、标签模糊，换更复杂的 router 也未必有用。

评结论在 CV 小模型且需推理时给标签，外推到语言 MoE 很弱；但“无参数路由打赢 learned gating”值得做个内部 ablation。
Boyao Wang,Zhihan Lei

Share the Judge, Learn the Deferral: Where Specialization Helps LLM Evaluation

Extracting Small Translation Specialists from LLMs by Aggressively Pruning Experts

这篇论文解决 MoE LLM 在机器翻译场景中过度参数化的问题。通用 MoE 模型具备大量与翻译无关的能力，部署翻译服务时仍要携带完整专家集合，导致显存和计算成本过高。论文目标是在不重新训练或只做少量恢复训练的情况下，从通用 MoE LLM 中抽取小型翻译专用子网。

评值得看，因为它直接碰 MoE 的一个硬问题：专家到底有多可分离；先看 pruning 准则和无重训结果，若 setup 干净，内部应复现。
