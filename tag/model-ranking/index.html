Seq@K: Evaluating Language Models Under Sequential Feedback

这篇工作要解决的问题很集中：现有 LLM/agent 评测大量使用 Pass@1 或 Pass@K，但这些指标默认每次尝试彼此独立，看不到模型在“失败—收到反馈—修正”这个真实使用闭环中的能力。论文提出 Seq@K，专门衡量模型在最多 K 次顺序尝试中，能否利用前序失败反馈完成任务。它要回答的不是模型会不会一次做对，而是模型会不会根据反馈逐步变好。

评这篇不改 pretrain prior，但会改你看 agent eval 的口径；只看协议定义和排名翻转结果，足够判断哪些 post-train 信号值得单独建模。

Who Thinks Best Depends on How Long You Let Them: Budget-Dependent Rankings in LLM Evaluation

这篇论文研究一个被标准评测默认忽略的问题：同一个模型在不同生成 token 预算下，能力排序、题目难度和模型互补性是否稳定。作者的结论是否定的。最大生成长度不是一个无关紧要的推理参数，而会改变模型是否答对、是否过度推理，以及哪个模型看起来更强。

评直接动摇现有leaderboard排名的稳定性假设，做内部评测或路由策略时必须纳入预算维度，重点看§3排名反转和§4路由实验。
Rodrigo Guedes de Souza,Alison R. Panisson
