Characterizing High Bandwidth Flash for LLM Serving

这篇文章要解决的问题很明确：当 LLM serving 进入长上下文、agentic multi-turn、prefix reuse 很重的阶段后，显存容量不再只是“能放下模型”这么简单，而是同时决定了 batch 大小、KV cache 保留率、重复 prefill 成本和整体吞吐。作者关心的是，高带宽闪存 HBF 能否作为 HBM 之外的设备侧扩展层，真正改善高吞吐 serving 的完成时间和能耗；如果能，前提是什么样的分层存储策略和调度策略。换句话说，问题不是“有没有更大内存”，而是“多出来的容量在真实多轮工作负载里怎样转化成有效吞吐，而不是变成低效搬运和高写入磨损”。

评只看系统模型和调度部分即可；对预训练不直接有用，但会改变长上下文 agent workload 的 KV 保留成本估计。
Zack Yu,Chloe Wong,Coleman Hooper,Minjae Lee,Wonjun Kang,Youngjin Cho,Michael W. Mahoney,Yakun Sophia Shao,Kurt Keutzer,Amir Gholami
