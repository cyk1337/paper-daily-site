9:T57e,The starting point is a continuous flow language model over categorical sequences. Tokens are represented as one-hot vectors, the source distribution is Gaussian noise, and the model learns a denoiser along a continuous path from noise to data. Existing flow-map language models learn the solution operator X_{s,t}, often parameterized through a two-time denoiser δ_{s,t}, so that generation can jump directly from s=0 to t=1 in one forward pass. In the synchronous version, all token positions share the same scalar time, so every position denoises at the same rate.

Asynchronous FMLMs replace this scalar time with tokenwise times τ_i. Each τ_i measures the denoising progress of position i. A scheduler controls how these tokenwise times evolve. The schedule may be prescribed, or it may be learned and state-adaptive, in the spirit of masked diffusion samplers that decide which positions should be resolved earlier. The technical step that makes this well-defined is to treat the tokenwise times as part of the dynamical state. The model then follows a coupled flow over token representations and their time variables. The paper shows that this coupled process defines a valid flow map and derives distillation objectives for learning it. MLFM uses a Brownian bridge as the stochastic interpolant between an embedded partially masked sequence and the embedded clean sequence. This choice is important for two reasons. First, the latent state evolves jointly across positions, so the model is not forced into the position-wise independence approximation used by standard masked diffusion models. That makes few-step generation better aligned with the true dependency structure of language. Second, at the boundary of the Brownian bridge, the interpolant reduces to the embedded partially masked sequence, which matches the input structure of pretrained MDMs. This enables warm-start adaptation from a large masked diffusion model instead of training a flow LM from scratch. Training follows the stochastic-interpolant / flow-matching view: the network learns a conditional velocity field that transports the continuous latent state toward clean token embeddings while conditioning on observed, unmasked tokens. Inference adds two mechanisms. The first is a new form of classifier-free guidance. Rather than only contrasting conditional and unconditional predictions, the method noises clean tokens inside the reference velocity so that the contribution of clean context can be isolated more cleanly. The second is online token promotion: once the posterior mode at a position exceeds a confidence threshold of 1-ε, that token is immediately committed and its clean embedding is inserted into the state. This means resolved tokens become usable context for later denoising steps instead of remaining noisy until the end.
