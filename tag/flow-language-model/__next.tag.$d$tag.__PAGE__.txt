MLFM uses a Brownian bridge as the stochastic interpolant between an embedded partially masked sequence and the embedded clean sequence. This choice is important for two reasons. First, the latent state evolves jointly across positions, so the model is not forced into the position-wise independence approximation used by standard masked diffusion models. That makes few-step generation better aligned with the true dependency structure of language. Second, at the boundary of the Brownian bridge, the interpolant reduces to the embedded partially masked sequence, which matches the input structure of pretrained MDMs. This enables warm-start adaptation from a large masked diffusion model instead of training a flow LM from scratch. Training follows the stochastic-interpolant / flow-matching view: the network learns a conditional velocity field that transports the continuous latent state toward clean token embeddings while conditioning on observed, unmasked tokens. Inference adds two mechanisms. The first is a new form of classifier-free guidance. Rather than only contrasting conditional and unconditional predictions, the method noises clean tokens inside the reference velocity so that the contribution of clean context can be isolated more cleanly. The second is online token promotion: once the posterior mode at a position exceeds a confidence threshold of 1-ε, that token is immediately committed and its clean embedding is inserted into the state. This means resolved tokens become usable context for later denoising steps instead of remaining noisy until the end.
