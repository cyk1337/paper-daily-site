9:T50e,GIFT trains a low-rank adapter on the pretrained base model, but replaces uniform token-level supervision with instruction-model-guided weighting. The pipeline has three stages. First, for each training pair, the instruction-tuned model runs once offline to produce token-level confidence scores q_t on the reference response. Second, these scores are used to reweight the token-level negative log-likelihood when training the adapter on the base model: tokens that the instruction model finds uncertain contribute less, while tokens it supports confidently contribute more. The motivation is that many target tokens are stylistic, formatting-related, or otherwise substitutable, and forcing the base model to fit them equally can inject noisy updates that later merge poorly into the instruction model. Third, the learned adapter is merged into the instruction-tuned model using a standard merge operator such as LoRA merging. Relative to Shadow-FT, Chat Vector, and related base-train-then-merge methods, the novelty is not in the merge rule but in using the instruction model during training to shape the learning signal.
