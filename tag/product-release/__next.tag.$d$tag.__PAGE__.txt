9:T52f,The system is built around managed agents in the Gemini Interactions API. A developer calls a single endpoint, while Gemini handles reasoning, code execution, package installation, file management, and web access inside an isolated cloud sandbox. The update adds four capabilities. First, background execution lets a client pass background: true, receive an interaction ID immediately, and later poll status, stream progress, or reconnect while the task continues on the server. Second, remote MCP integration lets managed agents connect directly to Model Context Protocol servers, so private APIs or databases can be exposed as tools without custom proxy middleware. Third, custom function calling composes local tools with built-in sandbox tools: server-side tools run automatically, while custom functions move the interaction into requires_action so the client can execute local business logic. Fourth, credential refresh allows a client to reuse an environment_id with a new network configuration, replacing rules or credentials while preserving the sandbox file system, installed packages, and cloned repositories. The main distinction from a chat-style agent is the runtime contract: tasks can survive disconnection, environments persist across interactions, and remote tool protocols become part of the execution plane.a:T753,The system is organized around a generalist coordinating agent. It has access to more than 60 curated skills and connectors for genomics, single-cell analysis, proteomics, structural biology, cheminformatics, and related life-science workflows. The coordinating agent can call tools, spawn other agents, and work with specialist agents created by users. A reviewer agent checks citations, calculations, and whether figures match the underlying code, then flags or corrects errors.

A key design choice is to treat scientific outputs as reproducible artifacts rather than final text or images. When Claude Science generates a figure, it stores the exact code, the execution environment, a plain-language account of how the figure was produced, and the full message history. Users can request edits in natural language, and the agent updates the code that produced the artifact. The app also renders scientific objects such as 3D protein structures, genome browser tracks, and chemical structures.

For compute, Claude Science can run locally on macOS or Linux, on a remote machine over SSH, on an HPC login node, or through Modal. It drafts a plan, asks before accessing new resources, and lets the user review or revoke decisions before submitting jobs. Large or sensitive datasets can remain on the lab’s own infrastructure; only the context needed for a given step is sent to Claude. A running session keeps context in memory, and users can fork a session to compare analysis paths.

The domain layer combines connectors to specialized resources such as UniProt, PDB, Ensembl, Reactome, ClinVar, ChEMBL, and GEO with access to external life-science models and libraries. Through NVIDIA’s BioNeMo Agent Toolkit, it connects to tools including Evo 2, Boltz-2, and OpenFold3. Labs can also package trusted pipelines as reusable skills so that future sessions inherit them.b:T6ed,There are no controlled benchmarks, ablation studies, or standard quantitative evaluations in the blog post. The evidence consists of system descriptions and beta-user case studies.

The concrete system numbers are: more than 60 preconfigured skills and connectors; compute scaling from a single GPU to hundreds of GPUs; beta availability for Claude Pro, Max, Team, and Enterprise users.

One case study comes from Manifold Bio. Claude Science was used to nominate targets for tissue-targeting medicines by assessing surface expression, trafficking, safety, and internal criteria learned from prior programs. The post does not report hit rates, experimental validation rates, or a controlled comparison against the previous process.

Another case study comes from Jérôme Lecoq at the Allen Institute. His team built a multi-agent computational review template with about 20 custom skills. Sub-agents read thousands of papers, extracted central claims and key quantitative findings, and stored them in an evidence state database. The workflow then built a narrative structure, wrote review sections with specialized agents, and generated quantitative cross-study figures from the evidence database. It used actor-critic pairs: one agent generated content while another checked accuracy and citation fidelity. The post says such reviews could previously take up to two years; the team now has about 10 reviews, many longer than 100 pages, with citations checked by reviewer agents. This is useful as a workflow signal, but it is not a rigorous evaluation.
