18:T440,The architecture interleaves local and global layers. Local layers use causal sliding-window attention with window size W. Inside these windows, RoPE is applied with a periodic index phi(t)=t mod W, so the rotation table is bounded to positions 0 through W-1 regardless of the absolute generation length. The paper proves that two tokens sharing the same periodic index are at least W positions apart and therefore cannot co-occur in the same length-W causal window. Global layers use attention without positional encoding, allowing information to move across windows without consuming new position indices. The design is motivated by earlier NoPE-style long-context architectures: causal convolution plus NoPE reportedly suffered from repetition, SWA+ALiBi improved stability, and P-RoPE is introduced as a RoPE-based local alternative that avoids manually chosen ALiBi slopes.
