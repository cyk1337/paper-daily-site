HybridCUA: Learning to Orchestrate GUI and CLI for Computer-Use Agents

这篇论文讨论 computer-use agent 如何在 GUI 和 CLI 之间选择合适的执行方式。GUI 通用但慢，坐标操作容易出错；CLI 高效、可组合，但现有模型通常不知道何时使用、如何使用，也缺少覆盖 GUI-only、CLI-only 和混合执行的训练轨迹。
