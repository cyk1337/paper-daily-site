PIVOT: Progressive Intervention via Online Teacher Correction

这篇工作处理的是 RLVR 在高难推理任务上的一个老问题：当学生策略几乎采样不到正确解时，只有 outcome-level 的二值 verifier reward，组内所有 rollout 都是 0，GRPO 一类方法就没有有效优势信号，训练会停在“不会做所以学不到”的状态。作者进一步指出，单独引入 teacher 也不够，因为 teacher 信号有两种不同作用：一类是把训练轨迹拉到更可能成功的区域，解决“采不到正样本”；另一类是给局部 token 提供稠密监督，解决“即使有好轨迹，学生也未必学得会”。如果只做前者，teacher 轨迹可能偏离学生分布，难以模仿；如果只做后者，学生已经走偏时，局部蒸馏也救不回来。论文的核心问题就是：怎样把 teacher 纠错同时用于轨迹构造和 token 监督，让 RLVR 在 hard reasoning 上真正获得可学习信号。

评探讨了在 RL 阶段如何优雅地引入 teacher 信号（干预+KL监督）来解决 sparse reward 问题，对当前做 reasoning RL (如 R1-Zero 范式) 遇到瓶颈的团队很有参考价值。
