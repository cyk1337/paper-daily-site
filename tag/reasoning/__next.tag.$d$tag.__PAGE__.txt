The design centers on:
1) Session isolation with controlled reuse: sessions can be isolated or shared; file resets and memory retention are controlled separately. When shared memory is updated by attempts, executions are forced to be sequential and not automatically retried, since failures can change inherited state.
2) Harness-native adapters: instead of forcing a unified agent loop, adapters standardize task I/O while preserving each harness’s native model-call patterns, tool permissions, feedback loops, and context updates—keeping comparisons faithful to real harness behavior.
3) Evidence-linked artifacts: each attempt stores an outcome record (correctness, score_status, runtime errors) linked to normalized traces (roles, content, tool calls/results) and resource usage (tokens, runtime). Reports include failed/unscored attempts, and the system uses the latest record per requested evaluation so retries do not inflate the evaluation count.

更具体地说，对同一道题 x，当前策略会采样 K 条解题轨迹。训练某一条 student trajectory 的某个前缀时，作者从同题样本里随机选 M 条 peer solution，再额外取一条来自其他题目的 cross-problem solution 作为 control。冻结的初始模型分别在“student prefix + 某条同题 peer”和“student prefix + cross-problem control”条件下给出 next-token 分布。两者之差可以看成该 peer 对教师分布施加的 residual shift。SRD 不直接平均这些 shift，而是做一个很保守的聚合：只保留那些在多个 peer 上方向一致的坐标，并把保留坐标的幅度截到所有支持该方向的 peer 中最小的那个。然后把这个 shared residual 加回冻结模型在 student 原始输入下的分布，形成 teacher target，学生再用 forward KL 去拟合。

这个设计有几个关键点。第一，cross-problem control 的作用是消掉“给模型额外看一段解答文本”带来的通用风格偏移，只保留与当前题目相关的 peer-induced change。没有这个参照，模型可能学到的是 generic solution-format bias，而不是题目局部推理信息。第二，取最小支持幅度而不是平均，是为了抑制错误 peer 带来的过强偏移，属于一种保守的交集式蒸馏。第三，学生训练时只看题目和自己的前缀，不看 peer；peer 只在训练时用于构造 teacher，因此推理时没有额外开销。这一点和 privileged-information distillation 的设定一致。

和 GRPO、RLVR 的区别很清楚：SRD 不需要 reward，也不需要按答案对错给 trajectory 排序。和标准 OPD 的区别在于，teacher 不是外部更强模型；和 OPSD 的区别在于，训练时也没有 reference answer，只利用同题 peer 的共享局部信号。论文真正的新意就在这里：把“多条未经验证解之间的一致残差”当成 dense token-level supervision。d:T7d7,The method is Shared Residual Distillation (SRD), an on-policy self-distillation scheme without privileged reference answers. The key idea is not to imitate any single peer solution. Instead, SRD measures how different same-problem peers consistently shift a frozen model’s token distribution relative to a shared control.

For a problem x, the current policy samples K trajectories. When training on a student-generated prefix, the method selects M same-problem peers and one cross-problem solution as a control. A frozen copy of the initial model predicts next-token distributions under two conditions: the student prefix plus a same-problem peer, and the student prefix plus the cross-problem control. Their difference is a peer-induced residual shift. SRD then aggregates these residuals conservatively: it keeps only coordinates whose direction agrees across peers, and sets the retained magnitude to the smallest supporting magnitude among those peers. This shared residual is added back to the frozen model’s distribution under the original student input, producing a teacher target. The student is trained with forward KL on that target.

Three design choices matter. First, the cross-problem control removes generic distribution shifts caused by simply appending a solution-like text, so the retained residual is more problem-specific. Second, the minimum-supported magnitude acts as a conservative intersection rule, reducing the influence of noisy or wrong peers. Third, peers are used only to construct the teacher during training; the student itself conditions only on the problem and its own prefix, so inference cost does not increase.

Compared with RLVR or GRPO, SRD needs no reward and no answer-level ranking. Compared with standard on-policy distillation, it does not rely on an external stronger teacher. Compared with prior on-policy self-distillation, it does not require reference answers.
