19:T446,The authors use MGSM and ask each model to solve the same problems independently in six languages. They keep only examples with valid reasoning traces in all languages, replay those traces, and record residual-stream activations at multiple layers. Candidate layers are selected with linear CKA: for each layer, pre-answer token representations are aligned by problem ID across languages, and the contiguous depth range with the highest mean pairwise CKA is chosen.

At each selected layer, two top-K sparse autoencoders are trained. The baseline SAE uses reconstruction loss only, with K=128 active features, a 4× dictionary expansion, and unit-norm decoder columns. GI-SAE keeps the same architecture but adds an InfoNCE contrastive term that pulls together feature activations corresponding to the same problem in different languages. The decisive evaluation is causal patching: shared feature values are swapped between languages, and the effect is measured through KL divergence in the downstream output distribution. This separates geometric alignment from functional interchangeability.1a:T40c,The study covers five models from four architecture families, six languages, and 78 layer observations, with both baseline SAE and GI-SAE trained for each observation. The main finding is that GI-SAE improves geometric similarity almost everywhere, but functional interchangeability improves only under specific conditions. When baseline sharing is moderate, the convergent profile shows an 83% win rate for GI-SAE, with a 95% confidence interval of [64, 93]%. In low-sharing layers, GI-SAE has no systematic benefit. In saturated layers, the win rate drops to 6%, suggesting little room for improvement.

The result is useful because it identifies a failure mode of contrastive representation learning for interpretability. The contrastive loss can make features look more aligned, but if the model has not already developed a partially shared computational substrate, that alignment may not support causal substitution. The paper also reports a normalized-space sensitivity check, with the Qwen convergent results described as stable.1b:T57a,The contribution is not a new generator but a careful intervention framework. GoT-R1-1B first emits a textual plan containing object spans, attributes, and bounding boxes, then generates 576 image tokens conditioned on both prompt and plan. The analysis has four parts. First, metric validation: the authors swap the two boxes inside the model's own chain, creating a known layout corruption, and test whether different evaluators detect it. Second, decoder-faithfulness tests: they compare planned relations against detected image layouts, and perturb object-segment order or remove the chain to identify what signal the decoder actually uses. Third, external-plan injection: they feed oracle plans into the decoder while varying text style and box statistics, to test whether execution depends on planner-specific phrasing, likelihood, or simply geometric quality. Fourth, inference-time repair: they apply symbolic verification, resampling, and minimal edits to planner outputs without retraining the model. A notable mechanistic finding is that the decoder binds boxes to object semantics rather than to positional slots in the serialized plan. Reordering object segments does not make it blindly follow token order, but internally inconsistent plans can trigger duplication and identity fusion. That points to a learned semantic-to-geometric conditioning map rather than brittle template matching.1c:T64c,Experiments use the color and spatial validation subsets of T2I-CompBench++, 300 prompts each. The model is GoT-R1-1B with 384px outputs, 576 image tokens, CFG 5.0, temperature 1.0, and matched decoding settings across all conditions. Headline results are tested with paired permutation tests. Key findings: 1) evaluator failure: swapping the two boxes flips the generated layout, and detector-based spatial accuracy drops from 0.75 to 0.48 (p<1e-3), while a VQA-style spatial score increases, showing that the judge is not layout-sensitive; 2) decoder faithfulness: on unperturbed chains, 94% of generated layouts realize the planned relation, with planned-vs-detected box IoU of 0.75; 3) planner bottleneck: roughly one in five prompts yields an invalid relation in the plan, and planning accuracy is highly phrasing-sensitive, ranging from 98% to 54% for semantically equivalent layouts, which the authors trace to mention-order or raster-order bias; 4) external plans: correct injected plans with clean, well-separated boxes outperform the model's own plans by +13.3 points (p=1e-4), while plans that preserve the planner's overlapping box statistics provide little benefit; text style, whether terse or verbose, matters little, and planner-likeness is irrelevant despite a 5x NLL gap; 5) training-free fixes: symbolic verification with resampling gives +5.0 points, and minimal in-place repair gives +6.0 points. Another important negative result is that removing the chain sharply hurts object presence, indicating that the plan is a primary conditioning channel rather than a decorative explanation layer.1d:T605,Model generation as a finite-horizon MDP: state = token prefix, action = next token, reward only at the end and normalized to [0,1]. Define policy variance σ^2_π(s)=Var_{a~π}[Q^π(s,a)]. Under deterministic transitions, the environment term in the return-variance decomposition vanishes, yielding a clean identity: trajectory return variance equals the sum over time of expected σ^2_π(s_t). This motivates “critical forks”: states with σ^2_π(s) above a threshold τ.

The paper separates two questions with different complexity regimes:
(1) Local discovery: how many samples from π(·|s) are needed to even observe an action with advantage ≥ c. Using concentration/one-sided inequalities (Cantelli/Chebyshev/Markov variants) on the centered advantage draw A^π(s,a), they derive a polynomial lower bound Ω(c^2/σ^2_π(s)), and show tightness on a canonical two-action fork.
(2) Long-horizon estimation: once such an action is observed, how many full trajectories are needed to estimate its advantage accurately enough to act on; this scales exponentially with remaining horizon, motivating local credit assignment.

They also provide a rollout-free screening step: bound σ^2_π(s) by the Gini–Simpson dispersion 𝒟(s)=1-||π(·|s)||_2^2, computable from a single next-token distribution. Low-dispersion states cannot be critical forks, though high dispersion is not sufficient (many paraphrase/formatting choices can be value-equivalent). Extensions to stochastic environments clarify which arguments rely on determinism.1e:T858,方法叫 R²-OPD，关键设计有三步。第一步，用 teacher-independent 的 process reward 估计 reasoning progress。做法不是只看最终答对与否，而是对连续推理状态采样后续 continuation，比较从不同中间状态继续生成时的 solve probability 变化，把某段推理对最终解题概率的边际贡献当作 progress signal。作者强调 raw process reward 噪声很大，原因一是 Monte Carlo continuation 采样方差，二是中间 reasoning span 的边界本身不稳定。

第二步，做 sign-consistent span merging。原始轨迹先被切成 reasoning spans，然后把 process reward 符号一致、相邻的 span 合并成更大的 segment。这样做有两个目的：一是减少对细粒度边界估计的依赖，二是让后续比较发生在更稳定的语义单元上。文中给了理论说明：如果内部边界估计有误差，合并后这些误差在段内会相互抵消；同时对 token-level divergence 做段内平均，也能在弱相关假设下降低局部方差。

第三步，用 ranking conflict 做 reward filtering，而不是 reward replacement。对每个合并后的 segment，作者聚合 token-level reverse-KL distillation loss，得到该段“偏离 teacher 的惩罚强度”；同时用 process reward 给出该段“推进解题的贡献”。如果两个排序冲突，例如 progress 更高的段反而被蒸馏损失惩罚得更重，就说明 teacher guidance 在这一局部可能不可靠。R²-OPD 不把 process reward 加到 loss 里，也不重写 OPD objective，而是把这些冲突段的 distillation reward mask 掉，只保留 progress 与 distillation 一致的部分继续监督。这个选择很关键：它把 process reward 用作校验器而不是训练主信号，降低了高噪声 reward 直接驱动优化的风险。

从实现上，论文基于 reverse-KL OPD，并采用 support-restricted 近似来计算 token-level KL，只在学生或师生联合的 top-H support 上做分布匹配，避免全词表计算。R²-OPD 叠加在这个标准 OPD 框架之上，因此兼容现有 on-policy 蒸馏流水线。1f:T866,The method, R²-OPD, has three main components. First, it estimates reasoning progress using teacher-independent process rewards. Instead of relying only on final correctness, it samples continuations from successive intermediate reasoning states and measures how the probability of solving the task changes. This gives a marginal contribution estimate for each reasoning span. The paper emphasizes that raw process rewards are noisy because continuation-based estimation has Monte Carlo variance and because fine-grained reasoning boundaries are themselves unstable.

Second, it performs sign-consistent span merging. The trajectory is segmented into reasoning spans, and adjacent spans with process rewards of the same sign are merged into larger segments. This reduces sensitivity to noisy internal boundaries and creates more stable units for calibration. The theoretical discussion argues that internal boundary estimation errors can cancel within merged segments, and that averaging token-level divergence over a segment reduces local variance under weak dependence assumptions.

Third, it detects local ranking conflicts between progress and distillation penalty, and uses those conflicts for filtering. For each merged segment, token-level reverse-KL distillation losses are aggregated into a segment-level penalty for deviating from the teacher. Process reward gives a segment-level estimate of reasoning advancement. If a higher-progress segment is penalized more heavily than a lower-progress one, the two signals disagree in ranking, indicating that teacher supervision may be unreliable there. Instead of adding process reward into the objective or replacing OPD, R²-OPD masks distillation rewards on the most inconsistent segments and keeps teacher guidance elsewhere.

This design choice is the core idea. Process reward is treated as a reliability probe rather than a primary training signal, which avoids directly optimizing against a high-variance reward. The implementation is built on reverse-KL OPD with support-restricted approximation over a top-H token set, so the method can be layered onto standard practical OPD pipelines.20:T776,The experimental section is aimed at validating the signal-calibration hypothesis rather than demonstrating a large-scale model jump. The tasks are reasoning-heavy, and the comparisons include vanilla OPD, variants that directly incorporate outcome or process rewards, and alternative filtering or weighting strategies.

Three findings stand out. First, the mismatch is real: the paper provides qualitative examples and aggregate analysis showing that some intermediate spans increase downstream solve probability while receiving stronger distillation penalties because they diverge from the teacher distribution. This is especially visible on harder reasoning problems.

Second, the gains come from removing bad supervision rather than injecting another reward. Compared with directly mixing process rewards into optimization, the filtering-based approach is more stable and more consistently helpful. The explanation is straightforward: raw process rewards are noisy, so using them as direct optimization targets can distort learning, whereas using them only to suppress clearly inconsistent teacher signals is safer.

Third, the ablations support the two main design choices: sign-consistent merging and segment-level averaging. Without merging, conflict detection becomes more brittle because boundary noise leaks into the comparison. With token-level filtering instead of segment-level filtering, lexical fluctuations create more false conflicts. The paper also studies the masking ratio and shows that more masking is not always better; excessive filtering removes useful teacher transfer.

That supports a practical conclusion: the main bottleneck in multilingual RL is not merely data availability, but the interaction among initial language competence, reward attainability, and policy drift during RL.25:T60e,CLR is a training-free two-stage framework. In Stage 1, the model samples K full solution traces. Each trace must output not only a final answer but also exactly M decision-critical claims: concise intermediate propositions whose failure would undermine the answer. These are meant to be semantic anchors such as key constraints, transformations, maximality conditions, or intermediate conclusions, not generic summaries or answer restatements. The purpose is to compress a long reasoning trace into a small set of high-information, checkable propositions. In Stage 2, the same model is not asked to solve the problem again. Instead, it receives only the original problem and the extracted claims, and it actively searches for contradictions, counterexamples, missing conditions, factual mistakes, or unsupported inferences. The central design choice is falsification rather than proof. There is a useful asymmetry here: constructing a fully correct solution is hard, but invalidating a wrong trace only requires finding one decisive flaw. After verification, CLR maps claim-level verdicts into a nonlinear trace-level reliability score and aggregates answer groups by total reliability. This allows a reliable minority to overturn an incorrect majority. Relative to self-consistency, the method reallocates part of the budget from generating more traces to verifying the semantic anchors of existing traces. - On easy/medium problems, correct traces tend to have higher average confidence.

- Instead of maximizing confidence uniformly, it enforces temporal asymmetry: penalize high confidence early (to avoid premature commitment) while rewarding high confidence late (to ensure convergence).
