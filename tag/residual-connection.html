Low-Rank Attention Residuals

这篇工作处理的是一种很具体但不小的问题：如果把 Transformer 里的固定 residual sum 换成沿“深度轴”做 attention，模型确实能学会在不同层输出之间做选择，但原始 AttnRes 把同一个子层输出同时当作 residual value 和 routing key，用全维度 hidden state 既承载表示、又负责路由打分。这样会带来两个问题。第一，表示和路由耦合，子层输出既要保留给后续层使用的信息，又要长得适合被 depth attention 选中，目标并不一致。第二，depth routing 的打分复杂度跟 hidden width d 线性相关，但它实际只是在几十个历史子层输出之间做选择，不像 token attention 那样需要高维相似度来区分大量位置。论文的核心就是把“残差内容”和“深度路由”拆开：value 仍保持全维，key 改成低秩、小维度表示，从而降低额外计算，并改善路由行为。

评深度路由只需低维key即可生效的结论值得在内部架构消融中复现，重点看§3的两种低秩设计与§4的缩放实验。
