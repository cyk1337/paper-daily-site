RBS-Attention: Radius-Bounded Sparse Prefill for Long-Context Large Language Models

长上下文 LLM 推理中的 prefill 阶段计算成本过高，而现有的基于块稀疏（block-sparse）的 prefill 方法容易出现“均值稀释”（mean dilution）问题：即一个高度相关的 token 被大量不相关的 token 包围时，其所在的块的平均相关性得分会被拉低，导致该块被错误丢弃。
