b:T455,HiLight is an Actor–Solver pipeline.
- Solver: a frozen LLM that performs the task on an emphasized version of the original context.
- Emphasis Actor: a lightweight policy that inserts minimal highlight tags around selected spans while preserving the raw context (no summarization, no rewriting).
Core design choices:
1) Non-destructive emphasis instead of compression/rewriting to avoid evidence loss and semantic drift.
2) Emphasis instead of hard pruning; the full context remains available, and tags act as attention/attribution cues.
3) Weakly supervised RL: the Actor is trained using only the solver’s task reward, with no token-level evidence labels and no access to solver gradients/activations—making it compatible with proprietary/API solvers.
4) Transfer hypothesis: because the Actor learns an input-level evidence policy rather than solver-specific internal features, it should generalize across solver families/scales; the paper validates this empirically.
