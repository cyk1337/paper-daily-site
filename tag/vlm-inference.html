WaveZip: Wavelet-Driven Space-Time Decoupling for Video Token Condensation

长视频输入LVLM时会产生海量时空视觉token，导致注意力计算复杂度随token数二次增长，推理效率低下。现有token压缩方法直接在空间特征域操作：硬剪枝会破坏空间连贯性，均匀合并会模糊语义显著区域，根源是这类方法在空域无法解耦两类混淆——空间维度上，任务相关的细粒度证据和冗余背景纹理混杂；时间维度上，慢变的语义趋势和采样噪声、视觉抖动、场景突变等高频波动混杂，即频率混淆问题。

评把“压缩决策放到频域”这条路走得更系统，适合做长视频推理的可解释基线；重点看频带假设是否在不同数据集/模型上稳。

Rotation-Aligned Key Channel Pruning for Efficient Vision-Language Model Inference

这篇论文解决 VLM 推理时视觉 KV cache 过大的问题。视觉输入通常被编码成数百到数千个 token，图像、视频和多图场景会让 KV cache 成为主要显存瓶颈。现有方法多做视觉 token pruning，但直接丢 token 会伤害文档理解、细粒度感知和 grounding 等任务。作者转向另一个压缩轴：在保留更多视觉 token 的同时压缩 Key 的 channel 维度。

评别把它当“新模型”，当成 VLM KV 压力的工程解法：重点看旋转对齐+结构化 mask 是否真比纯 token pruning 稳。
