GROM: Gradient-Free Rapid One-Shot Machine Unlearning

这篇工作处理的是 LLM 机器遗忘里一个很具体但长期存在的问题：现有主流方法大多依赖梯度微调，在 forget set 上压低概率、在 retain set 上尽量保性能，但这种做法成本高、调参重，而且遗忘往往不够“物理”。论文指出，很多微调式遗忘只是把目标知识藏进了小幅权重扰动里，低比特量化后会被重新暴露。作者要解决的不是再设计一个更稳的遗忘 loss，而是把遗忘直接改写成一个可解析求解的线性代数问题：对选定层做一次加性更新，在不破坏保留数据输出的前提下，显式压制需要删除的 token 或表征方向，并且整个过程不做反向传播、不做迭代优化。

评揭露梯度类机器遗忘的核心缺陷：仅隐藏知识而非真删除，量化即可复原，闭式解思路简洁可复用

Frustratingly Simple Black-Box Adaptation of Language Models via Logit Bias

这篇工作研究一个很受限但现实的问题：当模型只能通过 API 调用、拿不到权重、梯度和隐藏状态时，能否只靠一个对全词表共享、且在每个解码步都固定加到 logits 上的向量，完成有用的模型适配。论文关心的不是通用能力提升，而是这类黑盒部署场景下的最小控制原语是否足以实现稳定的行为修正，例如缩短输出、改善格式、在小规模私有分布上做轻量适配。全文的关键点是把这个问题写成 KL 正则化的 RL：最优策略天然是 prefix-dependent 的，而作者研究的是一个极弱的近似族——context-independent 的固定 logit bias，进而分析这种近似什么时候有效、误差来自哪里、如何在黑盒条件下估计和学习。

评方法极简且有理论支撑，§3的推导和§4的实验设计值得参考，可用于内部轻量适配的快速验证。
