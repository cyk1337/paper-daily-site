18:T8c5,方法核心是 Bounded Continuation Analysis（BCA）。作者把给定 prompt 下的自回归生成过程近似成一个有界的随机过程：从初始前缀出发，逐步展开一个 bounded continuation tree，只保留有限深度、且在概率上足够重要的续写路径。树上的节点是 token prefix，边对应下一 token 的条件概率。由于完整枚举整个输出空间不可行，BCA 只在有限 horizon 内构造高概率子树，再把终止续写交给语义 harm evaluator 打标签，判断该续写是否构成有害响应。随后，作者计算在这个有界树中“最终到达有害终端”的总概率，称为 bounded harm reachability。

这个设计有几个关键点。第一，它不是把 harm 判定放在 token 级，而是放在语义级终端续写上，这样能避免局部 token 模式和真实有害行为之间的错位。第二，它显式利用了自回归模型的条件概率，因此得到的是一个 reachability probability，而不是 judge 打分的启发式分数。第三，它把问题表述成 probabilistic model checking 里的 reachability 问题，用离散时间马尔可夫链和 PCTL 风格的“eventually reach harmful state”来组织计算，这让指标定义比较干净。

在固定 prompt 之外，作者还定义了 GAS（generative attack susceptibility），把自适应攻击预算映射到一个概率值：在攻击者迄今找到的所有 prompt 中，哪一个 prompt 的 bounded harm reachability 最高。这个定义适合黑盒 adaptive jailbreak search。实验里主要结合 PAIR 和 TAP 两类搜索：前者是顺序式 prompt refinement，后者是带分支和剪枝的搜索。作者还讨论了把 BCA 作为搜索信号，与传统 judge-guided 搜索并行使用，从而覆盖不同失败模式。

从方法取舍看，作者没有试图估计“全空间真实 harmful probability”，而是退到 bounded、high-probability tree 上做近似。这是合理的，因为完整分布不可算，且安全评测更关心攻击者在有限生成预算内能否触达有害区域。代价是结果依赖 horizon、树展开策略和 evaluator 质量；作者也承认 BCA 是一个 bounded proxy，而不是精确的全分布积分。19:T84b,The core method is Bounded Continuation Analysis (BCA). For a given prompt, the model’s autoregressive generation process is approximated as a bounded stochastic process over token prefixes. Starting from the prompt, BCA expands a bounded continuation tree up to a finite horizon, keeping only continuations that are sufficiently probable. Nodes are token prefixes, edges are next-token conditional probabilities, and terminal continuations are labeled as harmful or safe by a semantic harm evaluator. BCA then computes the probability of eventually reaching a harmful terminal within this bounded tree, which the paper calls bounded harm reachability.

Several design choices matter. First, harm is evaluated semantically at terminal continuations rather than by token-level heuristics, which better matches the actual safety question. Second, the score is probability-aware: it uses the model’s conditional distribution instead of only sampled outputs. Third, the formulation is grounded in probabilistic model checking, using a discrete-time Markov chain view and a reachability-style property analogous to “eventually reach a harmful state.” That gives the metric a clean formal interpretation.

The paper extends fixed-prompt analysis to adaptive attacks via Generative Attack Susceptibility (GAS). GAS maps an attack budget to the maximum bounded harm reachability among all prompts discovered so far by the attacker. This is evaluated with two black-box adaptive jailbreak methods, PAIR and TAP, which represent different search structures. The paper also studies using BCA itself as a search signal, alongside standard judge-guided search.

An important practical choice is that the method does not attempt to estimate the full harmful probability over the entire output space. Instead, it works on a bounded, high-probability continuation tree. That is a reasonable compromise: exact full-distribution computation is intractable, and finite-horizon reachability is closer to the operational threat model. The trade-off is that results depend on the horizon, tree-construction policy, and evaluator quality.1a:T640,The main empirical findings come in three parts. First, across several open-source instruction-tuned models with 0% greedy ASR on JailbreakBench, BCA still reveals nearly two orders of magnitude variation in hidden harmful mass. This is the central empirical point: identical refusal outcomes can hide very different levels of latent vulnerability.

Second, BCA correlates with realized attack outcomes under repeated sampling. For each behavior-template pair, the authors sample 100 completions from the target model and compute empirical ASR using HarmBench-Mistral-7B as the harm classifier. BCA’s reachability score tracks which prompts are more likely to yield harmful outputs under repeated sampling, suggesting that it captures something operationally meaningful rather than merely redefining the metric.

Third, in adaptive red-teaming, BCA-guided search and judge-guided search are complementary. Running them in parallel increases jailbreak coverage relative to either one alone. This indicates that the two signals explore different regions of prompt space: judge-guided search chases already realized harmful outputs, while BCA-guided search can prioritize prompts whose local continuation distribution still contains substantial harmful mass even if a harmful sample has not yet been observed.

From a foundation-model perspective, the most useful takeaway is the “0% greedy ASR but nontrivial hidden harmful mass” phenomenon.
