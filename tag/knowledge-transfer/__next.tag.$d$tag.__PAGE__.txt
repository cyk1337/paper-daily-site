9:T8fd,方法核心是把 teacher 与 student 的预测重写到一个 common support 上。做法分三步。

第一步是序列对齐。作者先用字符级 offset 和 decode 后文本一致性检查，找出 student token 序列与 teacher token 序列中覆盖同一文本子串的 chunk 对齐关系。这样对齐的不是 token id，而是“相同文本跨度”。

第二步是 common-support construction。对每个对齐 chunk，构造一组“文本等价 continuation event”。如果是 1-to-1 chunk，事件可以是两边词表里 decode 成同一字符串的 token 对；如果是 1-to-many 或 many-to-1，事件就变成“一边一个 token，对应另一边一个 token sequence”。关键点在于，sequence event 的概率不是额外建模，而是直接用自回归链式法则，把 chunk 内各步条件概率连乘得到。文中举的例子是 teacher 一个 token“120”对应 student 三个 token“[1][2][0]”；固定前缀 [1][2] 后，可以把 120↔[1][2][0]、121↔[1][2][1] 等都作为显式事件。这样做比 ALM 只保留 observed chunk 更细，因为它把 alternative continuations 也展开到了共同支持集里。

第三步是 residual normalization + uniform matching。显式列出的共同事件之外，其余概率质量都并入一个 residual event。于是 teacher 和 student 都得到定义在同一 support 上的归一化分布，可以统一用一个分布匹配目标训练，不再需要像 X-Token 那样按 tokenizer 覆盖率切换 P-KL/H-KL。这个设计的取舍很清楚：它不追求枚举全部跨词表续写，而是在可计算的 support 上尽量保留结构，再用 residual 保证概率闭合。

从全文看，真正的创新不只是“加了一个 residual”，而是把跨 tokenizer 对齐从 token identity matching 改成 text-equivalent event matching，并且把 one-to-many / many-to-one 情况纳入同一个目标。这样统一后，训练接口更像标准 logits KD，工程上更容易接到现有蒸馏流水线里。

另一个实用点是 top-k distillation。作者发现只取 teacher top-16 或 top-128 token 来构造 support，平均性能只小幅下降，但训练步时显著降低。这说明 CSD 的收益主要来自 teacher 分布头部的结构信息，而不是完整长尾。a:T878,CSD builds a common support of text-equivalent continuation events and matches teacher and student on that support.

Step 1 is sequence alignment. The method aligns student and teacher token ranges that decode to the same text span, using character offsets plus decoded-text consistency checks. The alignment target is therefore shared text, not shared token ids.

Step 2 is common-support construction. For each aligned chunk, CSD defines explicit events corresponding to equivalent textual continuations. In 1-to-1 cases, an event can be a pair of tokens from the two vocabularies that decode to the same string. In 1-to-many or many-to-1 cases, an event becomes a token on one side paired with a token sequence on the other side. The probability of a sequence event is computed directly from the model’s autoregressive conditionals via the chain rule. The example in the paper is a teacher token like “120” aligned with a student sequence “[1][2][0]”; by fixing the within-chunk prefix “[1][2]”, one can enumerate events such as 120↔[1][2][0], 121↔[1][2][1], and so on. This is the key difference from ALM: CSD does not only keep the observed chunk and a catch-all complement, but explicitly represents alternative continuations when they can be mapped onto shared textual outcomes.

Step 3 is residual normalization and uniform matching. Any probability mass outside the selected explicit support is assigned to a residual event. This gives both teacher and student normalized distributions over the same event set, so a single matching objective can be used across chunk types and tokenizer pairs. That removes the need for pair-specific loss selection such as X-Token’s P-KL versus H-KL.

The real contribution is not merely adding a residual bucket. It is the move from token-identity matching to text-equivalent event matching, while covering 1-to-1, 1-to-many, and many-to-1 cases within one formulation. The technical contribution is organized into four parts.

1) Knowledge flow. The authors first measure transfer among language, visual understanding, and visual generation on real-world data, then move to synthetic controlled environments to remove confounders. The key point is not just whether multitask training helps, but which capability transfers to which other capability, and whether the transfer is symmetric. Their answer is no: transfer is strongly asymmetric, and the interaction between visual understanding and visual generation is concept-dependent rather than universally positive.

2) Synergy vs. competition. The paper traces modality interaction to both data complexity and network structure. On the data side, simplified tasks in one modality can help the other modality, while high complexity can create competition for capacity. On the architecture side, the authors analyze where sharing helps and where separation is safer. Shared attention appears to support cross-modal routing and communication, while separate FFNs reduce destructive interference by keeping modality-specific transformations private. This is a useful architectural decomposition: attention as the communication layer, FFN as the modality-specialized computation layer.

3) Early unification. The paper varies when vision is introduced and how modalities are scheduled during training. The main result is that vision should be present early and trained jointly with language, not added after a strong language prior has already formed. Late introduction leads to what the authors call “vision laziness”: the model leans on existing language priors and under-optimizes the vision-related components. This is an important challenge to the common retrofit paradigm.
