18:T7fb,方法核心是 Stratified Sparse Attention，简称 SSA。思路可以概括成两层：先确定性保留一部分“高置信” token，再对剩余 token 按 proxy score 做重要性采样，而不是均匀采样。这里的 proxy score 是对真实 attention score 的廉价近似，用来避免对全量 KV 做精确打分。论文把 dense attention 看成对所有 value 的加权求和，然后把 sparse approximation 写成一个分层估计器：

1. 确定性层。先根据 proxy score 选出一组 heavy hitters。这个集合承担“低偏差”角色，确保高质量注意力质量块不会被采样噪声破坏。
2. 随机层。对剩余 token 不再一视同仁，而是按 proxy-guided distribution 采样。采样后用 importance weighting 做无偏或近无偏估计，从而把预算集中到更可能承载 residual mass 的位置。
3. 统一框架。作者把 top-k、top-p、top-k+uniform sampling 等都放进同一个框架里理解：它们只是 deterministic stratum 和 stochastic stratum 的不同特例。SSA 的区别不在“混合”本身，而在 residual 部分使用 score-guided sampling。
4. 理论部分。论文给出近似误差界，分析 proxy 质量、预算分配、残余质量分布与输出误差之间的关系。直观上，若 proxy 与真实分数排序相关，且高质量 token 已被 deterministic 层截住，那么在 residual 上做 importance sampling 会比 uniform sampling 有更低方差。
5. 系统实现。作者实现了配套 CUDA/Triton kernel，目标是减少 gather/scatter 和不规则访存带来的额外开销。因为很多 sparse attention 方法在 paper 上省 FLOPs，但 kernel 不友好，最后并不能换来 decode speedup。SSA 明显把这一点作为设计约束。

和已有方法相比，Quest / PQCache 更偏确定性检索；MagicPig 更偏采样估计；vAttention 是 top-k 加 uniform tail。SSA 的新意在于把“尾部覆盖”从盲采样改成了有分数引导的探索，因此在 attention 分布不够尖锐时更稳。19:T746,The method, Stratified Sparse Attention (SSA), combines deterministic retention of high-confidence tokens with score-guided importance sampling over the remainder. The key idea is to treat sparse attention as a two-stratum estimator.

1. Deterministic stratum. A proxy score is used to select a heavy-hitter set. This part reduces bias by ensuring that the largest contributors to attention are always included.
2. Stochastic stratum. Instead of uniformly sampling from the residual tokens, SSA samples according to a proxy-guided distribution. Importance weighting is then used so that the residual contribution is estimated with much lower variance than uniform tail sampling.
3. Unified view. The paper shows that top-k, top-p, and top-k plus sampling can all be interpreted within the same framework as special cases with different deterministic and stochastic allocations. SSA differs from prior hybrids because the stochastic part is score-aware rather than blind.
4. Theory. The analysis provides approximation guarantees that relate output error to proxy quality, budget allocation, and the distribution of residual attention mass. The intuition is straightforward: once the head is captured deterministically, importance sampling over a non-uniform tail is preferable to uniform sampling whenever the proxy preserves useful score structure.
5. Systems implementation. The authors implement CUDA and Triton kernels to make the method practical at decode time. This is important because many sparse-attention methods reduce nominal FLOPs but fail to deliver end-to-end gains due to irregular memory access and kernel overhead.

Relative to prior work, Quest and PQCache are more retrieval-centric, MagicPig is more sampling-centric, and vAttention uses top-k plus uniform sampling. SSA’s main novelty is the score-guided exploration of the residual set.1a:T5ab,The evaluation spans several open models and multiple long-context benchmarks. Models include Llama-3.1-8B-Instruct, Qwen3.5-4B, Qwen3.5-9B, Ministral-3-3B-Instruct-2517, and Ministral-3-8B-Instruct-2517. Benchmarks include RULER, LongBench, LOFT, and AIME, which gives a mix of retrieval-heavy long-context tasks and more reasoning-sensitive settings.

The main empirical findings are:
1. Under aggressive sparsity, SSA consistently outperforms deterministic retrieval baselines, sampling-based baselines, and hybrid baselines, reducing the gap to dense attention.
2. In the preliminary analysis, score-guided importance sampling achieves lower relative L2 error than uniform sampling. This is an important mechanistic result because it directly validates the design choice rather than relying only on downstream task scores.
3. The paper includes an oracle reference using exact top-k plus exact importance sampling. That helps separate the error due to imperfect proxies from the error due to the sparse estimator itself.
4. The authors report end-to-end decoding speedups over dense attention, not just kernel-level microbenchmarks. That makes the systems claim more credible.

The provided full-text excerpt does not include the complete result tables, so I cannot safely restate exact gains, sparsity ratios, or latency numbers.
