a:T8fc,The method has two components. The first is a sharding pipeline. For GSM8K and MATH500, an LLM decomposes each problem into minimal logical units, verifies completeness and non-redundancy, and withholds the core question from the shard sequence while repeating that question at every turn. Evidence is then revealed piece by piece. This is not random chunking: the goal is to preserve the dependency structure of the original reasoning problem so the model must accumulate state across turns. For LongBench QA, where such discrete reasoning units are less natural, the authors instead chunk documents into fixed-size sentence-aligned segments. They also build two ablation variants. Full-question places the full question in one random shard and fills the rest with Wikitext noise, testing whether the model is only learning relevance detection. Mixed interleaves logical shards with noise, testing robustness under distraction.

The second component is memory-augmented RL. At turn t, the policy receives the question q, current memory m_t, and incoming shard s_t, then generates a rewritten memory m_{t+1}. The memory is free-form natural language capped at 256 tokens, intentionally too small to copy the full history verbatim. At the final turn, the model answers using only q and the terminal memory m_K. Training extends the DAPO-style multi-conversation RLVR setup: for each sample, G=4 trajectories are sampled, a rule-based verifier scores only the final answer, and group-relative advantages are computed. A key design choice is to propagate the same trajectory-level advantage to all intermediate memory-writing steps rather than assigning turn-level credit. The rationale is that there is no unique correct intermediate memory, so direct supervision would overconstrain the policy. Optimization uses a dual-clipped PPO surrogate with token-mean aggregation across turns, preventing long memory outputs from dominating gradients, plus a separate KL penalty to limit policy drift. The main baseline is a full-history policy that sees the concatenated conversation history instead of an explicit compressed state. Both model families are evaluated under both memory-only and full-history inference conditions, which cleanly separates training effects from inference-time context compression.b:T6b9,The experiments use two model scales: Qwen2.5-Math-1.5B-Instruct and Qwen3-4B-Thinking, trained with 4 sampled trajectories per prompt on 2×A100 GPUs. Several findings stand out.

First, the Lost in Conversation degradation is substantially recoverable. The paper reports up to a 60-point recovery on GSM8K, which indicates that the failure is not an immutable consequence of fragmented context but a learnable deficiency in state maintenance.

Second, memory-trained policies outperform full-history baselines under every evaluation condition. The strongest evidence is the cross-condition result: a model trained with bounded memory still beats a model trained on full history even when both are given full history at test time. This argues that the gain comes from the training objective and state-update discipline, not simply from shorter inference context.

Third, the learned behavior transfers beyond the training domain. Models trained only on sharded GSM8K generalize zero-shot to the harder MATH500 benchmark and to out-of-domain LongBench QA. That supports the claim that the model is learning a reusable information-accumulation strategy rather than memorizing a dataset-specific format.

Fourth, the ablations are informative rather than cosmetic. Comparing Sharded, Full-question, and Mixed isolates the role of logical decomposition versus relevance filtering versus noise robustness. Additional MATH500 variants with n in {2, 4} inserted noise shards test whether the memory policy remains stable as conversations become longer and dirtier.
