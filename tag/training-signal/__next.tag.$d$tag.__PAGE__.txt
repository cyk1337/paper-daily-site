第二，作者把参考解前缀注入 prompt，作为 assistant message 的部分答案，让模型只补全后半段；前缀 token 不参与梯度，reward 仍按完整输出的最终答案计算。这样做的好处是实现层面几乎不改 trainer，只改数据管线和 loss mask。与直接做 trace SFT 不同，它没有把整条参考解当监督目标压给模型，而是只在条件分布上降低问题难度，保留了 RL 的探索空间。

第三，作者不是给每题固定一个 prefix ratio，而是做“全局基准前缀 + 每题静态偏移”的两级控制。训练前先做一次 cold-start calibration，根据 base model 在不同题上的条件成功率，给每个样本估一个 difficulty-dependent offset；训练时再维护一个全局 base prefix length，用 secant 或 binary search 这类 root-finding 更新规则，根据最近 batch 实际观测到的平均 k/G，把全局前缀往目标 solve rate 推。这样既避免逐题在线搜索的高成本，也比完全固定的 per-sample 前缀更能跟踪策略随时间的变化。

第四，训练后期把所有前缀 anneal 到 0，保证部署时模型不依赖提示拐杖。这个 annealing 很关键。如果一直带前缀训练，模型学到的是“条件补全参考解”的能力，而不是无辅助求解；逐步撤掉前缀，相当于把课程从 teacher-assisted completion 过渡到独立解题。

First, the paper analyzes how GRPO signal depends on the within-group success rate k/G. With unnormalized centered advantages, the aggregate positive learning mass scales like p(1-p), peaking near p=0.5. That is why the controller targets roughly a 50% solve rate. The choice to avoid std-normalized advantages matters here: normalization can make rare successes numerically dominant when p is tiny, while the unnormalized form preserves a cleaner and more stable signal-shape argument.

Second, the method prepends a correct prefix from a reference solution as an assistant message and asks the model to complete the rest. Gradients are masked on the prefix tokens, while reward is still computed from the final full answer. This is an important design choice. It lowers conditional difficulty without turning the whole trace into a supervised target, so it preserves more of the exploration behavior that plain trace SFT tends to suppress.

Third, the controller is not fully per-sample online and not fully static either. The paper uses a two-level scheme: a global base prefix length plus a fixed per-sample offset derived from a one-time calibration. During training, the system observes the realized batch mean k/G and updates the global base prefix using a root-finding style rule such as secant or binary search, pushing the observed solve rate toward the target. The per-sample offsets account for persistent difficulty differences, while the global term tracks the non-stationarity induced by policy improvement.

Fourth, all prefixes are annealed to zero by the end of training, so the deployed model solves problems unaided. This is crucial. Without annealing, the policy may become good at conditioned continuation of partially solved traces rather than independent problem solving.

Relative to concurrent prefix-based RL work, the distinction is the control perspective. Prior methods typically choose a few fixed prefix lengths so that the base model has a “reasonable” conditioned accuracy. It extends the line of work that connects in-context learning with instruction data selection, especially NUGGETS, but changes the evaluation protocol in three important ways.

First, instead of using a fixed global anchor set for every candidate, wICI builds a dynamic local probe set for each candidate example. The probe set is constructed in three stages: semantic retrieval to find related examples, semantic clustering to avoid near-duplicate probes, and complexity-guided selection to keep the probes challenging enough. This design addresses three failure modes of naive evaluation: unrelated probes add noise, redundant probes waste computation, and trivial probes overestimate demonstration quality.

Second, the paper measures influence through reductions in instruction-following difficulty (IFD). IFD is defined from the gap between conditional and unconditional generation difficulty, and is used as a proxy for how much the model benefits from the instruction. A candidate example is inserted as a one-shot demonstration; if the probe’s IFD decreases, the candidate is considered helpful. This is more informative than a binary success metric because it preserves the magnitude of improvement.

Third, the per-probe influences are aggregated with a normalized cosine-distance weighting scheme. The weighting is meant to emphasize transferable gains rather than over-rewarding memorization on extremely close neighbors. After scoring, the final subset is selected greedily under a diversity constraint based on cosine similarity, so the chosen tuning set is not overly redundant.

Relative to NUGGETS, the differences are clear: local semantically relevant probes instead of a fixed global anchor set, continuous influence scores instead of coarse binary scoring, explicit difficulty-aware evaluation, and a more efficient selection procedure.
