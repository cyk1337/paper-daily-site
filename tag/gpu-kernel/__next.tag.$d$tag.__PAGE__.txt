9:T578,The method builds on the LapSum operator. Given scores r, a budget k, and a temperature parameter α<0, LapSum smooths the hard top-k threshold using the Laplace CDF and outputs probabilities p with the exact constraint ∑ p_i = k. The computational challenge is solving for the threshold b. Previous GPU implementations rely on bisection and rescan all n scores at each iteration.

Fast LapSum computes the whole threshold curve instead. After sorting, a stable prefix/suffix scan constructs the piecewise curve. The correct segment is found by an index lookup, and the threshold is obtained with a closed-form root calculation. The backward pass uses an analytical vector-Jacobian product with a single reduction, avoiding straight-through estimators or biased hard-mask surrogates.

For million-scale vectors, sorting itself becomes the bottleneck. The paper adds a probabilistic bracketing pipeline: a kernel-noised subsample localizes the likely threshold region, one streaming pass over the full vector keeps only the uncertain middle band, that band is sorted, and a verification step certifies the bracket before the exact LapSum solution is applied. This keeps expected work linear while still recovering the exact threshold and exact budget.
