9:T4e4,Activation-Supported Parameter Decomposition represents a target weight matrix W using rank-1 components. Each component has a read direction v_c, a write direction u_c, and a context-dependent gate g_{t,c}(X). The read direction specifies what information is consumed from the input activation, the write direction specifies the output direction being produced, and the gate determines when the component is active at a token position. Pure parameter decomposition is underdetermined because many decompositions can represent the same matrix. ASPD constrains this ambiguity using the model’s actual activation distribution. Instead of optimizing expensive pairwise interventions between all activation features and all parameter components, it uses a shared sparse representation that both defines activation features and gates the corresponding weight components. A local internal reconstruction objective asks the learned components to reconstruct W x at the output of the analyzed matrix, avoiding reliance on final-output effects alone. This differs from activation-only SAE work and parameter-only decomposition by giving each component an explicit read-write interpretation and making these components composable into parameter-level circuits.a:T4e8,Targeted Parameter Decomposition (tPD) introduces a high-rank catch-all component Δ that handles all non-target data, so only mechanisms active on the target subset need to be explicitly decomposed into sparse rank-1 subcomponents. Key design details: 1. Training uses two parallel data streams: a small target dataset (inputs to be explained) and a non-target stream sampled from the model's original training distribution. 2. For target data, outputs are reconstructed using only a sparse set of rank-1 subcomponents, which capture mechanisms active on the target and do not need to sum to the full original weights. 3. For non-target data, outputs are reconstructed using the full-rank Δ component, defined as the residual between the original weights and the sum of target subcomponents; Δ captures all mechanisms never active on target data. 4. During training, Δ is adversarially ablated (0–100% of parameters) on target batches to force target outputs to be reconstructed solely from the sparse subcomponents; Δ is always enabled on non-target batches. 5.
