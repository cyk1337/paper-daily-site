a:T41f,This is work on unified multimodal pretraining and modeling paradigm, not just an incremental avatar demo. The proposed world plus event stream decomposition unifies ordinary video, interactive video, speech, behavior, and language into one causal sequence modeling framework. Three implications matter for foundation model research. First, it provides a pretraining task for joint video/audio/language/behavior modeling that is closer to agent interaction than plain video generation. Second, it writes open-vocabulary actions directly into the language event stream, avoiding a fixed action vocabulary and pointing toward a unified interface for agent behavior. Third, it frames pretraining as learning how a world evolves in real time given context and incoming inputs, then specializes that competence by changing the world configuration and input driver; this differs from both standard next-token language modeling and standard diffusion video generation. Relevant for multimodal foundation models, real-time interaction systems, and world modeling.b:T71f,The paper keeps the Wan-Streamer v0.1/v0.2 design: a single Transformer models text, audio, and video on one causal timeline, so perception, response timing, speaking, visible listening, and synchronized video are learned jointly rather than assembled from cascaded modules. The main change in v0.3 is not architecture but a reframing of the training objective and sequence representation. Any video is decomposed into a persistent world and a time-varying event stream. The world captures stable context over the timescale of a clip or interaction: environment, visual style, subject identity and appearance, ambient sound, voice characteristics, and other durable conditions. Events are localized changes: subject behavior, camera motion, environmental change, speech, and other sounds. The world is represented as a flexible structured record whose schema can vary by clip or task rather than being globally fixed. Each event has a time interval, a free-form description of the change, and an association to a character or to the environment. The pretraining task becomes: given the world and incoming inputs, predict how the world streams forward unit by unit in real time. For downstream interaction, the world configures scene, character, ambient sound, and voice; streaming user text/audio/video drive the model's event stream. The event stream interleaves spoken words with parenthesized natural-language behavior directives such as “(frowning slightly) What did you say?” This replaces a fixed action vocabulary with open-vocabulary actions grounded in the world, while conditioning audio-video generation through the same path as the language stream, so no new latency-critical component is added.
