Later frames are P-frames and are represented relative to the preceding sampled frame through motion vectors and residual signals. A conditional predictive cost, called pcost, decides when prediction is no longer reliable; high pcost triggers a reset and inserts a new reference frame. The model uses a dual-branch visual-token pipeline: one branch processes full reference-frame tokens, and another turns motion/residual information into compact P-tokens. The LLM receives an interleaved sequence of I-frame tokens and P-tokens. Training is done in two stages: first learning P-frame representations, then aligning the predictive code with the multimodal language model.
