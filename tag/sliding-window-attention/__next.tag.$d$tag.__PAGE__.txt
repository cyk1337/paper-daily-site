9:T87a,Maglev 由两个耦合模型组成：prefiller Q 和 decoder P。

Q 是训练时使用的强模型。它是因果的，但拥有比部署模型更强的上下文访问能力。文中实际实现里，Q 使用 interleaved full attention 和 sliding-window attention，因此它能在不看未来的前提下，用整段已观测前缀并行地产生每个位置的目标记忆 m'_t。这里的关键不是 Q 的具体形式，而是它必须比 P 更有表达力，能给出一个“理想记忆轨迹”。

P 是真正部署的模型。它只使用 sliding-window attention，再加一个 recurrent K/V injection 通道，把前一时刻或前一段的 memory window 作为额外 K/V 输入。P 在位置 t 既要预测下一个 token，也要输出自己的记忆 m_t。作者把 decoder 最后一层的 normalized state 同时作为 LM head 输入和 memory 写入值，因此不需要额外 memory token，也不需要单独的 memory cache 结构。推理时，P 只保留固定大小的 token window 和 memory window，随着序列增长成本不再增加。

训练难点在于：如果直接训练 P 的递归接口，就必须顺序生成 m_1, m_2, ..., m_T，失去 Transformer 预训练最重要的序列并行性。作者的 lifted parallel training 通过 Q 绕开这个问题。训练时先用 Q 在整段序列上并行生成 m'_1:T，再把移位后的 m'_{0:T-1} 喂给 P，让 P 在并行条件下学习两件事：一是用这些目标记忆做 next-token prediction，二是输出自己的 m_t 去逼近 m'_t。这个 consistency loss 把“内部状态监督”显式化了。到推理时，Q 被丢弃，P 用自己上一时刻生成的 memory 闭环运行。

从方法取舍看，Maglev 和 segment-level memory Transformer 的区别在于它是 token-wise memory，没有块边界；和 linear attention/SSM 的区别在于 memory update 经过完整 Transformer 深度，是非线性的；和普通 sliding-window Transformer 的区别在于它多了一个可持续的 latent memory 通道；和直接训练 recurrent Transformer 的区别在于它把训练中的 latent trajectory 外显出来，用双通路并行训练替代顺序展开。a:T885,Maglev consists of two coupled models, a prefiller Q and a decoder P.

Q is used only during training. It is causal, but more expressive than the deployed model because it has access to a larger receptive field. In the implementation described in the paper, Q uses interleaved full attention and sliding-window attention. Its job is to produce a target memory trajectory m'_1:T in parallel from the observed prefix, without leaking future information.

P is the deployed model. It uses sliding-window attention plus recurrent K/V injection, where a shifted memory window is inserted as additional key-value context. At each position, P predicts the next token and emits its own memory m_t. A notable design choice is that the decoder’s final normalized state serves both as the input to the LM head and as the written memory. This avoids dedicated memory tokens and avoids a separate memory-cache mechanism. At inference time, P keeps only a fixed token window and a fixed memory window, so cost remains bounded as the sequence grows.

The training challenge is that direct recurrent training would require sequentially generating m_1, m_2, ..., m_T, which destroys the sequence parallelism that makes Transformer pretraining efficient. The paper’s lifted parallel training avoids this by externalizing the latent trajectory. First, Q computes m'_1:T in a causal but sequence-parallel pass. Then shifted memories m'_{0:T-1} are fed into P, which is trained in parallel to do two things: predict next tokens and reproduce the target memories via a consistency loss between m_t and m'_t. At inference, Q is discarded and P closes the loop with its own generated memories.

Relative to prior approaches, Maglev differs from segment-level memory Transformers by writing memory at every token rather than at block boundaries. It differs from linear attention and SSMs by using full nonlinear Transformer depth for each memory update. It differs from a plain sliding-window Transformer by adding a persistent latent-memory channel. And it differs from directly trained recurrent Transformers by replacing sequential latent-state unrolling with a two-pass parallel training procedure.b:T62a,The headline experiment uses a deployed decoder at roughly 435M parameters trained on 43.52B tokens.
