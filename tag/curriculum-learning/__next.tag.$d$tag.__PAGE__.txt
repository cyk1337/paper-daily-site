5:T5c8,The pipeline has two stages. First, the authors estimate latent task difficulty from observed agent-task outcomes. Each trial is treated as a Bernoulli observation, forming a partially observed binary response matrix over agents and tasks. They fit a one-parameter logistic IRT model, or Rasch model, with one scalar ability parameter θ_a per agent configuration and one scalar difficulty parameter β_t per task. This is preferable to raw pass rate because difficulty is inferred relative to a population of agents on a shared scale, making it more suitable for cross-benchmark comparison.

Second, they train predictors of β_t using only pre-rollout features. These include textual task descriptions, environment and action-space descriptions, metadata, and uncertainty-related signals such as entropy that can be obtained without full interaction. A major methodological contribution is the evaluation protocol. The paper argues that response AUC can look strong even when task-level difficulty estimates are poor, so it emphasizes rank-based metrics such as Spearman correlation for judging whether the predictor actually learns difficulty ordering. The residual analysis is also important: discrepancies between predicted and observed IRT difficulty are used diagnostically. Large positive residuals often indicate hidden hardness factors such as infeasible environments or broken evaluators, while large negative residuals may reveal familiarity, templating, or shortcuts.6:T525,The empirical foundation is substantial. The main analysis subset contains 5,230 tasks from 17 benchmarks, evaluated by 497 agent configurations built from 216 models and 90 scaffolds. The full corpus includes 415,470 agent-task outcomes. Domains span coding and SWE, function calling, web navigation, computer use, terminal tasks, math, ML, cybersecurity, and general-purpose suites. Task dates range from 2010 to 2026, and each agent-task pair has about 1.2 trials on average.

The headline numbers are straightforward. Under K-fold evaluation, the combined feature set reaches Spearman ρ = 0.399, significantly better than the baseline at p < 0.001. Under out-of-distribution evaluation, it reaches ρ = 0.225. Among single feature families, entropy performs best. The paper also shows that response AUC can remain high even when task-level difficulty ranking is weak, which supports the claim that rank-based evaluation is the more faithful metric. The residual case studies are especially useful: some tasks predicted to be moderate turn out to be much harder because the environment is infeasible or the verifier is faulty, while others that look difficult in text are actually easy due to familiarity or shortcuts. (1) Trajectory level: Value-Variance Adaptation. A value model estimates token-level V(s_t) along each generated trajectory. The variance of these values (or a closely related advantage-variance proxy) is used as an intrinsic randomness / exploration indicator: high variance implies more exploratory, low variance implies rigid generation. The paper sketches a bound showing the policy-gradient norm can be upper-bounded by a term involving advantage variance under a bounded ∥∇ log π∥ assumption, motivating variance-aware control of update magnitude. Based on this, CVPO modifies advantage computation by scaling/reweighting trajectories according to their value-variance, with different handling for different reward types (e.g., sparse correctness vs denser rewards), aiming to extract more informative gradients from otherwise homogeneous outcomes.

The first is Progressive Curriculum Loss, designed to stabilize deep look-ahead training. Instead of assigning a constant or hand-decayed weight to every prediction depth k at position t, the model uses an adaptive weight ω_{t,k}. This weight combines two constraints. The Sequential Confidence Constraint uses the softmax confidence of preceding look-ahead predictions to estimate whether the trajectory up to depth k is still trustworthy. If an earlier step is already uncertain or off-track, supervision for deeper predictions is down-weighted. This suppresses the classic failure mode where distal targets keep backpropagating through a path that has already collapsed. The Retrospective Target Constraint adds another filter based on consistency with the target trajectory, further reducing noisy supervision from unreliable deep predictions. Together, these terms create an implicit easy-to-hard curriculum: the model first learns stable short-horizon prediction and only gradually receives stronger supervision on deeper horizons.

The second component is Confidence-Gated Dynamic Drafting for inference. Standard MTP usually fixes the drafting depth K, but fixed K is suboptimal for document parsing because entropy varies sharply across layouts, tables, formulas, and plain text spans. P-MTP instead decides online how far to draft based on cumulative joint confidence. If the predicted path remains reliable, the model keeps extending the draft; if confidence drops below a threshold, it truncates early. This directly optimizes the useful quantity αK, where α is the acceptance rate, rather than maximizing K in isolation. The paper also keeps the MTP branch lightweight, using a shared module that recurrently produces multiple look-ahead predictions, so the extra overhead γ stays small enough for real wall-clock gains.
