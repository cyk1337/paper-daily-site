Athanor: An Agent-Native System for Autonomous Post-Training Research

这篇工作要解决的不是“如何再做一个更强的 post-training recipe”，而是更难的一层：怎样把 post-training 研究本身做成一个可由 agent 独立执行、可长期运行、可审计、可复现的研究系统。作者把问题定义为 AutoPostTrain：给定一个原始 base model、公开数据、真实 GPU、封闭的 held-out 评测，以及不允许调用外部 teacher model 的约束，让 agent 自己完成完整研究闭环——诊断模型短板、引入和清洗数据、写训练代码、改训练算法、调超参、分析结果、决定下一轮实验，并最终提交一个单一 generalist checkpoint，在多项能力上同时提升。难点不在单次训练，而在长周期异步实验管理、研究状态外化、评测隔离、数据去污染、失败恢复，以及让 agent 能在真实工程摩擦下持续 hill-climb。
