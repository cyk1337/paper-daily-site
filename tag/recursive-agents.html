Recursive Agent Optimization

RAO 解决的是递归式 agent 如何训练的问题：如果推理时允许模型启动子 agent、拆分任务、并行求解和汇总结果，模型本身也需要学会何时委派、如何写子任务、如何跨层传递信息，而不能只把递归当作外部 prompt scaffold。

评这篇不直接改 pretrain，但它把 inference-time scaling 从“更长思维链”改成“可学习的递归委派”；先看方法设定和 ablation，若 compute 控制干净，值得内部复现。

Recursive Agent Optimization

这篇工作关注的是：如果递归式 agent 会成为一种重要的 test-time scaling 机制，那么模型不应只在推理时被外部脚手架“包起来”，而应该在训练中学会何时拆分任务、如何委派子任务、如何在层级之间传递信息，以及如何汇总子结果。
