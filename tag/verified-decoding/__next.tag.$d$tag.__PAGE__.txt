a:T446,Hybrid Verified Decoding keeps the standard draft-then-verify interface. A draft source proposes a block of tokens; the target model verifies the block and commits the accepted prefix. The payoff variable is accepted length, the number of drafted tokens accepted at the current decoding state. The method combines two draft sources. The first is a parameter-free cache drafter, instantiated with a suffix cache similar to SuffixDecoding, which searches the prompt and generated history for suffix matches and reuses following spans. The second is a model-based drafter, such as the EAGLE family. Before verification, a lightweight predictor estimates the accepted length of the current cache draft. If the predicted payoff is high, the cache draft is verified. Otherwise, the system falls back to the model-based drafter. The predictor is trained by trace replay: generation traces are replayed to obtain accepted-length labels for cache drafts at different states.
