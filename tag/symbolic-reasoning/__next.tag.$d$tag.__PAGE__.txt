9:T8c4,The method has three layers. The first is task construction. Instead of training only on the composite SOS task, the authors build a nine-task curriculum: four local algebra operations, four broader structural tasks, and one weighted-SOS search task. The motivation is straightforward. If training starts only from the composite task, supervision is too sparse to teach which intermediate forms are useful for certificate assembly. The supporting tasks provide denser algebraic supervision and decompose the search skill into learnable pieces.

The second layer is supervised fine-tuning. Starting from Phi-4-reasoning-plus, they apply assistant-token QLoRA SFT on direct solutions and simulated symbolic traces. An important design choice is that the SFT corpus contains evaluated Python-like symbolic snippets, but not native function-call messages. In other words, the model first learns the semantics and trajectory patterns of tool use rather than memorizing an API protocol. Native tool calling is introduced only at deployment through four SymPy-backed functions. This separation is methodologically clean: it tries to teach when and why to use tools, not just how to format a call.

The third layer is verifier-grounded GRPO. The model is further optimized with task-specific symbolic rewards. For weighted-SOS, a terminal candidate is accepted only if it satisfies strict structural constraints: it parses into a finite sum, every weight is an exact positive rational, every summand is a polynomial square, and the expanded identity matches the target polynomial coefficient by coefficient. The key point is that reward is anchored to decidable correctness rather than fuzzy preference signals. Compared with generic math RL, the room for reward hacking is smaller because terminal acceptance is exact.

The main novelty is not a new optimization algorithm. It is the full loop: curriculum-style algebra supervision, simulated traces, native symbolic tools, and exact verifier-based rewards. Unlike many tool-use agent papers, this one deliberately stays inside a fully checkable algebraic domain, which makes it easier to separate tool reliability from strategy failure. The paper is also careful not to overclaim beyond this setting.a:T80c,The experimental setup is fairly clear. Training uses 1.35 million synthetic examples spanning eight supporting tasks plus weighted-SOS. Evaluation uses 90,000 separately generated test instances. The complete system reaches 91.75% macro-average across the nine polynomial tasks. On the main weighted-SOS task, the Full system achieves 78.96% verified success, compared with 44.73% for the same backbone with the same tool interface but without the full post-training pipeline. That gap is the central empirical result: tool access alone is not the main source of gain; the algebra curriculum and verifier-grounded optimization are.

The paper compares Base, SFT, Base+Tools, and Full. The ablation is informative but not fully causal. In particular, it does not include SFT+Tools without GRPO or GRPO without tools, so the independent contribution of each component cannot be isolated cleanly. Still, the existing comparisons are enough to support the claim that simply attaching tools is insufficient, while the full training recipe materially improves composite symbolic search.

Two details matter for interpretation. First, the eight supporting tasks are solved directly without native tool calls in both training and evaluation, so their scores should be read as evidence of learned algebraic priors and intermediate-form competence, not direct evidence of tool-execution skill. Second, every weighted-SOS test polynomial is SOS by construction. Therefore, failure does not mean the instance is non-SOS; it means the search failed to find a certificate. That makes error analysis cleaner because the issue is search quality, not task infeasibility.

The paper also reports terminal failure categories. Even from the available text, the useful distinction is likely among parse failures, structurally invalid certificates, coefficient mismatches, exhausted search, and premature stopping. First, it identifies the mechanism. In tied embedding/unembedding decoder-only transformers, tokens that are unseen or rarely used during training develop nearly collapsed (un)embeddings. Even if the model learns the reasoning algorithm structurally, it cannot reliably distinguish U1 from U2 if their output representations are almost the same. Second, it provides theory. The authors show that under SGD with weight decay and LayerNorm, this collapse is not an accident but a natural consequence of the training dynamics. Intuitively, unseen tokens receive little task-specific gradient to keep them separated, while regularization and normalization push them toward a low-variance shared region. Third, it studies interventions. A copy-enabled architecture alone is insufficient, because copying does not solve the problem once multiple unseen tokens are already indistinguishable at the output layer. Reliable symbolic reasoning requires a combination of: a copy-capable architecture, sufficiently diverse symbolic training data, and a mechanism that prevents embedding collapse. The latter can be achieved by freezing the (un)embeddings or periodically resetting them. The paper also reinterprets active forgetting from earlier work: its benefit is not merely “preventing knowledge storage in embeddings,” but more concretely interrupting collapse.
