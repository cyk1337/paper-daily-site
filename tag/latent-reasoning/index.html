Sparse RL Relaxation for LLM Reasoning

这篇工作处理的是 soft CoT 在 RL 训练里一个很具体但一直没理顺的问题：中间“思维 token”如果不再是离散词，而是词表 embedding 的连续混合，那么它既不像标准 AR LM 那样是合法动作，也不该被当成普通离散 RL action 来做 policy gradient。已有做法为了套进 RL，会把 soft token 当作随机动作采样，但这样一来，跨 reasoning step 的梯度被截断，模型拿不到“前一个软思维选择如何影响后一个思维状态”的训练信号。作者要解决的，就是如何在没有 step-level CoT 标注、只靠最终答案奖励的条件下，既保留 RL 的探索能力，又恢复 soft token 作为可微中间计算的跨步梯度路径，同时避免大词表下软分布过于稠密、语义发散的问题。

评读方法和 ablation 即可；若梯度穿过 soft CoT 的 setup 干净，这会影响 latent reasoning 训练接口的 prior。

Does Latent Chain-of-Thought Actually Reason? A Single, Unifying Taxonomy for Latent Reasoning

这篇论文要解决的不是“latent CoT 能不能提高准确率”，而是更基础也更容易被误判的问题：模型在 latent chain 里到底做了什么计算，这些中间隐状态是否真的被用来得到答案。作者指出，过去很多证据都不够强。能从某个 slot 线性 probe 出答案，不等于模型在用这个 slot；删除链条后性能下降，也不一定说明模型在用链条内容，可能只是在用位置占位符或长度模式。为此，论文把 latent reasoning 拆成三个彼此独立的问题：一是 causal use，模型是否依赖链、依赖位置还是依赖内容；二是 encoded content，链里到底写了什么；三是 state dynamics，状态在链上如何演化、何时收敛、收敛后还能否被改写。这个拆分很关键，因为它把此前看似互相冲突的结论放进了同一个判别框架里。

评这篇会削弱“latent CoT 自动学会推理”的 prior；应重点读 deletion/replacement 实验而不是 probe 结果。
