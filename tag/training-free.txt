18:T703,The method starts by separating queries into two behavioral types. Local queries mostly attend to nearby tokens. Global queries, associated with TRTs, attend back to distant earlier context. The paper then shows that these global queries are not scattered arbitrarily in query-embedding space; they form a small number of similarity clusters. This motivates beacon queries: a compact set of representative queries intended to approximate future global revisiting patterns.

At eviction time, BeaconKV does not score historical KV entries using only recent queries. It also keeps a small set of beacon queries. A token is retained not only if it matters to the current local decoding state, but also if it is important to one of these representative global queries. This gives the system a way to protect tokens that may not look useful now, but are likely to be revisited later.

Because decoding is online, beacon queries cannot be obtained by offline clustering over the full query history. The paper therefore proposes Continual Farthest Point Sampling, an online procedure that incrementally selects geometrically diverse queries while keeping memory bounded. Intuitively, it maintains a compact cover of the query space seen so far. Compared with storing the full query history, this is memory efficient; compared with using only recent queries, it preserves information about potential future global attention patterns.

Methodologically, BeaconKV is training-free. It does not modify model weights and does not require distillation or calibration. Its main distinction from RPC and R-KV is not a better redundancy score, but an explicit treatment of future-query mismatch: future important queries may differ from recent ones, and a small representative set can partially bridge that gap.19:T537,The evaluation covers four open reasoning models: R1-Distill-Qwen-7B, R1-Distill-Llama-8B, Qwen3-4B, and Qwen3-14B. Benchmarks include AIME24, MATH-500, LiveCodeBench, and GPQA-Diamond, spanning math, coding, and science reasoning.

Several headline results matter. First, across a range of cache budgets, BeaconKV generally outperforms RPC and R-KV, with accuracy gains of up to 31.7 percentage points. That large gap suggests that under aggressive compression, the dominant issue is wrong eviction rather than raw capacity alone. Second, under strong compression, peak GPU memory can be reduced by up to 5.8x while keeping accuracy close to full-KV inference. Third, throughput improves by more than 4.3x over the uncompressed baseline, so the benefit is not only fitting longer traces but also improving practical serving efficiency.

The most informative ablations are the mechanism checks: TRTs indeed exhibit long-range attention; global queries show cluster structure in embedding space; recent-query-only scoring fails to cover these future revisiting needs; and adding beacon queries better preserves the tokens that full-KV inference would later rely on.
