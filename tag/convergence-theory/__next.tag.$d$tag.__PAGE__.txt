9:T5bc,The paper casts collaboration as finite block optimization over x=(x1…xm) with a global loss F(x) accessible via an exact verifier. Each agent b controls block xb and has a cheap local objective Lb that ignores interactions. Define the true conditional change fb(u;x)=F(x with xb←u)-F(x). The key construct is a correction term Rb capturing the interaction effects missing from Lb; agents instead optimize a corrected surrogate \hat{f}_b(u;x)=Lb(u)+\hat{R}_b(u;x), where \hat{R}_b approximates Rb and is anchored so \hat{R}_b(xb;x)=0.
Protocol: (1) parallel private search—each agent proposes an update u_b by optimizing \hat{f}_b with other blocks frozen; (2) exact verification—coordinator evaluates true global deltas via F; (3) compatibility-based merging—build a dependency graph over proposals and select a non-interfering subset (via coloring) to merge, guaranteeing non-increasing F. Extension: even interfering proposals may be merged if the coordinator verifies that their joint application yields a larger decrease; the convergence rate then depends on the realized joint improvement rather than worst-case interference.
Theory: linear convergence up to an explicit error floor determined by correction approximation error; the floor vanishes with exact corrections.
