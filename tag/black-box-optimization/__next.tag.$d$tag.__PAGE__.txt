b:T5d0,1) RL formulation: keep the base model π frozen; train a prompt-generation policy π' that outputs a system prompt x' conditioned on a meta-prompt s. Reward is binary correctness r(x,y) on dataset examples x with sampled responses y~π(·|x',x). Training uses an on-policy GRPO variant (no KL-to-reference, no std-based advantage normalization) with a value baseline V^{π'_t}(s)=E_{x'~π'_t}[r(x')].
2) Key analysis: decompose reward variance across system prompts into (a) response variance—stochasticity of sampled responses under a fixed system prompt, and (b) prompt variance—true differences in expected reward between system prompts. Prompt optimization succeeds when prompt variance is sufficiently large relative to response variance; it fails when response variance dominates (typical in complex reasoning like AIME).
3) Counterintuitive scaling: increasing the number of user prompts in the training set can reduce prompt variance because different examples prefer different system prompts; averaging over a larger, heterogeneous set cancels these preferences, making candidate prompts statistically indistinguishable.
4) p1 method: user-prompt filtering. Instead of optimizing on the full dataset, select a small subset of user prompts that exhibit high reward variance across candidate system prompts (i.e., they best discriminate good vs bad prompts). Training on this subset amplifies the optimization signal and can generalize better with far fewer training examples.c:T458,【skim】
