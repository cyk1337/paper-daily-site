9:T4fa,The framework defines a world as a pair of a reusable mechanism and a task rule. The learner first trains on task-independent source records, then adapts the same parameters using terminal correctness rewards, and is evaluated on held-out prompts. In the Sequential family, the mechanism is a transition table θ and the task rule is an initial operation η. The authors characterize a family of transformations that preserve all training rewards while flipping held-out answers for half of the worlds. Local source observations break this ambiguity by revealing transitions before their effects cancel in the reward data. In the Contextual Memory family, the mechanism is a retrieval map and the rule is a context–cue decision rule. The theory shows that finite source coverage leaves an exact error floor on unseen contexts, and additional terminal rewards cannot remove it. The optimization analysis then constructs finite sampled-Adam paths from specified random initializations. Source prediction trains transition execution or attention-based retrieval in the same parameters; reward adaptation then learns the task binding. This is stronger than a representation-existence argument because it specifies how gradient-based training can realize the division of labor.a:T5ce,The theoretical results provide explicit guarantees. In the Sequential setting, Theorem 4.1 identifies the reward-indistinguishable mechanism family, with half of the alternatives reversing every held-out answer. Theorem 4.2 gives a sampled-Adam path in which source prediction teaches execution on generated prefixes, and two REINFORCE updates using 2B_R terminal verifications select the initial operation, reaching at least 7/8 held-out success. In Contextual Memory, Theorem 5.1 gives the exact error floor induced by unobserved contexts. Theorem 5.2 shows that source Adam can acquire retrieval and reward Adam can learn an input-dependent rule, reaching at least 19/20 success; freezing randomly initialized query/key attention under the same schedule keeps success at most 1/64 above chance. The Qwen2.5 experiments test the same decomposition on real checkpoints. Across eight matched worlds, correct-source preparation followed by Sequential action-target reward training reaches 82.61% success, compared with 44.15% for a private-random source control. For memory tasks, replay preserves retrieval, and an independent eight-world confirmation reaches 75.32% task success versus 49.86% with alternative retrieval. A single-world comparison shows rapid reward learning even when task success is zero at reward entry, provided the correct source preparation was used. Key design principles:
1) Unified protocol: one identical system prompt across all tasks; no task-specific instructions, goal descriptions, or reward explanations;
2) Approximate biological references: rodent learning curves from the literature are mapped into a binary success criterion to form reference anchors (not strict competitive baselines);
3) Cognitive taxonomy: tasks cover spatial learning, working memory, instrumental conditioning, avoidance learning, etc.;
4) Multi-action episodes: per API call, the agent outputs up to k actions plus a capped-length free-text “learnings” field as explicit working memory.
Observation modes include ASCII_2D (default), egocentric ASCII_2D_FPV, and pseudo-3D ASCII_3D. Action space is four egocentric actions: FORWARD, ROTATE_LEFT, ROTATE_RIGHT, STAY.
