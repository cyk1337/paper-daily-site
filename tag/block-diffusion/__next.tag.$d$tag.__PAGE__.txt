5:T449,Multi-Block Editing adds a bounded revision phase to block diffusion. At inference time, after a new block is decoded, the method reopens a sliding window of already decoded blocks and performs joint forward passes over that window, allowing earlier tokens to be revised using later context. The design avoids token-level rollback logic and keeps the computation bounded by editing whole blocks through direct token-to-token revision. For windows beyond adjacent blocks, an entropy-based historical surprisal watermark is used to select the previously decoded block that is most likely to contain errors, rather than recomputing all history. The training component, Multi-Block Edit SFT, introduces bidirectional attention masks and a curriculum that expands the edit span from 2 to 4 blocks, so the model learns to exploit multi-block context instead of seeing it only at inference time.
