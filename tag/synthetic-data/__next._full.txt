具体看，企业域使用 Agent Script 来描述 agent：里面包含 router、subagent、typed actions、tool scope 和自然语言工作流指令。作者先做一个静态抽取，把这些声明式定义编译成 typed workflow graph。这个图里有工具参数 schema、状态读写、副作用、路由条件、循环与终止配置。也就是说，训练环境不是从对话日志反推出来，而是从 agent 的程序化定义直接生成。

然后，simulation pipeline 会把一个 specification 扩展成 scenario-conditioned 和 persona-conditioned 的多轮 session。scenario 决定用户需求和会触发哪些 workflow，persona 决定模拟用户在对话中的行为方式。训练样本既可以从对话开头开始，也可以从中间某个 prefix 开始，让策略在不同深度的状态上学习决策，而不是只学第一步。

执行层由 NeMo Gym 承担。对于没有真实后端的环境，作者用一个冻结 helper model 同时扮演三种角色：customer simulator、tool/function emulator、coverage judge。也就是用户回复、工具返回、任务是否完成的评分，都由外部服务提供。策略模型只负责在环境中 rollout。奖励核心是 grounded task-resolution reward，重点看任务是否真正通过工具调用被解决，而不是只看表面格式或局部步骤。这个设计比 token-level imitation 更接近最终 agent 目标。

优化上使用 GRPO。文中强调 joint training 多环境时，通过 agent_ref 做环境分发，并通过重复样本控制不同环境曝光率。这说明作者把多环境混训当成一个重要工程问题来处理，而不是只做单 benchmark 微调。整体上，这套方法更像“把 agent authoring system 变成 RL data engine”。19:T80e,The overall recipe is straightforward: start from Nemotron-3-Super-120B and apply GRPO directly, rather than first building a new SFT checkpoint. The main contribution is not a new RL algorithm. It is specification-driven task construction.

In the enterprise setting, the workflow is authored in Agent Script, which defines routers, subagents, typed actions, tool scopes, and natural-language instructions. A static extraction pass compiles this declarative specification into a typed workflow graph. The graph encodes tool argument schemas, state effects, routing conditions, and loop or termination logic. In other words, the training environment is generated from the agent program itself, not reverse-engineered from logs.

A simulation pipeline then expands each specification into scenario-conditioned and persona-conditioned multi-turn sessions. The scenario determines the user need and which workflows are exercised. The persona controls the simulated customer behavior. Training examples can start from the initial user request or from an intermediate dialogue prefix, so the policy learns decisions at different depths of the interaction rather than only the first move.

Execution is handled by NeMo Gym. In environments without production backends, a frozen helper model plays three roles during rollout: customer simulator, tool or function emulator, and coverage judge. The policy model only acts in the environment. The reward is a grounded task-resolution reward, centered on whether the task is actually solved through successful tool use, not whether the response merely looks plausible. That makes the signal much closer to the real agent objective than token-level imitation.

Optimization uses GRPO. The paper also notes practical details for joint training across multiple environments: agent_ref dispatch selects the environment per example, and exposure is controlled by repeating examples before shuffling. Stage 1 builds structured persona-scenario tuples. Using DeepSeek-v4.1-pro, the authors first create persona and topic seed pools, then expand them into two-speaker dialogue setups under consistency constraints. These setups include speaker attributes, scene, tone, narrative type, scene medium, a three-event progression chain, and an emotional arc. This matters because it separates high-level consistency control from later script realization.

Stage 2 generates dialogue scripts with explicit tags. Gemini-3.1-pro-preview writes spoken-style dialogues conditioned on the structured setup, while inserting three orthogonal tag families: duplex behavior tags (interrupt, backchannel, incomplete), emotion tags aligned with IndexTTS2’s supported emotions, and environmental/sound-event tags. This is a strong design choice: instead of inferring behavior during audio generation, the script already specifies what should happen.

Stage 3 performs expressive TTS and two-track assembly. The authors use IndexTTS2 because it supports disentangled control over speaker timbre and emotion. They synthesize each utterance separately, run forced alignment to obtain word-level timestamps, and then assemble two long-form speaker tracks. Duplex behaviors are realized during assembly rather than by training a specialized overlap synthesizer: incomplete utterances are rendered via ellipsis-induced pauses, interruptions are created by fading one speaker out while bringing the other in early, and backchannels are overlaid on top of the other speaker’s continuing speech. This is a pragmatic engineering solution with clear controllability.

Stage 4 injects background noise and sound events. Each speaker channel is paired with a background channel composed of environmental noise and short sound events. Environmental clips come from a 7-category bank; sound events come from a 52-category bank. Events are aligned to trigger words using the word-level timestamps from forced alignment, with controlled SNR. This makes the non-speech audio semantically grounded rather than random augmentation.

A quality validator filters low-quality dialogues before release, and the paper also uses dual LLM judges for script rationality checks. That improves reliability, although the final quality still depends heavily on how strong the upstream constraints are and how much the LLM judges bias the retained distribution.1e:T647,The dataset scale is the main empirical result. The experimental section is less about benchmark competition and more about validating that the synthesis pipeline produces trainable data.
