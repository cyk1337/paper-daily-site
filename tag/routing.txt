第一步，语义聚合移到 pre-RoPE 空间。也就是先在未旋转的 Q/K 表示上做 block 级汇聚，得到更稳定的 block semantic summary。这样做的原因很直接：pre-RoPE 表示没有相位旋转，均值或其他简单聚合不会破坏高频分量，也不会把相邻 token 的局部顺序信息在池化时互相抵消。

第二步，几何信息不再依赖 pooled post-RoPE 向量隐式携带，而是通过离线 structural prior 重建。论文里给出的做法是根据相对 block 几何关系，预先构造一个相对位置偏置项，在推理时与在线语义分数相加，形成 closed-form routing score。这个设计的关键不是“加一个 bias”，而是把位置建模从在线 token 计算里拿掉，变成离线可缓存的结构先验，因此 routing 成本只和 block 数相关，不需要额外 token-level matching。

第三步，路由完全在 block 级进行。对每个 query block，依据 decoupled score 做 Top-p 或预算约束下的 block 选择，生成 causal block mask，再交给 Triton/block-masked attention kernel 执行。作者强调 routing function 的复杂度必须远低于 O(L^2)，否则 sparse attention 在实际 GPU 上未必比高优化的 dense FlashAttention 更快。

The central idea is to decompose block affinity into two parts: online semantic evidence and offline geometric bias. Existing methods implicitly mix both inside pooled post-RoPE features. SGDR separates them explicitly.

First, semantic aggregation is moved to pre-RoPE space. Query and key features are summarized at the block level before rotary rotation is applied. This avoids destructive interference from averaging rotated vectors, especially in high-frequency dimensions. The result is a more stable semantic summary for each block.

Second, positional structure is reconstructed separately rather than being expected to survive pooling. SGDR introduces an offline structural prior based on relative block geometry. At inference time, this prior is combined with the online semantic score to form a closed-form routing score. The important design choice here is that positional bias is no longer recovered through token-level computation or heuristic correction; it is encoded as a reusable block-level prior.

Third, routing remains fully block-level. For each query block, the router selects top blocks under a sparsity budget and produces a causal block mask, which is then consumed by custom Triton/block-masked attention kernels. This keeps routing cost well below quadratic complexity and avoids the common failure mode where sparse attention loses its advantage because routing itself becomes expensive.

Relative to prior work, SGDR is not a coarse-to-fine method with token refinement, and it is not a calibration trick on top of post-RoPE pooled scores. It changes the score construction itself. The theoretical claim is that post-RoPE pooling destroys useful information through phase cancellation; the engineering claim is that offline geometric priors are a better replacement than online search.1a:T5c8,The evaluation covers long-context retrieval, understanding, language modeling, and video reasoning, with context lengths from 4K to 128K. Two results matter most.

First, SGDR stays close to exact full attention in accuracy across the tested range, and is better than or competitive with sparse baselines that depend on heuristic search or post-hoc compensation. The abstract does not list every task-level number, but the paper’s main empirical message is that fully block-level routing does not have to incur a large quality drop if the routing score is constructed correctly.

Second, the routing overhead is very small and remains stable as sequence length grows. The key number reported is that routing time stays below 3.4 ms across all evaluated lengths. At 128K, SGDR achieves a 5.03× speedup over FlashAttention. This is the result to pay attention to, because many sparse methods look attractive in asymptotic complexity but lose in wall-clock time once routing/search overhead is included.

The most informative ablations are likely the following: pre-RoPE vs post-RoPE pooling, to validate the phase-cancellation hypothesis; removing the geometric prior, to show that semantic pooling alone is insufficient; and varying block size or sparsity budget, to expose the quality/latency trade-off. 第一层，是把 speculative decoding 反过来。作者引入一个小型开源 draft model q，对黑盒 agent p 已经生成出的 token 序列做 teacher-forced scoring。也就是给定前缀 (x, y<t)，让 q 输出下一个 token 分布，再去读 agent 实际生成 token yt 在 q 下的概率。这样一次前向就能得到整条轨迹的 token-level 信号，不需要访问 p 的 logits，也不需要重复采样。文中提到至少提取了三类逐 token 信号，摘要截断处能确认其中包括 cross-likelihood 以及 draft 自己的 argmax 与 agent token 的偏差类信息；从方法描述看，核心是利用 q 与 p 在局部条件分布上的一致性/不一致性来近似失败风险。

第二层，是 phase-aware feature extraction。作者观察到 agent 轨迹不是同质 token 流，而是明显分成 reasoning phase 和 action phase。reasoning 段自由度高、熵高、语言噪声大；action 段受工具调用语法、参数格式、代码片段结构约束更强，熵低，但也更直接决定执行是否成功。如果像 HTC 那样把整段 token 概率简单平均，reasoning 段会淹没 action 段中真正与失败相关的信号。SU 因此按 harness 的消息结构把 token 标成 reason/action 两类，分别统计特征，再送入校准器。这个设计不是简单 feature engineering，而是在利用 agent 轨迹的生成机制差异。
