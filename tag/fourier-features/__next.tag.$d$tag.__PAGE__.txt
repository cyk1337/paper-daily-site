a:T6d9,The paper builds its case in three stages. First, it evaluates Llama-3.1-8B on months, weekdays, 24-hour time, and standard addition, using exhaustive combinations of concepts and offsets, with offsets ranging from 1 to 2p for cycle length p. The model does reasonably well on cyclic tasks, but performs surprisingly poorly on explicit modular arithmetic for mod 7, 12, and 24, already casting doubt on a direct modular-addition account. Second, the authors use Distributed Alignment Search to localize low-rank causal subspaces in the residual stream for input concept, offset, and output concept. They perform interchange interventions across layers and sublayers. The key finding is a shared transition point around the last-token position near MLP 18: before this point, input variables can be causally isolated with high accuracy; after it, intervention accuracy on the inputs collapses, indicating that the core computation has been carried out there. This pattern is similar across months, weekdays, hours, and ordinary addition. Third, they probe for Fourier features in the numerical representations and show that the model uses task-agnostic periodic features associated with base-10 number structure. These features support not only standard addition but also cyclic-concept tasks. They then identify a sparse set of 28 MLP neurons that write into these Fourier features and can be grouped into clusters responsible for different periodic components of the sum. The overall picture is a shared base-10 addition circuit followed by a later remapping into concept space.
