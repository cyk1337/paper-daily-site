Wrong Votes, Right Gradients: Why Majority-Vote Rewards Track Verifiable RL

这项工作解释了一个在 RL post-training 中很重要的现象：用模型自己采样结果做多数投票奖励，为什么经常能接近有标准答案或可验证奖励的训练效果。按单个 prompt 看，多数投票只能强化模型当前最常见答案，错误多数票不可能凭空提供正确性信息。作者认为这个视角不够，因为实际 RL 更新是 batch 级别的共享参数更新。单个 prompt 的错误标签只有在许多 prompt 上形成一致梯度方向时才会真正误导模型；如果错误是分散、互不相关的，它们会在 batch 聚合中被平均掉。

评这篇会改你看 self-label RL 的视角：别再只盯标签对错，先看跨样本梯度误差是否相干；建议立刻在内部 RL 日志里加 gradient coherence 诊断。
Dylan P. Wilson,Chengsong Huang,Jiaxin Huang
