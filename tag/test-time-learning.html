MoNe: Modular Neural Memory for Efficient Long Context Inference

MoNe 解决的是冻结 Transformer 在超长上下文推理中的成本和泛化问题：不重新训练基座模型，也不把完整上下文作为 prompt 重读，而是把长上下文压入一个可在线更新的神经记忆模块，让查询阶段的计算不随上下文长度增长。

评一种有趣的 test-time learning 记忆机制，将长上下文压缩为快速权重，O(1) 查询成本的设计对长文本 Serving 优化有启发，值得关注其具体实现和泛化能力。

Test-Time Learning with an Evolving Library

LLM在推理时对每个问题独立处理，无法跨问题累积和复用知识。现有测试时学习(TTL)方法要么依赖模型参数的梯度更新（不适用于黑盒API场景），要么需要外部监督信号（奖励函数、测试用例等），而无监督的测试时扩展方法（如多次采样、搜索）则在每个问题后丢弃所有知识，无法跨问题泛化。

评看方法和消融即可；若无标注轨迹能稳定沉淀技能，pretrain 数据课程和记忆机制都该重想。
