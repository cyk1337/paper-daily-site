Do Agent Benchmarks Do What They Say? An Executable-Contract Audit of Tool-Using Agent Environments

这篇工作要解决的问题不是“agent 能不能用工具”，而是“agent benchmark 给出的分数，是否真的对应了环境里发生过的状态变化”。作者指出，很多工具使用型 benchmark 默认相信工具接口的成功返回值，认为只要 tool call 回了 success，就等于环境状态按接口承诺被正确修改了。但这个假设可能是错的：工具实现可能没有真正写入状态、只做了部分写入、忽略了参数，甚至 evaluator 还会把这种错误成功信号当成得分依据。论文把工具接口视为一种可执行契约，逐个检查接口宣称、实现代码、环境状态变化和评分逻辑之间是否一致，并进一步追踪哪些任务分数暴露在这些缺陷之下。

评做 tool-use 或 agent RL 的人该看：它提醒你 benchmark 分数可能是在给环境 bug 打分；读审计 taxonomy 和静态检查结果就够，方法本身还不够成熟。
Rohith Reddy Bellibatlu,Zichong Wang,Wenbin Zhang
