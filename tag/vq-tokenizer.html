MegaParts: Scaling Part-Aware 3D Object Generation to 300 Parts via Token-Efficient Autoregressive Modeling

现有部件感知3D生成方法存在扩展性瓶颈——扩散类方法随部件数增加面临token长度与内存开销爆炸，自回归类方法则存在几何保真度与token效率的权衡，难以支持上百个部件的高复杂度3D物体生成。

GEAR: Guided End-to-End AutoRegression for Image Synthesis

现有自回归图像生成模型采用两阶段训练流程：先单独训练VQ分词器（仅优化重建目标）后冻结，再训练AR生成器；分词器完全不感知生成器的建模难易度，重建与生成目标存在固有张力（重建偏好高方差、细节丰富的潜表示，生成偏好简单、可预测的结构），同时离散VQ索引的不可微特性导致生成器梯度无法直接回传分词器，朴素直通估计器会引发码本崩溃。

RankE: End-to-End Post-Training for Discrete Text-to-Image Generation with Decoder Co-Evolution

离散自回归文生图模型在后训练时通常只更新 AR policy、冻结 VQ decoder。RankE 指出，这会造成 decoder 输入分布与其预训练时见过的 ground-truth VQ code 分布逐步偏离，即 Latent Covariate Shift，导致 reward/alignment 变好但图像保真度变差。

评值得看decoder共训练消融；若结论干净，会改变离散视觉token后训练中“冻结解码器即可”的默认做法。
