1) Kubernetes DRA driver for composable CXL memory:
- Publishes one ResourceSlice per CXL blade, but unlike node-local devices it sets a NodeSelector spanning all hosts connected to that blade.
- On demand, composes a CXL region via a fabric manager, materializes it as device_dax on each participating host, and injects it into pods under a single CDI device name so pods on different nodes map the same physical region.
- Adds lifecycle robustness (finalizers and redundant teardown metadata) to ensure free-on-delete survives plugin restarts.

- Implements a shared-memory KV tier whose directory lives inside the shared medium (atomic slot bitmap + parallel key array), avoiding an external metadata service.
- Hooks into vLLM/llm-d offloading connector; notes practical prerequisites like fixed hash-chain seeding for cross-instance reuse and block granularity effects (e.g., 256-token blocks causing partial-block recompute).
