这篇工作解决的是一个长期缺位的评测问题：现有代码修复基准大多围绕单进程软件缺陷，难以测到模型在分布式系统调试中的真实能力。分布式 bug 的关键难点不在“会不会改代码”，而在“能不能恢复跨进程因果链”：错误往往由超时、重试、消息乱序、竞态、协议不变量破坏等共同触发，根因通常不能从局部源码直接读出来，靠 agent 暴力探索也会被非确定性交互和组合爆炸拖垮。论文因此同时补两个空白：一是构建面向分布式系统源码级修复的 benchmark；二是在严格控制条件下，量化外部调试上下文——如日志、trace、诊断笔记、失败测试输出——到底能给 agent 带来多少帮助，以及这种帮助会如何改变模型排序、token 开销和行为模式。

评如果你关心 agent 能力评测，这篇比再看一遍 SWE-bench 排名更值；重点看它如何把“上下文供给”从混杂因素拆成可测变量。
Yibo Yan,Huijuan Wang,Junzhou He,Yizhuo Liang,Shaoyu Wang,Huanchen Sun,Seo Jin Park
