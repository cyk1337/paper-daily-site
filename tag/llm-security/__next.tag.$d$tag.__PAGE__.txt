The evidence comes from causal interventions and representation analysis: the authors examine how output confidence changes when internal activations are ablated or substituted, instead of relying only on descriptive attention patterns.

Second, they introduce the indicator-token sign test. For a malicious script family, they identify canonical indicator tokens such as Invoke-WebRequest. They then ablate those tokens from canonical malicious scripts and compare the change in malicious-class confidence between the base model and the fine-tuned model. If removing the token decreases malicious confidence in the base model, the token acts as a driver there. If removing the same token increases malicious confidence in the fine-tuned model, the token has become a suppressor. This sign divergence is interpreted as a warning signal: the family is now classified more through surrounding payload context than through the explicit command token, making it vulnerable to behavior-preserving rewrites.

Third, they use this signal for family-level prioritization. A linear probe near the classification boundary is used to detect representation drift and rank command families for targeted red-teaming. The benchmark is then built in three tiers: direct rewrites, command reconstruction, and case mutation, with matched seed/variant pairs and syntax or manual validation to preserve behavior. This is an important design choice. The benchmark is not just an obfuscation leaderboard. It isolates transformation classes so failures can be attributed to specific semantic rewrites.
