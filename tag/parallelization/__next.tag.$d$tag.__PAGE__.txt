9:T82d,ConvMem reformulates long-context QA as hierarchical convolution. Given a query Q and a very long document D, the model splits D into windows of size W. A frozen LLM, prompted with the query and a local chunk, acts as a semantic convolution kernel that extracts a chunk-level summary, evidence, or intermediate memory. All chunks at the same level are processed in parallel. Their outputs are then grouped and recursively summarized in higher layers, producing a tree of aggregations until a final global memory is formed for answer generation. Compared with sequential memory agents, the reasoning path becomes logarithmic in depth rather than linear in the number of chunks, while parallelism increases within each layer.

The paper adds three mechanisms on top of this backbone. First, configurable strides: using stride S < W creates overlapping windows, so the same evidence can be seen from multiple receptive fields. This is meant to reduce boundary truncation and improve recall when evidence spans chunk boundaries. Second, semantic skip connections: because hierarchical summarization can discard fine-grained details, high-confidence raw evidence is allowed to bypass intermediate compression stages and flow directly into the final reasoning stage. Third, multi-kernel convolution: the original query is decomposed into sub-questions, and separate semantic channels are used to extract evidence for different reasoning threads before merging them. This is intended to reduce interference between orthogonal subproblems.

Methodologically, ConvMem is a prompt-and-orchestrate framework rather than a newly trained model. It depends on the base LLM’s existing abilities in summarization, evidence extraction, and QA. Relative to MemAgent-style systems, the main differences are: no learned memory policy, tree-structured rather than chain-structured information flow, and parallel chunk processing instead of strictly sequential reading. Relative to standard retrieval pipelines, it is closer to full-document hierarchical coverage than sparse retrieval over a few selected chunks.a:T678,The evaluation is centered on long-context multi-hop QA settings, notably RULER-HotpotQA and RULER-2WikiMultiHopQA. The main empirical message has three parts. First, ConvMem outperforms training-free baselines, suggesting that hierarchical parallel aggregation is more effective than one-shot summarization, naive chunked QA, or simple map-reduce style prompting for multi-hop evidence integration. Second, ConvMem generalizes better than RL-trained memory agents on out-of-distribution settings. The authors emphasize that RL-based agents may look strong in-distribution but degrade more sharply under distribution shift and can produce plausible answers not actually grounded in the input. Third, the three architectural components each contribute: overlapping strides improve evidence recall, skip connections help preserve details, and multi-kernel decomposition is more useful on semantically entangled questions.

The paper explicitly studies overfitting in RL memory agents and argues that these systems can exploit pretrained knowledge or benchmark regularities instead of following a faithful memory trajectory over the document.
