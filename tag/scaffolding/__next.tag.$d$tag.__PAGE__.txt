In the experiments, a base model is trained on ground-truth demonstrations, then wrapped with a scaffold to form a teacher. A same-class, same-size student is trained on the teacher’s traces, either from scratch or by fine-tuning the base model. The tasks include Dyck languages, Sokoban, and modular arithmetic. The scaffolds include verifier-guided backtracking, A* search with model-pruned expansions, and a simpler fixed-token-deletion regeneration rule. The key experimental design separates local competence from compositional competence: the base model can perform the local steps, while the scaffold maintains candidates, search frontiers, visited sets, or verifier-controlled backtracking state. The theoretical part models search through directed s-t reachability. The base model answers local edge queries, which are computable by constant-depth Boolean circuits. The scaffold repeatedly uses these local queries to run BFS and decide reachability. Internalizing the scaffold requires the student to decide reachability from the graph representation. Under standard precision assumptions, fixed-depth polynomial-size Transformers can be simulated by TC0 circuits, even with logarithmic-length chain-of-thought in the cited setting.
