NeuroPrefetcher: Storage-Aware Sparse LLM Inference via Delta Prefetching

这篇工作处理的是一个比常见 edge LLM 部署更难的设定：模型在整个推理过程中始终大于可驻留内存，因而 NVMe/存储不再只是冷备份，而是解码关键路径上的主动权重层级。问题不只是“如何做稀疏推理”，而是“在自回归逐 token 解码里，如何利用跨 token 的稀疏激活时间局部性，提前知道下一步需要哪些 MLP 行权重，并且只搬运新增的那一小部分”。作者观察到相邻 token 的活跃神经元高度重叠，约 82–85% 会延续到下一 token；如果系统仍按 demand paging 或逐层临时判定来取数，就会把大量本可复用的权重反复放到 I/O 临界路径上，导致 CPU 长时间阻塞、GPU 空转。

评只看“跨token激活局部性=可预取的delta集合”这条观察和系统实现细节；收益是否稳健取决于稀疏门控与工作负载分布。
Nobel Dhar,Md Romyull Islam,Xuechen Zhang,Gongjin Sun,Sahidul Islam,Bobin Deng,Kun Suo
