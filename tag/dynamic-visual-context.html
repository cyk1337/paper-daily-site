FOVEA: Focused On-Demand Visual Evidence Adaptation for Cache-Friendly Multimodal Speculative Decoding

这篇工作解决的是多模态 speculative decoding 里的一个具体瓶颈：草稿模型既要便宜，又要拿到足够的视觉证据来提出可被大模型接受的 token；但视觉证据需求并不是固定的。现有方法通常给 drafter 一个固定视觉接口，要么固定视觉 token 预算，要么固定压缩表示。作者指出这两种做法都不合适，因为不同样本、不同解码阶段、甚至同一棵 draft tree 的不同分支，对视觉信息的需求都不同，而且“更多视觉输入”并不总是更好。

评VLM 推测解码的工程优化，核心 insight 是 drafter 不需要看全图，按需检索视觉特征能提速，做 VLM serving 的可以看看。
Hengjie Zhu,Dayan Wu,Zihao Zhang,Xinze Liu,Jingxuan Yu,Peng Fu,Zheng Lin,Weiping Wang,Ding Wang
