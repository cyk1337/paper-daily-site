9:T493,Hydra is a common-schema instrumentation and analysis framework. The authors instrument both HuggingFace Transformers and llama.cpp so that two very different inference stacks emit the same per-prompt timing record. The canonical schema covers at least tokenization, prefill, per-token generation, de-tokenization, inter-token latency, and end-to-end latency. These phase boundaries are then fused with high-resolution telemetry from tegrastats and NVML, enabling attribution of CPU activity, GPU utilization, DRAM traffic, power, energy, and thermal behavior to the prefill and decode windows. Two design choices matter. First, the measurement interface is decoupled from execution configuration, so models, precisions, prompt lengths, and SoC generations can be swapped without changing the analysis pipeline. Second, the framework spans both the Python framework path and the GGML/C++ path, which makes the comparison more realistic for deployment. The instantiated study covers three Jetson generations—AGX Xavier, AGX Orin, and AGX Thor—two backends, 13 instruction-tuned models from seven families, and five execution formats: bf16, F16, Q8_0, Q6_K, and Q4_K_M.a:T46b,The paper is more about stable findings than about one best number. First, performance depends jointly on backend, architecture, precision, and sequence length; model size alone is not predictive enough. Hydra’s phase-level timing shows that backend overhead, quantized decode throughput, and input/output-length scaling affect different parts of the inference pipeline. Second, quantization often reduces DRAM traffic and model footprint, but it does not automatically reduce latency or energy on edge SoCs, because CPU orchestration, GPU effective utilization, shared-memory bandwidth, DVFS, and thermal limits also matter. Third, backend choice changes CPU-side runtime behavior enough to alter decode throughput and efficiency. Fourth, gains across SoC generations are not uniformly realized; newer hardware can improve throughput or energy efficiency in some settings, but backend overheads or thermal constraints can offset part of the benefit in others.
