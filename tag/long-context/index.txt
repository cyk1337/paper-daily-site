18:T41b,The method is simple and well structured. The authors profile an API model over a grid of input and output token lengths, estimate and subtract network latency as much as possible, and fit generalized linear models to explain inference time. The resulting picture is intuitive: decode scales roughly linearly with generated tokens, while prefill requires both linear and quadratic terms in input length, matching the expected algorithmic behavior of attention-heavy inference.

For energy, the paper uses a local-equivalence strategy. Since API power cannot be measured directly, the same open-weight model is deployed locally under several hardware and software configurations. For each local setup, the authors fit a pair of GLMs: one for compute time and one for energy. They then compare the API time GLM to the local time GLMs, select the locally measured setup whose time behavior is most similar, and use its paired energy GLM as a grounded estimator of API energy. The key idea is behavioral matching rather than exact hardware identification.19:Tc55,模型是 decoder-only causal Transformer，但关键在若干组合设计。

一是混合注意力。Kolibri 在 50 层中采用 4:1 的 SWA 与 full attention 交替：每 5 层里 1 层 full attention，其他 4 层用 512 token 窗口的 sliding-window attention。这样做的目的很明确：大部分层用局部注意力压低训练和解码成本，少量 full attention 层负责全局信息混合。更有意思的是位置编码并非统一处理。SWA 层使用 RoPE，full-attention 层则使用 NoPE；同时对 Q、K 做 per-head RMSNorm，且在 SWA 层中先 norm 再加 RoPE。这个组合反映出作者的判断：局部窗口层需要显式相对位置信号来稳定局部建模，而全局层若继续叠加 RoPE，可能在长上下文外推或注意力尺度上带来额外负担，NoPE 反而更干净。论文把这些不是当作独立 trick，而是作为 hybrid attention 的配套设计来选。

二是 MoE 稀疏结构。每层有 384 个 routed experts，每个 token 选 6 个 routed experts，再加 1 个 shared expert；router 用 sigmoid logits，但 top-k 后不再归一化。这一设计明显受 DeepSeek 系 MoE 影响，目标是让路由权重表达更灵活，同时通过 shared expert 提供稳定的通用通道。负载均衡使用 EQB 和 LEI，而不是传统单一 auxiliary loss。Kolibri Origin 则是另一套更简单、稀疏度更低的对照架构：8-of-128 routed experts，前两层 dense，全层 full attention。作者通过代理实验逐步走向更高总容量、更低 active ratio 的 Kolibri 主架构。

三是 tokenizer。词表大小 128k，采用 UniBPE。它仍是自底向上的 merge 过程，但每一步 merge 选择依据是 Unigram loss，而不是标准 BPE 的频次启发式。作者特别强调德语形态学边界：与 GPT-5 tokenizer 相比，Kolibri tokenizer 在德语上有 65.2% 的 token 边界落在 morpheme boundary，而对方是 47.3%；在德语网页文本上 token 数减少 11.2%。这不是小修小补，因为德语复合词和屈折变化多，tokenizer 若切分不合理，会直接影响 token budget、上下文利用率和训练信号密度。

四是训练流程。Kolibri 总训练量 24T tokens，包含 pre-training、mid-training 和 long-context extension；目标最大上下文训练到 256k。作者没有只做一次大规模训练，而是先在 M/L 两个代理尺度上做受控消融。M 规模是 7.8B total / 0.6B active，训练 97.6B tokens；L 规模是 30.6B total / 2.1B active，训练 327.6B tokens。模型形状 sweep 时，还会在最小代理尺度上调学习率，而不是完全相信 scaling-law 预测值，避免把 shape 优劣和 learning-rate 失配混在一起。这一点很专业，也很少在公开报告里讲得这么明确。

具体做法分三层。第一层是重要性度量。它不去显式估计完整 attention map 的重要性，也不做额外 teacher distillation，而是用每个 query block 的输出梯度范数来近似该 block 对参数梯度的贡献。这个选择的好处是信号直接来自当前训练步的反向传播，且与 FlashAttention 的 tile/block 结构天然对齐。

第二层是预算式稀疏化。作者不是预设固定 sparsity ratio，而是设定一个“允许丢弃的梯度质量比例”预算。先根据 block 级梯度质量排序，再决定哪些 block 可以被跳过。这样稀疏率会随训练阶段、样本、层而变化；当梯度分布更尖锐时，可以跳过更多 block；当梯度更平时，自动保守。这比固定 top-k 或固定阈值更稳，因为后者容易在不同 batch 和不同长度下失配。

The forward pass is left unchanged and implemented with standard FlashAttention, so model outputs and serving behavior remain exactly those of a dense-attention model. Sparsity is introduced only in the backward kernel.

The first ingredient is block-level importance estimation. Instead of predicting sparse patterns from attention scores or distilling from a dense teacher, LazyFlash uses the norm of the output gradient for each query block as a proxy for that block’s contribution to parameter gradients. This is attractive because the signal is already available during backpropagation and aligns naturally with FlashAttention’s tiled computation.

The second ingredient is budget-based sparsification. Rather than fixing a sparsity ratio, the method sets a budget on how much gradient mass may be discarded. Blocks are ranked by gradient contribution, and the effective sparsity adapts to how concentrated the gradient distribution is at each step. This is more robust than fixed top-k or threshold rules, which can miscalibrate across batches, layers, or sequence lengths.

The third ingredient is unbiased estimation through importance sampling. Deterministically dropping low-contribution blocks would introduce bias. LazyFlash instead samples retained blocks with probability proportional to their gradient contribution and rescales them accordingly, yielding an unbiased gradient estimator. That is the key step that turns the method from heuristic pruning into controlled stochastic approximation.

Implementation-wise, the authors integrate this into a FlashAttention backward kernel and support both dense and variable-length inputs. Compared with methods such as SeerAttention or DSA, LazyFlash does not require computing dense attention targets for distillation, so the training-side savings are real.
