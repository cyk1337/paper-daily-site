From that one decode step, PeekKV derives two signals. The first is a head-group score, used to allocate KV budgets across groups of heads in proportion to their estimated importance. Starting from single-head attention, the paper avoids optimizing the exact post-deletion output error because softmax renormalization makes the objective combinatorial and strongly coupled. Instead, it uses calibration queries to approximate the query distribution encountered during reuse of the fixed context, and derives a quadratic surrogate over the resulting output error.

That surrogate has two properties that make the method practical:
1. For each candidate deletion, it yields a closed-form optimal compensating update to the remaining cache entries.
2. It also yields a closed-form score for the increase in surrogate loss after applying that optimal compensation.

This leads to KV-Surgeon: at each step, evaluate every candidate entry by the residual error after optimal compensation, remove the best candidate, apply the compensating update to the surviving cache, and repeat. The next deletion is then chosen against an already compensated cache, not the original one. This is the key difference from methods such as CAOTE, OBCache, or attention-matching-style selection, which either estimate single-deletion damage with the rest fixed or postpone refitting until after subset selection.

The paper also presents a faster variant, KV-Surgeon-fast, which trades some quality for much lower offline construction cost. A final joint refit is still used after selection, but the important point is that compensation already influences which entries survive. The retained set is therefore selected with awareness of how well the remaining cache can absorb the deletion.

A notable strength of the formulation is that it is not purely attention-mass based. It also captures value redundancy: if an entry's value is already close to the current output, removing it may have limited effect even when its attention weight is nontrivial. This helps explain why the method improves over attention-only heuristics.11:T5f4,The evaluation is fairly broad: QuALITY, LongHealth, and Long Code Arena; dense and MoE models; model sizes from 4B to 30B; and compaction ratios from 5x to 100x. For implementation or adaptation, the derivation and appendix deserve a closer pass.13:T683,The central idea is layer-major delayed eviction. Instead of processing the full prompt through all layers in the usual sequence-major manner, TideKV completes one layer over the entire prompt before moving to the next. The prompt is split into chunks. For a given layer, the system streams chunks one by one, accumulates that layer’s full uncompressed KV history, and only after the layer has consumed the whole prompt does it run KV selection/compression and release the full cache for that layer. This preserves full-prompt visibility for the selector, unlike online eviction, while ensuring that uncompressed KV is resident for only one layer at a time.

To prevent the compression step itself from creating another memory spike, the paper introduces a two-pass blockwise streaming top-k procedure. The first pass accumulates log-sum-exp normalization statistics over key blocks. The second pass computes token scores and performs selection, without materializing the full observation-by-prefix attention matrix. This keeps temporary memory independent of prompt length. An important design choice is the decoupling between scheduling and scoring: TideKV is compatible with existing prefix-based selectors, so the contribution is the cache-construction architecture, not a new token-importance rule. The framework also supports layer-adaptive and head-adaptive budget allocation, allowing non-uniform KV budgets across layers and heads under the same delayed-eviction invariant.

That distinction matters. The paper is not proposing a new compression criterion; it is proposing a new way to build a compressed cache entirely on GPU under a strict memory budget.14:T54e,From the full text excerpt, the evaluation covers Llama and Mistral models on LongBench and RULER, together with memory and latency measurements. The key comparison is among three regimes: standard full-prefill then compress, online chunk-level eviction, and TideKV’s delayed layer-end eviction. The intended empirical claim is twofold. First, peak memory drops substantially because only the active layer keeps full uncompressed KV and only the active chunk keeps temporary activations. Second, at the same final KV budget, quality is better than online eviction because selection is made after full-prompt exposure.

第二部分是 Linear Postmix。仅靠组内 Premix 还不够，因为 KV heads 只有 2，跨组的信息通道仍然受限。Postmix 在 attention 输出后施加一个低秩 identity-residual 变换 I + AB^T，其中秩 r 取 Hq'/2，例如 1.7B 模型里 r=4。这个设计的意图是用很小的额外参数和计算，把不同头、不同组之间的特征再融合一次。作者把它解释为 structured low-rank cross-head communication。与 MFA 通过增大 head dimension 来补容量不同，VHA 不去扩大每个头的宽度，而是在头之间做便宜的线性耦合，因此训练和 prefill FLOPs 不会上升，反而因为物理 query heads 减半而下降。

一个很漂亮的工程点是：Premix 和 Postmix 都是纯线性操作，没有非线性，也不依赖 token 位置或上下文状态，因此在推理时可以分别吸收到 WQ 和 WO 中。吸收后，线上模型就是一个标准 GQA-2 结构，完全复用现有 kernel 和 serving 优化，不引入额外 runtime overhead。这一点把它和很多“训练时好看、部署时麻烦”的注意力变体区分开了。

从对比关系看，VHA 与 GQA 的区别是：GQA 直接让更多 query heads 共享同一组 K/V，而 VHA 在共享前后都加了可学习线性补偿；与 MLA 的区别是：VHA 不做 latent KV 压缩，因此避免了 latent bottleneck 带来的质量损失；与 MFA 的区别是：VHA 不通过增大 head dim 来换质量，因此不会显著增加训练和 prefill 计算。28:T834,实验覆盖面比较完整。作者在四个基础规模上做了 4K context、50B token 预训练：0.6B、1.7B、4B dense，以及 8B-A1B MoE。结果是 VHA 在所有规模上都超过标准 GQA baseline，提升范围约为 +0.05% 到 +0.81%。这里绝对数值看起来不大，但要注意比较对象已经是很强的 GQA，而且 VHA 同时把 KV cache 压下去了。

以 1.7B 为例，GQA-8 的 KV cache 是每层每 token 4KB（BF16），直接降到 GQA-2 后变成 1KB，但会带来约 1.00% 的质量下降。MLA 的 cache 约 1.12KB，质量在多个尺度上最低。MFA 也能做到 1KB cache，质量接近 GQA-8，但在 1.7B、序列长度 4096 时训练和 prefill FLOPs 增加 49.8%。VHA 则在保持 1KB 级别 cache 的同时，相比 GQA-8 还把训练和 prefill FLOPs 降低了 7.9%，并且质量超过标准 GQA baseline。这正是论文所谓同时改进三角形三个顶点的证据。

This immediately reduces both KV cache and attention compute, but it also removes a large amount of head diversity. VHA restores that diversity through two lightweight linear modules.

The first is Q Premix. Within each KV group, Premix applies a near-identity linear transformation to the reduced set of physical query heads, effectively expanding them into a richer set of virtual query heads. The near-identity design is important. It keeps the model close to a stable GQA-2 parameterization early in training, while allowing the network to gradually learn structured specialization among heads that share the same KV pair. The authors’ matrix inspection suggests that this is exactly what happens: Premix learns group-conditioned query specialization rather than arbitrary mixing.

The second is Linear Postmix. Even with better within-group query diversity, using only 2 KV heads still limits cross-group interaction. Postmix therefore applies a low-rank identity-residual transformation, I + AB^T, to the attention output. The rank is small, for example r = Hq'/2 and r = 4 at the 1.7B scale. This gives the model a cheap way to fuse information across heads and groups after attention, without increasing head dimension or introducing nonlinear runtime structure. The paper interprets this as structured low-rank cross-head communication.

A major engineering advantage is that both modules are purely linear. Premix can be folded into the query projection matrix WQ, and Postmix into the output projection WO at inference time. After folding, the deployed model is just a standard GQA-2 model. This means VHA inherits existing inference kernels and serving optimizations from frameworks such as vLLM and SGLang with zero additional runtime overhead.

Relative to prior methods, the distinctions are clean. Compared with standard GQA, VHA adds learnable compensation before and after shared-KV attention. Compared with MLA, it avoids a latent KV bottleneck. Empirically, the leading half of H's eigenvectors captures 62% to 75% of the projection energy across models and layers, so RoLaQ restricts rotation learning to a compact subspace defined by this joint geometry rather than searching over the full latent space.
