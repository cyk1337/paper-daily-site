Because the distance term grows without bound, every positive slope will eventually underflow; larger slopes fail earlier, while flatter slopes fail later. The authors formalize the corresponding blindness distance and separate two effects: positional blindness, where distant values cannot contribute to the head output, and weight redistribution, where zeroed terms disappear from the softmax denominator. P is the deployed model. It uses sliding-window attention plus recurrent K/V injection, where a shifted memory window is inserted as additional key-value context. This avoids dedicated memory tokens and avoids a separate memory-cache mechanism. The training challenge is that direct recurrent training would require sequentially generating m_1, m_2, ..., m_T, which destroys the sequence parallelism that makes Transformer pretraining efficient. The paper’s lifted parallel training avoids this by externalizing the latent trajectory. First, Q computes m'_1:T in a causal but sequence-parallel pass. Then shifted memories m'_{0:T-1} are fed into P, which is trained in parallel to do two things: predict next tokens and reproduce the target memories via a consistency loss between m_t and m'_t. At inference, Q is discarded and P closes the loop with its own generated memories.

A long context is split into equal-sized chunks, and a global textual memory is initialized as empty. Each turn consists of three operations: read, select, and merge. In the read step, all chunks are processed in parallel conditioned on the same current global memory. This differs from standard recurrent-memory systems, where chunk i must wait for the memory updated by chunk i-1. The immediate consequences are lower latency and less risk that later chunks repeatedly overwrite a single evolving memory state before earlier evidence can be integrated.

In the select step, the model extracts observations from each chunk that contain new or complementary evidence. The important mechanism is that, in the next iteration, every chunk is read again under a memory that already contains evidence gathered from other chunks. Cross-chunk interaction therefore happens through iterative shared-memory refinement rather than through a single serial pass. The process stops either when no chunk contributes useful new evidence or when a predefined maximum number of turns K is reached, after which the model answers based on the question and the final memory.

Training is done end-to-end with reinforcement learning rather than stepwise supervision of memory contents. The reward combines answer accuracy with a turn-efficiency term that discourages redundant turns. The representation has three parts. First, for each layer and KV head, the method selects k anchor positions and stores their keys and values exactly. The anchor budget includes a recency window, so recent tokens are preserved with high fidelity by construction.

Second, every non-anchor token is approximated separately in K-space and V-space by projecting it onto the direction of its closest anchor. This turns a D-dimensional vector into an anchor index plus a scalar coefficient. It is more expressive than replacing tokens with a shared centroid, because magnitude remains token-specific even when direction is shared. Keys and values share anchor positions, but assignments, projection coefficients, and residual sets are separate, which makes sense because K and V affect attention in different ways.

Third, only a subset of positions receives an additional stored residual under a fixed byte budget. Residuals are rotated with a randomized Hadamard transform to spread energy and reduce outlier sensitivity, then quantized at 2 bits per coordinate using per-token absmax scaling and a four-level Lloyd-Max codebook. The important part is not just the codec: residuals are allocated according to how much they reduce attention-output error, not according to generic reconstruction loss. Residual budget is shared across heads within a layer, so heads compete for bytes where they matter most.

A notable design choice is what the method avoids. It does not rely on decode-time retrieval from host memory, so there is no fetch scheduling in the critical path. 第二步，压缩器不是把 learned memory token 插进 Transformer 里参与多层自注意力，而是用轻量、非注意力的局部压缩。具体做法是把一个 segment 的 hidden states 按连续窗口分块，每个 memory slot 汇总 C 个相邻 token 的 hidden state，先做 mean pooling，再做投影，得到 N_M 个 memory slots。这样每个 slot 对应一个局部区域，信息来源明确，也减少了“压缩 token 在层间不断漂移”的问题。作者显然是在反对 ICAE/soft prompt memory 那类让 memory token 在网络里不断被更新的设计。

第四步，只对选中的 memory block 做解压。decompressor 把紧凑 memory 恢复成与 decoder 某个中间层 l_inject 兼容的 hidden states，然后把这些重建状态注入 decoder。decoder 因此不是从压缩 memory token 直接生成，而是从“被恢复到中间表示空间”的证据上生成。作者把这叫 selective decompression。这里的关键不是压缩本身，而是把 storage 和 conditioning 解耦：memory 可以压得很紧，但真正参与生成的是解压后的、层空间匹配的表示。

全文还强调一个扩展能力：encoder 和 decoder 可以不是同一个模型规模。小模型可以离线构建 memory，大模型在线解压并回答问题。这样上下文处理成本和回答能力被拆开了。这一点对 serving 很现实，因为长文档预处理可以离线做，在线只保留 query-conditioned 选择和有限解压。

和已有方法相比，SeDeM 不同于 hard token selection，因为它保留的是连续 hidden-state memory；也不同于 learned memory token 直接作为 soft prefix 的方法，因为它不要求压缩表示同时承担存储和生成条件两种角色。作者的核心主张是：高压缩率下，直接 conditioning on compressed memories 是瓶颈，必须先恢复到 decoder-compatible hidden states。19:T96a,SeDeM has four stages: segmentation, compression, selection, and decompression with layer injection.

First, the long context is split into segments. For each segment, a frozen LLM acts as a feature extractor, and hidden states are taken from an intermediate extraction layer l_extract. The design intuition is that intermediate states already encode local context but are not yet too specialized by later layers.

Second, compression is deliberately lightweight and non-attentional. Instead of inserting learned memory tokens into the Transformer and letting them evolve through self-attention, the method partitions a segment's hidden states into contiguous local chunks. Each memory slot summarizes C neighboring token states via mean pooling, followed by projection, producing N_M memory slots per segment. This keeps each slot tied to a local region and avoids the representation drift that can happen when compression tokens are repeatedly updated across layers.

Third, given a query, a selector retrieves the top-k relevant memory blocks. The selector is trained with block-level evidence supervision, which is an important practical choice: it gives the retrieval stage explicit supervision about where answer-bearing evidence lives, instead of relying only on weak end-task signals.

Fourth, only the selected memory blocks are decompressed. A decompressor expands compact memories into hidden states that are compatible with an intermediate decoder layer l_inject, and those reconstructed states are injected into the decoder. The decoder therefore does not generate directly from compressed memory slots. This is the central claim of the paper: storage can be highly compressed, but generation should condition on reconstructed hidden states in the decoder's representation space.

The paper also emphasizes a cross-model setting. A smaller model can build memories offline, while a larger decoder consumes decompressed memories online. That decouples context-processing cost from answer-generation capacity, which is attractive for serving.

Relative to prior work, SeDeM differs from hard token selection because it stores continuous hidden-state memories, and it differs from soft-prefix memory methods because compressed memories are not used directly as the generation prefix. The key thesis is that direct conditioning on compressed memories becomes the bottleneck at high compression ratios.1a:T769,The evaluation covers four long-context QA datasets: 2WikiMultiHopQA, MuSiQue, QASPER, and HotpotQA-Distractor. Results are reported with Llama-3.2-1B and Llama-3.2-3B in same-backbone settings. The paper claims that SeDeM outperforms all evaluated compression baselines across the four datasets in the reported setup. With the 3B backbone, it even surpasses the full-context fine-tuned reference on 2WikiMHQA, QASPER, and HotpotQA-Distractor, while remaining below the full-context reference on MuSiQue. That pattern suggests the method is especially effective when evidence can be localized and selected at the block level, while more compositional multi-hop reasoning still suffers from compression and selection loss.

The setup is straightforward. Given a source model MSrc and its context cache KVSrc,Ctx for a long context xCtx, the goal is to produce a translated cache \hat{KV}Tgt,Ctx that a target model can continue from, ideally behaving similarly to the target model’s own native prefill on the same context. The challenge is that source and target models may differ substantially in architecture, so a simple one-shot projection is often too rigid.

MoT addresses this by using multiple translator modules instead of a single universal translator. A gating mechanism combines them, effectively allowing token-level or state-level mixtures of translation modes. The underlying claim is sensible: heterogeneous source–target mappings are not uniform. Different tokens or subspaces may require different translation behaviors, so a mixture can model local correspondences better than one global path or one shared latent space.

The paper also identifies two competing error sources:
1. Propagation error: if translation happens too early, translation noise is propagated and amplified through the remaining target layers.
2. Correction-deficit error: if translation happens too late, the target model has too few upper layers left to repair the mismatch.

This explains the reported U-shaped validation loss as a function of translation depth. MoT mainly attacks the first issue by increasing translation capacity. The Context Correction Loss addresses the second by supervising the replayed target-side trajectory after translation to match the native target trajectory.
