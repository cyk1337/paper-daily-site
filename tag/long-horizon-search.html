ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment

VibeSearchBench: Benchmarking Long-horizon Proactive Search in the Wild

这项工作提出并评测一种更接近真实用户搜索的长程交互任务：用户一开始只给出模糊需求，代理需要在多轮搜索、返回部分结果、追问偏好和调整方向中逐步逼近目标信息。它要解决的是现有搜索 benchmark 过度指定、单轮化、固定 schema 输出的问题。

评值得看任务构造和 graph-matching 评价；它比又一个静态 search QA 更接近真实 agent 失败面。
