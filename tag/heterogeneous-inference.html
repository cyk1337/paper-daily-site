PaT: Planning-after-Trial for Efficient Test-Time Code Generation

这篇工作解决的是 test-time code generation 里的计算分配问题：现有很多方法默认先规划再生成，也就是对所有样本都先付出 decomposition / planning 的成本，但真实任务难度分布并不均匀，很多题目直接生成就能过。论文要回答的是，能不能把昂贵的 planning 从默认前置步骤，改成只在直接尝试失败后再触发，从而把测试时算力集中到真正困难的样本上。

评对预训练本身帮助有限，但它把“验证失败才升级算力”做得很干净；只看方法图和成本曲线即可，适合拿来想 post-train/test-time compute 的资源分配。
Youngsik Yoon,Sungjae Lee,Seockbean Song,Siwei Wang,Wei Chen,Jungseul Ok
