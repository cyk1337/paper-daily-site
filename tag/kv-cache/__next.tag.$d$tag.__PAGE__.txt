9:T482,The proposed method is UMIM. It first builds a merge set from a general corpus by collecting frequent contiguous n-grams of length 2 to 4. At inference time, merge candidates are selected with a longest-match rule when spans overlap. For each selected span, UMIM takes the static token embeddings and uses a lightweight single-layer attention module to produce one surrogate embedding, which replaces the original multi-token embeddings at the input layer.

The merge module is trained with predictive distillation. The pretrained LM is frozen, and only the merge module is updated so that the next-token distribution under compressed inputs matches the distribution under the original uncompressed sequence. The context-independent design makes the module reusable, but it is also a limitation: the same n-gram receives the same surrogate wherever it appears, which may be brittle for ambiguous phrases or spans whose role depends strongly on surrounding context. The method is applied to both prompt compression and autoregressive decoding context compression, with rollback used to replace multi-token KV-cache entries by single-step surrogate states.a:T496,The experiment transfers state from Qwen3.5-4B-Base to Qwen3.5-9B-Base. The state is decomposed into attention keys and values, recurrent matrices, convolution buffers, and metadata. After the source processes a 4,096-token prefix, the receiver starts from the real next token and is evaluated on the following teacher-forced targets, with no target-side replay of the historical prefix. Attention KV is translated with ridge maps per layer, head, and role; keys are de-rotated before mapping and re-rotated for the target. Recurrent and convolution states are either directly reused or mapped with learned ridge-style translators. A factorial component experiment tests direct versus translated choices for K, R, and C. The encoder handles the causal prefill side, and decoder global KV is projected from the final encoder hidden states. This gives a cheaper prefill path and a stronger decode path, matching input-heavy agent workloads. Second, the paper introduces Compressed Sparse Attention 2, or CSA2. DeepSeek-V4 can be viewed as a sliding-window local-processing backbone plus compressed global context; V4.1-Flash keeps SWA in every layer but simplifies the global branch. CSA2 statically assigns layers to Full, Reindex, and Reuse modes. Full layers generate global KV and perform indexing. Reindex layers reuse global KV from a previous layer but use their own indexer Q to rescore shared indexer K and select fresh Top-K indices. Reuse layers reuse both global KV and Top-K indices. Each layer still keeps its own global Q and local SWA KV, so the method shares the expensive global cache components without collapsing all attention behavior into one shared layer. Third, the system combines FP4 global KV cache training with SWA Bounded Replay. FP4 global KV reduces runtime cache size with only small degradation. SWA Bounded Replay avoids persisting SWA KV to SSD by replaying only the most recent n_win tokens, rather than the L × n_win replay needed for exact reconstruction in the earlier design.
