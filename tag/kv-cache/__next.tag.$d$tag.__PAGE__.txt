RMF 的定义也比较讲究。作者不用逐样本 ratio 再取中位数，而是用 ratio of sums：先算 excess_total = L(Y_QF)-L(Y_CC)，再算 excess_compute = L(Y_QP)-L(Y_CC)，两者之差是 excess_route，最后 RMF = sum(excess_route)/sum(excess_total)。这样避免了分母接近 0 时的高方差问题。置信区间用 sequence-cluster bootstrap，而不是 token bootstrap，和自回归序列相关性相匹配。

The route-mediated fraction, RMF, is defined as a ratio of sums rather than an average of per-sequence ratios. Specifically, excess_total = L(Y_QF) - L(Y_CC), excess_compute = L(Y_QP) - L(Y_CC), excess_route = excess_total - excess_compute, and RMF = sum(excess_route) / sum(excess_total). If the scoring layer’s route set changes, the token is labeled jump. If the scoring layer is unchanged but some upstream layer changed, it is labeled nonlocal. Otherwise it is pure flux. This partition lets the authors separate direct local route flips from upstream route perturbations that propagate through later representations, and from route-weight changes that do not alter the selected set.

具体做法分三步。第一步，每个 layer、每个 KV head 选出 k 个 anchor 位置，这些 anchor 的 key 和 value 精确存储。文中强调 recency window 会被并入 anchor 预算，也就是最近一段 token 默认保真，这符合长上下文推理里“近邻依赖强、最近 token 更敏感”的经验。

第二步，对每个非 anchor token，分别在 K 和 V 空间里找到最相近的 anchor，用该 anchor 的方向做一维投影。于是一个原本 D 维向量，被压成“anchor index + scalar coefficient”。这一步不是把 token 聚成簇后共享同一个向量，而是共享方向、保留幅度，因此比纯聚类中心替代更细一些。K 和 V 共享 anchor 位置，但 assignment、投影系数、residual 集合分别独立，这个设计是合理的，因为 key 影响匹配分数，value 影响读出内容，两者误差敏感性不同。

第三步，在总字节预算固定的情况下，只给一部分位置额外存储 residual。residual 先做 randomized Hadamard transform，把能量打散，降低少数坐标异常值对 2-bit 量化的伤害；再按 token 做 absmax 归一化，用面向高斯源的四级 Lloyd-Max codebook 量化，坐标 2 bit 存储。更关键的是 residual 不是平均分配，而是按“恢复 attention output error 的收益”来选位置，并且同一层内各 head 竞争共享 residual 预算。这说明作者优化目标不是向量级 MSE，而是更贴近最终注意力输出的误差。

从方法取舍看，AnchorKV 刻意避开了两类复杂性。它不做 decode-time 动态检索，因此没有 host-device fetch 的调度开销；也不改 attention kernel 主体，因此部署路径比 retrieval/offloading 类方案短。代价是压缩质量高度依赖 prefill 结束时对整段 cache 的一次性分析，以及 anchor 选择和 residual 分配策略是否足够稳健。c:T7c9,The method compresses the KV cache once, at the end of prefill, without changing model weights or the decode-time attention formula.

The representation has three parts. First, for each layer and KV head, the method selects k anchor positions and stores their keys and values exactly. The anchor budget includes a recency window, so recent tokens are preserved with high fidelity by construction.

Second, every non-anchor token is approximated separately in K-space and V-space by projecting it onto the direction of its closest anchor. This turns a D-dimensional vector into an anchor index plus a scalar coefficient. It is more expressive than replacing tokens with a shared centroid, because magnitude remains token-specific even when direction is shared. Keys and values share anchor positions, but assignments, projection coefficients, and residual sets are separate, which makes sense because K and V affect attention in different ways.

Third, only a subset of positions receives an additional stored residual under a fixed byte budget. Residuals are rotated with a randomized Hadamard transform to spread energy and reduce outlier sensitivity, then quantized at 2 bits per coordinate using per-token absmax scaling and a four-level Lloyd-Max codebook. The important part is not just the codec: residuals are allocated according to how much they reduce attention-output error, not according to generic reconstruction loss. Residual budget is shared across heads within a layer, so heads compete for bytes where they matter most.

A notable design choice is what the method avoids. It does not rely on decode-time retrieval from host memory, so there is no fetch scheduling in the critical path. It also leaves the attention arithmetic intact, which shortens the deployment path relative to more invasive kernel or retrieval schemes. The trade-off is that compression quality depends on how well anchor selection and residual allocation can summarize the full prefill cache in one shot.d:T6f2,The main empirical claim is straightforward: at matched byte budgets, AnchorKV at 20x compression outperforms eviction baselines at 10x, meaning higher accuracy with half the memory. The headline number is on Llama-3.1-70B: 99.3% of the full-cache RULER score is retained at 20x compression, versus 86.8% for the strongest baseline reported in the paper. The authors also note that retention improves with model scale, which matters because large models are exactly where KV cache becomes most expensive.

The evaluation spans three model scales and three long-context benchmarks, with comparisons done under matched retained-byte fractions rather than nominal compression labels. That is the right comparison because metadata overhead differs across methods.

The ablations appear to support three points. First, anchor projection alone already gives substantial compression, but selective residual storage is what pushes the method into the near-lossless regime. Second, allocating residuals by attention-output impact works better than simpler heuristics based on vector error, suggesting that operator-aware budgeting is essential. Third, the Hadamard-plus-2-bit residual codec is not incidental; it is what makes ultra-low-bit residuals still useful.

On runtime and memory, the paper emphasizes that compression happens once after prefill, so decode does not need host-device fetches for evicted blocks. That should make the method attractive in high-concurrency settings. Still, the paper is mainly about memory reduction and accuracy retention, not guaranteed end-to-end latency wins over every approximate alternative.
