- Start with any existing pruning method to select a fraction of “important” multimodal tokens for initial prefill (plus all text/control tokens). Keep the remaining multimodal tokens as deferred tokens.

2）Layer-wise Structural Sensitivity，记作 S_l：表示该层扰动经由后续网络被放大的程度，通常可由梯度范数或相关敏感度指标近似。

有了这个分解，系统设计就对应两条线。

第一条线是降低 E_l。作者认为现有 merging 方法的主要问题是忽略了 RoPE。RoPE 会对 query/key 施加位置相关旋转，导致 token 在旋转后的空间里不再适合直接按原始相似性做合并。于是他们把 token aggregation 放到 Pre-RoPE 的“安全区”，即在位置旋转之前进行聚合。为了避免简单合并导致注意力质量守恒被破坏，方法还引入 attention-conserving logit bias，在物理合并 token 时尽量保持原有注意力质量分布。这里的直觉是：不是只保留 token 数量，而是尽量保留被这些 token 支撑的注意力质量。

第二条线是管理 S_l。作者不满足于知道哪些层敏感，而是把 memory management 写成动态资源调度问题：在总内存固定、希望达到近似 O(1) 占用的前提下，按层分配不同 KV budget。具体做法是利用 offline gradient priors 估计各层敏感度，然后把更多预算留给高敏感层，从低敏感层更激进地回收内存。这样做的含义是，压缩不再是所有层一刀切，而是层感知的非均匀分配。

整体上，这是一个 hybrid framework：Pre-RoPE aggregation 负责减少局部误差，sensitivity-aware budget allocation 负责抑制误差放大。它是 training-free、model-agnostic 的，不需要重新训练底座模型。和已有方法相比，区别主要有三点：一是给了一个明确的误差分析，而不是纯经验规则；二是把合并位置前移到 RoPE 前；三是预算分配按层敏感度动态调度，而不是固定比例压缩。1b:T8f8,The method starts from a first-order Taylor analysis. Let the final model output be O and the attention output at layer l be A^(l). The model is abstracted as O = G(A^(0), ..., A^(L-1)). Compressing the KV cache at layer l introduces a local perturbation ΔA^(l). Under a small-perturbation assumption, the final output deviation can be approximated by a first-order multivariate Taylor expansion, yielding two factors:

1) Local Approximation Error E_l: the information loss caused directly by compression at layer l.
2) Layer-wise Structural Sensitivity S_l: how strongly perturbations at layer l are amplified by the rest of the network, estimated through gradient-based signals or related sensitivity measures.

This decomposition drives two design components.

The first component minimizes E_l. The authors argue that many existing merging methods ignore the effect of RoPE. Since RoPE applies position-dependent rotations to queries and keys, the post-RoPE space is no longer a clean space for similarity-based token merging. Their solution is to perform token aggregation in a Pre-RoPE 'safe zone,' before positional rotation. To avoid losing attention mass during physical token consolidation, they introduce an attention-conserving logit bias so that the merged representation better preserves the original attention distribution.

The second component manages S_l. Instead of using a uniform compression ratio across layers, the paper formulates memory management as a dynamic resource scheduling problem under a fixed memory budget. Offline gradient priors are used to estimate layer sensitivity, and more KV budget is assigned to high-sensitivity layers while low-sensitivity layers are compressed more aggressively. In other words, compression becomes layer-aware rather than uniform.

Overall, the framework is hybrid: Pre-RoPE aggregation reduces local approximation error, and sensitivity-aware budget allocation controls downstream error amplification. It is training-free and model-agnostic, so it does not require retraining the base model. Compared with prior work, the differences are clear: an explicit error decomposition instead of pure heuristics, merging before RoPE rather than after it, and non-uniform layer-wise budget scheduling instead of fixed-ratio compression.1c:T5e1,The headline result is explicit in the paper: on Qwen2.5-VL-3B, Video-MemComp improves overall accuracy from 62.3% to 64.1% while limiting the average KV cache to 6,000 tokens per layer, reducing KV-cache memory by more than 90%. This is the paper’s 'less is more' result: removing redundant or harmful history can improve accuracy rather than merely preserving it.

The evaluation is conducted on benchmarks including MLVU, Video-MME, and EgoSchema, and across multiple MLLM architectures. The experiments support four main claims. First, under very low memory budgets, the method can match or even surpass the full-cache baseline. Second, the gains come from both parts of the design: Pre-RoPE aggregation lowers local approximation error, while layer-wise budget allocation reduces error accumulation. Third, layer sensitivity is highly non-uniform, so uniform compression across layers is suboptimal. Fourth, RoPE-aware handling matters; merging after RoPE performs worse.

The most informative ablations are likely the following: with and without Taylor-guided sensitivity, with and without the Pre-RoPE safe zone, with and without the attention-conserving logit bias, fixed versus dynamic budget allocation, and accuracy-memory curves under different cache budgets. The paper turns a systems bottleneck into a modeling question: compressed context changes draft–target alignment, and that degradation has a clear temporal structure. That matters for long-context modeling, self-speculation, and any training setup where inference-time visibility is constrained. The contribution has three parts. First, it characterizes decode staleness and shows that prefill-only selection is not a robust solution once output length becomes large, especially in hybrid-attention models. Second, it proposes RIFT, which combines recency and importance instead of treating sliding-window and importance-based selection as mutually exclusive choices. Third, it adds compression-aware distillation so the drafter is trained under the same visibility constraints it will face at inference. On the inference side, the paper starts from two static extremes. One is pure sliding-window attention, which always keeps the most recent B tokens. The other is prefill-based selection, where a fixed subset of prompt KVs is chosen once using aggregated attention scores, as in SnapKV. Sliding window is strong on recency but weak on remote context. Prefill selection preserves long-range prompt information but becomes stale as decoding progresses. RIFT combines the two. The KV budget is explicitly split between recent generated tokens and importance-selected historical tokens. This preserves local continuity while still keeping a sparse set of long-range anchors.

The second idea is decode-time refresh. The importance-selected subset is not frozen after prefill; it can be recomputed periodically during generation. That lets the retained historical context adapt to the current decoding state. The trade-off is extra latency, so RIFT is presented as a family of strategies with different refresh frequencies and complexity/quality trade-offs.

The training-side contribution is compression-aware knowledge distillation. The authors argue that a drafter trained with full context but deployed with compressed context suffers from a substantial mismatch. To address this, they distill under compression-driven attention masks that mimic the inference-time cache restriction. The student is therefore optimized to match the teacher/target distribution under limited context visibility, rather than under an unrealistic full-cache condition.

Compared with prior work, SnapKV mainly relies on prefill importance and does not address relevance drift during decoding, while pure sliding window discards remote selection entirely. RIFT’s main difference is not a fancier scoring rule; it is the explicit treatment of time and the use of training to compensate for compression-induced distribution shift.21:T80b,The main metric is acceptance length (AL), which is the right quantity for speculative decoding because realized speedup depends heavily on how many draft tokens the target accepts. The evaluation focuses on SPEED-Bench, especially 32K input length with reasoning enabled, which makes output length long enough for KV bottlenecks and staleness effects to matter.

The headline result is that under 4× KV compression and 32K ISL, RIFT retains almost all of the full-cache drafter quality, while SnapKV drops sharply. With Qwen3.5-4B drafting for Qwen3.5-122B, RIFT retains up to 96% of full-cache AL. With Nemotron3.5-Lightning drafting for Nemotron3-Ultra, it retains 97%. A key empirical pattern is that as output length increases, sliding-window attention catches up to and then surpasses SnapKV. This is direct evidence for decode staleness: the value of recent generated tokens keeps rising, while the value of a fixed prompt-based subset decays. The effect is stronger in hybrid-attention models, where the few full-attention layers become more sensitive to which KVs are retained.
