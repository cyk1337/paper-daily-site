19:T592,The method is called blockwise policy-drift gating. For each sampled response token, the paper computes the old-current log-probability shift: the difference between the current student’s log-probability and the behavior student’s log-probability on the same sampled token. This is not a full KL estimate; it is a sampled-path drift signal. Using token-level importance ratios such as exp(d_t) is a natural baseline, but the paper argues that it is too noisy. Instead, it aggregates drift at an intermediate granularity. Two variants are used: Block64-Gate, which averages shifts over fixed 64-token blocks, and NewlineSpan-Gate, which aggregates over newline-delimited spans with heuristics for merging or splitting spans by length. The aggregated score is passed through a detached soft gate and mean-normalized over valid response tokens, then broadcast back to all positions in the region as a multiplicative weight on the existing OPD position loss. Three design choices matter. First, the gate is detached, so the model cannot optimize the gate itself; it only changes how much each position contributes to the base loss. Second, teacher targets are unchanged, so the same gating family can be applied both to sampled-token OPD and to Teacher-TopK/LSM.
