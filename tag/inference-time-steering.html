Latent Reward Steering: An Adaptive Inference-Time Framework that Implicitly Promotes Cognitive Behaviors in Reasoning LLMs

这篇工作处理的不是“模型不会推理”，而是“模型在推理过程中不能稳定地调用合适的认知行为”。作者关注的失效点很具体：同一个模型明明具备验证、回退、修正假设这类能力，但在实际生成时，这些行为是否被触发、何时触发、触发强度多大，往往取决于局部状态，因而容易在早期一步走偏后持续漂移。现有方法要么靠提示词显式要求某种行为，要么先定义一个行为方向再做表示干预，问题在于它们都预设了“该推什么行为”，缺少对当前推理状态的自适应性。LRS 试图把这个问题改写成：不直接指定 verification 或 backtracking，而是学习一个对中间 latent state 打分的 reward model，在推理时沿 reward 梯度微调 latent，让模型更容易走到那些最终能导向正确答案的内部状态。

评将 SAE 与 Reward Model 结合做 inference-time steering 是个有趣的思路，值得关注其在复杂推理任务上的泛化能力，重点看 §4 的干预机制设计。
