Beyond Success and Failure: Length-Aware Contrastive Learning for GUI Agents

这篇文章处理的是 GUI agent 的 RLVR 训练里一个更细粒度的问题：现有从 GRPO 转向 contrastive/classification 目标的方法，虽然缓解了 reward-gradient mismatch，但仍然把整条轨迹压成成功/失败二元标签，无法区分“成功但很冗长”和“失败但离成功很近”这两类在 GUI 交互里很关键的差异。

评将 RLVR 转化为对比学习并引入轨迹长度作为细粒度 reward，思路简单有效，对优化 Agent 的 RL 训练过程有启发，可关注其 loss 设计。

Joint Agent Memory and Exploration Learning via Novelty Signals

在开放式 GUI 探索中，LLM agent 需要“记住自己试过什么”才能避免重复并持续探索；但保留完整轨迹代价高，而潜变量(latent)记忆又缺少逐步监督信号。论文要解决的是：如何用无需人工标注的 novelty 信号，把“记忆学习”和“探索策略学习”绑在一起训练，让 latent memory 变得可用。

评建议扫方法和实验信号定义；把 coverage 当记忆监督很干净，但离通用 Agent 还差跨域 novelty。
