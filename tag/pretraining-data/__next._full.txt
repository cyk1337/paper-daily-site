处理变量 T 不是直接用 simplex 上的原始比例，而是先做 log-mixture 变换 z=log(t+ε)。这样做有两个原因：一是经验 scaling law 常表现为边际收益递减，log 空间更适合局部线性近似；二是 compositional data 在 simplex 上直接回归不稳定，Aitchison 风格的几何处理更自然。随后作者不去拟合完整响应面 μ(x,z)，而是在历史 mixture 支持域附近采用 partially linear approximation：Y≈g(X)+θ(X)^T z+noise。这里 g(X) 表示由数据状态决定的基线性能，θ(X) 是状态条件化的边际数据回报向量。θ_k(X)>0 表示在当前数据状态下提高第 k 个域占比通常有利，θ_k(X)<0 则意味着可能存在负迁移或技能冲突。

为了从观测到的历史 run 中识别 θ(X)，作者使用 Double Machine Learning 和 causal forest。具体思路是先分别拟合 outcome model 和 treatment model，对 Y 与 T 关于 X 的可预测部分做 orthogonalization / residualization，再在残差空间里估计局部线性效应。这样做的目的是把“数据池本身更好，所以性能更高”与“某个域比例更高，所以性能更高”分开，减少混杂偏差。得到 CATE 估计后，作者不是直接跳到新的最优配比，而是做 trust-region 约束下的保守更新，避免由于局部估计噪声把 mixture 一步推到训练支持域之外。这一点很关键，因为历史 proxy run 只有有限覆盖，过度外推很容易失真。

与 RegMix 一类方法相比，差别不在于用了更复杂的回归器，而在于目标函数变了。RegMix 更像学习一个静态全局 surrogate；CausalMix 学的是“在给定数据状态下，沿哪个方向改 mixture 更可能带来真实收益”。这使它天然更适合数据池变化、模型规模迁移和解释分析。论文还把 CATE 用于分析域间相互作用，而不是只输出一个配比建议，这让方法从纯黑盒调参器变成了可诊断工具。37:T9f8,CausalMix formulates each proxy training run as a triplet (X, T, Y), where X is the pre-training data state, T is the domain mixture, and Y is the downstream performance after training. A key modeling choice is that X contains only pre-training statistics of the data pool, such as quality, difficulty, complexity, entropy, or style, and explicitly excludes any post-training model signal or evaluation outcome.

The treatment is not modeled directly on the simplex. Instead, the paper uses a log-mixture representation z = log(t + epsilon). This choice is motivated by two considerations: empirical diminishing returns are often closer to linear in log space, and compositional data are better handled with geometry-aware transforms than with raw simplex coordinates. Rather than fitting the full response surface mu(x, z), the paper adopts a partially linear local approximation, Y ≈ g(X) + theta(X)^T z + noise. Here g(X) captures the baseline performance implied by the data state, while theta(X) is the state-conditioned marginal return vector. Positive theta_k(X) means increasing domain k is locally beneficial under state X; negative values indicate local negative transfer or domain conflict.

To identify theta(X) from observational proxy runs, the paper uses Double Machine Learning and causal forests. The idea is to first model the predictable parts of both outcome and treatment from X, then residualize them and estimate the local linear effect in the orthogonalized space. This is the crucial step: it tries to disentangle “this pool performs better because the pool itself is better” from “this pool performs better because the mixture changed.” Once the conditional effect is estimated, the method performs a conservative trust-region update rather than jumping directly to an unconstrained optimum. That design is sensible because historical proxy runs only cover a limited region of the mixture space, and aggressive extrapolation would be unreliable.

Compared with methods such as RegMix, the main difference is not just a stronger regressor. The target itself changes. RegMix-style methods learn a static global surrogate from mixture to performance. CausalMix instead estimates a local, state-conditioned causal direction for how to move the mixture under the current pool. That makes it more suitable for distribution shift, transfer across model scales, and interpretation. The paper also uses the estimated CATEs to analyze domain interactions, which is more informative than returning a single recommended mixture.38:T5de,The core experimental setup uses 512 proxy runs of Qwen2.5-0.5B to fit the causal model, then tests whether the learned update rule transfers to unseen data pools and larger model architectures. From the provided text, these are the only hard numbers that can be confirmed directly: 512 runs and a 0.5B proxy model. The central empirical claim is that, unlike static-distribution mixture optimizers, CausalMix does not require retraining the proxy search from scratch when the data pool changes.

The reported findings, as described in the paper text, fall into three buckets. First, transfer: the learned causal update generalizes to unseen pools and larger models. Second, interpretability: the estimated conditional treatment effects reveal a conflict between factual-knowledge-heavy data and complex logical reasoning, and show that math and coding data become beneficial only above certain quality thresholds. Third, optimization behavior: trust-region updates appear more stable than aggressive reweighting, which is consistent with the local nature of the estimator.

What still needs to be checked in the full results section are the decisive quantitative details: which baselines were compared, the absolute and relative gains, how large the transfer models are, which data-state features matter most, and how much each component contributes in ablations.
