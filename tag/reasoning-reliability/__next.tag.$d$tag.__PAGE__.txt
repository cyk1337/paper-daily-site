a:T867,方法由三部分组成。第一部分是 token-wise potential 的定义与估计。给定题目、当前推理前缀和标准答案，在每个 token 位置 t，从该前缀继续 rollout N 次，统计最终命中正确答案的比例，得到 pot_t。文中用 N=64，在整条推理链的每个 token 上都估计，而不是像 Bachmann 等工作那样只抽稀若干点。这样做的代价高，但换来了定位精度。

第二部分是 cliff token 的统计判定。作者不是简单要求 pot_{t-1}-pot_t 超过固定阈值，而是要求它至少超过 0.1，并且通过一侧 two-proportion z-test 的 95% 置信检验。等价地，阈值写成 0.1 + 1.645 * SE_t，其中 SE_t 由相邻两个位置的 rollout 成功率估计方差决定。这样在 pot 接近 0.5、方差较大的区域，判定门槛会更高；在 pot 接近 0 或 1 的区域，门槛较低。作者明确想避免把 rollout 噪声误判成 cliff，这比固定 0.2 或 30% drop 的规则更稳。

第三部分是 cliff taxonomy。作者根据该 token 是否是 greedy choice，以及该位置分布熵的高低，把 cliff 分成 deterministic、uncertain、sampled-off 三类。可以把它理解为三种不同失败机制：deterministic cliff 表示模型高置信地走错；uncertain cliff 表示模型自己也不确定，错误 token 出现在高熵竞争位置；sampled-off cliff 则更像采样偏离，模型的 greedy 也许不会错，但采样选到了坏分支。这个分类不是装饰性的，因为后面的干预和训练结果表明三类 cliff 的可修复性不同。

First, it defines token-wise potential. For a prompt, a partial reasoning prefix, and a ground-truth answer, the model rolls out N continuations from every token position and measures the fraction that end with the correct answer. This gives pot_t at each token t. The paper uses N=64 and computes this densely over the full trace, not just at a sparse subset of positions. The cost is high, but the localization is precise.

Second, it introduces a statistical criterion for cliff detection. A token is not labeled a cliff simply because pot_{t-1} - pot_t exceeds a fixed threshold. Instead, the drop must be at least 0.1 and pass a one-sided two-proportion z-test at 95% confidence. This yields an adaptive threshold of the form 0.1 + 1.645 * SE_t, where SE_t depends on the estimated variance of the rollout success rates at adjacent positions. The point is to avoid false positives in high-variance regions, especially around intermediate potential values.

Third, the paper proposes a taxonomy of cliff tokens: deterministic, uncertain, and sampled-off. The categorization uses whether the token is the greedy choice and the entropy of the local token distribution. Intuitively, deterministic cliffs correspond to confident but wrong decisions; uncertain cliffs arise at ambiguous, high-entropy positions; sampled-off cliffs reflect failures introduced by sampling away from a better-ranked continuation. This taxonomy is not cosmetic. It becomes central in the intervention and training results.

The causal validation is well designed. The authors delete the first cliff token and resample from that point, then compare this with keeping the cliff token fixed and only resampling the suffix. If recovery happens only when the cliff token is removed, that supports the claim that the token is a trigger rather than a post hoc marker. They then build Cliff-DPO by constructing preference pairs around cliff positions and training on different cliff subsets separately. The motivation is that raw token probabilities mostly reflect fluency and frequency, not deductive validity. To fix this, the method constructs step-wise preference pairs that contrast logically correct but under-confident steps against confidently wrong steps. These pairs are optimized with iterative DPO, pushing probability mass away from invalid but high-confidence continuations and toward valid reasoning steps. The intended outcome is not only better step selection, but better calibration: correct steps should correspond to lower-entropy, more concentrated predictive distributions.

The inference component, Confidence-aware Thought (CaT), uses this calibrated confidence to guide reasoning-tree exploration. High-confidence branches are expanded, while uncertain branches are pruned, with claimed overhead on the order of O(V). The key point is that this is not just beam search over raw token probabilities. CaT depends on CASPO having made confidence more semantically meaningful; otherwise token probabilities would still favor fluent but logically weak steps.

Relative to prior step-wise preference or process-reward methods, CASPO avoids training a separate reward model and instead performs iterative calibration directly through DPO-style optimization.
