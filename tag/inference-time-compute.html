Adaptive Latent Agentic Reasoning

这篇论文解决的是多轮 LLM Agent 中逐步生成显式 CoT 的效率问题。单轮推理模型可以在回答前花较多 token 做推理，但 Agent 每一轮都要观察、调用工具、更新上下文、再决策。如果每个决策点都生成长 CoT，推理 token 会随轨迹长度累积，既增加延迟和成本，也挤占上下文。论文的核心问题不是简单压缩 CoT，而是让 Agent 在多数普通决策步使用隐式的 latent reasoning，只在确实需要深思的步骤切换到显式 CoT。

评读方法和预算对照即可；若 latent 推理不省 token 或不提稳健性，就只是换皮 CoT。
Dongwon Jung,Peng Shi,Yi Zhang,Junshan Zhang,Muhao Chen
