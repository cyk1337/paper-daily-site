Human-Anchored Factuality Evaluation with Strategic Annotation

这篇工作处理的是一个很实际、也很容易被低估的问题：在有限人工标注预算下，怎样得到“以人为准”的 factuality 指标，而不是被 LLM judge 的系统性偏差带偏。全文的关键点不只是“用少量人工校正自动评测”，而是把 reference-based factuality evaluation 明确写成一个带抽样设计的统计推断问题。作者指出，judge-human gap 在 factuality 上往往不是随机噪声，而是结构化残差：证据不完整、证据过时、证据只提供间接支持、claim 需要释义或常识推断、judge 的核验 rubric 比人工更僵硬。这意味着如果还按均匀抽样，或者只看 judge confidence 去分配人工预算，都会浪费标注，因为真正高残差的样本并不总是低置信度样本。论文要解决的核心，就是如何设计一个面向 factuality failure mode 的 annotation policy，让少量人工标签最大程度修正 judge 偏差，同时保留统计上的无偏性和置信区间有效性。

评只看 failure-space analysis 和采样策略；它比低置信度抽样更贴近 factuality judge 的真实偏差。
Yu Wang,Craig Erickson,Kevin Small
