a:T46f,LightningLM 0.1V is a recurrence-backbone language-model family grown in four stages: a 1.78B dense seed, then 5B and 9B MoE stages, and finally a 118.67B sparse MoE. The largest model uses 460 routed experts with top-12 routing, and activates 5.93B parameters per token path, roughly five percent of the stored parameters. Each stage is initialized from the previous trained model. The paper emphasizes preserving the learned interfaces during growth, rather than treating expansion as a mostly random reinitialization. Two supporting design choices matter for the memory budget. The model uses BrahmicTokenizer-131K, a 131,072-token byte-level BPE tokenizer, and replaces a conventional learned embedding table with a Kronecker input embedding. A standard lookup table at this vocabulary and width would require about 537M trainable parameters. The Kronecker projection uses about 33.55M trainable parameters and constructs embeddings from frozen byte and position bases through a trained projection.
