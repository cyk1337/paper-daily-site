On Subquadratic Architectures: From Applications to Principles

这篇论文要解决的是一个已经变得很实际的问题：当大模型开始系统性采用 hybrid backbone，用大量次二次复杂度算子替换标准 attention 层时，xLSTM、Mamba-2、Gated DeltaNet 这些候选序列算子到底该怎么选。过去这类架构常在通用语言建模或常识 benchmark 上比较，差距不大，也很难看出真正的归纳偏置差异。作者认为，问题不在于这些任务太简单，而在于它们没有充分暴露“长程、结构化依赖”对架构的要求。因此论文的核心问题有两层：第一，三类主流次二次 backbone 在代码和时间序列这类复杂依赖数据上谁更合适；第二，如果 xLSTM 确实更强，优势来自哪些底层状态更新机制，而不是来自训练 recipe 或偶然实现细节。

评值得看，但要带着怀疑读：作者有明显 xLSTM 立场；重点读统一 formulation 和 synthetic 任务，判断其“memory correction”解释是否真站得住。

OSDN: Improving Delta Rule with Provable Online Preconditioning in Linear Attention

论文要解决的问题是：DeltaNet 类线性注意力用单个标量 gate 写入记忆，无法按 key 维度适配曲率和频率差异，导致关联召回能力受限。

MDN: Parallelizing Stepwise Momentum for Delta Linear Attention

这篇论文解决的是 Delta Linear Attention 中“逐步动量更新难以并行化”的问题。线性注意力把序列建模写成递归状态更新，训练时需要 chunkwise 并行，推理时需要严格因果递推。已有 Delta Rule / GDN / KDA 类方法可以解释为对隐式目标做在线 SGD，但 SGD 只用当前梯度，历史信息衰减快，长上下文检索容易掉细节。动量可以缓解这个问题，但标准 stepwise momentum 是强序列依赖，直接使用会破坏大规模预训练的吞吐。

评这篇会直接影响你怎么看“线性递推=在线优化器”这条线；先读动力系统分析和稳定门控设计，若实验扎实，值得在内部长序列 pretrain 上复现。
Yulong Huang,Xiang Liu,Hongxiang Huang,Xiaopeng Lin,Zunchang Liu,Xiaowen Chu,Zeke Xie,Bojun Cheng
