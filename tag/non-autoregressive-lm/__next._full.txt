18:T446,The method introduces per-position latent auxiliary variables. At inference time, auxiliaries are sampled from a prior and a parallel decoder maps them to a block of tokens in one model call. The dependencies among predicted tokens are routed through the auxiliary variables rather than through left-to-right token generation. Direct likelihood training is intractable because it requires marginalizing over auxiliaries; random auxiliary samples would almost never decode to a given training sequence. The paper therefore trains an autoregressive encoder q_theta(u_i | x_<=i) that proposes auxiliaries for observed sequences and optimizes an ELBO. Operationally, this gives a self-distillation-style objective with an autoregressive language modeling component and a parallel decoding component. The distinction from PTP is important: PLMs are trained from raw sequence data, not distilled from an existing AR model. The distinction from discrete diffusion is also clear: consistency is handled through latent variables in a single or few decoding calls rather than through iterative denoising.19:T434,The method augments a Transformer denoiser with a tractable probabilistic inference layer. From the same backbone states, it produces token potentials for per-position predictions and compact context gates that reweight shared coupling parameters. The important design choice is that the coupling is context-dependent: the model can prefer different joint token combinations under different prompts, instead of using one fixed dependency layer. Unlike approaches that attach a separately trained joint head to a frozen denoiser, Codpula trains through the joint distribution, so the backbone learns both token preferences and coupling signals. The training procedure includes a dual-flow update to handle signed learning statistics introduced by conditional normalization while keeping valid probability parameters. At decoding time, the same potentials and gates support conditional dependence queries. A proposal can be deferred if its probability changes sharply after conditioning on other proposed tokens, and this does not require an extra backbone pass within the step.1a:T9a3,方法的出发点来自 Anari et al. (2026) 的精确 rejection correction。设 proposal 是把一个 block 内多个 token 按各自条件边缘独立采样得到的分布，target 是该 block 的真实联合条件分布。两者的 likelihood ratio 的对数，可以沿 block 内某个顺序分解成若干 token-level increment 之和；每个 increment 都能通过额外查询 score function 得到。问题在于完整求和要对 block 中每个 token 都查询一次。

SIRS 的关键改动，是不再显式求完整 log acceptance ratio，而是随机抽取一个 increment 来构造其无偏估计。单次估计只需一次查询，因此单个增量的获取成本与 block 大小脱钩。难点在于 rejection sampling 需要的是 acceptance probability，也就是 exp(log-ratio)；对 log-ratio 的无偏估计直接指数化后并不是 acceptance probability 的无偏估计。为此，论文引入 Poissonized Bernoulli factory：先采样一个 Poisson 个数的 clipped increments，再通过 Chen et al. (2026) 的 Bernoulli factory 机制，把这些随机增量组合成一个 [0,1] 内的随机接受概率，其期望恰好等于目标接受率。这样 rejection sampler 的边际输出仍可对准目标分布。

为了保证 Bernoulli factory 的输入可控，作者对 increment 做了区间 [-B, B] clipping。clipping 是 score 精确时唯一的近似来源。B 越大，理论误差越小，但期望查询次数会上升，文中给出每个 unmasking step 的期望查询成本上界为 (1+2B)e^{2B}，与 block size 无关。另一个重要技巧是 Rao-Blackwellization：虽然一次 score 查询是为某个随机选中的 increment 服务，但该查询实际上会返回当前剩余所有 masked 位置的条件分布，因此可以对所有可能的 token-level increment 做条件平均，降低方差而不增加查询成本。理论部分也证明了 Rao-Blackwellized increment 对 clipping-induced error 的上界更紧。

误差分析上，论文把输出分布与数据分布之间的 KL 分解为三部分：proposal 误差、acceptance probability 误差、clipping 误差。若 score function 精确，前两项消失，只剩 clipping 误差。并行独立采样对应 B=0，此时误差就是 block joint 与 marginals product 之间的完整相关性误差；SIRS 则只保留超出 clipping 区间的那部分增量贡献，因此当所有 increment 都落在 [-B,B] 内时可以恢复精确修正。1b:T9c6,The starting point is the exact rejection correction of Anari et al. (2026). Let the proposal be the product of token-wise conditional marginals used by parallel sampling, and let the target be the true joint conditional distribution over the block. The log likelihood ratio between target and proposal can be decomposed into a sum of token-level increments along an ordering of the block, and each increment can be obtained from the score function. The problem is that evaluating the full sum requires one score query per token.

SIRS replaces the full evaluation with a single randomly sampled increment, yielding an unbiased estimator of the log acceptance ratio at the cost of one query. The main obstacle is that rejection sampling needs the acceptance probability, namely the exponential of that log ratio, and exponentiating an unbiased estimator does not preserve unbiasedness. To handle this, the paper uses a Poissonized Bernoulli factory following Chen et al. (2026): it samples a Poisson number of clipped increments and combines them into a random acceptance probability in [0,1] whose expectation matches the desired acceptance rate. Since rejection sampling only depends on the expected acceptance probability, the marginal output distribution remains correct under the construction.

To make the Bernoulli factory valid and stable, increments are clipped to [-B, B]. With an exact score model, clipping is the only source of approximation. Larger B reduces approximation error but increases query cost; the paper gives an expected per-step query bound of (1+2B)e^{2B}, independent of block size. A practically important refinement is Rao-Blackwellization. One score query returns conditionals for all remaining masked positions, so the sampled increment can be averaged over all eligible token choices at no extra query cost, reducing variance. The theory also shows a tighter clipping-error bound for the Rao-Blackwellized version.

The analysis decomposes the KL divergence between the sampler output and the data distribution into proposal error, acceptance-probability error, and clipping error. When the score function is exact, the first two vanish. Standard parallel sampling is recovered at B=0, where the method keeps the full correlation error between the block joint and the product of marginals. SIRS removes part of that error, leaving only the contribution from increments that exceed the clipping range; if all increments lie within [-B, B], the correction becomes exact.1c:T4ad,The experimental section is intentionally narrow and theory-driven. The authors evaluate on two discrete systems with exact score functions, an Ising chain and a Pólya urn, where the KL divergence can be computed directly. Three findings matter. First, under the same score-query budget, SIRS with the Rao-Blackwellized increment achieves lower KL divergence than standard parallel sampling when within-block dependence is weak. Second, when dependence is strong, SIRS still corrects part of the bias, but the extra rejection and clipping overhead can make it less attractive than simply using smaller parallel blocks; the paper is explicit that small-block parallel sampling may remain cheaper in that regime. Third, Rao-Blackwellization consistently improves the estimator with essentially no extra query cost.
