NVIDIA-labs OO Agents: Native Python Object-Oriented Agents

这篇工作要解决的是 agent 开发中的接口碎片化问题：同一个 agent 的行为通常被拆散在 prompt 模板、tool schema、回调代码、workflow 图和外部配置里，导致开发者和模型面对的是两套不同抽象。作者提出的核心主张是，把 agent 直接定义成原生 Python 对象，让“类、方法、字段、类型注解、异常、asyncio”这些已有语言结构同时承担开发接口和模型接口，从而减少 DSL 和框架专有抽象。

评做Agent基础设施或合成训练数据管线的人看§2编程模型设计即可，其“方法体=LLM补全”的抽象值得借鉴到数据生成脚手架。
