From Visual Affinity to Learning Credit in Multimodal Reinforcement Learning

这篇工作讨论的是多模态 RLVR 里的 token credit assignment。现有做法常把同一条回答的 response-level advantage 均匀分给所有 token，或者用“这个 token 和图像有多相关”来决定权重。但作者指出，这两种思路都不够稳。第一，视觉相关不等于应该被更强更新，因为一个 token 可能同时依赖图像和文本上下文，单看 image affinity 分不清。第二，在负 advantage 的回答里，即便某个视觉观察本身是对的，若后续推理错了，简单上调视觉 token 权重反而会放大错误的负更新。论文要解决的核心问题因此不是“如何测视觉依赖”，而是“如何在 outcome-only 奖励下，把视觉关联转成合理的学习 credit”。

评如果你关心 VLM 的 RL 或 mid-training，这篇值得看 credit assignment 设计；别太在意 headline，重点看它如何把视觉证据和结果成败解耦。
