b:T409,The paper builds a visual testbed analogous to classic length-generalization tasks in LMs (e.g., parity), but where the model must actively aggregate spatially local evidence to track an underlying state. It varies difficulty along task length (minimum required steps) and image resolution/entity density. The key experimental factorization is a 2×2: recurrent vs non-recurrent computation, and local sequential glimpses vs global full-image input. The main claim is mechanistic: recurrence alone is insufficient—if a recurrent model still receives a global view, it can learn perceptual shortcuts that do not extrapolate. Robust OOD length generalization emerges when recurrence is paired with strictly local perception. The paper also separates state-tracking tasks from recall-style tasks, arguing locality is unnecessary (and not helpful) for the latter. A practical nuance is that glimpse size/resolution acts like an information bottleneck: too large leaks global cues; too small starves the model and destabilizes learning.c:T41c,SaGe builds an automated pipeline that converts image-text examples into hierarchical scene graphs. Nodes represent objects, sub-entities, or parts, enriched with attributes, bounding boxes, and estimated depth ranges. Edges encode spatial, interaction, and semantic relations. A sub-entity mining step increases granularity, so the graph is not limited to coarse object nodes. The training data is then produced by LLM-guided graph sampling and traversal. Node-centric samples ask about attributes such as color, material, state, and location; edge-centric samples ask about relations such as spatial layout, interaction, and ownership. The reasoning traces are node-articulated: entity names, coordinates, and depth cues are explicitly written as evidence. Architecturally, DeepLatent is built on Qwen2.5-VL, but it does not ask the LLM to autoregressively emit a sequence of latent tokens. Instead, when the model produces a <latent> trigger, a separate LatentFormer is invoked. Starting from a set of learnable 2D latent queries, it uses multi-layer cross-attention over the original image features to generate a spatial latent grid. This grid is produced in parallel, not token by token, and is inserted into the reasoning sequence as a block that the LLM consumes in one forward pass.

The design is motivated by two explicit claims. First, parallel generation avoids the structural mismatch of forcing a 2D visual state into a 1D causal order. Second, grounding every latent directly in image features prevents the information flow from drifting from image-to-latent toward latent-to-latent. To make the latent state depend on the current reasoning context, LatentFormer predicts three modulation parameters that control latent scale, latent distribution, and image-feature distribution. So the model does not simply extract a fixed latent from the image; it generates a context-conditioned visual state.

Training has three stages. In SFT stage 1, the model is trained on image-text interleaved reasoning trajectories that include assistant images, and the hidden states at those image positions are cached as teacher visual states. In SFT stage 2, the explicit assistant images are removed, and LatentFormer is trained to reconstruct those teacher states using cosine similarity, next-token prediction, and latent-scale losses. In the final RL stage, the paper extends GRPO into continuous space to sample and optimize the latent modulation parameters, while also refining when latent invocation should happen. The important point is not merely that RL is used, but that the optimized object is a continuous control variable over intermediate states rather than only discrete text actions.f:T682,The paper motivates itself by noting that prior latent reasoning methods can trail tool-based methods by up to about 5 points on difficult visual reasoning benchmarks such as HRBench. DeepLatent is presented as a way to narrow that gap. The main empirical claims fall into three groups. First, on several visual reasoning benchmarks, DeepLatent outperforms prior latent visual reasoning methods and moves closer to tool-based approaches. Second, because the latent grid is generated in parallel and inserted into the LLM in one shot rather than autoregressively expanded token by token, inference is more efficient. Third, representation analyses suggest that the generated latents are more diverse and carry stronger visual information, alleviating the homogeneity issue reported for earlier latent-token methods.

The paper also introduces DeepLatent-180K, a dataset for latent visual reasoning. Its importance is not only scale but supervision format: image-text interleaved trajectories with assistant images make it possible to first learn from explicit intermediate visual evidence and then distill that evidence into implicit latent states.
