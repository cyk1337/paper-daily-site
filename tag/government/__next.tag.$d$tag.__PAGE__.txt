5:T509,The deployment uses parallel coding agents rather than a single sequential assistant. Alberta reportedly ran around 50 Claude Code agents over roughly 3,400 repositories and 466 million lines of code. The scan used a two-stage routine. First, a rules engine flagged known vulnerability patterns, playing the role of a high-recall static analyzer. Second, Claude reviewed the flagged findings in context and cited exact files and lines so engineers could verify the result. For remediation, Claude could generate patches, create missing tests, run builds, and in some cases rewrite old systems into a more maintainable language and structure. The continuous-review layer uses specialized agents built on the Claude Agent SDK: a red-team agent probes applications from an attacker’s viewpoint and maps possible exploit paths; a blue-team agent evaluates defenses against an international security standard and writes a file-level remediation plan; additional agents review code quality and public-facing text. Each pass checks around 95 security controls.
