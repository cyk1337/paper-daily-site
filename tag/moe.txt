18:Tb13,技术核心是一个四运行的因果 apparatus，用来给“路由中介损伤”定价。四个运行分别是：Y_CC，clean compute + free route，作为基线；Y_QP，quantized compute + clean route pinned，用来测纯 compute path；Y_QF，quantized compute + free route，是实际受扰系统；Y_CT，clean compute + quantized route transplanted，用来测 clean-context 下的 route path，并检查 interaction。这里最关键的设计是 pinning 不是简单 ablation，而是把 clean run 中选出的 expert set 和对应权重原样移植到 quantized hidden state 上，且不重新归一化，以匹配特定实现中的 norm_topk_prob=False。作者明确说明这不是 natural indirect effect，而是一个受控中介干预下的 interventional controlled-route contribution，因此 RMF 的解释依赖这个干预语义。

RMF 的定义也比较讲究。作者不用逐样本 ratio 再取中位数，而是用 ratio of sums：先算 excess_total = L(Y_QF)-L(Y_CC)，再算 excess_compute = L(Y_QP)-L(Y_CC)，两者之差是 excess_route，最后 RMF = sum(excess_route)/sum(excess_total)。这样避免了分母接近 0 时的高方差问题。置信区间用 sequence-cluster bootstrap，而不是 token bootstrap，和自回归序列相关性相匹配。

在 token 级别，作者又做了 attribution partition。对每个 decode token，记录所有层 clean/quantized 下的 top-k route set。若当前 scoring layer 的 route set 变了，记为 jump；若当前层没变但任一上游层变了，记为 nonlocal；若都没变但仍有 route-mediated harm，则记为 pure flux。这个划分的价值在于，它把“路由损伤”进一步拆成局部翻转、上游翻转传导、以及权重/概率流动但不改集合的影响。全文一个很有信息量的发现是，净 signed route-mediated contribution 的 99.8% 与 route-set change 相关，而且多数来自 nonlocal，而不是当前层 jump。这说明很多伤害不是在出问题的 token 当层直接发生，而是上游层 route 改写了后续表征。

检测部分，作者系统测试了 inference-time 可见特征族，尤其是 router margin。margin 对“是否发生 flip”有一定判别力，但对“这个 flip 的损伤符号是正还是负、修了是否有益”几乎无力。即便加入跨 16 层 router vector 等更丰富局部特征，benefit prediction 仍接近 rate-matched random selector。这个结果不是理论不可能性证明，而是对这类局部特征协议下 selective repair 的经验上界。

最后，作者还用 clean-route pinning 测了 reference-fidelity ceiling，并通过同 checkpoint 的 flag swap 分析 gate normalization convention 的作用。结论是某些实现差异更像 damage magnitude moderator，而不是决定 route recoverability 的根因。19:T791,实验主体围绕三类结果展开。第一类是 route-mediated fraction 的测量。在 OLMoE-1B-7B、4-bit KV 的 pilot 设置下，作者报告 RMF 约 0.31。更具体地，五个 process 的均值是 0.313 ± 0.020；discovery anchor 给出 0.31，区间约 [0.20, 0.41]；预注册重执行得到 0.231。作者没有把单次数字包装成稳定常数，而是反复强调 RMF 依赖架构、量化剂量和 damage domain。另一个重要点是 compute × route interaction 非零，因此不能把总损伤简单看成两条独立路径线性相加。

第二类是 token-level attribution。作者发现净 signed route-mediated contribution 中 99.8% 与 route-set change 相关，而其中多数是 nonlocal，不是当前 scoring layer 的 jump。这说明如果只盯当前层 flip，会漏掉主要伤害来源。这个观察对做 router stabilization 或 route-aware quantization 很重要，因为优化目标可能需要跨层而不是逐层局部化。

第三类是检测与修复上界。router margin 对 flip occurrence 的 AUC 为 0.772，说明“会不会翻”并非完全不可见；但对 flip harm 的 AUC 只有 0.490，基本等于随机。作者还测试了多种局部特征族，没有任何方法能在损伤符号预测上稳定超过 rate-matched random selector。也就是说，若 selective repair 只能依赖这些推理时可见信号，那么收益判断几乎做不到。与此同时，强行 pin clean route 只能回收 routed ceiling 的一部分，幅度约 +0.23 到 +0.46，且不同架构差异明显。这进一步说明 route repair 即便有 oracle，也只能修复总损伤中的有限切片。

从实验设计看，作者比较重视证据等级控制：三架构预注册 probe、held-out split 只读一次、三个预注册 endpoint 中一个 miss 也如实报告。这些细节让结论的边界更清楚：它是 pilot 规模上的经验事实，不是普适定律。1a:Ta42,The core method is a four-run causal apparatus that prices the route-mediated component of quantization damage. The four runs are: Y_CC, clean compute with free routing; Y_QP, quantized compute with the clean route pinned; Y_QF, quantized compute with free routing; and Y_CT, clean compute with the quantized route transplanted. The key intervention is route pinning: the clean expert set and clean routing weights are imposed verbatim under quantized hidden states, without renormalization, matching the implementation convention with norm_topk_prob=False. The authors are careful about semantics: this is not a natural indirect effect, but an interventional controlled-route contribution under a cross-context mediator intervention.

The route-mediated fraction, RMF, is defined as a ratio of sums rather than an average of per-sequence ratios. Specifically, excess_total = L(Y_QF) - L(Y_CC), excess_compute = L(Y_QP) - L(Y_CC), excess_route = excess_total - excess_compute, and RMF = sum(excess_route) / sum(excess_total). This avoids unstable behavior when per-example denominators are near zero. Confidence intervals are computed with sequence-cluster bootstrap, which is the right unit for autoregressive dependence.

The token-level attribution is also well designed. For each decoded token, the top-k route set is recorded at every layer under clean and quantized compute. If the scoring layer’s route set changes, the token is labeled jump. If the scoring layer is unchanged but some upstream layer changed, it is labeled nonlocal. Otherwise it is pure flux. This partition lets the authors separate direct local route flips from upstream route perturbations that propagate through later representations, and from route-weight changes that do not alter the selected set.

A notable empirical result is that 99.8% of the net signed route-mediated contribution is associated with route-set changes, and most of that is nonlocal rather than local jump. That is an important mechanistic clue: much of the damage is not a same-layer routing event on the harmed token, but a consequence of earlier route changes.

For detectability, the paper evaluates inference-time observable feature families, especially router margin.
