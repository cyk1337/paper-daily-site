The first is Masked Trajectory Prediction. A GUI interaction is represented as a multimodal trajectory consisting of the user instruction plus, at each step, a screenshot m_t, a reasoning trace r_t, and an action a_t. Instead of defining separate input-output mappings for different tasks, the method randomly masks a fixed proportion of components in the full trajectory and trains the model to autoregressively recover the missing parts. This turns step-wise decision, state-action alignment, and long-horizon planning into the same problem: predict missing pieces given a partially observed trajectory. The important point is not masking by itself, but the move from task-specific marginal dependencies to modeling a more unified trajectory structure. The second component is role-aware adapter learning. The authors argue that heterogeneity is not only dataset-level but also token-role-level: instruction tokens, action tokens, reasoning text, and visual-state-related tokens induce different optimization directions. They therefore add token-wise adapters routed by semantic role, so different token types can use specialized representation subspaces while still sharing the backbone.
