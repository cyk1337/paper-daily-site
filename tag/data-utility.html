Not All Synthetic Data Is Yours to Learn From

这篇工作要回答的不是“合成数据能不能用”这个泛问题，而是一个更尖锐的问题：在没有 prompt、没有 teacher、没有 verifier、没有 reward model 的极弱设定下，模型能否仅靠自己从 BOS 无条件采样出来的纯文本继续训练，并得到稳定收益。作者把问题进一步收紧为一个关系性判断：决定收益的关键，不是某份 synthetic corpus 自身“质量高不高”，而是 source model 与 student model 是否兼容。全文围绕一个具体假设展开：预训练已经把一部分能力编码进参数里，但这些能力在 base decoding 行为中没有充分显现；弱自训练只能把这些潜在能力重新表面化，而不能可靠地凭空注入缺失能力。这个问题对预训练研究很关键，因为它直接触到 synthetic data 的边界条件、self-training 的有效机制，以及“模型从自己生成的数据里到底学到了什么”。

评合成数据效用的关系性结论推翻了“源模型越强数据越好”的默认认知，应立刻在内部合成数据实验中加入谱系匹配的消融
Sina Alemohammad,Li Chen,Richard G. Baraniuk,Zhangyang Wang
