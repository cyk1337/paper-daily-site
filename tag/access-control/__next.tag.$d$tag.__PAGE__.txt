For a fixed public task context W=w, the context includes the task, claimed identity, role, and stated use, but these claims are not treated as evidence of actual downstream use. The deployment has a finite release menu A, including refusal. Each release has a utility under a legitimate-use world B and a misuse utility under a malicious-use world M; because the malicious user can choose how to exploit the answer after observing it, the malicious utility takes the most useful allowed misuse. A safeguard is modeled as a Markov kernel over terminal releases conditioned on a pre-release transcript H. The central assumption is that the attacker can reproduce the same observable evidence as a legitimate user. Total variation distance is used to quantify imperfect copying or credential separation. Under a legitimate utility target q, the paper derives a capability floor Γ(q): the unavoidable amount of attacker assistance induced by preserving useful answers. This differs from jailbreak-specific work because it proves a structural lower bound for any safeguard based only on copyable evidence, including randomized decisions and multi-turn verification.a:T469,Gradient-Routed Auxiliary Modules (GRAM) has three core components. (1) Architecture: each MLP layer in a dense Transformer is augmented with several smaller auxiliary MLP modules, each dedicated to one target capability domain, while the main MLP handles general core capabilities. (2) Training routing: forward and backward passes for auxiliary modules are selectively enabled based on the domain of the current batch. Core data updates only the backbone; data from a specific auxiliary domain updates both the backbone and the corresponding auxiliary module; gradients never flow to unrelated auxiliary modules. This design maps data domains to parameter subspaces, physically isolating the learning of different capabilities. (3) Inference control: ablating an auxiliary module at inference time removes its corresponding capability without retraining; enabling arbitrary subsets of modules produces arbitrary capability profiles from a single deployed model.
