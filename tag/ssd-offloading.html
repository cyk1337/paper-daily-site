The Other Half of the Memory Wall: Serving 35B MoEs from SSD with Trained Routing Prediction

这篇工作解决的是一个很具体、也很现实的 MoE 推理部署问题：35B 级别的稀疏模型即便每 token 只激活少量专家，权重总量仍然大到无法在消费级机器上常驻内存。把专家权重直接放到 SSD 并不能自动解决问题，因为第 N+1 层该读哪些专家，要等第 N 层当前 token 的路由结果出来后才知道，磁盘读取无法提前，最终每层每 token 都会被 I/O 延迟卡住。论文的核心问题不是“如何进一步压缩模型”，而是“如何让不驻留内存的 MoE 仍然能流式解码”。

评这篇会改你对‘MoE 稀疏=天然省内存’的直觉；重点看 prerouter 是否把预测路由直接当真路由后仍能稳住质量，若成立，对训练时路由可预测性也有反向启发。
Yu Lin,Yiming Wang,Runyuan Cai,Hanze Liu,Xiaodong Zeng
