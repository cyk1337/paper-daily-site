Rethinking Video Token Compression with a Global Codebook: Learning Once, Compressing Everywhere

这篇论文解决的是 Video-LLM 中视觉 token 过长的问题，但切入点不是再做一个在线剪枝或合并器，而是把“如何分组压缩视觉 token”的知识从单个视频中抽出来，预先学习成一个可复用的全局 codebook。核心问题是：视频中大量局部视觉模式会跨样本重复，是否可以把这种重复性离线建模，并在推理时用很低的额外成本完成压缩。

评值得看 codebook 训练和压缩-精度曲线；离线全局码本若稳，Video-LLM serving 可少一层在线启发式。

Taming the Entropy Cliff: Variable Codebook Size Quantization for Autoregressive Visual Generation

离散视觉 tokenizer 采用“所有位置共享同一 codebook”的默认设计时，训练集的可用信息量会在序列前几个位置被迅速“耗尽”，导致后续大多数位置的条件分布在训练集上接近确定性（conditional entropy 迅速掉到接近 0），AR 视觉生成因此更像在记忆训练集而不是学习可泛化的条件生成；论文要解决的是：如何在不牺牲重建质量的前提下，重新分配序列各位置的离散容量，推迟这种 entropy cliff。

评读 entropy-cliff 推导和消融即可；若结论抗 raster order，视觉 token 接入 LM 的 prior 要改。
Bowen Zheng,Weijian Luo,Guang Yang,Colin Zhang,Tianyang Hu
