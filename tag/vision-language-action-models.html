Just Noticeable Difference Modeling for Token Compression in Vision-Language-Action Models

这篇文章讨论的是 VLA 推理中的 token compression 应该由什么信号来指导。作者认为，现有方法大多依赖冗余度、注意力、显著性这类间接指标，但对机器人闭环控制来说，真正关键的问题不是 token 看起来重不重要，而是它被压缩、替换或复用后，会不会让下游 action 偏离到不可接受的程度。文章试图把传统压缩里的 JND 概念迁移到机器接收端，把“可压缩性”定义成对策略输出动作几乎不可察觉的表示扰动边界。

评将 JND 引入 VLA token 压缩，视角新颖，关注其如何量化 token 变化对 action 的影响即可。
Zhuoyuan Li,Rui Zhao,Jin Wang,Hanwei Zhu,Cong Zhang,Giuseppe Valenzise,Weisi Lin,Kin-Man Lam
