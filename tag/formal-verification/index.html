TreeThink: A Modular Tree Search Library for Mathematical Reasoning with LLMs

评不是新算法，但把“异步搜索+vLLM+REPL验证”做成积木很实用；想做 verifier-in-the-loop 数据闭环的只看接口设计与速度对比即可。

AgentLens: Production-Assessed Trajectory Reviews for Coding Agent Evaluation

这篇工作解决的是编码 Agent 评测对象定义不对的问题。现有 benchmark 往往只看任务最终是否通过测试，但真实产品使用中，用户感受到的是完整轨迹：是否理解需求、是否安全使用工具、是否会验证自己的修改、出错后能否恢复、最终沟通是否诚实清楚。AgentLens 把“完整交互轨迹”而不是“最终 pass/fail”作为主要评测对象，并试图把这种评测做成可复用、可解释、可用于生产回归检测的流程。

评看评测 rubric 和 judge 一致性就够；二值 pass/fail 确实太粗，但 LLM review 若无校准会把噪声包装成诊断。
