9:T404,VoiceTTA uses a pretrained zero-shot TTS model and optimizes learnable prefixes during inference. The discussed backbone is a flow-matching TTS system: a Gaussian latent is transported toward a mel-spectrogram distribution under text and speech-prompt conditioning, then converted to waveform by a vocoder. Candidate utterances are sampled with varying temperatures to create enough diversity for preference optimization.

The reward combines style and intelligibility signals. F0 coefficient-of-variation difference measures whether pitch dynamics match the reference. Energy coefficient-of-variation difference measures whether loudness dynamics and stress patterns are similar. Speaker similarity keeps the generated voice close to the prompt speaker. A Whisper-based WER reward discourages outputs that imitate style at the cost of intelligibility. GRPO is then used over a group of sampled candidates to update only the prefix parameters. This design keeps the adapted state small and avoids modifying the main TTS weights.a:T423,TF-TTCL implements an Explore–Reflect–Steer loop.
- Explore (Semantic Query Augmentation): multi-agent role-playing generates multiple semantic views of the same query. A Teacher produces high-confidence anchor solutions; a Tutor rewrites the query to induce diverse reasoning paths; a Student answers across views to produce a set of trajectories.
- Reflect (Contrastive Experience Distillation): without labels, the method groups outputs by consistency and uncertainty to form relative “better vs worse” pairs. Instead of updating parameters, it distills the contrast into explicit positive/negative textual rules (what to do vs what to avoid) and stores them in an experience rule repository.
- Steer (Contextual Rule Retrieval): for each new test query, relevant rules are retrieved and appended to the prompt/context to steer the frozen LLM.
Key distinction from prior work: no weight updates (vs gradient TTA) and no external guidance (vs RAG or verifier-based feedback); the supervision is self-derived and operationalized as retrievable rules.b:T46e,Shortcut Guardrail is a two-stage framework:

2) Unsupervised LoRA debiasing via Masked Contrastive Learning (MaskCL): train a lightweight LoRA adapter on unlabeled test batches. For each input, create augmented views by masking individual high-attribution tokens; optimize a contrastive/invariance objective that penalizes representation shift between the original and masked views. Intuition: if the model is overly dependent on a shortcut token, masking it causes large representation/prediction changes; enforcing invariance pushes the model to rely more on broader context/semantics.
