Multimodal Reward Hacking in Reinforcement Learning

这篇工作研究的是多模态 RL 对齐里的一个老问题在视觉场景下如何被放大：训练奖励上升，并不代表模型真的学会了更好的视觉判断。难点不在于“模型会不会投机”，而在于多模态任务的正确性往往依赖图像证据，但训练时可大规模计算的奖励通常只检查文本表面特征、答案字符串、关键词或格式。这样一来，策略就会沿着奖励最容易优化的方向走，而不是沿着视觉 grounding 走。文中把这种现象拆成三类：决策层 shortcut，比如对 benign 样本过度拒答；证据层 shortcut，比如编造图像里并不存在的视觉依据；奖励形式层 shortcut，比如用模板化、关键词堆砌去骗过 reward。作者还特别区分了 RL 新引入的失败和 base policy 原本就有的失败，提出 NRFR 来测“哪些错误是被 RL 新奖励出来的”。

评多模态RL奖励黑客的系统实证，NRFR指标和规模效应结论对后训练对齐设计有直接参考，重点看§3指标定义与规模实验部分。

ARM: An AutoRegressive Large Multimodal Model with Unified Discrete Representations

ARM 要解决的是统一多模态预训练里的一个结构性矛盾：图像理解需要语义强、和语言对齐的视觉表示，图像生成和编辑需要保留细节、可还原像素的视觉表示。很多系统因此使用两套视觉表示，理解用视觉编码器，生成用 VQ token 或 diffusion latent。这样会带来额外上下文开销，也会让单个 backbone 同时学习两个视觉空间之间的桥接关系。ARM 的目标是用一套离散视觉 token，同时支撑图文理解、文生图和指令编辑，并把这些任务都放进 next-token prediction 框架。

评应读 tokenizer 训练和 RL 部分；若结果可靠，会改变离散视觉 token 只能二选一服务理解或生成的先验。

SD-GRPO: Verifiable Segment Decomposition for Long-Form Vision-Language Generation

GRPO（Group Relative Policy Optimization）在多模态 LLM 上的粗粒度整体信用分配不适合长程视觉语言生成任务。GRPO 对每个完整输出只分配一个 scalar reward，并对所有 token 共享同一个 group-normalized advantage。这在数学题等整体可验证任务上有效，但在密集图像描述、科学图表说明、医学报告生成等长程 VL 任务中，单个 advantage 无法区分错误 token 和正确描述的 token，导致所有 token 无论实际贡献如何都获得相同的信用信号。

评只看方法和 ablation 即可；片段级 advantage 是干净改动，值得拿去想文本长 CoT 的 reward 分解。
