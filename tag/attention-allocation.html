ConSA: Controllable Sparsity in Hybrid Attention via Learnable Allocation

这篇论文解决的是混合注意力结构中 FA/SWA 如何分配的问题。已有 Mistral、Gemma 2 一类模型多用手工交错规则，LoZA 一类方法用校准分数再排序，但都很难在给定稀疏率下稳定找到合适的层或头分配。ConSA 把问题改写成带约束的离散结构搜索：在指定 SWA 占比时，学习每个层或 KV-head 应该保留 full attention 还是改成 sliding-window attention。

评不是范式突破，但把 hybrid attention 从拍脑袋规则改成可学习约束优化，这点很实用；只看 learned pattern 和 head-wise ablation 就够。
Yao Chen,Yinqi Yang,Junyuan Shang,Xiangzhao Hao,Simeng Zhang,Yilong Chen,Tingwen Liu,Shuohuan Wang,Dianhai Yu

ReasonAlloc: Hierarchical Decoding-Time KV Cache Budget Allocation for Reasoning Models

这篇论文解决的是 reasoning model 在长 CoT 解码时 KV cache 快速增长的问题。已有 decoding-time KV 压缩方法主要决定“删哪些 token”，但通常给所有层和 attention heads 分配近似均匀的预算；作者指出，推理模型不同层、不同 head 对历史 KV 的需求并不均匀，统一预算会让关键路径被过度压缩。

评针对长 CoT 推理的 KV Cache 优化，提出了非均匀的层级/头级动态分配策略，揭示的“Reasoning Wave”现象对理解长推理模型的内部机制有启发。
Wenhao Liu,Hao Shi,Yunhe Li,Weizhi Fei,Xiangyuan Wang,Mengzhe Ruan,Hanxu Hou,Peisong Wang,Linqi Song,Shuang Qiu

MODIX: A Training-Free Multimodal Information-Driven Positional Index Scaling for Vision-Language Models

论文解决的问题是：现有RoPE类位置编码在VLM中对所有token使用统一的pos index/步长（stride），忽略了跨模态与模态内的信息密度差异，导致注意力“把位置分辨率浪费在冗余视觉patch上”，而对信息更密集的文本或关键视觉区域分配不足；作者将“位置粒度”视为一种隐式资源，提出在推理时按信息贡献动态缩放位置索引（positional index scaling）。

评训练 free 改 RoPE 的 pos index 来做“位置分辨率预算”挺巧，但像推理期补丁、泛化边界不明；只扫核心公式与消融表。
Ruoxiang Huang,Zhen Yuan
