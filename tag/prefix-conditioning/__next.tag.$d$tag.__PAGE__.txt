第三段是 step-layer evidence selection。候选证据仍然很多，所以作者训练一个选择器，对每个 step-layer 单元打分，在固定 evidence budget 下保留 top-K。关键点在于选择粒度是“step-layer”，不是简单地对整条轨迹做池化，也不是只选 step 不选 layer。作者的核心假设是：幻觉相关信号既有时间稀疏性，也有层级稀疏性。某些层更像语义定型层，某些步更像错误固化步，混在一起平均会把信号冲淡。

和已有方法相比，区别主要有三点。其一，不再依赖 output-only uncertainty 或 self-consistency，而是显式利用 denoising trajectory。其二，不满足于轨迹级统计量，而是做可选择的 hidden evidence 单元。其三，把检测器设计成 verifier LM，而不是单纯的二分类头，因此可以自然扩展到结构化解释输出。a:T89f,HIVE has four main stages. First, it extracts candidate hidden evidence from the denoising trajectory. The method does not keep all token positions from all steps and layers. Instead, for each retained denoising step, it focuses on the last token position of the current answer and on positions whose decoded token identities changed relative to the previous step. This is a targeted design: in diffusion text generation, token changes often mark where the answer is still being revised or where an error is getting locked in.

Second, it compresses hidden states. Since raw hidden vectors are too large to feed directly into a verifier, the method applies low-dimensional random projections, using an OPORP-style projection, to map each hidden state from dimension d to a much smaller evidence dimension r. This avoids training a heavy evidence encoder while preserving enough geometry for downstream selection.

Third, it performs step-layer evidence selection. Each retained step-layer pair forms a candidate evidence unit. A selector scores these units and keeps only the top-K under a fixed evidence budget. This is the key structural choice. The selection is not only temporal and not only layerwise; it is explicitly step-by-layer. The underlying hypothesis is that hallucination signals are sparse both across denoising time and across network depth. Pooling everything together would wash out the useful signal.

Fourth, the selected evidence is injected into a verifier LM through prefix embeddings. The verifier takes the QA pair together with the evidence prefixes and produces structured verification outputs: hallucination decision, hallucination type, evidence pairs, and short rationales. In parallel, the logits associated with the verifier’s decision tokens are converted into a continuous hallucination score. This gives both a scalar detector and a structured verifier.

Relative to prior work, the differences are clear. It uses denoising trajectories rather than output-only uncertainty, it selects explicit hidden evidence rather than relying on coarse trace summaries, and it uses an LM verifier instead of a simple classification head, which naturally supports structured outputs.b:T5f9,The evaluation covers two diffusion LLMs, three QA benchmarks, and eight baselines. The main empirical result is consistent: HIVE outperforms output-only uncertainty methods, trajectory-summary baselines, and variants without explicit step-layer evidence selection. The paper emphasizes detection metrics such as AUROC and AUPRC, along with the quality of structured verification outputs.

The ablations are more informative than the headline table. First, evidence-source ablations show that using only final-answer hidden states is weaker than using denoising trajectories, which supports the claim that hallucination signals are distributed across the generation process. Second, selector ablations show that removing the step-layer selector, replacing it with averaging, or using random evidence hurts performance. This directly supports the sparse-evidence hypothesis. Third, evidence-injection ablations indicate that prefix conditioning works better than cruder alternatives, suggesting that the verifier benefits from structured access to hidden evidence. Fourth, budget and retained-step studies show that the method remains effective under a limited evidence budget, so the gains are not simply coming from feeding much more information.
