9:T740,The method, ARIA, stands for Autoencoder-gated Inference-time Unlearning. It has three main components. First, the authors pretrain sparse autoencoders on general corpora to decompose hidden activations from the frozen base model into sparse latent features. SAE latents are used instead of raw hidden states because they are more interpretable and sparse, which makes downstream detection easier to audit and less entangled. Second, they train a lightweight sparse linear detector on top of these frozen SAE latents to recognize forget-related generation states. Importantly, the detector operates over generation trajectories rather than only classifying prompts, so it can catch leakage that appears through paraphrases, intermediate reasoning, or indirect continuation patterns. Third, at inference time, the detector gates the next-token policy. If the detector is not triggered, decoding follows the original frozen model exactly. If it is triggered, ARIA applies a suppressive intervention to the token distribution to block exposure of the target knowledge. This is the key difference from weight-editing approaches: the intervention is local, conditional, and state-dependent rather than global and permanent. The theoretical section provides a useful decomposition: forget leakage is bounded by detector false negatives, while retain degradation is bounded by detector false positives. That turns the problem into learning a high-quality state detector rather than searching for a single ideal weight update. The feature-level analysis is also notable: because the detector is sparse and linear over SAE features, individual triggers can be attributed to a small set of layer-specific latents.
