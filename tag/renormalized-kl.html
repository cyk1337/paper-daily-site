UBTree: Parallel Tree Drafting via Unigram and Bigram Models for Speculative Decoding

这篇工作处理的是并行 speculative decoding 的一个老问题：并行 drafter 虽然便宜，但只能给出单一路径，遇到目标模型分布熵较高、后续 token 存在多种合理延展时，接受长度会明显下降。已有方法要么靠轻量 AR 修正头补 token 依赖，要么直接把单路径并行 drafter 拿去做树验证，但前者牺牲并行性，后者存在明显的 train–inference mismatch：训练时优化的是“单条最好路径”，推理时却希望它给出“多条值得分配验证预算的候选路径”。UBTree要解决的就是：在不放弃全并行神经计算的前提下，显式建模局部 token 依赖，并把训练目标改成面向 tree verification 的多路径优化。

评这篇值得看，因为它抓住了 parallel speculative decoding 真瓶颈：不是 draft 长度，而是高熵时 branch coverage 不够；先看训练目标和 acceptance-vs-entropy 曲线，别只看平均加速比。
Chumeng Liang,Linxuan Wang,Xinyu Peng,Huabin Liu,Yuxin Chen,Ge Liu,Guang Lin,Qifan Song,Jianguo Li
