Learning When Not to Act: Mitigating Tool Abuse in Agentic Reinforcement Learning

工具增强型Agent RL训练中的工具滥用（tool abuse）问题：模型在RL训练中逐渐将工具调用当作默认推理策略，即使对内部推理足以解决的简单查询也会调用工具，造成不必要的计算、延迟和部署成本。现有解决方案（统一工具使用惩罚或硬限制）会同时抑制对困难查询有用的工具辅助探索。核心难点在于标准rollout中几乎不包含无工具轨迹，训练过程缺乏'模型能否独立解决该查询'的直接证据，因此难以区分必要工具使用与滥用。

评字节针对 Agent RL 中 tool abuse 问题的解法，difficulty-aware reward shaping 和无工具轨迹注入的思路很实用，做 RL post-training 的必读。
Liuji Chen,Dianxing Tang,Xing Shi,Dingshuo Chen,Qiang Liu,Shu Wu,Liang Wang
