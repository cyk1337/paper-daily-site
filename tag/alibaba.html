PCoMoE: Shifting MoE Inference from Monolithic Expert Selection to Fine-Grained Path Composition

这篇论文关注的是 MoE 推理效率里的一个老问题：理论上的稀疏激活并没有自动变成端到端的高效 serving。作者认为瓶颈不只是 token-to-expert 路由不规则，更在于现有系统把 expert 当成不可再分的原子单元，只能做“选这个 expert / 不选这个 expert”的粗粒度决策。这样会过早固定优化边界，忽略 expert 内部 FFN 结构中的冗余与可重组空间。论文要解决的核心问题是：能否把 MoE 推理从 whole-expert selection 改成更细粒度的 intra-expert path composition，在不明显伤害质量的前提下，把专家内部计算也纳入可裁剪、可共享、可调度的优化空间。

评只看路径分解和剪枝约束即可；若质量损失控制干净，MoE 推理不应再只按 expert 粒度优化。

Learning to Evolve: A Self-Improving Framework for Multi-Agent Systems via Textual Parameter Graph Optimization

多智能体系统（MAS）的性能高度依赖大量“文本参数”（各 agent 的 system prompt、工具描述、通信协议、工作流规则等）。这些参数彼此耦合、交互非确定，导致人工调参成本高且难定位问题；现有自动 prompt 优化多是“扁平文本编辑”，缺乏结构化定位与跨任务积累经验的自我改进能力。

评不是 pretrain 论文，但“textual gradients + 结构化系统搜索”这个接口值得借去做 post-train pipeline 自动调参；先看方法图和 ablation，别先信总分。
