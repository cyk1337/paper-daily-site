One component, Schema-Guided Action Adaptation, addresses heterogeneous control spaces. Instead of feeding raw action vectors directly, each control dimension is converted into a semantic token defined by its schema, while the synchronized numeric value is injected through affine modulation. This decouples semantic meaning from task-specific vector layouts. The design is motivated by the fact that the same tensor dimension can mean entirely different things across environments, so raw vectors are a poor shared interface.

The second component, Agent-Aware Spatial Modulation, addresses stream-to-agent binding. From an agent description, the model derives an agent-specific spatial gate that selectively updates visual tokens associated with the intended entity. Each branch attends only to its corresponding action stream. The point is to prevent action leakage across agents in a shared latent space, especially when entities overlap, look similar, or interact closely.

For efficient rollout, the paper keeps the full HAI while transferring a bidirectional video teacher to a blockwise causal generator. This uses teacher forcing for AR tuning and distribution matching distillation for streaming video. The paper also introduces causal temporal alignment between raw actions and compressed video latents, plus a global latent offset so action windows advance consistently with cached rollout.
