研究 Agent 长期记忆系统中的“记忆投毒”问题，即错误信息被持久化存储并在未来会话中被检索，导致 Agent 效用下降。

评揭示了 Agent 长期记忆系统对简单错误信息注入的脆弱性，以及现有内容过滤方法的失效，对设计鲁棒的 Agent 记忆机制有参考价值，作为 literature 备查即可。
