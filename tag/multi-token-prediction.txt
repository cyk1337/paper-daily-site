18:T815,方法分三层。第一层是训练。作者不用单独的 draft model，而是在同一个模型里联合训练 next-token prediction 和 MTP。这样模型既保留标准 AR path，又学会 mask-conditioned 的 block-causal drafting。这里的关键不是简单多一个 loss，而是让模型在 block 预测时适应“缺少中间真实 token 输入”的条件，从而缓解 naive masked drafting 的质量损失。

第二层是解码。作者给了三种策略：confidence-only、speculative-only、hybrid。confidence-only 依赖模型自身置信度决定接受前缀，不走额外 verifier；speculative-only 用 AR path 做验证；hybrid 在两者之间折中，提供不同 quality-throughput operating point。这里的设计重点是单模型双能力：同一个 backbone 既能并行 draft，又能顺序 verify，避免传统 speculative decoding 需要双模型带来的额外存储和调度复杂度。

第三层是 runtime，也是文章最有信息量的部分。M1 是按 replay width 专门化的低比特执行，并使用 role-dependent output projection，减少不同 block 宽度下的无效计算。M2 是 finite-state CUDA Graph atlas：把 accepted-prefix 变化后可能到达的 pending-prefix 状态离散成可 replay 的固定形状图，并在 shared KV storage 上复用历史，避免每次都做全历史复制。M3 是在 hybrid decoding 中把 verifier 输入准备提前到 host 分支决策之前，减少 CPU-GPU 同步和调度空洞。贯穿三者的是 accepted-prefix alignment：已提交前缀、已 materialize 的 causal KV 边界、以及 CUDA Graph 当前 replay 状态必须保持一致，否则 graph reuse 会失效，甚至产生错误状态。

和已有 MTP 或 speculative decoding 相比，区别主要有三点。第一，它面向 ultra-low-bit backbone，而不是默认 BF16/FP16。第二，它把“动态 accepted prefix”当成一等公民来设计 runtime，而不是只在算法上讨论接受率。第三，它强调单模型 joint NTP+MTP，而不是 draft/verifier 双模型分工。19:T7f9,The method has three layers. First, training: instead of using a separate draft model, the authors jointly train next-token prediction and MTP within a single model. This preserves a standard AR path while teaching the model mask-conditioned block-causal drafting. The key point is not merely adding another loss, but adapting the model to block prediction without intermediate ground-truth token inputs, which is where naive masked drafting loses quality.

Second, decoding: BitMTP supports confidence-only, speculative-only, and hybrid decoding. Confidence-only accepts prefixes based on model confidence and avoids verifier replay. Speculative-only uses the model’s AR path for verification. Hybrid trades off quality and throughput between the two. The notable design choice is single-model dual capability: the same backbone can draft in parallel and verify autoregressively, avoiding the storage and scheduling complexity of separate draft/verifier models.

Third, runtime: this is the most informative part of the paper. M1 specializes low-bit execution by replay width and uses role-dependent output projections to reduce wasted block computation. M2 builds a finite-state CUDA Graph atlas so that reachable pending-prefix states can be replayed with fixed shapes over shared KV storage, avoiding full-history copying. M3 hoists verifier-input preparation ahead of the host branch decision in hybrid decoding, reducing CPU-GPU synchronization gaps. The unifying constraint is accepted-prefix alignment: the committed prefix, the materialized causal-KV boundary, and the CUDA Graph replay state must stay consistent, otherwise graph reuse breaks or becomes incorrect.

Compared with prior MTP or speculative decoding work, the main differences are: it targets ultra-low-bit backbones rather than standard precision; it treats dynamic accepted prefixes as a runtime design problem rather than only an algorithmic acceptance-rate issue; and it emphasizes a joint NTP+MTP single-model setup instead of a two-model draft/verifier split.1a:T501,The experiments cover BitNet b1.58-2B and Bonsai models from 1.7B to 4B, evaluated on H20, RTX 3090, and Jetson Orin. A useful negative result appears early: applying block-parallel prediction directly to BitNet b1.58-2B improves throughput in BF16, but in W2A8 the naive BitNet++MTP setup loses both throughput and quality relative to the SFT AR baseline. This is an important empirical point: in low-bit settings, iteration cost and accepted-prefix-dependent KV work can dominate the benefit of fewer decoding steps.

With the full BitMTP stack, the paper reports mean decoding speedups up to 2.4× on H20 and 2.0× on RTX 3090, and a 3.3× speedup on MBPP+ on Jetson Orin. The results are presented at comparable task quality against the SFT AR baseline, not as raw throughput-only wins.

The first is Progressive Curriculum Loss, designed to stabilize deep look-ahead training. Instead of assigning a constant or hand-decayed weight to every prediction depth k at position t, the model uses an adaptive weight ω_{t,k}. This weight combines two constraints. The Sequential Confidence Constraint uses the softmax confidence of preceding look-ahead predictions to estimate whether the trajectory up to depth k is still trustworthy. If an earlier step is already uncertain or off-track, supervision for deeper predictions is down-weighted. This suppresses the classic failure mode where distal targets keep backpropagating through a path that has already collapsed. The Retrospective Target Constraint adds another filter based on consistency with the target trajectory, further reducing noisy supervision from unreliable deep predictions. Together, these terms create an implicit easy-to-hard curriculum: the model first learns stable short-horizon prediction and only gradually receives stronger supervision on deeper horizons.

The second component is Confidence-Gated Dynamic Drafting for inference. Standard MTP usually fixes the drafting depth K, but fixed K is suboptimal for document parsing because entropy varies sharply across layouts, tables, formulas, and plain text spans. P-MTP instead decides online how far to draft based on cumulative joint confidence. If the predicted path remains reliable, the model keeps extending the draft; if confidence drops below a threshold, it truncates early. This directly optimizes the useful quantity αK, where α is the acceptance rate, rather than maximizing K in isolation. The paper also keeps the MTP branch lightweight, using a shared module that recurrently produces multiple look-ahead predictions, so the extra overhead γ stays small enough for real wall-clock gains.
