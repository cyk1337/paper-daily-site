On-Policy Residual Learning for Diffusion Language Models

这篇论文解决的是 diffusion language model 里 residual context 应该如何训练的问题。已有工作已经发现，把前一步去噪时产生的预测分布作为 residual context 传给下一步，可以明显改善 speed–quality tradeoff；但多数方法把 residual 当成一个架构或 decoding 技巧，而没有把“模型在自己生成的 residual 轨迹上学习”这件事单独建成训练问题。作者的核心判断是：residual learning 天生是 on-policy 的。因为推理时模型看到的是自己前几步生成的 partially denoised block 和 residual 分布，离线构造的 teacher trajectory 与真实 rollout 状态不一致；而且 residual 分支更新速度往往快于 backbone，直接训练会不稳定，模型也未必学会在每一步真正减少不确定性。ORL 要解决的就是：如何在 DLM 中稳定地做 on-policy residual learning，并显式优化每一步的“进展速度”，而不是只优化最终 token 正确率。

评这会改变我对 DLM residual context 的 prior：不是缓存技巧，而是训练分布问题，应优先看算法和系统耦合部分。
