Search-G1: Grounded Search Agents via Representation-Based Intrinsic Rewards

这篇工作处理的是 search agent 训练里一个很具体但长期没有被好好刻画的问题：奖励函数无法区分“检索是必要的”与“检索只是多余动作”，也无法区分“答案真的依赖检索证据”与“模型本来就会，只是检索后顺手答对了”。只用 outcome reward，会把这几类轨迹都压成同一个正确标签；只用熵、置信度、信息增益这类内部信号，又更多是在测模型不确定性，而不是测证据 grounding。论文的目标，是在不依赖昂贵过程标注、也不调用外部 judge 的前提下，给 RL 训练提供一个低成本、细粒度、且随策略变化而更新的 grounded-search 奖励。

评看 readout 校准实验；若干净成立，它比“让 judge 打分”更像可扩展的 agent RL 信号。
