18:Tb12,方法上，作者先定义 observation-driven finite-state controller：模型先读入输入串，随后在生成阶段可以输出 token、发出工具命令、接收工具观测或停止。任何具有 B bit 内部状态的固定有限精度 recurrent model，都可视为至多 2^B 个状态的确定性控制器。

第一部分是有限状态工具的可内化定理。若 oracle 也只是有限内存 M、有限命令字母表和有限观测字母表，那么控制器只需额外增加 log2|M|+O(1) bit，就能把 oracle 的状态并入自身状态，做 product-state simulation。这个结论说明：有限接口、有限记忆的工具不会从根本上突破有限状态机的表达边界。作者还强调有限状态接口假设是必要的；一旦放松，哪怕是 1 bit oracle，也可能因为接口编码方式而变得任意强。

第二部分是最小无界工具的构造。作者定义了一个 tape oracle，只支持局部 read / write / move 三种操作。控制器内部只需 O(log|Q|+log|Γ|) bit，就能模拟任意单带图灵机，其中 Q 是图灵机状态集，Γ 是带符号表。这里的思想很直接：把无界工作记忆完全外包给 tape，控制器只维护当前 TM 状态和少量局部信息。这个构造给出了“工具增强表达力”的最小充分条件：不是复杂计算器，不是强检索器，而是可寻址、可写、可移动的无界外部存储。

第三部分是有限问题上的严格分离。作者用 EQ_n 作为例子，证明没有工具时需要 2^n 个控制器状态；而有 tape access 时，一个固定常数大小的控制器就能对所有 n 求解。这一点很重要，因为它避免了只给出渐近图灵完备而缺少有限规模 separation 的常见问题。

第四部分把上述控制器结果落到 selective affine SSM。作者证明，任意 observation-driven finite-state controller 都可以被一层 finite-precision selective affine SSM 精确实现，隐藏状态采用 one-hot binary 编码，转移矩阵取 {0,1}，bias 为 0。把 tape simulation 套进去，就得到 finite-precision selective SSM controller 在带 tape oracle 时可达图灵完备。正文中的 one-hot 实现需要 O(|Q||Γ|) hidden dimension；补充材料进一步给出对数级改进：在明确不把固定参数表和外部 tape 计入 recurrent-memory 预算的前提下，只需 O(log B) recurrent bits 就能模拟任意 B-state 图灵机。与此同时，作者还给出一个 matching impossibility：若没有外部内存，要在一次 affine recurrent update 中精确实现任意转移映射 f:[B]×{0,1}→[B]，总 recurrent dimension 必须恰好是 B-1，即使允许多层 triangular selective-affine 结构也不行。这个负结果把“为什么对数级结果成立”依赖哪些建模约定讲得很清楚。19:Ta82,The setup is an observation-driven finite-state controller. After reading the input, the controller enters a generation phase where it may emit output tokens, issue tool commands, receive observations, or halt. Any fixed finite-precision recurrent model with B bits of internal state induces such a controller with at most 2^B states.

The first result is a product-state simulation theorem for finite-state tools. If the oracle has finite memory M and finite command/observation alphabets, then the controller can internalize the oracle by augmenting its own state with only log2|M|+O(1) extra bits. So bounded-interface finite-state tools do not fundamentally extend expressivity. The bounded-interface assumption is essential; once it is relaxed, even a one-bit oracle can encode arbitrarily strong behavior.

The second result introduces a minimal unbounded tool: a tape oracle with only local read, write, and move operations. The controller needs only O(log|Q|+log|Γ|) internal bits to simulate any single-tape Turing machine, where Q is the TM state set and Γ is the tape alphabet. The construction isolates the true source of added power: not sophisticated computation inside the tool, but unbounded writable addressable memory.

The third step gives a finite, non-asymptotic separation. For the language EQ_n, a controller without tools needs 2^n states, while a single constant-size controller with tape access solves EQ_n for all n. This is useful because it complements the Turing-completeness statement with a concrete finite-size gap.

The fourth step maps the controller results to selective affine SSMs. The paper proves that every observation-driven finite-state controller can be realized exactly by a one-layer finite-precision selective affine SSM with one-hot binary hidden states, {0,1} transition matrices, and zero biases. Plugging in the tape simulation yields Turing completeness for finite-precision selective SSM controllers with tape access. The main text gives a one-hot realization with hidden dimension O(|Q||Γ|). The supplement then sharpens this to O(log B) recurrent bits for simulating any B-state Turing machine, under an explicit accounting convention where the external tape is free memory and fixed parameters/readout tables are not charged to recurrent memory. The supplement also proves a matching impossibility result: without external memory, exactly realizing an arbitrary transition map f:[B]×{0,1}→[B] in one affine recurrent update requires total recurrent dimension exactly B-1, even with multiple triangular selective-affine layers. That negative result makes the modeling assumptions behind the logarithmic simulation fully explicit.1a:T4e0,There are no training experiments; the evidence is entirely in exact constructions and unconditional lower bounds. The key quantitative results are resource bounds:
1. A finite-state oracle can be internalized with only log2|M|+O(1) extra bits, where M is the oracle memory.
2. With a read/write/move tape oracle, the controller needs only O(log|Q|+log|Γ|) internal bits to simulate any single-tape Turing machine.
3. For EQ_n, a tool-free controller requires 2^n states, while a constant-size controller with tape access handles all n.
4. The direct one-hot selective affine SSM realization uses hidden dimension O(|Q||Γ|), while the supplement reduces recurrent memory to O(log B) bits for simulating any B-state Turing machine.
5. The supplement gives an explicit three-symbol realization with constant C0=9.
6. Without external memory, exactly implementing an arbitrary f:[B]×{0,1}→[B] in one affine recurrent update requires recurrent dimension exactly B-1.

If one wants an “ablation” view, the paper effectively ablates assumptions: finite-state oracle versus unbounded tape, one-hot realization versus logarithmic simulation, and external memory versus no external memory. Each capability jump is tied to a precise resource change.1b:T4dc,For a skim, start with the Introduction and Table 1. They contain the main dichotomy and the intended interpretation. Then read Section 4 for the product-state simulation theorem; this is the cleanest part if you want to understand when tool use is merely composing finite automata. Next read Sections 5 and 6 to see why the tape oracle is already sufficient and what the controller actually has to remember internally. Section 7 is worth reading because the EQ_n separation turns the asymptotic story into a concrete finite example. If your interest is in SSM expressivity, go to Section 8 and focus on the exact realization of finite-state controllers by one-layer selective affine SSMs.

The supplement is where the sharper resource accounting lives.
