RL Post-Training Builds Compositional Reasoning Strategies

核心问题是 RL post-training 到底只是在放大 base model 已有的低概率行为，还是能把预训练中学到的原子能力组合成新的高层推理策略。该工作把这个问题放到一个完全可观测的 rewrite-grammar 环境里，避免真实 LLM 中常见的混淆：不知道行为是否出现在预训练数据里，不知道采样能否早已覆盖，不知道轨迹里的步骤是有效推理还是偶然拼接。

评这篇会改变你对“RL 只是把 base model 里已有能力采样出来”的 prior；先复现它的合成环境，再拿内部 reasoning traces 检查是否也有同样的分阶段组合现象。
Azwar Abdulsalam,Nishil Patel,Andrew Saxe

Reasoning Depth and Environment Complexity: A Controlled Study of RLVR Data Allocation across Logical Reasoning Tasks

在 RLVR（verifiable reward 的强化学习）后训练里，固定预算下训练样本应该如何分配，才能让“推理能力”的提升更稳、更可迁移。论文指出以往把难度几乎等同于“推理深度”（链条更长）过于单薄；真实失败模式还有一类来自“环境复杂度”（干扰结构多、交互结构多，要求做相关结构选择）。同时，RLVR 往往只奖励演绎式前向推理，忽略了溯因、归纳、类比等推理家族。论文用一个可控的合成 KG 世界，把预训练分布和 RLVR 分布都显式化，系统研究：深度×复杂度的配比策略，以及不同推理家族在 RLVR 下的差异响应。

评值得看实验设计，不是看结论数字；RLVR 数据配比别只按链长分桶，这个 setup 可直接改造成 internal ablation。
Yihua Zhu,Qianying Liu,Fei Cheng,Jiaxin Wang,Akiko Aizawa,Sadao Kurohashi,Hidetoshi Shimodaira
