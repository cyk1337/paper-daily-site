It derives seven bottlenecks: Autonomy, Horizon, State, Resilience, Delegation, Correctness, and Cost. The proposed architecture has four abstractions. A level is a time-scale layer that keeps a bounded file summarizing the layer below and sends sparse directives downward. A tick is one autonomous action cycle: read state, reason, act, and write state back. A protocol is a named file or channel with specified writer, reader, cadence, and check. A tier is an intelligence level, including judgment models, labor models, and deterministic processes. Cascaded intelligence routes work upward when the cost of being wrong justifies a stronger model or human attention. Downward channels carry steering, while upward channels carry compressed state, back-pressure, escalation lines, and kill verdicts.
