UniWALM: Unified World Action Language Model for Embodied Robot Control

这篇工作要解决的是：能否把视频、动作、语言放进同一个生成式控制模型里，让三种模态既互相条件化、又互相监督，并且让模型自己生成的语言在跨时间步被重新消费，充当工作记忆，从而提升操作控制和长时依赖任务的表现。它针对的是现有机器人 foundation model 的一个结构性缺口：VLA 往往把语言当静态条件，不生成语言；world-action model 能建模视频与动作，但没有语言；带记忆的系统通常依赖外挂 planner、VLM 或 retrieval buffer，语言推理和动作控制是分阶段的，记忆也不在控制闭环里。UniWALM 试图把这些拆开的部件收回到一个统一主干中。

评值得看方法和 ablation：它把语言当可再消费的状态变量，而不是外挂 planner，这会影响 action-token 预训练设计。
