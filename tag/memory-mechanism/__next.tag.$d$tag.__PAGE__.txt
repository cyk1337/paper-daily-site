9:T4c0,EVAF (Echo-Valence Attractor Field) is framed in the complementary learning systems (CLS) spirit: a fast working-memory state and a slow parametric store with selective consolidation.
- State geometry: the prefix hidden state s(t) is treated as fast working memory constrained to a per-token product manifold (motivated by high-dimensional thin-shell concentration). This is used to make “echo/attractor” effects more measurable.
- Dual-gate selectivity: consolidation is triggered by a combination of surprise (novelty) and valence (value/emotional tag), mirroring the CLS idea that only salient novel events shape the slow store.
- Algorithmic ingredients: the paper positions itself as reusing continual-learning components (e.g., replay, EWC-style anchoring, PEFT updates) but focusing on characterizing the consolidation decision and its signatures.
- Evaluation protocol: a test–retest setup intended to distinguish retrieval/context carryover from true parametric change by repeatedly probing behavior/representations over time.
