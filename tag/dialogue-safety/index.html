SIT-Eval: Situation-Based Interactive Turn-by-Turn Evaluation of Conversational Agents

这篇工作要解决的是对多轮对话 agent 做“情境覆盖充分、规则可解释、逐轮可定位”的评测。现有对话 benchmark 多依赖自然对话分布，稀有但高风险的情境样本太少；同时很多评测只给整段对话一个总分，掩盖了中间回合的具体失误。论文提出的核心问题，是如何在不依赖大规模真实稀有样本的前提下，系统评估 agent 在不同情境下是否遵守预定义行为规则。

评读 framework 定义和 judge 规则即可；它的价值在覆盖稀有情境，LLM judge 偏差要单独打折。
Ravil Mussabayev,Saveliy Zavertyaev,Dmitriy Parpulov,Andrey Savchenko
