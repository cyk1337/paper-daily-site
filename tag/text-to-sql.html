Iteration Without Elaboration: A Simple ReAct Architecture Suffices for Text-to-SQL Generation

这篇工作处理的是 text-to-SQL 里两个经常被混在一起、但机制上不同的问题：一是 composition，即如何稳定地产生可执行、结构正确、长而嵌套的查询；二是 grounding，即自然语言里的概念如何对上真实数据库中的表、列、值和连接键。作者的判断是，很多复杂 pipeline 把这两类问题一起交给自由形式 SQL 生成，再靠 schema linking、retrieval、candidate refinement、verifier 去补救，结果是系统越来越重，延迟和工程复杂度越来越高，但收益并不总是成比例。论文要回答的是：如果把“生成 SQL”改成“在受限 typed DSL 上逐步构造关系代数程序”，再配一个很朴素的 ReAct 式交互循环，是否已经足够接近当前复杂系统的准确率，同时显著降低成本和时延。

评用极简的 ReAct + DSL 替代复杂的 Text-to-SQL pipeline，证明了约束动作空间对 Agent 推理的价值，值得关注其 action space 设计。

From Test-Time Scaling to Reusable Memory: Measuring Crystallization in Text-to-SQL

这篇工作讨论的不是如何把 text-to-SQL 做得更高，而是如何衡量 test-time scaling 产生的“后续价值”。很多系统会用执行反馈、自修复、多轮采样等额外推理计算把一次失败的 SQL 修好，然后把修复轨迹存成 memory，供后续问题复用。现有评测通常只给一个端到端分数，无法区分收益到底来自重复问题的直接回放，还是来自对新问题的迁移帮助，也无法判断究竟是收集、验证、存储格式还是检索策略在起作用。作者把这个测量问题定义为 crystallization：一次性 test-time 计算，究竟有多少被“结晶”为可复用记忆，并在未来问题上兑现价值。

评读实验拆分就够了；4.34pp/44.4% 这个 amortization 数字，比又报一个 Text-to-SQL 分数更有用。
Jiaqian Wang,Yutao Qi,Wenjin Hou,Yuanxi Che,Muning Wen
