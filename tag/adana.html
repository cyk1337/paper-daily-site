Optimizer Memory Schedules for Outscaling the Overtraining Axis

这篇工作研究的是：当语言模型沿着 overtraining 轴继续训练，也就是固定模型规模、把训练 token 从 Chinchilla 附近一路拉到 256× OT 时，优化器的相对优劣和最优超参会怎样变化。已有优化器比较大多只看单一训练时长，默认“在 20 token/param 左右调好的 optimizer recipe 可以外推到更长 horizon”。全文给出的结论是否定的。学习率 schedule、weight decay、momentum memory 都会随训练 horizon 改变，甚至最优选择会反转。如果不把这些量随 OT 一起调，优化器排名会被严重误判。论文进一步追问：固定记忆的 AdamW / Muon / SOAP，与记忆随时间增长的 ADANA，谁能在高 OT 区间真正 outscale。

评应立刻复现实验里的 horizon-dependent WD 和 memory sweep；它会改变小模型长训时默认套 AdamW recipe 的 prior。
Katie Everett,Shikai Qiu
