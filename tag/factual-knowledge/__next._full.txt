18:T752,The core contribution is a double-gate evaluation protocol. For each compositional instance of depth k, the authors define the required atomic facts, multiple paraphrased probes for each atom, and aligned sub-questions that match how each atom appears inside the chain. An example passes the atomic gate only if every atomic fact is answered correctly and consistently across paraphrases. It then passes the sub-question gate only if every aligned sub-question is answered correctly in isolation. Residual composition failure is measured only on examples that pass both gates but still fail on the main compositional question.

This changes the estimand. Instead of attributing the entire single-hop to multi-hop drop to composition, the protocol conditions on stable atomic access and explicit local verbalization. The paper then decomposes post-training gains into three channels: Δatom for atomic stability, Δcomp for residual composition at matched atoms, and Δdepth for the depth at which residual failure first exceeds 50%. This decomposition is the main conceptual tool of the paper.

The benchmark is D4v2, a temporal compositional dataset with 390 main questions and 2,490 atomic sub-questions spanning four task families and depths 2 through 11. The evaluation covers six open-weight models in the 7B–13B range across several post-training recipes: base, RLHF, SFT reasoning-trace distillation, and native outcome-verified RL. A particularly strong part of the design is the controlled same-base LoRA study comparing SFT-answer, SFT-trace, and GRPO-style training, which helps isolate objective-level effects from base-model confounds. The authors also note an important caveat: residual composition failure is still an upper bound on pure composition failure, because formatting issues, distractor attention, and decoding-path degeneracy can also contribute.19:T636,There are four results worth retaining. First, base models are mostly filtered out by the atomic gate rather than by composition. The paper reports that base models admit fewer than five cases at any depth, which means many apparent multi-hop failures are really failures of stable atomic access.

Second, once atomic stability is matched within 2 percentage points, residual composition failure can still vary from 0% to 47% at depth 2 depending on the post-training recipe. This is the empirical signature of composition collapse: nearly identical atomic knowledge, sharply different composition behavior. Under matched data and compute, outcome-verified RL substantially outperforms SFT trace distillation on this metric.

Third, training on a specific composition depth closes much of the residual failure at that depth but transfers only weakly to nearby held-out depths. That suggests the learned behavior is not a broadly extrapolating compositional procedure.

Fourth, enabling chain-of-thought reduces residual failure by roughly 3–5×. This is an important clue about mechanism: a large part of the bottleneck lies in generation-time computation, not only in static knowledge representation. The model may already possess the required facts, yet still fail to assemble them without enough inference-time workspace.

Because the paper combines cross-model comparisons with same-base LoRA interventions, the results support a stronger claim than simple leaderboard differences: training objectives themselves can alter the composition channel after atomic knowledge is controlled.1a:T4d1,This is labeled skim, but it deserves a careful skim if you care about reasoning evaluation or post-training analysis. Start with the introduction and focus on why the usual compositionality gap is an inadequate estimand. Then read the method section and Figure 1 closely; the double-gate protocol, residual composition failure, and the three-channel decomposition are the conceptual core. After that, inspect the main result tables with attention to comparisons made under matched atomic stability rather than raw overall accuracy. The same-base LoRA intervention is the next priority, because it most directly isolates the effect of the training objective. Finally, read the sections on CoT-enabled evaluation and depth transfer, which speak to two important questions: whether generation-time computation matters, and whether compositional improvements generalize across chain depth.

A focused 45-minute read should be enough for the main ideas. A useful detail is that redirects are not treated as uniformly valid aliases; the dataset construction includes filtering and category annotations, separating alternative names, abbreviations/initialisms, spelling variants, diacritic changes, punctuation variants, and common erroneous forms. The evaluation protocol holds the relation and gold object fixed and changes only the subject string, which removes confounds from template choice or fact difficulty. If only surface frequency mattered, the phenomenon would look mostly string-local. If entity frequency still explained performance after controlling for surface frequency, that would indicate shared entity-level representations or cross-surface transfer.
