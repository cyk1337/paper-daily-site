a:T442,The method combines bidirectional cross-modal latent prediction with per-modality distributional regularization. Given an image encoder and a text encoder, image embeddings are passed through a modality-specific predictor to predict stop-gradient text embeddings, and text embeddings predict stop-gradient image embeddings in the reverse direction. There are no in-batch negatives, no softmax denominator, no sigmoid pair classification over all image-text pairs, no learned temperature, and no momentum teacher. Collapse is handled by SIGReg applied separately to each modality, encouraging the marginal embedding distribution to be close to an isotropic Gaussian. During training, LeVLJEPA embeddings are not L2-normalized because the regularizer operates in Euclidean space; normalization is used only at evaluation time when cosine similarity is needed. This differs from CLIP, which uses symmetric InfoNCE; from SigLIP, which uses independent pairwise sigmoid losses; and from VL-JEPA, which uses a JEPA-style prediction framing but still relies on InfoNCE negatives to avoid collapse.b:T461,The method is evaluated at two data scales: CC12M with 12 million image-text pairs and Datacomp-L with 92 million pairs. An online encoder processes visible context patches, an EMA target encoder provides target features for masked patches, and a predictor maps context plus mask tokens to predicted target representations.

The key change is in the predictor. Instead of compressing the caption into a single global text embedding, the model introduces a fine-grained text conditioner. At multiple predictor layers, target patch prediction is modulated through sparse cross-attention over text tokens. This lets each predicted patch selectively attend to relevant words and implicitly learn patch-word correspondences.

The paper also adds regularization on patch-word similarities, including sparsity and consistency constraints. The purpose is to prevent diffuse or unstable alignments across layers, so that text genuinely reduces uncertainty rather than becoming an extra noisy channel.

This differs from CLIP-style contrastive learning in a fundamental way. CLIP aligns whole-image and whole-text representations and often sacrifices local detail for semantic invariance. TC-JEPA keeps feature prediction as the training objective, so it has a better chance of preserving dense visual information while still injecting semantics.
