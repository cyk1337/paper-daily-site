9:T45c,The analysis separates two mechanisms. Feedback exposure describes where quantization error is structurally dangerous. In models such as Huginn-3.5B and Recurrent-Llama, recurrence passes through a non-residual loop-entry adapter. Quantizing this adapter perturbs the recurrent state without an identity path, so the error is injected into future steps. Quantizing the residual core is much less harmful because the identity path buffers the perturbation. The paper uses the local spectral radius of the per-step Jacobian as a stability diagnostic for possible amplification directions. Calibration blindness is a different issue. GPTQ builds a Hessian proxy H=X^T X from calibration activations. If X is collected only from the first invocation of a shared layer, it can miss directions that appear in later loop steps. The paper compares this one-step calibration with trajectory calibration, which accumulates activations across all recurrent invocations.
