The basic recipe is to estimate a refusal direction from a few hundred contrastive prompts, then orthogonalize the weights that write to the residual stream against that direction so the model can no longer express refusal along it. The technical difficulty comes from three shifts. First, in an MoE, the residual writers are no longer just attention and dense MLP projections; routed experts and shared projections also matter. The paper shows that if one reuses the old dense-model implementation based on module-name traversal, many fused expert parameters are never touched. The edit appears to run cleanly but changes almost nothing, which creates a silent-failure mode. Second, GLM-5.3-Flash uses a four-wide hyper-connection residual. The authors argue that this topology does not fundamentally block directional ablation because the stream-mixing weights are scalar: if a direction is zeroed in every stream, later mixing keeps it zero. This is why directly editing residual-writing weights is more complete than hooking layer outputs. Third, the paper tests whether the single-direction hypothesis survives at frontier scale. It does not rely only on rank-1 ablation; it also tries higher-rank fitted subspaces and uses random orthogonal directions as controls. The main technical conclusion is twofold: the editable part of refusal is distributed across attention, dense/shared projections, and routed experts, and a nontrivial residue remains even after low-rank subspace removal, concentrated in a few content categories. So refusal is not fully captured by one simple linear direction in this model.19:T684,The target model is GLM-5.3-Flash: 320B parameters, 288 routed experts, a four-stream hyper-connection residual, and block-FP8 weights. The most informative experiment decomposes the edit effect across all subsets of writer groups. The result is strongly non-additive. Editing attention alone, dense/shared projections alone, or routed experts alone removes only 0.039, 0.016, and 0.148 of refusal, respectively. Editing all three together removes 0.776. In other words, roughly three quarters of the removable effect appears only under joint editing, not within any single module family. That directly argues against a simple picture in which refusal is localized to one component type. The paper also quantifies the MoE implementation pitfall: the conventional name-matching recipe reaches only a subset equivalent to 0.066 out of the available 0.776, so on this architecture it mostly misses the target while looking successful. Another comparison shows that directly editing residual-writing weights is more thorough than boundary hooking. To verify specificity, the authors ablate random directions orthogonal to the refusal direction and observe essentially no refusal removal. On seven harmful benchmarks, the method reduces refusal by 41 to 89 percentage points with no detected capability loss. The spread is itself informative: the weaker gains occur on benchmarks enriched with resistant categories.
