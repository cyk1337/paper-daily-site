Attention as Frustrated Synchronization

这篇工作要解决的不是“再做一个注意力变体”，而是更具体的问题：为什么把注意力理解成同步系统之后，Kuramoto-style attention 在重复片段检索很强的场景里仍然落后于标准 Transformer。作者给出的诊断是，普通自注意力沿深度传播时会把 token 表征推向共识，这对“找到相关上下文”是合适的，但对“根据上下文预测下一个符号”并不充分，因为它更像把当前位置拉向被检索片段本身，而不是拉向那个片段之后会发生什么。FSN 试图把 value pathway 从“同步到被关注 token”改成“同步到被关注 token 的后继偏移”，让检索直接服务于续写预测，尤其针对 copy-depth 较深的重复结构。

评从同步动力学重构注意力的概念性工作，重点看§3耦合核设计与标准注意力的等价性推导，小模型结果仅作初步参考
Joshua Nunley
