StepCodeReasoner: Aligning Code Reasoning with Stepwise Execution Traces via Reinforcement Learning

代码推理训练长期只监督最终答案，无法约束中间执行状态。模型可能给出正确输出，但变量更新、分支路径或循环过程是错的。StepCodeReasoner 要解决的是：把代码推理从终点奖励问题改成可验证的逐步执行建模问题。

评把“可验证中间态”做成训练信号这点很实用；但先只读方法与消融，确认提升不是来自更强的执行器/评测泄漏。
