9:T415,Tiered Language Models use a secret key as a permutation specification over selected parameter positions. In the public configuration, the released weights are used normally. In the keyed configuration, the same weights are partially permuted, creating an alternative computation graph. This cannot be retrofitted to an already trained model, because arbitrary parameter permutation destroys learned computation. The training recipe has two stages. First, asymmetric joint pretraining trains both public and keyed configurations on public data, while shaping gradient flow so the public configuration relies less on parameters that will later be rearranged. Second, private fine-tuning updates the rearrangeable parameters through the keyed configuration on private data, with regularization to preserve public behavior. Compared with prompt passwords, authorization is moved out of the input space. Compared with adapters, the key contains no learned weights. Compared with separate deployments, the artifact remains a single open-weight model.a:T434,Skin-Deep compares an aligned model M with its base counterpart M0. For harmful-request prompts and length-matched benign instructions, it extracts final-token residual-stream activations at each layer. It first uses contrastive PCA to find candidate directions that separate harmful requests from benign instructions by comparing activation covariance in the aligned and base models. It then measures separation with Cohen’s d. PERMANOVA and RBF-kernel MMD are used as full-space validation checks, so the signal is not only a one-dimensional projection artifact. Additional controls include PCA on unit-normalized activations to rule out pure norm effects and cosine comparison with the Arditi refusal direction to test whether the recovered directions collapse to a known refusal axis. The causal step is direction ablation during generation: selected peak-layer directions are removed and compared with random-direction controls.
