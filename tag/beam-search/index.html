Value Probes: Learned Value Functions for Beam-Search Red Teaming

这篇工作解决的是自动化 red teaming 的搜索效率问题。现有多轮安全审计通常让一个 auditor LLM 在对话树里边走边试，再用 LLM judge 给当前轨迹打分。问题在于，这个过程本质上是在一个高分支、多步长的树上做搜索，但现有方法没有把它明确当成序贯决策问题来处理，因此分支选择依赖昂贵的语言模型评估，探索深度和覆盖面都受限。论文要解决的是：能否把 red-team auditing 形式化成 MDP，用更便宜的 value heuristic 来引导 beam search，从而更高效地找到会诱发目标危险行为的对话路径。

评值得看 Value Probe 的 setup；若线性激活能预测未来违规，安全 eval 可从采样转向内部状态引导搜索。
