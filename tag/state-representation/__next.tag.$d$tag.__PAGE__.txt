9:T938,The framework has three main components. First, a VLM-based coding agent takes a reference image and natural-language instructions, initializes the world, identifies entities, assigns attributes and states, and writes executable programs that define interactions, triggers, and objectives. Second, a state executor maintains an explicit global world state and updates it according to user actions and programmed rules. This state includes off-screen entities and non-visual fields, so the system does not depend on the renderer to remember the world. Third, a generative renderer produces observations conditioned on compiled controls derived from the current state.

The key design choice is the intermediate representation. The paper compares text descriptions, 2D boxes and masks, detailed 3D scenes, and dense rendering controls such as G-buffers. It then chooses a state-augmented 3D oriented bounding box for each entity. The OBB encodes position, extent, and orientation in a shared world coordinate system, and is augmented with persistent identity, semantic category, dynamic state, and appearance information. This is a deliberate compromise. It is more geometric and view-consistent than text, less camera-tied than 2D controls, and much lighter than full 3D assets that would require explicit pose and geometry synthesis at inference time.

A deterministic state compiler then projects the evolving OBBs along the target camera trajectory and rasterizes them into pixel-aligned spatiotemporal controls. This is important. Instead of asking the video model to infer camera projection and entity-pixel correspondence implicitly, the compiler resolves those constraints explicitly. The renderer is left to synthesize fine geometry, articulation, texture, and secondary dynamics that are not specified by the compact state. In effect, the system splits the problem into explicit state evolution plus conditional generative completion.

The training side includes a data curation pipeline that recovers the spatial and semantic supervision needed for this interface from videos. Even from the available text, it is clear that the authors treat this pipeline as necessary for scaling: without extracting entity-level structure from video data, the proposed interface would remain a hand-built control mechanism rather than a trainable pretraining target.a:T461,The visible experimental emphasis is on state-video consistency rather than generic video quality. The benchmark focuses on combat scenarios and measures whether the number of visible alive characters is correct and whether death states are visually realized. That is a sensible choice because these are exactly the kinds of failures that expose a mismatch between explicit state execution and generative rendering.
