Beyond Accuracy: Auditing Spatial Provenance in Visual Token Pruning for OCR-Critical MLLM Inference

这项工作指出视觉 token pruning 在 OCR-critical MLLM 推理中的一个评测盲点：保留较少视觉 token 后，答案仍可能正确，但被保留 token 中已经没有可追踪到关键文字区域的空间证据。只看 accuracy 和 keep ratio 会掩盖这种 evidence loss。
