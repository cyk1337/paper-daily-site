GRIP: Grounded Reasoning via Information-Restricted Premises

GRIP 处理的是 RAG 中的证据未被有效使用问题。作者把它定义为 query dominance：模型虽然接收了检索文本，但内部证据表示高度可由 query 预测，生成时更接近 P(Y|Q) 而不是 P(Y|Q,E)。这类问题不能只靠更强检索器或更长上下文解决，因为高容量 query 通路会让证据通路退化成 query 的压缩副本。

评结论值得复现：它挑战“证据编码越强越好”的直觉；只看瓶颈设计、MI 诊断和消融即可。
