Memory Reward Inflation in Self-Improving LLM Agents

这篇论文研究的是 memory-based self-improving agent 里的一个失真源：agent 不更新参数，而是把过往 episode 写入外部记忆库，并用一个分数决定哪些记忆会被未来检索和复用。问题在于，部署环境通常没有真实标签，这个分数只能由 LLM 自评或近似 judge 给出。论文指出，这会产生系统性的 reward inflation：错误 episode 可能被高分写入，并在后续被反复检索，形成作者称为 Echo Gap 的正反馈回路。核心问题不是一般性的 judge 噪声，而是“被高估的错误经验会持续进入策略循环并放大”。

评值得看失败案例和 judge 相关性分析；它提醒 memory self-improvement 不是免费 RL，奖励噪声会被检索放大。
Mohammad Asadolahi,Amir Amini,Samira Talebi,Amirfarhad Farhadi,Azadeh Zamanifar

Experience Graphs: The Data Foundation for Self-Improving Agents

长时程 agent 在一次任务里会产生“搜索树/轨迹”的大量中间状态（候选方案、工具输出、reward、失败原因、分支关系、统计量等）。现有框架把这些当作进程内对象或 JSON checkpoint，导致崩溃恢复困难、并行协作脆弱、跨 session 复用差、训练数据回收成本高。论文要解决的问题是：把这种“经验图（experience graph）”提升为一等数据库对象后，系统层面应如何建模、存储、查询与治理，才能支撑可持续的自我改进（RSI）式 agent 工作负载。

评从系统/数据库视角重新审视 Agent 轨迹数据，对构建 RL 训练数据飞轮（如 R1-Zero 范式）的底层基础设施有启发。
