IterSynth: Rethinking Deep Search Agents via Role-Decoupled Iterative Synthesis

这篇工作解决的是 deep search agent 在长时程搜索里两个结构性缺陷：一是 role coupling，单一 policy 既要规划信息需求、发起搜索、筛选证据、更新中间结论、又要写最终答案，能力负担过于混杂；二是 context accumulation，ReAct 式线性轨迹会不断堆积检索结果、思考痕迹和中间结论，导致上下文被噪声淹没，早期错误也会一路传递。作者不是把问题归结为“模型还不够大”，而是认为搜索范式本身把规划、证据整合和状态表示混在了一起，所以即便给到 64K 上下文，BrowseComp 上仍有超过 59% 的 ReAct 轨迹在上下文耗尽前都无法终止。论文要回答的是：能否在不增加参数集数量的前提下，同时获得多角色分工的好处和摘要式状态压缩的好处，并且让这种结构能被端到端训练，而不是靠外接 summarizer 拼出来。

评读方法和 ablation 即可；summary state 替代完整轨迹是干净的 agent memory prior，RDPO 是否稳要看实验细节。

DASC: Decay-Aware State Compression for Hybrid Linear-Attention Serving

混合线性注意力（full-attn + 线性/递归状态）模型在 serving 时做 prefix reuse 需要保存“递归状态 checkpoint”，但全量存储会造成内存压力与 prefill 重算；如何在不明显掉质的前提下压缩这些状态。

评这篇把“状态衰减=可压缩结构”讲得很工程化，适合立刻对自家 hybrid/SSM-like 模型做 retention 分布统计并复现压缩收益；重点看 retention horizon 的推导与 serving 指标。
