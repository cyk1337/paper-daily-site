Sep-Latent: Separator Tokens as Natural Compression Anchors for Implicit Reasoning

这篇工作关注的是隐式推理里一个很实际的难点：如何把显式 CoT 的中间推理压缩进少量 latent states，同时避免固定长度 latent 序列带来的表达僵化和表示坍塌。已有方法如 Coconut、CODI 往往需要预设 latent token 数量，问题简单时浪费，问题复杂时不够，而且 latent token 容易逐渐失去可分辨语义，变成难以解释、难以稳定训练的连续噪声。论文试图用语言模型里天然存在的分隔符 token 作为压缩锚点，让模型把推理信息主动汇聚到这些结构位置上，再把显式路径蒸馏到隐式路径。

评只看方法和 ablation 即可；如果 separator 真能缓解 latent collapse，值得在内部小模型复现。
Yinlong Xu,Jianfeng Huang,Zhengdong Zhou,Mingjie Lin,Fuyu Lv,Dan Ou,Hongxia Xu,Jian Wu

Think Wider: Mitigating Latent Rank Collapse in Implicit Chain-of-Thought Reasoning

评latent reasoning 现在最缺的不是新口号，而是训练失效机理；这篇如果实验做得干净，会直接影响你怎么看 implicit CoT 的可扩展性，先盯 rank 统计和长轨迹消融。
