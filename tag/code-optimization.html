UniCoder: Unified Visual-to-Code Generation via Symbolic Rewards and Reference-Guided Code Optimization

视觉到代码（图表/矢量图/SVG/网页）要求像素级结构对齐与可执行性，SFT 往往停在“语义像、细节不准”。直接上 RL 又会卡在两点：奖励太粗（CLIP 等语义指标纵容细节幻觉；像素 MSE 又对渲染噪声过敏）以及探索停滞（代码空间稀疏且脆，冷启动阶段生成不了可执行轨迹，学习信号塌缩）。论文要解决的是：给视觉到代码的 RL 提供可用的细粒度奖励与可启动的探索机制。

评将 RL 应用于多模态代码生成，通过辅助 LLM 提取符号属性作为细粒度 Reward，对多模态后训练和 Reward 设计有一定启发。

PerfCodeBench: Benchmarking LLMs for System-Level High-Performance Code Optimization

这篇工作要解决的是一个评测空白：现有代码 benchmark 大多考察功能正确性、算法题求解或仓库级修 bug，但很少真正衡量模型能否做系统级性能优化。作者关心的不是“代码能不能跑”，而是“在语义不变前提下，模型能不能把慢实现改成接近专家水平的快实现”，而且这种优化要覆盖真实系统中的 cache locality、SIMD、并行同步、GPU kernel、数据搬运和硬件利用率等问题，而不只是换一个更优时间复杂度的算法。

评仅看§2的基准任务设计，可作为代码预训练的下游评估集补充
