Audio Jailbreaks in Large Audio-Language Models: Taxonomy, Attack-Defense Analysis, and Cost-Aware Evaluation

音频-语言大模型（LALM）的越狱攻击不再只是“把文本 prompt 换成语音”这么简单，而是覆盖从声学感知、ASR/表征到推理与输出的整条链路。现有工作威胁模型、预算、指标各不相同，导致攻击可行性与防御代价无法横向比较。论文要解决的是：给出统一的攻击/防御/评测分类框架，并在同一套模型、数据与指标下做受控对比，回答“哪些攻击在现实成本约束下更可用、哪些防御在不牺牲可用性的前提下有效”。

评音频 jailbreak 的分层 threat model 比单看 ASR 有用；建议看攻击 taxonomy 和误拒/延迟指标。
Bo-Han Feng,Yu-Hsuan Li Liang,Chien-Feng Liu,You-Hsuan Chang,Yun-Nung Chen

Token by Token, Compromised: Backdoor Vulnerabilities in Unified Autoregressive Models

这篇论文研究统一自回归多模态模型的后门风险。问题不只是文本触发恶意文本，或提示词触发恶意图像，而是统一 token 空间和自回归生成会让一个模态的后门输出继续进入上下文，并诱导另一个模态也产生攻击者指定的内容。

评只看攻击设置和 clean degradation；若投毒比例很低仍稳定触发，这会改变统一 token 预训练的数据审计优先级。
