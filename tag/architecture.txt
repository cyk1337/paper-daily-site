1a:T4b6,MDLMPE explicitly conditions positional representations on the denoising state. It starts from a binary availability sequence indicating which positions contain revealed tokens and which positions are masked or attention-invalid. For each target token, a target-centered Gaussian weighting is applied to represent the spatial distribution of visible evidence around that token. For an attention pair, the two centered views are averaged into a joint distribution, so the attention relation can depend on both relative distance and the surrounding availability pattern.

The distribution is then projected through a cosine basis to produce features. The method injects these features through two paths. Token-level features are added to the token representation. Pair-level features are mapped by a lightweight MLP into angular offsets for RoPE. This keeps the relative-position geometry of RoPE, but makes the rotations responsive to the current mask pattern. The method is different from long-context RoPE adaptations such as LongLLaDA and UltraLLaDA, which mainly target extrapolation beyond the pretraining length; MDLMPE targets the changing availability topology within the current denoising sequence.1b:T6bd,1) Definitions:
- Native Memory State: a stateful backbone whose internal dynamic parameters/state persist across multiple inferences; the state’s semantic space is aligned during pretraining or mid-training.
- Native Memory Procedure: memory operations (store/forget/update/use) are executed as part of the model computation, not via external retrieval and prompt concatenation.

2) Architecture (Metis prototype):
- Inspired by Fast Weight Programming: introduce fast-changing weights/states integrated into the backbone.
- A Metis block contains a hyper memory block and a local memory block, and injects memory via a dedicated memory-attention mechanism.
- Intuition: local memory acts like writable short-term state; hyper memory controls/stabilizes how state is written/read (akin to gating or a hypernetwork-style controller).

3) Training objectives (making memory both information-bearing and operational):
- Memory reconstruction objective: enforces that the memory state actually compresses and retains past information (an upper bound on what can be stored/recovered).
- Memory operation objectives: supervise or self-supervise the desired state transitions for write/update/forget/read, so the model learns procedures, not just storage.
- Regularization objective: improves robustness under complex scenarios, mitigating drift, contamination, or uncontrolled accumulation.

4) Data: large-scale synthetic “memory-specific” mid-training data derived from public datasets. The paper frames memory as a prediction problem under streaming constraints: you store without knowing future use, and later you can only act on what was stored, so training should force purposeful lossy compression for future utility.1c:T517,The work first proposes Routing Slot Memories (RSM), a unifying framework that decomposes fixed-size memory updates into two independent dimensions: (1) write routing, which selects a subset of memory slots to write new content to; (2) slot-wise decay, which applies forgetting operators only to slots that receive new writes, leaving unselected slots completely untouched with no overwrites or decay. Under this framework, SSMs correspond to the extreme of dense full-slot writes with global gradual decay, while SWA corresponds to the extreme of deterministic round-robin single-slot writes with hard eviction (unselected slots retain content until overwritten on their rotation). Raven is a concrete RSM instantiation that uses learned, input-dependent sparse routing to select a small subset of slots per step—neither writing to all slots nor rotating deterministically through a single slot. New content is only written to selected slots, and learnable decay is applied exclusively to these updated slots, while unselected slots retain their content indefinitely without any update or decay. The Raven block requires no auxiliary convolution or sliding-window attention layers; a single RSM layer supports both persistent memory and precise recall while maintaining strict linear time complexity.1d:T44b,The architecture repeatedly applies one Transformer block Fθ to a hidden state, h^{t+1}=Fθ(h^t,e), with optional input injection through a learned adapter. The main grid uses NoPE, with positional-encoding controls in the appendix. The key methodological move is to replace tail instruments with a head instrument. Tail instruments such as skipping a late loop or comparing Jacobians across late loops are unreliable because converged trajectories sit near fixed points; near such states, skipping is cheap and local circuits look similar by construction. The proposed diagnostic is convergence-time scaling τ(n,i): the first loop at which the decoded output at position i reaches its final value and stays there. Its scaling class acts as a mechanism signature. Constant τ indicates shortcut or refinement, τ proportional to log n indicates a parallel scan, and τ proportional to n indicates serial step-indexed computation. A streaming positive control validates the instrument: when token i is revealed only at loop i, τ recovers a linear slope of 1.0, while shortcut controls remain flat.1e:T577,The experiments are controlled population studies over many seeds, recipes, and model sizes. The reported scales include a small model with a 2-layer block and d=128, a medium model with a 2-layer block and d=256, and a larger model with a 4-layer block and d=512. Tasks include prefix parity, LSB-first increment-with-carry, and group word problems over Z60, S4, S5, and A5. These tasks have known algorithmic structure: some admit constant-depth shortcuts, while S5 and A5 connect to NC1-complete word problems, and associative scan gives a logarithmic-depth solution in principle. The main empirical result is a linear computation frontier learned by free training. The frontier solves v positions per loop, with v approximately n_tr/T_tr; under T=n training, the speed is about 1 position per loop. Giving more loops at test time rescues late positions at fixed input length. Standard tail diagnostics fail: skip retention is essentially total on sufficiently solved examples, cross-step Jacobian alignment is uniformly high, and these metrics do not predict length generalization. The study also separates optimization walls from circuit complexity: A5 hardness is not the main barrier, while S5 operator scale is; an operator-first curriculum removes that wall. Budget annealing transfers the learned mechanism across loop contracts in 4 out of 4 seeds, avoiding the from-scratch seed lottery.1f:T8d0,实验分成四块，结构比较完整。

第一块是合成任务 S5-Retrieval。这个任务同时要求不可解群状态跟踪和 in-context retrieval，单纯 Transformer 或单纯 recurrent 模型都难以胜任。作者用它证明中层时间递归确实能表达“跨步持续的抽象状态”，不是只在自然语言任务上靠数据偏置取巧。摘要里没有给出具体数值，但正文结论是 shallow T^2MLR 能解这类标准架构失败的组合任务，这对机制层面的说服力很重要。

第二块是自然语言预训练。作者在 data- and parameter-matched 设置下比较 T^2MLR 与标准 Transformer，结果是 perplexity 更低，且下游 NLP benchmark 也更好。一个很关键的消融是：最好的收益出现在只对约 20% 的中间层做 recurrence/looping，而不是全层递归。这说明收益并不来自“多加一条状态通路”本身，而是来自把递归放在合适的层段。论文还把规模扩到 361M 和 1B 参数、50B pretraining tokens，收益仍然存在，说明不是小模型特有现象。

The model caches a representation from a deeper middle layer at token t-1 and injects it into an earlier middle layer at token t through a gated fusion pathway. This creates a continuous latent channel across decoding steps, but places that channel inside the part of the network where abstract computation is believed to happen.

Two design choices matter. First, the recurrent signal does not re-enter through the embedding layer. It is fused directly into the middle of the computation graph, so the previous token’s abstract state can continue evolving in the current token’s middle-layer processing. Second, recurrence is localized to a subset of middle layers rather than applied everywhere. The rationale is functional: early layers are more lexical/syntactic, late layers are closer to vocabulary projection, and middle layers are the best place to preserve reasoning state.

Architecturally, T^2MLR defines a write location and a read location. A hidden state from the write layer is cached, then consumed at the read layer of the next token. A gating module controls how much of the current token’s local representation should be mixed with the carried-over latent state. This is more flexible than a plain residual addition because the model can decide contextually when to rely on persistent latent state and when to ignore it.

The training story is a major part of the contribution. Exact temporal recurrence would introduce token-to-token dependencies under teacher forcing and break standard sequence-parallel training. The paper proposes an approximate temporal-parallel training scheme that preserves scalable parallelism while still training the recurrent pathway. The approximation introduces a train-time compromise between recurrence fidelity and throughput, and that trade-off is central to evaluating the method.

First, retrieval is triggered by a continuous query. Second, the KB is a dense key-value store rather than a relational database. Keys are learned continuous vectors; values are human-readable text spans. This preserves editability and attribution while removing the representational constraints of subject-relation-object schemas.
