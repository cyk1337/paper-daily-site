Scaffolding the Strategist: Architecture-Dependent Reasoning Interventions in Hotelling Spatial Markets

LLM 在策略性经济推理上的能力边界尚不清晰，现有博弈论评测多集中于离散动作空间与同时行动博弈，缺少对连续策略空间、多阶段逆向归纳、反直觉均衡的诊断；同时，内置推理能力的模型（如 reasoning-optimized 架构）与外部推理脚手架（scaffolding）之间的交互机制也未被系统研究。

评验证了推理模型（如 o1）对传统 prompt scaffolding 的负面响应，对理解 RL pretrain 模型的行为特性有一定参考价值。
Pratyush Singh

CogniConsole: Externalizing Inference-Time Control as a Formal Abstraction for Reliable LLM Interactions

把 LLM 系统中的“可靠性问题”（输出方差大、对 prompt/上下文顺序敏感、多步交互易漂移）从“模型能力不足”转向“推理时控制层缺失/不可形式化”的解释框架，并提出一种将控制结构外置、可组合、可调参的抽象与实现（CogniConsole）。

评结论对后训练与prompt设计有弱信号：很多"能力不足"其实是控制层缺失，重点看探针设计与方差分解部分。
Vanessa Figueiredo,Wilter Franceschi
