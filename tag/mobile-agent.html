MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks

这篇工作要解决的不是“手机 GUI 自动化”本身，而是如何评测一类更接近真实移动端助手的 central planner：它需要在有状态的手机环境里，把自然语言请求转成可执行的多步计划，并在结构化工具、记忆检索、复合技能、以及必要时的 GUI 子代理之间做正确编排。现有 benchmark 要么偏静态 function calling，只看 API 匹配，不看运行时反馈和状态变化；要么偏视觉 GUI 操作，把问题压成点击和截图理解，弱化了系统级工具调用、权限约束、异常恢复和长程任务分解。MobilePA-Bench 试图补上这块空白，评测对象是“移动端规划代理”的决策与编排能力，而不是单纯的界面操作能力。

评构建了一个带真实沙盒和状态反馈的移动端 Agent 评测基准，比静态 API 匹配更接近真实场景，关注 Agent 评测的研究员可扫读其沙盒设计。
