18:T504,TIPS formulates finite-step dLLM decoding as a finite-horizon Markov decision process. At each step, the frozen dLLM proposes token distributions for masked positions. A lightweight controller then outputs a binary next-step visibility action for every response position. For a masked position, visibility means committing the current proposal; non-visibility leaves it masked. For an already visible position, visibility keeps the token; non-visibility remasks it so that it can be regenerated later. This single action space covers both unmasking and revision. The controller is a shallow two-layer transformer using visibility-aware confidence features, mask indicators, and normalized decoding time. A key design choice is to decouple ordering from pace. The policy ranks positions by relative preference, while a fixed power-law schedule determines the expected visible fraction. A shared shift on the policy logits matches that target fraction without changing the relative preferences. Training has two stages: supervised warmup from reference-derived visibility decisions, followed by group-relative policy optimization using terminal answer correctness.
