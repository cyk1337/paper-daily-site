DA-DLM: Explicitly Modeling Token Dependencies in Diffusion Language Models

这篇论文解决的是 diffusion language model 里一个结构性短板：在每个去噪步同时预测多个 token 时，现有 DLM 往往按位置独立建模，只学到 token-wise marginal，而没有显式建模这些同时生成 token 之间的依赖关系。结果就是局部 token 可能都“像对的”，但拼起来不协调，尤其在少步去噪、每步要并行决定更多 token 时，连贯性和全局一致性会明显变差。作者把这个问题和非自回归翻译里的 multi-modality problem 对齐，认为 DLM 的并行预测失真与 NAT 的独立位置预测是同一类病灶，只是 DLM 还多了一个迭代去噪、逐步锚定的约束。

评应立刻看方法和 ablation：它把 DLM 的独立预测问题改写成结构化依赖问题，可能改变对少步去噪质量上限的判断。
Pengyu Ji,Zichen Zhang,Xiang Hu,Kewei Tu
