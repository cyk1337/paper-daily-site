9:T4db,RheoSampling introduces a dual-identity probability design. Instead of relying purely on deterministic top-k expansion, it inserts one stochastically sampled token into the candidate pool after the top-m deterministic selections. The key idea is to give this sampled token two probability identities. During dynamic tree construction, it is assigned a proxy probability so it can compete with deterministic candidates for expansion and survival. During verification, it is evaluated with its true sampling probability, which preserves lossless stochastic decoding.

This decoupling resolves the conflict between context-adaptive dynamic trees and proper stochastic sampling. The second major contribution is an equivalence-class analysis. Once randomness is introduced into a dynamic tree, token identities and tree topology become tightly coupled, making direct analysis intractable. The authors compress this large stochastic tree space into equivalence classes and use that framework to prove losslessness. The third component is an Optimal-Transport-based verification algorithm, designed to improve acceptance rate while maintaining correctness. They also add a sparse draft distribution strategy to reduce overhead on large vocabularies.a:T482,The experimental comparison is mainly against top-k dynamic-tree baselines such as EAGLE-3, with acceptance rate and wall-clock speedup as the main metrics under standard stochastic decoding. The paper explicitly points out that EAGLE-style implementations effectively treat draft probabilities as 1.0 during verification, which explains the one-hot collapse and poor tail exploration.

The experiments are designed to show that the theoretical fix matters in practice. 第二部分是 Learnable Parallel Sampling, LPS。现有 confidence-based decoding 的问题在于：只有当 token 置信度超过阈值时才 finalize，而很多 token 在更早步骤就已经预测正确，只是概率还没高到阈值，因此会被继续 remask 和重复预测。LPS 试图学习一个 position-aware 的 finalize policy。它利用每个位置在当前 step 的 entropy、位置编码、step index 等特征，预测该位置是否已经“足够收敛”，从而允许早于传统阈值进行定稿。因为 LBS 已经把难度相近 token 组织成 block，LPS 可以在 variable-length block 上执行并行 finalize，而不是受固定 block 边界限制。

The first is Learnable Block Size (LBS). The authors observe that token entropy across positions often follows a staircase-like pattern, suggesting that some positions—contiguous or even non-contiguous—share similar uncertainty and semantic coherence. Instead of using fixed-size blocks or heuristic boundaries such as delimiters, LBS uses a lightweight network to predict block groupings on the fly from token-level statistics, including entropy, positional information, and semantic cues. The goal is not syntactic chunking. It is difficulty-aware grouping: easy tokens should not be delayed by harder ones simply because they happen to sit in the same fixed block.

The second is Learnable Parallel Sampling (LPS). Standard confidence-based decoding finalizes a token only when its confidence exceeds a threshold. The paper argues that this wastes computation because many tokens become correct well before their confidence reaches that threshold. LPS learns a position-aware finalization policy using per-token features such as entropy, position, and denoising step. It predicts which positions have already converged enough to be finalized early. Because LBS already organizes tokens into variable-length groups, LPS can operate under adaptive blocks rather than fixed boundaries.

A key design choice is that the paper does not modify the diffusion LM backbone or training objective. Instead, it adds lightweight decision modules on top of the decoder loop. This makes the method easier to integrate with existing dLLMs and compatible with KV-cache pipelines. The trade-off is that these auxiliary networks need to be trained, and their robustness may depend on the backbone, task distribution, and sampling setup. Instead of sorting positions independently by that score, ADAS builds the subset greedily. Once some positions have already been selected, each remaining candidate is discounted according to how strongly it attends to those selected positions and how uncertain those selected positions still are. Intuitively, if candidate i depends heavily on an already selected but still fragile position j, then the marginal value of committing i in the same step should be reduced.

The paper frames this as greedy construction under a non-additive subset utility: confidence acts as an individual utility proxy, while attention acts as a pairwise compatibility proxy. This is the key distinction from prior samplers. Top-k, Fast-dLLM, and EB-Sampler differ mostly in their budget constraints: fixed cardinality, confidence threshold, or entropy budget. They do not make the value of adding one position depend on which other positions are already in the subset. ADAS does exactly that, while remaining plug-compatible with all three.

A notable design choice is using attention as the dependency signal instead of explicit search, planning, or a verifier.
