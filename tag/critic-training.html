How to Train a Critic Stably and Efficiently

这篇工作处理的是一个很具体、但在 LLM RL 里长期没有被认真拆开的难点：单 rollout 的 actor-critic 训练为什么总是不稳，以及怎样把 critic 真正做成比 GRPO 更省样本、又不更脆弱的方案。作者指出，现有 critic-based recipe 的问题不是单一组件失效，而是几处设计彼此错配：PPO 的 ratio clipping 对高低概率 token 约束不均；bootstrap value target 会把 critic 自身误差再喂回训练；固定 λ 的 GAE 在不同长度回答上会让终局奖励权重差异很大；线性 value head 可以预测到 reward 支持集之外；batch 内 advantage normalization 会在人为固定尺度的同时抹掉“策略残差信号已经变小”这一事实。论文的核心任务，就是把这些不匹配逐项拆开，给出一套在 outcome-only reward 的 LLM 场景下可稳定工作的 critic 优化配方。

评只看 recipe 消融就够；若结果稳，内部 RLVR 应复现 bounded value 和 rubric-conditioned critic。
Penghui Qi,Xiangxin Zhou,Wee Sun Lee
