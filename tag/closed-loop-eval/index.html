System1-Arena: Which Decisions Can Be Left to System 1?

这篇工作要回答的核心问题是：哪些离散决策任务可以交给单次前向、直接输出选项概率的 System-1 模型，哪些任务仍然需要带显式推理过程的生成式 LLM。这个问题看似偏应用，但它触到一个更基础的建模边界：语言模型到底是在做“生成”，还是在做“条件决策”；如果任务目标是分类、路由、控制、打分、动作选择，那么 next-token 生成是否只是一个间接接口，是否存在更合适的训练目标和模型形态。作者用一个统一 benchmark 去比较专门的 decision model、开闭源 AR LLM，以及可通过 answer-token 概率转成 decision interface 的模型，试图把这个边界测清楚。

评这篇会直接影响你对 test-time compute 分配的 prior：不是所有决策都该上 CoT；先看任务分层和 closed-loop 结果，再决定内部路由策略。
Tianyu Chen,Xinyang Liu,Ruyi An,Zhendong Wang,Mingyuan Zhou
