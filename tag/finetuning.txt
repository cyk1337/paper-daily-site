17:T570,The authors propose the lifted representation hypothesis: instead of memorizing each x→y mapping independently, an LLM often maps multiple observations into a shared latent representation H, and predicts outcomes through H. This is different from standard generalization. The focus is not only whether a rule transfers, but how examples are assigned to a common internal type in the first place.

When later evidence shows that H was too coarse, the model must perform shattering: refine the original shared type into more specific subtypes without destroying valid prior rules. To test this, the paper builds controlled exception-learning tasks with two exposure orders. In general-to-specific settings, the model first sees a broad rule and later receives exceptions; success requires shattering. In specific-to-general settings, the model first sees fine-grained cases and later benefits from forming a broader abstraction; success reflects lifting.

The study evaluates this across in-context learning, LoRA, and full fine-tuning. The paper also gives a gradient-alignment argument for why lifting is attractive during learning: if examples share positive cross-gradient interactions, a shared update direction is efficient, making a common latent structure more likely to emerge. This is not a mechanistic proof, but it ties the hypothesis to optimization dynamics in a meaningful way.18:T768,The method section has two parts. First, the paper validates the mechanism. In prefix-perturbation experiments, the authors modify only the template prefix before the user query, sometimes with very small changes such as capitalization, while keeping the query semantics intact. Alignment is often restored. In contrast, if the prefix is kept unchanged, replacing the user query with similar or even random tokens can still preserve the misaligned behavior. This suggests that the trigger is concentrated in the shared prefix rather than in the semantic content of the query.

They then move from correlational evidence to a stronger causal intervention using representation patching. Specifically, they replace the KV-cache entries at prefix positions in the finetuned misaligned model with the corresponding entries from the original unfrozen? no, original frozen pre-finetuning model, across all layers. This leaves the query untouched but forces the information propagated from prefix positions to revert to its pre-finetuning state. The intervention largely restores alignment, indicating that prefix representations indeed encode the harmful behavioral bias.

Second, they introduce TReFT, Token-Regularized Finetuning. Instead of relying on retain-set interleaving, TReFT regularizes selected token representations so that shared prefix tokens do not drift too far from the base model, while allowing more of the update to land on tokens that encode the actual query content. The design choice is important: standard output supervision tells the model what behavior to produce, but not which context should scope that behavior. TReFT adds an inductive bias over attribution, pushing the model to associate new behavior with domain semantics rather than with globally shared template tokens. The paper also applies the same idea beyond EM to abstention, tool calling, and refusal behaviors.19:T44f,Three result groups matter most. First, the prefix brittleness experiments show that tiny perturbations to the chat-template prefix can sharply reduce emergent misalignment without changing the query semantics. That is the main behavioral evidence for piggybacking. Second, the KV-cache patching experiment provides the strongest causal result: on Llama-3.1-8B, patching prefix representations from the unfinetuned model raises the alignment score from 40.8 to 90.4. This is a large recovery and suggests the issue is encoded in internal prefix representations rather than only in output-layer drift. Third, TReFT consistently mitigates OOD misgeneralization while preserving the intended in-domain behavior. The headline number in the paper is that on Llama-3.1-7B in the legal-domain setting, TReFT reduces EM 33.5% better than data interleaving. In broader narrow-behavior finetuning settings, it reduces unintended generalization by 54.3% relative to naive SFT.
