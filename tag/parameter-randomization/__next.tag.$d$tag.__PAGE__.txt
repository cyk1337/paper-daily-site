b:T5b3,Built on the Qwen3-VL backbone, Qwen-RobotNav unifies all navigation tasks as waypoint trajectory prediction and exposes a two-dimensional parameterized interface. First, task modes (VLN, PointNav, ObjNav, Tracking) allow the upper planner to select appropriate navigation behavior. Second, controllable observation parameters (visual token budget, temporal decay, per-camera importance weights) govern how the visual stream is encoded. All interface parameters are randomized during training to prevent overfitting to fixed configurations, enabling generalization to any inference-time setup without task-specific fine-tuning. Camera identity, temporal order, and embodiment type are passed entirely via natural language tags and prompt preambles, with no modifications to the base backbone architecture. A two-tier hierarchical agent system is also designed: the upper-tier Qwen3.6-Plus planner decomposes complex goals into sub-goals and dispatches configurable navigation calls, while Qwen-RobotNav acts as a reactive executor for high-frequency waypoint prediction. A two-level memory system (compact single-episode rollout summary + persistent cross-episode memory storing searched regions, candidate object locations, etc.) supports long-horizon reasoning.
