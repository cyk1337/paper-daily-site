9:T406,An Agent Behavior Map is built from shared reference trajectories. For each external history in a trajectory, the target agent reconstructs its own input using its harness, including history handling, retrieval, summarization, prompting, and action grammar. The recorded reference action is then teacher-forced, and the model assigns an action log-likelihood. The vector of log-likelihoods over all reference points is centered to produce the agent’s coordinates. A new agent can therefore be placed on the map with forward passes only, without environment interaction. The theory relates squared coordinate distances to trajectory KL under explicit locality and reference-mismatch assumptions. The error decomposition includes local approximation, mismatch between the reference distribution and the policies being compared, centering error, and finite-sample error.
