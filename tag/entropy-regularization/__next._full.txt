19:T8ce,方法分两步。先做结构观察，再据此设计损失。

第一步是熵结构分析。作者对 frozen base model 的 next-token 分布做 top-K 截断并归一化，默认 K=30，然后计算 Shannon entropy 和 Renyi-2 entropy，并用 effective support size 来解释“相当于有多少个均匀候选”。他们发现熵分布不是平滑单峰，而是在接近 ln 1、ln 2、ln 3 … 的位置出现明显峰值。这意味着很多 token 位置可以被看成处在若干离散 uncertainty regime：有些位置几乎确定，有些位置天然有 2 到 5 个左右的合理候选。这个观察直接决定后面 preservation set 的大小不应固定，而应随位置变化。

第二步是 LP-SFT 损失。对每个位置 t，先用 base model 的分布构造一个自适应 preservation set。直观上，集合大小由该位置的熵 regime 决定，目标是覆盖 base model 认为“局部合理”的若干替代 token，而不是机械取固定 top-k。然后把监督标签 token y_t 从这个集合里移除，避免 preservation loss 与 CE 在标签 token 上拉扯。最后只在这个集合内部做 locally normalized KL：先把 student 和 base 在 preservation set 上的概率重新归一化，再最小化 KL。这样保留的是候选替代 token 之间的相对排序和相对比例，而不是要求 student 维持这些 token 的原始总质量。

这个局部归一化是方法的关键。若直接做全分布 KL，student 为了拟合标签 token 需要把概率质量向标签集中，而 KL 会惩罚这种必要迁移；若只做 top-k token matching 但不归一化，又会把“保留结构”和“保留总质量”混在一起。LP-SFT 通过去掉标签 token + 局部归一化，把两件事拆开：CE 负责学目标答案，local KL 负责少破坏非标签候选的局部几何结构。

和已有方法相比，它更接近一种结构保持正则，而不是蒸馏、label smoothing 或 preference optimization。label smoothing 给的是人工平滑先验，不依赖 base 的真实局部结构；full KL distillation 保留过多、冲突也更大；一些 forgetting-aware SFT 方法通常在样本级或任务级做约束，而这里是在 token 级、位置级做自适应控制。1a:T94e,The method has two parts: an empirical analysis of pretrained token distributions, and a fine-tuning loss built around that analysis.

First, the authors study the frozen base model’s next-token distribution using top-K truncation and renormalization, with K=30 by default. They compute Shannon entropy and Renyi-2 entropy, and interpret them through effective support size. The key observation is that the entropy histogram is multimodal, with peaks near ln 1, ln 2, ln 3, and so on. This suggests that many token positions fall into discrete uncertainty regimes: some are nearly deterministic, while others naturally admit a small set of plausible alternatives. That motivates an adaptive preservation mechanism rather than a fixed top-k rule.

Second, they introduce LP-SFT. At each token position, they build an adaptive preservation set from the base model’s next-token distribution. The set size is guided by the local entropy regime, so the method preserves a variable number of plausible alternatives depending on how uncertain the base model is at that position. Crucially, the supervised target token is removed from this set to avoid direct conflict with the cross-entropy objective. The preservation loss is then defined as a locally normalized KL divergence: both the student and base distributions are renormalized only over the preservation set, and KL is computed within that local simplex.

This local normalization is the core design choice. A full-distribution KL would penalize the student for moving probability mass toward the supervised label, even when that movement is exactly what SFT should do. A non-normalized top-k matching loss would still entangle two different goals: preserving relative structure and preserving total mass. LP-SFT separates them. Cross-entropy learns the target token; local KL preserves the geometry among plausible non-label alternatives.

Relative to prior work, this is closer to structure-preserving regularization than to standard distillation, label smoothing, or preference optimization. Label smoothing injects a hand-crafted prior rather than using the base model’s actual local uncertainty. Full KL distillation preserves too much and conflicts more strongly with adaptation. Forgetting-aware SFT methods often operate at the sample or task level, whereas LP-SFT works at token level with position-wise adaptivity.1b:T611,The experimental story is about trade-offs rather than a single headline metric. The paper compares LP-SFT against vanilla SFT and recent SFT-enhancement baselines, reporting both pass@1 and pass@k style metrics. The main claim is that LP-SFT improves or at least preserves pass@1 while retaining better pass@k and higher generation diversity, which is exactly what one would expect if the method preserves alternative valid continuations instead of collapsing them.

The ablations are the most informative part. Removing the step that excludes the label token from the preservation set makes the regularizer conflict more directly with cross-entropy and hurts performance or stability. Replacing locally normalized KL with ordinary KL or other non-local variants tends to over-constrain the student toward the base distribution and weakens target-domain adaptation. Using a fixed-size preservation set is generally worse than the entropy-guided adaptive set, which supports the claim that the multimodal entropy structure is not just an analysis artifact but a design signal.

The abstract does not expose the full numeric table, but the full paper emphasizes improved overall trade-offs across pass@1, pass@k, and diversity-related measures. The evaluation setup appears especially relevant for coding and reasoning tasks where multiple valid solutions exist. When reading results, focus on the Pareto frontier between single-sample accuracy and diversity, forgetting-oriented evaluations, and the ablation tables around preservation-set construction.1c:T44a,For a skim, start with the introduction and the method overview figure. The key question is what exactly is being preserved: not the whole base distribution, but the relative structure among plausible non-label alternatives. Then jump to the entropy analysis figures and check whether the multimodal peaks near ln k are convincing, and how the authors interpret them through effective support size.

After that, read the loss definition carefully. Three details matter most: how the preservation set is chosen adaptively from entropy, why the target token is removed, and how locally normalized KL differs from ordinary KL. If those are clear, the method is mostly understood.

In experiments, prioritize three blocks: main results on pass@1 and pass@k, diversity and forgetting evaluations, and ablations comparing adaptive vs fixed sets, with-vs-without target removal, and local-vs-global KL. A useful skim should take about 25 to 35 minutes. If you are considering adopting the idea in your own recipe, then check appendix material on hyperparameter sensitivity and preservation-set statistics.1d:T7a5,The method, Conditional Entropy Shaping (CES), is built on top of DAPO. The starting observation is that a small number of high-entropy tokens in a reasoning trace often act as forking points, where the trajectory could branch in different directions. Prior work often rewards such tokens uniformly to preserve exploration, but that also encourages already-correct trajectories to remain diffuse and verbose. CES changes this by making the shaping policy both conditional and bidirectional.

During training, the model first receives a response-level correctness signal. Token-level entropy is then used to reshape the advantage:
1. For correct trajectories, high-entropy tokens are penalized. The intuition is that if a path already leads to the right answer, the model should become more confident and direct at those branching points rather than keep exploring unnecessarily.
2. For incorrect trajectories, high-entropy tokens are rewarded. The intuition is that these branching points are exactly where more exploration is useful, since the current path failed.

This differs sharply from a plain length penalty. Length penalties only care about output size and cannot distinguish necessary deliberation from wasteful expansion. CES instead tries to intervene at the uncertain decision points. It also differs from uniform entropy encouragement, which assumes exploration is always beneficial. CES says exploration should depend on whether the current reasoning path is already successful.

Algorithmically, CES does not replace DAPO. It augments DAPO’s token-level advantage shaping with a correctness-by-entropy conditional term.
