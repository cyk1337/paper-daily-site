Optimizing What Policies Learn From: Recoverability-aware Rollout Intervention Learning

这篇工作关注的是 group-based、critic-free RL 里另一个常被忽略的问题：rollout 预算通常被均匀分配，但不同任务、不同轨迹状态的学习价值差异很大。尤其在 agentic 或稀疏奖励场景里，有些状态再多采样也学不到东西，有些状态则值得额外分支探索。已有方法多用 reward variance、entropy、uncertainty 之类静态启发式来决定是否多采样，但这些信号会随着 policy 演化而失真，而且通常只能决定“多采几个”，不能表达“在什么位置、用什么方式介入”。论文要解决的核心问题，是如何在线学习一个结构化的 rollout intervention policy，让训练过程把算力花在更能产生学习信号的地方。

评后训练RL中自适应分配rollout信号的思路可迁移到预训练的数据课程与训练信号筛选，重点看上下文bandit建模部分。

HiFloat4 Format for End-To-End Reinforcement Learning Post-Training of Large Language Models

这篇工作处理的是一个很具体但很硬的工程研究问题：能不能把 LLM 的 RL post-training 真正做到端到端 FP4，也就是 rollout policy 和 training policy 的前向、反向都在 4-bit 下运行，而不是只把一部分路径降精度。难点不在“4-bit 会不会有误差”这种泛泛层面，而在 RL 场景里 rollout 与 training 是耦合的：rollout 生成的轨迹决定训练信号，若 rollout 侧量化失真改变了采样分布，训练侧即便更高精度也未必能补回来。作者的核心发现是，FP4 RL 的主要退化来源不是训练侧量化噪声，而是 rollout activation 的量化下溢和由此带来的 rollout–training mismatch。

评反常识发现价值很高——RL量化退化主因在rollout激活而非训练侧，精度不匹配反而更差，重点看§3的消融分析。

Branching Policy Optimization: Sandbox-Native Language Agent Reinforcement Learning

这篇工作解决的是一个很具体但长期被忽略的问题：现有 LLM agent 的 RL 算法，仍沿用 RLHF 时代“从初始状态独立采样 N 条完整轨迹，再用组内均值做 baseline”的 rollout 结构；但 sandbox agent 的环境是可快照、可恢复、通常近似确定性的，训练却没有利用这一点。结果是长时程任务里，回报方差主要由早期分叉放大，GRPO/RLOO 这类 trajectory-level baseline 只能消掉 prompt 级别的公共方差，无法消掉共享前缀带来的可解释方差。论文要解决的核心，就是如何把 sandbox 的 checkpoint/restore 变成训练原语，在相同 rollout 预算下构造更低方差、仍然无偏的策略梯度估计。

评利用sandbox可快照特性重构RL rollout拓扑的思路很巧妙，对agent RL训练的效率和方差优化有直接参考，重点看rollout结构设计部分。

Information Gain-based Rollout Policy Optimization: An Adaptive Tree-Structured Rollout Approach for Multi-Turn LLM Agents
