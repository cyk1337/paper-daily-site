18:T5de,The method has two main pieces. First is a retrieval-based labeling pipeline. Starting from a corpus of user sessions, the system uses an off-the-shelf memory extractor (mem0 in the paper) to produce atomic candidate facts from each session. Under an infinite-budget construction, all extracted facts are added to a growing candidate memory pool. For each candidate fact, the pipeline scans future user turns. A turn is first judged on whether memory is needed; if memory is queried, retrieval is performed. A fact is labeled useful if it is retrieved in a later interaction and its content is actually incorporated into the model’s answer. An LLM judge is used to verify that the retrieved fact was genuinely used, reducing noise from superficial retrieval hits.

Second is Warm-Start UCB. The offline stage learns a shared utility pattern from historical users, providing a prior or initialization. The online stage adapts to a new user with an upper-confidence-bound algorithm under one-sided delayed feedback. Because feedback is observed only for admitted facts and only after an unknown delay, the problem is cast as an apple-tasting style decision process. UCB handles the exploration–exploitation trade-off by favoring facts with both high predicted value and high uncertainty. Compared with pure offline supervision, this explicitly models partial and delayed feedback.
