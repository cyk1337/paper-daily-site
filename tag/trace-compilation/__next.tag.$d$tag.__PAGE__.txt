Events may include messages, reasoning summaries, tool calls, outputs, exceptions, state updates, and human approvals. Compilation is performed over an unsupervised intent cluster rather than a single trajectory, because a single trajectory mixes reusable procedure with one agent’s search behavior. The key technical rule is argument-level dependency verification: an edge from call a to call b is retained only when an argument of b consumes a value uniquely attributable to a.
