EdgeBench: Unveiling Scaling Laws of Learning from Real-World Environments

这篇工作要回答的问题不是“agent 能不能做长任务”，而是“agent 在真实环境中通过交互学习时，整体性能是否也像预训练 scaling law 那样 obey 某种稳定函数形式”。作者认为，部署后的环境学习能力会越来越重要，因为很多知识不在静态训练语料里，而在工具、私有数据、反馈循环和持续变化的现实环境里。现有 benchmark 大多任务短、反馈弱，测到的是一次性解题能力，不足以测学习动态。

评新交互场景下的scaling测量，注意log-sigmoid形状很大程度来自任务性能天花板，重点看跨代学习速度趋势即可。

HIPIF: Hierarchical Planning and Information Folding for Long-Horizon LLM Agent Learning

核心问题是长程 agent 任务中的上下文干扰。许多 LLM agent 在多轮交互中持续把完整 observation-action 历史塞回上下文，历史越长，冗余信息越多，模型越难判断当前任务阶段，也更容易在后续规划和执行中漂移。HIPIF 关注的不是单纯稀疏奖励或 credit assignment，而是训练模型学会分解子目标，并把已完成子目标的历史压缩成可用进度。

评只看方法图和消融即可；若 folding token 的训练信号干净，它会影响长上下文 agent 训练 recipe。
