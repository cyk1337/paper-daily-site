Language Models Need Sleep

在“有限 KV cache + 固定大小快权重（fast weights）”的混合注意力/SSM 架构里，长上下文问题不只来自存储容量，还来自“被逐出上下文窗口的 token 需要多少计算才能被压缩成可用于后续推理的内部状态”。论文要解决的是：当问题需要更深的推理链路（reasoning depth）时，传统一次前向的快权重写入不足以把已见上下文转化为可用的长期状态，导致即便快权重容量足够，模型在窗口清空后仍无法正确推理。

评只看 fast-weight consolidation 的机制和 N-scaling 曲线；它给长上下文记忆提供了比加 KV 更像训练问题的路径。

RecMem: Recurrence-based Memory Consolidation for Efficient and Effective Long-Running LLM Agents

长时运行的 LLM agent 需要外部记忆来突破上下文窗口，但现有记忆系统普遍对每次交互都做“急切式”LLM 记忆抽取与合并，导致构建阶段 token 成本过高。论文要解决的是：在不显著损失可用性的前提下，如何决定“什么时候值得调用 LLM 做记忆巩固”。

评这不是 pretrain 论文，但它把“记忆提炼触发条件”从每步调用改成 recurrence 触发，系统味道很对；只看方法和成本曲线，别把任务收益当成普适结论。

Useful Memories Become Faulty When Continuously Updated by LLMs

研究“持续记忆巩固（consolidation）”在 LLM agent 中是否可靠：当代理把已解决任务的轨迹反复压缩成文本化抽象记忆，并在后续任务中持续更新这份记忆时，记忆是否会稳定变得更有用，还是会逐步漂移并反噬性能。论文把“输入经验是否有用”这个变量尽量控制住（用已成功轨迹或直接用 ground-truth 解），从而把问题聚焦到“巩固/改写这一步本身是否会引入系统性错误”。
