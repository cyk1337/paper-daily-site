First, it replaces standard PPO clipping with DPPO. Standard PPO clips the probability ratio, which means low-probability sampled tokens can be clipped by tiny absolute probability changes while high-probability tokens tolerate much larger ones. In large-vocabulary language models, this creates uneven update geometry. DPPO instead clips the absolute probability change of the sampled token, giving a common absolute-probability trust region.

Second, it bounds value predictions to the reward range. In outcome-reward settings, the return support is known. An unconstrained linear value head can easily overshoot that range, especially early in training, which then destabilizes both value fitting and downstream advantage estimates. Bounding the value head injects a simple but strong task prior.

Third, it trains the critic on Monte Carlo returns rather than bootstrapped targets. Because intermediate rewards are zero and the terminal reward carries the whole signal, the variance reduction from bootstrapping is limited while the bias from critic self-reinforcement can be severe. BPCO therefore prefers direct supervision from observed outcomes.

Fourth, it removes batch-wise advantage normalization in the policy update. The argument is that as the policy improves, the residual advantage scale should naturally shrink. Forcing every batch to unit scale erases that information and can keep magnifying noise late in training. BPCO preserves the raw advantage magnitude.

Fifth, it introduces length-adaptive GAE. With a fixed lambda, terminal reward is propagated backward with a length-dependent profile, so short and long responses receive systematically different credit assignment. The adaptive schedule is designed to make the effective weighting of terminal reward more consistent across response lengths.

A notable extra feature is privileged critic input. Since the critic is discarded at inference time, it can condition on reward-defining information unavailable to the policy, such as a reference answer, official solution, or grading rubric. This does not change the ideal value function for a prompt, but it can make that function much easier to approximate. That is a meaningful advantage over group-relative estimators, which do not naturally exploit such side information.10:T650,The empirical section has three layers.

For each rollout group, half of the branches are standard GRPO rollouts, while the other half receive Gaussian noise injected into the last hidden layer during the prompt-encoding prefill pass. The noisy branches therefore start generation from displaced latent states. If a branch still reaches the correct answer despite the displacement, it is reinforced relative to branches that fail, so sensitivity to that latent perturbation is converted into policy-gradient signal through group-normalized rewards.

Several design choices matter.

First, the noise is injected only once during prefill, not throughout decoding. The paper is careful about this distinction: it changes the departure state of the rollout, but does not keep perturbing the cached representation during generation. This keeps decoding cost identical to standard GRPO and makes attribution cleaner.

Second, the noise scale is calibrated to the hidden-state norm. The perturbation magnitude is proportional to the norm of the original hidden vector, so sigma becomes a dimensionless relative scale rather than an architecture-dependent absolute one. The paper also shows that the relative perturbation magnitude concentrates with variance 2/d, which means the actual perturbation size is tightly controlled in high-dimensional hidden spaces.

Third, the noise follows an annealing schedule: stronger exploration early, decaying to zero later. This mirrors prior noisy-rollout schedules, but moves the perturbation from pixel space into latent space.

Fourth, the paper includes antithetic and steered probes. These are designed to test whether the gain comes from simply adding more noise budget or from creating independent stochastic branches. The conclusion is that independent stochastic diversity is the active ingredient, not a specific direction or just larger perturbation energy.
