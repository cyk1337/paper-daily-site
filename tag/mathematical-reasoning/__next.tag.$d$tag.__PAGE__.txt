9:Ta1d,方法叫 BPCO（Best-Practice Critic Optimization）。它由五个关键部件组成。

第一，用 DPPO 替代标准 PPO clipping。标准 PPO 用概率比值裁剪，低概率 token 的微小绝对变化也可能触发 clipping，而高概率 token 可以承受更大的绝对变化；在大词表 LM 中，这会让不同 token 的更新几何很不均匀。DPPO 把约束改成 sampled token 概率的绝对变化上界，相当于让每个被采样 token 共享同一 absolute-probability trust region，更适合语言模型的长尾词分布。

第二，把 critic 输出限制在 reward range 内。论文考虑的是 outcome reward，回报天然有已知范围。若 value head 仍是无界线性层，训练早期很容易出现超范围预测，随后 GAE 和 value loss 都会被放大。作者将 value prediction bounded 到 reward 支持集，使 critic 的函数类与任务先验一致，减少无意义外推。

第三，critic 直接拟合 Monte Carlo return，而不是常见的 bootstrap target。由于中间 reward 全为 0、终局才给分，且 γ=1 的设置很常见，此时用 bootstrap target 的收益并不大，却会把旧 critic 的误差传播到新 critic。BPCO 直接用观测到的最终回报训练 value，相当于在 outcome-only 场景里主动放弃一部分低方差，换取更少偏差和更稳定的 critic 学习。

第四，policy update 不做 batch-wise advantage normalization。作者的论点很直接：当策略逐渐收敛时，真实 advantage 的尺度本来就应该变小；若每个 batch 都强行归一到单位方差，就等于持续放大残余噪声，容易造成后期训练抖动甚至过更新。BPCO 保留 raw advantage scale，让优化器看到“信号正在衰减”这件事。

第五，使用 length-adaptive GAE。固定 λ 在短回答和长回答上对应的 terminal reward 传播形状不同，导致 credit assignment 随长度系统性偏移。作者设计按 response length 调整的 λ，使不同长度样本上终局奖励向前传播的权重分布更一致。

除此之外，论文还强调一个 critic-only 的额外自由度：privileged critic input。因为 critic 只在训练时使用，可以额外看到 reward-defining information，例如数学题参考答案、官方解、或开放式任务的 rubric，而 policy 仍只看原始 prompt。这样不会改变最优 value function 的定义，但会显著降低 value approximation 难度。这个点和传统 RLHF/GRPO 的差别很大：group-relative estimator 很难自然利用这类只在训练时可见的信息。a:T7b2,实验分三层。

First, it replaces standard PPO clipping with DPPO. Standard PPO clips the probability ratio, which means low-probability sampled tokens can be clipped by tiny absolute probability changes while high-probability tokens tolerate much larger ones. In large-vocabulary language models, this creates uneven update geometry. DPPO instead clips the absolute probability change of the sampled token, giving a common absolute-probability trust region.

Second, it bounds value predictions to the reward range. In outcome-reward settings, the return support is known. An unconstrained linear value head can easily overshoot that range, especially early in training, which then destabilizes both value fitting and downstream advantage estimates. Bounding the value head injects a simple but strong task prior.

Third, it trains the critic on Monte Carlo returns rather than bootstrapped targets. Because intermediate rewards are zero and the terminal reward carries the whole signal, the variance reduction from bootstrapping is limited while the bias from critic self-reinforcement can be severe. BPCO therefore prefers direct supervision from observed outcomes.

Fourth, it removes batch-wise advantage normalization in the policy update. The argument is that as the policy improves, the residual advantage scale should naturally shrink. Forcing every batch to unit scale erases that information and can keep magnifying noise late in training. BPCO preserves the raw advantage magnitude.

Fifth, it introduces length-adaptive GAE. With a fixed lambda, terminal reward is propagated backward with a length-dependent profile, so short and long responses receive systematically different credit assignment. The adaptive schedule is designed to make the effective weighting of terminal reward more consistent across response lengths.

A notable extra feature is privileged critic input. Since the critic is discarded at inference time, it can condition on reward-defining information unavailable to the policy, such as a reference answer, official solution, or grading rubric. This does not change the ideal value function for a prompt, but it can make that function much easier to approximate. For each rollout group, half of the branches are standard GRPO rollouts, while the other half receive Gaussian noise injected into the last hidden layer during the prompt-encoding prefill pass. The noisy branches therefore start generation from displaced latent states. If a branch still reaches the correct answer despite the displacement, it is reinforced relative to branches that fail, so sensitivity to that latent perturbation is converted into policy-gradient signal through group-normalized rewards.

Several design choices matter.

First, the noise is injected only once during prefill, not throughout decoding. The paper is careful about this distinction: it changes the departure state of the rollout, but does not keep perturbing the cached representation during generation. This keeps decoding cost identical to standard GRPO and makes attribution cleaner.

Second, the noise scale is calibrated to the hidden-state norm. The perturbation magnitude is proportional to the norm of the original hidden vector, so sigma becomes a dimensionless relative scale rather than an architecture-dependent absolute one. The paper also shows that the relative perturbation magnitude concentrates with variance 2/d, which means the actual perturbation size is tightly controlled in high-dimensional hidden spaces.

Third, the noise follows an annealing schedule: stronger exploration early, decaying to zero later. This mirrors prior noisy-rollout schedules, but moves the perturbation from pixel space into latent space.

Fourth, the paper includes antithetic and steered probes. These are designed to test whether the gain comes from simply adding more noise budget or from creating independent stochastic branches. The conclusion is that independent stochastic diversity is the active ingredient, not a specific direction or just larger perturbation energy.

第一部分是 step validity。把自然语言推理链切成 atomic steps，用 verifier g 对每一步在给定题目和前缀推理下是否成立打分。这里 verifier 可以是 LLM critic、确定性算术检查、矛盾检测器等的组合。为了既惩罚单个致命错误又保持可微和平滑，作者不是简单取平均，而是把几何均值和最小值混合，得到一个对“最早致命错误”敏感的局部可信度分数，并返回 earliest suspect step。

第二部分是 reasoning-to-answer entailment。即使每一步看起来都顺，最终答案也可能不是由整条链推出，而是后验拼接出来的。于是作者估计 e = P_g(R ⊧ A | x)，衡量完整推理链是否蕴含最终答案。这个设计是为了压低 post-hoc rationalization 的分数。

第四部分是 targeted counterfactual sensitivity。作者认为仅靠表面 entailment 仍可能被“因果惰性”的漂亮解释骗过，所以会对关键步骤做定向干预，检查答案是否按预期方向变化。如果改动一个枢纽步骤后答案几乎不动，说明原始解释可能只是装饰性的，不是真正驱动答案的因果链。这个部分是 RAFS 最有辨识度的设计，因为它试图把 explanation plausibility 和 causal relevance 区分开。

最后，RAFS 输出不仅有总分，还包括 failure type、最早可疑步骤和 abstention decision。论文明确强调它不是 reasoning truth oracle：如果模型在多次采样中稳定重复同一个误解，RAFS 仍可能给出较高一致性分数。因此它测的是 observable faithfulness，而不是绝对正确性。13:T938,The main proposal is RAFS, the Reasoning–Answer Faithfulness Score, a 0–100 instance-level score. It does not try to estimate whether the answer is correct in an absolute sense. Instead, it estimates whether the observed reasoning trace is locally credible, whether it entails the final answer, and whether that reasoning–answer relation is stable under resampling and targeted interventions.

The first component is step validity. The chain of thought is segmented into atomic steps, and a verifier g scores whether each step follows from the problem and the preceding steps. The verifier can combine an LLM critic, deterministic arithmetic checks, contradiction detection, and related tools. Rather than averaging step scores, the paper uses a mixture of geometric mean and minimum so that a single fatal step is penalized strongly while the score remains smooth. The earliest low-confidence step is also returned as the suspect step.

The second component is reasoning-to-answer entailment. Even if each step looks plausible, the final answer may still be post-hoc or only loosely connected to the chain. The paper therefore estimates e = P_g(R entails A | x), which is meant to reduce the score of polished but unsupported explanations.

The third component is answer consensus and conditional reasoning consistency under resampling.
