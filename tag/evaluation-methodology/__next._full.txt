Structurally, for an odd-numbered unweighted majority panel with k judges and a single replacement ballot, the panel prediction can change if and only if the original vote margin is one, m = |2s-k| = 1. This is a deterministic arithmetic fact about majority voting, not a statistical claim. It identifies the exact affected set for single-ballot substitution.

Empirically, the authors build multi-model judge panels for code-generation evaluation and introduce a verification signal from a different evidence source. They compare several replacement rules, including random replacement, fixed replacement, and replacing a vote on the majority side. They then report two diagnostics on the same data: the same effective-vote statistic used in prior work, and margin-stratified accuracy/error analyses. The key result is that these diagnostics answer different questions. Aggregate dependence can remain unchanged while conditional gains on pivotal examples are large and reliable.

The mechanism is simple. Most examples are structurally unaffected by single-ballot substitution, so averaging over the full population dilutes any verifier benefit. If the verifier is especially useful where the panel is near the decision boundary, the gain is real but localized. The paper also includes an exploratory analysis linking part of the pivotal-region error pattern to panel composition.1b:T552,The experiments cover three code benchmarks and four panel sizes, k in {3, 5, 7, 9}. The main setting uses seven LLM judges plus one verification signal. At larger scale, replacing one judge with the verifier changes the effective-vote count by about -0.04 with a 95% confidence interval of [-0.10, +0.02], so the aggregate metric shows no distinguishable improvement. Yet panel accuracy still increases.

The margin-stratified analysis explains why. For non-pivotal cases, such as at least 5–2 agreement in a 7-judge panel, single-ballot substitution cannot alter the majority outcome, so the accuracy gain is exactly 0. For 4–3 cases, the same verification signal improves accuracy by more than 10 percentage points. In the main setting, 199 of 569 panel errors occur in the pivotal region. So pivotal cases do not contain all errors, but they have higher error rates, and every decision change induced by single-ballot substitution is confined there.

The paper also evaluates margin gating. Once a substitution rule is fixed, verifier calls outside the pivotal region can be skipped without changing predictions. In their experiments, this reduces verifier-call frequency to 12%–27% while preserving the same outputs as universal substitution.
