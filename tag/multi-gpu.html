CTA-Pipelining: A Latency-Oriented Spatial Scaling Method for Multi-GPU Systems

这篇论文解决的是多 GPU LLM 推理中的单请求低延迟扩展问题。现有 TP 在算子内部切分计算，但需要 AllReduce 等集合通信，延迟下降很快遇到上限；PP 更偏吞吐，不适合单 batch 交互延迟。作者试图利用 GB200、H200、B200 这类 NVLink/NVSwitch 共享内存多 GPU 系统，在 inter-operator 层面做更细粒度的空间流水。

评看 §实现和算子形状表：若收益只在小 MLP 形状成立就是工程特例，若覆盖 decoder block 才值得复现。

EnergyLens: Predictive Energy-Aware Exploration for Multi-GPU LLM Inference Optimization

现有LLM推理能耗评估方法存在明显局限：直接 profiling 需要GPU资源和大量工程实现成本，TDP等粗粒度方法会高估解码阶段能耗最高达60%，LLMCO2不支持算子融合与MoE架构，内核级预测器无法捕捉多GPU并行、计算通信重叠等分布式部署的核心能耗特征，导致从业者无法高效探索推理优化的能耗-延迟权衡空间。

评和预训练目标无关，但 MoE 多 GPU 能耗建模值得扫；重点看 MoE imbalance 和通信能耗部分。
