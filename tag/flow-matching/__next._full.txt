Existing unified multimodal systems typically suffer from two structural constraints. They either use different generation mechanisms for different modalities, or they quantize one modality to fit the other. They also factorize outputs in a fixed order, so the first modality cannot adapt once the second starts to form. JUICE asks whether both modalities can instead live in a shared continuous target space provided by frozen pretrained encoders, and whether a single flow-matching backbone can learn the joint distribution over those representations. If that works, conditional generation, bidirectional generation, and truly coupled image-text generation all become different inference paths inside one model rather than separate systems.1a:T4f1,Its importance for pretraining is threefold. First, it reframes unified multimodal modeling as a pretraining objective and representation design problem, not just a systems integration problem. The key move is to generate both image and text in continuous semantic spaces, which removes the need to anchor the whole system around a pretrained autoregressive language model. Second, the paper provides a fairly complete study of the design space that practitioners usually handle heuristically: whether text should remain tokenized or be generated continuously, which denoising regions must be covered during training, whether reconstruction-oriented spaces or semantic encoder spaces are better targets, and how these choices behave under scaling. Third, it gives evidence that joint distribution modeling yields a capability that is not captured well by standard multimodal benchmarks. The coupled-sampling planning results show that the model can let image and text revise each other during generation. That is a stronger claim than simply saying one set of weights can solve multiple tasks. Lafa adopts block-autoregressive factorization: the prefix remains causal, while the continuation is partitioned into fixed-size blocks. This choice has two immediate benefits. First, generation across blocks remains left-to-right, so prefix caching is retained. Second, parallelism is localized within each block, which makes training and inference much easier to implement on top of existing Transformer infrastructure.

Inside a block, Lafa does not use standard flow matching with a single shared time variable for all positions. Instead, it introduces asynchronous flow through tokenwise time. Tokens are first embedded into a continuous space, and flow matching is performed from Gaussian noise to token embeddings. Different positions follow different time schedules τ_i(t): earlier positions move toward clean token embeddings faster, later positions more slowly. This creates a left-to-right bias inside the block without enforcing strict causality. The result is a hybrid inductive bias: bidirectional interaction within the block, but with an ordering preference that better matches language than fully symmetric denoising or fully bidirectional masked modeling.

Architecturally, the model uses causal attention on the prefix and bidirectional attention within the current block, while asynchronous tokenwise time ensures that different positions are denoised at different rates. This allows the model to condition on a stable prefix while updating multiple future positions in parallel. Because continuation still advances block by block, cached history from previous blocks can be reused much like in AR decoding, which is a major practical advantage over many non-AR approaches.

The paper interprets this as a multi-token-prediction-like effect: flow training encourages the model to better capture local future-token structure conditioned on the prefix, which then feeds back into the AR head.
