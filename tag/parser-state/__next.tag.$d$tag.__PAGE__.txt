a:T4fc,The method, SHIM, adds an offline-trained logit correction on top of standard masked decoding. The correction is conditioned on parser state, lexer state, and the candidate next token. The central observation is that incremental parsing infrastructure already tracks where the current prefix sits in both grammar space and lexical space. Parser state alone is too coarse when the model is partway through a lexeme; lexer state captures character-level progress inside an unfinished tokenizable unit. The paper’s BV4 example makes this concrete: several operator completions may still be possible while the parser remains unchanged, but the lexer has already narrowed the continuation set substantially. SHIM learns a multiplicative adjustment factor that approximates how likely a candidate token is to admit a valid continuation in the future. At inference time, this becomes an additive correction in logit space. Compared with online sampling methods, SHIM gives up exact recovery in exchange for low constant overhead. Compared with surrogate probabilistic models, it does not try to model the full LM distribution; it only learns the missing global reachability signal that local masking fails to encode. That narrower target is why the controller can stay lightweight.b:T43f,From the available full-text excerpt, the experimental story appears to have three main components. First, compare against plain masking-based GCD to show better fidelity and output quality under the same hard grammatical guarantees. Second, compare against online resampling approaches to show a better latency-quality tradeoff. Third, run ablations over parser-only, lexer-only, and combined state features to demonstrate that lexer state is essential when validity depends on progress inside an unfinished lexeme. The introduction clearly claims that SHIM better matches the LM’s distribution over valid sequences and avoids collapse toward low-probability but locally admissible outputs. For a careful read, the numbers worth checking are the controller size, how training examples are constructed from parser transitions and valid token sequences, per-step latency overhead, task-level gains on structured generation benchmarks, and wall-clock comparisons against online sampling.
