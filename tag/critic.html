Probe-and-Resume: When and How to Evaluate Agent Execution

这篇工作问的是：在可分叉的终端执行环境里，Agent 什么时候应该让 critic 介入评估，以及 critic 需要看到什么状态，才能真正提升任务成功率。论文的关键发现是，直接把 MCTS 搬到终端 Agent 上效果有限，因为中间状态的价值很难判断；更有效的做法是在 actor 声称完成任务时，让 critic 在隔离分叉环境里主动运行检查，再决定提交还是把反馈交还给 actor 继续修复。

评这篇不是在教你怎么把 search 做强，而是在提醒你很多 agent test-time scaling setup 根本没有可用评估信号；先看失败分析和 critic 触发时机，别急着堆树搜索。
Jiakai Xu,Tiancheng Ge,Tujie Guan,Yusheng Li,Rohan Timmaraju,Eugene Wu,Kostis Kaffes

Privy to the Foil: Recasting Value Estimation with a Self-Privileged Critic for RLVR

在基于强化学习的 LLM 推理任务（RLVR）中，由于奖励稀疏且仅在序列末尾出现，传统的 Actor-Critic 方法（如 PPO）在估计中间状态价值时面临巨大挑战。Critic 需要同时理解正确的解空间并预测策略的未来行为，导致价值估计不准，进而影响信用分配和训练稳定性。

评读 critic 设计即可；若同 prompt 成败轨迹能稳住 advantage，值得在内部 RLVR ablation 复现。

A Nash Equilibrium Framework For Training-Free Multimodal Step Verification

这篇工作要解决的是多模态逐步推理里的 step verification，但切入点不是训练一个更强的 process reward model，而是在没有标注、没有额外训练的条件下，怎样把多个冻结 verifier 的分歧信息利用起来。作者认为现有 training-free 聚合方法把多个 judge 的分数直接平均，会把“高置信一致”和“强烈冲突后的中间值”混为一谈，导致错误步骤被误接受。核心问题因此是：如何把 verifier 之间的 disagreement 变成可操作的拒绝信号，而不是把它在平均过程中抹平。

评不是 pretrain 论文，但“把 judge 分歧当信号而非噪声”这个点值得借到 verifier/RL reward 设计里；先看方法定义和六个 benchmark 的泛化表。
Rohit Sinha,Kunal Tilaganji,Tanuja Ganu,Nagarajan Natarajan,Amit Sharma,Vineeth N. Balasubramanian
