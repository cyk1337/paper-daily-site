Skill Neologisms: Towards Skill-based Continual Learning

论文讨论的是如何在不更新模型权重的前提下，为已训练好的 LLM 增加可复用、可组合的新技能。目标不是学习一个任务前缀，而是学习一种“技能词”：模型在上下文中看到这个新 token 后，能更稳定地调用某类程序性能力，并且能和已有技能或其他独立学到的技能组合。

评看 compositionality 实验和 token 分析；若结果稳，它会改变“新技能必须改权重或塞上下文”的默认取舍。
