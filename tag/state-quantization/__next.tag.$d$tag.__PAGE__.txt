9:T921,方法由三部分组成。第一部分是 periodic rounding。作者观察到，预填充阶段的 chunked kernel 本来就不是每个 token 写回一次状态，而是每个 chunk 写回一次；真正导致误差频繁注入的是 decode 阶段每 token 一次的状态落盘与量化。PACE 在解码时引入 decode buffer，把最近若干 token 的 key/value 暂存在小缓冲区里，只在 buffer flush 时才把状态推进并量化一次。这样 decode period dP 从 1 变成 8 等较小整数，量化误差注入频率下降，而且两次注入之间有更多衰减步数。论文在理论部分给出 retained error bound：某个 head 的误差保留量随 head decay 增大而增大，随 rounding period 增大而减小。这不是严格的最优性证明，但足够解释为什么“少量化几次”比“每次都量化得更精细”更有效。

第二部分是 channel-aligned grouping。作者分析 gated-delta state 的结构，发现大值不是随机散落，而是沿 state 的列方向集中；更具体地说，某些 delta-value channel 会在连续多个 token 上持续偏大，于是外积写入后在 state 中形成整列的大条纹。如果量化分组沿 value axis 横着切，会把大值和大量小值混在同一组里，共享 scale 后小值分辨率很差；如果沿 key axis、按列分组，就能让同一组内部动态范围更一致。作者用 max/RMS 指标比较不同分组方向，并通过打乱 channel 排列的实验说明这种列结构确实来自 delta channel 的时间一致性，而不是偶然统计现象。

第三部分是 head-level mixed precision。PACE-4 让所有 head 都用 4-bit；PACE-4/8 则把每层中误差保留最久的四分之一 head 保留为 8-bit，其余仍为 4-bit。这里的依据来自前面的 per-head decay 分析：高 decay head 对量化误差更敏感，统一 4-bit 不划算。这个设计很朴素，但比全局升 bit 更节省内存，也更符合递推系统的异质性。

实现上，作者还给出 Triton kernel，支持 packed 4-bit state 和 periodic decoding，说明该方法不是只在离线模拟里成立，而是考虑了真实 decode 路径中的 kernel 组织与 buffer 成本。论文也明确把 decode buffer 的显存算进总内存，而不是只报 state 本体，这是比较严谨的地方。a:T8bb,PACE combines three ideas. First, periodic rounding. During prefill, chunked kernels already update and write the recurrent state only once per chunk. The problematic regime is autoregressive decoding, where the kernel is invoked once per token and the state is quantized after every step. PACE introduces a decode buffer that stores recent keys and values for a small number of generated tokens, and only flushes them into the recurrent state every dP steps. This reduces how often quantization noise is injected. The paper derives a per-head retained-error bound showing that the surviving error increases with head decay and decreases with the rounding period. The argument is simple but useful: if the recurrence contracts errors between writebacks, less frequent rounding can outperform more frequent rounding even at the same bit width.

Second, channel-aligned grouping. The authors analyze the gated-delta state and find that large-magnitude entries are column-structured rather than randomly scattered. Intuitively, some delta-value channels stay large across many tokens, and the outer-product update writes that persistence into whole columns of the state. If quantization groups cut across columns, one large entry can dominate the shared scale and waste levels on many small entries. Grouping along the key axis, so that each group stays within a column, produces more homogeneous dynamic ranges. The paper supports this with max/RMS statistics and a channel-permutation experiment that ties the observed structure back to persistent delta channels.

Third, head-level mixed precision. PACE-4 quantizes all heads to 4-bit. PACE-4/8 keeps the quarter of heads in each layer that retain rounding error the longest at 8-bit, while the rest remain at 4-bit. This follows directly from the per-head decay analysis: some heads are much more sensitive to quantization than others, so uniform precision is wasteful.

The implementation side is also important. The paper includes Triton kernels for periodic decoding with packed 4-bit state, and it accounts for decode-buffer memory in the reported totals. That makes the evaluation more credible than papers that report only compressed state size while ignoring auxiliary buffers.b:T5db,The evaluation spans four hybrid linear-attention backbones ranging from 4B to 35B parameters. The main empirical pattern is consistent: for all sub-8-bit settings, increasing the decode rounding period from 1 to 8 reduces quality degradation. That directly validates the error-propagation story. Against prior post-hoc state quantizers such as DAMP and Q-Mamba, PACE preserves perplexity or downstream accuracy better at 4-bit, and the mixed PACE-4/8 variant closes the gap further for sensitive heads.

The ablations are the most informative part. Period ablations show that the gain comes from less frequent decode-time rounding rather than from prefill behavior; prefill chunk length is fixed at 256 in the benchmark setup. Grouping ablations show that column-aligned grouping beats row-aligned grouping, and the gap widens with larger group width because a bad grouping direction amplifies shared-scale mismatch. Precision-allocation ablations show that a small fraction of 8-bit heads captures most of the benefit. The systems experiment with Triton kernels indicates that periodic decoding keeps the throughput advantage of decode buffers rather than giving it back through packing overhead.

One deployment detail from the introduction is worth remembering: at 64-way concurrency, fp32 recurrent states account for roughly 10% to 41% of total memory occupied by weights plus states, depending on the backbone.
