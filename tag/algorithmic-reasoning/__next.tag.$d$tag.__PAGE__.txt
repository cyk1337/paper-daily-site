Because enumeration is exact, the map from program behavior to prior mass is a sufficient statistic, and the posterior predictive for any few-shot context is computed in closed form. To remove output-polarity bias, F is complement-symmetrized into sF; each task is paired with its bitwise complement twin, on which the optimum scores identically, so the original-twin gap isolates the model's own inductive bias. Ground-truth certification uses GPU-accelerated enumeration, an independent pure-Python reference, and exact cross-checks (byte-for-byte agreement of per-output program counts, witness re-execution, bit-identical posterior agreement). The first is a finite-precision transformer with polylogarithmic width and rightmost-unique hard attention. It emits reasoning tokens at the level of Word RAM instructions instead of simulating Turing-machine tape movements. For a t-step Word RAM execution with word size w = Θ(log(n+t)), the construction uses O(w^2) tokens per instruction, or O(t log^2(n+t)) tokens overall. For instruction sets without multiplication, division, and modulo, the per-instruction overhead drops to O(w), giving O(t log(n+t)) tokens. The second setting uses fixed-width transformers with continuous CoT, where hidden vectors carry intermediate state and a Turing-machine oracle is invoked per Word RAM instruction. The third setting augments transformers with a linear RNN layer and supports explicit CoT. For an instruction set whose primitive operations take κ(w) Turing-machine time, these latter constructions use O(tκ(w)) CoT steps. The first main result is a negative one. With standard positional encodings and a finite alphabet, any input and CoT trace expressible in C-RASP is also definable in TC0. This strengthens prior observations that C-RASP CoTs are not Turing complete, because it ties the limitation directly to learnable length generalization rather than mere representability.

The constructive result identifies two barriers in simulating Turing machines with length generalization: arbitrary copying and position-based retrieval. A Turing machine simulation needs to address tape cells and recover the latest content written to a cell. In a standard trace, this becomes a non-unique retrieval problem over an increasingly long history. The proposed fix uses two ingredients. First, signpost tokens provide unique addresses for cells or structural positions, with the symbol inventory growing with instance size. Second, value-change encoding records transitions between old and new values only when a value changes. This replaces “retrieve the most recent write” with a count-comparison computation over changes, which is more compatible with C*-RASP-style length-generalizable computation.
