X-Token: Projection-Guided Cross-Tokenizer Knowledge Distillation

论文处理的是跨 tokenizer 知识蒸馏中的“词表不兼容”问题。标准 KD 在每个位置对 teacher 与 student 的 next-token 分布做 KL，需要共享 tokenizer；这会把 student 绑定到同一 tokenizer 家族，限制了使用 Qwen、Phi、Llama 等异构 teacher 的能力。已有 logit-based 方法虽然部署成本低，但要么只用正确 token 概率，丢掉 teacher 分布里的暗知识；要么把词表切成 common/uncommon 两部分，依赖严格字符串匹配和 rank-based 对齐，导致两类问题：关键 token 落入 unmatched subset 后被错误压低，例如多位数字；以及等价 token 或 teacher 多 token 分解无法被利用，例如 student 的一个词对应 teacher 的多个子词。

评NVIDIA团队提出的跨tokenizer蒸馏方法，指出了Llama→Qwen蒸馏中数字token被压制的具体问题，对模型迁移和tokenizer兼容性研究有直接参考价值。
Sharath Turuvekere Sreenivas,Adithyakrishna Venkatesh Hanasoge,Mingyu Yang,Ali Taghibakhshi,Saurav Muralidharan,Ashwath Aithal,Pavlo Molchanov
