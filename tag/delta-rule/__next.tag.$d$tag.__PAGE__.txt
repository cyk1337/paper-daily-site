9:T431,Built on channel-wise gated delta / DPLR-style recurrence (diagonal per-channel decay plus low-rank delta updates), the baseline delta rule treats the memory matrix S_t as an associative map and performs a corrective update so that the readout at the current key k_t, i.e., S^T k_t, moves toward v_t.

Erase-then-Delta Attention (EDA) decouples where to erase from where to write:
1) Erase step: select an independent erase address and apply a targeted suppression along a learned erase direction, explicitly cleaning stale content at that address.
2) Delta step: perform the standard delta-style corrective write at the current write key k_t, preserving the desirable “correct-what’s-stored” behavior.

Conceptually, EDA separates three signals: (i) address-agnostic diagonal/channel decay, (ii) independently addressed erasure, and (iii) write-coupled delta correction. The authors report that the learned erase and write addressing becomes nearly orthogonal, suggesting the erase path is not merely stronger forgetting but a distinct conditional cleanup mechanism.a:T607,The method has two main components. First, content-aware forgetting. Instead of deriving the erase gate solely from the current token representation, CARVE lets the model inspect the current state before deciding what to remove. The key design goal is to do this without introducing extra asymptotic cost or breaking the algebraic structure needed for chunk-parallel execution. Second, value-efficient gating. The authors argue that GDN-2's full d_v x d_k gate is over-parameterized along the value dimension: it is expressive, but expensive in a way that may not be necessary. CARVE therefore reparameterizes the gate so that the model retains fine control where it matters most, while reducing the cost of value-wise gating.

Importantly, CARVE still keeps the delta-rule style error-corrective write. The state predicts the value associated with the current key, and the model writes back a rank-1 correction proportional to the prediction error. So the novelty is not the associative-memory update itself, but how forgetting is decided and how the gate tensor is parameterized. This distinguishes it from both older gated RNNs and diagonal-state linear recurrences: the model does not rely on a coarse scalar decay or fixed state dynamics, but on content-dependent, hardware-conscious memory editing.

The design trade-off is clear. The paper is not trying to recover full attention-like retrieval.
