Fast LapSum: Exact Differentiable Top-k at Million Scale

评算子层面有用，尤其给 MoE 路由和稀疏注意力；先看 VJP 推导和真实 GPU benchmark，端到端收益仍要怀疑。

PrunePath: Towards Highly Structured Sparse Language Models

这篇工作处理的是一个很具体但长期没有被很好解决的问题：FFN 占了现代 LLM 大部分参数和相当一部分推理开销，但常见剪枝方法要么是非结构化稀疏，难以转成真实硬件收益；要么结构过硬，精度掉得快。MoEfication 这条路把 dense FFN 重排成若干 expert，只激活部分 expert，方向是对的，但已有代表方法 LTE 用独立 sigmoid 给每个 expert 做二分类，缺少 token 级全局预算约束，容易在低预算场景下保守过激活，导致稀疏度不够可控，重建误差也偏大。PrunePath 的核心问题，就是如何把 dense FFN 变成一种既结构化、又可按 token 自适应、还能在单一 checkpoint 上连续调节稀疏度的稀疏 FFN。

评别只看“稀疏-精度曲线”，重点看它把路由做成 token 级预算旋钮、以及解码 kernel 是否真能吃到收益；若实现细节不扎实就只是换皮 MoE。
Zhexuan Gu,Zixun Fu,Yancheng Yuan
