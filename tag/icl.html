CLBench-V: Evaluating Multimodal Context Learning from Grounding to Knowledge Acquisition

这篇工作要解决的不是一般的多模态问答，而是更细一层的“多模态上下文学习”评测问题：当模型在推理时拿到一段包含文档页、图表、表格、网页截图、多图证据等在内的上下文，它到底是在哪一步失效的。现有 benchmark 多半只看最终答对没有，或者只覆盖纯文本 context learning，难以区分模型是没有找到证据、找到了但不会用，还是明明上下文里定义了新知识却仍被预训练先验带偏。CLBench-V 试图把这三类失败拆开，并在统一框架下评估多模态模型从 grounding 到新知识获取的完整链条。

评多模态ICL评测的新基准，三维度能力拆解可用于模型失效定位，只看任务设计与维度划分部分即可

Spurious Prompts: Can Irrelevant Prompts Steer Large Language Models?

这篇工作研究一个很少被正面拆开的现象：LLM 是否会被与任务语义无关的 prompt 稳定操控。更具体地说，作者关心的不是 prompt wording 的常规敏感性，也不是更清楚地描述任务能否提升效果，而是那些刻意避开任务词汇、领域线索和常见推理提示的“无关提示”，是否仍然能显著改变模型行为，甚至提升准确率或诱导系统性偏置。

评读实验设计和失败案例：它会削弱对 prompt 语义解释的信心，也提醒 eval prompt 可能藏着非语义捷径。
Pawel Batorski,Abtin Pourhadi,Jerzy Sarosiek,Przemyslaw Spurek,Paul Swoboda
