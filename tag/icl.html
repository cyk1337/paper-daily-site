When Context Misleads: In-context Learning with Jurisdiction in Large Language Models

这篇工作讨论的不是常见的“模型能不能从 few-shot 示例里学到规则”，而是更细的一层：模型能不能判断这些上下文规则是否对当前问题有管辖权。现有 ICL 训练大多默认示例里的规则就应该被执行，因此会把“从上下文抽取映射关系”的能力越练越强，却没有同步训练“什么时候不该跟着上下文走”。作者把这个缺口形式化为 context-authority discrimination，并构造了一个专门测试该能力的场景：上下文内部自洽、示例也一致，但它描述的是伪科学规则、私有规则或未部署规则；查询却要求现实世界或正式系统下的正确答案。模型如果输出 context-induced answer，说明它已经学会了示例规则，却没学会判断规则适用范围。

评只看 FakeContextBench 设计和 14.95pp 退化案例；它提示 ICL tuning 可能在静默削弱 base model 的事实先验。

Unifying ICL, SFT, KL-Regularized RL Through a Bayesian Lens

这篇文章要解决的不是一个新训练算法，而是一个统一解释框架：如何把 ICL、SFT、KL-regularized RL、on-policy distillation，以及 test-time search / CoT 这些看起来分属不同阶段、不同目标的过程，放进同一个概率推断模板里。全文的核心论点是，这些方法都可以写成两步：先用先验/参考策略与效用信号构造一个 generalized Bayes 或 Gibbs posterior，再用参数化模型去逼近这个后验或后验预测分布。作者尤其强调两组对应关系：其一，few-shot ICL 在层次贝叶斯任务分布下，对应 Bayes posterior predictive；其二，SFT 是对 teacher conditional distribution 的 forward-KL 投影，而 KL-regularized RL / OPD 则是在参考策略约束下对 reward-weighted 或 advantage-weighted posterior 的近似。文章想解释的现象包括：为什么 ICL 和 SFT 常常能互相替代一部分功能，为什么 RL-tuned reasoning model 上 few-shot prompting 的收益会变得不稳定，以及为什么 OPD、RLHF/RLVR、search-based inference 在形式上并没有想象中那么割裂。

评值得扫公式框架：它把 ICL/SFT/RL 的差异压到 posterior 构造和 KL 投影上，可校准 posttrain 直觉。
Junxin Fan

CLBench-V: Evaluating Multimodal Context Learning from Grounding to Knowledge Acquisition

这篇工作要解决的不是一般的多模态问答，而是更细一层的“多模态上下文学习”评测问题：当模型在推理时拿到一段包含文档页、图表、表格、网页截图、多图证据等在内的上下文，它到底是在哪一步失效的。现有 benchmark 多半只看最终答对没有，或者只覆盖纯文本 context learning，难以区分模型是没有找到证据、找到了但不会用，还是明明上下文里定义了新知识却仍被预训练先验带偏。CLBench-V 试图把这三类失败拆开，并在统一框架下评估多模态模型从 grounding 到新知识获取的完整链条。

评多模态ICL评测的新基准，三维度能力拆解可用于模型失效定位，只看任务设计与维度划分部分即可

Spurious Prompts: Can Irrelevant Prompts Steer Large Language Models?

这篇工作研究一个很少被正面拆开的现象：LLM 是否会被与任务语义无关的 prompt 稳定操控。更具体地说，作者关心的不是 prompt wording 的常规敏感性，也不是更清楚地描述任务能否提升效果，而是那些刻意避开任务词汇、领域线索和常见推理提示的“无关提示”，是否仍然能显著改变模型行为，甚至提升准确率或诱导系统性偏置。

评读实验设计和失败案例：它会削弱对 prompt 语义解释的信心，也提醒 eval prompt 可能藏着非语义捷径。
Pawel Batorski,Abtin Pourhadi,Jerzy Sarosiek,Przemyslaw Spurek,Paul Swoboda
