- Definition (epistemic Sybil resistance): marginal evidential contribution is measured by conditional mutual information I(Θ; Z | R). If it is zero, Z is merely an apparent new voice, not new evidence.
- Report-only identification barrier: different latent ancestry structures can induce the same observable report profile (including similarity/diversity patterns) yet require different Bayes-optimal posterior updates. Therefore, no aggregator that only sees report content can be generally correct.
- No-minting bound: descendants of fixed evidence cannot collectively contain unbounded information about Θ; there is a source-level ceiling.
- Gaussian shared-root model: reports are generated from a shared root signal plus extraction noise. The analysis shows (i) shared ancestry does not imply complete redundancy—repeated extraction can add information up to a ceiling; (ii) correlated extraction errors (e.g., agents sharing the same base model) accelerate saturation and reduce effective information gain.

These families are chosen to span different sources of grounding friction: reference-frame alignment, lexical/category alignment, and indexing/ordinal alignment. Each task is designed so that a single model can solve it when given the full view, after which the information is partitioned across two agents. Third, the paper develops a mechanistic account of failure. It identifies a four-stage conversational cascade: grounding, querying, integration, and re-derivation. Grounding failures occur when agents introduce facts supported by neither private view. Querying failures occur when they do not ask the partner for missing information. Integration failures occur when they fail to combine both views before committing. Re-derivation failures occur when the receiver accepts an answer without recomputing it. The authors then show that conversation-shape features predict the tax well: model capability largely sets the intercept, while conversation structure sets the slope. Finally, they test a simple prompt-only intervention that adds one clause targeting each stage.
