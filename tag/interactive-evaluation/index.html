SIT-Eval: Situation-Based Interactive Turn-by-Turn Evaluation of Conversational Agents

这篇工作要解决的是对多轮对话 agent 做“情境覆盖充分、规则可解释、逐轮可定位”的评测。现有对话 benchmark 多依赖自然对话分布，稀有但高风险的情境样本太少；同时很多评测只给整段对话一个总分，掩盖了中间回合的具体失误。论文提出的核心问题，是如何在不依赖大规模真实稀有样本的前提下，系统评估 agent 在不同情境下是否遵守预定义行为规则。

评读 framework 定义和 judge 规则即可；它的价值在覆盖稀有情境，LLM judge 偏差要单独打折。

FDE-Gym: The Last Mile of AI Delivery

这篇工作要解决的不是“模型能不能把任务做完”，而是“模型能不能在企业交付场景里找对问题、补全约束、改动真实生产系统，并让客户业务指标变好”。现有 benchmark 大多默认问题已经定义清楚，最多考信息缺失或实现能力；FDE-Gym 则把 sponsor 需求可能偏题、关键约束藏在文档和 stakeholder 里、最终按业务指标计分这三件事放到同一个环境里。它评测的是 forward-deployed engineer 式能力：在不完备、甚至带误导的需求下，识别真正的改进杠杆，而不是机械满足字面要求。

评一个非常 hardcore 的 Agent 评测基准，引入了需求澄清和交互成本惩罚，比传统的静态任务 ticket 更接近真实工程落地，值得关注其环境构建和评分设计。

MobilePA-Bench: Benchmarking Mobile Planner Agents on Complex Real-World Tasks

这篇工作要解决的不是“手机 GUI 自动化”本身，而是如何评测一类更接近真实移动端助手的 central planner：它需要在有状态的手机环境里，把自然语言请求转成可执行的多步计划，并在结构化工具、记忆检索、复合技能、以及必要时的 GUI 子代理之间做正确编排。现有 benchmark 要么偏静态 function calling，只看 API 匹配，不看运行时反馈和状态变化；要么偏视觉 GUI 操作，把问题压成点击和截图理解，弱化了系统级工具调用、权限约束、异常恢复和长程任务分解。MobilePA-Bench 试图补上这块空白，评测对象是“移动端规划代理”的决策与编排能力，而不是单纯的界面操作能力。

评构建了一个带真实沙盒和状态反馈的移动端 Agent 评测基准，比静态 API 匹配更接近真实场景，关注 Agent 评测的研究员可扫读其沙盒设计。
