Key components:
1) Browser-hosted Android-like simulator implementing interaction semantics (task stack, keyboard, notifications, permission flows, intent routing, back navigation).
2) Full environment state represented as structured JSON, enabling state readability (inspection), writability (reset/config), forkability (snapshot/clone), and comparability (diff).
3) Layered state model: largely read-only world data + compact per-environment runtime state + OS runtime state; only runtime state is exposed for reset/judging to keep snapshots small and stable.
4) Deterministic judging: outcomes are verified against structured state rather than inferred from screenshots by a VLM judge.
5) AnswerSheet protocol for query tasks: typed fields submitted through the GUI to avoid fragile free-text matching.
