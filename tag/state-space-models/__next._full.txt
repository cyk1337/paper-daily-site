18:T41d,SSDi8 combines execution-path engineering with SSD-aware quantization:
- Persistent INT8 path: identify channel-/shape-varying activations that are repeatedly reused across SSD modules; quantize them at carefully chosen points and reuse cached INT8 activations to avoid frequent precision bouncing and DRAM overhead.
- Element-wise/GEMM entanglement: SSD interleaves element-wise multiplications with matrix multiplications, which commonly forces higher-precision intermediates. The paper proposes a sparse-aware reformulation that reorganizes these computations so INT8 kernels can be used end-to-end, and argues correctness via a formal equivalence analysis.
- Exploit SSD’s intrinsic 2D structure: the external model dimension is effectively factored into (num_heads, head_dim) with different outlier behaviors; SSDi8 explicitly leverages this to reduce quantization error instead of using a single coarse scaling scheme.
- Error-mean correction: add a per-channel error-mean correction term to compensate systematic bias and improve PTQ stability.19:T56c,The setup is intentionally controlled. Using the official Mamba implementation and the public Muon reference code, the authors compare a pure AdamW baseline against three hybrid assignments: Muon on the input projection group only, Muon on the output projection group only, and Muon on both groups, with all remaining parameters still trained by AdamW. This turns the question into a clean assignment study rather than a noisy optimizer bake-off.

Muon works by applying a fixed-step Newton-Schulz orthogonalization to matrix-valued momentum updates, approximating steepest descent under spectral norm geometry. AdamW, in contrast, is coordinate-wise adaptive. The paper goes beyond loss curves and tracks spectral diagnostics of the affected matrices: condition number, effective rank, and spectral norm. The goal is to test whether any optimization gain is accompanied by systematic spectral changes.

The main technical takeaway is that Muon is not uniformly helpful inside Mamba-2. Applying it only to the output projection group works better than applying it only to the input projection group, and better than applying it to both. The authors also test a natural explanation and reject it: although Muon does reduce the condition number of the matrices it touches, that alone does not explain the validation-loss differences. Functional role matters, not just improved conditioning.1a:T602,The experiments use Mamba-2 130M on OpenWebText and FineWeb-Edu, with token budgets of 1B, 2.6B, and 50B. This is a sensible design because it checks both early token efficiency and behavior well beyond the usual compute-optimal regime, while also testing whether the effect survives across corpora.

The most consistent result is that Muon on the output projection group gives the best outcome among the tested assignments. The gain is primarily in token efficiency: it reaches a given validation loss faster than pure AdamW, rather than dramatically changing the eventual floor. Muon on the input projection is weaker, and applying Muon to both input and output projections does not improve further. That pattern suggests a localized architectural fit rather than a generic optimizer advantage.

The long-budget runs matter. The advantage persists even when training continues far past the nominal compute-optimal point, which makes the result more credible than a short-horizon comparison. On the diagnostic side, Muon systematically lowers the condition number of the matrices it updates and changes their spectral statistics, but those changes do not map cleanly to validation performance. That is an important negative result: cleaner spectra are not sufficient to explain better language-model training.

For pretraining researchers, the useful signal is not a single headline number but the structure of the result: the same optimizer can help one projection group, do little for another, and fail to compose when applied to both.1b:T41d,This is a skim paper, but a careful skim is worthwhile. Start with the parameter-group definitions and the figure showing where the input and output projection groups sit inside the Mamba-2 block. Without that, the optimizer-assignment result feels arbitrary. Then read the main validation-loss comparisons across datasets and token budgets. Focus on whether the ranking of assignments is stable, not on tiny absolute differences.

After that, read the spectral diagnostics. The key point is not that Muon changes condition numbers, but that improved conditioning does not fully account for the training gain. That is where the paper becomes more than a benchmark table.

If time is limited, 20 to 30 minutes is enough to extract the main message: Muon can help Mamba-2, but the benefit is localized to specific projection groups and mostly shows up as token efficiency. If you want a follow-up experiment idea, the obvious next questions are why the output projection is the right target and why applying Muon to both groups fails to compound the gain.1c:T458,The method starts from the state space duality view of Mamba-2. Under SSD, a selective SSM layer can be interpreted as structured causal attention: the recurrent state behaves like a compressed KV cache, the update writes token-dependent content into the state, and the readout decodes the value needed by the current token. The key observation is that Mamba-2 decodes token-conditioned values from this state, but does not explicitly decode token-conditioned keys. DART adds a state-memory attention branch on top of the Mamba-2 scan. Chunk state contributions produced by the chunked scan are treated as compressed memory slots. The model decodes both keys and values from these state memories, attends to them with the current query, and adds the retrieved state readout back to the Mamba-2 output through a gated residual correction. The design avoids reconstructing a full token-level KV cache, while giving the model a more selective retrieval path than a single recurrent readout. The implementation reuses the Mamba-2 chunked scan and computes the new attention branch with a FlashAttention-style kernel.1d:T61e,The model starts from diagonal SSMs and adds explicit delayed-state feedback. In a standard discrete SSM, the next state depends on the current state and the current input. In DSSMs, one or more delayed states, such as h_{t-τ}, are also injected into the recurrence. This gives the model a direct pathway to preserve and reuse historical information instead of relying entirely on exponentially decaying modes in the current hidden state. The paper has to solve three technical issues. First is stability: delayed feedback makes the system more delicate than standard ODE dynamics, so the authors introduce a practical parameterization and discretization that keep the recurrence stable. Second is history management: a DDE-inspired discrete model needs explicit buffers for past states and careful handling of delay indexing and initialization. Third is parallel training: standard LTI SSMs can be trained via convolution kernels and FFT, but delayed feedback changes the transfer function and creates aliasing and numerical issues in the frequency domain. The paper derives the exact transfer function for the delayed recurrence and proposes a kernel contour shift technique to suppress time-domain aliasing, preserving efficient FFT-based training. The use of diagonal parameterization is deliberate, since it keeps modes decoupled and makes both stability analysis and FFT implementation tractable. Unlike H3 or hybrid attention-SSM models, DSSMs do not add an external recall module; they modify the underlying dynamics to include explicit historical feedback.1e:T477,The experiments are organized around three settings: targeted delayed-memory tasks, efficiency benchmarks, and standard sequence-modeling datasets. The paper is more convincing as a mechanism-validation study than as a large-scale language-model benchmark. On targeted memory tasks, DSSMs outperform standard diagonal SSMs on patterns that require delayed access and precise recall, which is the most important evidence because it directly matches the motivation. On efficiency, the model still supports FFT-style parallel training and linear recurrent inference, showing that delayed feedback does not collapse back into expensive attention. On standard datasets, the delayed-memory mechanism appears to transfer beyond synthetic tasks into broader sequence modeling. For foundation-model readers, the experiments mainly show that the architecture addresses a real weakness of SSMs, not that it already beats mainstream LLM backbones at scale. If you are looking for detailed LM-style reporting with parameter counts, token budgets, and perplexity tables, this paper is lighter there; its emphasis is feasibility and dynamical interpretation.1f:T4ad,The method replaces the in_proj and out_proj layers in all 48 Mamba-2 blocks with grouped ternary linear layers. These 96 modules account for about 85.7% of the parameters. Weights are partitioned into groups, mainly with group size 128. For each group, the scale is recomputed as the mean absolute weight value, then weights are clipped, rounded to {-1, 0, +1}, and dequantized by multiplying by the group scale. Gradients pass through a straight-through estimator. The SSM dynamics parameters A_log, D, and dt_bias, as well as conv1d, embeddings, lm_head, and norms, remain FP16 because prior SSM quantization work finds these components sensitive at low precision. Training uses the public FP16 Mamba-2 1.3B checkpoint as initialization and a frozen FP16 teacher for distillation, mixing language-model loss and distillation loss with α=0.5 and temperature 1.0. A key observation is zero-ratio collapse: when group scales are learned parameters, optimization can increase the scale, widen the zero region, push more weights to zero, and reduce capacity in a positive feedback loop. Recomputing absmean scales at every forward pass provides a stabilizing feedback and keeps sparsity around 26%.20:T457,The main run trains for 50k steps on C4 with sequence length 1024, totaling about 102M tokens, on a single H100 for roughly 4 hours. The compressed model reduces storage from 2687 MB to 744 MB, a 3.61x reduction. It reaches 48.1% average zero-shot accuracy over seven tasks, close to Bi-Mamba's 48.4%; the 0.3 percentage-point difference is within the reported approximate ±0.9pp confidence interval. Group-size ablations show only about 0.06 PPL range, indicating that the ternary constraint, not scale granularity, is the main bottleneck.21:T926,The core object is a generalized linear recurrence. For each position i, the output y_i is written as the sum of two terms: a linear combination of past inputs x_j with coefficients alpha_{i,j}, and a linear combination of past outputs y_j with coefficients beta_{i,j}. In matrix form, this becomes Y = AX + BY, hence Y = (I - B)^{-1}AX, where A is lower triangular and B is strictly lower triangular.

This formulation does several useful things. First, attention appears as the special case B = 0: all influence is direct input-to-output mixing, with no explicit recurrent propagation through previous outputs. RNN/SSM-like models correspond to structured B, often with banded or subdiagonal patterns, plus constrained A. That reduces architectural differences to the structure of A and B rather than to surface-level implementation categories.

Second, the paper isolates recurrence order as an independent design axis. Standard RNNs and many SSMs are effectively first-order: the current state depends only on the immediate predecessor. Here, y_i may depend on multiple previous outputs, yielding higher-order recurrence. The motivation is straightforward: forcing all history through a single-step state update can bottleneck expressivity, while allowing multi-step dependence may recover richer memory behavior without paying full quadratic attention cost.

Third, the authors construct families of mixers by imposing structure on A and B. Different sparsity patterns and recurrence structures yield different complexity classes, from linear to near-linear, subquadratic, and quadratic. The intended message is that there is a broad middle ground between cheap but restrictive first-order recurrence and fully expressive but expensive dense attention.

Fourth, the framework supports both recurrent execution and parallel-solver views. Since Y = (I-B)^{-1}AX, one can exploit matrix structure for more parallel training-time computation instead of relying purely on token-by-token recurrence. That matters because many recurrence-based alternatives are attractive at inference but weak in training parallelism; the paper argues that structured B can soften that trade-off.

Relative to prior work, this is less a single new module than a unifying algebraic view plus a systematic exploration of higher-order recurrence inside that view.22:T6f3,The experiments are split between synthetic tasks and language-model pretraining. The synthetic side is mainly for mechanism validation: it tests long-range dependency handling, memory propagation, and the effect of recurrence order. The key qualitative result is that higher-order recurrence improves tasks that require information to propagate across multiple steps, suggesting that the added recurrence order buys real modeling capacity rather than only formal flexibility.

The language-model side uses small-to-medium pretraining setups to compare perplexity and efficiency across mixer designs. The emphasis is not on leaderboard-style claims, but on tracing a continuous performance/complexity frontier. Linear-complexity designs are cheapest but more limited; O(n log n) and O(n^{3/2}) constructions recover part of the gap toward attention; full quadratic designs remain the most flexible but also the most expensive. That empirical shape is central to the paper’s argument.

The most useful results are likely the ablations: changing recurrence order, bandwidth, sparsity pattern in B, and direct-connectivity structure in A, then measuring how quality and cost move. For architecture researchers, those ablations are more informative than the final headline numbers because they map directly to controllable design variables.

At the same time, the paper appears closer to proof-of-concept than to production-scale validation. It does not provide strong evidence that these mixers can replace Transformer attention in large frontier LLM pretraining. - Wake phase: the model runs normally with a limited KV cache plus SSM-style fast weights (e.g., GDN / Mamba-like outer-product or delta-rule updates).
- Sleep phase: the model stops consuming new tokens and performs N offline recurrent forward passes over the accumulated context. Across these passes, fast weights inside SSM blocks are updated recursively via a learned local update rule, effectively turning “memory writing” into an iterative computation.
- After consolidation, the KV cache is cleared and the model resumes wake-time prediction with updated fast weights; crucially, prediction remains single-pass (no looping at inference time).
Training is end-to-end: gradients are backpropagated through the sleep procedure to optimize post-sleep task performance. A standard SAE uses vector decoder atoms, which is appropriate for reconstructing residual activations. But in Gated DeltaNet-like models, the native per-token write is a rank-1 outer product k_t v_t^T into a matrix state S_t. One can still train an SAE on vec(S_t), but a generic vector atom does not correspond to a valid native write event. WriteSAE therefore constrains each decoder atom to factor as a rank-1 outer product v_i w_i^T, matching the architecture’s write shape. The model is trained as a TopK SAE on mean-centered state vectors with reconstruction loss plus a dead-feature revival term. This makes each atom interpretable as a cache-slot write primitive that can be swapped in for a native write.

The paper then builds three validation mechanisms. First is cache-slot substitution: replace one native write with a learned atom at matched Frobenius norm, continue the forward pass, and compare the resulting output KL against a matched-norm ablation baseline. If the atom beats ablation, it is doing more than simply deleting the write. Second is a closed-form logit-shift approximation. This is useful because it links a local recurrent-state intervention to final token logits using quantities observable from a single forward pass. Third are direct interventions—erase, install, and generation probes—to test whether the learned atoms can causally steer model behavior.
