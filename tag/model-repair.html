Where RL Breaks: Localizing and Repairing Failures via Targeted Continued Pretraining

这篇论文问的是：RLVR 在推理任务上失败时，基座模型到底缺了什么，能不能在重新做 RL 之前用很小的 continued pretraining 补上。它不是把失败归因于奖励函数或 RL 算法，而是把 RL rollout 中的失败位置局部化到一小批具有诊断性的 n-gram。核心观察是，某些短语或操作表达一旦出现在推理轨迹里，后续结果很可能失败；这些 n-gram 不一定是失败原因，更像是模型进入低恢复概率状态的可见信号。

评题目踩中 RL↔pretrain 闭环；优先看 failure localization 是否干净，若只是补数据修 benchmark 就降级。
Xinyi Wang,Danqi Chen

RESCUE: Repairing Language Model Errors to Sparse Circuits via Reinforcement Learning

这篇工作要解决的不是一般意义上的“提升任务分数”，而是一个更具体的问题：当大模型在某一类任务上反复犯错时，能不能把错误归因到一小撮可定位的内部计算单元，并且只改这部分参数，就把错误修掉，同时尽量不伤到别的能力。作者把问题从“能力电路”推进到“错误电路”：过去机制可解释性更多在找支撑正确行为的 sparse circuit，RESCUE 则假设失败同样来自局部、稀疏、可干预的错误计算路径。难点有两个。第一，错误不是一个静态标签，而是生成过程中的结果，单靠 teacher-forced 对齐很容易漏掉真正导致自由生成出错的内部单元。第二，即便找到了候选单元，如何证明它们对错误有因果作用，并把修复限制在这些单元上，而不是退化成普通微调。

评将 Mechanistic Interpretability 用于定位错误回路并用 RL 做局部修复，思路有趣，可作为 post-training 阶段精细化干预的参考。
Chuanpu Liu,Miao Yu,Yikai Cai,Yuanhe Zhang,Zhenhong Zhou,Li Sun,Zuming Jiang,Yufei Guo
