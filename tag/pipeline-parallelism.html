Demystifying Pipeline Parallelism: First Theory for PipeDream

PipeDream (PD) 是流水线模型并行的代表性方法，通过 1F1B 调度将多个微批次重叠执行以减少管道气泡，系统效率优势明确。但 PD 的优化行为一直缺乏理论分析——核心困难在于 PD 的确定性调度产生了结构化、依赖阶段的权重陈旧度，每个反向传播使用的是对应前向传播时缓存的阶段局部权重版本，跨阶段版本依赖关系复杂。论文解决的核心问题是：(1) 为 PD 提供首个非凸收敛性理论保证；(2) 从理论上解释 PD 随阶段数增加时扩展性变差的原因；(3) 对比 PD 与 LocalSGD 作为替代策略的优劣。

评对 PipeDream 这种 1F1B 风格的流水线并行给出了严谨的收敛性证明和延迟 scaling 分析，做分布式训练系统和优化器的研究员可以扫一眼结论。

Speculative Pipeline Decoding: Higher-Accruacy and Zero-Bubble Speculation via Pipeline Parallelism

这篇工作处理的是单序列低并发场景下 speculative decoding 的两个结构性瓶颈。第一，主流方法依赖 multi-token drafting，越往后预测越依赖草稿模型自己生成的浅层、未验证状态，误差会沿 draft length 累积，接受率快速下降。第二，draft 与 verify 往往仍有串行依赖，目标模型会等待草稿，或者草稿模块本身要串行生成多个 token，导致加速被 drafting latency 吃掉。作者想解决的不是再把 draft 头做得更强，而是换一个执行范式：把 target LLM 改成 pipeline 形式，让不同 token 同时处在不同深度，再只预测“下一个需要填进流水线的 token”，从而避免传统 speculative decoding 中 draft length 带来的长程衰减和等待开销。

评只看系统图和 speedup 假设；若硬件利用率和 acceptance rate 同时成立，单请求 serving 的 pipeline prior 要改。
