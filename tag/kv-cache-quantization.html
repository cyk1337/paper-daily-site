Output-Aware Rotation for INT2 KV-Cache Quantization

RoPE-Aware Bit Allocation for KV-Cache Quantization

这篇工作处理的是长上下文推理里一个很具体但常被粗糙处理的问题：RoPE 模型中的 key cache 量化，不应被看成普通向量压缩，而应被看成“对未来 attention logit 影响不同的频率块之间如何分配比特”的问题。现有低比特 KV-cache 方法大多把每个 key 当成平坦向量，优化重建误差；但在 RoPE 下，query-key logit 是按 2 维旋转频率块分解的，不同 block 对未来 logits 的敏感度并不一样。结果是，统一 bit allocation 会把预算浪费在低影响 block 上，同时压坏真正决定注意力分布的高能量 block，尤其在长上下文和推理任务上会出现性能塌陷。

评RoPE频率块特性是预训练架构设计的核心细节，重点看§3的块能量计算逻辑，可反哺预训练时的RoPE超参与维度分配。
