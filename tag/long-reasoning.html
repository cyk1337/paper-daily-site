PS-PPO: Prefix-Sampling PPO for Critic-Free RLHF

这篇工作解决的是 critic-free RLHF 在长推理轨迹上的一个实际瓶颈：像 GRPO、RLOO 这类方法虽然省掉了 critic，但通常把同一个 trajectory-level reward 广播到整条输出序列的所有 token 上，导致每次更新都要对完整轨迹做前向和反向，长链路推理时计算和显存开销都很高。作者的核心问题不是重新做 credit assignment，而是问：既然很多任务在中间前缀处就已经基本决定成败，是否可以只更新一段前缀，同时保持对原 critic-free broadcast update 的无偏近似。

评想做长 CoT 的 RLHF/RLVR，PS-PPO 的“随机截断+无偏校正”值得抄作业；但要盯紧 cutoff 分布是否引入高方差与偏置。
Doo Hwan Hwang,Kee-Eung Kim

Information-Aware KV Cache Compression for Long Reasoning

长上下文与长解码推理使 KV cache 成为推理阶段的主要内存/带宽瓶颈。现有 KV 压缩多用“最近窗口的注意力权重”估计 token 重要性，偏短视：它更像在回答“最近在看什么”，而不是“未来会不会用到什么”。论文要解决的是：如何用更前瞻的信号挑选应保留的 KV token，在相同 cache budget 下尽量不伤长推理能力。

评建议读分析图：高熵 token 影响远未来这个 prior 若稳，KV 策略不能只按 attention heavy hitter 做。

ZoomR: Memory Efficient Reasoning through Multi-Granularity Key Value Retrieval

长输出推理（长链式思考）会导致 Transformer 解码阶段 KV cache 随生成长度线性膨胀，带来两类瓶颈：GPU 显存占用过高（难以部署/批量推理）与注意力计算随缓存增长而变慢。现有 KV 优化多聚焦“长输入 prefill”，对“长输出 decoding”场景适配不足，动态淘汰类方法在复杂推理中易丢失长程关键信息而显著掉点。

评只需看解码期 KV 增长的 profiling 与多粒度检索的 ablation；若你做长 CoT 部署，它给了一个可落地的显存-正确率折中点。
David H. Yang,Yuxuan Zhu,Mohammad Mohammadi Amiri,Keerthiram Murugesan,Tejaswini Pedapati,Subhajit Chaudhury,Pin-Yu Chen
