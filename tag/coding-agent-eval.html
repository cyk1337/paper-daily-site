SWE-INTERACT: Reimagining SWE Benchmarks as User-Driven Long-Horizon Coding Sessions

这篇工作把 SWE 评测从“一次性给全需求、让 agent 自主实现”改成“用户逐步澄清需求、审查代码、要求修改”的长程交互会话。核心问题不是代码能力本身，而是 coding agent 能否在含糊初始指令下发现用户意图，并在多轮反馈中保持实现的一致性。

评对预训练研究员的价值在§3的任务设计与§5的失败模式分析，可反推长程推理与交互能力的训练信号缺口。

Verus-SpecGym: An Agentic Environment for Evaluating Specification Autoformalization

论文研究代码 Agent 能否把自然语言编程题准确转写成形式化规格，而不只是生成能通过验证器的代码和证明。核心难点是规格本身是否忠实表达用户意图：过弱会放过错误程序，过强会拒绝正确程序。

评读评估协议和错误案例；它提醒代码能力评测不能把 verifier acceptance 当成语义正确。

ProcBench: Evaluating Process-Level Defects and Control Preservation in LLM Coding Agents
