DropKV: Decoupling Residual-Output Perturbation for Near-Optimal KV-Cache Eviction

这篇工作处理的是长上下文推理里的一个很具体但很硬的系统问题：KV cache 随序列长度线性增长，已经成为推理内存和带宽瓶颈；而 cache eviction 虽然实用，但如果目标是最小化删掉若干 token 后对注意力输出的扰动，原问题是组合优化，通常是 NP-hard。现有方法要么只看 attention score，忽略 value 的作用；要么试图更精确地建模输出扰动，但策略复杂、近似不干净、实现上也不容易 kernelize。DropKV 试图把这个问题改写成一个可线性计算、可证明近似、还能高效落地的 per-token 打分问题。

评将 KV-Cache 驱逐的组合优化问题解耦为 per-token 评分，理论上有常数因子近似保证，且有高效的融合算子实现，值得关注其在长上下文推理中的实际加速效果。
