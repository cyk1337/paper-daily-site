9:T563,XMerge has two components. The first is cross-axis selection. Each block is scored along two axes: relative magnitude, which measures the size of the residual displacement, and Block-Influence, which measures directional change between input and output hidden states. The two scores are standardized across eligible layers and combined with a maximum. A block is considered quiet only when neither axis is large. This max rule is intentional: an average could hide a large angular change with a small magnitude score, or the reverse. The second component is reconstructive layer merging. Instead of dropping a layer, analytically folding weights, or adding a learned replacement module, XMerge distills the original adjacent two-block mapping into one existing standard Transformer block. For calibration inputs, it caches the pair input h_l and the original pair output h_{l+2}, then optimizes all parameters of the surviving block so that the single block maps h_l directly to h_{l+2}. After k merges, the result is an ordinary L-k-layer Transformer with no extra inference-time parameters, no task labels, and no end-to-end fine-tuning.
