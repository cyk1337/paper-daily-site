9:T521,The method defines a Bayesian model over hypotheses h.
- Representation: each hypothesis is a pair (natural-language description, Python implementation). Language provides a compressible, flexible concept description; code provides an executable semantics.
- Prior p(h): favors shorter NL descriptions (an Occam/MDL-like bias implemented in the language channel).
- Likelihood p(e_t|h): scores how well the program’s execution matches the observed evidence at time t.
- Inference: exact posterior p(h|e_{1:t}) is intractable, so they use LLM-augmented Sequential Monte Carlo (LLM-SMC-S). Maintain K particles; for each new observation, use an LLM prompt as a bottom-up proposal q(h_{t+1}|e_{1:t+1}, particles), then importance-weight by prior×likelihood and resample; optionally “revise” particles to better fit new evidence.
- Inquiry: because the particle set encodes posterior uncertainty, the agent can choose questions/experiments that best discriminate among particles (information-gain style), closing the induction–inquiry loop.

The probe term uses a small calibration set and measures cosine distance between reasoning-conditioned activations and generic activations, aiming to estimate how sensitive that tensor is to reasoning behavior. The two are mixed with a fixed alpha of 0.5. MRI is used as a soft prior, not a hard merge rule. Third is a low-dimensional adaptive merge genome optimized by evolutionary search. Rather than assigning an independent coefficient to every tensor, Darwin encodes block-level and component-level merge decisions in a 14-dimensional genome and searches that space without gradients. This keeps the search tractable while still allowing nonuniform recombination. Fourth is MRI-Trust Fusion. Instead of fully trusting diagnostics or fully trusting search, Darwin learns a trust parameter that fuses MRI-derived ratios with genome-derived ratios into final tensor-wise merge coefficients. The motivation is straightforward: diagnostics are biased, but unconstrained search is sample-inefficient and unstable. The paper also introduces an Architecture Mapper for heterogeneous parents. It establishes tensor correspondences using tensor type, shape compatibility, and depth alignment before numerical recombination. Stage 1 is Draft. Given a prompt p, the LLM generates a coarse visual draft d in the form of discrete vision tokens. This draft is not treated as the final image. It is a low-fidelity scene plan. The paper argues that this step is necessary because, without a concrete visual instance, later evaluation would collapse into generic prompt rewriting rather than grounded diagnosis.

Stage 2 is Evaluate. The same LLM takes the original prompt and the draft, compares them, and outputs a grounded evaluation e: a concise textual description of what is wrong or missing in the draft. This is the key move in the paper. The system exploits the empirical asymmetry that the unified model is better at post hoc diagnosis than at one-shot generation. Instead of asking the model to satisfy all constraints directly, it first asks it to create something inspectable and then to critique that object.

Stage 3 is Diffuse. A frozen SANA diffusion model is conditioned jointly on (p, d, e). The prompt provides the global semantic target, the draft provides a spatial anchor and scene layout, and the evaluation provides localized corrective instructions. The paper repeatedly argues that these signals are complementary: draft alone would preserve its own mistakes, evaluation alone without a visual anchor would reduce to prompt rewriting, and prompt alone returns to the standard text-conditioned diffusion setup.

Relative to prior work, this is not just prompt enhancement, because the evaluation is grounded in a specific visual draft. From a pretraining perspective, the method also encodes a practical division of labor: the LLM handles discrete planning and semantic verification, while diffusion handles high-fidelity rendering.
