DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training

这篇工作处理的是一个比常见 RLVR 更难的设定：长时程 agent 训练里没有可用的终局 verifier，训练时完全看不到 ground-truth success，只能依赖过程性 rubric 打分。在这种 outcome-blind 条件下，现有做法通常把一次轨迹的 rubric 分数压成单个标量，再均匀分给整条轨迹的所有 token 或步骤。问题在于，长轨迹里真正决定成败的步骤很少，很多步骤只是中性、冗余，甚至带有偶然性；统一赋分会把噪声扩散到整条轨迹，导致 credit assignment 很差。论文要解决的核心问题有两个：一是没有 verifier 时，如何构造足够贴合具体 rollout 的评价标准；二是有了 trajectory-level rubric verdict 之后，如何把它稳定、可解释地分配回具体步骤，形成可用于 GRPO 的细粒度优势信号。

在小规模开源模型上，仅依赖结果反馈（outcome-only）的强化学习（RL）用于长程交互式 Agent 任务时，常被认为存在性能天花板，导致现有研究转向使用密集奖励、SFT 预热或多智能体编排等复杂补偿机制。本文旨在证明该天花板并非 outcome-only RL 的固有缺陷，而是训练轨迹分布失真导致的假象。

评值得读训练动态部分；若结论成立，agent RL 的瓶颈更像覆盖率和漂移控制，不是 outcome reward 本身。
Liming Pu,Xiaoxia Li,Yifu Liu,Teng Cao,Bin Yang
