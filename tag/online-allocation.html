BOSS: Token-Budgeted Online Sampling and Selection for LLM Reasoning

这篇论文解决的是 test-time scaling 里一个常被回避、但在真实部署中很关键的问题：当单个样本有严格 token 上限时，额外预算到底该花在继续生成更多候选解，还是花在比较和裁决已经生成出的候选解上。过去很多方法要么只管多采样，要么在固定采样后再做 rerank/selection，但没有把“生成”和“裁决”放进同一个实时预算账本里统一决策。BOSS 研究的是 within-instance allocation，也就是对同一道题，预算如何在线分配给 generate / adjudicate / stop 三种动作。

评这不是 pretrain 论文，但它把 test-time compute 当可分配资源来做得很干净；读决策规则和同候选池对照，能直接启发 inference scaling 设计。
Yupeng Chang,Yahan Li,Chenlu Guo,Diana Inkpen,Yuan Wu,Yi Chang

AlloBench: Measuring Online Tool Allocation Capability in LLM Agents

LLM Agent 在面对任务流和有限工具创建预算时，是否具备有意识的工具分配能力——即判断何时值得为一类任务创建可复用工具，而非为每个任务一次性处理。现有评测只测「能否写出正确工具」或「能否从工具库中选对工具」，从未测量更基础的「何时应该创建工具」这一预算感知决策能力。

评只看任务设计和 failure-mode 表；它测的是抽象规划到工具构建的迁移断裂，比常规 tool-use 分数更有诊断性。
Daniel Wang,Andrew Xu
