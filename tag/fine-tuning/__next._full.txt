18:Ta30,实验覆盖语言、视觉、流体仿真和表格学习，重点不是刷统一 benchmark，而是验证这套分解、证书和检验是否真的可用。

1. 证书正确性：在 trained transformer、TabPFN、occupancy network、stereo network 上，作者一共得到 64 个可能证书中的 25 个，以及 96 个可能证书中的 36 个可触发案例；所有触发的 certificate 都与实测 winner 一致。这个结果说明上界虽然不总是足够紧，但一旦给出判断，方向是可靠的。

2. held-out 检验选择 context 还是 weights：在两个 OpenML 表格任务上，使用 128 行数据时，检验在所有 seed 中都选择 TabPFN 这类 in-context learner，而不是在同样 128 行数据上训练的 XGBoost。说明在小样本表格场景里，context 通道更有效。相反，在 airfoil pressure field 任务上，使用 128 个设计样本时，检验在所有 seed 中都选择训练好的 surrogate model 而不是 in-context learner；当样本降到 32 个设计时，3 个 seed 里有 2 个转而选择 in-context learner。这个结果很符合直觉：样本少时，临时读取更划算；样本多时，参数化归纳更占优。

3. 错误率控制：在没有真实 winner 的模拟流上，检验最多只在 3.3% 的流上错误地宣布一方更优，低于设定的 5% 水平。说明 anytime-valid test 不是只在静态离线数据上成立。

4. 上下文局部价值分析：occupancy network 中，真正观测到局部几何特征的 300 个点，对每个 query 可贡献 17.66 bits；而来自未变化几何区域、数量匹配的 300 个点只值 0.001 bits。stereo network 中，能看到目标表面的相机，其信息量约为看不到该表面的相机的 3 倍。这些结果说明该度量确实抓到了“证据是否相关”，而不是简单偏好更多 token。

5. context learning curve 的非单调性：在 occupancy network 里，一个真正覆盖目标特征的 patch 能把该特征位置的 code length 从 4.99 bits/site 降到 0.05；但 8 个没有覆盖该特征的 patch 反而把它升到 9.06。也就是说，更多 context 不一定更好，错误或无关证据会伤害预测。这个观察对长上下文训练和检索增强都很重要。

6. 证据预算与 verifier：在两个语言模型 verifier 上，作者用“claim 需要多少 bits、evidence 提供多少 bits”的比较恢复了 Trace Budget adjudicator，区分支持证据与不足证据的 AUROC 达到 0.91。这里虽然不是预训练实验，但对 reasoning verifier 和 evidence sufficiency 分析有直接启发。19:T8b0,The core result is an exact decomposition of expected code-length gain from memory. For both context memory and fine-tuned weights, the expected savings split into three terms: (1) information stored about the query, (2) a prior-repair term that corrects the model’s output prior even when the memory does not directly encode query-specific evidence, and (3) decoding loss, which measures how much predictive value is left unused by the decoder given the stored memory. This decomposition is the paper’s main contribution because it cleanly separates what is stored from how well the model reads it out.

On the context side, the value of a context subset is defined by deleting that subset and rerunning the model, yielding an exact leave-one-out valuation for held-out queries. This only requires predictive probabilities and the ability to rerun with partial context, so it applies beyond transformers to occupancy networks, stereo networks, kriging-style learners, and TabPFN-like in-context tabular models.

On the weight side, fine-tuning is treated as writing information into a bounded parameter state. The paper derives capacity-based ceilings for what such a state can save. The decision logic is asymmetric but useful: if measured context gain exceeds the ceiling of any weight state with a given capacity, context is certified as the better channel; if a fine-tuned model exceeds the ceiling of any window-limited context memory, weights are certified as better. A particularly interesting result is that when the relevant evidence fits in context, fine-tuning can add at most the context decoder’s decoding loss. In other words, parameter updates only buy what the context pathway failed to decode, not arbitrary extra information.

The paper also introduces an anytime-valid test for the practical case where exact information terms are unavailable. It accumulates held-out evidence sequentially and controls error at any stopping time. The appendix goes further and writes a transformer KV cache exactly as a form of weight write with query-dependent addressing, which strengthens the claim that context state and parameter memory can be analyzed in one framework rather than merely compared by analogy.1a:T95e,The experiments span language, vision, fluid dynamics, and tabular learning. The goal is not benchmark coverage but validation of the decomposition, certificates, and sequential test.

1. Certificate correctness: on a trained transformer, TabPFN, an occupancy network, and a stereo network, the paper reports 25 triggered certificates out of 64 possible cases in one setting and 36 out of 96 in another; every triggered certificate agrees with the empirically measured winner. The key detail is that SST projects the applied parameter update, not the raw gradient. That distinction matters because stateful optimizers such as Adam transform gradients through momentum and coordinate-wise rescaling; a projected gradient does not guarantee a projected final step. By acting on the actual update written into the weights, SST becomes optimizer-agnostic.

The projection is bilateral: it removes components aligned with principal singular directions on both the output side and the input side. This is stronger than a one-sided constraint and is meant to preserve the dominant mapping structure of the pretrained matrix. Conceptually, SST freezes the high-energy spectral structure and pushes adaptation into the tail subspace.

The paper also addresses a practical limitation of a fixed protected basis. If the SVD basis is computed once and never updated, the allowed complement can become too restrictive as training progresses.
