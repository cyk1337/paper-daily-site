a:T9fa,方法叫 TaNOS，由三个部件组成，而且三者各自对应一个失效来源。

第一是 operation sketches。作者不让模型从自然语言问题里自己完整恢复运算模板，而是显式提供一个最小化的运算草图，类似把“同比变化”“差值”“比例”“聚合后再比较”这类计算骨架抽出来，用抽象变量和操作符表示。关键点不在于给模型更多信息，而在于把本来会消耗容量的低层算术模板识别外显化，让模型把注意力放到表中实体定位、行列关系、条件筛选和变量绑定上。论文的立场很明确：这些草图在测试时并非额外 oracle，因为问题本身通常已经隐含了这种结构，只是作者把它显式化，减少模型在 trivial operation inference 上的浪费。

第二是 header anonymization。作者不是做全局统一替换，而是实例级、双射式的 header 映射。每张表的列名被映射成唯一占位 token，既保留同一表内的引用一致性，又切断跨样本的词汇共现统计。这样做比简单删除 header 更稳，因为结构关系还在；也比固定匿名词表更强，因为模型难以在不同样本间重新建立稳定的“某个匿名 token 常对应某类运算”的伪规律。这个设计很像在预训练里故意破坏 spurious lexical anchor，但保留局部结构可解性。

第三是 self-supervised learning，而且是 program-first 而不是 question-first。作者先从表中构造可执行程序，得到确定答案，再让 LLM 把程序和答案表达成自然语言问题。这样生成链路的约束方向与常见做法相反：不是先写问题再猜程序，而是先保证程序正确、答案可执行，再生成语言表述。好处是逻辑一致性高，训练样本可自动验证，减少“问题像真的、程序是错的”这类噪声。结合 operation sketches，模型在训练时看到的是表、匿名 header、问题、草图以及对应程序/答案，从而把监督集中到结构映射而不是词面联想。

从方法差异看，TaNOS 不是单纯的数据增强，也不是普通 CoT 提示。它更接近一种面向结构推理的中间表示工程：用 sketch 约束推理空间，用 anonymization 改变可利用统计规律，用 program-first SSL 提高监督纯度。和只做 SFT 的基线相比，核心区别是训练信号被重新组织了；和直接合成更多 QA 数据相比，核心区别是作者强调 correctness-guaranteed 的可执行监督，而不是规模优先。b:T831,实验围绕金融表格数值推理展开，主模型是 8B instruction-tuned LLM。论文给出的主结果有几个点。

一是全监督场景下，TaNOS 在 Financial TableQA benchmark 上达到 85.38% execution accuracy，明显高于 fully supervised baseline 的 73.97%。这个提升幅度已经说明它不是只靠多一点数据或 prompt 技巧，而是训练信号组织方式确实改变了泛化行为。

二是低资源场景下，只用 10% 标注数据，TaNOS 仍有 80.13% accuracy，依然超过全监督基线和文中比较的 API 模型。这个结果支持作者关于 SSL 能缓解逻辑监督稀缺的判断，也说明中间训练带来的收益不只是“有更多样本”，而是样本质量和结构偏置更合适。

三是跨域迁移。作者在多个金融数据集之间做 train-on-one, test-on-another 的迁移评估。引言里给了一个典型例子：在 FinQA 上训练的模型，域内 program accuracy 为 68.72%，迁移到 MultiHiertt 降到 43.74%，到 NumReason-500 降到 39.66%。TaNOS 的目标就是缩小这种 gap。论文声称在 domain-shift 实验中，TaNOS 的跨域性能差距只有约 2 个百分点，而普通 SFT 超过 10 个百分点，说明 header 依赖和模板记忆被明显削弱。

四是消融。虽然给出的全文片段没有完整表格，但从方法设计和文中叙述可以看出，三个组件是互补关系：operation sketches 主要改善复杂结构推理和数据效率；header anonymization 主要改善 header-shift 鲁棒性；SSL 主要带来低资源收益和更稳定的迁移。值得注意的是，这类方法若只有 anonymization 而没有 sketch，模型可能因为语义锚点减少而更难学；若只有 sketch 而没有 anonymization，模型仍可能把草图和原始 header 词汇绑定起来。作者强调的是组合效果，而不是单点技巧。

First, operation sketches. Instead of forcing the model to infer the full computational template from the natural-language question, the method provides a minimal symbolic sketch of the operation structure, such as ratio, difference, percentage change, or simple compositions of these. The point is not to inject heavy supervision, but to externalize low-level arithmetic structure so the model can spend more capacity on table grounding: row/column selection, entity binding, conditional filtering, and relational interpretation. The paper explicitly argues that these sketches are not unrealistic test-time oracles, because the question already implies the operation pattern; the sketch simply makes that structure explicit.

Second, header anonymization. This is not a global replacement scheme. It is an instance-level bijective mapping applied separately to each table. The design preserves within-table referential consistency while breaking cross-example lexical statistics. That matters: removing headers entirely would destroy useful structure, while using a fixed anonymization vocabulary could still let the model relearn stable pseudo-correlations. The per-instance mapping is a stronger way to suppress lexical memorization while keeping the task solvable through structure.

Third, self-supervised learning via a program-first pipeline. The authors reverse the usual generation order. They first construct executable programs over tables, obtain verified answers, and only then use an LLM to verbalize them into natural-language questions. This is a key design choice. In many synthetic pipelines, question-first generation leads to semantically plausible but logically inconsistent program annotations. Program-first generation keeps the supervision executable and correctness-guaranteed, which raises the purity of the training signal. During training, the model sees tables, anonymized headers, questions, sketches, and corresponding programs/answers, encouraging alignment between language and structure rather than language and lexical shortcuts.

Relative to prior work, TaNOS is not just data augmentation and not just prompting. It is a representation-and-objective redesign for structural reasoning.
