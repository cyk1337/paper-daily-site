A Temporal Reasoning Benchmarking Framework for LRMs via Difficulty-controlled and Dynamic Test Generation

TRACE 解决的是大推理模型 temporal reasoning 评测不可靠的问题。现有静态 benchmark 容易被数据污染，合成任务的难度控制通常较粗，且只看最终答案会掩盖错误推理。论文希望用可动态生成、难度可控、可验证推理过程的框架，测出模型在时间关系演绎上的边界。

评只看任务生成和 oracle 设计；它比又一套静态推理题干净，但与预训练改法还隔一层。
