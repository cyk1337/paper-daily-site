Co-LMLM: Continuous-Query Limited Memory Language Models

这篇工作解决的是：如何把“知识外置”的 LMLM 范式从依赖关系型 KB、依赖 Wikipedia 实体结构、依赖预先写死查询路径的设定，推进到更可扩展、更通用的预训练框架。Rel-LMLM 的关键问题有三层。第一，知识表示受限，只能外置成 subject-relation-object 一类关系片段，很多自由文本中的事实无法自然落到这种结构里。第二，检索表达受限，模型必须生成离散的自然语言查询，既增加推理时 token 开销，也把查询空间限制在人工定义的关系模板内。第三，训练监督过强地规定了“该怎么查”，预处理阶段直接合成查询文本，导致模型学到的是固定检索路径，而不是更灵活的查询表示。Co-LMLM 的目标就是保留 LMLM 的可编辑、可归因、可直接 unlearning 的优点，同时把查询改成连续向量，把 KB 改成 dense key + text value 的形式，让模型在预训练中联合学会语言建模和检索，而不是只学会复现预先指定的关系查询。

评应读方法和 ablation；它把“知识进参数还是进外存”做成预训练范式问题，值得内部小规模复现。
Yair Feldman,Linxi Zhao,Nathan Godey,Dongyoung Go,Yilun Hua,Kilian Q. Weinberger,Jennifer J. Sun,Yoav Artzi
