第二层是 dense-to-language interface，这是全文最关键的创新。模型先基于引用框或 referring prompt 确定对象区域，再在这些区域内对预测深度和 decoder feature 做 pooling，形成 object-aligned continuous geometry tokens，并且显式绑定 object identifier。这里的设计重点不是把整张深度图塞给 LLM，而是把“哪个对象对应哪段几何证据”编码清楚，避免多对象问题里对象-数值错配。

第三层是几何信息保持机制。作者注意到，仅靠最终答案监督，geometry token 在进入语言上下文后很容易失去可恢复的 metric content。因此加入 auxiliary depth objectives，在 context interaction 前后都要求能从这些 token 中恢复对象级深度；同时加入 ranking objective，监督对象间深度顺序。这个设计很像给跨模态 bottleneck 加了信息守恒约束：不是只要求最后答对，而是要求中间表示仍然保留可读出的几何量。

First is the Level-0 dense metric depth branch. The model uses a coarse-to-fine DPT-style decoder that fuses intermediate vision features with the final visual hidden states to predict full-resolution metric depth. To recover absolute scale, camera intrinsics are explicitly encoded into normalized calibration, field-of-view, and aspect-ratio descriptors, then mapped through an MLP into FiLM parameters that modulate every decoder scale. This is more targeted than simply appending camera values to language tokens, because the dense branch needs direct metric calibration. A high-resolution RGB refinement pathway is added to recover thin structures, sharp boundaries, and local detail that compressed visual tokens tend to lose.

Second is the dense-to-language interface, which is the central idea of the paper. Given object boxes or referring prompts, the model pools predicted depths and decoder features over each referenced region, producing object-aligned continuous geometry tokens tied to explicit object identifiers. The point is not to feed a whole depth map into the language model, but to preserve the mapping between object references and their geometric evidence.

Third is geometry preservation. The authors argue that answer supervision alone is too weak: once geometry tokens interact with the language context, their metric content can degrade. To prevent this, they add auxiliary depth objectives that require object-level depth to remain recoverable both before and after contextualization, plus a ranking loss that supervises relative depth ordering across objects. This effectively imposes an information-preservation constraint on the multimodal bottleneck.

Fourth is instance-level instruction tuning and cached continuation. The geometry tokens are injected into answer generation together with the question, while cached continuation avoids repeatedly re-encoding the image and prompt. Training covers both instance-level measurement and compositional reasoning, so the model learns not only to estimate depth values but also to use them in interval filtering, thresholding, and relational decisions.

Compared with prior work, DepthLM absorbs depth prediction into language modeling but does not provide an explicit object-grounded evidence interface.
