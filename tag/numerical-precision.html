From Expert Reduction to Behavioral Divergence: Tracing Numerical State through Sparse MoE Inference

这篇论文研究的是稀疏 MoE 推理中的一个容易被低估的问题：在专家输出加权求和时，数学上等价的 reduction 顺序，在有限精度实现里并不等价。这个差异不是只停留在最后几位数值误差上。对动态 MoE 解码器来说，小的 hidden state 扰动可能先改变后续 router 的 top-k 选择，再改变 greedy decoding 的下一个 token；即使当前 token 仍然相同，扰动也可能写入 KV/cache 等持久状态，在后续 decode step 延迟触发输出分叉。论文的核心问题是：专家聚合的数值语义是否已经成为 MoE 模型执行语义的一部分，以及应该如何定位、复现和验收这种差异。

评生产MoE上精确隔离浮点reduction顺序对路由/输出的放大效应，C方案bitwise复现是硬结果，立即纳入内部MoE精度ablation。

Stage-Replay Divergence Follows the KV Cache: Fixed-Prefix Precision Controls and Bidirectional Cache Transplantation

这篇论文检查一个常被默认接受的诊断假设：把中间 token prefix 重新 prefill 一遍，是否等价于从原始 autoregressive decode 到达该 prefix 时的 live KV cache 继续生成。作者在一个 Qwen2.5-derived 系统中发现，在 BF16 下，两者可以消费完全相同的 token prefix，却产生不同后续轨迹。

评KV cache构造方式+BF16精度会导致显著输出分歧，做后训练蒸馏/对齐时必须统一推理精度配置，重点看FP32对照实验与缓存移植方法

P-Cast Precision in FP8 Attention: Sink-Induced Collapse and the Optimality of S=2^8

该工作分析 FP8 attention 中把 softmax 概率矩阵 P cast 到 E4M3 时的精度失效：attention sink 会让前向 KV block 迭代中的大量非 sink 概率下溢为 0，而 P 的静态缩放因子决定失效阈值。

评对FP8 attention实现有直接工程指导价值，结论清晰且有构造性证明；做推理引擎或训练优化时应检查是否采用反向迭代+S=256配置。
