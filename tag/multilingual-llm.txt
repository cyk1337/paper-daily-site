The authors add 25,600 Hindi tokens from the Nanda tokenizer. On 100,000 Sangraha Hindi documents, this reduces Hindi fertility from 1.95 to 1.25 tokens per word.

They compare more than 20 initialization configurations. The design space includes vocabulary averaging baselines, external or learned methods such as FOCUS, top-k semantic retrieval and residual MLP mappings, subword composition, norm calibration, and asymmetric initialization for input embeddings versus the output projection.

The strongest family is subword composition. A new token is tokenized by the old tokenizer, and its vector is initialized from a weighted average of the constituent old-token embeddings. This directly reuses the pretrained embedding geometry, which appears more reliable than projecting from an external semantic space. The best reported configuration uses uniform subword averaging with Hindi-specific norm calibration for the input embedding, and character-length-weighted subword averaging for the output head. A MuRIL-BERT semantic input weighting paired with character-length output weighting performs nearly the same, suggesting that external semantic information can help on the input side but is not the main driver.18:T5b9,1) Formalization:
- Define the set of valid tokenizations T(x) for a string x, including the canonical tokenization T_canon(x).
- Define tokenization invariance as identical model behavior for any t1,t2∈T(x), and quantify deviation via a distance d (performance gap or representation difference).

2) Non-canonical tokenization generation:
- Construct alternative token sequences composed of valid vocabulary tokens that decode to the exact same surface string, isolating distribution shift purely in token segmentation.

3) Evaluation protocol:
- A multilingual sweep over 27 languages spanning diverse scripts, 6 downstream tasks, and 3 recent model families.
- Importantly includes non-generation semantic tasks (e.g., cross-lingual sentence retrieval using embeddings), to test whether the effect is representational rather than just decoding fluency.

4) Mechanistic analysis:
- Emphasizes token fragmentation as a key explanatory factor: languages that are more fragmented under a shared multilingual vocabulary are more exposed to out-of-distribution segmentations; longer sequences and rarer subpieces can amplify sensitivity.

5) Training implication:
- Treat non-canonical tokenizations as augmentation: sample multiple valid segmentations for the same string during training to encourage invariance. (1) Neuron-level steering: Following a LAPE-style selection (Tang et al., 2024), the method computes per-dialect activation probabilities for each MLP neuron (ReLU-on frequency) and measures selectivity via the entropy of the normalized across-dialect activation distribution (low entropy = selective). Neurons are selected if they are highly active for at least one dialect (top n%) and highly selective (bottom m% LAPE). During decoding, activations of target-dialect neurons are multiplicatively amplified (α), while MSA-associated neurons are suppressed (γ), optionally also suppressing competitor dialect neurons (γ_comp).

(2) Distributed direction steering: A dialect direction is extracted from contrastive dialect–MSA pairs in activation/residual space, then injected during inference to bias generation. This targets a global, distributed representation rather than a small neuron subset.

The work treats unlearning methods (continued fine-tuning style) as the object of study; the novelty is in multilingual transfer characterization and reversibility evidence, not a new unlearning algorithm.22:Ta2e,The analysis has three layers: logit-lens observation, representational probing, and mechanistic localization.

First, the authors use the logit lens to inspect intermediate next-token distributions during transliteration. They find that when the model is producing a non-Latin output, middle-to-upper layers often transiently predict romanized subwords before committing to the final script. In other words, the model often does not move directly from source script to target script. It appears to pass through an intermediate representation aligned with Latinized forms. The paper turns this into a quantitative phenomenon, latent romanization, and studies it across scripts and models rather than relying on a single anecdotal example.

Second, the paper analyzes representations of the same language written in different scripts. Script identity becomes increasingly linearly separable in deeper layers. Based on this, the authors construct simple linear steering directions that flip the output script while largely preserving semantic content. Two points matter here. One is that script choice can be manipulated with a low-complexity linear intervention, suggesting that script identity is explicitly encoded in later layers. The other is a strong directional asymmetry: steering toward non-Latin scripts is more reliable than steering toward Latin. This supports the paper’s main hypothesis that Latin is not a compact target cluster but a more diffuse representational region.

Third, the authors localize a small set of late-layer attention heads that causally mediate script generation. With activation patching on only a few heads, they can redirect the output script on natural prompts, and the same heads transfer across unrelated languages and writing systems. This suggests that script choice is not uniformly distributed across the network. Instead, part of it is concentrated in a small number of routing components in later layers. The asymmetry appears again at the mechanistic level: non-Latin generation depends on compact, identifiable mechanisms, whereas Latin generation is more distributed and harder to control through a small intervention.

From a pretraining perspective, the paper is effectively arguing for a joint effect of data frequency, tokenization convenience, and representational sharing. Latin script is more common in pretraining corpora and often easier for tokenizers to encode cleanly, so it becomes a natural shared substrate. Non-Latin scripts then require additional late-stage routing to write the shared semantic content back into a specific surface form.23:T783,A representative qualitative example uses Llama-2-13B to visualize transliteration from Malayalam to Devanagari. The model choice is deliberate: its tokenizer makes Devanagari visually legible in logit-lens plots, whereas more byte-fragmented tokenizers such as Llama-3 obscure the transition. That detail is informative on its own, because it shows how tokenization affects the observability of internal mechanisms.

The main empirical findings come in several forms. First, quantitative logit-lens analysis supports latent romanization: romanized pieces of the target word appear in intermediate layers before the final target script emerges. Second, representations of the same language in different scripts become more separable in deeper layers, implying that script identity is not fully disentangled from the start but is progressively made explicit later in the network. Third, linear steering can reliably flip output script while preserving meaning to a large extent, and the steering directions transfer to unseen languages and writing systems. However, the transfer is asymmetric: moving toward non-Latin scripts is easier than moving back toward Latin.
