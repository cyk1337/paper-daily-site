18:T41a,EasyProver separates proof search, Lean interaction, and final proof validation. Each task fixes a Lean 4 environment and a frozen theorem signature; only the proof body can change. The system uses the off-the-shelf Anthropic Fable-5 model with no fine-tuning and no separately trained policy or value model. Agents can inspect proof states, run sandboxed shell commands, retrieve premises, probe tactics in parallel, and spawn recursive child agents. Child agents receive isolated contexts and private project copies, so they can explore auxiliary lemmas or alternative strategies without polluting the parent’s context with failed attempts. Final acceptance is handled by Lean Comparator, which rechecks the generated file with lake env lean and #print axioms under a shared read-only toolchain. Aegis turns competitive programming problems into verification tasks by generating safe Rust implementations, translating them into Lean with Aeneas, generating specifications, and labeling frozen statements with kernel-checked proofs or refutations.19:T6af,The work has two main components. The first is the benchmark. The authors build two synthetic fine-tuning tasks, atomic function bindings and compositional routing rules. A pretrained LM is then fine-tuned on datasets containing only fictitious facts, so the supporting fine-tuning documents are the only possible source of the target knowledge. This gives unambiguous attribution ground truth. They then vary one axis at a time: how many documents repeat the same fact, how many total facts are present, whether lexical distractors are added, and related dataset properties.

The second component is algorithmic diagnosis. Token-level attribution analysis shows that causal evidence inside a document is concentrated in a small number of tokens. Standard methods often average or sum scores over the whole document, which dilutes the signal with irrelevant background text. The paper studies two underexplored design choices. First, it replaces cross-entropy with token-level negative log-odds. The motivation is that cross-entropy gradients vanish when the target token is already predicted with high confidence, hiding the most informative evidence. Negative log-odds removes this confidence suppression and surfaces the relevant tokens more clearly. Second, instead of aggregating over all tokens, the method scores a document using only the top-k token attributions. This explicitly matches the empirical observation that evidence is sparse and localized.

Importantly, these changes are tested across multiple gradient-based attribution methods, including TRAK, EK-FAC, and Grad-Dot. The contribution is therefore about a shared bottleneck in the attribution pipeline, not a narrow tweak to one estimator.1a:T552,The main empirical result is the dilution phenomenon. As fact redundancy increases or lexical distractors become more prominent, fact-tracing recall drops sharply across attribution methods and dataset settings. This is a systematic failure mode rather than benchmark noise. Once the authors switch to token-level negative log-odds and top-k token aggregation, recall improves by 35 to 72 percentage points across multiple methods and controlled settings. That is a large gain, and it strongly suggests that the dominant problem lies in signal extraction and aggregation rather than only in second-order approximation quality.

The paper also checks whether the finding transfers beyond the synthetic setup. On FTRACE-TREX, using counterfactual retraining performance as the external criterion, token-level negative log-odds improves TRAK, EK-FAC, and Grad-Dot by up to 4.9x. This matters because it shows the benchmark is not merely producing synthetic artifacts; it is exposing a failure mode that also appears in more realistic fact-tracing settings.

The ablations are especially useful. Instead of only comparing method A versus method B, the paper decomposes the pipeline into loss choice, token scoring, and document aggregation.
