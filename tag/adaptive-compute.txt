18:T89e,方法核心是 Sep-Latent。整体训练是一个从显式 CoT 逐步过渡到隐式推理的 curriculum。作者观察到分隔符 token，例如换行、逗号、句号，在注意力里天然容易成为结构汇聚点，于是把它们当作 semantic anchors。

第一部分是 Attention-Decay。做法是在显式 CoT 路径中，对非分隔符的 step tokens 施加逐步增强的 attention suppression。直观上，模型原本可以直接在每个推理词上保留和传播信息；加入 decay 后，这些普通 token 的可访问信息通路被压窄，模型被迫把关键语义压缩到相邻的 separator hidden states 上。这样，separator 不再只是标点，而变成承载步骤摘要的 latent carrier。这个设计和直接引入额外 latent token 不同，它复用了原始词表中的结构 token，因此不需要额外定义固定长度的隐变量槽位。

第二部分是 dual-path distillation。论文同时保留显式路径和隐式学生路径，并在 token-level 与 sequence-level 做多层蒸馏对齐。显式路径提供可监督的 CoT 轨迹，隐式路径学习用更少的 latent anchors 复现这些推理状态。作者强调 online-policy distillation，即蒸馏对象来自模型自身当前策略生成的 latent trajectory，而不是完全离线的教师缓存。这一设计据称能降低训练内存开销，也让学生更贴近推理时真实会走到的状态分布。

第三部分是 Dynamic Implicit Exit。模型学习一个退出信号，根据当前问题复杂度和内部推理状态决定何时停止 latent reasoning 并输出答案。相比固定 latent 步数，这让简单问题可以更早结束，复杂问题保留更深的内部计算。

从建模角度看，这篇工作的关键不是提出新的 backbone，而是把“结构 token + 注意力约束 + 双路径蒸馏 + 动态退出”组合成一个隐式推理训练框架。它与 Coconut/CODI 的主要区别在于：latent 容量不再由固定数量的专用 latent token 决定，而是由输入中自然出现的 separator 及其压缩后的表示来承载；同时用 attention-decay 主动塑造信息流，而不是只靠蒸馏目标被动学到压缩。19:T77e,Sep-Latent is a curriculum that transitions from explicit CoT to implicit reasoning. The central observation is that separator tokens such as newlines, commas, and periods already act as structural aggregation points in attention. The method amplifies that tendency and turns those tokens into semantic anchors.

The first component is Attention-Decay. During training on the explicit reasoning path, the model progressively suppresses attention to non-separator step tokens. This narrows the information pathways through ordinary reasoning words and forces the model to route and compress useful intermediate information into the hidden states of separator tokens. In effect, separators become compact carriers of step-level reasoning summaries. This differs from methods that introduce a fixed number of dedicated latent tokens: Sep-Latent reuses natural vocabulary items and lets the compression structure emerge around them.

The second component is dual-path distillation. An explicit path with textual CoT is kept as a supervised reference, while an implicit student path learns to reproduce the reasoning trajectory using compressed latent anchors. Distillation is applied at both token and sequence levels. The paper further uses online-policy distillation, meaning the model distills from its own current latent trajectories rather than only from an offline teacher cache. The claimed benefit is lower memory cost and better alignment with the states encountered at inference time.

The third component is Dynamic Implicit Exit. The model predicts when to stop latent reasoning based on the current internal state and the difficulty of the query, instead of consuming a fixed latent budget for every example.

The novelty is therefore not a new backbone, but a training framework that combines structural-token anchoring, constrained information flow, explicit-to-implicit distillation, and adaptive stopping.1a:T461,The evaluation covers math and commonsense reasoning benchmarks. The headline number in the provided text is 56.8% on GSM8K using only 5.4 tokens on average, with more than 2x better token efficiency than CODI and SIM-CODI. The paper’s claim is not that it reaches the highest absolute reasoning accuracy, but that it preserves competitive performance with much shorter reasoning traces.

Several supporting observations are reported. Attention-Decay is said to compress reasoning into separator anchors with negligible loss in perplexity and base accuracy. PCA visualizations suggest that the latent representations remain semantically diverse rather than collapsing into a narrow region, and that they stay grounded in the vocabulary space. Dynamic exit allows the amount of implicit computation to vary with task complexity.

From a foundation-model perspective, the experiments are more of a proof of concept than a scaling study. The paper demonstrates feasibility and efficiency gains, but it does not yet establish how robust the method is across larger models, different tokenizers, or broader training regimes.1b:T515,For each output position, the model runs an internal decision process over a hidden state h, a fast-weight memory M, and a counter of Think steps. The latent policy chooses among Think, Recall, and Exit. Think applies a shared Transformer block again, increasing effective depth without adding new block parameters, and writes the resulting state into memory. Recall reads from the same memory and injects the retrieved representation into the current hidden state. Exit stops the inner loop and emits the next token through the language-model head. This differs from external-memory agents, where memory is usually read back as text or context, and from looped latent-reasoning models, where the loop has no native memory read action.
