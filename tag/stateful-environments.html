OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution

OpenART 解决的是 agent 安全评测中的“环境持久化”问题。传统评测多看单轮提示、短任务或可重置环境，但真实 agent 会反复读写同一工作区、记忆、工具状态和权限配置。早期看似无害的状态修改，可能在几十步之后触发安全失败。OpenART 把评测单元从单个 prompt 转到可执行、可演化的环境。

评值得扫方法和任务统计；它提醒 agent eval 不能只看单轮成功率，状态污染会改变风险曲线。

Echoverse: Deep, Evolving Environments for Training Computer-Use Agents at Scale

计算机操作 Agent 的训练依赖可交互、可重置、可评分的真实状态环境，但高价值应用（邮箱、聊天、银行、云控制台）均为登录态、有状态且无法直接训练；现有合成环境流水线解决了数量问题，但环境内部的行为深度、对模型真实失败点的针对性、以及环境与模型共同进化的机制仍缺失，浅层环境甚至会损害训练效果。

评Agent训练环境的范式性尝试，协同进化循环的设计对合成训练数据的质量迭代有参考，重点看§4的环境评分与进化触发机制。
