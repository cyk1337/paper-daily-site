Local proxies for memory-efficient training

这篇工作处理的是一个很具体、也很基础的问题：能不能在 Transformer 上用“局部学习”替代标准端到端反向传播，同时把显存占用显著降下来，而精度不要掉得太多。标准 backprop 的瓶颈不只是算力，更是 activation 必须跨整网保存到反传结束，这让深层模型、长序列和大 batch 都直接受限。已有 local learning 方法往往用局部辅助损失训练每一层或每一块，但这些局部目标和全局任务梯度之间缺少严格对应，所以一旦网络变深，误差会快速累积。作者要解决的核心不是再设计一个经验上可用的 local loss，而是构造一种有明确梯度近似含义的局部替代：每个 block 只看本地激活，通过一个 proxy 去预测全局输出，再用 proxy 内部反传来近似真实的全局梯度。

评探讨用局部代理网络替代全局 BP 以节省显存，理论分析有意思（残差连接下的误差界），但目前只在 CIFAR-100 的 ViT 上验证，离 LLM 预训练的 scale 还有距离，可关注其理论推导。
Wu S. Zihan,Brian A. Yuan,Guillaume Bellec

1% of Tokens Can Be Enough: On Gradient Estimation in On-Policy Distillation

这篇论文解决 sparse on-policy distillation 里的一个被低估的问题：一个 token 位置即使有用，也未必适合用单个 sampled next token 来估计 reverse-KL 梯度。稀疏监督只保留很少 token 时，token 的“有用性”和“梯度估计可靠性”需要分开判断。

评对 on-policy 蒸馏（如 RLHF/DPO 变体）中 token 级别的梯度方差做了很好的理论刻画，提出的 IER 指标在极低计算预算下效果惊人，做 RL 数据合成或高效对齐的同学必读。
Huanxin Sheng,Zhiling Ye,Haonan Wang,Jian Wang,Jinjie Gu,Jian Kang

RL2ML: Finite-Rollout Surrogate Objectives from Reinforcement Learning to Maximum Likelihood

这篇论文解决的是 correctness-based RLVR 里一个很具体但常被混在一起的问题：我们到底在优化什么目标，以及在有限 rollout 预算下，实际用到的随机梯度更新又对应什么目标。已有工作如 MaxRL 说明 RLVR 与 maximum likelihood 有联系，但大多讨论停留在大样本或一阶近似层面。RL2ML 关心的是更实际的设定：每个 prompt 只能采有限个 rollout，训练步数也有限，这时“更像 ML”未必自动更好。作者要做的是构造一族有限 rollout 下仍然与目标严格对齐的 surrogate objective，并用一个连续参数 γ 去控制从普通 RL、到 ML、再到超出 ML 的低成功率 prompt 放大。

评应把 group-level update scale 加进 RLVR ablation；它提醒你别用 population objective 解释有限 rollout 更新。
Yifu Zheng
