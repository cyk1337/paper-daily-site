具体做法分三步。第一步，每个 layer、每个 KV head 选出 k 个 anchor 位置，这些 anchor 的 key 和 value 精确存储。文中强调 recency window 会被并入 anchor 预算，也就是最近一段 token 默认保真，这符合长上下文推理里“近邻依赖强、最近 token 更敏感”的经验。

第二步，对每个非 anchor token，分别在 K 和 V 空间里找到最相近的 anchor，用该 anchor 的方向做一维投影。于是一个原本 D 维向量，被压成“anchor index + scalar coefficient”。这一步不是把 token 聚成簇后共享同一个向量，而是共享方向、保留幅度，因此比纯聚类中心替代更细一些。K 和 V 共享 anchor 位置，但 assignment、投影系数、residual 集合分别独立，这个设计是合理的，因为 key 影响匹配分数，value 影响读出内容，两者误差敏感性不同。

第三步，在总字节预算固定的情况下，只给一部分位置额外存储 residual。residual 先做 randomized Hadamard transform，把能量打散，降低少数坐标异常值对 2-bit 量化的伤害；再按 token 做 absmax 归一化，用面向高斯源的四级 Lloyd-Max codebook 量化，坐标 2 bit 存储。更关键的是 residual 不是平均分配，而是按“恢复 attention output error 的收益”来选位置，并且同一层内各 head 竞争共享 residual 预算。这说明作者优化目标不是向量级 MSE，而是更贴近最终注意力输出的误差。

从方法取舍看，AnchorKV 刻意避开了两类复杂性。它不做 decode-time 动态检索，因此没有 host-device fetch 的调度开销；也不改 attention kernel 主体，因此部署路径比 retrieval/offloading 类方案短。代价是压缩质量高度依赖 prefill 结束时对整段 cache 的一次性分析，以及 anchor 选择和 residual 分配策略是否足够稳健。10:T7c9,The method compresses the KV cache once, at the end of prefill, without changing model weights or the decode-time attention formula.

The representation has three parts. First, for each layer and KV head, the method selects k anchor positions and stores their keys and values exactly. The anchor budget includes a recency window, so recent tokens are preserved with high fidelity by construction.

Second, every non-anchor token is approximated separately in K-space and V-space by projecting it onto the direction of its closest anchor. This turns a D-dimensional vector into an anchor index plus a scalar coefficient. It is more expressive than replacing tokens with a shared centroid, because magnitude remains token-specific even when direction is shared. Keys and values share anchor positions, but assignments, projection coefficients, and residual sets are separate, which makes sense because K and V affect attention in different ways.

Third, only a subset of positions receives an additional stored residual under a fixed byte budget. Residuals are rotated with a randomized Hadamard transform to spread energy and reduce outlier sensitivity, then quantized at 2 bits per coordinate using per-token absmax scaling and a four-level Lloyd-Max codebook. The important part is not just the codec: residuals are allocated according to how much they reduce attention-output error, not according to generic reconstruction loss. Residual budget is shared across heads within a layer, so heads compete for bytes where they matter most.

A notable design choice is what the method avoids. It does not rely on decode-time retrieval from host memory, so there is no fetch scheduling in the critical path. It also leaves the attention arithmetic intact, which shortens the deployment path relative to more invasive kernel or retrieval schemes. In standard end-to-end evaluation, compression affects both the generation of the reasoning trace and the later use of that trace, so it is hard to tell whether failure comes from not producing the right reasoning or from not being able to use already-produced reasoning. The authors decouple these factors. First, a Full-KV model generates a complete reasoning trace without compression. Then each compression method is evaluated by prefilling the same question and the same textual trace, protecting the question cache, compressing only the KV states corresponding to the reasoning trace, and resuming decoding immediately after the closing reasoning tag. This means every method sees identical reasoning content in text form; differences reflect whether the compressed KV representation still lets the model use that content effectively.

On top of this protocol, the paper evaluates three metrics. The first is standard final-answer accuracy. The second is answer–chain consistency, which measures whether the final answer remains aligned with the visible reasoning chain. The third is perturbation faithfulness, which probes whether the compressed model responds appropriately when intermediate reasoning content is perturbed in controlled ways. The authors are careful not to claim that KV states physically decompose into separate “answer” and “evidence” components; the distinction is behavioral rather than mechanistic.

Instead of minimizing only ||W - W_hat||, the method minimizes a layerwise objective of the form ||(W - W_hat - BA)X||. This changes the problem in two important ways.

First, it becomes activation-aware. Errors are weighted by their actual effect on layer outputs under calibration inputs, rather than by raw weight discrepancy. This directly targets a weakness of weight-only approaches: some large weight errors barely matter functionally, while small errors along high-energy activation directions can be very damaging.

Second, the method explicitly separates correctable and uncorrectable quantization noise. The outer optimization over W_hat is encouraged to place dominant error components inside a low-rank subspace, while the inner optimization over BA captures the best local correction within that subspace. Intuitively, one step estimates the best low-rank corrective subspace for the current quantized layer, and the other performs quantization under a projection constraint so that the residual error is pushed toward that subspace.
