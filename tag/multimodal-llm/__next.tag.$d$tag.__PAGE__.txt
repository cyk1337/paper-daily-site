9:T72d,LongVU-TTT inserts a TTT-Conv resampler between a pretrained ViT encoder and the LLM. The input to this stage is a per-frame spatial grid of visual features, preserving a 27x27 token layout instead of flattening everything into a 1D sequence upfront. The method has three main ingredients. First, the fast-weight parameterization is convolutional rather than MLP-based. Unlike TTT-MLP or SSM-style operators such as Mamba that process flattened sequences, the hidden state here is represented by two grouped convolution kernels, W1 and W2, which together define a time-varying convolutional mapping over the 2D feature grid. Grouping partitions channels into subsets, allowing specialization while keeping the update efficient. Second, the module uses causal inner-loop updates. For each frame, lightweight heads produce keys, values, queries, per-group learning-rate gates, and momentum coefficients. These signals drive gradient-style updates to the fast weights, and the updated convolutional mapping contextualizes the current stream using only preceding history. The causality claim is specifically about update ordering: each frame can only depend on accumulated past state, not future frames. Third, the model uses a hybrid frame selector. Instead of training an auxiliary scoring network, it derives change-aware importance directly from the inner-loop training signals, combining gradient-direction shifts and alignment-loss deltas with uniform sampling. This is meant to preserve both scene transitions and within-scene changes under a fixed frame budget. TokenSwap-Bench is built on top of MMLU. The construction has three main stages. First, Gemini-2.0-Flash is used to identify concepts in questions and answer options that can be visually grounded. Second, each concept is turned into an image with a text-to-image model. Third, the benchmark applies several filters to ensure that measured gaps are not artifacts of poor substitutions. The important filters are:
1. Faithfulness verification: the generated image must correctly represent the intended concept in context.
2. Task relevance verification: if removing the replaced concepts from the original text does not affect prediction, the sample is not useful for measuring a meaningful gap and is filtered out.
3. Semantic recoverability: the substituted image is captioned and the caption is inserted back into text form to check whether the original semantics can be recovered.

The training-side intervention is data-centric rather than architectural. The authors augment training with image-interleaved counterparts of text data, and they test this both in pre-training and post-training settings. The intuition is simple and plausible: repeated exposure to semantically matched text and image realizations should force the model to learn more stable cross-modal representations and more consistent reasoning under token-type substitution.
