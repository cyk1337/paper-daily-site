The Kinetics of Training: A Driven-Nucleation Rate Law for Emergence, Plasticity Loss, and Circuit Control in Language Models

Inherited Circuits, Learned Semantics: How Fine-Tuning Creates Evasion Vulnerabilities Invisible to Standard Evaluation

这篇工作研究的是一个很具体、但对安全场景很麻烦的问题：同一个基座模型在安全分类任务上经过微调后，表面上的标准测试集准确率会提升，但模型可能同时学到一套对“规范写法”过度依赖的判别语义，导致它在语义不变、行为不变、只是写法被改写的脚本上出现系统性漏检。作者关心的不是一般意义上的分布外鲁棒性，而是微调本身是否把原模型内部已有的判别回路重新加权，变成一种对指示 token 敏感、对变形脆弱的分类器。更具体地说，在 PowerShell 恶意脚本检测里，像 Invoke-WebRequest、Invoke-Expression 这类命令家族既是语义线索，也是攻击者最容易做别名替换、字符串重构、大小写扰动的部位。论文要解决的是：能不能在部署前、不先枚举大量逃逸样本的情况下，仅凭规范输入上的内部表征变化，提前发现哪些命令家族已经成为高风险逃逸面。

评只看§4因果干预实验，微调复用预训练电路而非新建的结论，为后训练安全与电路复用假设提供干净证据

Mechanistic origins of catastrophic forgetting: why RL preserves circuits better than SFT?

这篇工作想解释一个具体现象：为什么在同一类能力迁移或领域适配中，RL 往往比 SFT 更少遗忘原模型能力。它不只看 benchmark 分数和 KL drift，而是把问题推进到 attention head 级别，检查 fine-tuning 是否破坏了原模型中支撑能力的内部 circuit。

What Happens Inside Agent Memory? Circuit Analysis from Emergence to Diagnosis

Agent memory 的 write–manage–read 三段式外部流程很清晰，但失败往往是“沉默的”：模型输出流畅，却在抽取、路由、或 grounding 上出错。论文要解决的是：这些阶段在模型内部是否对应可分离、可追踪的计算电路（circuits）？这些电路如何随模型规模涌现？能否据此把端到端错误定位到具体阶段，从而做诊断而不是只看一个总分？

评揭示了小模型在 Agent 任务中'看似懂路由但实则无法提取内容'的机制原因，对设计小参数量 Agent 模型有直接启发，重点看控制/内容回路的涌现规模差异。
