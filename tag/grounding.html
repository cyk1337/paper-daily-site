评这篇真正值得看的点不是视频，而是它把自进化监督的核心从“更难”改成“更有证据”；只看问题生成与 grounding ablation 就够了。

Video2GUI: Synthesizing Large-Scale Interaction Trajectories for Generalized GUI Agent Pretraining

这篇工作解决 GUI agent 预训练数据规模不足的问题。现有 GUI 轨迹数据多来自人工标注或模拟环境，质量可控但覆盖面窄，难以覆盖真实网站、桌面软件和移动应用中的长尾交互。论文尝试把未标注互联网视频转成可训练的 GUI 操作轨迹。

评值得看数据管线，不必迷信 benchmark 涨幅；重点判断自动抽取轨迹的噪声结构，若噪声可控，这类视频挖掘会是 agent pretrain 的便宜数据源。

CiteVQA: Benchmarking Evidence Attribution for Trustworthy Document Intelligence

这篇工作关注的是文档理解中的证据归因，而不是基座预训练方法本身。它要解决的问题是：现有 Doc-VQA 只看答案对不对，不检查答案是否真的落在正确的文档区域上，因此模型可能“答对了，但证据错了”。作者把这个问题形式化为 answer + citation 的联合评测，要求模型返回元素级 bounding-box 证据，并用严格指标同时检查答案正确性和证据忠实性。

评把“引用是否对”从口号变成可量化指标，适合用来检验你家 VLM 的 grounding 训练是否真有效；只看评测协议和错误类型统计就够。
