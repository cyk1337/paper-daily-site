Coverage-Driven KV Cache Eviction for Efficient and Improved Inference of LLM

这篇论文处理的是长上下文推理中的 KV cache 压缩问题。已有 eviction 方法主要按注意力分数保留 token，但在高压缩率下，不同 head 和不同 layer 往往保留同一批靠近 prompt 末尾的 token，导致被覆盖的唯一 token 数下降。作者把这种现象称为 coverage loss，并认为它是长上下文任务性能下降的关键原因。

评别只把它当又一篇 KV eviction；若主表成立，‘coverage 而非 attention 峰值’这个解释值得迁移到长上下文训练与稀疏注意力设计里。
