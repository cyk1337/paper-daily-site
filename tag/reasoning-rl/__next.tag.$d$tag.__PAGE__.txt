Second, the method prepends a correct prefix from a reference solution as an assistant message and asks the model to complete the rest. During training, the system observes the realized batch mean k/G and updates the global base prefix using a root-finding style rule such as secant or binary search, pushing the observed solve rate toward the target. The per-sample offsets account for persistent difficulty differences, while the global term tracks the non-stationarity induced by policy improvement.

The paper’s contribution is not a new reward but a clean factorization of gate and reward as two independent axes. The authors study two environments. One is Python output prediction. If collapse still appears in the DSL setting, it is much harder to blame the environment; the failure must come from the optimization dynamics of the self-play loop itself.

Several reward variants are tested, with the most important contrast being self-consistency reward versus grounded reward. Self-consistency does not use the true answer; it rewards agreement across multiple solver samples. Grounded reward uses execution truth. A common intuition is that sufficiently grounded rewards should naturally suppress bad data. The paper shows that this intuition fails. Once ambiguous or exploitable tasks enter the pool, self-consistency can assign higher reward to corrupted data than to clean data, because ambiguous tasks are exactly where spurious consensus is easiest to maximize.

Three mechanistic findings stand out. First, the intrinsic-grounded gap measures the difference between the solver’s intrinsic reward and grounded accuracy. When this gap widens, the system is converging toward an attractor that is internally self-consistent but externally wrong. Second, the Grounded Proposer Paradox shows that when the solver is trained with self-consistency reward, a proposer with access to ground truth can accelerate collapse rather than prevent it. The reason is subtle: a grounded proposer concentrates training on clean, well-structured tasks that provide the lowest-resistance path to spurious consensus. Third, the gate is relaxed continuously through a strictness parameter epsilon rather than only toggled on or off.
