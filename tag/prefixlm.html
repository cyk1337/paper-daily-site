HRM-Text: Efficient Pretraining Beyond Scaling

论文要解决的是低预算条件下从零训练语言模型的问题。主流路线依赖互联网规模原始文本和大算力，训练目标主要是预测下一个 token，其中相当一部分计算花在提示格式、网页噪声和弱相关文本上。HRM-Text 的问题设定更窄：如果模型最终主要用于条件生成，是否可以用更强的结构先验和更贴近使用形态的训练目标，在 40B 级 token 预算内得到可用的基础能力。

评值得立刻看实验表：如果 Transformer baseline 和数据预算对齐干净，这会改变“小数据只能做 post-train”的默认判断。

HRM-Text: Efficient Pretraining Beyond Scaling

这篇论文想回答一个很直接的问题：在没有万亿级 token 和大规模集群的条件下，是否还能从零训练出有竞争力的语言模型。作者没有沿用“更大 Transformer + 更多 raw text”的路线，而是同时改模型结构和训练目标：用层级循环结构增加有效计算深度，用 instruction-response 任务完成目标替代普通 raw-text next-token 预训练。

评应读正文的 ablation：若同算力对照干净，它会动摇“低 token 预算只能靠缩小 Transformer”的默认做法。
Guan Wang,Changling Liu,Chenyu Wang,Cai Zhou,Yuhao Sun,Yifei Wu,Shuai Zhen,Luca Scimeca,Yasin Abbasi Yadkori

HRM-Text: Efficient Pretraining Beyond Scaling

这篇论文要回答两个更根本的问题。第一，语言模型预训练是否必须依赖 Transformer + 海量原始文本 + next-token 这一套高算力配方，还是可以通过更强的结构归纳偏置和更贴近使用场景的训练目标，在小得多的 token 与算力预算下得到可用的通用能力。第二，若采用深层递归、双时间尺度的 HRM 架构，怎样解决语言建模中最棘手的训练稳定性问题，避免 recurrent depth 带来的梯度消失、爆炸和信用分配失效。论文的核心不是单点提速，而是试图给出一个“低预算也能做从零预训练”的存在性证明。

评这篇会直接碰你的 prior：原始文本 AR 预训练未必是唯一高效路径；先查 baseline 是否同等 compute、instruction-only 数据是否泄漏任务分布，若对比干净，建议立刻做小规模复现。
Guan Wang,Changling Liu,Chenyu Wang,Cai Zhou,Yuhao Sun,Yifei Wu,Shuai Zhen,Luca Scimeca,Yasin Abbasi Yadkori
