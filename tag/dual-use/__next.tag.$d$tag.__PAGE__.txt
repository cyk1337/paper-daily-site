5:T4bf,The analysis uses a finite decision-theoretic setup. For a fixed public task context W=w, the context includes the task, claimed identity, role, and stated use, but these claims are not treated as evidence of actual downstream use. The deployment has a finite release menu A, including refusal. Each release has a utility under a legitimate-use world B and a misuse utility under a malicious-use world M; because the malicious user can choose how to exploit the answer after observing it, the malicious utility takes the most useful allowed misuse. A safeguard is modeled as a Markov kernel over terminal releases conditioned on a pre-release transcript H. The central assumption is that the attacker can reproduce the same observable evidence as a legitimate user. Total variation distance is used to quantify imperfect copying or credential separation. Under a legitimate utility target q, the paper derives a capability floor Γ(q): the unavoidable amount of attacker assistance induced by preserving useful answers.
