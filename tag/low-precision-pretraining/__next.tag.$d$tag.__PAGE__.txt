9:T77b,The analysis first formalizes Shrinkage Bias: for non-uniform floating-point grids like E2M1, representable values follow geometric spacing, creating asymmetric rounding bins where the interval midpoint sits closer to the smaller-magnitude value. Under Round-to-Nearest-Even (RTNE, the default deterministic rounding for NVFP4), this structure produces a consistent negative expected rounding error. The bias accumulates multiplicatively across layers, rather than averaging out as zero-mean noise. The original intuition for choosing E2M1 was that non-uniform grids provide better dynamic range for heavy-tailed natural tensors; however, RHT—applied to spread outlier energy and improve codebook utilization—transforms tensor distributions to near-zero, approximately Gaussian shape, which falls exactly in the value range where E2M1 bin asymmetry is most severe, amplifying bias instead of reducing quantization error. Uniform grids (E1M2, INT4) use equal spacing between representable values, eliminating this geometric asymmetry entirely; these grids also match the post-RHT near-Gaussian tensor distribution, converting RHT-induced codebook utilization gains into consistent quantization quality. The resulting UFP4 recipe makes two core design choices: first, apply RHT to all three linear layer GEMMs in training (forward pass, data gradient, weight gradient), resolving the prior failure mode of training collapse when using RHT across all paths with E2M1; second, restrict stochastic rounding exclusively to quantization of the upstream gradient dY, using deterministic RTNE for weights and activations to minimize update variance.
