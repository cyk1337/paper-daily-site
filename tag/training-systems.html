Not Every Sync Is Safe: Calibrated DiLoCo Scheduling for Shared AI Infrastructure

这篇工作处理的不是 DiLoCo 本身能不能省通信，而是共享算力环境里“什么时候做 outer sync 才安全”这个调度判定问题。工业环境里训练常和在线 serving 共用主机、网络、checkpoint 资源，outer merge 一旦落在高压窗口，会直接伤害延迟敏感业务。已有工作多比较固定周期、简单 pressure gate 或 workload-aware 策略，但没有把“同步次数预算”和“同步时机选择”拆开评估，因此很容易把预算控制误当成 workload awareness。作者要解决的核心问题，是给 DiLoCo 同步调度建立一个可校准的评估协议：只有当某个调度器在相同同步预算下，能稳定优于随机放置这些同步窗口，才说明它真的学到了何时同步，而不只是少同步。

评戳破了近期DiLoCo调度论文的基线漏洞，同预算随机调度就能打平多数启发式策略，做分布式训练的重点看基线对照部分即可。

AMDP: Asynchronous Multi-Directional Pipeline Parallelism for Large-Scale Models Training

这篇工作解决的是大模型训练中的异步 pipeline parallelism 收敛退化问题。已有异步流水线为了消除 bubble，会持续把 minibatch 推入 pipeline，但这样会让同一个 minibatch 的 forward 和 backward 使用不同版本参数，形成 parameter mismatch；而且 pipeline 越深，这个错位越严重。论文的目标是在尽量保留异步流水线高吞吐的同时，把这种错位控制在一个可分析、可实现、对收敛影响较小的范围内。

评做大规模 pretrain 可以看：它不是新并行花样，而是把 async pipeline 的 stale-weight 伤害显式有界化；先看方法图和收敛曲线，再决定要不要复现。
