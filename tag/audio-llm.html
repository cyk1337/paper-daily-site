Auditing Generative Audio Calls for Known-Task Audio-LLM Evaluation

这篇工作讨论的是一个很具体但常被混淆的问题：在已知闭集标签任务上，音频波形里确实可能包含 transcript 没有的信息，但这并不自动意味着系统必须调用 generative audio-LLM。作者要分离两件事：一是“是否需要声学证据”，二是“是否需要生成式音频模型来利用这些证据”。很多现有评测只比较 transcript-only 和 audio-LLM，结论容易被误读成 generative audio call 本身有必要；而论文要审计的是，在 transcript、判别式音频 encoder、以及开发集上训练好的 selector 都可用时，额外调用 Qwen2-Audio / Qwen2.5-Omni / MOSS-Audio 是否还带来足够的决策增益。

评指出了音频 LLM 评测中的一个重要坑：很多时候你以为是 LLM 的功劳，其实只是底层声学 encoder 的功劳，对于设计多模态 benchmark 很有启发。
