9:T53f,AgentMemBench implements five memory families under one harness. ICW keeps only a recent in-context window. EKV stores conversation snippets in an external key-value memory and retrieves them by dense similarity. GEM extracts entities and relations into an episodic knowledge graph, then retrieves structured neighborhoods. CBS compresses older context into natural-language summaries. WAM augments the agent with external web or MCP-style tool access. The benchmark uses three public datasets: 200 question turns from LoCoMo, 187 from MultiDoc2Dial, and 104 from MSC, for 491 annotated question turns in total. This yields 15 main configurations across five strategies and three task types. The metrics cover retrieval quality, including Memory Recall@k, MRR, and nDCG@k; answer quality, including Answer F1 and an LLM-judge faithfulness score; and deployment efficiency, including memory footprint, token cost, and latency. A notable design choice is provenance-aware retrieval evaluation: retrieved items carry true session/turn provenance, so retrieval metrics are computed against gold-session annotations rather than against ad-hoc retrieval indices.
