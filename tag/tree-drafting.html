PRESTO: Prefix-Aligned Tree Drafting for Diffusion Speculative Decoding

PRESTO 解决 diffusion LLM 作为 speculative decoding drafter 时的候选路径利用不足问题。现有 diffusion drafting 多采用单路径线性草稿，但 diffusion 模型一次 forward 会在多个位置给出多个候选 token，天然形成组合空间。只取一条 top-1 轨迹会浪费候选。直接套用 AR tree drafting 也不合适，因为 diffusion 输出的是位置级 marginal probability，而 AR verifier 接受 token 时依赖前缀条件概率，两者的打分语义不一致。

评扩散 LM 推测解码的扎实改进，前缀对齐与树状草稿的组合解决了一个真实的结构性 mismatch，做 dLLM 推理的人应读 §3 和实验部分。

Unlocking Parallelism in Autoregressive Language Models via Speculative Decoding with Progressive Tree Drafting

这篇工作处理的是训练外、模型内 speculative decoding 的一个具体瓶颈：目标模型虽然有并行计算能力，但现有 endogenous drafting 方法大多让模型独立地产生多条线性候选，结果是不同分支高度相似，重复消耗 attention 和 KV 计算，接受率也不稳定。论文想解决的不是“能不能做自草稿”，而是“如何用结构化方式把 AR 模型潜在的并行能力真正转成可验证、可接受、可带来端到端加速的 draft”。

评只看方法图和端到端延迟表；若加速不依赖小 batch 或短输出，值得放进内部 speculative decoding ablation。

SpecBlock: Block-Iterative Speculative Decoding with Dynamic Tree Drafting

这篇工作处理的是 speculative decoding 里一个很具体但很关键的矛盾：树式草稿如果想让 target 一次验证接受更多 token，就需要 draft tree 既有足够覆盖率，又不能让 drafter 本身变成新的时延瓶颈。EAGLE-3 这类自回归 drafter 的问题是路径一致性好、接受长度高，但树每加一层都要多一次串行 drafter forward，drafter 延迟会吃掉不少收益；并行多位置 drafter 则把多步预测压到一次 forward 里，但不同深度位置彼此看不到对方，拼成树后会产生大量不连贯路径，target 验证预算被浪费。SpecBlock 的核心问题就是：能不能在少量 drafter 调用下，仍然保留路径内依赖，让 draft tree 既便宜又更容易被 target 接受。

评投机解码 drafter 设计有实用新意；先看 block 内依赖机制和 acceptance/latency 分解，不必读训练细节。
