ALIAS: Evaluating Performance and Memorization in LLM-Written TLA+ Specifications

这篇论文检验 consistent identifier renaming，即 CIR，是否能可靠检测 LLM 在 TLA+ benchmark 上的记忆。核心结论是：重命名后分数下降不一定说明模型记住了原题，也可能来自 benchmark 的 exact-name grading 或随机名字本身增加了任务难度。

评指出了代码评测中常用的变量重命名（CIR）测试记忆的方法存在 '评分标准过严' 的坑，强调基于执行等价性的评测，对设计 coding benchmark 很有启发。
Arslan Bisharat,Mujtaba Nazari,Khushboo Bhadauria,Brian Ortiz,Eric Spencer,Beatriz Santos,TaiNing Wang,George K. Thiruvathukal,Konstantin Laufer,Mohammed Abuhamad

TLA-Prover: Verifiable TLA+ Specification Synthesis via Preference-Optimized Low-Rank Adaptation

通用大模型生成的TLA+分布式系统形式化规范通过率极低，现有最优公共基线的语法解析通过率仅26.6%，TLC模型检查通过率仅8.6%；同时直接以TLC检查结果作为奖励信号存在奖励黑客风险——模型可生成永真式不变式通过检查，却不具备实际验证价值。

评将 GRPO 用于形式化验证代码生成（TLA+），利用 TLC 检查器作为 ground-truth reward，是 RL 在严谨代码生成领域的典型应用，值得关注其 RL setup 和 reward 设计。
Eric Spencer,Arslan Bisharat,Brian Ortiz,Khushboo Bhadauria,TaiNing Wang,George K. Thiruvathukal,Konstantin Laufer,Mohammed Abuhamad
