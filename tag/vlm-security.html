Once Poisoned, Arbitrarily Controlled: A Programmable Backdoor in VLMs

这篇论文研究的是 VLM 训练数据投毒里的一个更强威胁模型：攻击者不是在训练前把“某个触发器→某个固定目标文本”绑定死，而是希望只投毒一次，就在推理时按需指定任意目标 caption，并即时合成对应触发器，让模型输出此前从未在投毒阶段预定义过的文本语义。论文要解决的核心问题有两个：训练时如何把“触发器作为隐式指令”的能力植入模型；推理时如何把任意目标文本编码成一个足够隐蔽、又能稳定激活后门的视觉触发器。

评值得看 threat model 和投毒构造，重点是 VLM 可能学到“触发器即指令”的规则；实验细节不够前先别外推。
Tao Lin,Gaojie Jin,Zongxin Liu,Peng Wu,Lijia Yu

A Cross-Modal Prompt Injection Attack against Large Vision-Language Models with Image-Only Perturbation

这项工作研究 LVLM 的跨模态 prompt injection：攻击者只修改图像，却希望同时改变模型对图像内容和文本指令的理解。核心问题不是让图像被误识别，而是让图像扰动进入图文融合过程，进而劫持模型对文本任务意图的解释。

评VLM安全值得扫；重点看隐藏态优化是否真比视觉embedding攻击更稳，实验若不跨模型就打折。

If you're waiting for a sign... that might not be it! Mitigating Trust Boundary Confusion from Visual Injections on Vision-Language Agentic Systems

VLM智能体在真实场景中需要遵循“环境内嵌信号”（如交通灯），但同类视觉信号也可被攻击者伪造为注入提示，导致智能体越权偏离用户意图（trust boundary confusion）。

评作为“视觉注入=环境信号同通道”的问题定义值得记住；读数据集设定与失败模式即可，防御结论在无数值细节前当弱信号。
