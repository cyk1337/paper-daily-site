17:T553,StateKV treats streaming prefill as approximating full self-attention using a small, fixed-size set of historical tokens.

Assumptions/observations:
- Most attention is intra-frame; inter-frame attention mass is concentrated on a small subset of historical tokens (“temporal sinks”) that evolve slowly.
- Therefore, cross-frame context can be carried by a constant-size memory K, independent of video length.

Mechanism:
- Maintain two coupled caches per layer:
  1) A fixed-capacity temporal state (size K) used for cross-frame attention. It is updated online by selecting historically important tokens (including sinks) based on an importance measure derived from attention weights.
  2) A per-frame cache that preserves full token detail for each frame, retained for the final text decoding stage.

Complexity profile:
- Prefill becomes O(N): each new frame attends cross-frame only to the fixed state plus its own intra-frame tokens.
- Decoding can still condition on all frame tokens (potentially O(N) in generation), but the paper argues prefill dominates in long-video QA, so linearizing prefill yields linear end-to-end scaling in practice.

Difference vs sliding-window streaming:
- Sliding windows impose a recency prior (hard truncation).
- StateKV uses importance-based retention to better match the full-attention behavior of the frozen
