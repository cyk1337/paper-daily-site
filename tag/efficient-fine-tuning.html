Preference-aware Influence-function-based Data Selection Method for Efficient Fine-Tuning

这篇工作解决的是预算受限条件下的 SFT 数据选择问题：当目标行为由一组 target examples 定义时，现有 influence-based data selection 往往把这些 target 一视同仁，导致构造出来的“目标方向”混入了离当前模型很远、短期内难以通过少量数据推动的行为信号，从而降低选数效率。作者要解决的是，如何让 target behavior 的表示更贴近当前模型的局部可塑性，而不是只做均匀平均。

评将 Influence Function 与模型当前偏好结合做 SFT 数据选择，逻辑很 make sense，值得关注其在实际 LLM 微调中的加速比和最终效果。
