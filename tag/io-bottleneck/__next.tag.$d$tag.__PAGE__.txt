9:T5f0,The central idea is predictive delta prefetching. First, the system predicts downstream sparsity early. Instead of using per-layer predictors that reveal a layer’s active set only when execution reaches that layer, NeuroPrefetcher runs a single GPU-resident predictor after layer 0 and predicts active-neuron masks for all downstream MLP layers in one shot from early-token features. This creates a lookahead I/O schedule before sparse execution begins. Second, the runtime converts predictions into movement decisions. For each layer it tracks which weight rows are already resident, compares that resident set with the predicted active set for the next token, and fetches only the incoming delta from NVMe. This reframes the I/O cost from “how many rows are needed now” to “how many new rows are needed relative to the previous token.” Third, the implementation addresses a platform-specific coherence issue on Jetson-style unified-memory systems: direct I/O can bypass CPU cache coherence and expose stale data to the GPU, so sparse rows are routed through a cache-coherent staging path before execution. Fourth, the runtime uses a memory-adaptive dense/sparse split. Limited GPU memory is divided between a fully resident dense prefix and a sparse suffix with active-row buffers. With more memory, more early layers stay dense; with less memory, the sparse suffix expands to preserve model executability. The design is therefore not just sparse execution, but a coordinated predictor-runtime-memory policy.a:T4fd,The most important evidence starts with system profiling.
