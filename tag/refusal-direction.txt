18:T6b4,The core method is still directional ablation, adapted to MoE, multi-stream residuals, and FP8 weights. The basic recipe is to estimate a refusal direction from a few hundred contrastive prompts, then orthogonalize the weights that write to the residual stream against that direction so the model can no longer express refusal along it. The technical difficulty comes from three shifts. First, in an MoE, the residual writers are no longer just attention and dense MLP projections; routed experts and shared projections also matter. The paper shows that if one reuses the old dense-model implementation based on module-name traversal, many fused expert parameters are never touched. The edit appears to run cleanly but changes almost nothing, which creates a silent-failure mode. Second, GLM-5.3-Flash uses a four-wide hyper-connection residual. The authors argue that this topology does not fundamentally block directional ablation because the stream-mixing weights are scalar: if a direction is zeroed in every stream, later mixing keeps it zero. This is why directly editing residual-writing weights is more complete than hooking layer outputs. Third, the paper tests whether the single-direction hypothesis survives at frontier scale. It does not rely only on rank-1 ablation; it also tries higher-rank fitted subspaces and uses random orthogonal directions as controls. The main technical conclusion is twofold: the editable part of refusal is distributed across attention, dense/shared projections, and routed experts, and a nontrivial residue remains even after low-rank subspace removal, concentrated in a few content categories. So refusal is not fully captured by one simple linear direction in this model.19:T684,The target model is GLM-5.3-Flash: 320B parameters, 288 routed experts, a four-stream hyper-connection residual, and block-FP8 weights. The most informative experiment decomposes the edit effect across all subsets of writer groups. The result is strongly non-additive. Editing attention alone, dense/shared projections alone, or routed experts alone removes only 0.039, 0.016, and 0.148 of refusal, respectively. Editing all three together removes 0.776. In other words, roughly three quarters of the removable effect appears only under joint editing, not within any single module family. That directly argues against a simple picture in which refusal is localized to one component type. The paper also quantifies the MoE implementation pitfall: the conventional name-matching recipe reaches only a subset equivalent to 0.066 out of the available 0.776, so on this architecture it mostly misses the target while looking successful. Another comparison shows that directly editing residual-writing weights is more thorough than boundary hooking. To verify specificity, the authors ablate random directions orthogonal to the refusal direction and observe essentially no refusal removal. On seven harmful benchmarks, the method reduces refusal by 41 to 89 percentage points with no detected capability loss. The spread is itself informative: the weaker gains occur on benchmarks enriched with resistant categories. The authors then fit category-specific subspaces up to rank 12 and still observe residual refusal, suggesting that in this model safety alignment is not fully removable by a single direction, and not even fully removable by a small low-rank linear subspace.1a:T511,This is a skim paper, but it rewards reading the main body. Two failure modes are highlighted: subthreshold activation, where harmfulness is internally represented but does not cross the refusal threshold, and semantic recovery failure, where the harmful representation collapses before the refusal mechanism can use it.1c:T46b,The method, SafeVec, extracts a refusal direction from a safety-aligned reference model within the same architecture family, then scores a target model by how strongly its hidden states align with that direction under unsafe and jailbreak prompts. The pipeline has five stages:
1. collect last-token residual activations for safe and unsafe prompts at each layer;
2. define the layer-wise refusal direction as the normalized difference between mean unsafe and mean safe activations;
3. select a continuous layer window, avoiding early lexical layers and very late layers that may be dominated by readout effects;
4. use a small set of calibration models with different safety levels to map raw cosine similarities into a 0–100 Refusal Alignment Score (RAS);
5. score the target model using its alignment to the refusal direction on unsafe and jailbreak inputs.
