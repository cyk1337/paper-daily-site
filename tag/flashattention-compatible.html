Epiphany-Aware KV Cache Eviction Without the Attention Matrix

这篇工作解决的是长链式推理模型在推理阶段的 KV cache 内存瓶颈，具体是：在不读取 attention matrix 的前提下，怎样做有效的 decode-time KV eviction。现有方法大多用 attention weight 估计 token 重要性，但这条路有两个问题。第一，attention weight 在长推理轨迹里并不等于真正的“未来可用性”，会被 attention sink、生成时的局部流畅性 token、格式性 filler 干扰。第二，更关键的是工程上不兼容现代高效推理栈：一旦为了拿 attention 权重而打开 output_attentions，就会迫使系统退出 FlashAttention 路径，重新承受 O(n^2) 级别的注意力矩阵物化开销，长上下文下几乎不可部署。

评重点看§3的Epiphany Score定义和§4.3的长上下文扩展实验，其token重要性度量思路可迁移到预训练的课程数据筛选
