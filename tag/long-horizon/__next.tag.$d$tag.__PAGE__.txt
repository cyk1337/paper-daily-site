A User Agent interacts with a Target Agent over multiple turns, and in adaptive attacks the next user action is generated conditioned on the target agent’s actual behavior and the current attack state. The Target Agent acts in a stateful tool environment where tool calls, outputs, and resulting state transitions are explicitly recorded. This matters because the benchmark can judge what the agent actually executed, not just what it claimed in text. The current release includes 22 attack families and 35 scenarios across 7 domains, with 25 core-domain and 10 cross-domain scenarios. The dataset contains more than 2,500 long-horizon trajectories with an average length of 14.7 turns. The adjudication protocol is a major design point. The first is dynamic per-trajectory rubric generation. Instead of writing one fixed rubric for the whole task distribution, the judge first proposes criteria from the task instruction, then extends those criteria using what each sampled rollout actually attempted, where it failed, and which subgoals emerged during execution. The criteria proposed from all trajectories in the same GRPO group are merged into a shared rubric set. The motivation is straightforward: fixed rubrics under-specify long trajectories, while rollout-conditioned rubrics can evaluate what the policy concretely did rather than what a generic template expected.

The second component is rubric-conditioned advantage redistribution. Standard GRPO assigns one scalar advantage to every token in a trajectory. DRACO asks the judge to score each rubric criterion, aligns criteria to the steps responsible for them, and then applies a closed-form redistribution rule to produce per-step advantages. The paper emphasizes several formal properties of this rule, including conservation of total push, sign preservation, and length independence. These properties are meant to prevent the usual failure mode where long trajectories dilute credit or where trajectory length itself introduces systematic bias.

Training remains within the GRPO framework: sample a group of trajectories, score them with a frozen judge under the dynamic rubric, and replace uniform trajectory-level advantage with redistributed step-level advantage. A notable design choice is that the method does not rely on a learned reward model and does not anchor step rewards to terminal verifiers or gold answers. That is the main distinction from much of the prior process-reward and step-credit literature.e:T662,The main experiments are on AppWorld.
