It decomposes total variance in binary success observations into the agent main effect (the true general capability signal), independent main effects for each facet, pairwise interaction effects between facets, and residual variance. Three independent variance estimators are used to cross-validate results: Henderson Method-I, restricted maximum likelihood implemented via lme4, and a Bayesian binomial generalized linear mixed model run on GPU. Building on the G-study (variance component estimation), a D-study (decision study) translates variance components into a budget frontier of minimum tasks, steps, and judges required to meet target reliability thresholds (generalizability coefficient Eρ² ≥ 0.85 for relative ranking decisions, dependability coefficient Φ ≥ 0.90 for absolute threshold decisions such as SLA gates). Instead of assigning uniform trajectory credit, the method runs a mean-backup Bellman fixed-point evaluation on this empirical graph to estimate node values under the current rollout policy. It then computes fixed-point temporal-difference residuals and propagates them along each trajectory using GAE to obtain step-level advantages.

The central addition is a graph-confidence gate. If a state has only one observed successor, the graph provides no empirical basis for comparing alternative transitions, so the Bellman step credit is suppressed and the update relies mainly on group-relative outcome advantage. If a state has multiple observed successors, the local graph contains comparative evidence, so the Bellman credit is activated and given more weight, while the outcome signal is still retained as a stabilizer.
