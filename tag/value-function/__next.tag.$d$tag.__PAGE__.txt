b:T942,技术主线有两条：一个算法，一个可识别性理论。

算法部分提出 P-learning，可以看成 Q-learning 的逆问题。普通 Q-learning 在固定环境转移核 P 下，通过 Bellman 更新逼近 Q；P-learning 则把一组固定的 (Q^g, π^g, r^g) 当作观测，迭代更新候选 world model，使它与这些 value functions 的 Bellman 关系越来越一致。作者在 tabular 情形下把这个过程写成线性方程组，并证明收敛到一个由 Moore–Penrose 伪逆给出的解。直观上，Q、policy 和 reward 提供了关于“从状态动作对出发，后继状态分布必须满足什么约束”的大量线性条件；当这些条件足够丰富时，P 就能被唯一识别。文中也说明在很多实际设置里，π 往往由 Q 通过 argmax 或 softmax 导出，因此输入可以近似理解为一组 goal-conditioned Q 和 reward。

理论部分是全文更核心的内容。作者系统分析了在不同 MDP 类型下，什么样的 goal set 能打破 value equivalence。结论分四类。第一，有限状态、确定性 MDP 中，一个“generic” goal 就可能足够识别真实 P。这里 generic 的意思不是任意 goal，而是能让不同后继状态在回报结构上被区分开。第二，有限状态、随机 MDP 中，goals 需要张成状态空间；换句话说，reward family 必须足够丰富，才能把随机转移分布的自由度约束住。第三，确定性连续状态情形里，有限个 goals 有时也足够，这一点有些反直觉，因为连续空间通常让人预期需要无限监督。第四，随机连续 MDP 中，关键不再是 goal 的个数，而是 coverage：对 Gaussian rewards，需要 goal set 有非空内点；对 indicator rewards，需要覆盖状态空间。作者还给出当 Q 只有 ε 近似精度时，恢复出的 P 的误差界，说明 world model 的准确性会随 value 误差平滑退化，而不是脆弱崩掉。

这套方法与传统 world model learning 的区别在于，它不直接拟合转移样本，而是从 agent 已经学到的价值结构中反演环境。与 successor features、forward-backward learning、一般 goal-conditioned RL 的关系则是：这些方法原本被视为多目标 value learning，这篇论文说明在目标集足够丰富时，它们携带的信息量其实接近显式动力学模型。c:T86d,The paper has two technical pillars: P-learning as an inversion algorithm, and identifiability results that characterize when inversion is possible.

P-learning is introduced as an inverse analogue of Q-learning. In standard Q-learning, the transition kernel is fixed and Bellman updates are used to estimate values. Here the values, policies, and rewards are treated as given, and the transition model is updated so that the Bellman equations become increasingly consistent with those fixed quantities. In the tabular setting, this becomes a structured linear inverse problem, and the paper proves convergence to a solution expressed through the Moore–Penrose pseudoinverse. Intuitively, each tuple (Q^g, pi^g, r^g) imposes constraints on what the next-state distribution must be for every state-action pair. If the goal family is rich enough, those constraints pin down the true kernel.

The more fundamental part is the identifiability theory. The paper characterizes when value equivalence can be broken in four regimes. In deterministic finite MDPs, a single generic goal can be sufficient to identify the true dynamics. In stochastic finite MDPs, the reward family must span the state space; otherwise the stochastic degrees of freedom remain hidden behind equivalent values. In deterministic continuous MDPs, somewhat surprisingly, a finite number of goals can still suffice in some cases. In stochastic continuous MDPs, the key notion is coverage rather than cardinality: for Gaussian rewards, the goal set needs non-empty interior; for indicator rewards, it must cover the state space. The paper also provides error bounds showing that if the Q-functions are only epsilon-accurate, the recovered model degrades gracefully rather than catastrophically.

This differs from standard world-model learning because the method does not fit transitions directly from rollouts. Instead, it extracts dynamics from the value structure already learned by the agent. It also reframes goal-conditioned RL, successor-feature style methods, and related approaches as potentially implicit model-learning procedures when the goal family is sufficiently expressive.d:T6d3,The experiments ask two main questions: can P-learning recover accurate world models in practice, and are the recovered models useful beyond the training goals?

For finite MDPs, the paper validates the theory on three FourRooms variants: deterministic, windy, and teleporting. As stochasticity increases, the number of goals needed for near-perfect recovery also increases. The headline numbers are that |G| = 1, 4, and 20 goals are sufficient, respectively, for quasi-perfect recovery in those three settings. This aligns well with the theory: deterministic environments need much less reward diversity than stochastic ones.

In continuous control, the paper studies Reacher and finds that only |G| = 4 goals are enough to recover an accurate implicit world model. A notable result is that the recovered model is accurate even on variables that the reward never directly depends on. Planning inside the recovered model then transfers to out-of-distribution goals, including angular-velocity targets despite training only on position-based goals. That is a strong sign that the agent has internalized more than a narrow reward-specific shortcut.

The MountainCar experiments probe this implicit generalization further. Training on velocity-based goals instead of position-based goals yields an almost identical recovered world model, suggesting that agents optimized for very different objectives may still internalize similar dynamics. Finally, the paper reports a very strong correlation between agent performance and recovered world-model accuracy, with Spearman rho = 0.98. One regularizer has the form of Monte Carlo value learning: intermediate predictions are tied to the final trajectory-level RM score. The other has the form of TD value learning: adjacent token positions are encouraged to satisfy temporal consistency. The output at position k only sees the prompt and the response prefix up to token k, which is exactly the conditioning set for a prefix value estimate. Compared with a standard RM, TCRM does not change the architecture, data format, or inference interface; it changes what the otherwise discarded intermediate outputs are trained to mean. 作者在实践上用 final model score r(x, y) 作为未观测 ground-truth reward 的 proxy，然后要求中间输出 r(x, y0..k) 与这个 final reward 的条件期望一致。两个正则项分别对应 Monte Carlo 和 TD 风格的 value learning。一个是 MC 型正则，让中间位置直接回归最终分数，从而鼓励每个 prefix 的输出成为“看到当前前缀后，对最终结果的平均预测”；另一个是 TD 型正则，约束相邻位置之间的时序一致性，使当前 token 的预测与下一步预测之间满足类似 Bellman 的递推关系。论文给出相应引理，说明这些正则项的最小化解就是条件期望，因此不是拍脑袋的平滑项，而是有明确统计目标。

这套设计有几个值得注意的点。第一，它不需要 process labels。传统 PRM 往往依赖 step-level 标注，成本高且定义不稳定；TCRM 只用常规 preference pair，就把 RM 训练成了一个近似 process-aware 的模型。第二，它不改推理接口。训练后仍然可以像普通 RM 一样只读 final token 分数，但如果需要，也可以读取中间轨迹做解释、credit assignment 或 value estimation。第三，它自然导出 token-level incremental contribution：相邻位置分数差 d(yk | x, y0..k-1) 可以解释为该 token 对最终质量预测的边际影响。这一点对分析 reward hacking、模板化套话、冗余推理步骤等问题很有用。

和已有 RM 训练相比，区别不在于换了偏好损失，而在于把“final-only supervision”改成“full-trajectory consistency under the same supervision”。它仍然是 pairwise preference learning，但把每个中间位置都纳入了一个 value-style 约束框架。10:T7d9,Temporally Coherent Reward Modeling (TCRM) augments the standard Bradley-Terry pairwise loss with two regularizers that force intermediate outputs to approximate the conditional expectation of the final reward. The key observation is architectural: in a decoder-only transformer with causal masking, the hidden state at position k depends only on the prompt and the first k response tokens. That is exactly the conditioning structure needed to represent E[R | x, y0..k]. So the limitation is not representational capacity; it is the training objective.

Since the true scalar reward R is unobserved in pairwise preference training, the paper uses the model's final score r(x, y) as a proxy target under an unbiasedness assumption. It then adds two value-learning-style regularizers. One is Monte Carlo-like: intermediate predictions are encouraged to match the final score, making each prefix output a predictor of the eventual outcome. The other is TD-like: adjacent token positions are constrained to be temporally consistent, in a way analogous to Bellman-style bootstrapping. The paper proves via lemmas that the minimizers of these regularizers are conditional expectations, so the objective is statistically grounded rather than heuristically smoothed.

Several aspects are notable. TCRM requires no process labels, unlike standard process reward models that depend on expensive step-level supervision. It also leaves inference unchanged: one can still use only the final token score if desired, but now the full token trajectory is meaningful and can be used for analysis, credit assignment, or value estimation. Finally, the model naturally yields token-level incremental contributions through score differences between adjacent positions, which can help diagnose reward hacking, verbosity bias, or unhelpful reasoning steps.

Relative to prior RM training, the novelty is not a new preference loss but a shift from final-only supervision to full-trajectory consistency under the same preference data.11:T71f,The empirical story is focused and convincing. The clearest result is on intermediate-token pairwise accuracy. Standard reward models are near chance in the middle of a sequence, around 50%, because those outputs are never trained to mean anything. TCRM raises middle-token pairwise accuracy to as high as 88.9% while preserving final-token accuracy. That is strong evidence that the regularizers are not merely smoothing trajectories; they are making intermediate outputs genuinely predictive of final preference.

A second important result is process-level evaluation. TCRM is used as a process reward model without any step-level labels and achieves 44.9% average F1 on ProcessBench. The significance here is not just the absolute number, but the fact that useful process supervision can be extracted from ordinary preference data if the objective is designed correctly.

The third major result is in PPO. Because the TCRM regularizers align with Monte Carlo and TD value learning, the same model can serve as both reward model and value model. The paper reports a 27% reduction in peak GPU memory and a 19% reduction in training step time, with no degradation in final LLM quality. For practical RLHF systems, that is a meaningful systems-level gain.

The paper also discusses policy shift. Intermediate conditional expectations depend on the continuation distribution: offline training uses the dataset distribution, while online RL changes the policy over time. Empirically, TCRM's intermediate-token accuracy is reported to be no more sensitive to this shift than final-token accuracy, and even a frozen TCRM can function effectively as a value model in PPO.
