先看 tokenizer。作者没有沿用传统重建导向的 VQ，而是提出 SigLIP-VQ，把连续视觉输入离散成“fully semantic discrete tokens”。这里的关键不是单纯做更好的压缩，而是让 token 更接近语义单元，能被语言式 backbone 直接消费。传统 VQ token 往往偏局部纹理和重建细节，适合生成但不利于理解；如果压缩率再高一些，生成也会受损。SigLIP-VQ 试图在语义保真和离散统一格式之间找到平衡，使视觉 token 既能支持问答推理，又能作为后续图像生成的中间表示。

再看 backbone。LLaDA2.0-Uni 以 LLaDA2.0 的 16B MoE dLLM 为核心，不走 next-token AR，而是对文本和图像 token 统一采用 block-level masked diffusion。这里的 block-wise mask prediction 很重要。它不是逐 token 自回归，也不是完全无结构地全局去噪，而是在块级别进行掩码和恢复，兼顾并行解码效率与上下文建模能力。作者强调 modality-agnostic MoE，说明专家路由不是按模态硬切，而是让文本和视觉 token 在共享 backbone 中竞争专家容量，这对统一表示学习是更激进的设计。

第三部分是 diffusion decoder。由于 backbone 输出的是语义离散视觉 token，而不是可直接还原高保真图像的重建 token，因此需要一个专门 decoder 把这些 token 转成图像。这个 decoder 经过蒸馏后只需 8 步推理，目的是把统一建模和高质量生成拆成两个相对独立的问题：前者由 dLLM 解决，后者由 decoder 解决。相比把所有视觉细节都塞进统一 backbone，这样更符合容量分工，也更容易扩展到高分辨率生成。

The tokenizer is central. Instead of a standard reconstruction-driven VQ tokenizer, the paper introduces SigLIP-VQ to convert continuous visual inputs into fully semantic discrete tokens. The goal is not just compression, but semantic usability. Traditional VQ tokens often preserve local texture and reconstruction detail, which can help generation but are weak for understanding; stronger compression then hurts generation as well. SigLIP-VQ is designed to produce discrete visual units that are useful for reasoning while still serving as an intermediate representation for image synthesis.

The backbone is built on LLaDA2.0, a 16B MoE discrete diffusion language model. Rather than next-token prediction, it uses a shared block-level masked diffusion objective over both text and image tokens. The block-wise design matters. It is not token-by-token autoregression, but it is also not an unstructured fully bidirectional denoising process. It aims to balance parallel decoding efficiency with stronger contextual modeling. The paper also emphasizes modality-agnostic MoE routing, suggesting that experts are shared across text and vision instead of being hard-partitioned by modality. That is a stronger form of unification than simply concatenating modalities into one sequence.

The third component is a diffusion decoder. Because the backbone predicts semantic discrete visual tokens rather than reconstruction-ready image codes, a dedicated decoder is needed to turn those tokens into high-fidelity images. This decoder is distilled to run in only 8 inference steps. Architecturally, this is a clean decomposition: the dLLM handles unified semantic modeling, while the decoder handles visual detail synthesis. Compared with forcing the backbone to carry all low-level image detail, this is a more scalable allocation of capacity.

Training is described as a curated large-scale, multi-stage pipeline. The excerpt here does not include all stage details, but the likely structure includes tokenizer training, unified multimodal dLLM training, decoder distillation, and staged mixing of understanding and generation data. The key point is objective unification: both text and vision are optimized in the backbone with the same masked diffusion objective, instead of using AR for text and diffusion for images and then balancing heterogeneous losses.

On inference, the paper adds two practical optimizations. First, prefix-aware decoding reduces redundant updates and recomputation for conditioned generation in the backbone. Second, few-step distillation compresses the decoder to 8 steps.
