RED-PIM: Reducing Data Movement for Transformers using Processing-in-Memory

Transformer自注意力操作需要O(N²)级别的数据移动，且生成的N×N注意力图远大于单个HBM存储体（bank）的容量。现有存内计算（PIM）方案需要将注意力数据拆分到多个bank，引入高额跨bank通信开销，抵消了PIM减少数据移动的收益，难以支撑长序列场景。

评关注底层硬件（PIM）与注意力算法的协同优化，虽然偏向体系结构，但其将数据移动复杂度降至 O(N) 的思路对理解和优化 LLM 推理瓶颈有一定启发。
