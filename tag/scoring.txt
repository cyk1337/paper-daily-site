17:T4ef,The method is deliberately lightweight and training-free. Instead of training a separate verifier, it reads how much each generated token attends back to visual tokens and uses that as a proxy for visual reference usage. The scoring has two levels. First, token-level calibration: each token is scored using both its generation likelihood and its visual lookback strength. This matters because plain likelihood over-rewards generic fluent tokens, while many visually decisive words are object, attribute, or relation tokens. Second, response-level aggregation: token scores are not simply averaged. They are aggregated under a visual relevance distribution that gives more weight to tokens with stronger visual reference usage. This separation is one of the paper’s better design choices. It distinguishes whether a token is visually supported from how much that token should matter for the final response score. Compared with prior approaches, LookBack avoids extra reward models, preference labels, and additional verification passes. Compared with pure confidence scoring, it explicitly injects image sensitivity. Compared with vision-only heuristics, it still preserves the model’s own uncertainty signal rather than replacing it with raw attention
