Learning from Interaction Experience via Localized Context Distillation

这篇论文解决的是部署后 LLM 如何从交互经验中持续学习。现有 context distillation 有一个两难：off-policy 方法让带 privileged context 的 teacher 生成完整修正轨迹，监督信号清楚，但训练状态来自 teacher，和学生推理时自己的状态分布不一致；on-policy 方法在学生自己的 rollout 上让 teacher 给监督，状态分布一致，但当学生从未走到正确行为附近时，监督很难把新行为注入进去。LoCD 的目标是在“低 exposure bias”和“能学到新行为”之间找到更好的训练位置。

评应读方法和消融；局部重写把 on-policy 分布和教师信号接起来，值得在内部 agent 轨迹上复现。
