Verus-SpecGym: An Agentic Environment for Evaluating Specification Autoformalization

论文研究代码 Agent 能否把自然语言编程题准确转写成形式化规格，而不只是生成能通过验证器的代码和证明。核心难点是规格本身是否忠实表达用户意图：过弱会放过错误程序，过强会拒绝正确程序。

评读评估协议和错误案例；它提醒代码能力评测不能把 verifier acceptance 当成语义正确。

Verus-SpecGym: An Agentic Environment for Evaluating Specification Autoformalization

这篇工作处理的不是“代码能否被形式化验证”，而是更前一层的问题：模型能否把自然语言里的编程意图，稳定地翻译成忠实的形式化规格。难点在于，形式验证只保证“代码满足规格”，并不保证“规格符合用户意图”。如果规格写弱了，错误程序也可能被证明正确；如果规格写强了，正确程序反而无法通过验证。论文抓住了这个瓶颈，并把问题具体化为 specification autoformalization：给定 Codeforces 风格的自然语言题面，生成 Verus 规格，并判断该规格是否真正刻画了题意。

评规格自动形式化是代码推理能力的新评测方向，对抗性评测设计值得关注；对预训练研究员来说，了解评测方法即可，无需深入。
Anmol Agarwal,Natalie Neamtu,Pranjal Aggarwal,Seungone Kim,Jannis Limperg,Cedric Flamant,Kanna Shimizu,Bryan Parno,Sean Welleck
