第一层是构造 candidate pool。对每个问题，除了离线 expert trajectory 之外，作者还从当前模型按 on-policy rollout 采样多条解答，并通过可验证器筛出正确轨迹。这样每道题不再只有一条离线答案，而是有 expert + verified self-generated trajectories 的局部候选集合。

第二层是估计 problem-level solvability。作者用当前策略在该题上的 rollout 成功率，作为这道题对当前模型而言的“可解性”指标。这个量不是看 token 置信度，也不是看 expert 轨迹内部哪些 token 难学，而是直接问：模型自己能不能把题做出来。若成功率低，说明当前策略确实需要更强的 expert 纠偏；若成功率高，说明模型已经掌握了这类题的某些有效路径，此时继续强压单条 expert 轨迹，收益会下降，甚至会伤害已有分布。

第三层是基于 solvability 做 trajectory-level adaptive weighting，并加入 reference-constrained regularization。论文的表述里，RASFT 并不把问题显式写成 RL 的 reward/advantage 优化，而是把 expert 轨迹和模型自己生成的正确轨迹都视为“对齐候选”，然后根据 problem solvability 动态调整它们的训练权重：难题更偏向 expert，易题则放松对 expert 的刚性模仿，并允许正确的 self-rollouts 参与训练。与此同时，作者引入 frozen reference model 与当前 policy 的逆比率约束，用来抑制过度 policy drift。这个设计和 ASFT 一类 reference anchoring 有相似处，但这里的作用不是单纯稳定训练，而是更保守地“激活”模型已有推理能力，避免被新一轮 imitation 覆盖。

和已有方法相比，区别比较清楚。DFT、ASFT、ProFiT 都是在 expert trajectory 内部重加权，关注 token-level 或 objective-level 的拟合强弱；RASFT 则把适应性提升到 problem level，并显式利用 on-policy rollout 的可验证结果来决定 supervision strength。它不是简单把正确 self-generated data 混进来，而是先判断这道题当前是否还需要 expert 作为主导信号。d:T779,The method replaces the fixed expert-only target with a policy-conditioned candidate set and problem-level adaptive weighting.

First, for each problem, RASFT builds a local candidate pool containing the offline expert trajectory and verified correct trajectories sampled from the current policy. This is important: the model is not only trained on static demonstrations, but also on its own successful rollouts when they are available.

Second, it estimates a problem-level solvability score from the success rate of on-policy rollouts. This score is the central control signal. It does not ask which tokens in the expert trace are easy or hard. Instead, it asks whether the current model can already solve the problem. Low solvability means the model still needs strong expert correction; high solvability means strict imitation of one expert path is less necessary and may even be harmful.

Third, RASFT performs trajectory-level adaptive supervision. Expert trajectories receive higher influence on hard problems, while correct self-generated trajectories are allowed to contribute more on problems the model can already solve reliably. The paper frames this as policy-aware regularized SFT rather than explicit RL with rewards and advantages. In addition, it introduces an inverse-ratio constraint between a frozen reference model and the current policy to limit excessive policy drift. This reference anchoring is not only for optimization stability; it is meant to preserve the model’s existing reasoning distribution and avoid overwriting it through aggressive imitation.

Relative to prior SFT variants, the distinction is clear. DFT, ASFT, and ProFiT mainly adapt supervision within the demonstration, typically at token or objective level. RASFT moves adaptivity to the problem level and uses verified on-policy behavior to decide how much expert guidance is needed. The fix is simple—move the gradient copy outside the conditional so it runs after every micro-batch accumulation—but the paper goes beyond code inspection and validates the patch against two independent references: a GPU-resident DeepSpeed optimizer in OpenRLHF and a PyTorch FSDP optimizer in verl. After the fix, loss trajectories and gradient norms align across implementations.

The second layer is the loss aggregation bug. In standard SFT, cross-entropy should be computed as the total loss over all valid response tokens divided by the total number of valid tokens, i.e. a global per-token mean. OpenRLHF, Llama-Factory, and earlier verl versions instead compute local means within each mini-batch and then average those means across gradient accumulation steps or distributed ranks. Because mini-batches contain different numbers of active response tokens, this gives equal weight to each mini-batch rather than each token, distorting the contribution of short and long samples. The correct fix is to aggregate token-level loss sums and token counts first, then divide once globally.

Motivated by prior work showing that parameter groups play different roles in factual storage and task behavior, the authors freeze selected subsets of parameters during SFT. The key observation is that the model can still learn the downstream task format and behavior while becoming much worse at absorbing new facts, and this reduction in factual plasticity sharply lowers forgetting on old facts. The point is not that freezing is universally optimal, but that it provides a clean intervention showing that task learning and factual writing are not fully coupled.

Third, the paper applies self-distillation as a continual-learning regularizer. During SFT, the current model is trained not only on supervised targets but also to stay close to its own pre-update output distribution, limiting output-distribution drift. This is similar in spirit to KL-based regularization, but the role here is specific: preserve old factual behavior while still allowing new factual acquisition. The mechanism section strengthens this interpretation with synthetic-fact experiments. The authors vary the surface form of new entities: either name-like strings, which are likely to live near existing entities in representation space, or UUID-like identifiers, which are not. If forgetting were mainly due to global capacity limits or generic behavior cloning, both conditions should behave similarly. Instead, forgetting rises strongly with scale for name-like entities, while UUID-based entities induce almost no forgetting even with 1M new facts. This points to representational overlap as the main driver.
