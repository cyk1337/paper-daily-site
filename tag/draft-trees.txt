18:T4ba,TreeSpark builds on DSpark. A small bidirectional backbone runs once over a block of masked positions and emits hidden states and base logits U_d for each draft depth. DSpark also has a low-rank Markov head B(x,v)=<W1[x],W2[v]> that adds a transition bias from parent token x to candidate token v. TreeSpark uses this existing Markov head to construct parent-conditioned child distributions for every concrete tree node. Evaluating another parent requires only an embedding lookup and a rank-r matrix-vector product, not another backbone pass. Raw proposal probability q0 is then calibrated with target-verification labels using a two-parameter map p_hat = sigmoid(a logit(q0)+b), fitted only on edges whose ancestors were accepted. Nodes are prioritized by the product of calibrated edge probabilities along the path, and expansion stops when the best remaining path survival score falls below a threshold theta. The runtime selects theta from a load-dependent ladder. For nonzero-temperature decoding, TreeSpark samples siblings without replacement from the residual q_T and reconstructs the proposal during recursive rejection sampling. This avoids the bias introduced by deterministic top-k tree expansion.19:T4b0,CaDDTree reframes draft-tree construction as throughput maximization.
- Setup: a block-diffusion drafter produces per-position marginals q_i in one forward pass (factorized joint Q), enabling tractable computation of node/prefix probabilities used by DDTree-style methods.
- Limitation of prior work: maximizing expected accepted length under Q (a surrogate for the target model) is non-decreasing in the node budget n=|T|, so it cannot determine the right budget; existing adaptive-shape methods still fix n offline.
- Key change: define a per-round throughput objective, roughly E[1+α(T)] / (draft_cost(n)+verify_cost(n)), where α is the number of accepted tokens and costs are explicit functions of tree size.
- Main theoretical lever: under a mild convexity assumption on verification cost (increasing marginal cost with n), throughput as a function of n becomes unimodal. This reduces budget selection to an efficient 1D search/greedy procedure that jointly grows the tree and decides when to stop, enabling per-round budget adaptation.
