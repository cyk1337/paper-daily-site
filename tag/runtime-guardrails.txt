19:T45c,ClawGuard is a runtime security framework enforcing a user-confirmed rule set at every tool-call boundary:
1) One-time pre-session rule induction: before the first tool call, automatically derive task-specific access constraints from the user’s objective and have the user confirm them, producing ℛ_task that is uncontaminated by adversarial tool outputs.
2) Per-tool-call enforcement with ℛ = ℛ_base ∪ ℛ_task via four components:
- Content Sanitizer: redact sensitive spans from outgoing tool arguments and incoming tool outputs before they enter the conversation history;
- Rule Evaluator: check each proposed tool call against rules covering tool invocations, local file paths, and outbound network destinations;
- Skill Inspector: automated risk assessment + mandatory user confirmation before first skill execution;
- Approval Mechanism + Audit Log: route ambiguous calls to the user for explicit authorization and record all events for auditing.
