The Working Set of a Coding Agent: Coherence Debt in Repository-Scale Tasks

这篇论文研究 repository-scale coding agent 的一个很具体也很关键的问题：模型在做跨文件修改时，真正决定成败的不是“上下文长不长”或“会不会分解任务”，而是编辑当下所需的耦合事实是否可用。作者把这些事实的可用来源分成两条通道：最近上下文中的 read-derived facts，以及模型参数里已经记住的 parametric memory。若某个必要事实两条通道都覆盖不到，就形成 coherence debt，模型会在不完整世界模型下继续写代码，导致局部看似合理、全局却不一致的补丁。论文要回答的是：这两条通道能否互相替代，缺失事实到底造成多大损失，以及现有基于“读了什么”的诊断方法为什么经常看不清真正的问题。

评这篇的价值在于把“代码 Agent 不会做”拆成“事实拿不到”；先看 rename 故障和 distance 无关那组结果，它会直接影响你对 parametric memory 与 context engineering 的判断。
Bardia Mohammadi,Lars Klein,Aman Chadha,Akhil Arora,Laurent Bindschaedler
