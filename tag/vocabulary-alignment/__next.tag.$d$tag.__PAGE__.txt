9:T47f,VASAE (Vocabulary-Aligned SAE) adds a soft anchoring objective to standard SAEs so that each learned decoder direction stays close to some token embedding.
- Training target: SAEs are trained on post-residual stream activations in decoder-only Transformers; dictionary features are decoder columns; sparse codes reconstruct activations.
- Key issue: standard SAE features can reconstruct well while being far from vocabulary directions; conversely, hard-tying the SAE decoder to the token embedding matrix overly constrains the dictionary and hurts reconstruction.
- Proposed fix: augment the SAE loss with a vocabulary-aligned anchor term. For each feature direction, identify its nearest token embedding as an anchor and penalize distance to it with coefficient λ_anchor (soft constraint). After training, the nearest token string becomes the feature’s intrinsic name.
- Diagnostics: define a nearest-token alignment score and report the fraction of features exceeding a threshold (0.8 in the paper).
