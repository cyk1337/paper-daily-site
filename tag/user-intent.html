How You Ask Shapes What You Get: A Theory-Seeded Measurement of Articulation in Advice-Seeking LLM Conversations

这篇论文研究的是自然聊天数据中“用户如何提问”是否有稳定结构，而不是把表达差异当作提示词噪声。对象限定在 advice-seeking first-turn prompts，即用户希望模型帮助自己做选择、给建议、推荐方案的首轮请求。核心问题是：articulation，也就是约束是否明确、上下文是否可用、是否列出备选项、语气是否犹豫等表达方式，能否形成与 topic 分离的低维结构；以及这种结构是否会系统性影响模型回复。

评对 user prompt 分布的细致分析，区分了 topic 和 articulation，对构建更鲁棒的 eval set 和理解真实用户分布有启发，可看特征提取部分。
Juneha Baek,Suhyeon Lee,Donghyuk Shin

LLMs Get Lost in Evolving User Intent

这项工作研究 LLM 在多轮交互中能否持续追踪变化的用户意图。问题设定比普通多轮对话更具体：用户不会一次性给出完整需求，而是在对话中逐步披露信息、修改先前约束，或在完成一个子任务后切换到相关任务。模型最后仍需要按最新意图执行正确动作。

评将静态 benchmark 转化为多轮动态意图测试的思路很实用，适合关注 agent 评测和长上下文意图跟踪的研究员。
Jihoon Tack,Philippe Laban,Jennifer Neville
