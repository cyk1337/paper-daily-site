Atria Dawn: The Dawn of Agentic Superintelligence

这篇工作要解决的不是单点 agent 能力，而是一个更难的问题：怎样把“可验证的工具交互经验”系统化地变成 foundation agent 的通用能力，并进一步观察这种 agent 在真实研发流程里到底承担了什么角色。论文把问题拆成两层。第一层是训练层：普通静态文本预训练很难覆盖长程工具使用、环境反馈、失败恢复、产物校验这些行为；如果没有外部可验证信号，agent 学到的往往只是表面格式，而不是可复用的工作流能力。第二层是组织层：当 agent 开始参与模型研发本身，单看 benchmark 分数已经不够，需要知道它是在提出方法、执行实验、诊断错误，还是只是在做低层劳动。Atria Dawn 试图同时回答这两层问题。

评看 Verifiable Experience Pipeline 和任务日志分析；性能表先打折，标题过满但训练信号设计值得拆。
