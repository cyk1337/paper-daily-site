Same Bytes, Different Authority: Reserved-Token Representations in Chat-Template Prompt Injection

这篇论文解决的是 chat-template prompt injection 里一个此前没有被真正拆开的核心问题：攻击之所以有效，到底主要来自伪造 marker 的可见文本形式，还是来自这些 marker 被 tokenizer 编成 reserved token 后对应的特殊 token id 与其学习到的 embedding。作者把这两个因素在“字节完全相同”的条件下分离出来，发现对不少模型来说，攻击权威性主要来自 reserved-token representation，而不是字符串表面长得像 system/user/tool 边界。换句话说，同样的字节序列，只要服务器端 tokenizer 让模型看到的是保留 token id，而不是普通子词，攻击强度就会显著不同。

评应立刻查自家 tokenizer 和 chat template；同字节不同 token 权限这个消融很干净，会改变安全评测口径。
Yan Zhan,Yunze Song,Mengkai Hou,Wanting Zhang,Shaobo Liu,Zhijun Gao
