18:T442,AdaptiveSpec has two adaptive components. The first is margin-based lossy verification. At the first mismatch between the draft token and the target model’s top-1 token, the method checks the ratio between the target probability assigned to the drafted token and the target probability of its own top-1 token. If the ratio exceeds a threshold, the drafted token is promoted and accepted. The rule uses logits already computed by the target model, requires no semantic-equivalence verifier, and avoids FLy’s dependence on a downstream window of W tokens without further mismatches. The second component is dynamic tree shaping. At each decoding step, the system adjusts the draft-tree parameters, including n_steps, top-k, and ndt, using a draft confidence score based on the draft model’s top-1 probability and a rolling acceptance history.
