RegMix-D: Dynamic Data Mixing via Proxy Training Trajectories

这篇论文解决的是预训练数据配比里的一个老问题：不同语料域的最优 mixture 并不是整个训练过程都不变，但现有像 RegMix 这样的做法只用 proxy run 的终点 loss 去选一个静态配比，等于默认“全程一个最优解”。作者要做的是在不引入复杂额外训练机制的前提下，把 proxy 训练轨迹里的时序信息利用起来，得到随训练阶段变化的动态 data mixture schedule。

评应在内部 data-mixture ablation 里复现；重点看 trajectory 信号是否真能跨尺度迁移。

FastMix: Fast Data Mixture Optimization via Gradient Descent

评把 mixture search 从黑盒扫参变成可微双层优化，直接对应 data ratio 调参的真实痛点；应在内部小规模 proxy 上复现这个 reweighting 等价关系。
