PROBE: Manipulation-Grounded Visual Question Answering with VLM Agents

这篇工作要解决的问题，不是一般的静态图像 VQA，而是“必须先动手，才能看见答案”的闭环 VLM agent 评测与训练问题。具体说，它把问题定义为 Manipulation-Grounded VQA：初始视角下证据可能被遮挡，模型需要先判断是否需要操作，再调用感知与操作工具，最后基于更新后的场景回答问题。难点不在单次视觉理解，而在多步交互中的决策、状态更新、遮挡消除和工具使用策略。

评具身 agent 评测资产多于方法创新；看任务定义和失败类型，别把机器人桌面结论当通用 agent scaling 信号。
Vineet Bhat,Siyi Chen,Alex Zook,Xuning Yang,Stan Birchfield,Valts Blukis,Jonathan Tremblay
