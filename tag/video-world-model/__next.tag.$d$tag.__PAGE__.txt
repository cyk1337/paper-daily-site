Long videos are generated chunk by chunk: recent clean latents are kept as a sliding temporal context, while the newly generated chunk is appended to the history archive. The new component is an implicit memory module. A memory encoder maps historical latent frames into a compact representation, initialized from pretrained 3D representation encoders to inherit a 3D inductive bias. The memory encoder, the pose-conditioned readout module, and the video DiT are then jointly optimized so the memory space co-adapts to the DiT token space. The key design is pose-guided readout: given the target camera trajectory, the model extracts a fixed number of memory tokens that are relevant to the requested viewpoints.
