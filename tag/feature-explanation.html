Descriptive Collision in Sparse Autoencoder Auto-Interpretability: When One Explanation Describes Many Features

这篇工作讨论的不是 SAE 特征本身是否可解释，而是“解释是否能唯一指向特征”。作者指出，现有 auto-interpretability 评估默认把问题设成：给定一个特征，解释是否准确描述它的激活模式；但即便解释是对的，也可能同时适用于很多别的特征。作者把这种 many-features-to-one-explanation 的现象定义为 descriptive collision，并把它和 polysemanticity 区分开：polysemanticity 是一个特征对应多个语义，collision 是多个特征共享同一个语义描述。前者损害解释完整性，后者损害解释辨识性。论文要解决的核心问题，就是现有基于自然语言解释的 SAE 自动解释与打分体系，是否真的在“识别 feature”，还是只是在给 feature 所在的粗语义簇贴标签。

评揭示了 SAE 自动解释中的 'descriptive collision' 现象（多个 feature 对应同一个解释），对做 mech interp 和特征级控制的研究员是很好的避坑指南，建议看量化分析部分。
Jordan F. McCann
