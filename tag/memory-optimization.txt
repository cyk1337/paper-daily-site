19:T5ae,The first component is offline top-K logit distillation. For each token position, the teacher’s top-K probabilities and indices are cached once, with K=100 in the main setup. Importantly, the retained mass M is not renormalized to 1. Instead, the forward KL is rewritten exactly for a truncated teacher distribution: the loss decomposes into a teacher-entropy term, a cross term over the retained support, and an M log Z term that depends on the student’s full-vocabulary log-normalizer. This means the implementation only needs to gather student logits on the top-K support plus compute a scalar logsumexp over the vocabulary, rather than materializing dense teacher and student distributions. The paper discusses three mathematically equivalent offline variants, differing only in how densely they instantiate tensors. The second component is a fused, chunked KL loss. Borrowing from recent fused CE kernels, the authors fuse the output projection with the loss and chunk along the sequence dimension so that dense B×S×V tensors are never materialized. Because the target is a sparse teacher rather than a one-hot label, the gradient differs from standard CE: support tokens subtract teacher mass, while off-support tokens only enter through the truncated mass M times the student softmax. This yields a sparse forward-KL kernel whose peak memory scales roughly linearly with sequence length, enabling longer-context distillation on a single GPU.1a:T50a,The system combines several memory-saving techniques. First, the frozen base model is stored with mixed-precision post-training quantization: most linear layers use INT4, the output head uses INT8, and input embeddings use INT16. Since the training setup assumes FP32 activations and FP32 matmul kernels, weights are dequantized on demand: quantized weights live off-chip, are materialized into FP32 only for the current forward or backward operation, and are immediately released afterward. Second, the paper introduces a checkpointing scheme that combines selective activation rematerialization with off-chip tensor offloading. The transformer is represented as an ordered sequence of compute nodes, such as embedding, decoder blocks, and output layer. Only selected boundary activations are cached, intermediate activations are recomputed during backward, and weights or tensors are loaded and evicted as needed. This differs from standard activation checkpointing because it jointly schedules recomputation and off-chip storage. Third, the output-side memory is reduced through softmax approximation over semantically relevant token subsets and logits masking. The contribution is best understood as an execution strategy for constrained training rather than a new adaptation objective.1b:T4fe,BAOC partitions trainable parameters into N disjoint blocks and assigns one optimizer configuration to each block. A configuration combines update mechanism and state precision, such as momentum usage, adaptive statistics, and low-precision states. The pipeline has four stages. First, it samples sparse gradient streams from each block; the default sampling rate is 0.1% of coordinates, fixed after sampling. Second, it computes lightweight block-level metrics with running statistics, including signals such as directional stability, scale anisotropy, and noise. Third, it converts these metrics into a mismatch-risk score for each block-configuration pair. Fourth, it solves a constrained mixed-integer linear program that minimizes total risk while satisfying optimizer-state memory and update-time budgets. The memory definition is careful: it counts only persistent optimizer-owned state tensors and excludes parameters, gradients, activations, scratch buffers, FP32 master weights, and EMA copies. Update time is normalized against AdamW16 and estimated with a lightweight one-step timing measurement.
