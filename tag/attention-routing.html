Language Models Can Control Their Own Attention

这篇论文解决的是长上下文解码时一个很现实的瓶颈：模型每生成一个 token，都要从 KV cache 里扫描几乎整个历史上下文，哪怕真正有用的只是一小部分位置。现有做法通常用外部代理分数去预选重要 token，但这类方法每步仍要做 O(N) 级别的 cache 读取或扫描。作者提出的问题更直接：既然模型自己在推理时已经隐含知道“接下来该看哪里”，能不能把这个信息显式说出来，并直接驱动稀疏注意力，而不是再用一个外部机制去猜？

评这篇会改变你对“长上下文必须靠外部检索/代理打分裁剪”的 prior；先看方法接口和消融，若结果站得住，内部应立刻复现这种 model-runtime 协议。

Chiaroscuro Attention: Spending Compute in the Dark

这篇工作想解决的是 Transformer 在所有 token、所有层上一视同仁地做 full self-attention 所带来的计算浪费。作者的判断是，不同 token 的跨 token 交互需求并不相同：有些 token 结构平滑、局部可预测，不值得付出 O(n^2 d) 的代价；只有少数高复杂度 token 真正需要动态全局交互。核心问题因此不是再做一种统一的 attention 近似，而是能否给每个 token 一个有理论依据的复杂度信号，再据此在层内切换不同 operator。

评混合算子架构的干净消融很有参考价值，路由坍塌的发现对架构选型有直接指导，重点看第4节的消融实验。
Prateek Kumar Sikdar
