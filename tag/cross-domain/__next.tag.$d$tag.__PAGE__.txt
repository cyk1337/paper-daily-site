9:T604,The core contribution is FrontierChallenge, a cross-domain benchmark of end-to-end scientific workflows. The full collection contains 300 tasks; 97 are released and evaluated in this work, while 203 remain held out internally. The released tasks span six domains: quantum chemistry, molecular dynamics, materials characterization, analytical chemistry, life science, and electrochemistry/environment.

Each task is packaged as a self-contained unit with aligned components including a task description, fixed inputs, an execution environment, a deliverable contract, and a task-specific grader. The curation follows four principles: representativeness, complexity, diversity, and verifiability. In practice, that means tasks must resemble real professional workflows, require dependency-aware multi-step execution, avoid trivial template variation, and support automated, repeatable scoring through files, numerical checks, plots, or explicit acceptance criteria.

The evaluation protocol is built around two metrics. Pass Rate is the primary metric and requires satisfying the full task contract. Avg. Score is secondary and measures partial progress under task-specific rubrics. This distinction is central to the paper: many agents can produce some correct intermediate outputs, but still fail the workflow because the final bundle is incomplete, inconsistent, or not reproducible. The authors evaluate 12 frontier models under 3 agent scaffolds and also analyze 970 Claude Code trajectories to characterize failure modes and end states.a:T5c7,The released benchmark contains 97 tasks, evaluated with 12 frontier models and 3 agent scaffolds. Tasks require real scientific software such as ORCA, CP2K, LAMMPS, AmberTools, and PLUMED, and demand executable code, quantitative analysis, visualizations, and evidence-grounded reports.

The main empirical result is a large gap between partial progress and full completion. The best-performing configurations—GPT-5.6 Sol with Codex and Grok 4.6 with Claude Code—complete only 20 of 97 tasks, corresponding to a Pass Rate of 20.6%. Yet the highest Avg. Score reaches 87.9. So the models often make substantial progress on substeps while still failing to satisfy the complete deliverable contract.

This gap is even sharper in some domains. In analytical chemistry, the highest Avg. Score is 87.6, but the best Pass Rate is only 4%. In electrochemistry/environment, the highest Avg. Score is 94.9, while the best Pass Rate is 0%. That pattern suggests the bottleneck is often not local scientific knowledge alone, but end-to-end execution reliability: file organization, consistency across outputs, formatting constraints, edge-case handling, and coherence among code, figures, tables, and prose.

The paper also includes failure analysis through contract-breach signatures and final-status/error behavior in 970 Claude Code trajectories.
