1a:T4af,PIPO changes the basic decoding unit from a single token to a token pair. On the input side, a compressor MLP takes the concatenation of two consecutive token embeddings and maps them to one latent vector. The compressor is initialized so that f([a;b]) is close to a+b, which keeps the initial input distribution closer to what the backbone has seen. On the output side, the backbone predicts the first next-token distribution, while an MTP or draft head predicts the second token distribution. A confidence head predicts whether the draft token should be accepted. During training, the label for this confidence head is derived from the speculative acceptance probability min(p_t/p_s, 1), where p_t comes from the teacher and p_s from the student or draft model in OPD. At inference time, if the confidence exceeds a threshold, the draft token is accepted; otherwise it is replaced by a padding token before the next compression step, preserving the pair-level interface. Compared with EAGLE-style speculative decoding, the expensive verifier pass is replaced by a small head.
