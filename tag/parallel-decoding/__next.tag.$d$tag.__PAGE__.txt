1) TSPD (Temporal-Spatial Parallel Decoding): a lightweight temporal-spatial controller predicts, per position, whether a token is ready to be fixed/committed. Inputs are short-horizon trajectory features over recent steps—confidence, entropy, and a momentum-like change statistic—augmented with relative position within a block to capture positional effects. A shared sequential perception model is used to recognize regimes that defeat step-local rules (steady growth, underconfident-but-correct, oscillatory confidence, delayed stabilization).
2) CE (Confidence Extrapolation): a training-free plug-in module that models confidence evolution with a simple state-space process, forecasting near-future confidence along with uncertainty. A risk-aware horizon rule limits look-ahead based on forecast uncertainty and left-context progress, so extrapolation is only applied when the recent trace supports it.
TSPD improves the correctness of commit decisions; CE reduces “waiting time” when trends are predictable. Both operate purely at decoding time and are designed to compose with system optimizations like KV caching.18:T5be,The method, CLAD, has three main components. First, it builds confidence-induced clusters (CICs). At a denoising step, the decoder computes token-level confidence for masked positions and merges adjacent high-confidence masked tokens into maximal contiguous spans. Each span becomes a candidate update unit. The underlying assumption is simple but important: neighboring confident positions are often supported by the same local context and can be committed together. Second, CLAD estimates dependencies between clusters. Instead of training an auxiliary module, it reuses self-attention maps from the same forward pass, aggregates token-level interactions into inter-cluster dependency scores, and constructs a conflict graph. To keep the graph sparse, it retains only mutually strongest inter-cluster dependencies. This pruning is important; otherwise the graph becomes too dense and the decoder turns overly conservative. Third, CLAD selects a maximum-weight set of non-conflicting clusters for parallel commitment. Cluster weights come from aggregated confidence. This turns each denoising step into a constrained combinatorial selection problem rather than independent token ranking. Relative to token-level dependency-aware methods such as DAPD and DAWN, the key difference is not merely using attention at cluster level. The deeper change is the two-stage decomposition: define locally reliable span candidates first, then resolve global compatibility among them.19:T4d7,The evaluation covers mathematical reasoning and code generation, using pretrained MDLMs from the LLaDA and Dream families on four benchmarks. Two aspects are important. First, the supervision comes from the model itself rather than external labels. Second, the estimator predicts the full pairwise MI matrix in one pass rather than computing each pair separately.

The motivation is straightforward. Standard MDM training learns marginals such as p(x_i | x_t), which are enough for denoising but not enough for deciding which positions can be safely sampled in parallel. To recover dependence information, the authors derive ground-truth MI targets from the model’s own conditional distributions and then train an auxiliary network to regress those MI values from hidden states. This avoids the usual difficulty of high-dimensional density estimation in classical MI estimation and avoids expensive pairwise enumeration at inference time.

From the paper’s description, the estimator takes position-wise hidden representations from the MDM backbone and outputs an L by L matrix of pairwise MI predictions. That is a practical design for inference because it turns dependency estimation into a single structured prediction problem rather than O(L^2) separate queries.

The estimated MI is then used in two ways. First, for interpretation: the authors visualize which positions the model considers strongly dependent in Sudoku and protein sequences. Second, for MI-guided parallel decoding: they sample together only subsets of variables that are approximately conditionally independent, instead of relying on confidence-based unmasking.
