9:T724,The setup is formalized as follows. Let q be the parallel drafter with block length L. Its distribution at position l, q_l(.|c), depends only on the current context c. The verifier p is autoregressive, so its distribution at the same position is p_l(.|c, x_<l), which depends on the sampled prefix inside the current draft block. Therefore, for a fixed student head q_l, different sampled drafts induce different teacher distributions. Existing on-policy distillation methods effectively supervise the same student prediction with these separate, potentially conflicting conditional targets. This creates an averaging problem: the student is asked to imitate multiple incompatible teacher views while lacking access to the within-block prefix that generated them.

MDraft solves this by aggregating verifier feedback across multiple drafts before constructing the training target. Intuitively, it tries to estimate which tokens are broadly useful for acceptance at a given position under the distribution of plausible prefixes, rather than which token is preferred under one particular sampled prefix. That is a better match to the structure of the parallel drafter, because the drafter cannot observe those prefixes in the first place.

The key contribution is therefore not a new model architecture but a new teacher-target construction for on-policy distillation. Instead of forcing an autoregressive conditional distribution directly onto a prefix-agnostic parallel student, MDraft approximates a marginal target over multiple sampled drafts. The paper’s argument is strong on this point: if the real objective is to maximize speculative acceptance rather than to minimize teacher cross-entropy under a mismatched conditioning structure, then the training target should reflect acceptance utility across possible prefixes.a:T4a5,The main metric is acceptance length, not standard language-model perplexity. The authors fine-tune parallel drafters and evaluate them on mathematical, coding, and conversational benchmarks. MDraft achieves the best overall mean acceptance length among the on-policy distillation baselines considered, meaning that the verifier accepts more drafted tokens per pass and speculative decoding becomes more efficient. The abstract does not expose the full numeric table, but the body indicates that the gains are consistent across task types rather than confined to a single domain.

More importantly, the experiments support the mechanism claim. When verifier targets from different sampled prefixes are distilled separately, the student becomes overly conservative and acceptance drops. Aggregating verifier information across multiple drafts produces a student distribution that better matches what the verifier is willing to accept in actual use. If you read the full paper, the most informative ablations are likely the number of drafts used for aggregation, the block length L, and the exact aggregation rule, since these directly test whether the method is solving the stated mismatch.b:Taa6,方法由三个关键部件组成。

第一，训练目标。作者采用 uniform token replacement 而不是 mask corruption。也就是每个位置以概率 1-α_t 被替换成词表中的均匀随机 token，而不是替换成特殊 [MASK]。这样得到的输入始终是一份“完整草稿”，错误 token 没有显式标记，模型必须同时学会两件事：当当前位置本来就对时要保留，当它错时要修复。训练时在所有位置上监督 clean-token posterior，等价于让 denoiser 在完整但带噪的草稿上做全位置重建。

第二，单次前向的上下文评估。直接拿 denoiser 对当前 token 的概率给草稿打分会有偏差，因为在 uniform corruption 信道下，观察到 token x_i 本身会显著提高 x_i 为真的后验概率，即便把该位置拿掉后，周围上下文其实更支持另一个 token。作者用已知的 corruption process 做 Bayes 校正，把“观察到自身 token 带来的证据”除掉，再重归一化，恢复出该位置的 cavity conditional，也就是 p(x_i | c, z_{-i}, t) 这一类“给定条件和其他 noisy token，但不看自己”的分布。然后把草稿每个位置真实 token 的负对数 cavity conditional 相加，得到 cavity energy。这个量不是精确联合似然，而是一个噪声平滑后的 pseudo-likelihood 型能量分数，但足够用于候选草稿之间的比较。

第三，推理算法 propose-read-retain。推理不是标准 diffusion ancestral sampling，也不是每轮完全重启。流程是：保留当前最优草稿；对其做部分 re-noise，避免陷入局部最优，同时保留部分结构；用同一个 denoiser 对所有位置并行预测 clean token，直接形成 candidate draft；再用一次新的前向、在固定 read noise level 下计算 candidate 的 cavity energy；若能量更低则接受，否则保留旧草稿。所有 proposal pass 和 scoring pass 都计入固定预算，最后返回最低能量的草稿。这里有两个设计很关键：一是“提案”和“评估”分开，避免用生成时的同一组 logits 给自己背书；二是 retain best draft，而不是每轮独立采样，这使得搜索更像局部修订而不是盲目重启。

和已有方法相比，差异主要在三点。相对 MDLM/UDLM 一类离散 diffusion，作者不依赖 reverse transition 逐步采样，而是把 denoiser 的 clean-token 预测直接当作修订操作。相对普通 non-autoregressive refinement，作者补上了一个有理论依据的整稿评分机制，而不是默认并行替换一定更好。相对 energy-based LM，这里的能量不是单独训练的打分器，而是从 denoiser 的后验结构中解析出来的。c:T477,For pretraining and alternative language-modeling paradigms, the contribution is meaningful in three ways. First, it moves diffusion-style language modeling away from schedule-driven ancestral denoising toward a draft-refinement loop where the denoiser acts as both editor and evaluator. Second, it introduces cavity energy, which turns a denoiser trained under uniform corruption into a contextual whole-draft scoring mechanism resembling noise-smoothed pseudo-likelihood. That is relevant beyond this paper: masked LM, any-order LM, energy-based LM, and draft-based reasoning all face the same issue of scoring partially self-supported token configurations. Third, it identifies and fixes a subtle but important failure mode: denoiser confidence on an observed token mixes contextual support with evidence from seeing that token itself. If that self-token evidence is not removed, the model can prefer internally stable but wrong drafts. This is not a drop-in replacement for mainstream large-scale AR pretraining, but it is a serious step in the line of work that tries to challenge next-token decoding with alternative generation dynamics.d:T9f4,The method has three main components.

1) Training under uniform corruption. Instead of mask corruption, each token is independently replaced with a uniformly sampled vocabulary token with probability 1-α_t. The noisy input is therefore always a complete draft: every position contains an ordinary token, and wrong positions are unmarked. The denoiser is trained to reconstruct the clean sequence at every position. This forces it to learn both preservation and repair: keep a token when it is already supported, change it when the surrounding draft suggests it is wrong.

2) One-pass contextual evaluation via cavity correction. A naive score based on the denoiser probability of the current token is biased, because under the known corruption channel, observing token x_i itself is strong evidence in favor of x_i, even if the rest of the draft would support another token. The paper derives a correction that divides out this self-token likelihood and renormalizes, recovering the cavity conditional: the distribution of x_i given the condition and all other noisy draft tokens, but not the observed token at position i itself. Summing the negative log cavity probabilities assigned to the draft tokens yields cavity energy. This is not an exact joint likelihood; it is a learned, noise-smoothed pseudo-likelihood-style energy. But it is enough to rank candidate drafts.

3) Propose-read-retain inference. Inference starts from random tokens. At each round, the current retained draft is partially re-noised, then the same denoiser predicts clean tokens in parallel to form a candidate draft directly, without a diffusion reverse transition. A fresh forward pass at a fixed read level computes the candidate's cavity energy. The candidate is accepted only if its energy is lower; otherwise the retained draft stays. Proposal passes and scoring passes both count toward a fixed inference budget, and the final output is the lowest-energy draft seen so far.

The design differences from prior work are important. Compared with MDLM/UDLM-style discrete diffusion, the model does not rely on schedule-specific reverse transitions for generation; clean-token predictions are used directly as edits. Compared with generic non-autoregressive refinement, the paper adds a principled whole-draft evaluation rule instead of assuming that parallel local improvements compose globally. Compared with energy-based LM, the energy is not learned by a separate scorer; it is extracted from the denoiser's posterior structure using the known corruption process.e:T686,Experiments focus on synthetic reasoning tasks that require global consistency rather than fluent local continuation: Countdown, Sudoku-Extreme, and Maze-Hard. The model is small, only 6M parameters, which makes the comparison about generation dynamics rather than scale.

Main results: DRLM reaches 87.6% on Countdown-4, 44.4% on Countdown-5, 93.9% on Sudoku-Extreme, and 73.0% on Maze-Hard. Relative to the strongest diffusion baseline evaluated in the paper, the gains are +14.3, +34.1, +28.4, and +33.7 percentage points respectively. The size of the gains suggests that the benefit is not a minor decoding tweak; it comes from the proposal-and-evaluation loop itself.

The ablations are especially informative. Retaining the best draft matters: restarting independently or failing to preserve the lowest-energy draft hurts performance, which shows that the search accumulates structured improvements over time. Partial re-noising is better than either freezing the draft too aggressively or restarting from scratch, indicating a useful balance between preserving global structure and escaping local optima. Self-token correction is critical: without it, the model overvalues drafts whose tokens are merely self-supported by observation under the corruption channel. Separating proposal from evaluation with a fresh read pass also helps, meaning the logits used to generate a candidate should not be trusted as an unbiased score of that same candidate.

The largest gain appears on Countdown-5, which is consistent with the paper's claim: the harder the task depends on global compatibility among many local choices, the more valuable whole-draft evaluation becomes.f:T599,Read the paper in three passes.

First, focus on the cavity derivation. At inference time, auxiliaries are sampled from a prior and a parallel decoder maps them to a block of tokens in one model call. The dependencies among predicted tokens are routed through the auxiliary variables rather than through left-to-right token generation. Direct likelihood training is intractable because it requires marginalizing over auxiliaries; random auxiliary samples would almost never decode to a given training sequence. The paper therefore trains an autoregressive encoder q_theta(u_i | x_<=i) that proposes auxiliaries for observed sequences and optimizes an ELBO. Operationally, this gives a self-distillation-style objective with an autoregressive language modeling component and a parallel decoding component. The distinction from PTP is important: PLMs are trained from raw sequence data, not distilled from an existing AR model. The distinction from discrete diffusion is also clear: consistency is handled through latent variables in a single or few decoding calls rather than through iterative denoising.11:T6ef,DPara 的关键做法是把 DSpark-style drafter 拆成“重的 diffusion backbone”和“轻的 autoregressive head”。在 target model 正在 verify 当前 draft 时，DPara 不去猜最终 accepted prefix 和 bonus token，而是让 diffusion backbone 为所有可能的 acceptance boundary 预先计算 draft representations，并且暂时不绑定 bonus token。等 verification 结果返回后，真实的 accepted boundary 和 bonus token 已经确定，再由轻量 AR head 把这些信息接进去生成下一轮可用 draft。这样，概率性错误不再导致 backbone fallback；只要 backbone 能在 target verification window 内跑完，backbone 延迟就被完全隐藏，关键路径上只剩 AR head。

标准 DFlash 并不能直接满足这个使用方式，因为它通常依赖单个带有上下文 feature 的 anchor，而 DPara 需要同时覆盖多个 acceptance boundary，并从 feature-less anchors 预测。论文因此提出 M-DFlash：从公开 DSpark checkpoint 初始化，只 finetune diffusion backbone，让它适配 multiple-anchor、feature-less 的输入 regime；AR head 保持冻结，不引入新的可训练参数。这一点很重要，因为它说明 DPara 不是重新训练一个完整 drafter，而是用较小代价把已有 DSpark-style drafter 改造成适合并行排程的版本。

与 SSD/PEARL 这类方法相比，DPara 的差别不在于“更会猜 outcome”，而是不再把 overlap 建立在猜测 outcome 上。与普通 DSpark 相比，DPara 保留了 parallel drafter 的 acceptance 能力，同时把最重的 backbone 从串行 draft-verify 路径里拿掉。代价是需要为多个 boundary 准备 backbone 输出，并要求额外 drafting 设备或足够的同机资源来保证 overlap window。12:T68a,DPara exploits the internal structure of a DSpark-style drafter: a heavy diffusion backbone followed by a lightweight autoregressive head. While the target model verifies the current speculative block, DPara runs the diffusion backbone ahead of time for every possible acceptance boundary and leaves the bonus token unspecified. Once verification completes, the true accepted boundary and bonus token are known; the lightweight AR head then conditions on that outcome and produces the next draft tokens. As long as the backbone finishes within the target verification window, the dominant part of drafting latency is hidden, and only the AR head remains on the critical path.

A standard DFlash backbone is not directly suitable for this schedule. In the serial setting, it anchors prediction on a single token after a fully featured prefix. DPara needs predictions from multiple feature-less anchors, one for each possible acceptance boundary. The paper introduces M-DFlash by initializing from a published DSpark checkpoint and finetuning only the diffusion backbone for this multiple-anchor, feature-less regime. The AR head is kept frozen, and no new trainable parameters are added.

The key difference from SSD or PEARL is that DPara does not try to make a better guess about the accepted prefix or bonus token. It removes the need for that guess. The key difference from serial DSpark is that DPara keeps the strong parallel drafter but moves the expensive backbone computation out of the serial draft-verify path. The cost is extra boundary coverage work and a requirement that drafting resources be provisioned well enough to complete inside the verification window.13:T4d5,The evaluation uses Qwen3-8B and Qwen3-14B on math, coding, and chat benchmarks. The first is Learnable Block Size (LBS). The authors observe that token entropy across positions often follows a staircase-like pattern, suggesting that some positions—contiguous or even non-contiguous—share similar uncertainty and semantic coherence. Instead of using fixed-size blocks or heuristic boundaries such as delimiters, LBS uses a lightweight network to predict block groupings on the fly from token-level statistics, including entropy, positional information, and semantic cues. The goal is not syntactic chunking. It is difficulty-aware grouping: easy tokens should not be delayed by harder ones simply because they happen to sit in the same fixed block.

The second is Learnable Parallel Sampling (LPS). Standard confidence-based decoding finalizes a token only when its confidence exceeds a threshold. The paper argues that this wastes computation because many tokens become correct well before their confidence reaches that threshold. LPS learns a position-aware finalization policy using per-token features such as entropy, position, and denoising step. It predicts which positions have already converged enough to be finalized early. Because LBS already organizes tokens into variable-length groups, LPS can operate under adaptive blocks rather than fixed boundaries.
