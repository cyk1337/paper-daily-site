9:T5de,The method has two main pieces. First is a retrieval-based labeling pipeline. Starting from a corpus of user sessions, the system uses an off-the-shelf memory extractor (mem0 in the paper) to produce atomic candidate facts from each session. Under an infinite-budget construction, all extracted facts are added to a growing candidate memory pool. For each candidate fact, the pipeline scans future user turns. A turn is first judged on whether memory is needed; if memory is queried, retrieval is performed. A fact is labeled useful if it is retrieved in a later interaction and its content is actually incorporated into the model’s answer. An LLM judge is used to verify that the retrieved fact was genuinely used, reducing noise from superficial retrieval hits.

Second is Warm-Start UCB. The offline stage learns a shared utility pattern from historical users, providing a prior or initialization. The online stage adapts to a new user with an upper-confidence-bound algorithm under one-sided delayed feedback. Because feedback is observed only for admitted facts and only after an unknown delay, the problem is cast as an apple-tasting style decision process. UCB handles the exploration–exploitation trade-off by favoring facts with both high predicted value and high uncertainty. Compared with pure offline supervision, this explicitly models partial and delayed feedback. Compared with a cold-start contextual bandit, warm start uses population data to avoid learning each user from scratch.a:T4ba,From the provided full-text excerpt, the evaluation is built on PerMemBench-S and an additional longer-horizon synthetic benchmark, PerMemBench-L. The paper reports comparisons across different memory budgets and interaction lengths, against prior LLM-based gating baselines and an admit-all baseline. The main empirical claim is that Warm-Start UCB consistently outperforms both, suggesting that online personalization matters and that the retrieval-derived labels are useful for learning.

The most informative parts are likely not just the aggregate score tables but three supporting analyses. First, label-validity checks in the appendix test whether retrieval-based labels really correspond to future usefulness. Second, the paper analyzes which utility patterns are shared across users and which are user-specific; that directly motivates the two-stage design. Third, the theory argues that warm start helps leverage offline data while the online UCB component moves toward user-specific behavior.
