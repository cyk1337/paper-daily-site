18:T50c,The proposed circuit has three main parts. First, each label token stores the label identity as a value and the class of the preceding demonstration sentence as a key. About 20 middle-layer attention heads write this class key into the residual stream at label positions, in the sense of K-composition. Second, at the query position, about 90 upper-layer heads compute the class of the query sentence, attend to label slots whose stored keys match that class, and copy out the corresponding label identity. These readers behave like induction heads keyed by class rather than by token identity. Third, the readout is gated. Early duplicate-token heads detect whether labels have appeared more than once and pool this signal into a residual direction at the query. That direction lowers the readers’ logit for the position-0 attention sink. If no label repeats, the sink wins the softmax and the readers produce a near-null action. The paper also identifies roughly two dozen negative heads, called brakes, that oppose the most recent label bias; removing them nearly triples the margin but makes the model more biased toward the latest label. Compared with work that isolates induction heads or function vectors, the contribution is the composition of these pieces into a working algorithm.19:T4a0,The analysis covers Qwen3-4B, SmolLM3-3B, and Llama-3.2-3B. The tasks include two-class label retrieval and function selection with invented-word and natural labels, using up to 12 demonstrations. The interventions are built around matched prompt pairs that differ only in one span: a sentence, a label, or the query. The authors use activation patching, head and group ablations, position-level interventions, and residual steering, with matched controls such as random heads from the same layers and random directions of the same norm. Head sets selected on one prompt draw are validated on fresh draws. The logit accounting is unusually tight: contributions from all heads and MLPs reconstruct the model’s answer logit to within 0.05 nats. A notable empirical regularity is a simple softmax law for reader attention: attention to matching slots is described by the number of matching slots, total slots, and a null logit. Constants fitted on 12-demonstration prompts predict a one-slot-per-class regime in Qwen and Llama, but fail on longer prompts.
