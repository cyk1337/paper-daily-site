18:T4b6,The proposed method, GRAFT, stands for Graph-based Faithful Step-level credit assignment. It reorganizes multiple rollout trajectories from the same prompt into a trajectory graph instead of treating them as isolated chains. Nodes represent states and edges represent actions. State canonicalization merges identical or semantically similar states using exact matching or embedding-based similarity. The outgoing actions from a merged node then form an on-state action group, which is closer to the group required by the standard advantage definition. The method estimates node values by Bellman-style propagation over the graph using only terminal outcome rewards. Given these values, the step advantage is defined as A_t = gamma V(s_{t+1}) - V(s_t). The paper also introduces Graph GAE, extending generalized advantage estimation to the trajectory graph by aggregating multi-hop future advantage estimates. Compared with PRM-based approaches, GRAFT does not require step-level reward annotation. Compared with group normalization by step index, it avoids mixing different states into one baseline.
