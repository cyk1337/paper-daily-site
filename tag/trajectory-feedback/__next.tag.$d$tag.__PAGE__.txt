9:T56c,OptiMAS builds all agents on a shared ReAct-style execution primitive. Each agent alternates between thought, action, and observation. Multi-agent coordination is implemented through a proactive assign-deliver protocol: a parent agent delegates a subtask as a tool call, the sub-agent solves it, and the result is returned as a structured observation. This removes the need for a fixed workflow while still keeping execution structured.

The optimization scope covers prompts, role definitions, skill descriptions, tool access, model choices, and the directed collaboration graph among agents. To avoid unstable free-form code generation, tools are selected from a predefined macro-library. The collaboration graph is constrained to be a DAG, which helps prevent uncontrolled recursive delegation.

The main departure from search-based MAS evolution is the optimization loop. A candidate MAS runs on training tasks, producing full interaction trajectories and task-level metrics. These are converted into a textual loss signal for an agentic optimizer, which induces textual gradients and edits the MAS configuration. A dual-track memory mechanism stores, validates, and retrieves optimization insights across a long evolution horizon.
