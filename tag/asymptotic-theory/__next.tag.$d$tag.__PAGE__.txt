9:T502,The authors build a solvable model of chain-of-thought as iterative refinement in an in-context weight prediction problem. Instead of standard ICL next-label prediction, the model must infer the underlying linear regression weight vector from contextual examples. During pretraining, a single-layer linear self-attention model learns to map prompts to a weight estimate. At inference time, CoT is formalized as repeatedly applying the learned update rule to refine the current estimate. This turns CoT into an analyzable dynamical system rather than free-form text generation.

Using high-dimensional asymptotics and random matrix tools, the paper derives an exact expression for test generalization error as a function of reasoning depth, pretraining sample count, and context length. The analysis reveals four regimes: exponential improvement, polynomial improvement, saturation, and overthinking. Pretraining task diversity controls the stability of the iterative refinement and the optimal depth, while the number of in-context examples controls the per-step information gain and the asymptotic error floor.
