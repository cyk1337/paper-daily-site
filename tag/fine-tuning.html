Fine-Tuning Diffusion Language Models with Context Selection and Target Weighting

这篇论文处理 diffusion language model 在 SFT 阶段的一个核心训练问题：mask 不是一个无关紧要的数据增强，而是同时决定了模型能看到什么上下文、以及哪些 token 会产生监督信号。随机 mask 会把这两个决策混在一起，可能让模型在缺少关键证据时预测难 token，也可能把最有训练价值的 token 直接 reveal 掉，导致 SFT 效率低，甚至伤害 base model 的能力。GoldiMask 的目标是在每个样本内部协调“哪些 token 作为上下文暴露”和“哪些剩余 masked token 应该被更强监督”。

评应放进 diffusion LM 内部复现实验；它把 mask policy 从噪声日程问题推进到信息分配问题。

HEAT: Faster Fully Homomorphic Inference via Approximations-Weights Co-Adaptation

这篇工作处理的是 FHE 场景下 LLM 推理过慢的问题，但切入点不是重新设计一套加密友好模型，而是在保持原模型架构不变的前提下，降低推理时所需的乘法深度。全文的关键观察是：FHE 里真正拖慢延迟的，不只是非线性函数需要近似，而是这些近似通常用统一、保守的迭代次数配置，按最坏情况给全模型每个位置都配足精度，结果大量位置为并不需要的局部精度付出了额外乘法和 bootstrapping 成本。论文要解决的核心问题因此不是“如何做更准的近似”，而是“如何让每个近似位点只保留任务最终输出真正需要的精度，并让权重共同适应这种近似误差”。

评将 FHE 推理的非线性近似迭代次数作为可学习参数与权重联合微调，思路巧妙，对关注隐私计算和模型压缩的系统研究员有启发。

When Safety Routing Breaks: Understanding Alignment Fragility under Benign Fine-Tuning

论文研究一个很具体的问题：为什么已经对齐的 LLM 在只用少量无害数据做 SFT 后，拒答能力会迅速失效。作者认为主要原因不是有害样本、异常无害样本，或简单的 utility-safety 梯度冲突，而是安全拒答依赖一条低秩的输出侧 routing 通路。无害微调扰动了这条通路，使模型从“把有害表示路由到拒答”切换为“把有害表示路由到顺从回答”。

评不是安全应用文，而是在拆对齐到底刻在表示里还是刻在输出路由里；先看 Fisher 低秩和 output-side MLP 证据，若成立会影响你对 post-train 持久性的 prior。
