19:T48c,VisReflect replaces discrete localization (bbox / temporal interval tokens) with continuous reflection embeddings generated in the model’s latent space. A vision encoder produces visual tokens Z_v, projected into the LLM embedding space; the text query yields Z_q. Instead of outputting coordinates and triggering a second cropped forward pass, the model generates a small set of reflection tokens that attend sharply to the original visual tokens within the same forward pass. These reflection tokens act as latent retrieval queries, pulling salient regions/frames into the model’s effective attention budget and mitigating attention sink.

Key differences vs. tool-using zoom/crop methods:
- No discrete numeric prediction for localization, reducing sensitivity to small coordinate errors.
- No second visual re-encoding / extra prefilling, improving latency and compute.
- Mechanistically closer to latent routing/retrieval: a compact intermediary token set reshapes attention over a long visual sequence.
