9:T616,VISOR couples a diagnostic module (VSNR) with routed remediation.
- Two-pass decomposition: For each (image I, yes/no query), compute δ_vis = logit(yes|I) − logit(no|I). Then run the same query on a uniform gray null image I_∅ to get δ_prior = logit(yes|I_∅) − logit(no|I_∅), treated as a language-only bias estimate for the attribute word.
- Decision coordinate and layer tracing: Since the first answer token fixes the label under deterministic decoding, δ_vis=0 is the boundary. They also apply the final norm+LM head to intermediate layer states to define δ_vis^(l), and define SNR(w,l)=|E[δ_vis^(l)]|/Std[δ_vis^(l)] to localize where the decision-relevant visual signal becomes low-margin or misaligned.
- Mechanistic taxonomy: (1) threshold-correctable low-margin cases (direction correct, margin insufficient), reported more for color/state; (2) directional failures in the final yes/no logit space, reported more for material.
- Mechanism-aligned remediation (routed operators): Calib shifts the boundary using a calibrated prior term when the visual direction is correct but underweighted; Abstain handles low-SNR cases without training by refusing to answer; Adapt uses a targeted adapter to repair the visual projection/readout when the visual signal is directionally wrong.
