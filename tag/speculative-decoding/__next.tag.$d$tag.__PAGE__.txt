Instead of waiting until depth R is completed for the current token, LoopSpec samples an early draft from a shallower depth and immediately starts partial computation for the next token conditioned on that draft.

The first component is single-branch self-speculation. Given a prefix X, the model produces a first proposal at depth r1. Before the original branch reaches final depth R, the system appends that proposed token and starts computing recurrent steps for the following position. Once the original branch reaches p_R, the proposal is verified using exact speculative decoding / rejection sampling. If accepted, some work for the next token has already been done; if rejected, the computation rolls back to the verified prefix.

The second component is the main algorithmic addition: a residual second proposal from a deeper depth r2. Since deeper recurrent states are typically closer to the final distribution, LoopSpec generates a second proposal and launches an alternative continuation before the first proposal is fully verified. This is not just running two independent drafts. The paper defines the second proposal through a residual distribution construction so that probability mass not covered by the first proposal is handled correctly, while preserving exactness of the final sampling distribution.

The third component is gating. A fallback continuation is only created when the deeper recurrent state disagrees with the first draft. This avoids paying the overhead of a second speculative branch when the first proposal is already likely to be accepted. In other words, the system uses disagreement between intermediate depths as a trigger for extra speculative work.

The theory section is stronger than a typical systems paper. First, the authors prove that the restart probability depends only on the depth of the second proposal, not on the first proposal depth. Intuitively, once the first branch fails, what matters is how close the backup branch is to the final distribution. Second, they empirically observe a power-law decay in the TV distance between intermediate and final distributions, and derive closed-form optimal proposal depths from that decay. The predicted optima match measured best settings well, which gives a principled way to choose r1 and r2.

On the implementation side, the paper integrates LoopSpec into SGLang with branch-wise KV-cache management and CUDA Graph optimization. This matters because different speculative branches sit at different token positions and recurrent depths.
