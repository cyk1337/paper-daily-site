Second, it evaluates “losslessness” at the sequence level under different numerical precisions instead of relying on downstream task scores.

For training, the AR backbone is frozen and a diffusion view is trained to propose multiple future tokens in parallel. The main methodological change is the distillation data distribution. Rather than using generic human-written continuations, the authors build a teacher-generated corpus: they take prompts from public Hugging Face datasets, ask Qwen/Qwen3-1.7B to produce greedy continuations, and train on those prompt-response pairs. This better matches the states the frozen AR model actually visits during generation, reducing the mismatch between teacher forcing and on-policy decoding. They keep prompts between 50 and 1,000 characters and obtain 4,113,358 distilled samples, training on eight H100 GPUs.

For evaluation, the criterion is exact token-by-token identity with the corresponding frozen AR model. Because decoding is a discrete decision process, those small perturbations can cross a decision boundary at some step and cause the entire continuation to diverge. 第三层，是轻量校准。作者没有训练复杂判别器，而是用线性 calibrator 把 phase-aware 特征映射成“下一步 action 会通过验证”的概率。这样做有两个好处：一是样本效率高，便于跨 agent 迁移；二是输出可直接作为 gate/routing/human intervention 的决策分数。部署时，SU 插在 code generation 和 execution 之间。如果预测失败概率高，就先 veto 当前 action，触发更便宜的 replan，而不是进入 execute-fail-retry 循环。

The target is a calibrated probability that the current action will satisfy a verifiable objective Ω before execution; in the coding setting, Ω is whether execution succeeds without exceptions.

The first ingredient is reverse speculative scoring. A small open-weight draft model q is run in teacher-forcing mode over the black-box agent trajectory produced by model p. For each token, q conditions on the prefix and assigns probability to the token actually emitted by p. This yields token-level cross-likelihood style signals in a single forward pass, without access to p’s internals and without repeated sampling. The method relies on disagreement between q’s local distribution and p’s realized tokens as a proxy for downstream failure risk.

The second ingredient is phase-aware feature extraction. The paper argues that agent trajectories are structurally heterogeneous. Reasoning spans are high-entropy and linguistically noisy; action spans are lower-entropy, more syntax-constrained, and more directly tied to execution success. If one averages token scores over the whole trajectory, as in prior holistic calibration approaches, the action-relevant signal gets diluted by the reasoning phase. SU therefore separates reasoning and action tokens using the harness structure and computes features for each phase independently before calibration.

The third ingredient is a lightweight calibrator. Rather than training a heavy classifier, the paper uses a linear calibration layer to map phase-aware features to a failure likelihood. This keeps the method sample-efficient and easier to transfer across agents. In deployment, SU is inserted as a gate between code generation and execution: if the predicted failure risk is high, the system triggers a cheaper replan instead of entering an execute-fail-retry loop.

Relative to prior work such as trajectory calibration with white-box log-probabilities, the differences are clear: no white-box access, no repeated sampling, and explicit modeling of reasoning versus action phases. 二，训练流程：先 AR，后 diffusion distillation。训练分两阶段。第一阶段完全按常规 NTP 训练 AR 权重，得到高质量基模型。第二阶段冻结 AR 权重，只训练 diffusion 权重，让它通过 Diffusion Distillation 学会从 AR 分布中提出高质量 block proposal。这个设计有两个关键好处。其一，最终语言分布仍由 AR 模型定义，因此不会因为 diffusion 训练不稳定而伤害 base quality。其二，已有开源 AR 模型可以后加 Uno 模块，不需要从头重训整模型。文中还说明既可以 from scratch 联合构建，也可以对现有 open-weight AR LLM 做 augmentation。

TDES, or Target-Distilled Edge Scoring, addresses parent-child mismatch. DDTree is effectively parent-agnostic: a child token contributes the same score regardless of which parent path it extends, because scoring is driven by per-position token probabilities. GRAFT instead learns an explicit edge scorer distilled from target-model traces. The scorer takes candidate parent-child pairs from adjacent positions, together with contextual features, and predicts how compatible that transition is with the target model. Tree assembly then uses these edge scores, rather than only the product of marginal token probabilities, to select target-compatible paths under a node budget.

Mechanistically, this is a lightweight structural predictor that compresses local target preferences into a cheap model. It does not rerun the target and does not force the DLM drafter into autoregressive expansion. It patches the missing conditional dependency at the tree-assembly stage. That is the right intervention point, because the failure mode is not merely missing candidate tokens; it is incorrect attachment among already available candidates.

SABA, or State-Aware Budget Allocation, addresses budget misallocation. The paper models per-round throughput as a trade-off between draft gain and verification cost, then chooses the budget conditioned on the current decoding state. Easy rounds already have long accepted prefixes, so larger trees mostly add cost. Hard rounds benefit more from extra nodes, but only up to a saturation point. SABA predicts the utility of different budgets from state features and selects the throughput-optimal one online.
