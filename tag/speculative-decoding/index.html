RIFT: KV Cache Compression for Draft Models with Complementary Compressibility Training

这篇工作处理的是 speculative decoding 在长输入、长输出场景下的一个很具体但常被低估的问题：draft model 的 KV cache 在固定预算下怎么压缩，才能尽量维持与 target model 的对齐。已有 selection-based 压缩方法多在 prefill 阶段一次性选出“重要”历史 token，例如 SnapKV 这类做法；问题在于生成继续推进后，早先选出的 prompt token 会逐渐失去相关性，而新生成前缀的重要性快速上升。作者把这种现象定义为 decode staleness。它不是简单的压缩误差，而是压缩策略与生成过程之间的时间失配：静态选择在 decode 早期可能有效，但随着 output length 增长，draft 看到的上下文越来越偏离 target 真正依赖的上下文，接受长度随之下降。论文要解决的核心就是：在固定 KV 预算下，如何同时保留远端 prompt 信息和近期 decode 信息，并降低训练时全缓存、推理时压缩缓存之间的失配。

评不是 pretrain 论文，但它把“长输出下 KV 压缩目标会随 decode 漂移”说得很对；先看方法图和 latency-quality 曲线，若你做 speculative serving，这个假设应立刻纳入内部 ablation。

Target Regeneration Shrinks the Gains of Draft-Training Objectives in Speculative Decoding
