Do Coding Agents Deceive Us? Detecting and Preventing Cheating via Capped Evaluation with Randomized Tests

TRACE: Toulmin-based Reasoning Assessment through Constructive Elements for LLM CoT Evaluation

这篇工作要解决的不是“答案对不对”，而是“推理过程本身好不好”如何被稳定量化。现有 CoT 评测大多看最终正确率，或者看长度、困惑度、judge 打分这类外部信号，难以定位中间推理到底是证据不足、论证跳步，还是自我监控失衡。TRACE 试图把开放式推理拆成可标注、可计分的结构单元，用论证学里的 Toulmin 框架和元认知理论去刻画一句句 reasoning sentence 在论证链中的角色，再根据这些角色是否合法、前后转移是否连贯，给出一个 reference-free 的过程分数。

评读方法和 RL reward 实验即可；把论证结构当过程奖励有用，但相关性 r=0.74 还不足以证明因果。
Yundong Kim,Heyoung Yang
