18:T981,技术核心是把当前层的 full weight gradient 分解成 LoRA 可访问部分和不可访问部分。对注入 LoRA 的线性层，设有效权重为 W_base + sBA。给定当前 batch 的输入激活 X 和反向信号 δ，完整权重梯度可恢复为 G_raw = δ^T X（按文中记号，batch 和 token 维展平后计算）。作者证明，由当前 A、B 的欧氏梯度所诱导出来的等价权重空间梯度，恰好张成当前 LoRA 参数化的 tangent space，也就是所谓 LoRA-accessible gradient space。于是可以把 G_raw 正交分解为切空间内的分量和法向分量；后者被称为 normal gradient。

这个 normal gradient 有两个关键性质。第一，只要它非零，取其负方向，在固定当前 adapter 与其他权重的局部条件下，是当前 batch loss 的下降方向。第二，它与当前 LoRA 一阶可达的所有方向都正交，因此不是通过改 adapter 学习率、初始化或梯度重标定就能补回来的。这也是作者为什么不继续做 LoRA factor 的优化修补，而是直接把 normal 分量用于更新 base weights。

GDLoRA 的实现分成两条支路：adapter branch 仍然是标准 LoRA + AdamW；normal branch 则从同一次前向/反向中恢复 full gradient，投影到当前切空间的正交补上，得到 normal gradient，然后直接更新 base weights。这里有两个实现细节值得注意。其一，作者只对 normal branch 做 token-count normalization，即按输入位置数归一化梯度幅值，保持方向不变，目的是让不同序列长度或 token 数下的 normal update 更稳定。其二，base weights 不维护额外的 momentum / variance buffer，也就是不用 Adam 状态去追踪这条支路，从而避免像 FFT 那样为全量参数付出 optimizer-state 内存。这样做的取舍很明确：用更“轻”的 base update 换取部分 full-gradient 信息，而不是完全复制 FFT 的优化器行为。

和已有方法相比，差异也很清楚。Fira 试图用低秩投影近似 full-rank adaptive update，但需要周期性 SVD 或复用投影基，存在梯度子空间漂移问题。LoRA-GA、LoRA-Pro 则仍停留在 adapter 参数化内部，改善的是 LoRA 所诱导的权重梯度与 full gradient 的对齐程度。GDLoRA 直接承认当前 LoRA 切空间之外还有信息，并显式抽取这部分正交分量来更新 base weights，因此方法逻辑更直接。19:T95c,The method starts from a LoRA-injected linear layer with effective weight W_base + sBA. Given forward activations X and backward signals delta for the current batch, the unconstrained full weight gradient can be reconstructed as G_raw = delta^T X after flattening batch and token dimensions. The key theoretical result is that the set of equivalent weight-space gradients induced by Euclidean gradients on A and B coincides exactly with the tangent space of the current LoRA parameterization. This defines the LoRA-accessible gradient space.

Once this space is characterized, the full gradient can be orthogonally decomposed into a tangent component and a normal component. The latter is called the normal gradient. This component has two important properties. First, when nonzero, its negative is a local descent direction for the current batch loss when the current adapters and other parameters are held fixed. Second, it is orthogonal to every first-order direction available through the current LoRA factors, so it cannot be recovered merely by better initialization, rescaling, or re-optimizing the adapter gradients within the same parameterization.

GDLoRA uses two update branches. The adapter branch is standard LoRA optimized with AdamW. The normal branch reconstructs the full gradient from the same forward/backward pass, projects out the tangent-space component, and directly applies the remaining normal gradient to the base weights. A notable design choice is that token-count normalization is applied only to the normal branch, to stabilize update magnitude across different numbers of input positions while preserving direction. Another important choice is that the base weights do not maintain additional momentum or variance buffers. This is how the method avoids the optimizer-state overhead of FFT. In effect, GDLoRA supplements LoRA with a lightweight base-weight update that carries information unavailable to the current low-rank factors.

Compared with prior work, the distinction is clear. Fira approximates full-rank adaptive updates through projected gradients and periodically refreshed low-rank bases, which introduces basis-refresh trade-offs. LoRA-GA and LoRA-Pro improve how adapter gradients approximate the full gradient, but still remain inside the LoRA-induced update space. GDLoRA instead explicitly extracts the orthogonal complement and uses it directly.1a:T5a4,The experiments span natural language understanding, mathematical and commonsense reasoning, and image classification. The main empirical claim is that under matched adapter and optimizer configurations, GDLoRA improves average performance by about 2% to 4% over standard LoRA and often approaches, or in some settings matches, full fine-tuning.

The emphasis on matched configurations matters. The paper is not claiming gains from extra trainable parameters or full optimizer states. It is testing whether the normal-gradient branch consistently adds useful information beyond what LoRA can express at first order. The most informative comparisons are therefore against standard LoRA, FFT, and methods such as Fira, LoRA-GA, and LoRA-Pro.

The ablations to pay attention to are the ones that isolate the mechanism: whether token-count normalization is necessary for the normal branch; how much is gained by combining LoRA updates with normal base-weight updates versus using either alone; how the method behaves at different ranks; and whether the benefit shrinks as rank increases. If the paper’s interpretation is correct, the gain should be more pronounced at lower ranks, where the LoRA tangent space is narrower and the normal component is more likely to contain important descent directions.

This is not a large-scale scaling-law paper. The value lies in making the missing-gradient story concrete, measurable, and empirically useful.1b:T4e1,Read this paper with one question in mind: is LoRA limited mainly by low-rank capacity, or by the restricted first-order update space of its current parameterization? Start with the introduction and the theorem-level characterization that the accessible gradient space equals the tangent space. That is the conceptual center of the paper.
