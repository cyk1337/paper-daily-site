Evo-Bench: Can Language Models Improve Agent Harness?

这篇工作要解决的不是“模型能不能把任务做对”，而是“模型能不能持续改进承载任务执行的 agent harness”。这里的 harness 指可执行的外层脚手架：提示、工具调用流程、状态管理、错误恢复、子任务编排、代码逻辑等。难点在于，现有 agent benchmark 往往把基础模型能力、任务难度、harness 设计混在一起，导致你很难判断分数提升究竟来自更强的 base model，还是来自更好的 harness。作者把问题拆成三个必须同时满足的条件：任务要对 harness 改动敏感，而不是被底模能力主导；验证集和测试集要在这种“敏感性”上分布一致，避免在验证集上过拟合；评测过程要允许多轮、长时程的代码级迭代，而不是单轮 prompt search。

评harness自主进化是agent能力的新维度，对研究长程agent能力演化有参考，只看 §2 的benchmark构建逻辑即可。

GST-Bench: Can VLMs Develop Global Spatial Awareness from Video?

这篇工作要解决的不是一般的视频问答，而是 VLM 在连续第一视角视频中能否形成“全局空间表征”。更具体地说，模型是否能把沿轨迹看到的局部观察整合成一致的场景地图，并在一个从未出现在视频轨迹上的新视角下，回答“我在哪里、目标在哪里、场景整体长什么样”这三类问题。作者认为现有空间 benchmark 大多停留在单帧或少量视角，很多题目其实可以靠局部线索或单图感知完成，无法真正测到跨时间、跨视角、带全局坐标约束的空间推理能力。GST-Bench 的核心设计就是把这些捷径尽量堵住：目标物体在 query 视角中不可见，query 视角不在原视频轨迹上，答案采用距离和角度等精确数值而不是粗粒度左右前后判断，并显式引入 top-down 图像来测试局部观察到全局地图的映射能力。

评只看任务定义和局部/全局拆分实验；它能提醒 VLM 预训练别把单帧空间题当作 embodied 能力代理。

Skill-Use: Can LLMs Actually Use Skills in Agentic Harnesses?

在“渐进披露（progressive disclosure）”的 agent harness 里，技能（skill）通常只以“名称+短描述”先暴露给模型，完整步骤需要模型主动检索后才能执行。现有评测多看最终任务成败或技能文档质量，无法回答一个更基础的问题：模型是否能自己判断该用哪个技能、主动触发检索、并按技能步骤执行且不越界。该论文要评测的就是这种端到端的“技能使用能力”，并把失败拆成可定位的三个环节。

评值得扫 metric 定义；它把 agent skill failure 拆得更干净，读 §benchmark/score 即可，不必期待预训练结论。
