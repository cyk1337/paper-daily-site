评读协议定义和失败案例即可；它提醒 VLM 对齐别只训解释文本，反事实一致性才是更硬的信号。

ERPBench: A State-Grounded Evaluation Paradigm for Computer-Use Agents in Enterprise Software

论文解决的是企业软件中 computer-use agent 的评测失真问题：只看截图轨迹或页面反馈，会高估 agent 能力，因为表面操作成功不等于数据库中的业务状态被正确修改。

评针对 GUI agent 的高质量 benchmark，亮点在于通过底层数据库状态（State-Grounded）而非纯视觉变化来验证 agent 操作的正确性，这种 evaluation protocol 值得关注。
