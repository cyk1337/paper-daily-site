19:T5cf,They propose a two-stage selective evaluation policy with joint threshold calibration.
- Setup: an examinee model produces an answer; a judge outputs a binary verdict. A held-out calibration set provides ground-truth evaluation labels (human or reference-based matching). Define a Bernoulli failure indicator for whether the judge verdict matches ground truth.
- Mode 1 (parametric judging): the judge decides using only its internal knowledge and emits an uncertainty/confidence score. If uncertainty is below threshold τ1, accept the verdict.
- Mode 2 (retrieval-augmented judging): otherwise, trigger web search, re-judge with retrieved evidence, and accept if uncertainty is below τ2; else abstain.
- Risk control: thresholds (τ1, τ2) are calibrated on the labeled calibration set using Clopper–Pearson upper confidence bounds to ensure the error rate (framed as FDR / false discovery among accepted verdicts) is bounded by a user-specified α with high probability.
- Key technical point: they argue the Bernoulli structure required for the CP bound still holds under the two-threshold routing scheme, so the finite-sample guarantee extends without extra distributional assumptions.
- Compared to prior selective prediction: prior work is typically single-threshold accept/abstain; here retrieval is an intermediate action, and the two thresholds are jointly calibrated to increase coverage under the same risk constraint while concentrating retrieval cost on uncertain cases.1a:T4b5,CORA frames safety as selective action execution (prediction with abstention). At each step, a base policy proposes an action a^t; a safety controller decides Execute vs Abstain.

CORA couples three components:
1) An action-conditional Guardian model Rψ that estimates the risk of executing the specific proposed action in the current GUI state/history.
2) A Conformal Calibration module using Conformal Risk Control (CRC) to calibrate the execute/abstain boundary to satisfy a user-specified risk budget α on the executed-harm rate (rather than thresholding raw scores). For deployment realism, it incorporates weighted calibration under covariate shift and conservative extensions for sequential dependence.
3) A trainable Diagnostician that handles rejected actions with minimal interventions—Confirm, Reflect, or Abort—to reduce harm while controlling user interruption.

Additionally, CORA uses Goal-Lock: it freezes the user goal and treats on-screen text as untrusted evidence to mitigate indirect prompt injection/goal hijacking.
