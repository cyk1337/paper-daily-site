Modaliff: A Unified Token Diffusion Model for Any-to-Any Generation

这篇工作要解决的是 any-to-any 多模态生成里的训练约束问题。现有统一扩散模型通常走两条路：一条是把多模态 token 直接拼起来做联合建模，但往往依赖完整对齐的 text-image-audio 三元组；另一条是先把不同模态压到共享表示空间，再在共享空间里做条件生成，但这样会牺牲模态原生结构。Modaliff 试图避开这两个限制：只用更常见的双模态配对数据训练，同时保留文本、图像、音频各自的原生 latent token 序列，不强行做共享 latent。论文真正关心的是，如何让一个统一 denoiser 在不改架构的前提下处理任意源模态到任意目标模态的生成，以及如何在训练只见过双模态配对时支持多条件生成。

评将所有模态统一为 Token 并使用纯 Diffusion 建模，是 AR+Diffusion 混合架构之外的另一种 Any-to-Any 探索，值得关注其 Token Diffusion 的具体实现和 Scaling 潜力。
Duc Kieu,Kien Do,Minh Khoa Le,Tung Kieu,Dang Nguyen,Thin Nguyen
