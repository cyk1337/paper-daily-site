VERITAS: Verifier-Guided Proof Search for Zero-Shot Formal Theorem Proving

VERITAS 解决的是形式化定理证明中“验证器反馈没有被充分利用”的问题。现有 LLM prover 常把 Lean 返回的语法错误、类型错误、目标变化、证明完成状态压成一个 pass/fail 信号，搜索过程只能靠重新采样碰运气。论文要证明的是：在零样本设置下，把这些结构化反馈持续喂回生成和搜索，比单纯增加采样更有效。

评只看方法协议和 CombiBench 结果：它把 verifier 失败当“可学习的负例”，比泛泛的 self-critique 更干净，值得迁移到 RLVR/过程监督数据管线。

Diffusion-Proof: Recipe for Formal Theorem Proving Beyond Auto-Regressive Generation

这篇工作关注 formal theorem proving 中一个很具体的建模问题：自回归语言模型按 token 左到右生成证明，容易在长证明里累积错误，也不擅长局部修补；而形式化证明恰恰要求长程一致性和可验证性。作者想验证 diffusion LLM 能否在这个场景里替代或补充 AR 生成，并给出一套可训练、可推理的 formal proof recipe。

评方向有意义——形式化证明是 dLLM 长程一致性的硬测试，但摘要没给数，先看实验表再决定是否跟进复现。
Ruida Wang,Rui Pan,Pengcheng Wang,Shizhe Diao,Tong Zhang
