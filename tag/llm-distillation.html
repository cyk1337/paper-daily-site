OPD+: Rethinking the Advantage Design for On-Policy Distillation

On-policy distillation（OPD）把“学生模型自己采样的轨迹”拿来做 token 级蒸馏，常被写成 RL 风格目标：reward 由学生与教师分布的 divergence 构成。实践里为了稳定，很多实现会对 reward 里的 log-ratio（或更一般的 divergence 项）做 stop-gradient，把它当常数回报来做 REINFORCE/PPO 式更新。论文要解决的是：这种 stop-gradient 在数学上是否成立？如果不成立，正确的梯度/advantage 应该怎么写，能否在不牺牲稳定性的情况下带来可观收益？

评读目标推导即可；若内部还在用 stop-gradient OPD，这篇会改变对“稳定但无偏”的默认假设。
Hanyang Zhao,Haoxian Chen,Han Lin,Genta Indra Winata,David Yao,Wenpin Tang

Bounded Behavioral Indistinguishability for Black-Box LLM Distillation

这篇工作讨论的不是“学生模型答得像不像老师”，而是一个更接近部署现实的问题：在只有黑盒 API 访问的条件下，蒸馏后的学生模型，是否会在可观察行为上与教师模型难以区分。作者指出，常见的语义相似度、任务正确率、输出重合度，只能说明答案内容接近，不能说明行为层面的细粒度模式也被迁移了。这里的行为包括风格、拒答策略、格式习惯、冲突指令处理、安全边界和鲁棒性反应。为此，论文提出 bounded behavioral indistinguishability，把“不可区分”定义成一个带约束的经验命题：在给定提示分布、查询预算、计算预算和对手类别下，任何对手都不能以超过 ε 的优势判断输出来自教师还是学生。

评核心insight值得注意：蒸馏的语义相似度和行为不可区分是两个独立维度。只看实验设置和主要结果即可，行为探测方法可借鉴到蒸馏质量评估中。
Munawar Hasan

Teacher-Guided Policy Optimization for LLM Distillation
