What Really Improves Mathematical Reasoning: Structured Reasoning Signals Beyond Pure Code

论文重新检验一个预训练数据配比中的常见判断：代码数据是否真的提升通用数学推理。作者的核心结论是，纯可执行代码主要提升编程能力，并不会稳定提升数学推理；过去归因于 code 的推理收益，很大一部分可能来自 code-text、math-text 这类跨域结构化推理轨迹，而不是来自 standalone executable programs。

评应立刻看实验设计：它会改变“加代码就涨推理”的默认数据配比假设，尤其要复现 Code-NL 控制组。
Yuze Zhao,Junpeng Fang,Lu Yu,Zhenya Huang,Kai Zhang,Qing Cui,Qi Liu,Jun Zhou,Enhong Chen
