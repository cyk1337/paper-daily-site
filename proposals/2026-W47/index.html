#1H · 硬待研判2026-11-20symmetry-aware-test-time-compute

测试时计算不应只买更多样本：结构对称性会改变预算最优解

Test-Time Compute Should Not Only Buy More Samples: Symmetry Changes the Optimal Budget

» 在有群对称或等价重写的任务上，重复采同一个 prompt 可能只是在估计同一个偏差。更可检验的断言是：先沿输入的等价轨道覆盖错误模式，再决定是否增加 self-consistency 样本。

触发：2611.24032 直接给出 test-time symmetrization 的 scaling law；2611.06372 说明跨样本预算由 prior 质量决定；2611.22778 把“多想是否真的会变好”做成反事实账本；2611.17610 又指出多 Agent 结果常把通信和更多采样混在一起。

锚点论文

  • 2611.24032Test-Time Symmetrization: Scaling Laws for Model-Agnostic Learning under Structure— 把等价输入重写与同 prompt 重采样放在同一预算曲线上比较。
  • 2611.06372Give Up to Get More: Priors, Not Policies, Govern Test-Time Compute Allocation— 说明预算分配不是单调按难度加码，而取决于可用 prior 的质量。
  • 2611.22778A Full-Ledger Counterfactual Audit of Adaptive Reasoning— 区分“当前会错”和“继续计算会改对”，适合作为 symmetrization 的验收协议。
  • 2611.07367Test-Time Self-Play: Scaling without a Verifier— 给出无 verifier 场景下用额外推理计算增益的对照阵营。
  • 2611.17610More Agents, More Samples, or More Thinking? Untangling Coordination, Ensembling, and Test-Time Compute in Multi-Agent LLMs— 提供把通信、采样数、token 和工具调用分开的 baseline ladder。

对立阵营

  • · 阵营 A：固定 prompt 多次采样，用 self-consistency 或 majority vote 降低方差。
  • · 阵营 B：沿任务对称性做输入重写，用等价轨道覆盖系统性偏差。
  • · 阵营 C：用反事实 ledger 或 prior 估计器决定何时放弃某个样本，把预算转给更有边际收益的输入。

品味：重点是预算曲线，不是再造投票技巧。

  • · 阵营 C：用 user simulator 或 LLM judge 扩展交互，但必须单独审计 simulator 失真。

品味：要写 coverage 缺口，不写环境大而全。

#3H · 硬待研判2026-11-20multimodal-reasoning-state-allocation

The Bottleneck in Multimodal Long Reasoning Is Not Looking More, but Allocating Visual State

» 长链推理 VLM 里，视觉 KV 被文本推理挤出会掉能力；但每个生成 token 都读完整视频又浪费计算。更稳的接口应把视觉证据、文本草稿和摘要状态分开记账。

触发：2611.23769 把多轮 VLM 失败定位到视觉 KV 驱逐；2611.24259 反过来主张长视频思考阶段先写下再看开；2611.24431 用小模型做长交错图文 prefill 筛选；2611.24267 在流式视频里比较 look closer、look back 和 wait。

锚点论文

  • 2611.23769Keep the Reasoning, Read the Image: On-Demand Visual KV for Multi-Turn Reasoning VLMs— 显示文本 CoT 会挤出视觉 token，并提出按需保留视觉 KV。
  • 2611.24259Do Thinking VLMs Need to Keep Looking at Long Videos? Write It Down, Then Look Away— 提出推理阶段可用文本记录替代反复读取完整视频 KV。
  • 2611.24431Let a Small Model Read First: Faster Prefill for Long Interleaved Image-Text Inputs— 把长交错图文 prefill 的证据定位交给小模型，改变目标模型自筛默认做法。
  • 2611.24267Look Closer, Look Back, or Wait for Agentic Streaming Video Understanding— 在有限记忆和低延迟下测量当前、过去、未来证据的取舍。
  • 2611.22709Know When to Zoom: How Small Is Too Small for Vision-Language Models?— 说明很多小目标失败来自服务端缩放和 token 预算，而不是推理能力本身。

对立阵营

  • · 阵营 A：保留更多视觉 KV，避免推理文本挤掉原始感知证据。
  • · 阵营 B：把视频或图像证据写成中间文本状态，思考阶段尽量不再读取全量视觉上下文。
  • · 阵营 C：先用小模型、路由器或 zoom policy 定位证据，再让大模型只读高价值片段。

品味：关键是状态 ABI，不是 KV 剪枝榜单。

#4H · 硬待研判2026-11-20latent-reasoning-progress-control

Latent Reasoning 不该固定步数：要训练进展、停止和可读出的求解方向

Latent Reasoning Should Not Use Fixed Horizons: Train Progress, Stopping, and Readable Solution Directions

» 更多 latent step 不一定带来更好答案；无进展计算会污染支持证据。近期结果还显示，CoT 文本答错时 hidden state 可能已经含有可读出的正确方向，这要求训练目标区分“状态进展”和“生成解释”。

触发：2611.24001 直接质疑 fixed-horizon latent reasoning；2611.24598 从 CoT hidden state 中读出 direct-answer 方向；2611.23677 简化 tiny recursive model，提示递归复杂性未必是关键；2611.20404 和 2611.21608 则把每 token 计算容量放回 pretrain 架构选择。

锚点论文

  • 2611.24001Rethinking Fixed-Horizon Latent Reasoning— 把 latent step 的边际收益和停止准则作为主要对象。
  • 2611.24598Chain-of-Thought Hidden States Reveal Task-Solving Directions for Direct Answers— 显示 hidden state 里的求解方向可与输出 CoT 成败分离。
  • 2611.23677Simpler Tiny Recursive Models— 说明递归结构的复杂度不是 puzzle 泛化收益的充分解释。
  • 2611.20404Latent Feedback Is a Compute and Data Amplifier— 把重复数据和改变每 token 计算路径放在同一 FLOP 账上比较。
  • 2611.21608Latent Lattice Language Models— 探索不靠单纯加深或标准 recurrent state 来增加 token 计算容量。

对立阵营

  • · 阵营 A：固定 latent horizon，默认更多内部步骤平均有益。
  • · 阵营 B：按进展自适应停止，避免无效 latent compute 破坏答案支持。
  • · 阵营 C：从 hidden state 读出或监督求解方向，让 latent state 不必完全经由文本 CoT 表达。

品味：别比步数，要量化每步信息增益。

锚点论文

  • 2611.24058MIRAGE: A Framework for Multi-hop Reasoning under Dynamic Knowledge Injection— 把新事实、冲突事实和参数记忆放在同一多跳路由任务里。

  • 2611.24000A Mechanistic Analysis of In-Context Learning and Out-of-Context Hallucination— 解释上下文角色信息为何没有在关键 token 决策处约束输出。
  • 2611.23530Dreaming Up Authors: Factual Prevalence and LLM Hallucinations in Academic Authorship Attribution— 把长尾事实幻觉与训练语料可见度联系起来。

对立阵营

  • · 阵营 A：扩大 RAG 或 prompt facts，默认上下文证据会覆盖参数记忆。
  • · 阵营 B：训练模型服从显式 fact block，但要防止 false-fact 泛化和指标 Goodhart。
  • · 阵营 C：把每一跳的 source routing 作为可测对象，要求模型在冲突、新事实和长尾事实间校准信任。

品味：平均 QA 分数会漏掉逐跳信任错误。
