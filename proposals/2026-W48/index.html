#1H · 硬待研判2026-11-23judge-scale-priors-to-policy

LLM Judge 不是中性量尺：数字拓扑会变成后训练偏置

LLM Judges Are Not Neutral Rulers: Score Topology Becomes Post-Training Bias

» 同一套 rubric 换一个分数方向或区间，judge 的归一化分数仍会系统漂移。更危险的是，RL 不会继承 judge 的事实知识，只会把类别级盲区和数值先验放大成策略。

触发：2611.25588 和 2611.26077 连续指出 1–5 分量表不是中性接口；2611.25191 显示 judge 的类别盲区会经 RL 放大；2611.25135 与 2611.25168 又把问题推进到 calibrated reward 和 belief-level label。

锚点论文

  • 2611.25588Rubric Semantics or Numerical Priors? Auditing Scale-Direction Bias in LLM Judges— 直接证明分数方向会改变 judge 行为。
  • 2611.26077Same Judgement, Different Scores: Numerical Scoring Topology in LLM-as-a-Judge Evaluation— 把分数区间形状作为独立变量审计。
  • 2611.25191Blind Spots Travel, Knowledge Stays Home: What RL Inherits from an LLM Judge— 把 judge 偏差从评测问题接到 RL 训练结果。
  • 2611.25135Calibrated Decision Rewards: Training Language Models with a Judge That Knows How Sure It Is— 提出 reward 概率校准，回应 reference-free reward 的失真。
  • 2611.25168What a Calibrated Probability Hides: Belief-Level Post-Training for Decision Models— 指出聚合概率会混淆人群分歧与共同不确定性。

对立阵营

  • · 阵营 A：把 rubric 文字当作主要语义约束，数字只是输出格式。
  • · 阵营 B：把分数轴、方向、区间和归一化看作 reward model 的一部分。
  • · 阵营 C：用 calibrated probability 或 belief-level target 替代裸分数，但需要处理分布外校准和人群分歧。
  • · 阵营 D：在 RL 中只看 reward 上升；反方要求审计类别级偏差是否被策略放大。

品味：judge 分数轴会进策略，不能只验相关性。

#2M · 中待研判2026-11-23author-fingerprint-data-governance

数据治理的最小单元可能是作者，而不是文档

The Unit of Data Governance May Be the Author, Not the Document

» 单样本文风识别把训练暴露风险从“这段文本是否见过”推进到“这个作者是否可识别”。去重、污染检测和成员推断若仍以文档为单位，会低估作者级隐私和风格泄漏。

触发：2611.26216 报告 frontier model 可在 zero-shot、无候选列表设置下识别人类或 AI 作者；2611.21315 显示 benchmark 泄漏已下沉到 base model；OpenAI adversarial distillation 讨论把 CoT 视为可被蒸馏的数据资产。

锚点论文

  • 2611.26216Frontier models need only one text to unmask its human or AI author— 把作者级可识别性变成最小实验设置。
  • 2611.21315Benchleaking Is Accelerating— 显示污染风险已不止 post-training，base model 也受影响。
  • blog-openai-alignment-5a5ba5d7Combatting adversarial distillation— 把受保护推理轨迹作为训练资产和泄漏面讨论。
  • 2611.24844General progress substitutes for specific training data in language models— 说明移除特定数据不等于移除相关能力。
  • 2611.12864Is Persona Generalization Predictable?— persona 迁移提示风格与行为特质可跨样本泛化。

对立阵营

  • · 阵营 A：文档级去重、评测集匹配和成员推断足以描述训练暴露。
  • · 阵营 B：作者级、账号级和实验室级风格指纹才是更细的治理对象。
  • · 阵营 C：能力删除依赖数据删除；反方认为通用进展和风格迁移会恢复部分能力。
  • · 阵营 D：保护文本内容；反方还要保护 CoT、格式、风格和交互轨迹。

品味：隐私风险从逐字记忆扩展到风格识别。

#3M · 中待研判2026-11-23latent-readout-gap

模型知道但说不出：表示、读出与串行计算要分开评估

Models May Know More Than They Can Say: Separate Representation, Readout, and Serial Compute

» 多个新结果指向同一个盲点：线性探针、head-guided decoding 或 recurrence 能取出模型内部已有信息，但普通 prompting 取不出来。把失败全归因于预训练缺知识，会把读出接口和串行计算瓶颈漏掉。

触发：2611.25210 用 recurrent VLM 解决 shell game；2611.25211 认为精确状态跟踪需要外置可组合状态；2611.25960 和 2611.25808 都显示音频/文本中的信息可被读出但难以 verbalize；2611.24994 把激活转文本用于安全审计。

锚点论文

  • 2611.25210Recurrent Vision Language Models Solve the Shell Game— 把视频状态跟踪失败定位到串行计算不足。
  • 2611.25211Learning to Read Events for Exact State Tracking with Frozen Language Models— 说明长事件流需要显式状态更新接口。
  • 2611.25960When Sounds Turn Heads: Recovering Event Timing That Audio LLMs Fail to Say— 给出音频事件时间“内部有、输出无”的案例。
  • 2611.25808Language models represent more about emphasis than they can tell you— 证明可线性读出的重音信息不等于可提示输出。
  • 2611.24994What the model knows but does not say: monitoring medical LLMs through verbalized thoughts— 用激活转文本审计隐藏状态。

对立阵营

  • · 阵营 A：任务失败说明预训练或监督数据不足。
  • · 阵营 B：信息已在表示中，失败来自输出接口、decoding 或 verbalization。
  • · 阵营 C：增加 CoT token 提供串行计算；反方用 recurrence、latent loop 或外部状态提供计算。
  • · 阵营 D：probe 分数即能力；反方要求因果读出和干预验证。

品味：别把读出失败误判成知识缺失。

#4H · 硬待研判2026-11-23proxy-signals-not-causal-utility

高注意力、高路由分数、高探针准确率，都不等于因果有用

High Attention, Router Scores, or Probe Accuracy Do Not Imply Causal Utility

» 近期多篇论文从不同系统层面给出同一个警告：attention 分数、router probe、CHAIR 改善和 QK 全维点积都可能是代理信号，不是因果贡献。压缩、解释和后训练若直接优化这些 proxy，会删错 token、误读专家或高估对齐收益。

触发：2611.25433 指出长 CoT 中高 attention token 可能是冗余；2611.24969 用全局重要性替代局部 attention；2611.25780 显示 MoE router probe 高 AUROC 不等于因果解释；2611.25814 拆出 VLM 反幻觉收益中的少说和剪枝成分；2611.26363 又挑战 QK 全维计算的必要性。

锚点论文

  • 2611.25433RoCoKV: Accelerating LLM Inference Serving through Uncertainty and Redundancy Aware KV Cache Compression— 说明 reasoning trace 的 KV 价值不能只看 attention。
  • 2611.24969Global Importance Estimation for KV Cache Eviction— 用全局重要性估计替代局部注意力保留。
  • 2611.25780RouteVerify: Routing Interventions for Step-Level Verification in Mixture-of-Experts Models— 把 router 可读性和因果作用分开。
  • 2611.25814What Does Anti-Hallucination Training Buy? Saying Less, Cheap Pruning, and the Rest— 把指标改善拆成 grounding、少说和后处理。
  • 2611.26363HiSA: Sparsifying the Hidden Dimension of RoPE Attention in LLMs— 检验 QK 隐藏维度是否全都必要。

对立阵营

  • · 阵营 A：attention、router、probe 或 benchmark 子分数可直接作为重要性。
  • · 阵营 B：重要性必须通过删除、替换、重排或路由干预做因果验证。
  • · 阵营 C：局部分数足够做 KV eviction；反方要求估计未来全局效用。
  • · 阵营 D：指标改善即能力改善；反方要求 accounting，拆出少说、剪枝和格式效应。

品味：proxy 若不做干预，很容易变成错因果。

#5M · 中待研判2026-11-23grep-baseline-agent-memory

Agent 记忆先过 grep 基线：晚绑定检索比复杂摘要更难被击败

Agent Memory Must Beat Grep First: Late-Bound Retrieval Is a Hard Baseline

» 长期 agent 记忆的核心难点不是把历史压成更漂亮的摘要，而是在未来问题未知时不提前删掉关键细节。无损日志加简单搜索是一个强反基线；复杂 memory 若不能在成本、恢复率和可审计性上同时超过它，不应算有效改进。

触发：2611.25123 直接提出 lossless log + grep later；Anthropic 的 memory components 把写入、巩固和回忆拆开；2611.26427、2611.25705、2611.25407 分别从 folding、personalized graph 和 temporal dossier 给出更复杂方案，正好形成可比较分歧。

锚点论文

  • 2611.25123Forget Freely, Grep Later: Lossless, Index-Free Memory for Long-Horizon LLM Agents— 给出复杂 memory 方案必须击败的反基线。
  • blog-anthropic-research-f0247d2bThe components of agent memory— 把长期 agent memory 分解成可讨论的组件。
  • 2611.26427MemFolder: Structure-Guided Memory Folding for Efficient Agent Memory Management— 代表结构化压缩与可恢复验证路线。
  • 2611.25705STARK: Moving towards Personalized Agents That Truly Learn and Remember— 代表长期个性化图记忆路线。
  • 2611.25407ChronoDossier: Long-Form Personas as Temporal Memory Representations— 提供时间变化 persona 记忆评测。

对立阵营

  • · 阵营 A：摘要、结构化 memory 或图存储应尽早压缩历史。
  • · 阵营 B：完整日志先保留，等未来问题出现后再搜索和恢复。
  • · 阵营 C：embedding/index 是必要组件；反方要求先击败 grep 和关键词搜索。
  • · 阵营 D：memory 质量看最终任务分；反方要求报告恢复率、prefill 成本、审计轨迹和误删率。

品味：复杂记忆若打不过 grep，就是错基线。
