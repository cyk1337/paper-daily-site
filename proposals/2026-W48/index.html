#1H · 硬待研判2026-11-24rlvr-update-invariance-failures

RLVR 的等价性假设正在失效：同一字符串、同一奖励，不代表同一更新

RLVR Invariance Is Failing: Same String and Same Reward Do Not Imply the Same Update

» RLVR 常把“答案字符串相同、verifier 奖励相同”当作训练信号等价。但近期结果显示，分词、rollout 长度上限、SFT 初始化轨迹和 judge 盲区都会系统性改变策略梯度方向。

触发：2611.27083 直接证明无损重分词会移动 RLVR 更新；2611.26756 显示 RL 能从损坏 CoT SFT 中恢复，只需要格式模板；2611.26863 指出知识任务中长链 RL/post-training 会记住自身幻觉；2611.26172 又把 rollout token cap 从成本参数变成行为约束。

锚点论文

  • 2611.27083How Far Does Lossless Re-tokenization Move an RLVR Update?— 把“同字符串同奖励”的隐含等价性打成可测梯度差异。
  • 2611.26756Reinforcement Learning Unlearns Corrupted SFT Reasoning— 显示 reasoning SFT 的主要作用可能是格式和行为初始化，而不是正确推理轨迹。
  • 2611.26863LLMs Memorize Their Own Hallucinations During Post-Training— 指出 outcome reward 加长 CoT 在知识任务上会固化自生成错误。
  • 2611.26172Budget Internalization: Fixed-Budget RLVR Trades Test-Time Scaling for In-Budget Accuracy— 证明训练时 rollout cap 会内化成测试时推理长度偏好。
  • 2611.25191Blind Spots Travel, Knowledge Stays Home: What RL Inherits from an LLM Judge— 区分 judge 的知识不会迁移与类别级偏差会迁移。

对立阵营

  • · 阵营 A：RLVR 的核心变量是 verifier 和 policy objective；只要最终奖励正确，轨迹细节可视为噪声。
  • · 阵营 B：RLVR 更新由隐藏坐标决定；tokenization、长度截断、初始化轨迹和 judge 偏差都会改变可学习信号。
  • · 阵营 C：与其改 objective，不如先重做数据覆盖、格式初始化和 rollout 预算审计；很多 RL 增益来自可见成功样本的选择。

品味：可证伪、可复现，且直接影响 RL 预算。

权重空间正在变成接口：自编辑、护栏移除和能力区域持久性必须一起评估

Weight Space Is Becoming an Interface: Self-Editing, Guardrail Removal, and Persistent Capability Regions Must Be Evaluated Together

» 把权重当成只由梯度训练产生的静态产物已经不够。近期工作同时显示，模型可能读写权重、少量白盒编辑可移除护栏，而能力相关区域在量化、剪枝和 LoRA 后仍可能保持功能。

触发：2611.26841 与 2611.28833 把 in-context learning 推向 weight-space programming；2611.21885 直接提出无梯度自我改写权重；2611.27426 显示不训练只改权重即可削弱开放权重护栏；2611.27445 又指出能力区域在多种优化后仍可能保持因果作用。

锚点论文

  • 2611.26841Weight-Space Programming Writes In-Context Learning and Matches Fine-Tuning in Language Models— 把少样本适配从 prompt 层搬到权重编辑层。
  • 2611.28833Self-WSP: Can Language Models Improve Themselves Through Weight-Space Programming?— 测试模型是否能读取并编辑自身权重形成递归改进闭环。
  • 2611.21885Language Models Can Rewrite Their Own Weights— 近期自编辑权重叙事的直接触发点，需要严查隔离和对照。
  • 2611.27426Cleave: Severing Guardrails and Auditing Spectral Coupling in Open-Weight LLMs— 把权重编辑从能力适配带到开放权重安全审计。
  • 2611.27445Structurally Different, Functionally Persistent: Capability Regions Under Model Optimization— 说明量化、剪枝和 LoRA 后，原能力区域未必失效。

对立阵营

  • · 阵营 A：权重编辑只是微调的低成本近似，应按下游准确率和遗忘副作用评估。
  • · 阵营 B：权重空间已经是可编程接口；需要权限、审计、可逆性和隔离协议。
  • · 阵营 C：多数自编辑结果可能来自脏 setup 或搜索泄漏；最小闭环必须包含随机搜索、隐藏测试和跨版本复现。

品味：高风险但不能忽略，先验收隔离。

工具能力不一定是后训练补丁：搜索原生预训练与 harness 外包正在正面对撞

锚点论文

  • 2611.26897ProbeAgent: Principled Diagnosis of Agent Failures in Verifiable Environments— 提供环境中失败归因的反事实诊断口径。

对立阵营

  • · 阵营 A：工具使用是推理期协议问题；强 base 加好 harness 和 verifier 足够。
  • · 阵营 B：工具调用应进入预训练分布；模型需要从一开始学习何时缺证据、何时查询、如何消费返回结果。
  • · 阵营 C：外部记忆和搜索世界应随能力共同扩张；固定环境会把探索能力误判成失败。

#5H · 硬待研判2026-11-23judge-scale-reward-inheritance

LLM Judge 不是中性标尺：量表拓扑、数值方向与类别盲区会进入 RL 信号

LLM Judges Are Not Neutral Scales: Score Topology, Numeric Direction, and Blind Spots Enter RL Rewards

» 把 judge 输出当成一个可校准标量是危险的近似。同一 rubric 换分数方向或分数区间，归一化后仍会系统漂移；进入 RL 后，迁移的往往不是 judge 的知识，而是类别级偏好和盲区。

触发：2611.25588 和 2611.26077 同时把 LLM-as-a-Judge 的数值轴问题拆开；2611.25191 进一步显示 judge 盲区会被 RL 学生放大；2611.25135 则把 reference-free reward 的失败落到概率校准。

锚点论文

  • 2611.25588Rubric Semantics or Numerical Priors? Auditing Scale-Direction Bias in LLM Judges— 直接检验 5=好 与 1=好 两种编码是否等价，给出量表方向不是中性实现的证据。
  • 2611.26077Same Judgement, Different Scores: Numerical Scoring Topology in LLM-as-a-Judge Evaluation— 固定 prompt、rubric、样本和 judge，只改分数空间形状，仍产生系统性漂移。
  • 2611.25191Blind Spots Travel, Knowledge Stays Home: What RL Inherits from an LLM Judge— 把 RL 继承对象从答案知识改写为类别级奖励偏差，是核心反例。
  • 2611.25135Calibrated Decision Rewards: Training Language Models with a Judge That Knows How Sure It Is— 给出 judge reward 必须校准为概率的训练接口，而不是只喂相对分数。
  • 2611.20608Same Papers, Different Verdicts: Tracing Version Drift in LLM Peer Review— 说明 judge model 版本变化会改变评审阈值，不能跨版本复用分数线。

对立阵营

  • · 阵营 A：把 LLM judge 当作便宜、可替换的标量评测器，重点做 prompt 和多数投票稳定化。
  • · 阵营 B：把 judge 看成带量表拓扑、版本漂移和类别盲区的测量仪器，先校准再进 RL。
  • · 阵营 C：绕开自由形式 judge，优先使用 verifier、结构化断言或可审计的 pairwise 决策。

品味：好题不在 judge 准不准，而在偏差会被训练放大。

#6H · 硬待研判2026-11-23rlvr-rollout-budget-as-policy-prior

RLVR 的 rollout cap 不是成本参数：它会被模型内化成推理策略

RLVR Rollout Caps Are Not Just Cost Controls: Models Internalize Them as Reasoning Policies

» 固定 rollout token 预算不只是限制训练账单。它会改变模型对“何时继续想”的学习目标，使测试时给更多 token 也不一定换来更好答案。

触发：2611.26172 明确提出 budget internalization；2611.26084 说明 RL 只能强化已见成功轨迹；2611.25191 显示 reward 来源的盲区会迁移；2611.18627 又从异步单 rollout 挑战 GRPO 的固定组采样假设。

锚点论文

  • 2611.26172Budget Internalization: Fixed-Budget RLVR Trades Test-Time Scaling for In-Budget Accuracy— 把 rollout cap 从训练成本变量改写为行为先验，是这个 topic 的直接触发点。
  • 2611.26084RL Can Only Reinforce What It Sees Succeed— 给出干净机制：稀有成功轨迹没被采到，RL 就不会稳定学到它。

  • 2611.07639Measuring the Marginal Value of Verifier-Based RL Beyond Supervised Fine-Tuning— 提醒 RLVR 增益要和 SFT 覆盖、verifier 形状分账。

对立阵营

  • · 阵营 A：固定 rollout cap 是工程成本控制，训练后可在测试时用更多 token 补回来。

  • · 阵营 C：用自适应 rollout、单 rollout 异步更新或 coverage-aware reference reset，把计算预算作为优化对象。

品味：可证伪：放宽测试预算若不涨分，cap 已进策略。

#7H · 硬待研判2026-11-23denoising-shortcuts-in-nonar-lm

非自回归 LM 的训练信号要防捷径：看见自身噪声不等于学会上下文

Non-AR Language Models Need Shortcut-Proof Training Signals: Seeing Self-Noise Is Not Learning Context

» diffusion / flow LM 的一个隐藏错误是假设 denoising supervision 自然会学习跨 token 依赖。若模型能利用目标坐标自身的腐蚀状态，它可能降低 loss，却没有学到真正的 leave-one-out 条件分布。

触发：2611.26359 直接挑战 jump diffusion 中“看见自身噪声没事”的假设；2611.19127 用 leave-one-out Transformers 同时处理稀疏监督和自修正；2611.07721 则指出 continuous LM 的 embedding MSE 甚至可能丢失 token identity。

锚点论文

  • 2611.26359Learning from Context: Leave-One-Out Prediction in Jump Diffusions— 提出目标坐标腐蚀状态会形成捷径，直接命中训练目标的可识别性问题。
  • 2611.19127Empowering Masked Diffusion Models to Self-Correct with Leave-One-Out Transformers— 把 leave-one-out 结构做成模型接口，同时处理监督稀疏和已选 token 修正。

  • 2611.07845Masked diffusion as random sequential adsorption: an exactly solvable model for parallel decoding— 给出并行解码速度—错误权衡的可解析模型，可作为训练与采样错配的理论背景。
  • 2611.11551When Should Diffusion Language Models Reconsider Their Commitments?— 从可撤回承诺角度暴露 MDM 条件独立采样的局部一致性问题。

对立阵营

  • · 阵营 A：标准 denoising / mask prediction 足够，主要问题在 sampler、schedule 和 commit policy。
  • · 阵营 B：训练目标本身有捷径，必须用 leave-one-out、identity-aware supervision 或局部遮蔽约束修正。
  • · 阵营 C：把错误修正交给推理期循环、remask / edit policy 或 Levenshtein 操作，但不改主训练目标。

品味：关键不是更会悔棋，而是 loss 是否学到条件分布。

对立阵营

  • · 阵营 B：作者身份、账号风格和模型来源是可学习属性，不能用字符串去重覆盖。
  • · 阵营 C：通过预训练期压制、属性级 attribution、许可分层和作者级 holdout 来定义治理闭环。

Agent 推理优化不能用短文本验收：量化、KV 压缩和采样器要在轨迹分布上校准

Agentic Inference Optimizations Need Trace-Distribution Validation, Not Short-Text Proxies

» PPL、短问答和单轮吞吐不能预测长程 agent 的真实退化。100K token 工具轨迹、反复自检、回退和长 CoT 会改变量化误差、KV 价值和采样失败模式。

触发：2611.26157 显示 sub-3-bit 量化在短任务正常、在长程 agent 任务退化；2611.25433 指出 reasoning trace 的 KV 价值不能只看 attention；2611.25905 进一步要求用真实 workload replay 验证 agentic serving 平台。
