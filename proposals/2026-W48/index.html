#1H · 硬待研判2026-11-23judge-scale-geometry-reward-interface

LLM Judge 的分数轴不是中性接口：评测量表会变成训练奖励

The Score Axis Is Not Neutral: LLM-Judge Scales Become Reward Interfaces

» 同一个 rubric 换成 1–5、5–1 或不同分数拓扑，归一化后仍会系统漂移。更危险的是，一旦 judge 分数进入 RL，迁移的常常不是知识，而是类别级盲区和数值先验。

触发：2611.25588 和 2611.26077 同时把 LLM judge 的数值量表当作可操纵变量；2611.25191 进一步显示 judge 的盲区会被学生 RL 放大；2611.25135 和 2611.25168 则把问题推到 reward 校准与 belief-level 标签。

锚点论文

  • 2611.25588Rubric Semantics or Numerical Priors? Auditing Scale-Direction Bias in LLM Judges— 直接检验反向量表后 judge 是否仍按 rubric 语义评分。
  • 2611.26077Same Judgement, Different Scores: Numerical Scoring Topology in LLM-as-a-Judge Evaluation— 把分数空间形状本身作为干预，显示归一化不能消除系统漂移。
  • 2611.25191Blind Spots Travel, Knowledge Stays Home: What RL Inherits from an LLM Judge— 说明 judge reward 进入 RL 后，类别级偏差比单题知识更容易迁移。
  • 2611.25135Calibrated Decision Rewards: Training Language Models with a Judge That Knows How Sure It Is— 把 reference-free reward 的问题落到概率校准和分布外失败。
  • 2611.25168What a Calibrated Probability Hides: Belief-Level Post-Training for Decision Models— 指出聚合概率会混淆人群分歧与共同不确定性。

对立阵营

  • · 阵营 A：judge 是便宜评测器，固定 prompt 和 rubric 后可近似当作测量仪器。
  • · 阵营 B：judge 是带先验的决策模型，分数轴、方向、区间和校准方式都会改变估计对象。
  • · 阵营 C：judge 进入 RL 后不再只是评测噪声，而会把类别级偏差写入 policy。

品味：关键不是 judge 好坏，而是分数轴是否可训练。

#2M · 中待研判2026-11-23author-fingerprint-exposure

数据治理的单位要从样本升级到作者：单文本可识别性暴露了训练语料的新风险

From Sample Exposure to Author Exposure: One-Text Identifiability Changes Data Governance

» 成员推断问的是“这条样本是否在训练集里”，但作者级风险问的是“一个人是否可由风格、偏好和语料痕迹被识别”。如果 frontier model 只凭单段文本就能识别作者或模型来源，去重和污染审计都低估了暴露面。

触发：2611.26216 把 zero-shot、无候选列表、单文本识别推进到作者和账号级；2611.21315 显示 benchmark 泄漏已下沉到 base models；2611.24844 又说明删除特定数据不必然删除对应能力。OpenAI 的 Perplexity and Intelligence 同期把 loss 重新包装为能力信号，也提醒低 loss 可能包含细粒度作者统计。

锚点论文

  • 2611.26216Frontier models need only one text to unmask its human or AI author— 近期最直接的作者级可识别性证据，且设置刻意最小化外部辅助。
  • 2611.21315Benchleaking Is Accelerating: Benchmark contamination has worsened sharply in the past month -- from post-training down to pre-training base models— 说明泄漏问题不能只归因于 post-training 或榜单刷题。
  • 2611.24844General progress substitutes for specific training data in language models— 指出删掉某类数据后，模型仍可能通过通用进展恢复能力。
  • blog-openai-research-1a10f167Perplexity and Intelligence— 把 pretrain loss 与能力进展重新连接，适合作为低 loss 吸收细粒度统计的背景。
  • Carlini2021ExtractingTrainingDataExtracting Training Data from Large Language Models— 训练样本逐字泄漏的历史锚点。

对立阵营

  • · 阵营 A：隐私风险主要来自逐字记忆、PII 和训练成员推断。
  • · 阵营 B：作者级风格指纹本身就是可暴露对象，即使没有逐字复现。
  • · 阵营 C：能力可由替代数据恢复，删除样本不等于删除作者可识别特征。

品味：单样本文风识别把数据治理粒度改了。

MoE Routing Is Not Explanation: From Decodable Expert States to Intervenable Specialization

» router probe 的 AUROC 高，只说明路由状态携带信息，不说明它因果决定判断。MoE 专家分工要区分三件事：数据分配造成的 specialization、gate 学到的 dispatch、以及干预路由后任务行为是否改变。

触发：2611.25780 直接对 MoE verifier 的路由状态做干预，挑战“可读出即解释”的做法；2611.25167 尝试用训练数据分配替代显式 gate；Beam 501.3B/23.4B-active 和 Marin 535B-A23B 把大规模开放 MoE 的训练轨迹与系统约束放到台面上。

锚点论文

  • 2611.25780RouteVerify: Routing Interventions for Step-Level Verification in Mixture-of-Experts Models— 把 router probe 从相关性推进到因果干预。
  • 2611.25167Game-Theoretic Data Allocation for Expert Specialization and Routing— 用数据分配形成专家分工，挑战必须训练显式 gate 的默认路径。

对立阵营

  • · 阵营 B：路由可读出性，认为 router state 只是携带相关信号，需要因果干预验证。
  • · 阵营 C：路由可设计性，通过数据分配、shared expert、负载均衡和系统拓扑共同塑造专家分工。

#4M · 中待研判2026-11-23hidden-dimension-attention-economy

注意力稀疏化不只发生在 token 轴：QK 隐维计算也该进入预训练账本

Attention Sparsity Is Not Only Along Tokens: QK Hidden-Dimension Compute Belongs in the Pretraining Ledger

» 长上下文优化默认盯 token 维度：稀疏前缀、KV eviction、linear attention。HiSA 提醒另一个变量：RoPE QK 点积的隐藏维度可能有大量冗余，少算约三分之二维度仍可能不掉点甚至涨点。

触发：2611.26363 把 QK hidden dimension 的静态稀疏化推到 LLM attention 本体；2611.22947 用现代 kernel 重新压低 linear/kernel attention 的效率想象；2611.12956 说明 token-sparse attention 的索引器会吃回收益；2611.24809 也显示层选择代理和最终 hybrid 模型之间会失配。

锚点论文

  • 2611.26363HiSA: Sparsifying the Hidden Dimension of RoPE Attention in LLMs— 直接提出 hidden-dimension QK sparsity，并报告三分之一 QK 乘积仍可工作的反直觉结果。
  • 2611.22947The Kernel Reality Check: Benchmarking and Distilling Efficient Attention at Scale— 用现代 kernel 和质量对照重估 efficient attention 的真实收益。
  • 2611.12956ADIndex: Layer-Adaptive Sparse Attention Indexing via Group-Level Distillation— 显示 token-sparse attention 的 indexer 成本是实际瓶颈。
  • 2611.24809On-Policy Morphing into Hybrid Attention Models— 指出冻结代理选择 attention 层可能无法预测最终部署模型。
  • RoPE2021RoFormer: Enhanced Transformer with Rotary Position Embedding— RoPE QK 几何的基础锚点。

对立阵营

  • · 阵营 A：沿 token 轴省计算，靠 sparse attention、KV 压缩或线性 attention 降低长上下文成本。
  • · 阵营 B：沿 hidden 轴省计算，直接减少 QK 点积有效维度。
  • · 阵营 C：先做 kernel reality check，避免理论 FLOPs 被索引器、访存和部署形态吃掉。

品味：若结果稳，attention 成本模型要改维度。

#5M · 中待研判2026-11-23set-quality-over-independent-samples

多样化采样不是温度调参：合成数据和测试时计算都需要集合质量目标

Diverse Sampling Is Not Temperature Tuning: Synthetic Data and Test-Time Compute Need Set-Level Objectives

» pass@K 和 self-consistency 常把 K 次采样当作独立抽奖，但真实失败是候选集集中在相似语义模式上。若训练数据生成、rubric 构造和 test-time scaling 都依赖候选池，目标应从单样本质量转向覆盖、去冗余和可选择性。

触发：2611.25003 用 PoolDPP 形式化集合多样性；2611.25557 显示 rubric 构造常不是生成不出候选，而是从候选池里选不准；2611.24032 指出等价重写输入比重复采样有不同 scaling；2611.17610 则要求多 agent 收益先按样本数和计算量对齐。

锚点论文

  • 2611.25003A Model of Diverse Sampling from Language Models— 把多次采样的集合覆盖问题形式化，并给出 PoolDPP 目标。
  • 2611.25557The Coverage Selection Gap: Ranking, Not Generation, Limits LLM Rubric Construction— 说明候选生成足够时，瓶颈会转向候选选择。
  • 2611.24032Test-Time Symmetrization: Scaling Laws for Model-Agnostic Learning under Structure— 把 test-time compute 从重复采样转向结构等价重写。
  • 2611.17610More Agents, More Samples, or More Thinking? Untangling Coordination, Ensembling, and Test-Time Compute in Multi-Agent LLMs— 要求把多 agent 协调与更多样本、更多 token 的贡献拆开。
  • SelfConsistency2022Self-Consistency Improves Chain of Thought Reasoning in Language Models— 多样本推理聚合的基础锚点。

对立阵营

  • · 阵营 A：提高温度、top-p 或 K，用更多独立样本买覆盖。
  • · 阵营 B：显式优化候选集多样性，用 DPP、聚类或结构重写减少语义冗余。
  • · 阵营 C：把候选生成和候选选择分账，单独测 ranking、selection 与 verifier 误差。

品味：候选池是训练对象，不只是采样副产物。
