17:T5f1,The central claim of Interaction Models is that real-time collaboration should no longer be simulated outside the model by VAD, UI state machines, and tool schedulers; feedback timing, foreground copresence, and background reasoning should become part of the trainable system [TMLInteraction2026]. A 200ms time-aligned micro-turn gives up some plug-and-play flexibility of the traditional harness in exchange for capabilities that are hard to emulate: proactive interjection, simultaneous translation, live commentary, and visual correction; encoder-free early fusion hands the audio, video, and speech-output clock to the main model instead of freezing semantics through a Whisper-like encoder, a vision encoder, or a TTS decoder [Bai2024dMel][Touvron2022hMLP][Lipman2022Flow]. The more important agent/harness lesson is foreground interaction model × async background model: it is the real-time form of coding-agent sub-agent dispatch, where the foreground continuously absorbs user feedback while the background runs tools, search, and long reasoning, sharing context rather than switching between thinking and instant modes [KAME2025][MoshiRAG2026]. This route pushes tool scheduling, context accounting, and safety refusal from discrete turns into continuous time; TM's batch-invariant kernels and SGLang streaming sessions are therefore not systems appendices, but prerequisites for making 200ms interaction behavior reproducible, attributable, and regression-testable [TMLNondeterminism2025][SGLang2026Streaming].18:T493,The core value of Interaction Models is not the multimodal product shape, but a new split of turn detectors, foreground state machines, and background worker dispatch inside agent harnesses. 200ms micro-turns move feedback timing into the model forward pass, encoder-free early fusion reduces front-end semantic bottlenecks, and foreground interaction model × async background model looks like the real-time form of coding-agent sub-agent dispatch [TMLInteraction2026][KAME2025][MoshiRAG2026]. The deeper judgement is that once copresence becomes default, tool scheduling, context accounting, and safety refusal must migrate from discrete turns into continuous time; TM's Defeating Nondeterminism therefore becomes a reproducibility prerequisite for interaction research, not a detached systems detail [TMLNondeterminism2025][SGLang2026Streaming].19:T4f9,The key change is not a faster voice assistant, but moving interactive feedback from a VAD/state-machine harness into the model forward pass. The TM blog interleaves 200ms of input and 200ms of output into one time-aligned sequence, so silence, interruption, backchannels, and visual cues become context [TMLInteraction2026]. Moshi also removes explicit turn boundaries, but mainly models user speech and model speech as parallel streams for low-latency spoken dialogue [Moshi2024]; PersonaPlex adds voice and role control on that line, while the control variables remain conversational attributes [PersonaPlex2026]. TM's architectural implication is closer to an agent harness: feedback timing previously maintained by VAD, UI event loops, and state machines is compressed into a trainable sequence. The cost is also clear: VAD harness plugability drops, and debugging moves from readable rules to model behavior; the gain is that proactive interjection, simultaneous translation, live commentary, and visual correction no longer require separate harnesses. Clark and Brennan provide the interaction coordinates of copresence, contemporality, and simultaneity, but TM's engineering move is putting those coordinates into tokenization and serving clocks [ClarkBrennan1991].1a:T4c8,TM's encoder-free early fusion is not a minor optimization that saves one encoder; it refuses to let large independent front-ends decide multimodal semantics first. Audio enters through dMel and a lightweight embedding [Bai2024dMel], video becomes 40×40 patches projected by hMLP [Touvron2022hMLP], and audio output is generated through a flow head [Lipman2022Flow], all co-trained with the Transformer [TMLInteraction2026]. The difference from a Whisper-like encoder + frozen LM + TTS decoder pipeline is responsibility assignment: cascades let front-ends decide what reaches the LM, while TM makes the main model learn which audio/video details change interaction actions on the 200ms clock. Qwen3-Omni is one of the strongest public contrasts, using modular Thinker/Talker components for low first-packet latency and broad modality coverage [Qwen3Omni2025]; TM's choice is more aggressive because the real-time interaction clock is also inside the main training problem. The risk is higher training cost and harder attribution, but the route fits Sutton's judgement about scalable learning systems: hand-written interfaces win early controllability, learned interfaces absorb more exceptions at scale [Sutton2019Bitter].1b:T494,TM's most important agent lesson is not multimodality, but keeping a foreground interaction model and an async background model present at the same time. In coding-agent harnesses, Task/sub-agent dispatch is usually discrete: the main agent stalls, sends a subtask, waits for a return, then merges context. TM turns the same structure into a real-time version: the foreground model keeps listening, watching, answering, refusing, and absorbing user corrections, while the background model runs tools, search, and long reasoning; results are woven back by the foreground according to the current interaction moment [TMLInteraction2026]. KAME already demonstrates a speak-while-thinking tandem architecture [KAME2025], and MoshiRAG uses gaps in full-duplex response for retrieval [MoshiRAG2026], but their background path is closer to a knowledge-assist layer. TM's difference is shared context plus persistent foreground: the background is not another response mode, but a worker co-present with the user. Tool scheduling, context accounting, and safety refusal therefore cannot be decided only at turn end; they need budgeting, preemption, and rollback in continuous time.1c:T4a1,Continuous interaction amplifies nondeterminism from evaluation noise into product behavior differences, so TM's batch-invariant kernels and trainer-sampler bitwise alignment are infrastructure for Interaction Models. The TM blog reported that TML-Interaction-Small uses deterministic kernels with less than 5% end-to-end overhead, including NVLS all-reduce/reduce-scatter on Blackwell and Split-KV consistent accumulation between prefill and decode [TMLInteraction2026][TMLNondeterminism2025]. The difference from ordinary LLM serving is attribution pressure: when 200ms prefill, streaming sessions, tool dispatch, and speech overlap coexist, one different accumulation order can surface as a different interruption time, refusal boundary, or tool call. SGLang streaming sessions are the other half of the inference stack: each 200ms chunk arrives as a request, while the server keeps a persistent sequence in GPU memory to reduce repeated metadata work and allocation [SGLang2026Streaming].
