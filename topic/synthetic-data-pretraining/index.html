Synthetic Data for Pretraining：证据地图与实验路线

从网页重述到结构化语料：阶段、对照与端到端成本

15 篇论文·2026年10月31日

领域综述

围绕预训练合成语料的来源、生成方式、训练阶段与预算对照，整理 15 篇论文及一个开放项目；覆盖 WRAP、Phi、Nemotron-CC、计入生成成本的 Rewriting Scaling Laws，以及 2026 的结构化教材、QVAC、PPT 与 Indic 进展。明确区分直接 pretrain、midtrain 与相邻证据。

TL;DR

合成数据应按它改变了什么学习信号来评估：来源覆盖、表达方式、监督密度、文档组织或初始化。先区分从零预训练与 midtrain，再在等训练预算和等总成本下比较；语料更大、分数更高都不能单独证明可扩展。[4][11][13]

先按训练阶段划清证据边界

这里的 synthetic data 指模型或程序实际生成的新文本、重写文本、翻译文本或结构化序列。给真实网页打质量分、筛选 FineWeb/DCLM 风格语料，本身不等于生成训练 token。一个重要反例是 DeepSeekMath：摘要明确说 120B math-related tokens 源自 Common Crawl，随后继续预训练，并另外研究 GRPO；不能把这 120B 写成合成数学语料。[5]

从零 pretrain、从已有基座继续预训练的 midtrain、以及 instruction SFT/RL 必须分开。QA 格式并不自动代表 SFT：WRAP 的 QA 风格重述被用于联合预训练；反过来，“pre-trained model”只描述初始化，不能据此认定某个数据集被用于 pretrain。[4] 本文保留 midtrain 和相邻 scaling 研究，但明确标注它们不能直接证明从零基座训练的收益。

核心证据地图：可复用什么，不能推出什么

表中数字来自已打开的原始摘要或项目正文，只表达作者报告的设定与结果。不同论文的指标、训练阶段与预算不相同，不能横向拼成统一收益曲线。

三条优先落地的数据路线

第一条是 source-grounded rewrite：保留 source 文档和版本，比较原文、原文+重述、只有重述；把文风、事实保留、内容覆盖与去重作为分开的变量。WRAP 提供联合预训练证据，Nemotron-CC 把重述放进更长 horizon 的数据治理问题，但它同时改变了过滤策略。[4][7]

第二条是 seed-grounded textbooks：从覆盖可审计的主题或文档 seed 生成教材，不只扩大同一批 prompt 的采样次数。Cosmopedia 的公开项目包含超过 30M 文件、25B tokens，使用 Mixtral-8x7B-Instruct-v0.1，并强调 prompt curation 和多样性；它是可参考的开放生成流程，不能仅凭语料大小推断训练收益。[16] Phi 系列给出小模型教材化训练的证据，但必须拆开基座与后续微调。[2][3]

第三条是 structured / executable synthesis：代码执行轨迹、具备 source grounding 的整本教材、或程序化初始化序列。CodeAlchemy 提供代码语义视图与执行轨迹；Book-level 研究说明同样文本怎样组成文档也是实验轴；PPT 研究把合成数据放在自然语言 PT 之前的初始化课程。[9][11][13] 三者不是可互换的数据桶。

2026 增量：从生成量转向信息来源与组织方式

最值得优先复查的是 Book-level 的控制链：Full 对比同内容 Split，控制生成内容；对比同长度 RandomConcat，控制长度；对比同 retrieval pool 的 Rephrase，比较结构化生成。摘要分别报告 Full 对 Split 的 +1.02、对 Rephrase 的 +1.17 平均收益。它是 midtrain 证据，迁移到从零 pretrain 时要重新测，而不是直接套用差值。[11]

QVAC 把弱学生失败转成纠错说明、成功转成选项级解释；公开摘要给出 1.7B from-scratch 消融。它提示“生成什么监督”可受学生状态驱动，但不同模型规模、非 STEM 长尾和 teacher 成本仍需要额外实验。[12]

PPT 的 500M–7B 与最多 100B PT tokens 实验报告收益仍存在；其摘要反对把收益统一解释成 grammatical prior，转而指向 long-range retrieval。该结论是作者在这些任务与混合语料下的机制判断，不能等同于合成自然文本的规模律。[13]

Indic 项目则把翻译、质量评估、修复、文档结构与 source traceability 连起来。它支持面向低资源语言的 continued-pretraining 配方，并专门检查 Indic share 对英语表现的影响；语言收益与通用能力保持要一起看。[14]

10 月关键增量：计入生成成本的 rewriting scaling law

Rewriting Scaling Laws 是这次整理中与 pretrain synthetic + scaling 最直接交叉的一篇。它用模型大小、训练 tokens、rewrite fraction 与自然数据重复轮数预测 loss，并把生成 rewrite 的 compute 计入预算。[15]

在 compute-limited 设置，自然数据充足，使用外部 rewriter；作者报告估计的最优 rewrite fraction 从 3×10^18 FLOPs 时的不足 10%，增至 10^22 FLOPs 时的 32%。从小规模拟合向外推 33× FLOPs，训练 22B 模型，最终 loss 与预测偏差在 1.1% 内。这些都是该论文设置下的结果，不是可直接复制到任意训练的 32% 配方。[15]

在 data-limited 设置，固定自然 seed 数据，rewriter 与 target 同规模且先在该 seed 上训练；摘要报告直到 3B 的各规模，使用 rewrites 的模型都优于该设置下最好的自然数据-only run。其“超过 rewriter”的证据是若干 web domains 上的 BPB，而不是全面能力超过 teacher。[15]

因此下一个实验优先级是：在自己的数据分布和生成成本上重拟合 mixture 曲线，并留出高预算点检验，而非只在固定比例上扩大合成量。

Scaling：先区分三个预算

建议把每个实验写成三本账：source budget（独立 seed、文档与 teacher 版本）、generation budget（teacher input/output、候选数、过滤保留率）、student budget（unique tokens、累计 tokens、参数量和训练 FLOPs）。这是一份实验设计建议，不是文献已经证明的最优策略。

Fixed-Source Synthesis 工作在固定 seed-question pool 与 teacher 的条件下扩大 response budget，对比 source expansion；作者发现相同 total-sample budget 下，大预算时增加 seed 问题优于继续多采样。[10] 它对合成预算设计很有价值，但不能把该结果直接称作从零 pretraining 的已验证规律。

WRAP 的 pretraining 效率、PPT 节省的后续 PT tokens、以及语料发布的 token 总量，是三个不同的口径。[4][13][12] 推荐同时报告等 student FLOPs 与等端到端成本两种曲线；只有生成数据能复用到多个 run 时，才另报明确摊销次数的成本。

递归风险：累积数据不等于无限安全

Recursion 工作指出生成数据反馈可能造成原分布尾部丢失；Accumulation 工作在原始真实数据与历代合成数据共同累积的设置下，展示了避免 collapse 的结果。[1][6] 后者修正的是数据替换假设，不支持“只要留 30% 真实数据就安全”或“加 verifier 就永不坍塌”。

工程上建议保留可追溯的原始真实数据锚点，按代记录 teacher、seed 与所有数据变换，并分别监控 held-out real-text loss、低频知识、长尾域、语言分布和重复率。过滤后高平均分与尾部覆盖可能冲突；何种真实/合成比例最好，应由固定预算下的混合曲线决定，而不是由一条通用阈值决定。

建议的最小实验矩阵

以下全部是建议实验，未在本项目执行，不是论文结果。先固定 tokenizer、初始化、模型、sequence length、训练 tokens 与优化设置，再做小规模筛选；通过后在更大模型和更长 token horizon 上留出验证点。

A：原始真实数据 baseline；B：同一真实数据重复采样；C：筛选后的真实数据；D：真实+source-grounded rewrite；E：真实+教材生成；F：同内容的不同文档组织。B 防止把“多看一遍”当成新增信息，C 把筛选贡献与生成贡献分开，F 借鉴 Book-level 的控制思路。[11]

第一轮可把 synthetic consumed-token fraction 设为 0、0.1、0.3、0.5 的候选网格，只是搜索起点，不是推荐生产比例。对优胜路线固定 source/teacher 改每 seed 采样数，再固定采样数扩展独立 source。后者受 Fixed-Source 的实验分解启发，仍需在目标 pretrain regime 验证。[10]

验收同时看领域下游分数、通用 held-out loss、长尾/多语言保持、去污染后的评测、等 FLOPs 收益和总生成成本。连续生成的兄弟样本必须按 source family 分组切分，避免同一个 seed 的改写同时进入训练和验证。大规模外推至少留一个未参与拟合的模型/预算点；报告排序是否反转和不确定性，而不只给拟合曲线。

日报怎样持续追踪这个专题

日报新增可复查的 research-focus 元数据：同一论文可以同时进入 synthetic 与 scaling；训练阶段保留文本证据，缺失时标“待确认”，不由 corpus/textbook/pretrained 猜测。首页和近 60 日汇总默认展示 synthetic 的 pretrain+midtrain，并可切到 SFT/posttrain、待确认或全部阶段。

机器阶段标签只是检索线索，尤其标题的“pretraining corpus”与实验的 continued pretraining 可能不一致。专题中的阶段判断以已读原文为准：例如 Indic 明确列在 continued pretraining；Fixed-Source 列为相邻预算证据。[14][10] 新论文优先补齐 teacher、source、阶段、语料库存/训练消耗、消融与成本缺口，再决定是否提升阅读优先级。

实践要点

优先复现有 source grounding 且有干净对照的重述或结构化教材路线。把 teacher 采样数与 source 扩展分开，把库存 token 与训练 token 分开，把训练提速与总成本分开。任何“最佳合成比例”和“不会 collapse”的判断都需要对应模型、预算和尾部评测。
