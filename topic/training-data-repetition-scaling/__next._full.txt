17:Ta53,有限数据能不能被重复用，答案不是“能”或“不能”，而是要先判断重复发生在哪类子集上。在 web-bulk 上，重复主要是在同一信息上继续写权重；Hernandez 2022 与 Muennighoff 2023 看到的 2–4 epoch 后 effective token 折算率下降，仍是最可靠的默认线 [Hernandez2022RepeatedData][Muennighoff2023DataConstrained]。在 reasoning、算术和长尾事实上，相同结论不成立：Charton 2024 的算术实验、Allen-Zhu 2024 的事实写入曲线、Wang 2025 的 implicit-reasoning scaling law 都指向同一件事——有些能力不是靠更多不同样例出现，而是靠同一pattern 被看够次数后才 lock in [Charton2024Emergent][AllenZhu2024Knowledge][Yang2025ImplicitReasoning]。所以“扩 unique data”和“重复有限高质量数据”不是替代关系；前者解决覆盖面，后者解决某些 key 没有写深的问题。把二者混成一个 global epoch 超参，才是 4-epoch 神话真正的问题。

更精确的边界是三条曲线。曲线 0 是 Chinchilla/Kaplan 的 compute-bound 区间：D 充裕时，1 epoch 的 fresh token 是基准，重复通常浪费 [Kaplan2020][Hoffmann2022Chinchilla]。曲线 1 是固定 mixture 的 uniform repeat：干净池前几轮仍有收益，但收益很快从“等效新鲜 token”变成 memorization 与 capacity crowding [Hernandez2022RepeatedData][Xue2023TokenCrisis]。曲线 2 是 targeted repeat：对 math/code/reasoning/长尾事实这类子集，8–32 次曝光仍可能比同 token budget 的更多 fresh examples 更有效 [Charton2024Emergent][Zuo2025MemoGuided]。Cabannes 2024 的 associative-memory 解释把这三条线接起来：重复不是凭空创造新 key，而是把已有 key 写深；该 key 未写够时是泛化收益，已饱和时就是记忆化挤占 [Cabannes2024AssocMem]。

因此，最低成本的验证不应是“看哪个 epoch loss 最低”，而应是一个小型 scaling ladder：3 个模型规模 × 3 个 multiplicity × 3 类 subset，在同 token budget 下比较。loss/bpb 只回答语言模型平均拟合得更好没有，不能回答是否学到目标能力、是否进入记忆化相位、是否污染评测。Hong 2024 证明 representation-side memorization 早于 val loss 反弹出现 [Hong2024ROME]；Charton 2024 证明能力浮现时 loss 可以几乎不动 [Charton2024Emergent]。所以 ladder 的验收指标至少要包括 val loss、memorization window、per-skill learning curve、独立 contamination probe 和 capability eval。这样得到的不是一个“4 epoch 上限”，而是每类子集自己的 repeat envelope。18:Tad1,Finite data can be reused, but only after asking *which subset* is being repeated. On web-bulk, repetition mostly keeps writing weights on the same information; the 2–4 epoch decay in effective-token exchange rate from Hernandez 2022 and Muennighoff 2023 remains the best default line [Hernandez2022RepeatedData][Muennighoff2023DataConstrained]. On reasoning, arithmetic, and long-tail facts, that line does not hold: Charton 2024's arithmetic experiments, Allen-Zhu 2024's fact-acquisition curves, and Wang 2025's implicit-reasoning scaling law all say the same thing — some abilities do not appear from more different examples, but from seeing the same pattern enough times to lock it into the weights [Charton2024Emergent][AllenZhu2024Knowledge][Yang2025ImplicitReasoning]. Thus "more unique data" and "reusing limited high-quality data" are not substitutes: one buys coverage, the other deepens under-written keys. Collapsing both into a single global epoch knob is the real mistake behind the 4-epoch myth.

The cleaner boundary is three curves. Curve 0 is the Kaplan/Chinchilla compute-bound regime: when D is plentiful, one pass over fresh tokens is the baseline and repetition is usually waste [Kaplan2020][Hoffmann2022Chinchilla]. Curve 1 is uniform repeat over a fixed mixture: the first few passes over a clean pool still help, but the return quickly shifts from fresh-equivalent tokens to memorization and capacity crowding [Hernandez2022RepeatedData][Xue2023TokenCrisis]. Curve 2 is targeted repeat: for math/code/reasoning/long-tail facts, 8–32 exposures can still beat more fresh examples at the same token budget [Charton2024Emergent][Zuo2025MemoGuided]. Cabannes 2024's associative-memory account links the curves: repetition does not create new keys; it writes existing keys deeper. If the key is under-written, this is generalization; if it is already saturated, it becomes memorization crowding [Cabannes2024AssocMem].

The cheapest validation is therefore not "pick the epoch with the lowest loss", but a small scaling ladder: 3 model sizes × 3 multiplicities × 3 subset classes at matched token budget. Loss/bpb only says whether average language modelling got easier; it does not say whether the target capability appeared, whether the run has entered a memorization phase, or whether the eval was contaminated. Hong 2024 shows representation-side memorization appears before val-loss rebound [Hong2024ROME]; Charton 2024 shows capability can emerge with almost no loss movement [Charton2024Emergent]. The ladder therefore needs val loss, memorization window, per-skill learning curves, an independent contamination probe, and capability evals. The output is not a universal 4-epoch ceiling; it is a repeat envelope for each subset class.19:Ta82,**答案不是“多找数据”或“多训几轮”，而是先给每类子集定 repeat envelope。** 同一训练 run 里至少有三种不同数据对象：web-bulk、curated high-quality、reasoning/long-tail。它们共享一个 optimizer，却不共享同一条 repetition law。

**Q1：是否真的必须 scaling up unique data？** 在 web-bulk 上，是。Hernandez 与 Muennighoff 的 uniform-repeat 实验仍是最可靠的默认线：前几轮能近似兑换 fresh token，随后折算率快速下降 [Hernandez2022RepeatedData][Muennighoff2023DataConstrained]；Xue 2023 在 1B–13B 多尺度复现了这个方向 [Xue2023TokenCrisis]。这类文本的主要价值是覆盖面，重复一遍不能替代新页面、新主题、新格式。

在 reasoning、算术和长尾事实上，答案相反。Charton 2024 在受控算术上给出最干净的反例：同 token 预算下，少样例 × 高 multiplicity 出现能力，多样例 × 单次曝光不出现 [Charton2024Emergent]。Allen-Zhu 2024 的 per-fact 曲线也指向同一个机制：很多事实不是一次曝光就进入参数，而是在第 K 次曝光附近突然 lock in [AllenZhu2024Knowledge]。Wang 2025 把这个现象写进 implicit-reasoning scaling law：pattern multiplicity 是独立变量，不是 D 的别名 [Yang2025ImplicitReasoning]。

Galactica 处在中间：100%-curated 科学池 4+ epoch 仍能降 loss [Taylor2022Galactica]，说明高质量有限池可以被重复使用；但它不证明 web-bulk 也能无脑重复，也不证明不需要扩新数据。更稳的结论是：扩 unique data 买覆盖，targeted repetition 买 key depth。两者是互补约束，不是二选一。

**Q2：简单 scaling ladder 怎么做，loss 能不能作唯一指标？** 最小 ladder 不需要大：3 个模型规模 × 3 个 multiplicity × 3 类 subset，同 token 预算即可。这个设计不是为了找“最低 loss 的 cell”，而是为了 falsify 两个假设：web-bulk 是否真的在 m=4/16 之后进入折算率下降，reasoning-targeted 是否在 m=16 才出现能力。Lin 2025 的结论很直接：proxy 不带 K-epoch 维，就无法预测 frontier reasoning 曲线 [Lin2025ProxyReasoning]。

loss 只能当守门指标，不能当结论指标。Hong 2024 显示 representation/logit 侧的 memorization 早于 val loss 反弹 [Hong2024ROME]；Charton 2024 显示能力浮现时 loss 可以几乎不动 [Charton2024Emergent]。因此 ladder 每个 cell 至少要同时报：val loss/bpb、memorization window、per-skill learning curve、0-exposure contamination probe、capability eval。只看 loss，等于看不见 curve 1 的越线，也看不见 curve 2 的收益。1a:Tb1b,**The answer is neither “find more data” nor “train more epochs”, but assign a repeat envelope to each subset class.** A single run contains at least three different objects: web-bulk, curated high-quality data, and reasoning/long-tail data. They share an optimizer; they do not share one repetition law.

**Q1: must we scale up unique data?** On web-bulk, yes. Hernandez and Muennighoff's uniform-repeat experiments remain the best default line: the first few passes can exchange for fresh tokens, then the exchange rate decays quickly [Hernandez2022RepeatedData][Muennighoff2023DataConstrained]; Xue 2023 reproduces the direction across 1B–13B [Xue2023TokenCrisis]. The value of this text is coverage; another pass over it does not replace new pages, topics, and formats.

On reasoning, arithmetic, and long-tail facts, the answer flips. Charton 2024 gives the cleanest counter-example on controlled arithmetic: at matched token budget, few examples × high multiplicity produces capability, while many examples × single exposure does not [Charton2024Emergent]. Allen-Zhu 2024's per-fact curves point to the same mechanism: many facts do not enter the weights after one exposure, but lock in around the K-th exposure [AllenZhu2024Knowledge]. Wang 2025 writes this into the implicit-reasoning scaling law: pattern multiplicity is an independent variable, not a synonym for D [Yang2025ImplicitReasoning].

Galactica sits in the middle: a 100%-curated science pool still reduced loss after 4+ epochs [Taylor2022Galactica], so limited high-quality pools can be reused. But it does not prove web-bulk can be repeated blindly, and it does not remove the need for new data. The stable conclusion is: unique data buys coverage; targeted repetition buys key depth. They are complementary constraints, not substitutes.

**Q2: what should the small scaling ladder test, and can loss be the only metric?** The minimum ladder is small: 3 model sizes × 3 multiplicities × 3 subset classes at matched token budget. It is not a search for the lowest-loss cell; it is a falsification test for two hypotheses: whether web-bulk really enters exchange-rate decay at m=4/16, and whether reasoning-targeted data only starts paying at m=16. Lin 2025 is direct: a proxy without a K-epoch axis cannot predict frontier reasoning curves [Lin2025ProxyReasoning].

Loss is a gate metric, not a conclusion metric. Hong 2024 shows representation/logit-side memorization appears before val loss rebounds [Hong2024ROME]; Charton 2024 shows capability can emerge with almost no loss movement [Charton2024Emergent]. Each ladder cell therefore needs at least val loss/bpb, memorization window, per-skill learning curves, a 0-exposure contamination probe, and capability evals. Loss-only evaluation misses both Curve 1 crossing the line and Curve 2 starting to pay.1b:Tb01,**曲线 0（compute-bound）**: D ≥ 20·N，1 epoch 最优 [Kaplan2020][Hoffmann2022Chinchilla]。对今天的 frontier 几乎不再适用，但仍是衡量 efficiency 的零点——任何 multi-epoch 配方都该和“同 compute 下用更多 fresh token 1 epoch”做对照。

**曲线 1（uniform repeat）**: 在固定 mixture 上均匀多 epoch。三篇互相印证的工作：
- Hernandez 2022 [Hernandez2022RepeatedData] 在 small/mid scale 上观察到：把一个干净池子里塞入 0.1%–10% 的“被重复 K 次”子集，整体 loss 与 K 不是单调下降——超过约束阈值后开始反吞，并在 induction-head 上留下机制指纹；
- Muennighoff 2023 [Muennighoff2023DataConstrained] 把它写成可拟合的“effective fresh-token equivalent”函数：前 ~2–4 epochs 接近 1（每多一遍 ≈ 等量新鲜），后续以 e^{-α·(E-4)} 形式衰减；
- Xue 2023 [Xue2023TokenCrisis] 在 1B–13B 多个尺度独立复现，并观察到 quality不一致时曲线斜率剧变——高 quality 子集多 1–2 epoch 仍然涨，低 quality 子集 1 ep 后立掉。
**判别**：阵营“4 ep 作普世上限”的同学读这三篇时常常忽略两件事：(a) 实验都是uniform passes over fixed mixture，不能直接外推到 per-subset 决策；(b) Galactica [Taylor2022Galactica] 的 4-epoch 是在已经 100% 人工筛过的科学语料上，和 web-scale 的 4 epoch不是同一条曲线——把这两个 number 混着说，是“4 epoch 神话”的关键源头。

**曲线 2（targeted repeat）**: 同一子集重复 8–32 次仍涨。三篇组合：
- Charton & Kempe 2024 [Charton2024Emergent] 在受控算术任务上，同 token 预算下**少样例 × 高 multiplicity** 触发 emergent capability，**多样例 × 1 ep** 不触发；
- Allen-Zhu 2024 [AllenZhu2024Knowledge] 在受控合成事实上做 per-fact 跟踪，证明事实写入参数所需 exposure 远多于 1，且很多事实在第 K 次曝光才突然 lock-in；
- Zuo 2025 [Zuo2025MemoGuided] 用 memorization window 信号在 LLM 上把uniform 4-epoch 上限往后推；同样 budget 下 quality-test set 仍持续涨。

**为什么三条曲线不能合一**：曲线 1 的退化机制（key 容量已饱和→ memorization挤占 generalization）和曲线 2 的获益机制（emergent capability 必须经历多次曝光才浮现）发生在同一个模型里——但**作用在不同子集上**。Cabannes 2024 的associative-memory 模型 [Cabannes2024AssocMem] 给出最简的统一解释：repeat = 把已有 key 写得更深；这件事在 key 已经存在但没写够时是收益（曲线 2），在 key 早已饱和但模型还在花容量去复读时是损耗（曲线 1）。**全局 epoch 旋钮把两者混成一条平均曲线，自然得到一个 4-epoch 假上限**。1c:Tb0d,**Curve 0 (compute-bound)**: D ≥ 20·N → 1 epoch is optimal [Kaplan2020][Hoffmann2022Chinchilla]. Hardly applicable at the frontier now, but still the efficiency zero — any multi-epoch recipe should be benchmarked against "same compute, more fresh tokens, 1 epoch."

**Curve 1 (uniform repeat)**: uniform multi-epoch on a fixed mixture. Three mutually corroborating studies:
- Hernandez 2022 [Hernandez2022RepeatedData] observes at small/mid scale: inserting a 0.1%–10% repeated-K-times subset into a clean pool yields a non-monotone loss in K — past a threshold, returns reverse and induction heads carry a mechanistic fingerprint;
- Muennighoff 2023 [Muennighoff2023DataConstrained] formalises it as a fittable "effective fresh-token equivalent" function: near 1 within ~2–4 epochs (each pass ≈ fresh-equivalent), then decay as e^{-α·(E-4)};
- Xue 2023 [Xue2023TokenCrisis] independently reproduces across 1B–13B and shows the slope is sensitive to quality — high-quality subsets keep gaining 1–2 extra epochs, low-quality flips to negative immediately past 1 epoch.
**Judgment**: the "4 ep as universal ceiling" camp tends to miss two things in these papers: (a) the experiments are uniform passes over fixed mixture and don't extrapolate to per-subset decisions; (b) Galactica's [Taylor2022Galactica] 4 epochs sits on a 100%-curated science corpus and is not the same curve as a web-scale 4 epochs. Conflating these two numbers is a primary origin of the "4-epoch myth."

- Charton & Kempe 2024 [Charton2024Emergent]: on controlled arithmetic, at matched token budget, **few × high-multiplicity** triggers emergent capability while **many × single exposure** does not;
- Allen-Zhu 2024 [AllenZhu2024Knowledge]: per-fact tracking on synthetic controlled facts shows fact encoding needs many exposures and many facts lock in only at the K-th;
- Zuo 2025 [Zuo2025MemoGuided]: a memorization-window signal on real LLMs pushes the uniform 4-epoch ceiling further while quality-test loss keeps decreasing at matched budget.

def should_continue(policy, monitor) -> bool:
    """Per-step decision: does this subset still earn its next pass?

    monitor is the state object produced by the training loop; it carries the
    val_loss series, the per-example loss-retention window, and per-skill
    accuracy curves on the held-out reasoning suite.
    """
    if monitor.epochs[policy.name] >= policy.epoch_cap:
        return False
    if policy.stop_signal == 'val_loss':
        return monitor.val_loss_still_decreasing(policy.name, window=2_000_000)
    if policy.stop_signal == 'memo_window':
        # See Zuo et al. 2025: continue while loss-retention growth
        # outpaces downstream-eval growth by < 1.5x; stop once retention
        # dominates (== mostly memorizing).
        return monitor.memo_window_score(policy.name) < 1.5
    if policy.stop_signal == 'per_skill_curve':
        # See Kang et al. 2024: per-example trajectory signature; stop
        # when generalization gap on held-out reasoning re-opens.
        return monitor.gen_gap_reopening(policy.name) is False
    return False

def step(batch_iter, policies):
    monitor = TrainingMonitor()

                  if p.curve != 'guardrail'
                  and should_continue(p, monitor)]
        # honour multiplicity caps; sample within active subsets only.
        sample = batch.draw_from(active)

SUBSETS   = ['web_bulk', 'curated_quality', 'reasoning_targeted']

class LadderCell:
    N: str
    multiplicity: int
    subset: str
    tokens: int = TOKENS_PER_CELL

    @property
    def expected_curve(self) -> str:

        if self.subset == 'web_bulk':

        if self.subset == 'curated_quality':
