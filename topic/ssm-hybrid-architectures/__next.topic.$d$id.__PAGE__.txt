4:T53a,Several commonly reused assumptions are often conflated and need separation. (1) Operator complexity is not end-to-end throughput: SSM’s O(L) pays off only when kernels map scan/conv to hardware-friendly forms. Mamba’s parallel scan and hardware-aware implementation is a key step [Gu2023Mamba]; SSD further treats SSMs as structured-mask attention, allowing matmul-friendly routes to replace parts of scan and yielding 2–8× training speed ranges [Dao2024TransformersAreSSMs]. (2) “Usable long context” depends on addressable interaction: attention naturally provides token-to-token discrete selection, whereas pure recurrent state behaves more like continuous compression and is more prone to interference in copying/exact recall. 6:T543,Once attention is confined to “discrete retrieval/routing,” layer ratios naturally move toward sparsity. Jamba uses 1:7 (attention:Mamba) and adds MoE: a small number of attention layers provide addressable cross-token interaction, while Mamba carries most sequence computation; the paper also gives a workable 256K setup on a single 80GB GPU, showing that attention need not appear in every layer to maintain usable quality [Lieber2024Jamba]. Samba sits at the other end: it further restricts attention to SWA and uses 1:3 (SWA:Mamba) to improve long-context training throughput, reporting ~4× faster training at 128K [Ren2024Samba]. Zamba pushes “less attention” to the limit by reusing one shared attention block across multiple positions, suggesting that the load-bearing piece is a small global interaction channel, not many stacked attention parameters [Glorioso2024Zamba]. These designs match the earlier motivation for state-space augmented Transformers: let attention handle sparse cross-token interaction and delegate most token computation to linear modules [Zuo2022SSAugmentedTransformer]. By contrast, “pure SSM will replace attention” must explain how the structural copying/ICL gap is closed; current evidence instead supports treating attention as necessary but scarce [Jelassi2024RepeatAfterMe][Grazzi2024IsMambaICL].7:T57d,The Transformer camp’s claim is simple: context can be extended without changing architecture, using sparse/windowed/approximate attention and positional encoding. Longformer uses local windows plus a few global tokens to reach near-linear complexity [Beltagy2020Longformer]; Sparse Transformers factorize attention with fixed sparse patterns to reach subquadratic cost [Child2019SparseTransformers]; Performer approximates softmax attention with kernel methods for linear time [Choromanski2020Performer]; Reformer reduces memory via LSH attention and reversible layers [Kitaev2020Reformer]; Mistral 7B’s SWA + GQA shows that “windowing + head compression” works in practice [Jiang2023Mistral7B]. But “enough” has to cover two failure modes: (i) length generalization and sensitivity to positional representations—positional encoding choices strongly affect extrapolation [Kazemnejad2023PELengthGeneralization], and randomized positional encodings improve copying-style extrapolation [Ruoss2023RandomizedPE]; (ii) long-context usage efficiency—Lost in the Middle shows degraded use of mid-context information [Liu2023LostInTheMiddle]. As a result, Transformer extensions are often the simplest default up to ~32K; but under matched-throughput constraints at 128K+, whether they can maintain usable recall at similar cost still requires head-to-head evaluation against Hybrid [An2023LEval].8:T449,RWKV’s value proposition is clear: at inference, KV cache memory does not grow with L, making it fit streaming and tight-memory deployments; on the training side, it rewrites linear recurrence into a parallelizable form to avoid “RNN training is slow” [Peng2023RWKV], with algorithmic lineage back to parallel scan for linear recurrences [Martin2017ParallelLinearRNN]. GateLoop further makes recurrence updates data-controlled, showing that linear recurrence need not mean fixed decay and can learn richer gating and memory writes [Katsch2023GateLoop]. But for LM architecture selection, the gaps are just as clear: (i) no matched-token/compute/context head-to-head comparisons against Mamba/Hybrids on exact recall (copying/MQAR/needle); (ii) theory suggests constant-memory recurrence may need stronger state structure or external interaction channels to express certain discrete addressable behaviors [Merrill2020RNNHierarchy]. Therefore, treating RWKV as a full replacement for Transformers is under-supported; treating it as an engineering-specialized route for streaming/edge is safer.9:T787,一条可执行的清单（带边界与理由）：
1) Do：上下文 ≤8K 的生产默认用 Transformer；不要为了“未来可扩展”提前引入 Hybrid，两套 kernel 与训练配方的维护成本通常抵不过收益 [Vaswani2017AttentionIsAllYouNeed][Jiang2023Mistral7B]。

1) Do: For ≤8K production contexts, default to Transformers; don’t introduce Hybrids “for future extensibility” because maintaining two kernel stacks and recipes rarely pays off [Vaswani2017AttentionIsAllYouNeed][Jiang2023Mistral7B].
2) Do: For 32K–256K with throughput sensitivity, start from 1:3 (SWA:Mamba). SWA caps attention cost to a window while Mamba provides linear throughput; there is a concrete 128K training-throughput gain report [Ren2024Samba][Gu2023Mamba].
3) Do: For >256K with MoE/capacity needs, prefer 1:7 (attention:Mamba)+MoE. Treat attention as scarce global interaction layers; there is a workable 256K single-80GB configuration [Lieber2024Jamba].
4) Don’t: Treat matched training loss as evidence of “usable long context”; validate on L-Eval or needle/copying-style tasks for mid-context usage and exact recall [An2023LEval][Liu2023LostInTheMiddle].
5) Don’t: Expect exact recall to naturally catch up in pure Mamba/pure recurrence; copying and ICL comparisons suggest a structural inductive-bias gap that needs an explicit addressable interaction channel (a few attention layers or external memory) [Jelassi2024RepeatAfterMe][Grazzi2024IsMambaICL][Park2024CanMambaLearnHowToLearn].
