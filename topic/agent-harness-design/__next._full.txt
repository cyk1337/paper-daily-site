This lineage differs from earlier tool-learning work in its main variable. Toolformer uses self-supervised API-call insertion to teach when to call tools [Schick2023Toolformer]. Gorilla, ToolLLM, and RestGPT focus on API retrieval, invocation accuracy, and real REST interfaces [Patil2023Gorilla][Qin2023ToolLLM][Song2023RestGPT]. The Tool Learning survey and Augmented LM survey group these as tool-augmented model capabilities [Qin2023ToolLearningSurvey][Mialon2023ALMSurvey]. A coding harness draws a harder engineering boundary: a tool is not a function name in training data; it is an external contract with permissions, state, error codes, and audit logs.
