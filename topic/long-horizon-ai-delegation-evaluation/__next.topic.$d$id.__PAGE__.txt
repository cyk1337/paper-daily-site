三条线不能合成一个分数。pretrain eval 给出底层能力:证据是否被保留、位置是否稳定、多跳依赖是否能聚合。agent eval 给出系统能力:harness、工具权限、状态恢复、验证 oracle 与 human handoff 是否闭合。SWE eval 是公开基准里最接近“Delegation-ready 工作”的一支,因为它有真实 repo 和 patch+test oracle;但它仍主要是边界清晰的单 issue,缺少多 PR、部署、回滚、用户反馈、安全边界与长期维护 [Jimenez2024SWEBench][OpenAI2024SWEBenchVerified][Yang2024SWEAgent][OpenHands2024][SWELive2025]。

Video-Reason/VBVR 提供的是视频推理训练和评测的正常技术背景:VBVR 声称覆盖 200 个任务、1,000,000+ 视频片段、rule-based human-aligned scorers 和早期 OOD 泛化迹象 [VideoReasonHF2026][VBVR2026]。这支持“视频推理评估需要可验证过程”的方向,但不能直接推出“长程 AI Delegation 已经解决”:VBVR 的强项是可控视频推理训练和评测,离真实开放环境中的目标分解、工具调用、失败恢复和人机交接还有一层 agent harness。a:T81d,The central claim is that long-horizon evaluation is not about making the context, video, or software task longer; it is about measuring whether the work is actually delegable. RULER, LongBench, NoCha, BABILong, and SummHay probe pretraining-side evidence use, position robustness, aggregation, and long-document synthesis; Video-MME, LongVideoBench, and VBVR move the same pressure into cross-frame state, causality, and verifiable generation trajectories; SWE-bench, WebArena, OSWorld, GAIA, and tau-bench place the model inside a tool-and-environment loop [RULER2024][LongBench2023][NoCha2024][BABILong2024][SummHay2024][VideoMME2024][LongVideoBench2024][VBVR2026][Jimenez2024SWEBench][WebArena2023][OSWorld2024][GAIA2023][TauBench2024].

These tracks should not be collapsed into one score. Pretraining eval measures substrate capability: whether evidence is retained, whether position is robust, and whether multi-hop dependencies can be aggregated. Agent eval measures system capability: whether the harness, tool permissions, state recovery, verification oracle, and human handoff close the loop. SWE eval is the closest public line to delegated work because it uses real repos and a patch+test oracle, but it still mostly tests well-bounded single issues rather than multi-PR maintenance, deployment, rollback, user feedback, safety boundaries, and long-lived ownership [Jimenez2024SWEBench][OpenAI2024SWEBenchVerified][Yang2024SWEAgent][OpenHands2024][SWELive2025].

Video-Reason/VBVR is useful as technical background for video-reasoning training and evaluation. VBVR reports 200 tasks, more than one million video clips, rule-based human-aligned scorers, and early OOD generalization signals [VideoReasonHF2026][VBVR2026]. That supports the direction that video reasoning needs verifiable processes, but it does not prove long-horizon AI Delegation is solved: VBVR is strongest as controlled video-reasoning training and evaluation infrastructure, while real delegation still requires goal decomposition, tool use, failure recovery, and handoff in open environments.b:T464,SWE-bench has a clear advantage: real repos, real issues, patch outputs, and tests as a hard oracle, which is closer to work delivery than most web or assistant tasks [Jimenez2024SWEBench]. SWE-bench Verified removes part of the ambiguous-issue and weak-test noise so model differences are less hidden by data defects [OpenAI2024SWEBenchVerified]. SWE-agent and OpenHands then show that changing the agent-computer interface, sandbox, and action schema can materially change outcomes for the same base model [Yang2024SWEAgent][OpenHands2024].

The limitation is equally concrete. Real SWE delegation often spans multiple PRs, review feedback, CI flakes, schema migrations, deployment observation, rollback, and user feedback; a single issue patch can reward strategies that merely satisfy tests while under-measuring safety boundaries and long-term maintenance cost [SWELive2025]. The next SWE long-horizon eval should move the work unit from issue to maintenance episode: requirements clarification, implementation, review response, CI repair, migration verification, launch checks, and rollback plan should score together.c:T406,The user's long-horizontal phrasing is best read as cross-stage spread: multiple documents, videos, tools, and decision rounds coexist. In long-document evaluation this decomposes into retrieval hit, multi-hop aggregation, synthesis, delayed dependency, position robustness, and memory update [LostMiddle2023][SummHay2024][NoCha2024][BABILong2024]. In video evaluation the same structure becomes cross-segment event tracking, object persistence, causal explanation, future prediction, and process trajectories [VideoMME2024][LongVideoBench2024][EgoSchema2023][VBVR2026].

This horizontal axis is closer to delegation than merely longer input. Real delegated work rarely asks a system to only read a long document; it combines webpages, code, logs, video, meeting notes, and test results into one decision chain. Evaluation design should log where evidence came from, when it was used, whether the verifier covered it, and whether later actions depended on it.
