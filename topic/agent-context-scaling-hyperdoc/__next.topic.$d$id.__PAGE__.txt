Bottom line: treating long context as a PE/packing problem misses the failure mode that ships—windows are large enough, yet agents still hallucinate. Standard NTP teacher-forcing marginalizes out-of-document variables Z into the prior p(y|S); when evidence is missing, the model fills gaps with that prior. A more actionable reframing is to treat context scaling as offline recovery of the Z cut off by document boundaries, and write it back into the corpus as hyper-doc pretraining (HDP). The objective extends log p(x_{t+1}|x_{1:t}) to log p(x_{t+1}|x_{1:t}, c_t), where c_t is constructed context such as retrieved evidence, recall, tool feedback, or plans. d:T73f,HDP context construction can be split into two complementary pipelines. Evidence Restitching applies when Z is citable/retrievable: hyperlinks, citations, dependency files, API docs, tool-call results. LinkBERT uses linked documents as the pretraining unit, showing that cross-doc organization can systematically inject external dependencies [LinkBERT2022]. RALM improves factuality by concatenating retrieved documents into context, showing that conditioning itself is useful [RALM2023]. Toolformer writes tool outputs back into training samples, giving a synthetic form of environment feedback Z [Toolformer2023]. Intent Inversion applies when Z is not stably retrievable but can be reverse-engineered: noisy web, code snippets, discussion threads, commits/PRs. Rephrasing the Web rewrites web text to make it more consistent, effectively making latent structure explicit so the same patterns are learned with fewer tokens [RephrasingWeb2024]. Instruction Backtranslation and LongForm reverse-instruction perform “output → input” back-translation, writing missing prompts/intents back as a proxy for Z [InstrBacktranslation2023][LongFormReverseInstr2023]. ProX scales doc-level rewriting; the point is not filtering but per-sample rewriting [ProX2024]. Magicoder shows engineering feasibility in code by synthesizing instruction data from OSS snippets [Magicoder2023]. The boundary reduces to an operational question: can the seed doc’s Z be recovered by stable retrieval as citable evidence? If yes, prefer Evidence Restitching; if not, Intent Inversion is closer to reconstructing latent task structure. Both pipelines share the same discipline: loss masking. Evidence C and action tokens are out of loss; plans/solutions are in loss. Otherwise the model treats retrieved evidence as target text to memorize, increasing templating and leakage.e:T61e,The HDP failure mode is letting “add context” degenerate into indiscriminate token inflation: longer C raises training cost and can amplify noise and templates. That assumption often breaks in agent settings: the model may ignore evidence, treat it as decoration, and continue generating from the prior. RALM shows that concatenating retrieved docs into the context improves factuality, but still leaves retrieval behavior to inference time [RALM2023]. HDP instead makes retrieval part of the training distribution: repeatedly expose the model to “retrieve/tool-call → read evidence → generate”, while masking actions and evidence out of the supervision signal [Toolformer2023]. RAG-considerate scaling laws make this a tuning problem: under fixed compute, parametric memorization trades off with external retrieval, so “pretrain then bolt on RAG” may not lie on the same optimum [RAGConsiderateScaling2026]. By contrast, Chinchilla’s compute-optimal token:params ratio is derived under standard NTP without systematic retrieval conditioning [Chinchilla2022]. Once C is introduced systematically, optimal token allocation, repetition strategy, and retriever quality become coupled. A more robust engineering path is two-stage: first use Intent Inversion to normalize/structure the corpus (reduce noise, make plans/prompts explicit), then apply Evidence Restitching retrieval expansion only to high-gap segments—concentrating retrieval cost where evidence is needed, rather than making all training depend on expensive online retrieval.11:T565,A common shortcut in agent training is to collect CoT/self-reflection traces from stronger models and distill them; two negative results should be treated as default risks: output imitation does not imply capability transfer, especially when the supervision is unverifiable explanatory text [FalsePromise2023]; and CoT may fail to transfer reasoning capability in distillation settings [CoTDistillEffectiveness2025].
