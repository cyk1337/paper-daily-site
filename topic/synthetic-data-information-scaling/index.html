合成数据的效用与规模边界

信息增量、学习动力学与递归训练

摘要

合成数据通过教师知识转移、表示重组和验证反馈改善学习，不必增加独立外部事实。改写、书级组织与来源扩张研究支持特定条件下的训练收益；递归研究则区分了平均误差稳定与尾部保留。判断规模价值，需要分开核算生成库存与实际训练 token 数，分别比较学生训练计算和全链路成本，并在留出的大模型上检验排序。现有结果尚不足以给出跨训练阶段通用的合成比例或防坍塌保证。

信息与学习信号

数据干预的收益取决于学生初始化、优化过程、预算和目标分布。在这些条件固定时，可以用可重复的性能变化比较数据效用。同一样本在早期可能有用，在更长训练中则可能冗余。

机制上应区分四件事：独立来源提供事实支持，教师转移学生尚未掌握的知识，表示或监督使已有信息更易学习，以及仅仅生成不同字符串。前三者可以改变学习条件，最后一项本身不证明知识增长。教师可能知道种子材料之外的内容，但知识转移仍需事实核查；推导新结论也不同于取得新观测。

这一分析可作限定性形式化。令 ZZZ 为目标世界变量，SSS 为来源，WWW 为教师权重，VVV 为验证器及其全部固定资源。若输出 YYY 仅由这些输入和给定 S,W,VS,W,VS,W,V 后与 ZZZ 条件独立的随机性产生，且无额外观测，则

I(Z;Y∣S,W,V)=0.I(Z;Y\mid S,W,V)=0.I(Z;Y∣S,W,V)=0.

这不意味着 I(Z;Y)=0I(Z;Y)=0I(Z;Y)=0，也不意味着有限算力学生无法获益。数据库、人工标注或环境返回若带来额外观测 OOO，应计入信息来源。确定性验证则可将已有约束转成接受、拒绝或错误定位信号，无须增加外部事实。这是分析框架，而非文献共同证明的经验定律。

表达转换以 WRAP、BeyondWeb 的来源改写为代表；教材生成包括 Textbooks，以及 Cosmopedia 的来源、受众和体裁组合。[51][2][49][7] SynthLLM 通过概念抽取与图算法重组跨文档联系，但训练阶段和部分训练时域信息仍不清晰。[48] 蒸馏也可直接传递预测分布，无须生成语料文件；经典 MNIST 与声学实验提供机制背景，不是语言模型预训练证据。[13]

内容、组织与监督的对照

机制识别应固定事实比较表达、固定文本比较组织、固定候选池比较选择。BookOrganization 的 Full／Split 固定文本与 token 数，RandomConcat 控制长度；32B-token 中期训练含 Llama3-8B 验证，支持该设置的组织效应，但边界、注意力可见范围与打包仍共同变化。[3]

WRAP 匹配预训练计算而非生成成本；BeyondWeb 的 3B／8B 对照匹配 180B 实际训练 token，不等于匹配 FLOPs。Nemotron-CC 同时改变过滤、改写与独立自然来源，收益不能全归于合成。[51][2][35]

阶段归因同样重要：Textbooks 最终代码成绩包含练习微调，TinyStories 仅展示受限故事分布的可学性；Phi-4 约 400B 未加权合成 token 是库存，超教师 STEM 成绩来自数据、课程与后训练共同变化的系统，不是预训练教师上限检验。[49][50][36]

指令生成、复杂度演化与问题改写主要提供 SFT 证据；正确答案筛选不保证推理逐步正确。[46][52][31][44] DeepSeek-Prover 微调 DeepSeekMath-7B，Lean 验证不保证翻译忠实、题目非平凡或无泄漏，whole-proof 成绩须保留生成次数。[9]

QVAC 的 1.7B 从零训练消融未在摘要中完整披露成本与评估控制，解析成功也不等于语义正确；Practice 的 ImageNet 动态样本结果不能直接推广至语言预训练。[38][37]

来源、重复与规模

扩展独立语料与在固定来源上多采样，是两种不同的数据投资。FixedSource 固定问题池和教师，对 7B、8B 指令学生进行数学与物理 SFT；采用相同 epoch，主要指标是每题八次生成的平均正确率，而非 pass@8。来源扩张对照匹配样本数，未保证匹配 token、拒绝采样成本或学生训练 FLOPs。大预算下新种子更有利，是这些师生与问题分布上的发现，不是从零预训练定律。[14]

经典缩放研究支持模型、数据与计算联合分配，但不同实验得到的最优配置不同，自然数据拟合参数不宜直接移植到合成训练。[45][4] DataConstrained 覆盖最高 9B 模型和 900B 实际训练 token 数，显示重复的边际价值衰减；有限重复实验没有给出普适安全 epoch 阈值。[8]

RewriteScaling 联合研究模型规模、训练量、改写比例和自然数据重复，以小预算拟合、大预算留出检验预测，包含 22B 运行。主要评估是 4096 上下文下 Paloma 宏平均 BPB，以及问答、数学、代码的正确答案 BPB，而非生成准确率。它支持特定实验族的外推和部分指标上的超重写器表现，不建立任意教师、来源或 agent 任务的通用关系。[43]

规模预测因此需要同时保留来源量、学生规模、训练时域、重复数、合成比例和师生差距。小模型排序可能随冗余、优化配置或任务权重改变，但排序反转应直接检验，不能由某项收益不单调推出。比拟合优度更有说服力的证据，是对未参与拟合的规模作出并验证预先预测；预测成功与机制识别仍是不同目标。

递归训练与尾部保留

递归风险取决于数据如何跨代流动。一次蒸馏、以新生成数据替换旧数据、累积历史、保留固定锚点和持续加入独立新数据，应分别比较。尾部丢失、错误放大、模式收缩、固定数据过拟合与基准退步也是不同结果。Collapse 区分早期尾部遗失与后期退化，其语言模型实验涉及微调，不能统一表述为从零预训练结论。[6]

Accumulation 每代重新初始化 9M 至 125M 模型，以 470M-token TinyStories 为原始锚点；该锚点本身由 GPT 模型生成，并非广泛真实人类语料。积累组在相同 epoch 下经历更多训练步骤，另有匹配数据量的替换消融。线性理论在特定假设下证明测试误差有界，并不证明分布信息完整保留。[1]

MAD 主要讨论图像生成质量、多样性、真实数据新鲜度和采样偏置；Accumulation 的 VAE 实验也报告细节多样性下降与误差缓慢增加。[30][1] 两者可以同时成立，因为指标、模型和数据增长制度不同。StatisticalCollapse 的混合上限同样依赖统计假设。[47]

防护应围绕来源独立性与实际曝光展开：保存来源和生成谱系，按来源及语义簇去重，审计少数语言、稀有概念与失败类型的实际训练 token 数。固定真实比例、保存历史文件或通过验证器，都不能自动保证尾部曝光，也不能补足新知识与分布变化。

验证还可能改变难度分布。Llama3 报告过严格模型过滤导致下游退步，说明更高筛选分数未必带来更大学生效用。[28] 同族评分器的一致意见不是独立确认，不同验证器也可能共享漏洞。拟议压力测试应以一次蒸馏为非递归对照，比较替换、积累、固定锚点与持续加入新鲜真实数据，监测真实留出损失、尾部覆盖、错误传播及验证器漏检、错拒，并预设停止与回滚条件。

模型披露中的训练阶段

判断合成数据作用，应比较接收信号的训练阶段，而非产品版本。三组对照最能说明披露边界。

首先，GLM5 仅在 Math & Science 预训练小节排除合成、AI 生成及模板数据，中期训练仍包含合成长上下文与 agent 轨迹，不能把局部排除扩展到全部训练。GLM5.3 与 GLM5.2 共享 base，将收益归于后训练扩展；环境、任务多样性和计算共同变化，尚未隔离环境合成本身的贡献。[18][16][17]

其次，Nemotron3.5 从已有 base 初始化，1T-token 蒸馏衡量监督训练曝光，约 2.83T Indic 生成 token 则是按 Gemma4 分词器统计的库存。Super 的 100B-token 继续预训练包含 10B 自然与合成 Indic 混合及 90B 前序混合，65.4B agent 中期训练另属一阶段。库存、监督曝光与混合语料不能相加为实际合成训练 token 数。[33]

最后，最新模型的一般披露不等于精确预训练配方。Claude Opus5.5 与 Gemini4 Argon 列出合成来源，但阶段、比例、教师及独立贡献仍未知；Claude 的合成用户描述属于评估。[5][23] 模型规模、上下文长度、新发布或任务演示中的反馈循环，也不补足这些信息，更不证明继承旧版本配方。[25][39] 其余模型逐项见独立清单；未披露应保持未知，而非判为未采用。

成本与尺度检验

合成数据须区分等学生训练 FLOPs 的效用与等全链路预算的能力，不能声称一次对照同时严格匹配二者。RewriteScaling 假设生成输入输出长度相近、提示开销小、生成受 FLOPs 约束且不跨学生运行摊销，因此不是生命周期账单；计算节省也不等于墙钟加速。[43]

最直接的拟议检验是冻结 STEM／代码来源，比较自然重复、固定源改写与独立来源扩张，交叉来源数和每源采样数。从零预训练与固定 base 中期训练分开运行，按谱系、模板及时间划分选择集和真实测试集。库存、实际训练 token、来源及近重复曝光分列，并记录生成尝试、接受数和过滤后补足的重复。

在至少三个开发规模或预算上，分别比较等训练 FLOPs 与等全链路成本，控制分词器、上下文、打包、优化器、时域和调参额度。冻结预测形式及迁移规则，再检验留出的大模型和另一家族，与简单预测基线比较；这是拟议设计，不是已有尺度结论。

成本分列教师建设／适配、全部生成、验证、学生训练、存储、传输与服务，报告已有教师下的边际成本及明确复用次数下的摊销成本。FLOPs、GPU 时间、货币和存储不直接相加；MoE 分列总／活跃参数，soft-label 前向与存储不计作生成语料 token。

评估同时覆盖 base 和共享后训练配方，保留真实留出损失、生成、校准及尾部指标；agent 固定工具、访问权、推理预算和框架。n-gram 去污染不能排除释义泄漏，需时间隔离、语义核查与独立新任务。[10] 种子、来源抽样与评估噪声分开分析，同一运行检查点不作独立重复。

结论与开放问题

合成数据的研究价值，在于把已有知识变成更可学习的表示与监督，并在确有外部输入时扩展事实支持。可复用的判断规则是：先用内容匹配辨认干预，再用双预算比较确定代价，最后以留出的大模型、真实尾部及受控后训练决定是否扩量。来源扩张、多采样和验证改进应依据边际收益选择，而非追求通用合成比例。

四个开放问题可将这一判断转成可证伪研究：

  • 来源何时优于多采样？ 固定来源监督饱和后，独立来源能否在全链路等成本下占优？若大尺度留出中多采样持续更好，该假设的适用范围就需收缩；同时检验教师差距、训练时域和合成比例能否预测排序反转。
  • 组织收益能否跨格式迁移？ 匹配内容、长度和训练设置后，若书级组织收益仅限同格式测试，一般长依赖学习解释将受到削弱。
  • 验证改善了监督还是只选出简单题？ 若来源和难度匹配后收益消失，就应重新解释验证器的贡献。
  • 平均稳定能否掩盖尾部退化？ 在固定计算和增长计算两种积累制度下，预注册尾部指标，检验平均损失稳定是否伴随稀有内容遗失。
