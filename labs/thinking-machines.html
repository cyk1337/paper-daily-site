Interaction Models: 200ms micro-turn 如何改写 agent harness

Interaction Models: how 200ms micro-turns redraw the agent harness

这篇的价值不在多模态产品发布,而在把 VAD、前台状态机和后台 worker 调度重新切分:200ms micro-turn 把反馈时机推进模型 forward,前台互动模型持续接住用户和视觉变化,后台模型异步执行工具、搜索和长推理。它给 coding-agent harness 的启发是连续时间治理:tool scheduling、context accounting 与 safety refusal 都不能只在 turn 结束时决策。

The value is not the multimodal launch surface, but a new split of VAD, foreground state machine, and background worker dispatch. 200ms micro-turns move feedback timing into the model forward pass; the foreground model keeps absorbing user and visual changes, while the background model runs tools, search, and long reasoning asynchronously. For coding-agent harnesses, the lesson is continuous-time governance for tool scheduling, context accounting, and safety refusal.

On-Policy Distillation: RL 搜策略,OPD 压策略

On-Policy Distillation: RL searches strategies, OPD compresses them

这篇不只是说明 OPD 比 RL 省算力,而是给 post-training 一个更清楚的分工:RL 或强 teacher 搜索 semantic strategies,OPD 用 student 自己采样的轨迹和 dense reverse-KL 把 final policy 压回小模型参数。对 agent 个性化和长期记忆更关键的是行为锚点:midtrain 注入新知识后,旧 policy 或 teacher policy 可以恢复 instruction following、tool-use 和拒绝边界。

The point is not merely that OPD can be cheaper than RL, but a cleaner division of labor for post-training: RL or a strong teacher searches semantic strategies, while OPD uses student-sampled trajectories and dense reverse-KL to compress the final policy into a smaller model. For agent personalization and long-term memory, the key is a behavior anchor: after midtraining adds new knowledge, an old or teacher policy can restore instruction following, tool use, and refusal boundaries.

LoRA Without Regret: 小模型更新的容量账

LoRA Without Regret: the capacity ledger for small-model updates

这篇把 LoRA 从“便宜但有损”的经验印象拉回容量与训练配方问题:低秩更新是否够用,取决于 rank、batch、数据量、任务支持集和监督密度。它和 OPD 构成一条线:LoRA/Tinker 负责低成本写参数,OPD 负责用 dense teacher signal 写行为,两者都在回答小模型如何可靠获得专长。

This post reframes LoRA from a cheap-but-lossy trick into a capacity and recipe question: whether low-rank updates suffice depends on rank, batch, data volume, task support, and supervision density. It connects directly to OPD: LoRA/Tinker gives a low-cost way to write parameters, while OPD writes behavior with dense teacher signal; both ask how small models reliably acquire expertise.

Modular Manifolds: 模块化不是任意拼装

Modular Manifolds: modularity is not arbitrary composition

这篇更偏机制直觉:模型中的模块化能力不能只看局部组件,还要看表示流形如何让组件可组合、可移动、可复用。放在 TM 线索里,它给 LoRA 与 OPD 的背后问题提供几何语言:低成本更新为什么有时能对齐一块行为,有时却破坏已有能力,关键在更新方向是否落在可组合的表示区域。

This is more mechanistic: modular capability should not be read only from local components, but from how representation manifolds make components composable, movable, and reusable. In the TM line, it gives geometric language to the question behind LoRA and OPD: low-cost updates sometimes align a behavior and sometimes damage existing capability depending on whether the update direction lies in a composable representation region.

Defeating Nondeterminism: 可复现 serving 是训练与互动的地基

Defeating Nondeterminism: reproducible serving as training and interaction infrastructure

这篇把 nondeterminism 从“同 seed 为什么不同”的现象,推进到 batch-invariant kernels、通信路径和 accumulation order 的系统工程问题。它和 Interaction Models 直接相连:当模型每 200ms 接收输入、输出语音、调工具并合并后台结果时,数值分叉会表现成不同打断时机或安全边界,因此 bitwise alignment 变成行为归因工具。

This post moves nondeterminism from the surface question of why same-seed runs differ into systems issues: batch-invariant kernels, communication paths, and accumulation order. It connects directly to Interaction Models: when a model receives input, speaks, calls tools, and merges background results every 200ms, numerical divergence can appear as different interruption timing or safety boundaries, so bitwise alignment becomes a tool for behavioral attribution.
