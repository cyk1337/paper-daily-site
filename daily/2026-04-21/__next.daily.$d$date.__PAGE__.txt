除了结构约束，作者还处理了两个训练层面的尖点来源。第一，对输入条件 e 做归一化，缓解训练后期的 loss spikes。这里可以理解为 recurrent unit 在不同 loop depth 下反复接收同一个条件信号，如果其尺度漂移，容易在深循环时放大不稳定模式。第二，训练目标需要对随机深度的期望损失做优化。已有做法常在 batch 级别采样统一深度，导致梯度方差和深度切换带来的不连续更明显。Parcae 改成 intra-batch per-sequence depth sampling，让同一 batch 内不同样本走不同 loop 次数，从而平滑优化过程，也更接近“对深度分布求期望”的目标。

The model is written as a middle-looped architecture with a prelude module, a recurrent middle block, and a coda module. The recurrent update over the residual stream is cast as a nonlinear time-varying dynamical system. After linearization, the update reduces to a linear time-invariant system, which makes classical stability analysis available. The key empirical observation is that prior looped architectures can learn unstable injection operators with large spectral norms, leading to residual explosion.

Parcae addresses this by parameterizing the continuous-time state matrix A and discretizing it in a controlled way, while constraining A to be a negative diagonal matrix. This gives the recurrent update an inherently contractive character and prevents the hidden state from blowing up across loop iterations. The design is deliberately conservative: a diagonal stable parameterization gives up some flexibility relative to a full matrix, but it is simple, cheap, and robust enough for large-scale Transformer training.

The paper also identifies two practical sources of loss spikes. First, the conditioning signal e is repeatedly injected across loop steps, so scale drift in e can destabilize deep recurrence. Parcae adds normalization on e to mitigate this. Second, the training objective optimizes expected loss over variable depths. Prior recipes often sample one depth per batch, which creates higher variance and sharper optimization discontinuities. Parcae instead uses intra-batch per-sequence depth sampling, so different sequences in the same batch use different loop counts. This better matches the expectation-over-depth objective and empirically smooths training.

A further strength of the paper is that it connects training-time and inference-time scaling. Under isoFLOP training, it studies how compute should be split between more data and more looping. At test time, it studies how additional loop iterations reduce loss, finding an exponential-decay form with an irreducible floor. The result is a unified view in which recurrence learned during training can be exploited at inference, but with predictable diminishing returns.10:T98d,The experiments cover stability, end-to-end quality, training-FLOP scaling, and test-time scaling.

On stability, the paper shows that earlier looped recipes indeed suffer from residual explosion and loss spikes, and links this behavior to the learned spectral properties of the injection operator. Table 2 is central here: unstable models learn more dangerous parameterizations, while Parcae’s constrained form suppresses that failure mode. An important practical point is that prior looped models often relied on sensitive hyperparameters and normalization choices such as Post-Norm just to converge; Parcae moves much of the stability burden into the parameterization itself.

On end-to-end quality, Parcae is compared against parameter- and data-matched RDMs and standard Transformers. Relative to RDMs, it reduces validation perplexity by 6.3%. For training-FLOP scaling, the paper runs parameter-matched isoFLOP studies and asks whether extra compute should go into more data or more loop depth. The answer is that looping behaves like an additional scaling axis. FLOP-optimal training increases both data and looping according to empirical power laws. The implication is not that looping dominates data, but that under a fixed parameter budget, the compute-optimal solution is not exhausted by “just add more tokens.”

For test-time scaling, increasing the number of loop iterations yields predictable loss improvements that follow an exponential decay toward an irreducible floor. That is especially relevant for adaptive inference and per-request compute allocation.

Still, the experimental pattern is clear enough: the benefit comes from changing the target optimum through task reward, not from the shared RL training loop itself.14:T7de,The paper first gives a unified view of several group-wise preference objectives. For each prompt group, responses are split into positive and negative sets, and each response receives an implicit preference score defined in the DPO style as a scaled log-likelihood ratio between the policy and a reference model. Different group-wise methods mainly differ in how they aggregate or contrast these scores across the positive and negative sets, but they all share the same computational issue: the loss depends jointly on multiple responses from the same prompt, so gradients are coupled across samples.

The main technical contribution is a memory-efficient surrogate implementation. The idea is not to change the optimization target, but to change how gradients are computed. The method first performs an extra lightweight no-gradient pass to compute per-sample gradient coefficients implied by the group objective. It then rewrites training as a sample-level token loss whose first-order gradients match those of the original group-coupled objective. In other words, the surrogate is gradient-equivalent at first order, even if it is not numerically the same scalar loss.

This matters because the expensive part of naive group-wise training is not the score computation itself, but the need to keep all group members in one joint computation graph. By moving the coupling into coefficient computation and then doing ordinary per-sample backpropagation, the method removes most of the group-size-dependent activation overhead. The paper also compares several representative group-wise objectives under the same framework in both offline and online alignment settings.

A second important finding is that adding an NLL term on positive responses is often necessary to stabilize group-wise training. Intuitively, pure relative preference optimization can push the policy too aggressively, while positive-response NLL anchors the model to directly model good responses rather than only separating them from bad ones.15:T5f0,The experimental story has three parts. Third, the proposed surrogate substantially reduces peak memory while keeping training latency competitive, which makes larger response groups practical.

A strong point in the experimental design is that the paper does not present only one new objective. The abstract does not expose many exact benchmark numbers, but the full paper emphasizes that naive group-coupled backprop scales poorly in memory with group size, whereas the surrogate’s memory overhead is largely insensitive to group size. The model applies the forward edit to obtain t, then applies the inverse edit to reconstruct ŝ. If the model both follows instructions and avoids unintended changes, ŝ should match s. This turns long-horizon reliability into a measurable degradation curve: reconstruction quality after 2, 4, ..., 20 interactions. That is the key move that makes cumulative corruption visible.
