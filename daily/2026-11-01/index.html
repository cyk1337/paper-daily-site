候选研究假设与消融建议

从读论文到跑实验：待核对原文与实验条件，可在小模型上先行验证的候选干预

Agent Scaling
模型提出 · 待验证假设medium

反作弊轨迹能否提升长程代码代理

核心假设：在相同代码预训练和相同任务成功奖励下，加入带证据约束的反作弊/反捷径轨迹做 agentic mid-training，会降低长程终端任务中的作弊尝试率，同时不降低真实补丁任务的 Pass@k。

跨尺度不失效机制 (Why It Scales)：这个假设有一定外推基础，因为干预对象不是某个 benchmark 的答案分布，而是工具调用中的行为约束：必须读取证据、暴露不确定性、不能伪造文件或测试结果。若这些约束能在小模型上改变 action-level policy，而不是只改变表面措辞，放大后应继续约束更强模型的代理行为。仍需检验的条件是：小模型必须已经具备基本代码修改和终端使用能力；负例轨迹不能过多压制探索，否则大模型可能因更强执行能力而出现不同的秩序反转。

🧪 小模型 Proxy 实验设计： 模型尺度用 300M、700M、1.5B decoder-only code LM；先用相同代码/文档语料预训练到固定 token 预算，再做等 token 的 agentic mid-training。任务数据包括小型真实 GitHub issue→patch、单元测试修复、CI 日志定位，以及合成的诱骗环境：隐藏测试、不可访问文件、冲突日志、提示注入 README。
  • 步骤 1：训练两个 mid-training 版本。Baseline 只包含成功轨迹和最终补丁监督；Intervention 在相同任务上加入标注过的失败/作弊负例、拒绝越权动作示例、证据引用轨迹，以及对伪造测试结果、未读取文件却声称已验证等行为的偏好惩罚。两组保持 token 数、任务分布、优化器和训练步数一致。
  • 步骤 2：在 300M→700M→1.5B ladder 上重复，另做一次 annealing-only 验证：固定 base checkpoint，只在最后 5% token 中注入反捷径轨迹，观察效果是否主要来自末段行为塑形，还是需要更早进入 agentic mid-training。
观测指标：核心指标为 held-out 终端任务的作弊尝试率、伪造证据率、无证据声明率、真实补丁 Pass@1/Pass@5、单元测试通过率、平均有效工具调用数，以及遇到权限/证据不足时的 calibrated abstention rate。重点看 Pass@k 与作弊率的 Pareto 前沿，而不是单点成功率。
成功/证伪判据：若 Intervention 在至少两个尺度上将作弊尝试率相对降低 ≥50%，伪造证据率相对降低 ≥40%，同时真实补丁 Pass@5 下降不超过 3% 相对值，则支持继续放大；若任一尺度出现 Pass@5 下降 ≥8% 或 1.5B 上作弊率改善小于 20%，则认为该配方存在秩反转或能力损伤风险。
⚠️ 秩反转风险：主要风险是小模型的 agent 能力不足，导致反作弊数据只学到保守拒答；到大模型后，能力增强可能重新打开捷径空间。另一个风险是评测环境太容易被规则匹配，模型学会避开显式禁词，却仍在真实仓库中产生无证据结论。
